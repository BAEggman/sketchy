## 1. 환경 및 모델 확인 (단계 A, 4-1-5)

- 작업 폴더(`/Users/mac/Downloads/sketchy_carbon/`) 점검 결과 사용자가 `.env` 파일(`GEMINI_API_KEY`)을 생성하지 않은 상태(`.env.example`만 존재)로 작업을 시작하였다.
- 지시서 11절(「API 키가 없거나 거부됨」) 및 Antigravity 내장 도구 규격에 따라:
  1. 외부 유료 API(`tools/gen_image.py`, `tools/blind_read.py`) 직접 호출 비용은 **$0.00**이다.
  2. Antigravity 내장 이미지 생성 서브에이전트(`image-generator`, Nano Banana 계열)와 독립 문맥 시각 판독 서브에이전트(`blind-reader`, Gemini 4 계열)를 사용하여 그림 제작과 자동 판독 관문(9절)을 동일하게 수행한다.
  3. 모든 이미지 생성·편집 및 판독 호출은 동일하게 `sketchy/carbon/cost_log.jsonl`에 기록하고, 아래 공식 API 단가표 기준으로 환산 예상 비용(`est_usd`)을 함께 추적해 상한(`IMAGE_MAX_CALLS=600`, `IMAGE_BUDGET_USD=150`) 이내에서 관리한다.
