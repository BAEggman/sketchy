# 과 열쇠: hist-01b
- **주제**: 의학사 (hist-01b)
- **장소**: 한옥 별채와 진달래 마당 (漢 = 한옥 · 晉 = 진달래)

## 공용 부호표
1. **숫자 물건 열 개 (아래 받침 = 앞자리, 위 얹힘/손에 쥠 = 뒷자리)**:
   - 0 = 공룡 · 1 = 일렉기타 · 2 = 이층 버스 · 3 = 삼지창 · 4 = 사과 · 5 = 오징어 · 6 = 육각 너트 · 7 = 칠면조 · 8 = 팔레트 · 9 = 구미호
2. **왕조 터 표지 (발밑/배경)**:
   - 漢 = 한옥 · 晉 = 진달래 · 梁 = 목줄 맨 흰 양 · 隋 = 수국 · 唐 = 사탕 · 北宋 = 문 위 솔가지 / 南宋 = 문턱 아래 솔가지 · 金 = 금광 · 元 = 원두막 · 明 = 붉은 등불 · 淸 = 맑은 유리
3. **의의 · 책 · 공용 인물**:
   - 금메달 = 최초 / 현존 최고 · 붉은 리본·밀랍 봉인 = 관찬 · 쪽지 책 = 주석 · 처방 쪽지 = 방서
   - 담요 두른 환자 = 傷寒 · 외과 메스 = 외과·수술 · 손목 짚기 = 맥진(寸關尺·獨取寸口)
   - 소리·뜻 고리: 사물의 뜻이나 첫·연속 음절이 인물·호·서명을 가리킴(정중앙 자리·경치 병풍·꽃·덩굴·통나무·팔꿈치 뒤 주머니 등)
