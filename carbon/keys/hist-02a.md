# 과 열쇠: hist-02a
- **제목**: 南北朝 — 本草와 製藥
- **장소**: 강가 도자기 공방 마당 (왼쪽 물레 · 가운데 화덕 · 오른쪽 약장)

## 공용 부호표
1. **숫자 물건 열 개 (아래 받침 = 앞자리, 위 얹힘/손에 쥠 = 뒷자리, 백의 자리는 어귀 큰 물건)**:
   - 0 = 공룡(티라노) · 1 = 일렉기타 · 2 = 이층 버스 · 3 = 삼지창 · 4 = 사과 · 5 = 오징어 · 6 = 육각 너트 · 7 = 칠면조 · 8 = 팔레트 · 9 = 구미호
   - 통짜 수: 사계절 바퀴(봄꽃·여름해·가을단풍·겨울눈) = 365
2. **왕조 터 표지 (인물 발밑이나 걸상에 맞닿음)**:
   - 漢 = 한옥 · 晉 = 진달래 · 梁 = 목줄 맨 흰 양(방석 없음) · 隋 = 수국 · 唐 = 사탕 · 北宋 = 문 위 솔가지 / 南宋 = 문턱 아래 솔가지 · 金 = 금광 · 元 = 원두막 · 明 = 붉은 등불 · 淸 = 맑은 유리
3. **의의 · 책 종류**:
   - 금메달(물건에 매닮) = 최초 / 현존 최고
   - 붉은 리본·밀랍 봉인 = 관찬(나라가 엮은 책) · 쪽지 빼곡한 책 = 주석 · 처방 쪽지 = 方書 · 노래하는 사람 = 歌賦
4. **주요 공용/소리 상징**:
   - 풀잎 망토 농부 신 = 神農 · 흰 가운 의원 = 名醫 · 담요 두른 환자 = 傷寒
   - 소리 고리: 사물 이름의 첫 음절 또는 연속 음절이 한자 독음(인명·서명·왕조)을 나타냄 (예: 도공=陶, 홍학+안경=弘景, 별=別, 집 모양 주전자=集注, 천둥신=雷公, 서랍장=徐).
