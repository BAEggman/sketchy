# 과 열쇠: hist-02b
- **주제**: 의학사 (hist-02b)
- **장소**: 수국 정원 서숙 (梁 = 목줄 맨 흰 양 · 隋 = 보라색 수국)

## 공용 부호표
1. **숫자 물건 열 개 (아래 받침 = 앞자리, 위 얹힘 = 뒷자리)**:
   - 0 = 공룡 · 1 = 일렉기타 · 2 = 이층 버스 · 3 = 삼지창 · 4 = 사과 · 5 = 오징어 · 6 = 육각 너트 · 7 = 칠면조 · 8 = 팔레트 · 9 = 구미호
2. **왕조 터 표지 (발밑/걸상 맞닿음)**:
   - 漢 = 한옥 · 晉 = 진달래 · 梁 = 목줄 맨 흰 양(방석 없음) · 隋 = 수국 · 唐 = 사탕 · 北宋 = 문 위 솔가지 / 南宋 = 문턱 아래 솔가지 · 金 = 금광 · 元 = 원두막 · 明 = 붉은 등불 · 淸 = 맑은 유리
3. **의의 · 책 · 공용 표지**:
   - 금메달 = 최초 / 현존 최고 · 붉은 리본·밀랍 봉인 = 관찬 · 쪽지 빼곡한 책 = 주석 · 처방 쪽지 = 방서 · 외과 메스 = 외과·수술
   - 소리·뜻 고리 원칙: 사물·동작이 인명·서명의 독음·뜻을 가리킴(도깨비=鬼, 남긴 쪽지=遺方, 줄자·전원 기립·새 둥지·무늬 다른 알·버드나무 꼭대기 크고 흰 갈래 천 등)
