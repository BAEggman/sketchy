# 과 열쇠: hist-05a
- **주제**: 의학사 (hist-05a)
- **장소**: 소나무 약초 계단밭 아랫단 (宋 = 푸른 솔가지)

## 공용 부호표
1. **숫자 물건 열 개 (아래 받침 = 앞자리, 위 얹힘/손에 쥠 = 뒷자리)**:
   - 0 = 공룡 · 1 = 일렉기타 · 2 = 이층 버스 · 3 = 삼지창 · 4 = 사과 · 5 = 오징어 · 6 = 육각 너트 · 7 = 칠면조 · 8 = 팔레트 · 9 = 구미호
2. **왕조 터 표지 (발밑/머리 위 맞닿음)**:
   - 漢 한옥 · 晉 진달래 · 梁 목줄 맨 흰 양 · 隋 수국 · 唐 사탕 · 北宋 문 위 솔가지 / 南宋 문턱 아래 솔가지 · 金 금광 · 元 원두막 · 明 붉은 등불 · 淸 맑은 유리
   - ★주의: 발밑 터(솔가지=宋)가 왕조이며, 손에 든 사물(사탕 등)은 성씨·별칭 소리 고리일 수 있음.
3. **의의 · 책 · 공용 표지**:
   - 금메달 = 최초 / 현존 최고 · 붉은 리본·밀랍 봉인 = 관찬(나라가 엮은 책) · 쪽지 빼곡한 책 = 주석 · 처방 쪽지 = 방서
   - 소리·뜻 고리 원칙:
     - 열린 보물 상자(개보 開寶) · 손바닥 무늬 옷(성씨 掌) + 가위로 쪽지 보태기(가우·보주) · 약초 그림책(도경 圖經) · 돋보기(신미 愼微) · 글+그림 합친 큰 책(집대성)
     - 큰 망원경(대관 大觀) + 교정 렌치(교정) + 어좌/정치 도장 찍은 관찬 교정본(정화)
     - 삿갓(구 寇) 쓰고 돌판(석 奭) 쥔 인물 · 물줄기 넘쳐 흐르는 두루마리(연의 衍義) · 자기 장부 문패(심장·간 등) 달린 오두막으로 보따리 메고 걸어 돌아가는 약초(제 경락·장부로 돌아감 = 약물귀경)
