3. 의의 · 책 종류 · 공용 기호
- 금메달(물건에 매달림): 교재·문제집의 「최초」·「現存 最古」
- 붉은 리본과 밀랍 봉인: 나라가 엮은 책(官修·勅撰)
- 쪽지가 빼곡히 꽂힌 책: 주석서(註解)
- 처방 쪽지: 方書 / 두루마리를 노래하는 사람: 歌賦 / 점 찍힌 인체 괘도: 明堂圖·圖經 / 끈으로 묶은 뭉치: 集
- 풀잎 망토 농부 신: 神農 / 담요 두른 환자: 傷寒 / 금 거울: 金鏡·金鑑
- 성씨·글자 공용: 도공=陶, 천둥신(북 고리)=雷公, 서랍 약장=徐, 버드나무=楊, 자두=李, 오리=吳, 구명튜브=濟, 회중시계=時

4. 오장·경락 인물 정본
