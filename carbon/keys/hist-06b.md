# 과 열쇠: hist-06b
- **제목**: 金·元 ② 傷寒 주해와 舌診
- **장소**: 금광 성문(왼쪽)과 고개 너머 원두막 거울터(오른쪽)

## 공용 부호표
1. **숫자 물건 열 개 (아래/큰 것 = 앞자리, 위/꿴 것 = 뒷자리)**:
   - 0 = 공룡 · 1 = 일렉기타 · 2 = 이층 버스 · 3 = 삼지창 · 4 = 사과 · 5 = 오징어 · 6 = 육각 너트 · 7 = 칠면조 · 8 = 팔레트 · 9 = 구미호
   - 통짜 수: 사계절 바퀴 = 365
2. **왕조 터 표지 (인물 발밑이나 구조물에 맞닿음)**:
   - 漢 = 한옥 · 晉 = 진달래 · 梁 = 목줄 맨 흰 양 · 隋 = 수국 · 唐 = 사탕 · 北宋 = 문 위 솔가지 / 南宋 = 문턱 아래 솔가지 · 金 = 황금 광석 금광 · 元 = 초가 원두막 · 明 = 붉은 등불 · 淸 = 맑은 유리
3. **의의 · 책 종류**:
   - 금메달(물건에 매닮) = 최초 / 현존 최고
   - 쪽지 빼곡한 책/담요 = 주석(註解) · 처방 쪽지 = 方書 · 담요 두른 환자 = 傷寒 · 금 거울 = 金鏡/金鑑
4. **소리·뜻 고리**:
   - 성문+무기 = 成無己 · 두더지(杜)+나무 뿌리(本) = 杜本 · 반 갈라 씨가 보이는 오이(오이씨) = 敖氏.
