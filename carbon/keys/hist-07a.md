# 과 열쇠: hist-07a
- **제목**: 침구 의학사 혈 수 계보 (세 단 비탈길)
- **장소**: 굴(穴) 마을의 세 단 비탈길 (어귀 → 아랫단 → 가운뎃단 세 굴 → 윗단)

## 공용 부호표
1. **숫자 물건 열 개**:
   - 백의 자리: 마을 어귀의 큰 물건이 전체 백의 자리를 짐
   - 십의 자리: 각 단(아랫단 · 가운뎃단 · 윗단)의 바닥/덕장/받침 사물이 십의 자리를 짐
   - 일의 자리: 각 인물 곁이나 머리 위·발치에 맞닿은 물건이 일의 자리를 짐
   - 0 = 공룡 · 1 = 일렉기타 · 2 = 이층 버스 · 3 = 삼지창 · 4 = 사과 · 5 = 오징어 · 6 = 육각 너트 · 7 = 칠면조 · 8 = 팔레트 · 9 = 구미호
2. **왕조 터 표지 (굴 문간·인물 발에 맞닿음)**:
   - 漢 = 한옥 · 晉 = 진달래 꽃떨기 · 梁 = 목줄 맨 흰 양 · 隋 = 수국 · 唐 = 사탕 · 北宋 = 문 위쪽 솔가지 / 南宋 = 문턱 아래쪽 솔가지 · 金 = 금광 · 元 = 원두막 · 明 = 붉은 등불 · 淸 = 맑은 유리문
3. **의의 · 책 종류 · 공용 상징**:
   - 금메달 = 최초 / 현존 최고 · 붉은 리본·밀랍 봉인 = 나라가 엮은 책(칙찬)
   - 갑옷 입은 새+밀 이삭 = 皇甫謐 『鍼灸甲乙經』 · 점 박힌 구리 사람 = 王惟一 銅人 · 엄지에 자 대고 재기 = 王執中 同身寸 『鍼灸資生經』 · 섬의 버드나무+침 부채 = 楊繼洲 『鍼灸大成』 · 구명튜브(濟)+회중시계(時) = 濟時 · 오리(吳)+절하는 사람(謙)+금 거울 = 吳謙 『醫宗金鑑』.
