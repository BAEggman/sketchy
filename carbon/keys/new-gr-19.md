# 과 열쇠: new-gr-19
- **제목**: 舍岩鍼法 ① 手太陰肺經 (正格 · 勝格 · 寒格 · 熱格)
- **장소**: 바위에 기댄 초가 1번 방 (왼쪽 正格 3단 찬장 · 가운데 경락 인물 · 오른쪽 勝格 3단 찬장 · 맨 오른쪽 화로와 물통)

## 공용 부호표
1. **12경락 인물 정본**:
   - 肺 = 흰 도포 흰 수염 노인 · 大腸 = 관 청소솔 흰 작업복 · 胃 = 국자 노란 요리사 · 脾 = 노란 옷 농부 · 心 = 금관 붉은 용포 임금 · 小腸 = 체 붉은 앞치마 · 膀胱 = 물지게 검은 옷 · 腎 = 검은 옷 대머리 장사 · 心包 = 칼·방패 붉은 갑옷 호위무사 · 三焦 = 삽 주황 옷 · 膽 = 저울 초록 판관 · 肝 = 초록 갑옷 장군
2. **舍岩 찬장 · 대장간 부호**:
   - 왼쪽 3단 찬장 = 正格(위 칸 母 채움 = 補母, 가운데 칸 官 쏟음 = 瀉官)
   - 오른쪽 3단 찬장 = 勝格(가운데 칸 官 채움 = 補官, 아래 칸 子 쏟음 = 瀉子)
   - 물이 가득 찬 독 = 補 · 엎어져 쏟아진 독 = 瀉 · 뚜껑 덮인 독 = 쓰지 않음
   - 눈 창 아래 불 키운 화로 + 물 퍼내는 물통 = 寒格(補火瀉水)
   - 해 창 아래 물 붓는 물통 + 흙 퍼내는 흙더미 = 熱格(補水瀉土)
3. **혈명 사물 고리**:
   - 눈 덮인 흰 산봉우리 = 太白(태백산) · 깊은 돌 우물 = 太淵 · 작은 붉은 관청 = 少府 · 물고기 배 가장자리 = 魚際 · 자(尺)가 꽂힌 연못(澤) = 尺澤 · 초승달 그늘 골짜기 = 陰谷 · 벼락 모양 패 = 偏歷.
