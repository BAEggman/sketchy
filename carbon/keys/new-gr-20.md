2. **舍岩 찬장 · 대장간 · 主客原絡 부호**:
   - 왼쪽 3단 찬장 = 正格(위 칸 母 채움 = 補母, 가운데 칸 官 쏟음 = 瀉官)
   - 오른쪽 3단 찬장 = 勝格(가운데 칸 官 채움 = 補官, 아래 칸 子 쏟음 = 瀉子)
   - 물이 가득 찬 독 = 補 · 엎어져 쏟아진 독 = 瀉 · 뚜껑 덮인 독 = 쓰지 않음
   - 눈 창 아래 풀무·화로 + 물 퍼내는 물통 = 寒格(補火瀉水)
   - 해 창 아래 물 붓는 물통 + 흙/숯불 퍼내는 수레 = 熱格(補水瀉土/火)
   - **인물 곁 主客原絡 패**: 둥근 황금 인장 테두리 패 = 主(본경 原穴) · 붉은 번개 표지 패 = 客(표리경 絡穴) · 허리 붉은 번개 꼬리표 = 본경 絡穴
