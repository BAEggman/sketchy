# 과 열쇠: new-gr-34
- **주제**: 경락·사암 (new-gr-34)
- **장소**: 암벽 협곡 아랫단 틈새 (郄 = 틈 극, 위층 틈 셋 · 아래층 틈 둘)

## 공용 부호표
1. **12경락 인물 정본**:
   - 肺(手太陰) = 흰 도포 흰 수염 노인
   - 大腸(手陽明) = 관 청소솔 든 흰 작업복 일꾼
   - 胃(足陽明) = 국자 든 노란 앞치마 요리사
   - 脾(足太陰) = 밀짚모자 노란 옷 농부
   - 心(手少陰) = 작은 금관 쓴 붉은 용포 임금
   - 小腸(手太陽) = 체 든 붉은 앞치마 일꾼
   - 膀胱(足太陽) = 물지게 진 검은 옷 일꾼
   - 腎(足少陰) = 검은 옷 대머리 장사
   - 心包(手厥陰) = 칼·방패 든 붉은 갑옷 호위무사
   - 三焦(手少陽) = 삽 멘 주황 옷 일꾼
   - 膽(足少陽) = 저울 든 초록 관복 판관
   - 肝(足厥陰) = 초록 갑옷 장군
2. **郄穴 및 혈명 뜻·기경 표지**:
   - 깊게 갈라진 바위 틈 = 郄穴(기혈이 깊이 모이는 틈)
   - 나무 들보(梁) 다리가 놓인 언덕(丘) = 梁丘
   - 땅(地) 위에 놓인 베틀(機) = 地機
   - 번쩍이는 황금(金) 대문(門) = 金門
   - 바위에서 맑은 물(水)이 솟는 샘(泉) = 水泉
   - 바깥쪽(外)에 솟은 언덕(丘) = 外丘
   - 한가운데(中) 세운 도읍 성루(都) = 中都
   - 발등(跗) 위 해(陽) 문양 장대 + 높인 발목 장화(陽蹻) = 陽蹻脈 跗陽
   - 달(陰) 문양 장대 아래 편지 주고받음(交信) = 陰蹻脈 交信
   - 해 배지 금빛 그물(維) 교차 매듭(交) = 陽維脈 陽交
   - 다진(築) 돌축대 위 귀한 손님(賓) 맞이 = 陰維脈 築賓
