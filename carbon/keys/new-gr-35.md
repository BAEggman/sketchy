# 과 열쇠: new-gr-35
- **주제**: 경락·사암 (new-gr-35)
- **장소**: 열두 띠 해시계 광장 (위 줄 좌·중·우 3구역 = 자오유주 12시진, 아래 왼쪽 = 맥장 4막대, 아래 오른쪽 = 기혈다소 3탁자)

## 공용 부호표
1. **숫자 물건 열 개**:
   - 0 = 공룡 · 1 = 일렉기타 · 2 = 이층 버스 · 3 = 삼지창 · 4 = 사과 · 5 = 오징어 · 6 = 육각 너트 · 7 = 칠면조 · 8 = 팔레트 · 9 = 구미호
2. **12경락 인물 정본**:
   - 肺(手太陰) = 흰 도포 흰 수염 노인
   - 大腸(手陽明) = 관 청소솔 든 흰 작업복 일꾼
   - 胃(足陽明) = 국자 든 노란 앞치마 요리사
   - 脾(足太陰) = 밀짚모자 노란 옷 농부
   - 心(手少陰) = 작은 금관 쓴 붉은 용포 임금
   - 小腸(手太陽) = 체 든 붉은 앞치마 일꾼
   - 膀胱(足太陽) = 물지게 진 검은 옷 일꾼
   - 腎(足少陰) = 검은 옷 대머리 장사
   - 心包(手厥陰) = 칼·방패 든 붉은 갑옷 호위무사
   - 三焦(手少陽) = 삽 멘 주황 옷 일꾼
   - 膽(足少陽) = 저울 든 초록 관복 판관
   - 肝(足厥陰) = 초록 갑옷 장군
3. **자오유주·맥장·기혈다소 공용 기호**:
   - 12지 띠 짐승 차례: 子(쥐, 23~1시) → 丑(소, 1~3시) → 寅(호랑이, 3~5시) → 卯(토끼, 5~7시) → 辰(용, 7~9시) → 巳(뱀, 9~11시) → 午(말, 11~13시) → 未(양, 13~15시) → 申(원숭이, 15~17시) → 酉(닭, 17~19시) → 戌(개, 19~21시) → 亥(돼지, 21~23시)
   - 손(手) 모양 / 발(足) 모양 + 달(陰) / 해(陽) 표지 + 눈금 자(尺) = 手足 음양 삼음삼양 맥장
   - 부풀린 구름·풀무 바람 = 氣(많음/적음) · 붉은 물동이/물방울 = 血(많음/적음)
