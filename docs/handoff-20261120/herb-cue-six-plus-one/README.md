# 본초 단서 재설계 인계 묶음

읽는 순서: final.md → scores-table.md → selected.json 또는 CSV → judge.md → 필요 시 원본6안 비교.

- 최종 사용 기준은 selected.json이다. 각 행 decision=hold는 완성 그림 제작 보류다. revise는 개선 설계의 시험 후보이며 사람의 회상시험 통과가 아니다. keep도 이번에 실제 회상률을 측정했다는 뜻이 아니다.
- proposals/01..06.md 및 json은 서로의 안을 보지 않고 작성한 여섯 원본이다. 제안자의 판정과 최종 심사자의 판정이 다를 수 있다. 원본의 확신 문구를 최종 승인으로 읽지 않는다.
- source.md는 사용자가 준 Gemini 대화·원안이며, 잘못된 이름·관계·수량 주장도 대조용으로 원형 보존했다.
- dictionary.json은 원문148표 기계추출본. name의 원문 표기와 display_name의 교정표기를 구분한다. 白礬은 백반, 斑蝥는 이번 교재 표적 반묘로 관리한다.
- scene-inventory.json은 이후43분류장면의 대상 묶음 감사. 동의어·복수대상·오기를 정규화한 본초종수표가 아니다. 사전 밖의 본초까지 모두 새로 설계했다는 뜻이 아니다.
- 그림·음성·사이트를 이번 작업에서 생성하거나 배포하지 않았다. 다음 작업은 선택된 단서의 낮은 비용 시안과 실제 회수시험이다. 실패안은 다시 설계하고 완성본으로 게시하지 않는다.
