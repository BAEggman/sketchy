# 모든 제안에 공통으로 적용할 원자료 확인

회수 기준 보충: Sketchy처럼 최초 설명으로 그림↔이름 연결을 한 번 배우는 것은 허용한다. 처음 보는 그림에서 한의학 용어를 무학습으로 맞혀야 한다는 조건이 아니다. 다만 설명 제거 후 그림이 단서가 되어 정확명으로 도착해야 한다. 냉독시험은 '사물이 무엇으로 보이는가', 학습후시험은 '정확 본초명으로 회수되는가'로 구분한다. 全元起→전원 기립, 薛己→백설기처럼 긴 일반어구 안의 연속된 목표음절이 남는 것은 허용. 모든 음절을 한자훈으로 1:1 바꾸도록 강요하지 않는다. 대안의 단점은 표시하되 근접음이라는 이유만으로 좋은 상호작용 장면을 전부 폐기하지 않는다.

root가 사용자 DOCX D01,D02,D03,D34 네 파일을 실제 재추출했다. evidence/D01.txt 등. 과거 추출과 현재 SHA256 동일.

- D34 포제 암기시트 및 D01은 白礬=백반, 斑蝥=반묘. 따라서 사전 백번은 백반으로 교정, 반모는 표준/교재 시험명 반묘를 주표적으로 설정하며 원문 표기는 alias로 기록. https://www.nifds.go.kr/nhmi/download.do?flgrpNo=745&sn=1 제목 반묘(斑猫), 기원 식물 아닌 곤충 南方大斑蝥 표기 확인.
- D01,D02 보음약은 楮實子=저실자. 분류 이야기 횡실자는 일치하지 않음.
- D03 사용자 자료는 槐角을 실제 淸熱瀉火 표에 포함하고 白礬을 수삽표에 포함한다. 통용 분류와 다르다고 무조건 원안오류로 덮어쓰지 말 것. 교재별 분류 메타데이터로 관리하고 확정 전 분류복 영구고정 금지.
- D03은 七情 相畏 예시 人參畏五靈脂 및 十九畏에도 같은쌍을 적고, D01도 +십구외라고 적는다. 원자료 혼용 자체를 기록해야 하며 Gemini만의 오류라고 단정하지 말 것. 교재의 시험상짝은 보존하되 실제 그림에서 '오령지가 인삼 독성을 해독'으로 단정하지 않음. 十九畏와七情相畏 뜻구별 공공근거: https://www.jining.gov.cn/art/2015/7/17/art_319_63.html 21줄. 인삼을 독약캐릭터로 바꾸지 말 것.
- 원 사전148행은 실제148개. 분류장면 괄호추출 275개 등은 별명/동의어/방제명이 섞인 '추가 표기' 수이지 정규화된 추가 본초 종수 아님.
- 秦皮/陳皮는 한글이 같아도 다른 본초. source.md 분류 청열해독 진피와 이기 진피 통합 금지.
