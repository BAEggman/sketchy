읽는 순서: final-plan.md → judge.md → proposals/01.md~06.md.
원안은 제7 심사 전 독립 제안이므로 탈락 후보도 들어 있다. 최종 실행안·심사의 판정이 우선한다.
현재 사이트를 수정한 결과물이 아니라 구현 계획이다. 실제 기준 HEAD·미게시 Gemini 작업은 시작할 때 재확인한다.

- current-sample/: 직접 확인한 배포 그림6장과 관련JSON7과,227과목록. 수정본 아님.
- evidence/source-manifest.json: 선택 교재의 실제 로컬 경로·해시·검토상태. PDF는 존재확인/미독이다.
- evidence/current-observations.md: 진행 중 공통 관찰기록. 후속 정정과 final-plan.md의 정확한 판정을 우선한다.
- original-checksums.json: 동결된 원안6개의SHA-256. 다른제안이나최종안으로원안을덮어쓰지않는다.

사이트 변경·생성·검수 진행 기록을 별도STATE.json에 남겨 중단 뒤 재개할 수 있게 한다.
