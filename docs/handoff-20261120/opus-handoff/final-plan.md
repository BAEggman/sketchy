# 한의학 Sketchy 재설계 — Opus 실행 계획

작성일 2026-11-20 · 계획 및 표본 감사 · 사이트 수정·이미지 생성·배포는 이번 작업에서 수행하지 않음.

## 1. 최종 목표와 우선 결정

목표는 인물이나 소품을 알아보는 데서 끝나지 않고 **정확한 이름·저서·행위·기여·의의를 시험장에서 복원하는 것**이다. 그림 수를 늘리는 것을 성과로 세지 않는다. 교재 범위를 사실 단위로 관리하고, 그 사실에 맞는 그림·유주도·표 복원·두문자·원문 인출을 선택한다.

실행 우선순위는 ① 정답과 출처 충돌 정리 ② 실제 교재 목차와 전체 자산 연결 ③ 허브 네 기능 ④ 대표 실패 사례의 제작 방식 검증 ⑤ 전 단원 감사·수정 ⑥ 회귀검사·완료 보고다. 기능 개발과 원자료 감사는 병행할 수 있지만 미확정 사실로 그림을 대량 생성해서는 안 된다.

- **의학사**: 이름 단서를 유지하면서 저서와 편찬 행위를 연결한다. 인물·字/號·활동 시대/국가·저서·기여·의의를 각각 독립적으로 검사한다.
- **경락·奇經**: 정확한 신체 경로를 먼저 만들고 기존 유주 암기문장을 해당 위치에 연결한다. 이름을 그린 그림과 유주를 가르치는 그림을 동일시하지 않는다.
- **사암**: 12개의 방 그림은 보관하고 선택 복습으로 남긴다. 주학습은 五輸 혈명표, 생극 원리, 검증된 처방표, 전체 빈 표의 지연 인출로 바꾼다.
- **본초·포제**: 약재의 고유 단서 사전, 두문자/리듬 문장, 포제법별 대상 집합을 결합한다. 큰 장면에 약재 전부를 억지로 몰아넣지 않는다.
- **허브**: 교재 순서와 추천 선행 순서를 별도로 관리하되 같은 안정 ID의 그림을 연결한다. 왼쪽 썸네일·오른쪽 별표·다음 그림 자동 넘김·구간/전체 반복을 제공한다.
- **제작 심사**: 여섯 독립 후보→별도 일곱 번째 심사→통합 설계→실제 생성 결과 검사. 기획 점수와 사람의 기억 성과는 별개다.

## 4. 먼저 해결할 사실 충돌

1. **醫宗金鑑360 / 鍼灸逢源361**: 최신 JSON은 前者361을 ‘교재·기출 기준 확정’이라고 적는다. 경락 요약 DOCX도 오겸 아래 두 저서를 합쳐 놓았다. 이 문구는 근거가 아니다. 교과서 원본 표·문제집 정답·의학사 원전/연구를 대조해 저서별 편자·판본·혈명 수·양측 포함 총혈수의 집계 기준을 따로 기록한다. 349·354·359·359·360·361로 표현할 경우 두359가 서로 다른 저서라는 사실을 유지한다. 354/355 변이 역시 같은 항목인지 확인한다.
2. **陽蹻 風府/風池**: 현재 new-gr-14는 申脈→風府를 쓴다. 심사자가 확인한 사용자 경락 DOCX의 관련 줄은 ‘풍지風府GV16’으로 한글 이름과 한자·코드가 내부에서부터 불일치한다. 검색한 『脈經』 전사와 『奇經八脈考』 관련 원문은 風池를 지지한다. 따라서 DOCX를 무오류 정답으로 삼거나 風府를 무비판 보존하지 않는다. 원본 스캔의 해당 줄과 경유·교회·종결을 대조한 후 해당 문항·대본·도해를 함께 교정한다.
3. **王冰 주석과 宋代 교정 판본**: 王冰762, 次注, 重廣補註 명칭, 林億 등의 新校正 층위를 한 저자 한 행위로 뭉개지 않는다. 교재의 명칭 사용을 유지하되 판본 관계를 주석으로 분리한다.
4. **杜本·敖氏**: 원전의 기존12舌에24圖를 더하는 관계를 근거로, 원저자·증보자·후대 간행자를 구별한다. ‘현존 최초 舌診 전문서’ 같은 의의는 ‘최초’의 범위와 한정어까지 저장한다.
5. **사암 大腸 陽谿/解谿와 熱格 예외**: 이전 감사의 알려진 오류를 전체 표의 회귀 항목으로 둔다. 한열보사를 모두 단일 식으로 자동 생성하지 않는다. 현재 mer-12 제목의 일반화와 각 경 열격 자료가 일치하는지도 확인한다.
6. **한자 원문과 독음**: 十問歌 婦人/婦女, 六經提綱, 葉天士 네 치법, 脈·증상 목록의 생략을 원문·독음·현대어 필드에서 검수한다. 대본을 짧게 했다는 이유로 정답을 줄이지 않는다.

충돌 항목은 범위에서 삭제하지 않는다. 정답 상태를 `source_conflict`로 남겨 제작과 자동 출제를 차단하고 해결 근거를 기록한다. 다른 학습 항목과 허브 작업은 계속 진행한다.

## 5. 교과서 목차·그림 위계·선행 순서

기본서 원본의 `장→절→항`을 기본 목차로 사용하고 총강 목차로 전환할 수 있게 한다. 같은 그림을 여러 단원에서 참조해도 자산은 하나다. 각 행에는 왼쪽 현재 그림 썸네일, 제목과 그림 링크, 필요한 선행 그림, 오른쪽 별표가 들어간다. 교재 순서·추천 학습 순서·별표 모음은 서로 다른 보기다.

학습 선행관계는 따로 저장한다. 예: 공용 소품 사전→五行生剋→陰陽經 五輸 배속→60혈 이름표→사암 正勝 원리→寒熱 및 예외→전체 빈 표. 경락은 신체 위치 용어→走向·交接→개별 경로→교회·연결→病候로 이어진다. 의학사는 공용 인물·책 상징→원전→주석·증보·간행 계보→유사 저서 구별 순서다. 순환 의존, 없는 선행 ID, 과도한 선행조건을 검사하고 강제 학습 잠금은 두지 않는다.

| person/book | 이름과 字/號/別名의 종류, 출생지와 활동국가, 원저·편찬·주석·증보·교정·간행을 구별한 관계 |
| cue | 고유 cue_id, 목표의 전체 독음, 물체/행동, 소리·뜻 연결, 충돌목록, 최초 학습 설명, 기존 사용자 승인 여부 |
| asset | 안정 scene_id/asset_id, 그림·크롭·썸네일·대본·오디오 버전/해시, 부모장면, 실제 파일, 이전판, 보존/수정/보류 |
| coverage | fact_id×표현매체, 실제 보이는 좌표, 대본 위치, 인출문항, 직접 검사자/방법, 판정과 실패 이유 |

| learning | 정답표 버전, 사용자 응답·오류종류·마지막 회상·다음 학습, 별표/재생설정과 분리 |

사실이 문자열 한 칸에 여러 개 있으면 분리한다. `王冰·唐·762·啓玄子·素問 주석`을 단서 하나를 맞혔다고 모두 맞힌 것으로 세지 않는다. `any()`로 묶음 전체를 통과시키거나 요약문·프롬프트를 실제 그림 증거로 인정하지 않는다.

최신 그림이 실패해도 이전 합격본과 그 아이디어·대본은 삭제하지 않는다. 한 파일에서 일부를 회수할 수 있도록 **아이디어 판정과 그림 판정**을 분리한다. 기존 URL, 학습기록, 별표는 안정 ID와 명시적 이전표로 유지한다. 자동 추정으로 인물/저서를 다른 항목에 붙이지 않는다.

## 7. 의학사 장면의 제작 명세

모든 의가에 같은 사실 양식을 적용하되 한 그림에 전부 넣으라는 뜻은 아니다. 교재가 요구하는 사실을 정확히 저장한 뒤 ① 이름 고정점 ② 시대 위치 ③ 고유 서명 표식 ④ 직접 하는 작업 ⑤ 결과와 의의로 연결한다. 핵심 장면이 복잡해지면 같은 배경의 확대·단계 보기를 쓰고, 서로 무관한 삽화를 액자로 덧붙이지 않는다.

**도홍경**: 현재 도공·홍학/안경·흰 양을 우선 보존한다. 붉은 본경 계열과 검은 별록 계열이 도공의 작업대로 들어오고 도공이 원문을 보존하면서 합편·주석한 완성본을 내놓게 한다. 작은 농부 인형만으로 『神農本草經』, 별 하나만으로 『名醫別錄』이 되었다고 통과시키지 않는다. 집주전자는 ‘集注’의 보조로 쓸 수 있지만 완성 저서와 떨어진 장식물로 두지 않는다. 『本草經集注』·『肘後百一方』·『養性延命錄』 등 교재 요구 서명은 각각 담당 관계를 지정한다. 한 장면이 모두 감당하지 못하면 설명·정확답·역방향 문항으로 명확히 연결하고 그림만으로 전부 표현했다고 보고하지 않는다.

**왕빙**: 현재 얼음 위 왕관과 검은 구슬 상자는 유지 후보다. 열쇠가 잠금장치에 꽂히고 왕빙의 손이 실제 여는 모습을 만든다. 이는 啓·玄의 의미 단서이며 완전한 발음 연상은 아니므로, 첫 학습 후 ‘啓玄子’ 정확 복원을 검사한다. 子를 아기로 추가해 독립 인물로 보이게 하지 않는다. 素問의 고정 표식과 주석·보입 행위를 별도로 붙인다. 왕도 망대와 왕빙 얼음, 저서 『外臺秘要』와 『素問』이 바뀌는지도 역질문한다.

**두본**: 원두막·두더지/뿌리, 오이씨·금거울·혀를 우선 유지한다. 이미 있던 도해 묶음에 두본이 새 묶음을 덧붙이는 행동을 명시한다. 12+24=36은 정확한 보조표와 회상문항으로 확인하며 생성기가 혀36개를 정확히 그리도록 기대하지 않는다. ‘두 본의 책’으로 인물 cue를 바꾸는 안은 책 수 오독과 기존학습 변경 비용 때문에 우선 채택하지 않는다. 金鏡만 맞히고 敖氏傷寒金鏡錄을 못 쓰면 서명 문항은 부분 실패다.

**다른 의가 전체**: 徐之才·全元起·楊上善·劉涓子 등 사용자가 기억하는 이름 단서는 동결 보존 후보로 삼는다. 저서·시대·기여가 붙어 있는지 별도 검사하고, 관행적인 저자 표기와 전승·후대 편찬을 구별한다. 의의는 금메달 하나로 끝내지 않는다. 최초의 범주가 설진인지 포제인지 임상서인지 해당 도구·행동으로 구별돼야 한다.

## 8. 숫자·혈수 기억

사용자의 기존 peg와 현재 Carbon의 숫자 사전은 서로 다르다. 새 안을 고를 때마다 다른 숫자 사전을 도입하면 기억 간섭이 생긴다. 현재 사전은 3삼지창·4사과·5오징어·6육각너트·9구미호·1일렉기타 등을 쓴다. 이미 학습한 정도를 확인하고 한 사전만 고정한다. 변경이 필요하면 전체 사용처 목록과 전환표를 함께 수정한다.

혈수는 ‘동굴 번지’와 먼 공용 배경을 조합하게 하지 않는다. **저서의 고유 표식 바로 옆에 왼쪽→오른쪽의 세 자리 물체를 하나의 행동 묶음으로 붙인다.** 예컨대 검증된359라면 삼지창–오징어–구미호를 그 책의 소유자가 붙잡는 하나의 순서로 표현한다. 여러 나무가 뒤섞인 배경을 세게 하지 않는다. 360의0과361의1은 같은 장소에서 대비해 마지막 자리 차이가 눈에 띄어야 한다.

검사는 ‘그림→정확한 세 자리’, ‘숫자→인물·저서’, ‘저서→숫자’, ‘359인 두 저서 구분’, ‘360과361 저서 교환 오답 수정’으로 나눈다. 정답 숫자와 한자를 HTML 학습표에 표시하는 것은 허용한다. 그림 속 불필요한 글자를 줄이라는 요청을 정확한 표·정답까지 없애라는 뜻으로 확대하지 않는다.

## 9. 奇經과 경락 전체의 유주

사용자 DOCX의 유주 스토리는 새로 발명하기 전에 회수한다. ‘신맥의 원숭이’, ‘기충 열차’, ‘축빈 손님’ 같은 단서는 문장 원문·혈명·독음·경맥·해부 위치를 연결한 뒤 보존한다. 잘못된 혈 코드나 동음 혈명 표기는 정정 주석을 남긴다.

한 신체 기준도에 경로별 층을 두고, 필요할 때 한 경로씩 보인다. 시작·진행 방향·안팎/전후·분지·교회·종결을 표시하고 그 위치에 스토리 소품을 붙인다. 經脈 유주, 經穴 배열, 병후, 八脈交會穴은 서로 다른 항목이다. 묘사상 기점과 연결 경맥의 시작을 혼동하지 않는다. 표준화가 필요한 경로선·혈위 위치는 코드/SVG 등 결정적으로 그리는 도구로 작성하고 생성 그림은 정확한 좌표의 근거로 사용하지 않는다.

시험은 경로를 따라 읽기→일부 빈칸→그림 없는 순서 회상→백지 신체에 경로 그리기→기능/병후와 연결 순으로 만든다. ‘帶=허리띠, 維=그물, 蹻=죽마’를 기억하는 것만으로 유주 합격 처리하지 않는다. 양쪽 해부 좌우와 보는 사람 기준 좌우도 검사한다.

감사 범위는 十二經脈, 十二經別, 經筋, 皮部, 十五絡, 奇經八脈, 標本根結氣街四海, 五輸·原絡郄募背兪·下合·八會·八脈交會, 骨度分寸·刺法·病候 등 실제 교재 항목으로 확정한다. 이름이 목차에 있다는 이유로 세부 문장이 커버됐다고 세지 않는다.

## 10. 사암침법 전체표 학습

정답표는 경맥·正格/勝格/寒格/熱格·補/瀉·자경/타경·혈명·한자·코드·출전으로 저장한다. 통상 각격四穴 체계라면 12경×4격×4혈=192개의 **처방 내 자리**가 된다. 이는192개의 서로 다른 혈이라는 뜻이 아니다. 실제 표의 이설·예외에 맞춰 확정하며 자경허실보사와 주객원락은 별도 표로 추가한다. ‘사암허실’의 범위를 정승격과 임의로 동일시하지 않는다.

| 단계 | 학습 과제 | 다음 단계로 갈 근거 |
|---|---|---|
| 1 | 陰陽經 五輸五行, 十二經의 五輸穴60개(12×5) 이름을 정확히 연결 | 한자·경맥·오행을 혼동하지 않고 답함 |
| 2 | 검증된 표에서 補母瀉官·補官瀉子의 관계를 풀기 | 원리 설명과 실제 혈명이 동시에 맞음 |
| 3 | 기존 사용자 문장의 혈명 청크를 회수 | 문장이 정확한 전체혈명으로 복원되고 보사가 바뀌지 않음 |
| 4 | 한 쌍→한 행→한 경의 네 격을 빈칸 작성 | 누락·추가·補瀉 반전·비슷한 혈명 오답을 구별해 교정 |
| 5 | 寒熱과 표의 예외, 혼동 경맥을 섞어 시험 | 규칙으로 추정한 값과 정답표가 다르면 출전으로 바로잡음 |
| 6 | 전체 빈 표, 무작위 셀, 혈명→처방 역질문 | 행의 순서를 외운 것과 혈명을 아는 것을 구별 |
| 7 | 시간 간격 후 다시 전체표 복원 | 직후 정답과 지연 정답을 별도 기록 |

한 쌍의 補혈을 답할 때 순서가 평가대상이 아니면 같은 두 혈의 순서를 바꾼 답은 허용한다. 자경/타경 칸이 따로 있는 문제라면 위치까지 맞춰야 한다. 교재가 요구하는 한자와 공인 이체자·독음 허용 범위도 정답표에 명시한다.

처음에는 설명·예시를 충분히 보이고 점차 단서를 줄인다. 익숙해진 뒤 正勝/寒熱을 섞고, 오답이 난 혈명만 기존 그림·음성문장으로 돌아간다. 반복 시청을 정답 기록으로 바꾸지 않는다. 복습 간격은 실제 지연 성과에 따라 조절하고 ‘이 일정이면 전부 암기된다’고 보장하지 않는다. 五行은 계산·검산을 돕지만 출처별 예외를 덮는 자동 정답 생성기가 아니다.

## 11. 본초·포제의 두문자 이미지화

단계는 **정확 대상목록→동음충돌 해결→전체약명 단서→두문자 문장→포제 동작→집합 인출**이다. 약재를 앞글자 하나에만 묶지 않는다. 유향/유황, 천궁/천련자/천오/천산갑, 반하/박하처럼 충돌하는 이름은 두세 음절·대표 사물·고유 행동으로 구별한다. 같은 약재는 다른 포제법과 처방에서도 같은 기본 모습으로 유지하되 목적·보료·상태를 바꾼다.

사용자 암기시트에서 확인한 醋炙 목록은 유향·몰약·현호색 / 삼릉·아출 / 시호·향부자·청피 / 대극·감수·원화·상륙이다. 사용자가 제시한 ‘유몰삼아시향청현 감대원상’과 같은 집합인지 확인하고, 순서 차이는 가사 순서와 분류 순서를 별도로 기록한다. 이 12개가 모든 교재의 모든 醋法 대상이라는 뜻은 아니다. 醋炙·醋炒·醋煮 등 명칭과 조건은 교재에 맞춘다.

유령→유향처럼 첫 음절만 맞고 유황과도 통하는 그림은 실패 후보다. ‘몰래’는 행동이지만 몰약 전체가 나오지 않으면 부족하다. 약명별 후보를 여러 개 낸 뒤 실제 한국어로 짧게 말할 수 있는 것을 고른다. 하나의 포제 작업장 안에서 고정 순서의 작은 사건을 만들되, 시큼한 냄새처럼 보이지 않는 감각만으로 약재나 법을 구분하지 않는다.

첫 복습에서는 순서대로 전체명을 말하고, 이후 임의 위치에서 이어 말하기·그림 없이 대상약 전부 쓰기·다른 포제법의 약재 섞인 목록에서 오류 찾기·한 약재의 여러 포제법/목적 구별을 한다. 노래의 앞부분이 없으면 뒤를 못 떠올리는 연쇄 실패도 검사한다. 사전의 전체약명과 정확명단을 고정하기 전 기존 가사를 정답 원장으로 채택하지 않는다. Suno 음원은 접근·청취한 뒤 가사를 전사해서 대조한다.

## 12. 허브 기능의 확정 동작

**현재 코드의 출발점**: `src/lessons/build_player.py`는 ID 사전순으로 정렬한다. `player.js`에는 시험기록 저장/내보내기, 음성속도·음성 켜기 설정이 이미 있다. `S.auto`는 과 내부 정거장의 자동이동이다. 사용자 요청의 다음 그림/과 자동넘김과 별개다. TTS의 `done(false)`를 정상 청취처럼 처리하고 안전 타이머도 다음 정거장으로 넘기는 부분을 고친다.

| 기능 | 사용자 동작 | 데이터·예외·검수 |
|---|---|---|
| 왼쪽 썸네일 | 교재 목차를 훑으며 현재 그림을 보고 눌러 이동 | 실제 현재버전 축소본, 지연로딩, 비율 보존, 잘림으로 핵심단서 제거 금지, 링크실패 표시 |
| 오른쪽 별표 | 클릭/키보드로 켜고 끄기, 별표만 보기 | scene_id로 저장, 다시 열기/교재보기 변경에도 유지, 저장불가 알림, 내보내기/가져오기, 구ID변환 |
| 다음 그림 자동 넘김 | 기본 끔, 켜면 현재 과의 마지막 정거장 완료 후 다음 과 | 정거장 자동진행 설정과 분리. 음성 정상 종료 또는 무음 체류시간 후 실행. 수동이동/끄기/탭전환은 타이머 취소 |
| 반복 | 끔/전체/구간 중 하나, 구간 시작·끝 그림 선택 | 확정된 현재 재생목록을 기준으로 ID 저장. 전체 끝→처음, 구간 끝→시작. 자동넘김이 꺼졌으면 종료에서 기다림 |

재생목록은 시작 시 교재/추천순서/필터가 적용된 scene_id 배열로 고정한다. 중간에 별표나 검색조건이 바뀌었다고 재생순서를 몰래 바꾸지 않는다. ‘새 목록 적용’ 때 일시정지하고 현재 항목과 반복 구간을 다시 계산한다. A→B 구간은 현재 순서에서 A가 B보다 앞이어야 한다. 한 그림만 고른 구간은 그 그림 반복으로 허용한다. 반복 범위에서 빠진 ID가 생기면 반복을 해제하고 이유를 보여 준다.

음성/그림 오류 시 멈추고 재시도·명시적 건너뛰기를 제공한다. ‘실패→자동완료’ 처리는 금지한다. 음성이 없는 그림은 조절 가능한 체류시간을 사용하되 로딩 완료 전에는 시간을 세지 않는다. 브라우저가 자동 소리를 막으면 사용자 재생 버튼을 기다린다. 오래된 종료 이벤트가 새 그림을 넘기지 못하게 재생 세대 토큰과 이벤트 해제를 사용한다. 종료 콜백과 타이머가 동시에 발생해도 이동은 한 번뿐이다.

퀴즈 중에는 답을 쓰기 전에 자동 이동하지 않는다. 마지막 그림에서 반복 끔이면 정지하고, 자동넘김 끔이면 반복설정이 있어도 자연 종료로 움직이지 않는다. 사용자가 ‘다음’을 누르는 경우의 구간 끝 래핑은 반복설정에 따른다는 점을 UI 설명에 명시한다. 페이지 재접속 시 설정은 복원하되 소리/재생을 자동 시작하지 않는다. 배경 탭에서는 기본 일시정지하고 재개 버튼을 제공한다.

현재 그림이 새 구간 밖이거나 새 목록에서 사라지면 일시정지 상태에서 새 시작 항목을 보여 준다. 빈 목록은 재생 불가로 표시한다. 수동 다음·이전 뒤에는 재생 중이었으면 이어 재생하고 일시정지 중이었으면 정지를 유지한다. 무음 일시정지는 남은 체류시간을 보존하며, 다른 그림으로 수동 이동하면 새 체류시간으로 시작한다. 오프라인 HTML이 열린다는 것과 별표 저장이 보장된다는 것은 별개다. file://의 브라우저별 저장 동작을 검사하고 저장이 막히면 메모리상 사용과 명시적 내보내기·복원을 제공한다.

## 13. 여섯 독립안·일곱 번째 심사 운영

이번 문서의 부록에는 실제 작성된 원안01~06을 수정 없이 수록한다. 별도 심사자의 채점과 채택/보류 판단은 별도 파일이다. 공통 원자료와 오류목록만 여섯 작성자에게 제공했으며 작성자 간 원안 공유는 하지 않았다. 최종 동결 뒤 일곱 번째가 여섯 안을 비교한다.

후속 제작은 장면 하나마다 인물을 새로 발명하는 방식이 아니라 **같은 목표 사실 묶음**을 여섯 명에게 동시에 준다. 각 제안은 물체/행동→자연스러운 한국어→목표의 정확한 독음/개념→관계→정답, 대안·버린 이유, 다른 단서와 충돌, 실제 화면에서 보일 위치, 역회상 문제를 포함한다. 모델/사고수준은 실제 확인 가능한 설정만 기록한다.

공통100점: 사실·출처20, 단서 회상가능성25, 인물·저서·행위 관계15, 교재 범위·선행순서15, 학습부담·그림수10, 구현·검수10, 근거·한계5. 이 값은 계획 비교를 위한 운영 기준이다. 개인 단서에는 회상가능성의 세부항목으로 발음 자연성·사물식별·중간 변환수·변별성·역회상을 적는다.

평가자는 전원기/전원기립의 친숙한 행동과 소리, 편작/납작까치의 자세와 식별, 설기/백설기의 정확한 음절 포함을 기준으로 삼는다. 의미만 그럴듯한데 이름이 안 나오는 안, 고유명사를 맞히려면 여러 번 번역해야 하는 안, 서명 일부만 맞히는 안은 구분한다. 새 단서가 설명 없이 처음부터 정답을 맞혀야 한다는 기준은 쓰지 않는다. **그림 판독 검사**와 **설명을 배운 뒤 지연 회상 검사**를 별도로 한다.

필수 사실 오류, 핵심 소품 부재, 저자 바꿔치기, 해부/유주 왜곡, 같은 핵심소품의 충돌은 총점과 관계없이 낙제다. 합성할 때 가장 높은 소품을 전부 넣지 말고 최소구성으로 고른다. 합성 후 혼잡·연결·사전 충돌을 다시 심사한다. 기획 통과와 실제 생성 통과는 별개다. 사람의 시험 결과 없이 ‘97% 회상 검증 완료’ 같은 말을 쓰지 않는다.

## 14. 전수 감사와 생성 실패 처리

각 사실에서 원문→완전한 정답→그림의 실제 위치→크롭→썸네일→대본→오디오→문항을 대조한다. 매체별로 `검사됨/미검사/없음/오류/보류`를 남긴다. 이미지 파일이 열리는 것과 의미가 맞는 것은 별도 검사다. 모델이 볼 때 정답표·대본을 함께 주었으면 순수 그림 판독으로 기록하지 않는다.

전체 분모는 ① 교재별 범위 항목 ② 중복 제거한 사실 ③ 그림을 사용하기로 한 사실 ④ 현재 자산이다. 모든 내용을 그림으로 표현할 의무는 없지만, 어떤 매체로 회상하도록 했는지는 모든 사실에 있어야 한다. 보류·미검토·원문미확인을 분모에서 빼고 커버율을 올리지 않는다. 새로 발견된 교재내용은 새 사실로 추가하고 변경 이력을 남긴다.

실패 결과는 게시본을 덮지 않는다. 원인에 따라 구도·물체·행동·사실 수를 수정해 다시 시도하고, 같은 실패가 반복되면 장면 설계 단계로 돌아간다. 재시도 횟수와 달라진 점을 남긴다. 품질이 끝내 확보되지 않으면 마지막 합격본을 유지하거나 ‘그림 미완료’로 표시하고 정확한 표/설명만 제공한다. 실패한 그림을 완성품처럼 올리지 않는다.

필수 회귀 사례: 心 임금 익선관/왕관 및 舌·汗 혼입, 脾의 대머리·딸기 혼입, 肝火 옆구리와 타인 발 크롭, 腎陽虛/腎陰虛 전경·크롭 불일치, 十問歌 頭身의 몸 누락·화풍 불일치, 氣分 현대군복, 婦人/婦女 인용, 枳實 색, 燥屎 식품 오독, 上熱下寒의 전신불, 喜按 악수/피얼룩, 廉泉 등 혈명 표기, 淸營湯·犀角地黃湯 약물, 사암 陽谿/解谿, 이전그림보기·파일경로. 각 항목을 해당 최신판에서 재확인하며 과거 오류가 현재도 있다고 미리 단정하지 않는다.

> P0~P4를 끝까지 진행하고 각단계 후 재개기록을 남겨라. 부분 완료를 전체완료로 보고하지 마라. 정확답의 원문·한자·독음·필수대비를 요약하다 지우지 마라. 현재판에서 실제로 확인한 것과 사람회상 미검증을 구별하라. 이 문서의 새 cue도 실제 생성·검수 전 후보이며 맹목적으로 채택할 정답은 아니다.
