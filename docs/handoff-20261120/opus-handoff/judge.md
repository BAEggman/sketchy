# 제7 평가자의 심사와 종합 결정

심사일: 2026-11-20. 대상: 동결된 독립 원안 `01.md`~`06.md` 전부. 이 문서는 구현·그림 생성·배포를 하지 않은 설계 심사다. 원안은 수정하지 않았다.

가장 적합한 방향은 **사실·관계를 먼저 확정하고, 기억하기 좋은 기존 단서는 보존하며, 그림·공간 도해·빈 표 인출을 자료 성격에 맞게 결합하는 것**이다. 한 안을 통째로 선택하지 않는다. 03안의 학습 구조를 중심으로 01안의 사실 원장, 02안의 한국어 행동 검토, 04안의 유주 구조, 05안의 허브·재생 설계, 06안의 실물 검수 절차를 합친다. 아래에서 탈락시킨 소품은 좋은 다른 부분과 함께 다시 섞어 넣지 않는다.

## 심사 범위와 판단의 한계

심사자는 여섯 원안 전체, 공통 근거, 최신 JSON 7과와 아래 실물 6장, 관련 플레이어 코드를 확인했다. 원문 D18 경락 DOCX의 수혈수·유주 표, D34 포제 암기시트의 醋炙 목록도 직접 확인했다. 최신 227과 전체의 그림·음성·교재를 전수 심사했다는 뜻은 아니다.

- 기준본: BAEggman/sketchy `v7.0-carbon`, main SHA `539bab2a87625459874739246d0c5d8ca931d257`, 2026-11-18, 메타데이터상 227과.
- 직접 본 최신 그림: `hist-02a`, `hist-03b`, `hist-06b`, `hist-07a`, `new-gr-14`, `new-gr-19`.
- 읽은 JSON: 위 여섯 과와 `new-gr-30`. 마지막 과의 실물은 이번 심사에서 보지 않았다.
- 코드: `build_player.py`의 ID 정렬, `player.js`의 저장·정거장 자동 이동·TTS 종료 및 오류 처리.
- 이전 감사는 반드시 회귀검사로 계승하지만, 이전 판의 결함이 최신 판에도 존재한다고 자동 판정하지 않는다.

**아래 점수는 모델의 설계 판단이며, 사람의 회상 성공률·검증된 효과 크기·그림 구현 성공률이 아니다.** 한두 점 차이에 통계적 의미를 부여하지 않는다. 전체 계획의 높은 점수로 개별 후보의 오류를 상쇄할 수도 없다. 종합안에도 별도의 혼잡·충돌·실물 검사를 적용하며, 종합했다는 이유로 100점이나 완성을 선언하지 않는다.

공통 조사에서 기본서 후보 폴더가 16장까지 보였으나 9·13~16장 폴더에 현재 분할 파일이 없는 상태다. 다른 위치의 『한의학개론.pdf』와 『한의학총강.pdf』는 발견되었고 아직 목차·해당 본문을 완전히 읽지 않았다. 따라서 일부 원안의 ‘기본서 12장 체계’는 실행 기준으로 고정하지 않는다. 그렇다고 ‘원문 자체가 없다’거나 ‘16장 목차 확정’으로 고쳐 쓰는 것도 부정확하다. 상태는 **분할 DOCX 없음 / 원본 PDF 위치 확인 / 목차·본문 대조 대기**로 나눈다.

### 01안 — 관계 원장을 채택하되 새 암호 사전의 증식을 막는다

**강점:** 의가 이름만 맞는 것을 성공으로 보지 않고 저서·편찬 역할·시대·의의를 분리한다. 짧은 음성 설명 때문에 정답의 원문과 감별 사실이 삭제되지 않게 하는 방향이 좋다. 교재 사실→장면→양방향 문답의 추적도 명료하다.

**감점 근거:** 신규 숫자 사물과 소부의 작은 부채 같은 후보는 기존 사전에 비해 자연스럽다고 입증되지 않았다. 새 숫자 5=오리 등의 안은 다른 숫자의 오리와 충돌할 수 있다. 목록의 묶음과 순서를 새로 만들 때 사용자가 이미 익힌 노래의 이점도 잃을 수 있다. UI 요구는 충족하지만 늦게 도착한 음성 종료·오류·목록 변경의 처리까지 확정되지는 않았다.

**채택:** 원자 사실과 관계 원장, 정확한 답과 짧은 안내 대본의 분리, 기존 杜本 유지, 王冰 본인에게 귀속한 열기 동작. **탈락/보류:** 독자 숫자 사전의 즉시 도입, 작은 부채→少府의 즉시 채택. 이 후보는 단순히 ‘재미있다’는 이유로 생성하지 않는다.

### 02안 — 말로 자연스럽게 읽히는 장면과 서지 관계를 채택한다

**강점:** 보이는 행동을 일상 한국어로 부른 뒤 목표 독음까지 이어지는지 가장 구체적으로 묻는다. 著·註·輯·補·刊을 다르게 다루고, 劉涓子와 정리자의 역할, 楊上善의 분류 재편을 단순 합본과 구별한다. 최신 정정에서 현재 숫자 사전을 먼저 활용하도록 개선했다.

**감점 근거:** ‘명의별록=별+록 기타’, ‘두 권을 든 두 본’, 큰 흰 비단→太素 등은 정확한 대상까지의 중간 단계가 많다. 후보의 위험을 솔직히 적었지만 그 자체가 해결된 것은 아니다. 모든 단원의 누락 분모와 구체적인 표 범위는 상대적으로 추상적이다. 숫자 표제의 다섯 값만 보고 두 359 저서 중 하나가 사라지지 않도록 별도 보완이 필요하다.

**채택:** 기존 전원 기립에 고유 素問 책의 주석 행동을 연결하는 구조, 원저자·정리자 구별, 全元起·王冰·楊上善의 편집 행위 비교. **탈락:** 別錄의 록 기타(현재 1=일렉기타와 충돌), 杜本의 ‘두 권’(저서 수 사실로 오독). **보류:** 흰 비단→太素, 속삭임→素問은 실제 서명 인출을 확인하기 전 출판 승인 불가.

### 03안 — 종합안의 주 학습 구조로 채택한다

**강점:** 그림으로 표현하기 어려운 사실을 삭제하지 않고 빈 표·경로 복원·정확한 한자 인출로 남긴다. 사암은 五輸穴 바탕표→규칙→부분 지원→한 행→혼동 행→빈 전체 표→지연 인출로 이어진다. 순서가 무의미한 정답까지 배열 차이 때문에 틀리게 처리하지 않는 세부 판단도 적절하다. 노래의 직렬 의존을 줄이고 중간 묶음부터 꺼내게 하는 방식도 유용하다.

**감점 근거:** 기존 숫자 사전을 저서 곁으로 옮기는 수정은 적절하지만, 사과밭·오징어덕장을 작은 사물로 줄여도 같은 수가 회상되는지와 새 0 후보는 미검증이다. 약물 두문자 장면도 아직 가설이다. ‘유물’만으로 유향·몰약을 정확히 확장하거나 ‘대감 원숭이 상륙’으로 대극·감수·원화·상륙 전체를 회수한다고 가정할 수 없다. 포제 노래를 듣기 전에 기존 어구를 교체해서도 안 된다. 사암 인접 표와 UI 오류 상태의 명시를 더해야 한다.

**채택:** 전체 표 인출, 오류 원인별 교정, 점진적 단서 제거, 간격을 둔 재검사, 유사 항목 변별, 사실에 맞는 매체 선택. **보류:** 새 0 후보와 두문자 후보의 실제 그림 승인. 학습 구조가 좋다는 이유로 그 안의 모든 소품까지 승인하지 않는다.

### 04안 — 유주와 교재 대응을 채택하고 일부 한자풀이 그림은 버린다

**강점:** 起始·循行·分枝·交會·終止와 정확한 신체 위치를 기준으로 유주 이야기를 재구성한다. 교재 표·각주·이미지의 누락과 문서 속 한자·혈위 코드의 오기도 검사한다. 전체 유주, 특정 교회혈 목록, 八脈交會穴을 섞지 않도록 하는 방향이 좋다.

**감점 근거:** 啓玄子를 표현하려고 王冰의 작은 아이를 추가하면 새 인물과 자호의 귀속이 혼동된다. 杜本의 두 번 찍기도 ‘번→본’ 음 변경을 요구하며 필요한 서지 관계와 관계없는 반복 행동을 늘린다. 이 두 후보는 익숙한 독음에 가까운 사물보다 한자를 모두 그림으로 채우려는 부담이 크다.

**채택:** 몸의 고정 좌표 위에 기존 사용자 유주 문장의 경유점을 붙이는 구조, 혈명·코드 검증, 세 자리 수를 책 바로 옆에 묶는 원칙. **탈락:** 王冰의 아이, 杜本의 두 번 도장. **수정:** 羊은 현재 위치 관례를 먼저 확인한 뒤 왕조용 문맥으로 제한한다. 한 과에서만 새 ‘왕조 입구’ 관례를 만들어 기존 발밑 약속과 충돌시키지 않는다.

### 05안 — 낮은 전체 순위와 별개로 구현 명세는 최우선 채택한다

**강점:** 별표의 안정된 ID, 기존 저장 이행, import 시 모르는 ID 보존, 검색과 재생 목록 분리, 실제 음성 실패, 중복 종료, 구간 경계, 저장 차단, 모바일·키보드 조작까지 다룬다. 현재 TTS가 오류에도 청취 완료를 기록하는 실제 코드 결함을 발견하고 해결 순서를 명시했다. 이 부분은 다른 안보다 구체적이다.

**감점 근거:** 구체 단서의 ‘子=작은 물체’와 別錄의 사슴은 자의 풀이가 부정확하거나 여러 단계 해독을 요구한다. 집주전자에서 주석 종이가 나오는 행동 역시 완전한 서명과 실제 주석 관계를 분명히 만드는지 미검증이다. 숫자는 최종본에서 현행 사전 우선으로 수정되어 이 부분의 변경 부담은 줄었다. 다만 0=공룡의 기존 사전 적용 범위는 전체 사전에서 확인해야 한다. 일부 역사·교재 사실은 직접 대조보다 공통 기록 의존도가 높고, 기본서12장이라는 미확정 표현도 남았다. 전체 앱 계획의 완성도가 이러한 단서·자료 공백까지 해결하지는 않는다.

**채택:** UI·저장·재생 상태 명세 전반, 기존 시험 기록 보존, TTS/파일 음성 어댑터 분리. **탈락:** 子를 구슬/작은 물체라고 풀이, 별+사슴을 別錄의 기본 정답 단서로 승격. **추가 채택:** 최종본이 현행 숫자 부호를 책별로 재배치하고 두359를 보존한 방향. **수정:** 적정 재시도 횟수는 고정 두 번으로 끝내는 규칙이 아니라 실패 원인에 따라 프롬프트·구도·매체를 바꾸는 절차로 둔다.

### 06안 — 실제 그림 검수 계약을 채택하고 수혈수 후보의 내부 모순을 고친다

**강점:** 대본에 적힌 내용과 실제 화소에 그려진 내용을 구분한다. 이미 생긴 열쇠·구슬, 梁·합편을 인정하면서 남은 귀속 문제를 지적한다. 같은 수인 王執中359와 楊繼洲359를 모두 보존하고 AI 자체 점수와 인간 회상을 구별한다. 실패 결과를 게시하지 않는 기준도 분명하다.

**감점 근거:** 앞부분은 두 359를 보존하지만 후보9는 ‘공통 300 구역+다섯 책’으로 돌아간다. 공통 3이 다시 멀어지고 필요한 저서가 하나 빠질 수 있어 현재 문제를 반복한다. ‘두 본을 본뜨는’ 이름도 자연스러운 한국어가 아니다. 실제 그림과 교과서 전체를 아직 보지 않았으므로 설계 심사 이상의 완성 판정은 불가능하다.

**채택:** 실제 물체·행위·소유자·확대 범위의 시각 계약, 본화와 단서 그림 동시 검사, 네 종류의 커버 지표 분리, 실패 기록. **탈락:** 다섯 책+공통300 후보, ‘두 본’ 새 인물. **수정:** 각 책에 완전한 세 자리 수를 부착하고, 같은359인 별개 저서를 유지한다.

## 좋은 단서의 기준과 개별 채택 판정

좋은 단서는 ‘모든 한자를 뜻풀이했다’가 아니라 **보이는 것에서 익숙한 말을 꺼내고, 그 말에서 목표와 관계까지 짧게 돌아갈 수 있다**는 공통점이 있다.

| 기준 예 | 작동하는 이유 | 함께 확인할 한계 |
|---|---|---|
| 全元起 → 전원 기립 | ‘전원’이라는 집합과 ‘기립’이라는 뚜렷한 동작이 한 번에 보이고 목표 이름의 소리가 이어짐 | 일부만 서 있으면 실패. 이름 회상만으로 저서·주석 기여까지 커버한 것은 아님 |

## 최종 종합안: Opus에게 넘길 실행 결정

### 1. 범위와 원문을 먼저 연결한다

`교재 판본 → 장·절·항 → 원자 사실 → 평가 목표 → 학습 단위 → 본화/도해/문답/음성`을 안정된 ID로 연결한다. 기본서와 총강은 원래 목차를 각각 유지하고 같은 사실을 참조한다. 동일 내용을 두 목차에 링크한다고 중복 학습 과를 새로 만들지 않는다. 과거 manifest59개, 최신227과, 총강 OCR5,444문단은 각각 자료 수이며 완전한 커버의 분모가 아니다.

교재의 표·본문·각주·원문·그림에 있는 시험 사실을 목록으로 만들고, 누락을 `사실 자체 없음 / 답에서 누락 / 그림 표현 없음 / 실물 미검수 / 출처 충돌 / 그림 대신 다른 학습 매체`로 구분한다. 그림으로 안 그리는 사실도 정확한 정답과 인출 경로에서 빠져서는 안 된다. 원문을 짧은 음성 대본에 맞춰 줄이지 않는다.

저서별 인물표는 최소 `성명·字·號·별칭 / 출생·활동 시대 및 나라 / 저서 정식명·이명 / 著·註·輯·補·刊 역할 / 기여 / 의의와 한정어 / 출처`를 가진다. 모든 칸을 한 장에 쑤셔 넣는 대신 시험에서 같이 바꾸는 관계를 묶는다.

### 2. 목차와 선수 순서를 함께 제공한다

허브의 기본 정렬은 실제 교재의 명시적 순서다. 현재 `lessons.sort(id)`를 학습 순서로 사용하지 않는다. `본화 → 필요한 상세 확대 → 비교 그림 → 빈칸 복원/전체 시험`의 위계를 표시하고, 선행 과는 실제 의존 관계로 연결한다. 선수 그래프의 순환·없는 ID·고립된 필수 사실을 검사한다.

권장 선행 예: 공통 숫자/왕조/책 표지 약속→의가별 관계→유사 저서 비교, 五行·陰陽 五輸 배속→十二經 혈명→사암 4격 규칙·예외→전체 표, 인체 위치·경혈명→奇經 기능→검증 유주→빈 몸 그림 복원. 교재를 읽는 순서와 이 권장 순서를 별도로 선택할 수 있게 한다.

### 3. 의학사는 ‘이름 소품+저서 편찬 사건’으로 재설계한다

도홍경은 기존 梁·도공·합편을 살리고, 입력 두 책과 출력 『本草經集注』가 같은 편찬 사건에 속하게 한다. 杜本은 기존 인물 유지 여부부터 비교하고 敖氏의 원자료에 본인이 증보하는 사건을 만든다. 王冰은 현재 검은 구슬을 여는 행동을 王冰에게 귀속한다. 全元起·楊上善·徐之才·劉涓子 등 이미 좋은 이름은 보존하고, 각자의 책·주석/편집/배오/외과 등 역할을 검증한다.

미완성 책 표지는 후속6안 과제로 남긴다. 이번 원안에 ‘집주전자’, ‘작은 의원’이 있다는 이유만으로 전체 서명 문제를 해결했다고 하지 않는다. 정확한 책 제목을 한 번 학습한 후 단서를 보고 복원하는 고유 표지로 정착시킬 수는 있으나, 실패하면 더 자연스러운 후보나 별도 인출카드로 전환한다.

### 4. 유주는 정확한 도해와 기존 이야기로 만든다

생성 그림에는 띠·벼리·죽마와 기억 장면을 맡긴다. 혈위·경로·분지·내외측·합류는 출전별 검증 SVG/도해가 맡는다. 이야기의 각 구절은 실제 지점에 대응하고, 그 구절이 경맥의 전체 경로인지 교회혈만의 기억 순서인지 명시한다. 이야기에 맞추려고 해부 위치를 옮기지 않는다.

DOCX의 잘못된 한자·경명·혈위 코드를 교정한 다음 본화·확대·정답·대본을 같은 사실 원장에서 갱신한다. 지도를 가리고 경로를 복원하는 시험과, 경로를 보고 맥을 가리는 비교 시험을 모두 둔다.

### 5. 사암은 원문 전체 표를 외우는 학습기로 바꾼다

사용자가 목표로 한 正格·勝格·寒格·熱格은 통상적인 `12경×4격×4혈` 범위라면 **192개 역할 칸**이다. 이는 서로 다른 경혈192개가 아니다. 각 셀에 경맥·격·補/瀉·본경/타경·혈명·五輸·五行·출처를 남긴다. 원문에 다른 범위나 예외가 있으면 그 기준을 별도로 기록한다.

**自經補瀉와 主客原絡도 별도 표로 포함한다.** 최신 肺·肝 JSON에 이미 나타나므로 192칸만 만들고 전체 완료라고 하면 누락이다. 12경에 각각 두 항목씩 있는 정본이라면 각24칸이지만, 실제 교재 행과 범위를 대조한 뒤 분모를 확정한다. 主客原絡을 사암4격의 일부처럼 섞지 않는다. 교재의 ‘사암허실’ 명칭도 실제 정의를 확인한다.

학습은 03안의 단계대로 五輸 재료→원리→부분행→완전행→유사행 변별→전체표→지연 재검사로 진행한다. 규칙으로 만든 답을 정답으로 삼기 전에 **모든 셀을 원문과 대조**한다. 熱格瀉 예외와 大腸 陽谿/胃 解谿는 필수 회귀 항목이다. 규칙을 설명할 수 있어도 실제 혈명이 안 나오면 미완료다.

현재12개 방과 문장은 삭제하지 말고 보조 자료로 보존한다. 주 화면은 빈 표와 정확한 답이다. 기존 혈명 단서를 재사용하되 읽어야 할 소품이 줄지 않는다면 그림을 더 만들지 않는다. 완성도는 셀 정확도, 완전한 행, 완전한 표, 지연 재검사를 구분해 기록한다. 95%·99%를 ‘전부 암기’로 표시하지 않는다.

### 6. 포제는 정확한 목록과 사용자의 두문자·노래를 우선한다

직접 확인한 암기시트의 醋炙12개는 `유향·몰약·현호색 / 삼릉·아출 / 시호·향부자·청피 / 대극·감수·원화·상륙`이다. 이것은 해당 암기시트의 범위이며 모든 교재의 보편적 최종 목록이라는 주장이 아니다. 교재의 醋炒·醋炙·醋製 구별과 목적을 대조한다.

사용자의 Suno 가사를 실제 확보해 각 어절→두문자→완전 약명→포제법→목적 대응표를 만든다. 기존 리듬이 맞으면 순서도 보존한다. 필요한 경우 첫 음절보다 두 음절을 써 유향/유황·감수/감초 같은 충돌을 줄인다. 두문자를 외운 것과 전체 약명을 쓰는 것을 별개 검사한다.

목록은 짧은 묶음·리듬·빈칸표, 포제 공정과 성질 변화는 비교 장면, 약재 실물은 정확한 사진/자료가 맡는다. 본초마다 거대한 장면을 생성하는 방향은 채택하지 않는다. 炮製와 後下·包煎 같은 煎服 정보도 데이터 범주에서 구별한다.

### 7. 요청한 UI 네 기능은 05안으로 구현한다

| 기능 | 확정 동작 | 꼭 확인할 예외 |
|---|---|---|
| 왼쪽 썸네일 | 교과서 목차의 각 그림 행 왼쪽에 실제 현재 본화의 작은 그림. 누르면 해당 그림으로 이동 | 최종본과 일치, 깨진 경로 표시, 모바일 줄바꿈, 비율 보존, 지연 로딩 |
| 오른쪽 별표 | 각 그림 행 오른쪽 독립 버튼으로 켬/끔. `lessonId`에 저장, 재정렬·개정 후 유지 | 링크 클릭과 분리, 키보드·눌림 상태, 저장 차단 안내, export/import·분할/통합 ID 이행 |
| 다음 그림 자동 넘김 | 토글. 한 그림의 필수 안내가 정상 종료하면 다음 그림, 무음이면 표시 완료 후 설정 시간 적용 | 현재 과 내부 정거장 이동과 구분. TTS 오류/취소/시간 초과는 정상 완료가 아님. 토글을 끄면 예약 이동 취소 |
| 전체·구간 반복 | 반복 없음/현재 확정 재생목록 전체/그림 A~B 양끝 포함 중 하나. 한 그림 반복 허용 | 검색으로 목록 몰래 변경 금지. 자동 넘김 꺼짐 시 반복 이동 비활성. A/B가 삭제·목록 밖이면 중단 후 범위 수정 |

재생은 하나의 중앙 제어기로 관리한다. 현재 음성은 `speechSynthesis`이므로 HTML audio API만 붙여 완료로 처리하지 않는다. TTS와 녹음 파일에 서로 다른 어댑터를 두고, 실행 토큰·현재ID·종료1회 조건으로 늦은 이벤트와 이중 이동을 차단한다. 현재 코드의 `done(false)` 무시 및 watchdog 후 자동 이동을 먼저 고친다. 기존 시험 기록·속도·음성 설정을 보존한다. 재접속 시 위치는 복원하되 소리를 저절로 틀지 않는다.

### 8. 앞으로의 제작도 독립6안→제7심사→실물재검수로 진행한다

동일한 원문 사실·기존 사전·금지된 혼동·화면 조건을 여섯 제안자에게 주되 다른 원안은 보여 주지 않는다. 여섯 명은 각각 전체 문제를 검토하고 `소품/행동 → 자연 발화 → 목표 → 소유/관계 → 역질문 → 예상 오독 → 폐기 조건`을 제출한다. 단순 역할 분업을 ‘독립6안’이라고 부르지 않는다.

제7심사자는 이번 성공 기준과 공통 척도로 판정하고, 좋은 부분을 합친 후 **합성 장면을 다시 심사**한다. 한자 의미를 전부 그리는 안에 자동 가점을 주지 않는다. 출처 충돌·필수 cue 부재·틀린 귀속·타 정거장 혼입은 전체 평균과 관계없이 생성/게시 보류 사유다.

제작 이후에는 정답을 보지 않고 물체·동작·소유자부터 기술하는 검사를 하고, 의도와 대조한다. 이후 훈련된 약속에서 사실을 복원하는 검사를 별도로 한다. 모델이 잘 읽었다고 사람이 외웠다고 쓰지 않는다. 실제 사용자 검사는 가능한 표본부터 축적하되, 그 응답이 없다는 이유로 원문 감사·구현·이미지 검수를 중단하지 않는다. 표시 상태를 `사실 검증`, `그림 검수`, `학습자 회상 검증`으로 분리한다.

실패하면 원인을 밝혀 해당 소품 수정→구도 재작성→전체 재생성→정확한 도해/표 전환을 비교한다. 같은 실패를 프롬프트만 약간 바꾸며 반복하지 않는다. 합격 자산으로 검증되지 않은 결과는 기존 그림을 덮거나 공개 허브의 기본본으로 올리지 않는다. 실패한 항목·시도·남은 이유를 사용자에게 보고한다.

## 기존 감사의 회귀검사와 완료 보고

사용자가 제공한 5판 감사 및 후속7개 항목을 각각 ID로 등록하고 최신 과·정거장 ID와 대응한다. 장상·진단 답 줄이기, 한자 원문, zds-02 임금 외형/舌·汗 혼입, zds-03 脾·腎 인물 충돌, zds-07 협통의 손 위치·본화/단서 불일치, zds-11 頭身·단서화풍·婦人/婦女, zds-16 군복·치법 원문, 乾燥한 변·말린枳實·上熱下寒·喜按 등 기존 지적을 새 디자인으로 가려 버리지 않는다. 실제 최신 파일을 열어 해결/미해결/현재ID확인대기로 판정한다.

출판 전에는 필수 사실 누락, 잘못된 귀속, 본화와 crop 불일치, 사라진 이전 그림, 깨진 경로, 원문 정답 축약, 표 셀 오류가 해결되어야 한다. 파일 검사는 이미지가 실제 디코딩되는지와 이전 판 링크가 유효한지까지 확인한다. 원본·현재본·확대본을 같은 별도 자산으로 잘못 연결하지 않는다.

완료 보고에는 다음 분모를 각각 적는다.

1. **원문 범위:** 확보한 교재·판본·장절과 아직 원문 대조하지 못한 구간.
2. **사실 커버:** 추출한 필수 사실 중 정답·문답·다른 학습 경로에 연결된 수. 그림 표현이 없는 것은 따로 표시.
3. **실물 검수:** 전체 본화·단서 그림·도해·음성 중 실제 열어 확인한 수, 보류·실패 수.
4. **학습자 검증:** 실제 사람의 즉시/지연 인출 결과가 있는 항목과 아직 없는 항목. AI 점수와 합산하지 않음.
5. **기능 검증:** 썸네일·별표·자동 넘김·전체/구간 반복, 기존 기록 이행, 오류 처리와 파일 열기 결과.

‘227과가 목록에 있다’, ‘모든 파일이 열린다’, ‘AI 평균97점’, ‘여섯 안을 합쳤다’ 가운데 어느 하나도 전 범위 학습 완성의 증거가 아니다. 구현 완료와 사람의 암기 완료를 구분한다.

## 심사에 참고한 외부 근거

- [Cepeda 외(2008) 원 논문](https://www.evullab.org/pdf/CepedaVulRohrerWixtedPashler-PS-2008.pdf): 목표 유지 기간에 따라 유리한 복습 간격이 달라질 수 있다는 근거. 한의학 표에 적용할 특정 일정을 보편적 최적값으로 확정하지 않는다.
- 인출연습 등 다른 학습연구와 역사 원문 링크는 각 원안의 근거 절에 보존했다. 연구에서 일반적으로 효과가 있었다는 사실과 이 그림·이 사용자에게 효과가 입증되었다는 주장은 구별한다.

실행에 필요한 출처 충돌 해소와 학습자 시험이 남아 있다. 그 한계를 명시한 상태에서 위 결정은 Opus가 실제 자료 감사·허브 구현·제작을 시작할 수 있을 만큼 구체적인 작업 기준이다.
