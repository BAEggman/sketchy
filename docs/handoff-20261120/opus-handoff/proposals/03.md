# 독립 원안 3 — 그림의 기억 단서와 정확한 표 복원을 결합하는 재설계 계획

작성일: 2026-11-20. 이 문서는 Opus에게 넘길 계획서이며, 실제 구현·그림 생성·배포를 하지 않았다. 다른 다섯 원안은 읽지 않았다. 출발점은 인출연습, 간격학습, 의미 있는 묶음, 유사 항목의 변별이다.

## 1. 핵심 결정과 확인 범위

그림의 장수를 늘리는 것을 진척으로 세지 않는다. 그림은 인물·저서·관계·순서의 기억 입구로 쓰고, 정확한 한자명과 긴 목록은 그림을 가린 인출과 표 재구성으로 완성한다. 어떤 항목을 그림으로 표현하지 않기로 했다면 그 항목을 삭제하는 대신 다른 학습 경로와 정답에 반드시 남긴다.

이번 계획에서 직접 확인한 것은 사용자의 감사 기록, Sketchy 공식 방법론·복습 기능 설명, 일부 학습연구의 원문·초록, 로컬 경락 DOCX의 혈수표와 奇經 유주·혈명 암기 문장, 포제법 암기시트의 醋炙 목록, 최신 lesson_map의 버전·227개 lesson·해당 제목이다. 루트가 별도로 확인한 최신 실제 그림 6장에 대한 공통 관찰 기록도 전달받았다. 최신 Gemini 산출물 전수의 실제 화소·음성·대본과 기본서·총강 전체를 확인한 것은 아니다. 따라서 현재 산출물에 대한 전수 합격 선언이나 최종 콘텐츠 누락률은 내리지 않는다.

## 2. Sketchy에서 채택할 것과 다른 방법으로 보완할 것

Sketchy 공식 설명에서 취할 핵심은 익숙한 공간, 독특한 사건, 반복되는 상징, 상징끼리의 위치와 관계, 설명과 장면의 결합이다. 공식 Symbol Explorer의 개별 상징 미리보기, 정답 숨기기, 전체 장면 집중 보기, 검색도 차용한다. 단순한 예쁜 삽화나 인물의 성만 그리는 것은 충분하지 않다.

인출연습 연구는 다시 읽는 것과 별도로 기억에서 꺼내는 연습의 가치를 뒷받침한다. 간격 연구는 나중 시험까지의 기간에 따라 유리한 간격이 달라짐을 보여 준다. 범주 학습에서 항목을 섞어 제시한 연구는 비슷한 항목을 구별하는 설계의 근거가 된다. 다만 이 연구들이 한국 한의학의 사암침법 전체 표나 이 프로젝트의 그림을 직접 검증한 것은 아니다. 아래의 일정·통과율·구획 크기는 이 프로젝트에서 시험할 운영 가설이다.

모든 사실을 한 장의 장면에 억지로 끼우지 않는다. 다음 네 방법을 병용한다.

| 학습 대상 | 기본 표현 | 최종 인출 과제 |
|---|---|---|
| 의학사 인물·저서·기여·의의 | 인물이 책에 실제로 행동하는 장면 | 인물→저서/의의, 저서→인물/시대, 의의→저서 |
| 사암침법 표 | 五輸穴 기반 행렬 + 원리 + 예외 단서 | 빈 표에 補瀉·經·穴名을 정확히 복원 |
| 유주·분지·교회 | 정확한 신체 경로도 + 경로상의 소품 | 빈 인체 위 경로 추적 + 혈명·분지 순서 |
| 본초·포제의 다항 목록 | 의미별 묶음 + 두문자·리듬 + 최소 이미지 | 단서 없이 전체 집합/필요한 순서 복원, 역방향 분류 |

그림 안 글자는 원칙적으로 없앤다. 정확한 숫자·한자·원문은 그림 바깥 정답 패널과 훈련 표에 둔다. 데이터가 정확해야 하는 해부 경로·표는 생성형 이미지에 맡기지 않는다. 꼭 글자가 필요한 객관적 도해는 별도로 명시한다.

## 3. 교과서 목차, 학습 선행 순서, 허브

먼저 두 교재 및 원본 DOCX의 판본·수정일·목차를 추출하여 서로 대응시킨다. 문서 이름의 ‘최종’이나 날짜만으로 정본을 추정하지 않는다. 기본 허브는 사용자가 공부하는 교재의 순서를 유지하고, 다른 교재에는 같은 사실·그림의 별도 위치 매핑을 둔다. 하나의 그림 파일을 복제하지 않고 안정적인 asset ID를 공유한다. 공통 조사에서 실제 발견된 『한의학총강』 통합 제3~11장 5444문단은 기본서 목차 체계와 다르므로 두 목차를 억지로 하나로 합치지 않는다. 기본서 13~16장 빈 폴더와 한의학개론 PDF 원본도 발견되었으므로, 추출된 12장까지가 전 범위라고 고정하지 않는다. 빈 폴더는 교재 내용 부재의 증거가 아니다. OCR 문단은 원본 페이지와 대조하고, 교재별 커버 분모를 따로 계산한다.

구조는 `교재 → 장 → 절 → 학습 대상 → 전체 장면 → 단서/표 복원`으로 잡는다. 목록의 좌측은 실제 그림의 축소본, 가운데는 번호·제목·형식·직접 링크, 우측은 사용자가 켜고 끄는 별이다. 장 제목 밑에 해당 그림 링크가 실제 목차 순으로 나온다. 폐기된 그림, 소품 단독 후보, 검수 대기물을 학습 순서에 섞지 않는다.

교과서 순서와 선행 개념 관계는 별도 데이터다. ‘먼저 보면 좋은 것’을 표시하고 선택하면 그 순서로 재생하되 교과서 기본 목차를 바꾸지 않는다. 예를 들어 사암은 五行 관계→음양 경별 五輸穴→本經·他經과 補瀉 원리→正格/勝格→寒格/熱格→혼합 표 복원, 경락은 방향·체표 기준→十二經→奇經 공통 기능→각 맥의 유주·분지→교회혈·유사 경로 변별로 연결한다. 실제 교재가 다른 순서를 택하면 원래 목차는 그대로 보여 준다.

학습자가 순서 때문에 헤매지 않도록 각 그림에는 ‘전체 장면으로’, ‘이 단서의 책 위치’, ‘관련 대비 그림’, ‘다음’을 제공한다. 선행 관계의 순환, 고아 단서, 빈 장, 같은 항목의 중복 큐를 검사한다. 현 build_player.py의 lesson ID 사전순 정렬은 명시적인 교재순서 키로 바꾸는 구현 과제로 등록한다. 파일명·ID·표제의 문자열 순서로 학습 순서를 추정하지 않는다.

## 4. Gemini 최신본 전수 감사와 좋은 아이디어 보존

실행자는 현재 사이트·최신 저장소·Gemini 결과물·직전 비교본의 버전과 해시를 확보한다. 과거 V7 폴더가 있다고 최신 Gemini본을 봤다고 간주하지 않는다. 자료마다 `현재 실물 확인 / 옛 파일 확인 / 사용자 지적만 있음 / 접근 불가`를 표시한다.

원본의 사실을 원자 단위로 분해한 뒤 다음 연결표를 만든다.

`source_fact_id ↔ textbook_location ↔ scene_id ↔ cue_id ↔ answer_item ↔ script_segment ↔ audio_span ↔ retrieval_task`

감사는 과·그림·단서·정답·대본·음성의 수를 각각 분모로 삼는다. 그림을 안 봤는데 설명이 맞는다는 이유로 그림 합격을 주지 않는다. 전수 작업 후에도 확대 원본, 잘린 단서, 실제 화면 배치를 따로 검사한다. 이미지의 실제 내용과 설명이 다른 경우에는 대본을 그림에 맞추어 사실을 줄이지 않는다.

좋은 아이디어의 보존 단위는 전체 파일이 아닌 ‘인물 외형 / 소품 / 동작 / 배치 / 이야기 연결 / 정확한 대본 문장’이다. `그대로 보존`, `동일 단서 재작화`, `다른 방법으로 전환`, `폐기`, `판단 유보`를 지정한다. 승인된 전원 기립·납작 까치 같은 단서를 화풍 통일 때문에 임의 교체하지 않는다.

사용자의 이전 감사는 회귀 검사 항목으로 고정한다. zds-02 #6의 사탕·땀 혼입과 임금 관모, zds-03의 脾 농부/腎 대머리 충돌, zds-07의 명치/脇 위치와 다른 사람의 발 crop, 腎陽虛·腎陰虛 전체 장면/단서 불일치, zds-11의 頭身 누락과 화풍·단서 불일치, zds-16의 시대가 다른 군복, 婦人/婦女 인용 차이, 大腸 陽谿/胃 解谿, 燥屎가 음식으로 보이는 문제, 上熱下寒의 전신 불길, 喜按 악수 등은 새 그림에서 다시 발생하지 않아야 한다. 본문 답을 줄여 원문·감별점이 빠지는 문제도 별도 회귀 검사다.

미완성 그림은 새 학습본으로 게시하지 않는다. 실패 사유, 시도한 후보, 현재 유지할 이전본, 남은 작업을 기록한다. ‘실패’와 ‘검토하지 못함’은 다른 상태다.

## 5. 의학사: 사람을 알아보는 그림에서 관계를 복원하는 그림으로

모든 인물에 대해 `이름 / 字·號·異名 / 활동 왕조·지역 / 저서와 역할 / 기여 / 의의와 최초의 범위 / 출처`를 채운다. 없거나 확정할 수 없는 자호는 빈칸의 사유를 적고 만들지 않는다. 출생지와 활동국, 초간 저자와 증보자, 최초와 현존 최초를 혼합하지 않는다.

각 인물의 영역에 공통 문법을 적용한다. 인물은 중심에 있고, 시대는 해당 단원의 공통 공간에, 별칭은 인물에게 붙은 소품에, 저서는 손에 들거나 작업 중인 대상에, 기여는 동작에, 의의는 동작의 결과에 둔다. 모든 장면에 같은 크기의 상자를 여섯 개 놓는 방식은 피한다. 정보가 많으면 하나의 책 만드는 사건을 두 컷으로 나누되 연결 동작과 인물 외형을 유지한다.

### 王冰·啓玄子

최신본에는 검은 구슬과 열쇠가 있으므로 해당 아이디어를 보존하며 귀속을 고친다. 얼음 왕이 **열쇠를 검은 구슬의 실제 열쇠구멍에 꽂아 열고 있는 순간**을 그린다. 검은 구슬이 배경 장식이거나 열쇠가 바닥에 떨어져 있으면 부족하다. 王冰의 冰, 별칭의 啓·玄을 연결하는 의미 단서이며, 이것만으로 ‘子’까지 자연히 발음된다고 과장하지 않는다. 별칭을 배운 뒤 그림→啓玄子와 啓玄子→王冰을 각각 인출하게 한다. 唐의 공통 공간과 王燾의 망대를 분리하여 얼음과 망대가 서로의 인물에 붙지 않게 한다. 王太僕 등의 추가 별칭은 교재 범위에 있을 때 별도 사실 ID로 검사한다. 唐762의 王冰 주석과 宋의 重廣補註 판본층위는 별도 사실로 나누어 연결한다.

### 梁·陶弘景·『本草經集注』

현재의 두 내용물을 합치는 동작·羊·도공·집주전자라는 개선을 보존 후보로 삼는다. 도자기 작업장 주인이 두 개의 서로 구분되는 원본을 받아 한 권의 새 책으로 **합치고 주석을 붙이는 행동**이 장면의 중심이어야 한다. 첫 원본은 神農本草經의 기존 표상, 둘째는 名醫別錄의 별도 표상을 유지한다. 결과물이 本草經集注이고 단순히 책 세 권이 늘어선 그림이 아니다. 현재 그릇 합치기에서 정확한 저서로의 연결이 약하다면, 원본 두 책의 물질이 그릇으로 들어가고 합쳐진 내용이 새 책으로 나오는 관계를 추가하는 후보를 비교한다. 梁의 羊은 다른 왕조 표지와 혼동하지 않게 단원 입구에 고정하여 시험한다. 이 후보가 陽이나 보양으로 자꾸 회상되면 폐기한다.

책 제목을 농부·명의·주석의 일반 의미로만 표시하고 정확한 서명이 자동 복원된다고 주장하지 않는다. 책 표상과 정확한 서명을 먼저 짧게 학습한 뒤, ① 두 원본을 모두 말하기 ② 최종 저서 말하기 ③ 저자/왕조 말하기 ④ 반대 방향으로 합성 관계 설명하기를 검사한다. 신농 한 권만 기억하거나 名醫別錄을 陶弘景의 단독 창작이라고 회상하면 재설계한다. 약물 수·朱墨 분별·분류법은 정본 교재에 있으면 별도 묶음으로 추가한다.

### 杜本·『敖氏傷寒金鏡錄』

국가중의약박물관 자료는 敖氏의 舌圖 12폭을 바탕으로 杜本이 증보하여 36폭으로 만든 관계와 ‘현존 가장 이른 驗舌 전문서’를 설명한다. 이 관계를 직접 보여 주는 혀를 비추는 금 거울과 그림을 보태는 행동을 중심으로 한다. 그림 바깥의 학습 표에는 原作·增補·書名·元·字伯原·現存最早라는 서로 다른 사실을 분리한다. 교재와 원전이 확인되기 전 숫자와 ‘최초’ 범위를 확정하지 않는다.

杜本의 음 단서를 ‘두 개의 본드 통’으로 만드는 것은 후보로는 적을 수 있지만 본드의 뒷음절을 버려야 하고 출판 작업과 중복되므로 낮은 점수다. 이 후보가 자연스러운 것처럼 확정하지 않는다. 기존 인물 표상이 양호하면 유지하고, 실제 기여 관계와 금 거울의 소유를 강화하는 편을 우선한다. 책 이름 전체를 무리한 억지말 한 줄로 압축하는 것보다 정확한 제목 인출을 따로 훈련한다.

徐之才·全元起·楊上善·劉涓子를 포함한 나머지 의가도 같은 사실 행렬로 전수 검사한다. 좋은 이름 단서가 있다고 저서·의의 항목을 합격 처리하지 않는다.

## 6. 349·354·359·360·361: 세 자릿수와 저서 연결을 둘 다 검사

먼저 교재·원전별 `저서–판본–집계 정의–혈수–근거` 표를 고정한다. ‘349→354→359→360→361’은 검증할 요구 목록이지, 등장하는 책을 빠뜨려도 되는 유일한 역사 계보가 아니다. 같은 359라도 두 책이 있을 수 있고 같은 책도 판본/집계가 다르면 이를 분기한다. 원문이 검증되지 않은 ‘355’ 등의 수는 보류 배지를 붙인다.

숫자 기억법 후보는 공통 숫자 소품 0~9를 먼저 익힌 뒤 **백·십·일 자리의 고정 위치**에 소품을 놓는 것이다. 최신본에는 3=삼지창, 4=사과밭, 5=오징어덕장, 6=너트, 9=구미호, 1=일렉기타라는 공통 사전이 있으므로 우선 재사용한다. 큰 배경인 사과밭·오징어덕장은 휴대 가능한 사과·오징어 소품으로 줄여도 같은 수를 회상하는지 확인한다. 그러면 349는 삼지창–사과–구미호, 354는 삼지창–오징어–사과, 359는 삼지창–오징어–구미호, 360은 삼지창–너트–공, 361은 삼지창–너트–일렉기타라는 후보가 된다. 공=0은 기존 사전에 없으면 새로 학습·검증해야 한다. 같은 숫자에 갈매기/삼지창 등 여러 새 체계를 동시에 도입하지 않는다.

이 숫자 사물군은 해당 책이나 저자가 직접 들고·사용하게 한다. 동굴 주소처럼 주변에 숫자를 써 놓고 기억되기를 기대하지 않는다. 공통 3을 생략하려면 생략된 자리도 항상 복원된다는 시험이 먼저다. 세 사물을 모두 새로 외우는 비용이 크면 검증된 두 자리 이미지 체계와 비교하여 채택한다.

검사는 (1) 그림→세 자릿수, (2) 책→수, (3) 수→해당하는 모든 책, (4) 354/359와 360/361 같은 최소 차이쌍, (5) 그림 없이 전체 계보 재구성으로 나눈다. 숫자만 맞고 저서가 바뀌면 실패다. 숫자 소품만 보고 정답이 떠올라도 실제 그림에서 너무 작으면 실패다.

## 7. 奇經 유주: 이름 단서와 실제 경로를 분리 후 연결

확인한 DOCX에는 奇經의 기능·유주뿐 아니라 독맥·임맥·충맥의 혈명 순서와 이미 작성한 이야기, Suno 링크가 있다. 이를 먼저 추출한다. 예를 들어 독맥의 장강→요유→요양관… 이야기와 충맥의 기충 열차→횡골→대혁…은 보존 후보다. 음성 파일을 실제 들었는지, 링크만 확인했는지 구별한다.

원본을 그대로 그림으로 옮기기 전에 문서 내부의 맥명·경명·분지·혈명 오류도 검증한다. 예컨대 같은 DOCX에 ‘족궐음담경’ 같은 혼합 표기가 보이며, 이런 문자열을 생성 프롬프트에 넘기면 오개념이 굳어진다. 교재 채택 정답과 출전별 차이를 명확히 한 다음 다음 세 층을 연결한다.

1. 帶=허리띠, 維=그물의 벼리, 蹻=죽마는 이름·핵심 기능의 표상이다.
2. 정확한 인체 도해는 시작점, 진행 방향, 앞/뒤·안/밖, 분지, 교회, 끝점을 보여 준다. 경로는 코드/벡터로 작성하고 자료에 근거한 좌표를 검수한다.
3. 소품 이야기는 도해의 실제 경로상 구간에 붙인다. 한 구간에서 다른 구간으로 이동하는 이유와 방향이 보이고, 인체와 무관한 연상 나열이 되지 않도록 한다.

陰維/陽維, 陰蹻/陽蹻를 같은 방향에서 나란히 비교하고, 이름을 가린 채 경로를 보고 맞히는 문제와 경로를 가린 채 이름으로 그리는 문제를 모두 둔다. 외관/내관, 공손/충맥 같은 교회 관계도 기본 유주와 혼동하지 않도록 별도 관계 유형으로 저장한다. 학습 완료는 이름 맞히기가 아니라 분지 포함 경로 복원과 해당 혈명 집합·순서 복원이다.

## 8. 사암침법: 표를 외우는 데 필요한 최소 그림

사암침법의 최종 산출물은 **정본의 전체 표를 단서 없이 복원하는 기능**이다. 正格·勝格·寒格·熱格, 사암허실과 교재에 포함된 변형·예외를 모두 범위 목록에 넣는다. ‘오행 원리만 이해하면 된다’로 사용자의 혈명 암기 요구를 축소하지 않는다.

실제 처방 표가 확보되기 전에는 혈 조합을 추정해서 채우지 않는다. 자료의 각 셀을 `판본 / 經 / 格 / 補瀉 / 순번 / 穴漢字 / 독음 / 五行 / 本他經 / 출처 위치`로 전사하고 이중 대조한다. 별도 기준표에서 경혈 이름·오행·경맥을 검증한다. 원리로 계산한 결과와 교재 결과가 다르면 어느 한쪽을 자동 덮어쓰지 않는다.

### 학습 절차

1. **이름 재료 준비.** 교재 범위의 음·양경 五輸穴 이름을 정확히 익힌다. 경명→井滎輸經合의 혈명, 혈명→經·五行·穴類를 양방향으로 묻는다. 한글 동음만 맞히는 것은 한자 시험에서 충분하지 않다. 음역·한자 이체자는 승인된 동의어 사전으로 처리한다.
2. **규칙과 의미 묶기.** 五行의 生克, 본경과 타경, 補와瀉의 자리를 이해한다. 규칙은 소수의 공통 도해로 보여 주며 셀마다 다른 장면을 만들지 않는다. 이해가 혈명 회상을 대체하지 않도록 실제 정답 혈명과 즉시 연결한다.
3. **부분 완성.** 한 줄의 경명·格·補瀉를 주고 일부 혈을 비운다. 처음에는 五行 힌트를 보이고, 이후 이를 없앤다. 같은 위치에 놓였다는 이유로 손이 기억하지 않도록 질문 순서를 바꾼다.
4. **전체 줄 복원.** 경명×格만 제시하고 해당 줄의 모든 혈과 補瀉 구분을 직접 쓰거나 말한다. 정답을 누르기 전에 응답하게 한다. 모르는 답을 반복해서 추측시키지 말고 시도 후 즉시 교정한다.
5. **유사 행 변별.** 正/勝, 寒/熱, 本經/他經, 이름이 비슷한 혈을 섞어 묻는다. 처음부터 모든 차이를 한꺼번에 섞지 않고 기본 틀이 생긴 뒤 범위를 넓힌다. 大腸의 陽谿와 胃의 解谿 혼입은 기존 오류에 근거한 필수 검사다.
6. **빈 전체 표 복원.** 원본 형식의 빈 표와 행·열을 재배열한 표를 번갈아 사용한다. 표의 위치 기억과 지식 회상을 분리하여 검사한다. 순서가 의미 없는 항목은 임의 순서 때문에 오답 처리하지 않되 補瀉·경·혈의 대응은 엄격하게 채점한다.
7. **지연 인출.** 첫 학습 뒤 당일·다음 날·수일 뒤·더 긴 간격의 재검사를 시작안으로 두고, 실패한 묶음을 더 빨리 돌린다. 고정된 1·3·7일이 보편적으로 최적이라고 쓰지 않는다. 숙달한 셀도 무작위 전체 표 검사에 계속 포함한다.

이미지는 공통 규칙도, 기억하기 어려운 혈명의 소품, 반복 오답 예외에만 사용한다. 예외에 색깔 점 하나만 붙이는 방식은 이름을 복원하지 못하므로 예외의 실제 혈명과 연결한다. 예외가 많아지면 ‘규칙 하나’로 포장하지 말고 교재의 정확한 여러 묶음으로 다시 나눈다.

채점은 셀 정확도와 완전한 줄/표 정확도를 별도로 보인다. 99% 셀이 맞아도 틀린 한 셀은 교정해야 한다. 학습 진행의 잠정 통과 기준은 두 차례 이상 간격을 둔 완전한 표 복원과 무작위 질문에서 정확한 대응을 확인하는 것이다. 이는 의료적 숙련을 보증하지 않으며 침 시술 능력 평가도 아니다.

## 9. 포제·본초: 두문자와 그림을 연결하는 절차

포제는 방법 정의·보조재·작용·대상 본초·예외를 서로 분리한다. 炮製와 煎服의 後下·包煎 등을 같은 범주로 합치지 않는다. 개별 본초는 여러 포제법에 등장할 수 있으므로 ‘이 본초는 오직 이 방법’이라는 단서를 만들지 않는다.

확인한 `doc7_포제법_암기시트.docx`는 醋炙를 다음처럼 적는다. 활혈지통: 유향·몰약·현호색 / 파혈: 삼릉·아출 / 소간이기: 시호·향부자·청피 / 독성 감소: 대극·감수·원화·상륙. 이것은 발견된 암기시트의 목록이며 기본서·총강·문제집을 합친 최종 전체 목록이라고 선언하지 않는다. 주된 교재에서 醋炒·醋炙·醋製의 분류가 어떤지 대조하고 포제 조건·독성 관련 정보는 특히 원전을 확인한다.

후보 구절은 `유몰현호 / 삼아 / 시향청 / 대감원상`처럼 원문의 의미 묶음을 유지한다. 자연스러운 완성 문장을 만들기 위해 본초 하나를 빼거나 이름을 바꾸지 않는다. ‘유물(유향·몰약)을 현호색 인물이 집어 들기’, ‘삼각형 아래 아치(삼릉·아출)’, ‘대감이 원숭이를 상륙시키기(대극·감수·원화·상륙)’는 그림 후보지만 각 음절이 무엇인지 추가로 학습해야 하며, 성분·효능의 실제 의미로 읽히지 않도록 한다. 중복 단서와 어색한 음절 압축은 최종 선정 전에 탈락시킬 수 있다.

사용자가 제공한 Suno 노래를 실행자가 직접 듣거나 가사를 확보하여 실제 완전 목록·발음·누락·순서를 검사한다. 듣지 않았으면 ‘확인하지 못함’으로 둔다. 좋은 리듬이나 사용자 친숙한 어구는 보존한다. 노래 전체를 처음부터 끝까지 불러야 한 항목에 접근할 수 있는 직렬 의존을 줄이기 위해 중간 묶음 시작점과 무작위 본초→포제법 질문도 제공한다.

훈련은 보조재→목록 전체, 본초→해당되는 모든 포제법, 혼동되는 이웃 목록 비교, 한글→한자/본초 실물의 순서로 이어진다. 일상 사물의 phonetic cue와 실제 약재 모습을 구별하여 보여 준다.

## 12. 6개 독립 안과 7번째 심사자의 실행 규칙

1. 공통 사실 팩을 먼저 고정한다. 각 agent에 동일한 원본 사실, 사용자 성공/실패 사례, 문자 최소화 원칙, 최신 이미지와 대본을 준다. 여섯 명을 분야별 분업으로만 나누지 않고 각자 문제 전체에 대한 독립 대안을 만들게 한다.
2. 여섯 agent는 다른 원안을 보지 않고 소품·동작·이야기·그림 간 연결·비그림 대안을 제출한다. 후보마다 정확한 목표, 보이는 물체와 행위, 소리 대응, 의미 대응, 오독, 선행 지식, 출처, 평가 과제를 명시한다.
3. 원안을 수정 불가능한 스냅샷으로 보존한 뒤 7번째 심사자에게 익명 순서로 제공한다. 이미 승인된 全元起·扁鵲·薛己 사례와 실패 사례를 먼저 분석하게 한다.
4. 심사자는 사실 정확성과 실제 존재성을 필수 통과 조건으로 둔다. 그 뒤 직접 회상 25, 발음/의미 자연스러움 20, 책·인물·기여 관계 20, 다른 cue와 변별 15, 시각 명료성 10, 과도한 학습 부담과 추가 글자 최소화 10의 잠정 100점 척도로 평가한다. phonetic cue가 없는 관계 그림은 불이익을 주지 말고 그 자리에 적절한 의미 연결을 평가한다.
5. 점수는 비교를 위한 전문가 판단이며 학습효과의 실측값이 아니다. 높은 합계로 사실 오류·없는 소품·틀린 방향·다른 사람의 단서 혼입을 상쇄할 수 없다.
6. 좋은 부분을 결합할 때 기존 상징 사전과 충돌하는지 다시 검사한다. 따로는 좋은 두 소품이 합쳐지면 과밀하거나 잘못된 인과로 보일 수 있다. 최종안은 각 요소의 원안 출처와 선택 이유, 탈락 이유를 보존한다.
7. 텍스트 설계 통과 뒤에만 Gemini 제작 지시를 작성한다. 사고수준 설정은 실제 사용 가능 설정·값·시각을 기록하고 낮음에서 높은 설정으로 바꿨다고 결과 검수가 끝나는 것은 아니다. 최초 그림 뒤에는 ‘설명 없이 보이는 것’을 먼저 적는 검수와 정답 대조를 순서대로 수행한다.
8. 생성 실패가 반복되면 단순화·분할·벡터도해 전환·기존 그림 유지 중에서 선택한다. 수정 예산과 중단 기준을 정하고, 탈락본은 학습본에 섞지 않는다.

최종 전달물에는 6개 원안 그대로, 7번째의 항목별 점수·탈락 사유, 종합안, 채택한 소품/관계 사전, 구현 작업목록을 모두 포함한다. 이 계획 단계에서 Opus나 Gemini를 실제 실행한 것처럼 표현하지 않는다.

## 13. 완료의 정의와 실행 순서

실행 단계는 ① 최신본·정본 고정 ② 교재 원자 사실 및 목차 매핑 ③ 기존 자산 전수 감사 ④ 단서 후보 6+1 선정 ⑤ 작은 대표 묶음으로 인출 가능성 확인 ⑥ 전체 적용 ⑦ 기능·내용·전수 이미지 재검수 ⑧ 비교본과 누락표 인계 순이다. ⑤의 작은 묶음은 전체 범위를 축소하는 명분이 아니라 실패 패턴을 일찍 발견하기 위한 단계다.

최종 완료 조건은 다음과 같다.

- 모든 교재 사실에 `표현됨 / 텍스트·표 인출로 커버 / 의도적 제외+이유 / 출전 미확정` 상태가 있다. 그림에 없다는 이유로 정답에서도 빠지는 항목이 없다.
- 모든 최신 그림과 단서가 실제로 열리고, 전체 장면–crop–설명–대본–음성이 같은 의미와 버전을 가리킨다. 수량·분모와 미확인 목록이 함께 보고된다.
- 의학사의 인물·자호·왕조·책·기여·의의는 각 필드의 정방향과 역방향 질문이 있다. ‘최초’의 범위가 보존된다.
- 사암의 모든 범위 셀과 예외가 출처와 연결되고, 정확한 한자명·補瀉를 전체 표로 복원할 수 있다. 원리 설명만으로 완료 처리하지 않는다.
- 奇經의 이름뿐 아니라 실제 유주·분지·교회와 원문 혈명 순서가 검증된다. 본초 목록은 집합 누락·중복·분류 혼입을 검사한다.
- 별표·썸네일·자동 다음·구간 및 전체 반복이 실제 학습 경로에서 동작한다. 이전 그림 보기와 다운로드/압축 분할본의 파일 무결성도 회귀 검사한다.
- 남은 실패·불확정·접근 불가를 숨기지 않는다. 생성 수, 읽은 파일 수, 합격 수, 학습자가 지연 회상한 수를 서로 혼동하지 않는다.

초기 파일럿에서는 즉시·다음 날·일주일 뒤의 이름/관계/표 정확도, 틀린 경쟁 단서의 종류, 회상 시간, 힌트 의존 여부를 기록한다. 소수 사용자에게서의 결과를 일반적 효과로 주장하지 않는다. 높은 회상률에 이르지 못하면 그림 자체와 학습 절차 중 무엇이 문제인지 분리해 고친다.
