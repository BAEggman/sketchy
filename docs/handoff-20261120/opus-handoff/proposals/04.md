# 독립 원안 4 — 교과서의 사실과 공간 경로를 먼저 고정하는 재설계

작성일: 2026-11-20. Opus에게 전달할 설계안이다. 이 문서 작성자는 다른 다섯 원안을 읽지 않았다. 이 단계에서 사이트 수정·새 그림 생성·배포는 하지 않았다. 아래의 새 단서는 모두 검증 전 후보이며, 학습자가 실제로 잘 기억한다고 확인된 결과가 아니다.

## 1. 해결의 중심

교과서의 한 문장이나 표 한 칸을 학습해야 할 사실의 최소 단위로 만든다. 그 사실을 어떤 그림·대본·설명·문제로 복원하게 할지 연결한다. 그림의 수를 늘리기 전에, 한 그림이 책임지는 사실과 그 그림을 보기 위한 선행 지식을 명시한다.

설계의 기본 단위는 `교과서 사실 → 관계 → 기억 단서 → 장면 속 위치 → 인출 질문`이다. 의학사의 인물 이름, 경락 이름, 포제 이름만 떠오르고 정답의 나머지가 나오지 않는 상태를 이 연결에서 찾아낸다. 예를 들어 陶弘景은 ‘도자기 인물’로 끝나지 않고 ‘梁의 陶弘景이 두 기존 문헌을 합하고 주석을 붙여 本草經集注를 편찬했다’라는 사건을 재현해야 한다.

구조적 규칙이 있는 사암침법은 표 복원 훈련을 중심으로, 순서가 있는 유주는 몸 위의 경로를 중심으로, 분류별 대상약 목록은 두문자와 집합 인출을 중심으로 만든다. Sketchy의 일관된 공간·상징·행동·해설은 이 각각의 학습 과제를 지원한다.

## 3. 교과서 목차와 선수 학습을 서로 연결한다

### 3.1 교과서 목차는 원래 순서를 보존한다

최종 기본서와 총강 각각의 판본·파일 해시·장절 제목·쪽 또는 DOCX 문단/표 위치를 기록한다. 목차는 실제 원문에서 추출한다. 둘의 목차가 다르면 기본서 보기·총강 보기를 제공하고, 같은 사실을 공통 ID로 연결한다. 임의로 의학사→경락 순서를 ‘교과서 순서’라고 만들지 않는다.

HTML 허브의 행은 `작은 썸네일 | 제목·학습 목표·선행 그림·진행 상태 | 별표`로 통일한다. 기본서의 장→절→항 아래에 관련 그림을 정렬한다. 한 그림이 여러 항을 다루면 본래 위치 하나와 다른 위치의 참조 링크를 둔다. 복제 파일은 만들지 않는다.

목차의 가장 작은 제목 아래에 세 종류의 내용을 함께 표시한다.

1. 핵심 개념 장면: 이번 항에서 학습할 사실과 관계.
2. 세부 경로·정확한 표: 유주·혈위·숫자·원문·약물 전체 명단.
3. 복원 연습: 설명 가리기, 빈 표 채우기, 부분에서 전체 찾기, 반대 방향 질문.

### 3.2 선수 관계는 별도의 학습 경로로 보여 준다

예를 들어 사암은 ‘陰陽經의 五輸穴 배속 → 각 經의 혈명 → 相生·相剋 → 補瀉의 실제 표 → 정격·승격 감별 → 寒熱 및 예외’ 순으로 갈 수 있다. 유주는 ‘몸의 안/밖·앞/뒤 → 正經과 奇經의 역할 → 각 奇經의 경로 → 교회혈 → 八脈交會穴 → 병증’으로 연결한다.

이 선수 관계는 순환 여부를 검사하는 그래프로 관리한다. 교과서 정렬과 추천 학습 경로를 모두 표시하고, 자동 넘김은 사용자가 현재 선택한 경로를 따른다. 이미 아는 선행 항을 강제로 다시 보게 하지 않는다. 교재의 순행, 실제 혈위 배열, 교수자가 만든 암기 순서는 서로 다른 순서라는 점을 데이터에 구별한다.

### 3.3 정확한 데이터 단위

최소 레코드는 다음과 같다.

| 항목 | 내용 |
|---|---|
| source_id | 교재/판본/쪽/문단/표 좌표, 원문과 정정 이력 |
| fact_id | 한 번에 채점할 사실: ‘A가 B를 증보했다’, ‘혈 X는 이 행의 瀉’ |
| entity_id | 인물·저서·경맥·혈·본초의 동일성을 유지하는 ID |
| relation | 저술·주석·증보·합편·발행·소속·교회·선후 관계 |
| cue_id | 보이는 물체/행동, 발음 연결, 목표 말, 혼동 후보 |
| scene_id | 장면·좌표·원본/세부 컷 연결·버전 |
| question_id | 정방향·역방향·감별·전체복원 문제 |
| status | 원문확인/사실확정/단서후보/그림검사/인출검증 상태 |

‘표에 존재함’, ‘설명에만 있음’, ‘그림에서 복원 가능함’을 별개의 상태로 저장한다. 모두를 하나의 완료 표시로 합치지 않는다.

## 4. Gemini 작업의 보존과 재설계 기준

각 기존 그림과 설명·대본을 함께 묶어 보존본을 만든다. 최소한 원본 경로·해시·수정 시각·연결된 강의/단서/썸네일·이전 버전을 기록한다. 이미 학습한 全元起 전원 기립, 扁鵲 납작 까치, 薛己 백설기와 사용자가 좋다고 한 인물은 우선 보존 목록에 둔다. 보존은 그림 전체 무수정이라는 뜻이 아니라 정확한 cue의 정체성과 위치 관계를 유지한다는 뜻이다.

각 장면의 판정은 다음 네 가지로 한다.

- 유지: 사실·복원·구별·장면 통합이 모두 성립한다.
- 국소 수정: 물체 한 개나 동작의 위치로 해결되며 주변 단서의 의미가 바뀌지 않는다.
- 구조 재설계: 입력 문헌→편찬 결과와 같은 관계가 없거나 한 장면에서 서로 다른 단서가 섞였다.
- 사실 보류: 출전이나 숫자가 충돌하여 아직 그릴 수 없다.

대본에 좋은 발음 연결이 있어도 그 물체·동작이 그림에 없으면 ‘대본 단서만 존재’로 판정한다. 왕빙은 현재 열쇠·구슬의 존재가 확인되었으므로, 동작과 별칭의 인물 귀속이 대표적인 추가 검사 항목이다. 그림에 들어간 단서를 설명에서 빠뜨린 경우도 반대로 기록한다.

관계가 없는 소품 나열을 재설계할 때는 ‘A가 B를 잡아 C에 넣는다’, ‘이전 책에 주석을 붙인다’, ‘같은 사람에게 증상이 양쪽에서 대비된다’처럼 동작이 문법 역할을 담당하게 한다. 필수 글자는 웹의 정답·원문·범례에 두고 그림 안의 문장은 최소화한다.

## 5. 의학사는 ‘한 의가의 신원표 + 편찬 사건’으로 고친다

모든 의가에 대해 아래 여섯 필드를 교재와 문제집에서 대조한다. 해당 사실이 출전에 없으면 ‘확인되지 않음’으로 두고 만들어 채우지 않는다.

| 필드 | 그림으로 복원할 정보 | 오류를 잡는 질문 |
|---|---|---|
| 인물 | 기존 얼굴·의상·소리 단서 | 이 소품은 누구인가? |
| 字·號·별칭 | 별칭과 그 사람의 동일성 | 이 별칭은 다른 의가의 것이 아닌가? |
| 국가·시대 | 출생지·활동국·왕조를 구분 | 어느 시대의 어느 행위인가? |
| 저서 | 완전한 제목과 문헌 고유 상징 | 제목을 일부만 말해도 맞다고 처리하지 않는가? |
| 기여 | 저술/증보/주석/합편의 방향 | 누가 원저자이고 누가 손질했는가? |
| 의의 | 시험에서 구분하는 특징·최초의 범위 | ‘최초’가 어떤 범위의 최초인가? |

문헌은 덱 전체에서 재사용할 고유 상징을 갖는다. 本草經 같은 흔한 부분과 太素·訓解·金鏡錄 같은 구별 부분을 나눠 가르친다. ‘그냥 책’은 어떤 저서인지 알려 주지 못하므로 문헌의 명명 단서 또는 고유 인물이 가진 상징이 필요하다. 한 장면 안에 전 내용을 우겨 넣기 어려우면 동일한 방에서 두세 개의 사건을 순서대로 보여 주며, 줌 컷이 원래 방의 소품과 정확히 일치하게 한다.

## 7. 혈위 수는 ‘저서–세 자리 수’의 양방향 기억으로 만든다

## 8. 奇經八脈은 몸의 고정 지도와 기존 문장을 결합한다

### 8.1 한 몸, 여러 층

한 개의 표준 신체도를 전·후·내측·외측으로 전환한다. 신체 방향은 언제나 같다. 이름을 위한 띠·벼리·죽마는 이 지도에 붙인다. 실제 경로와 혈위·분지·교회는 검증된 선과 점으로 작성한다. 그림 생성 모델에게 정밀한 유주선을 최종 확정하도록 맡기지 않는다.

각 맥은 다음 묶음을 빠짐없이 가진다: 기시 설명, 체표 경로와 내부 가지, 종지·상회, 교회혈, 고유 기능, 병증, 八脈交會穴, 타맥과 감별. 교회혈과 八脈交會穴은 별개 자료로 관리한다. 전자를 공손·내관 같은 통혈만으로 대체하지 않는다.

원문 설명이 출전마다 다르면 특정 교재의 기본 경로와 다른 출전의 가지를 색만 달리 쓰지 않고 명시적인 층/범례로 구분한다. 학습자가 어느 출전 답을 인출하는지 알 수 있어야 한다.

### 8.2 사용자 문장을 구조화한다

doc4에서 찾은 문장들은 원문 사본을 보존하고 `원래 표현 → 목표 혈명 → 표준 한자/코드 → 몸 위치 → 읽는 순서 → 수정 이유` 표로 옮긴다. 말장난이 훌륭해도 잘못된 혈코드까지 보존하지 않는다. ‘큰 닭=太谿’처럼 사용자가 이미 외운 음 연결은 한자 뜻풀이로 전면 대체하지 않는다.

각 단계에서 화면을 확대하면 같은 몸의 같은 부위와 같은 소품이 보인다. 카드마다 새로운 인물·새 풍경을 만드는 대신 초점만 이동한다. 경로 중간에서 시작하기, 역방향, 빈 지도에 다시 그리기, 특정 교회혈이 속하는 맥 찾기를 추가해 이야기 첫머리에만 의존하는 암기를 줄인다.

### 8.3 빠짐 감사 범위

‘경락’ 장에는 十二經脈뿐 아니라 經別·絡脈·經筋·皮部·奇經, 原絡郄募背俞·五輸·下合·八會·八脈交會·교회혈 등이 실제 목차에 있는지 대조한다. 기능·유주·혈명·병증·출전 원문·임상 연결 각각의 누락을 표시한다. 임상 연결은 교재의 이론적 관계·감별 근거로 제시하고 그림의 유사성을 치료 효과의 증거로 사용하지 않는다.

## 9. 사암침법: 적은 장면과 정확한 전체 표 복원

목표는 ‘원리가 그럴듯하게 이해됨’이 아니라 사용자가 지정한 正格·勝格·寒格·熱格·허실 보사 등의 표를 **필요한 혈명, 補瀉, 자기 경/타경 위치까지** 재현하는 것이다. 최종 표의 행·열·예외는 실제 교재에서 확정한다.

### 9.1 세 층의 기억

- 공통 지도: 相生·相剋, 陰陽經 五輸穴의 오행 배속을 한 지도에서 학습한다.
- 혈명 사전: 실제 표에 등장하는 고유 혈마다 한자·독음·經·五行·필요한 위치를 한 번 학습한다. 魚際와 少府처럼 반복되는 혈은 매번 새로운 물건으로 그리지 않는다.
- 처방 표: 같은 틀의 행에 補 두 칸·瀉 두 칸을 넣고 원리를 따라 재구성한다. 규칙에서 벗어나는 조합은 출전별 예외로 직접 외운다.

기존 사암 문장의 좋은 소리 연결은 ‘해당 행을 기억하는 짧은 문장’으로 보존한다. 모든 행에 새 배경화를 만들기보다 공통 무대에 혈 상징만 바꾸고 표는 별도로 인출한다. 표의 수와 이미지 수의 일대일 대응을 요구하지 않는다.

### 9.2 훈련 진행

처음에는 완성 예제 한 행→두 칸 빈칸→한 행 전체→섞인 행→전체 빈 표를 사용한다. 정격·승격을 각각 익힌 뒤 비교하여 간섭을 줄인다. 이후 특정 혈을 주고 어느 처방·어느 補瀉 칸인지 묻는다. 다음 날과 일정 시간이 지난 후 다시 전체 표를 복원해 기억이 유지되는지 본다. 1·3·7일 같은 초기 간격은 제품 기본값의 후보이며 보편적 최적 주기로 주장하지 않는다.

채점은 원문 표의 셀마다 한다. 다른 경의 동음 혈, 혈명이 맞아도 補瀉가 바뀐 경우, 두 혈을 다른 쌍으로 섞은 경우를 구별한다. 四穴의 내부 나열 순서는 정답 정의에 근거해 평가하고, 외우기 편한 순서를 학술 순서로 둔갑시키지 않는다.

운영 완료 기준은 ‘모든 표를 제공하고 오류 없이 채점할 수 있음’과 ‘사용자가 간격을 둔 무단서 복원에서 모두 맞힘’을 구별한다. 개발자가 그림을 완성했다고 사용자 암기가 완료됐다고 말하지 않는다.

### 9.3 기존 감사의 회귀 검사

s18d07의 大腸 陽谿/胃 解谿 혼동, 熱格 예외 설명, 正勝과 寒熱의 보사 역할을 원본 표와 대조한다. 이전 교정이 다른 파일이나 대본에서 되돌아오지 않는지 같은 fact_id로 연결해 검사한다. 표를 규칙으로 자동 생성하더라도 최종 셀 전체를 원문 확정 표와 비교한다.

## 10. 포제는 ‘법·목적·대상약 집합’을 함께 외운다

사용자가 말한 초법을 醋炙와 炒法의 발음이 같은 문제까지 포함해 정확히 구분한다. 두문자 목록을 만들기 전에 교재의 표기를 기준으로 炮製法·輔料·목적·대상약·예외를 추출한다. 기본서·총강·사용자 암기시트가 다르면 각 출전을 유지한다.

doc7의 醋炙 12개는 네 묶음의 시범 대상이다. `유몰현 / 삼아 / 시향청 / 대감원상`은 추출된 머릿글자 원재료이며 완성된 자연스러운 암기구호라고 평가하지 않는다. 6개 에이전트가 각각 짧고 말이 되는 문장·행동을 내고, 각 약물이 빠짐없이 한 번만 복원되는지 7번째가 검사한다.

한 포제법의 항아리·도구를 공통 장소로 쓰고, 소수의 묶음만 서랍처럼 연다. 한 묶음의 장면은 해당 두문자 순서를 복원하고, 다음 단계에서 각 약의 전체 이름과 한자를 인출한다. 예를 들어 ‘감’이 감수인지 감초인지 모호하면 손실 없는 두 음절이나 해당 약의 기존 물건으로 보강한다. 강제로 한 음절로 줄이지 않는다.

좋은 음원이 있으면 원문 가사·문자 목록·이미지 묶음의 대응을 맞춘다. 듣고 따라 부르기 외에 전체 명단을 쓰는 모드, 순서를 바꾼 약 이름→포제법 모드, 잘못 섞인 약 찾기 모드를 둔다. 다중 포제법이 가능한 본초는 하나의 법에만 속한다고 오채점하지 않는다.

목적을 위한 五味·歸經·방향성 기억은 연결 설명으로 쓰고, 모든 대상약이나 예외를 그 규칙에서 추론할 수 있다고 하지 않는다. 특히 독성 감소·效能 증감의 범위는 실제 교재의 표현으로 제한한다.

## 11. HTML 허브의 네 기능을 동작까지 확정한다

| 요청 | 구현 계약 | 확인할 사례 |

자동 넘김은 이동 권한, 반복은 끝에 도달했을 때의 목적지 규칙으로 정의한다. 자동 넘김을 끄면 반복이 설정되어 있어도 타이머가 임의로 페이지를 넘기지 않는다. 재생 목록의 범위는 ‘현재 선택 장/학습 경로/별표 목록’ 중 무엇인지 화면에 표시한다. 필터를 바꾸면 새 목록을 만들고 기존 A–B의 유효성을 검사한다. 숨겨진 항을 통과해 반복하거나 무한 재시도하지 않는다.

음성 읽기와 단순 그림 슬라이드 재생은 구분한다. 브라우저가 음성 자동재생을 막으면 한 번의 재생 조작으로 시작하도록 한다. 선택한 이미지·재생 상태·반복 상태가 URL 또는 저장 상태와 충돌하지 않게 한다. 가능하면 ‘복원 시간 뒤 답 보기’를 제공하지만, 사용자가 별표로 표시한 중요도와 학습 정답률은 별도로 관리한다.

## 12. 전수 감사는 분모와 관찰 증거를 남긴다

세 가지 분모를 별도로 센다: 실제 교재 fact 총수, 강의·단서·그림판·도해·썸네일·비교본의 asset 총수, 원문·대본·정답의 text item 총수. 사용자에게는 ‘그림 141장 봄’과 ‘교과서 사실 전부 포함’을 같은 말로 보고하지 않는다.

각 파일에 `열림/원본 해상도 확인/장면 확인/설명 대응/원문 대응/세부 컷 일치/역질문 결과/판정자/시간`을 기록한다. 자동 링크 검사·중복/해시 검사는 파일 상태를 보장하고, 실제 그림 읽기 검사는 단서 존재와 의미를 보장한다. 두 검사를 대체하지 않는다.

사용자가 이미 지적한 항목은 모두 회귀 목록으로 옮긴다. zds-02 임금과 사탕·땀의 혼입, zds-03 脾 인물의 대머리 및 딸기, zds-07 장군 옆구리/명치·다른 사람 발 유입·腎陰陽虛의 강의와 단서 불일치, zds-11 화풍과 頭身·婦人/婦女, zds-16 현대 군복·치법 원문, s16u01 喜按/拒按, 사암 표를 포함한다. 목록에 있는 오류를 현재 확인한 오류로 미리 단정하지 않고 새 버전에서 재검사한다.

이전 그림보기는 파일 존재만이 아니라 실제 링크→이미지 로딩→교체 전 전체/세부 일치까지 점검한다. 원본을 덮어써 이전판 링크가 새 그림으로 바뀌는 구조는 피한다. 실패한 후보는 승인본 대신 노출하지 않고 실패 원인·시도한 수정·미해결 사실을 기록한다.

그림 제작 후 검사할 핵심 질문은 다음과 같다.

1. 프롬프트에서 요구한 물체와 행동이 실제로 보이는가?
2. 설명 없이 물체를 명명했을 때 목표 단어가 나오는가?
3. 대상·관계·숫자·위치가 정확하게 이어지는가?
4. 다른 정거장의 단서로 잘못 답할 더 쉬운 길이 있는가?
5. 전체 장면과 세부 컷, 썸네일, 대본, 정답이 같은 버전인가?
6. 한자 원문과 시험 감별점이 요약 과정에서 빠졌는가?

## 13. 독립 6안과 제7 심사의 반복 절차

여섯 설계자에게 같은 원문 사실표·현재 이미지·기존 성공 cue 사전·혼동 사례를 제공한다. 첫 원안을 저장할 때까지 서로의 후보를 읽지 않는다. 각 안은 전체 해결안과 함께 물체→소리/뜻→목표→관계, 역질문, 실패 가능성, 재사용/폐기 목록을 제출한다.

제7 심사자는 먼저 사실 오류·목표 누락·명백한 충돌·필수 물체 부재를 탈락 조건으로 검사한다. 이후 가중 점수로 비교한다.

| 항목 | 배점 | 보는 것 |
|---|---:|---|
| 사실·출처 | 20 | 목표 사실·단위·판본 및 출전 충돌의 처리 |
| 단서 회상가능성 | 25 | 친숙한 소품/행동에서 목표 독음·개념으로 복원되며 다른 단서와 구별되는가 |
| 인물·저서·행위 관계 | 15 | 누가 어떤 문헌을 어떻게 다뤘는지, 補瀉·유주 관계가 연결되는가 |
| 교과서 범위·선행순서 | 15 | 필수 사실과 원문 목차, 학습 선수 관계를 보존하는가 |

| 구현·검수 | 10 | 실제 제작·관찰·기능 검증이 가능한가 |
| 근거·한계 | 5 | 실제 관찰과 계획, 모델 판단과 사람 검증을 구별하는가 |

이 점수는 설계 판단을 기록하기 위한 운영 도구다. 실험으로 검증된 기억 확률을 뜻하지 않는다. 예컨대 85점 같은 승인선을 쓰더라도 그 수치를 학습과학이 정한 기준이라고 말하지 않는다. 全元起·扁鵲·薛己의 좋은 점은 한국어로 명명 가능한 친숙한 사물/행동, 목표 단어와 짧은 연결, 인물에 고정된 특이성이다. ‘특이하다’는 이유만으로 복잡한 말장난에 높은 점수를 주지 않는다.

심사자는 한 후보 전체를 고르거나, 서로 충돌하지 않는 부분만 합친다. 합성 후에는 다시 단서 수·역질문·관계 완전성을 채점한다. 독립 원안 여섯 개, 원안별 점수와 근거, 탈락 이유, 합성본의 변경 내역을 모두 납품한다. 이 과정 자체가 이미지 생성의 허가 기준이 되며 사용자가 매번 중간 승인에 끼어야 하는 절차로 만들지 않는다.

## 14. Opus 실행 순서와 완료 조건

1. **자료 확정**: 최종 기본서·총강·문제집·최신 Gemini 작업물의 실제 파일을 찾아 manifest를 만든다. 미확보 파일은 명단에 남긴다.
2. **원문 감사**: DOCX 표·도형·주석까지 확인해 사실표와 목차를 추출한다. 출전 충돌표·정정표를 만든다. 이 단계에서 그림 내용의 확정 근거를 얻는다.
3. **보존 판정**: 기존 이미지·대본·문답의 좋은 단서를 목록화하고 동일 인물·문헌·숫자 사전을 고정한다. 최신 버전과 이전 버전의 링크도 시험한다.
4. **기억 구조 설계**: 의학사 관계표, 기경 신체도와 사용자 문장, 사암 전체 표, 포제 집합을 각각 설계한다. 독립 6안/심사1을 돌린다.
5. **대표 문제의 먼저 확인**: 陶弘景의 두 문헌 합편, 王冰의 별칭, 숫자 354/359, 陰維 또는 陽蹻의 경로, 사암 한 행의 실제 인출, 醋炙 명단을 대표 시범으로 확인한다. 기준을 통과한 구조를 같은 유형의 전체 단원에 적용한다.
6. **HTML 구현**: 원문 목차·선행경로·별표·썸네일·재생 상태·구간 반복을 구현한다. 작은 파일/자산 분리를 사용해 불필요하게 거대한 단일 HTML로 만들지 않는다. 사용자가 필요하면 독립적으로 열리는 분권 패키지를 제공한다.
7. **전 범위 제작·감사**: 원안 승인 사실의 그림을 만들고 모든 산출물의 필수 단서·구도·문답·대본·목차 위치를 검사한다. 실패하면 원인을 보고하고 기존 승인본을 유지한다.
8. **납품**: 원문별 내용 커버표, 파일별 시각감사표, 보존/수정/재설계/미해결 목록, 6원안+심사+합성본, 깨진 링크 및 재생 검증 결과, 버전 되돌리기 방법을 함께 제공한다.

완료는 확보한 교재 사실과 자산의 분모가 모두 보고되고, 미검토/미확정이 숨겨지지 않으며, 기능 시험과 시각/내용 검사가 통과했을 때 선언한다. 실제 학습자의 지연 인출 검증이 아직이면 그 상태를 별도로 남긴다. ‘전부 완벽’이라는 표현보다 실제 통과 범위와 잔여 항목을 전달한다.

- Sketchy 공식 방법 설명: https://www.sketchy.com/blog/visual-memory-and-elaborative-encoding — 상징, 익숙한 공간, 색·위치·근접성·이야기, 해설, 능동 인출·간격 복습의 결합을 확인. 제품의 효능 표현을 독립적인 실험 결과로 취급하지 않음.

- Roediger & Karpicke, 2006, 인출 연습 원연구: https://pubmed.ncbi.nlm.nih.gov/16507066/ — 단순 재읽기와 구별되는 인출 연습의 설계 근거.

- 王冰, 북경중의약대학 박물관: https://bowuguan.bucm.edu.cn/kpzl/ysmt/38547.htm — 啓玄子/啓元子, 唐, 次注素問 및 편찬·보충·주석의 구별. 본문의 이름·서명 관계 검토에 사용.
- 奇經八脈考, 底本을 표시한 원문 전사: https://jicheng.tw/tcm/book/%E5%A5%87%E7%B6%93%E5%85%AB%E8%84%88%E8%80%83/index.html — 帶·維·蹻의 역할과 순행을 연결할 원문 확인. 사용자의 교재와 다른 가지/혈목록은 강제로 합치지 않음.
- 本草經集注 卷第一, 원문 전사: https://zh.wikisource.org/wiki/%E6%9C%AC%E8%8D%89%E7%B6%93%E9%9B%86%E6%B3%A8/%E5%8D%B7%E7%AC%AC%E4%B8%80 — 神農本經과 名醫 계열 자료의 합편 검토. 전사 판본별 권수 등 차이는 별도 확인.
- 陶弘景/本草經集註, 부산대 KOCW 강의 PDF 검색 결과: https://contents2.kocw.or.kr/KOCW/document/2017/pusan/lyujeongah/6.pdf — ‘神農本草 + 名醫別錄 + 注釋’의 교육자료상 표현 확인. PDF 열기는 타임아웃으로 실패하여 전체 확인했다고 쓰지 않음.

원문은 가능한 한 판본을 가진 고전 전사·대학/공공기관 자료를 대조하고, 한 출처가 내놓은 서로 충돌하는 字/號·연도·서명을 그대로 복사하지 않는다. 자료의 합의 범위와 불확실성을 사실표에 남긴다.
