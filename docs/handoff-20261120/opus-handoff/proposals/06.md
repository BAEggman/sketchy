# 독립 원안 6 — 실제 그림에서 복원되는 정보만 인정하는 재설계

작성 목적: Opus가 실행할 계획이다. 이 문서 작성 중 사이트 코드, 그림, 오디오를 수정하지 않았다. 다른 다섯 원안을 읽지 않고 작성했다. 아래 점수·통과 기준은 설계 심사 기준이며 사용자 기억 성과를 보증하지 않는다.

## 1. 판단과 우선순위

현재 사용자가 반복해서 지적한 문제는 그림의 미감보다 **그림에서 알아낼 수 있는 사실과 설명에 적힌 사실의 불일치**다. 인물 이름만 떠오르고 저서·공헌·의의가 빠지는 것은 문장 보충만으로 해결되지 않는다. 한 단서를 설명할 때 지칭하는 대상과 동작이 실제 전경과 확대 그림에 존재해야 한다. 인물·자호·시대·저서·공헌·의의 중 어떤 것을 어느 소품으로 기억하는지 계약을 먼저 만들고 그 계약을 그림으로 구현한다.

실행 우선순위는 ① 자료와 최신 수정본 확정 → ② 교재 목차와 사실 목록 복원 → ③ 기존 그림·설명·오디오 감사 및 보존 결정 → ④ 단서 설계 경쟁과 심사 → ⑤ 대표 단원 시험 제작·사용자 회상 확인 → ⑥ 전체 제작 → ⑦ 전수 대조와 HTML 허브 검증이다. 누락 목록을 만들기 전에 전면 그림 재생성에 들어가지 않는다. 이미 유효한 단서는 유지하되, 그것에 연결되지 않은 저서·공헌 등의 정보를 추가 설계한다.

## 2. 확인한 것과 아직 확인하지 못한 것

직접 확인한 외부 자료는 아래 출처 목록에 한정한다. 공통 자료 `/tmp/sketchy-opus-plan/evidence/common.md`와 `evidence/current-observations.md`, 최신 `current/lesson_map.json`의 hist-02a·hist-03b·hist-06b·hist-07a도 읽었다. 이 가운데 hist-02a·hist-03b·hist-07a WebP 세 장은 직접 열어 보았다. 공개 저장소의 기준은 main `539bab2a87625459874739246d0c5d8ca931d257`(2026-11-18), lesson_map은 `v7.0-carbon`, 227과다. 사용자 제공 감사 문서와 문제 사례는 요구사항 및 회귀검사 자료로 사용한다. 이 원안만으로 현재 Gemini 그림 결과물 전부, 프로젝트 DOCX 전부, 이전 그림 링크, 음성 실제 재생, Suno 링크의 가사를 확인했다고 주장하지 않는다. 실제 실행자는 최신 자산을 식별한 뒤 파일 단위 증거를 남겨야 한다.

- Sketchy 공식 방법 설명: 익숙한 가상 공간에 기억할 기호를 배치하고 색·위치·다른 기호와의 근접성·이야기를 연결한다. 이것은 제품의 설계 방법 설명이며 이 프로젝트의 효과 검증은 아니다.
- 학습과학 원문: 인출 연습 및 분산 학습을 계획의 중심에 둔다. 키워드·그림 암기법의 유용성은 자료와 과제에 따라 제한되므로 사암의 전체 표를 그림 수만 늘려 해결하지 않는다.
- 陶弘景: 北京中醫藥大學 박물관에서 梁, 字通明, 號華陽隱居 및 『神農本草經』·『名醫別錄』을 합쳐 『本草經集注』로 편집한 관계를 확인했다.
- 杜本: 국가중의약박물관의 설명과 『敖氏傷寒金鏡錄』 전자 원문에서 기존 12舌에 24圖를 추가한 관계를 교차 확인했다. ‘敖氏의 원저’와 ‘杜本의 증보’를 별도 동작으로 표현해야 한다.
- 王冰: 국가중의약박물관 자료에서 唐과 號啓玄子를 확인했다. 다만 개별 사이트가 『重廣補注黃帝內經素問』 등 후대 판본 명칭을 단순 병기할 수 있으므로 저서명·편찬 역할은 교재와 판본별로 분리 확인한다.
- 혈수 349→354→359→360→361의 정확한 저서·저자·판본 대응은 교재 확인 전 확정하지 않는다. 단측 穴名 수와 좌우를 합친 穴位 수, 저서·판본의 집계가 혼재할 수 있다. 특히 354를 어느 저서에 대응시키는지 단순 검색 결과로 확정하면 안 된다.
- 요청받은 cintcm 도메인을 검색했으나 이번 검색에서 위 사실을 직접 뒷받침하는 해당 도메인의 자료는 확보하지 못했다. 다른 신뢰 가능한 중국 기관 자료와 원문으로 확인 범위를 보완했다.

최신 매핑에서 직접 읽은 중요한 차이는 다음과 같다.

- hist-02a에는 흰 양·도공·안경 홍학, 붉은 단지와 검은 단지의 내용물을 합치는 동작, 집 주전자가 실제 보인다. 이 부분은 개선된 요소로 보존할 가치가 있다. 그러나 작은 농부·의원과 그릇의 색만으로 神農本草經/名醫別錄이 특정되는지, 집 주전자로 本草經集注 전체가 복원되는지는 약하다. ‘합편을 전혀 그리지 않았다’는 과거 상태를 현재에도 그대로 적용하면 안 된다.
- hist-03b에는 왕관이 붙은 얼음, 오른쪽 아래의 검은 구슬이 가득 든 열린 상자와 바닥 열쇠가 **실제로 있다**. 최신 문제는 부재가 아니라 열쇠가 떨어져 있어 ‘열기’ 동작과 王冰·啓玄子 귀속이 약한 것이다. 물체의 존재와 관계의 가독성을 따로 평가해야 한다.
- hist-06b는 杜本을 두더지+나무 뿌리, 제목을 오이씨·담요·금거울, 36을 삼지창·육각너트로 기록한다. ‘오이씨→敖氏’의 독음 근접성, 나무 뿌리→本의 비직관성, 원저와 증보 관계 누락을 점검한다. 좋은 기존 요소가 있으면 아래 신규 후보보다 먼저 비교한다.
- hist-07a 제목은 `349→354→359→359→361`이고 王執中359와 楊繼洲359가 각각 존재한다. **반복된 359를 오타로 보고 하나를 360으로 바꾸면 안 된다.** 현재 吳謙 『醫宗金鑑』에 361을 붙이고 ‘교재·기출 확정’이라 쓰며 『針灸逢源』을 한 줄로 낮춘 부분이 출전 충돌 해결의 핵심이다. 사용자 요청의 360 항목을 따로 검증·복원하고, 필요한 계보는 항목 수 자체를 늘려 두 개의 359를 모두 보존할 수 있다.
- 공통팩에 따르면 DOCX doc4에도 吳謙 행에 『醫宗金鑑』·『鍼灸逢源』/361이 묶여 있고 354/355 변이가 있다. 교재는 범위 기준이지만 모순된 표를 무조건 정답으로 삼지 않는다. doc4의 奇經 유주 이야기와 사암 문장, doc7의 醋炙 12개가 존재한다는 사실은 공통 조사에서 전달받았으며 이 원안에서 직접 전체 전사·대조한 것은 아니다.
- 공통 실물 조사에서 new-gr-14의 띠·그물·죽마는 존재하지만 공간 유주가 약하고, 陽蹻의 요약 끝점이 JSON 風府와 DOCX 風池로 어긋난다고 보고되었다. 이것은 어느 하나를 즉시 정답 처리할 사안이 아니라 출전·요약 범위의 대조 대상이다. new-gr-19의 우물 장면과 원문 ‘태백산의 태연이’도 대응 확인이 필요하다.
- 공통 조사에서 『한의학총강 통합 제3장~제11장 p226~874』 DOCX, 5,444문단이 추가로 확인되었다. 텍스트는 문맥 OCR 검증이 필요하며, 총강과 기본서의 장 번호가 다르므로 책별 분모와 목차 대응표가 필요하다.

## 3. 교재 중심의 전수 목록과 목차

Opus의 첫 산출물은 그림 목록이 아니라 **출전이 붙은 사실 목록**이어야 한다. 한의학기본서·한의학총강의 판본, 파일 해시, 목차 계층, 본문 표·각주·그림 설명까지 추출한다. DOCX의 제목 스타일만 믿지 말고 실제 목차와 페이지/표 제목을 대조한다. 쪽 번호가 불안정하면 원본 파일명+절 번호+표 행/열+문단 식별자를 함께 남긴다.

공통 파일 조사에서 13~16장 이름의 빈 폴더와 별도 한의학개론 원본 PDF 경로도 발견되었으나 본문은 아직 확인되지 않았다. 따라서 발견한 DOCX 장 번호까지만을 전체 교재 범위로 단정하지 않는다. 빈 폴더는 내용 존재 증거가 아니며 원본 PDF의 실제 목차·페이지를 읽어 범위를 확정한다.

각 사실에는 다음 필드를 둔다.

| 필드 | 필요한 내용 |
|---|---|
| 출전 | 교재·판본·장절·쪽·문단 또는 표 위치 |
| 사실 | 한 번에 참/거짓을 판정할 수 있는 문장 또는 관계 |
| 범주 | 인물·字號·국가/왕조·저서·공헌·의의·유주·혈명·포제 대상·원문 등 |
| 조건 | ‘최초’의 범위, 현존 여부, 저술/증보/교정 역할, 예외, 출전 차이 |
| 현재 매핑 | 강의 ID·그림 ID·정거장 ID·설명 문장·음성 구간 |
| 실제 표현 | 전경 소품/행동, 확대 위치, 표현하지 않는 사실의 대체 학습 방식 |
| 상태 | 미검토 / 근거 확인 / 단서 설계 / 생성 실패 / 검수 통과 / 회상 시험 대기 |

커버리지는 서로 다른 네 수치로 낸다. ① 교재 사실을 목록화한 비율, ② 학습 항목에 연결한 비율, ③ 그림/표/설명/문답을 실제 대조한 비율, ④ 사용자의 회상 시험을 거친 비율이다. 파일이 존재하는 것을 ‘내용을 다 봤다’로 계산하지 않는다. 정당한 제외는 출전과 이유를 남긴다. 처리되지 않은 행은 숨기지 않는다.

허브는 `교재 → 편 → 장 → 절 → 개념/강의 → 전경 → 단서 확대·비교 그림` 순으로 표시한다. 교재 순서를 기본 순서로 고정하고, 다른 단원에서도 쓰는 그림은 같은 자산에 대한 교차 링크로 표시한다. 교재 두 권의 목차가 다르면 한 권으로 다른 권을 덮어쓰지 않고 책 선택 및 대응표를 둔다. 그림의 고유 ID와 별표 저장 키는 목차 변경으로 바뀌지 않아야 한다.

공통 코드 조사에서 `src/lessons/build_player.py`의 ID 사전순 정렬이 확인되었다. 이를 단순 자연수 정렬로 바꾸는 것으로 해결하지 말고, 교재 장절별 명시적인 순서와 교차참조를 출력하도록 계획한다. 기존 `hist-*`, `new-gr-*` 등 파일 접두사가 교육적 선행관계나 교과서 순서의 근거가 되어서는 안 된다.

선수관계는 목차와 별도로 둔다. 예: 오행 기본 대응과 相生相剋 → 五輸穴의 오행 배속 → 사암 기본 구성 → 正格·勝格 전체표 → 寒格·熱格 및 예외. 奇經은 음양/내외·신체 표면의 기준 → 각 맥의 유주 → 交會穴·八脈交會穴 등 해당 교재 관계로 진행한다. 의학사는 시대 지도 → 인물·자호 → 저서 편찬 관계 → ‘최초’·혈수 계보 → 혼동 대조의 순서를 추천하되, 사용자가 목차를 자유롭게 탐색할 수 있게 한다.

## 4. Gemini 수정 내용 감사와 보존

현재 파일의 변경 시각만으로 ‘최신’을 판단하지 않는다. 저장소 커밋, 내보낸 HTML, 연결 이미지, 설명·오디오를 한 묶음으로 기록하고 실제 링크 해석 결과를 확인한다. 파일명에 v5/v6가 있어도 동일 이미지일 수 있으므로 해시·크기·해상도와 참조 관계를 확인한다.

보존은 자산 전체에 하나의 판정을 주는 방식보다 다음처럼 나눈다.

| 판정 | 기준 | 조치 |
|---|---|---|
| 보존 | 사실이 맞고 역회상·오독 검사를 통과한 기존 기호 | 이름·외형·역할을 고정한 채 유지 |
| 부분 수정 | 성공한 인물/장소는 있으나 소품 한 개 또는 동작이 누락 | 해당 관계만 수정하고 다른 기호의 변형 여부 재검사 |
| 재구성 | 여러 정거장 혼입, 저서/공헌 관계 부재, 전경과 확대 불일치 | 성공한 기호 사전은 유지하고 공간 배치부터 재구성 |
| 다른 형식으로 전환 | 정확한 표·숫자·유주를 장면만으로 복원하기 어려움 | 검증된 도해·가림표·인출 카드와 최소한의 이미지 결합 |

좋은 오디오 아이디어는 소리·문장·표현을 보존할 수 있다. 다만 그림에 없는 소품을 ‘여기에 보이죠’라고 말하는 대본은 그대로 보존하지 않는다. 이야기의 좋은 부분과 사실의 연결을 분리하여 각각 근거를 기록한다.

## 5. 단서를 그리기 전에 만드는 시각 명세

모든 단서마다 아래 정보를 확정한다.

1. 목표 정답: 예를 들어 王冰의 號가 啓玄子라는 **관계**.
2. 보이는 요소: 동일한 王冰 기호(현재는 왕관이 붙은 얼음), 실제 검은 구슬, 구슬에 꽂힌 열쇠, 열린 구슬의 경계. 상자를 여는 버전을 선택하면 상자·열쇠·구슬의 관계를 명세에 정확히 바꿔 적는다.
3. 행위와 소유: 누가 무엇을 여는지. 열쇠와 구슬이 따로 놓여 있으면 관계가 약해진다.
4. 혼동 대상: 검은 구슬이 腎/水의 기호로 오독되는지, 열쇠가 다른 인물의 저서 기호인지.
5. 전경에서의 위치와 확대 범위: 확대해도 행위자·대상·행동의 필요한 부분이 함께 남아야 한다.
6. 설명·음성 대응: 어느 문장에서 어떤 보이는 물체를 설명하는지. 보이지 않는 것은 보인다고 말하지 않는다.
7. 회상 문항: 그림→대상, 대상→그림 위치, 책→저자, 공헌→책/인물, 유사 인물의 바꿔치기.
8. 실패 판정과 대안: 없거나 읽히지 않으면 재생성할 부분, 다시 실패하면 사용할 정확한 대체 학습 형식.

이미지 안 글자는 원칙적으로 쓰지 않는다. 사실의 정확한 한자 표기는 HTML 설명·정답·인출 화면에서 제공한다. 숫자·유주·표의 정확성이 핵심인 별도 도해는 검증 가능한 글자·선을 사용하되, 이것을 이미지 생성 모델이 그린 글자에 맡기지 않는다. 단서 그림에 글자가 꼭 필요한 예외는 이유를 명시하고 최소 단위로 제한한다.

## 6. 성공한 단서가 좋은 이유와 새로운 후보

全元起→전원 기립은 음절이 가깝고 ‘전원’이 다 같이 일어나는 한 동작에서 보인다. 扁鵲→납작 엎드린 까치는 형태와 특정 동물이 결합되어 기억할 대상이 좁혀진다. 薛己→백설기는 친숙한 사물명 속에 목표 독음이 거의 그대로 들어 있다. 세 예 모두 사전 설명을 조금 받은 뒤 시각에서 단어를 역으로 꺼낼 수 있고, 복잡한 한자 풀이를 여러 단계 거치지 않는다. 이것이 다른 이름·저서·공헌까지 자동으로 기억된다는 뜻은 아니다. 성공한 이름 단서에 필요한 관계를 추가해야 한다.

아래는 심사 전 후보이며 채택안이 아니다. 한자 뜻풀이와 독음 연상은 구별하여 기록한다. 숫자나 복합 저서 기호는 사전에 학습한 기호표가 있어야 한다는 비용을 숨기지 않는다.

## 7. 의학사 재구성의 공통 형식

각 의가를 하나의 ‘이름 맞히기’로 보지 않고 여섯 항목을 갖는 관계로 설계한다.

| 항목 | 그림에서 구현할 방법 | 반드시 다른 방향으로 물을 질문 |
|---|---|---|
| 인물 | 이미 잘 먹히는 독음·형태·동작 기호 | 소품→인물 |
| 字·號·別稱 | 같은 인물에 귀속된 별도 행동 또는 소품 | 자호→인물, 인물→자호; 字와 號 구별 |
| 국가/왕조 | 시대 전체에서 일관된 배경 구획 | 책/인물→시대; 출생/활동/출판 시기 혼동 방지 |
| 저서 | 제목을 복원할 고유 기호와 그 사람의 쓰기·편집·증보 동작 | 책→저자/편자, 저자→책 |
| 기여 | 전/후가 보이는 변환이나 전달 | 행위→인물/책, 같은 작업을 한 다른 인물과 구별 |
| 의의 | 최초·현존 최초·공식 편찬 등의 조건을 구분하는 관계 | 무엇이 최초이며 어느 범위인가 |

徐之才·全元起·楊上善·劉涓子 역시 이 형식으로 전수 확인한다. 교재에 있는 모든 자호를 무조건 한 장면에 몰지 않고 시험 대상 관계로 기록한 뒤 전경·세부·가림 문답으로 분담한다. 인물 외형만 그려져 있으면 저서·공헌 항목은 미완료로 남긴다. ‘최초’ 메달 하나는 최초 本草/현존 舌診 전문서/국가 공인 藥典을 구별하지 못하므로 분야와 범위를 함께 복원하는 검사가 필요하다.

## 8. 奇經·경락의 빠진 부분을 채우는 방법

DOCX의 奇經八脈 구절·유주 mnemonic을 먼저 찾아 원문과 함께 보존한다. 해당 교재에 등장하는 모든 유주 항목을 기시·경유·분지·종지·左右/內外·交會·주치 등의 실제 항목별로 분해한다. 없는 항목은 임의로 채우지 않는다. 해부학 도해는 정확한 표면 기준과 전후·좌우가 고정된 그림을 사용하고, 생성 이미지로 혈위의 정확성을 판정하지 않는다.

학습은 ① 전체 이름·역할의 상징 → ② 몸 위 순서 따라 말하기 → ③ 선 일부/지점 이름 가리기 → ④ 빈 인체 위 복원 → ⑤ 두 맥의 혼동 비교 순으로 진행한다. 循行 순서를 연상하는 상황 그림과 실제 도해의 각 지점을 일대일로 연결한다. 卒中 등의 임상 연결은 교재 범위에서 별도 표시하고, 유주 자체와 동일한 사실인 것처럼 합치지 않는다. 오행 배속·臟腑·經脈 관계도 검증된 출전이 있는 경우에만 연결한다.

## 9. 사암침법: 그림 수 대신 전체 표의 정확한 재구성

목표는 표를 설명할 수 있는 수준에 그치지 않고 혈명을 모두 쓸 수 있는 것이다. 이를 위해 다음을 함께 만든다.

1. 교재의 사암 표를 행·열·출전 그대로 전사한 기준표. 正格·勝格·寒格·熱格·虛實 관련 표의 실제 범위를 전부 목록화한다.
2. 十二經 五輸穴의 이름과 오행 배속을 정확히 인출하는 바탕표. 이름의 독음 연상은 이 층에서 재사용한다.
3. 기본 원리로 표를 생성해 보는 연습. 원리에서 유도한 결과를 기준표와 모든 셀에서 대조한다. 계산 가능한 항목과 출전별 예외를 나눈다.
4. ‘경맥+格 → 補 두 혈·瀉 두 혈’을 적는 무단서 인출, 補瀉를 바꿔 제시한 오답 감별, 두 혈→어느 경·格인지의 역방향 인출.
5. 첫 학습은 유사 구조끼리 설명하되, 숙달 뒤에는 正/勝·寒/熱과 혼동되는 경맥을 섞어 인출한다. 매번 처음부터 표 전체를 읽기만 하지 않는다.
6. 세션에서는 일부 행을 뽑아 쓰고 주기적으로 전체 표를 빈칸 없이 재구성한다. 틀린 혈명·補瀉·경맥·순서 종류를 따로 기록한다.

‘大腸의 陽谿를 解谿로 잘못 쓴 경우’는 한 글자 오타 검사만으로 끝나지 않는다. 해당 경맥의 五輸配屬과 校正 근거까지 확인한다. ‘熱格瀉에 예외가 없다’ 같은 규칙 문장은 모든 행이 실제로 그 규칙을 만족하는지 계산·대조한다. 원리로 유도하지 못한 셀을 추정해서 채우지 않는다.

그림은 공통 구조와 혼동 큰 혈명의 보조에 제한한다. 각 처방마다 거대한 새 장면을 만들지 않는다. 표의 셀마다 기존 혈명 기호를 재사용할 수는 있으나 이것이 더 많은 그림 학습을 요구한다면 가림표가 더 낫다. 반복 간격은 처음에는 당일·다음날·며칠 뒤 등으로 시험하고 실제 오답에 따라 조정한다. 특정 간격을 보편적 최적값으로 보증하지 않는다.

## 10. 포제법·본초는 목록의 완전성과 두문자 복원을 우선

각 법에 대해 ‘교재의 방법 정의–대상 본초 전체–효과/목적–예외/다른 법과 중복’을 전사한다. 사용자 제공 두문자와 음원은 원문을 확보한 뒤 정확히 대응한다. 노래 링크 제목만으로 가사나 대상 본초를 상상하지 않는다.

두문자 한 덩어리는 말하기 쉬운 길이로 나누되 분할 크기는 사용자 시험으로 정한다. 각 음절이 어떤 **본초 전체 이름**으로 복원되는지 대응표를 둔다. 리스트가 길면 짧은 장면 두세 개와 순서 고리를 쓰며, 한 장에 낯선 물체를 십수 개 쌓는 것을 피한다. 첫 글자가 같은 본초가 있으면 추가 음절·성상·사용자 기존 연상을 보태어 구분한다. 순서 자체가 시험 대상인지, 집합 완전성이 목표인지도 구별한다.

검사는 방법→본초 목록 전체 쓰기, 본초→포제법 모두 고르기, 비슷한 두 법의 집합 차이 쓰기를 포함한다. 두문자 구호만 외우고 원래 약명이 나오지 않으면 학습 완료가 아니다. 약재 효능·포제 의의의 임상 연결은 교재에서 검증한 범위로만 붙인다.

## 11. HTML 허브와 재생 기능의 구현 명세

그림 한 행은 왼쪽에 작은 썸네일, 가운데에 제목·하위 관계·링크, 오른쪽에 토글 가능한 별표로 배치한다. 썸네일은 실제 현재 그림에서 만들고, 구판 보기 링크는 현재 자산과 구분된 버전 ID를 참조한다. 별표는 학습 성취/검수 통과와 섞지 않는 사용자의 중요도 표식이다. 누르면 켜지고 다시 누르면 꺼지며 키보드로도 가능하고 새로고침·정렬 변경 뒤 유지되어야 한다.

자동 다음의 기본값은 꺼짐으로 제안한다. 켜면 음성이 있는 그림은 종료 이벤트 이후, 없는 그림은 사용자가 정한 대기 시간 이후 다음으로 이동한다. 음성이 로드되지 않는 오류와 ‘음성 없는 항목’을 구별한다. 오류 때문에 무한히 빨리 넘어가거나 조용히 누락시키지 않는다. 수동 이동·일시정지·설명 열기 중 예약된 다음 이동이 뒤늦게 실행되지 않도록 현재 재생 ID에 결속시킨다.

반복은 끔/전체/구간 세 상태로 명확히 표시한다. ‘전체’의 범위는 현재 선택한 장/재생목록으로 UI에 보여 준다. 구간은 시작 그림 A와 끝 그림 B를 지정하고 양 끝 포함, A=B도 가능하다. 자동 다음은 그림 간 이동 여부를 제어하고, 반복은 끝에 도달했을 때 돌아갈 위치를 제어한다. 자동 다음을 끄면 현재 그림 뒤 자동 이동은 멈추고 반복 범위 설정만 보존한다. 이 동작을 버튼 근처의 짧은 도움말로 설명한다.

| 상태 | 음성/대기 종료 때 동작 |
|---|---|
| 자동 다음 끔 | 현재 그림에서 멈춤 |
| 자동 다음 켬 + 반복 끔 | 다음 그림, 마지막이면 멈춤 |
| 자동 다음 켬 + 전체 반복 | 목록 마지막에서 첫 그림으로 이동 |
| 자동 다음 켬 + 구간 반복 | B 종료 시 A로 이동 |

필터 변경으로 구간 끝점이 사라지면 현재 범위를 조용히 다른 그림에 붙이지 말고 반복이 일시 정지되었음을 표시한다. 브라우저의 음성 자동재생 차단은 수동 재생 버튼으로 처리한다. 자동재생만 한 것을 암기 성공으로 기록하지 않는다. 모바일·키보드·이미지 로드 오류·뒤로가기·북마크 링크를 확인한다.

## 12. 여섯 독립안과 일곱 번째 심사 절차

각 생성 에이전트는 동일한 사실 목록·기존 성공 기호·금지 충돌·기존 그림을 받고, 다른 제안은 보지 않은 채 목표별 후보를 낸다. 역할을 달리 주더라도 각 안은 인물·저서·의의·관계·유주·표 학습·UI와 검수 계획을 모두 답해야 한다. 서로 다른 과목을 나누어 맡은 여섯 보고서를 여섯 독립 대안이라고 부르지 않는다.

제안에는 대상 사실 ID, 후보 소품·행동·배치, 독음 대응, 역회상 질문, 예상 오독, 표현 난이도, 유지할 요소, 탈락 대안, 필요한 확인 자료를 반드시 넣는다. 일곱 번째 심사자는 처음에 아래 기준을 고정하고 각 안을 익명으로 채점한다.

| 기준 | 배점 | 판단 |
|---|---:|---|
| 사실 정확성·출처 | 20 | 출전·예외·귀속이 맞고 충돌이 드러나는가 |
| 단서에서 정답으로의 역회상 | 25 | 발음 연상이 자연스럽고 보이는 대상이 충분한가 |
| 관계와 차이의 표현 | 15 | 인물–자호–책–작업–의의, 입력/출력, 음양/보사 등 방향이 보이며 기존 기호와 충돌하지 않는가 |
| 교재 범위·선행 순서 | 15 | 필수 사실의 누락과 학습 순서를 식별하는가 |
| 장면 경제성·구현 가능성 | 10 | 이미지 수·새 기호 수·읽어야 할 글자·그림 난도를 감당하는가 |
| 검증 가능성과 실패 처리 | 10 | 실제 시각 확인·음성 대응·사용자 회상·철회 절차가 있는가 |
| 근거와 한계 | 5 | 검증된 사실·설계 가설·미확인을 구분하는가 |

총점이 높아도 사실 오류, 필수 사실 누락, 그림 없는 설명, 단서 혼입, 잘못된 혈명·경로·숫자는 해당 항목을 채택 불가로 한다. 85점 이상을 시험 제작 후보로 삼는 것은 운영 제안이며 과학적으로 입증된 임계값이 아니다. 70~84점은 구체 수정 후 재심사, 그 미만은 재설계한다. 최종 조합은 좋은 부분의 출처를 밝히고 합친 뒤 장면 전체를 다시 심사한다. 서로 상충하는 왕조 기호나 숫자 기호를 섞지 않는다.

공통 조사에서 기존 `carbon/blind/hist-03b_score.md`는 王冰을 검출하지 못했는데도 전체 PASS를 부여한 것으로 보고되었다. 이런 상황은 핵심 인물 단서의 실패를 평균점수가 덮은 것이다. 새 심사는 총점과 별도로 필수 사실별 통과표를 두어 한 항목의 중요 누락을 다른 장식적 성공으로 상쇄하지 못하게 한다.

심사 결과와 별개로 사용자 회상시험 전에는 ‘설계 통과’, 그림 생성 뒤 실제 존재 확인 전에는 ‘그림 통과’라고 부르지 않는다. 어느 에이전트나 모델이 실제 수행했는지 로그에 기록하고 사용할 수 없는 Opus/Gemini 모델을 사용했다고 말하지 않는다.

## 13. 그림 생성·수정과 실패 처리

먼저 성공한 인물과 화풍을 참조 이미지로 고정한다. 프롬프트의 ‘열쇠·검은 구슬’ 항목을 체크하는 것만으로 생성 결과에 있다고 판단하지 않는다. 원본 크기·모바일 크기·실제 썸네일에서 보고, 설명을 가린 상태에서도 대상·행동·관계를 읽을 수 있는지 확인한다.

전경과 확대 그림을 별도로 그리면 인물·옷·공간·행동이 달라질 가능성이 있다. 원칙은 승인된 전경에서 확대를 추출하되, 작은 소품이 충분히 선명하지 않으면 전경 소품 자체를 수정한다. 별도 확대 그림이 필요하다면 동일 사건의 상세화임을 확인하고, 전경에 없는 새 사건을 확대라고 붙이지 않는다.

한 오류에 대해 재시도는 문제를 진단한 뒤 소품/동작을 단순화하여 실시한다. 예를 들어 ‘손을 배에 놓기’ 실패를 장식 추가로 해결하지 않는다. 초안+수정 2회 정도를 한 검토 묶음으로 제안하되 고정 횟수만 채운다고 합격시키지 않는다. 계속 실패하면 원래 유효한 자산을 보존하고, 실패 이유·시도본·대체 도해 또는 재구성안을 남긴다. 깨진 그림을 정식 버전으로 승격하지 않는다. 그림을 갈아엎으면 그에 종속된 크롭·썸네일·설명·음성·이전보기 링크를 모두 갱신한다.

## 14. 필수 검수와 기존 결함 회귀검사

전수검사는 이미지 파일 수만 세는 작업이 아니다. 전경 전체, 각각의 크롭, 문답, 음성 대본/실제 구간을 사실 ID에 맞춰 모두 본 기록이 있어야 한다. 중복 파일은 실제 동일함을 확인한 경우 재사용 검수로 표시할 수 있으나 서로 다른 문맥의 오독 검사는 생략하지 않는다.

## 15. 완료 정의와 Opus 인수인계 산출물

‘전부 끝남’은 정해진 범위의 미검토 수가 0이고, 실패·제외·사용자 시험 대기 항목까지 공개했을 때만 사용할 수 있다. 그림의 완벽함이나 모든 사용자의 장기 기억을 보증하지 않는다. 공통 조사에서 전달된 기존 보고서의 99.3%→97.04%(43과), 조건부3개/CHECK1개 같은 숫자는 해당 검사 범위·분모·방법을 확인한 뒤 참고한다. 이 숫자를 227과 전체의 정답률이나 사용자의 기억 성과라고 표기하지 않는다.

Opus는 최종적으로 다음을 제출한다.

1. 교재·버전·목차와 사실별 커버리지 표, 누락·충돌·출전 미확정 목록.
2. Gemini 기존 결과의 보존/수정/재구성/다른 형식 전환 기록과 이전 파일을 여는 링크.
3. 여섯 독립 원안 원문, 일곱 번째의 고정 루브릭·점수·탈락 이유·통합 출처.
4. 최종 단서 사전과 인물/왕조/책/숫자 기호의 재사용 규칙.
5. 제작 전 시각 명세, 생성 후보·실패 기록, 전경/크롭/설명/음성 일치표.
6. 사암 전체 기준표·예외표·빈칸 인출, 奇經 유주 원문·정확 도해·복원 문항, 포제 대상 목록·두문자 대응표.
7. 교재 목차 허브와 별표·썸네일·자동 다음·구간/전체 반복, 실제 기능 검증 결과.
8. 사용자 즉시·지연 회상 시험 결과 또는 아직 시행하지 않았다는 명시.

시험 제작은 陶弘景, 王冰 啓玄子, 杜本, 혈수 계보, 奇經 한 쌍, 사암 한 묶음, 醋法 한 목록처럼 실패 유형이 다른 대표 대상으로 한다. 여기서 새 기호가 실제로 기억되는지와 제작 난도를 확인한 뒤 전체로 확장한다. 표본 검사를 전체 검수의 대체로 사용하지 않는다.
