# 한의학 음성 첫 묶음 통합

23구간: 원본 22개와 zds-11#1 take2 1개. 음성 생성은 Gemini Kore이며, 별도 Gemini 오디오 입력 검수와 승인 대본 대조를 수행했다. Codex 직접 청취로 표시하지 않는다. 사용자의 기준에 따라 경미한 연음·모음·억양 차이는 통과시키고 주요 개념·숫자·누락·잘림만 보류한다.

업로드된 WAV 26개(원본23+비교3)의 ZIP CRC, SHA256, 크기와 재생 시간을 검증했다. 선택한23개를 96kbps MP3로 변환했다. 원본 WAV는 사용자 업로드 ZIP에 보존되며 원본 해시는 audio/narration/manifest.json에 기록했다. 비교후보 중 s2/s6 take2는 사용하지 않는다.

빌드는 정거장 데이터·승인 대본·그림·배포 음성 해시를 검사한다. 실제 audio ended 이벤트로만 자동 이동하며 중지·이동은 이전 음성을 취소한다. 재생 실패는 자동 넘김 없이 다시 듣기를 제공한다. 미녹음 구간은 기존 브라우저 TTS를 유지한다.

검증: 전체 플레이어 빌드 227과/2067정거장/227그림, 경고0; JavaScript 구문 검사; ended 전 이동 방지·속도·중지·지연 이벤트·재생 거부·TTS fallback 동작 테스트 통과. 실제 기기에서의 최종 재생 확인은 별도다.
