# 반말 변환 후 재검토 — 2026-11-20

낭독문 2,806개와 제외 메모 3행의 전후 전문을 대조했다. 4,335회 어미 치환의 서로 다른 형태 663쌍을 검토하고, 동사·형용사 구분 및 명사와 서술격 어미의 결합을 살폈다. ‘적습니다’는 수량이 적은 문맥, ‘짭니다’는 천을 짜는 문맥, ‘보입니다’는 씨가 보이는 문맥임을 확인했다.

첫 두 곳은 반말 축약 뒤의 청취 모호성을 줄인 수정이다. 셋째는 기존 문장부호 문제이며 반말 변환이 새로 만든 오류는 아니다. 실제 음성의 청취 결과는 아니다. 정확한 전후 전문은 [추가 수정 기록](post-conversion-review-edits.json)에 남겼다.

## 전체 대조 결과

- 변환 함수를 호출하지 않고 어미 치환 위치, 수동 보완, 안내말 축약, 이번 추가 수정의 기록만으로 최종 대본 2,809행을 재현했다. 기록 밖의 변경은 없었다.
- 어미 변환 단계의 부정·금지·예외 표지와 문장부호를 보존했다.
- 전체 최종본에서 기존 숫자 표기와 한자, 큰따옴표 안 니모닉이 삭제되지 않았다. ‘45세부터 위가 약해진다’ 이야기도 유지했다.
- 원대본·원자료 필드, 카드 ID와 순서, 기존 보류 사유를 보존했다.
- HTML 2,809행, 본편 CSV 2,067행, 본편·부록 TXT의 낭독문이 최종 JSON과 일치했다. 본편 이미지 경로 227개를 확인했다.
- ‘양보·허불수보’를 ‘보인다’의 활용으로 바꾸지 않는 구분도 유지했다.

현재 확인한 범위에서는 추가적인 변환 손상을 발견하지 못했다. 자동 대조는 기록된 편집의 정확한 적용과 원문 보존을 확인하며, 의미나 의학적 사실의 완전성을 자동으로 증명하지 않는다.

## 남은 검토와 적용 범위

그림 불일치·세부 미확정·기존 의미 검토 등의 이유로 본편 464구간은 계속 보류한다. 부록 79판의 실제 그림 전수 대조와 why 필드에 섞인 추가 개념·제작 이력 정리는 미완료다. 원전 전수 확인과 음성 생성·발음 청취 검수도 완료한 것으로 표시하지 않는다.

반영 대상은 검토 페이지와 녹음용 대본 자료다. 기존 학습 플레이어의 say/tts와 과거 음성은 이번 게시로 교체하지 않는다. 공개 제작 계획에서는 개인 Gemini 세션과 기기·다운로드 실행 기록을 제거하고 공통 제작 절차만 남겼다.
