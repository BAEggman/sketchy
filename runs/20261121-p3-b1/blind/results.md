# B1 두 판독자 결과 (2026-11-21, 열쇠 모르는 판독자 둘, 전체 + 좌우 반쪽 원본 크기)

자동 판독은 참고치다. 합격은 사용자 검수.

## hist-04 — 새로 넣은 단서 모두 둘 다 읽음
- 아기 무릎 다섯 색 그림책 + 손 ○○ / 국방색 상자 탑 + 꼭대기 메달 ○○ / 약사 손의 붉은 봉인 초록(국방)색 책 ○○ / 허수아비 짚손 갈색 책 ○○ / 진돗개가 무를 묾 ○○ · 빈 말풍선 ○○ · 앞발이 닿는 곳은 「가면」으로 읽힘(책 아님) △△ / 걸상 위 펼친 책에서 회오리 · 벌 ○○
- 글자 · 숫자 없음, 이음매 없음.

## hist-05a
- 唐愼微 책(사탕과 같은 손) ○○ — 「한 손에 둘이라 답답」 지적 / 송아지 발굽이 꽃 그림책 위 ○○ / 證類 메달 없음 ○○ / 노란 큰 책의 획 지움 ○○
- 고칠 거리(옛 그림에서 남은 것, 이번 편집 밖): 금빛 두루마리 통에 글자처럼 보이는 꼬불꼬불한 줄(둘 다 지적), 가위질하는 책 면의 글자 같은 줄. → 묶음 뒤 「실패 · 손질 모음」에 넣음.
- 삿갓 노인의 물줄기는 보류 단서(寇宗奭) — 그대로.

## hist-05b
- 張元素: 깃발 · 붉은 주머니 진주 ○○, 어사화는 「상투에서 휘어 오른 꽃 덩굴」로 읽힘 △○ (어사화 모양 그대로 — 소리 단서는 대본이 진다)
- 李時珍 붉은 옷 · 검은 모자, 두 손이 그물 벼리 ○○ (얼굴이 그물에 가려 「모자가 납작」 지적 하나)
- 趙學敏 민들레 집기 ○○ / 姚瀾 펼친 책 + 바구니로 약초 ○○(책에서 쏟는다기보다 손에서 떨어뜨림으로 읽힘 △)
- 요요 든 손만 떠 있음(옛 그림, 姚瀾 단서 보류) — 그대로.
- 글자 · 숫자 없음.
