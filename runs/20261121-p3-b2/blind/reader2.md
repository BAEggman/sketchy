# reader2 판독 기록

## hist-01a (한옥 대문 + 대청 마당)

1. 사람·동물
- 왼쪽 소년: 하늘색 저고리 + 남색 조끼, 회갈색 바지, 흰 버선·검은 신, 남색 머리띠 + 상투. 오른손으로 머리 긁음(땀/당황 표시 선), 왼손에 펼친 두루마리 종이를 쥠. 발밑 땅에 펼쳐진 두루마리 하나 더 떨어져 있음(몸에 안 닿음).
- 노인: 흰머리 쪽(상투), 안경, 흰 수염, 갈색 두루마기·베이지 저고리. 무릎 꿇고 앉아 젊은이의 손목을 손가락으로 짚음(맥 보기?).
- 젊은이: 검은 머리 묶음, 남색 조끼·베이지 옷, 무릎 꿇고 팔을 노인에게 내밂.
- 대청 위 남자: 남색 도포, 흰 바지, 검은 신, 남색 머리띠 + 상투. 오른팔(그림 왼쪽)에 손인형(노란 옷·빨간 띠·흰 수염·관 쓴 노인) 끼움. 왼손(그림 오른쪽)은 빨간 끈으로 묶은 책/종이 묶음을 어깨 높이로 들고, 같은 손에서 가는 막대(침? 붓?)가 오른쪽으로 뻗음. 머리 옆 떨림 표시 선. 나무 마루 위에 서 있음.
- 오른쪽 남자: 긴 머리·수염, 나뭇잎 망토 + 나뭇잎 치마, 맨발. 왼손으로 풀 줄기를 입에 물고 맛봄, 오른팔로 초록 책을 배에 끌어안음. 발 옆에 풀 담긴 바구니, 바닥에 잎 몇 장.
- 까치: 대문 지붕 용마루 위에 앉음.

2. 책
- 초록 책(잎 무늬 표지): 잎 옷 남자가 오른손·팔로 몸에 붙여 꽉 쥠. 손 떨어져 있지 않음.
- 대청 남자의 빨간 끈 묶음(책 더미?): 왼손 손가락으로 아래를 받쳐 듦. 손과 닿아 있음.

3. 글자·숫자
- 뚜렷한 글자 없음. 벽 액자 3개는 비어 있음. 두루마리 2장도 백지. 꼬불꼬불 줄 없음.

4. 이상한 점
- 북이 대문 문턱 위에 옆으로 누워 있고 흔들림 표시 선 → 굴러가는 중? 
- 대청 남자 왼손에서 묶음 + 가는 막대가 동시에 나옴 → 막대가 손에 쥐어진 건지 떠 있는 건지 애매?
- 금메달(빨간 끈)이 기둥에 하나, 약재 선반에 하나 걸려 있음(누가 건 건지 맥락 없음).
- 이음매·번짐은 눈에 띄지 않음. 손가락 이상 없음.

5. 헷갈릴 물건
- 누운 북: 북 / 술통·바퀴?
- 빨간 끈 묶음: 책 더미 / 선물 상자·편지 꾸러미?
- 손인형: 인형 / 작은 신선·사람?
- 사계절 원판(봄 꽃·여름 해·가을 단풍·겨울 눈 소나무): 둥근 창 / 시계·간판?
- 선반의 말린 약재(보라 꽃다발, 빨간 고추 같은 것, 초록 콩깍지, 뿌리): 약재 / 채소·고추?
- 빈 액자: 액자 / 작은 창문?
- 기둥의 금메달: 메달 / 방울·종?

## hist-02b (기와 건물 정원 + 버드나무)

1. 사람·동물
- 하늘색 도깨비(요정?): 뾰족 귀, 큰 입 웃음, 목에 노란 줄자를 걸침. 오른손(그림 오른쪽)으로 종이 한 장 들고/떨어뜨림, 돌 벤치 위를 뛰어넘는 자세. 몸이 벤치에 닿지 않음(공중).
- 선생: 갈색 도포, 상투, 콧수염·턱수염. 양손으로 펼친 책(색색 책갈피)을 들고 읽음. 나무 탁자 뒤에 섬.
- 양: 흰 털, 회색 얼굴, 빨간 굴레·줄. 줄 끝이 풀밭에 늘어져 아무도 안 잡음. 탁자 옆에 섬.
- 학생 4명: (1) 회청색 옷, 손 모으고 놀란 얼굴 (2) 진회색 옷, 놀란 얼굴 (3) 갈색 머리 묶은 소녀, 검은 옷, 손 모음 (4) 뒷모습, 긴 땋은 머리, 검은 옷. 모두 선생 쪽을 봄.
- 둥지 남자: 베이지 옷, 상투, 웃는 얼굴. 양손을 큰 둥지 가장자리에 얹음.
- 초록 옷 청년: 초록 도포, 상투. 오른손을 높이 들어 버드나무에 매단 흰 천의 긴 자락을 잡아당김.

2. 책
- 선생이 양손으로 펼친 책을 쥠(손 닿음). 탁자 위 책 2~3권 쌓임(아무도 안 만짐).

3. 글자·숫자
- 벤치 위·도깨비 손 종이들에 글자 같은 가로줄.
- 메스 손잡이에 눈금 같은 줄, 줄자에 눈금 표시.
- 선생 책 펼친 면에 줄 무늬.
- 깃발에 빨간 십자(글자 아님). 흰 천은 백지.

4. 이상한 점
- 왼쪽 위 나무 수관이 x≈500(전체 그림 기준) 근처에서 수직으로 잘린 듯한 직선 경계(하늘색이 갈라짐) → 이음매?
- 오른쪽 버드나무 구역은 배경이 하늘색이 아니라 크림색이고 x≈1490 부근에서 세로 경계 → 다른 판을 붙인 듯한 이음매?
- 흰 천 아래쪽이 여러 갈래 띠로 찢겨 있음.
- 나무 의자(스툴) 3개 정도가 넘어져 흩어짐.
- 돌 벤치 모서리에 금메달(빨간 끈) 걸림, 둥지 앞에도 금메달 걸림.
- 손가락 이상은 못 봄.

5. 헷갈릴 물건
- 흰 천(아래가 띠로 갈라짐): 현수막·깃발 / 빨래·발(커튼)?
- 줄자: 줄자 / 목걸이·리본?
- 메스: 수술칼 / 펜·조각칼?
- 둥지 안 무늬 알 6개: 부활절 달걀 / 풍선·사탕?
- 큰 둥지: 새 둥지 / 짚 바구니?
- 빨간 십자 깃발: 적십자 / 스위스 국기?
- 도깨비: 도깨비 / 요정·외계인?
- 넘어진 스툴: 의자 / 작은 탁자?

## hist-03c (사탕 가게 + 눈/설탕 산)

1. 사람·동물
- 왕: 금관(빨간 보석), 갈색 긴 머리·수염, 보라 옷 + 흰 털 장식, 보라 망토, 갈색 허리띠, 갈색 장화, 금 목걸이. 흰 산(사탕 박힌) 꼭대기에 걸터앉음. 오른손(그림 왼쪽) 손바닥을 큰 책 흰 면의 하늘색 메모지에 댐. 왼손으로 큰 금 열쇠를 쥐고 검은 공의 열쇠 구멍에 꽂음.
- 노인: 대머리·흰 수염, 베이지 옷. 금 간 검은 공(알) 위쪽이 깨져 열린 틈에서 상반신을 내밂. 오른손 손바닥 위에 불꽃을 들어 올림. 위로 연기 소용돌이.
- 칠면조: 갈색, 큰 책의 파란 페이지 위에 발로 올라섬.
- 장수풍뎅이(뿔 있는 갈색 벌레): 두 발로 서서 은색 물뿌리개로 흰 산에 물을 뿌림.

2. 책
- 큰 책이 금속 받침대(봉 + 둥근 받침) 위에 세워짐. 왼쪽은 파란 페이지가 부채처럼 펼쳐짐, 오른쪽은 흰 페이지 묶음. 사람이 쥐지 않음.
- 왕 오른손이 흰 면 메모지에 닿음(손 떨어지지 않음). 칠면조 발이 파란 페이지 위.

3. 글자·숫자
- 분홍 메모지에 글자 같은 가로줄 3개. 나머지 메모지(노랑·하늘·초록·주황·노랑) 비어 있음.
- 불꽃 위 연기 꼬불선(글자 아님).

4. 이상한 점
- 오른쪽 가게 진열대가 노란 빛줄기 속에서 흐리고 번진 듯함.
- 책이 펼쳐진 모양이 이상(파란 페이지 덩어리 + 흰 블록이 따로 노는 듯) → 냉장고처럼 보이기도.
- 받침대 꼭대기에 바람자루(빨·흰·파 줄무늬)가 꽂힘.
- 손가락 이상은 못 봄.

5. 헷갈릴 물건
- 큰 책 + 메모지: 책 / 냉장고·화이트보드?
- 검은 공: 깨진 알 / 폭탄·대포알?
- 흰 산: 눈 더미 / 설탕·소금·아이스크림?
- 바람자루: 풍향 자루 / 고깔·확성기?
- 벌레: 장수풍뎅이 / 바퀴벌레?
- 금 열쇠: 열쇠 / 태엽 손잡이?
- 칠면조: 칠면조 / 닭?

## hist-07a (돌계단 + 흙층 단면)

1. 사람·동물
- 앉은 남자: 초록 셔츠, 갈색 바지, 갈색 머리. 머리 옆에 밀 이삭 하나. 무릎 위에 새(갈색, 은색 투구에 빨간 깃털 장식, 회색 갑옷)를 양팔로 안음. 분홍 철쭉 사이 돌 위에 앉음.
- 장인: 갈색 머리·수염, 초록 셔츠, 갈색 가죽 앞치마. 오른손 검지를 위로 세움, 왼손을 청동상 어깨에 얹음. 나무 문틀(소나무 가지 얹힘) 아래 섬.
- 청동상(갈색 맨몸 남자) 2개: 똑같이 생김, 각각 한 팔을 올려 큰 노란 보름달을 받침.
- 화난 남자: 하늘색 셔츠, 청바지, 갈색 구두. 오른손에 나무 자(끝에서 새싹이 남), 왼손에 끊어진 고리(C자) 쥠. 엉거주춤 자세.
- 달리는 청년: 빨간 민소매(흰 줄)·빨간 반바지, 회색 운동화. 왼팔로 성당 모형을 끼고, 오른손을 고리 쪽으로 뻗음.
- 흰 오리(거위?): 날개 끝으로 바둑판 위의 금덩이를 만짐. 유리문 옆에 섬.

2. 책
- 책 없음.

3. 글자·숫자
- 나무 자의 눈금 줄. 바둑판 격자. 글자 없음.

4. 이상한 점
- 유리문이 벽 없이 혼자 서 있음.
- 버드나무(빨간 등 달림)가 떠 있는 풀 섬 위에 있음.
- 왼쪽 청동상 들어 올린 팔이 어깨 뒤에서 나오는 듯 → 팔 붙은 위치 애매?
- 앉은 남자 머리 옆 밀 이삭이 손에 쥐어지지 않고 떠 있는 듯?
- 돌판 아래 흙층에 소나무 가지들이 깔려 있음.
- 이음매·번짐은 못 봄.

5. 헷갈릴 물건
- 금덩이: 금괴·금덩이 / 감자·레몬?
- 끊어진 고리: 고리 / 말굽·팔찌?
- 성당 모형: 성당 / 성·촛대?
- 바둑판: 바둑판 / 석쇠·와플판?
- 투구 쓴 새: 닭·꿩? / 참새·매?
- 청동상: 조각상 / 마네킹·사람?
- 보름달: 달 / 해·치즈?
- 유리문: 유리문 / 거울·진열장?
- 밀 이삭: 밀 / 벼·보리?

## hist-14 (개항 부두 + 서양식 건물 + 학교)

1. 사람·동물
- 서양 남자: 갈색 머리·수염, 남색 긴 외투, 갈색 조끼, 나비넥타이. 오른손으로 밧줄을 당겨 나룻배를 끌어옴(밧줄이 몸 뒤로 돌아 바닥에 감겨 있음), 왼손에 검은 왕진가방. 나무 부두 위.
- 나룻배 사람들 약 10명: 분홍·하늘·초록 한복, 노인, 아이, 납작모자 쓴 남자. 걱정스런 얼굴. 배 안에 짐 꾸러미.
- 서양 의사: 흰 가운, 청진기, 파란 넥타이, 콧수염. 청진기 끝을 쥐고 환자 가슴 쪽에 댐.
- 한의사: 검은 관모(탕건?), 상투, 베이지 한복, 수염. 오른손에 침(가는 바늘) 들고, 왼손 펼침.
- 환자: 청록 셔츠, 진회 바지, 파란 베개 베고 나무 평상 위에 누움, 눈 감음.
- 작은 한옥 안: 침 꽂힌 청동 인체 모형(둥근 받침) 양옆에 학생 4~5명(빨강·파랑 치마 소녀, 한복 소년)이 책을 들고 읽음.
- 검은 제복 남자: 검은 단추 제복(학생복/군복?), 넘긴 머리, 콧수염, 화난 얼굴. 한 손을 큰 나무 교탁(장?) 위에 얹고, 다른 손은 허리 뒤. 단 위에 섬.
- 무릎 꿇은 남자: 갈색 도포, 검은 관모(탕건?), 수염, 걱정 얼굴. 방석 위에 무릎 꿇고 손을 무릎에 얹음. 교탁 옆.

2. 책
- 한옥 안 학생들이 양손으로 펼친 책(청록색)을 들고 있음. 손 닿아 있음. 다른 곳엔 책 없음.

3. 글자·숫자
- 글자 없음. 인체 모형에 점·선(경혈?) 무늬, 비단 주머니에 용 무늬.

4. 이상한 점
- 서양 건물 정면 가로등 받침에 큰 금메달이 걸림(끈이 받침에 감긴 듯). 문 기둥에도 파란 끈 금메달.
- 서양 건물 벽에 큰 구명튜브가 붙어 있음.
- 서양 남자 밧줄이 손에서 몸 뒤로 돌아 바닥에 감김 → 줄 흐름이 약간 어색?
- 교탁 뒤 제복 남자가 서 있는 단 높이가 애매.
- 이음매·번짐은 못 봄. 손가락 이상 못 봄.

5. 헷갈릴 물건
- 구명튜브: 구명튜브 / 도넛·과녁?
- 비단 주머니(용 무늬, 위에 금화): 복주머니 / 항아리·꽃병?
- 금괴 3개: 금괴 / 버터·치즈?
- 청동 인체 모형: 침구 동인 / 마네킹·조각상?
- 큰 나무 교탁: 교탁 / 옷장·관?
- 검은 가방: 왕진가방 / 손가방?
- 메달: 메달 / 시계·징?
- 증기선: 증기선 / 군함?
