# 판독자1 — blind3 그림 판독

## hist-02a
1. 사람·동물
- 분홍 플라밍고: 동그란 안경, 얼룩진 갈색 앞치마, 나무 의자에 앉음. 왼쪽 날개로 액자(색동 한복 입은 아기 사진)를 들고, 오른쪽 날개는 물레 위 흙 항아리에 얹음. 다리 하나는 물레 받침 쪽으로 뻗어 있음. 의자 다리(또는 플라밍고 다리)에 끈이 묶여 위쪽 임신테스트기까지 이어짐.
- 흰 양: 엎드려 있음, 목에 밧줄, 밧줄 끝은 물레 받침·플라밍고 발 쪽으로 감김.
- 작은 남자(왼쪽 위): 초록 잎 망토, 갈색 옷. 초록 항아리 위에 걸터앉아 항아리를 기울여 초록 잎을 쏟음.
- 작은 남자(가운데 위): 흰 가운, 청진기. 노란 별 모양 항아리에 앉아 금색 가루·조각을 쏟음. 두 줄기가 꼬여서 식물 줄기가 됨.
- 파란 근육남: 뾰족한 파란 머리, 웃통 벗음, 초록 허리천, 갈색 바지, 맨발. 양손에 뒤집개 둘(하나는 구멍 뚫린 것)을 들고 돌 아궁이 위 큰 웍에서 초록 잎을 볶음. 웍 손잡이에 금메달이 걸려 있음. 등 뒤로 북 7개가 달린 둥근 고리.
2. 책: 없음.
3. 글자: 임신테스트기 창에 빨간 줄과 「0」 모양. 다른 글자는 없음.
4. 이상한 곳: 임신테스트기가 왼쪽 위 공중에 떠 있고 가는 줄로만 이어져 있음. 땅 가운데(웍과 집 사이) 흙길에 뜻 모를 곡선 한 줄. 집 모양 주전자 지붕의 뚜껑 문에서 금·초록이 꼬인 줄기와 빨간 끈에 매단 금메달이 나옴. 약장 위 식물 두 그루의 가지 끝이 사람 손 모양으로 악수함.
5. 헷갈릴 것: 임신테스트기 vs 체온계·USB? / 북 달린 고리 vs 탬버린·동전 고리? / 집 모양 주전자 vs 그냥 집? / 초록 항아리 vs 박·수박? / 약장 vs 서랍장.

## hist-03a
1. 사람·동물
- 남자아이: 상투, 노란 셔츠, 회색 바지, 크게 웃음. 쌍봉낙타 혹 사이에 앉아 금색 책을 두 손으로 쥠.
- 쌍봉낙타: 모래 상자 안을 걸음. 목에 파란 끈 금메달.
- 노인: 회색 도포, 상투, 염소수염, 웃음. 옆 아이(노란 저고리, 파란 바지, 놀란 얼굴)가 노인 가슴·어깨의 빨갛게 빛나는 점을 손가락으로 찌름.
- 개: 흰 바탕 갈색 점, 빨간 목줄과 금색 이름표. 뒷다리로 섬. 앞발에 빨간 권투장갑을 끼고, 장갑 쪽에서 붓이 나와 족자 속 사람 그림을 가리킴.
- 소: 갈색, 뿔, 녹색 보석 달린 검은 모자, 회색 중국식 매듭단추 옷. 한 손(검은 장갑 같은 손)은 이마에 대고(경례?·고민?), 다른 손으로 파란 책의 빨간 밀랍 봉인을 누름. 뒤로 꼬리가 보임.
2. 책: 아이는 금책을 두 손으로 꽉 쥠. 소는 탁자 위 파란 책(빨간 리본으로 묶임)의 봉인을 손으로 누르고 있음. 리본이 메달 끈으로 이어져 탁자 아래로 금메달이 늘어짐. 책 옆에 약초 그림 두루마리.
3. 글자: 없음. 파란 책 표지의 흰 라벨은 비어 있음. 이젤 판에 경락선 그린 사람 넷(앞·옆·옆·뒤). 족자에 점 찍힌 사람 몸. 선반의 병 라벨도 비어 있음.
4. 이상한 곳: 붓이 권투장갑을 뚫고 나온 듯 보이고 쥐는 방식이 분명하지 않음. 소의 손이 발굽이 아닌 다섯 손가락 장갑 손. 바닥에 붓이 하나 더 굴러다님. 사탕과 막대사탕이 사방에 흩어져 있음.
5. 헷갈릴 것: 왼쪽 아래 노란 덩어리 = 금덩이 vs 버터·치즈? / 날개 달린 노란 물건 = 원보(말굽은) vs 날개 모자·배? / 소 vs 물소? / 개 장갑에서 나온 것 = 붓 vs 화살·침?

## hist-03b
1. 사람·동물
- 초록 개구리: 검은 선글라스, 책상다리. 오른손 나무숟가락으로 죽을 떠먹고, 왼손에 죽 그릇. 그릇 밑으로 회색 책이 무릎에 걸쳐 있음. 앞의 낮은 상에 죽 한 그릇과 숟가락이 더 있음.
- 몸 없는 두 손: 하나는 위에서 내려와 펼친 약초책 위의 작은 갈색 조각을 집고, 하나는 왼쪽에서 들어와 검지로 책장을 짚음.
- 왕·관리: 검은 관모, 구름무늬 금빛 도포, 콧수염. 한 손 검지를 입술에 댐(쉿). 다른 손은 검은 천 덮인 책더미(띠와 자물쇠로 잠김, 종이가 삐져나옴) 위에 얹음. 책더미 뒤로 악어·도마뱀이 엎드려 있음.
- 칠면조: 얼음 덩어리 탁자 뒤에 섬. 앞에 색 포스트잇이 붙은 펼친 책.
2. 책: 개구리 책은 그릇과 무릎 사이에 끼임(손이 직접 쥐지는 않음). 몸 없는 손이 약초책을 만짐. 왕은 잠긴 책더미를 천 위로 누름. 배 돛대에 펼친 책이 돛처럼 붙어 있음. 칠면조 책은 손 닿는 이 없이 얼음 위에 놓임.
3. 글자: 칠면조 책 양쪽 면에 글자처럼 보이는 꼬불꼬불한 줄과 작은 그림. 병 라벨은 비어 있음.
4. 이상한 곳: 몸 없이 떠 있는 팔·손 두 개. 왼쪽 반 그림에서 약초책 오른쪽 가장자리가 세로로 곧게 잘린 듯 보임(이음매?). 큰 돌그릇 물 위의 목조 배에 보라색 공(포도? 환약?)과 작은 병이 실려 있고 빨간 깃발이 달려 있음. 얼음 탁자가 녹아 고드름이 생김. 작은 노란 왕관이 얼음 앞 공중에 떠 있는 듯함. 바닥에서 물기둥이 솟고 모닥불도 있음.
5. 헷갈릴 것: 깃발 8개(해, 무지개, 바람, 비구름, 번개, 눈송이, 비 오는 무지개, 파도) / 보물상자의 검은 알 = 흑두·검은콩 vs 석탄·구슬? / 열쇠 / 도마뱀 vs 악어 / 보라색 공 = 포도 vs 환약 / 갈색 조각 = 약재 vs 초콜릿·차?

## hist-07b
1. 사람·동물
- 남자1(왼쪽 위): 올리브색 도포, 비녀 꽂은 상투, 긴 수염. 금 바위 위에 서서 두 손으로 펼친 종이·두루마리를 듦. 옆에 물시계·모래시계(물이 위에서 아래로 떨어짐). 그 꼭대기에 작은 쥐·말 조각상.
- 남자2(노인): 흰머리 상투, 회색 도포. 한 팔에 기와집 모형을 안고, 손가락 하나는 입술에(생각·쉿), 또 한 손으로 긴 바늘·지시봉을 쥐고 땅 위 큰 나침반을 찌름.
- 남자3(정자 위): 두 손으로 종이를 들고 노래함(음표).
- 흰 수염 노인: 청록 조끼, 흰 셔츠, 갈색 바지. 무지개 미끄럼틀을 타고 내려옴. 오른손을 들어 흰 알(달걀? 돌?)을 쥐고, 왼손으로 경락 사람 그림 족자를 듦. 족자 아래에 빨간 끈 금메달.
- 봉황·불새: 약장 위에 앉아 날개를 폄.
- 젊은이(파란 도포): 노래함(음표). 두루마리가 가득한 서랍을 안고 한 손으로 두루마리 하나를 꺼냄.
- 장군: 붉은 깃 달린 투구, 비늘 갑옷, 빨간 망토, 분홍 장갑. 분홍 꽃다발과 펼친 책을 두 손으로 가슴에 안음.
- 앉은 두 사람(돗자리): 파란 도포는 손바닥을 펴 설명함, 초록 도포는 두 손으로 책을 들고 읽음. 옆에 베틀.
2. 책: 장군은 꽃과 함께 책을 쥠. 초록 도포는 두 손으로 쥐고 읽음. 나머지는 종이·두루마리.
3. 글자: 없음. 약장 서랍 이름표는 빈 판. 노래하는 사람 옆에 물결 「~」 모양.
4. 이상한 곳: 노인(남자2)의 손 3개?(집 모형 밑을 받친 손, 입술의 손, 지시봉 쥔 손). 미끄럼 노인의 족자와 메달 둘레에 흰 테두리(오려 붙인 스티커처럼 보임). 미끄럼틀 위쪽에 작은 점 하나가 떠 있음. 나침반 위 왼쪽 테두리 근처에 흰 번짐. 나침반 오른쪽 땅에 흐린 자국. 돗자리 앞 땅에 주황색 빛 번짐.
5. 헷갈릴 것: 물시계 vs 모래시계 / 흰 알 vs 돌·진주 / 꼭대기 조각상 = 쥐·말 vs 개? / 나침반 vs 시계 / 봉황 vs 불사조·닭 / 베틀 vs 의자.

## hist-08a
1. 사람
- 앉은 남자: 망건, 상투, 베이지 한복, 눈 감고 미소. 낮은 상 앞에 책상다리로 앉음. 오른손 젓가락으로 하얀 둥근 떡·케이크(김 남) 위에 빨간 열매(대추?)를 올림. 왼손은 펼친 책 위에 있고, 그 책 위에 빨간 열매가 하나 더 있음.
- 서 있는 남자: 망건, 상투, 짙은 남색 도포, 콧수염. 책장 앞에서 파란 책을 두 손으로 들고 꽂거나 꺼냄.
- 갓 쓴 남자: 수염, 하늘색 저고리 위에 남색 쾌자, 술 달린 띠. 놀라 입을 벌림. 왼손 펴 들고 오른손으로 빨간 책을 머리 위로 치켜듦. 한 다리를 들어 걷어차는 자세. 발 앞에 해 그림 노란 양동이(주황 물 담김)와 달 그림 회색 양동이(쓰러져 빔).
2. 책: 앉은 남자 손바닥이 책 위에 닿음. 남색 도포는 두 손으로 쥠. 갓 남자는 한 손으로 높이 쥠. 오른쪽에 책 더미, 책장에 두루마리와 책.
3. 글자: 없음. 책 면에 흐린 줄만.
4. 이상한 곳: 큰 것은 없음. 왼쪽 아래 구들 단면도(불길 화살표가 바닥 밑으로 흐름)와 벽난로·굴뚝. 바닥에 놓인 은색 쟁반에 침 같은 가는 도구, 작은 원형(뚜껑? 동전?), 흰 조각.
5. 헷갈릴 것: 흰 떡 vs 케이크·두부 / 빨간 열매 = 대추 vs 고추·체리 / 쟁반 도구 = 침 vs 숟가락 / 해·달 양동이.

## hist-09
1. 사람·동물
- 흰 오리: 잔디에 서서 한 발로 펼친 책을 밟음. 옆에 금 간 갈색 항아리에서 보라 연기가 나옴. 금빛 별똥별이 항아리 입구로 떨어짐.
- 초록 멜빵바지 남자: 손으로 입을 가리고 기침·재채기. 보라 연기가 코·입으로 들어감.
- 파란 셔츠 남자: 청바지, 초록 장화. 붉은 개울(피?)을 걸으며 오른손으로 갈색 책을 내밂.
- 파란 얼굴 노파: 베이지 담요를 뒤집어쓰고 떨고 있음(떨림 선). 붉은 개울 속, 온실 문 앞.
- 날개 달린 남자: 빨간 티셔츠, 천사 날개. 한 손에 큰 잎 줄기를 우산처럼 쥐고, 다른 팔로 초록 책을 가슴에 안음.
- 눈사람: 녹으며 물방울과 눈물, 김이 남. 나뭇가지 손으로 펼친 흰 책을 듦.
- 오리(걸이 바구니): 맨 위 바구니에 앉음. 바구니 안에 책. 둥근 알갱이 하나가 떨어지는 중(움직임 선).
- 수탉: 베틀 의자에 서서 날개를 베틀에 얹고 짬. 짜인 천에 모기(?)와 회색 쥐 그림.
2. 책: 오리는 발로 밟음. 파란 셔츠는 한 손으로 쥐고 내밂(노파 손은 안 보이고 책은 담요에 닿을락말락함). 천사는 품에 안음. 눈사람은 가지 손으로 쥠. 걸이 바구니 속 책에는 손이 닿지 않음.
3. 글자: 없음.
4. 이상한 곳: 빨간 종이등이 온실 문 모서리에 매달려 떠 있는 듯함. 떨어지는 알갱이가 공중에 있음. 천 위 쥐와 모기가 실물인지 무늬인지 애매함. 담요 노파의 손이 보이지 않음.
5. 헷갈릴 것: 붉은 개울 = 피 vs 진흙물 / 떨어지는 알갱이 = 씨앗 vs 알·동전 / 천 위 곤충 = 모기 vs 개미·새우 / 동심원 울타리 3겹(파랑·초록·빨강) 안 꽃 한 송이 / 큰 잎 = 토란잎 vs 연잎.

## hist-10
1. 사람·동물
- 말(갈색): 의자에 앉음. 구부러진 빨대로 검은 액체(먹물? 콜라?) 잔을 마심. 오른쪽 앞발굽으로 깃펜을 쥐고 노란 포스트잇이 붙은 펼친 책에 씀. 왼쪽 앞발굽은 잔 옆 책 위에 둠. 탁자 위 책 사이에 금메달과 끈.
- 노래하는 남자: 하늘색 셔츠, 회색 바지, 눈 감고 노래함(음표). 오른손으로 김 나는 냄비를 머리에 얹고 받침. 왼팔에 끈으로 묶은 책 더미를 낌.
- 초록 스웨터 남자: 왼팔에 초록 책들을 낌. 오른손 연필로 해부도 포스터의 아랫배(장 아래, 맹장·방광 근처?)를 짚음.
- 거북: 노란 등껍질, 머리에 뿔 하나. 등에 불 켜진 초. 물 채운 수조 바닥의 책 위에 섬.
2. 책: 말 발굽이 깃펜으로 책 면에 닿음. 노래하는 남자는 팔에 낌. 초록 남자는 겨드랑이에 낌. 거북은 책을 밟음.
3. 글자: 없음. 포스트잇은 비어 있음.
4. 이상한 곳: 물 수조 안(물속)에서 촛불이 타고 있음. 왼쪽 가장자리 중간쯤에 정체 모를 회색 사선 한 줄(높이 약 490). 벽의 투명 파이프: 위쪽에 검붉은 덩어리(혈전?)가 차 있고, 뚫어뻥이 꽂혀 있고, 아래 U자 부분은 붉은 액체와 덩어리.
5. 헷갈릴 것: 파이프 속 덩어리 = 어혈·혈전 vs 커피찌꺼기·흙 / 거북 뿔 = 코뿔소 뿔 vs 상아 / 말이 마시는 검은 액체 = 먹물 vs 커피 / 나뭇가지·잎 꽂힌 배낭(벤치 위) = 약초 채집 vs 캠핑.

## hist-11
1. 사람
- 정자 속 두 선생: 초록 옷(상투)은 잎 그림 펼친 책을 두 손으로 보여줌. 파란 도포(수염)는 회색 새(비둘기?) 그림 펼친 책을 두 손으로 보여줌. 앞에 아이 셋(빨강·초록·파랑 옷)이 앉아 작은 카드·종이를 듦.
- 쌀 나눠주는 남자: 망건, 파란 한복, 수염. 쌀 가득한 나무 궤짝에서 한 손 그릇으로 쌀을 퍼고, 다른 손 숟가락으로 거지 그릇에 담아줌. 궤짝 밖 땅에 쌀알이 흘러 있음.
- 거지: 백발에 마르고 누더기, 맨발. 두 손으로 그릇을 받음.
- 걸상 위 남자: 노란 저고리, 검은 두건. 걸상에 올라서서 녹색 물 담긴 그릇 그림 간판을 손으로 만짐(다는 중?).
- 바구니 든 두 남자: 초록 옷(머리띠)과 밀짚모자(갈색 옷). 둘 다 초록 잎이 가득한 바구니를 안고 걸음.
2. 책: 선생 둘이 펼친 책을 두 손으로 쥠. 다른 책은 없음.
3. 글자: 간판은 모두 그림뿐이고 글자 없음. 밀짚모자 챙에 작은 꼬불꼬불한 선(글자처럼 보이기도 함?).
4. 이상한 곳: 빨간 대문에 문 그림 액자가 비스듬히 매달려 떠 있는 듯함(지지대 불분명). 국그릇 간판이 흔들림(움직임 선). 벽에 방패 하나 걸림.
5. 헷갈릴 것: 왼쪽 위 돌탑 = 첨성대 vs 굴뚝·가마 / 청자 매병 vs 꽃병 / 흰 달항아리 vs 어항·풍선 / 간판 그림(탑, 선물 주는 손, 녹색 국·차, 절집, 문, 구명튜브, 눈), 기대어 세운 액자(눈, 탑) / 구명튜브 vs 도넛·화환 / 새 그림 = 비둘기 vs 매.

## hist-13
1. 사람
- 두 남자(파란·초록 옷, 상투): 보석 박힌 금테 타원 거울을 함께 들고 옮김. 거울이 커다란 책 위(책 표지 앞)에 붙어 있음. 손은 거울 테 아래를 쥠.
- 흰 수염 노인: 상투, 회색 옷, 무릎 꿇음. 왼손에 작은 펼친 책, 오른손으로 엎드린 사람 등에 침을 놓음. 환자는 웃통 벗고 회색 바지 차림으로 베개 베고 돗자리에 엎드림.
- 신부: 검은 사제복, 로만 칼라, 십자가 목걸이. 해골 그림 펼친 책을 든 채 창고 앞에 섬. 창고 문이 열려 있고 안에 보물상자와 금화(빛남).
- 노란 한복 남자: 망건. 책상다리로 앉아 파란 책 더미를 끈으로 묶음. 옆에 뚜껑 따진 통조림(노란 과일, 복숭아?).
- 말 탄 남자: 초록 한복, 상투. 보라색 과일(자두?)을 베어 먹음. 다른 팔에 책을 낌. 말은 고삐와 안장을 맴.
- 서 있는 넷: 근육질 웃통 벗은 남자(카키 바지), 뚱뚱한 웃통 벗은 남자(상투), 마른 웃통 벗은 남자(파란 바지), 여자(초록 윗옷, 보라 바지, 허리에 손).
- 걱정하는 남자: 갈색 도포, 염소수염. 물방울무늬 책을 쟁반처럼 받쳐 그 위에 찻잔(약?)을 올려 들고 있음.
- 소년: 웃통 벗음. 온몸에 빨간 반점. 걱정스러운 얼굴로 손을 뺨에 댐.
- 나이 든 여자: 흰·옥색 한복. 숟가락으로 갈색 물을 아기에게 떠먹임.
- 젊은 여자: 분홍 저고리. 우는 아기(기저귀)를 안음. 국그릇이 낡은 책 위에 얹혀 있음.
2. 책: 신부는 한 손으로 쥐고 펼쳐 보여줌. 노인은 왼손에 듦. 노란 한복은 끈으로 묶으며 만짐. 말 탄 남자는 팔에 낌. 걱정하는 남자는 책을 쟁반처럼 받침. 아기 쪽 낡은 책은 아래에서 손 하나가 받치는데 누구 손인지 애매함(분홍 여자?). 거울은 큰 책에 붙어 사람이 그 테를 쥠.
3. 글자: 신부 책 오른쪽 면에 글자 같은 줄. 해골 그림.
4. 이상한 곳: 소년 뺨의 손이 소년 손인지 걱정하는 남자 손인지 불분명함(소매 색이 애매함). 거울과 책이 하나로 붙어 있음.
5. 헷갈릴 것: 빨간 반점 = 두창 vs 홍역 / 보라 과일 = 자두 vs 포도·가지 / 통조림 = 복숭아 vs 귤 / 거울 vs 문·액자 / 갈색 물 = 약 vs 국.
