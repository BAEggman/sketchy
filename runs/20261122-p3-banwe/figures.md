# 이번 run에 나오는 사전 피규어(바꾸지 않음)

- 半夏(반하) = 반바지 하마 — 원안: 반바지 하마
- 瓜蔞(과루) = 넥타이 맨 채 녹초가 되어 엎어진 참외
- 貝母(패모) = 조개껍데기 핸드백 든 패션모델
- 白蘞(백렴) = 물구나무선 흰 염소(긴 수염 · 굽은 뿔, 목줄 없음)
- 白及(백급) = 구급상자를 입에 문 흰 개(백구)
- 甘草(감초) = 약방의 감초 — 약장 서랍마다 얼굴 내민 노란 감초 뿌리
- 大戟(대극) = 붉은 막이 걷힌 대극장 무대(간판 없음)
- 芫花(원화) = 원화 지폐 — 원안: 원화 지폐 꽃
- 甘遂(감수) = 감옥 쇠창살을 두 손으로 붙잡은 줄무늬 죄수
- 海藻(해조) = 춤추듯 꿈틀거리는 초록 해조류(미역) 다발
- 藜蘆(여로) = 화로를 끌어안고 토하는 여우
- 人參(인삼) = 왕관 쓴 인삼 뿌리 인형
- 丹參(단삼) = 단검을 든 붉은 뿌리 인형
- 玄參(현삼) = 구멍 숭숭한 검은 현무암 몸의 삼 인형
- 沙參(사삼) = 사자 갈기 단 삼 인형
- 苦參(고삼) = 머리띠 맨 고3 수험생 뿌리 인형
- 細辛(세신) = 목욕탕 세신사 — 때수건 낀 손을 흔듦
- 白芍藥(백작약) = 백작 약사 — 원안: 하얀 백작 약사
- 硫黃(유황) = 썩은 냄새 김 뿜는 노란 유황 바위
- 朴硝(박초) = 양초 쥐고 거꾸로 매달린 박쥐
- 水銀(수은) = 깨진 체온계에서 도망치는 수은 방울
- 砒霜(비상) = 따르릉 울리는 빨간 비상벨
- 狼毒(낭독) = 책을 펼쳐 낭독하는 늑대
- 密陀僧(밀타승) = 낙타를 밀어 태우는 승려
- 巴豆(파두) = 도화선 달린 파란 두부 폭탄
- 牽牛子(견우자) = 견우 — 원안: 소 끄는 견우 목동
- 丁香(정향) = 정장 입고 넥타이 맨 향로가 연기를 피움
- 鬱金(울금) = 엉엉 우는 울보 금붕어
- 牙硝(아초) = 아이스크림 콘에 꽂혀 녹는 양초
- 三稜(삼릉) = 화면에서 가장 키 큰 굵은 세모 날 쇠침(삼릉침) — 날 모서리 셋 · 단면 세모, 얼굴 · 다리 · 피 없음
- 川烏(천오) = 천막 자락을 뒤집어쓰고 고개만 내민 까마귀
- 草烏(초오) = 풀을 뜯어 먹는 초록 까마귀(천 두르지 않음)
- 犀角(서각) = 외뿔이 네모난 사각 블록인 코뿔소
- 五靈脂(오령지) = 유령이 들러붙은 오렌지
- 肉桂(육계) = 계피 막대가 젓가락처럼 꽂힌 육개장 한 그릇
- 赤石脂(적석지) = 적십자 완장 찬 붉은 돌덩이
- 附子(부자) = 머리카락이 활활 타는 불꽃인 부자 도련님(나비넥타이, 실크햇 · 돈 없음)
- 石膏(석고) = 물을 벌컥벌컥 들이켜는 하얀 석고 조각상
- 知母(지모) = 꼭대기에 커다란 지우개가 달린 모자
- 柴胡(시호) = 몸통이 자명종(숫자 없이 눈금만 있는 시계판)이고 수염이 시곗바늘인 호랑이
- 黃芩(황금) = 황금괴 — 원안: 번쩍이는 황금괴
- 黃柏(황백) = 노랑 · 하양 두 장이 포개진 황백지단(고명 달걀부침)
- 當歸(당귀) = 당나귀 귀부인 — 원안: 당나귀 귀부인
- 川芎(천궁) = 천사 궁수 — 원안: 천사 궁수
- 山藥(산약) = 마 뿌리를 피켈처럼 치켜든 산악인
- 黃芪(황기) = 깃대 꼭대기까지 솟구친 노란 깃발
- 香附子(향부자) = 향수를 너무 뿌리는 부자(실크햇 · 털 깃 · 굵은 금반지, 금술 단 붉은 방석 — 지폐 없음)
- 大黃(대황) = 왕좌에 버티고 앉은 거대한 누런 대왕 황소(왕관 없음)
- 黃連(황련) = 쓴맛에 혀를 내밀고 찡그린 노란 연꽃
- 生薑(생강) = 싱싱한 날생강 개구리 — 물기 반짝
- 防風(방풍) = 바람에 빵빵하게 부푼 빈 방풍 점퍼
- 乾薑(건강) = 청진기를 대고 건강검진 받으며 알통 자랑하는 마른 생강
- 厚朴(후박) = 후추 그라인더가 정수리에 꽂힌 둥근 박
- 澤瀉(택사) = 지붕에서 물을 분수처럼 뿜는 흰 택시(지붕등 글자 없음)
- 白芷(백지) = 이마에 새하얀 백지 한 장이 철썩 붙은 둥근 얼굴
- 雄黃(웅황) = 노란 웅덩이에서 뱀이 튀어 도망
- 熟地黃(숙지황) = 숙제 노트 펼친 검은 지하 황제
