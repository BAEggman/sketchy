# 여섯 안 지시 (본초 사전 6+1)

읽을 것은 셋뿐이다: `runs/RUBRIC.md`, `runs/20261122-p3-herbdict/common.md`, `runs/20261122-p3-herbdict/batch_<묶음>.md`. 다른 파일 · 다른 안은 열지 않는다. 웹 검색도 하지 않는다.

맡은 관점(번호)대로 묶음의 약마다 피규어 단서 하나를 고른다. 원안 · 계획서 안 · 다른 모델 안 가운데 하나를 그대로 골라도 되고, 새로 지어도 된다.

관점
1. 통째 동음어를 먼저 찾는다(약 이름 독음 전체가 흔한 낱말 하나로 나오게).
2. 낱말 속 연속 포함 · 가까운 소리의 한 낱말을 찾는다.
3. 피규어 하나가 「한 동작」으로 이상하게 눈에 걸리게 짠다(사건 먼저). 소리는 유지.
4. 짝 약끼리(공통 brief 1절 6항, 같은 글자를 가진 약) 갈리게 하는 데 집중한다.
5. 그릴 수 있음: 흰 바탕 스티커 하나로 Gemini가 틀리지 않고 그릴 단순한 꼴(사물 하나 또는 맞닿은 둘, 글자 없음).
6. 사용자 · Gemini 원안과 계획서 안을 최대한 살린다(바꿀 까닭이 뚜렷할 때만 바꾼다).

내는 꼴(꼭 지킨다): JSON 파일 하나, **1,500자 이내**, 한국어. 파일 `runs/20261122-p3-herbdict/<묶음>/p<관점>.json`:
```
{"p":3,"b":"B1","items":[["H009","목욕탕 세신사(때수건 낀 손)","세신사",1], ...],"note":"버린 후보 · 겹침 걱정 한두 줄"}
```
items 한 줄 = [id, 단서(25자 안), 운반 낱말(여럿이면 /), 유형 번호 1~7]. 묶음의 모든 약을 빠짐없이. 파일을 쓰고 「완료」만 답한다.
