# 여섯 안 지시 (修治 장면 6+1)

읽을 것: `runs/RUBRIC.md`, `runs/20261122-p3-suchi/brief.md`. (필요하면 `src/dict/herbs.json`에서 피규어 cue · draw_en 만 찾아본다.) 다른 안 · 다른 파일은 열지 않는다. 웹 검색 없음.

맡은 관점(번호):
1. 소리: 두문자 가사가 입에 붙게 — 가사를 끊어 읽는 자리와 장면의 쉼(목적 경계)을 맞춘다.
2. 보료와 목적: 보료 표지가 그 방법을 바로 부르고, 목적(①②③)이 소품 하나로 보이게.
3. 사건 먼저: 도미노 연결이 우습고 한 번 보면 이어지게(앞 동작 → 다음 피규어).
4. 혼동 짝을 가름: 酒 ↔ 醋, 明煅 ↔ 煅淬 ↔ 悶煅, 煮 ↔ 燀, 炒焦 ↔ 炒炭, 麩 · 米 · 土 · 砂 · 滑石粉이 서로 다른 장면 문법이 되게.
5. 그릴 수 있음: 한 장 새 물건 여덟 이하, Gemini가 틀리지 않을 단순한 배치 · 동작.
6. 기존 단서 살리기: pilot-cho 첫 장(부엌 작업대 · 팬 · 식초가 왼→오 흐름)과 hp-04 표지를 최대한 그대로 잇는다.

내는 꼴: JSON 하나, **1,500자 이내**, 한국어. 파일 `runs/20261122-p3-suchi/<묶음>/p<관점>.json`:
```
{"p":2,"b":"Q1","sheets":[["P01","작업대 · 보료 · 경계 한 줄","약1 동작→약2 …(짧게)"], ...],"new":[["貫衆","단서","운반낱말"]],"note":"한두 줄"}
```
new는 묶음에 새 사전 항목이 있을 때만. 묶음의 모든 장을 빠짐없이. 파일을 쓰고 「완료」만 답한다.

묶음: Q1 = P01~P06 · Q2 = P07~P12 · Q3 = P13~P18 · Q4 = P19~P22.
