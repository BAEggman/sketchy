# 여섯 안 — 修治 Q1 (P01~P06 炒法) · 2026-11-22

여섯 안은 서로의 안을 보지 않았다. 피규어 25개는 사전 그대로이고, 새로 지은 단서는 貫衆 하나다. 원안 전문은 `p1.json`~`p6.json`이다.
관점: 1 소리(가사 끊음 = 장면 쉼) · 2 보료와 목적 · 3 사건 먼저 · 4 혼동 짝 가르기 · 5 그릴 수 있음 · 6 기존 단서 살리기

## 새 사전 항목 — 貫衆(관중)

| 안 | 단서 | 소리 길 |
|---|---|---|
| 1 | 고사리 잎을 응원봉처럼 흔드는 관중석의 관중 | 관중 → 貫衆 (통째 동음어) · 고사리 = 기원 덤 |
| 2 | 고사리 머리띠를 두르고 파도타기하는 관중 셋 | 같음 |
| 3 | 고사리 잎 두 장을 응원술처럼 흔드는 관중 한 명 | 같음 |
| 4 | 관중석 의자 줄에서 파도타기하는 관중 셋 | 같음(고사리 없음) |
| 5 | 관중석 계단의 관중 셋이 고사리 잎을 흔듦 | 같음 |
| 6 | 관중석에 앉아 응원봉을 흔드는 관중 한 명 | 같음(고사리 없음) |

## P01 淸炒 · 炒焦 「산천치빈」

| 안 | 작업대 · 보료 · 경계 | 도미노 |
|---|---|---|
| 1 | 갈색으로 눌은 팬 · 「산천 / 치빈」 쉼 = 산비탈 · 시냇물 \| 도마 | 열매가 자라를 밂 → 지팡이가 치즈 자를 쓰러뜨림 → 치즈 자가 빈 도시락에 쏙 |
| 2 | 맨 팬 · 피규어 가장자리를 토스트빛 갈색으로 | 열매 → 자라 → 치즈 자 → 도시락에 쏙 |
| 3 | hp-04 둘째 팬(갈색 · 쪼그라듦) · 검정 금지 | 눌은 열매를 밟고 미끄러진 자라의 지팡이 → 치즈 자가 시소처럼 튀어 눌은 열매를 도시락에 → 신랑이 활짝 웃음 |
| 4 | 갈색 팬 · 핏방울 없음 = 焦 문법 | 열매 → 자라 → 치즈 자 → 도시락이 갈색 누룽지로 가득 참 |
| 5 | 팬 속 조각만 짙은 갈색으로 눌음 · 경계 없음 | 열매가 자라 발치를 침 → 지팡이가 치즈 자를 튕김 → 도시락에 쏙 |
| 6 | pilot-cho 작업대 그대로 · hp-04 둘째 팬 | 열매가 자라 등에서 구름 → 자라도 갈색으로 눌음 → 치즈 자도 갈색으로 쪼그라듦 → 도시락에 쏙 |

## P02 淸炒 · 炒炭 ① 「대소백목측」

| 안 | 작업대 · 보료 · 경계 | 도미노 |
|---|---|---|
| 1 | 炒炭 팬(검되 꼴 그대로) · 대게와 소라게를 크고 작게 나란히(大小) | 대게가 소라게 껍데기를 던짐 → 족집게를 침 → 머리카락이 목 단추를 휘감음 → 피에로가 백엽상에 넘어짐 |
| 2 | 피규어를 숯처럼 새까맣게(꼴은 그대로) · 오른쪽 끝 반창고 = 止血 | 대게 → 소라게가 족집게를 툭 → 머리카락이 단추에 감김 → 피에로가 측우기를 쥐고 반창고 위에서 멈춤 |
| 3 | hp-04 셋째 팬 · 止血 = 붉은 물이 검게 굳음 | 소라게 껍데기가 새까매짐 → 족집게를 걷어참 → 단추가 툭 날아가 측우기를 땡 → 측우기 속 붉은 물이 숯으로 굳음 |
| 4 | 새까만 팬 · 오른쪽 끝 피 떨어지는 빨간 수도꼭지(P02~P04 공통) | 대게 → 소라게 → 모근이 목 단추를 더 조임 → 피에로가 백엽상을 밀어 측우기가 수도꼭지를 막음 |
| 5 | 팬 속 조각만 검게 · 팬 손잡이에 반창고 · 피규어는 제 색 | 대게 → 소라게 → 머리카락이 단추를 튕김 → 단추가 날아가 측우기를 기울임 |
| 6 | hp-04 셋째 팬 · 팬 밖 피 한 방울이 굳음 | 대게 → 소라게 → 단추가 튕겨 측우기를 쓰러뜨림 (피규어를 모두 까맣게) |

## P03 淸炒 · 炒炭 ② 「천관괴건오」

| 안 | 작업대 · 보료 · 경계 | 도미노 |
|---|---|---|
| 1 | 같은 炒炭 팬 · 「천관」은 위층, 「괴건오」는 아래 한 줄(두 층) | 초고추장이 관중에게 → 고사리 응원봉이 각도기 뿔을 침 → 생강의 청진기가 튕김 → 매실 볼에 닿음 |
| 2 | 검게 탄 꼴 그대로 · 반창고 | 초고추장 → 파도타기 팔이 뿔을 침 → 괴물이 청진기를 당김 → 알통에 튕긴 매실 |
| 3 | 같은 炒炭 팬 · P02의 측우기가 올려다보던 천둥 구름으로 장을 엶 | 초고추장이 관중에게 철퍽 → 고사리를 휘둘러 뿔을 침 → 넘어지는 괴물이 청진기 줄을 잡아당김 → 생강 팔꿈치가 매실 볼을 툭 |
| 4 | 같은 炭 팬 · 수도꼭지 | 초고추장 → 파도타기 → 청진기 줄 → 매실이 수도꼭지에 박힘 |
| 5 | 검은 팬 · 반창고 손잡이 · 관중석 계단 | 초고추장 → 관중이 벌떡 일어나 고사리를 흔들다 뿔을 침 → 각도기가 청진기에 걸림 → 팔꿈치로 매실 |
| 6 | P02와 같은 검은 팬 | 측우기 물이 천둥 구름으로 → 초고추장 → 응원봉 → 괴물이 청진기를 잡아챔 → 알통이 매실을 밂 |

## P04 淸炒 · 炒炭 ③ 「지포권형」

| 안 | 작업대 · 보료 · 경계 | 도미노 |
|---|---|---|
| 1 | 炒炭 팬 · 「지포 / 권형」(지포 라이터: 기름 + 불꽃) | 주유기 기름이 포환에 튐 → 꽃가루 퍽, 불씨가 팬 숯에 옮음 → 백조가 펀치 → 개미가 형광펜을 놓침 |
| 2 | 반창고로 끝맺음(炒炭 세 장 = 止血 한 덩어리) | 노즐이 포환을 겨눔 → 꽃가루 퍽 → 백조 펀치 → 개미가 형광펜을 끌고 반창고 쪽으로 |
| 3 | 炒炭 끝 장 · 마지막에 팬 전체가 까맣게 | 검은 기름이 포환에 → 꽃가루 → 재채기한 백조가 헛펀치 → 형광펜이 튕겨 팬에 까만 줄 |
| 4 | 수도꼭지(炭 마지막 장) | 기름 → 꽃가루 → 펀치 → 형광펜이 튕겨 수도꼭지에 꽂힘 |

| 6 | 검은 팬 · 오른쪽 끝 불이 꺼짐 = 炒炭 끝 | 기름 → 꽃가루 → 재채기 펀치 → 개미가 형광펜을 끌고 팬 밖으로 |

## P05 加輔料炒 · 麩炒 「백산지창백」

| 안 | 작업대 · 보료 · 경계 | 도미노 |
|---|---|---|
| 1 | 밀기울 팬을 세 단 계단으로 · 「백산 / 지창 / 백」 = ①②③ | 산악인이 흰 배추 꼭대기에 피켈을 꽂음(백산) → 지퍼가 열려 실이 창 전사를 칭칭 묶음(緩和) → 창끝이 누에 코의 빨래집게를 떨굼(矯臭) |
| 2 | 밀기울 + 손잡이에 밀 이삭 묶음 · 세 칸: 위장 쿠션 · 창끝 코르크 · 빨래집게 | 위장 쿠션 위 배추를 받친 산악인 \| 실이 창에 감겨 코르크가 끼워짐 \| 창 자루가 빨래집게를 튕김 |
| 3 | 밀기울 팬 · 칸막이 둘 | 하얀 배추가 노릇하게 부풀어 산악인을 밂 → 피켈이 칸막이 너머 지퍼를 엶 → 실이 창날을 감아 무뎌짐 → 창 자루가 누에를 콕, 콧방울이 터짐 · 고소한 김 |
| 4 | 밀 이삭 다발 + 짙은 연기 · 세 단 | 흰 배추가 산악인 등을 밂(백→산) → 피켈이 지퍼에 걸림 \| 실이 전사를 감고 창끝이 밀기울에 묻혀 둥글어짐 \| 창 자루가 누에 이마를 콕, 악취 선이 걷힘 |
| 5 | 밀기울 팬 · 빈 틈 둘(칸막이 없음) | 배추 잎이 산악인에게 털썩 → 틈 너머로 피켈이 지퍼를 엶 → 실이 창에 감김 → 틈 너머로 창끝이 누에를 찌르지만 밀기울 연기 속에서 그대로 잠 |
| 6 | 밀기울 + 연기 · 뒤집개 둘로 세 칸 | 배추가 산악인에게 기대 배를 쓰다듬음 → 피켈이 지퍼를 당김 → 실이 창날을 감음 → 창 자루가 누에를 깨움, 악취 선이 걷힘 |

## P06 米炒 + 土炒 「당반산백」

| 안 | 작업대 · 보료 · 경계 | 도미노 |
|---|---|---|
| 1 | 쌀 팬 \| 부뚜막 흙 팬 · 「당반 / 산백」 · ①② 사이 짧은 틈 | 큐대 공이 벌레를 맞힘 → 물구나무로 버티고 독 연기가 걷힘, 쌀알이 흙 팬으로 튐 → 산악인이 흰 배추에서 내려옴(백산을 거꾸로) |
| 2 | 흰 쌀 팬 · 부뚜막 턱 · 아궁이 위 붉은 흙 팬 · 휴지 롤(止瀉) · 해골 연기(毒↓) | 큐 공 → 벌레 물구나무, 해골 연기가 걷힘 → 턱을 넘어 피켈을 밂 → 배추가 흙에 앉아 휴지 롤을 안음 |
| 3 | 쌀 팬(①\|② 낮은 쌀둑) · 부뚜막 흙 팬 | 쌀알을 당구공처럼 침 → 벌레가 고꾸라지고 독 연기가 쌀로 빨려 쌀이 누레짐 → 흙 팬 손잡이 시소 → 산악인이 배추를 걸어 앉힘(둘 다 흙빛 노릇) |
| 4 | 흰 쌀 가마니를 쏟은 팬 \| 아궁이 벽 \| 붉은 황토 팬 | 큐대가 벌레를 침 → 독 연기가 걷힘 → 벌레가 아궁이 벽에 부딪힘 \| 산악인이 흙벽을 긁어 흰 배추 위에 덮음 |
| 5 | 쌀 팬 \| 작은 흙 부뚜막 위 팬 · ①\|② 빈 틈 | 큐 공이 벌레를 쓰러뜨리고 독 연기가 걷힘 → 벌레가 흙 팬의 산악인 등에 떨어짐 → 산악인이 넘어지며 흰 배추를 끌어안음 |
| 6 | 쌀 팬(누레짐) · 부뚜막 턱 · 황토 팬 | 큐 공이 벌레를 넘김, 독 연기가 쌀에 빨림 → 벌레가 턱을 넘어 산악인 위로 → 피켈이 흰 배추를 흙에 눕힘(溫中) |

## 갈린 점

- 貫衆: 여섯 안 모두 「관중」(통째 동음어)을 냈다. 고사리 잎(기원 덤)을 쓴 안이 넷, 쓰지 않은 안이 둘이다. 한 명으로 낸 안(p3 · p6)과 셋으로 낸 안(p2 · p4 · p5)으로도 갈렸다.
- 焦 · 炭을 어디에 보이나:
  - 팬 속 조각에만: p1 · p4 · p5
  - 피규어 자체를 갈색 · 검정으로: p2 · p6, 그리고 p3 일부
- 止血 표지:
  - 반창고: p2 · p5
  - 피 떨어지는 수도꼭지: p4
  - 굳은 피 한 방울: p6
  - 측우기 속 물이 숯으로: p3
  - 없음: p1
- 檳榔: 여섯 안 모두 무언가가 빈 도시락 안으로 들어간다. p3은 신랑이 웃고, p4는 누룽지로 가득 찬다.
- 麩炒의 경계:
  - 계단: p1 · p4
  - 칸막이: p3
  - 빈 틈: p5
  - 뒤집개: p6
  - 칸마다 소품: p2
- 白朮 · 山藥: p3 · p4 · p5 · p6은 P05에서 「배추 → 산악인」, P06에서 「산악인 → 배추」로 미는 방향을 뒤집는다. p1은 「백산 ↔ 산백」 거울 가사로 같은 뜻을 낸다.
