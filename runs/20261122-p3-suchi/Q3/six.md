# 修治 6+1 · Q3 (P13~P18) — 여섯 안의 생각

관점: p1 소리(가사 쉼 = 목적 경계) · p2 보료와 목적 소품 · p3 사건 먼저 · p4 혼동 짝 가름 · p5 그릴 수 있음 · p6 기존 단서 살리기.

## P13 薑炙 — 황죽후

| 안 | 무대 · 경계 | 생각 한 줄 |
|---|---|---|
| p1 | 생강 쥐어짠 즙이 팬에 · 가사 「황죽, 후~」의 쉼 = 죽 김 | 즙 튐 → 黃連 혀 → 혀끝이 주걱 건드림 → 여사가 죽을 「후~」 불자 후추가 잦아듦(副作用↓) |
| p2 | 생강 짜는 손 · 칸막이 하나 · 멀미봉투(止嘔) · 목도리(목 자극 완화) | 목적을 소품 둘로 바로 보임 — 黃連 찡그림이 풀리고 厚朴은 즙 맞고 목도리 |
| p3 | 도마 위 생강 · 즙 그릇 · 죽솥 김이 경계 | 黃連이 연잎째 미끄러져 죽솥에 퐁당(和胃) → 튄 죽이 그라인더를 돌려 후추가 즙 그릇에 가라앉음 |
| p4 | 손이 위에서 즙만 떨굼(병 · 양동이 없음 = 薑) · 생강 조각 칸막이 | 黃連 헛구역이 멎음 — 酒炙에서 솟는 黃連과 가름 · 厚朴 후추 재채기가 즙에 멎음 |
| p5 | 팬 하나 · 생강 그릇 · 팬 턱 한 단 | 연꽃이 잎으로 생강을 짬 → 죽솥 → 주걱이 그라인더를 돌려 팬에 후추를 뿌림 |
| p6 | pilot-cho 작업대 그대로, 식초병 자리에 생강 · 생강 조각 그릇이 칸막이 | 연꽃 혀 → 주걱 침 → 죽이 튀어 그라인더가 돌며 후추 뿌림(맵기 순해짐) |

## P14 蜜炙 ① 潤肺止咳 — 마백관자비

| 안 | 무대 · 경계 | 생각 한 줄 |
|---|---|---|
| p1 | 꿀단지 · 꿀 팬 · 「마백 관자비」 2+3 숨, 칸막이 없음 | 망토 → 알통 → 동화책 꽃 → 깻잎 이불 → 소 꼬리가 비파 튕김, 꿀이 목 적셔 기침 멎음 |
| p2 | 꿀단지 · 한 칸 · 꿀 덮인 분홍 폐 풍선 | 망토 끈적 → 팔 감김 → 펀치에 책 → 꽃 → 소가 비파 퉁김 → 폐 풍선 촉촉 |
| p3 | 엎어진 꿀단지 · 꿀강 왼→오 | 망토가 투구에 걸림 → 팔꿈치로 책 → 꽃이 소 코 간질여 콜록 → 비파가 꿀에 젖어 잠잠(潤肺止咳) |
| p4 | 꿀단지 · 꿀 실이 다섯을 한 줄로 이음 | 다섯이 꿀 실로 묶이고 모두 목 감싸고 기침 멎음 |
| p5 | 꿀단지 왼쪽 · 꿀이 팬 따라 한 줄 | 망토 휙 → 어깨 → 동화책 꽃 → 소 깸 → 비파 줄 |
| p6 | 같은 작업대 · 왼끝 금빛 꿀단지(hp-04) | 꿀 젖은 마왕 망토 → 알통 → 책 → 꽃잎 이불 → 소 코골이에 비파 울림 |

## P15 蜜炙 ②③④ — 황감마마

| 안 | 무대 · 경계 | 생각 한 줄 |
|---|---|---|
| p1 | 「황감, 마-마!」(황감하옵니다 마마) 쉼 둘 = ②|③|④ | 깃발 → 감초 약장이 절함 ‖ 마왕 땀 멎고 망토 다시 걸침 ‖ 만두 두령이 꿀 핥고 웃음 |
| p2 | 세 칸 · 노란 배 풍선 · 땀 멎은 마왕 · 꿀로 막힌 방울 | 깃대가 서랍 밀어 배 풍선 부풂 · 땀방울이 꿀로 굳음 · 방울 소리 끊김 |
| p3 | 단 셋 | 깃발 끈이 서랍을 당김 → 감초가 꿀을 흘림 → 마왕 땀 멎고 망토 반만 → 망토 자락이 방울을 덮음 |
| p4 | 3단 선반 | 깃발 꿀이 감초 서랍에 고임 · 땀방울이 꿀방울로 굳음(P14는 기침, 여기는 땀) · 마두령이 꿀 찍어 먹고 구역질 멎음 |
| p5 | 팬 위 꿀 웅덩이 셋 | 깃대 쓰러짐 → 감초가 마왕을 찌름 → 망토 다시 두르고 땀 멈춤 → 방울 울림 |
| p6 | 꿀 줄기가 칸마다 끊김 | 깃대가 약장 툭 · 마왕이 망토 다시 두르고 얌전히 앉음 · 망토 끝이 방울 침 |

|---|---|---|---|

| p2 | 기름병 팬 · 두 칸 · 핫팩(溫腎) · 뼈 부스러기(粉碎) | 태극 무늬 곽티슈(휴지 솟음) | 기름 튐 → 휴지가 방망이 닦자 바삭 → 표범 막음 → 장갑이 찬합 뚜껑 |
| p3 | 쓰러진 기름병 · 기름 웅덩이 · 칸막이 | 태극 곽티슈를 뽑아 먹는 숫양 | 숫양이 병을 엎음 → 미끄러진 통뼈가 깨짐 → 표범 놓침 → 조각이 찬합에 쏙 |
| p4 | 주둥이 긴 기름칠 깡통(병 아님 → 酒 · 醋와 안 겹침) · 미끄러짐 문법 | 음양 곽티슈에서 숫양이 불끈 | 통뼈 바삭 → 표범 미끄러짐 → 찬합 미끄러짐 |

| p6 | 같은 작업대 · 노란 기름병 · 기름 줄기 끊김 | 흑백 태극 곽티슈에서 휴지 대신 풀잎 | 풀잎 뽑히며 기름 튐 → 호랑이 통뼈 → 표범 막음 → 찬합 흔들 |

## P17 明煅 — 백붕석대모적 (새 항목 硼砂)

| 안 | 무대 · 경계 | 硼砂 단서 | 생각 한 줄 |
|---|---|---|---|
| p1 | 화로 숯불 · 「백붕석대, 모적」 4+2 · ②는 화로 밖 모래 더미 | 불에 부풀어 붕 떠오른 흰 결정 사다리 | 백반 부풂 → 사다리 솟음 → 석쇠 쳐 안경 튐 → 막대자석에 붙음 ‖ 적석지가 모래를 눌러 조임 |
| p2 | 화로 위 맨몸 · 두 단 · 뻥튀기(結晶水) · 끈 졸라맨 복주머니(收斂) | 사다리 타는 흰 붕어 | 白礬 뻥 → 붕어 사다리 밀림 → 석쇠로 떨어짐 → 안경이 자석에 끌림 ‖ 완장 팔이 복주머니 끈 조임 |
| p3 | 화로 단(①) 아래 모래 둔덕(②) | 붕대 감은 사다리 | 백반 펑 → 사다리 넘어짐 → 안경이 자석에 → 자석이 둔덕 차 굴 덮음 → 적석지가 굴 조임 |
| p4 | 맨불(그릇 · 액체 없음 = 明煅) · 벽돌 턱 | 붕어빵 꼴 하얀 사탕 결정 | 白礬 팝콘 → 硼砂 김 빠짐 → 안경 김 서림 → 赭石 벌겋게 ‖ 굴 · 완장 꽉 조임 |
| p5 | 화로 하나 · ②는 화로 끝 식은 쪽 | 붕붕카를 모는 사슴 | 백반 흰 김 → 붕붕카 붕 뜸 → 석쇠 들이받아 안경 → 자석 ‖ 굴 껍데기 닫힘 · 완장 조임 |
| p6 | 작업대 오른끝 hp-04 화로 · 재 틈이 경계 | 흰 결정 붕어빵을 틀에서 꺼내는 사장님 | 백반 부풂 → 붕어빵 틀 뒤집다 전복 튐 → 안경이 자석에 ‖ 굴 모래 흩날림 → 완장 조임 |

## P18 煅淬 + 悶煅 — 자대자노혈건

| 안 | 무대 · 경계 | 생각 한 줄 |
|---|---|---|
| p1 | 액체 양동이(치익) · 봉한 단지 · 「자, 대자노! 혈건」(자, 대자로 누워!) | 집게가 말굽자석 담금 → 쇠못이 막대자석 끌어 눕힘 → 도끼가 양동이 침 → 감이 노 저음 ‖ 연탄 · 건빵이 단지에서 탄 |
| p2 | 화로 + 치익 양동이 · 밧줄 단지 · 김 기둥 / 숯 연기 | 쇠집게가 赭石을 양동이에 → 김에 동상 식음 → 노가 단지 밧줄 툭 ‖ 안에서 새까매짐 |
| p3 | 집게 · 양동이 / 밧줄 단지 | 자석 못 줄 치익 → 동상이 쩍 갈라짐(부서지기 쉬움) → 배가 단지로 → 노가 매듭 당김 → 건빵이 틈을 옻칠로 메움 |
| p4 | 화로 → 집게 → 양동이 / 밧줄 단지(공기 막힘) · 빈틈 | 磁石이 赭石을 끌어 붙은 채 치익 → 김이 동상을 덮음 → 돌배 노 젓기 ‖ 血餘炭 머리칼이 단지 묶는 밧줄 · 乾漆 붓이 뚜껑 틈 옻칠 밀봉 |
| p5 | 양동이 하나 · 단지 하나, 집게 · 화로 빼고 말굽자석이 집게 노릇(새것 8) | 말굽자석이 벌건 막대자석을 양동이에 치익 → 동상 뛰어듦 → 돌배가 양동이 건넘 → 노가 연탄을 단지로 → 건빵이 밧줄 묶음 |
| p6 | hp-04 집게 + 양동이 / 밧줄 단지 · 김 구름 대 연기 없는 단지 | 집게가 말굽자석 담금 → 막대자석 풍덩 → 동상 반짝, 돌배 밀어 노 → 노가 밧줄 툭 → 단지 옆 연탄 · 건빵 |
