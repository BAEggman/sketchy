1. 캐릭터: 사람·동물 없음. 왼쪽부터 — 은색 양동이(손잡이 달림)가 맨 위 단 위에 옆으로 쓰러져 물을 쏟음 / 바퀴 4개 달린 전자레인지(창 안에 운전대처럼 보이는 핸들)가 가운데 단 위로 기울어져 굴러 내려오며 왼쪽 옆구리에서 물을 뿜고, 아래 바닥에서도 물이 폭포처럼 아래 단으로 흘러내림 / 오른쪽 아래 단에 거꾸로 선 갈색 사발(또는 깔때기)이 아래 끝에 연필 지우개 머리(은색 쇠띠+분홍 지우개)를 달고 불꽃 속에 박혀 있음 / 맨 오른쪽 프라이팬 위에 노란 둥근 부침개(달걀프라이 위에 노란 팬케이크가 얹힌 모양, 물방울 무늬)
2. 소품·배경: 나무 조리대 3단 계단식(왼쪽 높고 오른쪽 낮음), 단마다 파란 가스불 + 빈 프라이팬(맨 위 1개, 가운데 2개, 아래 1개는 부침개 담김). 양동이 옆 흰 가루 더미(소금/설탕처럼). 하늘색 물줄기가 위 단 → 가운데 단 → 아래 단으로 연속해서 흐름. 아래 단 가운데에 빨강·주황 불꽃(가스불이 크게 타오름). 배경은 연한 베이지 벽.
3. 글자·숫자: 없음.
4. 이상한 점: 전자레인지에 바퀴·창 안에 핸들(자동차처럼). 사발 밑에 연필 지우개 끝이 붙은 이음매. 전자레인지 옆에서 물이 분수처럼 뿜어짐(구멍 출처 불명). 가운데 단 뒤쪽 프라이팬은 전자레인지에 반쯤 가려짐. 오른쪽 끝 단과 프라이팬 손잡이가 화면 밖으로 잘림.
5. 헷갈릴 물건: 흰 가루 더미 「소금으로도 설탕·밀가루로도 보임」 / 전자레인지 「전자레인지로도 토스터오븐·차(자동차)로도 보임」 / 갈색 그릇 「사발로도 화분·깔때기·도토리깍지로도 보임」 / 노란 부침개 「팬케이크로도 달걀프라이·치즈로도 보임」

## P13
1. 캐릭터: 왼쪽부터 — 화면 왼쪽 밖에서 들어온 사람 손이 생강 뿌리를 움켜쥐어 즙을 짜냄(노란 즙이 사방으로 튀고 아래로 떨어짐) / 노란 연꽃(초록 연잎 위) 얼굴 캐릭터가 눈을 질끈 감고 혀를 내밀어 구역질·토하는 표정, 몸을 떨고 있음(진동선), 입에서 노란 즙 방울이 떨어짐, 큰 냄비 가장자리에 걸쳐 있음 / 가운데 뽀글머리 할머니(보라색 꽃무늬 옷, 노란 꽃무늬 앞치마)가 웃으며 초록 대나무 같은 자루의 나무 주걱으로 냄비 속 죽을 휘저음 / 오른쪽 프라이팬 속 흰 조롱박(호리병) 얼굴 캐릭터가 볼 빨갛게 웃음, 옆에 얇은 생강(또는 감자) 조각이 세워져 있음 / 오른쪽 위 갈색 나무 후추통(후추 그라인더)이 공중에서 돌며 검은 후추 알갱이를 뿌림
2. 소품·배경: 큰 검은 양손 냄비에 흰 죽(갈색 덩어리, 초록 잎 조각 섞임). 오른쪽 검은 프라이팬에 노란 기름/국물, 아래 가스레인지 파랑+주황 불꽃. 나무 탁자, 연한 흰 벽. 주걱 자루 끝에서 죽이 분수처럼 위로 뿜어져 포물선을 그리며 조롱박 쪽으로 날아감.
3. 글자·숫자: 없음.
4. 이상한 점: 주걱 자루가 대롱처럼 뚫려 끝에서 죽이 뿜어져 나옴. 후추통이 손 없이 공중에 떠서 회전. 왼쪽 손은 팔만 있고 몸 없음(화면 밖에서 잘림). 조롱박 위쪽 주둥이가 열려 있음.
5. 헷갈릴 물건: 노란 연꽃 「연꽃으로도 수련·국화로도 보임」 / 생강 「생강으로도 인삼·마른 뿌리로도 보임」 / 조롱박 「조롱박으로도 호리병·흰 병·마늘로도 보임」 / 팬 속 노란 조각 「생강 편으로도 감자·바나나 조각으로도 보임」 / 초록 자루 「대나무로도 파(대파)·호스로도 보임」 / 후추통 「후추 그라인더로도 체스 말·소금통으로도 보임」

## P14
1. 캐릭터: 왼쪽부터 — 금색 꿀단지가 쓰러져 노란 꿀을 긴 쟁반에 쏟음 / 빨간 아기 도깨비(뿔 2개, 금관, 화살촉 꼬리, 노란 목수건)가 울며 땀 흘리고, 오른손으로 옆 전사의 노란 천(망토)을 붙잡아 당김 / 근육질 로마 전사(은색 투구에 빨간 깃, 빨간 망토, 손목 보호대)가 웃으며 양팔 알통 자세, 머리 뒤로 노란 천이 펄럭임 / 보라색 책이 펼쳐져 꽃들과 금관이 튀어나옴(표지에 왕관·노란 꽃 그림) / 보라색 소(뿔, 분홍 코)가 눈 감고 꿀 위에 엎드려 잠, 큰 초록 잎을 이불처럼 덮음, 코에서 흰 김(숨) 줄기가 오른쪽으로 흐름 / 맨 오른쪽 초록 잎 모양 몸통의 비파(현악기)가 꿀 속에 서 있음
2. 소품·배경: 나무 탁자 위 긴 은색 직사각 쟁반, 그 안을 노란 꿀이 왼쪽→오른쪽으로 가득 흐르고 오른쪽 끝에서 탁자 아래로 뚝뚝 떨어짐. 꽃(빨강·분홍·보라·노랑), 반짝이 별, 분홍 꽃잎. 흰 김(연기) 줄기. 연한 벽.
3. 글자·숫자: 없음(책 표지는 그림만).
4. 이상한 점: 전사의 노란 천이 도깨비 손까지 이어져 누구 것인지 모호(전사 망토는 빨강인데 노란 천이 따로 있음). 전사는 쟁반 뒤에 서 있어 하반신 가려짐. 책이 공중에 비스듬히 떠 있음. 비파 몸통이 나뭇잎 결무늬.
5. 헷갈릴 물건: 노란 액체 「꿀로도 카레·치즈·기름으로도 보임」 / 도깨비 「도깨비·악마로도 황소 아기로도 보임」 / 보라 소 「소로도 하마·돼지로도 보임」 / 초록 잎 「깻잎·들깨잎으로도 뽕잎·박하잎으로도 보임」 / 악기 「비파로도 만돌린·류트로도 보임」 / 노란 천 「망토로도 깃발·수건으로도 보임」
