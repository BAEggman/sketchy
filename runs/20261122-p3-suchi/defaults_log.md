# 기본값 적용 기록 (6+1 심판 추천을 기본값으로)

## Q2
- 烏梢蛇 새 피규어 = 「오! 초사이어인 검은 뱀」(심판 1위 21점) — 기본값 적용. 烏梅 「오매!」와 외침이 겹치나 그림(뱀 ↔ 매실)으로 갈림. 차점 p5 「오이 초밥 삼킨 검은 뱀」(16점)은 대안으로 남김.
- P12 가사 「차지황」 유지(brief 원안) — 기본값 적용. p1 「차 / 지모황백」 제안은 대안으로 남김.
- 목적 그림 문법 22장 공용 — 병합 때 Q1·Q3·Q4와 맞춤(毒性↓ = 보라 독구름 흩어짐 · 矯臭 = 초록 악취 김 → 하얀 김 · 上行 = 술 김 기둥 · 下行 = 아래 단으로 흐름 · 加輔料炒 = 센 주황 불 ↔ 炙 = 약한 파란 불, 3540행).
- 교재 확인(직접 읽음): 3537행 砂炒 ③ 矯味矯臭는 대상 약이 적혀 있지 않음(맞음). ④ 「洗淨 便利」는 교재에 털 제거라고 적혀 있지 않음 → 그림의 「잔털 그을림」은 그림 해석일 뿐 사실 문장으로 쓰지 않음. 3544행 鹽炙 ① 下行은 a 補肝腎 · b 治疝 · c 利尿 전체에 걸림(괄호 구조로 확인).

## Q4
- 何首烏 새 피규어 = 「하수구 맨홀에서 솟아 까딱이는 윤기 나는 검은 머리 오뚝이」(24점) — 기본값 적용. 하수구 · 오뚝이는 사전 어디에도 안 쓰임.
- P22 가사 「백반 | 천」 유지(원안) — 바꾸지 않으므로 기본값. p1 「백 반복 | 천 변」은 대안으로 남김.
- new-etc-18 단지 = 도자기(유리는 왕조 터 「맑은 유리」 표지와 겹침) — 기본값 적용.
- 烏頭-두부(煮法 괄호)는 P21 물건 한도 8 때문에 그림에서 빼고 학습층 글에만 둠 — 기본값 적용.
- 교재 확인(직접 읽음, 3553행): 燀法 대상은 교재 글자로 「萹豆」. 萹(마디풀 萹蓄의 글자)와 扁은 다른 글자라, 白扁豆로 읽은 것은 「확인 필요」로 둠. 학습층에는 교재 글자 「萹豆」를 그대로 적고 피규어만 白扁豆를 빌려 씀. 宣木瓜 → 木瓜 피규어도 같은 방식(교재 글자 그대로 적음).
- 生地黃은 사전에 없음 → P19의 날생선은 「生」 표지 소품으로만 씀(사실 추가 아님).

## Q3
- P18: hp-04 煅淬 표지 중 집게 · 화로를 빼고, 말굽자석(磁石)의 쇠못 줄이 집게 노릇으로 달군 代赭石을 양동이에 담금 — 기본값 적용(새 물건 8 한도). 「담금질 = 煅淬」 표지 자체(달군 것을 물에 담가 치익 김)는 그대로라 기존 결정을 바꾸지 않은 것으로 봄. 사용자 보고에 적어 이의 기회를 줌.
- 淫羊藿 새 피규어 = 흑백 음양 무늬 곽티슈에서 풀잎이 뽑혀 나옴(23점) — 기본값 적용. 예약표 태극 원반(yyox-02 · etc-01)은 「원반 · 연」이고 이것은 「곽티슈 상자 무늬」라 물건이 다름.
- 硼砂 새 피규어 = 붕 떠오른 붕붕카를 모는 사슴(21점) — 기본값 적용. 위험: 사슴이 五禽戲(hist-01) · 鹿茸 사슴뿔(new-etc-22)과 엮여 「鹿」으로 읽힐 수 있음 → 스티커 블라인드 판독에서 「사슴 → 鹿」 오독이 나오면 운전자만 바꾸는 6+1 필요로 표시.
- 기름칠 깡통(P16 표지)은 jq-23 「깡통+인형」과 모양 · 쓰임이 다름(주둥이 달린 기름통) — 그대로.
- 油炙 기름 넷(麻油 · 羊脂 · 菜油 · 蓍油, 3547행) 학습층에 모두 적음.
- 厚朴 副作用의 구체 내용은 교재에 없음 → 학습층에 지어 쓰지 않음.
