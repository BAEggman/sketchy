# runs — 6+1 실행 기록

소품 · 상황 · 그림 간 연결을 짓거나 고친 일은 모두 여기 한 폴더씩 남는다(계획서 5절).

```
runs/<run_id>/
  brief.md      사실 묶음: 교재 근거 줄, 바꿔 나오는 짝, 지킬 단서, 사전에 이미 있는 항목, 못 쓰는 운반 낱말
  p1.json … p6.json   여섯 독립 안(서로 안 봄)
  six.md        여섯 안이 생각한 소리 · 기억 단서 표
  judge.md      일곱 번째: 기준서 읽고 쓴 세 줄 → 단서별 25점 · 장면 100점 → 낙제 → 합친 안 → 채택 · 탈락 까닭
  final.json    채택한 명세(사전 항목 · 장면 · 그림 지시 · 대본)
```

자동 판독 점수는 참고로만 적고 합격 근거로 쓰지 않는다. 합격은 사용자 검수다.
