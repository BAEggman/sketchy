### 4-2. 사건 장면

과 하나의 그림은 인물 묶음 서너 개다. 묶음 하나는 **사건 한 컷**이다.

> 누가(인물 피규어) — 무엇에(서명 피규어) — 어떻게(기여 동사) — 그래서(의의)

- 인물의 **손이 책에 닿아 있어야** 한다. 책 피규어가 인물과 떨어져 놓이면 불합격이다.
- 기여 동사는 공용으로 고정한다. 과마다 새로 짓지 않는다.

  | 기여 | 고정 동작 |
  |---|---|
  | 지음(著) | 빈 것에서 처음 만들어 냄(빚음 · 낳음 · 꺼냄) |
  | 합쳐 엮음(合編 · 集注) | 둘을 한 그릇에 쏟아 섞음 |
  | 주석(注) | 원본에 쪽지를 붙임 |
  | 보탬(增補 · 補入) | 있던 것 옆에 새것을 덧댐. 원래 몫과 보탠 몫의 색이 다름 |
  | 교정(校正) | 틀린 것을 지우고 고쳐 씀 |
  | 나눔(分) | 하나를 둘로 가름 |
  | 분류해 다시 엮음(類編) | 섞인 것을 칸칸이 갈라 담음 |
  | 나라가 엮음(官修) | 붉은 봉인 |

- 의의는 금메달 하나로 끝내지 않는다. 「무엇의 최초인가」를 메달이 걸린 물건이 말해야 한다. 「現存 最古」와 「최초」는 교재 글자대로 갈라 적는다.
- 왕조는 지금의 「터」 표지(梁 = 흰 양, 隋 = 수국, 晉 = 진달래, 唐 = 사탕 …)를 그대로 쓴다. 터는 통음이고 사용자도 받아들였다.
- 한 그림에 새 물건은 여덟 개까지, 구역 편집 한 번에 셋까지. 이 한계는 실측이라 바꾸지 않는다.
- 그림 안에는 글자와 숫자를 넣지 않는다. 정확한 한자·독음·원문·수는 그림 밖 학습층(재생기의 사실 칸, 도해)에 다 적는다.


### 5-1. 기준서 — 통한 단서는 왜 통했나

일곱 번째 에이전트는 채점 전에 이 절을 읽고 「이번 묶음에 맞춰 기준을 어떻게 쓸지」를 세 줄로 먼저 적는다.

| 사용자가 통했다고 한 단서 | 통한 까닭 |
|---|---|
| 전원 기립 → 全元起 | 세 음절이 다 나온다. 누구나 아는 말이다. 한 컷의 동작이다. 우습다 |
| 백설기 → 薛己(설기) | 흔한 사물의 이름 안에 목표 음절이 **끊기지 않고** 들어 있다 |
| 유연한 자 → 劉涓子 | 전체 음절. 꾸밈말 하나 + 사물 하나 |
| 납작 엎드린 까치 → 扁鵲 | 뜻 고리지만 훈이 쉽고(납작 · 까치) 그림이 이상해서 눈에 걸린다. 걸음이 하나다 |
| 손자 + 사막 → 孫思邈, 경례하는 소 → 蘇敬 | 낱말 둘의 소리를 이으면 이름이 된다. 낱말이 서로 다르고 흔하다 |
| 胃 45혈 「45세부터 위가 약해진다」, 脾 21 블랙잭, 腎 27 「3의 3승」, 三焦 23 「이렇게 초초한데 삼초」 | 수에 **이유**가 붙었다. 임의 부호가 아니라 말이 되는 한 문장이다 |
| 舍岩 「태백산의 태연이가 어제 소부산으로 갔다」 | 혈 이름 넷이 문장 안에 소리째 들어 있다. 순서가 곧 補 둘 · 瀉 둘이다 |

약했던 것: 서랍 → 徐之才(첫 음절 하나만 나오고 之才는 문장에 기댄다), 부호표를 알아야 풀리는 것 전부.

여기서 나오는 채점 항목(단서 하나에 25점):

| 항목 | 점 | 묻는 것 |
|---|---|---|
| 음절 포함 | 6 | 목표 독음의 음절 가운데 그림 낱말이 직접 내는 비율. 전부면 만점 |
| 걸음 수 | 5 | 0걸음(동음어 그대로) 5 · 1걸음 4 · 훈을 거치는 2걸음 1 · 부호표가 있어야 하면 0 |
| 낱말 친숙도 | 4 | 사용자가 그 물건을 그 낱말로 부르는가. 한 낱말이거나 굳은 표현인가 |
| 한 덩어리 | 3 | 사물 하나 또는 맞닿은 둘, 동작 하나 |
| 이상함 | 2 | 정상에서 벗어난 한 가지(납작 · 기립 · 거꾸로) |
| 변별 | 3 | 사전 안에서 운반 낱말이 겹치지 않는가. 닮은 답과 갈리는가(金鏡 ↔ 金鑑, 大成 ↔ 大全) |
| 거꾸로 | 2 | 이름을 듣고 그림이 떠오르는가 |

유형의 우선순위(같은 점이면 위가 이긴다):
1. **통째 동음어**: 승마(升麻) · 낭독(狼毒) · 행인(杏仁) · 세신(細辛) · 상륙(商陸)
2. **낱말 속 연속 포함**: 백설기(설기) · 청피망(청피) · 대극장(대극)
3. **가까운 소리의 한 낱말**: 오렌지(오령지) · 택시(택사) · 물약(몰약)
4. **두 낱말 잇기**: 반바지 하마(반하) · 천사 궁수(천궁). 운반 낱말 중복 상한을 지킨다
5. **형태소 가족**: 시험이 가족으로 묻는 것만(烏頭類 = 까마귀, 朮 = 배추, 五參 = 뿌리 인형, 硝 = 양초)
6. **익숙한 실물**: 인삼 · 생강 · 국화
7. **뜻 고리**: 훈이 쉽고 한 걸음일 때만

장면(과) 채점은 100점이다: 사실·출처 20 · 단서 합(위 25점의 평균을 환산) 30 · 관계가 인물의 손에서 일어나는가 20 · 교재 범위와 혼동 쌍 10 · 소품 수와 그릴 수 있음 10 · 기존 약속 보존 10.

### 5-2. 절차

대상은 「소품 · 상황 만들기와 그 밖의 Sketchy 요소 · 그림 간 연결을 새로 짓거나 고치는 일」 전부다. 글만 고치는 일, 코드, 도해는 6+1을 거치지 않는다.

1. **사실 묶음을 만든다.** 과 하나 또는 인물 서너 명이다. 교재 근거 줄, 문제집에서 바뀌어 나온 짝, 지킬 기존 단서, 사전에 이미 있는 항목, 쓰면 안 되는 운반 낱말을 적는다. `runs/<run_id>/brief.md`.
2. **여섯 에이전트를 한 번에 띄운다.** 서로의 안을 보지 않는다. 출발 관점은 고정한다.
   1. 통째 동음어를 먼저 찾는 안
   2. 낱말 속 포함과 가까운 소리의 안
   3. 사건(누가 무엇에 어떻게)을 먼저 짜는 안
   4. 문제집의 바꿔치기 짝을 가르는 안
   5. 그릴 수 있음과 소품 수를 지키는 안
   6. 기존 단서 · Gemini 아이디어를 최대한 살리는 안
3. 각 안은 정해진 꼴로 낸다(`runs/<run_id>/p1.json` … `p6.json`). 단서마다 「물건/동작 → 한국어로 부르는 말 → 독음 → 목표」, 버린 후보와 까닭, 화면에서의 자리, 거꾸로 묻는 문항 하나.
4. **여섯 안을 보고한다.** 어떤 소리 단서 · 기억 단서를 생각했는지를 묶음별 표 한 장으로(`runs/<run_id>/six.md`). 사용자가 볼 수 있게 허브의 「설계 기록」에 건다.
5. **일곱 번째 에이전트가 심사한다.** 5-1절을 읽고 기준 세 줄을 적는다 → 단서별 25점, 장면 100점 채점 → 낙제 조건 확인 → 가장 적은 구성으로 합친다(높은 점 소품을 다 넣지 않는다) → 합친 뒤 사전 충돌과 혼잡을 다시 본다. `runs/<run_id>/judge.md` · `final.json`.
6. 채택한 단서를 사전에 올린다(`status: candidate`). 그림이 나오고 사용자 검수를 넘으면 `fixed`로 바꾼다.

낙제 조건(총점과 상관없이 탈락): 사실 오류 · 저자 바꿔치기 · 인물의 손이 책에 닿지 않음 · 사전의 기존 항목과 같은 운반 낱말 셋째 사용 · 유주나 해부를 틀리게 그림 · 사용자가 지키라고 한 단서를 까닭 없이 바꿈.

비용을 줄이는 규칙: 제안은 묶음당 1,500자 안의 JSON. 심사자는 원안을 고치지 않는다. 한 묶음에 한 번만 돌리고, 낙제로 채택안이 없을 때만 한 번 더 돌린다.
