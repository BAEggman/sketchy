# 六淫 통합판 s15u01 설계 (2026-10-13)

무대: 마을 긴 흙담(뒤) 바깥 앞길 — 外感의 外(담 바깥). 계절이 왼쪽 봄 → 오른쪽 겨울로 흐른다.
구역(왼→오): 風(春) · 暑(盛夏) · 火 · 濕(장마·長夏) · 燥(秋) · 寒(冬). 火를 暑 옆, 寒을 맨 끝에 — 寒의 얼음이 살아 있는 불과 맞닿지 않게(사전 陰 갈림).

라운드
R0 바탕: 담·길·계절 + 여섯 사람(자세만) — 새 요소 8
R1 風+暑: 모자·소매 옆날림(이미 R0) / 몸 곳곳 크기 다른 통증 표시 / 바람 꼬리의 작은 날씨 다섯 / 이글거리는 해 / 아지랑이 / 밑동 금 간 물동이에서 맑은 물 샘 / 발밑 진창·낮은 안개 — 새 6~7
R2 火+濕: 곧게 솟는 불길 / 코피·팔의 붉은 반점 / 노랗게 곪은 종기 / 끈적하게 느린 흙탕물 / 종아리 진흙·부종 / 벽 곰팡이 + 깨진 화로 꺼진 재 — 새 6
R3 燥+寒: 금 간 물동이 맑은 물 샘 / 살 부러진 흰 부채 / 갈라진 땅 + 곧게 떨어지는 마른 잎 / 눈송이 / 얼어 멈춘 물길 + 얼음 속 쇠못 / 깨진 화로 꺼진 재 — 새 6

규칙 173 역검색 메모
- 燥 물동이: 「밑동까지 마른 물독」= 內燥 와 충돌 → **마른 게 아니라 금 사이로 맑은 물이 새는** 물동이로(傷津). 暑와 같은 사물 = 「暑·燥 모두 傷津」 딥링크.
- 濕·寒 깨진 화로 둘 = 「濕·寒 모두 傷陽」 딥링크(의도된 중복).
- 寒 얼음: 사전 陰 갈림 — 살아 있는 불과 맞대면 陰. 火 구역과 떨어뜨림.
- 風 날아가는 모자: 太(머리에 쓴 큰 갓)와 갈림 — 머리에서 떨어져 날아감 + 밀짚모자.
- 風 잎은 옆으로, 燥 잎은 곧게 아래로 — 「燥는 風과 다르다」(함정 행)가 한 그림 안에서 대비됨.

## 진행 기록
- R0 바탕: 담·계절·여섯 사람 자세 — 전부 생성(1024×572). Gemini가 해를 미리 넣음.
- R1 風+暑 5개 추가: 5/5, 기존 소실 0 (그림이 1024×434 초광폭으로 바뀜).
- R2 火+濕 6개 한 번에: **실패 — 규칙 170 전면 발동.** 화면을 확대·재구성해 燥·寒 구역과 계절 띠가 사라지고, 5·6번째 사람 자세가 무표정 직립으로, 날아가던 모자가 손에 쥐어짐. 새 소품(장작불·흙탕물·깨진 화로·곰팡이)은 들어갔지만 판 전체가 무너짐.
  → 교훈: 이미 소품 ~20개가 든 판에 6개를 한 번에 더하면 모델이 「다시 그리기」로 넘어간다. 라운드당 3개로 줄이고 새 채팅에서 R1 원본을 올려 편집.
- R2a(새 채팅, R1 업로드, 火 3개): 구도 보존. 장작불 ✓ · 팔 반점 ✓ · 코피·종기는 얼굴이 작아 거의 안 보임.
- R2b(濕 3개): 구도 보존, 그러나 **깨진 화로·곰팡이가 燥·寒 사이로 잘못 붙음**(서수 지칭 「네 번째 사람」이 틀림). 흙탕물·부은 발목 약함.
- 고치기(옮기기 2): 곰팡이 ✓ 이동, 화로는 안 옮겨짐.
- R3a(燥 3개): 부채만 들어감(그것도 濕·燥 사이 애매), 물동이·갈라진 땅·곧은 낙엽 ✗.
  → 소품이 ~20개 든 파노라마에서는 라운드당 성공률이 5/5 → 2/3 → 1/3로 떨어진다. 그림 전체를 보여 주고 고치게 하면 모델이 「어디에」를 놓친다.
  → 전환: **구역 잘라 편집 후 다시 붙이기** — 구역 하나(사람 하나 + 소품 3~4)만 잘라 올려 편집하고, 결과를 원래 자리에 경계 페더로 붙인다. 모델이 보는 소품 수가 늘 4~6개라 실험의 안전 구간 안에 머문다.
- 전환 후(구역 잘라 편집 → 다시 붙이기): 濕·燥·寒·火 네 구역을 R2a에서 9:16으로 잘라 **각각 새 채팅**에서 3개씩 편집 → 4/4 구역 모두 3/3 성공, 다른 소품 소실 0.
  붙이기: 겹치는 타일 캡처(`tile_stitch2.py`, 겹침 96px 정합) → 원본 2배 캔버스에 구역별 정합(±12px 탐색) → 띠 경계 페더 14px. 燥의 물동이는 濕의 화로와 x가 겹쳐 띠로 못 살려 타원 패치로 18px 옮겨 붙임(`zone_composite.py`).
