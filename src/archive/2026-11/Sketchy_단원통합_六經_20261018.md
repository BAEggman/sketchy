# Sketchy 단원 통합 — 六經 두 장 s13u01 · s13u02 (2026-10-18)

六經 낱장 여섯(s13p01~06, 24행)은 사실 수로는 한 장 안(≤26)이지만 **사람이 아홉**(太陽·陽明·少陰이 두 사람 비교 칸)이고 소품이 얼굴 표지(땀·홍조·쓴 입·어지러운 눈)와 세간(무쇠솥·요강·항아리·모래시계)이라, 望色과 같은 이유로 **두 장**으로 갈랐다. 두 장은 **한 성(城)의 단면을 왼쪽에서 오른쪽으로 이어 그린 것** — 축은 病位의 깊이(表 → 半表半裏 → 裏 → 三陰)이고, 傳經 차례(太陽→陽明→少陽)는 도해 s13p11이 진다. 사람은 六淫판(s15u01)과 같은 마을 남자(상투·회청 저고리·황토 바지).

## s13u01 六經 ① 三陽 (s13p01·02·03 → 틀 + 12행)
돌 성벽이 그림을 가로지른다. 왼쪽 삼분의 일은 성 밖(찬 바람·마른 잎) = 太陽, 가운데는 아치 성문 통로(왼쪽 반 차고 흰 빛 · 오른쪽 반 등불 주황빛) = 少陽 半表半裏, 오른쪽 삼분의 일은 성 안 마당(이글거리는 해) = 陽明.
- 太陽 中風: 뒷목 쥠 + 땀 + 풀어헤친 옷깃 + 소매로 바람 가림 + 계피 가지 다발 / 傷寒: 여민 옷깃 + 제 몸을 끌어안고 떪 + 땀 없음 + 마디진 麻黃 다발
- 少陽: 몸 왼쪽 반 소름·오른쪽 반 땀 + 천장에서 좌우로 흔들리는 쇠추(往來) + 옆구리 갈비 아래 누름(胸脇苦滿) + 쓴 입·어지러움 소용돌이(口苦·目眩)
- 陽明 經證: 옷 열어젖히고 물동이 들이켬 + 튀는 땀 + 붉은 얼굴 / 腑證: 북처럼 팽팽한 배 + 돌로 눌러 닫은 무쇠솥 + 갈라진 마른 땅
- 과정: 바탕 1차 채택(다른 탭은 「이미지 생성 미지원」 글로 거절) → 구역 편집 1(桂枝·麻黃 다발 + 바지 글자 무늬 지움).
- **판독: 구역 3/3 · 최종 2인 三陽病 88% · 65%, 인물 5/5 · 5/5, 12행 모두.** 두 독자의 2순위가 모두 表裏辨證 — 성 밖/통로/성 안의 축이 그대로 읽혔다.

## s13u02 六經 ② 三陰 (s13p04·05·06 → 틀 + 10행, 틀 소실 낱장의 무대 행 둘은 틀로)
성 안 깊숙한 석조 건물의 방 셋 — 오른쪽으로 갈수록 깊고 어둡다. 곡식 가마니·벽의 성에가 있는 차가운 곳간(太陰) → 벽감 등잔이 꺼져 가는 창 없는 방(少陰 寒化·熱化) → 천장은 붉게 달아오르고 바닥은 얼음인 가장 깊은 방(厥陰).
- 太陰: 물렁하게 부푼 배에 김 오르는 따뜻한 천 + 김 안 나는 식은 밥·가득 찬 물잔 + 엎어진 요강 / 少陰 寒化: 웅크려 눈 감고 졺 + 검푸른 손발 끝 / 熱化: 앉아 눈 말똥 + 광대뼈 홍조 + 손바닥 위 불꽃 / 厥陰: 윗몸 붉고 허리 아래 얼음 + 가슴 누름 + 물동이 들이켬·빈 단지 여럿 + 밀어 놓은 밥 + 항아리의 회충 + 반 어두운 모래시계
- 과정: 바탕 1차 채택 → 구역 편집 1(식은 밥의 김 지움) → PIL(모래시계 위 절반 어둡게).
- **판독: 구역 3/3 · 최종 2인 三陰病 提綱 90% · 85%, 인물 4/4 · 4/4, 틀+10행 모두.** 사전 딥링크(倉 곳간 · 裏寒 성에 · 溫 따뜻한 천 · 厥 검푸른 손발)가 모두 섰다.
