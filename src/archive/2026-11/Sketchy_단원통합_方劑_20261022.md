# Sketchy 단원 통합 — 方劑 s14u03 (2026-10-22)

낱장 s14p07(四君子·四物·八珍 4) · s14p08(六味地黃丸·腎氣丸 4) · s14p09(小柴胡湯 6, 표제어 라벨을 소품 행으로) = 14행 → **틀 + 14행**, 한 장. s14u01(진열대)·s14u02(뒤뜰)에 이어 같은 한약방의 **안쪽 조제실** — 「약재를 짝지어 처방을 짓는 방」. 사람 둘(잠수부 = 腎, 문지방의 환자).

## 틀
긴 나무 탁자 + 뒤 벽 선반, 오른쪽 ⅓은 밖으로 나가는 문간. 탁자 위 처방 **쟁반** = 「약재 몇 가지가 한 쟁반에」.
- 四君子湯: 네 칸 쟁반(人蔘·白朮·茯苓·甘草) + 한가운데 **김 서린 찰랑한 국물**(사전 補 + 氣 = 補氣) + 선반의 **매·난·국·죽 화분 넷**(사군자 = 이름 다리)
- 四物湯: 똑같은 꼴의 네 칸 쟁반(地黃·當歸·白芍·川芎) + **붉은 액체 가득한 사발**(補-b 血) — 두 쟁반이 좌우 짝
- 八珍湯: 앞의 큰 둥근 쟁반에 여덟 + 한가운데 **진주**(珍)
- 六味↔腎氣: 잠수부(腎)가 왼손에 **얼음·성에 서린 사발**(환약 여섯 + 地黃 검붉은 뿌리) / 오른손에 **숯불·김·계피·附子** 사발 — 살아 있는 불과 맞댄 얼음 = 陰(사전 갈림)
- 小柴胡湯: **문지방에 선 환자**(門·表·裏 = 半表半裏) · 옆구리 짚음(胸脇苦滿) · 김 없는 커피(口苦) · 엎은 그릇(默默不欲飮食) · **수평 저울**(和解) · **섶 단**(柴)

## 과정 — Argon 정지와 Pro 대역
4 Argon이 이날 이미지 도구를 못 불러 바탕 요청이 10분씩 돌다 되돌아옴(짧은 시험 프롬프트도 같음; 글 질문은 정상). 3.1 Pro로 바꾸니 긴 프롬프트를 세 번 글로 거절(「저는 언어 모델이라서…」) — 이분법 시험에서 **잠수부를 농부로 바꾼 판**이 한 번에 섰고(잠수부 + 옆구리 환자 조합이 거절 원인), 그 바탕에 **구역 편집(Pro)으로 농부 → 잠수부**. Pro가 附子 덩이에 만화 얼굴을 그리고 셀 소품 수를 틀려(환약 5·八珍 7·四物 5) PIL로 맞춤(`board_hist/s14u03_post.py`).
판독: 구역 z21 四君子湯 ✓(매난국죽) · z46 四物·八珍·腎 ✓ · z70 補腎陽·和·苦 ✓ · **z95 少陽病 — 半表半裏·胸脇苦滿·柴 ✓** → 판 전체 O4·P4 補益 70%·70% → PIL 뒤 **Q4 補益 85% · R4 65%**, 처방 이름 다섯(四君子·四物·八珍·六味地黃丸·腎氣丸) 4/4 ✓, 인물 2/2.

## 잔결 (출력만)
- **小柴胡湯 구역이 판 전체에서 補益에 묻힌다**(「補 사용주의·腹痛」) — 和解劑 하나가 補益劑 넷 사이에 있어서. 다음 손질 후보: 환자 곁에 往來寒熱(문 밖 찬 바람 + 문 안 불꽃).
- 섶 단(柴)은 사전 밖이라 띠에서만 읽힘(판 전체는 黃芪·땔감) — 사전 柴 등재 후보 · 엎은 그릇 둘은 전원 뜻 미상 · 환자 옆구리의 붉은 자국이 血로 샐 수 있음 · 진주 → 華 갈림 · PIL 지운 자리 흔적 · 물안경이 CANON 꼴(타원 하나) 아님.

## 운용 교훈 (MASTER §7)
짧은 시험 프롬프트로 이미지 도구 생사부터 확인 → 멈췄으면 3.1 Pro가 바탕 대역(사람 2 + 소품 20 한 번에, 화풍도 따름; 얼굴 장난·개수 오류는 PIL 전제) · 긴 프롬프트가 거절되면 인물 하나를 평범한 사람으로 바꿔 받고 구역 편집으로 되돌리기 · 보내기 첫 클릭이 안 먹으면 2초 뒤 다시 · 성격이 다른 처방을 한 판에 섞으면 소수 구역에 제 단원 표지를 하나 더 · 처방 이름은 한자 풀이보다 **관용 사물**(사군자 = 매난국죽)이 세다.
