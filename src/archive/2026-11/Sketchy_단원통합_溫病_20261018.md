# Sketchy 단원 통합 — 溫病 衛氣營血 s13u03 (2026-10-18)

낱장 s13p07~10(衛分·氣分·營分·血分, 17행)을 한 장으로. 틀 소실 낱장 s13p08의 무대 행은 틀 행이 갈음 → **틀 + 16행, 사람 넷**(단계마다 하나).

## 틀
나무 기둥·흙벽 시골집의 **긴 방 단면** — 왼쪽 끝 활짝 열린 문으로 대낮 햇빛이 들고, 오른쪽으로 갈수록 안쪽·어둠, 오른쪽 뒤 벽 작은 창 밖은 밤하늘의 초승달, 오른쪽 끝은 가장 깊고 어두운 구석. 네 남자(六經판과 같은 마을 사람)가 문가 → 한가운데 → 안쪽 → 구석에 앉아 **넷 다 혀를 크게 내밀고 있다**(같은 크기, 색·이끼만 다름 — 舌象 비교 칸). 자리의 깊이 = 단계, 낮 → 밤 = 얕음 → 깊음. 六經 두 장(성의 단면)의 「자리 = 病位」 문법을 한 방 안에 다시 쓴 것.
- 衛分(문가·대낮): 목 감싸 쥠(咽痛) + 기침 입김 + 움츠림(微惡寒) + 땀 없음 · 혀 邊尖紅·薄白苔 · 소반의 인동꽃+개나리(銀翹散)
- 氣分(한가운데): 옷 열어젖힘 + 사발 물 들이켬 + 튀는 땀 + 붉은 몸 · 혀 紅·黃苔 · 석고 덩어리+쌀알(白虎湯) — s13u01 陽明經證과 같은 꼴(같은 白虎湯證, 의도한 겹침)
- 營分(초승달 창 아래): 부릅뜬 눈·헛소리·허공 잡는 손 · 혀 絳·少苔 · 가슴에 막 돋는 옅은 반점(斑疹隱隱)
- 血分(가장 깊은 구석): 빽빽한 자색 반점 + 코피 + 피 묻은 천 + 뒤로 젖혀진 경련 · 혀 深絳紫 · 무소뿔+地黃 조각(犀角地黃湯)

## 과정

## 잔결 (출력만)
- 營分 앞에만 처방 소품이 없음(淸營湯 빈칸 — 낱장도 반점 행에 治法을 얹어 둔 설계).
- 사전 舌 갈림(「혀가 보이면 心」)과 충돌 — 넷이 나란히 혀를 내밀어 舌診으로 읽혔지만 사전만 따르면 넷 다 心. 사전 舌 항목에 「여럿이 나란히 혀를 내밀고 색·이끼가 다르면 舌診」 갈림을 더할지 다음에 판단.
