# Sketchy 회상 훈련 페이지 recall.html (2026-10-25)

통합판 작업(§9)이 끝나 「사용자 회상 측정」으로 넘어가기 위한 도구. 허브(index.html)가 「보면서 외우기」라면 이 페이지는 「보고 떠올려 스스로 채점하기」다.

## 무엇
- `src/build_recall.py` → `recall.html`. library.json의 A·B 트랙 35판(475행)과 `blind6_사전요약.md`를 내장, 그림은 `images/*.webp` 링크(허브와 같음). 라이브: `https://baeggman.github.io/sketchy/recall.html`(푸시 뒤). 허브 헤더에 「회상 훈련 →」 링크.
- 흐름: 판 고르기 → 그림만 보고 자유 회상(한 줄에 하나) → 「답 보고 채점」 → 행마다 ○(떠올림)·△(반)·✗ → 저장 → 다음 판. 첫 행은 틀, ⚠는 함정 행, 「왜?」로 다리.
- 1단계(사전 없이) / 2단계(사전 읽고) 토글 — 판독 blind와 같은 두 단계. 「사전」 버튼으로 사전 요약(검색 가능)을 열어 읽고 2단계.
- 결과: 판·단계·○△✗·점수·시간을 localStorage(`sketchy_recall_v1`)에 저장, 「결과」에서 1·2단계 평균과 목록, JSON 내보내기/클립보드 복사.

## 측정 절차(사용자)
1. 1단계로 판 몇 개(처음엔 5~10판)를 사전 없이 돌리고 저장.
2. 「사전」을 한 번 읽고 2단계로 같은 판을 다시(또는 다른 판을).
3. 「결과 → JSON 내보내기」 파일을 Claude에게 보내면 판·행별로 어디서 막히는지(AI 판독과 사람 회상의 차이) 분석해 다음 손질·사전 다듬기 순서를 정한다.

## 주의
- 자가 채점이라 「○」는 핵심어(장부·글자·수)까지 떠올랐을 때만.
- 저장은 그 브라우저에만 남는다 — 기기를 바꾸면 결과가 따로 쌓인다(내보내기로 합친다).
- 도해(D) 23판은 답이 그림에 있어 뺐다.
