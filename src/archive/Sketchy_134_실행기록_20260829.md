## 요약 — ④는 전제가 틀렸다

진단서는 「장면 15·16의 19칸이 증상만 그리고 이름은 안 그린다 — **판을 다시 설계해야 한다**」고 적었다.
실행하려고 원문과 대조했더니 **그 칸들은 이름을 이미 지고 있었다.**

1차 판독이 물은 것은 「이름을 가리키는 **소품**이 있는가」였다. 그런데 이 칸들은 이름을
**동작·상태**로 나른다 — 김이 아래로 새면 下, 사방으로 터지면 亂, 매듭으로 뭉치면 結,
물이 얼어 막히면 凝滯, 살갗이 갈라지면 燥. **질문이 그 층을 통째로 배제했다.**

질문을 「㉠소품 / ㉡동작·상태 둘 다」로 고쳐 12칸을 다시 판독시켰다. **같은 그림, 같은 판독자, 다른 질문.**

## ① 문서만으로 되는 것 — 완료

**숨은 자산 18칸, 22행에 다리를 적어 올렸다.** 그림은 이미 나르고 있는데 장부에 없던 것들이다.
- `s09p01` 초록 갑옷 장군 = **將軍之官 직역** · 새싹 = 生
- `s09p04` 흰 도포 재상 = **相傅之官의 相** · 낫 = 金(쇠붙이)
- `s12p09` 달팽이 = 遲 · 토끼 = 數 · 뜸 = 浮 · 눌러야 = 沈 — **네 글자 전부 직역인데 장부에 없었다**
- `s14p10` 찜통=熟 · 볶기=炒 · 꿀 발라 굽기=炙 · 달군 돌=煅 — 수 다리이면서 글자 다리 넷을 겸한다
- `s15p01` **앞장선 바람 = 長(우두머리)의 자리 다리**
- `s16p09` **오행왕국 세 인물을 그대로 데려와 臟을 진다** — 세트 변별 자산
- `s16p07` 김의 양·방향이 虛·滯·逆·陷 네 글자를 그대로
- `s20p01`·`s20p02` 각각 네 글자 전부 직역

판독자가 적은 것 중 **셋은 오독이라 빼고 갔다** — s09p02 「대나무=竹」(웃자란 벼의 오독) · s10p05 「샘=泉」(이 칸에 샘 없음) · s16p01 「엿=飴」(따뜻한 국물의 오독).

**§5 공용 상징 사전에 세 줄 등재**
- **붉은 시내 / 붉은 냇물** — A 서사에서는 **丹溪**(인명), B·C 무대에서는 **血**. 갈림축은 트랙(규칙 51의 연장)
- **새 = 乙** — 『鍼灸甲乙經』. **갑옷(甲)과 짝으로만.** 다리는 why에 진작 있었는데 §5에 없어서 판독자가 갑옷과 새를 무관한 둘로 봤다
- **얼굴색이 여럿일 때** — 둘이 같은 황토색이면 s12p06(善色↔惡色), 셋이 서로 다른 노랑이면 s12p03(黃色主病)

**정정 — 진단서가 과장한 것 둘.** 왕관과 빗자루는 충돌이 아니었다.
§5에 「왕관=王씨」와 「곤룡포는 心 전용」이 이미 따로 서 있고, 판독자가 곤룡포와 함께 있는 왕관을 君으로 읽은 것은 **사전대로 작동한 것**이다. 빗자루는 규칙 81에 이미 적힌 실패 모드다.

## ③ 이름의 절반이 빈 자리 — s18p11 재설계 완료

八會穴 넷 중 **온전히 그려진 이름이 하나도 없었다.** 章門은 門만, 中脘은 脘만, 膻中은 둘 다 무기호, 膈兪는 膈만.
판독자가 87장 중 최악으로 꼽은 판이다.

**원인은 자리를 버린 것이었다.** 八會穴은 「어디에 있는 혈인가」가 곧 이름의 절반인데,
종전 판은 네 소품을 **방 네 귀퉁이**에 늘어놓아 자리를 통째로 버렸다.

**→ 네 자리를 몸 위에 붙였다.** 앞모습·뒷모습 두 사람으로 갈라 그렸다.

| 혈 | 그림 | 이름을 지는 것 |
|---|---|---|
| 氣會 **膻中** | 양 젖 사이 한복판의 얕은 사발, 위로 오르는 김 | 자리(膻=가슴) + **中(둘 사이의 한복판)** |
| 腑會 **中脘** | 배 한복판 항아리 셋 세로, **가운데 것에만** 대롱 | **中(셋 중 가운데)** + 脘(항아리) |
| 臟會 **章門** | 옆구리 갈비 끝에 얹힌 문간, 안에 보퉁이 다섯 | 자리(季脇 = 難經 원문 이름) + 門 |
| 血會 **膈兪** | 뒷모습 등, 기둥 넷 사이 팽팽한 흰 천 + 엉킨 붉은 실 | 膈(가로막) + 자리(등) |

**글자 사전 확장 (84 → 87자)**
- **中** — 「같은 것 셋 중 가운데」에 **「둘 사이의 한복판」을 더했다.** 이 한 줄로 종전 0/6이던 中이 두 자리에서 풀린다
- **兪 · 膻** — 포기. 兪는 자원(통나무배)이 s18p12 베틀북(杼)과 충돌하고, 背兪穴 계열이 공유하는 접미사라 **변별값이 0**이다
- **倉** — 신설(곡식 가마니가 쌓인 곳간 안). 갈림축은 「앞에 누가 있는가」 — 장부 든 사람이 서면 倉公, 없으면 藏. ⚠ `s02p01[1]`에 곳간이 **아직 없다**
