## 2. 두 칸 공통 무대 문법 — **한 문장**

> **「앓는 사람 곁에 오색 그릇이 놓여 있는데, 들려 있는 그릇의 색이 補하는 오행이고 바닥에 내려놓은 그릇의 색이 瀉하는 오행이다.」**

**이 문장이 감사 지적 넷을 한꺼번에 없앱니다:**

| | 어떻게 |
|---|---|
| **규칙 59**(동작 금지) | 補·瀉가 **동작이 아니라 정지 상태**다 — 들려 있음 ↔ 놓여 있음. 「끌어안아 일으킨다」 같은 서술이 사라진다 |
| **규칙 37**(그릇은 가구다) | **그릇이 아니라 색이 사실을 진다.** 그릇은 색을 담는 자리일 뿐이고, 다섯 그릇의 모양은 전부 같다 |
| **규칙 73**(오행 어휘를 둘로 안 만든다) | 오행을 **재질이 아니라 색**으로 짓는다 — 靑赤黃白黑은 CANON §3이 이미 「五色이 곧 사실」로 못박은 어휘다 |
| **규칙 51**(불의 극성 충돌) | **불을 안 쓴다.** 火는 **붉은 그릇**이다. s16p03의 「세 배 커진 불 = 陽勝則熱」과 부딪히지 않는다 |

**그릇 다섯의 규격 (통제 변인 · 규칙 67):** 모양·크기·재질이 전부 같고 **색만 다르다**. 靑(木) 赤(火) 黃(土) 白(金) 黑(水).

## 3. s18p09 — 正格 ↔ 勝格 : 들린 그릇과 놓인 그릇

**좌우를 가르는 것 = 가시덩굴 크기** (RULES §5 등재 「어두운 가시덩굴 뭉치 — **크기가 盛衰**」 · s16p01 딥링크. 正格은 虛證, 勝格은 實證이므로 같은 축이다)

> ⚠ **좌우 배치는 s16p01을 따른다.** 라이브러리 실측 — `s16p01[0]` 「**왼쪽** 사람 가슴 높이의 검은 가시덩굴 = 邪氣盛則實」 / `s16p01[3]` 「**오른쪽** 사람 손바닥만 한 시든 가시덩굴 = 精氣奪則虛」.
> **등재된 기호의 기존 배치가 원문 순서보다 우선한다** — 판독자는 s16p01을 본 상태에서 이 칸을 읽는다.
> (초안은 「왼쪽 = 正格」으로 원문 순서를 따랐다가 뒤집었다. 그대로 두면 같은 가시덩굴이 두 칸에서 좌우가 반대가 된다 — 규칙 67 위반)

| | **왼쪽 — 가시덩굴이 크다(實)** | **오른쪽 — 가시덩굴이 작고 시들었다(虛)** |
|---|---|---|
| | **勝格** | **正格** |
| 들린 그릇 | **官의 색**(剋我) | **母의 색**(生我) |
| 놓인 그릇 | **子의 색**(我生) | **官의 색**(剋我) |

**왜 이 배치가 사실인가** — 難經 六十九難 「虛則補其母 · 實則瀉其子」. 虛한 쪽(오른쪽)이 어미를 들고, 實한 쪽(왼쪽)이 자식을 내려놓는다. 그림의 좌우가 곧 그 문장이다.

**세 자리는 그림 안에 근거가 있다** (s09p06 五行 배치도 딥링크):
- **母(生我)는 위** · **子(我生)는 아래** — 相生은 위에서 아래로 흐른다
- **官(剋我)은 맞은편** — 相剋은 가로질러 간다

**한 겹 더 — 이 칸의 값어치:**
> **官의 색 그릇이 왼쪽(勝格)에서는 들려 있고 오른쪽(正格)에서는 놓여 있다.**
> 이것이 **「正格의 瀉 = 勝格의 補」**다. 코드 검산 **12/12 일치**. 한 칸을 외우면 반대 칸이 딸려 온다.
> **두 칸(s18p09·s18p10)이 같은 장치를 쓴다** — 한쪽에서 들린 것이 다른 쪽에서 놓인다. 통제 변인이 하나로 묶인다.

**소품:** 앓는 사람 2 · 그릇 4 · 가시덩굴 2 = **인물 2 · 소품 6** (RULES §1 통과)
**인물당 겹:** ① 虛↔實 ② 補의 자리 ③ 瀉의 자리 ④ 官 그릇의 뒤집힘 ⑤ 母는 위·子는 아래 = **5겹**

## 4. s18p10 — 寒格 ↔ 熱格 : 같은 검은 그릇

**좌우를 가르는 것 = 불꽃 ↔ 눈송이** (RULES §5 **등재 기호 그대로**. v1이 「불꽃 ↔ 물」이라 잘못 인용했고, §5는 「**寒은 눈송이가 진다 — 얼음 덩이로 쓰지 않는다**」까지 못박고 있다)

> ⚠ **좌우 배치도 라이브러리를 따른다.** 실측 — `s16p03[0]` 「**왼쪽**: 세 배로 커진 **불** = 陽勝則熱」 / `s16p03[3]` 「**오른쪽**: 세 배로 커진 얼음 = 陰勝則寒」. `s16p05[0]` 「**왼쪽**: 밀려 나가는 작은 **불씨**」 / `s16p05[3]` 「**오른쪽**: 밀려 나가는 **눈송이**」.
> **두 칸 모두 왼쪽이 熱이다.** 그러므로 熱格이 왼쪽이다. (초안은 반대로 잡았다가 뒤집었다)

| | **왼쪽 — 불꽃(熱證)** | **오른쪽 — 눈송이(寒證)** |
|---|---|---|
| | **熱格** | **寒格** |
| 들린 그릇 | **검은 그릇**(補水) | **붉은 그릇**(補火) |
| 놓인 그릇 | **놓인 자리가 비어 있다** | **검은 그릇**(瀉水) |

**이 칸이 지는 사실 넷:**
1. **寒格 = 補火 · 瀉水** — 12경 전부 같다. 예외 0
2. **熱格 = 補水** — 12경 전부 같다
3. **같은 검은 그릇이 오른쪽에서 놓이고 왼쪽에서 들린다** → **「熱格의 補 = 寒格의 瀉」** (코드 12/12)
4. **왼쪽의 빈 자리** → **「熱格의 瀉에는 규칙이 없다」** — 土 9경 · 火 3경이라 무대가 못 진다. **빈 자리가 그 사실이다**

> ⚠ **v1은 여기서 「물을 붓고 불을 끈다」고 썼다.** 그러면 熱格 = 瀉火가 되어 **12경 중 9경에서 틀린 것을 가르친다.**
> 라이브러리 `s18d07`이 이미 「肺 熱格 瀉 태백·태연(**土**)」로 옳게 적어 놨는데 설계서만 한 발 더 나갔다. **규칙 77 위반이었다.**

**소품:** 앓는 사람 2 · 그릇 3 · 불꽃 1 · 눈송이 1 = **인물 2 · 소품 5** (통과)
**인물당 겹:** ① 寒↔熱 ② 補火 ③ 瀉水 ④ 熱格 補水 ⑤ 검은 그릇의 뒤집힘 ⑥ 빈 자리 = **6겹**

**흡수한 것 (v1의 s18p30):**
> 「心 = 腎 · 小腸 = 膀胱은 **寒格에서만** 같다」 — 그림에 글자가 금지돼 「~에서만」을 못 넣으므로 **칸을 만들지 않는다.**
> 이 칸의 why에 적고, 도해 `s18d07`이 표로 진다. 칸으로 만들면 **48칸 중 6칸을 새로 틀리게 만든다.**

## 5. 오수혈 칸은 舍岩에서 분리한다 (감사 4·10)

v1의 s18p27(오수혈 다섯 물자리)은 **확정 칸목록의 「五輸穴 1칸」과 같은 자리**이고, 소품 15개라 RULES §1의 「12개 이상 반드시 실패」에 걸린다.

**그 칸으로 옮기면서 축도 바꾼다:**
> ~~「陽經은 陰經보다 두 칸 밀려 있다」~~ (세어야 읽힌다 · 방향에 따라 2 또는 3)
> → **「자리마다 陽의 물건이 陰의 물건을 剋한다」** — 井 金剋木 · 滎 水剋火 · 兪 木剋土 · 經 火剋金 · 合 土剋水. **5/5 성립하고, 한 자리만 봐도 읽힌다.**

그리고 그 칸에서도 오행은 **재질이 아니라 색**이다(§2와 같은 어휘).
⚠ 물길·냇물 계열은 쓰지 않는다 — RULES §5에 「사지를 세로로 지나는 물줄기 = 經脈」과 「손목 위 냇물 = 맥상」이 이미 등재돼 있고, 兪(개울)가 정확히 손목 자리다.

## 6. 무대가 못 지는 것 — 명시한다 (감사 11)

v1은 「혈 이름을 외울 필요가 없다」고 적어 이 구멍을 가렸다. **「肺正格은?」에 답하려면 여섯 단계가 필요하다:**

```
① 肺 = 金        ② 母 = 土        ③ 土의 자리 = 兪
④ 肺經의 兪 = 太淵   ⑤ 빌려올 경 = 脾   ⑥ 脾經의 兪 = 太白
```

| 단계 | 어디가 지나 |
|---|---|
| ①②③ | **무대 s18p09** ✔ |
| ⑤ | **「그 오행의 本經」 규칙 — 正勝 48짝 100% 성립.** s18p09의 why에 적는다 ✔ |
| **④⑥** | **어느 무대 칸도 안 진다.** 오수혈 60개 **이름**은 그림에 글자가 금지돼 못 넣는다 → **도해 `s18d03` + 소리 다리 카드** |
| **熱格 瀉 24자리** | **규칙이 없어 무대가 못 진다**(土 9 / 火 3) → 표·암기송이 계속 진다 |
| **寒熱 16짝 예외** | 〃 → 도해 `s18d07` |

> **이 세 구멍을 메우지 않으면 두 칸을 완벽히 외워도 「肺正格은?」에 답이 안 나옵니다.**
> 규칙 78의 짝은 성립한다 — 도해 s18d06·d07이 대조표를 지고, 이 두 칸이 **규칙**을 진다. 다만 **혈 이름은 어느 쪽도 못 진다**는 것이 남는 사실이다.
