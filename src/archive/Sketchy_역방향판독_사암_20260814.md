# 역방향 판독 — s18p09 舍岩 正格 ↔ 勝格 (2026-08-14)

## 판정 — **불통과. 치명 1건.** 다만 **핵심 관문은 통과했다**

| | 물었다 | 답 | 판정 |
|---|---|---|---|
| ⑤ | 같은 색 그릇이 한쪽에서 차고 다른 쪽에서 엎어지는가 | 「**빨간색 그릇** — **한눈에 보입니다**」 | **통과** ★ |
| ④ | 오른쪽 사람은 무엇을 채우고 무엇을 덜어 내나 | 「노란색을 채우고 · 빨간색을 덜어 냅니다 · 회색은 아무것도 아닙니다」 | **3/3 정확** |
| ④ | 왼쪽 사람은 | 「**노란색과 빨간색을 채워 넣고** · 회색을 덜어 냅니다」 | **불통과 — 補가 둘로 읽혔다** |
| ⑦ | 두 사람이 같은 사람인가 | 「얼굴·옷·모자·자세 모두 다른 데가 없습니다」 | 통과 (규칙 67) |
| ⑥ | 가시덩굴 큰 쪽의 뜻을 알겠는가 | 「**모르겠다.** 크기 차이는 눈에 띄게 납니다」 | **설계대로** |
| ⑧ | 여섯 그릇이 같은 그릇으로 보이나 | 「회색 그릇은 노란/빨간 그릇과 **모양과 크기가 달라 보입니다**」 | 불통과 (규칙 67) |
| ⑧ | 높은 그릇이 누구 것인지 헷갈리나 | 「명확히 배치되어 헷갈리지 않습니다」 | 통과 |
| ⑧ | 가운데 가구가 두 절반을 묶는가 | 「**두 선반이 원래 하나로 연결된 것처럼 보일 수 있습니다**」 | 불통과 (경미) |

**★ ⑤가 통과했다는 것이 이 판의 소득이다.** 「正格의 瀉 = 勝格의 補」 — 이 칸의 값어치 전부가 여기 있고, 판독자는 그것을 **한눈에** 읽었다.

---

## 1. 치명 — **빈 그릇이 「가득 참」으로 읽힌다**

판독자는 물음 3에서 여섯 그릇을 이렇게 읽었다:

| | 설계한 것 | 읽힌 것 |
|---|---|---|
| 왼쪽 · 높은 곳 · 노랑 | **비어 있고 똑바로 놓임** | **가득 참** ❌ |
| 왼쪽 · 옆 · 빨강 | 가득 참 | 가득 참 ✔ |
| 왼쪽 · 바닥 · 검정 | 엎어져 쏟아짐 | 엎어져 쏟아짐 ✔ |
| 오른쪽 · 높은 곳 · 노랑 | 가득 참 | 가득 참 ✔ |
| 오른쪽 · 옆 · 빨강 | 엎어져 쏟아짐 | 엎어져 쏟아짐 ✔ |
| 오른쪽 · 바닥 · 검정 | 비어 있고 똑바로 놓임 | 비어 있고 똑바로 놓임 ✔ |

**여섯 중 다섯이 맞고, 딱 하나 — 노란 빈 그릇만 틀렸다.** 그리고 그 하나가 물음 4의 답을 무너뜨렸다.

**화소로는 그림이 맞게 그려져 있다.** 그릇 한가운데를 세로로 훑은 값:

```
왼쪽 노란 그릇 (비어 있어야 함)      오른쪽 노란 그릇 (차 있어야 함)
 y 98  (234,218, 88)  진한 노랑        y102  (229,221,173)  연한 크림  ← 국물
 y102  (217,196, 71)  진한 노랑        y106  (218,214,167)  연한 크림
 y106  (216,197, 68)  진한 노랑        y110  (223,218,176)  연한 크림
 y118+ (240,225,100)  그릇 몸통        y118+ (235,205, 81)  그릇 몸통
```

**즉 그림은 옳고 눈이 못 가른다.** 노란 그릇 안쪽의 노란 그늘과 노란 그릇에 담긴 국물이 **같은 노란 덩어리**로 보인다.
붉은 그릇에서는 이 일이 안 일어난다 — 국물(243,230,199)과 그릇(180,65,45)의 대비가 크기 때문이다.
검은 그릇에서도 안 일어난다 — 엎어져 쏟아진 자국이 따로 있기 때문이다.

> **「비어 있음」은 그릇의 상태로 못 짓는다.** 그릇 색과 담긴 것의 색이 가까우면 빈 것과 찬 것이 안 갈린다.

## 2. 그리고 더 큰 것 — **답이 이미 라이브러리에 적혀 있었다** (규칙 77)

판독 결과를 고치려고 「빈 그릇 대신 무엇을 쓸까」를 정하기 **전에** 전수 검색을 돌렸다. 그러자 이렇게 나왔다:

```
s16p01[5]   오른쪽 사람 옆 그릇에 부어지는 따뜻한 국물   →  虛者補之
s16p01[2]   왼쪽 사람 옆의 짚 빗자루                  →  實者瀉之
s01p01      세간 내던지기 (아래 빗자루)               →  張從正 攻下派 · 邪去則正安
s15p10[0]   산더미 같은 빈 그릇                       →  過飽(너무 많이 먹음)
s15p10[1]   뒤집힌 빈 그릇                           →  過飢(못 먹음)
s09p03      나무 국자가 꽂힌 꿀단지                    →  甘(五味)
```

### ① 補는 발명이 아니었다 — **딥링크였다**

「그릇에 국물이 차 있다 = 補」는 **s16p01[5]가 이미 지고 있다.** v2 설계서는 s16p01을 **가시덩굴에만** 딥링크로 걸었고 그릇에는 안 걸었다.
**같은 칸이 이 무대의 두 어휘를 다 주고 있었는데 절반만 보고 있었다.**

### ② 瀉의 전담 기호는 **짚 빗자루**다 — 그런데 내 프롬프트가 그것을 **금지하고 있었다**

`s18p09_사암_정격승격.txt` 55~58행:

```
FORBIDDEN — none of these may appear:
...
No brooms, no brushes, no farm tools, no weapons.
```

**등재된 瀉 기호를 내 손으로 막아 놓고, 그 자리에 「엎어진 그릇」이라는 둘째 기호를 발명했다.**
규칙 73(충돌은 뜻의 개수로 센다)으로 세면 **「瀉」라는 하나의 뜻에 기호가 둘**이 된 것이다 — 어휘 분열이다.
그리고 「엎어진 그릇」은 이미 셋이 물고 있다:

| 칸 | 엎어진 것 | 뜻 |
|---|---|---|
| s13p04[3] | 엎어진 요강 | 自利益甚(묽은 설사) |
| s14p09[3] | 엎어진 그릇들 | 默默不欲飮食(먹기 싫어함) |
| s16p10[0] | 엎어져 바닥까지 마른 물독 | 內燥 — 津傷化燥 |

내가 넷째를 얹으려 했다.

### ③ 시정안으로 세우려던 「빈 그릇 = 아무것도 아님」도 **못 쓴다**

s15p10이 **빈 그릇**(過飽)과 **뒤집힌 빈 그릇**(過飢)을 둘 다 물고 있다. 규칙 51 위반이다.
→ **아무 일도 없는 자리에는 그릇을 아예 안 놓는다.** 「빈 그릇」을 그리지 않으면 s15p10을 밟지 않는다.
   그릇의 **부재**는 소품이 아니므로 어느 전담 기호도 건드리지 않는다.

### ④ 국자도 못 쓴다

s09p03이 「나무 국자 = 甘(五味)」로 물고 있다. 補를 「국자로 붓는 그림」으로 지으면 五味 어휘를 밟는다.

## 3. 그래서 v3 문법은 이렇게 된다

> **「앓는 사람 곁에 오색 그릇이 놓여 있다. 따뜻한 국물이 찰랑찰랑 찬 그릇의 색이 補하는 오행이고, 짚 빗자루가 기대어 선 그릇의 색이 瀉하는 오행이다. 아무 일도 없는 자리에는 그릇이 없다.」**

| | 어떻게 |
|---|---|
| **판독 실패** | **「비어 있음」이 사라진다.** 그릇은 사람당 **둘**뿐이고 둘 다 무슨 일이 일어나 있다. 빈 그릇을 볼 일이 없다 |
| **규칙 77** | 두 기호 모두 **s16p01의 것을 그대로 쓴다** — 발명 0 |
| **규칙 51** | s15p10(빈 그릇)·s09p03(국자)·s13p04·s14p09·s16p10(엎어진 그릇)을 **하나도 안 밟는다** |
| **규칙 73** | 「瀉」의 기호가 **하나**로 돌아온다 (빗자루) |
| **규칙 37** | 그릇은 여전히 가구다 — 사실은 **담긴 국물**과 **곁의 빗자루**가 나른다 |
| **RULES §1** | 소품 = 그릇 4 · 빗자루 2 · 가시덩굴 2 = **8** (4~8 통과. v3 이전은 10~12였다) |
| **규칙 67** | 그릇 셋의 모양·크기 통일 지시를 다시 못 박는다 (판독자가 「회색 그릇만 모양·크기가 다르다」고 지적) |

## 4. 경미 지적 둘 — v4에서 함께 고친다

1. **검정을 「회색」으로 읽었다.** CANON §3 五色의 黑이어야 한다 → 프롬프트에 「옻칠한 새까만 검정, 회색이 아니다」를 넣는다.
2. **가운데 선반이 분리선에 닿아 두 절반이 한 장면으로 보일 여지.** 3차 수정에서 지시했으나 렌더러가 안 들었다.
   → **편집으로 자리를 옮기는 것은 안 된다**(이번 판이 두 번째 증거다). v4는 **처음부터 다시 그리면서** 구도를 분수로 못 박는다.

## 5. 이 판에서 얻은 것 — 규칙 후보

> **「비어 있음」은 그림에서 상태가 아니다. 아무 일도 없음은 소품의 부재로 짓는다.**

규칙 77대로 먼저 찾아봤다. RULES·CANON·색인·라이브러리 어디에도 없다.
다만 **단독 규칙으로 세우지 않는다** — 실질은 **규칙 51의 사례**(빈 그릇은 s15p10 전담)이고, 판독 실패의 원인은 **규칙 67의 사례**(그릇 색과 내용물 색이 통제되지 않았다)다.
규칙 78·80이 「이미 있는 것을 다시 만듦」으로 기각된 전례가 있으므로(색인 머리말), **RULES §5 공용 상징 사전에 어휘 세 줄을 보태는 것으로 갈음한다:**

```
| 그릇에 찬 따뜻한 국물 | 補 — s16p01[5] 虛者補之 · s18p09 |
| 짚 빗자루            | 瀉 — s16p01[2] 實者瀉之 · s01p01 攻下派 · s18p09 |
| 빈 그릇 / 뒤집힌 빈 그릇 | 過飽 / 過飢 — s15p10 전담. 다른 뜻으로 쓰지 않는다 |
```
