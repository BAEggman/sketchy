# 역방향 판독 5차 — s18p10 v1 (寒格 ↔ 熱格) · 2026-08-15

**판독자 둘, 서로 모르는 채 같은 열두 물음.** 둘 다 설계서·RULES·라이브러리를 못 보게 하고 **그림 한 장만** 줬다.
(규칙 47 — 만든 사람이 판정하지 않는다. 이번엔 내가 그림을 보고 「완벽하다」고 판정했는데, 판독 둘이 같은 자리 셋을 무너뜨렸다.)

## 0. 판정 — **관문 통과, 그러나 사실 넷 중 둘이 틀리게 읽힌다. 한 판 더 그린다.**

| 설계서 §5가 확인하라고 한 것 | 판독 A | 판독 B | |
|---|---|---|---|
| **글자가 없는가** (조항 ⑥) | 없음 | 없음 | **통과 — 8판 만에** |
| ① 삼베 천 = 「정해진 것이 없다」 | 「숨겼다·발효 중·김 막음」 셋 사이 | 「**답은 불인데 가린 것**」 | **실패** |
| ② 눈송이 그릇의 뒤집힘이 한눈에 | 그릇 동일성 100%, **뒤집힘은 못 읽음** | 〃 | **절반** |
| ③ 큰 눈송이와 그릇 눈송이 혼동 | 「좀 헷갈린다」 | 「상당히 헷갈린다」 | **실패** |
| ④ 「모자란 것을 채운다」 | 「아래 칸이 규칙을 **깨뜨린다**」 | 「아래 칸에서 규칙이 **무너진다**」 | **실패** |

## 1. 이 판이 실제로 진 사실

| 사실 | 코드 | 판독 |
|---|---|---|
| 熱格 = 補水 | 12/12 | **둘 다 읽었다** — 「더운 사람 옆에 눈 = 식혀 준다」 |
| 寒格 = 補火 | 12/12 | **둘 다 읽었다** — 「추운 사람 옆에 숯불 = 없는 온기를 대준다」 |
| 寒格 = 瀉水 | 12/12 | **못 읽었다 — 오히려 규칙을 깨는 것으로 읽혔다** |
| 熱格의 瀉는 규칙이 없다 | 土9·火3 | **못 읽었다 — 「답은 있는데 가렸다」로 정반대** |

> **안 읽히는 것보다 나쁘다.** 판독 둘이 똑같이 「위 칸끼리는 깔끔한데 **아래 칸에서 규칙이 무너진다**」고 적었다.
> 학습자에게 이 그림은 **혼란을 준다.** 그래서 v1은 정본이 못 된다.

## 2. 뿌리 진단 하나 — **s18p09의 문법을 절반만 물려받았다**

s18p09를 다시 펴 보면 補와 瀉가 **두 가지**로 갈려 있다:

```
補 = 김이 오르는 국물이 찰랑찰랑 찬 그릇      ← 내용물 있음
瀉 = 텅 빈 그릇 + 곁에 기대어 선 짚 빗자루    ← 내용물 없음 + 빗자루
```

**갈림표가 둘이다** — ① 내용물의 유무 ② 빗자루의 유무. 그래서 하나를 놓쳐도 다른 하나가 받친다.

s18p10 v1은 瀉 자리 그릇에 **오행(水)을 담느라 눈을 가득 채웠다.** 갈림표 ①이 사라지고 **빗자루 하나만** 남았다.
판독 둘이 그 빗자루를 놓쳤고, 그 순간 **瀉가 補로 뒤집혔다.**

> **규칙 81 등재:** 「가득 참 = 補」와 「가득 참 + 빗자루 = 瀉」를 한 그림에 같이 두면, 빗자루를 놓치는 순간 瀉가 補로 읽힌다.

## 3. 판독이 준 나머지 두 진단 (규칙 48 — 진단만 받는다)

**빗자루가 짝이 없다.** 둘이 거의 같은 문장을 썼다.
> A: 「그림 전체가 철저한 좌우 대칭인데 **빗자루만 한쪽에 짝 없이 있다** … 나중에 끼워 넣은 기호처럼 보인다」
> B: 「**왼쪽에는 대응하는 빗자루가 없다.** 이 비대칭 때문에 살림살이가 아니라 뜻을 담으려 끼워 넣은 물건처럼 보인다」
→ **규칙 82 등재.**

**큰 눈송이와 그릇 속 눈송이가 같은 도형이다.**
> B: 「그릇 속 눈 더미에 그려진 작은 눈송이 무늬가 **큰 눈송이와 같은 도형**이라 … 공중의 눈송이를 그릇에 퍼 담아 놓은 것처럼 보인다」
불꽃 쪽은 안 섞였다 — 큰 것은 매끈한 불꽃 기호, 그릇 속은 **검은 숯덩이**로 사물이 달랐다.
→ **규칙 83 등재.**

## 5. v2 설계 — 세 진단을 한 번에 푼다

```
공통  s18p09와 같은 화풍 · 두 사람 거울 쌍 · 선반 둘 동일 · 그릇 넷 동일한 무채색 질그릇
      그릇 속 눈은 육각 무늬 없이 **맑고 흰 눈 무더기**로만 그린다              (규칙 83)

왼쪽  곁에 큰 주황 불꽃 = 熱證 = 熱格
      위 선반   흰 눈이 그릇 위로 수북이 솟은 그릇                      ← 補水
      아래 선반 거친 삼베 천으로 덮인 그릇 + 곁에 기대어 선 짚 빗자루    ← 쓸어내는 자리인데 무엇을 쓸어내는지 정해진 것이 없다

오른쪽 곁에 큰 흰 눈송이 = 寒證 = 寒格
      위 선반   붉은 숯불이 그득한 그릇                                ← 補火
      아래 선반 텅 빈 그릇 + 곁에 기대어 선 짚 빗자루
                + 그릇 바깥 선반 위에 쓸려 나온 흰 눈 한 무더기          ← 瀉水
```

**값어치가 오히려 세진다:**
> **같은 흰 눈이 왼쪽 위에서는 그릇 안에 수북하고, 오른쪽 아래에서는 그릇 밖으로 쓸려 나와 있다.**
> = 「**熱格의 補 = 寒格의 瀉**」 — 코드 12/12

| 진단 | v2가 어떻게 푸는가 |
|---|---|
| 규칙 81 (瀉가 補로 뒤집힘) | **瀉 그릇을 비운다.** 갈림표가 다시 둘이 된다 — 내용물 유무 + 빗자루 유무. s18p09 문법 그대로 |
| 규칙 82 (빗자루 짝 없음) | **빗자루를 좌우 아래 선반에 둘 다** 놓는다. 대칭 회복 |
| 규칙 83 (도형 섞임) | 그릇 속 눈에서 **육각 무늬를 뺀다** |
| 삼베 천이 「가린 답」으로 읽힘 | 천 그릇에도 **빗자루가 붙어** 「이 자리도 쓸어내는 자리」가 확정된다. 옆 칸엔 쓸려 나온 것이 보이는데 **이 칸만 안 보인다** → 「정해진 것이 없다」로 유도 |

**소품 세기 (RULES §1 「4~8개」):** 큰 불꽃 1 · 큰 눈송이 1 · 빗자루 2 · 삼베 천 1 · 그릇 속 눈 1 · 숯불 1 · 쓸려 나온 눈 1 = **8**. 상한 정확히. (선반·그릇은 가구 — 규칙 37)

## 6. v2 판독이 확인할 것

```
① 「빈 그릇 + 빗자루 + 밖에 쓸려 나온 눈」이 **덜어 낸 것**으로 읽히는가 — 담는 것으로 뒤집히지 않는가 (규칙 59)
② 왼쪽 위의 눈과 오른쪽 아래의 눈이 **같은 것**으로 읽히는가                      ← 관문
③ 「천으로 덮인 그릇 + 빗자루」가 「쓸어내긴 하는데 무엇인지 모른다」로 읽히는가
④ 「모자란 것을 채우고 넘치는 것을 덜어 낸다」가 네 칸 전체에서 어긋나지 않는가   ← v1이 무너진 자리
```
