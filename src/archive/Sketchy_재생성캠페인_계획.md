# 화풍 전면 재생성 캠페인 — 계획서

*착수: 2026-08-03 · 근거: `audit_full_20260803.md` 208건 전수 감사 · 기준: `CANON.md`*

## 왜 하는가

세트 6 이전 프롬프트에 **복장 고정문이 없었다.** 그 결과 마을 사람이 서양인·현대복으로 나오고,
오장 5캐릭터 정본이 무너졌다. 특히 **s09p02 火 임금이 담비 모피·십자 보관의 유럽 왕**인데,
이 칸이 s11p02·s14p01 등 모든 心 배속 칸의 기준이라 위쪽부터 오염돼 있다.

부분 편집으로는 안 된다. 인물의 인종·복장을 바꾸는 것은 §3-13 「장면이 통째로 바뀌면 폐기」에 걸린다.

## 규모

**재생성 대상 44칸 / 81칸.** 나머지 37칸은 유지.

## ⚠ 선결 과제 — 스펙이 51칸 분량 없다

`panels/` 에 남아 있는 스펙은 `set04`(s13)·`set06`(s15)·`set07`(s16) **30칸뿐**이다.
나머지 51칸은 프롬프트가 사라졌다. → **`library.json` 의 `prop` 서술에서 장면 서술을 복원**해야 한다.
rows 가 소품을 전부 한국어로 적어 두었으므로 복원은 가능하지만, 차수마다 이 작업이 선행된다.

## 차수마다 지키는 절차

1. `library.json` rows 에서 장면 서술 복원 → 스펙 JSON 으로 저장 (다시는 잃지 않도록)
2. 프롬프트 조립: `CANON.md` §6 순서 그대로. **§2 또는 §3 블록을 반드시 포함**
3. 생성 → **제3자 판정**(규칙 47). 만든 사람이 통과 판정을 내리지 않는다
4. 개수가 사실인 칸은 **픽셀 계수로 검산**(규칙 46)
5. 정사각형 확인(규칙 49)
6. 통과분만 `confirm.py` 재등록 → 차수 끝에 `build_local.py` + `make_map.py` → 배포

## 캠페인 중 배포 정책

**차수가 끝날 때마다 배포한다.** 44칸을 다 그린 뒤 한 번에 올리지 않는다.
중간에 세션이 끊겨도 그때까지의 개선이 라이브에 남아야 한다.

배포 시 주의: index.html 이 재생성으로 10.23 MB까지 늘어 상한을 넘겼다. `build_local.py` 를 **1100px · q70**으로 낮춰 맞췄다.
1차 배포 시점 8.84 MB. 재생성으로 크기가 늘면 `b64(maxw, q)` 를 더 낮추거나 이미지 외부 파일화를 검토한다.
