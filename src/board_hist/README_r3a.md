## 1차 → 2차 고친 것 (구역 재편집, 같은 채팅 §5-3)
- 陳無擇: 대나무 장대 → 竹 → 朱(朱肱)로 오독 · 개수도 2로 셈 → **마디 없는 나무 장대 셋을 위에서 한 매듭으로 묶은 세발 받침**.
- 許叔微: 누더기 옷이 陳(묵음)·傷으로 오독 → **옷을 깨끗하게** + **허수아비(許 소리 다리)**.
- 本草衍義: 빈 격자판이 本草綱目(綱=줄·目=칸)으로 오독 → **길게 풀려 강으로 늘어진 두루마리(衍)** 추가.
