## 1단계 — 생판 (사전 정보 없음, 그림만)

### ① 소품 전수와 나르는 사실
- **갈래진 강물(여울)**: 좌상에서 들어온 큰 물이 7~8갈래로 갈라져 화면 전체를 가로지름. 한 줄기만 짙은 남색(깊은 본류, 약 3배 폭)이고 나머지는 연한 하늘색 지류. → 물(水)·수도(水道)·수제(水製)·강(河·川) 축.
- **뇌우**: 먹구름 3덩이 + 번개 3줄 + 빗줄기(상단 중앙). → 雷(뇌공?)·雨·降.
- **화로의 남자**(두건·콧수염·목걸이 패): 돌절구 위에 주걱으로 약재를 볶고 김이 오름, 흙화로에 불. → 火製(炒·煅·炙)·蒸(김).
- **산호 1그루 + 조개·고둥 약 14개**: 짙은 강가 모래톱, 화로 바로 아래. → 介類(牡蠣·石決明 등)·海産·煅淬.
- **소년과 광주리**(우상): 냇가에 쪼그려 앉아 뿌리·잎을 고르고, 물에는 잎 조각·갈색 절편·흰 종이 2장이 떠내려감. → 採集·淨選·漂洗(水製).
- **흰 종이 2장**(물 위): 浮(뜨는 것)·書? 
- **주막풍 건물 + 용수(술 거르는 대바구니) + 흰 깃발**(좌하): 술집. → 酒·酒製.
- **상 위 흰 잔 10개**(5+5 두 무리): 酒杯 10. → 酒製 / 10이란 수.
- **밥상 5그릇**(국 1·죽 1·나물 3): 食·五味·輔料(薑·醋·鹽·蜜?).
- **한복 여인 + 약초 2단**(쑥·艾 모양) + 어린 나무 1그루: 植物藥·鮮藥·艾.
- **빈 입간판 1 + 빈 깃발 2**(좌상·좌중): 글자가 지워진 명패 → 지명·서명 자리(판독 불가).
- **마을·산·논(좌상 원경)**: 産地·土地.
- **연잎 1장**(우하 물 위), 돌멩이 몇 개(소년 쪽): 浮·石.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽음)

### ① 사전 어휘로 다시 읽은 소품
- 화로 불꽃 = **熱·陽**, 돌그릇 위로 솟는 흰 김 = **氣**(곧게 솟음 = 上). 돌그릇은 배 모양이면 **藥**(약연) → 「藥 + 陽(불) → 氣」 = 煎藥·炮製 또는 陽化氣.
- 붉은 산호 = **血**(붉은 것). 산호가 짙은 강 속에 앉음 → 血이 물(津) 안에 = 津血同源 / 脈 속의 血.
- 맑은 냇물·빗줄기 = **津**(맑은 물). 다만 비는 「길 위의 부슬비」이기도 해 **外濕**과 갈림 — 환자·병표지가 없어 外濕 쪽은 약함.
- 쏟아지는 비·가라앉은 조개 = **下**, 솟는 김 = **上** → 升降浮沉의 上下 축이 사전 글자로 성립.
- 포개진 먹구름 3 = **久**(같은 것 셋이 포개짐) 후보 — 久雨·久居濕地? 확신 낮음.
- 옆으로 뻗은 흰 깃발 3 = **風** 후보(옆으로 날림). 물 위 갈색 마른 잎 조각 = **燥** 후보.
- 국이 찰랑한 큰 사발 = **補**, 맑은 물 잔 10 = **淸**(맑고 찬 물 그릇) ×10 — 또는 그냥 酒杯·十劑.
- 기와지붕 건물 = **寺** 후보(의학사 기관?) — 그러나 다른 기관 글자(太·典藥·濟·惠)가 없어 고립.
- 매달린 대바구니 = **收**(끈으로 조인 자루)로 읽힐 수도 있으나 용수(술 거르개)가 더 자연스러움.
- 장부 의인화 인물(갑옷·곤룡포·밀짚모자·흰 도포·잠수복) 전무 → 臟腑 중심 생리판은 아님. 세 사람은 기호 없는 「일꾼」 = 採集·炮製·生藥.

### ② 표제어 후보(수정)
- 1순위 **本草 總論 — 藥性(四氣·五味·升降浮沉)·採集·炮製** — 30%. 약연(藥)+불(熱)+김(上·升), 비·조개(下·沉), 물 위 종이(浮), 잎약재(升浮)·조개·돌(沉降), 술잔 10(酒製 升提 / 十劑), 밥상 5(五味·輔料), 냇가 소년(採集·水製). 사전의 上·下·氣·熱·藥가 모두 이 축에 붙음.
- 2순위 **氣血津液 相互關係(陽化氣·津血同源·水穀化生)** — 25%. 사전이 직접 등재한 氣(김)·血(산호)·津(맑은 물)·陽(불)이 한 화면에 모두 있고, 밥상·술잔 = 水穀, 비 = 汗(血汗同源). 다만 脾·肺·腎 인물이 없어 「代謝」판은 아니고, 사람들이 약초를 다루는 점이 어색.
- 3순위 津·液 구분(연한 지류=津, 짙은 본류+조개=液→骨節) 10% / 六淫 지역성(風·濕·燥·火 + 빈 지명판) 10% / 寺·惠 의학사 기관 5%.
- 판정: 사전 어휘로 「氣·血·津」 삼자가 또렷해져 2순위가 크게 올랐으나, 인물·약초·약연 때문에 1순위는 여전히 本草 축. 두 축 차이는 작다.
