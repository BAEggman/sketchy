# 604 판독 기록

## 1단계 — 생판 (사전 없이)

**① 소품 전수와 나르는 사실**
- 설경 무대 전체(눈 덮인 땅·눈길·마른 풀 포기 3~4곳) = 겨울 → 寒(冬之主氣).
- 잎 없는 나무 1그루 + 고드름 = 寒則凝(얼어붙음).
- 눈 덮인 초가집 1채(처마 고드름) = 바깥 무대, 집 밖에 선 사람 → 外感.
- 사람 1인: 어깨 움츠리고 허리 굽힘·두 주먹 꽉 쥠 = 收引(筋脈拘急·氣機收斂); 얼굴 창백·푸르스름 = 寒傷陽氣(面色蒼白); 이 악물고 찡그림 = 疼痛; 어깨·소매에 눈 묻음 = 한사 침습.
- 헝겊 덧댄 자리 3곳(소매 1·바지 2) = 낡은 옷(가난·오래됨?) 또는 3대 성질 개수.
- 허리에서 나와 땅을 따라 강으로 뻗는 관 1줄, 이음새에 박힌 얼음덩이 1개 = 寒性凝滯 → 氣血 불통 → 不通則痛. 얼음 곁 맑은 물 웅덩이 = 막혀서 새어 나온 흐름(또는 분비물 淸稀).
- 얼어붙은 파란 강 = 寒則水凝.
- 우하단 금색 별 1개 = 중요도 표지(소품 아님으로 봄).

**② 표제어**
- 1순위 **寒邪(한사)의 성질과 치병 특징 — 陰邪傷陽·凝滯·收引** (75%)
- 2순위 **寒證(외감 한증·傷寒)** (35%)

**③ 뜻 모를 것·어색·잘림**
- 관이 사람 허리에서 돋아 나오는 연결점이 어색(경맥인지 장기인지 불명). 맑은 물 웅덩이의 뜻(淸稀 분비물? 단순 누수?)이 불확실. 별의 역할 불명. 관 오른쪽 끝·집 오른쪽·나무 꼭대기가 프레임에 잘림.

## 2단계 — 계통 (사전 어휘로 재독)

**① 소품 재판독**
- 사전 규칙 「불이 화면에 없고 무대가 겨울이면 얼음은 陰도 寒도 아니라 凝滯」가 그대로 적중: 불·해 없음 + 설경 → 관 속 얼음덩이 1개 = **凝滯**(寒性凝滯), 얼어붙은 강도 같은 글자.
- 관 = 通(안과 밖이 한 덩어리로 이어짐: 몸↔강) → 얼음이 그 가운데를 막음 = 不通. 단, 痛의 전담 기호(쇠못)는 없어 「痛」은 표정으로만 암시.
- 사람 옷에 묻은 눈송이 = **外寒**(갈림 조건: 눈송이) · 집(內) 밖·문 밖에 선 사람 = 外·表 → 寒邪가 겉(表)을 침범.
- 큰 병표지(떠 있는 눈송이)가 없음 → 병증 판이 아니라 病因(六淫) 판.
- 옆으로 눕는 것 없음 → 風 아님(風寒과 갈림). 진창·안개 없음 → 濕 아님.
- 손발 끝 검푸름 없음 → 厥 아님. 해·불이 줄어든 것 없음 → 陽虛 표기 아님.
- 웅크림·주먹 = 收引(단, 전담 기호 삼베 자루 없음 — 자연 묘사). 창백한 얼굴색 = 望色 영역(傷陽의 결과).
- 맑은 물 웅덩이 = 津(맑은 물) → 寒邪 분비물 淸稀 쪽으로 읽힘. 덧댄 헝겊 3곳은 「닳은 것 = 久」로 읽을 여지(久寒)가 있으나 포개진 셋이 아니어서 미확정.

**② 표제어**
- 1순위 **寒邪의 성질과 치병 특징(寒為陰邪·易傷陽氣 / 寒性凝滯 / 寒性收引)** (85%) — 얼음=凝滯 규칙·눈송이=外寒·문 밖=表가 한 축으로 모임.
- 2순위 **寒性凝滯 → 疼痛(不通則痛) 단독 판** (30%) — 관+얼음이 화면 하단 중앙에 가장 크게 놓임.
- 3순위 **外寒(傷寒·寒邪傷表)** (20%).

**③ 잔결**
- 痛의 전담 쇠못·收의 삼베 자루가 없어 收引·疼痛은 자연 묘사에 의존. 허리에서 돋는 관의 연결점, 맑은 물 웅덩이(津? 누수?), 헝겊 3곳(久? 의상?), 금색 별의 뜻이 불명. 관 오른쪽 끝·집·나무 꼭대기 프레임 잘림.
