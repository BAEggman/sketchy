# blind10 / 605 판독

## 1단계 — 생판 (사전 없이 그림만)

### ① 소품 전수
- 중앙 나무 기둥 1개 → 화면을 좌/우 두 무대로 가름(대비 구조).
- 좌상단 불꽃 1개(사람 머리 높이, 머리의 약 1.5배) → 熱(열증 또는 열 환경).
- 우상단 눈송이 1개(6각, 오른쪽 프레임에 잘림) → 寒.
- 같은 얼굴·같은 자세의 병약한 남자 2명(눈 밑 그늘, 처진 입) → 같은 환자 1인의 두 상황.
- 좌 남자: 눈(얼음) 수북한 사발 1개를 배 앞에 안음 → 열에 찬 것 = 熱者寒之.
- 우 남자: 벌겋게 달아오른 숯 사발 1개(숯 10여 덩이, 가슴에 주황 빛이 비침) → 한에 뜨거운 것 = 寒者熱之.
- 좌 탁자: 천으로 입을 꽁꽁 봉한 가득 찬 항아리 1개 → 實/塞(막힘).
- 우 탁자: 속이 빈 항아리 1개 + 흰 눈·거품이 탁자에서 바닥으로 쏟아짐 → 虛/通(새어나감·설사).
- 탁자 2개(좌·우 각 1).

### ② 표제어
- 1순위: **정치법(正治法·逆治) — 寒者熱之·熱者寒之·實則瀉之·虛則補之** (50%) : 좌=熱+實, 우=寒+虛, 각 사이드에 두 조목씩 배치된 구조로 읽힘.
- 2순위: **한열진가(眞寒假熱·眞熱假寒)** (30%) : 바깥 표식(불·눈송이)이 假象, 환자가 몸에 안은 것이 眞(좌: 眞寒假熱, 우: 眞熱假寒·가슴 홍조), 봉한 항아리=口渴不欲飮, 빈 항아리+쏟아짐=喜冷飮·熱結旁流.
- 3순위: 반치법(塞因塞用·通因通用) 10% — 항아리/쏟아짐은 맞으나 사발 대응이 반대라 탈락.

### ③ 뜻 모를 소품·어색한 것·잘림
- 우측 눈송이가 프레임에 반쯤 잘림.
- 흰 더미가 빈 항아리에서 나온 것인지 따로 놓인 것인지 불분명(항아리는 똑바로 서 있음).
- 두 남자가 왜 '환자' 얼굴인지(의사 없음) — 치법 판이면 치료자 부재가 어색.

## 2단계 — 계통 (blind6 사전 적용)

### ① 소품 재독
- 「병표지」규칙: 사람 곁에 크게 뜬 불꽃·눈송이 = 그 사람의 병증 → 좌 남자 = **熱證** 환자, 우 남자 = **寒證** 환자(눈송이=外寒 갈림이라 外寒 표지로 그린 점은 느슨함). 환경·치법이 아니라 병증임이 확정됨.
- 「補-b」: 그릇에 가득 담긴 것 = 그 사람에게 채워 주는 것, 담긴 것이 무엇을 채우나를 정함.
  - 좌: 얼음 가득 사발 — 「陰 갈림」: 살아 있는 불(좌상단 불꽃)과 맞대어 놓인 얼음이므로 **陰** → 熱證 환자에게 **補陰**.
  - 우: 불(숯불) 가득 사발 — 陽 = 불 → 寒證 환자에게 **補陽**.
- 좌 탁자 봉한 항아리 = 「實 = 팽팽하게 찬 것」(또는 입을 조인 收) → 陽光을 가두어 **制**.
- 우 탁자 빈 항아리 + 밖으로 쏟아진 흰 것 = 「瀉-b = 텅 빈 그릇 + 흘러넘친 내용물 = 덜어낸 것」, 흘러넘친 것이 흰 눈·얼음(불 곁이므로 陰·寒) → 陰翳를 **消**(덜어냄).
- 가운데 기둥 = 두 무대 가름(中 갈림: 몸·가구 위가 아니므로 글자 아님).
- 淸(맑고 찬 물 한 그릇)·溫(김 나는 천)을 쓰지 않고 굳이 얼음·불을 썼으므로, 「熱者寒之·寒者熱之」보다 「陰·陽을 채운다」는 뜻으로 읽힘.

### ② 표제어
- 1순위: **보기부족(補其不足) — 壯水之主 以制陽光(陽病治陰·補陰) / 益火之源 以消陰翳(陰病治陽·補陽)** (55%) : 좌=熱證+陰 가득 補+가둠(制), 우=寒證+陽 가득 補+쏟아내 덜어냄(消)으로 네 소품이 두 구절에 그대로 대응.
- 2순위: **조정음양(調整陰陽) 치칙 전체 — 損其有餘·補其不足** (25%) : 좌 實(팽팽한 항아리)=陽盛實熱 損其有餘, 우 瀉=陰盛 덜어냄까지 포함한 상위 개념.
- 3순위: 정치법 熱者寒之·寒者熱之 (15%) — 1단계 답. 사전 어휘로는 淸·溫 기호를 안 썼으므로 후순위로 내림.

### ③ 잔결
- 우측 눈송이 프레임 잘림(6각 중 절반).
- 寒證 표지가 눈송이(外寒)인데 뜻은 陽虛裏寒이라면 성에·서리가 맞음 — 느슨한 표지.
- 좌 항아리를 實로 볼지 收(조인 자루)로 볼지 미확정 — 어느 쪽이든 「가둠·制」로 수렴.
- 虛(삼분의 일 축소) 기호가 없어 陰虛·陽虛의 「虛」가 그림에 직접 안 보임 — 補-b 사발로만 추정.
