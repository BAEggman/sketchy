# blind10 / 606 판독 기록

## 1단계 — 생판 (그림만)

**① 소품 전수와 사실**
- 사방이 막힌 빈 상자 방(벽 3면·천장·회색 바닥) — 폐쇄된 무대, 안쪽(內·裏) 암시.
- 천장의 검회색 젖은 얼룩 1 + 거기서 곧게 떨어지는 물줄기 1가닥 — 비 새는 집, 濕이 위에서 아래로(趨下) 흐름.
- 기름종이 우산 1자루 — 소년이 오른손으로 받쳐 물줄기를 막음(실내에서 우산). 물이 우산에 닿아 튀는 점 2개.
- 노란 밀짚모자 1 + 황토색 한복 — 黃=土=脾 색.
- 소년(젊은 승려풍) 가부좌·맨발·움직임 없음 — 身重·困倦.
- 입가에서 흘러내리는 맑은 침 1줄 — 涎(脾之液).
- 깔고 앉은 붉은 방석 1 + 옆에 포개진 붉은 방석 3(모두 터져 회색 속이 비어져 나옴) — 합계 4. 눅눅해 상한 침구 → 居處潮濕.

**② 표제어**
- 1순위 **濕邪의 성질과 치병특징**(重濁=모자+우산으로 머리 무겁고 얼룩 탁함, 粘滯=끈적한 침·새는 물, 趨下=위에서 아래로 떨어짐·바닥 방석, 陰邪·阻遏氣機=닫힌 방에 갇힘) — 55%
- 2순위 **脾의 장상(脾惡濕·在液爲涎·色黃)** — 25%
- 3순위 痰飮(실내에 물 고임·침) — 10%

**③ 뜻 모를 것·어색함·잘림**
- 터진 방석 3개의 회색 속이 곰팡이인지 솜인지 불명. 방석 1+3의 개수 의미 불명.
- 밀짚모자와 우산을 겹쳐 쓴 이중 머리가림이 과잉 — 「頭重如裹」인지 별도 기호인지 모호.
- 상자 방이 무대 관례인지 內/裏 기호인지 불명. 프레임 잘림 없음.

## 2단계 — 계통 (사전요약 어휘로 재독)

**① 소품 재판독**
- 노란 밀짚모자 농부 = **脾** → 소년은 脾의 의인화(모자·황토옷 일치). 1단계의 「頭重」 읽기 폐기.
- 천장에서 떨어지는 물줄기 = 濕(부슬비 꼴, 길·발밑이 아니라 위에서 내림 → 外濕). 발밑 진창 없음 → 內濕 아님.
- 우산 = 「해로운 것과 사람 사이에 세워 막은 가리개」 = **惡** → 脾 + 惡 + 濕 = **脾惡濕(喜燥惡濕)**.
- 입(口=어두운 구멍)에서 흐르는 맑은 물줄기 = 津이 口로 나옴 = **在液爲涎·開竅於口**.
- 포개진 같은 방석 셋 = **久**(갈림: 닳아 못 쓰는 무더기는 傷이 아니라 久). 그 속의 회백색 끈적 덩이 = **痰** → 오래 묵은 痰이 脾에서 생김 = **脾爲生痰之源**(濕聚成痰).
- 상자 방 = 담 안쪽(內) 무대 — 脾가 몸 안(裏)의 臟임을 받침 정도.

**② 표제어**
- 1순위 **脾의 생리특성 — 脾惡濕(喜燥惡濕)·在液爲涎·脾爲生痰之源** — 65%
- 2순위 **痰飮의 형성(脾失健運→濕聚成痰, 脾爲生痰之源)** — 20%
- 3순위 濕邪 성질(1단계 1순위) — 10%로 하향. 1단계보다 이 어휘로 훨씬 잘 풀림(농부=脾, 가리개=惡가 확정 기호).

**③ 잔결**
- 회색 속이 痰(끈적 회백색 덩이)인지 곰팡이(居處潮濕)인지 완전 확정은 어려움.
- 깔고 앉은 방석 1개(온전)와 포개진 3개(터짐)의 대비가 별도 사실인지 불명(肌=도톰한 살덩이 → 主肌肉 가능성).
- 상자 방의 內/裏 의미 불명. 잘림 없음. 수 오류 없음.
