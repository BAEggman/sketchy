# blind10 / 607 판독

## [1단계 — 생판] (사전 미열람)

### ① 소품 전수 · 나르는 사실
- **큰 바람 소용돌이**(좌상 1개, 머리 둘레 1개, 허리·팔 둘레 1개 = 소용돌이 3곳): 바람(風)이 무대 전체를 지배 — 주인공 사기(邪氣)는 風.
- **벗겨져 날아간 삿갓**(머리 위로 솟음): 風性輕揚·易襲陽位(上部·頭面). 「傷於風者 上先受之」.
- **날리는 갈잎** 6~7장 + **분홍 꽃송이** 4송이·꽃잎 약 8장: 바람에 실려 떠다님 = 浮·輕揚, 봄꽃=風은 春의 主氣. 갈잎(가을)과 봄꽃이 섞임 = 數變(자주 바뀜)의 암시로도 읽힘.
- **좌측 날씨 아이콘 5개**: 눈결정(寒)·해(暑/熱)·비구름(濕)·갈라진 땅(燥)·불꽃(火) — 風을 뺀 나머지 五淫이 모두 바람 흐름선 위에 얹혀 있음 = **風爲百病之長**, 寒·濕·燥·熱이 風에 依附하여 침입(風寒·風濕·風熱·風燥).
- **사람 몸의 # 긁은 자국 5곳**(좌어깨·좌상완·좌전완·우어깨·좌무릎)과 **얼굴·양 전완의 붉은 반점**: 風盛則癢(가려움·風疹), 자리가 여기저기 흩어짐 = **善行而數變**(遊走性, 行痺).
- **펄럭이는 소매·옷자락, 흔들리는 나무·먼지**: 風性主動(動搖·眩暈·抽搐 類).
- **앙상한 나무**(좌), 초가·마을·길: 무대 배경. 나무는 잎이 다 떨어져 바람이 「흔든다」를 보강.
- **찡그린 눈·구부린 몸**: 두통·惡風 정도.

### ② 표제어
- 1순위 **풍사(風邪)의 성질과 치병특징 — 風爲百病之長·輕揚開泄·善行數變·主動** (85%)
- 2순위 **육음(六淫) 총론(풍사를 선두로 한 六氣 개관)** (10%) / 行痺(風痺) (5%)

### ③ 뜻 모를 소품·어색·잘림
- 붉은 점이 「발진(風疹)」인지 「땀(開泄)」인지 모호 — 색이 붉어 발진으로 읽었으나 開泄 표지가 따로 없음.
- 갈잎과 봄꽃의 계절 혼재가 의도(數變)인지 장식인지 불명.
- 날씨 아이콘 중 해(暑)와 불(火)이 둘 다 있어 「六淫 중 5개」로 세어야 하는지(暑·火 구분) 모호.
- 잘림: 우측 초가 지붕, 좌측 나무 가지가 프레임에 걸림 — 의미 손실 없음.

## [2단계 — 계통] (blind6_사전요약 열람 후 재판독)

### ① 소품 전수 · 사전 어휘로 다시 읽음
- **風** = 옆으로 눕고 흘러 날리는 것: 갈잎 6~7장·꽃잎이 전부 **옆으로** 흐름 → 風 확정(燥의 「곧게 떨어지는 잎」 조건과 갈림). 소용돌이 3곳(좌상 큰 것 1, 머리 둘레 1, 허리 둘레 1) — 좌상 소용돌이가 나머지의 약 2배 = **大**의 어림 → 風이 가장 큰 사기 = 百病之長.
- **上** = 머리 꼭대기로 곧게 솟음: 삿갓이 머리 위로 곧게 떠오름(머리에 씌워져 있지 않으므로 太는 아님) → 風性輕揚·易襲陽位·「上先受之」.
- **外** = 담 바깥: 무대가 마을 담 밖의 들길 → 外感·外風.
- 좌측 아이콘 열: **寒**(눈송이=外寒)·**陽/暑**(해; 사전엔 暑 없음, 陽 또는 暑로 읽음)·**外濕**(부슬비 구름, 길 위)·**燥**(갈라진 땅)·**熱**(불꽃) — 다섯이 모두 風의 흐름선 위에 얹혀 사람 곁에 크게 떠 있음(**병표지**) → 寒濕燥熱이 風에 依附하여 함께 침입 = **風爲百病之長**. 해를 陽으로 읽으면 「風爲陽邪」 보강.
- **散** = 사방으로 흩어져 날리는 것: 꽃잎·먼지가 사방으로 흩어짐 → 風性開泄(腠理 열림)의 암시.
- 몸의 **# 긁은 자국 5곳**(좌어깨·좌상완·좌전완·우어깨·좌무릎): 쇠못(痛)이 하나도 없으므로 痛이 아니라 **癢** → 風盛則癢. 자리가 5곳으로 흩어짐 → **善行而數變**(遊走性).
- 얼굴·양 전완의 **붉은 점**: 瘀 갈림(살갗 위 얼룩은 그 자리의 색) → 피부의 붉음 = 風疹·紅斑. 맑은 물방울이 아니므로 **汗은 아님**.
- 펄럭이는 소매·옷자락, 흔들리는 앙상한 나무 → 風性主動.
- 봄꽃(4송이) + 갈잎 혼재 → 數變(계절성 변화) 보강.

### ② 표제어
- 1순위 **풍사(風邪)의 성질과 치병특징 — 風爲百病之長(寒濕燥熱 皆依附於風)·輕揚開泄 易襲陽位·善行數變·主動** (88%)
- 2순위 **육음(六淫)의 공통 치병특징(外感性·季節性·相兼性)** (8%) — 外·계절혼재·六氣 동반이 받치지만 몸의 증상이 전부 風 전용이라 하위. 行痺는 痛(쇠못) 부재로 탈락(2%).

### ③ 잔결
- 해(暑)와 불(熱)이 둘 다 있어 「風 외 5淫」인지 「해=陽邪 표지」인지 사전으로도 못 가름.
- 붉은 점을 疹으로 읽었으나, 開泄(汗出)을 의도했다면 사전의 汗(맑은 물방울)과 어긋남 — 작화 쪽 불일치 가능.
- 큰 소용돌이 「大」 어림은 2배 남짓으로 경계선.
- 잘림: 우측 초가·좌측 나무(의미 손실 없음).
