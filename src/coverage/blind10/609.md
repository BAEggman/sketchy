# blind10 / 609 판독

## 1단계 — 생판 (사전 없이)

### ① 소품 전수와 나르는 사실
- 밤하늘(별 ≈12개) + 초승달 1 (우상단) → 夜·月 = 陰의 무대.
- 왼쪽 병풍 4폭: 먹구름 + 번개 1줄기 → 雷·電(陽·動·火의 상), 혹은 驚.
- 오른쪽 병풍 4폭: 버드나무 1그루 + 풀밭, 밝은 하늘 → 柳·風·木(柔·陰 혹은 春).
- 왼쪽 소년(삭발, 청록 저고리, 회색 바지, 맨발) : 오른발을 들어 발차기(궤적선 4줄) → 足·動·陽 쪽.
- 오른쪽 소녀(쪽머리, 황토 저고리, 붉은 치마가 바람에 펄럭임, 흰 버선+짚신) : 오른손 장풍, 바람 궤적 → 手·風 쪽. 치마가 날림 = 바람의 방향(소녀→소년).
- 두 아이 모두 성난 표정, 주먹 쥠 → 상쟁(對立·爭).
- 중앙 공중의 소용돌이 1: 청록 바탕에 붉은 심 → 두 기운이 맞붙어 섞이는 지점(交·互藏). 크기는 아이 머리의 약 1.5배.
- 바닥 중앙의 둥근 물그릇/거울 1 (아이 발 길이의 약 2배) → 水, 혹은 거울=서로 비춤(反·互根).
- 발자국 2: 소년 쪽 청록 1, 소녀 쪽 붉은 1 (모두 오른발, 오른쪽을 향함) → 좌우·청적의 대비.
- 무대 전체가 구름 위 → 天上의 무대, 추상 개념임을 표시.

### ② 표제어
- 1순위: **陰陽의 對立制約 (음양 기본관계: 대립·호근·소장·전화)** — 남/여, 좌/우, 뇌/풍, 족/수, 청/적이 짝지어 맞서고 가운데서 균형을 이룸. 거울=互根, 소용돌이=交感·互藏. 확신도 35%.
- 2순위: **五行 相乘·相侮(肝木 乘 脾土 / 土 反侮 木)** — 청록 소년(木)이 발로 치고(乘), 황색 소녀(土)가 되받아 밀어냄(侮), 거울=反(反克). 확신도 15%.
- 그 밖: 心腎不交·不寐(밤·번개=火·물그릇=水) 10%, 「風氣通於肝 雷氣通於心」 10%.

### ③ 뜻 모를 소품·어색한 것·잘림
- 발자국 둘이 왜 다 오른발이며 색이 다른지(청/적) 뜻 미상. 소녀는 신을 신었는데 맨발 자국이 찍힘.
- 병풍 배경이 교차된 느낌: 바람을 쓰는 소녀 뒤에 버들, 발차기 소년 뒤에 번개 — 어느 쪽이 陰·陽인지 단서가 엇갈림.
- 소용돌이의 붉은 심이 무엇(火? 血? 心?)인지 불명.
- 프레임 잘림 없음. 소품 수는 셀 만한 것이 적음(병풍 4폭×2, 발자국 2, 궤적 4줄).

## 2단계 — 계통 (사전 어휘로 재독)

사전의 「八卦 = 4폭+4폭 병풍 무대(마주 본 두 폭이 한 쌍) = 八卦 마주봄」이 이 판의 틀을 바로 연다. 좌 4폭·우 4폭 병풍이 마주 섰으니 八卦 판이고, 마주 본 한 쌍은 좌 병풍의 먹구름·번개 = 雷(震), 우 병풍의 버드나무·풀 = 風·木(巽)이다. 소녀의 치마·바람 궤적이 「옆으로 눕고 흘러 날림」 = 사전의 風 글자와 정확히 맞는다.

### ① 소품 재독
- 좌 병풍 雷 → 震. 소년 = 震為長男, 맨발로 발차기 = 震為足, 발차기 궤적 4줄 = 先天數 震4(추정). 청록 저고리 = 震為蒼筤竹·玄黃.
- 우 병풍 風·柳 → 巽. 소녀 = 巽為長女, 바람에 치마가 들려 허벅지가 드러남 = 巽為股, 바람 궤적 ≈5줄 = 先天數 巽5(추정). 손으로 밀어 소용돌이를 흩음 = 「風以散之」, 소년의 발차기로 소용돌이가 움직임 = 「雷以動之」.
- 두 아이가 성내어 맞붙음 = 說卦傳 「雷風相薄」(薄=迫, 서로 부딪쳐 밀어냄).
- 가운데 소용돌이(청록+붉은 심) = 두 기운이 맞닿는 지점. 구름 위 무대 = 추상 무대.
- 밤·달·별 = 무대 분위기(八卦 배경), 특별 글자 없음.

### ② 표제어
- 1순위: **八卦 先天 마주봄 — 雷風相薄 (震↔巽: 震=雷·足·長男, 巽=風·股·長女)** 70%.
- 2순위: **說卦傳 八卦 身體·家族 배속(震為足·巽為股, 長男·長女)** 15% — 같은 판의 하위 사실.
- 1단계의 陰陽對立·相乘相侮는 폐기(5%). 사전 어휘로 훨씬 잘 풀린다.

### ③ 잔결
- 바닥의 둥근 물그릇/거울: 사전에 없음. 「마주봄(서로 비춤)」 표시이거나 水(坎)로 읽힐 여지 — 뜻 미확정.
- 발자국 2(청록·붉음, 둘 다 오른발): 청록은 震為足의 발자국으로 읽히나 소녀 쪽 붉은 발자국은 미상(巽為進退? 혹은 血?).
- 번개 1줄기가 雷(震)인지 電(離)인지 — 說卦에서 電은 離이나 4폭 먹구름과 함께이면 雷로 본다.
- 궤적 수(4·5)는 先天數와 맞추려는 추정이며, 소녀 쪽 바람 줄 수는 정확히 세지 못함.
