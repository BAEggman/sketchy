# blind10 / 611 판독

## 1단계 — 생판 (사전 없이)

### ① 소품 전수
- **무대**: 빈 상자형 방(세 벽+바닥), 다른 배경 소품 없음.
- **중앙 인물**: 검은 잠수복·후드·물안경·오리발을 신은 잠수부 1명. 양팔을 좌우로 벌려 두 그릇을 든다 → 좌우 대비(對擧) 구도. 검은색·물 → 水·腎·寒 계열 암시.
- **왼손(화면 좌) 얼음 사발**: 사발 전체에 서리·고드름(얼음 = 寒·陰). 안에 붉은 둥근 정제(가운데 홈) **6개**(3+3) + 갈색 뿌리 1개(곧은 몸통, 끝이 두 갈래 — 인삼 꼴, 또는 지황·지모 류 뿌리약).
- **오른손(화면 우) 접시**: 접시 위에 불꽃 1 + 김(연기) 소용돌이 3가닥(熱·溫). 그 안에 붉은 둥근 정제 **6개**(3+3) + 끈으로 묶은 막대 다발(끝이 말림 → 계피/육계 또는 계지, 5~6개) + 회색 돌덩이 1(광물 또는 부자 덩이).
- 양쪽 정제가 같은 모양·같은 수(6=6)이므로 "같은 6알에 무엇을 더하느냐/어느 온도냐"가 축. 오른쪽은 6+2 = **8**.

### ② 표제어
- 1순위: **六味地黃丸 ↔ 八味地黃丸(腎氣丸)** — 잠수부=腎(水), 얼음 6알+지황 뿌리=六味(滋腎陰, 壯水之主), 불 6알+육계+부자=八味(溫腎陽, 益火之源). (45%)
- 2순위: **약성 寒熱(四氣) / 反佐·服藥法(寒藥熱服·熱藥冷服)** — 같은 약을 찬 쪽·뜨거운 쪽으로 나눠 든 대비. (20%)

### ③ 뜻 모를 것·어색·잘림
- 왼쪽 뿌리가 인삼 모양인데 六味라면 지황이어야 해 불일치. 회색 돌이 부자(뿌리)라면 돌로 그린 것이 어색(석고·광물로 읽히면 寒藥이 熱 쪽에 있어 모순).
- 오리발 끝이 프레임 하단에 닿아 살짝 잘림. 우하단 작은 별표(워터마크)는 소품 아님.

## 2단계 — 계통 (blind6 사전 어휘로 재독)

### ① 소품 → 글자
- 검은 잠수복·후드·고글 잠수부 = **腎** (사전 확정 항목). 1단계 추정(水=腎)과 일치.
- 왼손 얼음 사발: 얼음 = **陰** — 갈림 조건 「살아 있는 불과 맞대어 놓였을 때만」 충족(오른손에 산 불꽃). 안의 검붉은 뿌리 = **地黃**(사전 「검붉은 뿌리 조각」). 붉은 정제 6개 = 丸 6 → 腎+陰+地黃+6丸 = **六味地黃丸**. 그릇에 가득 담김 = 補-b → 腎陰을 채움(滋腎陰).
- 오른손 접시: 불꽃 = **熱/陽**, 그 위 서린 흰 김 3가닥 = **氣**. 정제 6개 + 묶은 계피 다발 + 회색 덩이(부자) = 6+2 = 8 → 腎+氣+丸 = **腎氣丸(八味地黃丸)**. 補-b → 腎陽(腎氣)을 채움(溫補腎陽).
- 좌우 대거: 같은 6丸에 桂·附를 더하면 八味, 빼면 六味 — 「壯水之主(얼음) / 益火之源(불)」의 짝.
- 1단계보다 사전으로 훨씬 잘 풀린다. 특히 김=氣가 腎氣丸을 글자 그대로 적어 준다.

### ② 표제어
- 1순위: **六味地黃丸 ↔ 腎氣丸(八味地黃丸)** — 腎陰虛엔 六味(壯水), 腎陽虛엔 八味(益火). (55%)
- 2순위: **腎陰虛·腎陽虛 치법 대비(滋補腎陰 / 溫補腎陽, 壯水之主·益火之源)** — 처방명보다 치법 개념이 표제일 가능성. (25%)

### ③ 잔결
- 붉은 정제: 사전상 「붉은 것=血」이라 血로 읽힐 여지가 있으나, 좌우 동수(6=6)·오른쪽 6+2=8 셈이 丸 수로 더 잘 맞아 丸으로 판정.
- 회색 덩이: 사전 「끈적한 회백색 덩이=痰」과 샐 수 있음. 모난 돌 꼴이라 부자(또는 광물)로 읽었으나 전담 기호가 없어 확정 불가.
- 地黃이 「조각」이 아니라 잔뿌리 달린 온뿌리(인삼 꼴)로 그려져 기호와 약간 어긋남. 오리발 끝 하단 잘림.
