# 612 판독 기록

## 1단계 — 생판 (사전 없이)

**① 소품 전수**
- 무대: 상자형 방, 뒷벽에 양쪽으로 활짝 연 창(2짝) + 봉에 걸린 커튼 1폭(고리 6개, 오른쪽으로 젖혀져 바람에 날림) → 바깥 바람이 안으로 들어옴(소용돌이 선 2~3가닥, 여자 얼굴 쪽으로 흐름).
- 왼쪽 남자(의자 1): 온몸(얼굴·팔·손)이 붉음, 뚱뚱함(여자 대비 몸집 약 2배), 눈 감고 사발 1개로 물을 벌컥 들이킴(입에서 물줄기), 땀방울 약 7개, 왼손에 쥘부채 1개 → 壯熱·面赤·大汗·大渴引飲·惡熱喜涼(實熱 陽盛).
- 오른쪽 여자(의자 1): 야윔, 얼굴 창백한데 양 볼만 둥글게 붉음(顴紅), 이마 땀방울 약 6개, 피곤한 눈, 두 손을 무릎 위에 손바닥 위로 펴놓음(手心), 맨발이고 발밑에서 열기 선 3가닥(足心熱) → 五心煩熱·顴紅·盜汗(陰虛 虛熱).
- 바닥 왼쪽: 얼음이 서린 젖은 천 1장(가장자리 서리·물방울) → 차가운 찜질/冷敷를 좋아함(喜冷) 또는 땀에 젖어 벗어던진 옷.

**② 표제어**
- 1순위 **實熱證 vs 虛熱證(陰虛內熱) — 熱證의 虛實 감별** (55%)
- 2순위 **陽盛則熱 · 陰虛則熱 (陰陽偏盛·偏衰 病機)** (25%)
- 3순위 白虎湯證(大熱·大汗·大渴) 대 陰虛, 또는 自汗 대 盜汗 (10%)

**③ 잔결**
- 얼음 서린 젖은 천: 冷敷인지 땀 젖은 옷인지 불확정. 창문 바람이 여자 쪽으로만 흐르는 뜻(惡風? 喜涼?) 불명. 프레임 잘림 없음.

## 2단계 — 계통 (사전 적용 후)

**① 사전 어휘로 다시 읽음**
- 實 = 팽팽하게 찬 것 → 배가 팽팽한 남자 = 實. 虛 = 줄어든 것 → 야윈 여자 = 虛. 둘이 나란한 좌우 대비가 곧 虛實 축.
- 汗 = 살갗 땀방울 → 두 사람 모두 汗(남 ≈7, 여 ≈6). 남자는 大汗, 여자는 가만히 앉아 흘리는 땀 = 盜汗 계열.
- 淸 = 맑고 찬 물 한 그릇 → 남자가 들이키는 사발 = 淸(淸熱, 喜冷飮). 부채 = 스스로 風을 일으켜 식힘 = 惡熱.
- 風 = 옆으로 눕고 흘러 날리는 것 → 창문 바람·젖혀진 커튼 = 風. 커튼이 가리개(惡)로 서 있지 않고 젖혀져 있으므로 惡風이 아니라 창을 열어 바람을 들이는 喜涼으로 읽힘(두 사람 모두 熱證).
- 心 갈림 「五心煩熱의 心은 손·발바닥」 → 여자의 펴든 손바닥 + 열기 오르는 맨발 = 五心煩熱이 이 책의 정식 기호임을 확인. 顴紅·盜汗과 합쳐 陰虛內熱.
- 陰 = 얼음 갈림: 살아 있는 불이 화면에 없으므로 서리 낀 천은 陰도 寒도 아님 → 글자가 아닌 장면 소품(冷敷·喜冷)으로 판정.
- 大 = 같은 것 둘 중 하나가 두 배 → 남자 몸집 ≈ 여자 2배가 大(大熱·大汗·大渴)로도 읽힐 여지 있으나, 虛實 대비가 더 직접적.

**② 표제어**
- 1순위 **實熱證 vs 虛熱證(陰虛內熱) — 熱證의 虛實 감별** (65%)
- 2순위 **陽盛則熱 · 陰虛則熱 (陰陽偏盛·偏衰 病機)** (20%)
- 3순위 白虎湯證(四大證) 대 陰虛證 / 自汗 대 盜汗 (10%)

**③ 잔결**
- 서리 낀 젖은 천: 사전 규칙상 陰·寒 모두 아니어서 글자 미해결(冷敷 추정). 창문 風이 여자 쪽으로 흐르는 이유는 여전히 불명. 잘림·수 오류 없음.
