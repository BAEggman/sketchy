# 613 판독

## 1단계 — 생판 (사전 없이)

① 소품 전수
- 흰 도포·세조대·검은 갓의 선비 1인(가운데, 담담한 표정) → 白(金의 색)·肺를 의인화한 인물로 추정
- 공중에 곧게 떨어지는 갈색 낙엽 8장 + 땅에 떨어진 낙엽 3장 = 11장 → 秋(가을)·肅殺. 잎 곁 짧은 세로줄 약 10개 → 가랑비인지 낙하선인지 모호
- 끈으로 묶은 볏단 약 9단(좌 5·우 4, 양끝은 프레임에 잘림) → 收穫·稻(金의 곡식). 9단이면 其數九
- 오른손의 낫 1자루 → 收(수렴·거둠)·金(쇠)
- 소반 위 접시의 붉은 고추 5개 → 辛(金의 맛)
- 거북등처럼 갈라진 마른 땅(전면) → 燥(金의 기)
- 허리의 작은 흰 주머니 1개 → 뜻 모름

② 표제어
- 1순위 **肺(金)의 五行 歸類 — 秋·燥·辛·白·稻·收** (65%)
- 2순위 **燥邪(秋燥·燥易傷肺)** (25%)
- 3순위 **四氣調神의 秋三月(容平·收斂·養收)** (10%)

③ 모호·잘림: 세로줄(비인가 낙하선인가), 갓의 의미, 허리 주머니, 좌우 끝 볏단 프레임 잘림, 볏단 수 9±1.

## 2단계 — 계통 (사전 적용)

① 소품 재독
- 흰 도포 재상 = **肺** (확정 기호)
- 갈라진 땅 + 마른 잎이 **곧게** 떨어짐(세로줄은 낙하선) = **燥** — 옆으로 날리지 않으므로 風이 아님. 물독이 없으므로 內燥가 아닌 외부 무대의 外燥(秋燥)
- 접시 위 붉은 고추 = **辛** (血이 아님)
- 볏단·낫 = 사전에 없음 → 자연독 收穫·秋·稻. 收의 등재 기호(아가리 조인 삼베 자루)와는 다르니 收 글자가 아니라 무대(가을걷이)로 읽는 게 안전
- 갓 = 「太 = 테 넓은 큰 갓」과 겹침 → 肺+太면 太陰(手太陰)이 될 수도 있으나, 재상 복식의 일부일 가능성이 커 보류
- 잎 8+3장, 볏단 ~9단, 고추 5개: 사전 수 기호(久=3·虛=⅓·大=2배)에는 해당 없음

② 표제어
- 1순위 **肺의 五行 歸類 — 秋·燥·辛(白·收·稻)** (65%): 肺 인물을 燥 무대에 세우고 辛 접시를 곁에 둔 구성은 金行 한 줄을 그대로 나른다
- 2순위 **燥邪(外燥·秋燥, 燥易傷肺)** (25%): 병표지 규칙(사람 곁의 표지=그의 병증)으로 보면 肺 주위에 떨어지는 마른 잎 = 肺가 燥를 앓는 그림. 곁의 辛은 치법(辛으로 輕宣) 또는 辛走氣의 금기로 읽힘
- 3순위 **辛入肺(五味 歸經)** (10%)

사전으로 肺·燥·辛 셋이 확정되어 1단계보다 핵심축이 선명해졌고, 세로줄의 정체(곧은 낙하=燥)가 풀렸다. 다만 볏단·낫·갓은 사전 밖이라 무대 장식인지 글자인지 남는다.

③ 잔결: 갓(太?)·허리 주머니·볏단과 낫의 글자 여부, 좌우 끝 볏단 프레임 잘림, 볏단 수 9±1.
