# blind10 / 614 판독

## 1단계 — 생판 (사전 없이 그림만)

### ① 소품 전수와 나르는 사실
- **무대**: 구름 위에 뜬 널판 무대, 배경은 별이 뜬 밤하늘 + 초승(그믐)달 1 → 밤·陰의 시간, 하늘(天)의 영역.
- **왼쪽 병풍 4폭**: 푸른 하늘·흰 구름 그림 → 天(淸陽爲天 · 雲出天氣).
- **오른쪽 병풍 4폭**: 누런 들판·구릉 그림 → 地(濁陰爲地 · 黃土).
- **왼쪽 남자 1**: 앞머리 민 상투(일본식 촌마게), 청록 도포, 두 손 맞잡고 허리 숙여 읍(揖) → 男·陽·天 쪽 인물. 일본식 머리 = 日(해)?
- **오른쪽 여자 1**: 쪽머리, 황토색 옷, 합장하고 허리 숙임, **배가 불룩(임신)** → 女·陰·地 쪽 인물, 「낳음(生·化生)」.
- 두 사람이 마주 보고 절함 → 交·相感(천지·남녀가 서로 통함).
- **바닥 둥근 거울(또는 얕은 물그릇) 1**: 두 사람 한복판 → 象(비침·應象) 또는 水.
- **발자국**: 남자 뒤 청록 발자국 2, 여자 뒤 붉은 발자국 2(발가락 조각 흩어짐) → 좌우의 「길(道路)」, 색은 氣(靑)·血(紅) 또는 水·火의 徵兆.
- 수 대비: 병풍 4폭 : 4폭(같음), 발자국 2:2(같음), 남녀 키 비슷, 여자 배 ≈ 몸통의 1.5배.

### ② 표제어
- 1순위: **陰陽의 기본개념 — 素問 陰陽應象大論 「天地者 萬物之上下也, 陰陽者 血氣之男女也, 左右者 陰陽之道路也, 水火者 陰陽之徵兆也, 陰陽者 萬物之能始也」(陰陽者 天地之道也 … 變化之父母)** — 45%
  (天地 병풍 · 남녀 · 좌우 발자국=道路 · 청/적 발자국=血氣 또는 水火 · 임신=能始·父母)
- 2순위: **陰陽交感(天地交感·萬物化生 — 「天地氤氳 萬物化醇, 男女構精 萬物化生」)** — 25%
  (마주 절함=交感, 임신=化生)

### ③ 뜻 모를 것·어색·잘림
- 거울(물그릇?)의 글자가 불확실(象인지 水인지 鏡인지). 남자의 일본식 촌마게 머리의 뜻 불명(日?). 달이 초승인지 그믐인지 불명. 발자국에 흩어진 발가락 조각의 뜻 불명. 좌우 끝 구름과 무대 아래가 프레임에 잘림. (주: 그림 Read를 원본 1회+부분 확대 3회 = 4회 하여 상한 3회를 1회 넘김.)

## 2단계 — 계통 (blind6 사전 적용)

### ① 사전 어휘로 다시 읽음
- **4폭+4폭 병풍 무대 = 八卦 무대, 마주 본 두 폭이 한 쌍** → 이 판은 八卦 중 **天(乾) ↔ 地(坤)** 한 쌍이 마주 봄 = 說卦傳 「天地定位」. 왼쪽 하늘·구름 병풍 = 乾(天), 오른쪽 들판 병풍 = 坤(地).
- 남자 = **乾道成男**, 여자 = **坤道成女**(繫辭上). 乾은 父, 坤은 母(說卦 「乾稱乎父, 坤稱乎母」) → 임신한 어머니 = **坤作成物·厚德載物**, 뱃속 = 六子(三男三女) 또는 萬物化生.
- 마주 절함 = 「剛柔相摩, 八卦相盪」·天地交感.
- 붉은 발자국 2 = **血**(붉은 것) → 女=血(陰); 청록 발자국 2 = 그에 짝맞춘 氣(陽) — 단 사전의 氣는 「흰 김」이라 어휘 밖 → 좌우의 「陰陽之道路」로 읽는 편이 안전.
- 둥근 거울 = 사전에 없음. 乾坤 사이 한복판(中)의 둥근 것 → 太極(太極→兩儀→八卦) 또는 「在天成象」의 象으로 추정.
- 밤하늘·달 = 사전의 陰(얼음·고인 물)이 아니므로 陰 글자가 아니라 「在天成象」의 천상(별·달) 배경. 해·불이 없으므로 陽 글자도 없음 → 이 판은 陰陽 글자 판이 아니라 **乾坤(天地) 판**이다.
- 사전의 왕국 다섯 인물(장군·임금·농부·재상·잠수부) 없음 → 장부 판 아님.

### ② 표제어
- 1순위: **乾坤 — 八卦의 乾(天·父·成男)과 坤(地·母·成女), 「天尊地卑 乾坤定矣 … 乾道成男 坤道成女, 乾知大始 坤作成物」(周易 繫辭上 · 說卦 天地定位) — 醫易·천인상응 장** — 50%
- 2순위: **陰陽의 기본개념(素問 陰陽應象大論 — 天地·血氣之男女·左右道路·水火徵兆)** — 25%
- 3순위: **陰陽交感·萬物化生(天地氤氳 男女構精)** — 15%
- 판정: 1단계는 陰陽 총론으로 읽었으나, 「4폭+4폭 = 八卦 마주봄」 기호가 확정 항목이라 이 판은 八卦 중 乾坤 짝으로 더 잘 풀린다. 임신(坤作成物)·天地 병풍·남녀가 모두 乾坤에 한 번에 맞는다.

### ③ 잔결
- 둥근 거울이 사전 미등재(太極? 象? 水?). 청록 발자국의 글자 미확정(氣는 사전상 흰 김이라 불일치). 남자의 일본식 상투 뜻 불명(日→日月=易 말장난?). 달의 모양(초승/그믐) 뜻 불명. 좌우 구름·무대 밑이 프레임에 잘림. 수 오류는 없음(4:4, 2:2 정합).
