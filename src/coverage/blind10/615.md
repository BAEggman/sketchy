# 615 판독 기록

## 1단계 — 생판 (사전 없이)

### ① 소품 전수와 나르는 사실
- 붉은 벽돌 성벽(총안 7개) — 도성·수도(서울/개성)라는 무대 배경.
- 기와집 관청(현판 빈 칸) 안: 책꽂이 2단에 푸른 책 묶음, 책상 2개에 펼친 책 2권 → 의서를 보관·편찬하는 관서(태의감/전의감·집현전류).
- 문간의 노란 도포·검은 건·수염 관리 1인, 허리에 보라 열매 2알 → 의서를 맡은 관원. 열매는 자두(李)로 보임 → 이씨 또는 조선 왕실(오얏) 표지?
- 왼쪽 약방: 격자 서랍 4×4=16칸에 말린 약재, 아래 경사 쟁반 6칸+옆 2칸, 위 바구니 2, 바닥 바구니 3(가장 왼쪽은 프레임 잘림) → 향약(토산 약재)의 수집·분류.
- 약재 고르는 아이 1인(붉은 머리띠, 허리에 자두 2알) → 약재 채집·정리 담당.
- 흰 머리띠 남자가 눈 감고 공손히 나무 널빤지 1장 들고 섬 → 목판(경판)을 바치는 모습 = 목판 간행.
- 보라 옷 사내가 종이 더미를 가위로 자르고 노끈으로 묶음: 상 위 종이 더미 3(낱장 1, 묶음 2), 상 아래 3(낱장 1, 묶은 책 2), 가위 1 → 책 편찬·제본(권수 묶기).
- 석탑(5층) + 버드나무 1그루 → 사찰·불교(대장도감?) 및 柳(버들) 표지.
- 오른쪽 짓다 만 목조 골조 안에서 **왕관(5각 금관)** 쓴 왕이 먹통에서 먹줄을 뽑아 치며 웃음, 바닥에 대팻밥 6~7, 끌·망치 → 왕이 몸소 기관(도감)을 세움 = 왕명 설치.
- 왕의 골조는 관청 건물보다 약 1.2배 크고 아직 지붕 없음 → "신설".

### ② 표제어 후보
- 1순위 **향약구급방(鄕藥救急方) — 고려 고종, 대장도감 간행(1236)** 40% : 향약(약방) + 목판·끌·대팻밥(판각) + 석탑(불교 도감) + 왕의 설치 + 제본.
- 2순위 **조선 세종대 의서 편찬·삼의사(향약집성방·의방유취, 전의감·혜민서·제생원)** 30% : 자두=李(조선), 관청 책꽂이, 약재 수집, 왕이 기관 신설.
- 3순위 고려 의료제도(태의감·혜민국·동서대비원·약점) 15%.

### ③ 뜻 모를 것·어색·잘림
- 허리의 자두 2알(두 사람)이 李 성씨인지 장식인지 불명.
- 버드나무가 柳 성씨인지 단순 풍경인지 불명.
- 흰 머리띠 남자의 널빤지가 목판인지 건축 자재인지 모호.
- 왼쪽 끝 바구니·오른쪽 끝 골조와 앞의 긴 널빤지가 프레임에서 잘림.
- 현판이 빈 칸이라 관청 이름 단서 없음.

## 2단계 — 계통 (사전 읽은 뒤)

사전의 성씨 기호(王=왕관·李=허리춤 자두·門=문간, 「어느 王·李인지는 무대가 진다」, 「明 서점」 무대 존재)로 다시 읽으니 1단계의 「왕이 기관을 세움」 독법이 무너지고 明代 의가 무대로 깔끔히 풀린다.

### ① 소품 재판독
- 왕관 쓴 사람 = 성 **王**. 그가 먹통에서 **먹줄(墨繩)을 뽑아 치는 것 = 準繩**(먹줄·수준기) → **王肯堂 『證治準繩』**(1602). 골조는 설치가 아니라 準繩 말장난의 무대.
- 허리춤 자두 2알 = 성 **李** 두 사람. ① 서점 **문간(門)**에 선 관리 = 李 + 入門 → **李梴 『醫學入門』**. ② 약방에서 약재를 고르는 아이 = 李 + 본초 분류 → **李時珍 『本草綱目』**. 격자 서랍 4×4=**16칸 = 16部**, 경사 쟁반 6칸 = 60類(어림).
- 기와집에 책꽂이·펼친 책·빈 현판 = 사전이 말하는 「明 서점」 무대(장씨 갈림 조건에 등장) → 시대 = 明.
- 종이를 가위로 잘라 노끈으로 다시 묶는 보라옷 사내 = 의서 편찬·重訂(錯簡重訂 또는 綱目 편제) — 성씨 기호가 없어 특정 불가(허리가 상에 가려 자두 유무 확인 불가).
- 흰 머리띠 남자가 받쳐 든 널빤지 = 목판(刊行) 또는 簡(錯簡)으로 보이나 사전에 없음.
- 석탑·버드나무·벽돌 성벽 = 사전 기호 아님 → 明 도성 풍경으로 둔다(寺=기와지붕 절 기호와는 모양이 달라 적용 안 함).

### ② 표제어 후보
- 1순위 **明代 의학사 — 李時珍 本草綱目·李梴 醫學入門·王肯堂 證治準繩** 65%
- 2순위 **證治準繩(王肯堂)** 단일 표제 15% — 왕관 인물이 무대 중앙 우측에서 가장 크고 유일하게 행위가 말장난이라 단일 표제일 가능성.
- 3순위 고려 王氏 무대의 향약구급방 10% — 1단계 독법, 사전의 王·李 성씨 규칙과 충돌해 하향.

### ③ 잔결
- 종이 묶는 사내와 널빤지 든 사내의 정체(方有執 條辨? 樓英 綱目? 楊繼洲 大成?) — 전담 기호 없음.
- 석탑(5층)·버드나무·성벽이 글자인지 풍경인지 불명.
- 왼쪽 끝 바구니, 오른쪽 골조, 앞의 긴 널빤지 프레임 잘림.
- 상 위·아래 종이 더미 6뭉치(묶음 4·낱장 2)가 권수인지 불명.
