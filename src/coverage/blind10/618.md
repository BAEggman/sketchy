# blind10 / 618 판독 기록

## [1단계 — 생판] (그림만 보고)

**① 소품 전수와 사실**
- 무대: 회색 맨 방(상자형), 소품은 나무 긴 의자 1개뿐. 벽·바닥에 아무 표지(불꽃·눈송이·물) 없음 → 사실은 오로지 **사람의 살빛·몸집**이 나른다.
- 앉은 환자 3인(같은 회색 옷, 맨발, 손을 무릎에):
  1. 왼쪽 마른 남자 — 얼굴·목·손·발까지 **귤껍질처럼 선명한 주황색**(一身俱黃, 鮮明如橘子色). 눈을 크게 뜨고 흰자가 누르스름하게 드러남(目黃).
  2. 가운데 뚱뚱한 남자 — 몸 너비가 양옆의 약 1.5~2배, 얼굴·손이 **옅은 담황색**에 부풀어 늘어진 모양(面黃虛浮).
  3. 오른쪽 여자 — 얼굴·손·발이 **연기에 그을린 듯 어둡고 탁한 황갈색**(晦暗如烟熏), 눈은 감긴 듯 흰 틈만 보임.
- 앞 왼쪽에 등을 보이고 무릎 꿇은 사람 1인 = 세 사람을 **바라보는 의사(望診 주체)**.
- 오른쪽 아래 별 모양 워터마크(소품 아님).

**② 표제어**
- 1순위: **望色 — 黃色 主病(黃疸의 陽黃·陰黃 / 面黃虛浮=黃胖·脾虛濕盛)** (60%)
- 2순위: **黃疸 변증(陽黃=濕熱·橘子色 vs 陰黃=寒濕·烟熏色)** (25%)
- 3순위: 望形體(肥人多痰濕·瘦人多火) 10%

**③ 어색·불명**
- 가운데 사람 색이 옅어 「白色(陽虛水泛의 面白虛浮)」로 읽힐 여지 있음 → 그러면 黃·白·黑 세 색이 되나 靑·赤이 없어 五色 판으로는 불완전.
- 세 사람 눈 표현(흰자만 드러남)이 目黃인지 단순 표정인지 애매. 잘림 없음.

## [2단계 — 계통] (사전요약 어휘로 재독)

사전에 「面 = 광택만 面, **얼굴색 자체는 望色 판 전담**」이라 되어 있고, 이 판은 병표지(불꽃·눈송이·진창·김) 하나 없이 살빛만 다르게 칠했으므로 **望色 판**임이 어휘로 확정된다. 세 사람의 색이 곧 사실:
- 왼쪽 **鮮明 橘子色** = 陽黃(濕熱). 「目 = 크게 뜬 눈·눈꺼풀 사이 열린 틈」이 왼쪽 사람에게만 뚜렷해 **目黃**(白睛黃染)을 같이 나른다.
- 가운데 **淡黃 + 腫(부풀어 팽팽)·大(옆 사람의 2배)** = 面黃虛浮 = **黃胖(脾虛濕盛)**. 사전의 內濕(발밑 진창)이 없으니 濕을 따로 그린 게 아니라 '虛浮'라는 모양으로 나른 것.
- 오른쪽 **晦暗 烟熏色** = 陰黃(寒濕). 눈 감김 = 陽黃의 뜬 눈과 대비(陽/陰).
- 무릎 꿇은 관찰자 = 望診의 「보는 이」. 긴 의자는 「같은 것 셋 중 가운데 = 中」 구도 → 가운데가 脾(中焦) 자리라는 암시와도 맞는다(脾主黃).
- 2단계 소견: 1단계 1순위가 더 단단해졌다. 中 구도까지 읽으면 「脾虛濕盛의 黃胖이 한복판」이라는 배치가 의도적으로 보인다.

**② 표제어**
- 1순위: **望色 黃色主病 — 陽黃(橘子色)·陰黃(烟熏色)·黃胖(面黃虛浮, 脾虛濕盛)** (65%)
- 2순위: **黃疸 陽黃·陰黃 변증** (22%)
- 3순위: 五色主病 중 黃·白·黑 三色(가운데를 白으로 볼 때) 8%

**③ 잔결**
- 가운데 인물의 색이 淡黃인지 白인지 경계가 흐림(白으로 읽으면 陽虛水泛). 瘦(왼쪽)가 사전의 虛(1/3로 줄어듦)에는 못 미쳐 虛 글자로 읽기는 무리. 잘림·수 오류 없음.
