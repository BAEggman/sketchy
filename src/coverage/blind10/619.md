# blind10 / 619 판독

## 1단계 — 생판 (사전 없이)

### ① 소품 전수와 나르는 사실
1. **조선 임금** (익선관·홍색 곤룡포·가슴 용보, 손 뒤로 짐, 화면 중앙, 가장 큼) — 君/王/主. 홍색 = 赤·心·火 계열.
2. **태양** (우상단, 광선 약 20줄, 임금 머리 크기의 약 1.5배) — 日·陽·火·熱·明.
3. **익은 곡식밭** (고개 숙인 이삭, 벼/조 모양, 이삭 좌 4·우 5 ≈ 9개, 화면 폭 전체) — 禾·米·穀·粳米. 논 = 濕 가능.
4. **아지랑이·김 선** (하늘에 좌 5·우 4 = 9줄) — 熱·暑·升散, 또는 气(김) → 米+气 = 氣.
5. **탕약 사발** (붉은 토기, 검은 액체, 김 3줄, 작은 나무 소반 위, 임금 키의 약 1/5) — 湯·藥·苦(쓴 약).
6. 우하단 네모 반짝이 1개 — 뜻 미상(워터마크?).

### ② 표제어
- 1순위 **王氏淸暑益氣湯** — 王(임금)+暑(뙤약볕·아지랑이 밭)+粳米(벼밭)+湯(사발). 확신 30%.
- 2순위 **暑邪(六淫의 暑)** — 陽邪·炎熱(해), 升散(오르는 선), 挾濕(논), 擾心神(홍포 임금 = 心 君主). 확신 25%.
- 3순위 **少陰君火/君火** — 君(임금)+火(해·열). 15%. 4순위 **心(君主之官)** — 君主·赤·火·苦·穀麥. 10%.

### ③ 모호·어색·잘림
- 임금이 왜 밭 한가운데 서 있는지(王氏인지, 心인지, 君火인지) 결정 단서 없음.
- 곡식이 벼인지 조인지 밀인지 불명 → 粳米/麥 판정 흔들림.
- 하늘의 물결선이 아지랑이(熱)인지 김/향(气·香)인지 불명.
- 좌우 가장자리 이삭 2개 프레임에 잘림. 우하단 반짝이 뜻 미상.

## 2단계 — 계통 (blind6 사전 적용 후)

### ① 소품 재판독
1. **붉은 곤룡포 임금** = 사전 확정 **心**(오행왕국 다섯 인물). 1단계의 王氏·君火 읽기는 폐기 — 王은 「왕관」이고 여기 임금은 익선관·홍포라 心이다.
2. **해** = **陽**(해 또는 불). 불꽃이 없으므로 熱·暑는 아니다 → 心은 「陽中之太陽」.
3. **하늘의 물결선 9줄 + 사발 위 3줄** = **氣**(서린 흰 김). 밭 위로 오르는 김 = 그 계절의 氣 → 「通於夏氣」.
4. **익은 곡식밭(이삭 약 9개)** = 사전 미등재 신소품. 心의 五穀인 **麥**(보리·밀, 초여름 麥秋에 익음)로 읽힘. 노란 농부(脾)가 없으니 脾·倉은 아니다.
5. **김 나는 검은 사발** = 사전 확정 **苦**(김 나는 검은 커피) → 心의 五味 「其味苦 / 苦入心」. 찰랑찬 국물(補)로도 볼 수 있으나 검은색이 결정적.
6. 우하단 반짝이 = 여전히 미상(워터마크로 봄).

### ② 표제어
- 1순위 **心 — 陽中之太陽·通於夏氣·其味苦·其穀麥 (心의 五行 배속)** — 임금(心)+해(陽·太陽)+여름 밭의 김(夏氣)+검은 사발(苦)+보리밭(麥)이 한 줄로 꿰임. 확신 55%.
- 2순위 **心氣·心陽 (心의 陽과 氣)** — 해=心陽, 김=心氣로만 읽는 경우. 밭·苦사발 설명이 남아 약함. 20%.
- 3순위 心煩(임금+가슴 한복판 용보, 열기) 10% — 표정이 평온해 약함. 4순위 君火·暑邪 10%.
- 판정: 사전 어휘로 1단계보다 훨씬 잘 풀린다(임금=心, 검은 김 사발=苦, 김=氣가 모두 등재 기호).

### ③ 잔결
- 곡식 종류(벼/조 vs 麥) 불명 → 「其穀麥」 판정은 추정. 보리라면 까끄라기·곧은 이삭이어야 하는데 고개 숙인 이삭이다.
- 하늘 김 9줄·이삭 9개의 수가 사실을 나르는지 불명.
- 좌우 가장자리 이삭 각 1개 프레임 잘림. 우하단 반짝이 미상.
