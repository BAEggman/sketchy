# 620 판독 기록

## [1단계 — 생판] (사전 없이 그림만)

### ① 소품 전수
- **왼쪽 돌 동상(관모·백발 수염, 책을 펼침, 등 뒤로 흰 깃·판 6~7개가 뻗침)** — 좌대 위 = 전설·열전급 인물. 등의 깃 = 새(鳥人) → **扁鵲**(한대 화상석 '인두조신' 扁鵲), 책 = 《難經》.
- **곳간(倉) + 지붕 위 가마니 10개쯤 + 안의 동상(목에 메달, 장부 펼침)** — 창고=倉, 메달=관직(太倉長) → **倉公 淳于意**, 장부 = 診籍(최초 진료기록).
- **활·화살통 멘 사내 + 바로 옆 긴 사다리(가로대 7단쯤)** — 弓+長 = **張** → 張仲景. 사다리 길이는 사내 키의 2배.
- **묘비 1 + 땅의 죽간 두루마리 2개** — 사다리·칼잡이 사이. 묘비 = 종족 2/3 傷寒 사망(仲景 序), 두루마리 2 = 傷寒論·金匱要略 두 책.
- **벽화: 호랑이·사슴·곰·원숭이·학 5마리** = **五禽戲** → 華佗.
- **칼 + 김 나는 사발 든 사내** = 외과수술 + **麻沸散** → **華佗**.
- **금투구 붉은 깃 갑옷 장군, 손을 새(갈색 닭·꿩류, 머리 위 '깨는' 선) 위에 얹음** — 갑옷·새·장군. 關羽(羽=깃→새, 刮骨療毒) 또는 甲乙(갑옷=甲, 새=乙).
- **땅에 꽂힌 작은 흰 깃발 밭 약 50여 개(7~8줄×7)** — 軍陣·침 자리·방(方) 수 중 하나.
- **왕관 쓴 왕(메달) + 무릎 꿇은 소년, 붉은 솥(화로+석쇠)에서 젓가락으로 음식** — 皇(왕)·食(먹음)·湯(솥) 중 하나. 伊尹·湯王(湯液) 가능성도.
- **묶은 섶 다발 1 + 납작 죽간 다발 1** — 灸(艾 다발) 또는 책 2권.
- **담장 덩굴(葛)** + **큰 통나무를 껴안은 수염 의원(붉은 십자 약주머니)** — 抱+朴(통나무) = **抱朴子**, 葛=葛洪, 약주머니 = 肘後備急方.
- **맨 오른쪽 여러 갈래 이정표(5~6 날개, 프레임에 잘림)** — 方(方向)·道(道士) 중 하나.

### ② 표제어
- 1순위: **醫學史 — 漢·魏晉 의가 열전(扁鵲·倉公·張仲景·華佗·皇甫謐·葛洪)** (50%)
- 2순위: **華佗**(五禽戲·麻沸散·외과·刮骨療毒 중심 판) (20%)
- 그 밖: 漢代 四大經典 판(통나무+덩굴 = 本草, 왕+소년 = 黃帝·岐伯) 15%.

### ③ 뜻 모름·어색·잘림
- 장군이 왜 닭을 쥐는지, 깃발 밭이 무엇의 개수인지 불명(50여 개는 349혈·52방 어느 것과도 안 맞음).
- 왕과 소년이 솥에서 먹는 장면의 인물 미확정(皇甫謐 寒食散? 伊尹·湯王?).
- 오른쪽 이정표 프레임 잘림, 왼쪽 동상 뒤 깃도 잘림. 가마니 수(10)와 사다리 7단의 의미 불명.
- (보조 계수) 깃발 밭을 화상처리로 세니 닫힌 깃발머리 47~51개 + 겹친 덩어리 1 → **약 50(47~53)개**. 五十二病方의 52와 맞아떨어질 가능성.

## [2단계 — 계통] (blind6 사전 어휘로 재독)

### 사전에 바로 걸리는 기호
- **倉 = 곡식 가마니 쌓인 곳간 + 앞에 관리(메달)** → 藏이 아니라 **倉** → **倉公(淳于意)**, 손의 장부 = 診籍. 1단계와 일치.
- **張 = 등에 멘 긴 활** → 성이 張, 어느 張인지는 무대가 결정. 무대가 扁鵲·倉公 동상·五禽戲의 漢代 거리이므로 → **張仲景**. 옆의 긴 사다리 = 長(弓+長=張)의 보강, 묘비 = 종족 2/3 傷寒 사망, 두루마리 2 = 傷寒論·金匱要略.
- **王 = 왕관** → 성이 王, 무대가 결정 → 晉 무대라면 **王叔和**(소년 = 叔·조카 관계, 솥의 음식 = 禾+口 和?) 또는 唐 **王燾**(솥 밑 불 = 燾의 灬). 사전의 和(수평 저울)가 없어 王叔和는 반쯤만 성립.
- **華 = 빛나는 것** → 새 머리 위의 광채선 = 華 → 새 = 禽 → **華禽 = 華佗 五禽戲**의 보강 라벨로 읽힘. 칼 + 김 나는 사발(沸 = 끓음)은 麻沸散·외과 그대로.
- 肝(초록 비늘갑옷 장군)은 아님 — 이 장군은 갈색 갑옷·금투구 → 장부 의인화가 아니라 **甲(갑옷 갑)**, 새 = **乙(새 을)** → 甲乙 → 깃발 밭(침 자리·針) + 화로 불·섶 다발(灸·艾) → **皇甫謐 《針灸甲乙經》**. 왕관 임금을 皇(임금 황)으로 읽으면 皇+甲乙+針灸가 한 묶음.
- 덩굴(葛) + 통나무를 껴안은 의원(抱+朴) + 팔꿈치의 붉은 약주머니(肘後·備急) → **葛洪 《肘後備急方》·《抱朴子》**. 맨 끝 이정표 = **方**(方向) 또는 道(도교).
- 왼쪽 깃 돋은 동상 = 한대 화상석의 鳥人 **扁鵲**(《難經》). 사전 외 기호지만 무대와 맞음.

### ② 표제어(재판정)
- 1순위: **醫學史 — 戰國~晉 의가 열전: 扁鵲·倉公·張仲景·華佗·皇甫謐(針灸甲乙經)·王叔和·葛洪(肘後備急方)** (55%) — 왼→오 연대순이 깨끗하게 선다.
- 2순위: **秦漢 醫學史 판(馬王堆 漢墓 五十二病方: 묘비+두루마리+깃발 52개; 黃帝=왕, 神農本草=통나무+덩굴)** (20%) — 깃발 계수 ≈52가 유일한 근거.
- 3순위: **華佗** 단독 판(장군=關羽 刮骨療毒, 왕=曹操) (10%).

### ③ 남는 의문
- 장군+새(甲乙?)와 왕+소년+솥(皇甫謐? 王叔和? 伊尹·湯王?)의 귀속이 사전으로도 확정되지 않음.
- 깃발 약 50개(47~53)가 349穴·52方 중 무엇인지 미확정. 이정표 프레임 잘림, 동상 뒤 깃 잘림.
