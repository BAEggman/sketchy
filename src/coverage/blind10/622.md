# 622 판독 기록

## 1단계 — 생판 (사전 없이)

① 소품 전수
- 초록 비늘갑옷·뿔 달린 투구를 쓴 장군 1명(화면 한복판, 눈을 꼭 감고 양 볼에 눈물 줄기 좌1·우1~2). 장군=將軍之官, 초록=木·靑, 눈물=肝在液爲淚, 감은 눈=目.
- 왼쪽 벽의 나무 판문(덧창) 1짝 — 장군이 왼손바닥으로 밀어 닫고 있음. 문틈에서 오른쪽으로 흐르는 바람선 3줄 + 옆으로 날리는 잎 3장. 바람을 막는 문=風邪 방어(惡風 또는 腠理 開泄).
- 발: 두 발 모두 짚신, 들린 왼발 짚신 바닥에 구멍 1개, 바닥에 움직임 선(걷는 중) → 筋·行.
- 오른쪽 바닥에 바닥이 뚫린 헌 짚신 3짝 포개짐(모두 구멍 1개씩) → 오래 걸어 닳음 = 罷極(피로)·善行.
- 크기: 장군 키 ≈ 문 높이의 2배, 잎은 손바닥 크기.

② 표제어
- 1순위 **肝 (장상 — 將軍之官·惡風·在液爲淚·罷極之本)** 50%: 장군=將軍之官, 초록=木, 바람 막기=肝惡風, 눈물=淚, 헌 짚신=罷極之本(主筋).
- 2순위 **防風** 30%: 「장군(防)이 바람(風)을 막는다」는 글자 그대로의 말장난. 눈물=歸肝經, 짚신 3짝=歸經 3(膀胱·肝·脾)로도 읽힘.
- 3순위 風邪 성질(百病之長·善行數變) 15%.

③ 잔결
- 허리 높이로 화면을 가로지르는 흐릿한 가로 띠(갑옷 위까지 번짐)가 바람선인지 생성 오류인지 불분명.
- 눈물인지 땀인지 — 눈꼬리에서 나오므로 눈물로 봄.
- 짚신 구멍의 뜻(閉·破?) 미상. 잘림 없음.

## 2단계 — 계통 (사전 적용)

사전 어휘로 다시 읽으면 거의 글자 단위로 풀린다.
- 초록 비늘갑옷 장군 = **肝** (확정 기호).
- 옆으로 눕고 흘러 날리는 잎 3장 + 바람선 = **風** (수직 낙엽=燥와 갈림 — 여기는 옆으로 흐르므로 風).
- 해로운 것(바람)과 사람 사이에 세워 막은 가리개 = **惡** — 장군이 손으로 받친 나무 판문이 바로 그 가리개. → 肝 + 惡 + 風 = **肝惡風**(五臟所惡).
- 같은 물건 셋이 포개진 것 = **久** — 헌 짚신 3짝. 사전 갈림대로 「닳아 못 쓰게 된 무더기」는 傷이 아니라 久. 걷는 자세·발 밑 움직임 선과 합쳐 **久行**(五勞 중 久行傷筋 → 筋=肝) 또는 肝者 **罷極之本**(其充在筋).
- 눈꼬리에서 흐르는 눈물 = 사전 미등재(津·汗과 다름) → 이 판이 새로 등재하는 **淚**(肝在液爲淚). 감은 눈은 「크게 뜬 눈=目」이 아니므로 目 아님.
- 성에·불·붉은 것 없음 → 寒·熱·血 사실은 이 판에 없음(藏血 미출제).

② 표제어
- 1순위 **肝 (장상 — 將軍之官·肝惡風·在液爲淚·罷極之本/久行傷筋)** 60%.
- 2순위 **肝惡風 (五臟所惡 계열 단일 명제 판)** 25% — 눈물·짚신은 덧붙은 속성.
- 3순위 **防風** 10% — 장군 기호가 肝으로 고정돼 있어 약재 말장난으로 읽기 어려움.

③ 잔결
- 허리 높이의 흐릿한 가로 띠는 風선의 번짐으로 보이나 생성 오류 가능.
- 짚신 바닥 구멍(각 1개)이 「닳음」 표시인지 별도 글자(竅?)인지 미상 — 竅=열린 어두운 구멍이라 샐 여지 있음.
- 잎 3·짚신 3의 수 일치가 우연인지 의도(久=셋)인지 불명. 잘림 없음.
