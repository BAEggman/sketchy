# blind10 / 624 판독

## 1단계 — 생판 (사전 없이)

① 소품 전수와 나르는 사실
- 조선 임금 1명: 익선관 + 붉은 곤룡포, 용보(龍補) 3개(가슴 1·양어깨 2), 검은 목화 2짝 → 君主 = 「心者 君主之官, 神明出焉」(素問·靈蘭秘典論). 붉은 옷·분홍 벽 = 心의 색 赤·火.
- 혀를 길게 내밈(붉고 설태 없음) 1 → 心開竅於舌, 舌爲心之苗.
- 오른팔 소매를 걷어 맨 팔뚝을 드러냄, 팔뚝 전체에 나뭇가지처럼 갈라진 붉은 혈관 그물 → 心主血脈, 諸血者皆屬於心. (왼팔은 소매 그대로 — 대비는 1:1 길이, 혈관 가지 수십 가닥)
- 이마·광대·콧대의 흰 광택 → 其華在面(가능).
- 크게 뜬 눈·올린 눈썹 → 在志爲喜 또는 神明(불확실).
- 창 1개(두 짝 활짝 열림) + 창밖 초록 나무 1그루 → 「開」(개규)의 시각화? 나무는 木生火(모자)? 확신 낮음.
- 회색 바닥·분홍 벽 방 = 무대.

② 표제어
- 1순위: **心의 생리기능 종합(主血脈·藏神/君主之官·開竅於舌·其華在面)** 65%
- 2순위: **心者 君主之官 神明出焉(靈蘭秘典論 十二官)** 20%
- 3순위: **心開竅於舌** 10%

③ 뜻 모를 것
- 창밖 나무의 역할, 표정이 喜인지 단순 「혀 보이기」인지, 汗(在液爲汗)·小腸(표리) 소품 부재. 프레임 잘림 없음. 가슴 한복판 용보가 단순 복식인지 별도 기호인지 미상.

## 2단계 — 계통 (사전 어휘로 재독)

① 소품 재독
- 붉은 곤룡포 임금 = **心**(사전 확정). 왕관이 아니라 익선관이므로 王씨 인물이 아니라 장부 의인화.
- 벌린 입 안의 혀 = 舌 — 갈림 「혀가 보이면 心」 조건 충족 → **開竅於舌(在竅爲舌)**.
- 걷어올린 맨 팔뚝 위에 더해진 것 = **充** — 더해진 것은 붉은(血) 혈관(脈) → **其充在血脈**.
- 이마·광대·콧대에 얹힌 광택 = 面, 빛나는 것 = 華 → **其華在面**. (얼굴색 자체가 아니라 광택만이므로 望色 판이 아님)
- 열린 창으로 방 안(內)과 바깥(外)이 한 덩어리로 이어짐 = **通**, 바깥의 녹음 짙은 나무 = 여름 → **通於夏氣**. 창은 밝아 「竅=어두운 구멍」이 아니므로 竅가 아니라 通이다.
- 크게 뜬 눈 = 目 기호와 겹치나 心 판이므로 신(神)의 발현 또는 喜 표정으로 읽힘(사전 미등재).
- 가슴 한복판 용보: 「임금+가슴 한복판 = 心煩」 갈림이 있으나 어깨에도 같은 보가 있어 복식으로 판정, 心煩 아님.
- 땀방울 없음 → 在液爲汗 미표현. 불·해 없음 → 陽中之太陽 미표현.

② 표제어
- 1순위: **心의 계통 연계 — 其華在面·其充在血脈·開竅於舌·通於夏氣(素問·六節藏象論/陰陽應象大論)** 80%
- 2순위: **心主血脈(심의 주요 생리기능)** 10%
- 3순위: **心者 君主之官 神明出焉** 5%

③ 잔결
- 눈 크게 뜬 것의 글자(目/神/喜) 미확정. 汗·小腸·太陽 소품 부재는 판의 범위로 보임. 잘림 없음, 수 오류 없음(용보 3, 창짝 2, 신 2).
- 사전 어휘(充·華·面·通·舌 갈림)로 1단계보다 훨씬 깔끔하게 풀림 — 1단계의 「창=開」 추측은 「通」으로 교정.
