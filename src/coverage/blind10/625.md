# 625 판독 기록

## 1단계 — 생판 (사전 없이)

**① 소품 전수**
무대 = 돌판 5장(윗단) + 나무 선반(아랫단).
- 돌판1: 생강 모양 뿌리 1개, 검푸른 물방울 약 12개 맺힘, 주변 모래·흙 부스러기 → 水製(洗·漬·潤) / 淨選.
- 돌판2: 대나무 찜통 1단(뚜껑 열림), 흰 김 크게 솟음, 안에 검붉은 윤기 나는 뿌리 조각 2~3개 → 蒸(水火共製). 찜통 높이는 프라이팬의 약 1.5배.
- 돌판3: 쇠 프라이팬 + 화구 불, 노란 절편 6개 → 炒(火製). 팬 아래 접은 흰 천(또는 젖은 종이) 1장 → 煨(紙煨)? 혹은 식히는 천.
- 돌판4: 맨불(장작) 위 주황 조각 4개 + 꿀 담긴 나무 숟가락 1개(꿀 흘러 고임) → 蜜炙(炙).
- 돌판5: 잿더미 위 돌덩이 1개가 불길 속(불꽃 높이 돌판4의 약 2배 = 武火) + 붉은 액체 웅덩이 1 → 煅 + 淬(醋淬).
- 선반: 스포이드 병(검은 액체) 1 + 베이지 절편 5 → 液體輔料(酒·醋·薑汁)와 切製 飮片; 사발에 윤기 나는 주황 조각 ~7 → 蜜炙品; 사발에 칩 ~12 → 炒品; 쟁반에 검은 덩이 ~9 → 蒸製品(熟地黃류); 쇠컵에 자홍색 가루 1 → 煅淬·水飛 粉末.

**② 표제어**
- 1순위 **본초 포제법(炮製法)의 분류 — 水製·火製(炒·炙·煅)·水火共製(蒸)** 60%
- 2순위 **화제법(火製法: 炒·炙·煅·煨)** 25%

**③ 잔결**
팬 아래 접은 천의 뜻 불명(煨의 종이인지, 단순 소품인지). 돌판5 붉은 웅덩이가 醋인지 피인지 애매. 돌판1 뿌리의 검푸른 방울이 물인지 특정 즙(黑豆汁·薑汁)인지 불명. 프레임 잘림 없음. 찜통 뚜껑이 공중에 뜬 듯 어색.

## 2단계 — 계통 (사전 적용 후)

사전으로 다시 읽으면: 氣=흰 김 → 찜통(蒸, 水+火=氣). 熱=불꽃 → 돌판3·4·5 세 불(火製 셋). 津=맑은 물방울 → 돌판1 뿌리의 방울(水製). 즉 윗단은 「水製 1 → 水火共製 1 → 火製 3」의 분류 축이 그대로 서고, 사전 어휘로 더 또렷해진다. 甘=나무 국자가 꽂힌 꿀 → 돌판4 꿀 숟가락은 蜜炙(甘·補 쪽 가공)의 표지. 地黃=검붉은 뿌리 조각 → 찜통 속 조각과 쟁반의 검은 덩이가 바로 地黃이며, 蒸의 예시로 「生地黃 → 熟地黃(九蒸九曝)」가 명시된 것. 溫=김 오르는 따뜻한 천 → 팬 아래 접은 천이 이 글자일 가능성(炒·炙로 약성을 溫하게 함)이 있으나 김이 없어 보류. 血=붉은 것 → 돌판5 붉은 웅덩이가 血로 읽히면 煅淬 다음 「入血·止血(炭·煅 止血)」을 뜻할 수 있으나, 포제 문맥에서는 醋淬의 醋로 보는 편이 자연스럽다.

- 1순위 **본초 포제법(炮製法)의 분류 — 水製(洗·漬)·水火共製(蒸)·火製(炒·蜜炙·煅淬)** 65%
- 2순위 **화제법(火製法: 炒·炙·煅·煨)** 15%
- 3순위 **지황의 포제(生地黃→熟地黃, 蒸)** 10%

**③ 잔결** 팬 아래 접은 천(溫인지 紙煨인지) 미확정. 붉은 웅덩이(醋 vs 血) 양갈래. 돌판1 방울이 검푸르러 사전의 「맑은 물방울(津)」과 색이 어긋남. 쇠컵 자홍 가루의 약재명 미상(代赭石·朱砂류 추정). 수 오류 없음, 잘림 없음.
