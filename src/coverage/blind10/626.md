# blind10 / 626 판독

## 1단계 — 생판(사전 없이)

**소품 전수**
- 익선관(날개 위로 솟음)+붉은 곤룡포(용보 3개 보임) 조선 임금 1인 — 무릎 꿇고 서안 앞 → 왕(王/君)
- 땀방울 5개(좌2·우3) → 汗
- 충혈된 눈·눈 밑 처짐, 볼 홍조 → 안질/피로/열
- 하체 알몸(맨다리·맨발) → 뜻 불명
- 서안 위 펼친 책 1권 → 편찬/독서
- 바닥 찢어진 책 더미: 3무더기, 제본 약 9권 + 낱장 3~4 → 산일된 옛 의서
- 세워진 널빤지 1장, 밑동~절반 검게 탐(높이는 임금 머리 높이, 화로의 약 4배) → 타는 나무
- 숯불 화로 1개(숯 약 10덩이, 불꽃 3) → 숯(숙)+불(화)
- 온통 붉은 방 → 열/화 무대

**읽기** 임금(王)+숯(숙)+불(화) 소리맞춤 = 왕숙화. 찢긴 책 더미=산일된 상한잡병론을 편차, 서안 책=맥경(10권 ≈ 책 수 10). 땀(汗=寒)으로 傷寒 암시. 대안: 불(火=華)+타는 널(타) = 화타(청낭서 소실, 붉은 눈·땀 임금=조조 두풍). 셋째: 병화로 의서가 흩어져 선조가 허준에게 동의보감 편찬을 명한 장면.

**표제어** 1순위 **왕숙화(王叔和) — 상한론 편차·맥경** 35% / 2순위 **화타(華佗) — 청낭서 소실** 25% / (3위 **선조·동의보감 편찬 하명** 15%)

**잔결** 하체 알몸·충혈 눈의 뜻 불명. 널빤지가 왜 세워져 있는지 불명. 프레임 잘림 없음. 책 수 9~10 어림.

## 2단계 — 계통(사전 적용)

사전으로 다시 읽으니 전혀 다른 판이다. 소리맞춤 아닌 글자-사물로 풀린다.
- 붉은 곤룡포 임금 = **心** (왕숙화·조조 아님. 王이면 왕관인데 왕관 없음)
- 세워진 널빤지 = **惡**(해로운 것과 사람 사이에 세워 막은 가리개) — 임금과 화로 사이에 정확히 놓임
- 화로의 불꽃 = **熱**(불=陽) → 가리개 너머의 해로운 것 = 熱 ⇒ **心惡熱**. 널의 밑동이 탄 것은 熱의 해가 가리개까지 미침(衰=타다 남은 것으로도 읽힘)
- 살갗의 땀방울 = **汗** ⇒ 心在液爲汗(五臟化液 心爲汗)
- 하체 알몸·땀·홍조 = 惡熱의 몸짓(옷을 벗어젖힘) — 사전 밖 추정
- 책 3무더기 포개짐 = **久**(같은 물건 셋 포개짐; 닳은 무더기는 傷 아닌 久) + 임금이 책을 봄(視) + 크게 뜬 눈(目)이 붉음(血) ⇒ **久視傷血**(五勞所傷). 찢긴 낱장은 傷血의 傷
- 붉은 방 = 血/赤(心의 색) 무대

즉 素問·宣明五氣의 心 항목 묶음: 心惡熱·心爲汗·(心主血·久視傷血). 1단계의 의학사 독법은 임금=心 사전 앞에서 폐기한다.

**표제어** 1순위 **心惡熱(심오열) — 心의 宣明五氣 묶음(心惡熱·心爲汗·久視傷血)** 50% / 2순위 **心陰虛·心火 병증(盜汗·失眠·顴紅)** 15%

**잔결** 하체 알몸은 사전에 없음(惡熱 몸짓 추정). 붉은 눈이 血인지 失眠인지 불명. 널의 탄 자국이 衰인지 단순 열 손상인지 불명. 땀 5·불꽃 3·숯 ~10의 수는 사실과 못 맞춤. 잘림 없음.
