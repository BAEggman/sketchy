# 627 판독 (blind10)

## 1단계 — 생판 (사전 없이)

**① 소품 전수와 나르는 사실**
- 농부 1명: 황색 저고리·바지, 황색 밀짚 삿갓, 맨발, 화면 한복판에 정면으로 섬. 표정 평온(병색 없음) → 황색·중앙 = 토(土)·비(脾).
- 비: 화면 전체 수직 빗줄기 → 습(濕)·장마·장하(長夏).
- 진흙 바닥 + 발밑 물웅덩이 2개(두 발 아래 이어짐) + 탁자 밑 웅덩이 1 → 습이 아래로 모임(습성취하).
- 바닥 안개(좌·우 하단, 낮게 깔림) → 습의 무거움(중탁).
- 검은 옹기 1 + 나무 숟가락 1, 황갈색 꿀/조청이 3줄기 흘러넘침(좌2·우1) → 감미(甘)·끈적임(점체).
- 황색 나무 탁자 1(4다리): 항아리 받침.
- 보리/밀 이삭 밭(배경 전면, 황록) → 곡(穀)·토가 만물을 기름.
- 삿갓·어깨 둘레 짧은 선 몇 개 → 빗방울 튐(강조선).
- 황색 사물 4종(옷·삿갓·탁자·곡식): 토 색 반복.

**② 표제어**
- 1순위 **토(土)·비(脾)의 오행 배속 — 장하·습·황·감·중앙** (45%)
- 2순위 **습사(濕邪)의 성질 — 중탁·점체·취하** (35%)
- 판단 근거: 환자 표지(부종·설사·무거운 머리)가 없고 농부가 멀쩡히 서 있으므로 병증판보다 배속판에 가깝다. 비·진창·안개·꿀이 각각 습·토·감으로 읽힌다.

**③ 뜻 모를 소품·어색한 것·프레임 잘림**
- 꿀이 넘쳐 흐르는 이유(과식 甘?)가 불명. 곡식 종류(보리·밀·벼) 특정 불가. 잘림 없음.

## 2단계 — 계통 (사전 적용)

**① 소품 재독**
- 노란 밀짚모자 농부 = **脾**(사전 확정 기호). 황색 옷은 그 보강.
- 수직 비·안개·진창 = **濕**. 「길에 있으면 外濕」 — 비가 하늘에서 내리므로 外濕(在天爲濕) 쪽. 다만 웅덩이가 「자기 발밑」에 고여 內濕(脾) 조건에도 걸침 → 갈림 양쪽 모두 가능하나 비가 주도하므로 外濕 우선.
- 나무 국자 꽂힌 꿀단지 = **甘**(사전 확정 기호). 넘쳐 흘러나오는 꿀 = **盛** 가능(甘盛)이나 꿀단지의 통상 장식일 수도 있음.
- 농부가 한복판에 섬 = **中**(中央).
- 바닥 흰 안개는 「氣=서린 흰 김」과도 비슷하나, 비·진창과 한 묶음이므로 濕의 안개로 읽음.
- 곡식밭·탁자는 사전에 없음(倉·藏은 가마니라 다름) → 土·穀의 무대 배경.
- 병표지(불꽃·눈송이), 虛(1/3 축소), 惡(가리개) 없음 → 병리판 아님.

**② 표제어**
- 1순위 **脾의 배속 — 中央·濕·甘 (「中央生濕, 濕生土, 土生甘, 甘生脾」 陰陽應象大論)** (55%): 中(한복판)→濕(비)→土(진흙·밭)→甘(꿀)→脾(농부) 사슬이 그대로 놓여 있음.
- 2순위 **外濕이 脾에 들다(濕困脾·脾惡濕)** (20%): 비 속 진창에 脾가 맨발로 선 구도. 단 惡 가리개·병표지가 없어 약함.
- 3순위 **甘味過盛→脾濕** (10%): 盛 읽기가 맞을 때만.
- 1단계와 비교: 사전의 脾·濕·甘 기호가 정확히 맞아 떨어져 「脾 배속」으로 수렴, 「습사 성질」 가설은 병표지 부재로 후퇴.

**③ 잔결**
- 넘치는 꿀이 盛인지 장식인지 불명. 발밑 웅덩이의 外濕/內濕 갈림 미확정. 곡식밭 미등재. 잘림 없음.
