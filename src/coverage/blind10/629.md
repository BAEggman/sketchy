# 629 판독 (blind10)

## 1단계 — 생판 (사전 없이 그림만)

**① 소품 전수와 사실**
- 흰 빈 깃발 7개(깃대 7) → 7개 정거장 = 7권의 책/시대 축. 강이 우상→좌하로 흐름 = 시간의 흐름.
- 1번: 소머리 모자 소년 + 금메달, 씨앗을 뿌림, 곡식 바구니 3개(큰 것 2, 작은 것 1 ≈ 1/2) → **神農**(人身牛首)·百草·3바구니 = 三品(上·中·下品), 메달 = 最古 본초서 → **神農本草經**.
- 2번: 물레 위 항아리 1 + 옆 항아리 1, 양손에 붓 2자루(왼손 **붉은** 붓·오른손 **검은** 붓) → 陶(도자기)=**陶弘景**, 朱墨分書 → **本草經集注**(神農 원문 朱, 名醫別錄 墨).
- 3번: 붉은 관복·烏紗帽 관리, 긴 두루마리(勅令), 손에 초록 인장함, 금메달, 뒤에 황색 기와 궁궐(인물 키의 약 2배) → 國家 勅撰, 메달 = 세계 최초 국가 약전 → **新修本草**(唐 659, 蘇敬).
- 4번: 머리띠 사공이 배 위에서 황금 보물상자를 **여는**(開) 중, 상자 ≈ 배 길이의 1/2 → 開+寶 = **開寶本草**(宋 973~4).
- 5번: 쪽진 여인이 가위로 큰 책(네모 틀 = 그림/항목)을 오려냄, 오린 종이 2장 → 經史에서 발췌·증거 수집 또는 圖 수집 → **證類本草**(唐愼微) 1순위 / 圖經本草(蘇頌)·嘉祐本草 2순위.
- 6번: 책 더미 2개(왼쪽 4권·오른쪽 5권), 손에 1권, 바닥에 펼친 1권, 3×3=9칸 분류 상자 → 수백 권 참고·綱目 분류 → **本草綱目**(李時珍, 16部 60類).
- 7번: 사람 없이 탁자 위 초록 옥인장 1개 → 勅撰/官定 또는 刊行(사후 간행). 3번 관리가 든 초록 인장함과 같은 물건 = 「관의 인가」 기호.

**② 표제어**
- 1순위: **本草學 발전사 — 역대 본초서 계보(神農本草經→本草經集注→新修本草→開寶本草→證類本草→本草綱目)** 70%
- 2순위: **中國醫學史 시대별 개관(漢~明, 官修 의서 전통)** 15%

**③ 뜻 모를 것·어색·잘림**
- 7번 정거장에 인물 없이 인장만 있음(어느 책인지 불명: 本草品彙精要? 본초강목 간행?).
- 6번 인물의 서양식 재킷·가르마(明代 인물로 보기 어색 — 현대 中華本草/藥典 가능성).
- 4번이 왜 배를 탔는지(강=시간축이라면 배는 잉여).
- 바구니 수 3 vs 크기 2:1 — 三品(120/120/125)과 수 비례 불일치.
- 9칸 상자 ↔ 綱目 16部와 수 불일치. 프레임 잘림 없음(강은 좌단으로 자연스럽게 빠짐).

## 2단계 — 계통 (blind6 사전 어휘로 재독)

사전 어휘 중 이 판에 걸리는 것: **久**(같은 것 셋 이상 포갬) = 6번의 책 더미 4권·5권 → 「오랜 세월」 = 李時珍 27년·三易其稿 → 6번=**本草綱目** 쪽이 강화됨. **藥**(배 모양 약연) — 4번의 배는 실제 舟이지만 「배 모양」 기호의 느슨한 변주로 읽으면 「藥(本草)」 표지가 되어 開寶**本草**를 뒷받침. **大**(같은 것 둘 나란, 하나가 2배) — 1번 바구니 큰 것 2·작은 것 1은 「大」로 읽힐 수 있으나 神農 쪽 서명에 大가 없어 三品으로 유지. **散**(사방으로 흩날림) — 1번 씨앗은 아래로 떨어지므로 散이 아니라 播種·百草. **官**(3층 선반장 가운데 층) — 6번 상자는 눕힌 3×3 쟁반이지 선반장이 아니므로 官이 아니라 분류(綱目). **寺**(기와 절 한 채) — 3번 뒤 건물은 다중 전각 궁궐이므로 寺가 아니라 무대(중국 조정·唐). **心**(붉은 곤룡포 임금) — 3번은 날개 달린 烏紗帽의 관리이고 오행왕국 다섯 인물 세트가 없으므로 心이 아님. **王·張·李**(관·활·자두) — 어느 인물에도 없음 → 성씨 확정 불가(6번이 李時珍이라면 자두가 없는 것이 잔결). 초록 인장(3번 손·7번 탁자)은 사전 미등재 → 「勅撰·官定」 기호로 판독 유지.

**② 표제어(재판정)**
- 1순위: **本草學 발전사 — 역대 본초서 계보(神農本草經→本草經集注→新修本草→開寶本草→證類本草→本草綱目, 7번=官定·간행)** 70%
- 2순위: **本草學 발전사 漢~宋 한정(…→開寶→圖經·嘉祐本草→證類本草→大觀·政和本草 官定)** 20%

**③ 잔결**
- 사전으로 새로 풀린 것은 久(책더미=오랜 편찬) 정도이고, 7번 인장·6번 복장·4번 배는 여전히 미확정. 李 자두 부재. 수 불일치(바구니 3:2:1, 9칸↔16部) 그대로.
