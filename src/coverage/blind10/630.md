# 630 판독 기록

## 1단계 — 생판 (사전 없이)

**① 소품 전수**
- 큰 해 1 (상단 중앙, 테두리가 불꽃 모양, 지름이 인물 머리의 약 2배 · 화면 폭의 1/4) → 한여름 뙤약볕·炎熱
- 상투 튼 중년 사내 1: 얼굴·가슴 벌겋게 달아오름(面赤), 눈 감고 입 벌려 헐떡임(口渴·氣短), 허리 굽혀 나무 지팡이 1에 기댐(乏力·氣虛), 윗도리 앞섶 풀어헤침
- 땀방울 ≈30 (얼굴·가슴·팔·다리), 소매·팔꿈치·손끝·바짓단에서 떨어지는 물방울 ≈7 → 大汗·傷津
- 주황 아지랑이(열기 선) ≈9 (머리 좌 3·우 2, 허리 좌우 2·2) → 사방으로 오르는 열기(升散)
- 발밑 물웅덩이 1, 진창 길, 바지 무릎 아래 진흙 얼룩, 땅에서 피어오르는 회색 안개 → 濕 동반
- 기운 헝겊 3 (팔꿈치 1·무릎 2) → 가난한 농부·노동
- 초가집 1(문 닫힘·인물은 바깥), 나무 1(황록 잎), 관목 2 → 시골 들길 무대

**② 표제어**
- 1순위 **暑邪 (六淫의 暑 — 陽邪炎熱·升散 耗氣傷津·多挾濕)** 70%
- 2순위 **中暑(陽暑, 動而得之)** 20%
- 그 외: 暑濕 / 濕邪 5%

**③ 뜻 모를 것·어색·잘림**
- 땅 안개가 濕(습기)인지 빠져나가는 氣인지 불분명
- 나무 잎이 황록색 — 계절(長夏?) 표시인지 단순 배경인지 모름
- 헝겊 3개가 수를 나르는지 불명
- 해 윗부분과 나무 좌상단이 프레임에 살짝 잘림

(비고: 세 번째 Read가 공용 스크래치 파일명 충돌로 다른 작업자의 그림을 띄워 이 판과 무관했음. 고유 파일명으로 하단 절반을 1회 더 읽어 대체함.)

## 2단계 — 계통 (blind6 사전으로 다시 읽기)

**① 소품 → 글자**
- 해 = 陽, 사람 곁에 크게 뜬 표지 = 병표지 → 이 병증은 陽邪. 햇살이 불꽃 모양 = 熱 → **暑爲陽邪, 其性炎熱**
- 사방으로 솟는 열기 선 9 = 上(머리 위로 솟음)+散(사방으로 흩어짐) → **暑性升散**
- 살갗의 땀방울 = 汗, 떨어지는 맑은 물방울 = 津이 몸 밖으로 → **傷津**; 벌린 어두운 입 = 口(口渴); 지팡이·굽은 허리 = 乏力 → **耗氣** (氣=흰 김은 몸에서 직접 새지 않음, 땅의 회색 안개는 아래 濕으로 읽음)
- 진창 길·안개·웅덩이 = 濕의 갈림 중 「길에 있으면 外濕」 → **暑多挾濕**(熱蒸濕動). 발밑 웅덩이는 자기 몸에서 배어나온 것이 아니라 길의 저지대라 內濕 아님
- 닫힌 문 밖·담 바깥에 선 인물 = 外 → 外感 六淫
- 붉은 얼굴은 사전상 望色 전담이므로 여기선 面赤 증상으로만 취함. 밀짚모자 없으므로 脾 의인화 아님, 단순 환자
- 헝겊 3은 포개지지 않아 久 아님 → 노동·빈농(動而得之)의 배경 소품
- 마른 잎·갈라진 땅 없음(燥 아님), 옆으로 눕는 것 없음(風 아님), 눈송이 없음(寒 아님)

**② 표제어**
- 1순위 **暑邪의 성질과 치병 특징 (陽邪炎熱 · 升散耗氣傷津 · 多挾濕)** 80%
- 2순위 **中暑·陽暑** 12%
- 3순위 **外濕(暑濕)** 5%
- 사전 어휘로 1단계 판독이 더 단단해짐(해=陽·땀=汗·물방울=津·진창길=外濕·문 밖=外가 모두 교과서 暑邪 조항과 1:1 대응).

**③ 잔결**
- 열기 선이 사전의 熱(불꽃)과 모양이 달라 「升散」으로만 읽힘 — 熱 자체는 햇살 불꽃 테두리에 기댐
- 땅 안개: 氣(흰 김)인지 外濕(안개)인지 갈림이 남음
- 황록 잎 나무·헝겊 3개는 사전에 없는 소품
- 프레임 잘림: 해 꼭대기·나무 좌상단 미세하게 잘림
