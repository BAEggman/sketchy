# blind10 / 631 판독

## 1단계 — 생판 (사전 없이)

① 소품 전수
- 노인 1인: 백발 수염·이마 주름 → 노년(老)·연륜 있는 인물
- 흑립(갓) 1개 → 조선 선비·사대부 신분
- 백색 도포 전신(허리띠·늘어진 띠 1줄) → 白色 → 金·肺 배속 추정
- 오른손을 왼가슴(심장 자리)에 얹음, 손 둘레 짧은 빛살 다수 → 胸中의 장(心 또는 肺)·神의 광채
- 왼소매를 걷어 맨팔뚝 전부 노출(위에 아무것도 없음) → 피부(皮)·맥 짚는 자리(寸口)? 불명
- 열린 창 1짝, 창밖 단풍나무 1그루(붉은 잎), 떨어지는 잎 3장(거의 수직) → 秋·金·燥
- 빈 흰 방(무대) → 배경

② 표제어
- 1순위 **폐(肺) 장상 — 秋·白·胸中·皮毛 배속** (40%)
- 2순위 **심(心) — 手按心·빛=神** (20%)
- 3순위 **조선 의인(허준·이제마 류) 인물판** (15%)

③ 뜻 모를 것
- 걷어올린 맨팔뚝(아무것도 얹히지 않음)의 뜻 불명
- 손 둘레 빛살이 「빛」인지 「털」인지 불명
- 노인으로 그린 이유 불명. 프레임 잘림 없음.

## 2단계 — 계통 (사전요약 적용)

사전 어휘로 다시 읽으면 거의 모든 소품이 한 문장으로 모인다.
- 흰 도포 입은 인물 = **肺**(재상). 노인·수염은 재상의 연륜 장식.
- 테 넓은 큰 갓 하나 = **太** → 肺와 묶여 **太陰**(陽中之太陰 / 手太陰).
- 열린 창으로 방 안과 바깥 단풍이 한 덩어리로 이어짐 = **通**, 단풍·낙엽 = **秋** → 「通於秋氣」. 잎이 곧게 떨어지므로 風이 아니라 **燥**(가을의 기)로도 겹쳐 읽힘.
- 걷어올린 맨팔뚝 = **充**의 무대, 그 위에 얹힌 것이 맨살(皮)뿐 → 「其充在皮」.
- 손 둘레에 은빛으로 서는 짧은 선 = **毛**(역광 잔털) + 빛남 = **華** → 「其華在毛」.
- 손을 가슴에 얹음 = 肺의 자리(胸中).

② 표제어
- 1순위 **肺 — 『素問·六節藏象論』 「肺者 氣之本 魄之處也 其華在毛 其充在皮 爲陽中之太陰 通於秋氣」** (60%)
- 2순위 **肺의 오행·장상 배속(秋·燥·白·皮毛·手太陰)** (25%)
- 3순위 **太陰人(사상) / 手太陰肺經** (10%)

판정: 1단계의 「肺」 방향은 맞았고, 사전 어휘(太·通·充·華·毛)로 읽으니 心 가설은 탈락하고 六節藏象論 한 구절로 수렴한다. 사전으로 더 잘 풀린다.

③ 잔결
- 氣(서린 흰 김)·魄 소품이 없어 「氣之本 魄之處」는 그림에 없다.
- 맨팔뚝 위에 「더해진 것」이 없어 充이 비어 보임(皮의 색 경계선도 희미).
- 빛살이 華인지 毛인지 한 소품에 겹침. 노인(주름·백수염)의 뜻 미확정. 잘림·수 오류 없음.
