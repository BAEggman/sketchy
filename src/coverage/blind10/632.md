# 632 판독 기록

## 1단계 — 생판 (사전 없이)

**① 소품 전수와 나르는 사실**
- 무대: 돌로 쌓은 성문 아치 1개. 좌우 위에 성가퀴(톱니) 각 4개씩 → 성벽·성문. 사람이 문 밖도 성 안도 아닌 **문간 한복판**에 서 있다.
- 사람 1명, 정중앙 세로선으로 정확히 반분. 좌(따뜻한 색·주황 옷): 얼굴 붉음, 땀방울 약 10개(얼굴 3·가슴 4·허리 아래 3), 손은 오른쪽 갈비 아래(협늑부)를 누름 → 발열·發汗·胸脇苦滿. 우(찬 색·청회색 옷): 얼굴 창백, 떨림선 약 6묶음(팔 2·몸통 2·다리 2), 이 악묾, 손으로 눈을 비빔 → 惡寒·寒戰·目眩.
- 추: 아치 꼭대기 고리에서 실 1가닥에 매달린 쇠구슬 1개(사람 키의 약 1/8), 구슬도 좌 금색·우 회색 반반, 정확히 몸 중앙선을 지남 → 왔다갔다 흔들리는 추 = **往來**, 두 쪽 사이의 **한복판**.
- 벽 등잔 1개(따뜻한 쪽 벽), 불꽃 켜짐 → 熱 쪽 표지. 샌들 1켤레 → 의미 없음.
- 오른쪽 머리 옆 날리는 물방울 2개 → 땀 또는 눈물(불명).

**② 표제어**
- 1순위 **少陽病(半表半裏證·小柴胡湯證)** 75% — 성문(표·리의 경계)에 반쪽 熱·반쪽 寒 + 추의 往來 = 寒熱往來·半表半裏, 협늑부 손 = 胸脇苦滿, 눈 비빔 = 目眩.
- 2순위 **瘧疾(寒熱往來)** 또는 단순 **寒熱往來** 15%.

**③ 잔결**
- 날리는 물방울 2개의 뜻 불명. 口苦·咽乾·喜嘔는 보이지 않음. 샌들 뜻 불명. 프레임 잘림 없음.
- (작업 메모) 하단 확대 3번째 Read는 스크래치 파일명 충돌로 다른 판의 조각이 떠서 무효 처리 — 추·발 부위는 전체 그림만으로 판독.

## 2단계 — 계통 (사전 어휘로 재독)

**① 소품 재판독**
- 表 = 문 밖 · 裏 = 성 안 · 門 = 문간 → 성문 무대는 등재 기호 그대로. 사람이 문틀 **한복판**(中 = 둘 사이의 한복판)에 서서 성 안 쪽(좌·등잔 켜진 통로)과 문 밖 쪽(우·흰 하늘)에 반씩 걸쳐 있음 → **半表半裏**가 사전 어휘로 바로 조립된다.
- 熱 = 불꽃 → 벽 등잔 불꽃이 熱 표지(손으로 감싼 것이 아니므로 保命 아님). 汗 = 살갗에 맺힌 땀방울 → 좌반신 땀 약 10개 = 發熱·汗出.
- 寒은 등재 기호(눈송이)가 아니라 푸른 색조·떨림선·이 악묾으로만 그려짐 → 惡寒·寒戰. 사전에 없는 변칙 표현.
- 병표지 = 사람 곁에 크게 떠 있는 표지 → 매달린 쇠구슬이 바로 그것. 금·회 반반 = 寒熱이 반반 교대 → **寒熱往來**. 저울추이나 「내리누르지」 않으므로 降이 아니다(갈림 조건 불충족).
- 目 = 눈 → 비비는 눈 = 目眩. 口 기호(어두운 타원)·苦 기호(커피) 없음 → 口苦 미표현. 협늑부 손은 등재 기호 없이 몸짓만 → 胸脇苦滿.

**② 표제어**
- 1순위 **少陽病(半表半裏·小柴胡湯證)** 85% — 表·裏·門·中·熱·汗·병표지 다섯 축이 모두 사전 어휘로 풀리며 한 점에 모인다.
- 2순위 **表寒裏熱** 10% — 성 안(裏) 쪽이 熱, 문 밖(表) 쪽이 寒이라는 배치만 보면 가능하나, 추의 往來와 협늑·눈 소품이 少陽을 가리키므로 열세.
- 3순위 瘧疾 5%.

**③ 잔결**
- 寒이 눈송이 대신 색·떨림선으로 표현된 점(사전 이탈). 머리 옆 날리는 물방울 2개(汗인지 津인지 불명). 샌들 무의미. 잘림 없음.
