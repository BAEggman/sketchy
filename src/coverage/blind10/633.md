# 633 판독

## 1단계 — 생판 (사전 없이)

**소품 전수**
1. 남자 상반신 전체가 붉게 달아오름, 정수리에서 붉은 열기선 3가닥이 곧게 솟고 양옆에 흰 김 2덩이 — 上熱, 기운이 위로 치솟음(氣上撞心).
2. 얼굴 땀방울 5개 — 熱로 인한 汗.
3. 청록 컵을 들고 벌컥 마심(내용물 적갈색, 컵엔 김 없음) — 갈증·물을 자꾸 찾음(消渴).
4. 손을 가슴 한복판에 대고 그 자리에 불꽃이 피어오름(불꽃 가닥 약 6) — 心中疼熱.
5. 반바지엔 서리 결정, 종아리·발은 얼음빛 푸른색(손은 붉음) — 下寒, 발끝 厥冷. 상반신:하반신 = 붉음:푸름이 허리선에서 딱 갈림 → 上熱下寒.
6. 발밑 맑은 물웅덩이(지름이 발 길이의 약 4배) + 옆에 작은 물방울 1 — 下利不止(설사가 그치지 않음).
7. 왼쪽 밥그릇 1개, 곡식 가득인데 손도 대지 않음 — 飢而不欲食.
8. 오른쪽 넘어진 유리병에서 기어나오는 벌레 1마리(웃는 얼굴) — 吐蛔(회충).
9. 오른쪽 위 모래시계 1개(위 회색·아래 노랑, 반쯤 흐름) — 시간 경과·교대(厥熱勝復) 또는 欲解時.

**표제어**
- 1순위: **厥陰病 提綱 — 厥陰之爲病, 消渴, 氣上撞心, 心中疼熱, 飢而不欲食, 食則吐蛔, 下之利不止** (80%)
- 2순위: **烏梅丸證(蛔厥·寒熱錯雜)** (15%)

**뜻 모를 것·어색한 것·잘림**
- 모래시계의 정확한 뜻이 애매(厥熱勝復인지 欲解時 丑~卯인지).
- 厥冷이 발에만 있고 손은 붉어 「手足厥冷」 표현이 반쪽.
- 컵 내용물이 갈색이라 물인지 약인지 불분명.
- 프레임 잘림 없음.

## 2단계 — 계통 (사전 적용)

**사전으로 다시 읽음**
- 「氣 = 흰 김」+「上 = 머리 꼭대기로 곧게 솟음」 → 머리 위 김과 열기선 = **氣上(撞心)**.
- 「熱 = 불꽃」+「中 = 몸 위에서는 한복판」 → 가슴 한복판 불꽃 = **心中疼熱**.
- 「厥 = 검푸르게 언 손발 끝」 → 푸르게 언 발 = **厥**. 「陰 = 얼음 — 갈림: 살아 있는 불과 맞댔을 때만」 → 가슴 불꽃이 살아 있으니 다리 얼음 = **陰**. 두 기호가 합쳐져 **厥陰** 두 글자가 몸에 그대로 쓰여 있다.
- 「寒 — 갈림: 밑에서 밴 서리 = 內寒」 → 반바지·다리에 밑에서 올라온 서리 = 下의 內寒(上熱下寒).
- 「下 = 아래로 쏟아짐」+「津 = 맑은 물방울」 → 발밑 맑은 웅덩이 = **下利不止**.
- 「汗 = 땀방울」 → 얼굴 땀 = 熱 쪽 汗(厥熱勝復의 熱 국면).
- 「補-b = 그릇에 가득 담긴 것 — 담긴 것이 무엇이냐가 뜻을 진다」 → 곡식 가득 그릇에 등 돌림 = **飢而不欲食**(淸의 「맑고 찬 물 한 그릇」이 아님 — 곡식이므로).
- 컵은 淸(맑은 물)도 苦(김 나는 검은 커피)도 아닌 적갈색 → 등재 밖, 그냥 「마신다」 = **消渴**.
- 벌레·모래시계는 미등재 → 벌레 = **蛔**(食則吐蛔), 모래시계 = 「병표지(사람 곁에 크게 뜬 표지)」로서 시간 교대 = **厥熱勝復**(또는 欲解時).

**표제어**
- 1순위: **厥陰病 提綱(厥陰之爲病 — 消渴·氣上撞心·心中疼熱·飢而不欲食·食則吐蛔·下之利不止)** (85%) — 사전 어휘로 厥·陰이 직접 읽혀 1단계보다 확신 상승.
- 2순위: **烏梅丸(蛔厥·寒熱錯雜)** (10%)
- 3순위: 上熱下寒 일반 (5%)

**잔결**
- 모래시계는 사전에 없어 뜻 확정 불가(厥熱勝復 vs 欲解時).
- 손이 붉어 厥이 발에만 성립.
- 컵 내용물 색이 사전 어떤 항목과도 안 맞음.
