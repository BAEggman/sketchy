# blind10 / 634 판독

## 1단계 — 생판 (그림만)

### ① 소품 전수와 나르는 사실
- **거대한 혀** (팔뚝 길이, 보통 혀의 약 4~5배): 가장자리가 붉고(舌邊尖紅) 한복판은 흰 태가 낀 모양(苔薄白). 이 판의 주역 소품 = 설진 소견.
- **얼굴 홍조** (양 볼·이마): 發熱·面赤.
- **입가의 주먹 + 침방울 2개**: 咳嗽(기침).
- **목을 쥔 손**: 咽痛·咽喉 불편.
- **팔 양쪽 떨림선** (왼팔 3줄, 오른팔 2줄) + 찡그린 눈썹: 가벼운 惡寒(微惡風寒).
- **탁자 위 꽃 두 가지(화병 없이 풀어 놓음)**: ① 흰·노란 두 색 꽃 1뭉치 + 잎 2장 = 金銀花(인동) ② 노란 4판화 가지(핀 꽃 7, 봉오리 4) = 連翹(개나리). 둘이 짝 = 銀翹散의 군약.
- **왼쪽 문간 커튼** (고리 4개, 바람에 날리지 않고 늘어짐): 몸의 바깥 가림막 = 表/衛.
- 나무 의자·작은 탁자: 무대 가구.

### ② 표제어
- 1순위 **銀翹散 — 風熱表證(衛分證)의 辛涼透表** (75%)
- 2순위 **衛分證(溫病 衛氣營血辨證의 衛分 단계)** (55%)
- 그 밖: 風熱感冒/風熱犯肺(50%), 桑菊飲(20% — 상엽·국화 없음)

### ③ 뜻 모를 것·어색한 것·잘림
- 커튼 고리 4개가 의미(衛氣營血 4단계?)인지 장식인지 불명.
- 혀가 과도하게 큰 것이 설태 강조인지 舌腫 소견인지 애매.
- 떨림선이 惡寒인지 단순 괴로움 표현인지 그림만으론 갈림.
- 프레임 잘림 없음(모두 액자 안).

## 2단계 — 계통 (사전 어휘로 재독)

### ① 소품 재독
- **문간(門틀) + 사람이 문 안쪽**: 門 = 작은 문간, 表 = 문 밖, 內 = 문 안쪽 → 환자는 안에 있고 병은 문 밖(表)에서 들어옴 = **表證**.
- **커튼 = 가리개**: 惡 = 「해로운 것과 사람 사이에 세워 막은 가리개」 → 惡(싫어함). 커튼이 옆으로 날리지 않으므로 風 기호는 없고, 눈송이도 없음 → 떨림선과 묶어 **微惡寒** 정도로 읽음.
- **열 표지 없음**: 불꽃(熱)·눈송이(寒) 병표지가 떠 있지 않음. 열은 **얼굴 홍조(望色)** 와 **혀 가장자리 붉음(血=붉은 것)** 으로만 실림 → 熱이 표(衛)에만 가볍게 있다는 뜻으로 읽힘.
- **혀 = 舌 + 苔**: 사전의 「혀가 보이면 心」 갈림은 장상(心開竅於舌) 맥락이고, 여기선 혀 위에 이끼(苔)가 낀 설진 판 → **舌邊尖紅·苔薄白**.
- **침방울 2개 = 津(맑은 물방울)**: 기침과 함께 튀는 津 → 咳嗽, 또는 口微渴의 암시.
- **목 쥔 손**: 쇠못(痛)이 없으므로 정식 痛 기호는 아니나 咽喉 부위 지목 = 咽痛.
- **풀어 놓은 두 약재**: 화병 없이 흩어 놓음 = **散**(흩어진 것) → 金銀花+連翹+散 = **銀翹散**.
- 떨림선 = 惡寒의 몸짓; 고리 4개 = 뜻 없음(장식)으로 판정.

### ② 표제어
- 1순위 **銀翹散(風熱表證·衛分證 — 辛涼透表·淸熱解毒)** (80%)
- 2순위 **衛分證(衛氣營血辨證 중 衛分: 發熱·微惡風寒·咳嗽·咽痛·舌邊尖紅·苔薄白)** (60%)
- 3순위 風熱感冒/風熱犯肺 (45%)
- 사전 어휘(門·表·惡·苔·血·津·散)로 1단계 독해가 더 단단히 묶임. 특히 커튼=惡 가리개, 풀어 놓은 약재=散이 새로 풀렸음.

### ③ 잔결
- 風 기호(옆으로 날림)가 없어 「惡風」인지 「惡寒」인지 확정 불가.
- 熱 병표지(불꽃)가 없어 열의 정도는 홍조에만 의존.
- 혀의 과장 크기는 강조로 판정, 腫(팽팽히 부풂)으로는 안 보임.
- 프레임 잘림 없음.
