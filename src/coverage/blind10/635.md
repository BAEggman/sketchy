# 635 판독 기록

## 1단계 — 생판 (사전 없이)

**① 소품 전수와 나르는 사실**
- 초록 비늘갑옷·초록 투구(창끝 + 검은 술 깃)의 수염 난 장군, 정면 직립 → 將軍 = 「肝者 將軍之官」. 갑옷·투구·무대 전체가 초록(靑) = 肝의 色.
- 맨발·맨손, 발톱·손톱이 또렷이 그려짐 → 其華在爪 / 足厥陰이 엄지발가락(大敦)에서 시작 / 肝主筋.
- 눈을 또렷이 뜬 얼굴 → 肝開竅於目.
- 분홍 꽃나무 3~4그루(좌상 1, 좌하 1, 우측 큰 것 1 + 우끝 작은 것) 꽃잎이 왼→오른쪽으로 옆으로 흩날림 → 春(계절) + 風(六氣: 風氣通於肝).
- 초록 언덕·초록 들판 → 木·東方 靑色.
- 나무 탁자 위 접시에 초록 자두/매실 약 9알 → 酸味(酸入肝) 또는 五果의 李.
- 밭이랑의 새싹(길쭉한 풀잎, 두 줄 약 13포기 + 우측 약 8포기 = 약 21포기) → 五穀 麥(보리싹) 또는 五菜 韭(부추).
- 크기 대비: 장군이 화면 높이의 약 3/4, 탁자는 장군 키의 약 1/4.

**② 표제어**
- 1순위 **肝 — 오행(木) 배속·將軍之官(靑·春·風·酸·爪·目·麥/韭)** 70%
- 2순위 **五味 酸入肝 / 風氣通於肝(단일 배속 구절)** 15%
- (기타) 大黃=將軍 5% — 봄·초록·매실이 안 맞음.

**③ 뜻 모를 것·어색한 것·잘림**
- 밭의 새싹이 麥인지 韭인지 구별 불가(둘 다 肝 배속이라 결론은 같음).
- 접시 위 열매가 李(자두)인지 梅(매실)인지 애매.
- 회색 속옷·바지, 투구의 검은 술 깃은 뜻을 모르겠음(장식으로 보임).
- 프레임 잘림 없음. 우측 하단에 희미한 별/반짝임 자국 하나 — 의미 불명.

## 2단계 — 계통 (사전 적용)

**① 사전 어휘로 다시 읽기**
- 「초록 비늘갑옷 장군 = 肝」 — 사전 확정 기호. 생판 판정과 일치.
- 「접시 위의 초록 매실 = 酸」 — 탁자 위 접시의 초록 열매 약 9알은 酸이다. 허리춤 자두(李 姓)가 아니라 접시 위이므로 성씨 李가 아님 → 五味 酸.
- 「風 = 옆으로 눕고 흘러 날리는 것」 — 꽃잎이 옆으로 흘러 날리고 나무가 옆으로 기울었으니 조건 충족 → 風.
- 「爪 = 손톱」 — 맨손·맨발의 손톱·발톱이 그려짐 → 其華在爪.
- 「目 = 크게 뜬 눈」 — 눈이 열려 있으나 특별히 크지 않음 → 약한 目 신호(開竅於目).
- 筋(갈색 힘줄 다발)·痛·熱 등 병증 기호 없음 → 병증판이 아니라 생리·배속판.
- 사전에 없는 소품: 분홍 꽃나무(春), 초록 무대(靑), 밭의 새싹(麥 또는 韭) — 이 판 고유 소품.

**② 표제어**
- 1순위 **肝의 五行(木) 배속 — 將軍之官·酸·風·春·靑·爪(·目·麥/韭)** 78%
- 2순위 **肝者 將軍之官 謀慮出焉(靈蘭秘典論 단일 구절)** 12%
- 3순위 酸入肝 / 風氣通於肝 단일 구절 7%

사전 어휘로 酸과 風이 확정 기호로 풀리면서 1단계 판정이 더 굳어졌다. 1단계 답을 바꿀 이유 없음.

**③ 잔결**
- 새싹(麥/韭)·꽃나무(春)는 사전 미등재 소품이라 뜻을 추정으로만 둠.
- 열매 수(약 9)·새싹 수(약 21)에 특별한 수 의미가 있는지 알 수 없음.
- 투구의 검은 술 깃·회색 속옷은 여전히 뜻 불명. 잘림 없음.
