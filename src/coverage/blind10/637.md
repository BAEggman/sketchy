# 637 판독 기록

## 1단계 — 생판 (사전 없이)

**① 소품 전수**
- 인물 2명(상투·맨발). 왼쪽: 청록 저고리, 평온한 얼굴로 곧게 섬. 오른쪽: 황토색 저고리, 허리를 굽히고 두 손으로 배를 감쌈, 찡그린 얼굴, 콧구멍에서 맑은 콧물 2줄기 → 腹痛 + 淸涕(분비물 淸稀).
- 불 2개: 왼쪽 큰 불(장작 4개, 사람 허리 높이) / 오른쪽 작은 불(장작 3개, 얼음의 약 1/3).
- 얼음 2개: 왼쪽 작은 각얼음(큰 불의 약 1/4) / 오른쪽 큰 얼음 기둥(작은 불의 약 3배).
- 왼쪽 발치: 나무 대접 안에 마르고 갈라진 덩이 1개 → 大便乾結(燥). 붉은 질항아리에 노란 액체(절반쯤) → 小便黃(短赤).
- 왼쪽 = 불 大·얼음 小 = 陽盛→熱(大便乾·小便黃). 오른쪽 = 얼음 大·불 小 = 陰盛→寒(腹痛·淸涕). 좌우 대칭 구도.

**② 표제어**
- 1순위 **陰陽偏盛(陽勝則熱·陰勝則寒)** 45% — 양쪽 다 불+얼음을 쌍으로 두고 크기 비를 뒤집은 것이 결정적.
- 2순위 **寒熱辨證(八綱 熱證·寒證 감별)** 35% — 발치 소품이 熱證(便乾·尿黃)·寒證(腹痛·分泌物淸稀)의 교과서적 감별점.
- 3순위 六淫 寒邪·火邪 10%.

**③ 잔결**
- 왼쪽 인물이 熱證인데 얼굴이 평온하고 面赤·汗 등 열 표지가 없음(어색).
- 대접 속 덩이가 大便인지 음식·흙덩이인지 단독으로는 애매. 콧물이 코에서 입까지 흘러 涕인지 涎인지 경계가 겹침.
- 프레임 잘림 없음.

## 2단계 — 계통 (사전 어휘로 재독)

**① 재독**
- 얼음은 「살아 있는 불과 맞대어 놓였을 때만 陰」— 양쪽 모두 불이 살아 있으므로 얼음=陰, 불=陽. 눈송이가 없으니 寒 글자가 아니라 陰 글자다 → 寒熱 판이 아니라 陰陽 판으로 읽힘.
- 「병표지 = 사람 곁에 크게 떠 있는 표지 = 그 사람의 병증」: 왼쪽 큰 불 = 陽盛의 熱病, 오른쪽 큰 얼음 = 陰盛의 寒病. 작은 쪽은 「衰(타다 남아 작아진 것)」·「虛(1/3)」로 상대편이 꺾인 모습 = 陽勝則陰病·陰勝則陽病.
- 갈라진 덩이 = 「燥 = 갈라진 땅」→ 陽盛이 津液을 말림(傷陰·燥). 노란 물이 줄어든 항아리 = 「요강(양·색이 사실)」= 小便短黃, 또는 「졸아드는 고인 물 = 陰」(陰 소모) — 둘 다 왼쪽을 熱→傷陰으로 수렴.
- 콧물 = 「津 = 맑은 물방울」이 鼻에서 흐름 = 淸涕(寒의 分泌物淸稀). 배를 감싼 손 = 腹痛(단, 痛의 쇠못 글자는 없음).

**② 표제어**
- 1순위 **陰陽偏盛(陽勝則熱, 陰勝則寒 / 陽勝則陰病, 陰勝則陽病)** 55%
- 2순위 **寒熱辨證(熱證·寒證)** 25%
- 3순위 **陰陽偏衰(陰虛則熱·陽虛則寒)** 12% — 작은 쪽이 1/3이라 虛로도 읽히나, 큰 쪽이 과장되고 증상이 實 계열(淸涕·燥結)이라 偏盛이 우세.

**③ 잔결**
- 大便 전담 글자(손잡이 뒷간통)가 아니라 나무 대접이라 「大便乾」과 「燥」 사이에서 갈림.
- 痛 글자(쇠못) 없이 몸짓만으로 腹痛을 나르는 점. 왼쪽 인물 얼굴에 熱 표지 없음.
- 수 오류·프레임 잘림 없음.
