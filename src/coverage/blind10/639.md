# 639 판독 기록

## 1단계 — 생판 (그림만 보고)

**① 소품 전수**
- 무대: 성벽·성문(총안 있는 탑 2기 + 가운데 아치 나무문, 문고리 2개, 문 닫힘). 두 사람 모두 **성문 밖**에 서 있음 → 外·表(겉).
- 바람줄기 약 6가닥(소용돌이 꼬리 2개), 양쪽 사람 다 맞음 → 風邪 / 惡風寒.
- 왼쪽 남자(청회색 얇은 홑옷, 맨다리·샌들): 이마·뺨 땀방울 3개, 팔뚝에 흘러내리는 푸른 물줄기, 눈 감고 찡그림, 한 손은 목덜미(頭項強痛), 다른 손에 **붉은 갈색 속 빈 나무가지 6~7개 = 桂枝**.
- 오른쪽 남자(두꺼운 황색 솜옷+붉은 목도리+바지+장화): 몸 둘레 떨림표 약 5개(오한), 얼굴에 땀 없음, 한 손 목덜미, 다른 손에 **마디진 초록 줄기 5~6개 = 麻黃**. 팔뚝에도 같은 푸른 길쭉한 것(고드름? 땀?).
- 키·소품 크기는 좌우 거의 1:1 대칭 — 두 증을 나란히 비교하는 구도.

**② 표제어**
- 1순위 **太陽病 中風(桂枝湯證)·傷寒(麻黃湯證) 감별** — 70%. 성문 밖=表證, 바람=惡風, 땀+홑옷=汗出·表虛·脈緩, 오한+솜옷+무한=無汗·表實·脈緊, 목덜미=頭項強痛.
- 2순위 **桂枝湯 vs 麻黃湯(辛溫解表 처방 감별)** — 55%.

**③ 뜻 모를 것·어색함**
- 양쪽 팔뚝의 푸른 길쭉한 물건이 동일 모양: 왼쪽은 땀줄기로 읽히나 오른쪽은 無汗이어야 하므로 모순. 손목 자리라 脈(緩/緊)일 가능성도.
- 성문이 닫혀 있는 이유 불명(腠理 開闔? 太陽爲開와는 어긋남). 프레임 잘림 없음.

## 2단계 — 계통 (사전 어휘로 재독)

**① 재독**
- 表 = 문 밖 / 外 = 담 바깥 → 성문 밖에 선 두 사람 = **表證·外感**. 裏(성 안)는 비어 있음 → 裏證 없음.
- 風 = 옆으로 눕고 흘러 날리는 것 → 수평 바람줄기 6가닥은 사전 글자 그대로 **風**.
- 汗 = 살갗에 맺힌 땀방울 → 왼쪽 얼굴의 땀방울 3개 = **汗出(自汗)**. 오른쪽 얼굴엔 없음 = 無汗.
- 寒 = 눈송이인데 눈송이가 없다 → 오른쪽의 추위는 寒邪 글자가 아니라 떨림·목도리·솜옷으로 그린 **惡寒(증상)**.
- 虛 = 1/3로 줄어든 것 / 實 = 팽팽하게 찬 것 → 얇고 펄럭이는 홑옷 vs 팽팽한 솜옷 = 表虛/表實 대비(준글자 수준).
- 充 = 걷어올린 맨팔뚝 위에 더해진 것 → 왼쪽 맨팔뚝의 푸른 것은 「충」으로도 읽히지만(衛氣充皮膚), 오른쪽은 소매 위라 조건이 안 맞음. 결국 땀줄기(좌)/고드름 혹은 脈(우)로 남김.
- 門 = 작은 문간인데 여기 문은 큰 성문 → 門 글자가 아니라 무대(藩籬=太陽主表)의 일부.
- 약재 식별: 붉은 속빈 가지 = 桂枝, 마디 초록 줄기 = 麻黃 — 사전 밖이지만 실물 묘사로 확정.

**② 표제어**
- 1순위 **太陽病 表證 — 中風(桂枝湯證: 汗出·惡風·脈緩) vs 傷寒(麻黃湯證: 無汗·惡寒·脈緊)** — 75%.
- 2순위 **表虛證 vs 表實證(八綱 表證 감별, 自汗/無汗)** — 55%.
- 3순위 衛氣 기능(充皮膚·司開闔) — 15%.

**③ 잔결**
- 오른쪽 팔뚝의 푸른 물건(無汗과 모순; 脈緊 표시일 수도). 寒 글자(눈송이)·惡 글자(가리개) 미사용. 桂枝 6~7개/麻黃 5~6개로 처방 약미수(5/4)와 일치하지 않음.
