# 641 판독

## 1단계 — 생판 (사전 없이)

① 소품 전수
- 배경: 성벽·성탑(큰 탑 2기, 양쪽 성벽, 뒤쪽 낮은 성가퀴 1줄) → 성 안 무대.
- 해 1개(머리 위, 톱니 광선) → 熱·陽.
- 왼쪽 남자(청회색 옷, 가슴 풀어헤침): 얼굴 붉음·땀 줄줄, 큰 항아리 1개를 들고 들이켬 — 입에서 물이 콸콸 넘침, 다른 손목에서도 물이 폭포처럼 쏟아짐(손목=脈 자리 → 洪大). 가슴·배에도 땀방울. → 大熱·大汗·大渴(引飲)·脈洪大 = 四大證.
- 오른쪽 남자(황토색 옷): 얼굴 붉음, 머리 둘레로 튀는 땀방울 6개, 이 악물고 찡그림, 두 손으로 팽팽히 부푼 배(배꼽 보임)를 움켜쥠 → 腹滿硬痛·拒按·潮熱汗出. 발밑 땅이 갈라져 마름 → 燥屎·便秘. 곁에 뚜껑 덮인 쇠솥 1개 → 煎藥(承氣湯) 또는 胃(腑).
- 나무 걸상 2개, 샌들 4짝(두 사람 모두 앉음).

② 표제어
- 1순위: **陽明病(傷寒論) — 經證(白虎湯證)과 腑證(承氣湯證)의 대비** 55%
- 2순위: **暑病(傷暑·中暑)** 20% — 해·땀·갈증은 맞지만 腹滿·갈라진 땅은 안 맞음.
- 3순위: **白虎湯證 四大證** 단독 15%.

③ 뜻 모를 것·어색한 것
- 쇠솥의 뜻이 불확실(약탕관인지 胃인지). 왼손목에서 쏟아지는 물이 脈洪大인지 단순히 흘린 물인지. 성벽이 무엇을 나르는지(腑? 裏?) 생판으로는 미확정. 프레임 잘림 없음.

## 2단계 — 계통 (사전 적용)

① 소품 재독
- 성벽 = **裏**(성 안) → 裏證. 해 = **陽** → 陽+裏 = 陽明 裏熱. 불꽃(熱 글자)은 없음 — 열은 해·붉은 얼굴·땀으로만 전달.
- 두 사람 살갗의 땀방울 = **汗** → 汗出(왼쪽 大汗, 오른쪽 潮熱汗出).
- 왼쪽 입·손목에서 넘쳐 쏟아지는 맑은 물 = **盛**(넘쳐 흘러나옴)+**津**(맑은 물방울) → 熱盛·津液 외출; 손목 넘침 = 脈洪大. 항아리 물 = **淸**(맑고 찬 물)로도 읽혀 經證의 治法 淸法(白虎湯)을 암시. 물이 아래로 쏟아짐 = **下**로도 읽히나 왼쪽 인물이라 어색.
- 오른쪽 팽팽한 배 = **實**(팽팽하게 찬 것) → 胃家實·腹滿. 발밑 갈라진 땅 = **燥** → 燥屎(자기 발밑이라 內燥 쪽). 痛 글자(쇠못)는 없어 찡그림은 표정일 뿐.
- 쇠솥: 사전에 없음(補의 「따뜻한 국물 그릇」도 아님) → 承氣湯 煎藥 또는 腑(胃) 추정 유지.
- 大(둘 중 하나가 두 배) 구도는 없음 — 四大의 「大」는 글자로 안 짓고 양으로 표현.

② 표제어
- 1순위: **陽明病 — 經證(白虎湯證: 大熱·大汗·大渴·脈洪大) vs 腑證(承氣湯證: 腹滿·燥屎·潮熱)** 65% — 裏(성)+陽(해)+實(배)+燥(땅)+汗이 모두 陽明 裏熱實證으로 수렴.
- 2순위: **陽明病 治法 감별 — 淸法(白虎湯)·下法(承氣湯)** 20% (항아리 맑은 물=淸, 솥=煎藥 承氣湯으로 읽을 때).
- 3순위: **熱盛傷津(津液 손상→燥)** 10%.

③ 잔결
- 쇠솥 전담 글자 없음. 熱 글자(불꽃)·痛 글자(쇠못) 부재. 손목 물줄기가 脈洪大 전용 기호인지 미확정. 프레임 잘림 없음.
