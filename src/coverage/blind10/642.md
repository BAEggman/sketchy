# blind10 / 642 판독

## 1단계 — 생판 (사전 없이)

**① 소품 전수**
- 왼쪽 이정표: 화살표 팻말 약 8개(좌 5·우 3) → 여러 갈래·分科 또는 周遊.
- 나무 단(계단 2단) 위 푸른 도포 선비가 죽간 두루마리를 읽고, 아이 6명이 듣는다 → 교육·弟子.
- A자 입간판에 그릇 3개(병·단지·사발) → 약방·三品?
- 큰 나무의 거대한 둥지(남자 키의 3배)에 알 5개(줄무늬·점·모자이크·금 간 것), 상투 남자가 둥지 곁에 섬 → 有巢氏?
- 버드나무 꼭대기의 대머리 승려가 흰 천(작은 것 4장+큰 것 1장)을 빨랫줄에 넘 → 帛書?
- 운하·돌다리 1, 붉은 문 1, 문 옆 빈 나무 게시판 1, 배경 황기와 궁궐.
- 갈색 옷 아이 1 + 궤짝 2(하나 닫힘·하나 열려 금화와 새 날개) → 金匱?
- 성벽 망루 위 왕관 쓴 왕: 횃불 1 + 죽간 1 → 焚書(秦始皇)?
- 오른쪽 정자 안 왕관 쓴 왕: 얼음 블록 3개 탁자, 죽간 두루마리 약 3개 + 붓 → 漢(寒) 醫書 정리?

**② 표제어** — 1순위 **秦漢시대 의학사(焚書·帛書·漢代 醫書)** 40% · 2순위 **醫藥의 起源(有巢氏·燧人氏) / 扁鵲** 20%.

**③ 잔결** — 승려와 빨래, 둥지 속 알 5개, 입간판 그릇의 뜻이 불명. 문 옆 빈 게시판 불명. 오른쪽 가장자리 횃불·정자가 프레임에 잘림.

## 2단계 — 계통 (사전 적용)

「王=왕관(어느 王인지는 무대가 진다)」「大=둘 중 하나가 두 배」「上=꼭대기로 솟음」「外=담 바깥」으로 다시 읽으니 무대는 **隋唐**이다.
- 둥지(巢)+알(病源·候) 속 남자 = **巢元方 諸病源候論**(隋, 50卷·1720候; 알 5=50卷?).
- 버드나무(楊) 꼭대기(上) 승려(善) + 흰 천 = **楊上善 黃帝內經太素** — 작은 천 4장 대 큰 천 1장(두 배) = 太素.
- 아이(孫)+금궤 2(千金) 중 하나에 날개(翼) = **孫思邈 千金要方·千金翼方**.
- 담 바깥(外) 망루(臺)의 王이 횃불(燾)에 비춰 두루마리 = **王燾 外臺秘要**.
- 얼음(冰) 탁자의 王이 죽간에 붓 = **王冰 素問 次注(七篇大論 보입)**. 얼음은 불과 맞대지 않아 陰이 아니라 글자 冰.
- 단 위 선비+아이 6+이정표 8갈래 = **唐 太醫署 분과 의학교육**(醫·鍼·按摩·咒禁, 體療·瘡腫·少小·耳目口齒·角法).
- 그릇 그림 입간판 = **新修本草 藥圖·圖經**(659, 최초 국가약전) 또는 陶弘景(陶=그릇).

**② 표제어** — 1순위 **隋唐 의학사(巢元方·楊上善·孫思邈·王燾·王冰·太醫署)** 80% · 2순위 **魏晉南北朝~隋唐 醫書(陶弘景 포함)** 12%.

**③ 잔결** — 입간판 그릇 3개의 정확한 글자 불명(新修本草 vs 陶弘景). 문 옆 빈 게시판 뜻 불명. 알 5개·얼음 3개의 수 의미 미확인. 오른쪽 가장자리 횃불·정자 잘림.
