# blind10 / 643 판독

## 1단계 — 생판 (다른 자료 없이)

① 소품 전수
- 인물 2명이 나란히 섬. 좌: 얼굴 둥글고 살집 있음, 옷 여며 입음, 바지 종아리 길이. 우: 얼굴 야위고 주름, 옷 앞이 열려 갈비뼈 드러남(형체 소수), 바지 긺. 둘 다 맨발, 상투.
- 좌 인물 발밑: 큰 얼음(불의 약 2배) + 작은 모닥불 + 갈색 솥(鼎) 1개. → 寒 > 熱 (陽虛則寒 / 陰盛).
- 우 인물 발밑: 큰 모닥불(얼음의 약 2.5배) + 작은 얼음. → 熱 > 寒 (陰虛則熱 / 陽亢).
- 좌 인물 오른손: 계피(桂) 막대 묶음 약 4개 + 검은 덩어리 1개(附子 또는 熟地黃으로 추정). 왼손 바닥: 작은 흰 원반 1개(환약? 동전?).
- 우 인물 오른손: 붉은 구슬 6개(六 → 六味地黃丸 암시; 혹 枸杞子·山茱萸). 왼손 빈손.
- 두 인물 체형 대비: 肥(좌) vs 瘦(우) — 「肥人多寒濕, 瘦人多火」.

② 표제어
- 1순위: **음허·양허(陰虛則熱·陽虛則寒)와 補法 — 壯水之主以制陽光 / 益火之源以消陰翳** (육미지황환·팔미지황환 대비) — 50%
- 2순위: **음양의 편쇠(陰陽偏衰)·陰病治陽 陽病治陰 치칙** — 30%
- 3순위: 팔미지황환(腎氣丸) vs 육미지황환 처방 대비 — 15%

③ 뜻 모를·어색·잘림
- 좌 인물 왼손의 흰 원반 1개: 환약인지 동전인지 불명.
- 갈색 솥: 불 옆에 있으나 불 위가 아님 — 釜(脾胃)·命門火 암시인지 단순 약탕관인지 불명.
- 검은 덩어리가 附子인지 熟地黃인지 판별 불가.
- 화면 중간(허리 높이) 가로로 번진 띠가 양쪽 인물을 가로지름 — 렌더링 결함/프레임 이음 흔적.

## 2단계 — 계통 (blind6 사전 어휘로 재독)

① 소품 재독
- 얼음 = 陰 (갈림 조건 충족: 양쪽 다 살아 있는 불과 맞대어 놓임) · 불 = 陽. 두 사람 곁에 크게 떠 있는 불·얼음 = 「병표지」= 각자의 병증.
- 虛 = 삼분의 일로 줄어든 것: 좌의 불은 우의 불의 약 1/3 → **陽虛**(좌). 우의 얼음은 좌의 얼음의 약 1/3 → **陰虛**(우). 大 = 같은 것 둘 중 하나가 두 배: 좌 얼음 2배(陰 상대적 盛 → 寒), 우 불 2.5배(陽 상대적 亢 → 熱). 사전으로 「陽虛則寒·陰虛則熱」이 바로 풀린다.
- 솥 = 補(그릇에 찰랑 찬 따뜻한 국물, 불 곁에 있어 따뜻함) — 좌(陽虛) 쪽에만 있어 溫補·補陽 축. 補-b 갈림: 담긴 것이 무엇인지는 불명(맑은 국물).
- 좌 손의 검은 덩이 = 地黃(검붉은 뿌리 조각)에 가장 가깝다(혹은 포附子) + 계피 = 桂·地黃 → 桂附地黃丸(八味·腎氣丸) 계열 = 益火之源 / 陰中求陽.
- 우 손의 붉은 구슬 6개 = 血(붉은 것)·六 → 陰血을 채움, 六味地黃丸 = 壯水之主. 瘀(손에 쥔 검붉은 알갱이)로 읽을 수도 있으나 매끈한 구슬이라 血/六味가 더 자연스럽다.
- 우의 드러난 갈비뼈 = 骨(흰 뼈, 곧은 능선) 노출 → 형체 소수(陰虛 瘦).

② 표제어 (사전 어휘로 1단계가 더 또렷해짐)
- 1순위: **陽虛則寒·陰虛則熱 — 虛寒·虛熱 변증과 補法(益火之源以消陰翳 / 壯水之主以制陽光)** — 55%
- 2순위: **補陽·補陰 처방 대비 — 八味(桂附)地黃丸 vs 六味地黃丸 (陰中求陽·陽中求陰)** — 25%
- 3순위: 陰陽偏衰 총론(盛·虛 네 갈래 중 虛 두 갈래) — 10%

③ 잔결
- 좌 왼손의 흰 원반 1개: 사전에 없음(丸약? 동전?) — 미해독.
- 솥이 좌에만 있고 우에는 補 그릇이 없는 비대칭 이유 불명.
- 검은 덩이 附子/地黃 미확정 · 허리 높이 가로 번짐 띠(렌더 결함).
