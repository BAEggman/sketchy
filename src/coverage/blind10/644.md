# 644 판독 기록

## 1단계 — 생판 (사전 없이)

**① 소품 전수와 나르는 사실(추정)**
- 왕관 쓴 남자가 혈자리 점선이 찍힌 **동인(銅人) 입상**을 잡고 있음(혈 점선 세로 열 약 10줄) → 침구·동인(王惟一 銅人 / 침구 전문서). 왕관=王(성씨) 또는 임금 명.
- 그 뒤 가게: 종이·책 뭉치 약 8더미, 작업대 위 조각칼·판목 → 목판/활자 **간행**(校正醫書局 또는 내의원 간행).
- 푸른 깃발 2, 적황 깃발 1(상점 표식, 뜻 불명).
- 새(참새류) 1마리가 노란 **돈주머니**를 물고 **요람 속 아기** 곁에 섬 → 錢(돈)+小兒 = 錢乙 소아약증직결? 또는 새=新, 아기=幼(及幼方).
- 누더기 걸인이 수첩에 **메모** → 惠民(빈민)+方 기록 = 太平惠民和劑局方 / 혜민서·활인서 / 經驗方.
- 사모·관복 관리, 목에 **금메달**, 눈 감고 두꺼운 책(책갈피 3) 앞에 앉음 → 金(금)+禮(관복)+蒙(눈감음)=金禮蒙·醫方類聚(가장 두꺼운 365권)? 또는 太平聖惠方·聖濟總錄.
- 금메달 걸고 **손거울**에 **혀**를 내미는 남자 → 혀=許, 금메달=寶, 거울=鑑 → **許浚 東醫寶鑑**.
- 대나무 장대 약 6개를 X자로 묶어 끄는 짐꾼 → 交+木=校(교정) 또는 聚(모음)·묶음.
- 창가 여인과 손을 입에 댄 아이 → 婦人/胎産(태산요록·부인대전양방).
- 우측 가게: 선반에 도자기 항아리 약 10, 유리장에 사발 3, 팔짱 끼고 어두운 안쪽에 앉은 **왕관 노인** → 王+懷(품)+隱(숨음)=王懷隱(太平聖惠方)? 또는 탕액·약항아리.
- 벽에 널어 말린 긴 국수 가닥(약 25가닥) → 국수=國手? 經(실)?
- 비 온 길·물웅덩이를 놀라서 뛰는 아이 2 → 救急(급함)/洗冤?
- 두 갈래 **이정표**(화살 2) → 類(갈래)/直指/擇.
- 오른쪽 끝 회색 **천막** 군집(약 7동) → 전쟁(임진왜란)/활인서 막사/陳(진영).

**② 표제어**
- 1순위: **조선 의학사 — 의서 편찬(의방유취·동의보감)** 40% (許·寶·鑑 말장난, 천막=임진왜란, 간행 가게, 두꺼운 책)
- 2순위: **송대 의학사(王惟一 銅人·錢乙·校正醫書局·惠民和劑局方)** 30% (왕관=王, 돈주머니+아기=錢乙, X자 나무=校, 걸인=惠民)

**③ 뜻 모를 것·어색함·잘림**
- 깃발 3개(청2·적황1)의 뜻 불명. 널린 국수 가닥의 뜻 불명. 도자기 가게가 약방인지 불명.
- 금메달이 두 사람(관리·거울 남자)에게 중복 — 한 글자(寶/金)인지 '어의'인지 갈림.
- 눈 감은 관리의 뜻(蒙/平/睡) 불확정. 오른쪽 천막이 프레임에 잘림. 두 아이가 뛰는 이유(비·급함) 불확정.

## 2단계 — 계통 (사전 적용 후)

**① 사전 어휘로 다시 읽은 소품**
- 왕관 2개 = **王** 두 사람(사전: 성이 王, 어느 王인지는 무대가 짐). 무대에 銅人·醫書 간행·소아·부인이 함께 서므로 무대=**宋**. 左 王+혈 점선 銅人 = **王惟一 銅人腧穴鍼灸圖經(1027)**.
- 右 老王 + 유리장의 **빈 사발 3**(사전 惠=여러 손이 받아 드는 빈 사발) + 팔짱(懷)·어두운 안쪽(隱) = **王懷隱 太平聖惠方**. 선반 3층(사전 官=가구의 가운데 층) → 官 편찬·官局.
- 사모 관리의 검은 큰 갓(사전 太=테 넓은 큰 갓) + 눈 감은 평온(平) + 두꺼운 책(100권/200권) = **太平**聖惠方·聖濟總錄 계열; 금메달=聖(미등재, 추정).
- 걸인의 수첩 = 民+錄 → **太平惠民和劑局方**(局=官 선반) 또는 總錄.
- 새(乙=제비 글자꼴)+돈주머니(錢)+요람 아기(小兒) = **錢乙 小兒藥證直訣**; 두 갈래 이정표 = 直(直訣/直指).
- X자로 묶어 끄는 대나무 = 木+交=校 → 종이·판목 가게와 함께 **校正醫書局(1057) 醫書 간행**.
- 창가 여인(아이의 약 2배 크기: 사전 大) + 아이 = **婦人大**全良方(陳自明); 오른쪽 회색 천막 군집 = 陳(陣) → 陳自明·陳無擇.
- 길 위 진창·물웅덩이(사전 外濕=길의 진창)를 놀라 뛰는 아이 2 = 外因(六淫)·內因(驚)·불내외인(달림) → **陳無擇 三因方**의 세 원인; 이정표=擇(가림).
- 한 밧줄에 매달린 국수 가닥 약 25 = 사전 **衆**(한 밧줄에 여럿 매달림) → 惠民(民衆)·普濟의 '뭇사람'.
- 혀 내민 거울 남자: 사전 舌=心은 장상 전담이라 무대에 안 맞음 → 혀=許 말장난 유지, 宋이면 **許叔微**, 金거울은 미등재(鑑/鏡).

**② 표제어**
- 1순위: **송대 의학사(宋: 王惟一 銅人·太平聖惠方·校正醫書局·錢乙·陳自明·陳無擇)** 55% — 王 2명·太·惠·官·大·外濕이 사전 그대로 들어맞고 무대가 宋 의서 목록과 1:1.
- 2순위: **고려·조선 의학사(濟衆·惠民局·許浚 東醫寶鑑)** 25% — 衆(국수 밧줄)+웅덩이 밧줄=濟衆, 혀=許·거울=鑑, 천막=임진왜란으로도 읽히나 王 두 사람과 銅人이 설명되지 않음.

**③ 잔결**
- 금 손거울+혀의 글자(鑑/鏡/許) 미확정, 금메달 2개(聖?)는 사전에 없음.
- 깃발 3(청2·적황1)과 국수 가닥의 뜻 불명(衆인지 絲인지). 오른쪽 천막 프레임 잘림.
- 이정표 화살이 2개라 三因의 셋과 어긋남 — 擇(가림)으로 읽으면 해소.
