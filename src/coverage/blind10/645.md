# blind10 / 645 판독

## 1단계 — 생판 (사전 없이)

**① 소품 전수와 나르는 사실**
- 큰 모닥불(장작 약 10개, 큰 불꽃 혀 약 6, 높이 ≈ 사람 허리) + 하늘로 곧게 솟는 연기 기둥(불 높이의 약 2배, 프레임 위까지) → 火熱, 炎上
- 갈라진 마른 땅(온 바닥) + 갈색으로 마른 잎의 나무(잎은 안 떨어짐) → 傷津耗液·旱燥
- 사내: 얼굴 전체가 벌겋다 → 面赤
- 땀방울: 얼굴에 맺힌 것 ≈6 + 튀는 것 4 → 汗出
- 크게 부릅뜬 눈·벌린 입·두 팔 치켜듦·굽은 다리 → 煩躁·狂躁(擾心神)
- 콧구멍에서 흘러 가슴까지 내려온 피 + 떨어지는 핏방울 2 → 衄血(動血)
- 양 팔뚝의 붉은 반점(왼팔 ≈10, 오른팔 ≈8) → 斑疹(迫血妄行)
- 목 옆의 노란 머리 종기 1개 → 癰腫瘡瘍
- 초가집(둔덕 위)·누더기 바지·맨발·오솔길 → 무대 소품(뜻 미상)

**② 표제어**
- 1순위 **火邪(火熱邪)의 성질과 치병 특징** — 65%. 陽邪·炎上(불·연기·팔), 傷津耗氣(갈라진 땅·땀), 動血(衄·斑), 擾心神(부릅뜬 눈·소리침), 致瘡癰(종기)이 다 한 판에 있다.
- 2순위 **暑邪** — 20%. 더위·땀·傷津耗氣는 맞으나 瘡癰·衄血·斑疹은 暑보다 火의 전담이고 해(日)가 없다.
- 3순위 熱入血分(血熱妄行) 10%.

**③ 모를 것·어색·잘림**
- 초가집과 둔덕이 무슨 사실인지 불명. 누더기·맨발도 사실 미상.
- 「生風」 축(경련·흔들림)이 뚜렷하지 않음.
- 왼쪽 나무 꼭대기와 연기 기둥, 오른쪽 초가집 처마가 프레임에 잘림.

## 2단계 — 계통 (사전 어휘로 재독)

**① 어휘로 다시 읽은 소품**
- 熱=불꽃, 陽=불 → 사람 곁에 크게 떠 있는 불꽃은 「병표지」 = 이 사람의 병은 火熱, 「火為陽邪」
- 上=머리 꼭대기로 곧게 솟음 → 연기 기둥·치켜든 두 팔 = 「其性炎上」
- 燥=갈라진 땅·마른 잎 → 바닥 전체의 균열 + 마른 잎 나무 = 傷津. 잎이 날리지 않으니 風은 없다
- 津=맑은 물방울, 汗=살갗에 맺힌 땀 → 맺힌 땀 ≈6 + 밖으로 튀는 물방울 4 = 迫津外泄, 「傷津耗氣」(연기=氣가 위로 빠져나감으로도 읽힘)
- 血=붉은 것 → 鼻(열린 콧구멍)에서 흐르는 피·핏방울 2·팔뚝 반점 ≈18 = 「動血」(衄血·發斑)
- 目=크게 뜬 눈, 口=어두운 구멍(혀 안 보임) → 擾心神(煩躁·狂)
- 腫=부풀어 팽팽한 곳 → 목의 종기 1 = 「易致瘡癰」
- 外=담 바깥 → 초가 둔덕 밖에 선 사내 = 外感 六淫의 邪
- 寒·濕·風 기호 전무 → 六淫 중 火(熱) 단독

**② 표제어**
- 1순위 **火邪(火熱邪)의 치병 특징 — 陽邪炎上·傷津耗氣·生風動血·擾心神·致瘡癰** — 80%. 사전 어휘(熱·陽·上·燥·津·汗·血·腫·目·外)로 다섯 축이 남김없이 풀린다.
- 2순위 **血熱妄行(熱入血分)** — 10%. 血·斑·衄·躁는 맞지만 瘡癰·갈라진 땅까지 품기엔 좁다.
- 3순위 暑邪 5% (日 없음, 濕 없음, 瘡癰 설명 불가).

**③ 잔결**
- 生風 축: 風 기호(옆으로 날리는 것)가 없어 「熱極生風」만 그림에 없다.
- 초가집·누더기·맨발은 外 무대 외에는 뜻 미상.
- 프레임 잘림: 연기 기둥 상단·나무 꼭대기·초가 오른쪽 처마.
