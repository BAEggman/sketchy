# 647 판독

## 1단계 — 생판 (사전 없이)

① 소품 전수
- 돌담으로 둘러싸인 겨울 지하실 무대: 오른쪽 위 창틀에 고드름 6개, 벽에 성에 결정 5개(또렷 4 + 흐릿 1) → 寒·冷 환경.
- 무릎 꿇은 중년 남자 1명: 얼굴 창백·눈 밑 거뭇·힘없는 반웃음(面色㿠白, 무력). 황갈색 도포에 붉은 깃.
- 배: 공처럼 팽팽하게 부푼 배 1(지름이 머리의 약 2배) → 腹脹·腹滿.
- 붉은 천 1을 배 위에 대고 손으로 누름 → 喜溫·喜按(온찜질로 편해지는 虛寒).
- 손잡이 달린 질항아리 1이 쓰러져 묽은 갈색 물이 흘러나옴 → 泄瀉·便溏(묽은 下利).
- 흰 밥이 수북한 사발 1, 손대지 않음 → 食不下·納呆, 또는 完穀不化(下利淸穀의 穀).
- 불·등잔은 화면에 전혀 없음.

② 표제어
- 1순위 **脾陽虛證(脾胃虛寒)** — 45% : 寒 환경 + 腹脹 + 喜溫喜按 + 便溏 + 不食.
- 2순위 **太陰病(腹滿·食不下·自利)** — 25% : 提綱 네 증 중 腹滿·食不下·自利 셋이 보임(吐는 없음).

③ 잔결
- 붉은 천이 「따뜻한 찜질」인지 「붉은 것=血」인지 불명(김이 안 보임).
- 밥그릇이 「못 먹음」인지 「완곡불화」인지 양쪽 가능.
- 통증 표지(못 등) 없음. 프레임 잘림 없음.

## 2단계 — 계통 (사전 적용)

① 소품 재독
- 돌담 「성 안」 = 裏, 벽 안쪽 성에 = **裏寒**(눈송이가 아니라 안쪽 성에이므로 外寒이 아님). 고드름은 「불이 없고 겨울 무대」 조건에 걸려 陰도 寒도 아닌 **凝滯**(寒性凝滯).
- 팽팽하게 찬 배 = 實(滿) 글자 → 腹滿. 몸 한복판이므로 中(中焦).
- 손잡이 달린 통 = 大便 글자, 쓰러져 쏟아짐 = 下·瀉-b(흘러넘친 것이 묽은 갈색 물) → 大便 稀溏·下利.
- 밥 가득한 사발 = 補-b(담긴 것=穀 → 脾胃에 채움) 또는 옆의 묽은 물과 짝지어 下利淸穀의 「穀」.
- 붉은 천 = 溫(따뜻한 천; 김은 희미)·누르는 손 = 喜溫喜按. 붉은 것만 보면 血이나 배 위라 溫이 맞음.
- 脾 농부(밀짚모자)·太 갓·痛 쇠못·厥 언 손발·腎 잠수부는 없음 → 脾·太陰·少陰 글자는 직접 등재되지 않음.

② 표제어
- 1순위 **脾陽虛證(脾胃虛寒 — 腹滿·便溏·喜溫喜按)** — 35% : 中(배) + 裏寒 + 下利 + 溫·補 치법 암시.
- 2순위 **裏寒證(虛寒證)** — 30% : 裏(성 안)+寒(성에)가 글자 그대로 두 겹으로 적혀 있고, 面白·喜暖·便溏·蜷跪가 八綱 寒證 그대로임.
- 3순위 太陰病 15%(太 갓 없음), 理中湯 10%(약재 소품 없음).
- 사전 어휘로 「裏寒」이 더 또렷해졌고, 脾 글자가 없다는 점에서 1·2순위 격차가 줄었다.

③ 잔결
- 고드름 6·성에 5의 수가 뜻을 갖는지 불명.
- 補-b(밥)와 瀉-b(쏟아진 통)가 같이 있어 치법 판인지 병증 판인지 갈림.
- 배가 實(팽팽) 글자인데 喜按(虛)과 상충.
