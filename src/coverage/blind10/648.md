# blind10 / 648 판독

## 1단계 — 생판 (사전 없이 그림만)

① 소품 전수
- 흰 도포·상투 남자 1 — 환자 또는 의원(백의). 손에 갈색 천 1장(땀 닦는 수건 → 汗/盜汗, 또는 그냥 布).
- 황금관·붉은 용포 임금 1 — 心(군주지관). 미간 찌푸리고 주먹을 가슴 한복판에 댐 → 心悸·心煩·胸中 답답.
- 임금 뒤 침상 1(개킨 이불·베개, 비어 있음) → 臥·不寐.
- 넘어진 회청색 물독 1(입구 열림, 속이 비어 마름, 깨지지 않음) → 水·陰液 고갈(독 크기는 사발의 약 3배).
- 사발 1 + 갈라진 흙덩이 1 → 燥(마른 땅)·便乾·口乾, 혹은 灶心土(伏龍肝).
- 세 발 달린 흙 화로 1(문 안에 붉은 불) → 火·熱, 灶.

② 표제어
- 1순위 **心陰虛(陰虛火旺)** 35% — 心煩·不寐·盜汗·口乾 + 불·마른 물독.
- 2순위 **心腎不交(水火不濟)** 25% — 불 화로 ↔ 빈 물독이 바닥에서 마주봄.
- 대안 **伏龍肝(灶心土)** 15% — 화로 + 사발 속 흙덩이 + 용포(龍).

③ 뜻 모름·어색: 흰옷 남자의 정체(환자·의원·肺?)와 천의 뜻이 불명. 흙덩이가 燥인지 약재인지 갈림. 임금 주먹이 心悸인지 心煩인지 불명. 프레임 잘림 없음.

## 2단계 — 계통 (사전 적용 후)

① 사전으로 다시 읽기
- 붉은 곤룡포 임금 = **心**; 주먹이 「가슴 한복판」 = **心煩**(사전 정의 그대로).
- 흰 도포 남자 = **肺**(흰 도포 재상). 손의 천은 김이 없으므로 溫이 아님 — 肺가 든 마른 천(乾咳 손수건?/皮毛?) 미등재.
- 사발 위 갈라진 흙 = **燥**(갈라진 땅, 「접시 위의 ~」 토큰 형식).
- 밑동까지 마른 물독 = **內燥**(津液 고갈) — 깨지지 않았으므로 傷 아님, 1/3 아니므로 虛 아님.
- 화로 속 불꽃 = **熱/火**; 문 안쪽의 불 → 內熱 가능.
- 침상 = 미등재, 心 곁이므로 不寐로 읽음.
- 바닥 삼각: 불(우) — 燥 사발(중) — 마른 물독(좌) = 熱이 津을 말려 燥가 됨. 위층: 心(불·煩·불면) / 肺(燥의 표적 장기).

② 표제어
- 1순위 **燥邪 — 溫燥(燥熱傷肺)** 40% — 燥 토큰 둘 + 肺 + 熱 + 心煩(溫燥 증상).
- 2순위 **火熱邪(擾心神·傷津化燥)** 25% — 心煩不寐 + 津傷 燥.
- 3순위 心火刑肺(火乘金) 15% / 內燥(津傷化燥) 10%.
1단계의 心陰虛·心腎不交는 腎 잠수부가 없고 陰(졸아드는 물)이 아닌 완전히 마른 독이므로 기각.

③ 잔결: 肺의 손에 든 천(김 없음)과 침상이 사전 미등재. 심판 글자 心煩이 燥 판에 왜 들어갔는지 모호 — 溫燥/火邪 갈림의 핵심.
