# blind10 / 650 판독

## 1단계 — 생판 (사전 없이)

**① 소품 전수**
- 인물 1명: 중년 남자, 걸상에 앉아 윗옷(청회색 셔츠)을 활짝 풀어헤쳐 맨가슴·배를 드러냄 → 옷을 벗어젖힘 = 惡熱(열을 싫어함)·身熱.
- 얼굴·가슴·배가 온통 붉게 달아오름 → 身大熱(壯熱).
- 땀: 머리 주위로 튀어 날리는 큰 땀방울 5개 + 이마·뺨에 4개 안팎 + 가슴·배에 8개 안팎 = 大汗出.
- 혀: 입을 벌리고 혀를 길게 내밀어 물그릇에 담금. 혀 몸은 붉고 윗면은 누런 이끼 → 舌紅苔黃.
- 물그릇: 얼굴 너비만 한(≈1.2배) 큰 갈색 사발에 맑은 물이 가득, 혀를 담가 들이킴 → 大渴引飲·渴喜冷飲.
- 옆 탁자: 흰 돌덩이 1개(결 있는 회백색 광물) = 石膏; 그 옆 납작한 노란 낟알 9개 = 粳米. 돌은 낟알의 7배쯤.
- 걸상 1·탁자 1·석판 바닥·맨 벽(배경 소품 없음).

**② 표제어**
- 1순위 **白虎湯 / 陽明經證(四大證: 大熱·大汗·大渴·脈洪大)** — 75%. 열·땀·갈증 셋이 몸으로, 石膏+粳米가 탁자로 그려짐.
- 2순위 **溫病 氣分證(氣分熱盛)** — 12%. 같은 증상군을 衛氣營血로 읽은 경우. 그 외 白虎加人蔘湯 5%(人蔘 없음).

**③ 어색·불명**
- 脈洪大는 그려지지 않음(진맥 소품 없음). 知母·甘草도 없음 — 石膏·粳米만.
- 낟알 9개의 수가 사실(六合)과 대응하는지 불명. 프레임 잘림 없음.

## 2단계 — 계통(글자 사전 적용)

사전의 기호로 다시 읽으면:
- 汗 = 살갗에 맺힌 땀방울 → 가슴·이마의 땀 = 汗. 얼굴에서 밖으로 튀어 날리는 방울은 盛(넘쳐 흘러나옴) → 汗盛 = 大汗出.
- 淸 = 맑고 찬 물 한 그릇 → 남자가 든 큰 사발의 맑은 물은 글자 그대로 「淸」(치법) — 동시에 혀를 담가 마시는 동작으로 渴喜冷飲을 겹쳐 나른다. 그릇이 얼굴 크기라 大渴.
- 舌·苔: 혀가 보이니 心 계열 혀이며 누런 이끼 = 苔黃. 혀 몸 붉음 = 血(붉은 것)=熱 in 氣分.
- 熱 = 불꽃이 화면에 없다. 대신 살갗 전체의 붉음 + 옷을 벗어젖힘이 身熱·惡熱을 진다(望色 방식). 병표지(떠 있는 불꽃)도 없음 → 이 판은 증상을 몸으로만 나른다.
- 石膏(흰 돌)·粳米(낟알 9)는 사전에 없는 신규 소품 — 지황처럼 약재는 실물로 그린다.
- 大(둘 중 하나가 두 배)는 명확한 쌍이 없음. 虛·實·久·寒 기호 없음 → 實熱 단일 축.

사전으로 읽어도 축은 바뀌지 않고 오히려 淸(찬 물 한 그릇)이 치법 글자로 확정되어 「淸熱 — 白虎湯」으로 좁혀진다.

- 1순위 **白虎湯(陽明經證·四大證, 淸熱法)** — 78%
- 2순위 **淸法(八法의 淸 — 淸氣分熱, 대표방 白虎湯)** — 12%; 3순위 溫病 氣分證 7%.

잔결: 불꽃(熱 기호) 부재, 脈洪大 미표현, 知母·甘草 없음, 낟알 9개의 뜻 불명.
