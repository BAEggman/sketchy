# blind10 / 651 판독

## 1단계 — 생판(사전 없이 그림만)

① 소품 전수
- 무대: 청기와 한옥풍 담·지붕(동아시아 궁·관청). 왼쪽 지붕 모서리에 **빈 편액(글 없음)** 1장.
- 왼쪽: 땋은 머리 아이가 입 벌려 노래(음표 5개) + 경사진 나무 책꽂이에 책 3권(흰·파랑·빨강 등).
- 중앙: 무릎 꿇은 아이가 **황금 손거울**(머리의 약 1.5배, 몸통만 함)을 머리 위로 치켜듦, 입이 얼굴 절반만 하게 벌어짐. 앞에 주황 방석 위 초록 옥 받침에 **옥룡 인장(玉璽)**. 뒤로 **백기(흰 깃발) 수십 개**(약 45~50, 가림으로 정확 계수 불가).
- 오른쪽: **왕관** 쓴 아이가 나무를 뿌리째 뽑음(흙더미·뿌리 노출, 나무는 사람 키 2배) + **인체도 족자**(장기·골격·관절).
- 오른쪽 아래: 연못에 황금 **거북**, 등에 놋 촛대와 **촛불** 1개.

나르는 사실(추정): 황금거울=寶鑑, 왕관=왕명(宣祖·光海君), 인체도=身形藏府圖(內景篇 첫머리), 옥룡인장=御命·內醫院 관찬, 나무 뿌리째=鄕藥(향약명 한글 표기·토산 약재), 백기 들판=임진왜란 중 편찬(1596 명·정유재란 중단), 노래+책3=諺解 3書(救急方·痘瘡集要·胎産集要) 또는 3대 조선 인용서(醫方類聚·鄕藥集成方·醫林撮要), 거북+촛불=구(龜)+급한 불=救急方(음차 추정).

② 표제어: 1순위 **東醫寶鑑(許浚)** 50% · 2순위 **許浚 인물판** 30% (기타 醫方類聚 10%).

③ 잔결: 빈 편액의 뜻 모름 · 거북+촛불 조합이 어색함 · 큰 입(고함)의 뜻 불명 · 백기 정확 수 세기 불가(가림) · 왼쪽 책꽂이 밑 술 장식이 방석에 잘림.

## 2단계 — 계통(사전 어휘로 재독)

사전으로 다시 읽으면 전혀 다른 무대가 풀린다.
- **吳 = 얼굴 절반만 한 큰 입** → 중앙 아이는 吳氏. + 황금 거울(金鑑) = **吳謙 『醫宗金鑑』**. 무릎 꿇음 + 옥룡 인장 = 御纂(乾隆帝 칙찬, 太醫院 교재).
- **王 = 왕관(성 王, 어느 王인지는 무대가 짐)** → 왕관 아이는 王氏. 곁의 맑은 연못(淸 = 맑고 찬 물) + 짊어진 거북(任 = 짐을 짊) = **王淸任**. 뿌리째 뽑는 나무 = 醫林의 잘못을 뽑음 = 『**醫林改錯**』, 흙더미 = 의총(義塚)에서 시체 관찰, 인체도 = 親見改正臟腑圖.
- 왼쪽 노래하는 아이 + 책 3권 = 三字 歌訣 → **陳修園 『醫學三字經』**(時方歌括 등 歌括 입문서) — 2안: 醫宗金鑑의 歌訣 체제.
- 연못(淸)·백기 들판(旗 → 八旗, 淸朝 무대 표지) = 시대 = **淸代**.
- 촛불 = 熱(불꽃)로 읽으면 거북+熱+물 → 溫熱 가능성도 있으나 溫(김 나는 천)이 없어 보류, 任으로 읽는 편이 깔끔.
- 빈 편액: 사전에 없음 — 太醫院 현판(이름 없음) 추정, 미확정.
- 1단계의 東醫寶鑑 읽기는 큰 입·왕관(성)·연못을 설명 못 하므로 폐기.

② 표제어: 1순위 **淸代 의학사(吳謙·王淸任·陳修園)** 50% · 2순위 **吳謙 『醫宗金鑑』** 30% · 3순위 王淸任 『醫林改錯』 10%.

③ 잔결: 빈 편액 뜻 미상 · 거북+촛불(任 vs 熱) 갈림 · 노래 아이 성씨 표지 없음(陳 표지 부재) · 백기 정확 수 불명.
