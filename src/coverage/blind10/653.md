# 653 판독

## 1단계 — 생판 (사전 없이)

**① 소품 전수**
- 책장(2단 6칸 + 밑 서랍 1, 위 오른칸은 빈 칸): ⑴ 빛나는 금테 거울이 박힌 책 = 「寶鑑」→ 東醫寶鑑 ⑵ 나무 베개에 침 6개 꽂혀 책 위에 얹힘 = 鍼灸 의서(鍼灸經驗方) ⑶ 붉은 반점 약 15개(큰 7·작은 8) 책 = 痘瘡·麻疹 의서(痘瘡經驗方/麻科會通) ⑷ 표지가 2×2 네 칸 책 = 四象 → 東醫壽世保元 ⑸ 끈으로 묶은 선장본 3권 = 다권 총서(醫方類聚/鄕藥集成方) ⑹ 서랍 1 = 方藥合編?(불확실)
- 웃통 벗은 소년 4명(앞 2·뒤 2): 가슴 벌어짐(胸襟)·목덜미(腦顀)·배 불룩(腰圍)·엉덩이(膀胱) = 四象人 體形氣像
- 갓 쓴 선비가 맥파 두루마리를 봄 = 脈診 의서(纂圖方論脈訣集成)
- 상투 남자가 요람의 아기를 돌봄 = 小兒·胎産(諺解胎産集要/及幼方)
- 지팡이 노인 + 노인 키 3배의 해(굴러 들어온 운동선) = 老人·養老 + 東(해 뜨는 동쪽)

**② 표제어** 1순위 **조선시대 의서 총람(한국 의학사·조선 의서)** 45% / 2순위 **東醫壽世保元·四象醫學(李濟馬)** 35%

**③ 잔결** 빈 칸 1개의 뜻 불명(散佚?). 묶인 3권이 어느 책인지 불명. 노인+해의 결합 의미(東? 壽? 養老?) 불명. 잘림 없음.

## 2단계 — 계통 (사전 적용)

사전에서 **太 = 테 넓은 큰 갓**, **陽 = 해**가 전담 기호로 확정된다. 그러면 오른쪽 세 장면은 책이 아니라 글자다: 갓 선비 = **太**, 해 = **陽**, 해를 등에 진 노인 = **老(陽)** = 太陽, 요람 아기 = **少** → 太陽·少陽·太陰·少陰 四象의 글자 네 벌(陰=얼음은 없음, 老·少 대립으로 대신). 네 소년(四象人 體形: 腦顀·胸襟·腰圍·膀胱)과 四分 표지 책(四象/四端論)이 이를 받친다. 상투 남자(갓 없음)는 太가 아님을 대비로 보여 준다.
책장은 醫源論·제목의 유래로 읽힌다: 거울 책 = 「東醫」寶鑑(許浚, 제목 東醫의 출처), 노인 = 壽世保元(龔廷賢)의 「壽」, 침·반점 책 = 鍼灸·痘疹(醫源論/辨證論이 언급하는 미완 영역), 묶인 3권 = 久(같은 것 셋) 또는 다권. 맥파 두루마리 = 脈(辨證의 보조).
① 소품: 위와 같음(수: 침 6·반점 15·칸 4·권 3·소년 4·해 3배). ② 1순위 **四象醫學·東醫壽世保元(李濟馬)** 50% / 2순위 **조선시대 의서 총람(한국 의학사)** 30%. ③ 잔결: 太 갓 선비가 보는 맥파 두루마리의 역할 불명(太陽人 脈? 脈經?), 빈 칸 1, 묶인 3권의 久/다권 갈림.
