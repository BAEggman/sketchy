# 654 판독

## 1단계 — 생판

① 소품 전수
- 왼쪽 남자(청록 저고리): 얼굴 회청색·창백, 눈 감고 고개 떨굼, 손발 축 늘어짐, 이마 땀방울 6개 안팎(가늘고 적음) → 冷汗·精神萎靡·面蒼白.
- 왼쪽 등잔 1: 불꽃이 심지 끝에 겨우 남아 연기 한 줄 → 陽氣가 꺼져 감(燈油將盡).
- 왼쪽 나무 사발 1: 인삼 1뿌리 + 검은 울퉁불퉁 뿌리 1개(검은 구슬 8알 배어남) → 人蔘 + 附子(또는 熟地黃) = 參附湯 류.
- 오른쪽 남자(주황 저고리): 얼굴·손발 붉음, 눈 뜨고 입 벌림, 온몸에 땀이 줄줄(왼쪽의 5배 이상) → 熱汗·面赤·煩躁.
- 오른쪽 맑은 물 접시 1 → 口渴·喜冷飲.
- 붉은 공 1(꼭지 달림), 위에 작은 것 6: 자두(酸)·커피콩(苦)·꿀방울(甘)·흰 소금더미(鹹)·고추(辛)·갈색 덩이(?) → 五味 → 五味子(生脈散의 약).
- 크기: 붉은 공은 사발 지름의 약 0.6배, 등잔은 사발과 비슷.

② 표제어
- 1순위 **亡陽·亡陰 비교(亡陰亡陽證)** 60% — 左 亡陽(冷汗·蒼白·陽衰 등잔·參附湯), 右 亡陰(熱汗·面赤·口渴·五味子=生脈散).
- 2순위 **汗의 問診 — 自汗(氣虛·陽虛) vs 大汗(實熱)** 20%.

③ 잔결: 검은 뿌리가 附子인지 熟地黃인지 불명. 붉은 공 위 갈색 덩이(6번째)는 五味에 없음. 왼쪽 남자 손발이 「厥冷」으로 보이기엔 푸르지 않음. 프레임 잘림 없음.

## 2단계 — 계통(사전 어휘)

사전으로 다시 읽으면 축이 더 또렷해진다.
- 汗 = 살갗 땀방울 → 두 사람 다 「汗」이 주제. 많고 적음(5배 차)이 汗의 질을 가른다.
- 衰 = 타다 남아 작아진 것 → 등잔 불꽃 = 陽衰(陽=불). 손으로 감싼 등잔이 아니므로 保命은 아님.
- 補-b = 그릇에 담긴 것 = 채워 주는 것 → 왼쪽 사발의 人蔘 + 검은 뿌리. 사전의 地黃 = 검붉은 뿌리 조각 → 검은 뿌리는 熟地黃일 수도 있으나, 色이 검붉다기보다 검정이라 附子 가능성도 남긴다. 어느 쪽이든 「왼쪽은 補·回陽」.
- 酸=매실·苦=커피·甘=꿀·辛=고추·鹹=소금 → 붉은 공 위 다섯이 그대로 五味 → 五味子 확정(생판보다 확신 상승). 갈색 덩이 하나는 여전히 잉여.
- 淸 = 맑고 찬 물 한 그릇 → 오른쪽 물접시 = 淸(熱 쪽에 찬 것을 줌) 또는 喜冷飲.
- 口 = 어두운 타원 구멍 → 오른쪽 벌린 입 = 口渴. 目 = 크게 뜬 눈 → 오른쪽만 해당, 왼쪽은 감음(精神萎靡).
- 面色 자체는 望色 판 소관이라 色으로만 읽음: 左 蒼白, 右 赤.

② 표제어
- 1순위 **亡陽·亡陰(亡陰亡陽證 감별)** 70% — 左: 汗+陽衰+補(參附) / 右: 汗+熱+口渴+淸+五味子(生脈散).
- 2순위 **絶汗·脫汗(冷汗 vs 熱汗)** 15% — 같은 축을 汗의 問診 항목으로 본 경우.
- 3순위 **自汗·盜汗** 10% — 右가 자는 모습이 아니어서 약함.

③ 잔결: 검은 뿌리의 附子/熟地黃 판별 불능, 붉은 공 위 갈색 덩이 1개 뜻 모름, 왼쪽 손발에 厥 기호(검푸름) 없음. 프레임 잘림 없음.
