# blind10 / 656 판독

## 1단계 — 생판 (그림만)

① 소품 전수
- 위 왼쪽: 가죽 풀무(바람통) 1개 — 바람·숨 = **氣**(補氣의 상징).
- 위 오른쪽: 청자 사발에 붉은 액체가 가득 — **血**(補血).
- 왼쪽 네 칸 상자(4칸): 사람 모양 인형(머리에 상투=蘆頭) = **人蔘** / 울퉁불퉁한 흰 덩이 = **白朮** / 층진 흰 버섯 같은 덩이 = **茯苓** / 노란 막대 = **甘草** → **四君子湯**(補氣).
- 오른쪽 네 칸 상자(4칸): 윤나는 검은 덩이 = **熟地黃** / 잔뿌리 많은 긴 뿌리 = **當歸** / 흰 둥근 조각 = **白芍藥** / 매듭진 노란 뿌리줄기 = **川芎** → **四物湯**(補血).
- 아래 큰 상자(칸 없음): 위의 8가지가 모두 한 상자에 담김 — 4+4=8, **八珍湯**. 아래 상자는 위 상자 하나의 약 1.5배.
- 수: 좌 4 · 우 4 · 아래 8 — 정확히 일치. 黃芪·肉桂가 없으므로 十全大補湯(10)이 아니다.

② 표제어
- 1순위: **팔진탕(八珍湯)** — 四君子湯 + 四物湯 = 氣血雙補. 85%
- 2순위: **기혈쌍보법(氣血雙補) 범주 / 십전대보탕(十全大補湯)** 10%

③ 잔결
- 풀무가 氣를 뜻한다는 것은 추론. 왼쪽 상자의 「울퉁불퉁 흰 덩이」와 「층진 흰 덩이」 중 어느 쪽이 白朮·茯苓인지 맞바꿔도 결론은 같다. 프레임 잘림 없음.

## 2단계 — 계통 (사전 적용)

① 사전 어휘로 다시 읽기
- 사발의 붉은 것 = 血(붉은 것) + 「그릇에 가득 담긴 것 = 채워 주는 것」(補-b) → **補血**. 담긴 것이 血이므로 채우는 것도 血.
- 검은 덩이 = 사전의 地黃(검붉은 뿌리 조각)과 맞음 → 熟地黃 확정.
- 풀무는 사전에 없는 기호(氣의 등재 기호는 「서린 흰 김」). 그러나 풀무가 바람을 밀어 넣는 도구이므로 「氣를 채워 넣음」= **補氣**로 읽힌다. 미등재이나 뜻은 명료.
- 虛(삼분의 일로 줄어듦)·人物(오행왕국) 표지는 없음 — 병증 판이 아니라 처방 구성 판.
- 「같은 것 둘 중 하나가 두 배 = 大」는 아님(아래 상자는 1.5배, 합집합이라는 뜻).

② 표제어
- 1순위: **팔진탕(八珍湯)** — 사군자탕 + 사물탕의 합방, 氣血雙補. 85%
- 2순위: **십전대보탕(十全大補湯) / 氣血雙補 치법** 10%
- 사전이 결론을 바꾸진 않았고, 血·補·地黃 기호가 1단계 판독을 그대로 뒷받침.

③ 잔결
- 풀무(氣) 미등재 기호. 白朮·茯苓 두 흰 덩이의 배정 모호(결론 무관). 잘림·수 오류 없음.
