# 658 판독

## 1단계 — 생판 (그림만)

① 소품 전수
- 무대: 3단 나무 서가(책장). 왼쪽 칸 3층, 오른쪽은 윗단 + 큰 빈 칸 + 서랍 2개.
- 윗단 좌: 낡아 해진 옛 책 2권 → 분홍→하늘색 리본 화살표 → 윗단 우: 새 책 1권(파란 물결무늬 표지·제첨 붙은 선장본). = 옛 의서를 모아 새로 엮음(新集·편찬/중간). 새 책 크기는 옛 책과 같음(1배).
- 중단 좌: 붉은 십자 그려진 흰 의서 1권에 금메달 1개(책의 약 1/3 크기)가 끈으로 걸림 = 「으뜸·최고(最古)·공인」 의서.
- 하단 좌: 번개⚡ 표지 책 1권 = 救急, 핀셋(족집게) 표지 책 1권 = 撮(가려 뽑음)·외과.
- 서랍 좌(작은 것): 끈으로 묶은 짚단 1·약봉지 1·잎가지 1·마른 버섯·뿌리 뭉치 = 鄕藥·본초 약재.
- 서랍 우(좌 서랍의 약 1.3배): 색색의 작은 네모 토막 약 30개(6~7열×4~5줄)가 줄맞춰 선 것 = 활자·경판(간행) 혹은 분류 카드.
- 오른쪽: 붉은 곤룡포·익선관의 임금 1인이 웃으며 서랍을 가리킴 = 어명(御)으로 편찬·간행.
- 중단 우 큰 칸은 비어 있음.

② 표제어: 1순위 **鄕藥救急方(향약구급방)** 45% — 향약(약재 서랍)+구급(번개)+현존 最古 의서(메달)+대장도감 간행(토막 서랍)+초간본→중간본(옛책→새책), 임금=고려 고종. 2순위 **세종대 의서 편찬(향약집성방·의방유취)** 25% — 옛 의서 집성(화살표)+향약+활자 간행+임금=세종.

③ 뜻 모를 것: 분홍→하늘색 화살표의 색 의미, 새 책의 물결무늬(바다 건너 일본 소장?), 토막 서랍이 활자인지 경판인지 약재칸인지, 핀셋 책의 정확한 뜻(撮要/치종/검시), 중단 우 빈 칸(失傳?). 잘림: 서가 좌하단 모서리가 화면 밑에 살짝 걸림 정도, 큰 잘림 없음.

## 2단계 — 계통 (사전요약 적용)

사전 대조: 「붉은 곤룡포 임금 = 心」이 그대로 맞으나 무대가 서가·옛 책·간행 토막이라 장상 판이 아니고, 王·張·李처럼 「어느 임금인지는 무대가 진다」 원칙으로 읽으면 이 임금은 역사 무대의 실제 임금(御)이다. 心으로 읽으면 번개·핀셋·옛책→새책·토막 서랍이 전부 풀리지 않는다. 「典藥 = 끈으로 묶은 약봉지 다발」이 왼 서랍의 끈 묶은 짚단·약봉지와 겹치므로 고려 典藥局 암시 가능성은 남긴다. 「官 = 3층 선반장 가운데 층」으로 보면 중단의 메달 의서가 官 자리에 놓여 「공인·官 간행」을 보강한다. 사전에 濟·衆·惠·典藥·太·寺·大 등 고려 의료기관 글자가 이미 등재돼 있어 이 책이 고려 의학사를 연속으로 다룬다는 점이 고려 읽기를 밀어준다.

① 재독: 옛 책 2→새 책 1 = 新集(새로 모아 엮음)·중간, 핀셋 = 撮要, 임금 = 御(어의·어명), 번개 = 救急, 약재 서랍 = 鄕藥(또는 典藥), 메달 의서 = 현존 最古, 토막 서랍 = 대장도감 간행(판·활자 약 30), 빈 칸 = 초간본 失傳.

② 표제어: 1순위 **鄕藥救急方** 55% — 고려 고종 대장도감 간행·현존 最古 의서·향약 180여 종·조선 태종 17년(1417) 중간본이 일본에 현존. 2순위 **新集御醫撮要方(최종준, 1226)** 20% — 新集(옛책→새책)+御(임금)+撮(핀셋)이 한 줄로 맞아 같은 판의 짝 표제어일 수 있음. 3순위 典藥局 10%.

③ 잔결: 화살표 색 변화·물결무늬의 뜻은 사전에 없음. 토막 개수(약 30)가 사실(권수·질수)을 나르는지 불명. 핀셋이 撮인지는 사전 미등재라 추정. 임금 기호가 心과 충돌하는 점은 무대로 갈라 읽었다.
