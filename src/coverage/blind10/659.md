# 659 판독 기록

## 1단계 — 생판 (그림만)

① 소품 전수
- 무대: 무채색 회백 방, 긴 나무 벤치 1개(진료 무대). 인물 4명 = 환자 3 + 의사 1.
- 의사 1: 뒤돌아 무릎 꿇고 세 환자를 바라봄 → 望診(눈으로 보는 진찰)의 주체.
- 환자① (왼쪽, 청년): 얼굴·목·손·발 전신이 회흑색(黧黑, 칙칙한 잿빛) → 面色黑·晦暗 = 腎虛·寒證.
- 환자② (가운데, 여성): 피부색은 정상이나 두 눈 주위(眼眶)만 검은 테, 배가 북처럼 둥글게 부풂(머리 약 1.5배, 腹大如鼓) → 目眶黑 + 腹腫 = 水飲·腎虛水泛(水腫·鼓脹).
- 환자③ (오른쪽, 중년 남): 얼굴·손·발 전신이 자흑색(紫黑), 손가락 마디가 굽고 울퉁불퉁 → 面色紫黑 = 瘀血(오래된 瘀·痛證).
- 우하단 흰 별표 1 (장식/서명).

② 표제어
- 1순위 **黑色主病 (望色 — 黑: 腎虛·寒證·水飲·瘀血·痛證)** 60%
- 2순위 **五色主病 (望面色 총론) / 青色主病(寒·痛·瘀血)** 20% — 오른쪽 환자의 자색이 青紫로도 읽힘.

③ 잔결: 별표의 뜻 모름. 환자③의 굽은 손가락이 痛인지 肌膚甲錯인지 불명. 프레임 잘림 없음. 전원 맨발·흰 옷이라 색은 오직 피부에만 실려 있음(의도적).

## 2단계 — 계통 (사전 어휘로 재독)

사전의 面 항목이 「광택만 面, 얼굴색 자체는 望色 판 전담」이라 하므로 이 판은 望色 판으로 확정. 瘀 갈림 「살갗 위의 멍·얼룩은 瘀가 아니라 그 자리의 색」 → 환자③의 자흑은 瘀 글자가 아니라 面色紫黑(色)으로 읽어야 하며, 색이 나르는 뜻이 瘀血이다. 腫 = 부풀어 팽팽해진 곳 → 환자②의 배 = 腹腫(水飲). 目 = 크게 뜬 눈 → 눈테 검음 = 目眶黑(水飲·腎虛). 厥 = 검푸르게 언 손발 끝 → 환자③의 보랏빛 손·발 = 寒凝·厥逆 → 黑色主 寒證·痛證. 痛 쇠못·寒 눈송이·腎 잠수부·병표지는 없음 → 색 자체가 사실을 나르는 望色 판.
세 환자 = 黑色이 主하는 병 셋: ① 전신 黧黑 = 腎虛·寒, ② 目眶黑+腹腫 = 水飲, ③ 紫黑+손발끝 검푸름 = 瘀血·寒凝·痛.

- 1순위 **黑色主病 (望色 — 黑色: 腎虛·寒·水飲·瘀血·痛證)** 72%
- 2순위 **青色主病 (寒·痛·瘀血·驚風)** 13% / 3순위 五色主病 총론 10%
- 잔결: 우하단 별표 뜻 불명. 환자③ 손가락 굽음은 痛 못이 없어 확정 못 함. 수 오류·잘림 없음.
