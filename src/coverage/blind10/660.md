# 660 판독 기록

## 1단계 — 생판 (다른 자료 없이 그림만)

### ① 소품 전수와 나르는 사실
1. 잿빛 흐린 하늘 + 나무·초가지붕·옷·손끝에서 떨어지는 물방울(셀 수 없이 많음) → 비·雨露浸淫 = 外濕 / 濕爲陰邪.
2. 남자 1명: 허리 구부정, 두 팔 축 늘어뜨림, 눈꺼풀 반쯤 감김, 지친 얼굴 → 濕性重濁의 「重」: 身重·困倦·頭重如裹, 阻遏氣機.
3. 양 종아리(무릎 아래)를 두껍게 덮은 진흙 — 다리가 평소의 약 2배 굵기로 보임 → 濕性趨下(下肢를 먼저 침범), 黏滯(들러붙어 안 떨어짐), 重.
4. 물웅덩이에 잠긴 맨발 2 → 下注·足腫, 趨下.
5. 쓰러진 흙항아리 1, 입에서 흐르는 탁한 황갈색 액체 → 「濁」: 排泄物·分泌物 혼탁(小便混濁·大便溏泄·帶下). 흙(土)항아리가 물을 못 담음 = 脾失健運 → 內濕 생성.
6. 초가집 1 + 이끼·곰팡이 핀 흙담 → 居處潮濕(환경 외습).
7. 물 뚝뚝 떨어지는 나무 1 → 비.
8. 기운 천 조각 3(팔꿈치 1·무릎 2) → 오래 끌어 낡음 = 濕病 纏綿難愈(黏滯)?
9. 진흙길·바퀴자국·웅덩이 → 泥濘 = 濕.
10. 드러난 갈비뼈 → 수척(陽氣 손상?) — 확신 낮음.
크기: 남자 ≈ 화면 높이 0.6, 항아리 ≈ 남자 키의 1/4, 초가집(배경) ≈ 남자 0.6배.

### ② 표제어
- 1순위 **濕邪(습사)의 성질과 치병특징 — 重濁·黏滯·趨下·陰邪** (85%)
- 2순위 **外濕(외감습사: 淋雨·居處潮濕)** (50%) / 차순위 **濕困脾(脾虛濕盛·內濕)** (25%)

### ③ 뜻 모를 것·어색·잘림
- 천 조각 3개가 수(數)를 나르는지 불명. 드러난 갈비뼈·상투 의미 불명.
- 항아리 액체가 「탁한 물」인지 「溏泄」인지 모호.
- 잘림: 오른쪽 초가집·담장이 프레임에 잘림, 왼쪽 나무 잎 끝 잘림. 핵심 소품은 잘리지 않음.

## 2단계 — 계통 (사전요약 어휘로 재판독)

### ① 소품 재판독
1. 부슬비(수직 낙하) + 안개 낀 원경 + 진창길 = 사전의 「濕 = 外濕 = 부슬비·안개·진창(길)」 삼종이 모두 등장. 비가 **수직**이라 風 갈림 조건 불충족 → 風濕 아님, 濕 단독.
2. 초가집·흙담이 있고 사람은 **담 바깥** 길 위에 서 있음 = 外. 발밑 웅덩이도 길 위의 것이지 「자기 발밑에서 배어 나오는 것」이 아님 → 內濕 갈림 불충족. 노란 밀짚모자 농부(脾)도 없음 → 脾·內濕 후보 탈락.
3. 쓰러진 항아리에서 탁한 흙물이 **아래로 쏟아짐** = 下 + 濕 → 濕性趨下. 瀉-b(빈 그릇+흘러넘침=덜어냄)로도 읽히나 치료 장면(빗자루·국물)이 없어 下로 읽는 것이 맞음. 탁한 색 = 濁.
4. 종아리를 두껍게 덮은 진흙 = 腫(부풀어 팽팽) + 濕 → 下肢腫·趨下·重. 들러붙은 진흙 = 黏滯.
5. 구부정한 허리·늘어진 팔·반쯤 감긴 눈 — 전담 기호 없음, 身重·困倦(重)으로 읽음. 눈이 크게 떠 있지 않아 目 아님.
6. 해·불·눈송이·흰 김·얼음 모두 없음 → 寒·熱·氣 사실은 안 나름. 해 없는 잿빛 하늘 = 陰邪 암시.
7. 살갗의 물방울: 사전상 汗(살갗에 맺힌 땀방울)로 읽힐 수 있으나 나무·처마에서도 같이 떨어지므로 비.
8. 천 조각 3: 久는 「포개진 셋」이라 조건 불충족 — 纏綿(黏滯) 암시 정도.

### ② 표제어
- 1순위 **外濕(외감습사)의 성질과 치병특징 — 重濁·黏滯·趨下·陰邪** (88%) — 1단계와 같고, 담 바깥·길 위 진창·수직 비로 外濕이 확정되어 확신 상승.
- 2순위 **濕性趨下(下肢腫·下注)** (40%) — 항아리 쏟아짐·진흙 종아리·웅덩이 발이 한 축으로 모임.
- 3순위 **濕困脾(內濕)** (10%) — 갈림 조건 불충족으로 하락.

### ③ 잔결
- 살갗 물방울이 汗 기호와 겹침(비로 읽었으나 오독 여지).
- 천 조각 3·드러난 갈비뼈·상투는 사전에 없어 뜻 불명.
- 잘림: 오른쪽 초가집·담장, 왼쪽 나무 잎 끝 — 핵심 소품 아님.
