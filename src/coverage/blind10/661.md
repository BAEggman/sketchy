# blind10 / 661 판독

## 1단계 — 생판 (그림만)

**① 소품 전수** — 4칸(2×2), 칸마다 상투 튼 맨발 사내 1명이 기와 문간·담 사이 마당에 서 있다(문간·담 구조물 각 칸 2개).
- 좌상(청록 저고리·황갈 바지): 어깨·머리 양옆에서 흰 김 4가닥이 위로 흩어져 오름(좌2·우2). 팔 늘어뜨림, 지친 얼굴, 입 다묾. → 기운이 몸 밖으로 새어 나가 無力 — 氣虛·氣脫(自汗 느낌).
- 우상(황토 저고리·붉은 바지): 두 손으로 배를 움켜쥐고 찡그림. 흰 김이 왼쪽 담 뒤에서 배로 들어와 오른쪽 돌기둥으로 가로질러 빠져나감(가닥 2, 수평). → 氣가 오르내리지 못하고 中焦에 가로로 막힘 — 氣滯·脹痛(橫逆).
- 좌하(청록·회색 바지): 허리 굽히고 입에서 맑은 침·물 3방울 흘림, 머리 위로 흰 김 2가닥 곧게 솟음. → 氣가 위로 거슬러 嘔吐·流涎 — 氣逆.
- 우하(황토·회색 바지): 배를 감싸 안고 땅에 꺼진 구덩이(사람 키 가로 2배 폭)에 무릎까지 빠져 있고, 배에서 흰 줄기 1가닥이 구덩이로 쏟아짐. → 氣가 아래로 가라앉아 久泄·脫肛 — 氣陷.
색 대비: 왼쪽 열 청록 2명 / 오른쪽 열 황토 2명 — 같은 사람의 네 상태로 보임.

**② 표제어** — 1순위 **氣의 병기 4종(氣虛·氣滯·氣逆·氣陷)** 55% / 2순위 **氣機 升降出入 실조(氣機失調: 出·入·升·降)** 25% / 3순위 **脾胃 升降 실조(脾氣虛·脘腹脹·胃氣上逆·脾氣下陷)** 10%.

**③ 잔결** — 우상의 「가로지르는 김」이 氣滯인지 風(바깥에서 들어온 바람)인지 모호. 좌상에 땀방울은 없어 自汗 확정 불가(김만 오름). 프레임 잘림 없음. 네 사내가 동일인인지 다른 인물인지 구분 표지 없음.

## 2단계 — 계통 (사전 적용)

사전 어휘로 다시 읽으면: **氣 = 서린 흰 김**이므로 네 칸의 김은 모두 氣다. **上 = 머리 꼭대기로 곧게 솟음**(좌하: 머리 위 곧은 김 2가닥 = 氣上 → 氣逆) · **下 = 아래로 가라앉거나 쏟아짐**(우하: 구덩이에 빠짐 + 김이 아래로 쏟아짐 = 氣下 → 氣陷) · **津 = 맑은 물방울**(좌하 입의 3방울 = 津이 위로 나옴 = 嘔吐·流涎, 氣逆의 증). 우하의 쏟아지는 줄기는 맑은 물이 아니라 흰 김이므로 津 소실이 아닌 氣의 下陷으로 읽는 것이 사전과 맞다. 좌상은 **汗(살갗의 땀방울)**이 없고 김이 몸에서 사방으로 흩어져 오르니(**散**) 氣가 몸 밖으로 새는 氣脫·氣虛不固 쪽 — 다만 **虛 = 삼분의 일로 줄어든 것** 표지가 없어 虛보다 脫에 가깝게 읽힌다. 우상의 가로지르는 김은 **風(옆으로 눕고 흘러 날리는 것)** 조건과 겹치나, 담 바깥이 아니라 사람 배 한복판(**中**)을 지나며 사람이 배를 움켜쥐므로 外風이 아니라 氣가 中焦에 가로막힌 氣滯(橫)로 판정한다. 무대가 모두 담 안쪽(**內**)이라 內傷 氣病 계열임을 뒷받침한다.

**② 표제어** — 1순위 **氣의 병기 4종(氣虛/氣脫·氣滯·氣逆·氣陷)** 60% / 2순위 **氣機失調(升降出入 — 氣脫·氣閉·氣逆·氣陷)** 25% / 3순위 **脾胃 升降 실조** 10%. 1단계와 같은 축이며 사전으로 上·下·氣·津이 확정되어 확신이 소폭 오른다.

**③ 잔결** — 우상: 痛 표지(쇠못)가 없는데 찡그림으로 통증을 암시 — 氣滯 脹痛인지 氣閉인지 미결. 좌상: 虛 표지 부재로 氣虛·氣脫 미결. 우상의 「가로 김」이 사전 風 조건과 부분 충돌(갈림). 잘림·수 오류 없음.
