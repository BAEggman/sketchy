# blind10 · 663 판독

## 1단계 — 생판(그림만)

① 소품 전수 (4컷 무대, 모두 상투 튼 같은 사내로 보임)
- 상좌: 뚱뚱한 사내가 앉아 양손으로 팽팽한 배를 움켜쥐고 찡그린 채 입에서 흰 숨구름을 내뿜음(트림). 옆에 빈 그릇 더미 — 네댓 단으로 포개져 약 20개(±3, 가장 높은 단 6~7개) + 앞에 낱개 1. → 過飽·暴飮暴食 → 「飮食自倍, 腸胃乃傷」, 食積(脘腹脹滿·噯氣).
- 상우: 갈비뼈·쇄골 드러난 야윈 사내가 뒤집힌 빈 그릇 하나를 들고 멍하니 봄. 그릇 수 대비 약 20:1. → 過飢·飮食不足 → 氣血生化之源 부족 → 氣血虛衰.
- 하좌: 사내가 네 발로 기며 땀을 10여 방울 흘림, 등에 밧줄 두 줄로 묶은 큰 장작 묶음(통나무 약 18~20개), 바닥에 흩어진 장작 좌 4~5·우 4개, 떨림선. → 過勞(勞力過度) → 「勞則氣耗」, 땀 = 氣隨汗泄.
- 하우: 살집 있는 사내가 돗자리에 나무베개를 베고 손을 배에 얹은 채 다리를 벌리고 잠듦. → 過逸(安逸過度) → 氣血運行不暢·脾胃기능 저하·「久臥傷氣」.
- 배경: 네 컷 모두 문틀·돌판이 있는 마당 안.

② 표제어
- 1순위 **飮食勞逸(飢飽勞逸) — 病因 중 飮食失宜·勞逸失度** (70%): 飽·飢·勞·逸 네 컷이 정확히 대응.
- 2순위 **內傷病因 총론(七情을 뺀 飮食·勞逸 묶음)** (20%). 3순위 李東垣 飮食勞倦傷脾 (10%).

③ 뜻 모를 것·어색·잘림
- 상좌 입김이 트림(噯氣)인지 숨참(喘)인지 확정 못 함. 그릇 약 20개·통나무 약 18개가 수치 사실인지 단순 「많음」인지 불명. 네 컷 배열 순서(飽→飢→勞→逸)의 의미 불명. 상우 문틀·하우 돗자리가 프레임 끝에서 잘림(의미 없어 보임).

## 2단계 — 계통(사전 어휘로 재독)

사전으로 되읽으면 큰 축은 그대로이고 세부가 또렷해진다.
- 氣 = 흰 김 → 상좌 입에서 나가는 흰 김은 「氣가 입으로 새어 나감」 = 食積으로 인한 胃氣上逆·噯氣. 
- 實 = 팽팽하게 찬 것 → 상좌의 팽팽한 배 = 食積 實證. 虛 = 삼분의 일로 준 것 → 상우의 야윈 몸·낱그릇 1개(약 20:1) = 氣血虛. 飽/飢가 實/虛 대립쌍으로 읽힘.
- 久 = 같은 물건 셋 이상 포개진 것 → 상좌의 포개진 그릇 더미는 「오래 거듭된 과식」(長期 飮食過量)으로 읽는 편이 낫다. 傷(깨진 물건)은 화면에 없으므로 「腸胃乃傷」의 글자 소품은 없고 뜻만 담김.
- 汗 = 땀방울 → 하좌 = 「勞則喘息汗出, 外內皆越, 故氣耗」(素問·擧痛論). 하좌 장작 묶음·흩어진 장작은 勞力의 양을 지는 소품.
- 內 = 문 안쪽 → 네 컷 모두 문틀 안 마당 = 內傷 병인임을 무대가 짐. 하우는 사전 글자 없이 「久臥傷氣」 뜻만(돗자리·베개는 포개짐이 없어 久 글자로는 안 읽힘).
- 補·瀉-b·惠(여러 손이 받는 빈 사발)는 조건이 안 맞음 — 상우의 빈 그릇은 한 손이고 쏟아진 내용물도 없어 단순 「먹을 것 없음」.

② 표제어
- 1순위 **飮食勞逸(飢飽勞逸) — 飮食失宜(過飽·過飢)·勞逸失度(過勞·過逸)** (78%).
- 2순위 **內傷病因 총론(飮食·勞逸 — 실/허 대립 포함)** (14%). 3순위 李東垣 飮食勞倦 內傷脾胃 (8%, 李=자두 소품 없음).

③ 잔결
- 상좌 흰 김이 사전상 氣인 것은 확실하나 噯氣인지 「飽則氣..」류 구절 인용인지 불명. 그릇·통나무 개수는 수치 사실이 아닌 「많음」으로 판단. 하우에 전담 글자 소품이 없어 逸 컷만 글자 없이 뜻으로 읽힘.
