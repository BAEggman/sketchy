# blind10 / 664 판독

## 1단계 — 생판 (그림만)

**① 소품 전수** — 네모 틀 안에 손목(촌구) 넷을 2×2로 놓고, 각 손목 위에 진맥하는 손이 손가락 두 개(검지·중지)를 얹었다. 손목 혈관 자리에 파란 물길이 흐르고, 소매 색이 네 판 모두 다르다.
- 좌상(청록 소매): 물길이 **실 한 가닥** 굵기(우상 강물의 약 1/10, 좌하 혈관의 약 1/5). 손가락이 눌러 짚음 → 脈細如線.
- 우상(황토 소매): **넓은 강물**이 물결치며 넘쳐흐르고, 짚은 손에 떨림선(파동이 손가락을 밀어올림). 소매 쪽은 넓고 손바닥 쪽으로 가늘어짐 → 來盛去衰·如波濤.
- 좌하(붉은 소매): 혈관 속에 **흰 진주 10알(±1)**이 줄지어 굴러감 → 如盤走珠·往來流利.
- 우하(회흑 소매): **대나무 갈퀴(4갈래)**가 혈관을 긁고, 안에 **자갈·모래 알갱이 약 30알**이 차 있음. 물길은 거의 끊김 → 輕刀刮竹·如雨沾沙·往來艱澁.

**② 표제어** — 1순위 **맥상(脈象) 4맥: 세맥(細)·홍맥(洪)·활맥(滑)·삽맥(澁) — 「如線 / 波濤·來盛去衰 / 盤走珠 / 刮竹·雨沾沙」 비유 암기** (75%). 위 두 판이 洪↔細, 아래 두 판이 滑↔澁의 상대 쌍. 2순위 **대맥(大)·세맥·활맥·삽맥**(우상을 洪이 아닌 大/實로 읽을 때, 15%).

**③ 뜻 모를 것** — 소매 색 4종(청록·황토·적·회흑)이 무엇을 나르는지 불명(오행색이면 木·土·火·水인데 맥상과 안 맞고, 활맥=적을 血實로, 삽맥=회를 血少로 읽는 정도만 가능). 우상 손의 떨림선은 「맥이 손가락을 치받음」으로 읽었으나 확정 어려움. 혈관 속 물이 붉지 않고 파란 것이 血인지 단순 흐름인지 모호. 프레임 잘림 없음. 진주 수는 10으로 셈(겹침 때문에 ±1).

## 2단계 — 계통 (사전요약 적용)

사전 어휘로 다시 읽음.
- **盛 = 넘쳐 흘러나오는 것 / 衰 = 작아진 것**: 우상 강물이 넘쳐흐르다 손바닥 쪽으로 작아지는 것이 바로 **來盛去衰** — 洪脈의 정의 그대로. 1단계의 洪 판정이 강화된다(實脈이면 고르게 팽팽해야 함 → 實 배제).
- **大 = 같은 것 둘이 나란한데 하나가 몇 배**: 위 두 손목이 나란히 놓여 실(細)과 강물(洪=大)이 대비 → 洪(大)↔細 쌍이 의도된 구도.
- **虛 = 1/3로 줄어든 것**: 좌상 실 가닥은 1/5~1/10 — 虛보다 더 가늘게 그려 「如線」(細)을 나타냄.
- **瀉 = 짚 빗자루**: 우하 도구가 짚빛이라 瀉로 볼 여지가 있으나, 끝이 짚 솔이 아니라 네 갈래 **대나무 갈퀴**이고 맥 문맥에서 瀉는 뜻이 없다 → 瀉가 아니라 「輕刀刮竹」의 竹(대나무)로 읽는 것이 옳다.
- **瘀 = 검붉게 굳은 알갱이(몸 밖)**: 우하 자갈은 회갈색이고 혈관 안에 있어 瘀 기호 조건 불충족 → 「如雨沾沙」의 沙. 다만 삽맥의 主病(氣滯血瘀·血少精傷)을 암시하는 연상 장치로는 통한다.
- **血 = 붉은 것**: 소매 중 붉은 것은 좌하(滑) 하나 → 滑脈 主 血實·痰食·妊娠과 연결 가능. 다른 소매 색은 사전에 없음(잔결).
- 혈관 속 파란 물은 血(붉은 것)이 아니므로 「脈의 흐름」 매체로 읽음.

**표제어** — 1순위 **맥상 4맥: 홍(洪=大)·세(細)·활(滑)·삽(澁) — 來盛去衰·如線·盤走珠·刮竹沾沙** (82%). 2순위 **대맥(大)·세맥·활맥·삽맥**(大 글자 구도를 그대로 표제로 둔 경우, 12%).

**잔결** — 소매 색 3종(청록·황토·회흑)의 뜻 미해독. 우상 떨림선 확정 불가. 진주 10알(±1).
