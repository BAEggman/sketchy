# blind10 / 666 판독

## 1단계 — 생판 (다른 자료 없이 그림만)

① 소품 전수
- 왼쪽 위: 왕관 쓴 아이가 개울 **발원지**에 무릎 꿇고 두 손으로 물길을 트고 있음(개울이 손에서 시작) + 글자 없는 나무 **푯말** 1개 + 풀 한 포기.
- 개울: 왼쪽 위 발원지 → 화면을 가로질러 → 오른쪽 아래 베틀로 들어가며 색실(5~6가닥)로 변함. 개울가에 흰 김 뭉치 약 9개.
- 가운데 위: 땅에서 솟는 색 연기 4줄기(빨강·파랑·노랑·초록, 흰·검정 없음) + 꼬리 달린 별똥별 3개(하늘에서 떨어짐). 입을 얼굴 절반만큼 벌린 아이가 초록 연기를 코·입으로 빨아들임.
- 오른쪽 위: 나뭇잎 관·나뭇잎 치마의 소녀가 대나무 발(簾) 4장을 걸고 있음(3장 걸림+1장 손에) — 발 아래서 김이 올라와 발을 통과. 옆에 가로대 3개 달린 장대에 흰 빈 깃발 1폭.
- 왼쪽 아래: 진창 웅덩이에서 김이 솟고 그 위에 눈송이 약 9개.
- 가운데 아래: 독 5개(3단으로 쌓임)에서 물이 위→중→아래로 쏟아짐, 입 크게 벌린 성난 아이가 맨 아래 독을 붙듦.
- 오른쪽 아래: 왕관 쓴 아이가 베틀에서 무지개 천(줄무늬 약 8색)을 짬. 색실은 개울이 변한 것.

② 표제어: 발원지에서 물길을 트는 관(冠)+푯말 = 「決瀆之官 水道出焉」, 독 3단 = 上中下焦(如霧·如漚·如瀆), 끝의 베틀 = 「水精四布(布=천) 五經並行(나란한 날실)」로 읽힘. 1순위 **진액(水液)대사 — 素問·經脈別論 「飮入於胃…水精四布 五經並行」** 45% / 2순위 **三焦(決瀆之官·上焦如霧 中焦如漚 下焦如瀆)** 30% / 3순위 **肺의 생리(通調水道·宣發肅降·朝百脈·開竅於鼻)** 15%.

③ 모를 것: 나뭇잎 소녀와 발 4장(宣發? 皮毛?), 흰 빈 깃발, 별똥별, 색 연기가 왜 4색인지, 눈+김 웅덩이(膀胱 寒水? 氣化?). 독은 3단인데 실제 5개. 무지개 천 끝과 별꼬리가 프레임에 살짝 걸림.

## 2단계 — 계통 (blind6 사전 적용)

사전으로 다시 읽으니 **인물·의학사 판**으로 완전히 다르게 풀린다. 왕관 = 王(성씨), 얼굴 절반 입 = 吳, 흰 김 = 氣, 눈송이 = 寒(外寒), 진창 = 濕, 쏟아짐 = 下.
- 가운데 위: 큰 입 아이 = **吳**, 색 연기(흰 氣와 다른 색 = 異氣·雜氣 4종)를 입·코로 들이마심 = 「邪自口鼻而入」, 별똥별(天)+땅(地) = 「天地間別有一種異氣」 → **吳有性(吳又可) 溫疫論·戾氣說**.
- 오른쪽 위: 나뭇잎 소녀 = **葉(葉天士·葉桂)**, 발 4장 = **衛·氣·營·血 4단**, 김(氣)이 발을 통과 = 透熱轉氣 → 溫熱論. 흰 깃발 = 白 → **薛生白(薛雪)**의 짝 표시로 추정.
- 왼쪽 아래: 진창(濕)+김(熱 증기)+눈송이(寒) = 「濕熱證 始惡寒 後但熱不寒」 → **薛雪 濕熱條辨**(눈=雪 이름 겹읽기). 대안: 王叔和 傷寒例 伏寒化溫.
- 가운데 아래: 큰 입 = **吳**, 독 3단 위→아래로 쏟아짐(下) = **三焦辨證(始上焦 終下焦)** → **吳鞠通 溫病條辨**.
- 오른쪽 아래: 왕관 = **王**, 베틀 = 經(날)·緯(씨) → **王孟英 溫熱經緯**(「軒岐仲景之文爲經 葉薛諸家之辨爲緯」) — 앞선 개울(계보)이 그의 날실이 됨.
- 왼쪽 위: 왕관 = 王, 발원지로 거슬러 물길을 틈 = 溯洄, 푯말 = 道 → **王履(王安道) 醫經溯洄集 「溫病不得混稱傷寒」** = 온병 분리의 원류(대안: 王叔和 傷寒例).

② 1순위 **溫病學派의 성립·계보(王安道→吳又可→葉天士→薛生白→吳鞠通→王孟英)** 60% / 2순위 **王孟英 溫熱經緯(단독 인물판, 나머지는 경·위 재료)** 20% / 3순위 1단계의 진액대사 10%.

③ 잔결: 발원지 王이 王安道인지 王叔和인지 무대 단서(푯말 글자 없음) 부족. 흰 깃발이 白(薛生白)인지 膈인지 불확정. 독은 3단인데 5개라 三焦 수와 어긋남. 색 연기 4색은 五行 오색이 아니라 雜氣로 읽었음. 별똥별(天)·개울가 흰 김(氣)의 정확한 글자 배당 미확정.
