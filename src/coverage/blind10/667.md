# blind10 / 667 판독

## 1단계 — 생판 (다른 자료 없이 그림만)

① 소품 전수
- 인물 3: 노란 밀짚모자·노란 옷·맨발 농부 / 검은 갓·흰 도포 선비 / 익선관·붉은 곤룡포(가슴 용보) 임금. 세 사람 모두 손에 같은 **담황색 뿌리 절편 1장씩(합 3장)** 을 들고 있다 → 한 약재를 세 쪽에 나눠 든 셈, 세 사람 = 그 약재가 가는 세 곳(노랑·흰·붉은 = 黃·白·赤 = 脾·肺·心)으로 읽힘.
- 좌하 사람 모양(머리·팔·다리) 큰 뿌리 1개 — 농부 키의 약 1/2, 절편의 약 4배 → 人形 뿌리 = **人蔘** 본체.
- 꿀단지 1 + 나무 국자 1(꿀이 흘러내림) → 甘味.
- 갈색 사발 1, 검은 액체 → 微苦 또는 탕(獨蔘湯·另煎) 으로 추정.
- 검은 비틀린 뿌리 1 + 붉은 X → 反藜蘆(十八反).
- 다람쥐(날다람쥐) 1 + 바닥 검은 알갱이 4개 + 붉은 동그라미 → 五靈脂(鼯鼠 똥) = 畏五靈脂(十九畏).
- 무대: 회색 벽·마루, 특별한 장소 표시 없음.

② 표제어
- 1순위 **人蔘** (95%) — 人形 뿌리 + 藜蘆 X + 五靈脂 ○ 조합은 인삼 외엔 성립하지 않음. 세 인물 색 = 歸脾·肺·心經, 꿀 = 甘, 사발 = 微苦.
- 2순위 **君臣佐使(임금·선비·농부 세 신분)** (5%) — 세 신분만 보면 가능하나 아래 소품이 모두 약재 각론이라 약함.

③ 뜻 모를 것·어색한 것
- 사발의 검은 액체가 「微苦」인지 「탕(補)」인지 구분 단서 없음(김 없음).
- 微溫·大補元氣·生津·安神 등 효능 소품은 보이지 않음(성미·귀경·금기 중심 판).
- 농부만 맨발인 이유 불명(脾主四肢 암시?). 프레임 잘림 없음, 소품 수 오류 없음.

## 2단계 — 계통 (blind6 사전 어휘로 재독)

사전에 「노란 밀짚모자 농부 = 脾 · 흰 도포 재상 = 肺 · 붉은 곤룡포 임금 = 心」이 등재돼 있어 1단계의 색 추정이 정식 글자로 확정된다. 세 장부가 **같은 절편을 하나씩 나눠 들었다** = 그 약재가 脾·肺·心 셋에 歸經한다는 문법. 「甘 = 나무 국자가 꽂힌 꿀단지」가 그대로 있어 甘味 확정. 사발은 「苦 = 김 나는 검은 커피」와 「補 = 그릇에 찰랑찰랑 찬 따뜻한 국물」 사이에서 갈리는데, 김이 없고 검은 색이 강조돼 있으니 微苦 쪽이 우세(김을 빼서 「微」를 표현했을 가능성), 補(大補元氣)는 2안. 「溫 = 김 오르는 천」은 없어 微溫은 생략된 것으로 본다. 藜蘆·五靈脂는 사전에 없으나 검은 뿌리+X, 다람쥐+똥 4알+○ 로 직설 묘사됐고 十八反(反)·十九畏(畏)를 X/○ 로 구분해 찍은 것으로 읽힌다. 人形 뿌리는 사전의 「地黃 = 검붉은 뿌리 조각」과 색·형태가 달라(담황·사람꼴) 지황이 아니다.

① 소품 재정리: 脾(농부)·肺(재상)·心(임금) 각 절편 1 = 歸脾肺心經 / 人形 뿌리 = 人蔘 / 꿀단지+국자 = 甘 / 검은 사발 = 微苦(2안 補) / 검은 뿌리 X = 反藜蘆 / 다람쥐+똥 4알 ○ = 畏五靈脂.
② 표제어: 1순위 **人蔘** (97%) — 性味 甘·微苦(微溫), 歸脾·肺·心, 反藜蘆·畏五靈脂가 한 판에 모두 맞물림. 2순위 **黨蔘** (3%) — 甘·歸脾肺·反藜蘆까지는 겹치나 心 귀경·五靈脂·人形 뿌리가 맞지 않음.
③ 잔결: 사발(苦/補) 한 가지 갈림, 微溫 소품 부재, 농부 맨발의 뜻 미상. 잘림·수 오류 없음.
