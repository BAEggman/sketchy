# 668 판독 (blind10)

## 1단계 — 생판 (다른 자료 없이 그림만)

**① 소품 전수와 나르는 사실**
- 야윈 노인 1명(화면 높이의 약 2/3): 구부정한 자세, 왼손으로 가슴 한복판을 누름, 입을 벌림(마른기침·헐떡임), 이마·목·팔·발등에 잔주름과 건조한 피부선 다수, 상투에서 삐져나온 마른 머리카락, 맨발, 기운 바지(천 조각 2개·바짓단 흙색) → 肺 손상(乾咳)·皮膚乾燥·毛髮乾枯·虛弱.
- 가을 단풍나무 1그루(화면 높이 약 1/2, 갈색·황갈 잎) → 秋(가을의 主氣 = 燥).
- 갈라진 땅: 오른쪽 흙벽·절벽에 세로 균열 다수, 땅바닥 전체에 마른 균열 → 燥性乾澀.
- 빈 나무 물통 1개(사람의 약 1/4 높이, 물 한 방울 없음) → 津液 고갈.
- 금 간 질화분 1개 + 축 늘어진 시든 식물(처진 잎 약 5장) → 燥傷津液·枯.
- 마른 낙엽 1장(바닥에 그냥 놓임) → 秋燥.
- 초가집 1채(문 1·창 2), 구불구불 마른 길 → 무대(시골·가을).

**② 표제어**
- 1순위 **燥邪(조사·秋燥 — 燥性乾澀 易傷津液 / 燥易傷肺)** 70%
- 2순위 **肺陰虛·津液虧虛(虛勞)** 15%

**③ 뜻 모를 것·어색함·잘림**
- 초가집이 단순 배경인지 뜻이 있는지 불명. 바지 아랫단의 색 경계(흙색)가 뜻이 있는지 불명. 물통이 '빈 것'인지 '마른 것'인지 구분 불가. 프레임 잘림 없음.

## 2단계 — 계통 (사전요약 어휘로 재독)

**① 소품 재해석**
- 燥 = 갈라진 땅 · 마른 잎 → 흙벽 균열·바닥 균열 + 바닥 낙엽 1장이 정확히 燥 기호. 낙엽이 옆으로 날리지 않고 바닥에 놓여 있고 나무잎도 흘러 날리지 않으므로 風과 갈려 순수 燥.
- 內燥 = 밑동까지 마른 물독(갈림) → 빈 나무 물통이 이에 해당할 가능성. 단 '독'이 아니라 '통'이고 안이 보이지 않아 조건 충족이 확실치 않음 → 外燥 무대 안의 보조 기호(津液 고갈)로 읽는 쪽이 안전.
- 外 = 담 바깥 → 노인이 초가집 담(흙벽) 바깥에 서 있음 + 가을나무 = 外燥(秋燥).
- 傷 = 그 글자의 사물이 깨져 못 쓰게 된 것 → 금 간 화분+시든 식물 = 燥傷津液(津의 그릇이 깨짐).
- 髮 = 윤이 흐르는 머리카락인데 이 머리는 윤 없이 마른 가닥이 삐죽 → 毛髮不榮. 口 = 어두운 타원 구멍 → 벌린 입 = 口乾·乾咳. 肺 기호(흰 도포 재상)는 없고 가슴 누름으로 직접 표현 → 燥易傷肺. 皮 = 색 경계선 → 피부 주름선·바짓단 색 경계는 皮膚乾燥의 보조.
- 虛(1/3로 줄어든 것)·痛(쇠못)·久(셋 포개짐) 기호 없음 → 虛勞·痛證 판이 아님.

**② 표제어**
- 1순위 **燥邪 — 燥性乾澀·易傷津液, 燥易傷肺(外燥·秋燥)** 80%
- 2순위 **內燥(津傷化燥, 物독 마름 기호 해당 시)** 10%

**③ 잔결**
- 빈 물통이 內燥 기호(밑동까지 마른 물독)인지 단순 津液 고갈 보조인지 불명. 초가집은 外(담 바깥) 경계 외의 뜻 없음으로 판단. 잘림 없음. 수 오류 없음.
