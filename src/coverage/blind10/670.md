# blind10 / 670 판독

## 1단계 — 생판 (사전 없이 그림만)

**소품 전수**
- 붉은 벽돌담 배경(평면 무대) 앞에 비늘갑옷 무사 2명이 나란히 섬. 생김·자세·장비가 동일한 복제 인물. 오른쪽 인물이 왼쪽의 약 1.3~1.4배 크고 더 앞에 섬.
- 각 인물: 꼭지 달린 투구, 초록 물고기비늘 갑옷(어깨·가슴·치마·가운데 방패꼴 앞가리개), 가슴끈 단추 2개씩, 허리띠, 무릎까지 걷어 올린 회색 바지, 소매 걷어 올린 속옷.
- 들어 올린 한쪽 손(화면 오른쪽): 손바닥 앞으로, 손가락 5개 벌림, 손등·손가락에 검은 반점 여러 개(인물당 8~10개), 손톱이 검고 길다.
- 늘어뜨린 반대쪽 팔: 소매 걷힌 맨팔이 가늘고 갈색 힘줄·핏줄이 도드라져 말라붙은 모양(한쪽만 枯).
- 바지 아래 두 정강이: 뼈가 드러나듯 가늘고 말라 있음(두 사람 모두).
- 오른쪽 아래 작은 별 모양 표식(워터마크로 보임).

**읽기**: 갑옷 무사 = 衛(지킴·營衛), 두 명 = 營·衛 한 쌍, 한쪽 팔만 마름 = 偏枯/不用, 반점 손 = 不仁(麻木) 또는 汗出偏沮, 마른 다리 = 痿·羸瘦. 비늘갑옷 = 肌膚甲錯 가능.

**표제어**
- 1순위 **榮衛俱虛 → 不仁且不用(肉苛, 素問·逆調論 — 榮氣虛則不仁, 衛氣虛則不用)** 35% — 두 衛士=榮衛, 크기차=榮虛衛實, 반점 손=不仁, 늘어진 팔=不用.
- 2순위 **偏枯(半身不遂 — 靈樞·刺節真邪 營衛稍衰·邪氣獨留 / 素問·生氣通天論 汗出偏沮使人偏枯)** 30% — 한쪽 팔만 枯, 반대 손의 반점=汗.
- 3순위 肌膚甲錯·羸瘦(大黃䗪蟲丸) 10%.

**어색·잘림**: 손등 반점의 뜻(땀·멍·麻木?) 불명. 두 인물의 크기차가 의도인지 원근인지 불명. 두 인물 발 모두 아래 프레임에 잘림, 오른쪽 인물의 든 손이 오른쪽 가장자리에 잘림, 투구 꼭지가 상단에 닿음.

## 2단계 — 계통 (사전 어휘로 재독)

사전으로 보면 1단계의 「衛士」 독법은 틀렸다. **초록 비늘갑옷 장군 = 肝**이 전담 기호이므로 두 인물은 營衛가 아니라 **肝의 의인화**다. 그러면 소품이 한 글자씩 풀린다.

- 걷어 올린 소매 + 맨팔뚝 위에 도드라진 갈색 힘줄 = **充**(걷어올린 맨팔뚝 위에 더해진 것) + **筋**(도드라진 갈색 힘줄 다발) → 「其充在筋」.
- 손가락 5개를 쫙 펴서 손톱을 내보임 = **爪** → 「其華在爪」(華=광택은 뚜렷하지 않으나 손톱 자체를 내보이는 장치).
- 크게 뜬 눈 = **目** → 「開竅於目」 보조.
- 정강이의 곧은 능선과 뼈 혹 = **骨**/筋 — 마른 사지 = 罷極(피로).
- 손등 반점: 사전 갈림에 따라 살갗 위 얼룩은 瘀가 아니라 「그 자리의 색」 → 검푸른 점 = **蒼**(其色蒼) 후보. 확신 낮음.
- 같은 인물 둘, 하나가 더 큼 = **大** 후보이나 배수가 약 1.35배로 「두 배」에 못 미침 — 원근일 가능성도 있어 미결.
- 벽돌담 = 內/外·裏의 담이나, 문도 안팎 구분도 없어 무대 배경으로만 읽음.

**표제어**
- 1순위 **肝 — 其充在筋·其華在爪(素問·六節藏象論 「肝者罷極之本, 魂之居也, 其華在爪, 其充在筋, 其色蒼」)** 55%
- 2순위 **肝主筋·開竅於目·其華在爪(장상 肝 계통 — 肝氣衰則筋不能動)** 25%
- 1단계의 營衛·偏枯 독법은 5% 이하로 내림.

**잔결**: 손등 반점의 글자(蒼? 汗?) 미확정 · 두 인물 복제와 1.35배 크기차의 뜻(大?) 미확정 · 두 인물 발 잘림, 오른쪽 인물 든 손 가장자리 잘림 · 우하단 별 표식은 소품 아님(워터마크).
