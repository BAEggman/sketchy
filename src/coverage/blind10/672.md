# blind10 / 672 판독

## 1단계 — 생판 (사전 없이)

**① 소품 전수와 나르는 사실**
- 밤 방구석 바닥에 주저앉아 벽에 기댄 남자 1명(기운 빠져 쓰러진 자세) → 熱病 중증·臥不安
- 창문(2열×3단 ≒ 6칸) 밖 초승달 1개 → 밤·夜間 → 「身熱夜甚」
- 입 밖으로 길게 늘어뜨린 **검붉은(絳색) 혀** 1 → 舌絳(熱入營血)·吐舌(心經熱)
- 허공을 움켜쥐려는 갈고리 모양 오른손(손톱 5개 또렷) → 撮空理線·譫語·躁擾(또는 抽搐)
- 크게 뜬 눈 2 + 눈 밑 검은 그늘·한쪽 눈 옆으로 돌아감 → 心煩不寐·神昏·直視
- 풀어헤친 셔츠 아래 가슴의 희미한 붉은 반점 2곳(양쪽 대칭) + 광대 홍조 → 斑疹隱隱·身熱
- 바닥을 짚은 왼손(손톱 5) → 일어나지 못함(기력 쇠)
- 바닥 오른쪽 아래 회색 네모별(반짝임) 1 → 뜻 모름
- 어둡고 푸른 방·돌바닥 → 밤 무대 배경

**② 표제어**
- 1순위: **營分證(熱入營分, 淸營湯證)** — 60%. 身熱夜甚(달)·心煩不寐(눈)·時有譫語(허공 움켜쥠)·斑疹隱隱(가슴 반점)·舌絳(혀) 다섯 축이 한 사람에 모여 있다.
- 2순위: **血分證(熱盛動風·斑疹透露)** — 20%. 갈고리손을 抽搐으로, 가슴 반점을 斑疹으로 읽는 경우. 출혈·紫絳이 없어 2순위.
- 그 밖: 吐舌(舌態, 心經有熱·疫毒攻心) 10%, 陽明病 循衣摸床 5%.

**③ 뜻 모를 것·어색한 것·잘림**
- 바닥 오른쪽 아래 네모별 반짝임: 서명인지 「隱隱」 표지인지 불명.
- 가슴 붉은 얼룩 2곳이 斑疹인지 단순 음영인지 애매.
- 熱證인데 불꽃·땀 같은 열 표지가 하나도 없고 방이 차갑게 푸르다 — 어색.
- 프레임 잘림 없음(발·손·창 모두 안에 들어 있음).

## 2단계 — 계통 (blind6 사전 적용)

**① 소품 재독**
- 벌린 입 안에 **혀가 보임** → 사전 「舌 갈림: 혀가 보이면 心」 → 장부 축 = **心**. 혀가 「붉은 것」(血) → 心營·營血의 열.
- 크게 뜬 눈 → 目. 밤(달)에 目이 크게 열려 있음 → 不寐. 달은 사전에 없으나 「병표지 = 사람 곁에 크게 떠 있는 표지」 자리에 놓여 있어 이 사람의 병증 조건(夜甚)으로 읽힘.
- 갈고리손의 **손톱** → 爪(肝 영역). 爪가 도드라진 움켜쥠은 肝風(抽搐) 또는 譫妄의 撮空 — 血分 쪽 신호로도 읽힘.
- 가슴 얼룩 2 → 사전 「살갗 위 얼룩은 瘀가 아니라 그 자리의 색」 → 斑(斑疹)으로 확정.
- 불꽃 없음 → 熱 글자는 등재 기호로는 안 찍힘. 열은 혀색(血)과 밤(夜甚)으로만 암시.
- 방 안 → 內. 어둠·푸른 벽은 무대 배경. 바닥 네모별은 華(광택)로 읽기엔 자리(바닥)가 안 맞아 미해결.
- 얼굴에 耳·鼻·口도 다 열려 있으나 혀가 압도적이라 五官 목록 판은 아님.

**② 표제어**
- 1순위: **營分證(熱入營分)** — 55%. 心(혀)+血(붉음)+夜甚(달)+不寐(目)+斑疹隱隱(가슴)+譫語(손)이 사전 어휘로도 같은 자리에 맞춰짐. 사전 적용 후에도 1단계와 같은 결론.
- 2순위: **血分證(熱極動風)** — 20%. 爪가 肝 기호라 갈고리손=抽搐으로 읽으면 血分. 다만 출혈·紫絳 소품이 없음.
- 3순위: **吐舌(심경열성·疫毒攻心)** 15% — 舌態 판일 가능성.

**③ 잔결**
- 바닥 네모별 1개 뜻 모름.
- 달(夜)은 사전 미등재 기호 — 새 글자로 보임.
- 熱 전담 기호(불꽃)가 없어 熱證 판독은 간접 추론. 프레임 잘림·수 오류 없음.
