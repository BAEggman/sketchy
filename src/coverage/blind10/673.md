# blind10 / 673 판독

## 1단계 — 생판 (사전 없이)

**무대**: 돌담 앞 흙바닥 마당, 맨발 남자 셋이 가로로 나란히. 키는 셋이 비슷하고 가운데만 공중에 떠 있음.

**① 소품 전수**
- 좌(1인): 얼굴이 회청색으로 창백, 눈 휘둥그레·입 벌림(공포), 관자놀이 땀방울 1, 머리 위로 곧게 오르는 흔들 선 3~4가닥, 두 손 늘어뜨림, 발 밑 웅덩이 1(김 2~3가닥 오름 → 따뜻한 액체 = 오줌). → **恐則氣下**(공포 → 기가 아래로 → 遺尿·二便失禁, 面色蒼白·冷汗).
- 중(1인): 두 발 모두 땅에서 떨어진 도약, 머리카락 곤두섬, 눈 휘둥그레·입 벌림(화들짝), 몸 주변 흰 연기 뭉치 약 9개(8~10)가 사방으로 흩어짐. → **驚則氣亂**(놀람 → 기가 흐트러짐, 心無所倚·神無所歸·慮無所定).
- 우(1인): 턱 괴고 팔짱, 미간 찡그린 사색, 땀방울 1, 머리 위 흰 연기가 매듭으로 꼬인 덩이 1. → **思則氣結**(생각 → 기가 맺힘, 脾氣鬱結).
- 배경 돌담·흙바닥: 특별한 사실 없음(무대).

**② 표제어**
- 1순위: **七情內傷 — 恐則氣下·驚則氣亂·思則氣結**(『素問·擧痛論』 九氣 중 情志 셋) — 70%
- 2순위: **怒則氣上·恐則氣下·思則氣結**(중앙 곤두선 머리·솟는 김을 怒髮衝冠으로 읽을 경우) — 20%

**③ 뜻 모를 것·어색·잘림**
- 좌 머리 위로 「솟는」 선 3~4가닥은 氣下와 방향이 반대 — 冷汗 김인지 氣인지 불명.
- 중앙 연기 뭉치 개수는 겹쳐 있어 ±1 오차.
- 프레임 잘림 없음(바닥 돌판이 하단 테두리에 걸치는 정도).

## 2단계 — 계통 (사전 적용 후)

사전 어휘로 다시 읽으면 **氣 = 서린 흰 김**이 세 사람 공통의 소품이고, 그 김이 「어디로 가느냐」가 각 사람의 글자다.
- 좌: 김이 **아래로 쏟아져 고임 = 下**(사전 「下 = 아래로 가라앉거나 쏟아짐」) → **氣下**. 창백 얼굴·공포 표정이 恐을 지정 → **恐則氣下**. 발 밑 웅덩이는 요강(小便 기호)이 아니라 바닥에 직접 쏟아졌으므로 「失禁」의 뜻이 강해짐. 땀방울 = 汗(冷汗).
- 중: 김이 **사방으로 흩어져 날림 = 散**(사전 「散」) → 九氣에서 흩어짐에 해당하는 **氣亂**. 도약·곤두선 머리·화들짝 표정이 驚을 지정 → **驚則氣亂**.
- 우: 김이 매듭으로 꼬임 → **氣結**(사전 등재 없으나 자명). 턱 괴기·찡그림 = 思 → **思則氣結**.
- 무대: 돌담이 뒤에 있고 세 사람은 **담 안쪽 = 內** → 外感(담 바깥)이 아닌 **內傷**. 불꽃(熱)·눈송이(寒)가 없으므로 寒則氣收·炅則氣泄은 이 판에 없음. 오행왕국 인물(갑옷·곤룡포 등)도 없어 장부 귀속보다 氣機 변화 자체가 주제.

**② 표제어(재판정)**
- 1순위: **七情內傷 — 恐則氣下·驚則氣亂·思則氣結** — 80% (사전의 氣·下·散·內가 모두 맞물려 1단계 답을 강화)
- 2순위: **九氣(擧痛論)의 氣機 변화 — 氣上·氣下·氣亂·氣結** (좌 머리 위 곧게 솟는 김을 사전 「上」으로 읽으면 怒則氣上이 끼어드는 경우) — 15%

**③ 잔결**
- 좌 머리 꼭대기에서 곧게 솟는 김 3~4가닥은 사전상 「上」이라 氣下와 충돌 — 冷汗 증기로 보았으나 작화 혼선 가능.
- 중앙 김 뭉치 수(약 9)는 사실을 나르는지(개수) 장식인지 불명.
- 잘림 없음.
