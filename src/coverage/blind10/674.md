# blind10 / 674 판독

## 1단계 — 생판 (사전 없이)

**① 소품 전수**
좌판(살찐 남자, 회청색 옷)
- 비만 체형(우판 남자 너비의 약 1.5배) → 肥人多痰(痰濕 체질)
- 입에서 흰 끈적한 액 한 줄기 토함 + 사발 안 흰 끈적 액(사발 밖으로 3줄 흘러내림) → 嘔吐痰涎, 痰涎壅盛
- 한 손으로 머리 짚고 찡그림 → 頭痛·眩暈(「無痰不作眩」, 痰蒙淸竅)
- 목 옆 혹 1개(머리 지름의 약 1/3) → 痰核·癭瘤(痰이 經絡에 停留 → 腫塊)
- 발치 넘어진 붉은 항아리에서 회백색 걸쭉한 반죽이 쏟아져 고임 → 津液 停聚 → 痰飮(濁·黏·重)
- 볼 홍조 → 뜻 불명(痰熱? 또는 단순 화풍)

우판(마른 남자, 청록 옷·황색 바지)
- 전신 피부 자흑색, 입술 자색, 손가락·손톱 자색, 야윔 → 面色黧黑·口唇爪甲紫暗·肌膚甲錯
- 양 팔뚝 자색 반점 약 8개(좌 3·우 5) → 瘀斑·瘀點
- 한 손으로 가슴·옆구리 움켜쥠 → 刺痛·固定痛(胸脇痛)
- 바닥 검은 웅덩이 속 붉은 실뭉치 1개 → 血이 응결해 굳은 瘀血(腫塊·癥積)
- 웅덩이에서 흘러나가는 회청색 물줄기 1줄 → 血行不暢 / 離經之血(흐름 밖으로 나간 血)

**② 표제어**
- 1순위: **痰飮·瘀血(繼發性 病因/病理產物)** — 70%. 두 폭을 가른 비교판: 좌=痰飮의 임상, 우=瘀血의 임상.
- 2순위: **氣血津液辨證 — 痰證·血瘀證** — 15%.

**③ 뜻 모를·어색·잘림**
- 좌판 볼 홍조의 뜻 불명. 항아리가 깨지지 않고 넘어져만 있음(破가 아니라 傾).
- 우판 가슴 움켜쥠은 통증 기호인지 명시가 없음(관습적 몸짓으로만 읽힘).
- 좌 하단 항아리가 좌측 틀에, 우 하단 바위·물줄기가 우측·하단 틀에 잘림(의미 손실은 없음).

## 2단계 — 계통(사전 어휘로 재독)

사전으로 다시 읽으면 양 판이 「병표지=사람 곁에 크게 떠 있는 것」 구조임이 선명해진다.
- 좌: 항아리에서 쏟아진 **끈적한 회백색 덩이 = 痰**(사전 전담 기호) + 아래로 쏟아짐 = 下(津液이 가라앉아 고임 → 痰飮 生成). 입·사발의 흰 끈적 액도 같은 痰이며 사발 밖으로 넘쳐 흐름 = **盛** → 痰盛·痰涎壅盛. 목의 부풀어 팽팽한 혹 = **腫** → 痰이 뭉친 痰核·癭瘤. 비만 = 肥人多痰. 발밑에서 배어 나오는 진창이 아니므로 內濕이 아니라 痰이다.
- 우: 바닥의 검붉게 굳은 덩이(몸 밖, 웅덩이 위) = **瘀** 전담 기호 그대로, 붉은 것 = **血** → 瘀血. 곁의 물줄기는 맑은 흐름(津·脈流)에서 벗어나 고인 모습 → 離經之血·血行不暢. 갈림 조건에 따라 팔의 자색 멍·얼룩은 瘀가 아니라 **그 자리의 색**, 즉 皮膚·口唇·爪甲 紫暗이라는 望色 소견으로 읽는다(瘀血의 임상표현으로 자연 귀결). 손발 끝만이 아니라 전신이 자색이므로 厥은 아니다. 가슴 움켜쥠은 쇠못(痛) 기호가 없어 통증은 추정에 그친다.
- 두 사람 사이의 세로 담은 「두 병리산물의 병렬 비교」 무대.

**② 표제어**
- 1순위: **痰飮·瘀血(病理產物性 病因)** — 85%. 전담 기호 痰(회백 덩이)과 瘀(몸 밖 검붉은 덩이)가 각각 한 폭씩을 차지하는 비교판.
- 2순위: **瘀血의 臨床表現(紫暗·腫塊·固定痛)** 단독 강조판 — 10%.

**③ 잔결**
- 좌판 볼 홍조는 사전에 대응 기호 없음(面 광택도 아님).
- 痛의 전담 기호(쇠못)가 없어 固定痛은 몸짓 추정.
- 우판 물줄기가 津(맑은 물방울)인지 血脈 흐름인지 사전만으로는 확정 불가.
- 틀 잘림: 좌 하단 항아리, 우 하단 바위·물줄기(경미).
