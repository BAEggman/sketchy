# 675 판독 기록

## 1단계 — 생판 (사전 없이)

① 소품 전수 (왼→오)
- 증기선(굴뚝 2·깃발 1·연기) 부두 정박 → 개항(1876)·서양 문물 유입의 무대.
- 간판1: 물에 빠진 사람 1 + 갈고리 밧줄 → 구제(濟)? 뜻 미확정.
- 서양인 의사(금발·안경·흰 가운)가 사다리에서 액자 걸기, 액자 속 한 봉에 매달린 사람 3 → 서양 의료선교사(알렌) 입국. 액자 뜻 불명.
- 간판2: 흰 천막 + 사발 3 → 불명.
- 한옥 대문 열림: 좌 약장(서랍 약 20칸=4×5), 우 족자 속 청진기 → 한의·양의 병존.
- 간판3: 천막 + 올가미 밧줄 → 불명.
- 곤룡포 임금이 양복 남자와 동전 주고받음, 돈자루 1, 뒤 서양식 2층 건물(깃발·시계) → 고종이 알렌에게 자금·건물 지원 = 제중원(1885).
- 간판4: 줄다리기 2:2(4명) → 대립·논쟁(동서의학 대립?).
- 흰 두루마기·탕건 노인이 떨며 울음, 발밑 찢어진 종이 3조각 → 한의사 지위 격하(1913 의생규칙)·면허 박탈.
- 갓·옥색 도포 남자가 해골(전신 골격) 두루마리 펼침 → 한의계의 서양 해부학 수용(동서의학 절충).
- 공사 중 벽돌 건물(벽돌 4층+골조 1층, 크레인 1, 깃발 1, 인부 3) — 2층 건물의 약 2.5배 → 한의학 교육기관·근대 병원 건립.
- 밧줄 울타리(기둥 5) — 무대 구획.

② 표제어: 1순위 **한국 근대 의학사(개항 이후 서양의학 도입과 한의학의 수난·재건)** 70% · 2순위 **제중원 설립(고종·알렌, 1885)** 20%.

③ 뜻 모름: 액자 속 매달린 3인, 천막+사발 3, 천막+올가미, 간판이 7장면 중 앞 4장면에만 붙은 까닭. 프레임: 좌 부두 끝·우 건물 사다리 끝·울타리 양끝이 살짝 잘림.

## 2단계 — 계통 (사전요약 적용)

① 소품을 글자로 다시 읽음
- 간판1 「물에 드리운 밧줄에 건져 올려지는 사람」 = **濟**.
- 의사의 액자 「한 봉에 여럿(3) 매달림」 = **衆** → 濟+衆 = **濟衆(제중원)**. 서양 의사가 이 액자를 직접 거는 것 = 알렌이 「제중원」으로 개명.
- 간판2 「넓게 펼친 차양(廣) + 받아 드는 빈 사발(惠)」 = **廣惠(광혜원)** — 1885 첫 이름.
- 간판3 「차양(廣) + 드리운 밧줄(濟)」 = **廣濟(광제원)** — 1900 내부병원 개칭; 그 아래 한옥의 약장+청진기 = 광제원의 한·양의 병존.
- 간판4 「한 밧줄을 여럿이 함께 당김」 = **同** → 정부(고종)와 선교의(알렌)의 공동 운영, 또는 同濟醫學校(1904)·同仁醫院(1906) 가능 — 미확정.
- 곤룡포 임금 = 오행왕국의 心이 아니라 역사 무대의 王(고종).
- 찢긴 종이 = 傷(못 쓰게 된 문서) → 한의사 지위 격하·의생규칙(1913).
- 갓 = 太? 보다는 전통 한의사 표지; 해골 = 骨 → 한의계의 해부학 수용·동서의학 절충.
- 공사 중 벽돌 건물: 같은 서양식 건물이 둘이고 하나가 두 배 이상 = **大** → 大韓醫院(1907, 광제원 통합·한의사 배제) 가능. 1단계의 「한의대 건립」보다 이 쪽이 사전에 맞음.
- 증기선·울타리·크레인 = 무대·장식(글자 아님).

② 표제어: 1순위 **개항기 근대 의료기관의 변천 — 광혜원(廣惠院)→제중원(濟衆院)→광제원(廣濟院)→대한의원과 한의학의 격하** 65% · 2순위 **제중원·광혜원 설립과 개칭(1885, 고종·알렌)** 20% · 3순위 한국 근대 의학사 통사 10%.

③ 잔결: 간판4 同의 지시 대상(공동운영/동제의학교/동인의원) 미확정; 갓을 太로 읽어야 하는지 불명; 벽돌 건물 大韓醫院 추정은 간접; 사발 3·매달린 3인의 「3」이 久(셋 포갬)와 혼동될 여지 있으나 포개지지 않아 惠·衆으로 읽음.
