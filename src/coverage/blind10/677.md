# blind10 / 677 판독

## 1단계 — 생판 (사전 없이)

### ① 소품 전수와 나르는 사실
무대 없이 소품 넷이 2×2로 놓였다. 넷 다 「담는 것 + 담긴 것」 꼴이다.
1. **돌우물(石井, 벽돌 4단)** 안에 **붉은 관(管)이 Y자로 갈라지며 엉킨 다발** — 테 밖으로 늘어진 가닥 좌3·우3 = 6, 안쪽 엉킴 8~10가닥. 붉고 가지치는 관 = 血脈. 우물 속은 물 없이 희다.
2. **초록 풀둔덕(陵)** 위 **콘크리트 둥근 테(샘·泉)** 안에 **노란 국수 같은 가닥 뭉치** — 테 밖으로 3가닥 흘러내림. 노랗고 질긴 가닥 = 筋(힘줄). 둔덕 너비 ≈ 우물의 1.2배.
3. **길쭉한 나무 베틀북(杼·梭, 양끝 쇠촉)** 안에 **흰 긴 뼈 1개(끝에 공 모양 뼈 혹, 혹 지름 ≈ 몸통 굵기의 3배) + 작은 뼈 조각 1** — 옆구멍으로 실 한 가닥이 빠져나와 늘어짐. 북 길이 ≈ 우물 너비의 1.5배.
4. **들보에 매단 종(懸鐘, 띠 3줄)** — 속이 크림색 골수 같은 것으로 차 있고 **추(舌)가 없다**. 종 높이 ≈ 우물 높이.

### ② 표제어
- 1순위 **八會穴 — 脈會 太淵(우물=淵+혈관) · 筋會 陽陵泉(둔덕=陵+샘=泉+힘줄) · 骨會 大杼(북=杼+뼈) · 髓會 絶骨=懸鐘(매단 종+골수)** — 80%
- 2순위 **五體(筋·脈·骨) / 奇恒之腑(脈·骨·髓)** 묶음 — 12%

### ③ 뜻 모를 것·어색함·잘림
- 종에 추가 없고 속이 크림색으로 찼다 — 골수(髓)인지 그냥 안쪽 음영인지 애매.
- 「大」杼·「太」淵의 大·太가 따로 그려지지 않음(북 하나·우물 하나뿐).
- 노란 가닥이 국수로도 읽혀 筋인지 麵인지 생판에서는 흔들림.
- 프레임 잘림 없음. 네 소품 다 온전.

## 2단계 — 계통 (blind6 사전 적용)

### ① 소품 재독
사전과 맞아떨어지는 항목: **杼 = 실 한 가닥이 옆구멍으로 빠져나온 길쭉한 나무 베틀북**(정확히 일치) · **骨 = 흰 뼈·끝의 뼈 혹** · **筋 = 도드라진 갈색 힘줄 다발**(노란 가닥 뭉치) · **會 = 담는 것 안에 담긴 것** — 네 소품이 모두 「그릇 안의 내용물」이라 會가 네 번 반복된다 → 「○會」 넷.
- 우물 안 붉은 가지친 관: 사전의 血(붉은 것)로도 읽히나 Y자 가지치는 관 꼴이라 脈(혈관)이 맞다. 우물=淵 → **脈會 太淵**.
- 초록 둔덕(陵)+둥근 테(泉)+筋 → **筋會 陽陵泉**. 陽(해·불)은 안 그려짐.
- 杼+骨 → **骨會 大杼**. 사전의 大(둘 나란히 하나가 두 배)는 안 쓰였다 — 杼만으로 특정.
- 들보에 매단 종(懸鐘)+속의 크림색 = 髓 → **髓會 絶骨(懸鐘)**. 사전의 痰(회백색 끈적 덩이)과는 색·결이 달라 髓로 둔다.
- 사전의 太(큰 갓)·膈(흰 천)·中(한복판) 없음 → 血會膈兪·氣會膻中·臟會章門·腑會中脘은 이 판에 없다.

### ② 표제어
- 1순위 **八會穴 중 筋·脈·骨·髓 넷 — 筋會陽陵泉·脈會太淵·骨會大杼·髓會絶骨(懸鐘)** — 88%
- 2순위 **奇恒之腑(脈·骨·髓) 또는 五體(筋·脈·骨)** — 7%

### ③ 잔결
- 종 안의 크림색이 髓라는 전담 기호는 사전에 없음(새 글자). 추 없는 종이 絶을 뜻하는지 불명.
- 大·太·陽이 사전 기호로 그려지지 않아 혈명은 杼·淵·陵泉·懸鐘만으로 특정한다.
- 잘림·수 오류 없음.
