# 680 판독 (블라인드)

## 1단계 — 생판 (사전 없이)

① 소품 전수
- 초록 비늘갑옷·초록 투구(꼭지 뾰족, 테에 못 약 6개)를 입은 수염 난 장군 1명 — 「肝者 將軍之官」. 초록·청색 일색(갑옷·투구·벽) = 肝의 色 靑. 갑옷=甲(甲木).
- 들어올린 오른손(관객 좌측) 손가락 5개 쫙 펼침, 손톱 5개 모두 검붉은 포도주색. 얼굴보다 약 1.3배 크게 그려짐 = 손톱이 주역 → 肝 其華在爪·肝血充足이면 爪甲紅潤.
- 늘어뜨린 왼팔: 소매 걷어 맨팔뚝, 팔뚝·손등에 갈색 힘줄 선 뚜렷, 손톱 5개도 붉음(총 붉은 손톱 10개) → 肝主筋.
- 창문(열린 창 1짝) 밖 가지에 새잎 약 20장 돋은 봄 나무 → 肝은 春·木·生發.
- 또렷이 뜬 두 눈 → 肝開竅於目(약하게).
- 샌들 2켤레, 맨발가락 노출(발톱은 붉지 않음).

② 표제어
- 1순위 **肝의 장상 총론(肝主筋·其華在爪·開竅於目·色靑·通於春)** 85%
- 2순위 **肝者 將軍之官, 謀慮出焉** 45%

③ 잔결: 수염·투구 꼭지·비늘 무늬의 뜻 불명. 손톱만 붉고 발톱은 흰 것이 어색(爪 범위 불일치?). 창문은 「竅」인지 「봄 배경」인지 애매. 프레임 잘림 없음(전신·창 모두 온전).

## 2단계 — 계통 (사전 적용)

① 사전 어휘로 재판독
- 「초록 비늘갑옷 장군 = 肝」 확정 → 장군 자체는 사실이 아니라 글자. 將軍之官은 표제어에서 내림.
- 爪 = 손톱, 血 = 붉은 것 → 붉은 손톱 10개 = 「爪에 血」 = 肝藏血·肝血→爪 (其華在爪). 다만 華 = 광택인데 손톱에 광택 없음(약점).
- 充 = 걷어올린 맨팔뚝 위에 더해진 것, 筋 = 도드라진 갈색 힘줄 → 걷은 소매 + 팔뚝 힘줄 = **其充在筋** 정확히 성립.
- 目 = 크게 뜬 눈 → 開竅於目. 竅(어두운 구멍)는 없음.
- 通 = 안팎이 한 덩어리로 이어짐 → 열린 창으로 봄 가지가 안으로 들어옴 = **通於春氣**. 風(옆으로 눕는 것) 아님.
- 초록 일색 = 其色蒼. 酸(매실)·魂·陽中之少陽 소품은 없음.
- 요약하면 素問·六節藏象論 「肝者…其華在爪, 其充在筋, 以生血氣, 其色蒼, 通於春氣」 한 구절이 한 판에 들어 있음.

② 표제어
- 1순위 **肝 — 其華在爪·其充在筋·通於春氣(六節藏象論 肝 장상)** 90%
- 2순위 **肝主筋·開竅於目·其華在爪(肝 생리 묶음)** 40%

③ 잔결: 수염·투구 꼭지·갑옷 못 개수 뜻 불명. 발톱이 붉지 않아 「爪=血」과 어긋남. 손톱에 광택이 없어 華 기호와 불일치. 잘림 없음.
