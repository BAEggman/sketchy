# blind10 / 681 판독

## 1단계 — 생판(사전 없이)

**① 소품 전수**
- 돌 문틀 + 활짝 열린 나무문(경첩 2개) → 사람이 **문지방 한가운데** 서 있음 = 半表半裏(안도 밖도 아님). 경첩·문 = 樞(少陽爲樞) 암시.
- 환자(가운·슬리퍼, 문 높이의 약 2/3): 눈 질끈 감고 얼굴 찡그림(目眩/默默), 오른손으로 옆구리·명치를 움켜쥠 = 胸脇苦滿. 땀 없음.
- 벽의 추 1개가 **불꽃(왼쪽) ↔ 눈송이(오른쪽)** 사이를 왕복 = 寒熱往來.
- 양팔 저울 1개, **수평** = 和解(和法).
- 쟁반 위 약재 3개: 회색 뿌리(柴胡) · 속 빈 노란 뿌리(黃芩, 枯芩의 빈 속) · 둥근 흰 덩이뿌리(半夏) → 小柴胡湯의 핵심 세 약.
- 문지방 위 작은 잔(검은 액체) 1 + 떨어지는 물방울 1 = 口苦 / 咽乾(한 방울뿐).
- 바닥: 접힌 수건 1 · 엎어진 빈 대야(잔의 4배) 1 · 쓰러진 빈 항아리 1 + 뚜껑 1 = 汗·吐·下 세 도구가 버려짐 = 少陽三禁(不可發汗·吐·下) 또는 不欲飲食·喜嘔.

**② 표제어** — 1순위 **少陽病(少陽證·소양병 제강: 口苦·咽乾·目眩 + 寒熱往來·胸脇苦滿·半表半裏·和解)** 60% / 2순위 **小柴胡湯** 25% (기타 和法 8%, 瘧疾 5%).

**③ 잔결** — 가운·수건·대야·항아리가 「목욕 장면」으로도 읽혀 三禁인지 목욕(發汗 금지)인지 애매. 물방울이 잔으로 떨어지는 의미(口苦인지 咽乾인지) 불명. 항아리 옆 둥근 뚜껑의 역할 불명. 프레임 잘림 없음.

## 2단계 — 계통(사전 어휘로 재독)

사전을 대니 생판의 뼈대가 거의 그대로 확정된다.
- 불꽃 = 熱, 눈송이 = 寒(外寒), 사람 곁에 크게 떠 있는 두 표지 = 「병표지」→ 그 사람의 병증이 寒·熱이고, 추가 둘 사이를 왕복하므로 **寒熱往來**. (추는 「내리누르는 추(降)」가 아니라 옆으로 흔들리므로 降이 아님.)
- 문 밖 = 表, 문 안쪽 = 內/裏, 작은 문간 = 門 → 문틀 한복판에 선 환자 = **半表半裏** 확정.
- 양팔이 수평으로 멎은 저울 = **和** 확정 → 和解少陽.
- 검은 커피 같은 잔 = **苦** → **口苦** 확정(김은 안 오름). 밑동까지 마른 물독(쓰러진 빈 항아리) = 內燥 계열 → **咽乾**. 눈을 감은 얼굴은 사전의 目(크게 뜬 눈)이 아니므로 目眩은 기호 아닌 표정으로만 실림.
- 쇠못이 없으므로 옆구리 손은 痛이 아니라 **苦滿**(胸脇苦滿)으로 읽는 것이 맞음.
- 빈 대야·항아리는 내용물이 넘친 것이 없어 瀉-b가 아니고, 깨지지 않아 傷도 아님 → 「쓰지 않은 도구」= 三禁(汗·吐·下 금지) 또는 不欲飲食으로 유지. 요강(小便) 가능성은 낮음(손잡이 달린 항아리형).
- 약재 3종은 사전에 없음(地黃 아님) → 柴胡·黃芩·半夏 유지.

**② 표제어** — 1순위 **少陽病(少陽證 — 口苦·咽乾·目眩·寒熱往來·胸脇苦滿·半表半裏·和解)** 70% / 2순위 **小柴胡湯(和解少陽)** 20% (和法 7%, 瘧疾 3%).

**③ 잔결** — 수건의 전담 글자가 사전에 없어(汗은 살갗 땀방울) 여전히 해석 보류. 물방울 1개가 津(맑은 물방울)인지 쓴 액체의 일부인지 불명. 추 모양이 저울추(降)와 겹쳐 처음 보는 독자가 오독할 소지. 수 오류·잘림 없음.
