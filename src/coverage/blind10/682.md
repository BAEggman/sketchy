# blind10 / 682 판독

## 1단계 — 생판 (그림만 보고)

**무대**: L자형 석재 조리대(약방·주방 카운터) + 앞쪽 원목 수납장. 뒤에 두 인물.

**소품 전수**
1. 밀짚모자 농부(좌) — 흰 사발 하나를 두 손으로 들고 들여다봄 → 「嘗/服」(맛보기·복용), 神農(농부) 암시 가능.
2. 흰 도포·사제 칼라 인물(우) — 흰 종이 쪽지(약첩?) 1장을 듦 → 醫/藥師 혹은 道士(陶弘景?).
3. 두 사람 사이 흰 김 한 줄기 → 蒸(찜) 또는 湯.
4. 노란 사발 + 흰 원판 1개 담김 → 蜜炙/酒炙(노란 액체 보조재).
5. 회색 사발 + 흰 액체 + 같은 흰 원판 1개 → 水製(米泔水·鹽水·乳 등). 같은 원판을 두 액체에 담근 대비.
6. 흰 반죽 덩어리 위 검남색 콩알 ~9개 + 주변 흩어진 ~6개(합 ~15) → 黑豆汁 製(製何首烏류) 또는 麵裹.
7. 붉은 고추 1개 → 辛/薑汁炙.
8. 접힌 베이지 종이·천 1장 → 紙煨(濕紙裹) 또는 製霜용 종이.
9. 회색 돌 1개가 부스러짐 + 조각 ~13개 → 煅(소성해 酥脆하게).
10. 흰 공 1개 + 검게 탄 구멍난 덩어리 1개 + 검은 연기 기둥 1줄기, 그 위에 붉은 X → 「炒炭存性」: 生도 X, 灰化(완전 소각)도 X.
11. 쇳덩이 추(저울추 모양) 1개가 풀 화분 위에 떠서 누름 → 壓(壓去油·製霜) 또는 沉降/重.
12. 수납장에 반짝이 ✦ 1개 → 淨製/신선·청결.
크기: 추 ≒ 화분 크기, 돌은 종이의 1/3, 고추 ≒ 반죽 덩어리 높이.

**표제어**
- 1순위 **炮製法(修治·飲片 가공)** — 蜜炙·水製·黑豆汁·薑製·煨·煅·炒炭存性·壓油가 한 판에 모임. 50%
- 2순위 **升降浮沉과 炮製의 약성 변화**(추=沉降, 김=升, 酒升·薑散·鹽下行) 20%
- 3순위 **本草學 역사(神農 嘗百草·陶弘景)** 10%

**뜻 모름·어색·잘림**: 사제 칼라 인물의 정체 불명확(의사? 도사?); 농부 사발 속 내용물 안 보임; 수납장 반짝이의 의미 불명; 추가 풀 위에 공중부양한 것이 어색; 흰 공과 검은 덩어리 둘 다 X 안에 있어 어느 쪽을 금하는지 모호; 우측 하단 검은 덩어리가 프레임 가장자리에 걸침; 프레임 잘림은 없음.

## 2단계 — 계통 (사전요약 적용 후)

**사전으로 다시 읽은 소품**
1. 노란 밀짚모자 농부 = **脾**(확정 기호). 흰 사발을 받아 듦 → 脾가 받는 것(水穀·補).
2. 흰 도포 재상 = **肺**(확정 기호). 흰 쪽지(얇은 접시?)를 듦.
3. 둘 사이 한복판의 흰 김 = **氣**(서린 흰 김) — 脾와 肺 「둘 사이의 中」에 놓임 → 脾·肺가 함께 만드는 氣(宗氣·中氣).
4. 붉은 고추 1개 = **辛**(접시 위 붉은 고추와 동형). 肺 쪽에 가깝다 → 辛入肺.
5. 노란 사발(꿀빛) + 원판 = **甘**(꿀)에 가까움, 농부 쪽 → 甘入脾. 찰랑찰랑 찬 그릇 → 補.
6. 흰 사발 + 흰 내용물 = **鹹**(굵은 소금)? 또는 淡(맑은 물). 미확정.
7. 회색 돌이 사방으로 흩어짐(조각 ~13) = **散**(사방으로 흩어져 날리는 것) → 辛能散 / 肺主宣發 / 脾氣散精.
8. 풀 화분을 내리누르는 저울추 = **降**(갈림: 누르는 추일 때 降 — 조건 충족) → 肺主肅降 / 苦·鹹 能降.
9. 검게 탄 덩어리 + 검은 연기 = **苦**(김 나는 검은 것)에 가장 가까움, 붉은 X → 禁(肺病禁苦?). 흰 공은 痰(회백색 덩이)?
10. 흰 끈적 반죽 덩어리(검남색 알 ~9+6) = **痰**(끈적한 회백색 덩이) 후보. 알갱이는 瘀(검붉게 굳은 알갱이)로 읽기엔 색이 검남색이라 미달.
11. 수납장 위 반짝이 = **華**(광택). 肺 其華在毛(옆의 가는 풀잎=毛?)로 잇기엔 약함.
12. 접힌 베이지 천 = 收(삼베 자루)와 비슷하나 아가리를 조인 자루가 아니라 미확정. 酸(초록 매실)은 화면에 없음.

**판정**: 1단계의 炮製 읽기는 사전 기호(脾·肺 의인화, 氣·散·降)로 더 잘 풀린다. 두 臟이 나란히 서고 그 사이에 氣, 카운터에 음식(水穀)과 五味, 그리고 散(宣발)·降(숙강)이 배치됨.

**표제어**
- 1순위 **脾肺 관계(土生金) — 脾 水穀精氣 + 肺 淸氣 → 氣 생성, 脾氣散精·上歸於肺, 肺 宣發(散)·肅降(降)** 40%
- 2순위 **五味의 作用과 所入 — 辛散(辛入肺)·甘補(甘入脾)·苦降泄·鹹軟堅, 辛甘發散爲陽** 30%
- 3순위 1단계의 **炮製法** 10%

**뜻 모름·어색·잘림**: 검남색 알 ~15개가 박힌 흰 덩어리의 글자 불명(痰+?); X 안의 흰 공·검은 덩어리 짝의 글자 불명(痰·瘀? 苦?); 재상이 든 흰 쪽지; 수납장 반짝이(華)가 무엇의 華인지; 접힌 천; 酸 부재; 프레임 잘림 없음(우하단 검은 덩어리는 가장자리 근접).
