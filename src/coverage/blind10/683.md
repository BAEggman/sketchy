# 683 판독 기록

## 1단계 — 생판 (사전 없이)

**① 소품 전수**
- 왼쪽 지붕 위 **금관 3개**(세 채 건물에 하나씩) → 王·왕실 기관이 셋 / 세 임금.
- 붉은 곤룡포·익선관 **임금 1명**이 이젤 위 두 폭 그림판을 가리킴. 그림판 왼폭 = 절구·공이(약 조제), 오른폭 = 두 손이 빛나는 싹(불꽃?)을 감쌈. 판 둘레에 **화살표 3개**(회전) → 이름이 바뀌었다가 돌아온다·개칭.
- 누각 교실: 책 펼친 **여교사 2명**, 바닥에 앉은 **학생 7명**(뒷줄 4·앞줄 3) → 의학 교육(博士 2인?·교재 7종?)·의녀 교육.
- 중앙 큰 청기와 관청(가장 큼): **사다리 1**, 큰 현판 「갓 + 끈 달린 긴 통(침통?)」, 그 옆 작은 현판 「기와집 그림」(큰 판이 약 2배) → 의료 관청 설치·개칭.
- 가게(약국 창구): 간판 「손이 사발을 건넴 | 끈으로 묶은 꾸러미 3단」, 창구 관원 1, **사다리에서 현판을 다는 남자 1**, 줄 선 백성 **6명** + 꾸러미 받은 사람 **3명**(자루 2) → 서민에게 약을 나눠 줌(혜민).
- **자물쇠 달린 큰 궤짝 1**, 뚜껑 열림, 안에 꾸러미 **6개**, 바닥 자루 1 → 국가 기금·창고에서 약재 분급.
- 오른쪽: 창살 창 안의 사람 1 + 작은 짐승 1, **흰 도포 인물 4명**(사다리 옆 가리키는 이·광주리 든 이·먼 오른쪽 서 있는 이·아래 아이), 지붕에 오른 남자 1, 둥근 약재(열매·뿌리) 담긴 **광주리 ~10개**(4-3-2단 + 2) → 약재 수집·보관, 병자 수용.

**② 표제어**
- 1순위 **조선 전기 의료제도 — 三醫司(內醫院·典醫監·惠民署)와 活人署·의녀 교육** (40%) : 금관 3=삼의사, 임금=내의원, 교실=전의감/의녀, 혜민 가게=혜민서, 창살·흰옷=활인서.
- 2순위 **세종대 향약 정책(鄕藥採取月令·鄕藥集成方)** (25%) : 임금이 절구·싹 그림을 가리킴 = 향약 장려, 광주리 약재 = 향약 수집.

**③ 뜻 모를 것·잘림**
- 갓 밑 끈 달린 긴 통(침통? 호패?)·창살 안 사람과 짐승·흰 도포 넷의 뜻 불명. 임금 판의 회전 화살표가 무엇과 무엇의 개칭인지 불명. 좌하·우하 건물과 우상 지붕이 프레임에 잘림.

## 2단계 — 계통 (사전 적용)

사전으로 다시 읽으면 글자가 바로 떨어진다.
- **王 = 왕관** ×3 → 임금 셋(무대가 어느 왕인지 짐). **藥 = 약연**(절구로 그림) + **保命 = 두 손으로 감싼 등잔불** 이 한 판에서 회전 화살표로 맞붙음 → 신라 **藥典 ⇄ 保命司**(景德王 개칭 → 惠恭王 復舊). 세 왕관 = 孝昭王(醫學 설치)·景德王·惠恭王. 교실의 **博士 2인 + 학생 7명** = 醫學(692) 博士 二人·교재 7종(本草·甲乙·素問·針·脈·明堂·難經).
- 중앙 관청 현판 **太 = 테 넓은 갓** + 긴 침통(醫) → **太醫監**, 옆의 작은 **寺 = 기와집 한 채** 현판 + 사다리 = **典醫寺**로의 개칭. 두 현판 하나가 2배 → **大**(大醫監 異稱).
- 가게 간판 **惠 = 손이 건네는 사발** + 줄 선 백성(民) + **典藥 = 끈으로 묶은 약봉지 다발** → **惠民局**(약 분급·판매). 자물쇠 궤짝에 쌓인 典藥 = 기금 **寶 → 濟危寶**. 
- 오른쪽 두 채(크기 2배 = **大**)·창살 안 병자·흰 도포(승려?) → **東西大悲院**. 광주리 ~10개 = 약재·곡식 비축(**倉/藏**에 가까움).

**② 표제어**
- 1순위 **한국 의학사 — 통일신라·고려 의료제도 변천(藥典→保命司·醫學 / 太醫監↔典醫寺·惠民局·濟危寶·東西大悲院)** (55%)
- 2순위 **조선 전기 의료제도(三醫司·活人署·의녀)** (25%) — 1단계 해석. 사전을 쓰면 太·寺·保命·惠·典藥이 모두 신라·고려 기관명으로 풀려 2순위로 내린다.

**③ 잔결**
- 왼쪽 세 왕관이 「세 왕」인지 「왕실 기관 셋」인지 그림만으로는 못 가른다. 흰 도포 4명 — 사전의 肺(흰 도포 재상)와 겹치나 장부 의인화 무대가 아니므로 肺가 아니라고 판정(승려·구호자?). 창살 안 짐승·오른쪽 지붕 위 남자·광주리 내용물 뜻 불명. 濟(밧줄) 글자가 없어 濟危寶는 궤짝=寶 하나로 추정. 좌하·우하·우상 잘림.
