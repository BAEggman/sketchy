# 684 판독

## 1단계 — 생판 (기호 목록 보기 전)

**① 소품 전수**
- 왼쪽 남자(청록 도포): 마르고 늙고 근심 어린 얼굴, 몸을 뒤로 축 늘어뜨림 → 겉모습은 약해 보임(羸狀). 팔짱은 가슴 위(배를 막고 손대지 못하게 하는 자세 → 拒按 쪽).
- 왼쪽 남자의 배: 반들반들 팽팽하게 부푼 둥근 배(하이라이트까지) → 속은 실함(大實, 腹滿).
- 검은 무쇠솥 1개(다리 3개, 비어 있음) + 뚜껑 1개를 벗겨 옆에 세워둠 → 열어서 비우는 것 = 瀉·下法(실한 쪽 치법).
- 오른쪽 남자(황색 도포): 건장·웃는 얼굴, 도포가 몸의 약 2배로 부풀고 좌우 흔들림선(2벌) → 겉모습은 성대함(盛候).
- 두 손으로 도포 앞섶을 벌려 보인 배: 안은 홀쭉하고 오목, 배꼽·털 → 겉만 크고 속은 빔(至虛). 스스로 눌러도 웃음 → 喜按·按之不痛 = 虛.
- 인삼 1뿌리(사람 모양, 얼굴·팔다리, 누워 있음), 오른쪽 남자 발치 → 補法(허한 쪽 치법).

**② 표제어**
- 1순위: **허실진가(虛實眞假) — 至虛有盛候·大實有羸狀** (45%). 왼쪽=羸狀인데 대실 → 瀉(솥), 오른쪽=盛候인데 지허 → 補(인삼).
- 2순위: **복만(腹滿) 허실 감별 — 按之不痛爲虛, 痛者爲實** (25%). 그 밖에 塞因塞用(10%), 虛虛實實之戒(10%).

**③ 잔결**
- 솥이 왜 왼쪽(실증) 옆인지·뚜껑이 무엇인지 확정 못 함(瀉/下? 釜底抽薪이라면 불이 없음).
- 도포 색(청록·황색)이 오행 기호인지 불명.
- 프레임 잘림 없음. 수는 사람 2·솥 1·뚜껑 1·인삼 1·솥다리 3.

## 2단계 — 계통 (blind6_사전요약 어휘로 재판독)

**① 소품 재판독**
- 왼쪽 배: 반들반들 팽팽하게 부푼 배 = **實**(팽팽하게 찬 것). 「腫」(부풀어 팽팽)과도 겹치나, 사람 몸통 한복판의 차오름이라 實로 읽음. 가는 팔다리·늘어진 자세·근심 얼굴 = 羸狀(사전 밖, 그림 그대로).
- 두 배 비교: 같은 종류 둘(배 둘)이 나란한데 왼쪽 배가 오른쪽의 드러난 속배보다 약 2배 = **大** → 왼쪽 = 「大實」.
- 오른쪽: 도포가 몸의 약 3배로 부풀고 흔들림선(겉이 성대 = 盛候 쪽). 두 손이 앞섶을 벌려 보인 실제 몸통은 겉부피의 약 1/3 = **虛**(삼분의 일로 줄어든 것). 두 손 사이 몸 한복판 = 中 → 中滿(허성 창만)의 그림.
- 인삼 1뿌리(사전 밖 실물 약재) = 補氣 → 虛 쪽(오른쪽) 치법.
- 빈 무쇠솥 + 뚜껑 벗김: 사전의 補(국물 찬 그릇)가 **아님** — 오히려 텅 빈 그릇이라 瀉-b 쪽이지만 쏟아진 내용물이 없어 조건 미충족. 실한 쪽(왼쪽) 곁이라 「補하지 말고 비워라(下)」로 어림.
- 도포 색(청록·황색)은 오행 인물(갑옷 장군·밀짚모자 농부)이 아니므로 臟 기호 아님 → 見肝傳脾 독해 폐기.

**② 표제어**
- 1순위: **허실진가 — 大實有羸狀(眞實假虛) · 至虛有盛候(眞虛假實)** (60%). 大·實·虛 세 글자가 사전대로 맞물림.
- 2순위: **塞因塞用(虛性 中滿을 人蔘으로 補함)** (15%). 그 밖 腹滿 按診 허실 감별(10%, 痛=쇠못이 없어 약화).

**③ 잔결**
- 솥: 補도 瀉-b도 조건이 덜 맞음(빈 그릇이나 흘러넘친 것 없음). 다리 3개·뚜껑의 뜻 불명.
- 盛(넘쳐 흘러나옴) 기호가 없음 — 盛候는 도포 부피로만 읽힘.
- 팔짱(拒按? 身寒?) 사전 밖. 프레임 잘림 없음.
