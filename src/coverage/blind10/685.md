# 685 블라인드 판독

## 1단계 — 생판 (사전요약 열람 전 확정)

**① 소품 전수와 나르는 사실**
- 무대: 회색 빈 방 + 긴 나무 벤치 1. 방 전체가 무채색(회·백) → 「白色」 계열 분위기.
- 벤치 위 환자 3인(모두 얼굴·손·발이 하얗게 칠해짐 = 面色白):
  - 좌: 잿빛 도는 흰 얼굴, 다크서클·처진 눈썹·풀 죽은 표정 → 灰白·無華 = **蒼白**(陽氣暴脫/陰寒) 또는 淡白+神疲(氣虛).
  - 중: 깨끗한 창백 얼굴의 여인이 흰 수건을 펼쳐 듦, 수건에 핏자국(큰 얼룩 1 + 작은 점 1) → **失血 → 淡白無華**(血虛·脫血).
  - 우: 얼굴이 퉁퉁 부음(눈두덩까지 부어 눈 감김), 피부·옷에 번들거리는 광택, 입술 청자색 → **㿠白虛浮 = 陽虛水泛**(광택 = 㿠의 '빛나는 흰색', 청순 = 寒).
- 앞 좌측: 등 돌려 무릎 꿇고 돌아보는 청년 1, 피부 정상 황색 + 볼 홍조 → **常色(紅黃隱隱·明潤含蓄)** 대조군. (대안: 顴紅=陰虛, 또는 面赤如妝=戴陽)
- 환자 3 : 정상 1. 핏자국 2점.

**② 표제어**
- 1순위 **望色 — 白色主病(虛證·寒證·失血; 淡白/㿠白/蒼白 분화)** 70%
- 2순위 **常色 vs 病色(面色 望診 총론)** 또는 **氣虛·血虛·陽虛의 面色 감별** 15%

**③ 잔결**
- 청년의 볼 홍조가 '정상 혈색'인지 '顴紅(陰虛)/戴陽'인지 모호 — 역할 미확정.
- 좌측 인물이 蒼白인지 淡白(氣虛)인지 시각적으로 구분 약함(중앙과 색차 작음).
- 청년 발끝이 하단에서 잘림, 좌하단 발치에 작은 줄무늬 물체(발찌?) 뜻 불명. 좌측 세로 검은 띠(프레임 가장자리).

## 2단계 — 계통 (blind6_사전요약 어휘로 재판독)

**① 소품 재판독**
- 사전의 「面」 갈림: "광택만 面 — **얼굴색 자체는 望色 판 전담**". 이 판은 얼굴·손발 색 자체가 주인공이므로 望色 판으로 확정된다. 사전 글자로 새로 풀리는 소품은 적다(눈송이·불꽃·김·못·그릇 등 전담 기호 없음).
- 우측: 얼굴이 부풀어 팽팽 = **腫**(浮), 이마·볼·콧대 번들거림 = **華/面**(광택) → '빛나는 흰색' 㿠 + 虛浮 = **㿠白虛浮 → 陽虛水泛**. 입술 청자 = 寒 쪽 보강(厥의 '검푸른 손발 끝'은 아님).
- 중앙: 천 위 붉은 얼룩 = **血**(몸 밖으로 나온 피) → **失血 → 面色淡白**. 단, 사전상 「천 위의 검붉은 덩이 = 瘀」 갈림에 걸릴 수 있어 瘀血로 샐 위험. 「셋 중 가운데 = 中」도 걸리나 벤치(가구) 위라 의미 없음으로 판정.
- 좌측: 광택 없는 잿빛 흰 얼굴 = 無華(華 부재) → **蒼白(白中帶灰)** 또는 **淡白無華(氣血不足)**.
- 앞 청년: 살갗 위 볼 붉은 기는 「그 자리의 색」(瘀 아님) → 정상 황색+홍조 = **常色(紅黃隱隱·明潤)** 대조, 대안 顴紅(陰虛).

**② 표제어**
- 1순위 **望色 — 白色主病(虛·寒·失血: 淡白無華 / 㿠白虛浮 / 蒼白)** 75%
- 2순위 **望面色 총론 — 常色 vs 病色 대비** 12%
- (3순위 **陽虛水泛의 㿠白虛浮** 단독, 5%)

**③ 잔결**
- 핏자국이 검붉어 사전의 瘀(천 위 검붉은 덩이)와 충돌 — 失血이면 더 선홍으로.
- 좌·중 두 인물의 흰색 차이(蒼白 vs 淡白)가 약해 1:1 대응이 흔들림.
- 청년 홍조의 역할(常色/顴紅) 미확정, 발끝 하단 잘림, 좌하단 줄무늬 소물체 뜻 불명.
