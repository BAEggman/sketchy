# 687 판독 기록

## ⚠ 파일 상태
`687.png` 는 **잘린 파일**이다 (1400×1400 선언, PNG IEND 없음, 196,673 B). Read 도구가 원본을 거부했고, PIL 로 잘린 데이터를 강제로 풀면 **위쪽 0~431행(약 31%)** 만 그림이 있고 432~1399행은 전부 검정이다. 아래 판독은 이 위쪽 3분의 1에만 근거한다. 무대의 핵심 소품(손·몸통·바닥·탁자 위)은 전부 소실 구간에 있어 판독이 사실상 불가능하다.

## 1단계 — 생판

**① 보이는 소품 (위쪽 31%만)**
1. **회청색(슬레이트 그레이) 상자형 방** — 천장·좌우벽·뒷벽이 원근 상자로 그려짐. 어둡고 차가운 회색 → 금(金)/수(水) 계열 색, 혹은 '폐쇄된 내부'.
2. **젊은 남자 1명** (화면 중앙) — 검은 올백 머리, 표정 무덤덤, **귀가 크고 뚜렷**함. 이마~코끝까지만 남음(입·몸 소실). 귀 강조라면 耳 → 腎開竅於耳 를 나를 수 있음.
3. **뒷벽 오른쪽 열린 문(문짝 1개, 안쪽으로 열림)** — 문 밖은 **희뿌연 흰빛/구름·안개**. 흰색 = 金·肺, 열린 문 = 門(출입구·竅).
- 셀 수 있는 것: 사람 1, 문 1, 문짝 1. 크기 대비: 문 개구부 ≈ 사람 얼굴 폭의 1.5배.

**② 표제어 후보**
- 1순위: **命門** (8%) — 문(門) + 귀 강조(腎) 조합을 억지로 엮은 것.
- 2순위: **魄門** (5%) — 흰빛(白→肺→魄) 쪽으로 열린 문.
- 근거가 극히 빈약; 사실상 추측.

**③ 뜻 모를 것·어색한 것·잘림**
- **그림 아래 69%가 파일 손상으로 소실** (프레임 잘림이 아니라 데이터 잘림) — 인물의 입·손·몸, 바닥, 모든 손 소품을 볼 수 없음.
- 큰 귀가 의도된 기호인지 그림체인지 불명. 문 밖 흰 안개의 뜻 불명.

## 2단계 — 계통 (blind6_사전요약 어휘로 재판독)

**① 사전 어휘로 다시 읽은 소품 (여전히 위쪽 31%만)**
1. **윤이 흐르는 검은 올백 머리** — 하이라이트가 굵게 얹힌 광택 머리 → **髮**(= 윤이 흐르는 머리카락) + 華(광택). 이 판에서 사전 기호와 가장 또렷이 맞는 유일한 소품.
2. **귀** — 정면 그대로 붙어 있고 귓구멍이 검게 열려 있지 않음 → 사전의 耳(옆으로 돌려 귓구멍이 검게 열린 귀) **조건 불충족**. 耳/腎 로 읽지 않는다(1단계 命門 근거 철회).
3. **눈** — 보통 크기, 크게 뜨지 않음 → 目 아님. 이마·콧대 광택도 약해 面 단정 불가.
4. **뒷벽 열린 문간(문틀+문짝)** → **門**. 사람은 문 안쪽(內), 문 밖은 **흰 안개·구름** → 사전의 外濕(부슬비·안개) 또는 表(문 밖) 가능. 다만 안개가 '흘러드는지'는 소실 구간 때문에 판정 불가.
5. **인물 정체** — 보이는 머리에 왕관·밀짚모자·후드고글·갓·투구 없음 → 오행 다섯 인물(肝心脾肺腎)도, 王·太 도 아님. 吳(큰 입)·張(활)·李(자두)는 입·몸 소실로 확인 불가. 옷(흰 도포 여부)도 안 보임.
- 셀 수 있는 것: 사람 1 · 문 1. 久(셋 포개짐)·虛(1/3)·大(두 배) 등 수량 기호는 보이는 범위에 없음.

**② 표제어 후보**
- 1순위: **髮 — 腎其華在髮 / 髮爲血之餘** (12%) — 보이는 유일한 확정 기호가 광택 머리.
- 2순위: **外濕(濕邪 外襲, 문 밖 안개)** (7%) — 門 + 문 밖 안개 조합.
- 사전 어휘가 1단계보다 조금 낫게 풀지만(耳 오독 제거, 髮 확보), 판 본체가 없어 어느 쪽도 신뢰할 수 없다.

**③ 뜻 모를 것·잘림**
- **파일 손상: 432~1399행(약 69%) 소실** — 몸통·손·바닥·탁자 소품 전무. 이 판은 판독 시험으로서 **무효에 가깝다; 원본 재출력 필요**.
- 회청색 방 색의 뜻(사전 미등재), 문 밖 흰빛이 안개인지 그냥 하늘인지 불명.
