# 701 판독

## 1단계 — 생판 (사전 어휘 없이 그림만)

**① 소품 전수와 나르는 사실**
- 굵은 뿌리 토막 **2개**: 겉은 흑갈색 껍질에 잔뿌리, 단면은 샛노랑. 큰 토막 단면 지름이 작은 것의 약 1.7배. 「크고(大) 노랗다(黃)」 → 大黃(根·根莖 약용), 단면 황색.
- 나무 판자 궤짝(울타리·기둥 3)에 흙덩이가 꽉 참 → 장 속 積滯·燥屎. 판자 한가운데를 부수고 흙이 터져 나와 조리대로 쏟아짐 → 攻積導滯·瀉下, 「蕩滌腸胃·推陳致新」, 將軍의 「斬關奪門」.
- 위에서 내려오는 나사봉 1개 → 뜻 모름(누르기·下?).
- 손이 노란 조각(+부스러기 1)을 김 나는 탕관에 나중에 떨어뜨림 → 湯劑에 **後下**. 탕관이 찻주전자 꼴 → 開水泡服 가능.
- 다른 불 위 질그릇 사발에는 검은 진흙 같은 찌꺼기와 잔뿌리 → 오래 달이면(久煎) 瀉下力 약해짐 대비(또는 熟大黃·大黃炭).
- 버너 2개, 회색 벽돌 벽 → 배경.

**② 표제어**: 1순위 **大黃** (80%) · 2순위 **大承氣湯**(大黃 後下) (7%)

**③ 잔결**: 나사봉 뜻 모름. 사발의 검은 찌꺼기가 久煎인지 炭·瘀血인지 애매. 버너·사발은 아래 테두리에서 잘리고, 왼쪽 뒤 궤짝은 왼쪽 테두리에서 잘림. 뿌리 2개라는 수의 뜻은 모름.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 소품 전수와 나르는 사실**
- 뿌리 토막 2개가 나란한데 큰 것이 작은 것의 약 2배(단면 지름 1.7배, 부피로는 2배 넘음) → 사전의 **大**(같은 것 둘 나란히, 하나가 두 배). 단면 샛노랑 → 黃. 둘을 합치면 大+黃 = **大黃**. 地黃(검붉은 뿌리 조각)과는 색으로 갈림.
- 궤짝 속 흙이 판자를 뚫고 아래로 쏟아짐 → **下**(아래로 쏟아짐). 궤짝 안 흙과 밖 흙이 한 덩어리로 이어짐 → **通**(안과 밖이 이어짐). 합치면 「瀉下 通便·通腑」, 장 속 積滯를 밀어냄(攻積導滯). 판자가 깨진 건 傷 같지만, 깨진 것이 글자 사물이 아니어서 갈림 조건에 맞지 않음 → 傷 아님(그냥 「뚫고 나감」을 보여 주는 연출).
- 손이 노란 조각을 위에서 탕관에 떨어뜨림 → 下 + 나중에 넣음 = **後下**(湯劑 후하). 찻주전자 꼴 → 開水泡服.
- 주전자 속 김 나는 검은 갈색 액 → **苦**(김 나는 검은 커피)로 읽힘 → 味苦. 김은 氣로도 읽히지만 여기서는 苦의 김으로 봄.
- 사발 속 흑갈색 덩이 진흙 → 그릇 위 검게 굳은 덩이면 **瘀** → 逐瘀通經(活血祛瘀)일 수 있음. 다만 검붉지 않고 흑갈색이라 반쯤만 맞음. 진창(濕)은 길·발밑 조건에 안 맞음. 久(셋 포개짐)가 없으니 1단계의 久煎 풀이는 근거를 잃음.
- 寒 기호(눈송이)는 없음 → 性寒은 안 나옴.

**② 표제어**: 1순위 **大黃** (90%) · 2순위 **大承氣湯**(大黃 後下·攻下) (5%)

**③ 잔결**: 나사봉의 뜻은 사전으로도 안 풀림(降 추도 아님). 사발 덩이가 瘀인지는 색이 갈려 애매함. 性寒 기호 없음. 버너와 사발은 아래 테두리에서, 왼쪽 궤짝은 왼쪽 테두리에서 잘림. 大의 배수는 약 2배로 맞음.
