# 702 판독

## 1단계 — 생판 (사전 없이 그림만)

**① 소품 전수와 나르는 사실**
- 좌측 거대한 검은 가시덤불(잎 없음, 가시 무수·밀집) — 「가시 = 刺/蒺藜」, 덤불 규모 = 邪(또는 해당 작용)이 盛함. 오른쪽 손에 든 잔가지 대비 약 10배 이상.
- 왼쪽 남자: 청록 도포, 눈 찡그리고 입 크게 벌려 고함 = **怒** → 肝陽上亢/肝火(實). 한 손은 덤불 속으로 들어가 있음.
- 왼쪽 남자의 빗자루(1) — 쓸어냄 = 祛風/瀉(邪를 쓸어냄).
- 가운데 십자 장대에 걸린 빈 흰 천(깃발, 글씨 없음, 1) — 「白」 색 전달 소품, 또는 비어 있음 = 虛.
- 오른쪽 남자: 회색 상의·붉은 띠·붉은 바지, 처진 눈썹·풀 죽은 얼굴 = 우울·抑鬱 → 肝氣鬱結(또는 虛證).
- 오른쪽 남자 손의 잎 달린 가시 잔가지(1) + 땅에 떨어진 같은 잔가지(1) = 2개.
- 김 나는 그릇(1) — 우윳빛 따뜻한 액체 = 湯藥 또는 乳汁(乳閉).

**② 표제어**
- 1순위: **白蒺藜(刺蒺藜) — 平肝潛陽(怒한 사람)·疏肝解鬱(우울한 사람)·祛風(빗자루)·乳閉(우윳빛 그릇)** (30%)
- 2순위: **虛實 대비 — 邪氣盛則實·精氣奪則虛 / 實則瀉之(빗자루)·虛則補之(湯)** (20%)
- 3순위 후보: 荊防敗毒散 vs 人參敗毒散(흰 깃발 = 敗/항복, 가시 = 荊, 허약자 + 湯 = 人參) (10%)

**③ 뜻 모를 소품·어색한 것·잘림**
- 흰 깃발이 白인지, 항복(敗)인지, 빈 것(虛)인지 확정 불가.
- 오른쪽 사람이 왜 가시가지를 들고 있는지(잎 달림 vs 좌측 잎 없음 대비 의미?) 불분명.
- 덤불 안쪽 회색 덩어리(왼손이 들어간 자리) 정체 불명. 덤불이 왼쪽 프레임에 걸쳐 잘림(전체 크기 불명).
- 두 사람 옷 색(청록 vs 회·적)이 의미를 나르는지 불명.

## 2단계 — 계통 (blind6_사전요약 어휘로 재판독)

**① 소품 재판독**
- 왼쪽 남자 손의 짚 빗자루(1) = 사전 **瀉**(짚 빗자루) — 확정 기호.
- 오른쪽 발치 김 나는 따뜻한 국물 그릇(1) = 사전 **補**(그릇에 찰랑찰랑 찬 따뜻한 국물). 김 = 氣(서린 흰 김)로 겹쳐 읽으면 補氣 쪽.
- 좌측 가시덤불: 사전에 「가시」 항목은 없음 → 해로운 것 = **邪**로 읽음. 왼쪽 프레임 밖까지 넘쳐 잘린 거대 덤불 = **盛**(넘쳐 흘러나오는 것) → **邪氣盛**. 오른쪽 잔가지(손 1 + 땅 1 = 2)는 덤불 대비 1/10 이하로 작은 邪.
- 두 사람: 오행왕국 인물(갑옷·곤룡포·밀짚모자·흰 도포·잠수복)이 아니므로 장부가 아니라 일반 환자. 왼쪽 = 고함(聲高氣粗)·건장 = **實證**, 오른쪽 = 풀 죽고 말없음(少氣懶言) = **虛證(精氣奪)**.
- 가운데 흰 깃발: 사전 기호 없음. 「中 = 둘 사이의 한복판」 위치이긴 하나 깃발 자체가 무슨 글자인지 미해결.
- 축: 왼쪽 「邪 盛 + 實 + 瀉」 ↔ 오른쪽 「正 虛 + 補」 좌우 대칭.

**② 표제어**
- 1순위: **虛實 補瀉 治則 — 實則瀉之·虛則補之 (邪氣盛則實·精氣奪則虛)** (55%)
- 2순위: **扶正祛邪 (補 = 扶正, 瀉 = 祛邪)** (20%)
- (1단계의 白蒺藜는 사전에 「白」「가시」 기호가 없고 빗자루·국물이 瀉·補로 확정되어 10% 이하로 내림.)

**③ 잔결**
- 흰 깃발(빈 천)의 글자 미해결 — 白·中·標 중 어느 것인지 불명, 군더더기일 가능성.
- 오른쪽 사람이 든 잎 달린 가시가지 2개의 뜻(虛인데 邪가 남음 = 正虛邪戀?) 불명. 「虛 = 1/3로 줄어든 것」으로 보기엔 덤불 대비 너무 작음(1/10 이하) → 수 비율 어긋남.
- 덤불이 왼쪽 프레임에 잘림(盛 표현으로 의도된 것으로 봄). 왼손이 덤불 속에 들어간 회색 덩이 정체 불명.
