# 901 판독 (A)

## 1단계 — 생판 (사전 없이)

**① 판 표제어**
- 1순위 **六淫의 性質과 致病特點(외감 병인)** — 90%
- 2순위 **四時 主氣(六氣)와 季節病(時令發病)** — 7%
- 근거: 왼쪽→오른쪽으로 봄(꽃잎·신록)→여름(큰 해)→장하(비)→가을(낙엽)→겨울(눈)이 흐르고, 같은 차림의 남자 6명이 각기 한 가지 邪에 당한다. 風·暑·火·濕·燥·寒 여섯 = 六淫.

**② 인물별 (왼쪽부터)**
1. **風邪** — 6개: 바람 소용돌이가 寒(눈송이)·濕(비구름)·暑(해)·火(불꽃)·燥(갈라진 흙판) 5아이콘을 싣고 옴=風爲百病之長(타 邪 5개를 挾) / 날아가는 삿갓=輕揚·易襲陽位(頭) / 몸 곳곳·허공의 붉은 #표 6곳=善行數變(遊走性 瘙痒·風疹) / 뛰며 팔 휘저음=風性主動 / 꽃잎·신록=春 主氣 / 풀어 헤쳐진 차림·홍조=開泄(陽邪).
2. **暑邪** — 5개: 머리 위 큰 해·붉은 얼굴=炎熱 / 몸에서 오르는 아지랑이 선+풀어헤친 땀 가슴=升散(多汗) / 금 가 물 새는 항아리=傷津(口渴) / 지팡이·구부정·흰 수염=耗氣(氣虛乏力) / 젖은 땅에서 피어오르는 김=暑多挾濕.
3. **火(熱)邪** — 5개: 위로 치솟는 모닥불·붉은 눈과 얼굴=炎上 / 코피=迫血妄行(動血) / 팔의 붉은 반점=發斑 / 목의 노란 고름 종기=瘡癰(火毒) / 떨리는 두 손(동작선)=熱極生風(+擾神 煩躁 가능).
4. **濕邪** — 5개: 처진 어깨·무거운 걸음=重(身重) / 흙탕물·바지에서 떨어지는 탁한 물=濁 / 이마에 들러붙은 젖은 머리·종아리에 엉긴 진흙=粘滯 / 진흙과 붉게 부은 발목=趨下·易襲陰位(下肢浮腫) / 비 맞아 불씨 꺼져 가는 흙 부뚜막=陰邪 損傷陽氣·濕困脾(土).
5. **燥邪** — 4개(+1 미상): 쩍쩍 갈라진 땅·마른 풀=乾澁 / 금 가 새는 항아리=傷津 / 가슴 짚고 기침=易傷肺(乾咳) / 낙엽=秋 主氣 / 찢어진 흰 부채=미상(秋扇? 凉燥?).
6. **寒邪** — 5개: 깨진 화로·식은 숯=陰邪 易傷陽氣 / 고드름·얼어붙은 웅덩이=凝滯 / 얼음에 박힌 못=凝滯 不通則痛(寒主痛) / 팔짱 끼고 웅크린 자세=收引(拘急·腠理閉) / 덜덜 떠는 선·잿빛 얼굴=惡寒.

**③ 잔결**
- 뜻 모를 소품: 燥 인물 발치의 찢어진 부채, 寒의 못(痛으로 추정), 濕 뒤 벽의 검푸른 얼룩(곰팡이=穢濁?), 2번 인물 배 위의 손.
- 暑·火가 큰 해 하나를 나눠 써서 경계가 흐림; 1번 위 5아이콘이 하늘 구석에 작게 몰려 작은 판처럼 보임.
- 프레임 잘림 없음. 배경 계절 전환(x≈1150 해→비, x≈1720 낙엽→눈)은 번지듯 이어져 이어 붙인 흔적은 보이지 않음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **六淫의 性質과 致病特點** — 95% (사전 어휘로 확신 상승)
- 2순위 **四時 主氣(六氣)와 季節病** — 4%
- 사전의 風(옆으로 날림)·寒(눈송이=外寒)·熱(불꽃)·陽(해)·濕(비·진창)·燥(갈라진 땅·곧게 지는 잎)이 여섯 인물에 하나씩 정확히 붙는다. 1단계 판정 유지.

**② 인물별 (왼쪽부터)**
1. **風邪** — 5개(+1 약): 옆으로 흘러 날리는 꽃잎·바람선=風 / 바람이 寒(눈송이)·濕(비)·陽(해=暑)·熱(불꽃)·燥(갈라진 땅) 5기호를 싣고 옴=**風爲百病之長**(挾 5) / 날아간 삿갓=輕揚·易襲陽位 / 붉은 #표 6곳=善行數變 / 뜀=主動 / 봄 배경=春. 삿갓은 「머리에 씌운」 것이 아니라 太로 읽지 않음. 開泄은 약하게만.
2. **暑邪** — 5개: 큰 해(陽)=陽邪·炎熱 / 머리 위로 오르는 선+가슴의 땀방울(汗)=升散 多汗 / 깨져 맑은 물(津) 새는 항아리=傷津 / 발치에 서린 흰 김(氣)이 흩어짐+지팡이=耗氣 / 같은 김을 안개(濕)로 읽으면 挾濕. 1단계의 「김=挾濕」은 사전상 氣 쪽이 더 맞아 傷津耗氣 짝으로 수정, 挾濕은 2순위.
3. **火熱邪** — 5개: 치솟는 불꽃(熱)·불티=炎上 / 콧구멍(鼻)의 붉은 것(血)=迫血妄行 / 팔의 붉은 점(血)=發斑 / 목의 부풀어 팽팽한 종기(腫)=瘡癰 / 떨리는 손=生風·擾神(사전 근거 없음, 약).
4. **濕邪** — 5개: 비+길의 진창=外濕(자기 발밑에서 솟지 않으므로 內濕 아님) / 처진 몸·흙탕물=重濁 / 들러붙은 머리·엉긴 진흙=粘滯 / 아래로 흘러내림(下)+붓은 발목(腫)=趨下·易襲陰位 / 금 간 부뚜막에 타다 남아 작아진 불(陽+衰·傷)=陰邪 傷陽(困脾 추정).
5. **燥邪** — 4개: 갈라진 땅·곧게 떨어지는 마른 잎=燥·乾澁(옆으로 날리지 않아 風과 갈림) / 금 가 물방울 듣는 항아리=傷津(밑동까지 마른 물독이 아니므로 內燥 아님) / 가슴 짚고 기침=傷肺 / 가을=秋. 찢긴 흰 부채는 여전히 사전에 없음.
6. **寒邪** — 5개: 눈송이=外寒 / 깨진 화로·식은 숯=傷陽(사전 12항 그대로) / 고드름·언 웅덩이=凝滯(살아 있는 불 없음→陰 아님) / 얼음에 박힌 쇠못(痛)=凝滯→主痛 / 팔짱 끼고 웅크림·떨림=收引·惡寒.

**③ 잔결**
- 찢긴 흰 부채(燥) 뜻 미상 — 흰색=肺金, 傷=깨진 사물로 「傷肺」 중복일 수 있으나 사전에 부채 없음.
- 濕 인물 뒤 벽의 검푸른 얼룩 미상(瘀 조건 불충족).
- 暑 발치의 흰 김: 氣(서린 김)↔濕(안개) 갈림이 그림으로 결정되지 않음.
- 寒의 못은 「살」이 아닌 얼음에 박혀 痛 조건과 어긋나나 凝滯→痛으로 읽힘.
- 火 인물의 떨리는 손에 대응 글자 없음. 프레임 잘림·이어 붙임 흔적 없음.
- 판정: 사전 어휘로 1단계보다 더 잘 풀린다(暑의 김, 寒의 화로·얼음, 濕의 內外, 燥·風의 잎 방향이 확정됨).
