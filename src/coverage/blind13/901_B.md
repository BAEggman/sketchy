# 901 판독 (B) — blind13

## 1단계 — 생판 (사전 없이 그림만)

**판 표제어**: 1순위 **六淫(외감 6邪)의 성질과 致病特點** (90%) / 2순위 **六氣·時令 — 사계(春夏長夏秋冬)와 外感病因** (8%)
배경이 왼→오로 봄(꽃·새잎)→한여름(큰 해)→장마(비)→가을(낙엽)→겨울(눈)로 바뀌며, 그 앞에 6인이 각각 한 邪를 맡는다.

**인물1 (왼, 봄바람) = 風邪** — 6개
- 하늘 소용돌이에 실린 아이콘 5개(해·눈송이·비구름·불꽃·갈라진 마른 원반) → **風爲百病之長**, 寒·濕·燥·熱(暑)·火를 실어 나름(5개).
- 날아가는 삿갓 → 風性輕揚, **易襲陽位**(머리 먼저).
- 얼굴·팔·가슴·허벅지·정강이에 흩어진 붉은 # 표 → **善行數變**, 遊走性(痛·癢 자리 이동).
- 몸 비틀며 팔 허우적 → **風性主動**(動搖).
- 꽃잎·새잎 → 春 主風.

**인물2 (해 아래 노인) = 暑邪** — 5개
- 큰 해·아지랑이 → 暑性**炎熱**, 夏至 이후 時令.
- 열린 가슴·땀, 위로 솟는 열기 → **升散**(腠理開泄 多汗).
- 지팡이 짚은 굽은 몸·흰 수염 → **耗氣**(氣虛).
- 금 간 항아리에서 물 샘 → **傷津**.
- 땅에서 피어오르는 김(습한 증기) → **暑多夾濕**.

**인물3 (모닥불) = 火(熱)邪** — 5개
- 위로 튀는 불티 → **炎上**(얼굴 붉음).
- 코피 + 팔의 붉은 반점 → **迫血妄行/動血**(衄血·斑疹).
- 목의 노란 고름 멍울 → **易致瘡癰(腫瘍)**.
- 떨리는 두 손(진동선) → **生風**(熱極生風).
- 찡그린 얼굴 → 擾心神(약함).

**인물4 (비) = 濕邪** — 5개
- 축 처진 무거운 몸 → **重**(頭身困重).
- 진흙투성이 하반신·부은 발목, 아래로 흐르는 흙탕물 → **趨下**, 易襲陰位·下肢浮腫.
- 흙탕물·벽의 검푸른 곰팡이 → **穢濁**.
- 금 간 흙 아궁이·꺼져가는 불씨 → 濕困脾·**損傷陽氣**/阻遏氣機.
- 느릿한 걸음·끈적한 진흙 → **黏滯**(纏綿難愈).

**인물5 (낙엽) = 燥邪** — 4개
- 가슴 움켜쥐고 기침 → **燥易傷肺**(乾咳).
- 갈라진 땅·마른 덤불 → **乾澀**.
- 금 간 항아리 → **傷津**.
- 낙엽 → 秋 主燥. (찢어진 흰 부채는 미상)

**인물6 (눈) = 寒邪** — 5개
- 웅크리고 팔짱 → **收引**.
- 고드름·언 물 → **凝滯**.
- 얼음에 박힌 못 → 凝滯 不通則痛(통증)로 추정.
- 금 간 화로·식은 재 → 寒爲陰邪 **易傷陽氣**.
- 떨림선·흰 서리 → 惡寒.

**잔결**: 찢어진 흰 부채(인물5)·얼음 속 못(인물6)·아궁이 옆 흰 네모 조각의 뜻 미상. 모닥불이 인물3·4 경계에 있고 금 간 항아리가 인물4·5 경계에 있어 주인 모호. 항아리 깨짐(傷津)이 인물2·5에 중복. 비 구역(x≈1150)과 눈 구역(x≈1740)에 하늘·담장이 세로로 끊긴 이어 붙인 흔적. 오른쪽 끝 화로와 눈 지붕이 프레임에 잘림.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**판 표제어**: 1순위 **六淫의 성질과 致病特點(風·暑·火·濕·燥·寒)** (95%) / 2순위 **外感病因 — 六氣의 時令(春·夏·長夏·秋·冬)** (4%)
사전으로 판 주제는 바뀌지 않고, 소품 몇 개의 뜻이 확정·이동했다.

**인물1 = 風邪** — 5개: 옆으로 날리는 꽃잎·삿갓·바람줄(**風** 기호 확인) / 바람에 실린 5개 표지(해=暑·陽, 눈송이=寒, 비구름=濕, 갈라진 원반=燥, 불꽃=熱) → **風爲百病之長**(5邪를 실음) / 머리에서 벗겨지는 삿갓 → 輕揚·易襲陽位(머리에 씌운 것이 아니므로 「太」 아님) / 몸 곳곳 붉은 # → 善行數變(遊走) / 허우적거림 → 主動.

**인물2 = 暑邪** — 6개: 해(陽) → 陽邪·炎熱 / 머리 위로 곧게 솟는 아지랑이(上) + 흩어지는 흰 김(氣·散) → **升散·耗氣**(지팡이로 氣虛 보강) / 가슴의 땀방울(汗) → 多汗 / 깨진 항아리에서 맑은 물이 쏟아짐(傷+津) → **傷津** / 지팡이 밑 진창(濕) → **暑多夾濕**. ※1단계에서 「김=夾濕」으로 읽었던 것을 「김=氣의 耗散」으로 고침.

**인물3 = 火(熱)邪** — 5개: 모닥불(熱) / 곧게 솟는 불티(上) → **炎上** / 코피·팔의 붉은 점(血) → **動血**(迫血妄行) / 목의 부푼 멍울(腫) → **易致腫瘍** / 떨리는 손 → **生風**(사전의 風 기호는 아님, 동작으로 읽음). 붉은 얼굴은 望色 전담이라 글자 아님.

**인물4 = 濕邪** — 5개: 부슬비(外濕) / 축 처진 몸·흙탕 → 重濁 / 진흙이 하반신에 몰림·흙탕이 아래로 흐름(下) → **趨下·易襲陰位** / 부은 발목(腫) → 浮腫 / 깨진 흙아궁이의 타다 남은 불씨(傷·衰+불=陽) → **濕爲陰邪 易傷陽氣**(困脾). 흙탕이 자기 발밑에서 흘러나오는 것은 갈림상 內濕(脾)으로도 읽혀 「外濕引動內濕」 가능.

**인물5 = 燥邪** — 4개: 갈라진 땅 + **곧게** 떨어지는 마른 잎(燥, 세로줄로 風과 갈림) → **乾澀** / 금 간 항아리의 물방울(傷+津) → **燥易傷津** / 가슴 쥔 기침 → **燥易傷肺** / 낙엽 → 秋.

**인물6 = 寒邪** — 5개: 눈송이(갈림상 外寒) / 고드름·언 물(이 구역에 살아 있는 불이 없음 → 凝滯) → **凝滯** / 언 물에 박힌 쇠못(痛) → **凝滯則痛**(1단계 미상이 풀림) / 깨진 화로·식은 재(傷陽) → **寒易傷陽氣** / 웅크려 팔짱 → **收引**.

**잔결**: 찢어진 흰 종이부채(인물5)는 사전에 없음 — 「傷」 형식이나 무슨 글자의 사물인지 미상(肺로 추정만). 아궁이 옆 흰 네모 조각·벽의 검푸른 곰팡이도 사전 밖. 인물1의 붉은 #은 사전상 「血=붉은 것」과 부딪혀 오독 소지. 쇠못이 살이 아니라 얼음에 박혀 있어 「痛」 정의(살에 박힌 못)와 어긋남. 모닥불(3·4 경계)·금 간 항아리(4·5 경계) 주인 모호, 傷津 항아리가 인물2·5에 중복. 비(x≈1150)·눈(x≈1740) 구역에 하늘·담장이 세로로 끊긴 이어붙임 흔적, 오른쪽 끝 화로·눈 지붕 프레임 잘림.
