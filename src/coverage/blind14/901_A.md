# 901 판독 (판독자 A)

## 1단계 — 생판 (사전 열람 전 확정)

**① 시대**: 1순위 **北宋~南宋 / 高麗 전기**(85%). 근거: 강에 開寶·圖經·證類 계열로 읽히는 소품이 차례로 놓이고, 길에 銅人 2구(王惟一)·요람 아기(錢乙)·官 도장 붙은 약장(和劑局)이 있으며, 거리에 寶 금고·施藥 창구 같은 高麗 구휼·의료기관이 있다. 2순위 **宋金元 / 高麗 중후기**(10%) — 오른쪽 끝 격자판을 本草綱目으로 읽으면 明까지 늘어난다.

**② 레인별 (왼→오)**

강(本草)
1. 배 위의 열린 보물상자 = 열 開 + 보배 寶 → **開寶本草**(宋 973~974).
2. 가위를 든 아이와 오려 낸 조각이 붙은 책 = 기워 붙임·補註 → **嘉祐補註本草**(1060). 다른 후보: 오려 모으기 = 輯錄(證類)
3. 이젤 위 식물 그림 3점(뿌리 달린 풀·꽃·알뿌리) → **本草圖經**(蘇頌, 1061).
4. 3×3 = 9칸 카드 상자와 책 3권을 끼고 앉은 선비 = 분류(類)+經史 인용 → **經史證類備急本草**(唐慎微).
5. 붉은 비단과 뗏목 위의 큰 옥새 = 관에서 다시 정함 → **大觀本草/政和本草**(官修 證類).
6. 잎사귀를 꽂은 큰 격자판과 幞頭 쓴 선비 = 그물의 벼리(綱)와 눈(目) → **本草綱目**(李時珍). 칸은 대략 6×8로 고르지 않다. 幞頭가 宋式이라 **本草衍義**(寇宗奭 1116)도 후보로 둔다.

길(中國 醫家)
1. 앞치마를 두른 왕관 쓴 남자와 경혈점 찍힌 동인형 **2구** → **王惟一**, 銅人腧穴鍼灸圖經, 天聖 銅人 2구 주조.
2. 요람 아기를 돌보는 노인, 요람 위에 돈주머니를 문 새 = 錢 + 乙(새 모양) → **錢乙**, 小兒藥證直訣, 소아과.
3. 누더기를 입은 남자가 수첩에 적고 있다(바지 기운 곳 2) = 낡은 陳 + 말 言 → **陳言**(三因極一病證方論). 2순위 **成無己**(빈털터리 無 + 註解 → 註解傷寒論)
4. 푸른 대나무 **2대**를 끈으로 묶는 아이 = 竹≈朱 → **朱肱**(類證活人書). 묶음이 類를 나타낼 가능성도 있다. 확신은 낮다.
5. 왕관 쓴 노인이 자기 손목(寸口)을 가리키고, 다른 손은 엄지와 검지를 집고 있다 = 王 + 脈 → **王叔和(脈經)**로 읽히나 시대가 맞지 않는다. 宋 안에서 고르면 **王執中**(집기 = 執, 鍼灸資生經) 또는 徽宗(聖濟總錄)이다.
6. 紗帽 쓴 관리, 약항아리 **8개**(위 2·아래 6), 옥새 → **太平惠民和劑局方**(官藥局·熟藥所).

거리(高麗)
1. 창고 앞 자물쇠 보물상자 1, 상자 2, 곡식 섬 2 = 寶 기금 + 곡식 구휼 → **濟危寶**(光宗 963). 다른 후보는 義倉·常平倉.
2. 큰 관청, 왼쪽 간판은 갓과 침통(또는 필통) = 官醫 → **太醫監**(典醫寺). 다른 후보: 醫業 科擧(958). 앞에 머리띠 한 학생이 있어 의학 교육으로 읽힌다.
3. 같은 건물 오른쪽 간판은 산속의 전각 = 절(寺) → **東西大悲院**. 다른 후보: 궁궐 = **尙藥局**
4. 사발과 약첩 꾸러미 간판, 창구에서 아이 3명이 사발을 받고, 기댄 널판에도 사발이 있다 → **惠民局**(睿宗 7년 1112, 백성에게 施藥).

**③ 잔결**: 길 레인의 배경 집이 韓式 기와집이라 중국 길과 화풍이 섞였다. 관리의 모자가 朝鮮 갓에 가깝다. 상자 옆 반짝임 선이 글자처럼 뭉개져 있다. 맨 왼쪽 銅人 1구가 왼쪽 틀에 닿아 잘렸다. 강의 카드 상자와 책이 강둑 아래 여백까지 비어져 나왔다. 세 레인 사이의 흰 띠와 거리 레인의 청록 지붕(길 레인은 회색 지붕)으로 보아 세 장을 이어 붙였다. 격자판 선이 고르지 않다. 창구 안에서 손만 나온다. 돈주머니를 문 새는 뜻이 약하다.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

사전에서 이 판에 걸리는 기호는 **王(왕관, 어느 王인지는 무대가 정함)·太(테 넓은 큰 갓)·寺(기와집 한 채)·惠(여러 손이 받아 드는 빈 사발)·典藥(끈으로 묶은 약봉지 다발)·倉/藏(곳간 곡식 가마니, 갈림)·官(3층 선반장 가운데 층, 갈림)** 이다. 거리 레인은 이 어휘로 훨씬 잘 풀린다.

**① 시대**: 1순위 **宋 / 高麗**(80%). 거리 레인이 高麗 초 濟危寶부터 말기의 개칭(典醫寺 1308, 惠民典藥局 1391)까지 걸치므로 高麗 전 시기로 넓힌다. 2순위 **宋金元 / 高麗 후기**(15%).

**② 레인별 (왼→오)**
- 강: 1단계와 같다. 사전에 해당 기호가 없어 바뀐 것이 없다. **開寶本草**(열린 보물상자) → **嘉祐補註本草**(가위와 오려 붙인 책) → **本草圖經**(식물 그림 3점) → **證類本草**(9칸 카드 상자 + 經史 책 3권) → **大觀·政和本草**(뗏목 위의 옥새, 官修) → **本草綱目**(잎을 꽂은 격자판). 2순위는 本草衍義.
- 길:
  - **王惟一** — 왕관은 성 王, 銅人 2구.
  - **錢乙** — 錢(돈주머니) + 乙(새) + 요람의 아기, 小兒藥證直訣.
  - **陳言**(三因方). 2순위 成無己. 누더기·수첩 기호는 사전에 없어 1단계대로 둔다.
  - **朱肱**(竹, 대나무 2대). 확신이 낮다.
  - 왕관 쓴 노인 = 王. 宋 무대에서는 엄지·검지로 바늘을 쥐는 자세(執)와 손목 혈자리를 짚는 손짓으로 보아 **王執中, 鍼灸資生經** 으로 고친다. 王叔和·王好古는 후순위.
  - 관리가 쓴 테 넓은 갓 = **太**, 3층 선반장 가운데 층의 항아리 6개 = 官, 옥새 → **太平惠民和劑局(方)**. 2순위 太醫局. 항아리는 모두 8개다.
- 거리:
  - 문 닫힌 곳간 밖의 곡식 가마니 2 + 자물쇠 보물상자 = 寶 + 구휼 → **濟危寶** 를 유지한다. 倉·藏은 둘 다 「곳간 안」 조건을 벗어나서 2순위인 **義倉·常平倉**으로 내린다.
  - 큰 관청 왼쪽 간판의 갓(**太**)과 침통(醫) → **太醫監**. 오른쪽 간판의 기와집 한 채(**寺**) → **典醫寺**(太醫監의 개칭). 1단계의 大悲院·尙藥局은 버린다. 머리띠 학생은 醫學 교육이다.
  - 간판의 빈 사발(**惠**)과 끈으로 묶은 약봉지(**典藥**) → **惠民典藥局**(1391 개칭). 땅에 기대 둔 사발만 그린 옛 간판은 개칭 전의 **惠民局**(1112)이다. 아이 셋이 손을 뻗어 사발을 받는 장면이 惠를 한 번 더 나른다.

**③ 잔결**: 1단계 내용에 아래를 더한다.
- 침통 속 막대는 사전에 없다. 바늘인지 붓인지 확정할 수 없다.
- 濟 기호(물에 드리운 밧줄)가 거리의 濟危寶에 없고, 오히려 강 왼쪽 배의 계류 밧줄이 물가로 늘어져 있다. 濟로 오독될 수 있다.
- 강·길의 본초 소품과 인물 소품(보물상자·가위·이젤·카드 상자·옥새·격자판·누더기·대나무)은 사전에 등재되지 않은 일회성 기호다.
- 大(둘이 나란하고 하나가 두 배)는 화면에 없다. 그래서 大觀本草의 「大」가 실리지 않았다.
