# 901 판독 (B) — 의학사 말판 한 구간

## 1단계 — 생판 (사전 열기 전 확정)

**① 시대** 1순위 **宋(北宋~南宋 초) / 高麗 전·중기** 85% · 2순위 南宋·金元 / 高麗 후기 10%. 강의 「열린 보물상자」(開寶)에서 시작해 관찬 개정(옥새)으로 이어지는 흐름, 거리의 寶·惠民·大悲 계열 기관이 근거.

**② 강 (왼→오)**
1. 배에 실린 열린 보물상자(보석 7~8알) → **開寶本草**(973·974, 칙찬). 배 = 앞 시대(唐 新修本草)에서 실어 온 것.
2. 가위 든 사람 + 조각을 오려 붙인 책(조각 3~4) → **嘉祐補注神農本草**(掌禹錫, 1060) — 오려 붙이기 = 補注.
3. 이젤 위 식물 그림 3점(뿌리 달린 잎풀·꽃·구근) → **本草圖經**(蘇頌, 1061) — 약도(藥圖) 첨부.
4. 앉은 선비 + 3×3 칸 9칸 분류함(꼬리표) + 책 2권 → **經史證類備急本草**(唐慎微) — 證類 = 분류, 책 = 經史 인용.
5. 선착장 없이 떠 있는 뗏목 위 옥새(붉은 보) → **大觀本草(1108)·政和本草(1116)** — 證類를 칙명으로 관찬 개정.
6. 幞頭 쓴 인물 + 약 6×9 격자판, 왼쪽 위 칸에 잎 한 가지 → **本草衍義**(寇宗奭, 1116) 1안 / 本草綱目(綱目 = 그물코) 2안. 확신 낮음.

**② 길 (왼→오)**
1. 왕관 + 앞치마 + 침혈 점 찍힌 인형 2구 → **王惟一 『銅人腧穴鍼灸圖經』**(1026), 銅人 2구 주조(1027).
2. 요람 속 아기 + 요람 위 새가 돈주머니를 묾 → **錢乙 『小兒藥證直訣』** — 새 = 乙(제비), 주머니 = 錢, 소아과 전문.
3. 누더기·기운 바지 사내가 수첩에 적음 → **陳言 『三因極一病證方論』**(陳 = 낡음) 또는 **許叔微 『普濟本事方』**(경험 기록). 확신 낮음.
4. 대나무 2줄기를 끈으로 묶는 소년 → **朱肱 『類證活人書』**(竹≈朱). 확신 낮음.
5. 늙은 왕관 노인이 가운뎃손가락 마디를 짚고 가리킴 → **王執中 『鍼灸資生經』**(執中 = 가운데 손가락을 잡음, 中指同身寸).
6. 관리 + 약항아리 8개(위 2·아래 6) + 옥새 → **太平惠民和劑局(관약국) / 『太平惠民和劑局方』** — 관영 약국·표준 처방집.

**② 거리 (왼→오)**
1. 창고 + 자물쇠 채운 보물상자 + 곡식 가마니 2 + 작은 궤 2 → **濟危寶**(963 광종) — 기금(寶)으로 곡식을 대여해 빈민·병자 구제.
2. 큰 관아, 간판 2개(갓+붓통 / 궁궐) + 머리띠 맨 학생들 → **太醫監**(의학 교육·醫業 과거) + **尙藥局**(궁중 의약). 갓+붓 = 과거 급제.
3. 사발·약첩 묶음 간판, 창에서 사발을 아이 3명에게 건넴, 사발 그린 판자 하나 기대 놓임 → **惠民局**(1112 예종, 서민에게 약을 팖) / **東西大悲院**(판자 = 둘째 원?).

**③ 잔결** 위쪽 약 150px 빈 여백 · 오른쪽 끝에서 격자판·노점·거리 건물이 잘림 · 강의 분류함·책이 길 레인 경계를 넘어옴 · 갓(흑립)은 조선 복식이라 고려 장면에 어색 · 기대 놓은 사발 판자와 학생 머리띠는 뜻 불명 · 누더기 사내·대나무 소년은 표제어가 흔들림. 이어 붙인 세로 이음매는 화소 검사에서 보이지 않음.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽음)

사전으로 크게 달라지는 곳은 **거리**와 **길 일부**다. 강에는 해당 기호가 거의 없어 1단계 해석이 그대로 남는다.

**① 시대** 1순위 **宋(北宋·南宋, 金 포함) / 高麗 전 시기** 85% · 2순위 金元 / 高麗 후기 10%. 거리에 寺(典醫寺 1308)와 典藥(惠民典藥局 1391)이 읽혀서, 한국 쪽은 고려 말까지 펼쳐진다.

**② 강** — 바뀐 것 없음: **開寶本草**(열린 보물상자, 보석 7~8) → **嘉祐補注本草**(가위·오려 붙인 책) → **本草圖經**(이젤 그림 3점) → **證類本草**(9칸 분류함 + 책 2권) → 관찬 개정 **大觀·政和本草**(옥새 뗏목) → 격자판 + 잎(**本草衍義** 1안). 大觀의 大(두 배 크기의 짝)나 政和의 和(수평 저울)가 그림에 없어서 옥새는 「칙명 개정」까지만 진다. 격자판 인물 허리에 자두(李)가 없으므로 本草綱目은 기각한다.

**② 길**
1. 왕관(王) + 銅人 2구 → **王惟一 『銅人腧穴鍼灸圖經』**. 무대가 宋이라 이 王이 확정된다.
2. 요람·아기 + 새(乙)·돈주머니(錢) → **錢乙 『小兒藥證直訣』**. 사전에 없는 기호지만 판독은 유지한다.
3. 찢어진 옷 = 傷(그 사물이 터져 못 쓰게 됨) + 수첩 = 註解 → **成無己 『註解傷寒論』** 1안, **龐安時·許叔微**(傷寒 연구) 2안. 寒(눈송이)이 없어 「傷寒」은 반쪽만 실린다.
4. 대나무 2줄기 묶음 → **朱肱 『類證活人書』**(竹≈朱). 사전 기호는 없지만 3번과 나란히 「宋代 傷寒학」으로 묶이니 정합한다.
5. 늙은 王 + 몸 위에서 가운뎃손가락을 짚음 = 中(몸 위에서는 中) → **王執中 『鍼灸資生經』**. 사전으로 확정된다.
6. 테 넓은 갓 = 太 + 3단 진열대 가운데 층 = 官(가구 위) + 약항아리 8(위 2·가운데 6) + 옥새 → **太平惠民和劑局(官藥局) / 『和劑局方』**.

**② 거리**
1. 창고 + 잠긴 궤(寶) + 가마니 2 + 작은 궤 2 → **濟危寶**(963) 1안. 다만 濟(물에 드리운 밧줄)가 없고, 가마니가 곳간 밖에 관리 없이 놓여 倉·藏도 완전하지 않다. 2안은 義倉·常平倉.
2. 큰 관아. 간판 ㉠ 갓을 씌운 붓통 = **太** → **太醫監**(의학 교육·醫業; 머리띠 학생 5명 = 수학생), 간판 ㉡ 기와지붕 산사 = **寺** → **典醫寺**. 한 건물에 간판 둘 = 太醫監→典醫寺 개칭. 1단계의 尙藥局은 철회한다.
3. 아이 셋이 손을 뻗어 받는 빈 사발 = **惠** + 끈으로 묶은 약봉지 = **典藥** → **惠民典藥局**(惠民局 1112 → 1391 개칭). 기대 놓은 사발만 그린 판자는 내린 옛 **惠民局** 간판이다. 1단계의 東西大悲院은 철회한다.

**③ 잔결** 傷寒의 寒, 濟危寶의 濟, 大觀의 大가 그림에 없음 · 격자판과 옥새에는 사전 기호가 없음 · 太가 두 번 쓰임(관리의 갓·간판의 갓) · 강의 계류 밧줄이 濟로, 배가 藥(배 모양 약연)으로 샐 위험 · 책 더미가 3권으로 보이면 久와 샘 · 위쪽 빈 여백과 오른쪽 끝 잘림은 1단계와 같음. 판정: 거리와 길 5·6은 사전 어휘로 더 잘 풀리고, 강은 사전 밖이다.
