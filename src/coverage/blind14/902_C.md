# 902 판독 — 판독자 C

## 1단계 — 생판 (사전 보기 전, 확정)

**① 시대**: 1순위 **宋(北宋~南宋) / 高麗(전·중기)** 85% · 2순위 **宋~金元 / 高麗(후기까지)** 10%. 근거는 길의 王惟一 銅人, 錢乙, 三因 삼발이, 和劑局 좌판이고, 강은 開寶에서 證類·官定本까지 이어진다. 거리에는 寶 궤짝과 곡식, 惠民 사발이 있다.

**② 레인별 (왼→오)**
- 강
 1. 배에 실린 열린 보물궤짝, 곁에 빈 잔교 → **開寶本草**(973). 궤짝을 연다(開)+보물(寶)
 2. 아이가 가위로 책 그림을 오려 냄 → **嘉祐補注本草**(1060). 오려 붙여 보충(補注)한다. 대안 **日華子本草**(子=아이)
 3. 이젤에 뿌리 달린 약초 그림 3포기 → **本草圖經**(蘇頌 1061). 圖=그림
 4. 幞頭 학자가 3×3=9칸 분류함과 파란 책 2권 옆에 앉음 → **經史證類備急本草**(唐慎微). 분류함=證類, 책=經史
 5. 붉은 천을 깐 뗏목 위의 옥새, 잔교에 닿지 않고 떠 있음 → **大觀本草/政和本草**. 證類를 나라가 校定함(官修)
 6. 검은 높은 관 쓴 이가 바닥까지 늘어진 두루마리를 읽음, 옆에 잎 꽂힌 격자판(약 6×8칸) → **本草衍義**(寇宗奭 1116, 衍=펼침). 격자판은 **本草綱目**(綱目=그물코)으로도 읽힌다
- 길
 1. 왕관+앞치마 사내, 경혈 점 찍힌 청동인형 2구 → **王惟一**: 銅人腧穴鍼灸圖經, 銅人 2座 주조
 2. 요람의 아기, 돈주머니 든 새 → **錢乙**(돈=錢, 새=乙): 小兒藥證直訣, 소아과
 3. 부스스한 사내가 수첩에 기록, 곁 허수아비가 그를 가리킴 → **許叔微**(허수아비=許): 普濟本事方/傷寒九十論, 기록=醫案
 4. 합장한 청년, 위를 묶은 장대 3개(삼발이) → **陳無擇(陳言)**: 三因極一病證方論, 三因(內·外·不內外)을 하나로 묶음
 5. 왕관 쓴 노인이 눈 감고 한 손을 오므리며 다른 손으로 손목을 짚음 → **王執中**(鍼灸資生經, 눌러 취혈)으로 1순위를 둔다. 손목=맥으로 보면 **王叔和 계열 脈書**, 늙음+미소로 보면 **王好古**도 후보
 6. 좌판에 날개 관 쓴 관원, 약단지 8개(위 2+아래 6), 옥새 → **太平惠民和劑局(方)**: 관영 약국, 관이 정한 成藥
- 거리
 1. 곳간 앞에 자물쇠 궤짝 1개, 나무상자 2개, 곡식 가마 2개 → **濟危寶**(광종 963). 寶=기금, 곡식 구휼. 대안 **義倉**
 2. 머리띠 학생과 동행 1명, 간판에 갓+침통(꽂힌 침 4개) → **太醫監**: 의료행정·의학교육·醫業 科擧
 3. 같은 건물 오른쪽 간판에 궁궐 그림, 머리띠 사내 1명과 뒤편 회색 인물 2명 → **尙藥局**: 왕실 御藥
 4. 간판에 사발+약첩 한 묶음(7~8첩), 창구에서 사발을 받는 3명, 사발 그린 널판 → **惠民局**(예종 1112, 서민 施藥). 건물 2채와 사발 2개를 東·西로 보면 **東西大悲院**

**③ 잔결**: 강 1번의 빈 잔교는 뜻이 없다. 길 뒤 건물 간판 2개와 거리 작은 건물 간판 1개는 비어 있다. 강 6번 격자판(綱目?)은 시대가 튀고, 오른쪽 끝에 붙어 다음 구간이 넘어온 것 같다. 길 오른쪽 끝 지붕과 거리 오른쪽 건물 지붕은 프레임에 잘렸다. 왼쪽 청동인형은 왼쪽 끝에 바짝 붙어 있다. 맨 위에는 빈 흰 띠가 있다. 레인 사이 이어 붙인 솔기는 없다.

## 2단계 — 계통 (blind6_사전요약 적용 후 재판독)

**① 시대**: 1순위 **宋 / 高麗** 80%, 2순위 **宋~元 / 高麗(말기까지)** 15%. 사전으로 읽으면 거리 간판에 **寺**(典醫寺, 1308)와 **典藥**(惠民典藥局, 1391)이 걸린다. 그래서 한국 쪽은 고려 전기 설치부터 말기 개칭까지 한 구간에 담겼다고 본다. 중국 쪽 宋 판정은 그대로다.

**② 재판독 (바뀐 곳 중심)**
- 강: 1단계와 같다(**開寶 → 嘉祐補注 → 圖經 → 證類 → 大觀·政和(官定) → 本草衍義 / 綱目?**). 사전 기호 가운데 강에 걸리는 것은 없다. 다만 다음 둘은 새는 자리다. 證類 분류함 9칸은 「담는 것 안에 담긴 것=**會**」로 읽힐 수 있다. 開寶 배의 계류 밧줄은 「물에 드리운 밧줄=**濟**」로 읽힐 수 있다. 둘 다 宋 본초 계보에는 해당 글자가 없어서 기각했다.
- 길: 왕관은 **王**이다. 사전은 성까지만 정하고 어느 王인지는 무대에 맡긴다. 그래서 왼쪽은 銅人 2구가 정해 주는 **王惟一**이다. 오른쪽 노인은 宋 무대와 陳言(1174) 다음 자리라는 위치로 **王執中**(鍼灸資生經 1220, 눌러 아픈 곳을 혈로 잡음)을 1순위로 둔다. 손목 짚기를 脈으로 보면 대안은 **王碩**(易簡方)이나 **王好古**다. 좌판은 2층 선반 6단지가 「3층 선반장 가운데 층=**官**」에 맞아서 **官營 藥局 → 太平惠民和劑局(方)**으로 굳혔다. 그러나 「여러 손이 받는 빈 사발=惠」가 없어 '惠民'은 그림이 나르지 않는다. **錢乙**(錢+乙), **許叔微**(허수아비), **陳言 三因**(삼발이)은 그대로다. 삼발이 장대 3개는 「같은 것 셋 포개짐=**久**」로도 읽힐 수 있어서 경계한다.
- 거리:
 1. 곳간과 곡식 가마니. **倉**은 '곳간 **안**'이고 藏과 倉은 「앞에 관리」로 가른다. 그런데 이 그림은 가마니가 문 닫힌 곳간 **밖**에 있고 관리도 없어서 둘 다 딱 맞지 않는다. 자물쇠 궤짝을 寶로 보아 **濟危寶**를 유지한다(원금은 잠그고 이자로 구휼). 濟(밧줄)가 없는 것이 약점이다. 대안은 **義倉**이다.
 2~3. 가운데 건물의 왼쪽 간판은 **太**(테 넓은 갓)+침통이므로 **太醫監**이 확정이다. 오른쪽 간판은 1단계에서 '궁궐'로 읽었다. 사전으로 보면 기와지붕 한 채=**寺**이므로 **典醫寺**(1308 개칭)로 고친다. 그래서 **尙藥局**을 철회한다. 머리띠 학생 2명+1명은 의학교육과 醫業 科擧를 나른다.
 4. 간판에 빈 사발(**惠**: 세 사람의 손이 받아 든다)과 묶은 약봉지 다발(**典藥**)이 있어 **惠民典藥局**(1391)이 된다. 벽에 기댄 사발 널판은 떼어 낸 옛 간판, 곧 **惠民局**(예종 1112)으로 풀린다. 이렇게 보면 개칭 한 쌍이 그림으로 설명된다. 1단계의 東西大悲院 대안은 버린다. 大(둘 중 하나가 두 배)로 맞춰 보려 해도 悲를 나르는 것이 없다.

**③ 잔결**: 사전으로 해결된 것은 太, 寺, 惠, 典藥이다. 남은 수수께끼는 다음과 같다. 길 3번의 허수아비와 부스스한 머리는 사전에 없다. 길 4번 청년의 합장도 무엇을 나르는지 모르겠다. 강 2번의 아이와 가위도 사전에 없다. 길 5번 노인의 오므린 손가락에 집힌 것도 보이지 않는다(뜸봉? 침?). 사전 기호가 새는 자리는 會(分類函), 濟(계류 밧줄), 久(삼발이)다. 거리 1번 가마니는 곳간 밖에 있어서 倉 규칙과 어긋난다. 빈 간판은 3개(길 2, 거리 1)이고 빈 잔교가 1개 있다. 강 끝의 격자판은 다음 구간(綱目)에서 넘어온 것으로 보인다. 오른쪽 끝 지붕 2곳은 프레임에 잘렸다. 이어 붙인 솔기는 없다.

**판정**: 이 어휘로 거리는 확실히 더 잘 풀렸다(尙藥局→典醫寺, 大悲院→惠民典藥局/惠民局). 강과 길은 거의 그대로다.
