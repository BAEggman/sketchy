# 902 판독 — 판독자 D

## 1단계 — 생판 (사전 없이, 그림만)

**① 시대**: 1순위 **북송(~남송 초) / 고려 전·중기** (85%) — 강에 開寶→嘉祐→圖經→證類→官修(大觀·政和)로 이어지는 송대 본초 계보가 보이고, 길에는 왕관(王)+동인 2구(王惟一), 새(乙)+돈주머니(錢)+요람(錢乙), 세 막대 묶음(三因) 등 송대 의가가 모였으며, 거리는 청기와 관청·창고·施藥 창구 = 고려 기관. 2순위 **남송~금원 / 고려 중·후기** (10%) — 강 끝 격자판을 본초강목으로 읽으면 뒤로 밀린다.

**② 강 (왼→오)**
1. 배 위 활짝 열린 보물상자(보석 가득) + 빈 선착장 → **開寶本草**(973~974, 開=열림·寶=보물). 빈 선착장 하나는 重定 2차본 암시일 수도.
2. 초록 옷 소년, 가위 + 조각을 오려 붙인 펼친 책 → **嘉祐補注本草**(1060, 補=덧대기·注). 조각 3~4개.
3. 이젤 위 식물 그림(잎 식물 2 + 구근 1 = 3그루, 뿌리까지 그림) → **本草圖經**(蘇頌, 1061) = 圖.
4. 좌정 학자 + 3×3 = 9칸 분류함(카드) + 책 2~3권 → **經史證類備急本草**(唐慎微) = 類 분류, 책 = 經史 인용.
5. 선착장 없이 떠 있는 뗏목 + 붉은 천 위 옥새 → 官修 **大觀本草(1108)/政和本草(1116)**.
6. 관모 쓴 관리가 긴 두루마리를 펼쳐 읽고, 곁에 약잎 달린 큰 격자판(약 6열×9행) → **本草衍義**(寇宗奭, 1116; 衍=길게 풀어냄) 1순위, **本草綱目**(격자=綱目 그물) 2순위.

**② 길 (왼→오)**
1. 왕관(王) + 흰 옷·청색 앞치마 + 경혈 점 찍힌 인형 2구 → **王惟一 銅人腧穴鍼灸圖經**(1026), 銅人 **2구**.
2. 머리띠 사내가 요람 아기를 돌봄 + 요람 위 새(乙)가 돈주머니(錢) → **錢乙 小兒藥證直訣**(소아과).
3. 헝클어진 머리 사내가 수첩에 기록 + 그를 가리키는 허수아비(허→許) → **許叔微 普濟本事方**(本事 = 치험 기록) / 傷寒九十論 후보.
4. 눈 감고 합장한 초록 옷 인물 → 미상. **成無己**(無己=나를 비움, 注解傷寒論) 또는 **太平聖惠方**(聖) 후보.
5. 세 막대를 한 줄로 묶은 삼각 다발 → **陳言 三因極一病證方論**(1174, 三因 하나로 묶음).
6. 늙은 왕관 인물이 손가락으로 제 손목(촌구)을 가리킴, 다른 손은 무언가를 집음 → **王叔和脈訣**(高陽生 위작, 늙은 가짜 왕) 1순위, **王執中 鍼灸資生經**(집을 執) 2순위.
7. 관모 관리의 가게 + 옥새 + 약항아리 8개(2+6) → **太平惠民和劑局方**(官藥局 和劑局).

**② 거리 (왼→오)**
1. 창고 + 자물쇠 보물상자 1 + 상자 2 + 곡식 가마 2 → **濟危寶**(963, 寶 = 기금·구휼) / 義倉 후보.
2. 큰 청기와 관청: 간판 ① 갓 + 붓통(관직·시험), ② 관청 건물 그림; 머리띠 수험생들 → **太醫監** + **醫業(醫科) 과거**(958).
3. 사발 + 약첩 7~8개 간판, 창구에서 사발을 받는 서민 3인, 사발 그린 기댄 널판 → **惠民局**(1112, 施藥) / **東西大悲院** 후보.

**③ 잔결**: 보물상자 위 반짝임 낙서(글자 같음); 배 옆 빈 선착장의 뜻 불명; 길의 기댄 판·빈 간판 여럿; 합장 인물·늙은 왕관 인물의 뜻 불확정; 오른쪽 곡식 가마·책 더미·허수아비 팔이 흐릿하게 사라짐(보정·이어붙임 흔적 의심); 좌우 끝 건물·동인 프레임 잘림; 맨 아래 1~3px 분홍 띠.

## 2단계 — 계통 (사전 요약을 읽고 다시 읽음)

사전에서 이 판에 걸리는 글자는 **王(왕관)·太(테 넓은 큰 갓)·寺(기와지붕 절)·惠(여러 손이 받는 빈 사발)·典藥(끈으로 묶은 약봉지 다발)**이고, 倉·藏·濟·大·和·藥(약연)은 조건이 맞지 않아 쓰이지 않는다. 결과적으로 **거리 레인이 가장 크게 다시 풀리고**, 길은 王 하나가 갈리며, 강은 사전 글자가 없어 1단계 그대로다.

**① 시대**: 1순위 **송(북송~남송) / 고려 전 시기** (90%) — 길이 1026(王惟一)~1220(王執中)에 걸치고, 거리 간판이 고려 초 기관과 고려 말 개칭명(典醫寺·惠民典藥局)까지 함께 보여 준다. 2순위 **금원 / 고려 후기** (7%).

**② 강**: 사전 글자 없음 → 1단계 유지. **開寶本草**(배 위 열린 보물상자) → **嘉祐補注本草**(가위·덧댄 조각) → **本草圖經**(이젤 그림 3그루) → **證類本草**(9칸 분류함·經史 책) → **大觀/政和本草**(뗏목 위 옥새 = 官修; 大 글자[같은 것 둘, 하나가 두 배]가 없어 둘 중 어느 쪽인지 못 가름) → **本草衍義**(두루마리 = 衍; 격자판 6×9가량은 미해독). 배의 계류 밧줄은 뭍 말뚝에 매여 있어 濟(물에 드리운 밧줄) 아님. 배도 실물 배라 藥(배 모양 약연) 아님.

**② 길**: ① 왕관+동인 2구 = **王惟一 銅人腧穴鍼灸圖經**(1026, 銅人 2구) — 사전대로 「어느 王」은 무대(동인)가 정함. ② 새(乙)+돈주머니(錢)+요람 = **錢乙 小兒藥證直訣**. ③ 기록하는 사내 + 그를 가리키는 허수아비 = **許叔微 普濟本事方**. ④ 합장 인물 = 사전에 없음, **成無己**(注解傷寒論) 잠정. ⑤ 세 막대 한 묶음 = **陳言 三因極一病證方論**(1174). ⑥ 늙은 王: 손가락으로 무언가를 **집고**(執) 다른 손으로 제 팔 **한복판**을 짚음(몸 위의 中) → **王執中 鍼灸資生經**(1220)로 바꿈 — 연대 순서(陳言 다음)와도 맞음. 王叔和脈訣은 2순위로 내림. ⑦ 관리 가게 + 옥새 + 약항아리 8개 = **太平惠民和劑局方**. 관리의 모자는 날개 달린 사모(幞頭)라 太(테 넓은 갓)가 아님 — 「太平·惠民·和」는 그림에 실려 있지 않음.

**② 거리**: ① 창고 + 잠긴 보물상자 1 + 상자 2 + 곡식 가마 2 = 寶만 확실. 가마가 곳간 **밖**이고 관리도 없어 倉/藏이 성립하지 않으며 濟도 없음 → **濟危寶**(963) 잠정 유지, 확신 낮음. ② 큰 관청: 간판 하나 = 테 넓은 갓(**太**) + 침통/붓통, 다른 하나 = 기와지붕 건물(**寺**) → 한 기관의 두 이름 **太醫監 ↔ 典醫寺**(개칭). 머리띠 학생(2명 + 뒤쪽 3명) = 醫學 교육·**醫業 과거**. ③ 창구에서 빈 사발을 여러 손이 받음 = **惠**; 간판 = 사발(惠) + 묶은 약봉지 다발(**典藥**) → **惠民典藥局**(1391 개칭). 땅에 내려 기대 놓은 「사발만 그린」 옛 간판 = 옛 이름 **惠民局**(1112, 睿宗). 즉 거리 ②③은 모두 「간판 둘 = 개칭 전후」 문법으로 읽힌다.

**③ 잔결**: 격자판(약 6×9)·두루마리·합장 인물·관청 간판의 통 속 막대(침? 붓?)는 사전에 없어 뜻이 확정되지 않음; 보물상자 위 반짝임 낙서; 배 옆 빈 선착장; 濟危寶 쪽에 濟 글자 부재; 大觀/政和 미구분; 곡식 가마·책 더미·허수아비 팔 끝이 흐려지는 보정 흔적; 좌우 끝 건물·동인 프레임 잘림; 맨 아래 1~3px 분홍 띠. 판정: 사전 어휘로 거리 레인과 길⑥은 **더 잘 풀린다**. 강은 사전 도움이 없다.
