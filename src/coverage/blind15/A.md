# blind15 판독 A — 951 · 952 (의학사 말판 한 줄, 951 왼쪽 → 952 오른쪽)

판독 조건: 원본 Read 2회(951, 952) + 크롭 확대(crop_A/). 다른 파일·사전은 1단계 확정 전에 열지 않음.

---

## 1단계 — 생판 (사전 없이)

### [951]

**① 시대** — 1순위 **중국 金(남송 병행, 金元 전반) / 한국 高麗 중기** (70%). 2순위 元 / 고려 후기 (25%).
근거: 가운데 길 배경 전체가 몽골·북방식 게르(굴뚝에 불꽃) → 북방 이민족 왕조. 길 위 인물이 금원사대가 전반부 순서로 읽힘.

**② 레인별 (왼→오)**
- 강(본초): 강 왼쪽 절반은 빈 물길(두 갈래가 합쳐지는 모래톱만 있음). 오른쪽에 앉은 학자 1인 — 책상 위 먹·종이와 **흰 구슬이 든 보라 주머니**(진주+주머니 = **珍珠囊, 張元素**), 오른쪽을 가리키는 **화살 표지판**(약을 특정 경락으로 이끈다 = **引經報使·藥物歸經**), 뒤에 **4×4 = 16칸 약초 액자**(본초 도감 표지 — 16의 뜻은 미상).
- 길(의가): ① 금메달 걸고 책상에서 주를 다는 선비 — 펼친 책 둘레에 노란(金) 쪽지 **8장**, 덮인 책 표지에 사다리 무늬 → **成無己『註解傷寒論』**(최초의 상한론 전문 주해; 메달=최초, 쪽지=註, 金=금대). 사다리 책은 『傷寒明理論』 후보. ② 큰 불을 눈꽃 섞인 찬물 호스로 끄는 남자, 뒤 게르 굴뚝 불꽃 **5개** + 큰 불 1 → **劉完素(劉河間) 寒涼派·火熱論**(五志過極皆爲熱甚 또는 六氣皆從火化). ③ 고삐로 말을 끄는 남자 → 말을 끌다 = 引, 전령 = 報使 → **張元素** 引經報使(강의 진주낭과 짝). ④ 불꽃 **6개**가 칸마다 붙은 사다리(7단) — 張元素 升降浮沈 또는 張從正 六門(風寒暑濕燥火) 중 귀속 미정. ⑤ 활(弓=攻)을 든 소년이 빗자루로 쓸고, 게르 지붕으로 유령(邪)이 빠져나가고 그릇이 위로 튕겨 오름 → **張從正(張子和) 攻邪派 汗·吐·下 3법**(유령=汗, 그릇=吐, 빗자루=下). ⑥ 허리에 붉은 자두(李)를 찬 노인 + 흙 둔덕(새싹 5개)·흙가마 속 따뜻한 단 빵·빈 바구니 **2개** → **李杲(李東垣) 補土派『脾胃論』**(흙=土, 따뜻한 단 것=甘溫除熱, 솟는 새싹=升陽, 빈 바구니 둘=脾胃虛·內傷).
- 거리(한국): 왼쪽 건물·가운데 서가 있는 건물은 배경. 가판대에 **번개 표시 파란 책** → 즉효 = **濟衆立效方(金永錫)** 후보(또는 救急類), **집게 그림 판** → 집어 추림 = 撮要 → **御醫撮要方(崔宗峻, 1226)** 후보.

**③ 잔결** — 사다리 6불꽃의 주인(張元素/張從正) 모호. 16칸 약초 액자·강 왼쪽 합류 모래톱의 뜻 미상. 오른쪽 끝 한옥(길)·약초 액자(강)가 프레임에 붙거나 잘림. 거리 배경·행인 배치가 952와 거의 똑같아 같은 바탕을 찍어 붙인 흔적.

### [952]

**① 시대** — 1순위 **중국 元 / 한국 高麗 후기** (85%). 2순위 明 초 / 고려 말~조선 초 (10%).
근거: 길에 몽골식 흰 천막, 朱丹溪 계열 인물과 금경록·滑壽 등 원대 의서가 이어짐.

**② 레인별 (왼→오)**
- 강(본초): 강폭이 갑자기 넓은 호수처럼 바뀜. 부두 **4개** 중 1개만 사용 — 왕관 쓴 노인이 청동 탕솥을 들고 약항아리 선반(그릇 **8개**) 옆에 섬 → 왕관=王 + 탕솥=湯液 → **王好古『湯液本草』**. 나머지 부두 3개는 비어 있음. 왼쪽 위 초승달, 오른쪽 하늘은 보랏빛 밤.
- 길(의가): ① 붉은 관복(朱) + 바닥의 붉은 시내(丹溪) + 손의 촛불(相火, 촛농이 녹음 = 陽常有餘·陰常不足) → **朱震亨(朱丹溪) 滋陰派·相火論**. ② 왕관 쓴 사람이 붉은 시내 상류에 무릎 꿇고 신발 끈을 묶음 → 王 + 신(履) = **王履『醫經溯洄集』**(물길 거슬러 근원 = 溯洄, 단계의 제자; 傷寒·溫病 구분). ③ 금메달 + 거울 속 혀 내민 얼굴에 놀란 사람 → 金 + 鏡 + 舌 = **『敖氏傷寒金鏡錄』**(최초의 설진 전문서). ④ 흙더미 미끄럼틀을 타는 아이 → 滑 = **滑壽(滑伯仁)**; 옆 장대에 흰 끈 약 12 + 붉은 끈 **2** ≈ 14가닥(經=날실) → **『十四經發揮』**(12경 + 任·督). ⑤ 국수 수레(그릇·찻잔·쌓은 접시, 걸린 쪽지 4장) — 뜻 미상(飮膳正要 후보 또는 배경). ⑥ 바늘 꽂힌 나침반(指南+針) + 「쉿」(幽) + 악보 두루마리(賦·歌) → **竇漢卿(竇默)『針經指南』·標幽賦**.
- 거리(한국): ① 왼쪽 건물에 3단 계단(뜻 미상). ② 손잡이 달린 책 모양 구급상자(적십자) + 초록 잎 + 금메달 → 鄕藥 + 救急 + 現存最古 → **『鄕藥救急方』**. ③ 붓걸이 앞 학동과, 맥파 그래프 두루마리를 펼친 관복 관원 → 脈 교육·시험 → **고려 醫業 과거/의학교육(典醫寺 계열)** 후보.

**③ 잔결** — 竇漢卿(1196~1280)은 朱丹溪보다 앞선 인물인데 맨 오른쪽에 있어 순서가 어긋남(다른 침구가일 가능성). 국수 수레·3단 계단·빈 부두 3개·초승달의 뜻 미상. 강의 양식(좁은 물길→넓은 호수)과 길 배경(게르→중국식 기와집)이 951과의 이음매에서 끊김. 거리 바탕·행인은 951 복제.

## 2단계 — 계통 (blind6_사전요약.md 어휘로 다시 읽기)

사전에서 이 두 판에 실제로 걸리는 기호: **王=왕관, 張=등에 멘 긴 활, 李=허리춤 자두, 馬=고삐로 매인 말**(모두 「어느 사람인지는 무대가 진다」), 熱=불꽃, 寒=눈송이, 瀉=짚 빗자루, 上=곧게 솟음, 舌=벌린 입 안의 혀, 血=붉은 것. 濟(밧줄)·衆·惠·廣·藥(약연)·典藥·太(테 넓은 갓)·寺·保命(두 손으로 감싼 등잔)은 두 판의 한국·중국 소품과 맞지 않음.

### [951] — 판정: 사전으로 더 잘 풀린다 (말 1건 정정)

**① 시대** — 1순위 **金(남송 병행) / 高麗 중기** (75%). 2순위 元 / 고려 후기 (20%). 게르 무대 + 金元 전반 인물 넷이 무대를 정함.

**② 레인별 (왼→오)**
- 강: **珍珠囊(張元素)** — 끈 조인 주머니에 흰 진주. 사전의 收(굵은 삼베 자루)는 비단 주머니라 해당 없음. 張 기호(활)가 없어 성은 표시되지 않고 책 이름 말장난이 이름을 진다. 화살 표지판 = **引經報使·藥物歸經**, 16칸 약초 액자 = 본초 표지(개수의 뜻은 미상).
- 길: ① **成無己** 『註解傷寒論』 — 금메달 = 최초 주해, 노란 쪽지 8장 = 註. ② **劉完素** — 熱(불꽃: 굴뚝 5 + 큰 불 1)에 寒(눈송이) 물을 뿌림 → 寒涼派·火熱論. ③ **馬宗素**(1단계 張元素를 정정) — 馬 = 사람 곁에 고삐로 매인 말 한 마리, 金元 무대이므로 劉河間 문인 馬宗素. 옆 사다리 6칸에 熱 6개 = 「傷寒 六經이 차례로 전해져도 모두 熱證」(『傷寒醫鑑』). 1단계에서 귀속이 애매했던 사다리가 여기서 풀림. ④ **張從正** — 張 = 등에 멘 긴 활(확인). 瀉 = 짚 빗자루(下), 위로 튀는 사발 = 上(吐), 지붕으로 빠지는 邪 유령(汗) → **汗·吐·下 攻邪**. ⑤ **李杲(李東垣)** — 李 = 허리춤 자두. 흙 둔덕·흙가마 = 補土·脾胃, 솟는 새싹 = 升陽, 흙 속 불(熱) = 陰火 또는 甘溫除熱 후보. 빈 바구니 2개는 넘친 내용물이 없어 瀉-b가 아니므로 뜻 미상.
- 거리: 가판대의 번개 파란 책 — 사전의 濟(밧줄)가 없어 **濟衆立效方**은 약한 후보로 내림(救急·立效류). 집게 판 = 撮要 → **御醫撮要方(崔宗峻)**.

**③ 잔결** — 빈 바구니 2·16칸 액자·강 왼쪽 합류 모래톱은 사전으로도 풀리지 않음. 흰 도포 인물(강·길)은 사전의 肺(흰 도포 재상)와 겉모습이 겹쳐 오독 위험이 있으나 오행왕국 무대가 아니므로 적용 안 함. 오른쪽 끝 한옥 잘림, 거리 바탕은 952와 같음.

### [952] — 판정: 1단계를 유지하고 사전이 보강 (王 두 사람이 무대로 갈림)

**① 시대** — 1순위 **元 / 高麗 후기** (85%). 2순위 明 초 / 고려 말~조선 초 (10%).

**② 레인별 (왼→오)**
- 강: **王好古 『湯液本草』** — 王 = 왕관 + 청동 탕솥(湯液). 약그릇 8개가 놓인 3층 선반장은 사전의 官(가운데 층)과 겹치지만 舍岩 전용 기호라 적용 안 함. 빈 부두 3개.
- 길: ① **朱震亨(朱丹溪)** — 붉은 관복 = 朱, 붉은 시내 = 丹溪(사전으로는 血 → 陰血 부족, 滋陰). 촛불(陽·熱) = 相火, 陽常有餘·陰常不足. ② **王履 『醫經溯洄集』** — 王 = 왕관, 신 끈 = 履, 붉은 시내 상류 = 溯洄. ③ **『敖氏傷寒金鏡錄』** — 舌(내민 혀) + 거울(鏡) + 금메달(金·최초). 舌의 갈림 「혀가 보이면 心」은 장부·구멍 맥락 전용이라 여기서는 舌診으로 읽음. ④ **滑壽 『十四經發揮』** — 미끄럼틀 = 滑. 끈 약 14가닥 중 붉은 2 = 任·督. ⑤ 국수 수레 — 사전의 補(찰랑이는 국물)와 久(셋 포갬) 어느 쪽도 분명하지 않음. 뜻 미상(飮膳正要 후보). ⑥ **竇漢卿 『針經指南』·「標幽賦」** — 바늘 꽂힌 나침반, 쉿(幽), 악보(賦).
- 거리: ① 3단 계단 — 미상. ② **『鄕藥救急方』** — 구급상자 + 잎(鄕藥) + 금메달(현존 최고). ③ 맥파 두루마리를 든 관원 + 학동 + 붓걸이 → **고려 醫業 교육·시험(典醫寺 계열)** 후보. 관원의 모자는 테 넓은 갓이 아니어서 太 기호가 아님.

**③ 잔결** — 竇漢卿이 시대 순서와 어긋남(朱丹溪보다 앞선 인물). 朱丹溪의 테 넓은 검은 갓이 사전의 太와 겹침. 거울 앞 사람 이마의 땀이 汗 기호와 겹침. 국수 수레·3단 계단·빈 부두 3·초승달·보랏빛 하늘의 뜻 미상. 951과의 이음매에서 강(좁은 물길 → 넓은 호수)과 길(게르 → 기와집) 양식이 끊김. 거리 바탕과 행인 배치는 951을 그대로 복제.
