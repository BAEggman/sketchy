# blind15 판독 B — 951 · 952 (나란히 이어지는 두 구간)

## 1단계 — 생판 (사전 열기 전, 그림만)

### [951]
① 시대: 1순위 **金(~元 초) / 고려 중기(무신~원간섭 초)** 65% · 2순위 南宋 / 고려 중기 25%. 근거: 길 뒤의 게르(유목 천막) = 북방 정복왕조, 금메달(金), 화열·공하·보토 3가가 한 줄.
② 강(본초): 왼쪽 2/3는 갈래가 합쳐지는 빈 강(모래톱). 오른쪽 끝 둑에 선비 1명 — 보랏빛 주머니 위에 흰 구슬 = **珍珠囊(張元素)**. 오른쪽을 가리키는 화살 표지판 = 引經報使(약이 갈 경락을 가리킴). 약초 그림 4×4 = 16칸 병풍(16의 뜻 미확정, 本草 표지로만 읽음).
 길(의가): ⑴ 금메달 + 금색 쪽지(주석 딱지) 약 8장을 붙이며 책에 쓰는 선비, 곁에 사다리 무늬 책 = **成無己《註解傷寒論》**(최초 전주) ⑵ 돌우물 속 큰불에 눈송이 섞인 물을 호스로 뿌리는 검은 옷 노인 = **劉完素(寒涼派)** — 불 굴뚝 게르 5채(五志化火?)·사다리 위 불 6개(六氣皆從火化?) ⑶ 말을 끄는 곱슬머리 사내 = 미확정(**張從正** 쪽 '驅邪' 또는 별개 인물) ⑷ 활(弓→張)을 메고 빗자루로 쓸어내는 젊은이 + 게르 지붕으로 빠지는 연기 귀신(汗) + 날아가는 사발(吐) + 쓸어내기(下) = **張從正 攻下派, 汗吐下 3법** ⑸ 흙담(垣) 동쪽 집, 흙화덕에 빵, 새싹(升陽), 등 뒤 손에 자두(李), 빈 바구니 2 = **李杲(東垣) 補土派《脾胃論》**(빈 바구니 2 = 內傷/外感 辨?).
 거리(한국): 가운데 집 책장 + 의자(서적?) / 진열대에 파란 책(번개 + 물에 빠진 사람들 구조) = **濟衆立效方**(濟衆=물에서 건짐, 立效=번개) 또는 **鄕藥救急方** / 집게가 그려진 판자 = **御醫撮要方**(撮=집어 냄?) / 오른쪽 집 어두운 창 = 뜻 없음.
③ 큰불 끝이 강 레인까지 솟음. 오른쪽 끝 기와집·거리 집이 프레임에 잘림. 강 왼쪽 2/3 공백. 말·곱슬머리 사내 미해독. 사다리(책 표지와 불 사다리 두 곳) 뜻 미확정.

### [952]
① 시대: 1순위 **元(중·후기) / 고려 후기(원간섭기~말)** 60% · 2순위 **明 초 / 조선 초** 30%. 근거: 하늘에 달+낮빛 동시(日月=明?)로 오른쪽이 밤으로 저묾, 게르 대신 흰 군막 1개 + 기와집.
② 강: 넓은 물에 나루 4개. 둘째 나루에 왕관 쓴 노인이 청동 세발솥 + 골동 도자 장(3단, 그릇 8점) = 王 + 好古 + 湯液 → **王好古《湯液本草》**(3단 = 3卷?). 나머지 나루 3개는 비어 있음.
 길: ⑴ 붉은 관복(朱) + 촛불(相火) + 붉은 시내(丹溪) = **朱震亨(滋陰派, 相火論·陽有餘陰不足)** ⑵ 왕관 쓴 노인이 붉은 시내 옆에서 신(履)끈을 맴 + 시내를 거슬러 오르는 발자국(溯洄) = **王履《醫經溯洄集》** ⑶ 금메달 + 금테 거울 속 혀 = **《敖氏傷寒金鏡錄》(최초 설진 전문서)** ⑷ 흙더미 미끄럼틀(滑) 타는 아이 + 국수 수레·말리는 가닥(흰 약 12 + 붉은 2 = 14) = **滑壽《十四經發揮》** ⑸ "쉿"(默) + 바늘 꽂힌 나침반(針經指南) + 악보 두루마리(賦) = **竇默《針經指南》·〈標幽賦〉**.
 거리: 왼쪽 집 계단 3단(뜻 모름) / 가운데 선반에 구급상자(救急) + 초록 잎(鄕藥) + 금메달(현존 최고) = **鄕藥救急方** / 오른쪽: 맥파 두루마리 든 관원 + 붓걸이 앞 학동 = **醫學 교육·醫業 科擧(典醫寺?)**.
③ 강 그림체가 951(좁은 강·모래톱)과 952(바다 같은 넓은 물·나루)에서 끊김. 거리 배경(집 3채·행인 5명 배치)이 951과 똑같이 복제됨. 竇默(1196~1280)이 朱震亨·滑壽보다 오른쪽 = 시대 순 어긋남. 빈 나루 3개·달·계단 뜻 미확정. 오른쪽 끝 집 잘림.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

사전에서 이 두 판에 걸리는 글자: **王(왕관)·張(등의 긴 활)·李(허리춤 자두)·馬(고삐 맨 말)** — 넷 다 "성까지만, 어느 사람인지는 무대가 진다". 그 밖에 瀉(짚 빗자루)·寒(눈송이)·熱(불꽃)·散(흩어져 날림)·氣(흰 김)·內/外(담 안/밖)·中(둘 사이 한복판)·補-b(그릇 가득)·濟(물에 드리운 밧줄에 건져지는 사람)·衆(한 밧줄에 여럿)·舌·血. 갈림 항목 중 舌(혀→心)·官(3층 선반 가운데)·八卦(4+4 병풍)·保命(두 손 감싼 등잔)은 조건이 안 맞아 적용하지 않음(아래 근거).

### [951]
① 시대: 1순위 **金 / 고려 중기(의종~고종)** 70% · 2순위 南宋·元 초 / 고려 무신정권~원간섭 초 20%. 거리에서 濟衆立效方(의종)·御醫撮要方(1226)이 읽혀 고려 중기가 굳어짐. 무대 = 게르 진영 → 성 글자들을 金元으로 가른다.
② 강: 오른쪽 끝, 성 글자 없는 선비 + 흰 구슬 담긴 주머니 = **《珍珠囊》**(사람이 아니라 책 표제; 收=굵은 삼베 자루와는 재질·크기가 달라 收 아님). 화살 표지판 = **引經報使(歸經)**. 4×4 약초 병풍 16칸 = 사전 八卦(4폭+4폭 마주 본 병풍)는 조건 불일치 → 本草 표지로만.
 길: ⑴ 금메달 + 금빛 주석 쪽지 약 8장 + 사다리 무늬 책 = **成無己《註解傷寒論》**(최초 전주) ⑵ 눈송이(寒) 섞인 물줄기로 불꽃(熱)을 끔 = **劉完素 寒涼派·火熱論**; 불 굴뚝 게르 5 = 五志過極皆爲熱甚, 사다리 위 불꽃 6 = 六氣皆從火化 ⑶ 고삐 맨 말 = 馬 → 金元 河間 무대 → **馬宗素**(劉完素 문인, 河間 계승) — 확신 낮음 ⑷ 등에 긴 활 = 張 + 짚 빗자루 = 瀉 → **張從正 攻邪(攻下)派**; 흰 김(氣) 지붕으로 흩어짐(散=汗)·사발 위로 날림(吐)·빗자루(下) = **汗吐下 3법** ⑸ 허리춤 자두 = 李 → **李杲(東垣)**: 흙담(垣) 동쪽 집, 담 안(內) 화덕 가득 빵(補-b)·담 밖(外) 빈 바구니 2 = **《內外傷辨惑論》**, 두 바구니 사이 한복판(中)의 꽉 찬 화덕 = 補中(益氣湯)·脾胃(土), 새싹 = 升陽 → **《脾胃論》 補土派**.
 거리: 파란 책 = 밧줄에 여럿이 매달려 건져짐(濟+衆) + 번개(立效) = **《濟衆立效方》**(1단계 鄕藥救急方 후보는 버림) / 집게 판자 = 撮 → **《御醫撮要方》**(崔宗峻) / 책장 가게·어두운 창 = 배경.
③ 큰불이 강 레인으로 솟음, 오른쪽 끝 기와집 잘림, 강 왼쪽 2/3 공백, 사다리 무늬 책 표지 뜻 모름, 馬 = 어느 馬인지 무대만으로 약함.

### [952]
① 시대: 1순위 **元 / 고려 후기(원간섭기)** 60% · 2순위 **明 초 / 조선 초** 30%. 게르가 사라지고 군막 1 + 기와집, 하늘이 달·낮빛 → 밤으로 넘어감(元→明 이행).
② 강: 왕관 = 王 → 元 본초 무대 → **王好古《湯液本草》**: 세발 청동솥(湯液)·골동 도자 장(好古), 3단 장 = 3卷(官 갈림은 '가운데 층' 강조가 없어 미적용). 빈 나루 3 = 뜻 모름.
 길: ⑴ 붉은 관복(朱, 왕관 없음 → 心 아님) + 촛불 = 불(陽·相火) + 붉은 물줄기(丹溪/血) = **朱震亨 滋陰派, 相火論·陽有餘陰不足** ⑵ 왕관 = 王 → 元末明初 무대 → 신(履)끈 매기 + 붉은 시내 거슬러 오른 발자국(溯洄) = **王履《醫經溯洄集》** ⑶ 금메달 + 금테 거울 속 벌린 입의 혀(舌; 갈림 '혀=心'은 장상 판 규칙이라 미적용) = **《敖氏傷寒金鏡錄》 최초 설진서** ⑷ 미끄럼틀(滑) + 말리는 가닥 흰 약 12·붉은 2 = 14 = **滑壽《十四經發揮》**(任督 포함 14경) ⑸ 쉿(默) + 바늘 꽂힌 나침반(針·指南) + 악보 두루마리(賦) = **竇默《針經指南》〈標幽賦〉**.
 거리: 가운데 선반 구급상자(救急) + 초록 잎(鄕藥) + 금메달(현존 최고) = **《鄕藥救急方》** / 오른쪽 맥파 두루마리 관원 + 붓걸이 학동 = **醫學 교육·醫業 科擧(典醫寺)** — 사전 太(큰 갓)는 모자 모양이 달라 미적용 / 왼쪽 계단 3단 = 뜻 모름.
③ 강 그림체(좁은 강↔넓은 물·나루) 951과 끊김. 거리 배경 집 3채·행인 5명이 951과 그대로 복제(이어 붙임 흔적). 竇默(1196~1280)이 朱震亨·滑壽 뒤 = 시대 순 어긋남. 오른쪽 끝 집 잘림.

**판정**: 사전 어휘로 951의 성 글자(張·李·馬)와 濟衆, 內外·中이 새로 풀려 1단계보다 낫다(특히 濟衆立效方, 內外傷辨惑論). 952는 王 두 개만 사전이 받쳐 주고 나머지는 1단계 해석 그대로.
