# z13 판독 (blind15z, 말판 ③줄 宋·金·元 세로 띠)

## 1단계 — 생판 (사전 없이)

**① 시대**: 元(金元 말 ~ 元末明初) / 高麗 후기 — 70%. 근거: 흙길 두 인물이 모두 朱丹溪 계열(丹溪 본인 + 門人)로 읽히고, 흙길 뒤 한족 기와집 사이에 끼어 든 천막(몽골 군막)이 元을 표시하는 듯하다. 맨 앞 거리는 기와 한옥이라 고려로 둔다.

**② 묶음별**
- 강(본초 계보) — 왕관 쓴 노인(王) + 골동 그릇 진열장(好古 = 옛것을 좋아함) + 품에 안은 청동 세발솥(湯液 = 달이는 솥) → **王好古** 《**湯液本草**》. 李杲 문하 易水學派 계열, 본초서를 「湯液」 이름으로 정리했다는 사실을 솥이 나른다.
- 흙길 왼쪽 — 붉은 관복(朱) 입은 관리(相 = 재상·관리)가 촛불(火)을 든다 → 相火 → **朱丹溪(朱震亨)** 「**相火論**」(陽常有餘 陰常不足, 滋陰派). 발밑에서 흘러가는 붉은 시내 = 丹(붉을)+溪(시내) = 丹溪 호(號)를 그대로 그린 것.
- 흙길 오른쪽 — 왕관 쓴 노인(王)이 무릎 꿇고 신발 끈을 맨다(履 = 신) → **王履(王安道)**. 붉은 시내(丹溪)의 상류 끝에 앉아 있고 시냇가를 따라 발자국이 거슬러 올라오므로 「溯洄(물길을 거슬러 근원을 찾음)」 → 《**醫經溯洄集**》. 丹溪 물줄기 끝에 꿇어앉은 자세 = 丹溪 門人(사승 관계).
- 거리(한국) — 기와집 두 채(왼쪽 바깥 계단 딸린 창고형, 오른쪽 선반 칸막이 가게형)와 흰옷 소년 둘(하나는 머리띠). 말을 거는 표지가 약하다. 억지로 읽으면 아이(子·童)→ 「三和子鄕藥方」 또는 童=東 → 「東人經驗方」, 백성(흰옷)+가게 → **惠民局** 정도. 확신 낮음(20%).

**③ 뜻 모를 것·이어붙임**
- 하늘의 초승달: 사람에 붙지 않아 뜻 불명(밤? 元?).
- 강 왼쪽의 빈 나루(잔교): 사람이 없다. 王好古가 선 잔교와 별개로 하나 더 있어 이어 붙인 흔적 같다.
- 흙길 뒤 천막: 元 표지인지, 帳=張(張從正 등) 말장난인지 불분명 — 이 띠에 張씨 인물은 없다.
- 붉은 시내 꼬리가 거리 레인 위 경계까지 번져 있다(레인 경계 침범).
- 오른쪽 가장자리 잘린 인물 = 이웃 띠 몫, 무시.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 시대**: 元 / 高麗 후기 — 75%(↑). 사전의 「王 = 왕관, 어느 王인지는 무대가 진다」가 그대로 맞는다. 천막은 사전상 張(= 등에 멘 긴 활)이 아니므로 帳=張 말장난은 버리고, 金元 유목 왕조 **무대 장치**로 확정한다(張 항목의 「明 서점↔金元은 무대로 갈린다」와 같은 문법).

**② 묶음별**
- 강 — 王(왕관) + 무대 = 宋金元 본초 강 → **王好古** 《**湯液本草**》. 청동 솥(湯液)·골동 진열장(好古)은 사전 밖 그림말이나 1단계와 같은 답. 솥은 뚜껑이 닫혀 국물이 안 보이므로 補(찰랑찰랑 찬 국물) 아님.
- 흙길 왼쪽 — 관리(相) + 불꽃(사전 熱·陽 = 火) → 「**相火論**」 → **朱丹溪(朱震亨)**, 陽常有餘 陰常不足·滋陰派. 붉은 시내는 사전의 血(붉은 것)과 부딪치지만, 瘀 갈림(「그 자리의 색」)과 같은 논리로 붉음은 시내 자체의 색 = 丹溪 호로 읽는다. 촛불은 한 손에 든 맨불이라 保命(두 손으로 감싼 등잔)과 갈린다 → 劉完素 《保命集》 아님. 붉은 관복도 곤룡포 임금(心)이 아니다(왕관 없음, 사모).
- 흙길 오른쪽 — 王(왕관) + 신 끈 매기(履) → **王履**. 丹溪 물줄기의 상류 끝에 꿇어앉고 발자국이 거슬러 오름 → 《**醫經溯洄集**》, 丹溪 門人. 사전과 충돌 없음.
- 거리(한국) — 惠(빈 사발)·濟(밧줄)·典藥(약봉지)·倉(가마니)·太(큰 갓)·寺 등 기관 기호가 하나도 없다 → **표제어 없음**(배경). 1단계의 三和子·東人·惠民局 추측은 철회.

**③ 잔결**
- 초승달·빈 잔교·발자국·신발은 사전에 없는 그림말(발자국·신발은 王履 해독에 쓰였으나 미등재).
- 강의 3층 그릇 선반장이 사전의 「官 = 3층 선반장 가운데 층(위 母·아래 子)」과 舍岩 「格(그릇·선반)」에 걸린다. 특정 층 강조가 없어 적용하지 않았지만 오독 위험.
- 관리의 사모 날개가 「太 = 테 넓은 큰 갓」으로 오독될 여지.
- 붉은 시내 꼬리가 거리 레인 경계까지 번짐 — 이어 붙인 흔적.
