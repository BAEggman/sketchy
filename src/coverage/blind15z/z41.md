# z41 판독 (blind15z · 말판 ③줄 宋·金·元 · 세로 띠)

## 1단계 — 생판 (사전 열기 전 확정)

**① 시대**: 중국 **元(말기)** / 한국 **高麗** — 확신도 75%. 흙길 세 묶음이 모두 원대 14세기 중엽 인물·서적으로 풀리고, 아래 거리는 기와집·상투 머리띠 학동이라 고려로 읽힘.

**② 묶음별 판독**
- **강(본초)**: 금관 쓴 노인 + 나루 위 빈 책장(찬장). 금관 = 王(성씨), 늙은 얼굴 = 古 → **王好古 『湯液本草』**(元, 역리 본초). 대안: 금관 = 황제 칙찬 → 宋 관찬 본초(**開寶本草**/證類本草), 또는 찬장 = 궁중 음식 → **忽思慧 『飮膳正要』**. 빈 나루 둘은 다음 칸 자리.
- **흙길 1**: 금관 쓴 남자가 무릎 꿇고 신(履)끈을 맴 → 王 + 履 = **王履** 『醫經溯洄集』(傷寒과 溫病 구분, 朱丹溪 문인). 왼쪽 땅의 붉은 줄은 이웃 띠 몫으로 봄.
- **흙길 2**: 금메달 건 남자가 금테 거울을 보는데 거울 속 얼굴이 혀를 내밂 → 金 + 鏡 + 舌 = **『敖氏傷寒金鏡錄』**(杜淸碧 增補) — 금메달 = 「최초」 → 최초의 舌診 전문서.
- **흙길 3**: 아이가 흙더미 미끄럼틀(滑)을 타고 내려옴 → **滑壽** 『十四經發揮』·『難經本義』·『診家樞要』. 아이 = 小兒(錢乙)일 가능성은 낮게 둠.
- **거리(고려)**: 푸른 기와 관청 앞 책장 위 구급상자(救急) + 초록 잎(鄕藥) + 걸린 금메달(최초/最古) → **『鄕藥救急方』**, 현존 최고(最古) 한국 의서. 머리띠 학동들이 관청을 향해 걸음 → 의학 교육/**醫業 과거**(고려 醫科) 또는 **太醫監**의 의학생.

**③ 잔결**: 강의 책장이 비어 있어 「서명」을 실어 주지 못함(왕호고인지 관찬본초인지 갈림). 왕리 왼쪽 땅의 붉은 띠 자국(이웃 띠 잔재 또는 피?). 미끄럼틀 흙더미는 뜻이 따로 있는지 불명. 거리 맨 오른쪽 머리띠 학동은 잘림(이웃 띠 몫).

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 중국 **元(말기)** / 한국 **高麗(후기)** — 확신도 80%. 사전의 「王 = 왕관, 성이 王이라는 것까지만 — 어느 王인지는 무대가 진다」가 금관 둘을 **황제가 아니라 성씨**로 못박아, 1단계의 「관찬 본초」 대안이 빠지고 원대 왕씨로 모인다.

**② 묶음별 판독**
- **강(본초)**: 왕관(王) + 3칸 빈 책장. 무대가 元 본초 강이므로 **王好古 『湯液本草』**. 사전 「官 = 3층 선반장의 가운데 층」은 **가운데 층에 무언가 놓일 때**의 조건부 기호인데 가운데가 비어 있어 발동하지 않음 → 官撰 독법 기각. 「湯液」을 나를 국물 그릇(補)은 없음.
- **흙길 1**: 왕관(王) + 무릎 꿇고 신(履)끈 매기 → **王履** 『醫經溯洄集』(傷寒·溫病 구분). 사전에 履 항목은 없어 신발은 소리 맞춤으로 읽음.
- **흙길 2**: 거울 속 얼굴이 혀를 내밂 = 사전 **舌**(벌린 입 안의 혀 — 「혀가 보이면 心」 갈림은 장상 판용이라 여기선 舌 그대로) + 금테 거울(金鏡) + 금메달 → **『敖氏傷寒金鏡錄』**, **최초의 舌診 전문서**. 남자의 크게 뜬 눈(目)·땀방울(汗)·벌린 입(口)은 사전 기호와 겹치나 놀란 표정 연출로 봄.
- **흙길 3**: 아이가 미끄럼틀(滑)을 내려옴 → **滑壽**(『十四經發揮』·『難經本義』). 사전 「下 = 아래로 쏟아짐」과 겹치지만 張(활)이 없어 攻下 독법은 서지 않음.
- **거리(고려)**: 책장 위 구급상자(救急) + 초록 잎(鄕藥 — 사전의 藥=약연과는 다른 기호) + 금메달(現存 最古) → **『鄕藥救急方』**. 뒤의 기와 관아는 사전 **寺**(기와지붕 한 채)로 읽혀 → **典醫寺**(고려 후기, 太醫監의 후신) 후보. 머리띠 학동들 = 의학생/**醫業 과거**. 「太 = 큰 갓」이 없으므로 太醫監보다 典醫寺 쪽.

**③ 잔결**: 「금메달」과 「신발(履)」「미끄럼틀(滑)」「초록 잎」은 사전에 없는 기호라 소리·뜻 맞춤에 기댐. 강의 빈 3층 책장은 官 기호를 연상시키나 가운데 층이 비어 혼선. 王履 왼쪽 땅의 붉은 띠는 이웃 띠 잔재(血로 읽으면 뜻이 서지 않음). 寺 건물이 배경인지 표제인지 애매. 두 왕관 노인이 거의 같은 얼굴이라 같은 인물(王好古)의 이중 등장으로 오독될 여지.
