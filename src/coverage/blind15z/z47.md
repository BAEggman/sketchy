# z47 판독 (blind15z)

## 1단계 — 생판 (사전 보기 전, 확정)

**① 시대**: 元 / 고려(후기) — 70%. 흙길 뒤 회색 게르(몽골 천막) 네 채가 「몽골=元」을 말한다. 金(여진)일 가능성 20%, 宋 10%.

**② 레인별 묶음**
- **강(본초)**: 물길과 모래톱뿐, 배·약초·사람 없음 → 이 띠에서는 본초서 표제 없음.
- **흙길(의가)**: 붉은 옷·붉은 투구의 노인 소방수가 호스로 물을 뿜어, 돌로 쌓은 우물(화덕)에서 치솟는 큰 불을 끈다. 뒤 게르 굴뚝마다 불꽃.
  - 1순위 **朱震亨(丹溪)** — 깊은 곳(우물=하초·肝腎)에서 솟는 불 = **相火論**, 물을 끼얹음 = **滋陰降火**, 사방이 불·물은 한 줄기 = **陽常有餘 陰常不足** → **養陰派(滋陰派)**. 게르 = 元代 의가.
  - 2순위 **劉完素(河間)** — 「모든 것이 불」(굴뚝마다 불) = **火熱論·六氣皆從火化**, 물로 끔 = **寒涼派**. 단 劉完素는 金代라 게르와 어긋남.
  - 노인 = 늦게 의학에 입문한 丹溪? (약한 근거)
- **거리(한국)**: 기와집 골목에 흰옷 소년 둘이 걸어가고, 오른쪽 집 안쪽에 책 선반(서점/서고). 말하는 소품이 약함. 후보: **鄕藥救急方**(고려 후기, 현존 最古 향약 의서 — 마을 아이·책)? 또는 의학 생도(교육기관)? 확신 낮음(25%).

**③ 잔결**: 호스가 왼쪽 탁자 다리에서 뚝 끊김 — 물의 출처가 왼쪽 이웃 띠(책상 앞 학자)에 걸려 있어 이어 붙인 흔적. 소방 호스·소방 투구는 시대착오(의도된 비유로 봄). 우물 속 불은 「물이 나와야 할 곳에서 불이 남」이라는 역설로 읽혔다. 오른쪽 아래 반짝이 워터마크. 거리 띠는 사실을 나르는 소품이 거의 없어 배경처럼 보임. 왼쪽 학자·오른쪽 말은 이웃 띠 몫으로 제외.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 元 / 고려(후기) — 70% 유지. 사전에 왕조 기호는 없어 게르가 그대로 시대를 진다.

**② 레인별 묶음**
- **강(본초)**: 사전 기호 0개 → 표제 없음(변동 없음).
- **흙길(의가)**: 사전으로 읽히는 글자 — 熱(불꽃: 우물 불 + 굴뚝 불 넷), 上(머리 위로 곧게 솟는 큰 불 = 火上炎), 內(돌담=우물 둘레 **안쪽**의 불 = 안에 숨은 火), 盛(우물 아가리를 넘쳐 흘러나오는 불), 陽(불), 津(튀는 맑은 물방울). 읽으면 「안에서 넘치는 陽火 + 맑은 물로 누름」 = **陽常有餘 陰常不足 / 滋陰降火** → **朱震亨(丹溪) · 養陰派**. 결정적인 것은 「없는 기호」: 張(등의 긴 활)·李(허리춤 자두)가 없으므로 金元四大家 중 **張從正(攻下)·李杲(補土)**는 빠지고, 劉·朱만 남는다. 게르(元)가 **劉完素(金·寒涼派·火熱論)**를 밀어내 1순위 **朱震亨** 65%, 劉完素 25%. 降(저울추)·淸(물 한 그릇)·陰(얼음/졸아드는 고인 물)은 그려져 있지 않아 「降火」「淸熱」을 사전 글자로 확증할 수는 없다(호스 물은 사전 밖 비유). 넓은 테 투구를 太(테 넓은 큰 갓)로 읽으면 중국 의가 줄에서 뜻이 서지 않아 버림.
- **거리(한국)**: 사전 기호가 거의 없다. 기와지붕(寺?)은 절이 아닌 살림집이라 갈림 조건 불충족, 典藥(약봉지 다발)·惠(빈 사발)·濟(밧줄)도 없다. 두 집 중 오른쪽이 더 큰 것을 大로 볼 여지는 있으나 종류가 달라 약함. 표제 판정 보류 — 굳이 꼽으면 책 선반 = 의서 간행/의학 교육(**鄕藥救急方**?) 20%.

**③ 잔결**: 1단계와 같음 — 호스가 왼쪽 이웃 띠 탁자 다리에서 끊긴 이음 흔적, 소방 호스·투구는 사전 밖 어휘(滋陰/降火를 나를 사전 글자가 없음), 거리는 사실 없는 배경, 오른쪽 아래 반짝이 워터마크. 사전이 흙길 표제를 劉·朱 둘로 좁혀 준 것(張·李 배제)이 유일한 이득이다.
