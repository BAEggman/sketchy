# z62 판독 기록

## 1단계 — 생판 (사전 없이)

**① 시대**: 중국 **宋**(金·元 초입 이전) / 한국 **高麗** — 60%. 흙길에 약 수레·포대기 줄 같은 「아이·약방」 소품이 몰려 있어 金元 四大家(寒涼·攻下·補土·滋陰) 쪽보다 宋代 관찬 방서·소아과 쪽으로 기운다.

**② 말하는 묶음**
- 강(본초): 물가로 내민 **나무 부두(선착장)** 하나. 사람 없음. 宋代 본초 계보 중 하나(開寶·嘉祐·圖經·證類·衍義)의 이음 표지로 보이나 특정 못 함 — 후보 **證類本草**(낮음, 25%).
- 흙길 ⓐ: 흙더미 위 **미끄럼틀**(왼쪽 가장자리, 일부 잘림). 흙(土)+내려감(下) → **張從正 攻下** 또는 **李杲 補土**의 꼬리일 수 있으나 이웃 띠 몫일 가능성.
- 흙길 ⓑ: 바퀴 달린 **약 수레**(사발+막대=유발·유봉, 단지, 뚜껑 접시, 처마에 늘어진 종이쪽) → 관에서 조제약을 파는 약국 → **太平惠民和劑局方**(宋 관찬 성방, 和劑局).
- 흙길 ⓒ: **빨랫줄에 늘어진 천 조각(기저귀?)** + **손가락을 입에 문 동안(童顏) 선비**(뒷짐) → 아이 → **錢乙 『小兒藥證直訣』**(소아과 독립, 兒科之聖, 五臟辨證·六味地黃丸).
- 거리 ⓐ: **흰 머리띠 두른 흰옷 사내**(수험생 머리띠) + 뒤의 두 아이 → **醫科(醫業) 과거/의학 교육**(高麗 醫業 科擧).
- 거리 ⓑ: 상투 튼 아이가 가리킴 → 관복·검은 모자 관리가 **맥파(지그재그) 두루마리**를 펼침, 옆 족자에 **산(山/M) 모양 꺾은선** → 맥(脈) → 醫業 시험과목 『脈經』 또는 의관 기관(**太醫監/典醫寺**) 후보.

**③ 잔결**: 부두가 사람 없이 홀로 떠 있어 뜻을 못 잡음. 족자의 「山」 꺾은선이 맥파와 같은 기호인지 별개 글자인지 불명. 빨랫줄 천 조각이 기저귀인지 약봉지·처방 쪽지인지 모호. 왼쪽 미끄럼틀은 이웃 띠에서 이어 붙은 흔적일 수 있음.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 시대**: 중국 **宋**(金元 경계) / 한국 **高麗** — 55%. 사전으로 확정되는 성씨 표지(張=등의 활, 李=허리 자두, 王=왕관)가 이 띠 안 어느 인물에게도 없고, 기관 글자(太=테 넓은 큰 갓, 惠=여러 손의 빈 사발, 濟=물에 드리운 밧줄, 典藥=묶은 약봉지 다발, 藥=배 모양 약연)도 하나도 맞지 않는다. 시대 판정은 1단계 근거 그대로이고 사전이 더하거나 빼지 못한다.

**② 묶음별 재판독**
- 강: **부두** — 사전에 대응 글자 없음. 미해독 그대로(후보 **證類本草** 25% 이하).
- 흙길 ⓐ: **미끄럼틀** = 사전 「下 = 아래로 가라앉거나 쏟아짐」에 들어맞는다. 흙더미(土)는 사전 미등재. 下가 확정되므로 왼쪽 이웃 띠의 **張從正 攻下派**(汗吐下) 꼬리일 공산이 커졌다 — 단 이 띠 안에 張(활)이 없어 표제어는 이웃 몫.
- 흙길 ⓑ: **약 수레** — 사발 속 막대는 꽂힌 국자로 볼 수 있으나 甘(국자 꽂힌 꿀단지)은 「단지」라서 갈리고, 補(찰랑이는 따뜻한 국물)는 김·국물이 없어 갈린다. 藥(배 모양 약연)도 아니다. 사전으로 풀리지 않아 1단계 **太平惠民和劑局方**은 근거가 약해졌다(惠 표지 부재).
- 흙길 ⓒ: **손가락 문 동안 선비 + 빨랫줄 천 조각** — 사전 미등재 어휘. 1단계 **錢乙 『小兒藥證直訣』**(아이=소아과) 해석을 유지하되 확신 낮음(35%). 대안: 생각에 잠긴 몸짓=明理 → **成無己 『傷寒明理論』**(20%).
- 거리 ⓐ: **머리띠 사내 + 두 아이** — 미등재. **高麗 醫業 科擧**(수험생) 해석 유지(30%).
- 거리 ⓑ: 오른쪽 기와집 두 채가 크기 1:2로 나란함 → 「大 = 같은 것 둘 중 하나가 두 배」로 읽힐 여지. 大+아이들(구휼 대상) → **東西大悲院** 후보(25%). 맥파 두루마리 관리는 미등재 → 醫業 시험과목 **『脈經』**/의관(**太醫監**은 큰 갓이 없어 탈락) 후보 유지.

**③ 잔결**: 부두·흙더미(土)·맥파 두루마리·「山」 족자·손가락 문 몸짓·빨랫줄 천 조각이 모두 사전 밖 어휘라 이 띠는 사전만으로는 거의 안 풀린다. 사전이 확정해 준 것은 下(미끄럼틀) 하나, 大(기와집 둘)는 정황 수준. 미끄럼틀이 왼쪽 가장자리에서 잘려 이웃 띠와 이어 붙은 흔적이 뚜렷하다.
