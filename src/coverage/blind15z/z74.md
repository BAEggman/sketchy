# z74 판독 (말판 ③줄 宋·金·元 — 세로 띠)

## 1단계 — 생판 (사전 열기 전)

① **시대**: 중국 **金 말~元** / 한국 **高麗** — 70%. 근거: 가운데 흙길 뒤 몽골 게르(=元 표지), 앞 거리의 기와 상가는 고려 개경 거리로 읽힘.

② **레인별 묶음**
- 강(본초): 흰 도포·염소수염 선비가 강가 서안에서 먹(墨)과 빈 종이로 집필 중. 고유 소품이 없어 특정이 어렵다. 1순위 **王好古『湯液本草』**(元, 易水學派 본초), 2순위 **寇宗奭『本草衍義』**·**張元素『珍珠囊』**.
- 흙길 왼쪽: 게르 앞에서 활(弓)을 메고 빗자루로 쓸어 내는 청년(흰 후광). 활=弓→張, 쓸기=사기를 쓸어냄 → **張從正(子和)** 攻下派(汗·吐·下 三法, 『儒門事親』). 다른 읽기: 弓(張)+게르(元)+掃(소→素) = **張元素**, 易水學派 개조(臟腑辨證·歸經·引經報使, 『醫學啓源』). 두 읽기가 반반.
- 흙길 오른쪽: 흙담(垣) 위 새싹, 흙 화덕(竈)에 찐빵, 빈 소쿠리 둘, 허리춤에 붉은 자두(李)를 찬 노인(흰 후광) → **李杲(東垣)** 補土派. 흙담=脾胃(土)·東垣의 垣, 화덕·빵=水穀 腐熟, 빈 소쿠리=飢餓·飮食勞倦 內傷, 새싹=升陽(補中益氣湯·甘溫除熱), 『脾胃論』『內外傷辨惑論』.
- 거리(고려): 흰 머리띠(붕대)를 매고 걷는 사내 → 구급 → **『鄕藥救急方』**(현존 最古 향약 의서). 덧문 열린 가게 앞 청년 → 백성에게 약을 파는 관설 약국 **惠民局**(1112). 뒤편 두 사람은 배경 군중.

③ **잔결**: 왼쪽 끝 곱슬머리·말 고삐 사내는 잘린 이웃 띠 몫. 게르에 기대 놓은 두 번째 빗자루가 청년의 빗자루와 중복(무엇을 나르는지 불명). 거리 오른쪽 가게 벽에 반짝이(✦) 두 개 — 생성 워터마크 흔적. 강변 선비는 고유 소품 부재로 표제어가 묻힘.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

① **시대**: 중국 **金~元**(金末元初 경계) / 한국 **高麗** — 75%. 게르는 사전에 없는 무대 표지(북방 왕조)로, 張·李를 金元 인물로 가르는 「무대」 구실을 한다.

② **레인별 묶음**
- 흙길 왼쪽: 등에 멘 긴 활 = **張**(어느 張인지는 무대 → 金元), 짚 빗자루로 쓸어 냄 = **瀉** → 張 + 瀉 = **張從正(子和)** 攻下派(攻邪, 汗·吐·下 三法, 『儒門事親』). 1단계의 張元素 읽기(掃→素 음차)는 사전에 없고 빗자루가 瀉로 등재돼 있어 기각.
- 흙길 오른쪽: 허리춤 자두 = **李**(무대 金元) → **李杲(東垣)** 補土派. 흙담(土·垣)과 그 담 안쪽(=內)의 화덕·찐빵(飮食) → 脾胃·**內傷**(『脾胃論』『內外傷辨惑論』), 담 위 곧게 솟는 새싹 → 升陽(補中益氣湯). 왼→오 순서도 張從正(1156~1228) → 李杲(1180~1251)로 맞는다.
- 강(본초): 사전상 흰 도포 = 肺(재상)이나 의학사 강에서는 무의미. 王(왕관)·張(활)·李(자두) 어느 성씨 기호도 없어 王好古『湯液本草』·張元素『珍珠囊』 읽기는 오히려 약해진다. 표제어 **미상**(약한 후보 **寇宗奭『本草衍義』**).
- 거리(고려): 후광 두른 머리띠 사내·대문 앞 청년이 있으나 太(큰 갓)·惠(빈 사발)·濟(밧줄)·典藥(약봉지)·藥(약연)·寺(절) 어느 기호도 들고 있지 않다. 1단계의 『鄕藥救急方』·惠民局은 사전 근거가 없어 철회 → **미상**.

③ **잔결**: 게르에 기댄 두 번째 빗자루(瀉 중복인지 무대 소품인지 불명). 빈 소쿠리 둘 — 쏟아진 내용물이 없어 瀉-b도, ⅓로 줄지 않아 虛도 아님(뜻 모름; 飢餓?). 강 선비·고려 거리 두 사람은 후광은 있는데 이름 기호가 없음. 대문 현판이 비어 있음. 거리 오른쪽 벽의 ✦ 반짝이 두 개 = 생성 워터마크. 왼끝 말 탄 사내는 이웃 띠.
