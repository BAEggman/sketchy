# z85 판독 (blind15z)

## 1단계 — 생판 (사전 열기 전 확정)

**① 시대**: 중국 **金·元(金元四大家 시기)** / 한국 **高麗** — 확신도 80%.
근거: 흙길 뒤 몽골식 게르(북방 유목 왕조 표지), 흙길 두 인물이 張從正·李杲로 읽힘, 거리는 고려풍 청기와 거리.

**② 말하는 묶음 (레인별)**
- 강(본초) — 강가 서안에 앉은 선비(먹·종이) + 오른쪽을 가리키는 나무 이정표 + 4×4 칸에 약초 그림을 끼운 병풍 + 보라색 끈주머니와 고리 끈. → **圖經本草**(蘇頌, 宋): 약초 그림판 = 「圖」, 이정표·길 = 「經」. 2순위 **證類本草**(唐愼微, 칸 나눔 = 「類」로 분류), 3순위 **本草衍義**(寇宗奭, 화살표 = 「衍」 넓힘). 주머니·끈은 해독 못 함.
- 흙길 ① — 게르 앞에서 빗자루로 땅을 쓰는 청년, 어깨에 활(弓). → **張從正(子和)**: 弓+長 = 張. 빗자루로 쓸어냄 = **攻邪派**(汗·吐·下 三法으로 邪를 몰아냄), 『儒門事親』. 게르 = 金代 인물 표지.
- 흙길 ② — 새싹 돋은 흙 둔덕(흙담)과 그 안의 흙 화덕(불 속에 빵·만두), 바구니 2개, 둔덕 오른쪽(東)에 선 노인 허리춤의 붉은 자두. → **李杲(東垣)**: 자두 = 李, 동쪽 흙담 = 東垣. 흙 둔덕 = 土 → **補土派·脾胃論**, 화덕 = 脾胃 속 불(甘溫除熱/陰火), 음식·바구니 = 飮食勞倦 內傷(『內外傷辨惑論』). 張(1156~1228) → 李(1180~1251) 순서도 맞음.
- 거리(고려) — 청기와 건물들, 머리띠 맨 남자가 걸어감, 뒤쪽 서민 둘, 흰 옷 청년이 덧문 열린 창구 앞에 섬, 가운데 건물 현판은 비어 있음. 말하는 소품이 약함. 후보 **惠民局**(백성에게 약을 파는 창구) / **藥店** — 확신 30%.

**③ 잔결**
- 창구 오른쪽 벽의 반투명 네 갈래 반짝이 2개 — 생성 워터마크 같은 흔적이고 뜻이 없음.
- 게르에 기대 놓은 두 번째 빗자루(중복), 서안 위 보라 주머니와 고리 끈, 이정표가 무엇을 가리키는지 확정 못 함.
- 왼쪽 가장자리의 말 끄는 남자, 게르 뒤 회색 천막은 이웃 띠 몫으로 보고 제외함.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽음)

**① 시대**: **金·元 / 高麗** — 85%. 사전에 「張 = 등에 멘 활, 어느 張인지는 무대가 정한다(明 서점↔金元)」가 있다. 무대가 게르이므로 金元의 張이 맞다.

**② 말하는 묶음 (레인별)**
- 강(본초) — **珍珠囊**(張元素, 金). 다시 보니 보라 주머니 아가리의 흰 알갱이가 진주다(진주 주머니 = 珍珠囊). 오른쪽을 가리키는 이정표 = **引經報使**, 칸마다 한 가지씩 끼운 약초 = **藥物歸經**. 사전 기호로 푼 것이 아니라 다시 봐서 얻은 읽기다. 서안의 선비는 활(張)을 메지 않아 저자 표지가 없다. 2순위 **圖經本草**.
- 흙길 ① — **張從正(子和)**: 활 = 張(사전 확정), 짚 빗자루 = **瀉**(사전 확정) → **攻邪派(攻下)**, 汗·吐·下 三法. 게르에 기대 놓은 두 번째 빗자루도 瀉라서 강조가 겹친다.
- 흙길 ② — **李杲(東垣)**: 허리춤 자두 = 李(사전 확정), 무대가 金元 → 李杲. 흙담(垣) 동쪽(오른쪽)에 섬 = 東垣. 흙 둔덕 = 土 → **補土派·脾胃論**(사전 밖 연상). 담 안쪽의 화덕 불 = 內(담 안쪽, 사전) + 熱/陽(불, 사전) → **內傷 發熱**(『內外傷辨惑論』, 陰火·甘溫除熱). 곧게 솟은 새싹 = 上 → **升陽**(補中益氣). 화덕 속 빵 = 飮食·胃의 腐熟.
- 거리(고려) — 사전 어휘(惠 사발·濟 밧줄·藥 약연·典藥 약봉지·太 큰 갓·倉 가마니)가 하나도 걸리지 않는다. 기와집(寺)은 모든 건물이 기와라 배경으로 본다. 표제어 없음. 굳이 고르면 **惠民局**이고 확신 15%다.

**③ 잔결**
- 창구 벽의 반짝이 2개는 사전대로라면 華(빛나는 것)지만, 짝이 되는 고려 기관이나 의서가 없다. 워터마크 같은 흔적으로 본다.
- 빈 바구니 2개는 虛(⅓로 줄어듦)가 아니다. 뜻을 모르겠다.
- 서안 위 고리 끈은 收(삼베 자루)처럼 보이지만 비단 주머니라 갈림 조건에 맞지 않는다.
- 土·升·歸經·引經은 사전에 전용 기호가 없어 사전 밖에서 연상해 읽었다.
