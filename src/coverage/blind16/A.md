# blind16 판독 — 판독자 A

## 1단계 (생판, 사전 열람 전)

### [961]
**① 시대** — 1순위: 金(·南宋) / 高麗 중기(무신정권~몽골 침입기, 12~13세기) 75% · 2순위: 元 초 / 高麗 후기(원간섭기) 20%. 근거: 흙길 전체가 몽골 게르촌(=北方 異民族 왕조), 金 메달, 金元 의가 넷이 한 줄로 늘어섬.

**② 강(本草)** — 오른쪽 끝 하나뿐. 앉은 학자 + 원소 주기율표 모양 약장(藥欌) + 책상 위 보라 주머니 + 오른쪽을 가리키는 화살 표지판 → **張元素 『珍珠囊』**. 주기율표 = 「元素」이자 약을 칸마다 배속 = **藥物歸經**, 화살 표지판 = **引經報使**, 주머니 = 囊. 약장 위 작은 깃발 1개(뜻 미상, 標?).

**길(의가)** — ⑴ 金 메달 건 관인 + 책상 위 펼친 책 둘레에 붙인 노란 쪽지 여러 장(주석) + 붓 4자루 + 사다리 무늬 책 → **成無己 『注解傷寒論』**(최초 전문 주석, 金). 붓 4 = 미상(四大家 머리표?). ⑵ 큰 불 + 돌우물 + 눈송이 둥근부채(寒으로 火를 식힘) → **劉完素(河間) 火熱論·寒涼派**; 게르 굴뚝 불 5개 = 五志過極皆爲熱. ⑶ 말 끄는 사내 + 불 6개 달린 사다리 → 사다리 = **六氣皆從火化**(劉完素) 또는 六門; 말 = 미상(攻? 馬宗素?). ⑷ 활(弓長=張) 멘 채 비질하는 사내 + 게르 꼭대기에서 날아가는 천(汗)·사발(吐) + 빗자루(下) → **張從正(子和) 攻邪派, 汗吐下 三法**(3). ⑸ 흙담(垣)·흙화덕·새싹 + 노란 죽 사발과 숟가락 + 허리에 붉은 과일(李) 노인 → **李杲(東垣) 補土派·脾胃論**.

**거리(한국)** — 가운데 건물 처마의 새둥지(集) 안 집게 3 + 판자에 집게 1(=撮) + 파란 봉투(새싹 표식, 향약 약첩?) → **『新集御醫撮要方』(崔宗峻, 1226)** 1순위, 『鄕藥救急方』 2순위.

**③ 잔결** — 강 왼쪽 2/3 비어 있음. 거리 오른쪽 건물의 검은 빈 간판, 가운데 건물 서가·벤치는 뜻 미상(배경?). 말의 뜻 미상. 오른쪽 끝 기와집이 길 레인에서 잘림.

### [962]
**① 시대** — 1순위: 元(원말) / 高麗 말(원간섭기~공민왕) 70% · 2순위: 明 초 / 朝鮮 초 25%. 근거: 길 왼쪽 절반 게르 → 오른쪽 절반 중국 기와집(元→明 교체), 거리 끝 조선 관복 인물.

**② 강** — 왼쪽: 왕관(王) 쓴 백발 노인(好古) + 화로 위 청동 솥(湯液) 속 얼음덩이 + 초승달 → **王好古 『湯液本草』**, 얼음·달 = 陰 → 『陰證略例』. 오른쪽 강은 빈 물길.

**길** — ⑴ 바늘 꽂힌 나침반(指南+針) + 노래 두루마리(賦) → **竇漢卿(竇默) 『針經指南』·「標幽賦」**. ⑵ 금메달(金) + 혀 비친 거울(鏡) + 두꺼비(杜) 아이 → **『敖氏傷寒金鏡錄』(杜淸碧 增補, 舌診 36圖)**. ⑶ 붉은 옷(朱) + 촛불(相火) + 빛 덩이(陽有餘) + 그에게서 흘러가는 붉은 물줄기(丹溪) → **朱震亨(丹溪) 相火論·陽常有餘陰常不足**. ⑷ 미끄럼틀(滑) 타는 아이 + 둔덕 + 빨랫줄 가닥 약 14개(經) → **滑壽(伯仁) 『十四經發揮』**. ⑸ 왕관(王) + 짚신(履) + 거슬러 굽이치는 붉은 물줄기(溯洄)와 발자국 → **王履(安道) 『醫經溯洄集』**, 丹溪 제자.

**거리** — ⑴ 초록 십자(救急)·잎(鄕藥) 책 + 금메달(현존 最古) + 빈 3단 선반(3卷 / 원본 佚失) → **『鄕藥救急方』**. ⑵ 관복 인물의 팝업책: 맥파(診脈) + 세모 봉우리(오른쪽 3=三峯, 왼쪽 1) → **鄭道傳 『診脈圖誌』**.

**③ 잔결** — 빨랫줄 탁자 위 쟁반·꾸러미 뜻 미상, 둔덕 자체 뜻 미상. 961 오른쪽 기와집과 962 왼쪽 기와집 이음은 무리 없음.

## 2단계 (사전 `blind6_사전요약.md` 대조 후 재판독)

### [961]
**① 시대** — 1순위: 金(金元) / 高麗 중기(무신정권~몽골 침입기) 70% · 2순위: 元 초 / 高麗 후기 25%. 사전의 성씨 기호(張=활, 李=자두, 馬=고삐 맨 말)가 모두 「무대가 어느 사람인지 정한다」고 했는데, 게르촌 + 金 메달 무대에서 張·李·馬가 한 줄로 서면 金元 의가로 풀리는 것이 가장 자연스럽다.

**② 강** — **張元素 『珍珠囊』**(유지). 사전에 등재 기호는 없으나 주기율표=「元素」 말장난, 칸칸 배속 = **藥物歸經**, 화살 표지판 = **引經報使**, 주머니 = 囊. (주머니는 삼베 자루가 아닌 비단 주머니라 收 아님.)

**길** — ⑴ **成無己 『注解傷寒論』**: 金 메달 + 주석 쪽지(유지, 붓 4 미상). ⑵ **劉完素 火熱論·寒涼派**: 熱=불꽃(큰 불 + 굴뚝 불 5 = 五志化火), 寒=눈송이 부채로 불을 식힘 → 寒涼. ⑶ ★수정: 사전 「馬 = 사람 곁에 고삐로 매인 말」 → 金元 무대의 馬 = **馬宗素**(劉完素 문인, 『劉河間傷寒醫鑑』). 곁의 불 6개 사다리 = 단마다 熱 = **六經傳受 皆爲熱證**(六經이 차례로 전해져도 모두 熱). 1단계의 「말 미상」이 풀림. ⑷ **張從正(子和)**: 張=멘 활, 瀉=짚 빗자루 → 攻邪·瀉下, 게르에서 날아가는 천·사발(散) = 汗·吐 → **汗吐下 三法**(3). ⑸ **李杲(東垣)**: 李=허리춤 자두(확정), 흙담·흙화덕·새싹 = 土, 노란 것이 가득 찬 사발(補-b) = 脾土를 채움 → **補土派·『脾胃論』**.

**거리** — 사전 기호(濟·惠·大·典藥·藏/倉) 어느 것도 없어 기관이 아니라 의서 한 권. 새둥지(集) 안 집게 3 + 판자 집게 1(撮) + 파란 약봉투 1 → **『新集御醫撮要方』(崔宗峻, 1226)** 1순위 / 『鄕藥救急方』 2순위. 둥지 안에 집게가 담김은 사전 「會」 꼴이지만 고려 의서에 會가 없어 채택 안 함.

**③ 잔결** — 강 왼쪽 2/3 공백. 붓 4자루·돌우물·약장 위 깃발·거리 오른쪽 검은 빈 간판·가운데 집 서가는 뜻 미상. 오른쪽 끝 기와집 프레임 잘림.

### [962]
**① 시대** — 1순위: 元(원말) / 高麗 말 75% · 2순위: 明 초 / 朝鮮 초 20%. 길 왼쪽 게르 → 오른쪽 기와집, 거리 끝 **三峯**.

**② 강** — **王好古 『湯液本草』**: 王=왕관(무대가 元 본초 강 → 王好古), 화로 솥 = 湯液. ★보강: 사전 「陰 = 얼음, **살아 있는 불과 맞대었을 때만**」 — 솥 속 얼음 바로 밑에 숯불이 살아 있어 조건 충족 → 陰 = **陰證(『陰證略例』)**. 달도 陰 보조.

**길** — ⑴ **竇漢卿 『針經指南』·「標幽賦」**(나침반=指南, 침, 노래 두루마리). ⑵ **『敖氏傷寒金鏡錄』**: 金 메달 + 거울(鏡) + 사전 「苔 = 혀 위 이끼」 — 거울 속 혀가 초록 이끼로 덮임 → **舌苔 診斷**(舌은 입 밖 거울 속이라 心 갈림 해당 없음). 두꺼비 = 杜淸碧 증보(36舌, 사전 외). ⑶ **朱震亨(丹溪)**: 붉은 관복(朱 — 곤룡포 임금이 아니라 心 아님), 陽=불 → 촛불 위 넘치는 빛 = **陽常有餘陰常不足**·相火論, 붉은 물줄기(丹+溪; 사전상 血일 수도). ⑷ **滑壽 『十四經發揮』**(미끄럼틀=滑, 빨랫줄 가닥 ≈14 = 經). ⑸ **王履 『醫經溯洄集』**: 王=왕관 + 짚신(履), 丹溪에게서 이어진 붉은 물줄기·발자국 = 丹溪 제자·溯洄.

**거리** — ⑴ **『鄕藥救急方』**: 잎(鄕藥) + 초록 십자(救急) + 금메달(현존 最古 향약서) + 빈 3칸 선반(上中下 3卷 / 원간본 佚失). 사전 「官 = 3층 선반장 가운데 층」은 舍岩 가구 문맥이고 가운데 층이 비어 있어 미적용. ⑵ **鄭道傳 『診脈圖誌』**: 사전 「三峯 = 펼친 책에서 솟은 봉우리 셋 + 맥박 물결 = 鄭道傳」과 정확히 일치(확정).

**③ 잔결** — 둔덕·빨랫줄 탁자 위 쟁반 뜻 미상, 거울 받친 두꺼비는 사전 밖 기호, 왼쪽 페이지의 네 번째 세모 1개는 三峯과 별개로 남음. 961↔962 이음 자연스러움.
