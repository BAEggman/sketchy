# blind16 / 960 — 판독자 C

## 1단계 — 생판 (사전 열기 전, 확정본)

**① 시대**: 1순위 **北宋~南宋 / 고려** (85%) · 2순위 **金元 / 고려** (10%). 근거: 개보·도경 계열 본초, 동인·전을·허숙미, 국방(局方) 소품이 한데 모여 있음. 거리의 고려 기관(제위보·혜민국 류)이 같은 시대를 받침.

**② 레인별 (왼→오)**
- 강(본초)
  1. 빈 나루 옆 배 + 열린 보물상자 → **開寶本草**(973, 宋 첫 관찬본초) — 寶 상자를 「연다」=開寶.
  2. 평민 소년이 가위로 책을 오려 조각 2~3개 → **嘉祐補注本草**(掌禹錫, 1060, 補注=덧대기) / 차순위 證類(발췌).
  3. 몸에 뿌리째 약초 그림 3포기 그린 소 → **圖經本草**(蘇頌, 1061, 약도 첨부).
  4. 복두 쓴 관리 + 증류 플라스크 속 책 2권 → 잎 1장 → **證類本草**(唐慎微, 嘉祐+圖經 두 책을 합쳐 하나로) / 차순위 本草衍義.
  5. 강 가운데 섬: 아치 뚫린 돌덩이(화덕?) 위 묘목 → 미상(**大觀·政和本草** 후보 — 證類의 관찬 개정판).
  6. 긴 두루마리 읽는 관리 + 6칸 서가(꼭대기에 잎날개 비둘기) → **本草衍義**(寇宗奭, 1116) 후보 / 칸=「類」라면 證類.
- 길(중국 의가)
  1. 앞치마 두른 왕관 사내 + 목인 2구 + 사람 모양 주형 2쪽 → **王惟一**《銅人腧穴鍼灸圖經》(1026), 銅人 2구 주조.
  2. 쪼그린 노인이 큰 엽전(錢), 네모 구멍 속 무지개 포대기 아기, 돈주머니 문 새(乙=새 을) → **錢乙**《小兒藥證直訣》, 소아과·五色/五臟辨證.
  3. 헝클어진 머리 사내 + 책 얹은 허수아비(허수→許叔) → **許叔微**《普濟本事方》(차순위 龐安時).
  4. 상투 청년 + 묶인 무 3뿌리(무→無) → **成無己**《註解傷寒論》(최초 전문 주해).
  5. 줄자 감은 노왕 → **王執中**《鍼灸資生經》(차순위 宋慈《洗冤集錄》).
  6. 관인 상자 + 옷걸이 8개에 약봉지 8개 걸린 관리 → **太平惠民和劑局方**(官局 성약).
- 거리(고려)
  1. 보석 가득한 쪼개진 박 2개 + 물독에 드리운 밧줄 → **濟危寶**(963, 기금=寶로 구휼).
  2. 갓 간판·전각 간판 2개 달린 큰 관아, 흰옷 학생 2+1명 → **太醫監**(의학교육·행정) / 차순위 尙藥局.
  3. 사발·약첩(6~7) 간판, 창구 손이 약사발을 3명 줄에 건넴 + 사발 그린 판자 → **惠民局**(1112) / 차순위 東西大悲院.

**③ 잔결**: 섬 위 돌 아치+묘목, 잎날개 비둘기, 기대 세운 사발 판자 뜻 미상. 강 띠 오른쪽(x≥2030, y0~510)만 검은 여백 → 강 띠를 따로 붙인 흔적. 플라스크 다리 아래(x≈1530, y≈470~500) 회색 번짐(이음 자국), 플라스크 받침이 강 띠 밖으로 삐져나옴. 서가·길 오른쪽 집은 오른쪽 끝에서 잘림. 왕관 인물이 둘이라 구분이 소품에만 달림.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 그대로 1순위 **北宋~南宋(金 겹침) / 고려** (85%) · 2순위 **金元 / 고려** (10%). 사전이 시대를 바꾸지 않음 — 王 두 명을 「무대가 진다」 규칙으로 宋 무대에 풀면 오히려 잘 맞음.

**② 다시 읽기**
- 강: 사전에 본초서 전용 기호가 거의 없어 1단계 유지. **開寶本草**(열린 보물상자) → **嘉祐補注本草**(가위로 오려 덧대기) → **圖經本草**(소 몸에 약도 3포기) → **證類本草**(플라스크 안에 책 2권 = 會 「담는 것 안에 담긴 것」 → 두 책 합본) → 섬(돌 아치=門? + 묘목) 미상, **大觀·政和本草** 후보 → 두루마리+3층 서가 관리 **本草衍義**(긴 두루마리 = 衍). 3층 선반장은 官(가운데 층) 갈림이 舍岩 전용이라 적용하지 않음.
- 길: **王惟一**(王=왕관, 宋 무대 → 銅人 주형·목인 2구 = 동인 2구 주조, 《銅人腧穴鍼灸圖經》) → **錢乙**(엽전=錢, 새=乙; 포대기 아기 = 소아과 《小兒藥證直訣》) → **許叔微**(허수아비, 책 = 《普濟本事方》; 곁의 헝클어진 사내는 본인 또는 龐安時 후보) → **成無己**(무=無, 무 3뿌리 = 《註解傷寒論》·《傷寒明理論》·《明理藥方論》 3서 후보 — 「셋 포개짐=久」는 병 기간 글자라 비적용) → **王執中**(王=왕관 + 줄자가 몸 한복판을 감음 = 「몸 위에서는 中」 → 執中, 줄자 = 同身寸·취혈 《鍼灸資生經》; 사전으로 확신 상승) → **太平惠民和劑局方**(관인 상자 = 官, 옷걸이 8개 약봉지 = 官藥局 成藥; 사전 기호 없음).
- 거리: **濟危寶**(물독에 드리운 밧줄 = 濟 확정, 쪼갠 박 속 보석 = 寶 기금; 박은 한 개를 쪼갠 두 쪽이라 大 아님) → **太醫監**(간판 둘: 받침 위 테 넓은 갓 = 太, 기와지붕 한 채 = 寺 → 太醫監 ↔ 후일 개칭 典醫寺를 한 관아에 겹침; 흰옷 학생 = 의학교육) → **惠民局**(창구에서 내민 사발을 여러 손이 받음 = 惠 확정, 줄 선 3명 = 백성, 간판의 묶인 약봉지 다발 = 典藥/藥 판매·施藥).

**③ 잔결**: 섬 돌 아치+묘목, 잎날개 비둘기, 바닥에 기댄 사발 판자(惠 중복?)는 사전으로도 안 풀림. 간판 약봉지 다발=典藥이면 고려 기관명과 어긋남(惠民局에 藥 일반으로 읽음). 강 띠만 오른쪽 검은 여백(x≥2030, y0~510) — 따로 붙인 띠, 플라스크 아래 회색 번짐 = 이음 자국. 서가·오른쪽 집 잘림은 이웃 구간 몫.
