# blind16 · 960 판독 — 판독자 D

## 1단계 — 생판 (사전 열기 전, 그림만)

**① 시대** 1순위 **宋(北宋→南宋) / 高麗** 85% · 2순위 元 / 高麗 말 8%.
근거: 강의 본초 계보가 開寶→嘉祐→圖經→證類→大觀→政和로 정확히 宋 순서로 읽히고, 길에 銅人(1026)과 錢乙이 있으며, 거리는 청기와 관아 + 鄕藥 박.

**② 강(본초서) 왼→오**
1. 나룻배 + 활짝 열린 보물상자 → **開寶本草**(開寶 = 보물을 연다, 宋 첫 관찬본초).
2. 가위 든 소년 + 구멍 뚫린 책·오린 조각 1 → **嘉祐補註本草**(오려 덧대기 = 補註).
3. 몸에 약초 그림(큰 포기 3 + 작은 가지 1, 뿌리째) 소 → **圖經本草**(소 = 蘇頌, 그림 = 圖經).
4. 앉은 사람 + 증류 플라스크 속 책 2권 → 잎 1장 → **經史證類備急本草**(唐慎微; 經·史 2책에서 약을 뽑음).
5. 물 위 큰 네모 받침대 + 묘목 화분 → **大觀本草**(크게 보이는 기념대 = 大觀).
6. 관모 관리가 두루마리를 펼침 + 6칸 약장 + 잎 문 비둘기 → **政和本草**(관리 = 政, 평화 비둘기 = 和, 두루마리 = 新修 칙명). 차선 **本草衍義**(펼친 두루마리 = 衍).

**길(중국 의가) 왼→오**
1. 왕관 + 앞치마 장인, 나무 인형 2구, 사람 형상 거푸집 1벌(2면) → **王惟一 『銅人腧穴鍼灸圖經』**: 銅人 2구 주조.
2. 쪼그린 노인이 든 엽전(네모 구멍 속 무지개 포대기 아기), 엽전 위 새가 돈자루 → **錢乙 『小兒藥證直訣』**(錢 + 乙鳥) 소아과, 무지개 = 오장(五色) 변증.
3. 지치고 초췌한 곱슬머리 남자 → 불확실: **成無己 『注解傷寒論』** / 龐安時(傷寒 환자상).
4. 펼친 책을 얼굴로 단 허수아비 → **許叔微**(허수아비 ≒ 허숙미) 『普濟本事方』.
5. 녹색 옷 젊은이 + 한 매듭으로 묶은 막대 3개 → **陳言 『三因極一病證方論』**(三因 → 極一).
6. 왕관 노인 + 허리 가운데 감은 줄자 → **王執中 『鍼灸資生經』**(王 + 가운데를 잡음 = 執中, 취혈 척도).
7. 사모 관리 + 관인 + 옷걸이 약 8개에 걸린 접은 종이/천 → **宋慈 『洗冤集錄』**(빨래 = 洗, 관인 = 提刑官). 차선 **太平惠民和劑局方**(관 + 약첩).

**거리(고려) 왼→오**
1. 쪼개진 박 2쪽(보석·동전) + 밧줄이 물독으로 → **鄕藥救急方**(흥부 박 = 鄕藥, 건져냄 = 救急).
2. 청기와 관아: 갓 간판 + 관아 그림 간판, 머리띠 학생 2명 → **太醫監**(의료행정·의학교육).
3. 사발·세모 약첩 간판, 창구에서 사발을 아이 3명에게 줌, 사발 그린 세움판 → **惠民局**(서민 施藥). 차선 濟危寶 / 東西大悲院.

**③ 잔결** 강 오른쪽 끝(위쪽 띠)에 검은 세로 띠가 있어 프레임이 잘린 흔적이 보인다. 플라스크 오른쪽 아래의 회색 얼룩은 붓 자국으로 보인다. 지친 곱슬머리 남자와 녹색 젊은이가 무엇인지는 알 수 없다(허수아비와 묶음인지 따로인지도 모호하다). 관아 오른쪽 머리띠 행인과 뒤의 2명도 뜻을 모르겠다. 강 3번 소의 젖과 4번에서 떨어지는 잎이 각각 사실을 나르는지도 미정이다.

## 2단계 — 계통 (글자 사전으로 다시 읽기)

**① 시대** 1순위 **宋 / 高麗** 90% · 2순위 宋初·五代 / 高麗 초 5%. 거리의 세 기관이 濟危寶(963) → 太醫監(목종) → 惠民局(1112) 순서로 읽히므로 高麗 전기~중기이고, 강·길의 宋 순서와 들어맞는다.

**② 사전 대조 결과**
- 사전으로 확정된 것
  - 왕관 = **王**: 성이 王이라는 것까지만 알려 주고, 무대(宋)가 누구인지 정한다. 銅人 거푸집 곁의 왕관 = **王惟一**, 줄자 곁의 왕관 = 王 + 몸 위 한복판(**中**, 「몸 위에서는 中」) = **王執中 『鍼灸資生經』**이다.
  - 아이 3명이 손을 뻗어 받는 빈 사발 = **惠**(여러 손이 받아 드는 빈 사발)이고, 세움판의 사발도 같은 글자다. 간판의 끈으로 묶은 약첩 다발 = **典藥**이다. 그래서 **惠民局 → 惠民典藥局**(이름이 바뀐 것까지 나름)이다.
  - 큰 갓 간판 = **太**, 산 사이 기와 절집 간판 = **寺**다. 같은 관아에 두 간판이 걸렸으니 **太醫監 → 典醫寺**의 개칭으로 읽힌다. 머리띠 학생 2명 = 의학 교육·醫業이다.
- 1단계에서 뒤집힌 것
  - 물독에 드리운 밧줄 = **濟**, 쪼개진 박 속 보석·동전 = 寶(기금)다. 그래서 **濟危寶**(광종 963, 기금 이자로 빈민 구휼·치료)다. 1단계에서 읽은 鄕藥救急方은 버린다.
- 사전 항목이 없어 1단계 판독을 유지한 것
  - 강: **開寶本草**(열린 보물상자) → **嘉祐補註本草**(가위·오려 낸 책) → **圖經本草**(소 = 蘇頌, 약초 그림 4포기) → **證類本草**(플라스크 속 책 2권 = 經·史 → 잎 1장) → **大觀本草**(큰 받침대 + 묘목) → **政和本草**/本草衍義(관리·두루마리·3단×2열 약장·비둘기)
  - 길: **錢乙**(엽전 + 새 = 錢乙, 무지개 포대기 아기 = 소아·五色) → (초췌한 남자: 미상, **朱肱/龐安時** 후보) → **許叔微**(허수아비) → **陳言 三因**(한 매듭으로 묶은 막대 3개) → **王執中** → **宋慈 『洗冤集錄』**(관인 + 걸린 빨래 8벌)
- 사전에 걸리지 않음을 확인한 것: 3단 약장은 舍岩의 官 선반 문법(가운데 층)이 아니다. 가운데 층이 비어 있고 비둘기가 맨 위에 있기 때문이다. 나룻배도 사전의 藥(배 모양 약연)이 아니라 진짜 배다.

**③ 잔결** 강 오른쪽 끝의 검은 세로 띠는 프레임이 잘렸거나 이어 붙인 흔적이다. 다음은 사전으로도 풀리지 않는다.
- 길의 초췌한 곱슬머리 남자와 녹색 옷 젊은이(누가 누구인지)
- 강 5번의 둥근 단지 + 네모 받침대
- 강 6번의 비둘기(和? 사전의 和는 수평 저울이라 맞지 않는다)
- 관아 앞 머리띠 행인 1명과 뒤의 2명
