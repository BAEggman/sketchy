# z12 판독 (①줄 세로 띠)

## 1단계 — 생판 (사전 없이)

**① 시대**: 1순위 **晉(西晉) / 한국 삼국시대**(고구려·백제·신라) — 확신도 65%. 2순위 後漢 말~三國.

**② 레인별 묶음**
- **강(본초)**: 이 띠 안의 강물은 비어 있다. 오른쪽 위 가장자리에 무언가의 끝(뱃머리?)이 잘려 보이나 이웃 띠 몫으로 본다. → 표제어 없음.
- **흙길(중국 의가·의서)** — 한 묶음으로 읽힌다.
  - 사람: 상투만 튼 맨머리, 관(冠)·관복 없는 소박한 베옷 차림의 중년 남자. 덧붙은 소품이 없다 → 벼슬하지 않은 처사(隱士)로 읽어 **皇甫謐**.
  - 닭: 깃털이 비늘·갑옷 미늘처럼 그려진 닭(갑옷 = **甲**, 새 = 乙鳥의 **乙**) 몸통에 침이 사방으로 꽂혀 있음(= **針灸**) → 서명 **『針灸甲乙經』**.
  - 닭 목의 금메달 → 「현존 最古의 침구 전문서」(최초 표지).
  - 뒤쪽 흰 깃발 수십 개를 꽂은 둥근 밭 → 몸 위 혈 자리 표지를 무더기로 정리한 것 = **경혈(349혈) 정리·부위별 배열**로 추정. 「明堂孔穴」 등 세 책을 모아 엮은 뜻일 수도.
- **거리(한국)**: 초가 두 채와 회색 기와집 한 채, 사람·말하는 소품 없음 → 이 시대 한국 거리는 비어 있음(배경). 굳이 읽으면 초가 = 삼국 초기의 소박한 상태.

**③ 뜻 모를 것·어색한 것**
- 흰 깃발 밭의 정확한 뜻(혈 수? 3서 종합? 白=?)이 확정되지 않는다.
- 남자에게 직접 붙은 소품이 하나도 없어 닭과 같은 묶음인지가 위치(바로 옆)로만 추정된다.
- 오른쪽 끝 탁자(위에 검푸른 물건)와 강 오른쪽 위 끄트머리는 잘린 이웃 띠 소품.
- 거리 가운데 회색 기와집만 채색이 빠진 듯 흐릿해 다른 그림을 이어 붙인 느낌.

## 2단계 — 계통 (blind6 사전으로 다시 읽기)

**① 시대**: 그대로 **晉(西晉) / 한국 삼국시대** — 확신도 70%. 사전에는 시대를 직접 나르는 기호가 없어 시대 판정은 1단계 논리(닭 = 甲乙經)에 기댄다.

**② 레인별 묶음**
- **강**: 여전히 비어 있음. 표제어 없음.
- **흙길** — 한 묶음.
  - 남자: 사전의 성씨 기호(王관·張활·李자두·馬고삐)도, 太(큰 갓)도 없다 → 성씨 기호로는 못 짚는다. 관 없는 처사 차림이라는 1단계 읽기를 유지해 **皇甫謐**(사전 기호 미등재 인물).
  - 닭: 사전의 비늘갑옷은 肝(초록 비늘갑옷 **장군**) 몫이지만, 이 닭은 갈색이고 장군이 아니며 장부 인물도 아니므로 肝이 아니다 — 비늘 = 갑옷 = **甲**, 새 = **乙**로 읽는 것이 맞다. 꽂힌 것은 痛(살에 박힌 **쇠못 하나**)이 아니라 손잡이 달린 가는 침 여러 개라 **針灸**. 散(흩어져 날림)도 아니다 — 박혀 있지 날지 않는다. → **『針灸甲乙經』**, 금메달 = 「현존 最古 침구 전문서」.
  - 흰 깃발 밭: 사전에 등재 없음 → 1단계대로 **경혈(349혈) 정리**로 둔다(확신 낮음).
- **거리**: 초가 둘 + 회색 기와집 하나. 사전 寺(기와지붕을 얹은 절 한 채)에 걸리는지 검토 — 그러나 절 표지(탑·처마 장식·스님)가 없고 흐릿한 원경이며 곁에 말하는 소품이 없다. 조건을 억지로 맞추면 寺 → 「法師」 → **『新羅法師方』**이 떠오르지만 근거가 약하다(20%). 판정: 빈 거리(배경)로 본다.

**③ 남은 것**
- 흰 깃발 밭은 사전으로도 풀리지 않는다(혈 수인지, 세 책 종합인지, 다른 사실인지 미상).
- 회색 기와집은 寺 기호와 배경 사이에서 갈린다.
- 남자는 사전 기호가 하나도 없어 닭 곁이라는 자리로만 皇甫謐이 된다.
- 결론: 사전 어휘로 새로 풀리는 것은 거의 없고, 오히려 肝·痛·散 오독을 걸러 1단계 읽기를 굳혀 준다.
