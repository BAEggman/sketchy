# z14 판독 (blind16z)

## 1단계 — 생판 (사전 열기 전)

**① 시대**: 중국 **北宋** / 한국 **高麗** — 확신도 80%. 근거: 강의 '보물상자'(開寶)·흙길의 '왕관+인체 거푸집'(王惟一 銅人, 1026)·'엽전 속 아기'(錢乙, 북송 말)가 모두 북송 전·중기에 몰린다. 거리의 청기와 집·흰옷 아이들은 고려로 읽힘.

**② 레인별 묶음**
- 강(본초) 좌: 배 위에 뚜껑 열린 보물상자 → 「보물을 연다」 = **開寶本草**(973, 송 최초의 관찬 본초).
- 강(본초) 우: 나루에 앉은 사람이 큰 가위를 들고, 앞의 책에는 오려 붙인 조각 → 가위=「가우」 소리로 **嘉祐本草**(嘉祐補注神農本草, 1060), 오려 붙인 조각 = 補注(덧붙임). 차선: 조각=그림 → **圖經本草**, 또는 經史에서 오려 모은 **證類本草**.
- 흙길 좌: 왕관 쓴 남자(王) + 나무 쟁반 위 인체 모형 2구 + 쇠 거푸집(인체 윤곽) 한 벌 → **王惟一** — 『銅人腧穴鍼灸圖經』, 銅人 2구 주조(鑄).
- 흙길 우: 쪼그려 앉은 노인이 큰 엽전(錢)을 굴리고, 네모 구멍 안에 무지개 포대기 아기, 엽전 위엔 돈주머니 문 새 → **錢乙** — 『小兒藥證直訣』, 소아과의 비조(兒科之聖). 새=「乙」(제비), 무지개 오색 = 五臟 辨證(오색·오장)으로 읽음.
- 거리(고려) 좌: 반 갈린 큰 박 속 보석·곡식, 박 꼭지 새끼줄이 물독에 잠김 → 寶 = **濟危寶**(963 광종, 빈민 구제). 물독+줄 = 「濟」(건짐)로 보조.
- 거리(고려) 우: 갓 그림 간판의 관아 앞을 걷는 흰옷 아이 둘 → 관(官) 의료기관 **太醫監**? 아이들=학생이면 醫學 교육. 미상.

**③ 잔결**: 왕관 남자의 파란 앞치마, 무지개 포대기의 뜻(오색?)이 분명치 않음. 거리 간판의 「갓 + 원통(단지)」 기호, 흰옷 아이 둘이 무엇을 나르는지 모름. 박 꼭지 줄이 물독으로 이어지는 모양(두레박?)이 두 소품을 억지로 이은 듯함. 오른쪽 끝에 잘린 사람은 이웃 띠 몫이라 무시.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 중국 **北宋** / 한국 **高麗(전기)** — 확신도 88%. 사전의 王(왕관)·濟(물에 드리운 밧줄)·太(테 넓은 큰 갓)가 그대로 맞물려 1단계 답이 굳어짐. 연대 순서도 開寶(973)→嘉祐(1060) / 王惟一(1026)→錢乙(1119) / 濟危寶(963)→太醫監(목종대)로 왼→오 흐름과 맞음.

**② 레인별 묶음**
- 강 좌: 열린 보물상자를 실은 배 → **開寶本草**(송 최초 관찬 본초). 사전 기호 없음, 「寶를 開」 직역.
- 강 우: 가위 든 사람 + 조각을 오려 붙인 책 → 「가위≈가우」 소리 말장난으로 **嘉祐本草**(嘉祐補注本草, 補注 = 덧붙인 조각). 사전의 補(국물 그릇)와는 무관하므로 補注는 기호가 아니라 장면 읽기. 차선 **圖經本草**(오린 그림 조각 = 圖).
- 흙길 좌: 왕관 = 王(사전: 성 王까지만, 어느 王인지는 무대) → 北宋 + 인체 모형 2구 + 인체 거푸집 + 주물공 앞치마 = **王惟一** — 銅人 2구 주조, 『銅人腧穴鍼灸圖經』. 같은 무대의 다른 王(王懷隱·王執中)은 銅人 소품과 안 맞아 배제.
- 흙길 우: 엽전(錢) + 그 위 새(乙, 제비) + 네모 구멍 속 포대기 아기 → **錢乙** — 『小兒藥證直訣』, 소아과 전문의 확립. 무지개 오색 포대기 = 五臟 辨證(차선, 사전 기호 아님).
- 거리 좌: 보석 찬 박(寶) + 박 꼭지 밧줄이 물독 물에 드리움 = 사전 濟 → **濟危寶**(광종 963, 빈민 구휼 기금). 흥부 박(가난 구제) 연상이 기능을 보탬.
- 거리 우: 간판의 「머리꼴 원통에 씌운 테 넓은 큰 갓」 = 사전 太 → **太醫監**(고려 중앙 의료행정·의학교육). 흰옷 아이 둘 = 의학 생도(醫生)로 읽음(확신 낮음).

**③ 잔결**: 濟危寶의 「危」를 나르는 소품이 없음. 강의 배가 사전 藥(배 모양 약연)과 겹쳐 보일 수 있음(물 위 진짜 배라 藥으로는 안 읽었다). 새가 문 끈 조인 돈주머니가 사전 收(끈 조인 자루)와 샘. 무지개 포대기·파란 앞치마·흰옷 아이 둘은 뜻이 약함. 박 꼭지 밧줄이 물독으로 이어지는 부분은 두 소품을 이어 붙인 흔적처럼 보임.
