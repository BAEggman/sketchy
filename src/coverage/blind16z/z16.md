# z16 판독 (blind16z)

## 1단계 — 생판 (사전 없이)

**① 시대**: 중국 **先秦(春秋·戰國) ~ 前漢** / 한국 **古朝鮮(빈 거리)** — 확신도 75%.
근거: 강 왼끝에 산·폭포(발원지)가 있어 본초 계보의 「시작점」 = ①줄의 맨 왼쪽 띠로 보인다. 흙길의 까치(鵲)→곡식 창고(倉) 순서는 扁鵲(戰國)→倉公(前漢) 순서와 맞다. 아래 거리는 초가 한 채뿐, 덧붙은 소품이 없다.

**② 레인별 묶음**
- 강(본초): 소머리 사람(牛首人身) + 목의 금메달 + 크기가 줄어드는 바구니 3개 + 발원지 폭포 → **神農 / 『神農本草經』** — 최초의 본초서(금메달·발원), 약물 상·중·하 **三品 분류**(대·중·소 바구니), 365종.
- 흙길 ①: 2×2 선반(장작 다발 / 마른 약초 다발 / 5칸 사다리 / 금테 상자) → 확정 못 함. 후보 **『黃帝內經』**(鍼·藥·導引 등 치료법 모음) 또는 扁鵲 소품(長桑君의 懷中藥 = 약초, 禁方書 = 상자, 上池之水 = 사다리「上」). 금테 상자 = 「金匱」라면 **張仲景**이지만 순서가 扁鵲보다 앞이라 어긋난다.
- 흙길 ②: 까치(鵲) + 책상 위 펼친 책 + 3색 깃발(白·紅·靑) + 뒤의 성벽 → **扁鵲(秦越人)** — 책 = **『難經』**(扁鵲 撰으로 전함), 깃발 3개 = 寸·關·尺 三部(獨取寸口)·脈診의 祖, 성벽 = 「視見垣一方人」(담 너머를 꿰뚫어 봄, 望診).
- 흙길 ③: 문 열린 곡식 창고(쌀가마 다수) → **倉公 淳于意**(太倉長) — 가마 더미 = **診籍**(최초의 醫案 25례).
- 거리(한국): 초가 한 채 → 표제어 없음(빈 거리).

**③ 잔결**: 선반 4소품의 뜻(특히 장작 다발·5칸 사다리)이 안 풀림. 소머리 사람·까치·금테 상자에 흰/금색 외곽선이 둘려 오려 붙인 스티커처럼 보임(합성 흔적). 오른쪽 끝 창고와 거리 오른쪽 끝 작은 나무는 띠 경계에서 잘림.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 중국 **先秦(戰國) ~ 前漢** / 한국 **古朝鮮(빈 거리)** — 확신도 70%. 강 발원지 + 神農 + 扁鵲은 그대로이나, 창고가 倉이 아니라 藏으로 읽혀 前漢(倉公) 근거가 약해짐.

**② 레인별 묶음 (사전 대조)**
- 강: 사전에 소·금메달·바구니 항목 없음 → 1단계 유지. **神農 / 『神農本草經』** — 최초 본초서, 바구니 대·중·소 = **上·中·下 三品**. (「中 = 같은 것 셋 중 가운데」, 「大 = 하나가 두 배」로도 크기 차등은 읽히나 포개지지 않았으므로 「久」는 아님. 폭포 = 「下」(쏟아짐)일 수 있으나 발원 배경으로 봄.)
- 흙길 ①(선반): 2×2 선반장이라 「官(3층 선반장의 가운데 층)」·舍岩의 格은 해당 없음. 마른 다발은 **짚 빗자루 = 瀉**로 읽힌다. 장작·5칸 사다리·금테 상자는 사전에 없음. 까치 꼬리가 선반에 닿아 **扁鵲 묶음의 소품**일 가능성 ↑ — 虢太子 치료의 鍼·熨(장작 = 熨 데우기)·湯, 瀉. 단독 표제어라면 **『黃帝內經』**(치료법 모음·「藏之金匱」 상자) 후보, 확신 낮음.
- 흙길 ②: 까치 = **扁鵲(秦越人)** — 펼친 책 = **『難經』**, 3색 깃발 = 寸·關·尺 三部(또는 隨俗爲變의 帶下·耳目痺·小兒醫 셋), 성벽 = 「視見垣一方人」. 「三峯」은 깃발 높이가 달라 해당 안 됨.
- 흙길 ③: 문 열린 곳간 + 가마니, **앞에 관리가 없음 → 갈림 규칙상 倉이 아니라 「藏」**. 扁鵲 묶음의 연장이면 「**盡見五藏癥結**」(담·문 너머 五藏을 꿰봄). 단, 곳간 오른쪽이 띠 경계에서 잘려 있어 관리가 오른쪽 이웃 띠에 서 있다면 倉 → **倉公 淳于意**(診籍).
- 거리: 초가 한 채, 사전 기호 없음 → 빈 거리.

**③ 잔결**: 장작 다발·5칸 사다리·금테 상자·3색 깃발은 사전에도 없어 뜻 미확정. 소머리·까치·금테 상자의 흰/금 외곽선은 오려 붙인 합성 흔적. 곳간이 倉/藏 갈림의 결정 요소(관리)를 띠 경계 밖에 두었을 가능성 — 단독 띠로는 판정이 갈린다.
