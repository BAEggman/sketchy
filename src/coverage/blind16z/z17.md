# z17 판독 (blind16z)

## 1단계 — 생판 (사전 없이)

**① 시대**: 明 후기(萬曆 전후, 16세기 후반) / 朝鮮 중기(宣祖~光海君) — 확신 80%.
근거: 흙길 인물 둘 다 明代 복두(검은 방건)·직령포. 앞거리는 기와집·우물·흰옷 상투 청년 = 朝鮮. 흙길 인물 후보(李梴·龔廷賢)가 모두 1570~80년대이고, 둘 다 같은 시기 朝鮮 의서(東醫寶鑑)의 주 인용서라 앞뒤 거리가 서로 맞는다.

**② 말하는 묶음 (레인별)**
- 강(본초 계보): 물결뿐, 소품 없음 (오른쪽 끝 작은 물체는 이웃 띠 몫).
- 흙길 왼쪽: 주름진 노인 + 꼬리깃에 지네 다리가 돋은 봉황(꼬리 끝 공작 눈무늬) → **龔廷賢** — 지네(百足·萬足, 蜈蚣의 蚣=공=龔)=萬, 불사조의 되살아남=回春 → 《萬病回春》; 노인=壽 → 《壽世保元》. 대안 ① **吳有性**(불새=溫, 독충=疫·戾氣 → 《溫疫論》, 蜈→吳) ② **吳崑**(蜈→吳, 昆蟲→崑, 《醫方考》).
- 흙길 오른쪽: 젊은 의가 + 손에 자두 + 홀로 선 문틀 + 바닥의 긴 통나무 → **李梴** 《醫學入門》 — 자두=李, 긴 나무(梴=長木)=梴, 문틀=入門. 대안 **李中梓**(통나무=梓; 문틀 설명 안 됨).
- 앞거리(朝鮮): 두레박 우물 + 해 뜨는 산수·전각 그림 간판 + A자 받침에 걸린 약초 자루 2개 + 흰옷 상투 청년 → **許浚 《東醫寶鑑》** — 우물 치기(浚井)=浚, 산 너머 해=東, 액자 그림(비춰 보는 거울)=寶鑑, 약초 자루=湯液篇/鄕藥. 대안 **惠民署**(흰옷 백성=民) 또는 **鄕藥集成方**(약초 자루=鄕藥, 두 자루=集成).

**③ 잔결**: 봉황+지네 합성이 한 글자(기괴함 처리)인지 두 글자인지 불명. A자 받침대(지게 같은 틀) 두 개의 뜻(人? 二?) 불명. 앞거리 오른쪽 담장 너머 붉은 기둥 정자와 오른쪽 건물은 소품 없는 배경으로 보이며, 왼쪽 건물과의 경계가 이어 붙인 자리처럼 보인다.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 시대**: 明 / 朝鮮 — 80% 유지. 다만 흙길은 明 후기(1570~80년대)로, 앞거리는 사전의 濟 때문에 朝鮮 초(1397~98)로 읽혀 같은 띠 안에서 시기가 어긋난다.

**② 말하는 묶음**
- 강: 소품 없음 (변동 없음).
- 흙길 오른쪽: 사전 「李 = 허리춤 자두」와 「門 = 작은 문간(문틀)」이 그대로 맞는다. 성 李 + 門, 무대는 明 → **李梴** 《醫學入門》(1575). 1단계보다 확신이 올랐다(약 80%). 통나무는 사전에 없는 기호다. 長木 뜻의 梴으로 보며, 李中梓의 梓로 읽는 것은 대안으로만 둔다.
- 흙길 왼쪽: 사전 「吳 = 얼굴 절반만 한 큰 입」인데 노인의 입은 작다 → 吳有性·吳崑 대안은 탈락. 張(활)·王(왕관)·馬(말)도 없다. 봉황+지네 합성은 사전 밖의 새 기호여서 1단계 풀이를 유지한다: **龔廷賢** — 지네 다리=萬, 꼬리가 사람을 한 바퀴 감음=回, 불사조=春 → 《萬病回春》, 노인=壽 → 《壽世保元》(약 45%). 대안은 **朱橚**(붉은 새=朱, 수만 개의 발=최다 처방 《普濟方》).
- 앞거리: 지붕 끝에서 우물로 드리운 밧줄 = 사전 「濟 = 물에 드리운 밧줄」. 자루에서 돋은 푸른 풀=生, 지게 틀에 실린 약초 자루 둘=鄕藥 채취·集成, 흰옷 백성=서민 구료, 간판 단 집=院 → **濟生院**(1397, 鄕藥 수집·서민 구료) 및 그곳에서 낸 **鄕藥濟生集成方**(1398). 1단계의 東醫寶鑑(산 너머 해=東, 우물=浚)은 사전과 부딪쳐(밧줄=濟) 대안으로 내린다. 다만 시기는 東醫寶鑑 쪽이 흙길과 맞는다.

**③ 잔결**: 앞거리 濟(1397) 읽기와 흙길 李梴·龔廷賢(16세기 후반) 사이에 약 180년 시차가 있다 — 어느 한쪽은 오독일 수 있다. 산수화 간판의 해는 사전대로라면 陽인데, 이 묶음에서 쓰일 곳이 없다. 통나무와 봉황-지네는 미등재 기호다. 밧줄이 도르래 없이 지붕 끝에 매여 있어 이어 붙인 티가 난다. 오른쪽 붉은 기둥 정자와 담장(內?)은 배경으로 본다.
