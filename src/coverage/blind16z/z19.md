# z19 판독 (blind16z)

## 1단계 — 생판 (사전 열기 전 확정)

**① 시대**: 중국 **元(宋 말~元)** / 한국 **高麗 말** — 확신도 55%.
근거: 맨 아래 한국 거리의 인물이 「맥 파형 + 세모 봉우리」 책을 들고 있어 고려 말 의서로 읽혔고, 가운데 길의 왕관 노인을 元대 「王」 성 의가로 읽음.

**② 레인별 묶음**
- **강(맨 뒤)**: 물결과 모래 둑뿐이고 덧붙은 소품이 없다 → 이 띠에서는 본초서 표제가 없음(공백 구간).
- **흙길-좌 (풀무덤 + 미끄럼틀 + 아이)**: 미끄럼 = 「滑」 → **滑壽**(元, 『十四經發揮』·『難經本義』·『診家樞要』) 1순위. 대안은 아이 = 小兒 → **錢乙**(『小兒藥證直訣』). 땅 위의 구불구불한 붉은 선을 「經脈」으로 보면 『十四經發揮』와 맞물린다. 다만 아이에게 후광(흰 테두리)이 없어 「말하는」 묶음인지는 약하다.
- **흙길-중 (빨랫줄의 흰 천 + 빨래판·뚜껑 얹은 나무 궤)**: 빨래 = 「洗」, 나무 궤 = 관(棺), 풀무덤 = 봉분 → **宋慈 『洗冤集錄』**(南宋, 세계 최초의 법의학서) 후보. 붉은 선을 핏자국으로 보면 이 해석이 강해진다.
- **흙길-우 (금관을 쓴 백발 노왕, 뒷짐, 후광 있음)**: 王 + 늙음(古) → **王好古**(元, 易水學派, 『陰證略例』·『湯液本草』) 1순위. 뒷짐(손을 감춤) = 陰證으로 읽었다. 대안은 금관 = 銅/金 → **王惟一**(北宋, 銅人, 『銅人腧穴鍼灸圖經』), 또는 금관 = 金 왕조.
- **거리(맨 앞) (초록 단령·검은 관모의 관원, 후광 있음, 펼친 책: 맥 파형 + 흰 세모 봉우리 3~4개)**: 맥 + 그림(圖) + 세 봉우리 = 三峰 → **鄭道傳 『診脈圖誌』**(고려 말). 뒤의 기와 건물은 관청(典醫寺 등)일 수 있지만 따로 지시하는 소품은 없다.

**③ 뜻 모를 것·이음새**
붉은 구불선은 말판의 길인지, 피인지, 경맥인지 알 수 없다. 아이·미끄럼틀과 빨래 묶음에는 후광이 없어 배경인지 표제인지 모호하다. 좌하단의 흰 도포 상투 인물과 옹기는 가장자리 이웃 몫이거나 장식으로 보인다. 우하단 섬광(✦)은 뜻을 모르겠다. 강 레인은 비어 있다.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 중국 **元 말** / 한국 **高麗 말** — 확신도 65%.
사전의 「三峯 = 고려 거리 + 맥박 물결 = 鄭道傳」이 거리 레인을 고려 말로 못박는다. 이 띠는 ③줄의 끝 쪽(元 말과 高麗 말이 만나는 자리)으로 읽힌다.

**② 레인별 묶음**
- **강**: 등재 기호가 하나도 없다 → 본초서 표제 없음. 1단계와 같다.
- **거리 (초록 단령 관원 + 펼친 책)**: 책에서 솟은 종이 팝업 봉우리는 사전의 **三峯**이다. 「고려 거리 + 맥박 물결」이라는 조건도 둘 다 들어맞는다 → **鄭道傳 『診脈圖誌』**(고려 말 맥학서). 맥 파형 = 診脈, 펼친 책 = 圖誌. 1단계 판독이 사전으로 확증됐다(확신 85%).
- **흙길-우 (금관 노인)**: 사전상 왕관은 **「성이 王」까지만** 말하고, 어느 王인지는 무대가 정한다. 무대는 宋金元 줄이고, 바로 아래가 고려 말 鄭道傳이다 → 시대를 맞추면 元 말의 **王履**(『醫經溯洄集』, 眞中風/類中風 구분, 傷寒과 溫病 구분)가 1순위다. 2순위는 **王好古**(易水學派, 『陰證略例』)다. 다만 王好古는 13세기 인물이라 고려 말과 시대가 어긋난다. 1단계에서 「늙음 = 古」, 「뒷짐 = 陰證」으로 읽은 것은 사전에 없는 기호라 철회한다. 王 외에 이 인물에게 덧붙은 사실 소품은 없다.
- **흙길-좌 (풀무덤·미끄럼틀·아이) / 흙길-중 (빨래 천·빨래판·궤)**: 사전에 해당하는 글자가 없다. 아이는 아직 미끄러지지 않았으므로 「下 = 쏟아짐」으로 보기 어렵다. 빨래 천은 곧게 늘어져 있어 風(옆으로 날림)도 아니고, 김이 없어 溫도 아니다. 넷 기둥에 팽팽히 친 천이 아니므로 膈도 아니다. 후광이 없어 「말하는」 묶음이 아닌 배경일 공산이 크다. 1단계의 **滑壽**(미끄럼 = 滑)와 **宋慈 『洗冤集錄』**(빨래 = 洗) 후보는 사전 밖의 말장난이라 낮춘다. 다만 滑壽(1341) 다음에 王履(1368)가 오는 순서와는 들어맞는다.

**③ 잔결·이음새**
- 붉은 구불선: 사전으로는 「血 = 붉은 것」이지만 의학사 표제로 이어지지 않는다. 양쪽 가장자리로 빠져나가므로 말판의 길이거나 이웃의 **朱丹溪(丹溪 = 붉은 시내)** 소품일 수 있다.
- 봉우리 수: 사전 규격은 「같은 높이로 셋」인데, 그림은 높이가 다른 봉우리 넷(왼쪽 쪽 1개, 오른쪽 쪽 3개)이다.
- 좌하단의 흰 도포 인물은 사전대로라면 「흰 도포 재상 = 肺」로 오독될 위험이 있다. 의학사 판에서는 행인이나 이웃 띠 몫으로 보인다.
- 섬광 ✦(華?)과 옹기는 뜻이 없다.
