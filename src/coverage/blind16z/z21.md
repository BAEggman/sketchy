# z21 판독 기록

## 1단계 — 생판 (사전 없이)

**① 시대**: 先秦(戰國)~漢 / 한국 쪽은 고조선·삼한(사실상 빈 거리). 1순위 **漢(西漢~東漢)**, 확신도 70%.

**② 레인별 묶음**
- **강(본초)** — 소머리 사람(神農=牛首)이 금메달을 걸고, 산 속 폭포(강의 수원)에서 막 시작되는 나루터에 섰다. 크기 순 바구니 3개. → **神農本草經**: 금메달 = 현존 최고(最古)·「최초」의 본초서, 폭포 수원 = 본초 계보의 원류, 바구니 3개 = **上·中·下 三品** 분류. 바구니 뒤 작은 원통은 뜻 불명.
- **흙길 ① (왼쪽, 기와 문루)** — 지붕 덮인 문(門)에 금빛 상자(**金匱**), 막대 묶음(竹簡 또는 침 묶음?), 짚·풀 다발(艾?), 사다리가 걸림. 금궤만 확실히 「말을 한다」 → **張仲景 『金匱要略』** 1순위. 다만 흙길은 왼→오 순서인데 오른쪽에 扁鵲·倉公이 오므로, 문 = 扁鵲이 이른 **虢宮 門下**(虢太子 소생) 또는 扁鵲이 舍長으로 있던 客舍일 가능성도 있음(그러면 금궤 = 長桑君의 禁方).
- **흙길 ② (가운데, 까치)** — 까치(鵲) + 책상 위 펼친 책 + 흰·붉은·푸른 깃발 3개. → **扁鵲**(秦越人): 책 = 扁鵲 저작으로 전하는 **『難經』** 또는 長桑君에게 받은 禁方書; 성벽(垣) = 「視見垣一方人」. 깃발 3개 = 뜻 미정(색 진단·望診?).
- **흙길 ③ (오른쪽, 곳간)** — 문 열린 창고에 쌀가마 가득. → **倉公 淳于意**(太倉長): 열린 곳간 = 창고 기록 = **診籍**(최초의 의안·병력 기록) 추정.
- **거리(한국)** — 초가 한 채만 덩그러니, 덧붙은 소품 없음. → 이 줄 한국 거리 **비어 있음**(초가 = 고조선·삼한 시대 배경).

**③ 뜻 모를 것·어색한 것**: 바구니 뒤 작은 원통(죽통?), 문루의 사다리·막대 묶음·짚 다발(금궤와 한 묶음인지 따로인지 불분명), 책상의 3색 깃발. 문루 안이 비어 있어 「사람」이 없음 — 금궤가 문루에 매달린 것이 어색. 오른쪽 끝 초가 지붕 귀퉁이는 이웃 띠 몫.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 변동 없음 — **漢(先秦 戰國 포함) / 고조선·삼한(빈 거리)**, 65%. 사전에 시대를 바꿀 기호가 없다.

**② 레인별 재판독**
- **강** — 바구니 셋 = 「같은 것 셋 중 가운데」의 **中** 문법과 맞아 **上·中·下 三品**이 오히려 굳어짐. 셋이 포개진 게 아니라 나란하니 **久** 아님, 둘이 아니니 **大** 아님. 소머리 + 금메달 + 수원 폭포 = **神農本草經**(최초 본초서) 유지.
- **흙길 ① 문루** — 사전의 **門**(문간) 위에 금궤, 짚 다발 = **瀉**(짚 빗자루)일 수 있음, 죽간 묶음·사다리는 사전에 없음. 張을 나르는 「등에 멘 활」이 없어 張仲景을 기호로는 세울 수 없다 → **『金匱要略』**은 그림(금궤)만으로 버티는 약한 후보로 강등. 扁鵲 고사의 **虢宮 門**으로 읽는 쪽이 왼→오 순서와 더 잘 맞음.
- **흙길 ② 까치** — 사전 무관, **扁鵲** 유지(책 = **『難經』** 후보). 깃발 셋은 **三峯** 아님 — 책에서 솟은 것이 아니고 무대도 고려 거리가 아니다.
- **흙길 ③ 곳간** — 사전 갈림: 문 열린 곳간 + 가마니 + **앞에 관리 없음 = 藏**(倉 아님). 그러면 **倉公 淳于意**는 기호상 성립하지 않고, 藏 계열(**『中藏經』**(華佗 托名) 등)이 떠오르나 中 기호가 따로 없어 확정 못 함. 곳간 오른쪽이 띠 끝에서 잘려 관리가 이웃 띠에 섰을 가능성은 남음.
- **거리** — 초가뿐, 사전 기호 없음 → **빈 거리** 유지.
- 성벽 앞 = 「담 바깥」 **外**로 읽을 수도 있으나 줄 전체에 이어지는 배경이라 봄.

**③ 잔결**: 사다리·죽간 묶음·3색 깃발·바구니 뒤 원통은 사전으로도 안 풀림. 곳간이 倉/藏 갈림에 걸려 표제어가 흔들림. 사전 어휘로 더 잘 풀린 것은 「三品」 하나뿐, 나머지는 1단계와 같거나 더 흐려졌다.
