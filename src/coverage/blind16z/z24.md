# z24 판독 (blind16z)

## 1단계 — 생판 (사전 열기 전 확정)

**① 시대**: 중국 **金·元**(남송 말~원) / 한국 **高麗** — 70%. 흙길에 왕관 쓴 노인·아이 미끄럼틀이 있고 아래 거리는 기와 관청 앞의 복건 쓴 관인·흰옷 서민이라 고려 쪽 의료기관으로 읽힘.

**② 말하는 묶음**
- 강(뒤): 소품 없음. 물·모래톱뿐이라 이 띠에는 본초서가 없음.
- 흙길 왼쪽: 나무(木) 미끄럼틀에 아이(子)가 탔으니 木+子 = 李. 풀 덮인 흙무덤(土)은 補土. → **李杲(李東垣)**, 補土派·「脾胃論」. 빨랫줄 가운데에 걸린 노란 천(白-黃-白)은 中焦 脾土를 위로 들어 올린다는 뜻(升陽·補中益氣)으로 짐작. 2순위로는 아이가 미끄러져 내려오니(下) **張從正** 攻下派.
- 흙길 오른쪽: 금관(王) 쓴 늙은이(古)는 **王好古**로 1순위. 새끼줄로 묶인 물고기와 핏자국 같은 붉은 줄은 확정하지 못함. 2순위는 **王履**: 상류로 거슬러 오르는 물고기(溯洄)를 묶었으니(集) 「醫經溯洄集」, 붉은(朱) 줄은 朱震亨의 제자라는 뜻.
- 거리(앞): 녹포에 검은 복건을 쓴 인물(테두리 후광 있음)이 관청 앞에 서 있고, 흰옷 서민(民)과 약항아리가 곁에 있음. → **惠民局**(고려 예종, 서민 구료·약 판매)이 1순위. 2순위는 **鄕藥救急方**, **東西大悲院**.

**③ 잔결**
- 빨래(흰·노랑 가닥, 국수 같기도 함)와 탁자 위 대야·벽돌 같은 덩어리는 뜻을 모름. 洗 → 宋慈 「洗冤集錄」일 수도 있음.
- 묶인 물고기와 붉은 줄이 무엇을 나르는지 확정하지 못함.
- 왕관 노인과 복건 인물에만 흰 후광 테두리가 있어 오려 붙인 흔적으로 보임.
- 아래 오른쪽 문짝에 흰 번짐이 있음(지우고 다시 칠한 흔적).
- 뒤편의 흰 산 윤곽, 골목의 초록 덤불, 흙길의 발자국(말판 칸 표시로 추정)은 뜻이 없어 보임.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 1단계와 같이 중국 **金·元** / 한국 **高麗**, 70%. 사전 규칙상 王이 어느 王인지는 무대가 정하는데, 이 줄(宋·金·元)에 늙은 王이 서 있으므로 金元 쪽으로 기움.

**② 사전으로 다시 읽은 묶음**
- 강(뒤): 소품 없음. 사전 어휘로도 읽을 것이 없음.
- 흙길 오른쪽: 금관 = **王**. 사전 규칙대로 성만 王으로 확정하고, 무대가 金元이므로 **王好古**(易水 계열, 李杲의 제자, 「陰證略例」)를 1순위로 둠. 다만 陰을 나르는 기호(얼음+산 불, 또는 졸아드는 물)는 화면에 없음. 붉은 줄 = **血**(붉은 것)인데, 王好古의 어떤 사실과 이어지는지 찾지 못함. 2순위 **王履**(「醫經溯洄集」). 그물·새끼줄에 감긴 물고기는 사전에 없는 기호라서 羅(그물) → **羅天益**으로 읽을 수도 있지만 근거가 약함.
- 흙길 왼쪽: 사전의 李 기호(허리춤 자두)가 없으므로 1단계의 「木+子 = 李」 읽기는 철회함. 다음 두 조각만 사전에 맞음.
  - 미끄럼틀을 타고 내려옴 = **下**. 다만 張 기호(긴 활)가 없어 張從正으로 묶을 수 없음.
  - 한 줄에 걸린 빨래 셋 가운데 노란 것 = **中**(같은 것 셋 중 가운데). 노란색을 土로 보면 補中 → **李杲** 補土派라는 추정은 남음. 그런데 같은 빨랫줄이 **衆**(한 밧줄에 여럿이 매달림)과도 맞아서 읽기가 둘로 갈림.
  - 흙무덤과 대야는 미등재 기호.
  - 이 묶음에는 후광 인물이 없음. 흙무덤도 왼쪽 가장자리에서 잘려 있어 왼쪽 이웃 띠 인물의 소품일 가능성이 큼.
- 거리(앞): 기와지붕 건물 한 채 = **寺** → **典醫寺**(고려, 太醫監의 후신·의료행정)가 1순위. 惠 기호(빈 사발을 받아 드는 손들)가 없으므로 1단계의 惠民局은 내림. 흰옷 인물이 복건 인물의 절반 크기라 **大**(같은 것 둘 중 하나가 두 배)로 볼 여지가 있고, 그렇게 보면 大+寺 → **東西大悲院**이 2순위. 복건은 腎(잠수부 후드)과 비슷해 보이지만 고글·잠수복이 없으므로 腎이 아님.

**③ 잔결**
- 사전 어휘로도 풀리지 않는 것: 묶인 물고기, 흙무덤, 탁자의 대야·벽돌 같은 덩어리, 약항아리, 복건.
- 붉은 줄은 血일 수도, 말판 길(발자국과 나란히 이어짐)일 수도 있음.
- 빨랫줄은 中과 衆 둘 다로 읽혀 기호가 겹침.
- 아래 오른쪽 문짝의 흰 번짐, 왕관 노인·복건 인물의 오려 붙인 후광 테두리.
- 판정: 사전 어휘로 더 확실해진 것은 王과 寺 둘뿐이고, 왼쪽 묶음은 오히려 흐려졌음.
