# z25 판독 (말판 ⑤줄 근대 구간 · 세로 띠)

## 1단계 — 생판 (사전 열기 전 확정)

**① 시대**: 한국 근대 — 조선 말~대한제국(1880년대 중심). 확신도 **85%**. 근거: 전신주·전선, 붉은 벽돌 2층 양옥, 기와집 사이에 양복 입은 서양인. 뒤 강은 비어 있고(本草 없음) 건너편엔 언덕뿐.

**② 레인별 묶음**
- 가운데 길 왼쪽: 갓 쓰고 갈색 도포 입은 중년 + 요람 속 아기가 약초 그림(위 칸에 약초, 아래로 글줄)이 그려진 두루마리를 내밂 → **황도연(黃度淵)**. 「아기 = 아들」이 책을 바침 → 아들 **황필수**가 편찬한 **『방약합편(方藥合編)』**(1884). 두루마리 윗단의 약초 = 상단 **藥性歌**를 두는 3단 체제.
- 가운데 길 오른쪽: 회색 두루마기에 검은 모자를 쓴 청년. 가슴에 초록 새싹을 꽂았고 발치에 노란 솔이 있음. 뒤로 약장(百子欌) 문이 있는 약방이 있고, 지붕 위에는 흰 양산 간판(오른쪽에서 잘림) → 노란(黃) 솔 = 筆? → **황필수**로 추정. 약장 = 약방·**方藥**. 확신도 낮음.
- 앞 거리 왼쪽: 문을 활짝 연 큰 기와집 문간에 콧수염 난 양복 차림 서양인 → **알렌(Allen)**. 왼쪽 간판은 양산 아래 사발 4개를 든 손(널리 덮어 은혜를 줌 = **廣惠**)이고, 가운데 간판은 물속 사람들을 밧줄로 건져 냄(**濟衆**) → **광혜원(廣惠院)→제중원(濟衆院)**, 1885년, 최초의 서양식 국립 근대병원이며 곧 개칭됨.
- 앞 거리 오른쪽: 회색 두루마기 청년이 걸어감. 담장 안 건물에는 두 사람이 줄을 당기는 간판(오른쪽 잘림) → 제중원 학생일까? 또는 한의·양의가 서로 줄다리기하는 **광제원**일 수도 있음(이웃 띠 몫일 가능성).

**③ 잔결**: 노란 솔이 무엇인지(黃筆의 소리를 땄다고 보기엔 억지스러움), 가슴의 새싹, 약방 위 양산 간판(앞 거리 광혜원 양산과 겹침). 줄다리기 간판, 오른쪽 아래 분홍 약주머니, 왼쪽 벽돌 양옥은 가장자리에서 잘린 이웃 띠 몫. 가운데 길에 사람이 둘(황씨 부자?) 서 있어 한 명이 중복된 것처럼 보임.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 한국 근대(조선 말~대한제국) — 확신도 **90%**. 앞 거리 간판이 사전 글자로 정확히 풀려 연대(1885)를 박아 준다.

**② 레인별 묶음**
- 앞 거리 왼쪽(사전으로 확정): 넓게 펼친 차양 = **廣**, 여러 손이 받아 드는 빈 사발 = **惠**, 물에 드리운 밧줄에 매달려 건져지는 사람 = **濟**, 한 밧줄에 여럿이 매달림 = **衆**. 양복 입은 서양인은 알렌 → **광혜원(廣惠院) → 제중원(濟衆院)**, 1885년, 최초의 서양식 국립병원이며 개원 직후 개칭됨. 간판 두 개가 한 집에 걸린 것이 「이름이 바뀌었다」는 뜻을 나른다.
- 앞 거리 오른쪽(잘림): 두 사람이 한 밧줄을 나란히 함께 당김 = **同**. 오른쪽 이웃 띠에 이어질 글자(濟?)와 합치면 **동제의학교(同濟醫學校)**(한의학 교육기관)일 가능성이 있음. 걸어가는 회색 두루마기 청년은 그 학생일 수 있음. 표제는 이웃 띠 몫.
- 가운데 길 왼쪽: 사전에 아기·요람·두루마리 글자가 없어 1단계 해석을 그대로 둠 → **황도연**과 아들(아기)이 바친 약초 두루마리 = **『방약합편』**(아들 황필수 편찬). 단, 「테 넓은 큰 갓 하나 = **太**」가 걸릴 수 있음. 그러나 이 무대의 양반은 모두 갓을 쓰므로 의상으로 보고 太는 읽지 않음(太醫院은 기관이라 앞 거리 몫). 확신도 중간.
- 가운데 길 오른쪽(잘림): 약방 지붕의 차양 간판 = **廣**(오른쪽에서 잘림) → 이웃 띠의 **廣濟院**(1900) 쪽 묶음으로 보임. 회색 청년도 오른쪽 가장자리에서 잘렸으므로 이웃 몫.

**③ 잔결**: 노란 손솔은 사전에 없음(瀉 = 「짚 빗자루」와 비슷하나 모양이 다름). 청년 가슴의 초록 새싹도 사전에 없음. 분홍 비단 주머니는 典藥(약봉지 다발)·收(삼베 자루) 어느 쪽과도 맞지 않음. 요람 아기는 사전 밖 기호(「아들」인지 「小兒」인지 갈림). 갓이 太인지 의상인지 모호함. 廣이 앞 거리(광혜원)와 가운데 길(약방)에 두 번 나와 혼동될 수 있음.
