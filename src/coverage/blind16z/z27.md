# z27 판독 기록

## 1단계 — 생판 (사전 열기 전)

**① 시대**: 중국 **魏晉南北朝(南朝 齊·梁 무렵)** / 한국 **삼국시대(신라 쪽 기울기)** — 확신도 65%.
근거: 길 위 「뿔 달린 도깨비(鬼)가 등을 보이고 떠나며 남긴(遺) 처방지·메스·금메달」이 劉涓子鬼遺方을 거의 그대로 부르고, 강가 「도공(陶)」이 陶弘景을 부른다. 두 표제어가 모두 南朝 齊·梁에 몰려 있다.

**② 묶음별 판독**
- 강(본초) — 물레 앞 여인(도공), 붉은 줄무늬 항아리 3개, 붉은 붓·검은 붓이 꽂힌 붓통 → **陶弘景 『本草經集注』**. 陶 = 도공·항아리. 붉은 붓 + 검은 붓 = 朱墨分書(神農本草經은 朱書, 名醫別錄은 墨書). 항아리가 겹쳐 쌓인 것 = 本經 365 + 別錄 365 를 합친 730종 「集注」로 읽힌다(약함).
- 강가 — 물로 뻗은 나무 선착장. 뜻 미상(정박=「集」?).
- 흙길 왼쪽 — 초록 도깨비가 등을 보이며 떠남, 뒤에 빈 종이(方)·글자 쪽지·메스·금메달 → **劉涓子鬼遺方**. 鬼가 남기고 감 = 「鬼遺」, 메스 = 외과(옹저·금창), 금메달 = 「현존 最古의 외과 전문서」.
- 흙길 가운데 — 검은 챙모자·보라 도포의 선비가 펼친 책 앞에 서 있고, 둘레에 걸상 8개가량(앞줄은 가지런, 뒤쪽은 뒤집히고 쓰러짐) → 강학·주해 자리로 보고 **全元起 『素問訓解』**(素問 최초의 주석)을 1순위, **姚僧垣 『集驗方』**(걸상을 모음=集)을 2순위로 둔다. 확신 낮음.
- 앞 거리(한국) — 금빛 기와지붕의 회색 벽 창고, 흰 옷·머리띠 소년(학생)이 걸어감, 오른쪽 가장자리의 칸 나뉜 판(쟁반) → **신라 醫學(효소왕 692, 의학 교육기관·의박사)** 1순위. 금빛 지붕 = 金 → 신라(또는 金武 도일). 칸 판 = 교재 칸/약재 말리는 판? 대안: **백제 의박사·채약사**.

**③ 뜻 모를 것·이어붙임**
선착장의 역할 불명. 도깨비 자리 작은 쪽지의 검은 글자(판독 불가). 걸상이 뒤집힌·쓰러진 이유 불명. 선비 뒤 가게 세 채(상자·선반)는 배경인지 소품인지 불분명. 칸 나뉜 판은 오른쪽 가장자리에서 잘려 이웃 띠 몫일 수 있음. 오른쪽 가장자리 중간에 잘린 인물(이웃 띠).

## 2단계 — 계통 (blind6_사전요약 적용)

**① 시대**: 중국 **魏晉南北朝(南朝 宋~梁)** / 한국 **삼국시대(신라)** — 70%. 사전에 鬼·陶 기호는 없어 근거는 1단계와 같고, 길 가운데 인물이 「太」로 풀리면서 南朝 宋 쪽으로 더 단단해졌다.

**② 묶음별 재판독**
- 강 — 도공 여인 + 붉은 붓·검은 붓 → **陶弘景 『本草經集注』** 유지(朱墨分書, 本經+別錄 730종). 사전 대조: 붉은 항아리는 「血 = 붉은 것」이지만 몸·병증 무대가 아니어서 해당 없음으로 본다. 붓통에 꽂힌 붓은 「會 = 담는 것 안에 담긴 것」 꼴이나, 陶弘景에 붙일 會 사실이 없어 그냥 붓통으로 읽는다. 항아리는 같은 물건 셋이 포개진 꼴이 아니어서 「久」는 아니다. 선착장: 「濟」(물에 드리운 밧줄)·「津」(맑은 물방울) 어느 쪽 조건도 맞지 않아 여전히 뜻 미상이다.
- 흙길 왼쪽 — 도깨비가 남기고 간 처방지·메스·금메달 → **劉涓子鬼遺方** 유지(「鬼遺」, 외과, 현존 最古 외과 전문서). 사전에 鬼·刀 기호가 없어 바뀌는 것이 없다.
- 흙길 가운데 — 선비의 검은 챙모자가 「**太 = 머리에 씌운 테 넓은 큰 갓**」에 맞는다. 太(醫) + 펼친 교재 + 학생 걸상 = 관립 의학교육 → **秦承祖(劉宋 太醫令) — 元嘉 20년(443) 「醫學」 설치 상주, 중국 최초의 관립 의학교육**. 뒤집히고 쓰러진 걸상 = 10년 뒤(453) 폐지된 것으로 풀린다. 2순위 **隋 太醫署**, 全元起 『素問訓解』는 3순위로 내린다. 가게 안은 상자뿐이고 곡식 가마니가 없어 「倉/藏」은 아니다.
- 앞 거리 — 학생 소년 → **신라 醫學(효소왕 원년 692, 의박사 2인이 교육)** 유지. 길 가운데의 「의학교육」과 짝을 이룬다. 금빛 지붕 건물은 「寺 = 기와지붕을 얹은 절 한 채」로도 읽히지만, 삼국에는 寺라는 이름의 의료 기관이 없다. 절로 읽는다면 대안은 **신라법사방**(승려 의방)이다. 확신은 낮다.

**③ 남은 것**
선착장(사전에도 대응 없음). 도깨비 자리 쪽지의 글자. 금빛 지붕 건물이 寺인지 배경인지. 오른쪽 가장자리의 칸 나뉜 판과 잘린 인물은 이웃 띠 몫으로 본다.
