# z31 판독 기록

## 1단계 — 생판 (사전 없이)

**① 시대**: 흙길의 두 인물이 변발(앞머리 민 辮髮)에 긴 袍 → **淸**, 아래 거리는 갓·도포·상투·기와 한옥 → **朝鮮 후기**. 1순위 淸 / 朝鮮, 확신 95%.

**② 레인별 묶음**
- 강(본초): 책 꾸러미를 등에 지고 자갈 강변에 서서 강을 바라보는 변발 소년. 「등에 요긴한 것을 갖춰 짐」= 備要 → **本草備要**(汪昂) 1순위. 자갈밭(줍기=拾) → **本草綱目拾遺**(趙學敏) 2순위. 확신 40%.
- 흙길 왼쪽: 갈색 袍의 변발 남자 + 땅에 꽂힌 바늘 하나가 엽전 꾸러미(꿰미)를 끊어 엽전이 흩어짐. 엽전(葉錢)의 「葉」→ **葉天士**, 곧추선 바늘 = 指南針 → 『臨證指南醫案』, 끊겨 여러 무더기로 나뉜 엽전 = 단계 나누기(衛氣營血 辨證)? 대안: 꿰미=「貫」을 바늘(砭)이 끊음 → 『醫貫砭』 → **徐大椿**. 확신 45%.
- 흙길 오른쪽: 회색 袍의 변발 소년 + 물웅덩이(가지 쳐 흘러나감) 위 금빛 거북, 등에 뿔(犀角 모양 회색 원뿔) 꼭대기에 촛불. 물(濕)+불(熱) → **薛生白**『濕熱條辨』 1순위. 대안: 犀(서)角+靈龜+흘러나가는 물(源流) → **徐大椿**(徐靈胎)『醫學源流論』. 확신 35%.
- 아래 거리(朝鮮): 갓 쓰고 팔짱 낀 통통한 선비가 한옥 앞에, 상투 튼 흰옷 청년 둘(오른쪽 하나는 가장자리에서 잘림). 덧붙은 소품이 없어 「말을 하는」 묶음으로 보기 어려움 — 굳이 읽으면 체형이 다른 사람들 → **李濟馬 四象人**? 확신 15%.

**③ 잔결**: 거북 등의 뿔+촛불은 무엇을 가리키는지 확정 불가(犀角·燭·命門火 중 무엇?). 엽전이 몇 무더기인지(4?) 애매. 강·흙길·거리 세 층 사이에 흰 가로 띠(이어 붙인 경계)가 뚜렷. 아래 거리는 소품이 없어 사실 운반이 비어 보임. 오른쪽 아래 청년·건물은 이웃 띠 몫.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 시대**: 사전에 시대 기호는 없으므로 판정 불변 — 변발·袍 = **淸**, 갓·상투·한옥 = **朝鮮 후기**. 95%.

**② 레인별 재판독**
- 강(본초): 등의 책 꾸러미는 6~7권이 묶인 것이라 「셋이 포개진 것」(久)에 해당하지 않고, 사전에 책·짐 기호가 없다. 1단계 유지 — **本草備要**(汪昂) 1순위, 자갈밭=拾 → **本草綱目拾遺** 2순위. 35%.
- 흙길 왼쪽: 사전으로 건질 수 있는 것은 바늘이 끊긴 두 꿰미 「둘 사이의 한복판」에 섰다는 것(中, 갈림 조건 충족)과 흩어진 엽전(散은 「날리는 것」이라 반쯤만 맞음), 꿰미가 끊겨 못 쓰게 됨(傷 — 단 꿰미가 어느 글자인지 미등재)뿐이다. 성씨 기호(王 왕관·張 활·李 자두·馬·吳 큰 입)는 없다. 그래서 인물은 미등재 기호(엽전=葉錢)로만 풀린다 → **葉天士**(바늘=指南 → 『臨證指南醫案』) 1순위 유지, 대안 **徐大椿**『醫貫砭』(貫을 끊는 침). 40%.
- 흙길 오른쪽: 촛불 = **熱**(불꽃) 확정. 거북 밑 맑은 물은 사전의 濕(부슬비·안개·진창)에 맞지 않고, 「살아 있는 불과 맞대어 놓인 고인 물」이므로 갈림 조건을 채운 **陰**으로 읽힌다 → 熱+陰 = 溫熱이 陰(津液)을 상함/存陰. 거북 등딱지(龜甲·鱉甲 → 三甲復脈湯·大定風珠)와 뿔(犀角 → 淸營湯)을 함께 보면 **吳鞠通**『溫病條辨』(三焦辨證·養陰) 1순위로 갈아탄다. 다만 吳 기호(얼굴 반만 한 큰 입)가 소년 얼굴에 없어 표제어 확정은 못 함. 2순위 **薛生白**(濕熱 — 사전상 濕 기호 불일치로 강등), 3순위 불=陽으로 읽어 水火(命門) 계열. 35%.
- 아래 거리: 갓 쓴 선비 하나만 테 넓은 큰 갓 = **太**에 맞는다. 두 건물이 「하나가 두 배」(大)로도 보이나 오른쪽 건물이 띠 가장자리에서 잘려 판정 불가. 惠·濟·衆·廣·藥·典藥·保命·倉 등 조선 기관 기호는 하나도 없다 → 표제어 보류, 굳이 太+집 → **太醫**류 기관 / 太陰人(**李濟馬**) 10%.

**③ 잔결**: 바늘(쇠못=痛과 다름)·엽전 꿰미·금빛 거북·뿔·책 꾸러미는 모두 사전 미등재 기호. 오른쪽 인물에 성씨 기호 부재. 아래 거리는 사실 운반 소품 없음. 세 층 사이 흰 가로 띠(이어 붙인 경계)는 그대로. 사전으로 확실히 풀린 것은 熱·陰(·中) 정도라 1단계보다 크게 나아지지 않았다.
