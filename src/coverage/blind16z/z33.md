# z33 판독 (말판 ③줄 세로 띠)

## 1단계 — 생판 (사전 없이)

**① 시대**: 중국 **北宋** / 한국 **高麗 전기** — 확신도 85%.
근거: 강의 「보물상자(寶)를 연(開) 배」 = 開寶本草(973), 흙길의 동인(銅人) 주형 = 1027년 銅人 주조, 거리의 「잠긴 보물상자+곡식 섬」 = 光宗代 濟危寶(963). 셋이 모두 10~11세기로 맞물린다.

**② 묶음별 판독**
- 강(본초) 왼쪽 — 뚜껑 열린 보물상자를 실은 배: **開寶本草**(開=열다, 寶=보물). 宋 최초의 관찬 본초.
- 강(본초) 오른쪽 — 맨머리 평복 사내가 가위로 책을 오려 조각을 늘어놓음: **證類本草**(唐慎微 『經史證類備急本草』) 1순위 — 경사(經史)·제서에서 발췌를 「오려 모은」 집성, 평복 = 布衣(민간) 의사. 2순위 **本草衍義**(寇宗奭), 3순위 嘉祐補註本草.
- 흙길 왼쪽 — 왕관(王)에 동그라미 하나(一)를 단 앞치마 차림 장인, 발치에 점 찍힌 인형 2구 + 사람 모양 두 짝 주형: **王惟一** — 『銅人腧穴鍼灸圖經』, 針灸銅人 **2구 주조**(경혈 점), 앞치마 = 주조 장인.
- 흙길 오른쪽 — 쭈그린 노인이 요람 아기를 돌보고, 요람 끝에 돈주머니를 문 새: **錢乙**(錢=돈주머니, 乙=새) — 『小兒藥證直訣』, 소아과의 성인(兒科之聖)·소아과 독립.
- 거리(한국) 왼쪽 — 자물쇠 채운 보물상자 + 곡식 섬 + 창고: **濟危寶**(寶=기금, 곡식 이자로 빈민 구료, 光宗 14년 963).
- 거리(한국) 오른쪽 — 머리띠 학생 둘이 「갓 + 약단지」 간판 집으로 걸어감: **太醫監**(의학 교육·醫業) 1순위, 2순위 **尙藥局**(갓 모양 = 尙자 / 官) 또는 惠民局(官營 약 판매).

**③ 잔결**
- 錢乙이 손끝으로 무언가를 집어 떨어뜨리는 손짓 — 환약(六味地黃丸 창방?)인지 불명.
- 王惟一 주형이 검은 돌처럼 그려져 「石刻 圖經」과도 겹쳐 읽힘.
- 거리 오른쪽 간판 건물이 오른쪽 끝에서 잘림 — 학생 묶음이 이웃 띠 소속일 가능성. 흙길 맨 오른쪽 잘린 사람은 이웃 띠 몫으로 무시.
- 흙길 뒤편 3채 가게 간판이 모두 빈칸 — 배경.

## 2단계 — 계통 (blind6 사전 적용)

**① 시대**: 그대로 **北宋** / **高麗 전기** — 85%. 사전의 「王 = 성까지만, 어느 王인지는 무대가 진다」가 오히려 무대(宋)를 먼저 확정하게 만든다.

**② 묶음별 재판독**
- 강 왼쪽 — 열린 보물상자 실은 배: **開寶本草** 유지. 사전의 藥(배 모양 약연)과 배가 겹쳐 보이나, 강의 배는 레인 문법(본초 계보) 자체로 읽는 편이 자연스럽다. 寶·開는 사전 미등재 → 그림 자체로 해독.
- 강 오른쪽 — 가위로 책 오리는 평복 사내: 사전에 해당 기호 없음. **證類本草**(唐慎微, 경사에서 발췌 집성) 1순위 유지, 확신 낮음(50%). 대안 **本草衍義**.
- 흙길 왼쪽 — 왕관 = **王**(사전 확정: 성 王). 무대 北宋 + 경혈 점 찍힌 인형 2구 + 두 짝 주형 → **王惟一**, 『銅人腧穴鍼灸圖經』·針灸銅人 2구 주조. 사전으로 성이 고정되어 1단계보다 확실(90%).
- 흙길 오른쪽 — 돈주머니 문 새 + 요람 아기: **錢乙** 유지(錢·乙은 사전 미등재). 『小兒藥證直訣』, 兒科之聖. 단, 끈으로 아가리를 조인 주머니가 사전의 收(조인 삼베 자루)와 모양이 겹친다 — 여기선 크기가 작고 새가 물고 있어 「돈주머니=錢」으로 판정.
- 거리 왼쪽 — 자물쇠 보물상자 + 곡식 섬 + 창고: 사전의 倉은 「곳간 **안**」, 藏은 「문 열린 곳간 안」인데 여기는 문 닫힌 창고 **밖**에 섬이 놓여 둘 다 조건 미달. 濟(물에 드리운 밧줄)도 없음 → 寶(상자)+곡식 기금으로 **濟危寶** 유지(65%). 倉으로 읽으면 義倉·常平倉 후보.
- 거리 오른쪽 — 간판의 「테 넓은 큰 갓」 = 사전 **太**, 갓 씌운 단지 = 醫자 아래 酉(술단지) → 太醫. 머리띠 학생 둘 = 의학 교육 → **太醫監**(고려 의학 교육·醫業 관장). 1단계 2순위였던 尙藥局은 탈락. 사전으로 더 잘 풀림(80%).

**③ 잔결**
- 가위·오린 책 조각(강 오른쪽)은 사전에 없어 표제어를 끝내 못 박음.
- 錢乙의 집는 손짓(환약?) 미해독. 새 주머니의 收 형태 누수.
- 창고 앞 곡식 섬이 倉/藏 조건과 어긋남(문 닫힘·밖) — 濟危寶의 濟 기호 부재.
- 太醫監 건물이 오른쪽 끝에서 잘림 — 이웃 띠와 이어 붙인 경계.
