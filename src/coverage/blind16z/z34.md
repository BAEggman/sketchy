# z34 판독 기록

## 1단계 — 생판 (사전 없이)

**① 시대**: 唐(~五代) / 統一新羅 — 85%. 흙길의 「王+冰」「臺」가 盛唐 8세기 중엽, 거리의 출자형 금관 왕이 신라.

**② 묶음별 판독**
- 강(본초) ⓐ 왼쪽 가장자리의 새 판잣집 + 금메달 + 옆에 걸린 바구니 + 사발 5개 → **新修本草**(새로 지은 집=新修, 메달=세계 최초 국가 약전) 1순위. 바구니=拾 → **本草拾遺**(陳藏器), 사발=食 → **食療本草**(孟詵) 가 같은 묶음에 겹쳐 있을 가능성. 집이 띠 경계에 걸려 있어 이웃 띠 몫일 수도.
- 강 ⓑ 부두 위 사람이 안은 거대한 자두(李) + 오른쪽 바다(짙은 물·조개·산호=海産) → **李珣 『海藥本草』** — 바다 건너 들어온 외래 약물(海藥) 본초. 五代.
- 흙길 ⓒ 담 위 2층 망루(臺) → **王燾 『外臺秘要』**(臺=외대). 담 「밖」의 누대.
- 흙길 ⓓ 왕관(王) 쓴 노인 + 얼음 탁자(冰) 위 두루마리 두 더미 → **王冰 次注 『黃帝內經素問』** — 素問 재편집·주석, 두루마리 더미 = 편차 정리 / 七篇大論 補入 추정. 왕관이 망루와 얼음 사이에 서 있어 王燾·王冰 두 「王」을 한 사람이 겸하는 듯.
- 거리 ⓔ 신라 금관 왕 + 약연·약봉지 간판(藥) ↕ 두 손이 감싼 등불 간판(命을 保) → **藥典 ↔ 保命司** — 경덕왕 때 개칭, 뒤에 환원(↕=양방향).
- 거리 ⓕ 흰 옷 학생 둘 → **醫學**(효소왕 692, 교육기관; 둘=醫學博士 2인?).

**③ 잔결**: 사발 5개의 「5」가 무엇인지 모름. 간판 뒤 회색 옷 두 사람(뒷모습)은 정체 미상(供奉醫師?). 두루마리 개수(6~7개 두 더미) 의미 불명. 메달 집이 이웃 띠와 이어 붙은 듯한 경계.

## 2단계 — 계통 (blind6_사전요약 어휘로 재판독)

**① 시대**: 唐(~五代) / 統一新羅 — 90%. 사전의 「王·李는 성까지만, 누구인지는 무대가 진다」를 적용하면 무대(唐 흙길·唐~五代 강)가 王燾/王冰·李珣으로 좁혀 줘 1단계와 같다.

**② 묶음별 재판독**
- 강 ⓐ 메달 판잣집 + 바구니 + 빈 사발 5개 — 사전에 해당 기호 없음. 빈 사발은 「여러 손이 받아 드는」 조건이 없어 惠가 아니고, 국물이 없어 補도, 쏟아진 것이 없어 瀉-b 도 아니다. 1단계 그대로 **新修本草**(새 집·메달=최초 국가 약전) 1순위, **本草拾遺**(바구니)·**食療本草**(사발) 은 후보로만 남김. 사전으로 더 풀리지 않음.
- 강 ⓑ 허리춤(밧줄로 묶인 허리 앞)의 자두 = **李**(사전 확정 기호) + 바다·조개·산호 → **李珣 『海藥本草』**(외래 해산 약물). 사전이 1단계를 확증.
- 흙길 ⓒ 망루가 담 「바깥」(길 쪽)에 섬 = **外**(담 바깥) + 臺 → **王燾 『外臺秘要』**. 사전의 外 덕에 「外」 글자까지 읽혀 1단계보다 확실해짐.
- 흙길 ⓓ 왕관 = **王**(성까지만) + 얼음 → **王冰 次注 『素問』**. 사전의 陰(얼음) 갈림 — 살아 있는 불과 맞댄 경우만 陰, 불 없는 겨울이면 凝滯 — 은 여기 불도 겨울도 없으므로 해당 없음 → 얼음은 이름자 冰. 두루마리 = 素問 재편차. 왕관 하나가 망루와 얼음 사이에 서서 두 王을 겸하는 구도는 그대로 애매.
- 거리 ⓔ 간판 = **藥**(배 모양 약연) + **典藥**(묶은 약봉지 다발) → **藥典**, ↕ 아래 간판 = **保命**(두 손으로 감싼 등잔불) → **藥典 ↔ 保命司** 개칭·환원(신라 경덕왕). 사전이 그대로 맞물려 확증. 금관 왕 = 신라 왕(경덕왕 추정).
- 거리 ⓕ 흰 옷 학생 둘 → **醫學**(효소왕) — 사전에 기호 없음, 1단계 유지. 「大(둘 중 하나가 두 배)」 조건은 크기가 같아 불성립.

**③ 잔결**: 사발 5개·바구니·메달 집은 사전 어휘로도 풀리지 않음. 간판 뒤 회색 옷 두 사람(뒷모습) 정체 미상. 두루마리 더미(3단 포갬)가 久(셋 포갬)로 오독될 여지. 王 하나에 臺·冰 두 묶음이 걸친 공유 구도.
