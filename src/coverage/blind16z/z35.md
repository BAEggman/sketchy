# z35 판독

## 1단계 — 생판 (사전 없이 그림만)

**① 시대**: 중국 **隋**(南北朝 말~隋唐 초 구간) / 한국 **삼국시대(신라 쪽)** — 확신 60%.
흙길 한가운데 「둥지(巢)에 앉은 병자」가 隋의 巢元方을 거의 확정해 주고, 강의 소품이 南北朝 본초(陶·雷)로 읽혀 南北朝→隋 경계 띠로 본다.

**② 레인별 묶음**
- 강(본초) ㉠ 좌: 여인 + 붉은 도기 더미 + 붓 두 자루 꽂힌 붉은 줄무늬 필통 → **本草經集注**(陶弘景). 도기 = 陶, 붉은/검은 붓 = 朱墨 구분 서사(本經은 朱書, 別錄은 墨書).
- 강 ㉡ 중: 가마솥에 약초(인삼 뿌리 포함)를 끓이는 화덕, 화덕 둘레에 북이 고리처럼 매달림 + 금메달 사내 → **雷公炮炙論**(雷斅). 북 고리 = 雷公(뇌신의 북), 불에 굽고 끓임 = 炮炙(포제), 금메달 = 최초의 포제 전문서.
- 강 ㉢ 우: 나루(부두) 위 사내 + 살아 있는 약초 화분 + 칸칸이 나눈 약재 상자(씨앗·흰 돌·콩·껍질 등) → 후보 **新修本草**(전국 약재를 거둬 그림(藥圖)과 함께 편찬한 국가 약전) 또는 약재 분류(자연속성 분류)의 보조 표지. 메달이 가려져 「최초」 여부는 못 읽음.
- 흙길(의가) ㉣ 중: 나뭇가지 둥지 속 초췌한 병자 + 무늬가 제각각인 알 여러 개 + 금메달 → **巢元方 『諸病源候論』**. 둥지 = 巢, 알 = 源(병의 근원), 알마다 다른 무늬 = 諸病의 각기 다른 候, 금메달 = 최초의 병인·병기·증후 전문서.
- 흙길 ㉤ 좌(왼쪽 가장자리, 일부 잘림): 책상에 펼친 책 + 빈 걸상 줄 = 강학 장면 → **隋 太醫署**(의학교육) 또는 **全元起 素問訓解**. 이웃 띠 몫일 가능성.
- 흙길 ㉥ 우끝: 늘어진 버드나무(楊) → **楊上善 『黃帝內經太素』** 예고. 잘림 → 이웃 띠.
- 거리(한국) ㉦: 황금빛 기와 관청, 닫힌 두 짝 문, 앞에 8칸 빈 약반(藥盤) → **신라 藥典**(약 관리 관청) 1순위, **백제 藥部** 2순위. 금빛 = 金(신라)로 읽음.

**③ 잔결**: 거리 띠 x≈413 지점에 세로 이음선(밝기 단차) — 관청 지붕·벽을 가로질러 이어 붙인 흔적. 빈 약반이 왜 비었는지(약이 없음=?) 불명. 강 왼쪽 여인이 陶弘景(남성)과 성별이 안 맞음. 화덕의 북이 雷 말고 다른 뜻(鼓)일 여지.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 시대**: 그대로 중국 **隋**(南北朝~隋 경계) / 한국 **삼국시대(신라)** — 확신 65%. 사전에 시대를 바꾸는 기호는 없고, 거리의 「寺」 판독이 신라 쪽을 조금 더 받쳐 준다.

**② 레인별 묶음**
- 강 ㉠: 사전에 陶·朱墨 기호는 없다. 「血 = 붉은 것」을 붉은 도기·붉은 붓에 대 보면 본초 계보와 맞지 않아 기각. 물레 위 도기(陶) + 붉은 붓·검은 붓(朱墨 구분) → 그대로 **本草經集注**(陶弘景). 「久 = 같은 것 셋 포갬」도 물레 받침이라 해당 없음.
- 강 ㉡: 북 고리(雷) + 불(熱)에 끓이는 약초 = 炮炙 + 금메달 → 그대로 **雷公炮炙論**, 최초의 포제 전문서. 솥 위의 김은 「氣」로 읽을 수 있으나 사실을 더하지 않음.
- 강 ㉢: 사전 어휘 중 「會 = 담는 것 안에 담긴 것」이 칸칸 약재 상자에 걸리나 본초 표제어로 이어지지 않음. 오른쪽 가장자리에서 잘려 이웃 띠 몫으로 미룸(후보 **新修本草**).
- 흙길 ㉣: 사전에 巢는 없지만 둥지·알·금메달 판독이 흔들리지 않음 → **巢元方 『諸病源候論』**, 최초의 병인·증후 전문서. 사내가 초췌한 것은 「病」 쪽 연출.
- 흙길 ㉤: 「太 = 테 넓은 큰 갓」을 대 보니 사내는 망건·상투뿐이라 太가 아니다. 강학 장면만 남음 → **隋 太醫署**(의학교육) 약후보, 이웃 띠 몫.
- 흙길 ㉥: 버드나무 → **楊上善** 예고(이웃 띠).
- 거리 ㉦: 사전의 「寺 = 기와지붕을 얹은 절 한 채」가 금빛 기와 전각과 맞는다. 「藥(약연)」·「典藥(묶은 약봉지)」 기호는 없어 1단계의 藥典·藥部 판독은 약해진다. 절(寺) → 승려(法師), 네모 칸 판 → 方, 금빛 → 金(신라) 로 읽어 **新羅法師方** 1순위, **藥典** 2순위로 바꾼다.

**③ 잔결**: 거리 x≈413 세로 이음선 그대로. 빈 8칸 판이 方인지 빈 약반인지 확정 못 함. 강 오른쪽 나루와 약재 상자는 사전으로 풀리지 않음.
