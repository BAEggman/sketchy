# z36 판독 (말판 ④줄 세로 띠)

## 1단계 — 생판 (사전 없이)

**① 시대**: 明 / 朝鮮 전기 (85%). 흙길 인물은 검은 방건·단령풍 明 문인 차림, 앞 거리는 기와집·돌담·승려 — 조선 전기 기관 풍경. 강에 「본초강목」으로 읽히는 그물이 걸려 있어 明 후기 구간으로 본다.

**② 레인별 묶음**
- 강(본초): 물 위에 굵은 **벼리 밧줄(綱)** 이 달린 **그물코(目)** 가 펼쳐지고 그 안에 잎(草)이 걸림 → **本草綱目**(李時珍). 그물이 띠 오른쪽 절반에서 시작 — 왼쪽은 빈 물.
- 흙길 왼쪽: 갈색 도포·검은 모자 사내, 어깨에 **봉황(鳳)**, 발치에 침 십수 개가 빙 둘러 꽂힘(침을 모두 갖춤=大全) → **徐鳳 『鍼灸大全』** (차순위 **楊繼洲 『鍼灸大成』**, 高武 『鍼灸聚英』).
- 흙길 오른쪽: 회색 도포 젊은이가 허리춤에 **자두(李)**, 곁에 **빈 문틀(門)** 과 문턱 앞에 가로누운 **긴 통나무(梴=긴 나무)** → **李梴 『醫學入門』**(문턱 넘어 들어감=入門).
- 거리 왼쪽: 우물(두레박), 약초 자루를 얹은 A자 짐틀 두 개, 간판에 탑·법당·승려 그림, 그 앞 동자승이 막대 꽂힌 통(침통/화살통?)을 안음 → 불교 구휼기관 기원의 **活人署**(東西大悲院 계승) 또는 약재를 나르는 **濟生院**/**惠民署** 후보. 확신 낮음.
- 거리 오른쪽: 붉은 기둥 관아(담장 안) 현판에 끝에서 연기 선이 나는 갈색 원통(뜸쑥대=灸?), 앞 돌판에 배 모양 **약연(藥碾)**, 맨 오른쪽 거대한 책 표지에 **초가집(鄕)+약초 덤불** → **鄕藥集成方**(1433, 鄕藥本草·炮炙法 수록 — 약연이 포자법, 뜸대가 침구법 조문?) 차순위 **鄕藥濟生集成方**.

**③ 잔결**: 갈색 원통 현판(뜸대인지 폭죽·통인지 불명), 동자승의 막대 통(침통·화살통·붓통 불명), 우물·A자 짐틀의 뜻 미상. 봉황이 사내 얼굴 위에 덧붙여져 겹침, 탑 그림 간판은 사진처럼 따로 붙인 판. 강 그물이 띠 중간에서 갑자기 시작하고 오른쪽 위 모서리에 검은 물체(배?) 잘림. 흙길·거리 오른쪽 끝 건물·책은 이웃 띠 몫.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 시대**: 明 / 朝鮮 전기 (90%). 사전의 확정 기호 李·門·藥이 그대로 맞물려 1단계 판독이 강화됨.

**② 레인별 묶음**
- 강: 사전에 그물·벼리 항목은 없음(目=크게 뜬 눈이라 그물코와 무관). 벼리(綱)+그물코(目)+잎(草)의 글자 그대로 읽기 유지 → **本草綱目**(李時珍).
- 흙길 왼쪽: 사전에 봉황 항목 없음. 침 무더기는 땅에 꽂혀 「살에 박힌 쇠못 하나(痛)」가 아님 → 鍼으로 읽음. 봉황=鳳 → **徐鳳 『鍼灸大全』**(1439). 왼→오른 순서상 오른쪽 李梴(1575)보다 앞이어야 하므로 楊繼洲(1601)보다 徐鳳이 맞음.
- 흙길 오른쪽: **허리춤 자두 = 李**(사전 확정, 무대 明이 李를 가름) + **작은 문틀 = 門**(사전 확정) + 문턱 앞 긴 통나무(梴/入) → **李梴 『醫學入門』**. 확신 상승.
- 거리 왼쪽: 우물 두레박 밧줄 = **물에 드리운 밧줄 = 濟**(사전), 간판의 절 = **寺**, 끈으로 매단 약초 자루 = **典藥**(끈 묶은 약봉지 다발) 근접. 濟+약초 수집·운반 → **濟生院**(1397, 鄕藥 수집·배포, 醫女 교육 시작) 1순위. 寺+승려는 불교 구휼기관 기원 → **活人署**(東西大悲院 계승) 차순위. 典藥은 묶음 모양이 자루라 확신 낮음.
- 거리 오른쪽: 돌판의 **배 모양 약연 = 藥**(사전 확정) + 초가집(鄕, 사전 미등재)+약초 덤불 + 거대한 책(集成) → **鄕藥集成方**(1433). 왼쪽 우물의 濟까지 한 제목으로 묶으면 **鄕藥濟生集成方**(1398) 가능. 붉은 기둥 관아 현판의 갈색 원통은 사전의 **杼(옆구멍 실 빠진 나무 베틀북)** 과 모양이 비슷하나 실이 끝에서 세 갈래로 나와 맞지 않음 — 뜸대(灸)면 鄕藥集成方의 침구법 조문.

**③ 잔결**: 현판 갈색 원통(杼인지 뜸대인지 미결), 동자승이 안은 막대 꽂힌 통(사전 미등재 — 침통·화살통·붓통), 간판 속 승려와 앞의 동자승이 같은 소품을 들어 그림에서 걸어 나온 듯 이중 배치. 봉황은 사내 얼굴 위에 덧붙여 겹침. 강 그물이 띠 중간에서 갑자기 시작되고 오른쪽 위에 잘린 검은 물체. 사전으로 새로 풀린 것은 濟·藥·李·門이고, 봉황·초가·원통·통은 여전히 사전 밖.
