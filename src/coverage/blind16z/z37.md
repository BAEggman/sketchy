# z37 판독 (③줄 宋·金·元 — 세로 띠)

## 1단계 — 생판 (사전 열기 전 확정)

**① 시대**: 중국 **元** / 한국 **高麗(후기, 元 간섭기)** — 70%.
근거: 가운데 길 뒤편에 몽골 게르(ger)가 줄지어 섬 → 몽골 = 元. 앞 거리는 기와집·돌길·상투 튼 흰옷 사내 → 한국(고려 말~조선 초 풍).

**② 레인별 묶음**
- 뒤(강): 빈 강 + 모래톱, 하늘에 초승달만. 본초서 소품 없음 → 이 띠에는 본초서 표제 없음(초승달은 장식으로 봄).
- 가운데 길 A (왼쪽): 맨발 누더기 **아이** + 목에 건 금빛 원판(뒷면 문양 있는 둥근 동경/금메달) + 금테 돋보기(거울)에 비친 초록 **혀** + 그 거울을 받친 **두꺼비**.
  → 표제 **《敖氏傷寒金鏡錄》** (금 테 거울 = 「金鏡」, 비친 혀 = 舌診). 두꺼비 = 「두」 → **杜淸碧(杜本)** 이 舌圖를 보충(12→36舌). 사실: **최초의 舌診 전문서**(元). 아이는 원저자 「敖氏」(미상)의 자리이거나 「兒」 계열 기호로 추정 — 미해결.
- 가운데 길 B (오른쪽): 붉은 단령(**朱**)·사모·흉배 관인 + 손에 짧은 초 한 자루, 불빛은 커다란 공처럼 넘침 + 발밑을 가로지르는 가는 붉은 실개천(**丹溪**).
  → 표제 **朱丹溪(朱震亨)**. 사실: 짧은 초(陰 적음)에 넘치는 빛(陽 많음) = **陽常有餘 陰常不足**, 촛불 = **相火論** → **滋陰派(養陰派)**, 金元四大家 막내, 《格致餘論》.
- 앞 거리: 기와집 앞 **텅 빈 4단 나무 선반** + 흰옷 상투 서민 둘.
  → 후보 ⓐ 고려 **惠民局**(서민 진료, 서민 행인) ⓑ 빈 서가 = 전하지 않는(佚失) 고려 의서(**御醫撮要方**·**三和子鄕藥方** 등) ⓒ 빈 약장 = 鄕藥 자립. 확신 낮음(30%).

**③ 뜻 모를 것·흔적**
- 아이의 정체(금 원판만으로는 錢乙 「錢」도 가능하나 시대가 안 맞음).
- 초승달(본초 강 위, 의미 불명).
- 元 의가에게 명·조선식 사모+흉배 관복 — 시대 어긋남.
- 앞 거리 오른쪽 돌길 위 네 갈래 반짝이(생성 워터마크로 보임).
- 좌우 끝 잘린 게르·기와 정자·행인은 이웃 띠 몫.

## 2단계 — 계통 (blind6_사전요약 어휘로 재판독)

**① 시대**: 중국 **元** / 한국 **高麗(후기)** — 75%. 사전에 시대 기호는 없어 게르 판단 유지.

**② 레인별 묶음**
- 뒤(강): 사전 기호 없음 → 표제 없음. 초승달은 사전의 陰(얼음·졸아드는 물)과 무관.
- 가운데 A: 거울 속 혀에 **초록 얼룩** = 사전 **苔**(혀 위 이끼) → 「舌+苔」 = 설태 진단. 舌 갈림(혀=心/구멍=脾)은 장부 개규용이고 임금(心)이 없어 해당 없음. → 표제 **《敖氏傷寒金鏡錄》** 유지(금테 거울 = 金鏡). 두꺼비 = **杜淸碧** 증보(사전 밖 말장난). 사실 = **최초 舌診(舌苔) 전문서**. 아이·금 원판은 사전 미등재 — 華(광택)로 읽어도 뜻이 안 섬 → 「최초」 표지 또는 **敖氏** 자리로 남김.
- 가운데 B: 촛불 = **陽**(불), 공처럼 넘치는 빛 = **盛**(넘쳐 흘러나옴), 타다 남아 짧은 초 = **衰** → 「불은 넘치고 밑천은 졸아든다」 = **陽常有餘 陰常不足** → **滋陰派**. 사전으로 1단계 해석이 오히려 단단해짐. 한 손으로 든 초라 **保命**(두 손으로 감싼 등잔 = 劉完素)은 아님. 붉은 옷은 곤룡포가 아니라 관복이라 心 아님. 붉은 실개천은 사전상 血(붉은 것)이 걸리지만 몸 밖 땅 위의 개천이라 **丹溪**(붉은 시내) 말장난이 맞음 → 표제 **朱丹溪(朱震亨)** 75%. ⚠ 머리의 **테 넓은 검은 갓** = 사전 **太**와 충돌 — 太로 읽으면 「太醫」 계열(예: 丹溪의 제자로 明 太醫院使가 된 **戴思恭**, 촛불 = 明)로 갈 여지가 있으나 근거 약함(15%).
- 앞 거리: 기와집 한 채 = 사전 **寺**에 약하게 걸림(절이 아니라 가게·관아풍) → **典醫寺**(고려, 1308 개칭)? 빈 4단 선반은 官 갈림(3층장 가운데 층)에 안 맞음. 典藥(약봉지)·惠(빈 사발)·倉/藏(가마니) 없음 → 표제 확정 불가(25%).

**③ 잔결**: 아이·금 원판·두꺼비·초승달은 사전 밖. 갓=太 충돌. 빈 선반의 몫 불명. 오른쪽 아래 돌길의 네 갈래 반짝이(생성 워터마크).
