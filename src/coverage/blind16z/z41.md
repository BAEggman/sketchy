# z41 판독 (blind16z)

## 1단계 — 생판 (사전 없이)

**① 시대**: 중국 **晉(西晉~東晉)** / 한국 **三國(고구려·백제·신라)** — 확신도 85%.
근거: 흙길 중앙 인물이 魏晉의 太醫令, 오른쪽 가장자리 인물이 東晉 사람으로 읽힘. 한국 거리는 초가뿐(빈 거리).

**② 레인별 묶음**
- **강(본초서 계보)**: 사람·소품 없음. 건너편 기슭에 대숲(竹)만 있음 → 말하는 묶음 없음(배경). 이 구간은 본초 계보가 비어 있거나 이웃 띠에 걸린 것으로 판정.
- **흙길 중앙**: 금관(王)을 쓴 회색 도포 사내 + 남색 구름무늬 맥침(脈枕) 위에 뻗은 커다란 팔뚝, 손목에 점 세 개 + 탁자 밑 끈으로 묶은 죽간 다발.
  → **王叔和**: 王 = 왕관 / 맥침·팔 = **脈經**(현존 最古의 맥학 전문서) / 손목 점 셋 = 寸口의 **寸·關·尺 三部** 정위(獨取寸口 정립) / 끈으로 묶어 다시 엮은 죽간 = 張仲景 『傷寒雜病論』을 **編次**(재편집)한 사실.
- **흙길 오른쪽 가장자리(잘림, 반쯤 보임)**: 칡덩굴(葛)에 칭칭 감긴 통나무(朴)를 껴안은(抱) 상투 튼 사람 → **葛洪**(號 抱朴子). 이웃 띠 몫으로 보이며 『肘後備急方』 등 곁 사실은 이 조각에서 확인 불가.
- **거리(한국)**: 문이 열린 큰 초가 한 채 + 오른쪽에 잘린 초가 한 채. 사람·소품 없음 → **빈 거리**(三國시대 줄).

**③ 잔결·어색한 것**
- 왼쪽 가장자리의 흰 깃발 무더기(땅에 꽂힌 작은 깃발 7~8개) — 이웃 띠 몫, 뜻 미상(穴자리 표시?).
- 강 왼쪽 끝의 동심원 물결 — 무언가 떨어진 자국 같으나 주인 없음.
- 팔뚝이 몸에 비해 지나치게 크고 탁자 위에 따로 놓인 듯 보임(과장 또는 합성).
- 죽간 다발 아래쪽이 흐릿하게 바래 반사·붙여넣기처럼 보임(이어붙임 흔적 의심).
- 문 앞 작은 자갈 두 무더기 — 의미 없음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 중국 **晉** / 한국 **三國** — 확신도 85% (변동 없음).

**② 레인별 묶음**
- **강(본초서 계보)**: 사전에 竹·대숲 항목 없음. 「濟(물에 드리운 밧줄)」「藥(약연)」 같은 물가 기호도 없음 → 여전히 **말하는 묶음 없음**.
- **흙길 중앙**: 사전 「王 = 왕관 — 성이 王까지만, 어느 王인지는 무대가 진다」가 그대로 맞는다. 무대 = 晉 흙길 + 맥침·寸口 팔 → **王叔和** 확정, 곁 사실 **脈經**(寸·關·尺 三部, 寸口診 정립) 그대로.
  - 검토한 갈림: 「充 = 걷어올린 맨팔뚝 위에 더해진 것」을 대면 왕관+맨팔뚝+점 = **王充**(後漢 『論衡』, 元氣論)으로도 읽힌다. 그러나 ⓐ 소매를 걷어올린 흔적이 없고 팔은 맥침 위에 놓였으며, ⓑ 점 셋이 손목 寸口에 나란해 脈位로 읽히고, ⓒ 오른쪽 이웃이 葛洪(東晉)이라 활동 순서상 王充(1세기)이 바로 왼쪽에 오기 어렵다 → 充 갈림은 **불성립**으로 판정, 王叔和 유지.
  - 묶은 죽간: 사전 「典藥(끈으로 묶은 약봉지 다발)」「收(끈으로 조인 삼베 자루)」와 다르다(대쪽 다발) → 기호 아님, 「책·**編次**(傷寒雜病論 재편)」 1단계 읽기 유지.
- **흙길 오른쪽 가장자리**: 사전에 葛·抱·朴 항목 없음 → 1단계 그대로 **葛洪(抱朴子)**, 이웃 띠 몫.
- **거리(한국)**: 「藏 = 문 열린 곳간 안의 곡식 가마니」— 문은 열렸으나 안이 비어 어둡고 가마니 없음 → 藏 아님. 「寺 = 기와지붕 절」— 초가라 寺 아님. 「倉」— 관리 없음. → **빈 거리** 확정.

**③ 잔결**: 사전 어휘로도 풀리지 않는 것 — 왼쪽 가장자리 흰 깃발 무더기(이웃 띠 몫, 뜻 미상), 강 왼쪽 동심원 물결(주인 없음), 죽간 다발 아래쪽의 흐릿한 바램(붙여넣기 흔적 의심), 지나치게 큰 팔뚝(充 오독을 부를 수 있는 모양). 사전은 王 확정에 기여했을 뿐 새로 풀린 소품은 없다.
