# z44 판독 기록

## 1단계 — 생판 (사전 없이)

**① 시대**: 中 **盛唐(8세기 전반~중반)** / 韓 **통일신라** — 확신도 75%.
근거: 강의 본초서가 唐 중기 것들(拾遺·海藥)로 읽히고, 흙길에 王씨 두 명(王燾·王冰 연대), 거리에 신라 금관(出자형 나뭇가지 입식).

**② 말하는 묶음 (레인별)**
- 강(가운데): 문 열린 나무 창고(藏) + 그 앞에 늘어놓은(陳) 그릇(器) **10개**(뒤3·앞2 × 좌우 두 무더기) + 처마에 걸린 채집 바구니(拾) + 금메달(최초) → **本草拾遺(陳藏器)**. 그릇 10 = **十劑 최초 제창**, 바구니 = 新修本草가 빠뜨린 약을 「주워 모음(拾遺)」.
- 강(오른쪽): 부두 위 소년 + 거대한 자두(李) → **海藥本草(李珣)** — 바다 건너 들어온 외래 약물. 소년 몸의 밧줄은 뜻 미상.
- 강(왼쪽 가장자리): 상 위 인삼·나물 그릇 → **食療本草(孟詵)** 후보, 잘려서 이웃 몫.
- 흙길(가운데): 왕관(王) 쓴 남색 관복 중년 + 뒤의 붉은 기둥 궁전(弘文館) + 궁 담장 밖 누대(外+臺) → **王燾 『外臺秘要』**(752) — 弘文館 秘籍을 모아 편찬, 지방관(外臺) 시절 완성.
- 흙길(오른쪽 가장자리): 왕관 쓴 주름진 노인(王+老) → **王冰**(素問 次注) 후보, 잘려서 이웃 몫.
- 거리: 신라 금관 쓴 왕(→신라) + 간판「두 손이 등잔을 받듦」(=供奉) → **供奉醫師** (2순위 **藥典**). 왼쪽 큰 기와집(문 열림) + 그리로 걷는 소년(학생) → **醫學**(692 효소왕, 의학교육기관). 간판 뒤 얼굴 가린 회색옷 두 사람 = 醫博士 2인 또는 학생 후보.

**③ 잔결**
- 거리 줄 x≈350에 세로 이음매: 기와 지붕이 어긋나고 밝기 차, 흰 벽에 계단식 단차. 흙길-거리 경계(y≈690~700) 오른쪽이 흐릿하게 번짐.
- 자두 소년의 몸을 감은 밧줄 — 뜻 모름.
- 금메달이 「무엇의 최초」인지 단정 불가(十劑로 추정).
- 흙길 왼쪽 가장자리의 날개 달린 갈색 물체 — 이웃 띠 몫.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 中 **盛唐(8세기 중엽, 玄宗~肅宗)** / 韓 **통일신라(경덕왕 무렵)** — 확신도 85%.
사전의 「保命 = 두 손으로 감싼 등잔불」이 간판에 정확히 맞아, 거리가 경덕왕대 藥典→保命司 개칭으로 좁혀지고 中 쪽 752 外臺秘要와 시기가 겹친다.

**② 말하는 묶음 (레인별)**
- 강(가운데): 문 열린 곳간 = 藏(⚠ 갈림 조건인 「쌓인 곡식 가마니」가 없고 비어 있음 → 약하게만 성립. 앞에 관리 없으니 倉은 아님) + 늘어놓은 그릇(器) 10개 + 채집 바구니(拾) + 금메달 → **本草拾遺(陳藏器)** — **十劑 최초 제시**. 그릇은 포개지지 않아 久 아님, 받는 손이 없어 惠 아님.
- 강(오른쪽): 「허리춤 자두」 = **李** 확정. 강(본초)·唐 무대이고 本草拾遺(739) 오른쪽(뒤)이므로 新修本草(李勣, 659)가 아니라 **海藥本草(李珣)** — 외래 약물 본초. 밧줄은 濟·衆·同 어느 조건(물에 드리움 / 여럿)에도 안 맞음.
- 강(왼쪽 가장자리): 인삼·나물 상 — 사전 어휘 없음, 잘림 → 이웃 몫(**食療本草** 후보).
- 흙길(가운데): 왕관 = **王**(성까지만, 무대가 지정) + 궁 담 바깥(外)의 누대(臺) → **王燾 『外臺秘要』** — 弘文館(뒤 궁전) 秘籍 집성. 누대는 두 王 「사이의 한복판」에도 서 있으나 中 어휘로는 뜻이 안 섬.
- 흙길(오른쪽 가장자리): 왕관 노인 = 王 → 순서상 **王冰**(素問 次注) 후보, 잘림 → 이웃 몫.
- 거리(오른쪽): 신라 금관 왕 + 간판 「두 손이 감싼 등잔불」 = **保命** → **保命司**(경덕왕이 **藥典**을 고친 이름). 간판 뒤 회색옷 두 사람 = 그 기관 관원.
- 거리(왼쪽): 큰 기와집 = 사전상 **寺**로 읽히나 신라에 맞는 「○○寺」 기관이 떠오르지 않음. 학생 같은 소년이 그리로 감 → **醫學**(692, 효소왕) 후보 유지. 이음매가 이 집과 王·간판 사이를 가르므로 별도 항목일 가능성 큼.

**③ 잔결**
- 거리 x≈350 세로 이음매(기와 어긋남·밝기 차·벽 단차) + 흙길/거리 경계 번짐 — 1단계와 동일.
- 곳간이 비어 있어 藏 갈림 조건 불충족. 금메달은 사전에 없는 기호(「최초」 추정).
- 자두 소년의 밧줄, 거리 기와집(寺?)의 정체 — 미해결.
