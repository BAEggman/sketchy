# z45 판독 (blind16z, 말판 ③줄 宋·金·元 세로 띠)

## 1단계 — 생판 (사전 없이)

**① 시대**: 중국 **北宋 후기~南宋·金(일부 元)** / 한국 **高麗** — 80%. 강의 본초 둘이 北宋 관찬·사찬 본초의 연속으로 읽히고, 흙길 끝의 왕관 노인이 元(금원 말) 쪽으로 읽힌다.

**② 묶음별 판독**
- 강(본초) — 부두 위 **이젤의 약초 도판**(뿌리까지 그린 식물 그림): 「그림 붙은 본초」 → **本草圖經**(蘇頌, 北宋, 전국 약재 그림 수집).
- 강(본초) — 부두에 앉은 복두 선비 + **칸칸이 나뉜 표본 상자(이름표 붙음)** + 곁에 쌓인 책: 「분류(類)·경사(經史) 책을 모아 엮음」 → **經史證類備急本草**(唐愼微). 상자 칸 = 類, 책 더미 = 經史 인용.
- 길 — **허수아비**(얼굴이 펼친 책, 밀짚모자): 「허수」 → **許叔微**, 책 = 普濟本事方(또는 傷寒九十論). 왼쪽의 수척한 평복 남자는 짝 소품이 불분명(허수아비의 주인 농부?).
- 길 — **무 세 뿌리를 한 줄로 묶은 단**: 무(無) + 셋을 하나로 묶음 → **陳無擇 『三因極一病證方論』, 三因(內因·外因·不內外因)學說**. 곁의 초록 저고리 청년은 무 단과 짝인지 별개인지 불확실(대안: 成無己 注解傷寒論, 혹은 小兒 → 錢乙).
- 길 — **금관 쓴 노인이 OK 손(엄지·검지 고리)을 손가락으로 가리킴**: 王(관) + 好(좋다 손짓) + 古(노인) → **王好古**(元, 易水學派, 陰證略例·湯液本草).
- 거리(高麗) — 청기와 관청, 왼 간판 **갓 + 약통** → 官 + 藥: **太醫監** 또는 **尙藥局**(관영 의료). 오른 간판 **산속 절집** → 院/大悲: **東西大悲院**. 머리띠 두른 환자와 회색 옷 빈민들이 걸어옴 → 서민 구료 기관(惠民局 가능성도).

**③ 잔결**: 왼쪽 수척한 평복 남자·초록 청년이 무엇을 나르는지 불명(빈 사람 소품 가능). 갓 밑 원통 안의 막대들(약숟가락? 산가지?) 뜻 불명. 오른쪽 위 붉은 천 뗏목·왼쪽 끝 부두·거리 양끝 인물은 이웃 띠 몫으로 무시.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 중국 **北宋 후기~南宋·金·元** / 한국 **高麗** — 82%. 사전의 王(왕관)은 「무대가 어느 王인지 진다」 — 金元 흙길이므로 元의 王씨로 좁혀져 1단계 판독을 지지한다.

**② 묶음별 재판독**
- 강 — **이젤 약초 도판** → **本草圖經**(蘇頌). 사전에 해당 기호 없음 — 그림 자체로 읽힘(유지).
- 강 — **칸 나뉜 표본 상자 + 經史 책 더미 + 앉은 선비** → **經史證類備急本草**(唐愼微). 상자 속 물건은 會(담는 것 안에 담긴 것)로도 읽히나 宋 본초 계보에 會 서명이 없어 기각, 類(분류)로 유지.
- 길 — **허수아비(밀짚모자 + 책 얼굴)**: 사전 脾 = 노란 밀짚모자 **농부**. 허수아비는 농부가 아니라 「가짜 농부」이므로 脾 조건이 완전히 맞지 않는다. 1순위는 여전히 소리 말장난 허수아비 → **許叔微**(普濟本事方·傷寒九十論, 최초의 傷寒 醫案集). 2순위로 밀짚모자=脾 + 책 = 『**脾胃論**』(李東垣, 補土派)가 걸리나 李(자두)가 없어 약함.
- 길 — **상투 튼 청년 + 무 세 뿌리 한 단**: 무 = 無(소리), 셋을 끈 하나로 묶음 = 三→一 → **陳無擇 『三因極一病證方論』, 三因學說**(1순위). 사전 久(셋이 포개짐)는 「포개짐」이 아니라 나란히 묶음이라 불일치, 典藥(약봉지 다발)도 약봉지가 아니라 불일치. 상투(成人)=成 + 무=無 → **成無己**(注解傷寒論, 최초의 傷寒論 全文 注解)는 2순위.
- 길 — **왕관 노인 + OK 손짓 가리킴**: 王(사전 확정) + 好(손짓) + 古(노인) → **王好古**(元, 易水學派, 陰證略例·湯液本草). 무대가 金元이라 王의 갈림 조건 충족.
- 거리(高麗) — 왼 간판 **테 넓은 큰 갓** = 사전 **太**, 그 밑 침통(바늘 꽂힌 원통) = 醫로 보면 → **太醫監**(고려 중앙 의료행정·의학교육·醫科). 오른 간판 **기와지붕 절 한 채** = 사전 **寺** → 한 건물에 간판 둘 = 같은 기관의 개칭 → **典醫寺**(太醫監의 후기 이름). 1단계의 「갓=官·절=大悲院」은 사전 어휘로 더 잘 풀려 교체. 大(둘 중 하나가 두 배)는 뒤의 회색 두 사람이 같은 크기라 성립 안 함 → 大悲院 기각.

**③ 잔결**: 왼쪽 수척한 평복 남자(소매 걷은 팔뚝 — 充 조건인 「팔뚝 위에 더해진 것」이 없음)와 거리의 흰 머리띠 행인·회색 두 사람은 기호로 안 풀린다(빈 소품 또는 이웃 띠 연결). 갓 밑 원통이 醫인지(사전에 醫 없음) 불확실. 「허수아비 밀짚모자」가 脾 기호와 겹쳐 오독 위험.
