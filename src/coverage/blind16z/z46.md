# z46 판독 기록

## 1단계 — 생판 (사전 없이)

**① 시대**: 淸 후기(19세기 전후) / 朝鮮 후기 — 85%. 흙길 인물 둘 다 앞머리를 민 변발(辮髮) = 淸. 앞 거리는 갓·도포·상투 차림의 조선 기와집.

**② 묶음별 판독**
- 강(뒤): 비어 있음. 물결과 풀 언덕뿐이라 본초서를 나르는 소품을 찾지 못함.
- 흙길 왼쪽: 갈색 장포를 입은 변발 남자. 등 뒤로 도랑물이 흐르고 거기서 김이 피어오름. 물(濕) + 김(熱)으로 읽어 **薛雪(薛生白)『濕熱條辨』**(濕熱病 전문)을 1순위로 봄. 김을 「溫」으로만 읽으면 **葉天士『溫熱論』** 또는 **吳鞠通『溫病條辨』**도 가능함. 溫病學派 쪽인 것은 거의 확실하지만 인물을 가리키는 소품이 약함.
- 흙길 오른쪽: 금관(王)을 쓴 남색 옷의 변발 남자와 베틀. 베틀에 짜이는 천에 불꽃(熱) 무늬가 있음. 베틀의 날실·씨실 = 經緯. 王 + 溫熱 + 經緯로 읽어 **王士雄(王孟英)『溫熱經緯』**(1852, 葉·薛·陳·余의 溫病 학설을 경(經)과 위(緯)로 엮음, 溫病學 집대성). 확신도 높음.
- 앞 거리 오른쪽: 갓 쓴 선비. 발치에 펼친 책이 있고, 뒤편 우물 도르래가 물에 빠진 말을 건져 올리고 있음. 「말(馬)을 건짐(濟)」 = 濟馬 → **李濟馬『東醫壽世保元』**(1894). 펼친 책이 이 서명이고, 학설은 四象醫學. 허리의 보라색 주머니(약낭?)는 뜻을 못 정함.
- 앞 거리 왼쪽: 흰 옷에 상투를 튼 소년 둘. 소품이 없음. 아이 = 소아과·마진으로 보아 **丁若鏞『麻科會通』**(1798)일 수도 있고, 이제마 곁의 「少(陽/陰)人」 둘일 수도 있음. 미정.

**③ 잔결**: 강에 소품이 없음. 갈색 옷 인물을 직접 가리키는 고유 소품이 없음. 김 기둥이 왼쪽 가장자리까지 이어져 있어 이웃 띠 몫일 가능성이 있음. 보라 주머니와 두 소년은 뜻 미상. 흙길 뒤 가게 휘장과 김의 경계에서 이어 붙인 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (blind6 사전 적용)

**① 시대**: 淸 후기 / 朝鮮 후기 — 90%. 사전의 李·濟·馬가 앞 거리에서 한 사람에게 맞물려 조선 말기가 굳어짐.

**② 묶음별 재판독**
- 강: 여전히 빔. 사전 기호(藥=약연, 地黃=뿌리 조각 등)도 나오지 않음.
- 흙길 오른쪽: 왕관 = **王**(성씨까지만이고, 어느 王인지는 무대인 淸이 정함). 베틀 천의 불꽃 = **熱**. 베틀 자체(날실·씨실 = 經緯)는 사전에 없는 서명 그림말임. 사전의 杼(실이 빠져나온 베틀북)는 따로 보이지 않음. 등 뒤로 이어지는 김 오르는 물을 溫으로 받으면 → **王士雄(王孟英)『溫熱經緯』**(溫病學 집대성). 1단계와 같고 확신도가 올라감.
- 흙길 왼쪽: 사전 대로면 피어오르는 흰 김 = **氣**이고, 물 위 안개를 外濕으로 볼 여지가 있음. 溫은 「김 나는 따뜻한 천」이라 조건이 맞지 않음. 吳(큰 입)·張(활)·李(자두) 같은 성씨 기호가 없어 인물이 정해지지 않음. 濕(안개) + 김을 熱 기운으로 보면 **薛雪『濕熱條辨』**, 氣를 衛氣營血의 氣로 보면 **葉天士『溫熱論』**이 됨. 둘 다 약한 추정이고, 사전으로도 더 풀리지 않음.
- 앞 거리 오른쪽: 허리춤의 보라 열매는 주머니가 아니라 자두 = **李**. 도르래 밧줄이 물에서 건져 올리는 것 = **濟**. 건져지는 것이 말 = **馬**. 사전의 馬는 「사람 곁 고삐 말」이지만 여기서는 濟와 합쳐진 이름 글자로 읽는 편이 자연스러움. → **李濟馬**. 펼친 책은 **『東醫壽世保元』**(1894), 학설은 **四象醫學**. 1단계의 「보라 주머니 미상」이 해소됨. 95%.
- 앞 거리 왼쪽 두 소년: 太(넓은 갓)·大(하나가 두 배)·中(둘 사이 한복판)에 맞지 않음. 같은 크기의 두 아이일 뿐이라 사전으로 풀리지 않음. 소아 = **丁若鏞『麻科會通』** 또는 「少陽·少陰」은 여전히 추정. 이웃 띠 몫(왼쪽에서 잘린 집)일 가능성도 있음.

**③ 잔결**: 강이 빔. 흙길 왼쪽 인물의 고유 성씨 기호가 없음. 두 소년의 뜻이 미상. 베틀(經緯)이 사전에 없는 1회성 그림말임. 馬가 사전 정의(고삐 말)와 달리 물속 말로 쓰임.
