# z48 판독

## 1단계 — 생판 (사전 보기 전)

**① 시대**: 1순위 **명(明) / 조선** (65%). 근거: 거리 레인의 인물이 흰 한복·상투, 기와 상점이 조선 거리풍이고, 가운데 흙길 인물도 저고리 차림에 흰 갓이 걸려 있다. 강의 약재 칸칸 상자가 「강목식 분류 본초」를 떠올리게 해 명대 쪽으로 기운다. 2순위 청 / 조선 후기.

**② 레인별 묶음**
- 강(본초) — 선착장에 선 사람 + 두 포기 약초 + 12칸으로 나뉜 약재 표본 상자. 칸칸이 나눈 상자 = 부(部)·류(類)로 나눈 분류 체계 → **본초강목(李時珍)** 1순위. 오른쪽 빈 선착장은 다음 칸 몫으로 보임(말 없음).
- 흙길(의가) — 버드나무 아래 선 사람, 나무에 흰 갓(긴 갓끈 여러 가닥)이 걸려 있음. 버드나무 = 楊/柳 → **楊繼洲(針灸大成)** 을 1순위로 추정(확신 낮음). 흰 갓·늘어진 끈이 무슨 사실(서명·학설)을 나르는지는 해독 못 함. 오른쪽 돌다리+개울도 독립 소품인지 배경인지 불분명.
- 거리(한국) — 흰 옷 걷는 사람 + 상점 선반: 낡은 고서 두 권 → 화살표 → 호쿠사이 「큰 파도」 표지의 책. 「조선 의서가 일본으로 건너가 거기서 남음/간행됨」 → **의방유취**(임진왜란 때 반출, 일본에 전본) 1순위, **동의보감**(일본판 간행) 2순위.

**③ 뜻 모를 것·이음 흔적**
- 흰 갓 + 길게 늘어진 갓끈(무슨 글자인지 모름), 돌다리와 개울.
- 화면 위쪽 x≈160 지점에 세로 이음선: 왼쪽 강·선착장·약재 상자가 밝기 다른 조각으로 덧붙어 있고, 약재 상자가 그 선에서 잘림.
- 왼쪽 가장자리 마른 가지 더미는 이웃 띠 몫으로 보고 무시.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: **수·당(隋唐) / 삼국(백제·신라·고구려) ~ 통일신라 초** (70%). 1단계의 「명/조선」은 버린다 — 흙길 묶음이 사전 어휘로 楊上善으로 풀리면서 시대가 통째로 당겨졌다. 흰 한복·상투는 이 그림책의 범용 인물 차림일 뿐 조선 표지가 아니었다.

**② 레인별 묶음**
- 흙길(의가) — 사전 「太 = 머리에 씌운 테 넓은 큰 갓 하나」, 「上 = 머리 꼭대기로 곧게 솟음」. 버드나무(楊)의 **꼭대기(上)** 에 씌운 **큰 갓(太)**, 그것도 **새하얀 갓·흰 갓끈 여러 가닥(素 = 흰 생명주)**. → 楊 + 上 + 太素 = **楊上善 『黃帝內經太素』**(수말당초, 『내경』을 분류해 주석한 최초의 분류 주석서). 나무 아래 사람이 楊上善. 善은 따로 실린 소품 없음.
- 거리(한국) — 낡은 고서 두 권 → 화살표 → 호쿠사이 파도 표지(=일본) 책. 이 시대 한국 의서가 일본으로 건너가 일본 의서 속에 인용되어서만 전한다는 사실 → **백제신집방(百濟新集方) · 신라법사방(新羅法師方)** → 일본 **『醫心方』**(丹波康賴, 984)에 인용·잔존. 넓게는 삼국의 일본 의학 전파(백제 의박사·채약사 파견 등).
- 강(본초) — 선착장의 사람 + 약초 + 칸칸 나눈 약재 표본 상자(사전에 해당 글자 없음). 이 시대 본초 계보로는 전국 약재를 조사·수집해 엮은 국가 주도 **新修本草**(唐 659, 蘇敬 등, 세계 최초 국가 약전) 1순위, 칸 나눈 상자를 「자연 속성 분류」로 보면 **本草經集注**(陶弘景) 2순위.

**③ 남는 것**
- 강 왼쪽 x≈160 세로 이음선 — 사람·약재 상자가 붙은 조각이 따로 덧대어졌고 상자가 그 선에서 잘림. 이 강 묶음이 이웃 구간에서 옮겨 붙은 것일 수 있다. 오른쪽 빈 선착장은 말 없음.
- 흙길 오른쪽 돌다리+개울: 사전 어휘(濟·通 등)로도 안 풀림 — 배경으로 판정.
- 사전으로 1단계보다 확실히 더 잘 풀린다(太·上이 결정적).
