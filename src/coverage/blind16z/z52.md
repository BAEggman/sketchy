# z52 판독 (blind16z)

## 1단계 — 생판 (사전 보기 전)

**① 시대**: 明 / 朝鮮 전·중기 (90%). 가운데 길 두 의가가 明 鍼灸·綜合醫書 세대, 강의 그물은 明 본초 대작을 가리키고, 앞 거리는 갓 대신 흑립·흰 바지저고리의 朝鮮 풍속.

**② 레인별 묶음**
- 강(본초): 오른쪽 절반에 굵은 밧줄(벼리) 달린 그물이 물에 떠 약초 잎을 잔뜩 걸러 잡음. 벼리(綱)+그물코(目) = **本草綱目**(李時珍, 1578). 약초를 「그물로 다 거둬들임」 = 집대성.
- 흙길 왼쪽: 갈색 도포 노인, 어깨에 공작꼬리 鳳凰이 얹혀 얼굴을 가림 + 발밑에 鍼이 수십 개 숲처럼 꽂힘. 鳳 = **徐鳳**, 침을 「한가득 모아 꽂음」 = **鍼灸大全**. (차선: 鍼 무더기를 「모음(聚)」으로 보면 **高武『鍼灸聚英』**.)
- 흙길 오른쪽: 회색 도포 청년이 자두(李)를 들고, 곁에 나무 문틀(門)과 그 앞에 가로누운 긴 통나무(梴). 李+긴 나무 = **李梴**, 문으로 들어감 = **醫學入門**(1575). 문지방 앞 통나무는 「入門」의 문턱.
- 앞거리 왼쪽 집: 우물(마을=鄕), 지게 두 개에 약초 자루, 산수화 간판(산 위 붉은 해 = 朝鮮/東), 흰옷 소년. 시골에서 캐 나르는 토산 약재 = **鄕藥集成方**(1433) 계열 (차선 **鄕藥採取月令** — 지게로 「채취」해 나름).
- 앞거리 가운데: 붉은 기둥 관아 + 갈색 원통에서 빛·소리선이 나오는 간판 + 아래 나무판에 배 모양 약연(藥碾)/주걱 새김. 관청 약방 → **惠民署** 또는 **典醫監**(약 제조·판매). 원통 뜻은 미상.
- 앞거리 오른쪽(가장자리): 큰 책 표지에 초가집+울타리와 약초 그림. 초가 = 村家 → **村家救急方**(1538) 후보. 오른쪽에서 잘려 이웃 띠 몫일 수 있음.

**③ 잔결 (1단계)**: (가) 관아 간판의 갈색 원통+방사선은 혼자 평면 아이콘 화풍이라 이어 붙인 티가 남, 뜻 모름. (나) 李梴 왼쪽에 흰 유령 같은 사람 윤곽(지운 인물 자국). (다) 화면 x≈520 근처에 세로로 옅은 이음선이 강·길·거리를 관통. (라) 鳳凰 꼬리깃이 李梴 쪽까지 뻗어 두 묶음 경계가 흐림. (마) 산수화의 붉은 해가 시대 표지인지 사실 소품인지 불분명.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 明 / 朝鮮 초·중기 (92%). 사전의 「李=허리춤 자두 — 어느 李인지는 무대가 진다」가 明 무대와 맞물려 李梴으로 굳고, 강의 綱目이 그 바로 위에 놓여 明 후기(16세기 후반)까지 닿는다. 앞거리는 산(艮=東北=우리나라)이 걸린 朝鮮.

**② 레인별 묶음**
- 강(본초): 사전에 그물 항목은 없음. 「濟=물에 드리운 밧줄」과 겹쳐 보일 수 있으나 밧줄은 물속으로 드리운 것이 아니라 그물 위쪽 벼리로 수면을 가로지름 → 濟가 아니라 벼리(綱)+그물코(目). **本草綱目**(李時珍) 유지. 바로 아래 李梴과 활동 시기도 겹침.
- 흙길 왼쪽: 鳳凰·鍼 무더기 모두 사전 밖 소품. 鍼이 살이 아니라 땅에 꽂혀 있어 「痛=살에 박힌 쇠못」도 아님. **徐鳳 『鍼灸大全』** 유지(鳳=이름, 鍼 한가득=鍼灸 大全). 확신은 1단계보다 조금 낮춤 — 등재 기호가 하나도 받쳐 주지 않음.
- 흙길 오른쪽: 허리춤 자두 = 李(등재), 작은 문틀 = 門(등재) → 李 + 入門. 통나무(梴)는 사전 밖이지만 李를 明 의가 중 하나로 좁힘 → **李梴 『醫學入門』** 확정도 상승.
- 앞거리 왼쪽 집: 우물 위로 밧줄에 매달려 내려진 두레박 = 「물에 드리운 밧줄」 = **濟**. 지게로 실어 온 약초 자루 + 산(艮)이 걸린 간판 = 토산 약재(鄕藥), 흰옷 소년 = 生(살림받는 백성). → **濟生院**(1397, 鄕藥을 모아 백성에게 施藥, 醫女 교육) 1순위, 그 기관이 엮은 **鄕藥濟生集成方**(1398) 2순위. 1단계의 鄕藥集成方·鄕藥採取月令에서 濟 기호 덕에 이동.
- 앞거리 가운데: 나무판의 배 모양 약연 = **藥**(등재). 원통 간판은 붉은 기둥 관아의 「담 안쪽」에 걸림 → 內(등재: 담 안쪽). 內 + 藥 → **內藥房 → 內醫院**(1443 개칭, 왕실 의료) 1순위. 惠(여럿이 받는 빈 사발)·典藥(약봉지 다발) 기호가 없어 惠民署·典醫監은 밀림.
- 앞거리 오른쪽(가장자리): 초가+약초 표지 큰 책 — 사전 밖. **村家救急方** 후보 그대로, 이웃 띠 몫일 가능성.

**③ 잔결 (2단계)**: (가) 원통+방사선 간판은 사전에도 없고 화풍도 혼자 평면 아이콘이라 뜻 못 품(華=빛나는 것으로 볼 여지만 있음). (나) 鳳凰·鍼 무더기·통나무·초가 책이 모두 미등재라 이름이 소품 하나에 걸린 의가가 많음. (다) 李梴 왼쪽 흰 유령 윤곽, x≈520 세로 이음선은 여전. (라) 우물 두레박이 濟인지 단순 마을 풍경인지는 「드리운 밧줄」 조건에 반쯤만 맞음(사람이 아니라 두레박이 매달림).

**판정**: 사전 어휘로 李·門·藥·濟·內가 잡혀 앞거리 두 기관이 더 잘 풀림(1단계 鄕藥集成方 → 濟生院, 정체불명 관아 → 內醫院). 가운데 길·강은 사전 밖 말장난(鳳·梴·綱目)이 그대로 지탱.
