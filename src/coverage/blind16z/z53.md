# z53 판독 (blind16z)

## 1단계 — 생판 (사전 없이 그림만)

**① 시대**: 중국 **前漢(西漢)** 중심, 漢 일반 / 한국 = 고조선~삼국 초 (거리는 빈 초가 한 채뿐). 확신도 60%.

**② 레인별 묶음**
- 강(본초서 계보): 비어 있음. 왼쪽 끝 물가의 둥근 바구니(통)는 이웃 띠 몫으로 보고 제외.
- 흙길 ①(왼쪽): 관모·수염의 漢代 관리가 **세로 괘선만 그어진 빈 장부**를 펼쳐 들고, 곁에 **곡식 가마니가 가득 찬 창고(倉)**가 문을 열고 있다. → **淳于意(倉公)** — 太倉長 출신이라 「倉公」, 펼친 괘선 장부 = 『**診籍**』(진료기록 25례, 현존 최초의 의안·병력기록).
- 흙길 ②(가운데): 돌 탁자 위 **누런 비단보(黃·帛)**, 그 위에 **죽간 묶음 둘** — 왼쪽 묶음 뒤로 **침(가는 막대)들이 꽂혀** 있고, 오른쪽 묶음은 **흰 실**로 묶여 있다. 탁자 앞에 **금메달**. → 1순위 **黃帝內經**(죽간 둘 = 素問(흰 실=素)·靈樞(=鍼經, 침), 금메달 = 현존 最古 의서·이론 체계 최초). 2순위 **馬王堆 출토 의서**(帛書+竹簡, 『足臂/陰陽十一脈灸經』『五十二病方』 = 현존 最古 의서). 3순위 武威漢代醫簡.
- 흙길 ③(오른쪽): 점선 윤곽의 **사다리**가 홀로 서 있음. 사람 없음 → 표제어 미상. 억지 후보 **皇甫謐 『鍼灸甲乙經』**(가로대=甲·乙 단계) — 근거 약함.
- 거리(한국): 초가 한 채 = 빈 거리(기관·의서 없음). 오른쪽 위 틈의 **나무판 표지에 ✱(米/눈꽃) 무늬가 찍힌 책 + 푸른 실 제본 책** 더미 → 표제어 미상(이웃 띠로 넘어가는 소품일 가능성).
- 배경 성벽·망루 = 漢의 도성/長城 → 시대 배경으로만 읽음.

**③ 잔결**: 사다리와 책 더미만 **검은 점선 윤곽**(오려 붙인 스티커 꼴) — 장면과 따로 논다. 거리 레인 x≈410 지점에 **세로 회색 띠(이음매)**가 초가 지붕을 가로지른다. 왼쪽 끝 푸른 깃발 꽂힌 상자, 강 왼쪽 끝 바구니는 이웃 띠 몫. 죽간 오른쪽 묶음의 흰 실이 바람에 날리는 듯한 선(뜻 미상).

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 중국 **漢(前漢→後漢)** / 한국 = 고조선~삼한(거리 비어 있음). 확신도 70%. 왼쪽 倉公(前漢)에서 오른쪽 傷寒(後漢)으로 흐르는 띠로 읽혀 1단계보다 오른다.

**② 레인별 묶음**
- 강: 비어 있음(변동 없음).
- 흙길 ①: 사전의 **倉 = 곡식 가마니 곳간**, 갈림 「앞에 관리가 서 있으면 倉(아니면 藏)」 → 관모 쓴 관리가 문 열린 곳간 앞에 서 있으므로 藏이 아니라 **倉** 확정. 「太 = 테 넓은 큰 갓」은 안 씌웠으니 太倉까지는 안 짓고 **淳于意(倉公)** 로 읽는다. 괘선 빈 장부 = 『**診籍**』(최초의 의안·병력 기록). 1단계와 같고 확신 상승.
- 흙길 ②: 탁자 묶음(누런 비단·죽간 둘·침·금메달)은 사전에 해당 글자가 없다. 사전의 「中/官」(가구 위)·「外(담 바깥)」 갈림은 성벽이 레인 전체 배경이라 적용하지 않는다. 오른쪽 죽간에서 피어오르는 흰 줄기는 **氣(서린 흰 김)** 로 읽힐 수 있으나 표제어를 바꾸지는 못한다 → 1단계대로 1순위 **黃帝內經**(素問·靈樞=鍼經, 금메달=現存 最古 의서), 2순위 **馬王堆 출토 의서**(사전의 「馬 = 고삐 맨 말」이 없어 1단계보다 낮춤).
- 흙길 ③(오른쪽): 사전 **寒 = 눈송이** → 1단계에서 「✱/米 무늬」로 본 나무판 책 표지가 **눈송이 = 寒** 이 된다. 寒이 박힌 책 = 『**傷寒(雜病)論**』, 아래 푸른 실 제본 책 = 나중에 갈라 엮은 판본(『**金匱要略**』 등, 雜病 쪽). 같은 점선 윤곽으로 함께 붙은 **사다리의 가로대가 정확히 6칸** → **六經辨證**(太陽→…→厥陰, 단계적 傳變). 표제어 **張仲景**. 다만 사전의 「張 = 등에 멘 긴 활」을 멘 사람은 이 띠에 없다 → 인물은 오른쪽 이웃 띠 몫, 이 띠는 그의 서명·학설 소품만 나른다. 「傷 = 깨진 물건」도 없어(책은 멀쩡) 傷寒의 「傷」은 그림이 직접 나르지 않는다.
- 거리(한국): 초가 한 채 — 사전으로도 해당 글자 없음, 빈 거리.

**③ 잔결**: 사다리+寒 책만 점선 윤곽(오려 붙인 꼴)이고 주인(張=활 멘 사람)이 띠 안에 없음. 금메달·누런 비단·돌 탁자·침은 사전 밖 기호라 「최초」「黃」로 추정만 함. 거리 x≈410 세로 이음매 띠. 傷寒의 「傷」을 나르는 깨진 소품 부재.
