# z54 판독 (blind16z)

## 1단계 — 생판 (사전 없이 그림만)

**① 시대**: 한국 — 조선 말~대한제국(1890~1910년대 전후). 확신도 70%. 근거: 전신주·전선, 붉은 벽돌 2~3층 양관, 갓·두루마기 노인과 중절모 양복 신사가 한 거리에 섞여 있음. 맨 뒤 강은 비어 있음(本草 강 공란 — 구간 설명과 일치).

**② 레인별 묶음**
- **가운데 흙길** — 갓 쓴 흰 수염 노인이 커다란 붉은 해(陽)를 두 손으로 머리 위에 받쳐 들고, 허리끈에 붉은 자두(오얏 = 李)를 매달았다. 李씨 + 해를 「떠받침(扶)」 = 扶陽 → **이규준(李圭晙, 石谷)** 1순위 — 부양론(扶陽論), 『소문대요(素問大要)』『의감중마(醫鑑重磨)』. 2순위 **이제마** (李 + 해 = 太陽人 자처 → 사상의학, 『동의수세보원』 1894). 「들어 올리는」 동작이 扶를 가리킨다고 보아 이규준을 택함(70:30).
- **앞 거리 왼쪽** — 3층 붉은 벽돌 건물 정면에 훈장(붉은 줄무늬 수, 꽃 모양 금장 — 대한제국 李花章처럼 보임), 그 앞 우물에서 아이가 밧줄을 타고 기어오름(우물에서 사람을 건짐 = 濟). 곁에 새싹 하나. → **광제원(廣濟院, 1900)** 1순위: 대한제국 국립병원, 한방·양방 병존. 대안 **대한의원(大韓醫院, 1907)**(훈장 = 大韓), **제중원(濟衆院, 1885)**(濟 + 최초 서양식 병원). 새싹 = 「최초/새로 시작」 표지로 추정.
- **앞 거리 오른쪽** — 두루마기 차림 남자와 중절모·양복 신사가 나란히 걸어감, 뒤는 빈 현판의 한옥 관아·담. → 한의(전통)와 양의(서양)가 「함께(同)」 가는 장면 → **동제의학교(同濟醫學校, 1906)** 또는 광제원의 한·양의 병존. 빈 현판은 이웃 띠와 이어질 몫일 수도.

**③ 뜻 모를 것·어색한 것**: 우물 옆 새싹의 몫이 불분명(生 → 醫生? 혹은 「최초」). 훈장 중앙 무늬가 작아 李花인지 확정 못 함. 한옥 현판이 비어 있음. 이어붙임 흔적은 뚜렷하지 않음(중경 벽돌 건물 띠와 앞 거리 사이 흙바닥 경계가 다소 급함).

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 한국 — 조선 말~대한제국(1880~1900년대). 확신도 75%. 사전에 시대를 바꿀 기호는 없고, 李·濟가 「무대가 진다」 규칙대로 한국 근대 무대에서 풀림.

**② 레인별 묶음**
- **가운데 흙길** — 허리춤 자두 = **李**(등재, 확정). 머리에 쓴 테 넓은 큰 갓 하나 = **太**(등재), 해 = **陽**(등재). 등재 기호만으로 李 + 太陽 → **이제마(李濟馬)** — 太陽人(스스로 태양인), 사상의학·『동의수세보원』(1894). 1단계의 **이규준**(扶陽論)은 「두 손으로 해를 떠받침 = 扶」라는 미등재 동작에 기대므로 2순위로 내림. 판정 이제마 55 : 이규준 45 — 받쳐 드는 동작이 너무 의도적이라 이 판의 새 기호(扶)일 가능성이 남는다. 사상(四象)을 나르는 소품(넷 묶음)은 보이지 않음.
- **앞 거리 왼쪽** — 우물에 드리운 밧줄에 매달려 올라오는 사람 = **濟**(등재, 확정). 밧줄에 매달린 이는 하나뿐이라 **衆**(여럿이 매달림) 아님, 함께 당기는 무리가 없어 **同** 아님, 넓은 차양이 없어 **廣**도 등재 기호로는 안 나옴. 따라서 濟 + 벽돌 양관 + 훈장(국가·대한제국 표지로 추정, 미등재) → **광제원(廣濟院, 1900, 대한제국 내부 소속 국립병원, 한방·양방 병존)** 1순위, **제중원(濟衆院, 1885, 최초 서양식 국립병원 — 새싹 = 「최초」로 읽을 때)** 2순위.
- **앞 거리 오른쪽** — 두루마기 남자 + 양복·중절모 신사가 나란히 걸음. 밧줄이 없으므로 사전의 同으로는 읽히지 않음 → 1단계의 동제의학교 독해는 근거를 잃음. 남는 뜻은 「한의·양의 병존」(광제원 한·양 진료 / 동서의학) 정도이며, 빈 현판 한옥과 함께 오른쪽 이웃 띠 몫일 가능성.

**③ 잔결**: 해를 받쳐 드는 동작(扶?)·훈장(韓/帝?)·새싹(生/最初?) 세 개가 사전에 없어 표제어를 확정 못 하게 함. 濟 묶음에 廣/衆이 빠져 기관명 첫 글자가 비어 있음. 한옥 빈 현판. 이어붙임 흔적은 없음.
