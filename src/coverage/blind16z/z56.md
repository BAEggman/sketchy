# z56 판독 (blind16z)

## 1단계 — 생판 (사전 열기 전)

**① 시대**: 中 **元** / 韓 **高麗** — 80%. 가운데 흙길 뒤에 몽골식 게르(굴뚝마다 불꽃)가 줄지어 있어 유목 왕조 = 元(일부 金 가능). 아래 거리는 청기와 목조 가옥·평상·상투 튼 소년 = 고려풍(조선 초 가능성 소수).

**② 말하는 묶음**
- 뒤 강(본초): 강이 왼쪽에서 갈래(지류)가 합류·분기하는 모양뿐, 소품 없음 → 이 띠에서 말하는 본초서 없음(본초 계보의 「갈래」 표시일 수는 있음).
- 가운데 길 왼쪽: 금빛 둥근 메달(거울?)을 목에 건 학자 + 붓걸이에 큰 붓 4자루 + 책상 위 펼친 책 둘레에 노란 쪽지 10여 장 + 사다리 무늬 표지의 책. 표제어 후보 **敖氏傷寒金鏡錄**(금빛 원반 = 金鏡, 쪽지 = 설태 그림 36幅, 최초 설진 전문서) / 차선 **金元四大家** 총괄(금 메달 = 金, 붓 4 = 四大家) / **羅天益 衛生寶鑑**(寶鑑 = 보배 거울).
- 가운데 길 오른쪽(왼쪽 인물보다 뒤 = 늦은 활동): 호스로 눈송이 섞인 찬물을 돌화덕 속 큰 불에 퍼붓는 인물 → 표제어 **朱震亨(丹溪)** — 滋陰派(養陰派), 相火論 「陽常有餘 陰常不足」, 滋陰降火. 차선 **劉完素** 寒凉派(火熱論, 「六氣皆從火化」) — 눈송이(寒)가 寒凉을 가리킬 수 있으나 元 배경이면 丹溪 우선.
- 앞 거리(고려): 기와집 두 채, 흰 머리띠 두른 소년과 동행 소년이 걸어감. 머리띠 = 붕대 → **鄕藥救急方**(구급)? 확신 낮음. 뚜렷이 말하는 소품 없음.

**③ 잔결**: 강이 텅 빔(본초 소품 0). 게르 굴뚝 불꽃이 상징(火)인지 단순 배경인지 불명. 쪽지 개수(10여 장)·사다리 무늬 책·붓 4자루의 정확한 뜻 미확정. 아래 거리 두 소년과 왼쪽 회벽 창고형 건물은 뜻 없음(이웃 띠 몫일 가능성). 오른쪽 끝 화덕 물줄기가 화면 밖으로 잘려 이어 붙임 경계로 보임.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 시대**: 中 **金**(차선 元) / 韓 **高麗** — 60%. 사전으로 보니 오른쪽 인물은 寒凉派로 읽히고(아래), 그러면 무대는 金이다. 게르는 「북방 이민족 왕조」의 일반 표지로 보고, 元이면 朱震亨으로 바뀐다(35%).

**② 말하는 묶음**
- 가운데 길 오른쪽: 눈송이(寒) + 맑고 찬 물(淸)을 호스로 뿜어 불꽃(熱)을 끈다 = 寒凉으로 火熱을 다스림. 뒤편 게르 굴뚝마다 불꽃(熱) = 온 천지가 불 → 主火論. 표제어 **劉完素(河間)** — 寒凉派, 火熱論, 「六氣皆從火化」, 金元四大家의 첫째. 사전의 陰(얼음·졸아드는 고인 물)은 화면에 없으므로 滋陰派 **朱震亨**은 차선으로 내린다.
- 가운데 길 왼쪽(劉完素보다 앞 = 먼저 활동): 금메달 = 「최초」(1등), 펼친 원전 둘레에 빽빽이 붙인 쪽지 = 주석. 표제어 **成無己 『注解傷寒論』** — 『傷寒論』 전문에 처음 주를 단 책(『傷寒明理論』도 그의 저서). 금빛 원반을 거울로 보면 **『敖氏傷寒金鏡錄』**(최초의 설진 전문서)이 차선이지만, 혀(舌·苔) 기호가 없어 낮춘다. 붓 4자루는 사전에 없는 기호이며, 「四大家」를 예고하는 것일 수 있다.
- 뒤 강(본초): 소품 없음, 이 띠에서 말하는 본초서 없음.
- 앞 거리(고려): 기와집(寺 조건인 「절」 아님), 머리띠 소년 둘 — 太(테 넓은 큰 갓)·惠(빈 사발)·倉(곡식 가마니)·濟(밧줄) 어느 기호도 맞지 않는다 → 말하는 묶음 없음(1단계의 鄕藥救急方 추정은 철회).

**③ 잔결**: 붓걸이의 붓 4자루(끝 하나만 붉다)와 사다리 무늬 표지의 책은 사전에 없다. 불을 둘러싼 돌 우물형 화덕은 內(담 안쪽)로 읽힐 여지가 있지만 사실과 이어지지 않는다. 고려 거리의 소년 둘과 회벽 창고형 건물은 뜻이 없다. 강은 비어 있다. 오른쪽 끝의 물보라는 띠 경계에서 잘렸다.
