# z57 판독 (blind16z)

## 1단계 — 생판 (사전 열기 전 확정)

**① 시대**: 中國 **明** / 韓國 **朝鮮**(前~中期) — 85%. 강의 「그물 속 본초」와 거리의 기와집·흰 한복 소년이 근거.

**② 레인별 묶음**
- **강(본초)**: 부두에 등 돌리고 선 남자(손에 풀잎, 허리에 주황 둥근 열매) + 굵은 밧줄(綱)에 매단 그물코(目) 안 가득한 약초 → **本草綱目 / 李時珍**. 밧줄=綱·그물코=目으로 서명을 나르고, 허리의 둥근 열매=李(오얏), 물가에 선 자세=瀕湖(호).
- **흙길 왼쪽**: 콧수염 남자 + 말뚝에 맨 말(馬) + 말 등의 죽간 두 묶음(하나는 침이 꽂힘=鍼經/靈樞, 하나는 끈으로 묶음=素問) + 노란 천(黃帝) + 금메달 → **馬蒔** — 『素問注證發微』『靈樞注證發微』, 靈樞 전체를 「최초」로 주석.
- **흙길 오른쪽**: 갈색 옷 젊은 남자 + 눈송이(雪=薛, 설) + 가위(오려 냄=摘要) + 장작/죽간 더미 + 사다리 → **薛己** — 『內科摘要』, 溫補學派의 선구(장작=溫·사다리=첫 계단?). 차순위 후보: 사다리=入門 → **李梴『醫學入門』**.
- **앞 거리(朝鮮)**: 세워 둔 거대한 책 두 권 — 왼쪽 표지는 초가 마을+연기+약초 다발(=鄕藥), 오른쪽은 새·물고기·사슴·여우·호랑이(동물 약재의 부류 분류) → **鄕藥集成方**(世宗, 鄕藥本草 수록). 후보: 두 권=**醫方類聚**와 짝, 혹은 『東醫寶鑑』 湯液篇. 흰 한복 소년 둘과 격자창 집 → 의학 생도·교육 기관(典醫監?) 짐작뿐.

**③ 잔결**: 처마의 흰 등롱 두 개(뜻 모름), 강 뒤 대숲, 눈송이 옆 흩어진 널빤지, 사다리의 몫, 소품 없는 흰 한복 소년 둘. 오른쪽 끝 버드나무+잘린 사람은 이웃 띠 몫으로 무시.

## 2단계 — 계통 (blind6_사전요약 적용)

**① 시대**: **明 / 朝鮮** — 90%. 사전의 성씨 기호(李·馬)가 「무대가 어느 사람인지 진다」고 하니, 明 줄이라는 전제에서 바로 사람이 정해진다.

**② 레인별 묶음**
- **강**: 허리춤 자두 = 李(사전 확정 항목) + 明 본초 강 → **李時珍 『本草綱目』**. 밧줄+그물코 = 綱目은 사전에 없는 말장난이지만 1단계와 같다. (그물 밧줄이 물 위에 걸려 있으나 「물에 드리운 밧줄」이 아니니 濟는 아니다.)
- **흙길 왼쪽**: 사람 곁에 고삐로 매인 말 한 마리 = 馬(확정) → **馬蒔**. 침 꽂힌 죽간=靈樞(鍼經), 묶은 죽간=素問, 노란 천=黃帝 → 『素問·靈樞 注證發微』, 靈樞 첫 전체 주석. 노란 천은 김이 없으니 溫이 아니다. 금메달은 사전에 없고(華=빛나는 것과는 걸칠 뿐) 「최초」로 읽는다.
- **흙길 오른쪽**: 눈송이 = 寒(갈림: 外寒). 사람 곁에 크게 떠 있지 않고 땅에 놓였으니 병표지는 아니고, 「寒을 다루는 책」으로 읽힌다 → 傷寒. 그 곁의 **흩어진 널빤지(=어지러워진 죽간, 錯簡)** + **가위(잘라 다시 엮음)** + **가지런히 다시 묶은 죽간 더미** + **사다리(가로대의 순서=條)** → **方有執 『傷寒論條辨』, 錯簡重訂派의 시작**. 사전에 음차 기호가 없으므로 1단계의 雪=薛(**薛己**)는 차순위로 내린다.
- **앞 거리**: 사전 어휘(藥=약연, 典藥=약봉지 다발, 大=두 배 크기)와 맞는 것이 없다. 초가 마을+약초 다발=鄕藥, 새·물고기·짐승을 한 책에 모음=集成 → **鄕藥集成方** 유지(차순위 **東醫寶鑑** 湯液篇). 흰 한복 소년 둘은 사전으로도 풀리지 않는다.

**③ 잔결**: 등롱 두 개, 금메달, 대숲, 소년 둘+격자창 집은 사전으로도 뜻이 정해지지 않는다. 오른쪽 띠의 눈송이가 外寒 기호와 겹쳐 「병표지」로 오독될 위험이 있다.
