# z58 판독 (blind16z)

## 1단계 — 생판 (사전 없이)

**① 시대**: 중국 **金~元**(金元 시기, 몽골 게르 천막촌) / 한국 **高麗** — 확신도 80%.
근거: 흙길 배경이 게르(유르트)·천막 위 횃불 → 북방 유목 왕조(金·元). 아래 거리는 청기와 한옥·한복 → 고려.

**② 말하는 묶음 (레인별)**
- 강(본초): 오른쪽을 가리키는 **화살표 나무 팻말** + 책상에서 먹·종이로 쓰는 선비(오른쪽 끝에 걸쳐 있음). 팻말 = 「이끌어 간다」 → **張元素『珍珠囊』의 引經報使(歸經)** 후보, 또는 「펼쳐 이어감(衍)」→ **寇宗奭『本草衍義』**. 선비는 오른쪽 이웃 띠 몫일 수 있음.
- 흙길 ①: 말 고삐를 쥔 남자 + 사다리 각 칸마다 불꽃 **6개** → 「六氣가 모두 火로 化한다」= **劉完素(河間)** — 主火論·寒凉派. 말(午=火)도 火를 거드는 소품으로 추정.
- 흙길 ②: 등에 **활(弓 → 張)**을 멘 남자가 **빗자루로 쓸어냄**(下) + 게르 꼭대기에서 솟는 **김(汗)** + 공중에 날아가는 **사발(吐)** → **張從正(子和)** — 攻邪派, 汗·吐·下 三法.
- 거리(한국): 파란 책 표지 = 번개(急) + 물에 빠진 이들이 밧줄에 매달려 구조(救) → **『鄕藥救急方』**(현존 最古 향약 의서). 건물에 걸린 **집게·펜치로 엮은 새둥지**와 펜치 그림 꼬리표 → 「쌓아 갈무리함(藏)」→ 간행처 **大藏都監** 후보(확신 낮음). 머리띠 두른 행인·배경 인물 두 명은 의미 미상.

**③ 잔결**
- 새둥지(집게·펜치 재료)와 펜치 꼬리표의 뜻이 불분명.
- 말 탄 사람 아님 — 말만 끄는 남자의 「말」이 무엇을 나르는지 불명(火 보강으로 처리).
- 왼쪽 끝 돌우물 위 큰 불·파란 원형 물체, 오른쪽 끝 한복 남자·책상 선비는 이웃 띠에서 잘려 들어온 것으로 보고 제외.
- 게르 꼭대기 김 덩어리가 천/유령처럼 그려져 汗인지 애매.

## 2단계 — 계통 (사전 적용 후)

**① 시대**: 중국 **金**(~元 초) / 한국 **高麗 중기** — 80%. 게르는 북방 왕조 무대 표지. 아래 거리 의서 둘이 12~13세기 고려 것으로 풀려 金과 맞물린다.

**② 말하는 묶음 (다시 읽기)**
- 강(본초): 사전에 화살 팻말이 없음 → 1단계 그대로. 오른쪽을 가리키는 팻말 = 「이끎」→ **張元素『珍珠囊』 引經報使** 후보(확신 30%). 책상의 선비는 등이 안 보여 張(활)인지 확인할 수 없다. 오른쪽 이웃 띠 몫일 가능성이 크다.
- 흙길 ①: 「사람 곁에 고삐로 매인 말」= **馬**(성씨). 金元 무대라서 **馬宗素**(劉完素의 직전 제자, 『劉河間傷寒醫鑑』)다. 곁의 사다리 칸마다 熱(불꽃)이 6개 있다. 이는 「六氣皆從火化」를 한 칸씩 물려받는 **河間學派 火熱論**의 계승을 뜻한다. 1단계에서 말을 「午=火」로 본 것은 틀렸다.
- 흙길 ②: 등에 멘 긴 활 = **張**, 짚 빗자루 = **瀉** → **張從正(子和)**, 攻邪派·攻下. 게르 꼭대기로 솟는 김은 사전상 汗(살갗 땀방울)이 아니다. 「上(곧게 솟음)」+ 튀어나가는 사발 = **吐法**으로 보아 汗·吐·下 가운데 吐·下를 나르는 것으로 읽는다(사발은 확신 낮음).
- 거리(고려): 책 표지에서 한 밧줄에 여럿이 매달림 = **衆**, 물 위 밧줄에 매달려 건져짐 = **濟**, 번개 = 즉효(立效) → **『濟衆立效方』(金永錫, 고려 의종 무렵)**. 1단계의 鄕藥救急方은 철회한다. 처마의 새둥지(隹 → **崔**)를 집게·펜치로 엮었고 꼬리표에도 펜치(집어 냄 = **撮**)가 있다. 이를 관청 기와집(御醫)에 걸린 **崔宗峻『御醫撮要方』**(1226)으로 읽는다. 둘을 왼쪽→오른쪽으로 놓으면 연대 순서와도 맞는다.

**③ 잔결**
- 번개(立效)·새둥지(崔)·펜치(撮)·화살 팻말·사발은 사전에 없는 기호라 추정에 기댄다.
- 게르 위 김은 氣(서린 김)·上 사이에서 애매하다.
- 머리띠 두른 행인과 배경 두 사람은 뜻을 알 수 없다.
- 왼쪽 끝 돌우물 위 큰 불(熱)과 파란 원형, 오른쪽 끝 한복 남자는 이웃 띠에서 잘려 든 것이다.
