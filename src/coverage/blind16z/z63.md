# z63 판독 (blind16z)

## 1단계 — 생판 (사전 열람 전 확정)

**① 시대**: 北宋 말(徽宗 무렵, 1100~1120) / 高麗 중기(睿宗) — 확신 55%. 근거: 강의 「관인+새싹」(官修本草)·「분류함」(證類), 흙길의 「옷걸이에 걸린 약첩+관인」(官藥局 처방집), 거리의 「사발·약첩을 서민 아이들에게 내주는 가게」(구휼·施藥 기관)가 모두 1100년 전후 宋·高麗의 관 주도 의료로 수렴.

**② 묶음별 판독**
- 강(본초) 왼 나루 — 가부좌 선비 + 칸칸이 이름표 꽂힌 상자 + 검은 책: 분류(類)+경사 서적(經史) → **唐愼微 『經史證類備急本草』**(개인 저술, 이후 관찬의 바탕).
- 강 가운데 — 물 위 돌좌대, 아치형 돌(관인 손잡이 모양) 위에 새싹: 관(官)+본초 → **大觀本草/政和本草**(證類本草의 관찬 개정), 차순위 **開寶本草**(돌문=開).
- 강 오른 나루 — 길게 펼친 두루마리 + 빈 격자 틀 + 잎 문 비둘기: 길게 늘인 해설 → **寇宗奭 『本草衍義』**, 차순위 **蘇頌 『圖經本草』**(격자 틀=圖).
- 흙길 — 무 두 뿌리 묶음: 무=無 → **成無己** 혹은 **朱肱(無求子) 『類證活人書』**(불확실).
- 흙길 — 왕관 쓴 노인, 구릿빛 도포, 줄자: 王+측량(혈 자리 寸)+銅 → **王惟一 『銅人腧穴鍼灸圖經』**, 차순위 **宋 徽宗 『聖濟總錄』**(왕관=황제).
- 흙길 오른쪽 — 갓 쓴 사내, 옷걸이에 줄줄이 걸린 종이 약첩 + 걸대 위 관인: 미리 지어 둔 成藥+官 → **『太平惠民和劑局方』**(官藥局), 차순위 朱丹溪 『局方發揮』.
- 거리 오른쪽 — 사발·약첩 간판, 창구에서 사발을 아이들에게 건넴, 사발 그린 판자: → **惠民局**(高麗 睿宗 7년, 1112, 서민 施藥), 차순위 **濟危寶/東西大悲院**.
- 거리 왼쪽 — 건물 그림 간판 집 + 머리띠 소년 행인: 표제어 미상(관서 일반?).

**③ 잔결**: 비둘기가 앉은 빈 격자 틀(뜻 불명), 돌좌대 아치(관인인지 돌문인지 모호), 흙길 왼끝 연두 저고리 아이(가장자리 잘림 — 이웃 띠 몫, 錢乙?)와 무의 소속 불분명, 중국 레인 인물이 조선식 갓을 씀, 거리 왼쪽 「집 그림 간판」 뜻 불명.

## 2단계 — 계통 (blind6_사전요약 어휘로 재판독)

**① 시대**: 北宋 중~말(1026~1116 무렵) / 高麗 — 확신 60%. 사전으로 「太」「王」「惠」「典藥」이 확정되면서 흙길·거리는 북송 官藥局 ↔ 고려 惠民 계열의 위아래 짝으로 더 단단해졌다. 강·무는 사전에 없어 1단계 근거를 그대로 쓴다.

**② 묶음별 재판독**
- 흙길 오른쪽 — 테 넓은 큰 갓 = **太**(사전 확정). 옷걸이에 줄줄이 건 약첩(묶은 다발이 아니니 典藥은 아님) + 걸대 위 관인 → **『太平惠民和劑局方』**(宋 官藥局이 만든 成藥 처방집, 陳師文 등 1107~1110). 1단계에서 「갓」이 표지인지 몰랐던 부분이 풀렸다.
- 흙길 가운데 — 왕관 = **王** 성(어느 王인지는 무대가 정함). 무대가 宋이고 소품이 줄자(혈 자리 寸 재기)와 구릿빛 도포(銅)이므로 → **王惟一 『銅人腧穴鍼灸圖經』**(1026)과 鍼灸 銅人. 1단계의 「황제=徽宗」 안은 버린다(사전: 왕관은 성씨일 뿐).
- 흙길 왼쪽 — 세 뿌리를 끈으로 묶은 무: 사전에 없음. 地黃(검붉은 뿌리)은 아니다. 「무=無」, 「셋을 하나로 묶음=三因極一」이면 **陳無擇 『三因極一病證方論』**(三因說)이 들어맞지만, 1174년이라 王惟一보다 왼쪽에 있는 것과 활동 순서가 어긋난다. 이웃 띠 인물의 몫일 수도 있다.
- 거리 오른쪽 — 여러 손이 받아 드는 빈 사발 = **惠**, 간판의 사발(惠)과 끈 묶은 약봉지 다발(**典藥**) → **惠民典藥局**(高麗 恭讓王 3년 1391). 그 전신인 **惠民局**(睿宗 7년 1112, 서민에게 약을 줌)도 같은 계열이다. 받는 이들이 아이·서민인 것은 「民」으로 읽힌다.
- 강 왼쪽 — 칸칸 이름표 상자(분류) + 책(經史) → **唐愼微 『證類本草』**(사전 무관, 1단계 유지).
- 강 가운데 — 돌 문간(門/開) + 관인형 돌 + 새싹 → 官修本草 **大觀·政和本草**(證類本草의 관찬 개정), 차순위 **開寶本草**.
- 강 오른쪽 — 긴 두루마리 + 3층 선반 맨 위 칸의 비둘기 → **寇宗奭 『本草衍義』**(1116). 비둘기가 가운데 칸이 아니므로 官 갈림은 해당하지 않는다.

**③ 잔결**: 3층 선반 위 칸의 잎 단 비둘기(사전의 母/子 칸 문법은 舍岩 판용이라 여기선 뜻 불명), 세 뿌리 무(미등재·순서 어긋남), 거리 왼쪽 잘린 건물의 「기와집 간판」(=**寺**, 이웃 띠 몫, 典醫寺?)과 머리띠 소년(뜻 불명), 흙길 왼끝 연두 저고리 아이(가장자리에서 잘림).
