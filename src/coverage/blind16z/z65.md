# z65 판독 (blind16z · 말판 ④줄 明 / 앞거리 朝鮮)

## 1단계 — 생판 (사전 열기 전, 확정)

**① 시대**: 明 後期(16세기 후반~17세기 초) / 朝鮮 中期(宣祖~仁祖 무렵) — 60%. (明/朝鮮 자체는 말판 문법상 90%. 정자 속 인물들의 모자가 明 사인의 높고 검은 四方平定巾, 꼭지 달린 瓜皮帽라서 가운데 줄=明 의가로 읽었다.)

**② 레인별 묶음**
- 강(本草): 빈 물결뿐. 왼쪽 끝의 소용돌이 하나 말고는 소품 없음 → 이 띠에는 본초서가 없음.
- 흙길(明) ㉠ 회색 옷에 높은 검은 관을 쓴 사람 + 불 땐 부뚜막(위에 솥 자리) = 「솥 밑의 불」(釜底之火·命門火) → **溫補學派** (**趙獻可** 『醫貫』 命門 / 또는 **薛己**·**李中梓** 脾腎).
- 흙길 ㉡ 파란 옷 + 활(弓)·전통(화살) + 놀라 부릅뜬 눈 + 탕 그릇·끈 매는 천 보따리 → 弓+長 = **張介賓**(景岳). 화살·군장 = 『景岳全書』 **新方八陣·古方八陣**, 천 보따리 = 補(溫補), 탕 = 처방. 대안으로 弓=龔 → **龔廷賢**(『萬病回春』).
- 흙길 ㉢ 갈색 옷 + 사람 키만 한 책 더미 두 개 → 대형 분류·집성서: **類經**(張介賓, 내경 분류) 또는 **王肯堂 『證治準繩』**·**朱橚 『普濟方』**.
- 정자 앞 턱(흙길/거리 경계) ㉣ 흰 옷 어른·아이가 붉은 물 단지를 안음, 어른 단지에 검은 점 하나 → 붉은 물(赤水)+검은 구슬(玄珠), 아이=孫 → **孫一奎 『赤水玄珠』**(命門動氣). 흰 옷이라 조선 쪽이면 **惠民署**(서민에게 약 팔기)일 수도.
- 앞거리(朝鮮) ㉤ 문 활짝 연 기와집(살창) + 머리띠 맨 남자·한복 여인·안을 들여다보는 남자 → 서민에게 열린 관청: **惠民署** 또는 **活人署**, 여인은 **醫女**.

**③ 잔결**: 강 왼쪽 소용돌이(무언가 빠진 자국?), 정자 뒤 담장 안 나무 궤짝(평상?)과 오른쪽 끝 흰 기둥은 뜻 모름(이웃 띠 몫일 수 있음). 정자(明 줄)에 흰 옷 조선 사람이 앉은 것은 레인을 넘어 이어 붙인 흔적 같다. 앞거리 집에는 「말하는」 소품이 없어 표제어를 정할 수 없다.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 明 後期 / 朝鮮 中期(宣祖~仁祖) — 75%. 사전에 「張 = 등에 멘 긴 활, 어느 張인지는 무대가 정한다(明 서점↔金元)」라고 되어 있다. 책 더미를 쌓은 정자는 「明 서점」 무대로 읽히니, 이 張은 明의 張이다.

**② 레인별 묶음**
- 강: 기호 없음.
- 흙길(明 서점) ㉡ 등에 활을 멘 파란 옷 = 張 → **張介賓**. 곁의 「찰랑 찬 따뜻한 국물 그릇」 = 補, 접힌 천 = 溫(김이 분명치 않아 반쯤 확신) → **溫補學派**. 부릅뜬 눈은 사전상 目이지만 張介賓과 맞는 사실이 없다.
- ㉢ 책 더미 둘(큰 것·작은 것) + 갈색 옷 = 서점 무대. 張 곁이니 **類經**·**景岳全書** 두 책으로 읽는다. 이름 기호가 없으니 독립 의가는 아님.
- ㉠ 회색 옷 + 아치형 아궁이 문(門) 속의 불(陽) + 가는 김(氣) = 命門之火. 이름 기호 없음 → 張介賓의 **「陽非有餘」·命門** 부속이거나 溫補 계열 **趙獻可**(『醫貫』). 1단계보다 약해짐.
- ㉣ 흰 옷 어른·아이 + 붉은 것(血)이 가득 찬 단지 = 補-b 「血을 채워 줌」 → 補血. 단지가 1:2 크기라 大, 검은 알갱이 = 瘀(그릇 속이라 갈림 조건 충족). → 張介賓 **眞陰不足·大補(大補元煎)** 묶음으로 읽힌다. 1단계의 **孫一奎 『赤水玄珠』**(赤水+玄珠)는 사전 밖 말장난이라 2순위로 내린다.
- 앞거리(朝鮮) ㉤ 문 열린 기와집 + 서민 셋. 惠(빈 사발)·濟(밧줄)·典藥(약봉지 다발)·廣(차양)·太(큰 갓) 어느 것도 없다 → 惠民署·濟生院·典藥署로 읽을 근거가 없고, 배경이거나 오른쪽 이웃 띠 몫이다. 표제어 없음.

**③ 잔결**: 사전으로 더 잘 풀린다(張·補·血·大가 확정됨). 그래도 남는 것: 화살 전통, 부릅뜬 눈(目?), 張 손의 흰 종이 뭉치(溫인지 약봉지인지 모름), 강 왼쪽 소용돌이, 정자 뒤 나무 궤짝. 明 서점에 흰 옷 조선 사람이 앉은 것은 레인 경계를 넘어 이어 붙인 흔적이다.
