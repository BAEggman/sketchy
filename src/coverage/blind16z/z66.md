# z66 판독 (말판 ③줄 宋·金·元 세로 띠)

## 1단계 — 생판 (사전 없이)

**① 시대**: 金·元(특히 元) / 高麗 후기 — 70%. 붉은 시내(丹溪)·「王」관을 쓴 노인이 金元 후반 의가를 가리키는 듯하고, 아래 거리의 녹색 도포·두건 인물과 기와집은 高麗식으로 읽힌다.

**② 묶음별 판독**
- 강(위): 소품 없음. 빈 물결과 모래톱뿐이다 → 이 구간에는 본초서가 없다(또는 이웃 띠 몫).
- 흙길 ⓐ 풀 덮인 흙무덤 위 미끄럼틀을 타고 내려오는 아이: 아이 = 「子」, 미끄러져 내려감 = 「下」 → **張從正(張子和)** — 攻下派(汗·吐·下 三法 중 下). 흙무덤(土)은 補土(**李杲**)로 읽힐 여지도 있다.
- 흙길 ⓑ 나무 기둥 빨랫줄에 널어 말리는 흰 천 + 종이·상자가 놓인 나무 궤: 젖은 천 = 汗(汗法)? 또는 杲(해 日 + 나무 木) = **李杲**? 궤 위 종이는 서명(書) 소품 같으나 확정 못 함.
- 흙길 ⓒ 바닥을 구불구불 흐르는 붉은 줄: 붉을 丹 + 시내 溪 → **朱丹溪(朱震亨)** — 滋陰派(養陰派), 「陽常有餘 陰常不足」.
- 흙길 ⓓ 금관(王)을 쓴 흰 수염 노인(옛 古), 뒷짐, 빛 테두리: **王好古** — 易水學派(李杲 제자), 『陰證略例』·『湯液本草』. 차선 王履(『醫經溯洄集』).
- 거리(아래) ⓔ 검은 두건·녹색 포 차림 사내가 펼친 책: 뾰족한 삼각형 여러 개 + 맥박 파형(심전도 곡선) → 「급함·구급」 → **鄕藥救急方**(현존 最古 우리 의서). 삼각형 = 三 으로 읽으면 **三和子鄕藥方**.

**③ 잔결**: 왼쪽 끝 흰 한복·상투 아이(빛 없음, 잘리지 않음)의 몫 불명. 아래 건물 오른쪽 모서리의 반짝 별 무늬 뜻 불명. 빨래 줄과 궤가 한 묶음인지 둘인지 불분명. 붉은 줄이 건물 뒤에서 나와 왕관 노인 발치까지 이어져 丹溪와 王의 경계가 이어 붙은 듯하다.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 시대**: 金·元(南宋 말 포함) / 高麗 후기 — 70% (1단계 유지). 사전으로 확정되는 시대 기호는 없고, 「王」과 아래 거리의 구급 의서가 시대를 떠받친다.

**② 묶음별 재판독**
- 강: 소품 없음 — 그대로.
- 흙길 ⓐ 미끄럼틀 아이: 「아래로 쏟아짐」 = **下** 가 사전으로 맞는다 → 攻下 = **張從正(子和)** 유지. 다만 사전의 張(등에 멘 긴 활)이 없어 성이 표시되지 않았고, 흙무덤 = 土(補土) 읽기는 李(허리춤 자두)가 어디에도 없어 버린다. 차선은 아이 = 小兒 → **錢乙**(『小兒藥證直訣』).
- 흙길 ⓑ 빨랫줄 흰 천 + 나무 궤: 사전에서 汗은 「살갗에 맺힌 땀방울」이고 膈은 「기둥 넷 사이에 팽팽히 친 흰 천」이라 둘 다 아니다(기둥 둘, 천이 늘어짐). 풀리지 않는다. 사전 밖 추정은 洗(빨래)+궤(관) → 宋慈 『洗冤集錄』(最初의 法醫書)이지만 근거가 약하다.
- 흙길 ⓒ 붉은 줄: 사전대로면 붉은 것 = **血**. 丹溪로 읽는 것은 사전 근거가 없어 확신을 낮춘다. 왼쪽 가장자리까지 이어지므로 말판의 길 표시이거나 이웃 띠 몫일 수 있다.
- 흙길 ⓓ 왕관 노인: 사전대로 성이 **王**인 것까지만 확정된다. 「어느 王인지는 무대가 진다」는 규칙에 따라 宋金元 흙길의 오른쪽 끝(후대)이고 붉은 시내가 시작되는 곳에 서 있으므로 → **王履**(朱丹溪 문인, 『醫經溯洄集』의 溯洄 = 거슬러 오름, 溫病≠傷寒)와 **王好古**(易水學派, 『陰證略例』·『湯液本草』)가 동률이다. 사실을 나르는 곁 소품은 없다.
- 거리 ⓔ 두건 사내 + 책: 사전 어휘 중 맞는 것이 없다(腎 잠수부는 고글·잠수복이 없어 아님). 1단계 그대로 맥박 파형 = 救急, 피라미드형 삼각 = 最古, 승려 두건 = 大藏都監 간행 → **鄕藥救急方**(현존 最古 우리 의서). 뒤 기와집을 寺(절 한 채) → 典醫寺로 볼 여지가 있으나, 모든 레인에 기와집이 있어 배경으로 판단한다.

**③ 잔결**: 왼쪽 흰 한복 아이와 오른쪽 아래 반짝 별(지운 소품의 흔적 같음)은 몫이 불명이다. 빨래·궤는 사전으로 해독되지 않는다. 붉은 줄은 왼쪽 가장자리에서 잘려 이어 붙인 흔적이 있다. 결론: 사전으로 더 잘 풀리는 것은 下·王 둘뿐이고, 丹溪 읽기는 오히려 약해졌다.
