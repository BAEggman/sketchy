# z73 판독 (blind16z)

## 1단계 — 생판 (사전 없이)

**① 시대**: 明 (16세기 후반) / 朝鮮 (전기, 세종~선조) — 확신 88%. 흙길 인물이 明式 검은 관모·團領, 앞 거리는 기와 관아·흰 한복 아이(조선).

**② 레인별 묶음**
- **강(본초)** — 강을 가로질러 친 그물: 위 굵은 벼리줄(綱)+그물코(目), 코마다 풀잎(本草)이 걸림 → **本草綱目**. 그물 끝을 잡은 부두 위 남자(뒷모습)는 허리에 둥근 열매(李=자두)·손에 풀잎 → **李時珍**. 사실: 그물로 온 약초를 다 건져 올림 = 집대성(1,892종·綱目體 분류).
- **흙길 왼쪽** — 회색 도포 남자가 보랏빛 자두(李)를 들고, 곁에 문틀만 선 빈 문(門 → 들어가는 문 = 入門)과 바닥의 긴 통나무(梴 = 긴 나무) → **李梴 『醫學入門』**(1575, 입문서).
- **흙길 가운데** — 소품 없는 수염 난 청포 남자 + 말(馬) 한 필: 등에 침이 꽂힌 판 묶음(鍼經=靈樞)과 끈으로 묶은 책판 묶음(素問), 노란 안장보(黃帝), 가슴의 금메달(최초) → **馬蒔** 『黃帝內經 素問·靈樞 注證發微』, 「靈樞 전문을 최초로 주석」. 대안: 침+책 묶음+금메달(大成) → **楊繼洲 『鍼灸大成』**.
- **앞 거리(조선)** — 크게 펼쳐 세운 책 두 쪽: 왼쪽 표지 = 초가 마을(鄕)+약초 다발(藥), 오른쪽 = 꽃·열매·잎·뿌리를 칸칸이 분류한 격자 → **鄕藥集成方**(1433, 향약 집대성; 오른쪽 격자 = 향약본초 부문). 격자를 달력(月令)으로 보면 **鄕藥採取月令**(1431)도 후보.
- **앞 거리 왼쪽 관아** — 담장 안 기와집 현판에 원통(끝에서 선이 뻗음 — 침통?)·담 앞 목판에 약연(藥碾)과 공이 → 약을 갈아 백성에게 주는 관청 **惠民署(惠民局)** 추정, 침통이면 **典醫監** 가능.

**③ 잔결**: 가운데 청포 남자가 아무것도 들지 않아 말과의 관계가 모호(말이 그의 이름표인지 별개 묶음인지). 관아 현판 원통(침통·두루마리·폭죽?) 뜻 불명. 강 건너 대숲 의미 없음(배경?). 오른쪽 가장자리 나무 판자 더미·흰 한복 아이는 이웃 띠 몫으로 무시.

## 2단계 — 계통 (blind6_사전요약 어휘로 재판독)

**① 시대**: 明 / 朝鮮 전기 — 확신 92%. 李·馬 성씨 기호는 「어느 李·馬인지는 무대가 진다」는 갈림이 붙어 있어, 明 흙길·本草 강·조선 거리라는 무대가 1단계 시대 판정을 그대로 받쳐 준다.

**② 레인별 묶음**
- **강(본초)** — 부두 남자의 **허리춤 자두 = 李**(사전 등재와 정확히 일치) + 明의 본초 강 → **李時珍**. 그물(벼리 綱 + 그물코 目)에 걸린 풀잎 = **本草綱目**(약초를 그물로 다 건짐 = 집대성). 사전에 綱目 기호는 없으므로 이 부분은 1단계와 같이 그림 뜻으로 읽음.
- **흙길 왼쪽** — 손에 든 자두를 허리춤에 댐 = **李**, 곁의 빈 문틀 = **門**(사전: 작은 문간) → 「門에 들어서는 李」 = **李梴 『醫學入門』**. 바닥의 긴 통나무는 사전에 없음 — 梴(긴 나무) 글자풀이로 읽으면 이름까지 맞음.
- **흙길 가운데** — 남자 곁 말뚝에 **고삐로 매인 말 한 마리 = 馬**(사전 일치) → 明 무대에서는 **馬蒔**. 말 등의 짐: 침이 꽂힌 판 묶음 = 鍼經(**靈樞**), 끈으로 묶은 책판 = **素問**, 노란 안장보 = 黃(帝) → 『**素問注證發微**·**靈樞注證發微**』, 금메달 = 「**靈樞 전문 최초 주석**」. 馬 기호가 확정되어 1단계의 楊繼洲 대안은 버림.
- **앞 거리 왼쪽 관아** — 담장 목판의 배 모양 약연 = **藥**(사전 일치), 현판 건물이 담 안쪽 = **內**(사전: 담 안쪽) → 內+藥 = **內藥房 → 內醫院**(세종 1443 개칭). 현판 원통(끝에서 선이 뻗는 통)은 사전에 없음 — 화살통(匚+矢 = 醫의 字源)으로 보면 「醫」. 惠(빈 사발 여러 손)·典藥(약봉지 다발) 기호가 없으므로 惠民署·典藥監은 후순위.
- **앞 거리 책** — 사전에 鄕·集成 기호 없음. 그림 뜻대로 초가 마을(鄕)+약초 다발(藥) 표지, 꽃·열매·잎·뿌리 분류 격자 → **鄕藥集成方**(1433) 유지, 격자를 月令으로 보면 **鄕藥採取月令**. 두 권이 같은 크기라 大(하나가 두 배) 아님.

**③ 잔결**: 강의 그물 윗줄이 물 위에 드리운 밧줄이라 사전의 **濟**(물에 드리운 밧줄)로 샐 위험 — 건져지는 사람이 없어 濟는 아님. 금메달·통나무·관아 현판 원통은 사전 어휘 밖이라 글자 확정 불가. 강 건너 대숲은 의미 없음. 오른쪽 가장자리 판자 더미·흰 한복 아이는 이웃 띠 몫.
