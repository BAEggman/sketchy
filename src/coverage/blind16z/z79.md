# z79 판독 (③줄 宋·金·元 구간, 세로 띠)

## 1단계 — 생판 (사전 열기 전)

**① 시대**: 중국 **金·元**(金元四大家 구간) / 한국 **高麗** — 확신도 85%. 근거: 가운데 길 뒤의 몽골식 게르(북방 유목 왕조 = 金·元), 거리의 기와집은 조선 이전 고려 거리로 봄.

**② 레인별 묶음**
- **강(본초)** — 강가 서안에서 붓을 든 학자. 탁자 위 진주 알이 비어져 나온 보라 주머니 = 珍珠囊, 뒤의 「주기율표」 모양 약장 = 元素 → **張元素《珍珠囊》**. 약장 칸마다 약초+흰 비둘기(전령), 꼭대기 깃발, 왼쪽 화살표 이정표 = 약을 경락으로 「끌고 가는」 → **引經報使·藥物歸經** 학설. (易水學派 개조)
- **길 ①(좌)** — 곱슬머리 남자+말(왼쪽 가장자리 일부 잘림) 옆 사다리, 가로대 6칸마다 불꽃 = 六氣皆從火化 → **劉完素** 火熱論·寒涼派(추정, 사람 자체는 이웃 띠 몫일 수 있음).
- **길 ②(중)** — 활을 멘 비질꾼: 활 = 弓+長 = **張**, 빗자루로 쓸어냄 = 攻邪. 게르 지붕에서 김이 솟고(汗) 사발이 위로 튀고(吐) 빗자루가 아래로 쓺(下) → **張從正(子和)** 攻下派·汗吐下 三法(《儒門事親》).
- **길 ③(우)** — 노인이 허리춤에 붉은 자두(李), 곁에 흙담(垣)에 새싹이 위로 돋고(升陽), 흙 아궁이(土)와 노란 곡식 그릇·숟가락(脾胃·飮食) → **李杲(東垣)** 補土派 《脾胃論》, 升陽益氣(補中益氣).
- **거리(한국)** — 고려풍 기와 거리. 왼쪽 노점에 물결무늬 파란 간판과 「八/人」 모양 나무패, 머리띠 맨 남자. 뜻이 분명히 서지 않음 → 고려 의료기관(**惠民局**? 藥局?) 후보, 확신 낮음.

**③ 잔결**: 거리 레인은 말을 하는 묶음이 사실상 없음(빈 거리처럼 보임). 노점 간판(물결·「八」자 패)과 머리띠 남자의 뜻 불명. 곱슬머리+말 인물은 왼쪽 이웃 띠와 이어 붙은 듯. 오른쪽 아래 반짝이 별 = 생성 워터마크. 게르 오른쪽에 회색 건물이 하나 더 겹쳐 있음(이어 붙임 흔적 가능).

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 중국 **金·元** / 한국 **高麗** — 88%. 사전의 성씨 기호(張=멘 활, 李=허리춤 자두)가 「무대가 어느 張·李인지 정한다」고 했고, 게르 무대에서는 金元 쪽으로 갈린다(明 서점 아님). 확신이 조금 오름.

**② 레인별 재판독**
- **강(본초)** — 사전에 「元素」·「珍珠囊」 기호는 없다. 진주가 비어져 나온 보라 주머니는 收(굵은 삼베 자루)와 재질·내용이 달라 收로 읽지 않는다 → 그대로 **張元素《珍珠囊》**. 단, 이 사람에게는 張 표지(멘 활)가 없어서 성은 「元素」(주기율표) 하나가 지고 있다. 비둘기집(pigeonhole) 칸마다 약초를 나눠 넣은 것 = 약마다 제 경락 칸이 있다 → **藥物歸經**. 깃발+오른쪽 화살표 이정표 = **引經報使**. 확신 75%.
- **길 ①(좌)** — 고삐를 쥔 남자+말 = 사전의 **馬**(성 馬). 金元 길에서 馬씨 표제어는 마땅치 않다(굳이 고르면 **馬丹陽** 天星十二穴, 약함). 말 앞부분이 왼쪽 밖으로 잘려 이웃 띠 몫으로 본다. 사다리의 불꽃 6 = 熱×6 → 六氣皆從火化 → **劉完素** 火熱論·寒涼派. 다만 劉를 가리키는 기호가 없어 이웃 띠에서 넘어온 소품일 수 있다.
- **길 ②(중)** — 멘 긴 활 = **張**(사전 확정), 짚 빗자루 = **瀉**. 게르 꼭대기의 흩날리는 흰 김·천(發散/溫 → 汗), 곧게 튀어 오르는 사발(上 → 吐), 빗자루(瀉 → 下) → **張從正** 攻邪派(攻下派), 汗吐下 三法. 1단계보다 확실해짐(85%).
- **길 ③(우)** — 허리춤 자두 = **李**(사전 확정) → **李杲**. 노란 곡식을 가득 담은 그릇 = 補-b(채워 주는 것이 노란 곡식 = 脾土) → **補土派**. 흙담 = 垣 → 東垣(소리 그대로 말장난). 흙담 위로 곧게 돋는 새싹 = 升陽. 담 안쪽(內)에 놓인 흙 아궁이(土) → 「內傷脾胃」·《**內外傷辨惑論**》까지 읽힐 여지 있음. 대표 의서는 《**脾胃論**》. 확신 85%.
- **거리(고려)** — 사전 기관 기호(惠=여러 손이 받드는 빈 사발, 濟=밧줄, 太=큰 갓, 藥=약연, 典藥=약봉지 다발, 寺=절)는 하나도 보이지 않는다. 노점의 파란 간판은 물결무늬가 아니라 뭉개진 가짜 글자이고, 三峯(같은 높이 봉우리 셋)도 없어서 鄭道傳 대입은 기각한다. 머리띠 남자와 「八」자 나무패도 사전에 없다. → 표제어 **없음**(빈 거리이거나 이웃 띠 소품).

**③ 잔결**: 거리 레인에 사실을 나르는 묶음이 없다. 노점 간판은 가짜 글자, 「八」 모양 패는 뜻 불명. 馬 인물과 불꽃 사다리는 왼쪽 경계에 걸려 있다(이어 붙임). 게르 뒤에 회색 집이 겹친다. 오른쪽 아래에 생성 워터마크(반짝이 별)가 있다. 張元素에게만 張 기호(활)가 빠져 있어 사전과 어긋난다.
