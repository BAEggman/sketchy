# z81 판독 (blind16z)

## 1단계 — 생판 (사전 없이)

**① 시대**: 明 / 朝鮮 전기 — 80%. 흙길의 망건·직령 차림 두 사람, 뒤 거리의 기와집과 흰 한복 아이들이 明–朝鮮 짝을 가리킨다. 다만 흙길 독해(만명 16–17세기)와 앞 거리 독해(세종대 15세기)가 시기상 어긋나 띠 안 시점은 확정하지 못한다.

**② 말하는 묶음 (흰 테두리로 떠오른 인물 기준)**
- 강(본초): 파란 도포를 입고 등을 보인 채 나루(잔교) 끝에 선 사내. 손에 푸른 약초 잎, 허리 뒤에 붉은 둥근 열매(또는 호로병). 물가에 섰으니 號 「瀕湖」 → **李時珍 《本草綱目》**(1578). 뒤쪽 대숲과 밧줄 다리(綱=벼리 줄?)가 「綱目」을 받치는 것 같지만 약하다. 차순위: **朱橚 《救荒本草》**(들풀 잎·열매 = 구황 식물).
- 흙길 ①: 갈색 도포 사내. 곁에 끈으로 묶은 죽간 다발(매듭이 반짝임), 흩어진 낱 죽간 조각, 가위. 경전을 잘라서 갈래별로 다시 묶었다는 뜻 → **張介賓 《類經》**(《內經》을 분류해 다시 엮음). 차순위: **李中梓 《內經知要》**(가위 = 절요), **王肯堂 《證治準繩》**(끈 = 繩).
- 흙길 ②: 회색 도포 사내. 뒤에 수양버들(楊), 침을 쌓아 올린 지붕 달린 탑(침구를 집대성), 둘레에 흰 깃발 수십 개 → **楊繼洲 《鍼灸大成》**(1601). 차순위: **高武 《鍼灸聚英》**(깃발이 모임 = 聚).
- 앞 거리 ①: 약초 잎과 인삼 뿌리를 그린 집채만 한 책 + 흰 옷 상투 아이 → **《鄕藥集成方》**(1433, 향약 집대성). 시골 아이 = 鄕.
- 앞 거리 ②: 흰 옷 아이 + 격자 달력에 날짜 하나 ○ + 금빛 둥근 메달 → **《鄕藥採取月令》**(1431, 달마다 캐는 시기). 금빛 원반 = 月로 읽었다.

**③ 잔결**: 강 왼쪽 x≈201에 세로 이음선이 또렷하다(물빛이 단절되어 나루 사내 부분을 덧붙인 흔적). 왼쪽 가장자리에서 잘린 말(노란 안장깔개, 죽간 다발, 초롱)은 이웃 띠 몫으로 보고 제외했다(읽는다면 馬蒔 《素問·靈樞注證發微》). 반짝이는 매듭, 흰 깃발, 금메달은 뜻이 확실하지 않고, 격자판 위의 금속 고리도 정체를 모르겠다.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 明 / 朝鮮 — 85%. 강의 인물에 성씨 기호 李가 확인되어 明 본초서 쪽 확신이 올라갔다. 앞 거리의 시점(15세기 세종대인지 17세기 초인지)은 여전히 열려 있다.

**② 묶음별 재판독**
- 강(본초): 사내 허리춤의 붉은 둥근 열매는 사전의 **李 = 허리춤 자두**와 정확히 맞는다. 손에 든 약초 잎은 본초를 뜻한다. 李가 「어느 李」인지는 무대가 정하는데, 무대가 明 본초 강이므로 → **李時珍 《本草綱目》**. 물가 나루에 선 것은 號 瀕湖로 덧읽을 수 있다. 1단계의 1순위가 사전으로 확정되었고, 차순위였던 救荒本草는 버린다.
- 흙길 ①(갈색 도포): **張 = 등에 멘 긴 활**이 없고 李(자두)·王(왕관)·吳(큰 입)도 없다. 성씨 기호가 비어 있으므로 張介賓 독해는 약해진다. 가위·묶은 죽간·흩어진 낱 죽간은 사전에 없는 소품이다. 반짝이는 매듭은 華(빛나는 것)에 걸리지만 이 묶음에서 華가 무슨 일을 하는지 풀리지 않는다. 남은 후보는 「잘라 다시 엮은 경전」 → **張介賓 《類經》**(활이 빠져 감점), 그리고 가위를 외과 기구로 읽은 **陳實功 《外科正宗》**. 판정 보류.
- 흙길 ②(회색 도포): 사전에 버드나무나 침 기호는 없다. 지붕 얹은 침 탑은 寺(절 한 채)가 아니다. 무등재 그림말이 그대로 → **楊繼洲 《鍼灸大成》**(버들 = 楊, 침을 쌓은 탑 = 침구 집대성). 흰 깃발은 여전히 미해석.
- 왼쪽 끝의 말: **馬 = 사람 곁에 고삐로 매인 말**이어야 하는데, 띠 안에서 고삐도 머리도 잘렸다. 이웃 띠의 몫이 맞다(그쪽에서 馬가 서면 馬蒔 《注證發微》 후보). 말 발치에 흩어진 죽간도 그 묶음에서 쏟아진 것일 수 있다.
- 앞 거리: 사전 어휘로는 새로 풀리는 것이 없다. 흰 옷 아이들은 肺(흰 도포 재상)가 아니다. 가운데 작은 집과 오른쪽 큰 집이 나란해 **大**(하나가 두 배)로 읽을 여지가 약간 있다. 1단계의 **《鄕藥集成方》**(약초·인삼을 그린 큰 책)과 **《鄕藥採取月令》**(○ 친 격자 달력)을 유지한다.

**③ 잔결**: 강 x≈201의 세로 이음선(나루 사내 덧붙임). 가위·죽간 다발·흰 깃발·금메달·격자판 고리는 사전에 없는 무등재 소품이다. 갈색 사내는 성씨 기호가 빠져 표제어를 확정하지 못한다.
