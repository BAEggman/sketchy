# z88 판독 (③줄 宋·金·元 세로 띠)

## 1단계 — 생판 (사전 열기 전 확정)

**① 시대**: 元 / 高麗 — 85%. 흙길 뒤 몽골 게르(유르트) 무리 = 元. 아래 거리는 청기와 한옥 = 고려(13세기 향약 의서와 맞물림). 金末元初도 범위 안.

**② 레인별 묶음**
- **강(본초)** — 금관(王) 쓴 노인(古) = **王好古**. 녹슨 청동 솥 안에 얼음, 화로 위에서 데움 = 끓여 물로 만듦 → 《**湯液本草**》. 얼음(寒)과 낮 하늘 초승달(陰)을 불로 데움 → 《**陰證略例**》(陰證을 溫補로 다스림)을 겹쳐 실은 듯.
- **흙길 ①** — 쪽찐 머리, 연녹색 도포 인물이 쟁반(盤)에 둥근 나침반을 받쳐 들었고, 그 바늘이 손잡이 고리 달린 호침(鍼)이다. 옆에는 음표 두루마리(歌·賦)가 있다. 鍼 + 指南(나침반) = 《**鍼經指南**》, 노래 두루마리 = 《**標幽賦**》. 그래서 **竇漢卿(竇默)**이 1순위다(金元, 流注八穴). 2순위는 다이얼을 시계(時辰)로 읽어 **何若愚 《子午流注鍼經》**(流注指微賦)으로 본 것이다. 인물이 여성으로 보이는데 이름과 어떻게 이어지는지는 못 풀었다.
- **흙길 ②** — 맨발에 누더기 차림의 소년이다. 덧붙은 소품은 없다. 아이(兒)로 읽어 소아과 의가를 가리킨다고 보면 **曾世榮 《活幼心書》**(元)이나 **錢乙**이 후보다. 확신은 낮다(30%).
- **거리(한국)** — 초록 십자(救急)와 풀잎(鄕藥)이 그려진 흰 책 = 《**鄕藥救急方**》. 책에 매달린 금메달 = 「현존 最古」 우리 의서. 빈 나무 선반(판목 시렁, 藏) = **大藏都監** 간행. 고려 고종 때다.

**③ 뜻 모를 것·이음 흔적**
- 유르트 사이에 청기와 한옥 정자 하나가 섞여 있다(거리 레인 양식이 번진 것인지, 원 간섭기 고려를 뜻하는지 모르겠다).
- 낮 하늘의 초승달이 소품인지 배경인지 애매하다.
- 소년에게만 소품이 없다.
- 여인 뺨에 검은 자국이 있다.
- 흙길 오른쪽 끝에 붉은 선이 있다(이웃 띠 몫).
- 오른쪽 아래 돌길에 흰 네모별 반짝이가 있다(생성 워터마크로 보임).
- 오른쪽 가장자리의 잘린 흰옷 인물은 이웃 띠 몫이라 판독에서 뺐다.

## 2단계 — 사전(blind6_사전요약) 어휘로 다시 읽기

**① 시대**: 元 / 高麗 — 85% 유지. 사전에 시대 기호는 없다. 「王은 성까지만, 어느 王인지는 무대가 진다」는 규칙 때문에 무대(게르 = 元)의 비중이 오히려 커졌다.

**② 레인별 묶음**
- **강(본초)** — 왕관 = 王(성만 나른다). 무대가 元이고 본초 강이니 **王好古**로 확정했다(노인 = 好古 보조). 얼음 덩이가 **살아 있는 불**(화로 숯불)과 맞대어 있어 갈림 조건이 충족되므로 陰이다. 그래서 「陰證」 = 《**陰證略例**》(陰證論, 溫補)로 읽힌다. 1단계보다 근거가 단단해졌다. 솥 안의 얼음은 「담는 것 안에 담긴 것 = 會」로도 읽히지만 王好古에 맞는 뜻이 없어 버렸다. 솥에 데워 끓인다 = 《**湯液本草**》는 사전 밖 연상이라 확신을 60%로 낮췄다.
- **흙길 ①** — 사전 기호가 하나도 걸리지 않는다. 張(활)·李(자두)·馬(말)·吳(큰 입)이 없으니 張元素·李杲·張從正 계열은 아니다. 침이 살이 아니라 다이얼에 꽂혀 있어 痛도 아니다. 뺨의 검은 자국은 살갗 위 얼룩이라 瘀가 아니다(갈림). 1단계와 같이 鍼 + 나침반(指南) + 노래 두루마리(賦) = **竇漢卿 《鍼經指南》·《標幽賦》**(2순위 何若愚 《子午流注鍼經》)로 둔다. 이 묶음은 사전 밖이라 독자가 못 풀 위험이 크다.
- **흙길 ②** — 맨발 누더기 소년 뒤의 청기와 정자가 사전의 寺(기와지붕 절 한 채)에 걸린다. 그러나 寺로 읽어도 元 의가 이름이 서지 않는다. 소년은 여전히 **小兒 → 曾世榮 / 錢乙** 추정이고 확신은 25%다.
- **거리(한국)** — 빈 나무 선반은 4판 3층 선반장이다. 「가구 위 = 官」 갈림은 **가운데 층**에 무언가 있어야 성립하는데, 세 층 모두 비어 조건이 덜 찼다. 그래서 官(관청 간행)은 60%로 둔다. 1단계의 판목 시렁 = 藏도 성립하지 않는다. 사전의 藏은 「문 열린 곳간 + 곡식 가마니」다. 그 결과 **大藏都監**은 근거를 잃고 「官刊」으로 약해졌다. 초록 십자 + 풀잎 책 = 《**鄕藥救急方**》과 금메달 = 「현존 最古」는 사전 밖 연상이지만 유지한다. 금메달의 광택이 華(빛나는 것)로 샐 위험이 있다.

**③ 잔결**
- 사전으로 풀린 것: 얼음 + 산 불 = 陰. 王 = 무대가 정함.
- 여전히 뜻 모를 것: 낮 하늘 초승달(사전에 없음 — 陰을 거듭 실은 것인지?), 소년(소품 없음), 게르 사이 청기와 정자(寺? 거리 레인 양식이 번진 이음 흔적일 가능성이 더 크다), 빈 3층 선반(가운데 층 표시가 없음).
- 오른쪽 아래 흰 네모별 반짝이는 華와 겹쳐 오독될 수 있는 생성 워터마크로 보인다.
- 흙길 오른쪽 끝의 붉은 선과 잘린 흰옷 인물은 이웃 띠 몫이다.
