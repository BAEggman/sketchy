# z91 판독 (③줄 宋·金·元 세로 띠)

## 1단계 — 생판 (사전 없이)

**① 시대**: 흙길에 몽골 게르(천막)가 줄지어 있음 → **金元(元 쪽)** / 앞 거리는 기와 처마의 **高麗**. 확신 85%.

**② 레인별 묶음**
- 뒤 강(본초): 강둑에 오른쪽을 가리키는 나무 화살 표지판 + 오른쪽 가장자리 낮은 탁자에서 종이에 쓰는 선비(탁자 위 검은 막대 = 먹?). 선비는 반쯤 잘려 이웃 띠 몫일 수 있음. 표지판 = 앞으로 「늘여 잇다(衍)」로 보아 **本草衍義**(寇宗奭), 또는 宋 본초 계보 정리자 **證類本草**(唐慎微). 확신 낮음(30%).
- 흙길 왼쪽 끝(잘림): 돌우물 위로 치솟는 불길에 찬물·눈송이를 끼얹음 → 火熱을 寒涼으로 끈다 = **劉完素** 寒涼派(火熱論). 가장자리라 이웃 띠 몫일 가능성.
- 흙길 가운데: 말 고삐를 잡고 선 남자 → 고삐로 「이끈다(引)」 = 引經報使 → **張元素**(易水學派, 藥物歸經·臟腑辨證). 곁의 사다리, 칸마다 작은 불꽃 → 약이 오르내림(升降浮沈) 또는 칸칸이 들어가는 歸經. 50%.
- 흙길 오른쪽: 활(弓 → **張**)을 메고 빗자루로 땅을 쓰는 사람 → 邪를 쓸어낸다 = **張從正(子和)** 攻邪(攻下)派. 게르 꼭대기로 빠져나가는 김(=汗), 뒤집혀 날아가는 사발(=吐), 쓸어내림(=下) → 汗吐下 三法. 게르 문 위 말린 두루마리 = 『儒門事親』? 75%.
- 앞 거리 왼쪽: 기와집, 안에 약장·약단지 선반, 앞에 평상 → 高麗 의료기관(**太醫監/惠民局** 계열 약국). 표제어 특정 불가(25%).
- 앞 거리 가운데: 노점 위에 집게(핀셋·펜치)로 엮은 새둥지, 아래 집게 하나 매달림, 앞에 파란 책 → 집게 = 「집을 撮」 → **御醫撮要方**(崔宗峻). 둥지 = 모아 엮음(集)이면 鄕藥集成方이나 조선이라 시대 불일치. 머리띠 두른 행인 = 救急 → 鄕藥救急方? 35%.

**③ 잔결**: 파란 책 표지 글자가 뭉개진 가짜 문자(판독 불가); 탁자 위 검은 막대 정체 불명; 오른쪽 끝 자루·바구니, 왼쪽 끝 불+물은 잘린 이웃 몫; 뒷모습 두 행인은 장식인지 불명; 사다리가 말 남자 몫인지 빗자루 남자 몫인지 경계 모호.

## 2단계 — 계통 (blind6 사전 적용)

**① 시대**: 게르 = 元, 기와 거리 = 高麗(13세기 高宗 무렵). **金元 / 高麗** 85% — 그대로.

**② 레인별 재판독**
- 흙길 가운데: 사전 「馬 = 사람 곁에 고삐로 매인 말 한 마리 — 성 馬, 어느 馬인지는 무대」가 정확히 들어맞음. 1단계의 「고삐=引經 → 張元素」는 철회. 金元 무대의 馬 → **馬宗素**(劉完素 문인, 河間學派) 1순위, **馬丹陽**(天星十二穴) 2순위. 곁 사다리를 다시 세어 보니 칸마다 불꽃(熱) 정확히 **여섯** → 六氣皆從火化 = 河間 火熱論 계승. 왼쪽 끝 「불 + 눈송이 섞인 찬물」(熱·寒/淸)이 **劉完素** 寒涼派라면, 스승 바로 오른쪽에 제자 馬가 오는 순서도 맞음. 45%.
- 흙길 오른쪽: 「張 = 등에 멘 긴 활」 확정 + 「瀉 = 짚 빗자루」 → 張 + 瀉 = **張從正(子和)** 攻邪派(攻下派). 金元 무대라 明의 張과 갈림. 게르 꼭대기에서 꼬리 달린 혼 같은 김이 쫓겨 날아가고 사발이 뒤집혀 튐(散) → 邪를 몰아냄(邪去正安) / 汗·吐·下 三法. 사다리 6칸을 이쪽에 붙이면 『儒門事親』 「六門三法」도 되나, 여섯이 모두 불이라 六門(風寒暑濕燥火)보다 火化 쪽이 낫다. 80%.
- 앞 거리 가운데: 사전에 없음 → 한국어 소리 말장난으로 풀림. 새둥지 = **새집 = 新集**, 집게 = 「집을 **撮**」 → 『**新集御醫撮要方**』(高麗 高宗 13년 1226, 崔宗峻). 파란 책 = 그 방서. 60%.
- 앞 거리 왼쪽 기와집 약방: 寺(절)·惠(빈 사발)·太(큰 갓)·典藥(약봉지 다발) 어느 기호도 없음 → 노점의 배경으로 보며 표제어 없음.
- 뒤 강: 표지판·필기 선비에 맞는 사전 기호(王 왕관 등) 없음. 선비는 오른쪽에서 잘림 → 이웃 띠 몫. 표지판은 강줄기 이음 표시로 봄(**本草衍義**? 20%).

**③ 잔결**: 강가 화살 표지판·탁자 위 검은 막대 뜻 불명; 파란 책 표지 가짜 문자; 머리띠 두른 행인·뒷모습 두 행인·오른쪽 끝 자루와 바구니는 사전 기호 없음(장식 또는 이웃 몫); 사다리가 馬 몫인지 張 몫인지 경계가 모호(빗자루가 사다리에 기대어 이어 붙인 듯).
