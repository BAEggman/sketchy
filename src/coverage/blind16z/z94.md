# z94 판독 (blind16z)

## 1단계 — 생판 (사전 열람 전)

**① 시대**: 중국 **後漢(東漢) 말** / 한국 **삼국 초기(원삼국)** — 확신도 90%.
강(본초 레인)은 이 띠 안에서 맨물로 비어 있고, 한국 거리도 왼쪽 끝 초가 처마(이웃 띠 몫)만 걸려 있어 사실상 빈 칸. 흙길에 성벽·망루를 배경으로 두 사람이 나란히 서 있다.

**② 말하는 묶음 (흙길 레인)**
- 흙길 왼쪽 — 갈색 도포의 나이 든 남자: **張仲景**.
  - 대쪽(竹簡) 책 표지의 눈꽃(❄) 무늬 + 아래 깔린 푸른 장정본 = 寒을 상하다 → **傷寒論**(傷寒雜病論).
  - 금빛 보물 궤짝 = 金匱 → **金匱要略**(雜病 부분).
  - 가로대 6칸 사다리 = 여섯 단계 → **六經辨證**(辨證論治의 체계 확립).
  - 뒤의 성벽·망루 = 長沙太守(坐堂) 연상 가능(배경일 수도 있음).
- 흙길 오른쪽 — 흰 저고리·회색 바지의 젊은 남자: **華佗**.
  - 김 오르는 탕 한 사발 = **麻沸散**(최초의 전신 마취제, 술에 타 마심).
  - 작은 칼 = 開腹 수술, **외과의 비조(外科鼻祖)**.
  - 호랑이·사슴·곰·원숭이·학 다섯 조각상 = **五禽戲**(導引 양생 체조).
- 두 사람 사이의 검은 위패(碑/牌): 「醫聖」 張仲景의 존칭이거나, 曹操에게 죽고 의서(靑囊書)가 불타 전하지 않는 華佗의 「빈 비석」. 어느 쪽 몫인지 갈린다(약간 華佗 쪽).

**③ 뜻 모를 소품·어색한 것**
- 검은 위패: 주인·뜻이 확정되지 않음(醫聖? 소실된 저작?).
- 왼쪽 끝 돌 제단 위 황금 보자기 대쪽 묶음 + 금 메달, 왼쪽 아래 초가 — 가장자리에서 잘린 이웃 띠 몫으로 보고 무시.
- 사다리가 張仲景보다 위패 쪽/화면 왼쪽으로 붙어 있어 소속이 약간 애매하나 張仲景으로 읽음. 이어붙인 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 그대로 중국 **後漢 말** / 한국 **삼국 초기(원삼국, 거리 비어 있음)** — 90%. 사전 어휘는 시대를 바꾸지 않는다.

**② 말하는 묶음 (흙길 레인)**
- 왼쪽 갈색 도포 남자: **張仲景** 유지.
  - 대쪽 책의 눈송이: 사전 「寒 = 눈송이」, **갈림** 조건상 눈송이 = **外寒** → 바깥 寒邪에 상한 병 = **傷寒論**. 1단계 읽기를 사전이 오히려 굳혀 준다(外感病서).
  - 단, 「傷 = 터져·깨진 물건」은 없음(대쪽 멀쩡) → 傷 자는 그림에 안 실렸고 서명 관용으로 메운 것.
  - 금 궤짝 = **金匱要略**(사전 항목 없음, 1단계 그대로). 6칸 사다리 = **六經辨證**(항목 없음).
  - 「張 = 등에 멘 긴 활」이 **없다** → 성 張을 사전 기호로 확인할 수 없음. 표제는 소품 조합으로만 선다.
- 오른쪽 흰 저고리 남자: **華佗** 유지.
  - 다섯 짐승 조각 = **五禽戲**, 칼 = **外科**·開腹. 성벽 앞(담 바깥)에 서 있어 「外 = 담 바깥」으로 外科를 한 번 더 짚는다고 볼 수도 있으나 두 사람 모두 담 밖이라 약함.
  - 김 오르는 국물 사발: 사전대로 읽으면 「補 = 찰랑찰랑 찬 따뜻한 국물」 + 「氣 = 서린 흰 김」 → **補氣**가 되는데, 華佗·칼과는 맞지 않는다. 의학사 문맥(칼과 짝)에서는 **麻沸散**(마취 탕)이 더 잘 풀린다 → 1단계 유지, 사전과 **충돌**로 기록.
- 가운데 검은 위패: 「中 = 둘 사이의 한복판」에 꼭 맞는 자리라 **中**으로 읽힐 수 있음 → 仲景의 仲(중) 음차? 또는 「醫聖」 위패. 사전으로도 결론이 안 남.

**③ 잔결**
- 국물 사발이 사전 補/氣와 겹쳐 麻沸散 독해를 흐린다.
- 위패의 뜻(中? 醫聖? 소실된 華佗 저작?) 미확정.
- 張仲景에 張(활) 표지 부재. 본초 강·한국 거리 빈 칸, 좌단 제단·초가는 이웃 띠 몫.
- 판정: 사전 어휘는 寒(外寒→傷寒)만 보강하고 나머지는 보태는 게 없거나 충돌한다 — 1단계 답이 그대로 더 잘 풀림.
