# blind17 판독 E — 950 · 951

## 1단계 — 생판 (사전 열기 전)

### [950]
① 시대: 1순위 **南北朝~隋 / 삼국(백제·신라)** 70% · 2순위 隋~唐初 / 삼국 말~통일신라 초 20%

② 강(왼쪽→오른쪽)
- 물레 앞 여인 + 빨강·검정 줄무늬 항아리 2 + 붓통(붓 2자루, 붉은 촉·검은 촉) → **陶弘景 本草經集注**(陶=도자기). 붉은·검은 줄 = 朱墨雜書(本經 朱書 / 別錄 墨書), 붓 2 = 두 색.
- 장작불 솥(인삼·약초 끓임) + 솥을 두른 고리에 북 5개(+작은 매단 것 1) + 금메달 소년 → **雷斅 雷公炮炙論**. 북 고리 = 雷公, 솥·불 = 炮炙, 메달 = 최초의 포제 전문서.
- 약장(닫힌 서랍 9 + 열린 서랍 3, 씨앗·광물·곡물) + 약초 화분 뒤의 남자 → 표제어 미확정. 후보 **徐之才 藥對**(서랍=徐) / 本草經集注의 자연속성 분류.
- 오른쪽 끝 빈 나루 → 다음 판으로 이어짐.

길
- 초록 도깨비가 걸어 나가며 남긴 종이·처방 쪽지·칼(수술칼)·메달 → **劉涓子鬼遺方**(鬼=도깨비, 遺=남김). 칼 = 외과, 메달 = 현존 최초 외과 전문서.
- 보라 옷 선비 + 펼친 책 + 둘레 걸상 약 8개(6개 바로 섬, 2개 넘어짐) → 후보 **全元起 素問訓解**(素問 최초 주석, 강학 자리. 넘어진 걸상 = 잃어버린 권?). 확신 낮음.
- 새 둥지에 앉은 초췌한 남자 + 무늬 알 약 9개 + 메달 → **巢元方 諸病源候論**(巢=둥지, 알=病源). 메달 = 최초의 병인·증후 전문서.
- 버드나무 위에 얹힌 흰 갓·흰 끈 + 소년 + 운하 위 돌다리 → **楊上善 黃帝內經太素**(楊=버들, 上=위에, 素=흰). 운하·다리 = 隋 대운하(시대 표지)로 추정.

거리
- 민짜 기와집 + 머리띠 소년(학생) → 후보 **고구려 侍醫 / 백제 藥部**(미확정).
- 큰 집 앞 8칸(4×2) 상 → 후보 **신라 藥典 / 백제 藥部**.
- 책 2권 → 화살표 → 큰 파도(가나가와) 표지 책 → **百濟新集方·新羅法師方이 일본 醫心方에 수록**(파도 = 일본).

③ 잔결: 약장+약초 남자 묶음 뜻 불명. 걸상 개수·넘어짐의 뜻 불명. 솥 고리의 작은 매단 것(북이 아닌 것) 1개. 강 양끝 빈 나루.

### [951]
① 시대: 1순위 **唐 / 통일신라** 85% · 2순위 唐末~五代 / 통일신라 말~고려 초 10%

② 강
- 관복·사모·메달을 걸친 소 + 발치의 옥도장 → **蘇敬 新修本草**(소=蘇). 관복·도장 = 국가 편찬·반포, 메달 = 세계 최초 국가 약전.
- 나루 위 상: 나물·인삼·물 그릇 약 7개 → **孟詵 食療本草**(음식 = 식료).
- 빈 오두막(문 열림·속 빔) + 망태기 + 메달 + 그릇 10개(5+5) → **陳藏器 本草拾遺**. 망태기 = 拾, 빈 집 = 遺, 그릇 10 = 十劑, 메달 = 십제 분류의 시초.
- 큰 자두를 안은 소년 + 산호·조개 바다 → **李珣 海藥本草**(李=자두, 산호·조개 = 바다 건너 온 약).

길
- 흰 수염 노인 + 메달 + 보물상자 2(하나는 날개 달림) → **孫思邈 千金要方·千金翼方**(千金=금, 翼=날개).
- 왕관 쓴 남색 옷 남자(뒤편 망루) → **王燾 外臺秘要**(王=왕관, 臺=망루).
- 왕관 쓴 갈색 옷 노인 + 얼음 탁자 위 두루마리 두 무더기(약 5~6 + 6) → **王冰 次注 黃帝內經素問**(冰=얼음; 두루마리 = 권, 補入한 運氣 7篇대론 추정).

거리
- 침 꽂힌 침방석 간판 집 + 관원 둘(본초 그림 책 / 인체 그림 책) → **통일신라 醫學(692)·醫博士**: 本草經·明堂(甲乙)經 교수.
- 학생 둘(하나는 머리띠) + 문 열린 큰 집 → **醫學 교육기관**(학생).
- 신라 금관 쓴 왕 + 등잔을 받든 두 손 간판 + 뒤의 사람 둘 → **供奉醫師·內供奉醫師**(供奉=받듦).
- 닫힌 문 집 앞 소년 둘(하나 가리킴) → 미확정.

③ 잔결: 거리 x≈1160에 세로 이음선(기와 어긋남·흰 띠) — 이어 붙인 흔적. 오른쪽 집 벽의 흰 얼룩. 거리 바닥의 잔 얼룩. 두루마리 개수 의미 불명.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

사전에서 이 두 판에 걸리는 기호: **王 = 왕관**(성만, 어느 王인지는 무대가 정함), **李 = 허리춤 자두**(성만), **太 = 머리에 씌운 테 넓은 큰 갓**, **保命 = 두 손으로 감싸 바람을 막은 등잔불**, **外 = 담 바깥**, **藏 = 문 열린 곳간**(갈림: 안에 곡식 가마니), 陰 = 얼음(갈림: 살아 있는 불과 맞댈 때만), 傷(갈림: 그 사물이 깨진 것), 久(같은 것 셋 포갬). 의미 없는 성 표지(張 활·馬 말·吳 큰 입)는 두 판 어디에도 없다.

### [950]
① 시대: 1순위 **南北朝~隋 / 삼국(백제·신라)** 75% · 2순위 隋~唐初 / 통일신라 초 15%. 거리가 사전 어휘로 읽히는 글자를 거의 안 지녀 한국 쪽 확신은 중국 쪽보다 낮다.

② 강
- 물레 여인 + 붉은·검은 줄 항아리 2 + 붓 2 → **陶弘景 本草經集注** — 朱墨 두 색 구분(本經=朱, 別錄=墨). 사전의 血(붉은 것)으로 읽을 자리는 아니다(본초 강·항아리 문맥).
- 북 5개 두른 솥·장작불(熱)·김(氣) + 메달 소년 → **雷斅 雷公炮炙論**, 최초의 포제 전문서. 사전 변화 없음.
- 약장(닫힌 서랍 9·열린 서랍 3) + 약초 화분 남자 → **徐之才 (雷公)藥對**(서랍=徐, 「雷公」 솥 바로 다음 자리) 45% · 대안 新修本草 藥圖. 화분 밑 검붉은 뿌리는 地黃 기호로도 읽히나 이 자리 뜻과 안 맞아 기각.

길
- 도깨비가 두고 간 종이·처방·칼·메달 → **劉涓子鬼遺方**, 현존 최초 외과서.
- 보라 옷 선비 + 펼친 책 + 걸상 8(바로 6·넘어짐 2) → **全元起 素問訓解**(素問 최초 주석) 40%. 넘어진 걸상은 깨진 게 아니라 傷이 아니고, 셋 포갬도 아니라 久도 아니다 → 사전 글자 없음. 걸상 8 = 8권(9권 중 1권 亡失)? 왕관·활·자두·말이 없으니 王·張·李·馬 계열이 아니라는 것만 확실.
- 둥지 남자 + 알 약 9 + 메달 → **巢元方 諸病源候論**, 최초 병인·증후 전문서.
- 버드나무 꼭대기에 **큰 갓(太)** + 흰 끈(素) + 소년 + 돌다리·운하 → **楊上善 黃帝內經太素**. 1단계의 「上」 풀이는 버림 — 사전의 上은 「곧게 솟음」이고, 갓은 사전에 **太**로 등재돼 있다. 太素 = 內經 최초 분류 편집본.

거리
- 민짜 집 + 머리띠 소년 → 미상(백제 藥部 / 고구려 侍醫 후보).
- 큰 집 + 빈 8칸 상 → 미상(藥部·藥典 후보). 사전 글자 없음.
- 책 2 → 화살표 → 파도 표지 일본 책 → **百濟新集方·新羅法師方 → 일본 醫心方에 수록**.

③ 잔결: 거리 왼쪽·가운데 두 묶음은 글자 없는 빈 무대(뜻 불명). 걸상 개수 뜻 불명. 솥 고리의 북 아닌 작은 매단 것 1. 강 오른쪽 빈 나루(다음 판 이음).

### [951]
① 시대: 1순위 **唐(~五代) / 통일신라** 85% · 2순위 唐末·五代 / 통일신라 말~고려 초 10%. 신라 금관 + 保命 간판이 통일신라를 굳힌다.

② 강
- 관복·사모·메달 소 + 옥도장 → **蘇敬 新修本草**(소=蘇), 국가 편찬·반포 최초 국가약전.
- 상 위 나물·인삼·뿌리·맑은 물 한 그릇 → **孟詵 食療本草**. 맑은 물(淸)은 식료 상차림의 일부로 보고 별 사실로 안 셈.
- 문 열린 **곳간(藏)인데 속이 빔** + 망태기 + 그릇(器) 10 + 메달 → **陳藏器 本草拾遺** — 藏+器로 이름, 빈 곳간+망태기 = 拾遺(빠진 것 줍기), 그릇 10 = **十劑** 최초 제시. 가마니가 없으니 사전 藏의 갈림은 「빔」으로 뒤집혀 遺를 보탠다.
- **허리춤 자두(李)** 소년 + 산호·조개 바다 → **李珣 海藥本草**(외래·해산 약물). 사전 李 확정, 본초 강 + 바다 무대가 李珣으로 고정.

길
- 흰 수염 노인 + 메달 + 금 상자 2(하나 날개) → **孫思邈 千金要方·千金翼方**(千金=금, 翼=날개). 상자 크기 같아 大 아님.
- **왕관(王)** 남색 옷 + 담 **바깥(外)** 앞의 망루(臺) → **王燾 外臺秘要**.
- **왕관(王)** 갈색 옷 + 얼음 탁자 + 두루마리 두 무더기(약 5·6) → **王冰 次注 素問**. 곁에 산 불이 없고 겨울 무대도 아니라 얼음은 陰·凝滯가 아니라 이름 冰. 두루마리 = 권수/補入 7篇 추정(개수 뜻 불명).

거리
- 침방석 간판 + 관원 2(본초 그림 책·인체 경혈 책) → **통일신라 醫學 博士 2인** — 本草經·明堂經(甲乙·鍼經 등) 교수.
- 학생 2(머리띠) + 문 열린 큰 집 → **醫學(692, 효소왕) 교육기관**.
- 신라 금관 왕 + **保命**(두 손이 감싼 등잔) 간판 + 등 돌린 2인 → **藥典 → 保命司 개칭(景德王)**. 1단계 「供奉」 풀이는 버림.
- 닫힌 문 집 + 소년 2 → 미상(다음 판으로 이어질 묶음?).

③ 잔결: 거리 x≈1185 세로 이음선(기와·벽 어긋남) — 이어 붙인 흔적 확정. 오른쪽 집 벽의 흰 사각 얼룩, 바닥 잔 얼룩. 등 돌린 2인·오른쪽 소년 2의 뜻 불명. 왕관 사전 갈림(王 성)과 신라 왕이 겹침 — 무대로 「왕」이라 읽음.
