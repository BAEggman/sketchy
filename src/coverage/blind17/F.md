# blind17 판독 F — 950·951 (의학사 말판, 나란히 이어지는 두 구간)

## 1단계 — 생판 (사전 열기 전 확정)

### [950] (왼쪽 구간)
**① 시대** 1순위 중국 南北朝(齊·梁)~隋 / 한국 三國時代 (75%) · 2순위 隋~唐初 / 三國 말~통일신라 초 (20%).
**② 레인별**
- 강(본초서): ⓐ 물레 앞 여인 + 붉은 바탕에 검은 줄무늬 항아리 3점 + 붓 2자루 → 도(陶)=도기, 붉은·검은 줄 = 朱墨 雜書 → **陶弘景『本草經集注』** (朱書=本經, 墨書=別錄). ⓑ 솥(약초 삶음·불) + 솥 둘레에 매달린 북 5개, 메달 찬 소년 → 북 고리 = 雷公(뇌신), 솥·불 = 炮炙 → **雷斅『雷公炮炙論』**, 메달 = 최초 포자 전문서. ⓒ 약장(3열×4단=12서랍, 맨 아래 3칸 열림·씨앗) + 약초 뒤 남자 → 미상. 후보 **『名醫別錄』**·**甄權『藥性論』**·본초경집주의 자연속성 분류(약장 서랍=분류).
- 길(의가·의서): ⓐ 등 돌린 초록 도깨비 + 빈 종이·풀(벌레?) 그림 쪽지·메스·메달 → 鬼가 남긴 方 + 칼 = 외과 → **『劉涓子鬼遺方』**(龔慶宣, 현존 최고 외과서=메달). ⓑ 보라 도포 선비가 책상에 펼친 책, 둘레 걸상 8개(선 것 6·넘어진 것 2) → 全(모든 자리)+起(일어섬)? → **全元起『素問訓解』**(최초 소문 주석, 망실 권 = 넘어진 걸상) — 확신 낮음. ⓒ 둥지에 앉은 슬픈 남자 + 메달 + 알 8개 → 巢(둥지)+元(근원=알) → **巢元方『諸病源候論』**(최초 병인·증후 전문서). ⓓ 버드나무(楊) 꼭대기(上)에 걸린 크고 흰 갓(太素) + 아래 소년 → **楊上善『黃帝內經太素』**. ⓔ 돌 아치 다리 + 수로 → 隋 대운하/趙州橋? 시대 표지로 추정, 미상.
- 거리(한국): ⓐ 닫힌 맞배집 + 머리띠 학생 → 미상(배경). ⓑ 큰 전각 앞 8칸 빈 쟁반(약 분류판?) → **백제 藥部**? ⓒ 가게 선반의 옛 책 2권 → 화살표 → 큰 파도(가나가와 파도) 표지 책 → 한국 의서가 일본 의서에 실림 → **『百濟新集方』·『新羅法師方』 → 『醫心方』** (2권).
**③ 잔결** 다리·수로(뜻 모름), 약장 남자(뜻 모름), 걸상 수(8? 9?) 불확정, 거리 왼쪽 건물·학생은 951과 같은 틀의 재사용.

### [951] (오른쪽 구간)
**① 시대** 1순위 중국 唐(~五代) / 한국 統一新羅 (88%) · 2순위 隋唐 / 통일신라·발해(남북국) (10%).
**② 레인별**
- 강: ⓐ 관복·복두 쓴 소(=蘇) + 메달 + 옥 도장 → **蘇敬 등『新修本草』**(국가 편찬 최초 약전). ⓑ 상 위 그릇 7개(인삼·나물·물) → 음식 = **孟詵『食療本草』**. ⓒ 열린 창고(藏)+메달+광주리(拾) + 둘레 사발 10개(器, 좌5·우5) → **陳藏器『本草拾遺』**, 사발 10 = **十劑**. ⓓ 커다란 자두(李)를 안은 소년 + 산호·조개 → **李珣『海藥本草』**(외래·해산 약물).
- 길: ⓐ 메달 찬 백발 노인 + 금궤 1개 + 날개 단 금궤 1개 → 千金 + 翼 → **孫思邈『千金要方』·『千金翼方』** (2서). ⓑ 왕관(王)·남색 도포, 오른편 망루(臺) → **王燾『外臺秘要』**. ⓒ 왕관(王) + 얼음(冰) 탁자 위 두루마리 두 무더기(6+6) → **王冰 次注『黃帝內經素問』**.
- 거리: ⓐ 침 꽂이 간판 건물 + 관원 2인이 든 본초 그림 책·인체 경혈도 책 + 걸어 들어오는 학생 2 → **신라 醫學(692, 효소왕)** 박사 2인, 本草經·明堂經(甲乙·針經 등) 교수. ⓑ 신라 금관 쓴 인물 + 두 손으로 등잔 받든 간판(供奉) → **供奉醫師**; 뒤의 회색 2인 = 승려(僧醫)? ⓒ 닫힌 문 건물 + 학생 2 → **藥典**? 미상.
**③ 잔결** 거리 레인 x≈1160 세로 이음매(지붕 끊김·흰 조각), 오른쪽 건물 벽의 흰 사각(지운 흔적), 바닥의 작은 얼룩 글자, 회색 2인 얼굴이 간판에 가려 잘림. 두루마리 수의 뜻 미상.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

### [950]
**① 시대** 1순위 中 南北朝(齊·梁)~隋 / 韓 三國時代 (80%) · 2순위 隋~唐初 / 三國 말 (15%). 사전이 시대 판정을 바꾸지 않음.
**② 레인별 (사전 대조)**
- 강: ⓐ **陶弘景『本草經集注』** — 사전에 陶 기호 없음. 붉은 바탕·검은 줄 = 朱墨 2색(사전 「血=붉은 것」은 장부 판 어휘라 이 무대엔 안 맞음). 붓 2·항아리 3. ⓑ **雷斅『雷公炮炙論』** — 솥 위 흰 김(氣)·불꽃(熱)은 사전 어휘로 읽히나 이름 아닌 「炮炙」(굽고 찜) 동작으로 보는 게 맞음. 북 5개 = 雷, 메달 = 최초 포자서. ⓒ 약장(12서랍, 3칸 열림) + 약초 뒤 남자 — 뿌리는 연갈색이라 「地黃=검붉은 뿌리」 아님, 약장도 「官=3층 선반장 가운데 층」 아님 → 미상, 연대 순서상 **甄權『藥性論』**(唐初) 1후보, **『名醫別錄』** 2후보.
- 길: ⓐ **『劉涓子鬼遺方』**(도깨비=鬼, 남긴 종이=遺方, 메스=외과, 메달=현존 최고 외과서) 유지. ⓑ 보라 도포 선비 + 펼친 책 + 걸상 8(선 것 6, 뒤집힌 것 1, 떨어진 판 1) — 사전에 걸상 기호 없음. 넘어진 걸상은 「傷=그 글자 사물이 깨진 것」으로 읽히나 이름에 이어지지 않음 → **全元起『素問訓解』**(최초 소문 주석, 망실 권) 유지, 대안 = 교실로 보아 **秦承祖 奏置 醫學(443 설치·453 폐지)/隋 太醫署**. ⓒ **巢元方『諸病源候論』** 유지(둥지=巢, 알 8, 메달=최초 병인·증후서, 슬픈 얼굴=病). ⓓ **楊上善『黃帝內經太素』** — 사전 「太=머리에 씌운 테 넓은 큰 갓 하나」로 太 확정, 갓이 버드나무(楊) 꼭대기(上)에 얹힘, 갓이 흼=素. 1단계보다 확신 상승. ⓔ 돌다리+수로 — 사전 「濟(물에 드리운 밧줄)」「通」 해당 없음 → 시대 표지(隋 운하)로 추정, 미상.
- 거리: ⓐ 맞배집+머리띠 학생 — 「寺=기와지붕 절 한 채」로 보기엔 절 표지 없음 → 배경. ⓑ 큰 전각 앞 8칸 빈 쟁반 — 사전 「藥=배 모양 약연」「典藥=묶은 약봉지」 없음 → **百濟 藥部**? 미상. ⓒ **『百濟新集方』·『新羅法師方』(2권) → 일본 『醫心方』** 유지.
**③ 잔결** 약장 남자·돌다리·8칸 쟁반의 뜻 미상, 걸상 수 애매(8? 떨어진 판 포함 여부), 거리 왼쪽 건물·가운데 전각은 951과 같은 틀.

### [951]
**① 시대** 1순위 中 唐(강은 五代까지) / 韓 統一新羅 (90%) · 2순위 隋唐 / 南北國(통일신라·발해) (8%).
**② 레인별 (사전 대조)**
- 강: ⓐ **蘇敬『新修本草』** — 소(=蘇, 한국어 소리), 관복·복두 + 메달 + 옥 도장 = 국가 편찬 세계 최초 약전. 사전에 해당 어휘 없음(1단계 유지). ⓑ **孟詵『食療本草』** — 상 위 그릇 7(인삼·나물·맑은 물 한 그릇). 「淸=맑고 찬 물 한 그릇」「補-b=가득 찬 그릇」이 겹쳐 읽히나 받는 사람이 없어 음식상 = 食療로 판정. ⓒ **陳藏器『本草拾遺』** — 사전 「藏=문 열린 곳간 안 곡식 가마니」에서 문은 열렸으나 가마니가 없음(빈 곳간), 앞에 관리 없음 → 倉 아님. 藏을 반쯤 충족 + 광주리(拾) + 사발 10(左5·右5 = **十劑**). 「惠=여러 손이 받아 드는 빈 사발」은 손이 없어 아님. ⓓ **李珣『海藥本草』** — 사전 「李=허리춤 자두」 그대로(밧줄로 허리에 묶인 큰 자두), 산호·조개 = 海藥(외래·해산 약물). 확신 상승.
- 길: ⓐ **孫思邈『備急千金要方』·『千金翼方』** — 금궤 + 날개 금궤(翼), 메달. ⓑ **王燾『外臺秘要』** — 사전 「王=왕관, 어느 王인지는 무대가 진다」 → 唐 무대 + 담 앞(外)·망루(臺). ⓒ **王冰 次注『黃帝內經素問』** — 王관 + 얼음 탁자. 사전 「陰=얼음은 살아 있는 불과 맞댈 때만」 → 불 없음·겨울 아님이라 陰·寒·凝滯 아님 → 이름 冰. 두루마리 2무더기(긴 것 6 / 짧은 것 6, 「大=하나가 두 배」로 보면 大論 보입?) — 수의 뜻 미상.
- 거리: ⓐ **신라 醫學(692, 孝昭王)** — 침 다발 간판(「痛=살에 박힌 쇠못 하나」 아님 → 針), 관원 2 = 醫學博士 2인, 본초 그림책·인체 경혈도 = 本草經·明堂經 등 교재, 학생 2. ⓑ 신라 금관 인물 + 두 손에 받든 등잔 간판 → 사전 「保命=두 손으로 감싸 바람 막은 등잔불」과 충돌. 손이 불꽃을 감싸지 않고 밑에서 받듦 + 신라 무대에 保命 기관 없음 → **供奉醫師**로 판정(왕실 진료), 뒤 회색 2인은 미상. ⓒ 닫힌 문 건물 + 학생 2 → **藥典**? 미상.
**③ 잔결** 거리 x≈1160 세로 이음매(전각 지붕이 끊기고 흰 조각), 오른쪽 건물 벽의 흰 사각(지운 흔적), 바닥 작은 얼룩, 회색 2인 얼굴이 간판에 가려짐, 등잔 간판이 사전의 保命 기호와 겹침, 빈 곳간(藏 조건 미달).
