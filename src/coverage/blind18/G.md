# blind18 — 판독자 G (940·941)

## 1단계 — 생판 (사전 열람 전, 확정)

### [940] (왼쪽 구간)

**① 시대**
- 1순위: 中國 戰國~兩漢(중심 = 漢) / 韓國 고조선~삼한(원삼국) — 70%
- 2순위: 中國 後漢 단독 / 韓國 삼한 — 20%

**② 레인별 판독 (왼→오)**
- 강: 폭포 흐르는 산(발원) → 부두에 선 소머리 사람(금메달) + 크기가 다른 바구니 3개
  → **神農本草經** — 神農(牛首), 금메달 = 현존 最古 本草書, 바구니 3 = 上·中·下 三品 분류(3).
- 길:
  1. 4칸 선반(죽간 묶음·풀 다발·사다리 5단·금궤) → 4대 고전 색인 추정(**黃帝內經·神農本草經·傷寒論·金匱要略**), 확신 낮음.
  2. 까치 + 책상 위 펼친 책 + 깃발 3개(백·적·청) → **扁鵲**(秦越人) / 책 = **難經**. 깃발 3의 뜻 불명(寸關尺 3부? 色診?).
  3. 곡식 창고(자루 약 25~28개) + 관모 쓴 관리가 책 펼침 → **倉公 淳于意**(太倉長) / 책 = **診籍**(의안 25례, 자루 수와 대응 추정).
  4. 누런 보 덮인 돌상 위 죽간 2묶음 + 침 몇 개 + 매달린 금메달 → **黃帝內經**(黃 = 누런 보, 素問·靈樞 2부, 靈樞 = 鍼經, 현존 最古 의서).
  5. 사다리 6단 + 노인 + 눈꽃 무늬 책(아래 청색 책) + 금궤 → **張仲景** / **傷寒雜病論** → **傷寒論**(❄=寒)·**金匱要略**(금궤), 6단 = 六經辨證.
  6. 검은 빈 비석 + 흰 도복 청년 + 김 나는 탕 + 칼 + 호랑이·사슴·곰·원숭이·학 조각상 5 → **華佗** — **麻沸散**(마취)·외과수술·**五禽戲**(5). 빈 비석 = 저서 실전? (불확실)
- 거리: 초가 2채뿐, 기관·의서 소품 없음 → 비어 있음(고조선·삼한).

**③ 잔결**
- 거리 레인 x≈1155에 세로 이음선 — 오른쪽 아래 구역이 덧붙여진 흔적.
- 張仲景·華佗 소품(사다리 밑동·책·금궤·탕·칼·五禽 조각상)이 거리 레인으로 내려와 침범.
- 선반 사다리 5단 vs 길 사다리 6단 불일치. 깃발 3개·빈 비석·폭포 산은 뜻 불명.

### [941] (오른쪽 구간)

**① 시대**
- 1순위: 中國 魏晉(三國~西晉·東晉) / 韓國 삼국 초기 — 70%
- 2순위: 中國 後漢末~西晉 / 韓國 원삼국(삼한) — 20%

**② 레인별 판독 (왼→오)**
- 강: 소품 없는 빈 강 + 건너편 대숲 언덕 → 이 구간 본초서 공백(神農本草經 뒤, 다음 본초서 전). 대숲 = 竹林(魏晉 표지) 또는 다음 판 예고(**陶弘景** 은거?) — 불확실.
- 길:
  1. 노인(940 노인과 같은 그림) → 앞 판 **張仲景**의 연결 표지 또는 **皇甫謐** 본인(불확실).
  2. 비늘 갑옷 닭 + 몸에 꽂힌 침 10여 개 + 금메달 + 뒤편 흰 깃발 무리(수십 개) → **鍼灸甲乙經**(皇甫謐) — 닭 비늘 = 甲, 침 = 鍼灸, 금메달 = 현존 最古 鍼灸 전문서, 깃발 = 경혈 수(349穴 추정).
  3. 왕관 쓴 사람 + 탁자 위 팔(손목에 점 3개) + 청색 구름무늬 맥침 + 끈 묶인 죽간 두루마리 → **王叔和** / **脈經** — 王(왕관), 寸·關·尺 3부(점 3), 죽간 = 傷寒論 편차(編次) 추정.
  4. 칡덩굴 감긴 사람이 통나무 안고 허리에 주머니 → **葛洪** — 葛(칡), 「抱朴子」(통나무 = 朴을 안음), 주머니 = **肘後備急方**(구급 휴대).
  5. 갈라지는 길 + 빈 팻말 + 끊긴 성벽 → 시대 분기(南北朝 예고?).
- 거리: 초가 3채 + 뒤편 기와집 1채, 소품 없음 → 비어 있음.

**③ 잔결**
- 940 오른쪽 노인과 941 왼쪽 노인이 같은 그림(복제) — 누구인지 갈림.
- 이음 불일치: 940 성벽(성가퀴·망루) ↔ 941 성벽(민벽·누런색), 강 수면 높이 어긋남.
- 王叔和의 팔이 몸과 떨어진 듯 어색. 죽간 두루마리가 거리 레인 경계에 걸침. 거리 바닥 작은 표식 2개. 빈 팻말.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

### [940]

**① 시대**
- 1순위: 中國 戰國~兩漢 / 韓國 고조선·삼한 — 75% (倉 표지로 前漢, 寒 표지로 後漢 末이 확정돼 1단계보다 오름)
- 2순위: 中國 後漢 단독 / 韓國 삼한 — 15%

**② 레인별 판독 (왼→오)**
- 강: **神農本草經** — 소머리 = 神農, 금메달 = 현존 最古 本草書, 바구니 3 = 上·中·下 三品(3). 크기가 다른 셋이라 사전의 中(같은 것 셋 중 가운데)·大(둘 중 하나가 두 배)는 맞지 않는다. 폭포 산은 사전상 배경 산(艮)이라 사실을 나르지 않는다.
- 길:
  1. 4칸 선반 — 둘째 칸 짚 다발은 사전상 **瀉(짚 빗자루)**로 읽히지만, 漢 무대에 瀉의 표제어(張子和 攻下)가 없다. 2×2라 官(3층 선반장 가운데 층)도 아니다. 색인 후보 **漢書 藝文志 方技 4류(醫經·經方·房中·神仙)**(사다리 = 神仙 승천) 또는 4대 고전. 결정 불가.
  2. **扁鵲** — 까치 = 鵲, 펼친 책 = **難經**. 깃발 3(백·적·청)은 사전에 없음. 뜻 불명.
  3. **倉公 淳于意** — 사전 「倉 = 곡식 가마니가 쌓인 곳간 안, **관리가 서 있으면 倉**(藏 아님)」과 정확히 맞는다. 太倉長, 책 = **診籍**(가마니 약 25 ≈ 의안 25례).
  4. **黃帝內經** — 누런 보 = 黃, 죽간 2 = 素問·靈樞, 침 = 靈樞(鍼經), 금메달 = 현존 最古 의서. 사전 어휘 추가 없음.
  5. **張仲景 / 傷寒雜病論** — 사전 「寒 = 눈송이(外寒)」 → 눈송이 책 = **傷寒論**(外感 傷寒과 정확히 맞음), 금궤 = **金匱要略**, 사다리 6단 = 六經辨證. 그런데 사전 「張 = 등에 멘 긴 활」이 노인에게 **없다** → 성 표지 누락(내용 소품으로만 張仲景).
  6. **華佗** — 칼 = 외과수술, 호·록·웅·원·조 5 = **五禽戲**(5). 김 나는 탕 그릇은 사전상 **補(찰랑찰랑 찬 따뜻한 국물)**·氣(서린 김)로 읽히나 華佗에게 補는 사실이 없다 → 맥락상 **麻沸散**(마취)으로 판정. 흑칠 비석은 사전 「華 = 빛나는 것·광택」이면 華 성 표지 후보(확신 낮음), 아니면 저서 실전.
- 거리: 초가 2채, 소품 없음 → 비어 있음.

**③ 잔결**
- 거리 x≈1155 세로 이음선. 張仲景·華佗 소품이 거리 레인을 침범.
- 張 활 표지 없음. 탕 그릇이 사전상 補와 충돌. 짚 다발이 사전상 瀉와 충돌. 선반 사다리 5단 vs 길 사다리 6단. 깃발 3 뜻 불명.

### [941]

**① 시대**
- 1순위: 中國 魏晉(三國·西晉~東晉) / 韓國 삼국 초기 — 75% (王 = 왕관은 「무대가 진다」 → 魏晉의 王 = 王叔和로 서로 받쳐 준다)
- 2순위: 中國 西晉 단독 / 韓國 원삼국(삼한) — 15%

**② 레인별 판독 (왼→오)**
- 강: 소품 없음 → 본초서 공백. 대숲 언덕은 사전에 없음(다음 구간 예고?).
- 길:
  1. 노인 — 940 노인과 같은 그림, 張 활 없음 → 표제어 못 붙임(皇甫謐로 볼 근거도 없음).
  2. **鍼灸甲乙經(皇甫謐)** — 비늘 갑옷 닭 = 甲(사전의 肝 장군은 초록·사람이라 아님), 침 10여 개 = 鍼灸(사전 痛 = 쇠못 하나와 다름), 금메달 = 현존 最古 鍼灸 전문서, 흰 깃발 수십 개 = 경혈 수(349穴).
  3. **王叔和 / 脈經** — 사전 「王 = 왕관, 어느 王인지는 무대」 → 魏晉 = 王叔和(확정). 맨팔뚝 손목 점 3은 사전상 **充(걷어올린 맨팔뚝 위에 더해진 것)**과 겹치나, 맥침 위 손목이라 **寸·關·尺 3부**로 판정. 끈 묶인 죽간은 사전 典藥(약봉지 다발)과 생김새가 달라 아님 → 傷寒論 편차 추정.
  4. **葛洪** — 칡 = 葛, 통나무 끌어안음 = **抱朴子**, 끈 조인 주머니는 사전상 **收(아가리를 조인 삼베 자루)**로 읽히지만 葛洪에게 收는 사실이 없다 → **肘後備急方**(허리에 찬 구급 주머니)으로 판정.
  5. 갈림길 + 빈 팻말 + 끊긴 성벽 → 시대 분기(南北朝 예고?). 사전에 없음.
- 거리: 초가 3 + 기와집 1, 소품 없음 → 비어 있음.

**③ 잔결**
- 940·941 노인 복제(표제어 불명). 성벽 양식·강 수면 높이 이음 불일치.
- 팔이 몸과 떨어져 보임(充 오독 위험). 주머니(收)와 탕 그릇(補)은 사전 어휘와 부딪힘.

**판정**: 사전은 **倉(倉公)·寒(傷寒論)·王(王叔和)** 세 곳을 확정해 주었다. 반면 張 활이 없어 張仲景 성 표지가 빠졌고, 補·收·瀉·充 네 어휘는 소품 생김새와 겹치지만 의학사 사실과 맞지 않아 오독을 부른다. 표제어 목록은 1단계와 같다.
