# blind18 판독 — H (940·941)

## 1단계 — 생판 (사전 열기 전, 그림만)

### [940] (왼쪽 구간)

① **시대**: 1순위 중국 **秦·漢(前漢~後漢 말)** / 한국 古朝鮮 말~三韓(원삼국) — 75% · 2순위 중국 戰國~前漢 / 한국 古朝鮮 — 15%.
근거: 벽돌 성벽+망루(漢 성곽), 신농 소머리 인물이 강의 발원(산·폭포)에 서 있음 = 본초 계보의 시작.

② **강**: 산·폭포(발원) 옆 부두에 소머리 사람(금메달) + 바구니 3개(대·중·소) + 작은 검은 원통.
→ **神農本草經** — 소머리 = 神農, 금메달 = 現存 最古 본초서, 바구니 3 = 上·中·下 **3品** 분류(365종).

**길**(왼→오):
1. 4칸 선반(묶은 막대·풀다발·작은 사다리·금궤) → **漢書 藝文志 方技略** 후보: 4칸 = 醫經·經方·房中·神僊 4類(사다리 = 승선 神僊, 풀 = 經方). 확신 낮음.
2. 까치 + 책상 위 펼친 책 + 깃발 3개(백·적·청) → **扁鵲(秦越人)**: 鵲 = 까치, 책 = **難經**, 깃발 3 = 邯鄲·洛陽·咸陽 세 곳에서 帶下醫·耳目痺醫·小兒醫로 바꿔 진료.
3. 관모 쓴 관리 + 곡식 창고(가마니 약 27~30개) + 펼친 책 → **倉公 淳于意**: 창고 = 太倉長, 책 = **診籍**(최초의 의안, 25例 — 가마니 수 근사).
4. 돌 상석 + 노란 천 + 竹簡 2묶음 + 뒤에 꽂힌 침 같은 막대 + 아래 금메달 → **黃帝內經**(黃 = 노란 천, 2묶음 = 素問·靈樞, 금메달 = 最古 醫經) 또는 **馬王堆 출토 의서**(상석 = 무덤, 노란 천 = 帛書). 반반.
5. 사다리(**6단**) + 노인(갈색 도포) + 눈꽃 표지 책 + 금궤 → **張仲景**: 6단 = **六經辨證**, 눈꽃(寒) = **傷寒論**, 금궤 = **金匱要略**(합쳐 傷寒雜病論).
6. 검은 위패 — 소속 불명(張仲景 醫聖 추존? 華佗 처형·靑囊書 소실?).
7. 흰 옷 젊은이 + 김 나는 사발 + 칼 + 동물상 **5**(호랑이·사슴·곰·원숭이·학) → **華佗**: 사발 = **麻沸散**, 칼 = 외과 수술, 동물 5 = **五禽戲**.

**거리**: 초가 2채뿐, 인물·소품 없음 → 비어 있음.

③ 잔결: 아래 절반 x≈1160에 세로 음영 띠(접힘/이어 붙인 흔적, 초가 지붕을 가로지름). 선반 안의 사다리·금궤가 張仲景 소품과 겹침(중복 의심). 부두 검은 원통·위패 뜻 불명. 강 오른쪽 2/3 비어 있음.

### [941] (오른쪽 구간)

① **시대**: 1순위 중국 **魏·晉(三國魏~西晉·東晉)** / 한국 **三國時代** — 80% · 2순위 중국 南北朝 초 / 한국 三國 — 15%.
근거: 皇甫謐·王叔和·葛洪 묶음, 성벽이 흙담으로 바뀌고 길이 갈라짐(분열 예고).

② **강**: 소품 없음. 건너편 기슭 대숲 → 표제어 없음(竹林 = 魏晉 분위기 또는 다음 본초서 예고, 약함).

**길**(왼→오):
1. 노인(갈색 도포, 940 노인과 같은 모습) — 단독, 옆 닭과 한 묶음이면 皇甫謐.
2. 침 꽂힌 닭(깃털 = 갑옷 비늘 '甲') + 금메달 + 뒤 흰 깃발 밭(약 80개) → **皇甫謐 『鍼灸甲乙經』**: 침 = 鍼灸, 금메달 = 現存 最古 침구 전문서, 깃발 밭 = 경혈 정리(349穴, 개수는 못 맞춤).
3. 왕관 쓴 사람 + 탁자 위 팔(손목 점 **3**) + 파란 脈枕 + 竹簡 두루마리(약 10쪽) → **王叔和 『脈經』**: 王 = 왕관, 점 3 = 寸·關·尺, 두루마리 = 10권.
4. 덩굴 감긴 사람이 통나무를 껴안고 팔꿈치 뒤에 주머니 → **葛洪**: 葛 = 덩굴, 안음(抱)+통나무(朴) = **抱朴子**, 팔꿈치 뒤(肘後) 주머니 = **肘後備急方**.
5. 끊긴 흙담 사이 갈림길 + 빈 팻말 → 시대 분기(南北朝 예고).

**거리**: 초가 3채 + 뒤 흐린 기와집 1, 인물·소품 없음 → 비어 있음(3채 = 三國 암시?).

③ 잔결: 940 노인과 똑같은 노인 반복. 성벽 양식 급변(벽돌 → 흙담). 오른쪽 집 프레임 잘림. 가운데 집 문 앞 작은 자국 2개 뜻 불명. 강 소품 없음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

사전에서 이 두 판에 걸리는 항목: **倉/藏**(갈림: 관리가 서 있으면 倉), **王 = 왕관**(어느 王인지는 무대), **張 = 등에 멘 긴 활**, **寒 = 눈송이**(갈림: 눈송이 = 外寒), **官 = 3층 선반장 가운데 층**, 그리고 겉모양이 겹치는 **補(따뜻한 국물 그릇)·收(끈 조인 삼베 자루)·充(맨팔뚝 위에 더해진 것)·瀉(짚 빗자루)·寺(기와집 한 채)**. 의학사 고유의 말장난(까치=鵲, 덩굴=葛, 금궤=金匱, 금메달)은 사전에 없다.

### [940]

① **시대**: 1순위 중국 **漢(前漢~後漢 말)** / 한국 古朝鮮 말~三韓(원삼국) — 80% · 2순위 중국 戰國~秦 / 한국 古朝鮮 — 15%. (1단계와 같고 확신만 올림)

② **강**: **神農本草經** — 소머리 = 神農, 금메달 = 現存 最古 본초서, 바구니 3개(대·중·소) = 上·中·下 **3品**. 사전의 中(셋 중 가운데)·大(두 배)는 가운데 강조나 두 배 비례가 없어 해당 없음. 1단계 유지.

**길**(왼→오):
1. 4칸 선반 — 2단이라 **官(3층 가운데 층) 아님**. 짚 다발은 사전상 瀉(짚 빗자루)처럼 보이나 자루가 없어 판정 보류. 왼쪽 끝 = 가장 이른 시기 규칙을 적용하면 **周禮 醫制(食醫·疾醫·瘍醫·獸醫 4분과)**가 **漢書 藝文志 方技略(4類)**보다 순서에 맞는다. 확신 낮음.
2. **扁鵲** — 까치(鵲), 펼친 책 = **難經**, 깃발 **3** = 세 곳에서 세 분과로 진료. 유지.
3. **倉公 淳于意** — 사전 갈림 「곳간 가마니 앞에 관리가 서 있으면 倉(아니면 藏)」에 **정확히 맞음**: 관모 쓴 관리 = 倉 → 太倉長 淳于意. 책 = **診籍**(가마니 약 27개, 25例 근사). 확신 상승.
4. 노란 천 + 竹簡 **2**묶음 + 금메달 → **黃帝內經**(素問·靈樞, 現存 最古 醫經). 순서상 倉公 뒤(前漢 成書)로 맞음. 대안 馬王堆 출토 의서.
5. **張仲景** — 눈송이 = 寒(갈림 「눈송이 = 外寒」 → 外感 寒邪 = **傷寒** 일치) → **傷寒論**, 금궤 = **金匱要略**, 사다리 **6**단 = **六經辨證**. 단 사전의 **張 = 등에 멘 활이 없다** — 성 표지 없이 저작으로만 지목됨.
6. 검은 위패 — 사전 항목 없음, 소속 미해결.
7. **華佗** — 동물상 **5** = **五禽戲**, 칼 = 외과 수술. 김 나는 국물 그릇은 사전상 **補**이지만 華佗 사실과 이어지지 않아 **麻沸散**(沸 = 끓어 김 남)으로 읽음.

**거리**: 초가 2채, 사전 기호(典藥·太·寺·濟·惠 등) 없음 → **비어 있음**.

③ 잔결: x≈1160 세로 음영 띠(이음/접힘). 선반의 사다리·금궤가 張仲景 소품과 중복. 張 활 부재. 위패·부두 검은 원통 뜻 불명. 국물 그릇의 補 갈림 미해결.

### [941]

① **시대**: 1순위 중국 **魏·晉(三國 魏~西晉·東晉)** / 한국 **三國時代** — 85% · 2순위 중국 南北朝 초 / 한국 三國時代 — 10%.

② **강**: 소품 없음, 건너편 **대숲**만(사전 항목 없음) → **비어 있음**(다음 본초서 예고 가능성만).

**길**(왼→오):
1·2. 노인 + 침 꽂힌 갑옷비늘 닭(甲) + 금메달 + 흰 깃발 밭(약 70~80개) → **皇甫謐 『鍼灸甲乙經』**(現存 最古 침구 전문서, 경혈 349穴 정리). 사전의 痛(쇠못 하나)은 여러 개라 해당 없음 → 鍼.
3. 왕관 = **王**(사전 확정 항목, 「어느 王인지는 무대가」) + 魏晉 무대 + 손목 점 **3**(寸·關·尺) + 脈枕 + 竹簡 두루마리(약 10쪽) → **王叔和 『脈經』**(10권). 맨팔뚝 위 점은 사전상 **充**처럼 보이나 무대가 맥진이라 寸口로 읽음. 확신 상승.
4. 덩굴(葛) + 통나무 안음(抱朴) + 팔꿈치 뒤 끈 조인 자루 → **葛洪**: **抱朴子**, **肘後備急方**. 자루는 사전상 **收**(끈 조인 삼베 자루)와 모양이 같으나 葛洪 사실과 무관 → 위치(肘後)로 읽음.
5. 끊긴 흙담 갈림길 + 빈 팻말 → 시대 분기(南北朝 예고).

**거리**: 초가 3채 + 뒤 흐린 기와집 1. 기와집은 사전상 **寺**(기와지붕 절 한 채) 후보지만 흐리게 물러난 배경이고 짝 기호가 없어 → **비어 있음**.

③ 잔결: 940 노인과 같은 노인 반복(이음새 중복 의심). 벽돌성 → 흙담 급변. 오른쪽 집 프레임 잘림. 가운데 집 앞 작은 자국 2개 뜻 불명. 자루=收·맨팔=充 갈림 충돌.

**판정**: 사전 어휘는 倉公(倉 갈림)·王叔和(王)·傷寒(寒=外寒)을 굳혀 주지만 새 표제어를 바꾸지는 않는다. 補·收·充·寺처럼 장상·치법 판에서 등재된 기호와 모양이 겹치는 소품은 의학사 무대에서는 오독을 낳으므로 1단계 문맥 해석을 유지한다.
