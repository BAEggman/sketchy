# blind19 판독 I — 950·951 (의학사 말판 한 줄, 이어지는 두 구간)

판독 조건: 원본 Read 2회(950·951 각 1회) + crop_I/ 확대 조각. 다른 파일 미열람.

---

## 1단계 — 생판 (사전 열람 전, 확정)

### [950]

**① 시대** — 1순위 **中國 明(15~16세기, 1439~1601 무렵) / 朝鮮 前期(태조~세종)** 80% · 2순위 元末明初 / 高麗末~朝鮮初 10%.
근거: 길 끝 楊繼洲(1601)·강의 本草綱目(1578), 거리의 鄕藥集成方(1433)·擇日 달력.

**② 레인별**
- 강(본초): 그물이 강을 가로지름 — 굵은 벼리줄(綱)+그물코(目), 코마다 약초 잎(약 45개, 「수많은 약물」 정도의 뜻, 1892종을 세는 숫자로는 안 읽힘) → **本草綱目**. 나루의 파란 옷 사람(허리에 붉은 둥근 열매 = 李?, 손에 약초 잎) → **李時珍**. 뒤 언덕 대숲은 뜻 미상.
- 길(왼→오):
  1. 갈색 옷 + 어깨에 봉황(鳳) + 땅에 꽂힌 침 약 18개 → **徐鳳 『鍼灸大全』**.
  2. 회색 옷 + 손에 자두(李) + 문틀(門) + 문 앞에 누운 통나무(문지방 → 넘어 들어감 = 入) → **李梴 『醫學入門』**(1575).
  3. 파란 옷 수염 사내 + 말(馬) + 노란 안장포(黃帝) + 등짐 2개(침이 꽂힌 죽간 더미 = 靈樞/鍼經, 묶인 죽간 더미 = 素問) + 가슴의 금빛 메달 → **馬蒔 『素問·靈樞 注證發微』**(靈樞 첫 전면 주석, 메달 = 「최초」?).
  4. 갈색 옷 + 흩어진 죽간 조각 + 다시 묶은 죽간 1다발 + 가위 → 經文을 잘라 부류별로 다시 묶음 → **張介賓 『類經』** 1순위(55%), 吳崑 『素問吳注』(경문 개정) 2순위.
  5. 회색 옷 + 버드나무(楊) + 침을 빽빽이 쌓은 누각(대성 = 集大成) + 둘레 흰 깃발 수십 개 → **楊繼洲 『鍼灸大成』**(1601).
- 거리(왼→오):
  1. 우물 + 산수화 간판(붉은 해·산·전각) + 지게 2틀에 약초 자루 → 지방 鄕藥을 거둬들이는 기관 → **濟生院**(1397) 1순위 / 惠民局 2순위.
  2. 담장 안 붉은 기둥 관아 + 침통(鍼筒) 그림 간판 + 약연(藥碾)을 새긴 나무판 → 침·약을 맡는 중앙 의료관청 → **典醫監** 또는 **內醫院**(미정).
  3. 펼친 큰 책: 왼쪽 면 = 초가(鄕)+약초 다발, 오른쪽 면 = 본초 칸 5개(꽃 / 열매 3알 / 잎 / 잎 / 뿌리 2뿌리) → **鄕藥集成方**(1433, 鄕藥本草 수록).
  4. 7×4칸 달력 + 한 칸에 불붙은 뜸봉(艾炷) + 금메달(金) → 날을 가려 침뜸 → **鍼灸擇日編集**(1447, 全循義·**金義孫**).

**③ 잔결** — 대숲 언덕·흰 깃발 무리·말 가슴 메달·산수화의 붉은 해·우물이 무엇을 나르는지 미상. 오른쪽 끝에서 흰 깃발과 거리 건물(금메달 건물)이 프레임에 잘림.

### [951]

**① 시대** — 1순위 **中國 明末(1600~1644) / 朝鮮 中期(선조~인조)** 80% · 2순위 明末淸初 / 朝鮮 中期 후반 15%.
근거: 王肯堂(1602)·吳有性(1642), 東醫寶鑑(1610)·鍼灸經驗方(1644).

**② 레인별**
- 강(본초): **빈 물결뿐 — 소품 없음.** (本草綱目 이후의 공백 구간으로 읽음.)
- 길(왼→오):
  1. 왕관(王) 쓴 사내 + 붓이 땅에 곧은 먹줄을 그음(準繩) → **王肯堂 『證治準繩』**(1602).
  2. 한 지붕 아래 다섯 사람 = 한 학파 → **溫補學派**. 아궁이에 불 땐 솥 = 釜底의 불(命門火·溫). 회색 정좌 사내 → **薛己**(?); 파란 옷 + 활(弓→張)·화살통(화살 약 6~7, 八陣?)·놀란 눈(驚→景?)·탕 그릇 → **張介賓 『景岳全書』**; 책 무더기 + 뒤의 갈색 사내 → 全書/叢書(薛氏醫案?) 또는 **趙獻可**; 흰 옷 아이(孫) + 붉은 물 잔(赤水) → **孫一奎 『赤水玄珠』**; 널판(梓) + 자두(李) → **李中梓**; 문고리 달린 큰 문(門) → 命門 = **趙獻可 『醫貫』**.
  3. 입이 얼굴만 하게 벌어진 사내(口 → 吳) + 입에서 나오는 여러 빛 기운 + 발밑 여러 색 웅덩이 6개 → 戾氣/雜氣가 口鼻로 들어옴 → **吳有性 『溫疫論』**(1642).
- 거리(왼→오):
  1. 보석 박힌 타원 거울(寶鑑) 속 인체 해부도(身形藏府圖), 두 사람이 받쳐 듦 → **東醫寶鑑**(1610, 許浚 외).
  2. 문 활짝 연 큰 빈 건물 — 소품 없음 → 미상(惠民署?).
  3. 백성 셋(머리띠 사내·흰 치마 여인·뒷모습 사내)이 들어가는 집 + 침통 간판 + 판목(木版) + 펼친 책 → **許任 『鍼灸經驗方』**(1644, 간행).

**③ 잔결** — 강 구간이 통째로 빔. 아궁이 솥 위 흰 방사무늬(찐빵?) 뜻 미상. 거리 가운데 큰 집 빈칸. 왼쪽 가장자리 x≈110에 세로 이음선(밝기 경계)이 길·거리를 관통. 950 오른쪽 강둑의 대숲 언덕이 951 첫머리에서 끊김(강둑 불연속).

## 2단계 — 계통 (사전 열람 후)

사전에서 맞물린 기호: 李=허리춤 자두 · 馬=고삐로 매인 말 · 張=활 · 王=왕관 · 吳=얼굴 절반만 한 입(⚠兌와 갈림 → 무대가 明 길이므로 吳) · 門=문틀 · 濟=물에 드리운 밧줄 · 收=아가리 묶은 삼베 자루 · 藥=배 모양 약연 · 內=담 안쪽 · 補=찰랑한 따뜻한 국물 · 溫=따뜻한 천 · 目=크게 뜬 눈 · 血=붉은 것. 갈림 항목(吳/兌, 舌, 陰) 조건을 확인하고 적용함.

### [950] — 2단계

**① 시대** — 1순위 **明(15~16세기) / 朝鮮 前期** 85% · 2순위 元末明初 / 高麗末~朝鮮初 8%. (변동: 거리 1번이 사전으로 濟生院 쪽으로 굳어 확신 소폭 상승.)

**② 레인별**
- 강: 나루 사내 허리춤의 붉은 열매 = 사전의 **李**(허리춤 자두) → **李時珍**이 확정. 벼리줄(綱)+그물코(目) 그물에 약초 → **本草綱目**. 대숲은 여전히 미상.
- 길:
  1. 봉황(鳳) + 침 약 18개 → **徐鳳 『鍼灸大全』** (사전 기호 없음, 1단계 유지).
  2. 허리춤 자두 = **李**, 문틀 = **門**(사전 일치), 문지방 통나무 = 入 → **李梴 『醫學入門』** — 사전으로 확정.
  3. 기둥에 고삐로 매인 말 = **馬**(사전과 정확히 일치), 明 무대 → **馬蒔**; 노란 안장포(黃帝) + 침 꽂힌 죽간·묶은 죽간 2짐 → 『素問·靈樞 注證發微』 2서.
  4. 가위 + 흩어진 죽간 + 다시 묶은 1다발 → 경문을 잘라 고침. 사전상 **張이면 활을 메야 하는데 활이 없음** → 張介賓 『類經』은 내려가고, 순서(馬蒔 1586 ↔ 楊繼洲 1601 사이)에 맞는 **吳崑 『素問吳注』**(1594, 경문 刪改) 1순위 45% / **張介賓 『類經』** 35%. 성씨 기호가 없어 미결.
  5. 버드나무(楊) + 침을 쌓은 누각(大成) → **楊繼洲 『鍼灸大成』**. 흰 깃발 무리는 사전에 없음.
- 거리:
  1. 우물 두레박 줄 = **濟**(물에 드리운 밧줄), 아가리 묶은 삼베 자루 = **收**, 산수화 = 지방(鄕) → 鄕藥을 거둬 구료 → **濟生院**(1397) 확신 상승.
  2. 담장 안 간판 = **內**, 배 모양 약연 = **藥**, 침통 간판 = 鍼(醫) → **內醫院(內藥房)** 1순위 / 典醫監 2순위(典藥=약봉지 다발 기호 없음).
  3. 펼친 큰 책(초가=鄕 + 약초 / 본초 5칸) → **鄕藥集成方**(1433) 유지.
  4. 7×4 달력 칸 위 불붙은 뜸봉 + 금메달(金) → **鍼灸擇日編集**(1447, 全循義·金義孫) 유지.

**③ 잔결** — 대숲 언덕·흰 깃발 수십 개·말 가슴 금 메달·산수화 속 붉은 해(陽?)는 사전으로도 안 풀림. 길 4번 사람만 성씨 기호가 없음. 오른쪽 끝 흰 깃발·금메달 건물이 프레임에 잘림.

### [951] — 2단계

**① 시대** — 1순위 **明末(1600~1644) / 朝鮮 中期(선조~인조)** 85% · 2순위 明末淸初 / 朝鮮 中期 후반 12%.

**② 레인별**
- 강: 소품 0 — 빈 물결. 사전으로도 채울 것 없음.
- 길:
  1. 왕관 = **王**(사전: 성만, 무대가 사람을 정함 → 明末) + 곧은 먹줄 → **王肯堂 『證治準繩』**.
  2. 큰 마루집(한 학파): 활 = **張**, 그 앞 상 위 **찰랑한 따뜻한 탕 = 補** + **흰 천 = 溫** → 「溫補」가 사전 기호로 그대로 읽힘 → **張介賓**을 대표로 한 **溫補學派**로 확정. 허리춤 자두 = **李** + 널판(梓) → **李中梓**. 흰 옷 아이 + 붉은 물 잔(사전 血=붉은 것이지만 여기서는 赤水로 읽음) → **孫一奎 『赤水玄珠』**. 큰 문 = **門** → 命門 → **趙獻可 『醫貫』**. 회색 정좌 사내 → **薛己**(기호 없음, 추정). 책 무더기 = 『景岳全書』/『薛氏醫案』 같은 큰 전집. 아궁이 불 = 陽(命門火).
  3. 얼굴 절반만 한 입 = **吳**(兌와 갈림 → 明 길이므로 吳) + 입에서 나는 여러 빛 기운(氣) + 여러 색 웅덩이 6개(雜) → **吳有性 『溫疫論』**, 雜氣·戾氣가 口鼻로 들어옴.
- 거리:
  1. 보석 테 거울(寶鑑) + 인체 장부도 + 받쳐 든 두 사람 → **東醫寶鑑**(1610, 許浚).
  2. 문 활짝 연 큰 빈집 — 사전 기호 없음(惠=빈 사발 무리 없음) → 미상.
  3. 침통 간판(鍼) + 판목·펼친 책(간행) + 백성 셋 → **許任 『鍼灸經驗方』**(1644).

**③ 잔결** — 강 구간 공백. 솥 위 흰 방사무늬 덩이(불 곁 얼음이면 陰, 찐빵이면 무의미 — 판정 불가). 張의 크게 뜬 눈이 사전상 **目**인데 나르는 사실 미상. 회색 정좌 사내·책 뒤 갈색 사내는 성씨 기호 없음. 거리 가운데 빈집. 왼쪽 x≈110에 세로 이음선. 950 오른쪽 강둑 대숲이 951 첫머리에서 끊김.

**판정** — 사전 어휘로 950 거리 1·2번(濟·收 / 內·藥)과 951 마루집(補+溫 = 溫補)이 1단계보다 분명해졌다. 950 길 4번은 사전 때문에 오히려 張介賓에서 멀어졌다.
