# blind19 판독 — 판독자 J (950 · 951)

Read 사용: 원판 2회(950, 951). 나머지는 crop_J/ 의 확대 조각으로 봄.

---

## 1단계 — 생판 (기호 사전 열기 전, 확정)

### [950] 왼쪽 구간

**① 시대** 1순위 中國 **明 중기~후기**(15세기 중엽~1600 무렵) / 朝鮮 **前期**(세종 대 전후) — 80%. 2순위 元末明初 / 高麗末·朝鮮初 — 12%.

**② 레인별 판독**
- **강**: 강을 가로지른 그물(綱+目) 안에 약초 포기 약 36개(정확한 수는 셀 수 없음) + 나루에 선 푸른 옷 사내(손에 초록 잎 = 本草, 허리에 붉은 둥근 열매 = 李?) → **李時珍 『本草綱目』**. 강 건너 대숲 언덕은 배경인지 다음 본초서인지 알 수 없음.
- **길** (왼→오):
  1. 어깨에 봉황(鳳) + 발치에 침 약 15개 꽂힘 → **徐鳳 『鍼灸大全』**
  2. 자두(李) 든 사내 + 빈 문틀(入門) + 쓰러진 긴 통나무(梴 = 긴 나무) → **李梴 『醫學入門』**
  3. 수염 사내 + 말(馬). 말 등 짐 2묶음(침이 꽂힌 죽간 = 靈樞/鍼經, 끈으로 묶은 죽간 = 素問) + 말 가슴에 금메달(최초) → **馬蒔 『素問注證發微』·『靈樞注證發微』**(靈樞 첫 전주)
  4. 갈색 사내 + 흩어진 죽간 조각 4~5개 + 새로 묶은 죽간 다발 + 가위 → 經文을 잘라 다시 묶음(분류) → **張介賓 『類經』** (2순위 吳崑 『素問吳注』)
  5. 회색 사내 + 버드나무(楊) + 침으로 쌓은 탑(大成) + 흰 깃발 수십 개 → **楊繼洲 『鍼灸大成』** (2순위 高武 『鍼灸聚英』: 高=탑, 武=깃발)
- **거리** (왼→오):
  1. 우물 + 해 뜨는 산수화 + 약초 자루 2개 건 나무틀 + 소년 → 鄕藥 수집·판매 기관, **濟生院**? / **惠民署**? (약함)
  2. 담장 대문 + 간판(갈색 통 + 선 3줄) + 바닥의 약연 → 의료 관서(**典醫監**?) (약함)
  3. 큰 책 펼침: 왼면 초가(鄕) + 큰 약초 다발(集成) → **『鄕藥集成方』**(1433) / 오른면 꽃·열매·잎·잎·뿌리 5칸(부위별 채취) → **『鄕藥採取月令』**(1431)
  4. 흰옷 소년 2명
  5. 달력 격자(7칸 너비) 한 칸에 뜸봉 + 금메달(金) → **『鍼灸擇日編集』**(1447, 全循義·金義孫)

**③ 잔결** 강 건너 대숲이 오른쪽 끝에서 뚝 잘림. 흰 깃발 무리도 오른쪽 끝 잘림. 대문 간판의 「통 + 선 3줄」 뜻 불명. 우물·산수화의 뜻 불명.

### [951] 오른쪽 구간

**① 시대** 1순위 中國 **明末**(1600~1644) / 朝鮮 **中期**(선조~인조) — 85%. 2순위 明末淸初 / 朝鮮 후기 — 10%.

**② 레인별 판독**
- **강**: 빈 물뿐, 소품 없음 → 이 구간에 놓인 본초서 없음(또는 綱目의 흐름이 이어짐).
- **길** (왼→오):
  1. 왕관(王) 쓴 사내 + 땅에 놓인 붓 + 길게 그은 먹줄(準繩) → **王肯堂 『證治準繩』**
  2. 정자 한 채에 5인 + 화덕 위 김 나는 솥(溫) + 국 그릇(補) + 문고리 달린 큰 문(命門) → **溫補學派** 묶음
     - 화덕 옆 회색 좌인 → **薛己**? (약함)
     - 활(弓+長 = 張) 멘 놀란 눈 사내 + 책 더미(全書) → **張介賓 『景岳全書』**
     - 책 더미 뒤 갈색 사내 → **趙獻可 『醫貫』**? (命門, 약함)
     - 붉은 물 든 병을 안은 아이(孫 + 赤水) → **孫一奎 『赤水玄珠』**
     - 자두(李) + 무릎 위 판자 든 사내 → **李中梓 『醫宗必讀』**
  3. 입을 크게 벌린 사내(吳 = 口+大) + 보라·초록 기운이 입으로 드나듦(口鼻而入) + 바닥에 6색 웅덩이(雜氣) → **吳有性 『溫疫論』**
- **거리** (왼→오):
  1. 보석 테 거울(寶鑑) 속 인체 장부도(身形藏府圖)를 두 관원이 받쳐 듦 → **許浚 『東醫寶鑑』**
  2. 문 열린 빈 큰 건물 — 뜻 불명(관서?)
  3. 흰옷 3인(머리띠 사내, 치마 여인, 들어가는 사람) — 서민 진료 기관? 醫女?
  4. 간판 침통 + 침 3개(鍼) + 상자(方) + 펼친 책 → **許任 『鍼灸經驗方』**(1644)

**③ 잔결** 강 전체가 비어 있음. 왼쪽 끝 x≈105 세로 이음선(따로 붙인 띠). 950 대숲이 이 판에서 이어지지 않음(강 색조도 다름). 가운데 빈 건물·흰옷 3인 뜻 불명. 화덕 속 붉은 것, 탁자 위 흰 천 뜻 불명.

## 2단계 — 계통 (blind6_사전요약.md 를 읽은 뒤 다시 읽기)

사전에서 이 두 판에 걸리는 항목: 王(왕관)·張(멘 활, 「明 서점」)·李(허리춤 자두)·馬(고삐로 매인 말)·吳(얼굴 절반만 한 입)·門(문간)·藥(배 모양 약연)·濟(물에 드리운 밧줄)·收(끈으로 조인 삼베 자루)·補(찰랑 찬 따뜻한 국물)·溫(김 오르는 따뜻한 천)·熱/陽(불꽃)·氣(서린 흰 김)·目(크게 뜬 눈)·血(붉은 것)·內(문 안쪽)·華(광택). 「갈림」 항목 중 걸리는 것은 吳(兌·口와 샘 → 의학사 무대이므로 吳로 가름) 하나뿐.

### [950] 다시 읽기

**① 시대** 1순위 **明(15세기 중엽~1601) / 朝鮮 前期(태조~세종)** 85%. 2순위 元末明初 / 高麗末·朝鮮初 8%. 성씨 표지(李·馬)가 明 무대를 굳힘.

**② 판독**
- **강**: 나루 사내 허리의 붉은 열매 = **李**(허리춤 자두)로 확정 + 그물(綱目) 속 약초 약 36포기 → **李時珍 『本草綱目』**. 1단계의 「李?」가 사전으로 풀림.
- **길**:
  1. 봉황 + 침 약 15개 → **徐鳳 『鍼灸大全』** (사전에 鳳 없음, 1단계 유지)
  2. 허리춤 자두 = **李** + 빈 문틀 = **門**(사전 등재) + 긴 통나무(梴) → **李梴 『醫學入門』** — 사전으로 확정
  3. 기둥에 고삐로 매인 말 = **馬**(사전 정의와 정확히 일치) + 짐 2묶음(침 꽂힌 쪽 = 靈樞, 묶인 쪽 = 素問) + 금빛 메달(광택 = 華? 또는 「최초」) → **馬蒔 『素問·靈樞注證發微』**
  4. 갈색 사내 + 잘린 죽간 + 다시 묶은 죽간 다발(흰 반짝임) + 가위. **활(張)이 없으므로 張介賓 『類經』은 철회**(사전상 明의 張은 서점 무대 = 951 정자). 입도 작아 吳 표지도 없음 → 성씨 표지 없는 의가. 후보 **吳崑 『素問吳注』**(經文 刪改, 1594 — 연대는 맞으나 吳 표지 부재) / **高武 『鍼灸節要』**(가위 = 節要). 미확정.
  5. 버드나무(楊) + 침 탑(大成) + 흰 깃발 수십 → **楊繼洲 『鍼灸大成』** (사전 무관, 1단계 유지)
- **거리**:
  1. 우물 두레박 줄이 물에 드리움 = **濟**, 아가리를 끈으로 조인 삼베 자루 = **收**(약초 거둠), 산수화 = 鄕(지방) → **濟生院**(1397, 鄕藥 수집·보급) — 1단계 「濟生院?/惠民署?」에서 濟生院으로 확정 쪽
  2. 담장 대문 + 배 모양 약연 = **藥** + 침통 간판(951 간판과 같은 꼴 = 鍼) → 藥·鍼을 맡은 관서. **典醫監**? (惠 표지인 빈 사발 없음 → 惠民署 아님) 미확정
  3. 펼친 큰 책: 초가(鄕) + 큰 약초 다발(集成) → **『鄕藥集成方』**(1433) / 오른면 부위별 5칸(꽃·열매·잎·잎·뿌리) → **『鄕藥採取月令』**(1431)
  4. 흰옷 소년 2명 (표지 없음)
  5. 달력 격자 한 칸의 뜸봉 + 금메달(金) → **『鍼灸擇日編集』**(1447, 全循義·金義孫). 2순위: 달력 = 月令 → 『鄕藥採取月令』

**③ 잔결** 강 건너 대숲(사전에 없음, 뜻 불명)이 오른쪽 끝에서 잘리고 951로 이어지지 않음. 흰 깃발 무리 오른쪽 잘림. 갈색 사내 묶음의 흰 반짝임·흰 깃발은 사전에 없음. 말·달력 곁 금메달 두 개의 뜻이 같은지 다른지 불명.

### [951] 다시 읽기

**① 시대** 1순위 **明末(1601~1644) / 朝鮮 中期(선조~인조)** 88%. 2순위 明末淸初 / 朝鮮 後期 8%. 王·張·李·吳 네 성씨가 모두 明末 인물로 맞물림.

**② 판독**
- **강**: 빈 물 — 이 구간 본초서 없음(綱目 뒤 공백).
- **길**:
  1. 왕관 = **王**(사전: 어느 王인지는 무대가 정함 → 明末) + 붓 + 땅에 그은 먹줄(準繩) → **王肯堂 『證治準繩』** — 확정
  2. 정자 = 사전의 「明 서점」(책 더미). 그 안:
     - 멘 활 = **張** → 明 서점이므로 **張介賓(景岳)**. 탁자 위 찰랑 찬 따뜻한 국 = **補**, 김 오르는 흰 천 = **溫** → **溫補** 확정. 크게 뜬 눈 = 目(뜻 불명). 책 더미 = 『景岳全書』
     - 허리춤 자두 = **李** → 明末이므로 **李中梓 『醫宗必讀』** (무릎 판자는 뜻 불명)
     - 붉은 물병 든 아이 → **孫一奎 『赤水玄珠』**(孫=아이, 赤水=붉은 물). 사전대로면 붉은 것 = 血이라 확신 낮음
     - 큰 문고리 문 = **門**(+문 안쪽 = 內) → **命門學說**(趙獻可·孫一奎·張介賓 공통)
     - 화덕 옆 회색 좌인(불꽃 = 熱/陽, 솥 김 = 氣) → 표지 없는 溫補 의가 **薛己**? / 책 뒤 갈색 사내 → **趙獻可 『醫貫』**? 둘 다 미확정
  3. 얼굴 절반만 한 입 = **吳**(갈림: 의학사 무대라 兌·口가 아니라 吳) + 입으로 드나드는 보라·초록 기운(口鼻而入) + 바닥 6색 웅덩이(雜氣) → **吳有性 『溫疫論』**(1642) — 확정
- **거리**:
  1. 보석 테 거울(寶鑑·광택 = 華) 속 인체 장부도 + 받쳐 든 관원 2명 → **許浚 『東醫寶鑑』** — 확정
  2. 문 열린 빈 큰 건물(문 안쪽 = 內) → **內醫院**? 미확정
  3. 흰옷 3인(머리띠 사내 · 치마 여인 · 들어가는 아이) → 서민용 **許浚 諺解 3서**(救急方·胎産集要·痘瘡集要, 1608)? 미확정
  4. 침통 간판(鍼) + 상자(方) + 펼친 책 → **許任 『鍼灸經驗方』**(1644)

**③ 잔결** 강 전체 공백. 왼쪽 끝 x≈105 세로 이음선. 화덕 속 붉은 것, 놀란 눈(目), 李의 무릎 판자, 가운데 빈 건물은 사전으로도 안 풀림.

### 판정
사전 어휘로 더 잘 풀린다. 李(李時珍·李梴·李中梓)·馬(馬蒔)·王(王肯堂)·張(張介賓)·吳(吳有性)·門(入門·命門)·濟(濟生院)·補+溫(溫補)이 확정되거나 굳어졌고, 1단계의 「950 갈색 사내 = 張介賓 『類經』」은 張 표지(활)가 없어 철회함. 남은 공백은 950 갈색 사내, 950 대문 관서, 951 정자 안 표지 없는 2인, 951 가운데 건물·흰옷 3인.
