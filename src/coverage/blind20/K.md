# blind20 판독 — 판독자 K

## 1단계 — 생판 (사전 열람 전, 그림만 보고 확정)

### [960]
① 시대: 1순위 **淸 전·중기(康熙~乾隆) / 朝鮮 후기(숙종~정조)** 80% · 2순위 明末淸初 / 朝鮮 중기 15%. 근거: 가운데 길 인물 전원이 변발(淸), 거리는 갓·도포의 조선 후기 풍경.
② 
- 강: 물가에 걸친 그물(=**綱目**) 사이로 빠져나온 풀을 여인이 줍는다(=拾遺) → **趙學敏 『本草綱目拾遺』**. 바닥 풀 4포기 + 손에 1 + 바구니 가득(개수 의미는 못 읽음).
- 길(왼→오):
  1. 머리에 주전자(=湯頭) + 노래 음표(=歌訣) + 짖는 개(=汪, '왕왕') → **汪昂 『湯頭歌訣』**(『醫方集解』『本草備要』 저자).
  2. 승려(=宗)가 금빛 원반(=金 거울, 鑑)을 받쳐 듦 + 둘레 흰 깃발 수십 개(대략 80~90, 정확 계수 불가) → **『醫宗金鑑』(吳謙 등 乾隆 勅撰)**, 깃발 = 90권?
  3. 엽전 꾸러미(=串)를 바늘이 끊어 두 줄(왼 약 13닢·오른 약 10닢)로 갈라지고 낱전 6닢 흩어짐 → **趙學敏 『串雅』(內編·外編, 鈴醫 비방)**. 두 줄 = 內·外 2편.
  4. 웅덩이(물줄기가 사방으로 흘러나감 = 源) 위 금빛 거북이 등에 뿔 모양 초(불꽃 = 心)를 지고 있음 → **黃元御 『四聖心源』**(黃=금빛, 元=黿 거북) 추정 / 2순위 **徐大椿 『醫學源流論』**(源流=웅덩이 물줄기, 靈胎=靈龜).
- 거리(왼→오):
  1. 왼쪽 빈 집 — 소품 없음.
  2. 갓 쓴 선비 + 검은 사제복(단추 달린 수단)·수염의 서양인이 해골 그림 두루마리 → **서양 해부학 전래 — 李瀷 『星湖僿說』 西國醫(湯若望 『主制群徵』)** / 2순위 **崔漢綺 『身機踐驗』**.
  3. 툇마루의 김 나는 약탕관 + 펼친 책 → 미상(**『濟衆新編』** 후보).
  4. 갓 쓴 사내가 얼굴에 붉은 반점 난 아기를 안음 → **丁若鏞 『麻科會通』**(麻疹) / 2순위 李獻吉 『麻疹方』.
  5. 흰옷 소년 2명 — 소품 없음.
③ 거북 등의 '뿔인지 초인지' 모호. 깃발 개수 셀 수 없음. 거리 2·5번 자리 빈 인물/빈 집. 960→961 가운데 길 점포 지붕·거리 기와집 배치가 똑같이 반복(같은 바탕 틀 재사용).

### [961]
① 시대: 1순위 **淸 중·후기(乾隆 말~咸豐) / 朝鮮 후기(순조~고종)** 85% · 2순위 淸末 / 大韓帝國 10%.
② 
- 강: 비어 있음(본초서 소품 없음).
- 길(왼→오):
  1. 왕관(=王) + 묘목 숲(=林, 4그루 + 지지대로 바로잡은 1그루 = 改錯) + 장부 해부도 두루마리 → **王淸任 『醫林改錯』**(장부도 교정).
  2. 잎사귀 옷(=葉) + 4겹 과녁(흰·노랑·주황·빨강, 겉→속) → **葉天士(葉桂) 『溫熱論』 衛氣營血辨證**(4층).
  3. 머리에 눈(=雪) + 김 나는 젖은 땅(=濕熱) + 뒤로 흐르는 도랑(=條) → **薛雪(薛生白) 『濕熱條辨』**.
  4. 입 크게 벌려 외침(=吳, 口) + 3단 계단 폭포(파랑·노랑·주황 3층 = 上·中·下焦) → **吳鞠通(吳瑭) 『溫病條辨』 三焦辨證**.
  5. 작은 왕관(=王) + 베틀(=經緯) + 천 위의 불(=溫熱) → **王孟英(王士雄) 『溫熱經緯』**.
- 거리(왼→오):
  1. 소년 1 — 소품 없음.
  2. 큰 기와집 문 열림, 약장 서랍(4×4) + 끈으로 묶은 책 2권 → **黃度淵 『方藥合編』**(약장=方藥, 묶음=合編) / 2순위 『濟衆新編』.
  3. 소년 2 — 소품 없음.
  4. 갓 쓴 사내(보라 주머니) + 도르래 달린 물웅덩이 속 말(=濟+馬) + 칸 4개짜리 그림 펼친 책 → **李濟馬 『東醫壽世保元』 四象醫學**.
③ 강이 텅 빔. 보라 주머니 뜻 모름. 소년 3명 빈자리.

### [962]
① 시대: 1순위 **(중국 행 종료) 朝鮮 말 개항기 ~ 大韓帝國·日帝强占 초(1880~1910년대)** 85% · 2순위 高宗 개항기만(1876~1897) 10%. 전신주·벽돌 양옥·제복·양복.
② 
- 강: 비어 있음.
- 길(한국, 왼→오):
  1. 흰 수염 노인(분홍 주머니)이 두 팔로 붉은 해를 떠받침(=扶陽) → **李圭晙(石谷) 扶陽論**(『醫鑑重磨』) / 2순위 이제마(太陽人).
  2. 갓 쓴 사내 + 쪽지 놓인 요람 속 아기 → 미상(소아 관련 의서?).
  3. 회색 도포·검은 관(가슴에 새싹 = 生) + 바닥 금빛 솔 + 쪽지 읽는 제복 관리, 뒤 간판 = 우산(廣) + 물속으로 내린 밧줄(濟), 안쪽 약장 → **廣濟院(1900)** + **醫生規則(1913, 醫師→醫生)**.
  4. 청진기 그려진 집 → 양의 진료(광제원 양방/대한의원 계열).
  5. 짓고 있는 비계 건물 → 신축 기관.
- 거리(왼→오):
  1. 금메달 붙은 벽돌집 + 우물(=池)에서 모종 화분(=種) 들고 나오는 사내 → **池錫永 種痘法(『牛痘新說』)**.
  2. 갈색 외투·양복 신사 2 — 소품 없음.
  3. 기와집 대문의 서양인(콧수염 양복) + 왼 간판: 우산 아래 잔 받드는 손 4(=廣惠), 끈 끊겨 늘어짐 / 오른 간판: 물속 4명 밧줄로 구함(=濟衆) → **廣惠院 → 濟衆院(1885, 알렌)** 개칭.
  4. 회색 도포 1 — 소품 없음.
  5. 5명이 장대·줄을 함께 당기는 간판 문 + 바닥 비단 주머니(한의) + 금메달(양의) → **東西 합동 단체/학교**(**同濟醫學校** 또는 대한의사총합소?) 미확정.
  6. 벽돌 양옥 + 중절모 신사 → **大韓醫院(1907)?**
③ 금빛 솔, 요람 쪽지, 금메달·주머니의 뜻 미상. 거리 순서가 연대순(제중원 1885이 지석영 뒤)과 어긋남. 961→962 사이 거리 풍경이 기와→벽돌로 급변(이어 붙인 경계로 보이지 않음, 강·언덕 바탕은 세 판 동일 반복).

## 2단계 — 계통 (blind6_사전요약.md 열람 후)

총평: 사전으로 **새로 풀린 것** = 허리춤 보라·분홍 동그라미가 주머니가 아니라 **자두(李)**, 간판 글자 **廣(차양)·惠(빈 사발 드는 손들)·濟(물에 드리운 밧줄)·衆(한 밧줄에 여럿)·同(한 밧줄 함께 당김)**, 吳(큰 입)·王(왕관) 확인, 中·下(3단 폭포)·熱(불꽃)·溫(천)·內濕(발밑 진창)·氣(김) 확인. 사전으로 **안 풀리는 것** = 주전자·개·승려·금원반·깃발·엽전·바늘·거북·그물·요람·금메달·금빛 솔·새싹(사전에 없는 고유 소품).

### [960]
① 1순위 **淸 전·중기 / 朝鮮 후기(영·정조)** 80% · 2순위 明末淸初 / 朝鮮 중기 10%. (변경 없음)
② 
- 강: **趙學敏 『本草綱目拾遺』** — 그물(綱目)에서 빠진 풀을 주움(拾遺). 사전 기호 없음, 1단계 유지.
- 길:
  1. **汪昂 『湯頭歌訣』** — 머리 위 주전자(湯頭)·음표(歌訣)·짖는 개(汪). 사전 기호 없음, 유지.
  2. **『醫宗金鑑』(吳謙, 乾隆 勅撰)** — 승려(宗) + 금빛 원반(金鑑) + 흰 깃발 수십(≈90권 추정). 유지.
  3. **趙學敏 『串雅』 內·外編** — 바늘에 끊겨 두 줄로 갈린 엽전 꾸러미(약 13닢·10닢) + 낱전 6닢. 사전의 傷(깨져 못 쓰게 됨)·散(흩어짐)으로도 읽히나 표제 결정엔 무력. 2순위 **徐大椿 『醫貫砭』**(貫=엽전 꿰미를 砭=침이 찌름).
  4. 사전 적용: 거북 등 **살아 있는 불꽃 = 陽**, 그 밑 **졸아든 웅덩이 = 陰**(산 불과 맞대어 조건 충족) → 陽을 陰 위로 받쳐 든 무대 = 扶陽抑陰 → **黃元御 『四聖心源』**(금빛=黃, 웅덩이 물줄기=源) 1순위 유지, 2순위 **徐大椿 『醫學源流論』**.
- 거리:
  1. 빈 집 — 없음.
  2. **서양 해부학 전래(李瀷 『星湖僿說』 西國醫·湯若望)** — 사제복 서양인 + 해골도(骨). 2순위 **崔漢綺 『身機踐驗』**. 갓은 복식으로 보고 太로 읽지 않음.
  3. 김(氣) 나는 약탕관 + 펼친 책 → 미상(**『濟衆新編』**? 그러나 濟·衆 기호 없음 → 약화).
  4. **丁若鏞 『麻科會通』** — 붉은 반점 아기(사전: 살갗 반점은 瘀가 아니라 그 자리의 색 → 발진 그대로). 2순위 李獻吉.
  5. 소년 2 — 없음.
③ 거북 등 물건(뿔/초) 모호, 깃발 수 불명, 빈 인물·빈 집, 960·961 바탕 배치 복제.

### [961]
① 1순위 **淸 중·후기(溫病學派, 乾隆~咸豐) / 朝鮮 말(순조~고종)** 85% · 2순위 淸末 / 大韓帝國 10%.
② 
- 강: 비어 있음.
- 길:
  1. **王淸任 『醫林改錯』** — 王(왕관, 사전 확인·무대=淸) + 숲(林, 4그루+버팀목 1그루=改錯) + 장부도.
  2. **葉天士 『溫熱論』 衛氣營血** — 잎 옷(葉) + 4겹 과녁, 한복판이 붉음(血) = 衛→氣→營→血.
  3. **薛雪 『濕熱條辨』** — 머리 위 눈 더미(雪; 사전의 寒 눈송이와 겹치지만 이름 쪽이 맞음) + **자기 발밑에서 배어 나오는 진창 = 內濕** + 서린 김(氣/熱) = 濕熱.
  4. **吳鞠通 『溫病條辨』 三焦辨證** — 얼굴 절반만 한 입 = **吳(사전 확인)** + 3단 폭포: 위·**中(셋 중 가운데)**·**下(쏟아짐)** = 上·中·下焦 3.
  5. **王孟英 『溫熱經緯』** — 王 + 베틀(經緯) + 천 위 불꽃 = **熱**, 김 오르는 천 = **溫**.
- 거리:
  1. 소년 — 없음.
  2. 문 열린 큰 집, 약장 서랍 + 끈으로 묶은 책 4권(2×2) → **黃度淵·黃泌秀 『方藥合編』**(약장=方藥, 묶음=合編). 사전의 **典藥(끈 묶은 약봉지 다발)** 으로 읽으면 典醫監 계열 기관이 되나, 그림은 책 표지·책장이 분명해 2순위.
  3. 소년 2 — 없음.
  4. **李濟馬 『東醫壽世保元』 四象醫學** — 허리춤 자두 = **李**, 물에 드리운 도르래 밧줄 = **濟**, 말 = **馬**(사전 확인), 칸 4개 그림책 = 四象.
③ 강 비어 있음, 소년 3명 빈자리.

### [962]
① 1순위 **(중국 행 종료) 開港期~大韓帝國·日帝强占期(1879~1930년대)** 85% · 2순위 高宗 개항기만(1876~1897) 10%.
② 
- 강: 비어 있음.
- 길(한국):
  1. **李圭晙(石谷) 扶陽論** — 허리춤 자두 = **李**(사전으로 새로 확정) + 두 팔로 떠받친 해 = **陽**.
  2. 큰 갓(**太**?) + 쪽지 놓인 요람 갓난아기 → 미상. 후보 **太醫院(1895)** / 『醫方新鑑』(갓난아기=新).
  3. 간판 = 차양 **廣** + 물에 드리운 밧줄 **濟** → **廣濟院(1900)**, 안쪽 약장(한방과). 회색 도포 한의(가슴 새싹=生?) + 문서 든 제복 관리 + 땅의 금빛 솔(사전 **瀉 짚 빗자루**? 뜻 안 맞음) → **醫生規則(1913)** 추정.
  4. 청진기 집 → 양방 진료. 5. 비계 신축 건물.
- 거리:
  1. 우물(池) + 모종 화분(種) → **池錫永 種痘法** + 금메달 벽돌집(醫學校?).
  2. 신사 2 — 없음.
  3. **廣惠院 → 濟衆院(1885, 알렌)** — 왼 간판 廣(차양)+**惠(빈 사발 받드는 손 4)**, 끈 끊겨 늘어짐(옛 이름), 오른 간판 **濟+衆(한 밧줄에 4명)**. 사전으로 확정.
  4. 회색 도포 1 — 없음.
  5. 문 간판 5명이 한 밧줄을 함께 당김 = **同** + 주머니·금메달 → **同濟醫學校(1906)** 1순위(濟 기호는 없음), 2순위 한의 단체(총합소 등).
  6. 벽돌 양옥 + 신사 → **大韓醫院(1907)?**
③ 금빛 솔·요람 쪽지·금메달(두 번)·비단 주머니 뜻 미상, 거리 순서와 연대 일부 불일치, 962 바탕이 기와→벽돌로 급변.
