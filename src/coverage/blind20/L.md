# blind20 판독 — 판독자 L (960 · 961 · 962)

## 1단계 — 생판 (사전 없이 그림만)

### [960]
**① 시대**: 1순위 中 淸 전·중기(강희~건륭) / 韓 朝鮮 후기(영·정조) — 85%. 2순위 明末淸初 / 朝鮮 중기 — 10%. 근거: 가운데 길 인물 전원 변발(淸), 아래 거리는 갓·도포의 조선, 서양 신부 등장(西學 유입기).
**② 레인별**
- 강: 아낙이 그물(굵은 벼리 밧줄=綱, 그물코=目) 곁에서 흘린 풀을 줍는다(拾遺) → **本草綱目拾遺**(趙學敏). 흩어진 풀 3포기 + 손에 1포기 + 바구니 1.
- 길(왼→오):
  1. 머리에 탕관(湯) + 노래(歌) + 짖는 개(汪汪=汪) → **汪昂 『湯頭歌訣』**.
  2. 황금 거울(金鑑)을 치켜든 인물 + 발치 흰 깃발 수십 개(대략 80~90, 90권 추정) → **吳謙 『醫宗金鑑』**(90권, 칙찬).
  3. 땅에 꽂힌 바늘 + 끊어진 엽전 꿰미 두 줄(串) + 낱전 5개 → **趙學敏 『串雅』(內·外編)** — 바늘 끝(頂)·꿰미(串)·끊음(截) = 走方醫 三法 추정. 대안 **趙獻可 『醫貫』**.
  4. 물웅덩이의 금빛 거북(느림=徐) 등에 촛불 뿔, 웅덩이에서 물줄기가 흘러나감(源流) → **徐大椿 『醫學源流論』**. 대안 **黃元御 『四聖心源』**(금빛=黃, 불=心, 샘=源).
- 거리(왼→오): 빈 집 → 서양 신부가 해골(골격) 두루마리를 갓 쓴 선비에게 보여 줌 → **西洋 해부학 유입(李瀷 『星湖僿說』 西國醫)**, 대안 **崔漢綺 『身機踐驗』** → 반점 아기를 안은 갓 선비 + 김 나는 탕관 + 펼친 책 → **丁若鏞 『麻科會通』**(마진), 대안 李獻吉 『麻疹奇方』 → 소품 없는 총각 2명.
**③ 잔결**: 거리 오른쪽 총각 2명·왼쪽 빈 집은 소품이 없어 뜻 불명(빈 칸/자리채움?). 거북 등 '뿔 모양 촛불'이 뿔인지 초인지 애매.

### [961]
**① 시대**: 1순위 中 淸 중·후기(가경~함풍) / 韓 朝鮮 말기(고종) — 85%. 2순위 淸 전기 / 朝鮮 후기 — 10%.
**② 레인별**
- 강: 비어 있음(본초 소품 없음).
- 길(왼→오):
  1. 왕관(王) + 어린 나무 숲(林) 5그루 + 버팀목으로 바로잡은 나무 1그루(改錯) + 장부도 두루마리 → **王清任 『醫林改錯』**(장부 오류 교정).
  2. 온몸 나뭇잎(葉) + 4겹 과녁(흰·노랑·주황·빨강) → **葉桂(天士) 『溫熱論』 衛氣營血 4단계**.
  3. 머리에 눈(雪) + 젖은 땅에서 김(濕+熱) → **薛雪 『濕熱條辨』**.
  4. 입 크게 벌린 인물(吳) + 3단 물계단(파랑·노랑·갈색) + 김(溫) → **吳瑭(鞠通) 『溫病條辨』 三焦辨證**(3단).
  5. 왕관(王) + 불무늬가 짜이는 베틀(經緯) → **王士雄(孟英) 『溫熱經緯』**.
  ※ 3~5 사이로 물길이 흐름 = 溫病學派 묶음 표지?
- 거리(왼→오): 소품 없는 총각 1 → 약장(藥欌) 앞 끈으로 묶은 책 2권(合編) → **黃度淵·黃泌秀 『方藥合編』**(1885) → 소품 없는 총각 2 → 갓 선비 + 두레박 물에서 건져지는 말(濟+馬) + 펼친 책 + 자줏빛 주머니 → **李濟馬 『東醫壽世保元』**(사상의학, 1894).
**③ 잔결**: 총각 3명 소품 없음. 이제마 허리 자주색 둥근 것(주머니/열매) 뜻 불명. 강이 비어 본초 계보 단절.

### [962]
**① 시대**: 중국 행 종료 — 가운데 길도 한국. 1순위 開港期~大韓帝國(1876~1910) — 75%. 2순위 日帝强占期 초(1910~20년대) — 20%. 근거: 전신주·벽돌 양관·순사/학생 제복·청진기 간판.
**② 레인별**
- 강: 비어 있음.
- 길(한국, 왼→오):
  1. 털모자 노인이 두 손으로 붉은 해를 떠받침(扶陽) + 분홍 주머니 → **李圭晙(石谷) 扶陽論 『醫鑑重磨』**.
  2. 갓 선비 + 요람(搖籃=탄생지) 아기 + 쪽지 → **池錫永** — 牛痘 種痘 혹은 **醫學校(1899) 설립** 추정(불확실).
  3. 간판: 넓게 펼친 우산(廣) + 물로 드리운 사슬(濟) → **廣濟院**(1900, 한·양방 병설). 사모 쓴 회색 도포 인물 가슴에 새싹(生=醫生) + 제복 관리가 문서 전달 + 금빛 솔 → **醫生規則(1913) 의생 면허** 추정.
  4. 청진기 간판 집 → **서양의학 진료소(양의)**. 그 아래 비계(공사 중 골조).
- 거리(왼→오):
  1. 금메달(최초) 벽돌 양관 + 우물에서 밧줄로 건져지는(濟) 사람이 새싹 화분(生)을 듦 → **濟生醫院**(1877 부산, 최초 서양식 병원).
  2. 갈색 외투·중절모 남 2명(소품 없음).
  3. 한옥 문 앞 서양 신사(알렌) + 간판①우산 아래 잔 4개 받드는 손(廣惠) + 간판②물속 4명이 밧줄 잡음(濟衆) → **廣惠院→濟衆院**(1885, 개칭).
  4. 한옥 대문 간판 '5명이 한 줄 당기기'(同) + 땅의 복주머니(內帑金?)·금메달(최초) → **同濟醫學校**(1906, 최초 근대식 한의 교육기관) 추정. 대안 **大韓醫院**(1907 통합).
  5. 중절모 남 + 비계 얹힌 3층 벽돌관 → **大韓醫院/세브란스** 건립(불확실).
**③ 잔결**: 비계 골조가 거리 건물 지붕에서 길 레인까지 솟아 레인 경계 침범(이어 붙인 흔적 의심). 금빛 솔·분홍 주머니 뜻 불명. 소품 없는 남자 3명.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

판정 요약: 사전 어휘는 **성씨 표지(王·李·吳)와 기관명 글자(濟·廣·惠·衆·同)**에서 1단계 추정을 확증·보강했다. 의미가 바뀐 곳은 "허리춤 둥근 자줏빛·분홍 열매 = 李" 두 곳(뜻 모를 소품 → 확정 글자)과 961 거리 묶음의 「典藥」 갈래뿐이다. 960은 사전 기호가 거의 쓰이지 않아(骨 정도) 1단계 그대로다.

### [960]
**① 시대**: 1순위 淸 전·중기 / 朝鮮 후기(영·정조) — 85%. 2순위 明末淸初 / 朝鮮 중기 — 10%.
**② 레인별**
- 강: **本草綱目拾遺**(趙學敏) — 벼리(綱)·그물코(目) 그물 + 흘린 풀 줍기(拾遺), 풀 3+1포기·바구니 1. 사전 기호 없음.
- 길: **汪昂 『湯頭歌訣』**(탕관=湯·노래=歌·짖는 개=汪) → **吳謙 『醫宗金鑑』**(황금 거울=金鑑, 깃발 수십=90권 추정; 큰 입이 아니므로 사전의 吳 기호는 없음 — 인물보다 책을 표지) → **趙學敏 『串雅』**(바늘+끊긴 꿰미 2줄=內·外編, 낱전 약 6; 사전의 痛(살에 박힌 못)은 땅에 꽂힌 바늘이라 해당 없음. 대안 趙獻可 『醫貫』) → **徐大椿 『醫學源流論』**(느린 거북=徐, 웅덩이에서 흘러나가는 물=源流, 촛불=陽? 대안 黃元御 『四聖心源』).
- 거리: 빈 집 → **西洋 해부학 유입**(신부의 해골도 = 骨; 李瀷 『星湖僿說』 西國醫, 대안 崔漢綺) → **丁若鏞 『麻科會通』**(붉은 반점 아기=麻疹, 김 나는 탕관·펼친 책; 대안 李獻吉) → 총각 2명.
**③ 잔결**: 총각 2·빈 집 무소품. 거북 등 '뿔 같은 초' 정체 애매. 960·961의 길·거리 배경 건물 배치가 거의 동일(배경 복제 흔적).

### [961]
**① 시대**: 1순위 淸 중·후기(가경~함풍) / 朝鮮 말기(고종) — 90%. 2순위 淸 전기 / 朝鮮 후기 — 7%.
**② 레인별**
- 강: 비어 있음.
- 길: **王清任 『醫林改錯』**(왕관=王 확정, 숲=林 5그루+버팀목으로 바로잡은 1그루=改錯, 장부도) → **葉桂 『溫熱論』**(잎옷=葉, 4겹 과녁 = 衛·氣·營·血, 가장 안쪽 붉음=血) → **薛雪 『濕熱條辨』**(머리 위 눈덩이=雪 — 눈송이가 아니므로 寒 아님; **자기 발밑에서 배어 나오는 진창 = 內濕(脾)** + 김 → 濕熱이 脾胃(太陰·陽明)에서 남) → **吳瑭 『溫病條辨』**(얼굴 절반 큰 입 = 吳 확정, 3단 물계단 = 上·中·下 三焦, 김) → **王士雄 『溫熱經緯』**(왕관=王, 베틀=經緯, 짜인 불꽃=熱).
- 거리: 총각 1 → **黃度淵·黃泌秀 『方藥合編』**(약장 앞 끈으로 묶은 2×2 꾸러미=合編; 사전 「典藥 = 끈으로 묶은 약봉지 다발」 갈래로 읽으면 '문 안쪽(內)의 典藥' 관청이 되나, 조선 말 무대와 맞는 관청이 떠오르지 않아 2순위) → 총각 2 → **李濟馬 『東醫壽世保元』**(허리춤 자두 = 李, 물에서 밧줄로 건져지는 말 = 濟+馬, 펼친 책; 사상의학 1894).
**③ 잔결**: 총각 3명 무소품. 꾸러미가 책인지 약봉지인지 애매(典藥 갈래와 충돌).

### [962]
**① 시대**: 1순위 開港期~大韓帝國(1876~1910) — 80%. 2순위 日帝强占期 초(1910~20년대) — 15%. 중국 행 종료, 길도 한국.
**② 레인별**
- 강: 비어 있음.
- 길: **李圭晙 扶陽論**(허리춤 자두 = 李 확정, 해 = 陽 을 두 손으로 떠받침 = 扶陽; 『醫鑑重磨』) → **池錫永**(갓·요람 아기·쪽지 — 種痘 또는 醫學校 1899 설립, 사전 기호 없음, 불확실) → **廣濟院**(1900; 간판 넓은 차양 = 廣 + 물에 드리운 사슬 = 濟 확정) + 사모 쓴 회색 도포 인물(가슴 새싹=生 → 醫生) + 제복 관리의 문서 = **醫生規則(1913) 의생 면허** 추정; 금빛 솔은 사전의 瀉(짚 빗자루)일 수 있음 → 한의 배제? → **서양의학 진료소**(청진기 간판).
- 거리: **濟生醫院**(1877 부산; 우물에서 밧줄로 건져지는 사람 = 濟 확정 + 새싹 = 生, 금메달 = 최초) → 외투·양복 남 2 → **廣惠院 → 濟衆院**(1885, 알렌; 차양 = 廣 + 여러 손이 받드는 빈 사발 4 = 惠 / 물속 4명이 한 밧줄 = 濟·衆 확정) → **同濟醫學校**(1906; 여럿이 한 밧줄을 나란히 당김 = 同 확정, 단 濟(물) 기호 없음; 복주머니 = 內帑金?, 금메달 = 최초 근대 한의 교육기관?) → 중절모 남 + 비계 얹힌 3층 벽돌관 = **大韓醫院**(1907) 추정.
**③ 잔결**: 同 간판에 濟가 빠져 '同○'의 둘째 글자 미확정. 금빛 솔·복주머니·금메달 사전에 없음. 비계가 거리 건물 지붕에서 길 레인으로 넘어옴(이어붙임 의심). 무소품 남 3명.
