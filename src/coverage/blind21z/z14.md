# z14 판독 (blind21z)

## 1단계 — 생판 (사전 없이)

**① 단원**: 1순위 **五行 歸類(五行配屬 — 五時·五氣·五色·五味·五化)** 50%. 2순위 **六淫(濕邪 중심)** 35%, 3순위 **五運六氣 主氣** 15%.
근거: 띠 하나 안에서 하늘이 왼쪽 해+아지랑이(夏) → 가운데 비(長夏) → 오른쪽 낙엽(秋)으로 계절이 흐르고, 땅도 가운데 물웅덩이 → 오른쪽 갈라진 마른 땅으로 바뀐다. 계절 순서로 인물을 늘어놓은 통합판.

**② 가운데 인물: 土(長夏·脾)**
- 인물: 온통 누런 옷 = **黃色**(五色). 삿갓 쓴 농부 = 土爰稼穡. 띠 정중앙에 꼿꼿이 섬 = 中央(五方).
- 발: 바짓단 걷고 맨발로 물웅덩이에 서 있고 김이 피어오름 = 長夏의 **濕**(五氣), 濕熱 薰蒸. (六淫으로 읽으면 傷於濕者 下先受之.)
- 하늘: 夏(해)와 秋(낙엽) 사이에 내리는 비 = 長夏는 여름과 가을 사이에 끼인 계절.
- 배경: 누렇게 익는 곡식밭 + 볏단 1 = **化**(生長化收藏) · 稼穡.
- 탁자 위 꿀단지(꿀이 흘러넘침) 1 = **甘**(五味). 대안: 흘러내리는 끈적함 = 濕性粘滯.
- 셀 것: 볏단 1·꿀단지 1 — 개수로 나르는 사실은 못 찾음.

**③ 잔결**
- 왼쪽 아래 빈 나무걸상: 뜻 불명(왼쪽 이웃 몫일 가능성).
- 꿀단지 탁자가 土 인물과 오른쪽 白衣 갓 쓴 양반(金·秋·燥로 추정) 사이에 걸쳐, 누구 소품인지 모호.
- 해와 비가 한 하늘에 동시(여우비) — 띠 이음매이거나 暑+濕 의도.
- 머리 회색 띠(망건?) — 首如裹일 가능성은 약함.
- 인물이 아픈 기색 없이 평온 → 병인(六淫)보다 배속(五行) 쪽으로 기움.

## 2단계 — 계통 (blind6 사전으로 다시 읽기)

**① 단원**: 1순위 **五行 歸類(五臟 配屬 — 五時·五氣·五味·五方)** 60%. 2순위 **六淫(暑·濕·燥의 계절과 臟 친화)** 30%, 3순위 **內生五邪** 10%.
사전으로 왼쪽 끝 잘린 붉은 옷 = 붉은 곤룡포 임금 = 心, 오른쪽 = 흰 도포 재상 = 肺. 心→脾→肺 = 火→土→金 相生 순서. 五味 글자(甘)가 臟 곁에 붙어 있어 배속표 쪽으로 더 기운다.

**② 가운데 인물: 脾**(노란 밀짚모자 농부, 사전 확정)
- 자리: 心과 肺 「둘 사이의 한복판」, 몸 위 = **中** → 脾土가 中央에 있음.
- 하늘의 부슬비 = 外濕 → 長夏의 氣 = **濕**(濕氣通於脾·脾惡濕).
- 발밑 물웅덩이: 「자기 발밑의 진창」이면 **內濕(脾)** 갈림. 다만 비가 같이 내려 外濕과 경계가 흐림.
- 나무 국자 꽂힌 꿀단지 = **甘** → 甘入脾.
- 곡식밭·볏단: 사전에 없음 → 생판 해석(長夏 **化**·稼穡) 유지.
- 이웃 단서: 해 = 陽(夏·心 쪽), 갈라진 땅 + 곧게 지는 마른 잎 = **燥**(秋·肺 쪽).
- 개수로 나르는 사실: 없음.

**③ 잔결**
- 빈 나무걸상: 사전에 없음. 「가구 위면 官」이지만 위에 아무것도 없어 뜻 불명.
- 비(外濕)와 발밑 웅덩이(內濕)가 한 자리에 겹쳐 外/內 판정 불가.
- 발밑 흰 김: 「氣 = 서린 흰 김」인지 「안개 = 外濕」인지 두 겹.
- 꿀단지 탁자가 脾와 肺 경계에 걸려 있으나, 국자 꽂힌 꿀단지 = 甘이 확정이라 脾 몫으로 판정.
- 해와 비가 한 하늘에 동시에 있음 = 띠 이음매.
- 판정: 사전 어휘로 인물(脾)·이웃(心·肺)·甘·濕·燥가 확정돼 1단계보다 잘 풀림.
