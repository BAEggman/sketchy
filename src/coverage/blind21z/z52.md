# z52 판독 (blind21z)

## 1단계 — 생판 (사전 열기 전, 그림만)

**① 단원(통합판 전체)**
- 1순위 **五行 歸類(五行配屬表)** — 55%
- 2순위 **六淫/六氣(계절 기후)** — 30%, 3순위 **五運六氣 主氣(太陰濕土→陽明燥金→太陽寒水)** — 15%
- 근거: 띠 안에서 왼쪽(비·푸르누런 들) → 가운데(낙엽·마른 땅) → 오른쪽(눈·얼음·검은 옷)이 **長夏(濕)→秋(燥)→冬(寒)** 순으로 이어진다. 가운데 인물에 기후뿐 아니라 色(白)·味(辛)·化(收)까지 붙어 있어 六淫 한 개념보다 五行 한 行의 歸類 묶음으로 읽힌다.

**② 띠 한가운데 인물: 金(秋·燥)** — 흰 도포에 갓 쓴 선비, 손에 낫
- 인물(흰 도포) = **白**, 金의 색
- 낫 = **收**(生長化收藏 중 收) / 秋의 肅殺
- 볏단 2개 = 秋收, 가을 거두기
- 떨어지는 낙엽 5장 = **秋**(肅降). 5라는 개수는 뜻을 모름(五之氣?)
- 거북등처럼 갈라진 마른 땅 = **燥**(기후. 燥性乾澁·津液 손상)
- 걸상 위 고추 접시(고추 3개) = **辛**, 金의 味
- 배경 왼쪽: 빗줄기와 푸른 이삭 = 이웃 **土(長夏·濕)** 몫
- 배경 오른쪽: 눈·얼음 바닥·초가·검은 잠수복 사람·입김 = 이웃 **水(冬·寒·黑, 초가=藏?)** 몫

**③ 뜻 모를 것 / 어색한 것 / 이음 흔적**
- 검은 갓과 양반 신분이 무엇을 나르는지 모르겠다(肺=相傅之官?).
- 낙엽 5장, 고추 3개라는 개수의 뜻을 모르겠다.
- 초가에 기대 둔 막대기, 잠수부 입김(흰 뭉게), 왼쪽 끝에서 잘린 나무 걸상은 뜻을 모른다.
- 마른 흙 바닥이 고추 걸상 근처(가로 약 3/4 지점)에서 얼음 바닥으로 바뀐다. 하늘도 비 오는 맑은 하늘에서 눈 오는 회청색으로 그라데이션된다. 날카로운 이음선은 없고, 고추 걸상이 두 바닥의 경계에 걸쳐 있다.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원**: **五行 歸類(五臟 配屬)** — 70%
- 사전에서 「흰 도포 재상 = 肺」, 「검은 잠수복·고글 잠수부 = 腎」이다. 그래서 이 판은 오행왕국 五臟 인물을 늘어놓은 歸類판으로 확정한다. 왼쪽(비 = 外濕, 脾 자리) → 肺 → 腎으로 土→金→水 相生 순서가 이어진다.
- 「燥 = 肺, 寒 = 腎」으로 짝지어져 있다. 이것은 陰陽應象大論 「西方生燥…辛生肺」 계열과 맞고, 宣明五氣의 五臟所惡(肺惡寒·腎惡燥)와는 반대다. 「惡」 가리개도 없다.
- 2순위 **六淫(燥易傷肺)** 20%. 고추(味)가 있어서 六淫판보다 歸類판 쪽이 낫다.

**② 띠 한가운데 인물: 肺** (흰 도포 재상) — 1단계의 「金(秋·燥)」보다 이쪽이 더 잘 풀린다.
- 갈라진 땅 + 곧게 떨어지는 마른 잎 5장 = **燥**. 잎이 수직으로 떨어지니 風이 아니다. 肺—燥(其在天爲燥)
- 접시 위 붉은 고추(3개) = **辛**. 肺—味 辛
- 볏단 2개·낫은 사전에 없다. 秋(肺通於秋氣)·거두기로 짐작만 한다. 사전의 收는 「삼베 자루」라서 낫은 收가 아니다.
- 흰 도포는 인물의 신분 표지일 뿐이라 白(色)을 따로 나르는 기호가 없다.
- 배경 왼쪽: 부슬비 = **外濕**, 이웃 脾 몫
- 배경 오른쪽: 눈송이 = **寒(外寒)**, 불 없는 겨울 얼음 = **凝滯**, 잠수부 곁 흰 김 = **氣**. 모두 이웃 **腎** 몫

**③ 잔결**
- 낫·볏단이 미등재라 秋·收가 확정되지 않는다.
- 머리의 테 넓은 큰 갓이 **太** 기호와 겹친다. 手太陰이라고 읽으려 해도 陰 기호가 없어서, 의상인지 사실인지 갈리지 않는다.
- 고추 셋이 포개져 있어 「久」로 읽힐 위험이 있다.
- 흙→얼음 바닥 경계선이 「皮(면 위의 색 경계선)」와 겹칠 수 있다.
- 낙엽 5장은 개수의 뜻이 없다.
