# 901 판독 (P)

## 1단계 — 생판 (사전 보기 전, 그림만)

① 판 표제어
- 1순위 **五行 歸類(五行配屬表: 五季·五氣·五色·五味·五化)** — 75%
- 2순위 **四時(五季) 生長化收藏 / 계절별 五氣(風暑濕燥寒)** — 15%
- 근거: 왼→오 다섯 구역이 봄·여름·장마·가을·겨울로 배경이 이어지고, 옷 색이 靑·赤·黃·白·黑, 탁자 위 맛이 酸·苦·甘·辛·鹹. 배열 순서 자체가 木→火→土→金→水 相生 순.

② 인물(왼쪽부터)
1. 초록 갑옷 장수 — **木/肝(將軍之官)**: 초록 갑옷=靑, 벚꽃·봄 언덕=春, 몸을 감는 바람줄과 흩날리는 꽃잎=風, 맨발 밑 새싹=生(發生), 탁자 위 풋매실 한 접시(5~6알)=酸, 장수=肝 將軍之官. (6)
2. 곤룡포의 왕 — **火/心(君主之官)**: 붉은 곤룡포=赤, 해=夏, 아지랑이(열기 물결)=暑·熱, 키 큰 무성한 풀=長, 작은 단지의 검은 탕액=苦, 왕=心 君主之官, 볼의 홍조=心 其華在面(?). (6~7)
3. 밀짚모자 농부 — **土/脾(倉廩之官)**: 누런 저고리·바지=黃, 쏟아지는 비=長夏, 맨발 아래 물웅덩이·김=濕, 꿀단지(흘러내리는 꿀)=甘, 익어 가는 이삭=化, 농부=倉廩之官 脾胃. (6)
4. 흰 도포·갓 선비 — **金/肺(相傅之官)**: 흰 도포=白, 떨어지는 낙엽(5장)=秋·肅降, 갈라진 마른 땅=燥, 손의 낫+볏단 2묶음=收, 고추 접시=辛, 선비/재상=相傅之官 肺. (6)
5. 검은 잠수복 사람 — **水/腎**: 검은 잠수복=黑, 잠수(물)=水, 눈 내림=冬·寒, 곡식 자루 쌓인 초가 곳간=藏, 소금 접시=鹹. (5)

③ 뜻 모를 것·어색한 것·잘림
- 왕 옆 작은 단지의 검은 액체: 쓴 탕약(苦)인지 간장(鹹?)인지 갈린다.
- 고추 탁자가 선비와 잠수복 사람 사이, 오히려 잠수복 쪽에 붙어 있어 소속이 흔들린다.
- 잠수복의 물안경, 초가에 기대 세운 막대기, 왕의 뒷짐: 뜻 불명.
- 맨 오른쪽 소금 탁자가 프레임 테두리에 잘림.
- 빗줄기가 가을 구역(낙엽 위)까지 넘어간다. 계절 경계는 그러데이션이라 이어 붙인 자국은 두드러지지 않음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

① 판 표제어
- 1순위 **五行 歸類 — 五臟(肝心脾肺腎)에 五氣(風·暑·濕·燥·寒)·五化(生長化收藏)·五味(酸苦甘辛鹹)를 붙인 표** — 85%
- 2순위 **五臟應四時(四時五臟: 肝-春 … 腎-冬)** — 10%
- 사전으로 더 잘 풀린다: 다섯 인물이 정본 장부 인물이고, 맛 다섯이 전부 사전 그대로이며, 새싹→푸른 벼→누런 이삭→볏단→곳간 가마니가 왼→오로 늘어서 「五化」 갈림 조건(덜 익은 것부터 차례로)을 채운다. 대신 옷 색(靑赤黃白黑)은 정본 옷차림 규칙상 따로 읽지 않으므로 五色은 이 판에서 아무 소품도 나르지 않는다.

② 인물(왼쪽부터)
1. 초록 비늘갑옷 장군 = **肝**: 옆으로 흐르는 바람줄·꽃잎 = 風(사전 「風」, 옆으로 날림 조건 충족) / 발밑 새싹 = 生(사전 「五化」) / 매실 접시 = 酸(사전) / 벚꽃 언덕 = 春(사전 밖). — 4
2. 붉은 곤룡포 임금 = **心**: 해 = 사전상 陽, 그러나 이 판 문법으로는 夏·暑(두 갈래에 걸림) / 아지랑이 = 暑(사전 밖. 熱=불꽃 없음, 氣=흰 김과도 다름) / 꼿꼿한 푸른 이삭의 벼 = 長(사전 「五化」) / 질그릇 단지의 검은 액체 = 苦(사전, 김 없음. 단 작은 그릇이라 「약한 苦」 갈림에 걸림). 볼의 붉은 반점은 「面」 갈림(광택만 面)·「瘀」 갈림(살갗 위 얼룩은 아님) 모두 불충족 → 뜻 없음. — 4
3. 노란 밀짚모자 농부 = **脾**: 쏟아지는 비·안개 = 外濕(사전 「濕」) / 맨발 둘레 웅덩이 = 길 위 진창(外濕)이냐 자기 발밑(內濕·脾)이냐 갈림이 맞서는 자리 / 국자 꽂힌 꿀단지 = 甘(사전, 정확히 일치) / 노르스름한 이삭 = 化(사전 「五化」, 단 고개 숙임이 약함). — 4
4. 흰 도포·검은 갓 재상 = **肺**(갓은 「太」 아님): 곧게 떨어지는 낙엽 + 갈라진 땅 = 燥(사전, 風과 갈리는 조건 충족) / 이삭 달린 채 허리 묶은 볏단 2 = 收(사전 「收」·「五化」) / 손의 낫 = 收 보강(사전 밖) / 고추 접시 = 辛(사전) / 낙엽 무대 = 秋(사전 밖). — 4
5. 검은 잠수복·고글 잠수부 = **腎**: 눈송이 = 寒(사전 「寒」 갈림상 정확히는 外寒) / 문 열린 초가 곳간의 가마니 = 藏(사전 「藏」, 앞에 선 이가 관리가 아니라 倉 아님) / 소금 접시 = 鹹(사전) / 기대 세운 장대 = 사전 밖·뜻 없음. — 3

③ 남는 결
- 해: 사전 「陽」과 판 의도(夏·暑)가 겹친다. 暑를 나르는 전담 사전 항목이 없다.
- 단지의 검은 액체: 작은 그릇 → 「약한 苦」로 읽힐 위험. 오른편 안개가 붙어 「김=氣」 갈림까지 건드림.
- 농부 발밑 웅덩이: 外濕/內濕 갈림이 갈리지 않는다.
- 쏟아지는 비는 「下」(아래로 쏟아짐)에도 걸리고, 빗줄기가 肺 구역 낙엽 사이까지 번진다.
- 고추 탁자가 腎 쪽에 붙어 있음, 소금 탁자가 오른쪽 테두리에 잘림, 임금 볼의 붉은 반점·잠수부 옆 장대는 뜻 없는 잔여물.
