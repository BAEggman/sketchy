# 901 판독 (blind22)

## 1단계 — 생판 (사전 열람 전)

**① 판 표제어**
- 1순위 **五行 歸類(五行 配屬表 — 五季·五氣·五色·五味·五化를 한 줄로)** (확신 85%)
- 2순위 **五臟 十二官(靈蘭秘典論 — 君主·將軍·倉廩·相傅·作強)** (확신 10%) — 인물 직업이 官職으로 읽힐 때.
- (3순위 참고: **洪範 五行 특성**(曲直·炎上·稼穡·從革·潤下) 5%)

배경이 왼→오로 봄(벚꽃)→여름(해)→장마(비)→가을(낙엽)→겨울(눈)로 이어지고, 다섯 인물의 옷색이 靑·赤·黃·白·黑, 걸상 위 음식이 酸·苦·甘·辛·鹹 — 五行 다섯 줄을 가로로 펼친 배치.

**② 인물별 (왼→오)**
1. 녹색 갑옷 장수 — **木(肝)**: 녹색 갑옷=靑 / 벚꽃=春 / 꽃잎 휘감는 바람 띠=風 / 접시 위 풋매실 6~7알=酸 / 맨발 밑 새싹=生 / 장수=將軍之官(肝). 사실 6개.
2. 붉은 곤룡포 임금 — **火(心)**: 赤 / 해 1개=夏 / 피어오르는 아지랑이 4줄=暑(熱) / 검은 액체 단지=苦 / 키 큰 푸른 이삭 풀=長 / 임금=君主之官(心) / 한쪽 뺨 붉은 점=面赤(其華在面?). 사실 6~7개.
3. 노란 옷 농부 — **土(脾)**: 黃(옷·밀짚모자) / 빗줄기=長夏·濕 / 발밑 물웅덩이=濕 / 흐르는 꿀단지=甘 / 익어가는 이삭=化 / 농부=稼穡·倉廩. 사실 6개.
4. 흰 도포 갓 선비 — **金(肺)**: 白 / 낙엽 5장=秋 / 갈라진 땅=燥 / 붉은 고추 3개=辛 / 볏단 2개+낫=收(낫=金屬·肅殺) / 선비=相傅之官(肺)?. 사실 6개.
5. 검은 잠수복 사람 — **水(腎)**: 黑 / 눈=冬·寒 / 소금 접시=鹹 / 초가 곳간 속 쌓인 자루=藏 / 잠수부=水(潤下, 作強?). 사실 5~6개.

**③ 어색한 것**
- 갑옷 장수·농부가 맨발 — 장수 맨발은 이유 불명(새싹=生 밟기용?).
- 잠수복·물안경 차림이 물 없는 눈밭에 서 있음(水 표시로는 읽히나 직업 표제는 모호).
- 초가 앞 기대 세운 긴 나무막대(노? 장대?) — 뜻 모름.
- 임금 오른뺨에만 붉은 점 — 의도 불명.
- 비 줄기가 선비 칸 왼쪽 위까지 넘어옴(濕·燥 경계 흐림).
- 프레임 잘림: 맨 오른쪽 소금 걸상·접시가 오른쪽 테두리에 잘림, 초가 지붕이 위·오른쪽 테두리에 닿아 잘림.
- 이어 붙인 흔적: 뚜렷한 이음선은 없고 계절 배경이 번지듯 섞임.

## 2단계 — 계통 (blind6_사전요약 적용 후)

**① 판 표제어** — 사전으로 더 잘 풀린다. 다섯 인물이 곧 다섯 臟(장군=肝·임금=心·농부=脾·재상=肺·잠수부=腎), 옷색=五色, 걸상 위 음식이 사전의 酸·苦·甘·辛·鹹과 하나하나 맞고, 새싹→푸른 이삭→익어 숙인 이삭→볏단→곳간 가마니가 왼→오로 늘어서 「五化」 갈림 조건(덜 익은 것부터 차례로)도 충족.
- 1순위 **五行 歸類 — 五臟·五色·五味·五氣·五化(+五季) 통합 配屬** (92%)
- 2순위 **四時五臟陰陽(天人相應 — 계절·기후와 五臟의 대응)** (5%)
- 1단계 2순위였던 「十二官」은 버림 — 사전에서 인물은 官職이 아니라 臟의 의인화이고, 官은 「3층 선반장 가운데 층」 전담이라 이 판엔 없음.

**② 인물별 (왼→오)**
1. 초록 갑옷 장군 = **肝(木)** — 5개: 靑(옷색 규칙/사전) · 風(꽃잎이 옆으로 흘러 날림/사전 風) · 酸(접시 위 초록 매실/사전) · 生(맨발 밑 새싹/사전 五化) · 春(벚꽃/사전 밖).
2. 붉은 곤룡포 임금 = **心(火)** — 5개: 赤(옷색/사전) · 苦(김 없는 질그릇 검은 커피/사전, 온전한 꼴) · 長(가슴 높이 꼿꼿한 푸른 이삭/사전 五化) · 夏(해/사전 陽과 걸림) · 暑(피어오르는 아지랑이/사전 밖 — 熱=불꽃 아님, 氣=흰 김으로 샐 위험).
3. 노란 밀짚모자 농부 = **脾(土)** — 5개: 黃(사전) · 濕(빗줄기=外濕 + 자기 발밑 물웅덩이=內濕(脾)/사전 濕 갈림 둘 다) · 甘(국자 꽂힌 꿀단지/사전) · 化(노랗게 익어 숙인 이삭/사전 五化) · 長夏(장맛비 무대/사전 밖).
4. 흰 도포 재상 = **肺(金)** — 5개: 白(사전; 검은 갓은 옷차림이라 太 아님) · 燥(갈라진 땅 + 곧게 떨어지는 마른 잎 5장/사전 燥) · 辛(붉은 고추 3개/사전) · 收(이삭 달리고 손잡이 없는 볏단 2개/사전 收·五化) · 秋(낙엽/사전 밖). 손의 낫은 사전 밖(金·收穫 보강으로 추정).
5. 검은 잠수부 = **腎(水)** — 5개: 黑(사전) · 寒(눈송이/사전 寒 갈림 → 外寒) · 鹹(굵은 소금 접시/사전) · 藏(문 열린 곳간 속 가마니/사전 藏 갈림 — 앞에 선 이가 관리 아닌 잠수부라 倉 아님) · 冬(눈 무대/사전 밖).

**③ 어긋남·잔결**
- 해: 사전은 陽 — 이 판에선 夏(火)의 계절 표지로 읽혀 두 뜻에 걸림.
- 아지랑이: 사전에 暑 항목 없음. 熱=불꽃·氣=서린 흰 김 어느 쪽에도 딱 안 맞음.
- 농부 발밑 웅덩이: 外濕(비가 고임)과 內濕(자기 발밑에서 배어남) 갈림 경계.
- 곳간 가마니: 바로 앞에 사람이 서 있어 倉으로 오독될 여지(잠수부는 관리 아님 → 藏).
- 임금 한쪽 뺨 붉은 점: 血(붉은 것)·面(광택만)·「살갗 얼룩=그 자리의 색」 어디에도 깔끔히 안 걸림 — 사전 밖·뜻 불명.
- 사전 밖 소품: 벚꽃·낙엽·눈 무대의 계절(五季), 낫, 초가 앞 기댄 긴 막대(뜻 모름), 장군·농부 맨발.
- 프레임: 오른쪽 소금 걸상·접시와 초가 지붕이 테두리에 잘림. 빗줄기가 재상 칸 왼쪽 위로 넘어옴. 뚜렷한 이음선 없음.
