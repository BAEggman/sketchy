blind21에서 짚인 사전 어긋남 셋을 `blind6_사전요약.md`(판독자에게 주는 사전)와 `glyph_dict.py`에서 고쳤다.

| 어긋남 | 고침 | 규칙 63-b 전수(막으면 안 되는 쓰임) |
|---|---|---|
| 收 = 삼베 자루뿐 → 볏단이 「사전 밖」 | 收에 둘째 꼴 「들판에서는 이삭 달린 채 허리를 묶어 세운 볏단」 + 갈림 「이삭이 달리고 손잡이가 없다 — 손잡이 달린 짚 빗자루는 瀉」. 五化 다섯 단계 항목 신설(왼→오 덜 익은 것부터 늘어설 때만) | 짚 빗자루 = 瀉(s16p01·s18p09) — 손잡이·이삭으로 갈림. 典藥(약봉지 다발)과 겹치지 않게 「끈으로 묶은 것 일반」으로 넓히지 않음 |
| 苦 = 「김 나는」 커피 → 김 없는 그림이 「반쪽」 | 「질그릇 잔·사발의 검은 커피 — 김은 苦의 일부가 아니다(김 = 氣)」 | 커피 쓰임 s14p01·s14p09 — 둘 다 김 없음과 맞음 |
| 太 = 「머리에 씌운 큰 갓」 → 재상의 갓과 겹침 | 「사람이 아닌 것(나무 꼭대기·도구) 위에 씌운 큰 갓 — 사람이 쓴 갓은 太가 아니다(옷차림)」 + 다섯 인물 머리에 「옷·모자의 모양은 그 인물을 가리킬 뿐, 다른 글자로 다시 읽지 않는다」 | 太 쓰임 셋 모두 물건 위(침통에 씌운 갓 — 太醫監, 버드나무 꼭대기 흰 갓 — 楊上善 太素). 「보통과 달라진 것(두 배 투구 = 上盛 s20p08, 날아가는 모자 = 風 s15u01)은 그 바뀜이 사실을 진다」를 단서로 붙임 |

## 판독
| 판독자 | 그림 | 결과 |
|---|---|---|
| P (1차 고침 뒤) | s09u01 | 收 ✓(사전 收·五化) · 太 언급 없음 ✓ · 苦 ✓이나 **「잔이 작아 약한 苦」**(내가 넣은 「잔이 작으면 약한 苦」가 역효과) · **五色이 빠짐**(「옷차림은 다른 글자로 읽지 않는다」가 옷 색까지 막음) — 인물마다 4개 |
| Q (회귀) | blind16z z48 楊上善 띠 | 太 ✓(「사람 아닌 나무 위」 조건 충족) → 楊上善 『黃帝內經太素』 그대로 |
| R (2차 고침 뒤) | s09u01 | **판 표제어 五行 歸類 92%, 인물 5/5, 인물마다 5개(色·季·氣·化·味)** — 收(사전 收·五化) ✓ · 苦(김 없는 질그릇 커피) ✓ · 재상 갓 「옷차림이라 太 아님」 ✓ · 五色(옷 색 규칙) ✓ |

2차 고침: 「잔이 작으면 약한 苦」를 뺐고(잔 크기 = 세기는 s14p01 한 판의 문법), 인물 머리글을 「**옷 색은 그대로 五色** — 옷·모자의 **모양**만 다른 글자로 읽지 않는다」로 나눴다.
