# 901 판독 (U)

## 1단계 — 생판 (사전 미열람)

**① 판 표제어**
- 1순위 **八卦 — 說卦傳 取象(自然·家族·身體)** (85%)
- 2순위 **先天八卦 對待 (天地定位·山澤通氣·雷風相薄·水火不相射)** (10%) — 1순위의 짝 관계 층위. 그 밖 **易의 陰陽(陽卦·陰卦)** 5%.

**② 인물(왼→오), 8명 = 4쌍. 발밑 발자국 파랑=陽卦(남) / 빨강=陰卦(여)**
1. **乾** — 하늘·구름 병풍=天 / 가장 큰 성인 남자=父 / 이마가 부푼 큰 머리=首 / 파란 발자국=陽 → 4개
2. **坤** — 누런 들판·구릉 병풍=地 / 성인 여자=母 / 만삭 배=腹 / 빨간 발자국=陰 → 4개
3. **坎** — 강물 병풍·대롱에서 솟는 물=水 / 중간 키 소년=中男 / 거대한 귀=耳 / 파랑=陽 (대나무 대롱=溝瀆?) → 4~5개
4. **離** — 불꽃 병풍·횃불=火 / 중간 키 소녀=中女 / 왕방울 눈=目 / 빨강=陰 → 4개
5. **艮** — 바위산 병풍=山 / 가장 작은 소년=少男 / 내민 손=手(멈춤=止?) / 파랑 → 4개
6. **兌** — 갈대 호수 병풍=澤 / 가장 작은 소녀=少女 / 크게 벌린 입=口 / 깔깔 웃음=說(悅) / 빨강 → 5개
7. **震** — 먹구름·번개 병풍=雷 / 큰 소년=長男 / 거대한 맨발=足 / 굴러 퍼지는 파문=動 / 파랑 → 5개
8. **巽** — 휘감는 바람=風 / 버드나무=木 / 큰 소녀=長女 / 바람에 들린 치마 아래 허벅지=股 / 빨강 → 5개
- 키 순서(父母 > 長 > 中 > 少)가 一索·再索·三索을 나른다.

**짝 관계**: 乾坤 마주 절=天地定位 / 坎의 물줄기는 왼쪽·離의 불줄기는 오른쪽으로 갈라져 안 만남=水火不相射 / 兌 입김이 艮 손에 이어짐=山澤通氣 / 震 발 파문과 巽 회오리가 맞부딪침=雷風相薄. 모든 짝이 陽-陰 對待.

**③ 잔결**: 초승달·별 밤하늘과 구름 위 무대(坎=月? 先天? 미상), 왼쪽 위 '+' 별, 坎 소년의 대나무(震=竹과 혼선 우려), 병풍 4폭씩(수 의미 없음), 쌍 배열 순서(乾坤·坎離·艮兌·震巽)가 說卦 3장 순서(天地·山澤·雷風·水火)와 다름, 오른쪽 巽 치마가 액자선을 살짝 넘음, 그림 맨 아래 흰 여백 밑 가는 검은 줄(레터박스 잔흔).

## 2단계 — 계통 (blind6_사전요약 어휘로 재판독)

**① 판 표제어**: 사전 「八卦 = 4폭+4폭 병풍 무대(마주 본 두 폭이 한 쌍)」이 그대로 맞는다(병풍이 모두 4폭이고 둘씩 마주 선다). 1단계의 '병풍 4폭' 잔결이 무대 기호로 풀린다.
- 1순위 **八卦 — 說卦傳 取象(自然·家族·身體)** (92%)
- 2순위 **先天八卦 對待 = 八卦 마주봄 (天地定位·山澤通氣·雷風相薄·水火不相射)** (7%) — 1순위 안의 짝 층위.

**② 인물 재판독(왼→오)**
1. **乾** — 天·父·首·陽 4개 (불룩한 이마가 사전 面(이마 광택)으로 샐 여지 있으나 무대가 八卦라 首)
2. **坤** — 地·母·腹·陰 4개 (만삭 배는 사전 腫·實(팽팽)과 겹치나 무대로 腹)
3. **坎** — 水·中男·耳·陽 4개. 사전 中 = 「같은 것 셋 중 가운데」 → 소년 셋 중 가운데 키 = 中男으로 뒷받침. 단 귀는 사전 耳(옆으로 돌려 귓구멍이 검게 열림) 꼴이 아니라 정면의 '크게 키운 귀'.
4. **離** — 火·中女·目·陰 4개. 사전 目(크게 뜬 눈) 확정. 횃불은 사전 熱/陽(불꽃)과 같은 사물이나 八卦 무대에선 火.
5. **艮** — 山·少男·手·陽 4개. 사전이 '배경 산 = 艮'을 이미 쓴다(三峯 항목).
6. **兌** — 澤·少女·口·說(悅)·陰 5개. 입이 얼굴 절반 = 사전 吳와 새는 꼴이고 혀가 보여 舌(心)로도 샐 수 있으나, 사전 스스로 「兌(口)… 무대로 가른다」 → 八卦 무대이므로 口.
7. **震** — 雷·長男·足·動(파문)·陽 5개.
8. **巽** — 風(사전 확정: 옆으로 흘러 날림)·木(버들)·長女·股·陰 5개. 허벅지는 사전 肌와 닮음.

**짝 관계**: 乾坤 맞절=天地定位 / 艮兌 사이 흰 띠는 사전 **氣(서린 흰 김)+通(한 덩어리로 이어짐)** = 山澤通氣로 1단계보다 단단해짐 / 坎·離 물·불줄기가 반대로 갈라짐=水火不相射 / 震 파문×巽 회오리=雷風相薄. 발자국 파랑(陽卦)·빨강(陰卦) 쌍.

**③ 잔결**: 초승달·별·구름 무대는 사전에 없음(坎=月? 미상) / 빨간 발자국이 사전 血(붉은 것)로 샐 수 있고 통념(붉음=陽)과 반대로 陰卦에 붙음 / 병풍=사전 惡(가리개)와 겹치나 八卦 항목이 우선 / 足·股·手·首·腹·長·少는 사전 미등재 / 쌍 배열이 說卦 3장 순서와 다름 / 巽 치마 액자선 침범 / 하단 검은 줄.
**판정**: 사전 어휘로 판 표제(八卦 마주봄)·目·風·氣通·中이 확정·강화되고, 1단계 해석을 뒤집는 항목은 없다.
