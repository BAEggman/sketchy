# z36 판독

## 1단계 — 생판 (사전 보기 전, 확정)

**① 단원**: **八卦(說卦傳의 卦象)** 65% · 다음 후보 **天氣通於肺…風氣通於肝·雷氣通於心(陰陽應象大論)** 15% · **五行(木)** 10%.
근거: 병풍마다 자연물 하나(못·우레·바람)가 붙어 있고, 그 앞 인물이 아들·큰딸·작은딸로 나뉜다 — 팔괘의 「자연상 + 가족상」 짝이다.

**② 인물**
- 가운데 왼쪽 까까머리 소년(녹색 도포) = **震**. 소품과 사실: 먹구름·번개 병풍 → 震爲雷. 사내아이 → 長男. 맨발을 번쩍 들어 구르고 바닥에 물결 고리(4~5겹)가 퍼짐 → 震爲足, 震 = 動(雷以動之). 녹색 옷 → 震은 木·東方·靑(蒼筤竹).
- 가운데 오른쪽 쪽머리 소녀(주황 저고리·붉은 치마) = **巽**. 버드나무 병풍과 소녀를 감싸는 회오리 1개 → 巽爲風·爲木. 소녀이고 震 소년과 키가 같음 → 長女. 바람에 치마가 들려 넓적다리가 드러남 → 巽爲股. 바람이 몸을 감고 듦 → 巽 = 入(風以散之).
- 관계: 둘이 주먹을 쥐고 마주 노려보며, 파란 발자국(소년 몫, 오른쪽으로 향함)과 붉은 발자국(소녀 몫, 왼쪽으로 향함)이 서로 다가선다 → **雷風相薄**. 長男·長女 = 한 쌍의 陽卦·陰卦. 震(東)·巽(東南)은 後天圖에서 이웃하고 「帝出乎震, 齊乎巽」으로 이어진다.
- 배경: 별 뜬 밤하늘과 구름 위 무대 → 天, 팔괘 전체의 하늘 무대. 왼쪽 가장자리의 더 작은 소녀와 호수·갈대 병풍은 이웃 띠 몫(兌 = 澤·少女)이고, 「山澤通氣」 다음이 「雷風相薄」이라는 순서를 받쳐 준다.

**③ 잔결**: 소년의 까까머리는 뜻이 보이지 않는다(說卦에서 寡髮은 巽의 상이라 오히려 엇갈림). 발자국 색은 청=남·적=녀로 읽었지만 오행색으로는 맞지 않는다. 병풍은 둘 다 4폭이라 수(數)를 싣지 않는 듯하다. 번개 병풍과 호수 병풍 사이 틈으로 흰 구름 덩이가 비친다. 이어 붙인 흔적은 뚜렷하지 않다.

## 2단계 — 사전 어휘로 다시 읽기

**① 단원**: **八卦** 88%. 사전에 「八卦 = 4폭+4폭 병풍 무대(마주 본 두 폭이 한 쌍) = 八卦 마주봄」이 있다. 1단계에서 「4폭은 수를 싣지 않는다」고 버린 병풍이 바로 단원 표지였다(4+4 = 八). 그래서 이 띠는 **先天八卦의 對待(마주봄) 한 쌍**이다.

**② 인물**
- 소년 = **震**: 우레 병풍 → 雷. 사내아이 → 長男. 들어 올린 맨발과 발자국 → 足. 구르기에서 퍼지는 물결 → 動. 녹색 옷은 오행왕국 다섯 인물이 아니어서(갑옷이 없다) 肝이 아니고, 木·東의 색 정도로만 읽힌다.
- 소녀 = **巽**: 치마와 회오리가 오른쪽 옆으로 눕고 흘러 날린다. 사전의 **風** 글자 그대로라서 巽爲風이 확정된다. 버드나무 → 木. 큰딸 → 長女. 드러난 넓적다리 → 股.
- 관계: 두 병풍(4+4)이 마주 서고 두 사람이 마주 노려본다 → **雷風相薄**. 先天圖에서 震(東北)과 巽(西南)이 마주 앉는 대대이고, 수로는 震4 + 巽5 = 9이며, 효로는 ☳와 ☴가 서로 뒤집힌 짝(錯卦)이다. 서로 다가서는 청·적 발자국이 「薄(맞닥뜨림)」을 나른다. 왼쪽 이웃(호수·작은딸 = 兌)은 艮과 짝을 이루는 山澤通氣 몫이다.
- 1단계와 비교: 단원·인물·관계 판정은 그대로 두고, 「後天 이웃(帝出乎震·齊乎巽)」을 「先天 對待」로 바로잡는다.

**③ 잔결**: 사전의 **血 = 붉은 것** 때문에 소녀의 붉은 발자국·붉은 치마가 血로 샐 수 있다(무대가 팔괘라 血로 읽지는 않았다). 퍼지는 물결 고리는 **散**(사방으로 흩어짐)으로 읽힐 소지가 있는데, 「風以散之」는 巽의 몫이라 震 쪽 물결과 엇갈린다. 까까머리 소년은 여전히 뜻이 없다(寡髮은 巽의 상). 발자국 청·적은 사전에 없는 기호다.
