# z44 판독

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원**: **陰陽** 60% — 『素問·陰陽應象大論』 「天地者萬物之上下也, 陰陽者血氣之男女也, 左右者陰陽之道路也, 水火者陰陽之徵兆也」를 한 무대에 펼친 것으로 읽힘. 2순위 **五行** 30%(옷색 靑·黃, 다섯 발가락, 병풍 풍경 하늘→들→물), 기타 10%.

**② 인물·소품**
- 왼쪽 남자 = **陽 / 天 / 男**: 하늘·흰구름 병풍(4폭) = 天(淸陽爲天). 비정상적으로 높이 솟은 이마와 정수리 상투 = 陽在上, 頭爲諸陽之會. 왼쪽 자리 = 左(陽升於左). 발 앞 청색 발자국(발가락 5).
- 오른쪽 여자 = **陰 / 地 / 女**: 누런 들판·구릉 병풍(4폭) = 地(濁陰爲地), 황색 옷 = 土. 만삭의 배 = 陰成形·腹爲陰·地生萬物. 오른쪽 자리 = 右(陰降於右). 발 앞 적색 발자국(발가락 5).
- 배경: 별 뜬 밤하늘 = 天(上), 무대 아래 구름 바다 = 地氣上爲雲.
- 셀 것: 인물 2, 병풍 2(각 4폭), 발자국 2(각 발가락 5).

**관계**: 둘이 같은 깊이로 마주 절함 = 陰陽 交感·平衡(陰平陽秘). 두 발자국이 서로를 향함 = 天氣下降·地氣上升(오가는 **道路**). 발자국 색이 엇갈림(陽인 남자 쪽이 청=水, 陰인 여자 쪽이 적=火) = 水火가 陰陽의 徵兆, 陽中有陰·陰中有陽(互藏).

**③ 잔결**: 여자의 황색 옷과 적색 발자국이 어긋남(남자는 옷=발자국 청색으로 일치) — 의도된 교차인지 불명. 오른쪽 끝 물결 병풍은 이웃 띠 몫(水?). 별 개수는 세어도 뜻이 안 잡힘. 이어 붙인 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (blind6_사전요약 적용)

**① 단원**: **陰陽(易·八卦)** 70%. 사전 「八卦 = 4폭+4폭 병풍 무대(마주 본 두 폭이 한 쌍) = 八卦 마주봄」이 그대로 맞음(병풍 2개 × 4폭 = 8). 이 띠의 개념은 **先天八卦 對待 — 天地定位(乾↔坤)**. 1단계의 「陰陽應象大論 天地·男女·左右·水火」 독해보다 이쪽이 더 많은 소품을 남김없이 설명함 → 갈아탐. **五行**은 10%로 내림(두 인물이 오행왕국 인물의 차림이 아님: 갑옷·밀짚모자 없음).

**② 인물·소품**
- 왼쪽 남자 = **乾**: 하늘·구름 병풍 = 乾爲天. 「보통과 달라진 것」인 거대한 이마 = 乾爲首. 남자 = 乾爲父. 검푸른 옷과 밤하늘 = 天玄.
- 오른쪽 여자 = **坤**: 누런 대지 병풍 = 坤爲地. 부푼 배 = 坤爲腹, 만삭 = 坤爲母(萬物資生). 황색 옷 = 地黃(「天玄而地黃」; 사전의 약재 地黃=검붉은 뿌리와는 무관).
- 배경: 별밤 위·구름 아래에 떠 있는 무대 = 하늘 위 세계 = **先天**.
- 셀 것: 한 쌍 2인, 병풍 2(4+4=8卦), 발자국 2(발가락 각 5).

**관계**: 같은 깊이로 마주 보고 절함 = 八卦 「마주봄」(對待)의 첫 쌍 **天地定位**. 발 앞 발자국 = 바닥에 찍힌 자리표 = 定位(각자 제자리에 섬). 오른쪽 끝 물결 병풍은 다음 쌍(**坎** 水 → 水火不相射로 추정)을 이웃 띠로 넘김.

**③ 잔결**: 발자국의 청/적 색과 다섯 발가락은 사전 어휘로 안 풀림(血=붉은 것을 대면 「女=血」이 되나 남자 쪽 청색이 짝을 못 찾음). 상투(정수리로 솟음)를 上으로 읽을지 차림으로 볼지 갈림 — 차림 규칙상 뺌. 별 개수 뜻 없음. 이어 붙인 흔적 없음.
