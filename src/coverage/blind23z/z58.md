# z58 판독

## 1단계 — 생판 (사전 없이)

**① 단원**: **陰陽 — 周易·八卦(說卦傳 取象)** 55% / 2순위 **八卦 단독 단원** 25% / 3순위 **五行** 10%.

**② 인물·소품·배경**
- 한가운데 왼쪽 소년 — **艮(少男)**: 뒤 병풍 = 산(艮爲山), 어린 사내아이 = 少男, 두 손을 앞으로 내밀어 보임 = **艮爲手**. 사실 3개(象·家人·身體).
- 한가운데 오른쪽 소녀 — **兌(少女)**: 뒤 병풍 = 물+갈대 = 못(兌爲澤), 어린 계집아이 = 少女, 입을 크게 벌림 = **兌爲口**(兌=說·悅). 사실 3개.
- **관계**: 소녀 입에서 나온 흰 김이 휘어 소년의 두 손에 닿음 = **山澤通氣**(說卦傳 「天地定位, 山澤通氣, 雷風相薄, 水火不相射」의 한 쌍). 서로 마주 보는 짝 배치 = 八卦相錯의 대대(對待).
- 왼끝(잘림) 소녀 — 불 병풍·크게 뜬 눈 = **離(火·中女·目)**. 오른끝(잘림) 큰 사내 — 먹구름 병풍·커다란 맨발·성큼 걷는 자세 = **震(雷·長男·足·動)** (먹구름이라 坎 가능성 남음).
- 배경: 밤하늘 초승달·별 = 陰(혹은 坎爲月 예고), 구름 위 무대 = 하늘(乾?)의 자리.
- 발자국: 빨강(離)·파랑(艮)·빨강(兌)·파랑(震) 교대 = 陰卦/陽卦 구분(여자=陰卦, 남자=陽卦). 셀 수 있는 것: 이 띠 안 卦 4개(온전 2 + 잘림 2).

**③ 잔결**: 발자국 색이 陰卦에 빨강(陽색)을 줘 거꾸로 읽힐 위험(「陰卦多陽」을 노린 것인지 단순 성별 색인지 불명). 흰 김이 소녀 입에서 한 줄, 소년 손에서 따로 한 가닥 위로 솟아 두 줄처럼 끊겨 보임(이음 흔적 의심). 震/坎을 가를 단서(번개·귀)가 없음. 초승달의 몫 불명.

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**① 단원**: **陰陽 — 周易·八卦** 60% (사전 「八卦 = 4폭+4폭 병풍 무대, 마주 본 두 폭이 한 쌍」과 「吳 ⚠ s10p04의 兌(口)」가 이 무대 문법을 확정 — 이 띠는 그 八卦 판의 한 토막). 2순위 **八卦 단독** 25%.

**② 다시 읽기**
- 병풍이 모두 4폭 = 사전의 八卦 병풍 그대로. 산 병풍 = 艮(사전 三峯 항목도 「배경 산 = 艮」으로 못박음).
- 소년 **艮(山·少男·手)**: 두 손 위에 서린 흰 김 = **氣**를 받쳐 듦. 사실 3 + 氣를 받는 쪽.
- 소녀 **兌(澤·少女·口)**: 크게 벌린 입 = 사전 吳 항목이 경고한 바로 그 **兌(口)**. 입에서 흰 김(**氣**)을 내보냄. 사실 3 + 氣를 내는 쪽.
- **관계**: 소녀의 입 → 소년의 손까지 흰 김이 한 줄로 이어짐 = **通**(안팎이 한 덩어리로 이어짐) + **氣**(서린 흰 김) = **山澤通氣**. 두 병풍이 마주 본 한 쌍 = 사전의 「八卦 마주봄」 = 先天八卦의 對(艮↔兌).
- 왼끝 소녀: 크게 뜬 눈 = 사전 **目** → **離(火·中女·目)** 확정도 상승. 오른끝 사내: 몸집이 離 소녀보다 훨씬 큼 → 長男, 맨발 강조 → **震(雷·長男·足)**. 이 둘의 짝(坎·巽)은 이웃 띠 몫.
- 초승달·별·구름 바닥: 사전에 없음 — 판 전체 배경(陰의 밤/天上 무대)으로만 읽음.

**③ 잔결**: 빨간 발자국이 사전 「血 = 붉은 것」과 부딪혀 血로 오독될 수 있음(파랑 짝은 사전에 없어 색 대비만 남음). 불 병풍은 熱·陽(불꽃)과, 옆으로 흐르는 흰 김은 風과 샐 여지가 있으나 八卦 병풍 문법이 덮어 줌. 소녀 입 안 혀가 살짝 보여 舌(心) 갈림을 건드릴 수 있음. 소년 손 위 김 한 가닥이 따로 솟아 보이는 이음 흔적은 그대로.
