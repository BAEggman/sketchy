# 902 판독 (판독자 W)

## 1단계 — 생판 (사전 없이 그림만)

**① 판 표제어**
- 1순위 **當歸 — 頭·身·尾 分用 (頭止血·身養血·尾破血, 全活血)** — 확신 75%
- 2순위 **藥用部位에 따른 效能 차이(同一 藥材 部位分用; 人蔘 蘆頭·主根·蔘鬚 류)** — 확신 10%
- 근거: 탁자 위 뿌리가 「울퉁불퉁한 머리 토막 | 매끈한 몸통 | 잔뿌리 꼬리」로 한 줄에 잘려 놓였고, 세 인물이 그 세 토막을 하나씩 들었다(황제·농부의 토막은 끊어진 단면이 서로 맞닿음). 아래 바닥 소품(핏방울·피 사발·벽 깨고 흘러내리는 물)이 모두 혈(血)에 관한 세 갈래 작용이라 張元素 「頭止血而上行, 身養血而中守, 梢破血而下流, 全活血而不走」로 읽힘.

**② 인물별 (왼쪽부터)**
- 인물1 갑옷 군인 — **當歸頭**. 마디진 머리 토막(생강처럼 보임). 발밑 핏방울이 떨어져 작은 웅덩이에서 멎음 = **頭止血**(1). 군인=지킴·막음 → 止. 「上行」은 그려지지 않음. → 1~2개
- 인물2 용포 황제 — **當歸身**. 가운데 굵은 몸통, 발밑 피가 가득 찬 사발 = **身養血(補血)**(1), 한가운데 자리 지킴 = **中守**(1). → 2개
- 인물3 삿갓 농부 — **當歸尾(梢)**. 잔뿌리 다발, 발밑 판자벽이 갈라지며 물이 아래로 쏟아짐 = **尾破血**(1) + **下流**(1). → 2개
- 탁자·배경 — 통째 뿌리 = **全當歸 活血/和血**(1). 꿀 숟가락=甘, 고추=辛, 피어오르는 김=溫 → **性味 甘·辛·溫**(3). 문 쪽으로 걸어가는 두 줄 발자국 + 열린 문 = 이름 「當歸(마땅히 돌아옴 · 氣血各有所歸)」로 추정(1, 불확실).

**③ 잔결**
- 군인의 머리 토막이 생강과 똑같이 그려져 「生薑」으로 오독될 위험.
- 발자국·문의 뜻 미정(歸 / 走 / 潤腸通便 중 어느 것?). 「全活血而不走」라면 발자국(走)은 오히려 반대.
- 쏟아지는 물이 붉지 않아 「血」과의 연결이 약함. 「頭…上行」 대응 소품 없음(방울은 오히려 아래로 떨어짐).
- 김이 탁자 윗선을 가로질러 내려와 선이 끊김(덧그림 흔적 경미). 문틀이 오른쪽 테두리에 붙음. 프레임 잘림은 없음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **當歸 — 性味 甘辛溫 · 歸經 肝心脾 · 頭止血/身養血/尾破血** — 확신 85% (↑)
- 2순위 **補血藥 總論(心·肝 歸經, 補血·活血)** — 확신 7%
- 사전으로 크게 달라진 점: 세 인물의 옷이 사전상 **초록 갑옷 장군=肝 · 붉은 곤룡포 임금=心 · 노란 밀짚모자 농부=脾**. 1단계에서 「지킴/중앙/농사」로 억지 해석하던 인물 정체가 곧 當歸의 **歸經 肝·心·脾** 세 경으로 정확히 풀린다. 생판보다 이 어휘로 훨씬 잘 풀림.

**② 인물별 (왼쪽부터)**
- 인물1 肝(장군) — **當歸頭**. 歸經 肝(1). 발밑 血(붉은 것) 방울이 떨어져 작은 웅덩이에서 멎음 = **頭止血**(1). 「上(머리 꼭대기로 곧게 솟음)」 기호가 없어 「上行」은 안 실림. → 2개
- 인물2 心(임금) — **當歸身**. 歸經 心(1). 세 토막 중 가운데 = **中**(같은 것 셋 중 가운데) → 「身…中守」(1). 사발에 붉은 것이 가득 = **補-b(담긴 것=血) → 補血·養血**(1). → 3개
- 인물3 脾(농부) — **當歸尾(梢)**. 歸經 脾(1). 깨진 판자벽 틈으로 물이 아래로 쏟아짐 = **下**(쏟아짐) → 「下流」(1) + 깨짐 → **破血**(1, 단 물이 맑아 血 기호 아님 — 열 위치로 붙임). → 3개
- 탁자·배경 — 꿀 숟가락=**甘**(사전은 「국자 꽂힌 꿀단지」, 여기선 꿀 숟가락: 근사), 고추=**辛**(접시 없음), 피어오르는 흰 김=사전상 **氣** → 藥의 氣(四氣) 곧 **溫**으로 읽음(사전의 溫은 「김 오르는 천」이라 엄밀히는 氣) → 性味 **甘辛溫**(3). 탁자 위 통째 뿌리 = **全當歸 活血/和血**(1). 열린 **門**(문틀)으로 이어지는 발자국 두 줄 — 사전 陽卦·陰卦 항이 「문 쪽 발자국 줄은 이 항목이 아니다」로 따로 뺌 → 미등재 기호. **歸**(돌아옴·氣血各有所歸, 이름 풀이) 1순위, **潤腸通便**(맑은 물=津 + 下 + 門 + 通) 2순위(1, 불확실).

**③ 잔결**
- 쏟아지는 물이 맑아 사전상 血이 아님(津에 가까움) → 「尾破血」인지 「潤腸通便」인지 갈림.
- 김에 천이 없어 溫인지 氣인지 사전 기준으로 애매. 甘·辛 소품이 사전 꼴(꿀단지·접시)과 조금 다름.
- 발자국+문은 미등재 기호라 뜻 확정 불가. 「頭…上行」 대응 소품 없음. 머리 토막이 생강과 같아 「生薑」 오독 위험.
- 이어붙임은 김이 탁자 윗선을 끊는 정도, 프레임 잘림 없음.
