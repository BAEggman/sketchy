# blind25 / 900 — 판독 X

## 1단계 — 생판 (사전 없이)

**① 판 표제어**
- 1순위: **五臟 배속 — 《素問·宣明五氣》(五惡·五勞所傷·五液)** — 70%
- 2순위: **五行 歸類表(五臟 통합판: 色·主·所惡)** — 25%
- 근거: 한 지붕 아래 방 5칸이 靑·赤·黃·白(회백)·黑 순 = 木火土金水 상생 순서. 다섯 자세(걷기·보기·앉기·눕기·서기)가 정확히 五勞所傷 다섯 항목, 다섯 방의 날씨(바람·열·누수·서리·마름)가 五惡 다섯 항목.

**② 칸별 (왼→오)**
1. 녹색 방 **肝** — 3개: 녹색 갑옷 장수(肝者將軍之官·靑) / 걸어 나가는 발 + 바닥이 뚫린 짚신 3켤레 = **久行傷筋** / 문틈으로 들이치는 바람·나뭇잎을 손으로 막음 = **肝惡風**. (눈물=淚는 안 보임)
2. 붉은 방 **心** — 4개: 홍룡포 임금(君主之官·赤) / 책을 들여다봄 + 해진 책 더미 = **久視傷血** / 이마 땀방울 = **心爲汗** / 아래가 그을린 판자·연기 나는 숯(?) 그릇 = **心惡熱**.
3. 노란 방 **脾** — 3개: 노란 옷·삿갓(黃) / 책상다리로 앉음 + 솜 터진 방석 3장 = **久坐傷肉** / 천장 얼룩에서 새는 물줄기를 우산으로 받음 = **脾惡濕**. (침=涎은 안 보임)
4. 회백 방 **肺** — 3개(+1?): 흰 옷(白) / 누워 있음 + 해진 베개 3개 = **久臥傷氣** / 문틈에 낀 서리 = **肺惡寒** / 요 밑 물방울 웅덩이 = 涕(?, 약함).
5. 흰 방 검은 잠수복 **腎** — 4개: 검은 옷·물동이(黑·水) / 서 있는 몸에 거미줄까지 = **久立傷骨** / 입에서 놋 타구로 흐르는 줄 = **腎爲唾** / 금 가고 벗겨진 벽·거미줄 = **腎惡燥**.

**③ 잔결**
- 4칸 바닥 검은 갓, 5칸 벽의 파란 수건, 5칸 마스크가 입을 가로지름 — 뜻 불명.
- 2칸 그릇 내용물(숯? 팥?) 판별 곤란, 4칸 얼굴 일그러짐, 2칸 임금 하의가 살색(벗은 듯).
- 淚·涎·涕가 1·3·4칸에 뚜렷하지 않아 五液 줄이 반쪽.
- 2·3·4칸 바닥 오른쪽 아래마다 ✦ 반짝이 표식 → 칸을 따로 생성해 이어 붙인 흔적.

## 2단계 — 계통 (사전요약 어휘로 다시 읽기)

**① 판 표제어** — 사전이 1단계를 굳힌다.
- 1순위: **《素問·宣明五氣》 五臟 통합 — 五惡 + 五勞所傷(+五液 일부)** — 85%
- 2순위: **五行 歸類(오행왕국 五臟: 五色·所惡·所勞)** — 12%
- 근거: 다섯 인물이 사전의 오행왕국 인물(장군=肝·임금=心·밀짚모자 농부=脾·흰 도포·검은 갓 재상=肺·잠수복·고글 잠수부=腎) 그대로이고, 옷 색이 곧 五色. 칸마다 **惡 = 해로운 것과 사람 사이에 세운 가리개**(판자문·그을린 판자·우산·문·수건)와 **久 = 같은 물건 셋 포갬**(짚신·방석·베개 3)이 되풀이된다 → 「X惡Y」「久X傷Y」 두 줄이 판의 뼈대.

**② 칸별 (왼→오)**
1. **肝** — 3개: 靑 / 짚신 3켤레 포갬(久)+내딛는 걸음 = **久行傷筋** / 손으로 버틴 판자(惡)+옆으로 날리는 잎(風) = **肝惡風**.
2. **心** — 4개: 赤 / 펼친 책+닳은 책 무더기(久) = **久視傷血** / 이마 땀방울(汗) = **心爲汗** / 임금과 불씨 그릇 사이에 선 그을린 판자(惡) = **心惡熱**.
3. **脾** — 3개: 黃 / 솜 터진 방석 3장 포갬(久+傷+도톰한 살덩이=肌) = **久坐傷肉**(사전으로 가장 깔끔히 풀림) / 천장 누수(濕)를 막는 우산(惡) = **脾惡濕**.
4. **肺** — 3개(+1?): 白 / 해진 베개 3개 포갬(久)+누움 = **久臥傷氣** / 닫힌 문 안쪽 틈의 성에(寒)+문(惡) = **肺惡寒** / 요 밑 맑은 물방울 웅덩이 = 涕(?)·津(?).
5. **腎** — 4개: 黑 / 거미줄이 몸에까지 낀 채 선 자세 = **久立傷骨** / 입→놋 타구 줄기 = **腎爲唾** / 갈라진 벽(燥)에 건 수건·물대야 = **腎惡燥**.

**③ 잔결**
- 傷의 대상 사물이 제 꼴로 안 그려짐: 筋(갈색 힘줄)·血(붉은 것)·氣(흰 김)·骨(흰 뼈)가 없다. 傷肉만 사전대로.
- 5칸에 3개 포갬(久)이 없음 — 거미줄로 대신.
- 2칸 그릇의 검붉은 알갱이는 사전상 **瘀**와 겹치고, 熱의 정식 꼴(불꽃)이 없음.
- 4칸 문틈 흰 것은 사전상 「안쪽 성에 = 裏寒」으로 읽혀 五惡의 寒과 어긋날 수 있음. 바닥의 검은 갓은 사람 머리에서 벗겨진 것이라 太는 아니지만 무슨 사실인지 불명.
- 淚(1칸)·涎(3칸)가 없어 五液 줄은 汗·唾(+涕?)뿐.
- 5칸의 파란 수건·젖은 얼룩, 물대야(補-b?)의 뜻이 확정되지 않음. ✦ 표식 반복 = 칸별 생성 뒤 이어 붙인 흔적.
