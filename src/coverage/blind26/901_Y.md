# 901 판독 (판독자 Y)

## 1단계 — 생판 (사전 열람 전 확정)

**① 판 표제어**
- 1순위 **『素問·宣明五氣』 五臟 대응 묶음 — 五液·五惡·五勞所傷** (85%)
- 2순위 **五行 歸類(五臟 계통 대응표) 통합판** (10%)
- 근거: 기와지붕 한 채에 방 5칸, 벽색이 靑·赤·黃·(灰白)·白 순이고 인물 옷이 綠·紅·黃·白·黑 → 肝心脾肺腎. 칸마다 「진액 하나 + 싫어하는 기후 하나 + 오래 하는 자세 하나 + 닳은 소품 더미」가 반복된다.

**② 인물별 (왼쪽부터)**
1. 녹색 갑옷 장수 — **肝**. 눈물 2줄 = 肝爲淚 / 문틈 바람·나뭇잎을 손으로 막음 = 肝惡風 / 걷는 자세 + 구멍 난 짚신 3켤레 더미 = 久行傷筋 / 장수 = 將軍之官(부가). 4개.
2. 붉은 곤룡포 임금 — **心**. 이마 땀방울 = 心爲汗 / 화로 불꽃 = 心惡熱 / 책 읽기 + 해진 책·종이 더미 = 久視傷血 / 임금 = 君主之官 / 판자 아래 검게 그을린 자국 = 焦(心臭, 추정). 4~5개.
3. 노란 옷·노란 삿갓 사내 — **脾**. 입가 침 한 줄 = 脾爲涎 / 천장 곰팡이 얼룩서 새는 물을 우산으로 받음 = 脾惡濕 / 방석 위 가부좌 + 솜 터진 방석 3장 = 久坐傷肉. 3개.
4. 흰 옷 선비(누움) — **肺**. 문틈 눈송이·찬 김·성에 = 肺惡寒 / 요 위에 누움 + 터진 베개 3개 = 久臥傷氣 / 요 끝에서 떨어지는 물방울·바닥 웅덩이 = 肺爲涕(추정) / 바닥 흑립 = 相傅之官(선비) 추정. 3~4개.
5. 검은 잠수복 사람 — **腎**. 입에서 타구로 침 줄기 = 腎爲唾 / 갈라지고 회벽 벗겨진 벽·거미줄 = 腎惡燥 / 꼿꼿이 서 있고 몸에까지 거미줄 = 久立傷骨 / 검은색 = 黑. 3개.

**③ 잔결**
- 4번 칸 콧물(涕)이 코에서 나오지 않고 요 가장자리에서 떨어진다 — 붙여 넣은 물방울이 제자리를 벗어남. 얼굴도 눌린 듯 일그러짐.
- 4번 바닥 흑립, 2번 판자의 검은 그을음, 5번 벽의 파란 수건·붉은 대야 — 뜻 불명.
- 눈물·땀·침 방울, 2번 불꽃, 4번 눈송이·김, 3번 낙숫물 선, 5번 침 줄기는 화풍이 달라 덧붙인 흔적이 뚜렷함. 프레임 잘림은 없음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **五臟 대응 — 五液·五惡·五勞所傷 (『素問·宣明五氣』)** (90%)
- 2순위 **五行 歸類 / 오행왕국 五臟 통합판** (7%)
- 다섯 인물이 사전의 肝·心·脾·肺·腎 의인화와 그대로 맞는다. 결정적인 것은 **惡 = 해로운 것과 사람 사이에 세워 둔 가리개**다. 문짝·판자·우산·문·수건이 다섯 칸 모두에 있어서 五惡이 확정된다. 1단계보다 잘 풀린다.

**② 인물별**
1. **肝**(초록 갑옷 장군): 눈물 = 肝爲淚 / 문짝 가리개(惡) + 옆으로 날리는 잎(風) = 肝惡風 / 걷기 + 짚신 셋 포개짐(久) = 久行(傷筋). 3개.
2. **心**(곤룡포 임금): 살갗의 땀방울(汗) = 心爲汗 / 판자 가리개(惡) + 불꽃(熱) = 心惡熱. 판자의 그을음은 막고 있다는 표시이고, 1단계의 「焦」 추정은 철회한다 / 책 읽기 + 해진 책 무더기 = 久視(傷血). 3개.
3. **脾**(밀짚모자 농부): 입가 침 = 脾爲涎 / 우산 가리개(惡) + 곰팡이 천장의 누수(濕) = 脾惡濕 / 가부좌 + 방석 셋(久) = 久坐(傷肉). 3개.
4. **肺**(흰 도포 재상): 닫힌 문(惡) + 눈송이(寒, 外寒) = 肺惡寒 / 누움 + 베개 셋(久) = 久臥(傷氣). 흰 김(氣)은 傷氣의 氣로도, 찬 바람으로도 읽힌다 / 물방울은 涕 추정. 갓이 바닥에 있는 것은 누웠으므로 벗은 것이고, 자리만 바뀐 재상의 옷차림이다(太 아님). 2~3개.
5. **腎**(잠수부): 입에서 놋 타구로 가는 침 줄기 = 腎爲唾 / 갈라진 벽(燥)에 덮은 수건 가리개(惡) + 물 대야 = 腎惡燥 / 서 있음 + 몸에까지 친 거미줄 = 久立(傷骨). 3개.

**③ 잔결**
- 4번 涕 방울이 코(鼻 없음)가 아니라 요 끝에서 떨어진다.
- 傷의 대상인 筋·血·肉·氣·骨이 사전 기호로 그려져 있지 않아 원문 지식에 기댄다.
- 5번의 久는 「셋 포개짐」이 아니라 거미줄이라 사전 밖이다. 2번 책 더미도 셋 포개짐이 아니다.
- 5번 놋그릇이 요강(小便)으로, 4번 문틀 성에가 裏寒으로 샐 위험이 있다.
