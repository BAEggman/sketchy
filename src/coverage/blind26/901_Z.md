# 901 판독 (판독자 Z)

## 1단계 — 생판 (사전 없이)

**① 판 전체 표제어**
- 1순위: **五臟 배속 통합 — 『素問·宣明五氣』의 五液·五惡·五勞所傷** (75%)
- 2순위: **五勞所傷(久視傷血·久臥傷氣·久坐傷肉·久立傷骨·久行傷筋) 단독** (15%) / 그 밖에 五行 五臟 배속표(五色) 10%
- 근거: 기와지붕 한 채에 방 5칸, 벽색이 靑·赤·黃·白(회백)·흑(검은 옷) 순 = 木火土金水. 칸마다 ⓐ 얼굴 체액 하나 ⓑ 방을 괴롭히는 기후 하나 ⓒ 오래 하는 자세 하나 + 해진 물건 더미가 반복된다.

**② 인물별 (왼쪽부터)**
- 인물1 녹색 칸 — **肝**: 갑옷 장수 = 肝者將軍之官 / 푸른 갑옷·벽 = 靑 / 눈물 = 肝液 淚 / 문짝을 밀어 막는데 문틈으로 바람·나뭇잎 = 肝惡風 / 걷는 중 + 바닥이 뚫린 짚신 3짝 = 久行傷筋 → 5개.
- 인물2 붉은 칸 — **心**: 익선관·곤룡포의 임금 = 心者君主之官 / 붉은 벽·옷 = 赤 / 머리에서 튀는 땀방울 = 心液 汗 / 불타는 화로 = 心惡熱 / 책을 들여다보며 씀 + 버려진 책 더미 = 久視傷血 / 세로 판자 한쪽이 검게 그을림 = 焦(心臭) 또는 熱의 보강(불확실) → 5~6개.
- 인물3 노란 칸 — **脾**: 노란 옷·노란 삿갓 = 黃 / 입가 침 = 脾液 涎 / 천장 얼룩에서 새는 물 + 우산 = 脾惡濕 / 방석에 가부좌 + 솜이 터진 방석 3개 = 久坐傷肉 → 4개.
- 인물4 회백 칸·흰옷 — **肺**: 흰 옷 = 白 / 누워 있음 + 터진 베개 3개 = 久臥傷氣 / 문틈의 눈송이·입김·성에 = 肺惡寒 / 요 아래로 떨어지는 물방울·웅덩이 = 肺液 涕(?) / 벗어 둔 검은 갓 = 뜻 미상(華蓋?) → 4~5개.
- 인물5 흰 칸·검은 전신복 — **腎**: 검은 옷 = 黑 / 입에서 길게 늘어진 침 → 놋쇠 타구 = 腎液 唾 / 꼿꼿이 선 채 거미줄 3개(겨드랑이에까지) = 久立傷骨 / 쩍쩍 갈라지고 벗겨진 벽·말라붙은 수건 = 腎惡燥 / 물대야 = 水(?) → 4~5개.

**③ 잔결**
- 뜻 모를 소품: 인물4의 갓, 인물2의 그을린 판자, 인물5의 물대야·얼굴 띠(마스크).
- 어색: 인물4 물방울이 코가 아니라 요 한가운데서 떨어진다(涕로 읽기 약함). 인물4 얼굴에 긁힌 듯한 선.
- 덧붙인 흔적: 눈물(파란 물방울)·불꽃(이모지풍)·침·눈송이(* 표)·입김 덩어리가 본그림과 화풍이 다른 디지털 오버레이.
- 프레임: 지붕 왼쪽 처마 끝이 화면 밖으로 잘림, 오른쪽 끝 2px 분홍 띠(이어붙인 경계), 아래쪽 1/5이 빈 여백.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 전체 표제어**
- 1순위: **『素問·宣明五氣』 五臟 통합 — 五液 + 五惡 + 五勞所傷** (88%)
- 2순위: **五勞所傷 단독** (7%) / **五臟 五行 歸類(五液·五惡)** 5%
- 사전으로 더 잘 풀린다. 「惡 = 해로운 것과 사람 사이에 세운 가리개」가 다섯 칸 모두에 있고(문짝·판자·우산·문·벽의 수건), 「久 = 같은 물건 셋 포갬 / 닳은 무더기는 傷이 아니라 久」가 짚신·책·방석·베개 더미를 한꺼번에 설명한다. 인물 다섯은 사전의 오행왕국 다섯 인물 그대로(장군·임금·밀짚모자 농부·흰 도포 재상·잠수부)이고 옷 색 = 五色. 15칸 = 3계열 × 5臟으로 깔끔히 닫힌다.

**② 인물별 (왼쪽부터)**
- 인물1 **肝**(초록 비늘갑옷 장군): 눈물 = 肝爲淚 / 문짝(가리개=惡) + 옆으로 흘러 날리는 잎(風) = **肝惡風** / 걷는 발 + 닳은 짚신 셋 포갬(久) = **久行傷筋**(筋 기호는 없음) → 3개.
- 인물2 **心**(곤룡포 임금): 머리에서 튀는 땀방울(汗) = 心爲汗 / 임금과 화로(불꽃=熱) 사이 세운 판자(가리개=惡), 불 쪽이 그을림 = **心惡熱** — 1단계의 「焦」는 철회 / 책 들여다봄 + 닳은 책 무더기(久) = **久視傷血** → 3개.
- 인물3 **脾**(노란 밀짚모자 농부): 입가 침 = 脾爲涎 / 천장에서 새는 물(濕) 아래 우산(가리개=惡) = **脾惡濕** / 가부좌 + 터진 방석 셋 포갬(久) = **久坐傷肉** → 3개.
- 인물4 **肺**(흰 도포 재상, 갓은 누우며 벗어 둔 옷차림 — 太 아님): 떨어지는 물방울·웅덩이 = 肺爲涕(위치 어색) / 문(가리개) 틈의 눈송이(寒) = **肺惡寒** / 누움 + 터진 베개 셋 포갬(久) = **久臥傷氣** — 문가 흰 김 덩이가 氣일 수 있음 → 3개.
- 인물5 **腎**(검은 잠수복·후드·고글 잠수부): 입에서 늘어진 침 → 놋 타구 = 腎爲唾 / 갈라지고 벗겨진 벽(燥) = **腎惡燥**, 물대야·벽에 건 수건은 건조를 막는 가습(가리개 꼴은 약함) / 꼿꼿이 선 채 몸에까지 친 거미줄 = **久立傷骨** → 3개.

**③ 잔결**
- 傷 쪽 대상(筋·血·肉·氣·骨)은 사전 기호로 그려지지 않음 — 인물4의 흰 김만 氣 후보.
- 인물5에는 「셋 포갬」 久가 없고 거미줄이 대신함, 惡 가리개도 뚜렷하지 않음.
- 인물4 涕 방울이 코가 아니라 요 가운데서 떨어짐. 문틀 안쪽 성에는 갈림상 裏寒으로 샐 수 있음.
- 갈림 충돌 위험: 놋 타구 → 요강(小便)으로 오독될 수 있음, 기와지붕 한 채 → 寺와 겹침.
- 오버레이(눈물·불꽃·침·눈송이·김)는 화풍이 다름, 지붕 왼쪽 잘림, 오른쪽 끝 2px 분홍 띠.
