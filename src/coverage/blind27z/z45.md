# z45 판독 기록

## 1단계 — 생판 (사전 없이)

**① 단원**: **望診·望色(五色主病)** 60% / 차순위 **黃疸(陽黃·陰黃 감별)** 20%, **五行 五色** 10%.
회색 빈 방, 긴 나무 의자에 맨발로 나란히 앉은 세 사람 — 소품 없이 피부색과 눈흰자만 다르다. 「얼굴(몸) 빛을 본다」는 무대 = 望色. 왼쪽 가장자리 이웃(분홍 손바닥·김 나는 발바닥·붉은 기운)은 다른 색(赤?) 몫으로 보고 제외. 오른쪽 벽 모서리와 테두리선이 있어 이 띠는 판의 오른쪽 끝으로 보임.

**② 인물**
- 왼쪽 남자(상투·바지·무릎 벌림, 굳은 얼굴): **陽黃** — 얼굴·목·손·종아리·발까지 온몸이 선명한 귤빛(黃色鮮明如橘子色), 눈흰자도 주황 → 目黃+身黃 2징(黃疸). 남성·열린 자세·찌푸린 얼굴 = 陽·濕熱.
- 가운데 여자(창백한 담황색, 마른 얼굴): **萎黃** — 淡黃·枯槁無華. 눈흰자만 새하얗다 = 目睛不黃 → 黃疸이 아님. 脾胃氣虛·氣血不足.
- 오른쪽 여자(어둡고 탁한 황갈색, 눈 밑 그늘, 눈흰자 누르스름): **陰黃** — 黃而晦暗如烟熏, 目黃. 여성·어두움 = 陰·寒濕困脾.

**관계**: 셋이 한 의자 = 黃色 한 가족(黃色主脾虛·濕證). 양끝 남/녀(밝음/어두움)의 짝 = 陽黃 vs 陰黃(鮮明 vs 晦暗, 濕熱 vs 寒濕). 둘 사이의 흰 눈 = 「눈이 노랗지 않으면 黃疸 아님」 — 萎黃 감별점. 밝음→옅음→어둠의 순.

**③ 잔결**: 소품이 전혀 없어 色 외 사실(소변黃 등 3징의 셋째)이 실리지 않음. 왼쪽 가장자리 이웃의 김·붉은 발광은 이웃 띠 몫. 이어 붙인 흔적은 뚜렷하지 않음(남자가 약간 큰 축척).

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**① 단원**: **望診·望色(五色主病) — 黃色 갈래** 70%. 사전의 面 갈림 「광택만 面, **얼굴색 자체는 望色 판 전담**」이 이 띠의 문법을 그대로 말한다 — 소품 없이 살빛 하나로 사실을 나르는 판. 셋 다 회색 옷이라 五色 옷의 오행왕국 인물(肝·心·脾·肺·腎)이 아니므로 **五行** 후보는 내려간다(5%). **黃疸** 단독은 15%.

**② 인물**
- 왼쪽 남자: **陽黃** — 귤빛 身黃 + 크게 뜬 눈(目)의 주황 흰자 = 目黃. 불꽃(熱)·진창(濕) 소품은 없어 濕熱 病因은 사전 기호로는 실리지 않고 「선명함」으로만 실린다.
- 가운데 여자: **萎黃** — 淡黃 枯槁, 크게 뜬 눈의 흰자가 하얗다(目不黃 → 黃疸 아님). 사전 「中 = 같은 것 셋 중 가운데」(몸 위·가구 아님)로 읽으면 **中焦 脾胃 虛·中氣不足**이 덧실린다 — 조건이 맞아 채택하되 의도 여부는 반신반의.
- 오른쪽 여자: **陰黃** — 晦暗如烟熏, 目黃, 눈 밑 그늘. 눈송이(寒) 없음 → 寒濕은 「어두움」으로만.

**관계**: 1단계와 같다 — 한 의자 = 黃色主脾虛·濕證 한 가족, 양끝 남(陽)·녀(陰) = 陽黃 鮮明 vs 陰黃 晦暗, 가운데의 흰 눈 = 萎黃은 目黃이 없다는 감별. 사전의 目(크게 뜬 눈)이 셋 모두에 있어 「눈을 보라」가 감별 열쇠임을 굳힌다. 광택(華·面) 기호는 셋 모두 없음 — 有華/無華는 색의 맑고 탁함으로만 실림.

**③ 잔결**: 黃色 넷째 갈래 **黃胖(面黃虛浮)** 가 없다(腫=부푼 곳 기호도 없음). 黃疸 3징의 小便黃(요강)도 없음. 왼쪽 이웃의 위로 편 분홍 손바닥·김 나는 발바닥(氣/五心煩熱?)은 이웃 띠 몫. 이어 붙인 흔적은 여전히 뚜렷하지 않음. 사전 어휘로 새로 풀리는 것은 中(가운데) 하나뿐이고 나머지는 1단계 판독을 확인하는 데 그친다.
