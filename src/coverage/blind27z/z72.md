# z72 판독

## 1단계 — 생판 (사전 열기 전 확정)

① 단원: **望診 — 望色(五色主病)** 82% (차순위 **五色診 안의 靑色主病** 단독판, **病因 驚** 10% 미만)

② 인물(왼→오, 회색 벽·회색 옷 = 얼굴·피부색만 정보로 남김. 한 벤치에 나란히 = 진찰 대기실, 순서대로 色을 보는 자리)
- 왼쪽 중년 남자 — **靑色主痛·主寒**: 두 손으로 배를 움켜쥐고 눈 감고 찡그림, 배꼽 둘레 靑紫 멍 → 寒凝氣滯 腹痛.
- 여자 — **靑色主瘀血**: 입술 靑紫, 팔뚝에 X자로 얽힌 푸른 핏줄(靑筋), 손끝 靑, 뺨·목에도 푸른 실선 → 血瘀. 제 팔을 감싸 쥔 자세는 寒(추위)도 겹침.
- 서 있는 아이 — **靑色主驚風(小兒)**: 眉間·鼻柱(山根)만 파랗게, 눈 동그랗게 뜨고 비명, 두 주먹 꽉 쥠(握拳=抽搐 전조). 발밑 깨진 옅은 청자 사발(큰 조각 3 + 잔 조각 약 8) = 쨍그랑 소리에 놀람(驚).
- 오른쪽 남자(띠 가장자리) — **赤色主熱**: 얼굴·손·발 온통 붉음(滿面通紅 = 實熱), 부채질, 발치에 벗어 던진 회색 이불/겉옷 = 惡熱 揭衣被.
- 관계: 남·여·아이가 한 가족처럼 같은 靑色을 나눠 가짐 = 靑色 主病 4개(寒·痛·瘀血·驚風)를 셋이 분담. 오른쪽에서 赤色이 시작 = 五色을 靑→赤(木→火) 순서로 줄 세운 판, 이 띠는 그 이음매.

③ 잔결: 사발이 왜 하필 푸른빛인지(靑 반복인지 소리원일 뿐인지) 불명 / 아이만 서 있음 / 위쪽 가로 천장띠 / 왼쪽 아래 가장자리 둥근 물체(이웃 띠 몫) / 여자의 寒·瘀 이중 신호가 남자의 寒과 겹침.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽음)

① 단원: **望診 — 望色(五色主病), 靑色主病 구간 + 赤色 첫머리** 90%. 근거: 사전의 面 갈림 「얼굴색 자체는 望色 판 전담」, 瘀 갈림 「살갗 위 멍·얼룩은 그 자리의 색」 — 이 띠의 정보가 전부 살갗 색에 실려 있다. 오행왕국 인물 옷 = 五色인데 여기 옷은 모두 회색 = 장부 인물이 아닌 환자, 색은 살갗에만.

② 
- 왼쪽 남자 — **靑主痛(寒凝 腹痛)**: 배꼽 둘레 靑紫는 瘀 기호가 아니라 「그 자리(臍腹)의 색」. 痛(쇠못)·寒(눈송이) 기호는 없고 배를 움켜쥔 몸짓이 痛을 진다.
- 여자 — **靑主寒 + 靑主瘀血**: 손끝이 검푸름 = 사전의 **厥**(검푸르게 언 손발 끝) → 手足厥冷, 陰寒. 입술 靑紫·팔뚝 푸른 핏줄은 살갗 색이라 瘀 기호(검붉은 덩이)로는 안 읽히고 望色의 「脣靑紫 = 血瘀」로 읽힘. 푸른 핏줄은 갈색이 아니라 筋 아님.
- 아이 — **靑主驚風(小兒)**: 靑이 크게 뜬 目 사이(眉間)에서 口 쪽 鼻柱로 내려옴 = 小兒驚風의 眉間·鼻柱 靑. 뺨에 땀방울 하나(汗) = 놀라 식은땀. 두 주먹 握拳 = 抽搐 전조. 깨진 빈 사발은 담긴 것이 없어 어느 글자의 사물도 아님 → 傷 아님, 놀람(驚)의 소리원.
- 오른쪽 남자(잘림, 이웃 몫 가능) — **赤主熱**: 熱 기호(불꽃) 없이 살갗 전체 赤 = 滿面通紅 實熱. 부채·벗어 던진 천(溫의 김 없음) = 惡熱.
- 관계: 회색 옷 셋이 같은 靑을 나눠 寒·痛·瘀血·驚風 4主病을 분담(가족 = 같은 색 다른 병), 오른쪽 赤으로 넘어감 = 五色 순서 靑→赤.

③ 잔결: 부채는 사전에 없는 소품(風 기호의 「옆으로 날림」도 없음) / 깨진 사발의 옅은 푸른빛 / 痛·寒 전담 기호 부재로 남자의 寒·痛이 몸짓에만 기댐 / 1단계보다 여자가 寒(厥) 쪽으로 이동.
