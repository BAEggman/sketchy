# 901 판독 (blind)

## 1단계 — 생판 (사전 없이)

**① 판 표제어**
- 1순위: **望色 — 五色主病 중 青·赤·黃 (病色 주병)** 80%
- 2순위: **五色配五臟 色診(肝青·心赤·脾黃) / 望診 面色 총론** 10%
- 근거: 빈 진찰실 긴 의자에 환자 9명이 색깔별로 줄지어 앉고(青 4 → 赤 2 → 黃 3), 앞에 의사 1명이 등을 보이고 무릎 꿇어 "바라보기만" 한다. 白·黑 환자는 없다.

**② 인물(왼→오)**
- 앞쪽 무릎 꿇은 의사(등 돌림, 손 무릎): **望診**(보기만 하고 만지지 않음) — 1개.
- 인물1 서리 담요 덜덜 남자: **青色主寒** — 서리 낀 담요·떨림선(惡寒), 입술 청색, 손끝 청색, 가슴에 댄 손(心胸 寒痛? 불명) — 4개.
- 인물2 배에 못 박힌 남자: **青色主痛** — 못(찌르는 통증), 못 둘레 보랏빛 멍, 두 손으로 배 움켜쥠(腹痛), 찡그린 얼굴 — 3개.
- 인물3 여자: **青色主瘀血** — 입술 청자색, 손톱·손끝 청자, 팔뚝·목의 푸른 핏줄(靑筋), 다른 팔의 X자 긁힌 결(肌膚甲錯?) — 4개.
- 인물4 서 있는 아이: **青色主驚風(小兒)** — 미간·코마루 청색, 두 주먹 꽉 쥠(握固), 부릅뜬 눈·벌린 입, 발밑 깨진 사발(驚, 조각 약 10개) — 4개.
- 인물5 붉은 남자: **赤色 — 實熱(滿面通紅)** — 얼굴·목·손발 전부 붉음, 부채(惡熱), 사발 들이킴(口渴喜飮), 바닥에 벗어던진 이불(揭衣被) — 4개.
- 인물6 노년 여자: **赤色 — 虛熱(陰虛, 兩顴潮紅)** — 두 뺨만 동그랗게 붉음, 이마 땀(盜汗/潮熱), 위로 편 붉은 손바닥(手心熱), 김 나는 붉은 발바닥(足心熱) → 五心煩熱 — 4개. (둥근 볼연지 = 戴陽 "泛紅如妝"일 가능성 15%)
- 인물7 주황 남자: **黃色 — 陽黃** — 귤빛 선명한 황색 온몸, 눈자위 황색(目黃), 굳은 표정 — 3개.
- 인물8 연노랑 여자: **黃色 — 萎黃(脾虛)** — 엷고 윤기 없는 황색, 눈흰자 흼(목황 없음=黃疸 아님) — 2개.
- 인물9 흑갈황 여자: **黃色 — 陰黃** — 연기 그을린 듯 어두운 황색, 눈자위 황색 — 2개.

**③ 잔결**
- 白色·黑色 환자가 없어 五色 중 3색만 — 반쪽 판인지 의도인지 불명.
- 인물1의 가슴 위 청색 손: 寒인지 心痛(胸痹)인지 미정. 인물3 왼팔 X자 무늬 뜻 애매. 黃胖(浮腫) 인물 없음.
- 프레임: 네 변에 검은 테(레터박스)만 있고 잘림·이어붙인 이음매 없음.

## 2단계 — 계통 (blind6_사전요약 적용 후)

**① 판 표제어**
- 1순위: **望色 — 五色主病(青·赤·黃 3색)** 88% ↑
- 2순위: **望診 面色 총론(善色·惡色 / 五色配五臟)** 7%
- 결정적 근거: 사전의 「面 = 광택만, **얼굴색 자체는 望色 판 전담**」 — 이 판이 바로 그 望色 판이다. 사람마다 피부색이 주병을 나르고, 장부 인물(갑옷 장군·임금·밀짚모자 농부)이 하나도 없어 五行 판이 아님도 확인된다.

**② 인물(왼→오), 사전 어휘로 다시 읽기**
- 의사(등): **望診** — 1개.
- 인물1: **青 → 寒** — 서리 낀 담요 = 寒(갈림: 눈송이 外寒/안쪽 성에 裏寒/밑의 서리 內寒 중 어느 것인지 애매, 담요 겉 반점), 떨림선(惡寒), 입술 青, 검푸른 손끝 = **厥**(肢冷), 가슴 댄 손(面色青灰·唇青·肢冷 → 心陽暴脫/心血瘀阻 가능) — 4~5개.
- 인물2: **青 → 痛** — 살에 박힌 쇠못 = **痛**(확정), 둘레 보랏빛 = 갈림상 瘀가 아니라 그 자리의 색(青), 배를 움켜쥠 = 腹部 — 3개.
- 인물3: **青 → 瘀血** — 瘀 글자(몸 밖 검붉은 덩이)는 없음 → 색으로만: 입술 青紫, **爪**(손톱) 青紫, 팔·목 푸른 핏줄, 팔뚝 X자 결(肌膚甲錯?) — 4개.
- 인물4: **青 → 小兒 驚風** — 眉間·鼻柱 青, **目** 크게 뜸(直視), 두 주먹 握固(抽搐), **口** 벌려 啼叫, 뺨 **汗** 한 방울, 흩어진 깨진 사발(놀람·驚則氣亂; 사발은 등재 사물이 아니라 傷 갈림 미충족) — 5~6개.
- 인물5: **赤 → 實熱(滿面通紅)** — 얼굴·손발 전부 붉음, 부채(惡熱), 마시는 사발 = **淸**(맑고 찬 물 한 그릇 → 喜冷飮·淸熱), 벗어던진 이불 — 4개.
- 인물6: **赤 → 虛熱(陰虛)** — 兩顴만 紅, 이마 **汗**(盜汗), 손바닥·발바닥 = 五心煩熱(사전 면제 조항과 정합), 발에서 오르는 김(사전상 氣지만 여기선 骨蒸·潮熱로 읽힘), 백발 노인 — 5개.
- 인물7: **黃 → 陽黃** — 귤빛 鮮明, **目** 흰자 황(目黃), 온몸 황 — 3개.
- 인물8: **黃 → 萎黃** — 淡黃·광택 없음, **目** 흰자 흼(黃疸 아님) — 2개. (脾 농부 표지는 없음)
- 인물9: **黃 → 陰黃** — 晦暗如煙熏, 目黃 — 2개.

**③ 잔결**
- 白·黑 환자 없음(3색만), 黃胖·戴陽 없음. 赤 두 사람 곁에 熱(불꽃) 표지 없음 — 색·몸짓으로만.
- 인물1 寒 갈림 판별 불가, 인물6 발 김(氣 vs 蒸), 인물1 손끝(厥)과 인물3 손끝(爪 青紫)의 겹침, 깨진 사발 뜻(傷 미충족).
- 잘림·이음매 없음.
- 판정: 사전 어휘(痛·目·汗·淸·厥·面 갈림)가 1단계 해독을 거의 그대로 굳혀 준다. 바뀐 표제어는 없다.
