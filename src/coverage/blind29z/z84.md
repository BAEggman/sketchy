# z84 판독

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원** — **望診·望色(五色主病)** 70% / 차순 **黃疸(陽黃·陰黃)** 12%, **五行 五色** 8%, 기타 10%.
근거: 회색 옷·회색 빈 방·나무 벤치만 두고 소품을 싹 지웠다 → 변수는 '피부색' 하나. 환자들이 대기석에 나란히 앉아 얼굴·손·발까지 같은 색으로 칠해짐 = 면색을 보는 장면.

**② 인물(좌→우)**
- 상투 튼 남자 — **靑(紫)色**. 얼굴·목·손·발 전신 보라회색, 입술 검보라(口唇靑紫=瘀血), 눈 크게 뜨고 굳은 표정(驚), 두 손을 갈고리처럼 무릎을 움켜쥠(痛). → 靑色主病 **寒·痛·瘀血·驚風 4가지** 중 痛·瘀·驚을 몸짓으로 나름. 보라가 짙어 **黑色**(腎虛·寒·水飮·瘀血·劇痛)일 가능성도 있음.
- 가운데 여자 — **黃色 鮮明**. 귤빛 노랑에 이마·볼에 하이라이트(광택), 침착한 얼굴 → **陽黃(濕熱, 鮮明如橘子色)** 또는 **善色(明潤含蓄)**.
- 오른쪽 여자 — **黃色 晦暗**. 같은 노랑인데 갈색·올리브로 탁하고 광택 없음, 눈밑 그늘, 처진 눈썹, 벌린 입(지침) → **陰黃(寒濕, 晦暗如煙熏)** 또는 **萎黃(脾胃氣虛, 枯槁無澤)**·**惡色**.
- 배경: 빈 방·자연광 같은 균일 회색 = 望色은 자연광·무채색 환경에서.

**관계**: 같은 黃色 두 사람을 맞붙여 **광택의 유무(明潤 vs 晦暗)** 만 다르게 함 → 같은 색이라도 **鮮明=陽(熱)·善色·예후 양호, 晦暗=陰(寒)·惡色·예후 불량**. 남자와 두 여자는 **五色 각각이 다른 병을 주한다**는 나열(靑=寒痛瘀驚 / 黃=脾虛·濕).

**③ 잔결**: 왼쪽 끝 잘린 인물은 손발이 분홍·붉음(赤色, 이웃 띠 몫). 소품이 전혀 없어 '한 소품=한 사실' 원칙으로는 셀 거리가 적음. 남자 혼자 바지·상투(남성)라 성별이 뜻을 나르는지 불명. 벤치 오른쪽 끝이 벽 앞에서 끊김—이음 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 단원** — **望診·望色(五色主病·善惡色)** 80%. 사전 「面」의 갈림 "얼굴색 자체는 **望色 판 전담**"이 이 띠를 그 판으로 지목한다. 소품 없는 회색 방은 그대로 유지.

**② 인물(좌→우)**
- 남자 — **靑色(靑紫) = 肝色**. 「瘀」 갈림(살갗 위 색은 瘀가 아니라 그 자리의 색) → 보라는 瘀血 기호가 아니라 **色 자체**로 읽는다. 「目 = 크게 뜬 눈」 → 肝開竅於目 → 靑-肝 대응을 눈이 확인. 靑色主病 **4가지(寒·痛·瘀血·驚風)**. 무릎 움켜쥔 손은 「痛 = 쇠못」이 없어 痛 기호가 아님 → 몸짓으로 痛·驚을 거드는 정도로 강등. 「厥(검푸른 손발 끝)」은 얼굴까지 같은 색이라 해당 없음.
- 가운데 여자 — **黃色 + 광택**. 「面/華 = 이마·광대의 광택」 → 이 판에서 광택은 **澤(明潤)** 축 → **善色**(또는 常色: 明潤含蓄) / 陽黃(鮮明) 후보 유지.
- 오른쪽 여자 — **黃色 + 무광 + 「口」**. 벌린 입에 혀 없이 구멍만 → 「舌」 갈림 = **脾**(開竅於口) → 黃=脾色, 枯槁無澤 → **萎黃(脾胃氣虛)**·**惡色**. 陰黃보다 萎黃 쪽으로 이동.

**관계**: 같은 黃을 둘 세우고 **光澤만** 다르게 → 「**色은 병의 성질·장부, 澤은 精氣 盛衰·예후**」 — 有澤=善色(輕·順), 無澤=惡色(重·逆). 남자의 目(肝)과 오른쪽 여자의 口(脾)는 **五色-五臟-五竅 대응**(靑肝目·黃脾口)을 나름.

**③ 잔결**: 왼쪽 끝 분홍 인물(赤 또는 常色, 이웃 띠). 가운데 여자의 광택이 「面」(전담 기호)인지 단순 채색인지가 판독을 가름. 남자 보라색이 靑紫인지 赤如衃血(赤의 死色)인지 단독으로 확정 불가 — 目이 靑 쪽을 민다. 이음 흔적 없음.
