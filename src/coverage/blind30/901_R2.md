# 901 판독 (R2)

## 1단계 — 생판 (사전 없이)

**① 판 표제어**
- 1순위: **望色 — 五色主病 (常色 vs 病色)** — 85%
- 2순위: **望診 총론(望面色·望形體 포함)** — 10% / 그 밖(五色-五臟 配屬) 5%

무대: 텅 빈 방, 긴 의자에 9명이 앉아 있고, 앞쪽에 등을 보인 채 무릎 꿇은 사람(**醫者 — 望診하는 이**)이 그들을 바라본다. 모두 같은 회색 옷이라 옷이 아니라 **얼굴·손·발 색**만 정보를 나른다 → 색 하나가 사실 하나.

**② 인물별 (왼쪽부터)**
0. 무릎 꿇은 이(앞, 등) — **醫者/望診**: 보기만 함 = 望(1).
1. 분홍빛·윤기·편한 얼굴 — **常色(主色)**: 紅黃隱隱·明潤含蓄(1), 健康(1). → 2개
2. 회색(무채) 얼굴·손발, 처진 눈꺼풀·노인 — **靑色(靑灰)** 추정: 寒·痛·瘀血 중 寒/瘀(1). 蒼白(亡陽) 가능성 남음. → 1~2개
3. 새하얀 얼굴·손발, 피 번진 흰 수건 든 마른 여인 — **白色 中 淡白無華**: 白=虛(1), 血虛(1), 失血(1). → 3개
4. 하얗게 부은 얼굴·눈두덩, 부은 손발, 푸르죽죽 입술 — **㿠白(虛浮)**: 陽虛(1), 水腫/水泛(1), 唇靑紫=寒(1). → 3개
5. 회흑색 얼굴·손발, 무표정 중년 — **黑而暗淡**: 腎陽虛(1), 寒(1). → 2개
6. 회색 머리, 눈 주위 검은 테, 불룩 드러낸 배 — **目眶周圍色黑**: 腎虛(1), 水飮(배=水停)(1); 帶下(寒濕) 가능. → 2개
7. 자흑색(보랏빛 검정) 전신, 무릎 움켜쥔 갈고리 손 — **黧黑/紫黑 = 瘀血**: 瘀血(1), 痛(손 움켜쥠)(1). → 2개
8. 밝은 귤빛 노랑, 윤기 하이라이트 — **陽黃(黃而鮮明 如橘子色)**: 濕熱(1). → 2개
9. 칙칙한 갈황색, 다크서클·벌린 입·지친 표정 — **陰黃(黃而晦暗 如煙熏)**: 寒濕(1); 萎黃(脾胃氣虛) 가능. → 1~2개

**③ 잔결**
- **赤色 인물이 없다** — 五色 중 하나 빠짐(1번이 赤이라면 너무 옅음).
- 2번 발 좌우 색이 다름(한쪽 흰색·한쪽 회색) — 칠 누락 의심.
- 2번 회색이 무채라 靑인지 蒼白/灰인지 판별 불가.
- 6번 배가 임신인지 水腫인지 애매.
- 테두리 검은 띠(약 10px) 외 잘림·이어붙임 흔적 없음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**판정**: 사전의 「面 = 광택 — **얼굴색 자체는 望色 판 전담**」 갈림이 이 판의 정체를 그대로 말해 준다. 옷은 모두 같은 회색(오행왕국의 옷색=五色 문법을 일부러 끈 것)이고 살색만 바뀐다 → 이 판이 望色 전담판. 사전 글자는 보조로만 몇 개 붙는다. 1단계 골격은 유지, 확신 상승.

**① 판 표제어**
- 1순위: **望色 — 五色主病 (常色 vs 病色)** — 92%
- 2순위: **望診 총론 / 常色·病色(善色·惡色)** — 6% (五色-五臟 配屬은 탈락: 장부 인물 옷 문법이 없음)

**② 인물별 (왼쪽부터)**
0. 무릎 꿇은 이 — **醫者(望)**: 사전 글자 없음. 1개
1. **常色** — 紅黃隱隱·明潤含蓄. 熱(불꽃) 없음 → 赤色 아님 확정. 2개
2. **靑色(靑灰)** 55% / **蒼白** 45% — 사전에 회색 글자 없음, 寒(눈송이)도 없어 판별 못 함. 厥(검푸르게 언 손발 끝)은 손발만이 아니라 온몸 색이라 해당 안 함. 1개
3. **淡白** — 수건의 선홍 얼룩은 액체가 튄 「血=붉은 것」이지 검붉게 굳은 瘀가 아님 → 失血(1)·血虛(1)·白=虛(1). 3개
4. **㿠白虛浮** — 얼굴·눈두덩·손발이 「腫=부풀어 팽팽」 → 浮腫(1)·陽虛水泛(1)·唇靑紫=寒(1)·㿠白(1). 4개
5. **黑而暗淡** — 腎陽虛(1)·寒(1). 2개
6. **目眶周圍色黑** — 「目」 둘레 검정(1) + 배가 「腫」(1) → 腎虛水飮(1). 회색 머리(腎衰)는 사전 밖. 3개
7. **面色黧黑(紫黑)=瘀血** — 사전: 「살갗 위 얼룩은 瘀가 아니라 그 자리의 색」 → 瘀 글자가 아니라 望色으로 瘀血(1). 「痛=쇠못」이 없어 갈고리 손의 痛 읽기는 철회. 黑而乾焦(腎陰虛) 가능. 1개
8. **陽黃** — 이마·광대·콧대 광택(面/華) = 鮮明(1), 濕熱(1). 2개
9. **陰黃** 55% / **萎黃** 45% — 晦暗(광택 없음)(1)·寒濕(1)·벌린 입에 혀 없이 구멍만 = 「舌 갈림: 구멍만 → 脾」(1). 3개

**③ 잔결**
- **赤色(滿面通紅/顴紅) 인물 부재** — 五色 중 赤 빠짐(사전 기준으로도 불꽃·붉은 얼굴 없음).
- 2번 좌우 발 색 불일치(한쪽 흰색), 2번 회색이 靑인지 蒼白인지 미결.
- 7번 갈고리처럼 무릎 움켜쥔 손 — 사전 글자 없음, 뜻 미상.
- 잘림·이어붙임 흔적 없음(검은 테두리만).
