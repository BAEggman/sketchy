# 901 판독 (S2)

## 1단계 — 생판 (사전 보기 전, 확정)

**① 판 표제어**
- 1순위 **望色 — 五色主病(面色 진찰)** 80%
- 2순위 **常色과 病色(주색·객색 / 善色·惡色 대비)** 12%
- (참고) 五行의 五色 배속 5%

무대: 텅 빈 대기실, 긴 나무 의자에 9명이 맨발로 일렬, 왼쪽 앞에 등을 보인 채 꿇어앉은 1명(= 얼굴빛을 보는 醫者). 모두 같은 회색 옷이라 「피부색만 보라」는 장치.

**② 인물별 (왼→오)**
1. **常色** — 혈색 도는 분홍빛 얼굴, 편안한 미소, 정상 손발: 紅黃隱隱·明潤含蓄의 정상 면색(기준점). 1개.
2. **蒼白(灰白)** — 얼굴·손·발 모두 잿빛, 늙고 처진 눈·입: 白에 灰가 섞인 蒼白 = 陽氣暴脫/陰寒內盛. 2개(蒼白, 寒·亡陽).
3. **淡白無華 = 失血·血虛** — 하얀 얼굴·손발 + 피 묻은 흰 천을 펼쳐 듦: 白色 主 失血(奪血). 2개.
4. **㿠白虛浮 = 陽虛水泛** — 뚱뚱, 퉁퉁 부은 흰 얼굴·눈두덩, 부은 손발(浮腫), 보랏빛 입술(陽虛 寒凝·唇青紫). 3개.
5. **面黑暗淡 = 腎陽虛** — 광택 없는 잿빛 검은 피부(얼굴·손·발), 처진 표정. 2개(黑 主 腎虛·寒).
6. **眼眶周圍黑 = 腎虛水飲(寒濕帶下)** — 얼굴은 정상, 눈 둘레만 시커멈 + 불룩 드러낸 배(水飲) + 회색 머리(腎虛·髮). 3개.
7. **黧黑(紫黑) = 瘀血·劇痛** — 보랏빛 도는 검은 피부, 무릎을 움켜쥔 갈고리 손(劇痛). 2개.
8. **陽黃 — 鮮明如橘子色 = 濕熱** — 밝고 윤기 있는 노란 얼굴·손발, 또렷한 눈. 2개.
9. **陰黃(또는 萎黃) — 晦暗如煙熏 = 寒濕/脾虛** — 칙칙한 갈황색, 처진 눈·벌린 입·지친 자세. 2개.

**③ 잔결**
- 五色 중 **赤**(실열·虛熱 顴紅·戴陽)과 뚜렷한 **青**(寒·痛·瘀·驚風)이 없음 — 2번 잿빛을 青灰로 읽어야 하는지 모호.
- 꿇어앉은 인물의 역할(醫者인지 환자인지) 표지 없음.
- 7번의 갈고리 손이 劇痛인지 肌膚甲錯인지 갈림.
- 오른쪽 끝 벽 모서리와 9번 사이 공간이 좁아 잘린 느낌, 이어붙임 흔적은 없음.

## 2단계 — 계통 (사전 요약을 읽은 뒤 다시 읽음)

**① 판 표제어**
- 1순위 **望色 — 五色主病(病色)** 90% — 사전의 「面 = 광택만, **얼굴색 자체는 望色 판 전담**」 항목이 바로 이 판을 가리킨다. 오행왕국 인물(五色 옷)이 아니라 모두 같은 회색 옷이므로 색은 장부 인물이 아닌 **피부색** 그 자체를 읽어야 한다.
- 2순위 **常色·病色(善色·惡色: 明潤 대 晦暗)** 7% — 1번 정상인과 8번(광택)·9번(무광)의 대비.

**② 인물별 (왼→오)** — 사전으로 바뀐 곳에 ★
1. **常色** — 관찰자(꿇어앉은 醫者)와 같은 살색, 편안: 明潤含蓄 기준. 1개.
2. **蒼白(灰白)** — 전신 잿빛·노쇠: 陽氣暴脫/陰寒內盛. 사전 기호 없음. 青(青灰)일 가능성 남김. 2개.
3. **淡白無華 = 失血** — ★흰 천의 선홍 얼룩 = **血**(붉은 것). 검붉게 굳은 덩이가 아니므로 瘀가 아니다 → 白色 主 失血·血虛. 2개.
4. **㿠白虛浮 = 陽虛水泛** — ★부은 얼굴·눈두덩·손발 = **腫**. 흰빛(陽虛) + 浮腫(水泛) + 보랏빛 입술(寒). 3개.
5. **面黑暗淡 = 腎陽虛** — ★얼굴에 광택(面)이 없음 = 暗淡. 黑 主 腎虛·寒. 2개.
6. **眼眶周圍黑 = 腎虛水飲** — 눈 둘레만 검음 + ★팽팽히 부른 배 = **腫/實**(水飲) + 윤기 없는 회색 머리(髮의 華 없음 = 腎精虧). 3개.
7. **黧黑(紫黑) = 血瘀** — ★살갗의 색은 瘀 기호가 아니라 「그 자리의 색」 → 색 자체로 黧黑=瘀血. 움켜쥔 갈고리 손은 사전의 **痛(쇠못)**이 없어 劇痛 확정 불가. 1~2개.
8. **陽黃(鮮明如橘子色) = 濕熱** — ★이마·콧대·광대의 광택 = **面/華** → 鮮明. 2개.
9. **萎黃(脾胃氣虛)** — ★벌린 입이 혀 없이 **구멍만** = 口 → **脾**(舌 갈림). 무광 갈황색(枯槁)·처진 눈(氣虛). 1단계의 陰黃보다 萎黃 쪽으로 옮김. 3개.

**판정**: 사전 어휘로 3·4·8·9번이 더 단단해졌다(血≠瘀, 腫, 面 광택, 口=脾). 7번 「劇痛」은 사전상 근거가 없어 약해졌다. 표제어는 1단계와 같다.

**③ 잔결**
- 五色 중 **赤이 없음**, **青**은 2번 잿빛으로만 애매 — 白3·黑3·黃2·常1로 읽힘.
- 7번 갈고리 손, 4번 보랏빛 입술은 사전 기호가 아니라 뜻이 갈림.
- 꿇어앉은 인물 역할 표지 없음. 사방 가장자리 얇은 검은 테(영상 캡처식 액자), 이어붙임 흔적은 없음.
