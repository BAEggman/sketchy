# 901 판독 (T2)

## 1단계 — 생판 (사전 어휘 없이)

**① 판 표제어**
- 1순위: **望診 — 望面色(常色과 五色主病)** (70%)
- 2순위: **體質 9분류(平和·氣虛·痰濕·血瘀·濕熱·氣鬱 등)** (12%)
- 근거: 앞쪽에 무릎 꿇고 뒷모습을 보이는 사람(醫者)이 긴 의자에 앉은 9명을 "보고" 있고, 9명은 피부색(얼굴·손·발 모두)만 계통적으로 다르다. 옷·배경은 전부 회색으로 눌러 피부색만 읽히게 해 둠.

**② 인물별 (왼쪽부터)**
- 0. 앞 왼쪽 무릎 꿇은 뒷모습 — **醫者/望診 시행자** (1개: 환자를 마주보고 살핌).
- 1. 혈색 좋은 젊은 남자 — **常色** (2개: 紅黃隱隱, 明潤含蓄 / 자세 반듯 = 神 있음).
- 2. 잿빛-흰 피부 늙은 남자, 처진 눈·눈밑 주머니 — **白色(蒼白·灰白)→氣虛** (2개: 회백색 = 虛·寒, 피로한 얼굴 = 氣虛). 대안 **靑色**(그러나 푸른 기 없이 무채색).
- 3. 새하얀 젊은 여자, 붉은 피 번진 흰 천 — **淡白 → 失血·血虛** (2개).
- 4. 비만, 얼굴 희고 부석부석, 눈두덩 부음, 입술 보라, 손발 부음 — **㿠白虛浮 → 陽虛水泛** (3개: 㿠白, 浮腫, 唇靑紫=寒凝/瘀).
- 5. 탁한 흑회색 남자(얼굴·손·발) — **黑而暗淡 → 腎陽虛·寒證** (2개).
- 6. 피부 정상, 눈둘레만 시꺼멓고 배를 드러낸 팽만 — **目眶周圍黑 → 腎虛水飮**(여성이라 寒濕帶下 가능) (2개).
- 7. 보랏빛 검은 피부, 날 선 눈, 검붉은 입술, 손가락 비틀린 손 — **黧黑(紫黑) → 瘀血**(肌膚甲錯?), 대안 黑而乾焦=腎陰虛 (2개).
- 8. 반짝이는 귤빛 노랑 — **黃而鮮明 → 陽黃(濕熱)** (2개).
- 9. 칙칙한 옅은 노랑, 처진 눈, 입 벌린 한숨 — **萎黃 → 脾胃氣虛**, 대안 陰黃 (2개).

**③ 잔결**
- 五色 중 **赤色 인물이 없음**(靑도 2번이 회색이라 불확실) → 五色主病판이라면 결손.
- 6번 드러낸 배가 腹水인지 임신인지 모호. 2번 주황 입술의 뜻 불명.
- 무대가 창 없는 빈 방 — 望診 조건(자연광) 소품 없음. 프레임 잘림·이어붙인 흔적은 보이지 않음.

## 2단계 — 계통 (사전요약 어휘 적용)

**① 판 표제어**
- 1순위: **望色(面色診) — 常色·五色 하위형·善色/惡色** (85%)
- 2순위: **體質 9분류** (5%)
- 근거: 사전의 「面 — 갈림: 얼굴색 자체는 望色 판 전담」이 이 판의 문법과 그대로 맞는다. 옷·벽을 무채색으로 눌러 피부색만 사실을 지게 함.

**② 인물별 (왼쪽부터)** — 1단계와 달라진 곳에 ▶
- 0. 무릎 꿇은 뒷모습 — **醫者(望診)** (1개).
- 1. **常色** (2개: 紅黃隱隱, 이마·광대 광택 = 明潤含蓄).
- 2. **蒼白(白中帶灰)** (2개: 白 중 가장 어두운 회백 = 亡陽·陽氣暴脫/實寒, 처진 눈 = 氣虛). 1번과 생김새가 달라(젊은이↔노인) 善惡 쌍둥이 갈림에 걸리지 않음 → 색 하위형으로 읽음. 靑 가능성은 남음.
- 3. **淡白 → 失血** (2개: 천 위 선홍 얼룩 = 血(붉은 것)·검붉게 굳지 않아 瘀 아님 → 失血; 淡白無華 = 血虛).
- 4. **㿠白虛浮 → 陽虛水泛** (3개: 㿠白 = 陽虛, 얼굴·눈두덩·손발 = 腫, 보라 입술 = 寒).
- 5. **黑而暗淡 → 腎陽虛** (2개: 黑 = 腎虛, 광택 없는 탁한 흑 = 陽虛·寒).
- 6. **目眶周圍黑 → 腎虛水飮** (2개: 눈둘레 흑, 불룩 팽팽한 배 = 腫 → 水飮; 여성이라 寒濕帶下도 가능).
- 7. **紫黑(黧黑) → 瘀血** (2개: 자흑색 피부 = 瘀血, 마른 갈퀴 손 = 肌膚甲錯?). 살갗 색이라 사전의 瘀 기호(몸 밖 덩이)는 아님 — 색 자체로 읽음. 대안 黑而乾焦(腎陰虛).
- 8. ▶ **黃 — 善色(有神)** (3개: 黃, 이마·광대·콧대에 배어 나는 광택, 곧은 목·맑은 눈).
- 9. ▶ **黃 — 惡色(無神)** (3개: 같은 黃에 잿빛이 덮여 반사 없음, 처진 눈꺼풀, 다물지 못한 입). 8·9는 가르마·쪽머리·얼굴형이 같은 쌍둥이 → 갈림 조건 충족이라 陽黃/萎黃이 아니라 **善惡 쌍**으로 고쳐 읽음.

**③ 잔결**
- 五色 중 **靑·赤 인물 없음**(이 판은 白3·黑3·黃2만) — 다른 판 몫이면 무방, 한 판 통합이면 결손.
- 2번 회백이 白(蒼白)인지 靑인지 그림만으로 가르기 어려움. 4번 보라 입술·7번 붉은 눈가는 사전에 없는 사실이라 뜻이 하나로 모이지 않음.
- 6번 배는 腫으로 읽었으나 임신으로도 보임. 잘림·이어 붙인 흔적은 없음.
- 판정: 사전 어휘로 8·9가 善惡 쌍으로 확정되고 3번 血 읽기가 굳어져 **1단계보다 더 잘 풀린다**. 나머지는 色 하위형 지식에 기댐.
