# 901 판독 (U2)

## 1단계 — 생판 (사전요약 열기 전에 확정)

**① 판 표제어**
- 1순위 **望色(面色 望診) — 常色과 病色의 主病 (白·黑·黃 위주)** — 75%
- 2순위 **五色主病 / 善色·惡色 대비** — 15%
- 근거: 등 돌리고 꿇어앉은 사람(醫者=望診하는 눈) 앞에, 같은 회색 옷을 입은 9명이 벤치에 나란히 앉음. 옷·배경은 모두 무채색이고 **피부색만** 사람마다 다름 → 판의 정보는 오로지 '얼굴(과 손발) 빛깔'. 赤色 대표가 뚜렷하지 않고 白 3·黑 3·黃 2가 몰려 있어 五色 전체보다 '색별 세부 主病' 판으로 읽힘.

**② 인물별 (왼쪽부터)**
- 앞줄 꿇어앉은 뒷모습: 醫者 → **望診**(보는 행위 자체).
- 인물1 **常色** — 발그레+누르스름, 윤기, 미소 → 紅黃隱隱·明潤含蓄 (2).
- 인물2 **蒼白(灰白)** — 얼굴·손·발 전부 잿빛, 처진 눈꺼풀·늙은 얼굴 → 白色 主 虛寒·陽氣 쇠약(또는 晦暗枯槁=惡色) (2).
- 인물3 **淡白無華** — 창백한 소녀가 피 묻은 흰 천을 펼쳐 듦 → 失血·血虛 (2).
- 인물4 **㿠白虛浮** — 희고 부은 둥근 얼굴, 부은 눈꺼풀, 퉁퉁하고 붉은 맨발, 자청색 입술 → 陽虛水泛(浮腫) (3: 㿠白·虛浮/浮腫·입술 靑紫=寒).
- 인물5 **黑而暗淡** — 얼굴·손발이 칙칙한 회흑, 무표정 → 腎陽虛(寒) (2).
- 인물6 **目眶周圍色黑** — 눈 주위만 검은 다크서클, 드러낸 불룩한 배, 잿빛 머리 → 腎虛水飮(배=水) / 寒濕帶下 (2).
- 인물7 **黧黑·紫黑** — 보랏빛 도는 짙은 흑색, 노려보는 눈, 무릎을 갈퀴처럼 움켜쥔 손 → 瘀血 + 劇痛 (2).
- 인물8 **黃而鮮明(陽黃)** — 반들반들 밝은 귤빛 노랑 얼굴·손발 → 濕熱 陽黃 (2).
- 인물9 **萎黃(또는 陰黃)** — 칙칙한 누런빛, 처진 눈·벌린 입·지친 표정 → 脾胃氣虛(萎黃), 차선 寒濕 陰黃 (1~2).

**③ 잔결**
- 인물2의 왼발(관객 기준)만 하얗고 오른발은 잿빛 — 색 불일치(白의 흔적인지 채색 오류인지 모호).
- 赤色 담당 인물이 없음(인물1의 홍조는 常色으로 읽힘) — 五色 판이라면 빈칸.
- 인물4 입술의 자청색은 白 계열 인물에 붙은 2차 정보로 의미가 갈릴 수 있음.
- 오른쪽 끝 가장자리에 검은 세로 띠(프레임 경계), 인물9가 벽 모서리에 바짝 붙음. 명확한 이어붙임 흔적은 없음.

## 2단계 — 계통 (사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **望色 — 常色·病色(白·黑·黃 하위형)과 善色/惡色** — 80%
- 2순위 **善色·惡色(有神/無神) 대비** — 10%
- 사전의 「面=광택만, **얼굴색 자체는 望色 판 전담**」이 이 판을 바로 가리킴. 옷이 모두 회색이라 五行 인물(옷색=五色)이 아님 → 피부색이 곧 글자. 불꽃·눈송이·비 같은 병표지가 하나도 없어 病因이 아닌 '색 자체'의 판.

**② 인물별 (왼쪽부터)**
- 꿇어앉은 뒷모습: 望診하는 醫者(미등재, 무대 장치).
- 인물1 **常色** — 紅黃隱隱·明潤含蓄 (2).
- 인물2 **蒼白(灰白)** — 잿빛 무광 전신·처진 눈꺼풀 → 陽氣 쇠약·虛寒 (2). 쌍둥이 짝이 없어 善惡 항목은 적용 안 함.
- 인물3 **淡白 + 失血** — 천의 얼룩은 선홍 '붉은 것'=血(검붉게 굳은 덩이가 아니므로 瘀 아님) → 失血·血虛 (2).
- 인물4 **㿠白虛浮** — 얼굴·발의 '부풀어 팽팽'=腫 → 陽虛水泛 (2) + 자청색 입술(미등재, 寒/瘀 추정).
- 인물5 **黑而暗淡** — 腎陽虛·寒 (2).
- 인물6 **目眶周圍黑** — 불룩한 배=腫 → 腎虛水飮(水腫) / 차선 寒濕帶下 (2).
- 인물7 **紫黑(黧黑)** — 살갗 색은 瘀 기호가 아니라 '그 자리의 색' → 望色으로서 瘀血 (1). 움켜쥔 손은 痛(쇠못) 기호가 없어 미확정.
- 인물8·9 — 같은 얼굴·머리·체격의 **쌍둥이, 같은 黃色** → 사전 「善惡」 조건 충족으로 판정.
  - 인물8 **黃·善色(有神)** — 이마·광대·콧대 광택(面/華)·맑은 눈·곧은 목 (3).
  - 인물9 **黃·惡色(無神)** — 잿빛 뿌연 덮임·반사 없음·처진 눈꺼풀·다물지 못한 입 (4). 1단계의 陽黃/萎黃 하위형 판독은 차선(쌍둥이가 아니라고 볼 때)으로 내림.

**③ 잔결**
- 赤色 담당 없음(五色 중 靑·赤 공백). 인물2 왼발만 흰색(채색 불일치). 인물4 자청 입술·인물6 잿빛 머리·인물7 갈퀴 손은 사전에 없는 기호라 뜻이 갈림. 인물5와 7은 생김새가 달라 善惡 쌍이 아닌 黑 하위형으로 읽었으나, 둘의 대비(무광 처진 눈 ↔ 맑은 눈)가 善惡 문법과 겹쳐 샐 위험. 오른쪽 끝 검은 세로 띠 외 이어붙임 흔적 없음.
- 판정: 사전 어휘로 인물8·9가 '陽黃/萎黃'에서 '善色/惡色'으로 다시 풀리고, 인물3의 血/瘀 구분·인물4·6의 腫이 확정됨 → 1단계보다 더 잘 풀림.
