# z28 판독

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원 1순위: 問診(十問歌)** — 35%. 차순위 **四診(問·聞)** 20%, **九氣(擧痛論: 寒則氣收·炅則氣泄·驚則氣亂)** 15%, **少陽病(往來寒熱·耳聾)** 10%.

**② 인물**
- 왼쪽 벤치 사내(정면, 무표정, 두 손바닥을 위로): 한 손엔 눈송이(寒), 한 손엔 불꽃(熱) — 2개. 표제어 **寒熱** — 十問歌 「一問寒熱」. 두 손에 갈라 든 모양은 寒과 熱을 가려 묻는다(惡寒·發熱의 유무·선후), 혹은 寒熱이 번갈아 온다(往來寒熱)로도 읽힘.
- 오른쪽 벤치 사내(눈썹 치켜뜨고 입 벌림, 손을 귀 뒤에 오므려 댐 = "뭐라고?"): 표제어 **耳聾(聾)** — 十問歌 「七聾八渴俱當辨」. 놀란·겁먹은 얼굴은 **驚/恐**(→ 腎 開竅於耳, 志恐)로 읽힐 여지.
- 앞쪽 무릎 꿇은 이(뒷모습, 두 사람을 마주함): 묻는 자 = **問**(의사·제자). 소품 없음.
- 배경: 빈 회색 방, 나무 벤치, 셋 다 같은 회색 도복 — 색 부호 없음, 사실 운반 없음으로 봄.

**관계**: 꿇어앉은 이가 묻고(問), 벤치의 두 환자가 각자 증상 하나씩을 답한다 → 問診은 寒熱부터 묻고(1번) 귀(聾, 7번)까지 차례로 가린다. 두 사람이 한 벤치에 나란히 = 같은 문진 목록의 항목들. 寒熱 곁에 耳聾이 붙은 것은 少陽(往來寒熱+耳聾)을 암시할 수도.

**③ 잔결**: 눈송이·불꽃만 광택 있는 이모지풍 아이콘이라 선화와 질감이 달라 덧붙인 티가 남(흰 후광). 오른쪽 사내의 표정(놀람)과 동작(귀 기울임)이 한 뜻으로 묶이지 않음 — 聾인지 驚인지 갈림. 꿇은 이는 소품이 없어 사실 운반이 불분명. 왼쪽 벽 모서리선·벤치 왼끝 다리는 이웃 띠와의 경계.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원 1순위: 問診(十問歌)** — 40%(↑). 차순위 **少陽病證(往來寒熱·耳聾·口苦·目眩)** 20%, **四診** 15%. 九氣는 氣(서린 흰 김)·收(자루) 기호가 없어 탈락, 腎(開竅於耳·恐)/心腎 水火 읽기는 五色 옷 인물(잠수부·임금)이 없어 탈락 — 셋 다 회색 도복 = 장부 인물이 아닌 보통 사람.

**② 인물**
- 왼쪽 사내: 「병표지 = 사람 곁에 크게 떠 있는 표지 = 그 사람의 병증」 → 눈송이·불꽃은 그가 앓는 증상. 寒 갈림에서 **눈송이 = 外寒**(성에·서리가 아님) + 熱 = 불꽃 → 표제어 **寒熱(惡寒發熱 = 外感 表證)**. 2개. 「一問寒熱」. 무겁게 처진 눈꺼풀·무표정은 사전 항목 없음.
- 오른쪽 사내: 耳 기호(옆으로 돌려 귓구멍이 검게 열린 귀)는 **충족 안 됨** — 귀가 오므린 손에 가려 구멍이 안 보인다 → 竅가 열리지 않음 = 못 들음. 표제어 **耳聾**(「七聾」). 크게 뜬 눈 = 目, 혀 없이 검게 벌린 입 = 口(구멍만 → 脾 쪽)로 사전에 걸리지만, 놀란 표정의 일부로 보여 사실 운반은 약함. 굳이 읽으면 口·目·耳 = 少陽(口苦·目眩·兩耳無所聞, 吐下則驚).
- 꿇은 이: 두 사람 사이 한복판 아래(中·下 후보)지만 사람이라 기호로 읽기 어렵고, 병표지가 없으니 환자가 아니라 **묻는 의사(問)**.
- 배경: 왼쪽 띠 밖으로 이어지는 긴 벤치 = 환자가 줄지어 앉은 대기석(옆 띠에도 문진 항목 인물이 이어질 것).

**관계**: 병표지가 벤치의 두 사람에게만 붙음 → 두 사람은 환자, 꿇은 이는 진찰자. 한 벤치에 나란히 = 같은 十問 목록의 항목. 단 十問 순서(寒熱 1 → 汗 2)로는 寒熱 옆에 聾(7)이 오는 것이 어긋나 순서 배열은 아님.

**③ 잔결**: 눈송이·불꽃 이모지풍 질감 불일치(후광) 그대로. 耳 기호 불충족이라 오른쪽 사내의 귀가 사전 문법이 아닌 몸짓으로만 읽힘. 오른쪽 사내 얼굴의 目·口가 사전 항목과 우연히 겹쳐 과잉 판독 위험. 꿇은 이는 사실을 지지 않는 빈 인물.
