# z89 판독

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원**: **脈診(切診) — 脈象** 1순위 70%. 차순위 **男女老少 平脈의 생리적 차이**(15%), **四診 총론**(10%).

**② 인물**
- 왼쪽 중년 남자(상투) = **男子脈 / 洪·細 대비**. 손목(寸口)에서 물이 흘러나옴 = 脈의 흐름. 그의 왼손(화면 오른쪽) 굵은 폭포 = **洪(大)脈** "來盛去衰·波濤", 오른손(화면 왼쪽) 가는 실줄기 = **細脈** "如絲". 즉 왼쪽이 크다 → 男子 左脈大爲順. 두 손 사이 납작돌 3개 = **寸·關·尺 三部**.
- 오른쪽 소녀 = **女子(婦人)脈 / 滑·澀 대비**. 그녀 오른손 물줄기에 구슬 6~7알 굴러감 = **滑脈** "往來流利 如盤走珠"(婦人에선 妊娠 징후). 왼손 물줄기는 잔자갈 10여 개에 걸려 끊겨 방울로 떨어짐 + 곁에 반 쪼갠 대나무를 칼로 긁어 부스러기 = **澀脈** "如輕刀刮竹·往來艱難"(血少·精傷). 오른쪽이 굵다 → 女子 右脈大爲順. 그녀 앞에도 큰 돌 3개 = 三部.
- 배경: 빈 방·같은 회색 옷·맨발 = 脈 이외 정보 배제(平人 진찰 조건, 靜).

**관계**: 남녀가 나란히 앉아 굵은 쪽이 좌우 반대 = **男左女右**(男子 左大, 女子 右大). 남자=洪/細(大小·氣血 많고 적음 축), 여자=滑/澀(流利·艱澀 축) — 서로 반대되는 **對擧脈 두 쌍**.

**③ 잔결**: 물이 손바닥 아닌 손목에서 나오지만 돌 3개는 손목 따라 놓이지 않고 두 손 사이에 가로 한 줄 — 三部인지 단순 장식인지 애매. 물줄기가 바닥 닿기 전 사라지고 웅덩이 없음. 아래 22%는 빈 바닥 띠(세로로 늘려 붙인 듯). 의자가 안 보임. 오른쪽 벽 모서리 = 방 끝(칸 경계).

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 단원**: **脈診 — 男女 平脈 차이 + 相對脈(洪·細 / 滑·澀)** 75%. 사전에 脈 전담 글자는 없지만 三峯 항목이 「맥박 물결」을 이미 쓰므로 물줄기 = 脈이 이 그림책 문법으로 확인됨. 차순위 **二十八脈**(15%).

**② 인물**
- 남자 = **男子脈(左大)**. 사전 **大**(같은 것 둘이 나란한데 하나가 두 배) → 그의 왼손 줄기가 오른손의 두 배 넘음 = 男子 左脈大爲順. 왼손 폭포는 넘쳐 쏟아짐 = **盛** → 洪脈 "來盛去衰". 오른손 실줄기는 약 1/3 = **虛** 갈래로 읽으면 細·虛. 곧게 솟은 상투 = **上**(약) → 男子 寸(上部) 盛·「男脈在關上」. 돌 3개의 가운데 = **中**(둘 사이 한복판; 가구 위라 官 갈림이 걸리나 3층 선반장이 아니라 中으로 봄) → 寸·**關**·尺 三部, 關 = 中焦.
- 소녀 = **女子脈(右大)**. **大** 거울상 → 오른쪽 줄기가 큼 = 女子 右脈大爲順. 오른손 흰 구슬 = 滑 "如盤走珠"(끈적한 회백색 덩이가 아니라 **痰**은 아님; 婦人 滑 = 妊娠). 왼손: 잔자갈 사방 흩어짐 = **散**, 맑은 방울 = **津** → 澀脈 "短且散·如雨沾沙" + 칼로 긁는 대나무 = "如輕刀刮竹" → 精傷·**津**血 虧少.

**관계**: 大가 좌우 반대로 놓임 = **男左女右**(男 左大·女 右大). 남=陽·上(상투), 여=陰. 두 쌍(洪↔細, 滑↔澀)은 반대맥 대비.

**③ 잔결**: 소녀의 크게 뜬 눈은 사전상 **目**인데 맥 사실과 이어지지 않음(표정으로 처리). 가운데 돌 中/官 갈림 애매. 반 쪼갠 대나무가 **傷**으로 새지 않는지(대나무는 등재 글자가 아니라 傷 아님). 돌 줄이 손목을 따라가지 않음, 물줄기 끝 웅덩이 없음, 아래 빈 바닥 띠. 1단계보다 大·散·津으로 男女 좌우와 澀의 "散"이 더 단단해짐.
