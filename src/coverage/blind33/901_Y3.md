# 901 — 판독 Y3

## 1단계 — 생판 (사전 어휘 없이)

**① 판 표제어**
- 1순위 **四診(望·聞·問·切)** — 55%. 왼쪽 무리(무릎 꿇고 바라보는 이 = 望, 귀에 손을 댄 노인 = 聞, 눈꽃·불꽃을 받쳐 든 노인 = 問寒熱)와 오른쪽 긴 상(손목에서 물이 흐름 = 寸口 切脈)이 네 진법을 나눠 맡은 것으로 읽힘.
- 2순위 **脈診 — 相對 綱領脈 8종(浮沈·遲數·虛實·滑澁)** — 35%. 상 앞 네 사람이 각자 두 손목에 한 쌍의 맥상을 들고 있어 판의 무게가 맥에 쏠려 있음.

**② 인물별 (왼쪽부터)**
1. 왼쪽 노인(벤치 끝, 눈꽃·불꽃): **問寒熱(惡寒·發熱)**. 왼손 눈꽃 = 寒, 오른손 불꽃 = 熱 → 사실 2개. 문진의 첫 항목.
2. 무릎 꿇은 뒷모습(앞쪽 바닥): **望診**. 두 노인을 마주 보고 살핌. 소품 없음 → 1개.
3. 귀에 손 모은 노인: **聞診(聽聲)**. 다른 해석은 十問의 「七聾」(耳聾) → 1개.
4. 상 1번(남, 상투): **浮·沈**. 오른손목 물 위에 뜬 호리병 = 浮(如水漂木), 왼손목 물줄기 속으로 가라앉는 돌 = 沈(如石投水), 손목 사이 돌 3개 = 寸·關·尺 → 3개.
5. 상 2번(백발 여인, 눈 감음): **遲·數**. 달팽이 = 遲, 손목 위 토끼 = 數, 돌 3개 일렬 = 寸關尺 → 3개.
6. 상 3번(남, 상투): **虛·實**. 왼쪽 물이 얕은 홈통 = 虛, 오른쪽 물이 넘치는 홈통 = 實, 돌 3개(2+1) → 3개.
7. 상 4번(소녀): **滑·澁**. 구슬 굴러 내리는 물줄기 = 滑(如盤走珠), 끊겨 방울지고 모래·잔돌 섞인 물 = 澁(如雨沾沙), 대나무+칼과 깎은 부스러기 = 澁(如輕刀刮竹), 큰 돌 3개 = 寸關尺 → 4개.

**③ 잔결**
- 손목 사이 돌 3개는 寸關尺인지 浮中沈 三候인지 갈림. 배열이 2+1(1·3번)과 일렬(2·4번)로 달라 뜻이 다른지 알 수 없음.
- 상 앞 네 사람의 나이·성별 차이(백발 여인 눈 감음, 소녀)는 뜻 미상. 노인 둘과 젊은이 넷이 대비되는 이유도 미상.
- 3번 홈통 왼쪽 것이 반투명 유리 상자처럼 상 앞 모서리 밖으로 삐져나옴. 벤치가 상 뒤로 이어지는 접합부(x≈700)가 약간 어색함. 프레임 잘림은 없음.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 판 표제어**: 결론은 그대로다. 1순위 **四診(望·聞·問·切)** 55%, 2순위 **脈診 綱領 8脈(浮沈·遲數·虛實·滑澁)** 35%. 3순위로 **問診(寒熱) + 切診** 묶음도 가능(10%). 사전이 실제로 바꾼 것은 노인1을 「진찰받는 환자」로 읽게 한 점이다(병표지 규칙).

**② 인물별 (왼쪽부터)**
1. 노인1: **問寒熱 → 惡寒發熱(表證)**. 손 위에 크게 뜬 눈송이·불꽃 = 병표지(그 사람의 병증). 눈송이 = 外寒(갈림 조건 충족), 불꽃 = 熱. 둘을 동시에 받쳐 들었으므로 寒熱往來보다 惡寒發熱 쪽 → 2개.
2. 무릎 꿇은 이: **望診(醫者)**. 사전 기호가 없음. 눈이 안 보여 目(크게 뜬 눈)도 아님 → 1개(자세로만 읽힘).
3. 귀에 손 모은 노인: **聞診**. 손이 귀를 덮어 사전의 耳(옆으로 돌려 귓구멍이 검게 열린 귀) 꼴이 아님. 聞인지 耳聾(十問 七聾)인지 사전으로 가려지지 않음 → 1개.
4. 상1: **浮·沈**. 호리병 뜸 = 浮. 돌이 물줄기 따라 가라앉음 = 下(가라앉음)와 겹쳐 沈을 뒷받침. 돌 3개 = 三部 → 3개.
5. 상2: **遲·數**. 달팽이·토끼는 사전에 없지만 고전 맥 비유라 그대로 읽힘. 돌 3개 → 3개.
6. 상3: **虛·實**. 물이 1/3로 준 홈통 = 虛(사전과 일치), 팽팽히 찬 홈통 = 實(사전과 일치). 앞 턱에서 넘치는 기색이 있어 盛(넘쳐 흘러나옴)으로 갈릴 여지가 있음. 돌 3개 → 3개.
7. 상4: **滑·澁**. 구슬 물줄기 = 滑, 끊겨 떨어지는 물방울과 모래 = 澁(如雨沾沙), 대나무+칼 = 澁(如輕刀刮竹). 칼이 박힌 곳은 살이 아니라 대나무라 痛·傷이 아님. 돌 3개 → 4개. 끊긴 물방울을 津(맑은 물방울)으로 보면 「澁 = 精血·津 虧少」가 1개 더 붙지만 확신 낮음.

**③ 잔결**
- 돌 3개에 中(셋 중 가운데) 항목을 대 보았으나 맞지 않음. 2+1 배열에는 가운데가 없고, 가구 위라 官 갈림에도 걸림. 寸關尺인지 浮中沈인지 사전으로 풀리지 않음.
- 상 1·2·4의 손목 물이 상 가장자리로 쏟아지는 모습은 下·盛로 잘못 읽힐 소음임.
- 호리병·달팽이·토끼·구슬·대나무칼은 사전에 없는 새 기호임. 다만 脈訣 비유를 알면 풀림.
- 상투를 上(곧게 솟음)으로 읽지 않음. 남녀 교대 배치와 눈 감은 여인의 뜻은 여전히 미상.
- 유리 홈통이 상 밖으로 삐져나옴. 벤치와 상의 접합부가 어색함. 프레임 잘림은 없음.
