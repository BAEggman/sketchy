# 901 판독 (Z3)

## 1단계 — 생판 (사전 없이)

**① 판 표제어**
- 1순위 **四診(望·聞·問·切) — 그중 切診(脈診)의 상대 綱領脈** (70%)
- 2순위 **脈象 綱領 8脈(浮沈·遲數·虛實·滑澁) 대립쌍** (25%) — 왼쪽 세 사람을 빼면 판 절반 이상이 맥 4쌍이라 이쪽일 수도.

구도: 왼쪽 긴 의자 구역(3명) = 望·聞·問, 오른쪽 탁자 구역(4명) = 切. 탁자 사람들은 모두 손바닥을 위로 해 손목(寸口)을 내밀고, 손목에서 물줄기(=脈)가 흘러나온다. 두 손 사이 돌 3개 = 寸·關·尺.

**② 인물별 (왼쪽부터)**
1. 의자 왼쪽 노인 — **問診(問寒熱)**: 오른손 눈송이 = 寒(惡寒), 왼손 불꽃 = 熱(發熱) → 2개.
2. 앞에 무릎 꿇고 등 보인 사람 — **望診**: 앉은 사람들을 바라봄 = 보고 살핌 → 1개(약함).
3. 귀에 손 댄 노인 — **聞診(聽聲)**: 소리 듣기 → 1개. 냄새 맡기(嗅) 소품은 없음.
4. 탁자 첫째 남자 — **浮沈**: 왼손목 물웅덩이에 뜬 조롱박 = 浮(如水漂木), 오른손목 물줄기 속 가라앉는 돌 = 沈(如石投水), 돌 3개 = 寸關尺 → 3개.
5. 눈 감은 여자 — **遲數**: 달팽이 = 遲, 오른손목 위 뛰는 토끼 = 數, 돌 3개 = 寸關尺, 눈 감음 = 調息(한 호흡에 박동 수를 셈)일 수 있음 → 3~4개.
6. 남자 — **虛實**: 왼손 넓고 얕은 상자 속 잔잔한 적은 물 = 虛(無力), 오른손 좁은 홈통에 가득 세찬 물 = 實(有力), 돌 3개 → 3개. (大·細 너비 대비로도 읽힘)
7. 젊은 여자 — **滑澁**: 구슬이 굴러가는 매끈한 물줄기 = 滑(如盤走珠), 끊겨 방울지는 물줄기·자갈 = 澁(往來艱澁), 대나무를 긁는 칼과 대팻밥 = 澁(如輕刀刮竹), 돌 3개 = 寸關尺 → 4개.

**③ 잔결**
- 돌 3개 배열이 4번·6번 탁자는 삼각(2+1), 5번·7번은 일렬 — 뜻이 있는지 모름.
- 남녀·노소가 섞임(5·7번 여자, 1·3번 노인) — 男女脈 차이를 뜻하는지 불명.
- 눈송이·불꽃만 이모지 같은 아이콘 화풍이라 붙여 넣은 느낌.
- 의자와 탁자가 맞닿는 곳에서 의자 뒤판이 탁자 뒤로 사라짐. 두 구역을 이어 붙였을 수 있음.
- 무릎 꿇은 사람의 정체(望診 의사인지 환자인지)가 소품 없이 자세만으로 전달됨.
- 프레임 잘림: 없음. 오른쪽 대나무가 탁자 끝에 거의 닿음.

## 2단계 — 계통 (blind6 사전 적용 후)

**① 판 표제어**
- 1순위 **四診 — 問(寒熱)·望·聞 + 切(綱領脈 4쌍)** (75%)
- 2순위 **脈診의 대립 8脈(浮沈·遲數·虛實·滑澁)** (20%) / 3순위 八綱(寒熱·表裏·虛實) (5%)

사전으로 1단계가 **강화**된다. 虛·實·下·寒·熱·병표지가 그대로 맞물리고, 반대로 읽히는 항목은 없다.

**② 인물별**
1. 寒熱 노인 — **問寒熱**: 사전의 「병표지」(곁에 크게 떠 있는 눈송이·불꽃 = 그 사람의 병증)에 해당하므로 이 사람은 환자다. 눈송이 = 外寒(갈림 충족), 불꽃 = 熱, 둘을 한꺼번에 들었으니 惡寒發熱(表證) → 3개.
2. 무릎 꿇은 사람 — **望診**: 사전에 해당 기호가 없다(目은 뒷모습이라 안 보임). 환자 앞에서 살피는 의사 → 1개.
3. 귀 노인 — **聞診**: 옆으로 돌린 귀 = 耳, 손을 오므려 댐 = 聽聲 → 1~2개.
4. **浮沈**: 뜬 조롱박 = 浮(사전 밖), 가라앉는 돌 = 下(사전과 일치) → 沈, 돌 3개 = 寸關尺 → 3개.
5. **遲數**: 달팽이 = 遲, 토끼 = 數, 寸關尺, 눈 감음 = 調息 → 3~4개(사전 밖 기호).
6. **虛實**: 왼쪽 상자 물이 1/3로 줄어 있음 = 虛(사전과 일치), 오른쪽 홈통이 팽팽하게 참 = 實(사전과 일치), 넓은 상자 = 虛脈의 大而無力, 寸關尺 → 3~4개. 1단계에서 남겨 둔 大細 읽기는 버린다.
7. **滑澁**: 구슬 = 滑, 끊긴 방울·자갈·刮竹 = 澁, 寸關尺 → 4개. 젊은 여자 + 滑 = 妊娠滑脈일 수 있음.

**③ 잔결**
- 浮·遲·數·滑·澁과 寸關尺 돌은 사전에 없는 새 기호다. 독자는 이 판에서 처음 배워야 한다.
- 中 = 「같은 것 셋 중 가운데」가 寸關尺의 關과 겹친다. 가운데 돌이 中으로 읽힐 소지가 있다.
- 澁 줄기의 맑은 물방울이 사전의 津과 부딪혀 「津少」로 읽힐 수 있다. 대팻밥이 갈색이라 瘀로 읽힐 위험도 조금 있다.
- 6번 인물이 상자 속에 손을 담근 모양은 會(담는 것 안에 담긴 것)로 잘못 읽힐 소지가 있다.
- 눈송이·불꽃은 병표지 문법에 맞으니, 1단계의 「붙여 넣은 아이콘」 판정은 철회한다.
- 의자·탁자 접합부와 돌 배열(삼각/일렬) 차이는 여전히 뜻을 모른다.
