# 902 판독 (X3)

## 1단계 — 생판 (사전요약 열기 전 확정)

**① 판 표제어**
- 1순위 **四診(診法) — 問診 + 切診(脈診) 통합판** (70%) : 왼쪽 걸상 구역은 의사(등 돌리고 꿇어앉은 인물)가 환자에게 묻는 장면, 오른쪽 긴 탁자는 손목을 내민 4인의 脈 구역.
- 2순위 **脈象 綱領脈 — 相對脈 4쌍(浮沈·遲數·虛實·滑澁)** (20%) / 3순위 **八綱(表裏·寒熱·虛實)** (10%, 浮沈=表裏, 遲數=寒熱, 虛實=虛實 대응을 의도했을 가능성).

**② 인물별 (왼쪽부터)**
- 꿇어앉은 인물(앞, 등): **醫者(問診하는 쪽)** — 1개: 환자 앞에 정좌해 묻는 역할.
- 인물1(걸상 왼쪽, 남, 눈꽃·불꽃): **問寒熱** — 2개: 왼손 눈꽃=寒(惡寒), 오른손 불꽃=熱(發熱), 둘을 동시에 들어 惡寒發熱(表證) 또는 寒熱 4형 중 하나.
- 인물2(걸상 오른쪽, 노인, 귀에 손 모으고 놀란 입): **問耳(耳聾·耳鳴)** — 1개: 十問歌 「七聾」. (또는 聞診 聽聲音 30%)
- 인물3(탁자, 남): **浮·沈** — 3개: 왼손목 물 위에 뜬 호리병=浮(如木漂水), 오른손목 물줄기 속 가라앉는 돌=沈(如石投水), 손목 사이 조약돌 3개=寸·關·尺.
- 인물4(탁자, 여, 눈 감음): **遲·數** — 3개: 달팽이=遲(느림), 손목 위 달리는 토끼=數(빠름), 돌 3개=寸關尺.
- 인물5(탁자, 남): **虛·實** — 3개: 왼손 얕게 고인 물통=虛(빈 맥), 오른손 물이 가득 차 넘치는 물통=實(또는 洪), 돌 3개=寸關尺.
- 인물6(탁자, 여): **滑·澁** — 4개: 구슬이 굴러가는 물줄기=滑(如珠走盤), 자갈에 막혀 끊겨 떨어지는 물방울=澁(往來艱澁), 대나무+칼+대팻밥=澁(如輕刀刮竹), 큰 돌 3개=寸關尺.

**③ 잔결**
- 눈꽃·불꽃이 이모지 스티커처럼 평면 질감이라 붙여 넣은 티가 남.
- 인물5의 물통 두 개가 虛實인지 細洪인지 갈림(크기 같고 수위만 다름).
- 인물2가 환자(耳聾)인지 聞診 의사인지 불분명.
- 탁자 오른쪽 끝이 오른쪽 벽 모서리 앞까지 바짝 붙음(잘림은 아님). 이어붙임 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **四診(望聞問切) — 問診(問寒熱·問耳) + 切診(相對脈 4쌍)** (75%) : 사전 어휘가 왼쪽을 「병표지 붙은 환자 + 묻는 의사」로, 오른쪽을 脈象 쌍으로 더 단단히 묶어 줌. 꿇은 인물=望(바라봄)·인물2=聞·인물1=問·탁자=切로 四診 전부를 늘어놓았을 가능성도 열림.
- 2순위 **脈診 — 綱領脈 相對 4쌍(浮沈·遲數·虛實·滑澁)** (20%). 八綱은 滑澁·耳가 설명되지 않아 5% 미만으로 내림.

**② 인물별 (왼쪽부터) — 바뀐 점 위주**
- 인물1: **問寒熱 — 惡寒發熱** — 2개: 사전 「병표지 = 사람 곁에 크게 떠 있는 불꽃·눈송이 = 그 사람의 병증」 그대로. 눈송이(갈림: 눈송이=**外寒**) + 불꽃(熱) 동시 → 外感 表證의 惡寒發熱로 좁혀짐(寒熱往來보다 우세). 「惡」 가리개는 없음.
- 꿇은 인물: **醫者(問 또는 望)** — 1개. 사전에 해당 기호 없음.
- 인물2: **問耳(耳聾·耳鳴)** — 1개(+보조 2): 귀를 손으로 가려 사전의 「耳(귓구멍이 검게 열린 귀)」 꼴은 아님. 크게 뜬 눈(目)·벌린 어두운 입(口)은 놀람 표정으로 보이며 글자로 읽으면 과잉. 聞診 의사 해석 30% 유지.
- 인물3: **浮·沈** — 3개: 뜬 호리병=浮, 쏟아지는 물에 가라앉는 돌 = 사전 「**下** = 아래로 가라앉거나 쏟아짐」과 겹쳐 沈 확정도 상승. 돌 3개=寸關尺(가구 위라 갈림상 「中」으로 읽지 않음 — 그냥 三部).
- 인물4: **遲·數** — 3개: 달팽이=遲, 토끼=數, 돌 3개. 사전 추가 없음.
- 인물5: **虛·實** — 4개: 왼 물통 수위가 약 1/3 = 「**虛** = 삼분의 일로 줄어든 것」, 오른 물통 가득 = 「**實** = 팽팽하게 찬 것」, 앞전으로 넘쳐흐름 = 「**盛** = 넘쳐 흘러나오는 것」(邪氣盛則實·精氣奪則虛 또는 洪脈 來盛). 돌 3개. 1단계의 細洪 갈림은 거의 해소.
- 인물6: **滑·澁** — 4개: 구슬 굴러가는 물=滑(如珠走盤), 자갈에 끊겨 듣는 맑은 물방울=澁(사전 「津 = 맑은 물방울」로 읽으면 津血 부족 → 澁 기전까지), 대나무+칼=如輕刀刮竹, 큰 돌 3개.

**③ 잔결**
- 눈꽃·불꽃 이모지 질감(붙여 넣은 티). 사전상 정상 기호라 뜻은 통함.
- 인물2의 귀가 사전 「耳」 꼴과 어긋남 → 耳聾인지 聞診인지 여전히 갈림.
- 각 탁자의 물줄기가 모두 탁자 끝에서 아래로 쏟아져 「下」가 여러 곳에 생김 — 沈 하나만 下로 읽어야 하는지 독자가 헷갈릴 소지.
- 인물6 대나무 끝이 반으로 갈라진 꼴은 「傷」으로 오독될 여지(사전상 대나무는 글자가 아니므로 傷 아님).
- 프레임 잘림·이어붙임 뚜렷하지 않음.
