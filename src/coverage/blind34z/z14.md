# z14 판독

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원**: **六淫(외감 病因) — 風邪·寒邪** 55% / 차순위 **傷寒論 太陽病(中風 vs 傷寒)** 30% / **八綱 表虛·表實** 10%.

**② 인물**
- 왼쪽 사내 = **風邪(太陽中風·桂枝湯證)**. 회오리 바람·흩날리는 낙엽·흔들리는 마른가지 = 風性善行數變·主動. 손을 뒷머리에 얹음 = 風爲陽邪 易襲陽位(頭) → 頭痛(頭項强痛). 앞섶 풀린 가슴 + 땀방울 = 其性開泄 → 汗出·惡風(表虛). 허리춤의 **계피(桂枝) 묶음 4개** = 風邪 4성(①陽邪·開泄·易襲陽位 ②善行數變 ③主動 ④百病之長) 겸 桂枝湯.
- 오른쪽 사내 = **寒邪(太陽傷寒·麻黃湯證)**. 웅크려 팔짱·떨림선 = 惡寒(寒爲陰邪 易傷陽氣)·寒性收引. 앞섶 꽉 여밈·땀 없음 = 腠理閉塞 無汗(表實). 이 악문 찡그림 = 寒性凝滯 → 痛(身疼). 가슴에 안은 **푸른 마디 줄기 다발(麻黃)** = 麻黃湯·宣肺平喘. 돌성벽 = 收引·閉藏, 발밑 서리 = 寒.
- **관계**: 바람줄기가 왼쪽에서 오른쪽 사내 머리로 불어감 = 風爲百病之長 — 寒이 風에 실려 들어옴(風寒). 동시에 같은 옷차림 두 사람의 대비 = 같은 太陽表證을 有汗(表虛·桂枝) vs 無汗(表實·麻黃)으로 가름.

**③ 잔결**: 風은 春 主氣인데 배경이 늦가을 낙엽·마른나무(燥·秋 혼입?). 두 사람 바지의 같은 기운 헝겊 조각(뜻 불명, 화풍?). 오른쪽 아치 성문은 띠 가장자리에서 잘림(이웃 띠 몫). 麻黃 줄기 수는 15개 이상으로 셀 수 없음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원**: **六淫 — 風邪·寒邪의 外感(表)** 60% / **傷寒論 太陽病 中風·傷寒** 25% / **八綱 表證** 10%. 성벽이 「裏=성 안 · 表=문 밖 · 外=담 바깥」으로 읽히면서 표리 축이 생겨, 六淫 단원의 「寒이 肌表에 머묾(傷寒) vs 裏로 直中(中寒)」 구분을 겨눈 판으로 보는 쪽이 더 잘 풀린다.

**② 인물**
- 왼쪽 = **風(風邪 襲表)**. 옆으로 흘러 날리는 낙엽·한쪽으로 휜 가지·가로 바람줄 = **風**(낙엽이 수직이 아니라 옆으로 날리므로 燥가 아님 — 1단계의 「가을 燥 혼입」 의문 해소). 가슴·이마의 땀방울 = **汗** → 風性開泄·汗出(表虛). 성 밖 들판 = **表/外**. 손을 뒷머리에 = 易襲陽位(頭)(사전 어휘 밖, 자세로 읽음). 계피 4개 = 桂枝(사전 밖; 셋이 아니므로 久 아님).
- 오른쪽 = **寒(寒邪 束表 = 傷寒)**. 성문 밖·담 바깥에 섬 = **表·外** → 寒이 아직 裏(성 안)로 못 듦. 땀방울 없음 + 여민 앞섶 = 無汗(寒性收引·腠理閉, 表實). 팔짱 떨림 = 惡寒·傷陽. 발밑 연푸른 서리 = 사전상 「밑에서 밴 서리=**內寒**」(갈림). 麻黃 다발(사전 밖).
- **관계**: 가로 바람줄이 왼쪽에서 오른쪽 사내 머리로 = 風이 寒을 싣고 감 → **風爲百病之長**(風寒). 둘 다 성 밖 = 風·寒 모두 表부터 침범. 有汗/無汗 대비 = 開泄 vs 收引(表虛 vs 表實).

**③ 잔결**: 오른쪽 사내 곁에 外寒 기호(눈송이)가 없고, 서리는 사전상 內寒인데 사람은 문 밖(表)에 서 있어 어긋남 — 서리가 성문 쪽으로 이어지므로 이웃 띠(성 안 = 內寒·中寒 인물)에서 번진 것일 수 있음. 惡風·惡寒의 **惡(가리개)**, 頭痛·身痛의 **痛(쇠못)** 기호가 둘 다 없어 자세로만 전달. 같은 옷·같은 얼굴 두 사람이라 **善惡 쌍둥이** 갈림을 검토했으나 잿빛·꺾인 목·벌린 입이 없어 해당 없음. 바지 헝겊 조각은 여전히 뜻 불명.
