# z66 판독

## 1단계 — 생판 (사전 보기 전)

**① 단원**: **問診 — 問寒熱** 50% (대안: **六經辨證 少陽病** 35%, **八綱 寒熱** 15%)

**② 가운데 인물(1명)**: **寒熱往來** (=**半表半裏 / 少陽病**)
- 몸과 바닥이 세로로 반은 푸른 냉색, 반은 등불 쪽 주황 난색. 한 발은 찬 바닥, 한 발은 더운 바닥 → 惡寒과 發熱이 한 몸에서 번갈아 나타남.
- 아치 꼭짓점 한 점에 매달린 쇠공 진자가 좌우로 흔들림(운동선 좌우 1쌍씩) → 寒↔熱의 「往來」 교대. 한 점에 매달린 축은 **少陽爲樞**.
- 아치 문턱(안도 밖도 아닌 곳)에 서 있음 → 半表半裏.
- 어지럼 소용돌이 3개 → 目眩. 오므린 입과 찡그린 얼굴 → 口苦/喜嘔. 두 손으로 명치와 옆구리를 움켜쥠 → 胸脇苦滿. 왼소매의 곤두선 털과 떨림선 → 惡寒(寒戰). 이마와 목의 땀 → 열이 오를 때 나는 땀. 벽 등불(불꽃 1) → 열원(發熱).
- 바지 기운 패치 2개 → 血弱氣盡·腠理開(正氣가 허해 邪가 들어옴)일 수 있음(약함).
- 오른쪽에 잘린 인물: 얼굴이 붉고 땀을 비 오듯 흘리며 옷을 풀어헤침 → **但熱不寒(壯熱)**, 또는 陽明의 大熱·大汗. 이웃 띠 몫.
- **관계**: 같은 옷을 입은 같은 환자가 寒熱往來에서 但熱不寒(壯熱·大汗)으로 넘어감 → 問寒熱 유형을 비교하는 것으로 읽힘. 六經 판이라면 少陽→陽明 傳變.

**③ 잔결**: 진자가 시계추보다 철거용 쇠공처럼 무거움(頭重을 뜻하는지 불명). 패치 2개의 뜻이 약함. 오른쪽 바닥의 물방울은 이웃 인물의 땀으로 보임. 몸 한가운데를 지나는 냉/난 경계선은 의도한 분할로 보이고, 이어 붙인 흔적은 아님. 오른쪽 아치 바깥 벽의 수평선이 살짝 어긋남.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원**: **問診 — 問寒熱** 55% (대안: **六經 少陽病** 30%, **八綱 寒熱** 15%). 사전으로 단원이 바뀌지는 않음. 다만 寒의 눈송이(外寒·裏寒·內寒)가 전혀 없으므로 「寒」은 寒邪가 아니라 환자가 느끼는 오한이라는 점이 분명해짐 → 問診 쪽으로 기움.

**② 가운데 인물**: **寒熱往來 = 半表半裏**
- 사전의 表 = 문 밖, 裏 = 성 안, 中 = 둘 사이의 한복판. 성문 아치 바로 밑에 선 사람 → 表와 裏 사이의 한복판 = **半表半裏**가 사전 문법으로 확정됨(1단계보다 강해짐).
- 熱 = 불꽃: 벽 등불의 불꽃 1개가 더운 쪽 절반을 나름. 寒 눈송이는 없고 냉색 조명만 있음 → 오한(惡寒)은 감각이지 寒邪가 아님.
- 毛 = 서는 잔털: 찬 쪽 왼어깨와 소매에 곤두선 털과 떨림선 → 毛竪·寒慄 = 惡寒이 드는 시기.
- 汗 = 살갗에 맺힌 땀방울: 이마 1·목 1, 모두 2방울 → 열이 날 때의 땀(열 나며 땀나는 시기).
- 병표지 = 곁에 떠 있는 표지: 소용돌이 3개 → **目眩/眩暈**.
- 진자 쇠공은 사전에 없음. 저울추(降)는 저울에 달릴 때만이고 이것은 운동선을 단 흔들이라 降이 아님. 좌우 왕복 그대로 **往來(교대)**. 和(수평으로 멎은 저울)도 아님 → 和解法은 그림에 없음.
- 痛 쇠못이 없음 → 명치와 옆구리를 움켜쥔 손은 통증이 아니라 자리를 가리킴 = **胸脇苦滿**. 오므린 입 = 口苦/喜嘔(口 구멍 글자는 아님).
- **관계**: 같은 옷의 오른쪽 인물은 완전히 더운 쪽에 앉아 있고 땀방울(汗)이 많음 → **但熱不寒 + 汗出**. 왼쪽 찬 곳에서 오른쪽 더운 곳으로 갈수록 열이 세지는 寒熱 유형 배열에서 「寒熱往來 → 但熱不寒」의 이웃 관계(問寒熱→問汗 연결 가능).

**③ 잔결**: 진자는 미등재 기호라 往來를 운동선 하나에만 기대어 나름(降과 헷갈릴 위험). 몸과 바닥을 가르는 냉/난 경계선은 皮(면 위의 색 경계선 한 줄)로 오독될 수 있음. 바지 패치 2개는 傷(사전에 오른 사물이 깨진 것)도 虛도 아니라 뜻이 없는 옷차림으로 판정. 왼귀 옆의 희미한 넷째 소용돌이는 개수가 흔들림.
