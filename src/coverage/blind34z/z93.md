# z93 판독

## 1단계 — 생판 (사전 없이)

**① 단원** — 1순위 **六淫** (60%). 이 띠는 그중 **暑**·**濕** 두 칸. 차순위: **暑邪** 단독 판(15%), **病因-飮食失宜**(飮傷/食傷, 10%), **宣明五氣**(心惡熱·脾惡濕, 心爲汗, 10%).

**② 인물**
- 왼쪽 = **暑**. 머리 위 거대한 해(日, 暑의 윗부분; 暑爲陽邪·其性炎熱, 여름 季節性) → 붉은 얼굴(面赤). 땀방울이 머리 위로 6~7개 튐(暑性升散 → 腠理開泄, 多汗). 항아리째 들이켜다 넘쳐 흐름(傷津 → 口渴喜飮). 앞섶 풀어 맨가슴(熱). 한 손은 배에(挾濕으로 이어 줌). 특성 3개(炎熱 / 升散·傷津耗氣 / 多挾濕) 중 앞 둘이 이 사람 몫.
- 오른쪽 = **濕**(暑挾濕). 두 손으로 감싼 훨씬 큰 배(濕阻氣機 → 脘腹脹滿, 濕困脾). 처진 눈꺼풀·축 처진 얼굴(重濁 → 頭身困重, 倦怠). 곁의 검은 쇠솥: 세 발, 뚜껑을 돌로 눌러 둠 → 重(重濁)·눌려 안 열림(黏滯·纏綿)·속에 물을 가둠·검정=陰邪. 바닥에 낮게 앉음(趨下).
- 배경: 사방 담으로 막힌 뜰(悶 → 暑濕의 胸悶). 해살이 두 사람 모두에 떨어짐.
- **관계**: 한 해 아래 나란히 앉아 둘 다 배를 감싸는 거울 자세, 둘 다 붉은 얼굴 → **暑多挾濕**(暑와 濕이 겸해 옴). 왼쪽이 마신 물 → 오른쪽의 부른 배로 이어지면 "여름 貪涼飮冷 → 濕困脾胃"로도 읽힘. 六淫 순서(風寒**暑濕**燥火)에서 이웃.

**③ 잔결**
- 濕 쪽 사람이 갈라진 **마른 땅** 위에 앉음 — 濕과 어긋남(오른 이웃 燥 칸이 번진 것?). 왼쪽은 젖은 돌바닥, 오른쪽은 갈라진 흙바닥으로 두 사람 사이(x≈250~300)에서 바닥 재질이 바뀜 → 이어 붙인 흔적.
- 세 발 솥(鼎/釜?)과 돌 누름이 무엇의 글자인지 불확실.
- 왼쪽 사람 배도 불러 있고 손을 얹음 — 暑의 사실인지 濕 연결 장치인지 모호.
- 왼쪽 가장자리 돌기둥(아치)은 이웃 띠 몫으로 무시.

## 2단계 — 계통 (blind6 사전 적용)

사전으로 다시 읽으니 1단계 독법이 무너진다. ⓐ 해 = **陽** — 「해=暑」 갈림은 *철이 차례로 바뀌는 들판·길의 하늘*일 때만인데 여기는 담 둘린 뜰이라 해당 없음 → 暑 근거 소멸. ⓑ 濕 = 부슬비·안개·진창뿐 — 화면에 없음 → 오른쪽 사람은 濕이 아니다. ⓒ 갈라진 땅 = **燥**, 사방 담 = **內**(裏). ⓓ 땀 = 汗, 사방으로 튀는 땀 = 散, 입에서 넘쳐 흐르는 물 = 盛, 열린 입 구멍 = 口, 팽팽한 배 = 實, 나란한 두 배 중 오른쪽이 두 배 = **大**, 몸 한복판(배) = 中.

**① 단원** — 1순위 **六經辨證(傷寒)**, 이 띠 = **陽明病**(해=陽 + 밝음=明, 兩陽合明) (50%). 차순위 **衛氣營血-氣分證**(15%; 단 氣=흰 김이 없음), **八綱-裏實熱**(15%), **六淫**(10%).

**② 인물**
- 왼쪽 = **陽明經證**(無形熱盛). 四大 4개 중 3개를 그림: 大熱(해·붉은 얼굴), 大汗(汗+散), 大渴(항아리째 들이켬, 口·盛). 脈洪大는 안 그려짐. 앞섶 풂 = 不惡寒反惡熱.
- 오른쪽 = **陽明腑證**(有形實邪). 痞·滿·燥·實 4개: 두 손에 감싼 팽팽한 배(滿·實, 왼쪽의 두 배 = 大 → 大實·大承氣), 발밑 갈라진 땅(燥), 돌로 눌러 닫은 세 발 쇠솥(腑=胃의 그릇이 막혀 안 열림 → 胃家實·不大便, 돌=燥屎). 처진 얼굴 = 腹痛拒按·괴로움.
- 배경: 담 안 = 內/裏 → 陽明은 裏熱實證.
- **관계**: 같은 해 아래 둘 다 배(中=胃)를 쥠 → 「陽明之爲病, 胃家實」. 왼쪽 젖은 돌바닥 → 오른쪽 갈라진 흙으로 바닥이 바뀜 = 經證의 大汗·大渴로 津液이 빠져 **化燥 → 燥屎內結**, 經證이 腑證으로 넘어감. 배 크기 1:2(大) = 熱만 盛 → 實까지 大.

**③ 잔결**
- 쇠솥·돌 누름은 사전 미등재(降=저울추와 혼동 소지). 便=나무 뒷간통이 없어 不大便은 막힌 솥으로만 짐.
- 經證 쪽 사람도 배가 불러 손을 얹음 — 胃 공유 표시인지 군더더기인지 모호.
- 열린 입은 혀가 안 보여 舌 갈림상 脾로도 읽힐 위험.
- 젖은 돌→갈라진 흙 바닥 이음매는 의도(化燥)로 풀리나 재질이 갑자기 바뀌어 이어 붙인 티가 남.
