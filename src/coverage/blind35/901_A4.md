# 901 판독 (A4)

## 1단계 — 생판 (사전요약 열기 전 확정)

**① 판 표제어**
- 1순위: **傷寒論 六經辨證 — 三陽病(太陽·少陽·陽明) 證治** (85%)
- 2순위: **表·半表半裏·裏 病位 傳變(外感熱病의 表→裏 진행)** (10%)
- 배경 설계: 왼쪽 성 밖(바람·추위·회색)=表, 성문 아치 안(반은 푸르고 반은 주황)=半表半裏, 성 안 담장 마당(해·마른 땅)=裏. 해=陽明(兩陽合明)·大熱.

**② 인물별 (왼쪽부터)**
1. **太陽中風(桂枝湯證)** — 계피 다발(4~5개)=桂枝湯 / 손을 뒤통수·목덜미에=頭項强痛 / 얼굴·가슴 땀, 앞섶 열림=汗出(表虛) / 바람결·낙엽·앙상한 나무=風邪·惡風. 사실 4개.
2. **太陽傷寒(麻黃湯證)** — 마디진 녹색 줄기 다발=麻黃(麻黃湯) / 팔짱 끼고 덜덜=惡寒 / 이 악문 얼굴=身疼·骨節疼痛 / 옷깃 여밈·땀 거의 없음=無汗(表實) / 차가운 성벽에 붙음=寒邪. 사실 4~5개.
3. **少陽病(小柴胡湯證)** — 아치 꼭대기서 좌우로 흔들리는 쇠공 추=往來寒熱 / 배경·몸 반은 청·반은 주황=半表半裏·寒熱 교대 / 머리 곁 소용돌이 3~4개=目眩 / 두 손으로 갈비 아래 움켜쥠=胸脇苦滿 / 오므린 입=口苦·喜嘔 / 성문 자체=樞 / 등불=相火(?). 사실 5~6개(小柴胡湯 소품은 안 보임).
4. **陽明經證(白虎湯證)** — 항아리 물을 들이붓듯 마심=大渴 / 땀방울 비산·젖은 가슴=大汗 / 붉은 얼굴·해=大熱 / (脈洪大는 소품 없음). 四大 중 3개.
5. **陽明腑證(承氣湯證)** — 붉고 팽팽한 배를 움켜쥠=腹滿·痛 / 붉은 얼굴=潮熱 / 갈라진 마른 땅=燥(燥屎) / 돌로 눌러 막은 검은 솥=閉結·不大便(痞滿燥實) / 솥 밑에 불 없음=釜底抽薪(急下·承氣). 사실 4~5개.

**③ 잔결**
- 등불(相火?)과 솥 뚜껑 위 돌의 뜻이 확정 안 됨. 2번 인물의 땀 유무가 애매(이마 한 점).
- 3번 인물 바지·얼굴이 좌우 반색으로 갈리는 것은 의도된 분할선. 오른쪽 끝 솥이 프레임에 바짝 붙음. 이어붙인 흔적은 없음.

## 2단계 — 계통 (사전요약 어휘로 다시 읽기)

**① 판 표제어** — 1단계 유지, 어휘가 공간 문법을 굳혀 준다.
- 1순위: **傷寒 六經辨證 三陽病(太陽中風·太陽傷寒·少陽·陽明經·陽明腑)** (88%)
- 2순위: **表·半表半裏·裏 病位(表裏辨證)** (9%)
- 근거: 성벽 바깥=外·表 / 문 통로, 寒(청)과 熱(등불)의 한복판=中 → 半表半裏 / 성 안=內·裏. 해=陽(갈림 조건인 「계절 들판」이 아니므로 陽 그대로) → 陽明.

**② 인물별**
1. **太陽中風** — 外·表(성 밖) / 風(옆으로 날리는 낙엽·바람결, 기운 나무) / 汗(얼굴·가슴 땀방울)=汗出 / 계피 4개=桂枝(사전 밖, 그림 그대로) / 뒤통수 짚기=頭項强痛. 5개.
2. **太陽傷寒** — 外·表(성벽 바깥) / 汗 없음=無汗 / 떨림=惡寒 / 麻黃 다발 / 이 악문 얼굴=身疼(痛 쇠못 없음). 寒 눈송이가 없어 「寒」은 소품이 아닌 연기로만 나른다. 4개.
3. **少陽** — 中(寒·熱 두 반쪽 사이, 表·裏 사이)=半表半裏 / 熱=등불 불꽃(오른쪽)과 찬 왼쪽 → 寒熱 / 흔들리는 쇠공=往來(저울추가 아니므로 降 아님, 수평 저울이 없어 和도 아님) / 소용돌이=目眩 / 갈비 아래 움켜쥠=胸脇苦滿 / 이마 땀 한 방울. 5개.
4. **陽明經證** — 內·裏 / 陽(해) / 口(크게 벌린 어두운 입)=大渴 / 盛(입에서 넘쳐 흘러내리는 물)=熱盛 / 汗·津(튀는 물방울)=大汗 / 淸(맑은 찬물 — 사발 아닌 항아리라 조건 일부)=白虎 淸法 / 붉은 얼굴=大熱(面 갈림상 얼굴색은 望色 기호로 안 씀). 5~6개.
5. **陽明腑證** — 實(팽팽한 배) / 大(나란한 옆 사람 배의 두 배)=大實→大承氣 / 燥(갈라진 땅)=燥屎 / 돌 눌린 솥=閉結(降 갈림 미충족, 확정 아님) / 불 없는 솥=釜底抽薪(사전 밖) / 붉은 얼굴=潮熱. 便(나무 뒷간통)이 없어 不大便은 직접 기호 없음. 4~5개.

**③ 잔결**
- 太(사람 아닌 것 위의 갓) 없음 → 「太陽」은 무대로만. 寒 눈송이·和(수평 저울)·痛 쇠못 없음 → 惡寒·和解·痛은 기호 없이 연기.
- 사전 밖 소품: 흔들리는 쇠공 추, 소용돌이, 솥 위 돌, 불 없는 솥.
- 오독 위험: 문 앞 서리 깔린 바닥 → 「밑에서 밴 서리=內寒」으로 읽힐 수 있음(太陽傷寒은 外寒). 끈으로 허리 묶은 麻黃 다발 → 收(볏단)와 겹침(이삭 없어 갈림 성립). 벽 등불 → 保命(손으로 감싼 등잔)과 겹칠 수 있으나 손 없음.
- 프레임 잘림·이어붙임 흔적은 없음.
