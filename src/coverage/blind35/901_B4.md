# 901 판독 (B4)

## 1단계 — 생판 (사전 없이)

**① 판 표제어**
- 1순위 **傷寒 六經辨證 — 三陽病(太陽·少陽·陽明)** (75%)
- 2순위 **表裏辨證(表 → 半表半裏 → 裏, 表寒 → 裏熱 傳變)** (12%) / 3순위 外感 六淫(風·寒·暑熱·燥)

판의 공간 짜임: 왼쪽은 성가퀴 달린 성벽 밖 바람 부는 들판(表·한랭), 가운데는 청/주황으로 반 갈린 아치문(半表半裏, 樞), 오른쪽은 담에 둘러싸인 뙤약볕 안뜰(裏·대열). 개합추(太陽開·少陽樞·陽明闔)로도 읽힌다. 같은 차림(회색 저고리·누빈 바지)의 한 사람이 단계별로 다섯 번 나오는 傳變 구도.

**② 인물별 (왼쪽부터)**
1. **太陽中風(桂枝湯證)** — 바람·흩날리는 낙엽(風邪·惡風), 얼굴·가슴의 땀과 풀어헤친 앞섶(汗出·表虛 / 腠理疏), 머리 짚은 손(頭痛·頭項強痛), 계피 묶음(桂枝湯, 계피 막대 4개). 5개.
2. **太陽傷寒(麻黃湯證)** — 온몸 떨림·자기 몸 끌어안기(惡寒), 땀 없고 여민 옷(無汗·表實), 이 악문 찡그림(身疼·骨節疼痛), 마디 있는 초록 줄기 묶음(麻黃湯). 4개.
3. **少陽病(小柴胡湯證)** — 반은 청, 반은 주황인 문 속에 섬(半表半裏), 좌우로 흔들리는 추(往來寒熱), 떨림선과 땀방울이 함께 있음(寒熱 교대), 머리 옆 소용돌이(目眩), 옆구리·명치를 움켜쥔 손(胸脇苦滿), 오므린 입(口苦·喜嘔), 등불(少陽 相火·一陽의 작은 불), 문 자체(少陽爲樞). 7~8개.
4. **陽明經證(白虎湯證)** — 이글거리는 해(大熱, 兩陽合明), 항아리째 들이켜기(大渴引飮), 흐르는 땀·물(大汗), 붉은 얼굴(面赤), 풀어헤친 옷(不惡寒 反惡熱). 4대증 중 3개 + 面赤 = 5개(脈洪大는 불확실).
5. **陽明腑證(承氣湯證)** — 불룩한 배를 누르는 두 손(腹滿·腹痛拒按), 붉은 얼굴(潮熱), 갈라진 마른 땅(燥 — 燥屎·津液 소모), 돌로 눌러 닫은 세발 검은 솥(腑氣 不通·不大便; 釜底抽薪 = 承氣湯 下法). 4개.

**③ 잔결**
- 太陽 둘에만 약재(桂枝·麻黃)가 있고 少陽·陽明에는 柴胡·石膏·大黃 같은 약재가 없다.
- 계피 4개라는 개수의 뜻을 모르겠다.
- 등불, 4번 발밑 배수 쇠살대는 뜻이 불확실하다.
- 麻黃 묶음은 평면 초록에 굵은 윤곽이라 붙여 넣은 듯하고, 팔 사이를 어색하게 통과한다.
- 해의 위쪽 빛살이 프레임에 잘렸다.
- 성가퀴 성벽과 오른쪽 낮은 안뜰 담의 이음새가 다르다.
- 화면 한가운데 청/주황 경계가 세로로 곧게 나뉘어 이어 붙인 자국처럼 보인다(의도한 연출일 수도 있다).

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **傷寒 六經辨證 — 三陽病(太陽中風·太陽傷寒·少陽·陽明經證·陽明腑證)** (65%)
- 2순위 **表裏辨證(表虛·表實 → 半表半裏 → 裏熱·裏實)** (25%)

사전의 外·表(담 밖·문 밖), 中(둘 사이의 한복판), 內·裏(담 안·성 안)가 그대로 무대 구조와 맞아, 그림이 표-반표반리-리 자리를 일부러 나눠 그린 것이 확실해졌다. 그래서 2순위 표리변증이 올라간다. 다만 桂枝·麻黃 두 약재와 해(陽)·갈라진 땅(燥)이 太陽·陽明이라는 六經 이름까지 가리켜, 1순위는 그대로 둔다.

**② 인물별 (왼쪽부터)**
1. **太陽中風(表虛)** — 外·表(성 밖 들판), 風(낙엽·바람결이 옆으로 흐름; 수직 아님이라 燥 아님), 汗(얼굴·가슴 땀방울) → 汗出·惡風, 桂枝(桂枝湯), 머리 짚기(頭痛, 쇠못이 없어 사전상 痛 아님). 5개.
2. **太陽傷寒(表實)** — 表·外(문 밖 성벽에 붙음), 汗 없음(無汗), 떨며 끌어안음(惡寒; 눈송이가 없어 사전상 寒은 미표기), 麻黃(麻黃湯), 찡그림(身疼, 못 없음). 4~5개.
3. **少陽(半表半裏)** — 中(표·리 두 무리 사이의 문 한복판), 熱(등불의 불꽃)과 맞은편 찬 청색 → 寒熱, 흔들리는 추(往來; 저울이 아니어서 降·和는 아님), 소용돌이(目眩), 옆구리 움켜쥠(胸脇苦滿), 汗 한 방울. 6~7개.
4. **陽明經證(裏熱)** — 內·裏(담 안 뜰), 陽(이글거리는 해 → 大熱; 철이 차례로 바뀌는 들판이 아니어서 暑 갈림은 해당 없음), 汗(大汗), 口(벌린 어두운 입 → 大渴), 넘쳐흐르는 맑은 물(盛·津 → 熱盛·津傷 / 맑은 찬 물이니 淸法 후보). 5~6개.
5. **陽明腑證(裏實)** — 內·裏, 實(팽팽히 찬 배), 大(옆 4번 배의 두 배 → 大實 / 大承氣 후보), 燥(갈라진 땅 → 燥屎), 돌로 눌러 닫은 세발 솥(不通·不大便 추정, 사전 없음), 붉은 얼굴(潮熱). 5개.

**③ 잔결**
- 寒의 눈송이와 痛의 쇠못이 판 전체에 없다. 그래서 惡寒과 頭·身·腹痛은 몸짓으로만 나른다.
- 흔들리는 추는 사전 어디에도 없다(저울이 아님).
- 세발 검은 솥과 그 뚜껑의 돌은 大便(나무 뒷간통)도 小便(요강)도 아니어서 뜻이 불확실하다.
- 桂枝·麻黃은 등재되지 않은 글자다.
- 문 한가운데의 세로 청/주황 경계는 皮(면 위의 색 경계선)로 잘못 읽힐 위험이 있다.
- 등불(熱인지 華인지), 배수 쇠살대, 계피 4개의 개수는 뜻을 모르겠다.
- 麻黃 묶음은 붙여 넣은 자국처럼 보인다.
- 해의 윗부분이 프레임에 잘렸다.
- 사전으로 판의 뼈대(表·中·裏, 風, 汗, 熱, 陽, 燥, 實)는 더 단단해졌지만, 寒·痛·往來·下法을 나르는 글자는 비어 있다.
