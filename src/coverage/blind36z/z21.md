# z21 판독

## 1단계 — 생판 (그림만)

**① 단원** 1순위 **問診(十問 — 寒熱·口渴·飮食·二便·胸腹을 묻는 虛寒 환자상)** 35%. 차순위 **八綱 寒熱 辨證(裏虛寒證)** 30%, **臟腑辨證 脾陽虛(脾胃虛寒)** 20%, **六淫 寒邪(中寒 直中)** 15%.

**② 인물** 띠 안 인물은 1명(노인, 가부좌).
- 표제어: **脾胃虛寒(脾陽虛) = 裏虛寒**, 문진 항목으로는 **畏寒·喜溫喜按**.
- 얼음 석실(고드름·서리·깊숙한 방) = 寒이 안(裏)에 있음, 고드름 = 寒性凝滯.
- 서리 덮인 곡식 자루 더미(3열) = 倉廩之官(脾胃)이 얼어 있음 → 中焦가 虛寒함.
- 김 나는 따뜻한 수건을 명치(胃脘)에 대고 누르며 편안한 얼굴 = 喜溫(寒)·喜按(虛) 2개 사실, 得溫則減(따뜻하게 하면 나아짐) = 畏寒이지 惡寒이 아님.
- 주름진 노인 = 久病 → 久病畏寒 = 虛寒.
- 부른 배 = 腹脹(脾失健運).
- 손대지 않은 가득 찬 물컵 = 口淡不渴. 손대지 않은 수북한 밥그릇 = 納少(食欲不振).
- 넘어진 항아리에서 맑은 물이 턱 아래까지 길게 흐름 = 小便淸長 또는 大便溏泄(淸稀), 곧 「諸病水液 澄澈淸冷 皆屬於寒」.
- 노란 바지·노란 수건 = 土色(脾)일 가능성.
- 관계: 띠 안에 인물이 하나뿐이라 인물 사이 관계는 없음. 이웃 띠의 熱證(口渴·小便短赤) 인물과 寒熱 대비를 이룰 것으로 추정.

**③ 잔결** 얼음방인데 물컵과 쏟은 물이 얼지 않았음. 배만 분홍(따뜻한 색)이라 腹脹 강조인지 熱 신호인지 모호함. 자루 수(왼쪽 열 9개쯤)·3열과 오른쪽 돌기둥(문틀)의 뜻을 모르겠음. 수건이 배가 아니라 명치·가슴 높이에 있음. 이어 붙인 흔적은 보이지 않음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원** 1순위 **六經辨證(傷寒論 六經病 — 이 띠는 太陰病)** 35%. 차순위 **八綱 寒證(裏寒)과 治法 溫中** 30%, **六淫 寒邪(中寒·直中)** 15%, **問診** 15%. 사전대로라면 문진 판은 二便을 요강·뒷간통(便), 통증을 쇠못(痛)으로 그렸을 텐데 이 띠에는 둘 다 없음. 그래서 問診의 무게가 내려감.

**② 인물(1명)** 표제어 **太陰病(脾臟 虛寒)**. 傷寒論 277條 「自利不渴者 屬太陰 以其**藏有寒**故也 當**溫**之」와 273條 提綱(腹滿·食不下·自利)이 소품마다 하나씩 실려 있음.
- 관리 없이 열린 곳간 안의 가마니 = **藏**, 벽·천장 안쪽의 성에 = **裏寒**(갈림 조건 맞음). 둘을 합치면 「藏有寒」.
- 세 열 가운데 열 앞에 앉음 + 천을 몸 한복판에 댐 = **中**. 김 나는 천 = **溫**. 둘을 합치면 溫中·「當溫之」.
- 팽팽한 배 = **實/腫**, 곧 腹滿.
- 넘어져 빈 항아리와 턱 아래로 흘러내린 물 = **瀉-b + 下**, 곧 自利(益甚). 물이 빠져나감.
- 맑은 찬 물컵 = **淸**, 손대지 않음 = 不渴.
- 가득 찬 밥그릇 = **補-b**(穀을 채움). 먹지 않았으니 食不下. 溫과 합치면 理中의 溫中補虛.
- 고드름은 불이 없으니 陰이 아니라 **凝滯**.
- 관계: 띠 안에 인물이 하나라 관계 없음. 이웃 띠의 少陰·厥陰과 三陰 순서를 이룰 것으로 추정.

**③ 잔결** 바닥 서리(內寒)와 벽 성에(裏寒)가 함께 있어 寒 갈림이 둘로 읽힘. 밥그릇은 補-b(채움)와 食不下(안 먹음)가 서로 어긋남. 물컵은 淸 기호인지 不渴인지 갈림. 太를 나르는 기호(사물 위 갓)도, 脾 농부도 없어서 「太陰」은 조합으로만 나옴. 痛(쇠못)·吐가 없어 時腹自痛·吐는 빠짐. 노란 바지는 五色 규칙이 다섯 인물에만 걸리므로 읽지 않음. 이어 붙인 흔적은 없음.
