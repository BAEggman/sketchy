# z57 판독

## 1단계 — 생판 (사전 없이)

**① 단원**: **傷寒論 六經辨證 — 少陰病** (45%). 차순위 **陰陽失調(陽虛·陰虛)** 30%, **問診 問睡眠(失眠·嗜睡)** 15%.
근거: 좌우 벽에 문이 하나씩 난 지하 석실 = 깊은 層의 한 「방」(六經 복도의 한 칸), 한 방 안에 같은 병의 두 갈래가 나란히 있음.

**② 인물·소품**
- 앉은 사내 = **少陰 熱化證**: 두 손바닥 위 불꽃 2개 + 붉은 가슴팍 = 手足心熱·心胸煩熱(五心煩熱 일부), 두 뺨만 붉음 = 顴紅, 부릅뜬 눈·꼿꼿이 앉음 = 心中煩 不得臥(不寐) → 陰虛火旺, 黃連阿膠湯.
- 누운 사내 = **少陰 寒化證**: 웅크림 = 惡寒蜷臥, 눈 감고 베개에 = 但欲寐(嗜睡), 얼굴·손·발이 보랏빛 = 手足厥冷·陽虛寒盛 → 四逆湯.
- 두 사람 기운 바지·짚신 = 虛證(정기 부족).
- 벽감 속 등잔 1개(불꽃 1, 연기) = 少陰君火 / 命門之火(어두운 방의 유일한 불), 밤 = 寐의 시간.
- 지하 석실·어둠 = 陰, 깊은 곳(腎·少陰).
**관계**: 한 방(少陰)에서 등잔을 사이에 두고 한쪽은 불이 넘쳐 잠들지 못하고 한쪽은 불이 꺼져 잠만 잔다 → 少陰病 提綱「脈微細 但欲寐」에서 從陰化寒 / 從陽化熱 두 轉歸, 心(火)·腎(水) 水火失濟. 거울 대칭 = 陽虛則寒 · 陰虛則熱.

**③ 잔결**: 손바닥 불꽃 2개뿐 — 발바닥은 짚신에 가려 「五心」 개수(5)가 안 나옴. 바닥의 흰 부스러기(서리? 소금? 잔해) 뜻 불명. 좌우 문은 이웃 띠로 가는 복도 흔적(이어 붙인 자리로 보이나 이음매 어긋남은 없음). 오른쪽 끝 불꽃은 앉은 사내의 다른 손 것.

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**① 단원**: **問診 — 問睡眠(失眠·嗜睡)** (45%). 차순위 **少陰病(寒化·熱化)** 30%, **問寒熱(但熱不寒·但寒不熱)** 15%.
사전 어휘로 보면 그림은 臟 인물(오행왕국)이 아니라 평민 환자 둘에 병표지를 붙인 「증상」 그림이다. 陰陽失調라면 얼음(陰)·1/3로 준 것(虛)이 나와야 하는데 없다 → 病機 판보다 診斷 판. 켜진 등잔(밤) 아래 하나는 자고 하나는 못 잔다 = 축은 「잠」.

**② 인물·소품**
- 앉은 사내 = **失眠(不寐) — 陰虛火旺·心腎不交**: 손바닥 위 불꽃 2 = 병표지 熱, 자리가 손바닥이라 「五心煩熱」(사전: 五心의 心은 臟이 아님). 크게 뜬 눈 = 目(目不瞑). 얼굴·광대 붉음 = 顴紅(색 자체는 望色 몫이나 陰虛 신호). 「心煩」은 임금+가슴이어야 하는데 임금이 없으므로 心煩으로 읽지 않는다.
- 누운 사내 = **嗜睡(多寐) — 陽虛陰盛·心腎陽虛(少陰 但欲寐)**: 보랏빛 손·발끝 = 厥(手足厥冷), 웅크림 = 蜷臥·畏寒, 감은 눈 = 目閉.
- 벽감 등잔 = 불(陽)이 작은 문틀(門) 안에 → **命門之火** 가능, 또는 단순히 밤 표지. 손으로 감싸지 않아 「保命」과 갈림.
- 석실 = 담 안쪽(內)·어둠 = 陰/夜.
**관계**: 열린 눈 ↔ 감은 눈 = 『靈樞·大惑論』 衛氣不得入於陰則目不瞑 / 留於陰則目閉. 陰虛로 陽이 陰에 못 들어가 못 자고, 陽虛로 陰이 성해 늘 잔다 — 같은 心腎(少陰)의 水火 한 쌍의 두 극.

**③ 잔결**: 등잔이 두 사람 사이 위쪽에 있어 「中(둘 사이 한복판)」으로 읽힐 소지 — 뜻 불분명. 불꽃이 손바닥 2개뿐이라 五心의 개수 5가 안 선다. 바닥 흰 부스러기가 「밑에서 밴 서리(內寒)」인지 잔해인지 갈리지 않음. 누더기 바지는 사전에 없는 차림(虛로 읽고 싶지만 虛 기호는 1/3 축소). 사전 어휘가 1단계보다 「증상 판(診斷)」 쪽으로 더 잘 풀어 줌.
