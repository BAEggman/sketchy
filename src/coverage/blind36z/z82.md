# z82 판독 (blind36z)

## 1단계 — 생판 (그림만 보고)

**① 단원**: **傷寒 六經辨證(六經病證)** 80% — 이 띠는 그 가운데 **厥陰病** 칸. (차순위: 八綱의 **寒熱錯雜/上熱下寒** 10%, 蛔厥·烏梅丸證 단독판 5%)

**② 가운데 인물 1명 = 厥陰病(提綱 326條)**
- 방 자체: 윗벽은 불꽃 벽돌, 허리 아래는 얼음벽·얼음바닥 → **上熱下寒 / 寒熱錯雜**(厥陰의 기본 병기). 얼굴도 이마는 붉고 턱은 창백.
- 단지를 들이켜고, 바닥에 빈 단지가 넘어져 있음(손 1 + 바닥 4, 그중 넘어진 것 2) → **消渴**.
- 붉게 달아오른 가슴을 움켜쥠 → **氣上撞心·心中疼熱**(2증).
- 손 안 댄 밥공기(밀려난 동작선) → **飢而不欲食**.
- 단지 구멍에서 기어 나오는 지렁이 같은 벌레 → **食則吐蛔**(蛔厥).
- 팔꿈치에 고드름, 두 발이 얼음에 잠김 → **手足厥冷 = 厥**(陰陽氣不相順接).
- 선반의 모래시계(검은 모래가 위에서 거의 다 빠짐) → **兩陰交盡·陰盡陽生**, 또는 **厥熱勝復**(厥과 熱의 날수 비교) / 欲解時(丑~卯). 셋 중 확정 못함.
- 提綱 6증 중 그림에서 찾은 것 5(消渴·撞心·疼熱·不欲食·吐蛔), **下之利不止**는 대응 소품 불명(바지 기운 자국 2개?).
- 관계: 띠 안 온전한 인물은 1명. 왼쪽 문간에 앉아 손바닥에 작은 불씨를 든 사람(이웃 띠)은 少陰(陽 쇠약, 한 점 陽氣)로 보이며, 문설주를 사이에 둔 배치가 **少陰→厥陰, 六經의 마지막 전변**을 나르는 듯.

**③ 잔결**: 바지의 기운 자국 2개와 허벅지 누런 얼룩의 뜻 불명(下利?). 벌레가 입이 아니라 단지에서 나와 吐蛔가 약함. 烏梅丸 소품 없음. 왼쪽 회색 돌벽·문간은 이웃 띠와의 이음매.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 단원**: **傷寒 六經辨證(六經病證)** 80% 유지 — 띠 = **厥陰病**. 사전 어휘가 단원을 바꾸지는 않고 厥陰 해석을 더 단단하게 한다. (차순위 **寒熱錯雜(上熱下寒)** 10%)

**② 가운데 인물 1명 = 厥陰病**
- 윗벽 불꽃 = 熱·陽. 얼음이 **살아 있는 불과 맞대어** 있으므로 갈림 조건이 맞아 얼음 = **陰**. 위는 불, 아래는 얼음 = **上熱下寒**.
- 불과 얼음이 수평선 하나에서 맞닿기만 하고 섞이지 않음 → **陰陽氣不相順接 → 厥**(337條).
- 두 발이 검푸르게 얼어 얼음에 잠김(팔 고드름 포함) = 사전의 **厥** = 手足逆冷.
- 바닥에 넘어진 빈 단지 3개 = **內燥**(밑동까지 마른 물독), 단지를 들이켬 → 熱이 진액을 말려 생긴 **消渴**.
- 몸 위의 한복판 = **中**. 붉게 달아오른 가슴 한복판을 손으로 누름 → **心中疼熱**(못·흰 김이 없어 疼·氣上撞心은 사전 기호로 나르지 않음).
- 가득 찬 밥공기(補-b, 채워 줄 곡식)를 밀어냄 → **飢而不欲食**.
- 단지 옆의 어두운 둥근 구멍(口·竅)으로 벌레가 나옴 → **食則吐蛔**.
- 모래시계는 사전에 없는 소품: **厥熱勝復**(날수 비교) 또는 **陰盡陽生/欲解時**로 보지만 확정 못함.
- 관계: 띠 안 인물은 1명이고, 사실은 **불(陽)과 얼음(陰)의 맞대 놓임 = 寒熱錯雜·不相順接**이 나른다. 왼쪽 이웃(**노란 옷 = 脾**, 손바닥의 작게 타다 남은 불씨 = **衰**)은 **太陰 脾陽衰**로 읽혀 1단계의 「少陰」 판정을 바꿈. 문설주로 갈린 陰經 이웃의 배치로 본다.

**③ 잔결**: 바지 기운 자국 2개·허벅지 얼룩은 사전에 없음(下之利不止의 자리가 비어 있음). 이마의 땀방울 같은 점(汗?)은 불확실. 모래시계는 기호 사전 밖. 왼쪽 돌 문간(門)은 이웃 띠와의 이음매.
