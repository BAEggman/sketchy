# 901 판독 (C4)

## 1단계 — 생판 (사전 어휘 없이)

**① 판 표제어**
- 1순위 **傷寒論 三陰病 提綱證(太陰·少陰·厥陰)** — 85%
- 2순위 **六經辨證 중 裏寒證·寒熱錯雜(脾·腎·肝 虛寒)** — 10%
- 근거: 석벽 방 3칸(왼 얼음방 / 가운데 어두운 방 / 오른 위붉고 아래얼음 방)이 太陰→少陰→厥陰 순서로 놓였고, 각 방 인물이 각 경 제강 증상을 그대로 연기한다.

**② 인물·구역 (왼쪽부터)**
- 인물1 **太陰病**(얼음방, 서리 앉은 곡식자루 앞 배불뚝이) — 6개: 큰 배=腹滿 / 김 나는 따뜻한 천을 배에 대고 찡그림=時腹自痛·喜溫喜按 / 가득 찬 밥그릇 손 안 댐=食不下 / 엎어진 항아리에서 물이 흘러 바닥 끝까지=自利(益甚) / 가득 찬 물컵 손 안 댐=自利不渴 / 서리 낀 곡식자루·고드름=脾(倉廩) 臟寒(藏有寒, 當溫之).
- 인물2 **少陰 寒化**(베개 베고 웅크려 잠든 보랏빛 사람) — 3개: 잠=但欲寐 / 웅크림=蜷臥 / 보랏빛 손발·얼굴=四肢厥冷(陽虛). (어두운 방·작은 등불=脈微細·陽氣微 로 추정)
- 인물3 **少陰 熱化**(눈 부릅뜬 채 앉아 두 손바닥에 불꽃) — 3개: 잠 못 들고 앉음=心中煩 不得臥 / 손바닥 불꽃=手足心熱(陰虛火旺) / 붉은 눈·홍조 뺨=虛火上炎(顴紅).
- 인물4 **厥陰病**(위는 불벽, 아래는 얼음벽) — 7개: 벽 위붉고 아래얼음=上熱下寒(寒熱錯雜) / 항아리째 들이켬+빈 항아리 3개=消渴 / 붉은 가슴 움켜쥠=氣上撞心·心中疼熱 / 발로 밀어낸 밥그릇=飢而不欲食 / 항아리 구멍에서 나오는 벌레=食則吐蛔 / 팔 고드름·얼어붙은 발=手足厥冷(厥) / 모래시계(위 검은 모래가 빠져나감)=兩陰交盡·陰盡陽生 또는 厥熱勝復(시간 교대).

**③ 잔결**
- 가운데 방 벽감의 작은 등불(君火? 脈微? 命門火?)·양옆 깊은 문간(少陰爲樞?) 뜻 불확실.
- 모래시계 뜻 둘로 갈림(兩陰交盡 vs 厥熱勝復/欲解時).
- 항아리 옆구리 구멍 + 벌레 2마리(테두리·구멍) 어색. 세 사람 모두 기운 바지 — 공통 소품인지 불명.
- 방마다 소실점이 따로라 세 칸을 기둥으로 이어 붙인 인상. 오른방 얼음바닥이 가운데 방 오른쪽 바닥까지 번짐. 왼방 쏟은 물이 하단 테두리 밖으로 흘러내려 프레임을 넘음.

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **傷寒論 三陰病 提綱證(太陰·少陰 寒化/熱化·厥陰)** — 90% (상향)
- 2순위 **六經辨證 裏證(臟寒·寒熱錯雜)** — 7%
- 사전으로 더 잘 풀린다: 왼방 김 나는 천(=溫), 가마니(=藏), 항아리 구멍(=口)이 1단계의 막힌 곳을 메워 준다.

**② 인물·구역 (왼쪽부터)**
- 인물1 **太陰病** — 6개: 부푼 배(腫·實)=腹滿 / 손 안 댄 밥그릇=食不下 / 엎어진 빈 항아리+쏟아져 아래로 흐르는 물(瀉-b·下)=自利 / 손 안 댄 물컵=不渴 / 앞에 관리가 없는 가마니 더미(藏)+안쪽 성에(裏寒)=「以其**藏有寒**故也」 / 김 오르는 따뜻한 천(溫)=「當**溫**之, 宜服四逆輩」. 제강(273)과 277조를 한 칸에 겹쳐 놓았다. 쇠못(痛)·토하는 모습이 없어 時腹自痛·吐는 그려지지 않았다.
- 인물2 **少陰 寒化** — 3개(+1): 베개 베고 잠=但欲寐 / 웅크림=蜷臥 / 검푸르게 언 손발 끝(厥)=四肢厥逆. 벽감 등잔 작은 불=陽**衰**(脈微細) 추정.
- 인물3 **少陰 熱化** — 3개: 베개 없이 앉아 크게 뜬 눈=心中煩·不得臥 / 손바닥 위 떠 있는 불꽃(熱 병표지; 사전이 「五心煩熱의 心=손·발바닥」으로 명시)=手足心熱·陰虛火旺 / 붉은 눈·뺨=虛火(얼굴색은 望色 판 전담이라 글자 아님).
- 인물4 **厥陰病** — 6개(+1): 산 불꽃 벽 바로 밑에 맞댄 얼음(陰 갈림 충족)=上熱下寒·陰陽氣不相順接 / 항아리째 들이켬+밑동까지 마른 빈 항아리 3개(內燥)=消渴 / 붉게 달아오른 가슴을 움켜쥠=氣上撞心·心中疼熱 / 동작선 그리며 밀려난 밥그릇=飢而不欲食 / 항아리의 어두운 타원 구멍(口)으로 나오는 벌레=食則吐蛔 / 팔 고드름·언 발=厥(검푸른 색은 약함). 모래시계는 사전에 없어 미해결(兩陰交盡? 厥熱勝復?).

**③ 잔결**
- 모래시계·벽감 등잔·가운데 방 양옆 문간(門? 少陰爲樞?)은 사전으로도 안 풀림.
- 충돌: 물컵(맑고 찬 물=淸으로 샐 위험, 실은 不渴), 가득 찬 밥그릇(補-b로 샐 위험, 실은 食不下), 왼방 고드름(불 없는 얼음=凝滯 갈림에 걸림).
- 세 사람 기운 바지 의미 없음. 방별 소실점이 달라 이어 붙인 인상, 오른방 얼음이 가운데 방 바닥으로 번짐, 왼방 물줄기가 하단 프레임을 넘음.
