# 901 판독 (D4)

## 1단계 — 생판 (사전 없이)

① 판 표제어
- 1순위 **三陰病(傷寒論 六經辨證의 太陰·少陰·厥陰 提綱證)** — 80%
- 2순위 **寒熱 辨證(裏寒·寒熱錯雜·上熱下寒)** — 10% / 그 밖 六經辨證 전체 판의 일부 10%

② 구역별 (왼쪽→오른쪽: 방 3칸, 인물 4)
- 구역1 얼음 곳간 · 인물1 **太陰病**(脾陽虛·寒濕) — 7개
  - 서리 낀 곡식자루 더미 = 脾(倉廩之官)·寒濕困脾
  - 둥근 부푼 배 = 腹滿
  - 김 나는 따뜻한 천을 배 위에 대고 찡그린 웃음 = 時腹自痛 + 喜溫喜按
  - 가득 찬 물컵(손 안 댐) = 口不渴(自利不渴者屬太陰)
  - 손 안 댄 밥그릇 = 食不下
  - 엎어진 단지에서 물이 흘러 바닥 끝까지 넘침 = 自利益甚(下利)
  - 얼음 방 전체 = 藏有寒(裏虛寒)
- 구역2 가장 깊고 어두운 방(쪽문 두 개 달린 벽감) · 少陰病
  - 인물2 **少陰 寒化** — 4개: 베개 베고 웅크려 잠 = 但欲寐·踡臥 / 보라색 손발·얼굴 = 手足厥冷(四逆) / 벽감 속 가냘픈 등잔불 = 脈微細(또는 命門火 쇠약) / 어두운 방 = 陽衰
  - 인물3 **少陰 熱化** — 4개: 충혈된 눈을 부릅뜸 = 心煩不得臥(不寐) / 두 손바닥 위 불꽃 = 手足心熱(五心煩熱) / 붉은 뺨 = 顴紅(陰虛火旺) / 앉아 버팀 = 누울 수 없음
- 구역3 위는 불벽·아래는 얼음벽 · 인물4 **厥陰病** — 8개
  - 위 붉음/아래 얼음, 상체 붉고 하체 하얗게 얼음 = 上熱下寒(寒熱錯雜)
  - 단지째 들이킴 + 바닥 빈 단지 3개 = 消渴
  - 붉게 달아오른 가슴을 움켜쥠 = 氣上撞心·心中疼熱
  - 발로 밀쳐진 밥그릇(움직임 선) = 飢而不欲食
  - 구멍 난 항아리에서 기어 나오는 벌레(1~2마리) = 食則吐蛔
  - 팔·옷자락에 매달린 고드름, 언 발 = 手足厥冷(厥)
  - 선반 위 모래시계(위 검은 모래 → 아래 흰 모래) = 厥熱勝復(날수 다툼) 또는 兩陰交盡·陰盡陽生

③ 잔결
- 모래시계 모래 색이 위 검정·아래 흰색으로 다른 이유 불명(陰→陽 전환인지, 시간 계산인지 갈림).
- 가운데 방 좌우 기둥에 붙은 쪽문 두 개의 뜻 불명(少陰爲樞?).
- 인물2·3·4 바지의 덧댄 헝겊(기운 자국) — 虛 표지인지 화풍인지 불명.
- 곡식자루 개수·단 수는 의미 없어 보임. 프레임 잘림·이어 붙인 흔적은 보이지 않음(방 사이 돌기둥 경계 자연스러움).

## 2단계 — 계통 (사전 어휘로 다시 읽기)

판정: 사전 어휘로 1단계 해석이 **뒤집히지 않고 더 단단해진다**. 특히 太陰 방과 厥陰 방은 원문 구절이 글자 단위로 맞물린다.

① 판 표제어
- 1순위 **三陰病 提綱(太陰·少陰 寒化/熱化·厥陰)** — 85%
- 2순위 **寒熱 辨證(裏寒 → 寒熱錯雜·上熱下寒)** — 8% / 六經辨證 전체 7%

② 구역별
- 인물1 **太陰病** — 6개
  - 문 열린 방에 쌓인 가마니(관리 없음) = 藏 + 그 위 성에 = 裏寒 → 「以其**藏有寒**故也」
  - 부풀어 팽팽한 배(腫·實 꼴) = 腹滿
  - 김 오르는 따뜻한 천 = **溫** → 「當溫之」(治法, 四逆輩)
  - 엎어진 단지에서 쏟아져 바닥 끝으로 흘러넘침(下·盛) = 自利益甚
  - 손 안 댄 밥그릇 = 食不下
  - 가득 찬 맑은 물컵 = 不渴(「自利不渴者屬太陰」) — 단 사전의 淸(맑고 찬 물)으로 읽으면 밥그릇과 묶여 「下利淸穀」 — **갈림**
- 인물2 **少陰 寒化** — 4개: 웅크려 잠 = 但欲寐·踡臥 / 검푸르게 언 손발 끝 = **厥**(四逆) / 벽감 속 작게 남은 등잔불(陽+衰) = 陽衰·脈微細 / 담 안쪽(內) 깊은 방 = 裏(心腎)
- 인물3 **少陰 熱化** — 4개: 손 곁에 크게 뜬 불꽃 = 병표지 熱(熱證) / 손바닥 불꽃 = 五心煩熱(사전이 心을 臟에서 면제) / 크게 뜬 충혈 눈(目) = 心煩不得臥 / 붉은 뺨 = 陰虛火旺
- 인물4 **厥陰病** — 7개
  - 살아 있는 불벽과 얼음벽이 허리 높이에서 맞댐 → 갈림 조건 충족, 얼음 = 陰·불 = 陽 → 上熱下寒 + 「**陰陽氣不相順接, 便爲厥**」
  - 단지째 들이킴 + 빈 단지 3개 = 消渴(흩어져 있어 久는 아님)
  - 붉게 단 가슴 한복판(몸 위의 中)을 움켜쥠 = 氣上撞心·心中疼熱
  - 밀쳐진 밥그릇 = 飢而不欲食
  - 항아리 속(會)에서 구멍(竅)으로 나오는 벌레 = 食則吐蛔(蛔厥)
  - 언 발·고드름 = 厥(手足厥冷)
  - 모래시계 = 厥熱勝復(날수) — 사전 없음

③ 잔결
- 모래시계(검은 모래→흰 모래)는 사전에 없는 소품 — 厥熱勝復인지 陰盡陽生인지 갈림.
- 少陰 방 좌우 쪽문 둘(門)은 少陰爲樞로 읽힐 수 있으나 확신 없음.
- 물컵: 不渴 / 淸(下利淸穀) 갈림. 痛 글자(쇠못)는 어디에도 없어 腹痛·心中疼은 표정·몸짓으로만 전달.
- 바지의 덧댄 헝겊은 사전에 없어 화풍으로 판정. 잘림·이어 붙인 흔적 없음.
