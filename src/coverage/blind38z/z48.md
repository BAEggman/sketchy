# z48 판독

## 1단계 — 생판 (사전 없이)

**① 단원**: **六經辨證(傷寒 六經病)** 75% / 2순위 **衛氣營血 — 氣分證** 15% / 3순위 **八綱 — 裏熱實證** 10%.
근거: 띠 양 끝에 같은 차림(회색 저고리·무릎 기운 누런 바지)으로 책상다리한 사람이 잘려 있다 → 같은 옷의 사람 여러 명이 한 줄로 앉은 판 = 한 병의 단계들을 줄 세운 그림(六經 傳變)으로 읽힌다.

**② 한가운데 인물 1명 — 표제어 **陽明病(陽明經證)****
- 얼굴·가슴·배가 온통 시뻘겋다 → **身大熱(壯熱)·面赤**
- 머리 둘레로 땀방울이 튄다(10여 개) → **大汗·汗自出**
- 큰 대접의 물을 벌컥 들이킨다 → **大渴引飮**
- 내민 혀에 누런 태 → **舌苔黃燥**
- 한 손으로 저고리 앞섶을 젖혀 가슴을 드러냄 → **不惡寒 反惡熱**
- 드러난 둥근 배 → 「陽明之爲病 **胃家實**是也」
- 바닥 쟁반: 흰 돌덩이 1 = **石膏**, 흰 낟알 한 무더기 = **粳米** → **白虎湯**(石膏·知母·甘草·粳米 4味 중 2味만 보임)
- 합하면 **陽明經證 四大症(大熱·大汗·大渴·脈洪大)** 중 3개가 몸에 실림; 脈洪大는 그려지지 않음.
- 배경: 누런 흙벽·누런 빛 → 陽明=**胃(戊土)** 의 黃色? (약함)
- 관계: 중앙 인물은 1명. 좌우 이웃과 같은 옷·같은 자세 → 「같은 환자가 단계를 옮겨 감」= **太陽→陽明 傳經**(六經 순서상 둘째 자리).

**③ 잔결**: 무릎·정강이의 기운 자국(헝겊 덧댐)은 이웃도 똑같아 뜻 없는 공통 의상으로 보임. 왼쪽 바닥의 풀잎 가지 2개는 왼쪽 이웃 몫(柴胡? 麻黃?)인지 불명. 왼쪽 기둥 옆 벽의 꼬불한 선(김? 금?) 뜻 모름. 知母·甘草·洪大脈 소품 없음. 이어 붙인 흔적은 안 보임.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 단원**: **六經辨證 — 陽明病 자리** 80% (2순위 **衛氣營血 氣分證** 12%, **八綱 裏熱實** 8%). 사전 어휘가 「實·裏」를 보태 傷寒 陽明 提綱 쪽으로 더 기운다.

**② 한가운데 인물 1명 — **陽明病(經證+腑證)****
- 살갗·이마의 땀방울 = **汗** → 大汗·汗自出.
- 맑고 찬 물 한 그릇(김 없음 → 補 아님) = **淸** → 淸法(辛寒淸熱); 들이키는 동작이 **大渴**.
- 혀 위 누런 이끼 = **苔** → **黃苔**, 가운데 갈라진 줄 → 燥. (舌 갈림 「혀가 보이면 心」은 五官 판 문법이라 여기선 苔의 받침으로만 읽음.)
- 팽팽하게 둥근 배(광택 하이라이트) = **實** → 「**胃家實**」 提綱.
- 앞섶을 젖혀 맨살을 드러냄 = 막을 **惡**(가리개)을 스스로 걷음 → **不惡寒·反惡熱**.
- 문 닫힌 방 안 = **內/裏** → 陽明은 **裏證**(裏熱實).
- 쟁반 위 굵은 소금 무더기 = **鹹** → 鹹寒 **芒硝** → **承氣湯**(腑實 瀉下·軟堅). 흰 돌덩이는 사전 밖 → 그대로 **石膏**(白虎湯). → 經證·腑證 두 治方이 한 쟁반에.
- 붉은 낯빛은 面 갈림(광택만 面)상 기호가 아니라 身熱·面赤 묘사.
- 관계: 같은 차림 셋 중 가운데 = **中**(약함) → 「陽明居中 主土也 萬物所歸 無所復傳」(傷寒論 184조) 또는 단순히 六經 줄의 傳經 한 칸.

**③ 잔결**: 熱=불꽃이 화면에 없어 熱 글자가 빠짐(붉은 살갗으로만 나름). 쟁반의 큰 덩이·작은 무더기가 **大**(같은 것 둘 중 하나가 두 배)로도 읽혀 「大熱·大渴의 大」인지 鹹+石膏인지 갈림. 흰 돌덩이(石膏?) 사전 미등재. 粳米로 보던 낟알이 사전상 소금(鹹)으로 바뀌어 白虎湯 구성이 깨짐. 脈洪大 소품 없음. 붉은 살갗이 血(붉은 것)로 오독될 여지. 무릎 기운 자국은 공통 의상.
