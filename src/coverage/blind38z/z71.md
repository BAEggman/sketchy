# z71 판독

## 1단계 — 생판 (사전 보기 전)

**① 단원**: 1순위 **衛氣營血辨證** (55%) · 2순위 **八綱(陰虛·虛熱)** (25%) · 3순위 **望診(望舌·吐舌)** (20%)

**② 인물**: 띠 한가운데 인물은 1명(오른쪽 끝의 발·바짓단은 이웃 띠 몫).
- 표제어: **營分證** — 밤 방 안에 앉은 남자.
- 창밖 밤하늘·달 → **身熱夜甚**(열이 밤에 심함).
- 눈을 부릅뜬 채 눈 밑이 거뭇함 → **心煩不寐**(營熱이 心神을 어지럽힘).
- 길게 내민 진홍 혀 → **舌質紅絳**(색이 핵심, 苔 없음). 2순위로 읽으면 **吐舌**=心脾積熱.
- 풀어헤친 앞가슴의 흐린 붉은 점 약 10개 → **斑疹隱隱**(뚜렷이 돋지 않은 점 = 營分. 뚜렷하면 血分).
- 높이 든 손바닥 → 煩躁·揚手(時有譫語)로 읽음. 陰虛로 읽으면 손바닥·가슴 = 五心煩熱.
- 붉은 두 뺨 → 熱(陰虛로 읽으면 兩顴潮紅).
- 무릎의 기운 자국 2개 → 營陰耗傷(陰이 닳음). 陰虛 독법에서는 '虛' 표지.
- 관계: 오른쪽 이웃(걸어 들어오는 다리)은 다음 단계(血分)로 넘어가는 진행, 곧 衛→氣→營→血 傳變 순서를 나르는 것으로 추정.

**③ 뜻 모를 것·어색한 것**: 든 손의 뜻이 하나로 정해지지 않음(譫語? 五心? 인사?). 짚신·문살창(오른쪽 위 창은 달밤인데 왼쪽 창호는 밝음 — 낮·밤이 섞임). 이마 양옆의 거뭇한 얼룩(땀인지 그림자인지 불명). 이어 붙인 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원**: **衛氣營血辨證** 유지 (55%). 사전이 단원을 바꿀 만한 기호를 주지 않음. 오히려 陰虛 독법을 약하게 만듦(아래). 대안 **望診(望舌)** 20%, **陰虛(五心煩熱·潮熱盜汗)** 15%, 六經 **少陰熱化**(心煩不得臥) 10%.

**② 인물**: 오행왕국 다섯 인물(곤룡포·갑옷·밀짚모자·도포·잠수복)이 아닌 서민 환자 1명 → 장부의 의인화가 아니라 병증을 보여 주는 인물.
- 표제어: **營分證**.
- 벌린 입 안에 혀가 보임 → 갈림 「혀가 보이면 **心**」 → 營熱이 心을 침(營氣通於心, 心神被擾). 혀가 진홍(血=붉은 것)이니 **舌絳**.
- 혀 위에 이끼(苔) 없음 → 少苔·無苔. 營陰이 닳은 것과 맞음.
- 크게 뜬 눈 = **目** + 밤 창 → 밤에 잠들지 못함(**心煩不寐**). **身熱夜甚**은 사전 밖의 무대가 나름.
- 앞가슴의 붉은 점 약 10개: 갈림 「살갗 위의 얼룩은 瘀가 아니다 — 그 자리의 색」 → 瘀血이 아닌 피부의 색, 곧 **斑疹隱隱**(흐림=營分. 뚜렷하면 血分).
- 붉은 두 뺨: 갈림 「얼굴색 자체는 望色 판 전담」 → 이 판에서는 面(광택)이 아님. 赤=熱 정도로만 읽음.
- 땀방울(汗) 없음, 불꽃(熱)·얼음(陰) 없음 → 陰虛의 潮熱盜汗 독법이 약해짐.
- 든 손바닥: 心 갈림 「五心煩熱의 心은 손·발바닥」에 걸어 볼 수 있으나, 손바닥은 하나뿐이고 발바닥은 짚신에 가려 성립이 약함. 1단계의 煩躁·譫語 쪽으로 남김.
- 관계: 띠 안에는 인물이 1명뿐. 오른쪽 이웃 띠의 다리가 같은 겨자색 바지·짚신 → 같은 환자가 다음 칸에서 **血分**으로 넘어가는 傳變(衛→氣→營→血) 순서로 추정.

**③ 잔결**: 무릎의 기운 자국 2개·짚신·든 손은 사전에 없어 뜻이 확정되지 않음. 왼쪽 창호는 낮빛인데 오른쪽 창은 달밤이라 낮·밤이 섞임. 이마 양옆의 거뭇한 얼룩은 땀방울(汗) 꼴이 아님.
