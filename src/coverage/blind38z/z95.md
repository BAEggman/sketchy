# z95 판독

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원**: **衛氣營血辨證**(溫病 辨證) 80% · 2순위 **火(熱)邪**(六淫) / **血熱證**(氣血辨證) 15%.

**② 인물(1명) — 表題 「**血分證**」**
- 인물: 집 가장 안쪽 **구석**(최심층 = 血分)에 벽에 기대 주저앉은 남자. 몸 전체가 자줏빛 + 짙은 자색 반점 빽빽 → **斑疹 顯露**(營分 「隱隱」보다 진행). 눈 감고 입 크게 벌려 소리침 + 머리·손·몸 주위 떨림선 → **躁擾不安·神昏譫狂**(+ 動風 抽搐 암시).
- 혀: 길게 내민 혀가 짙은 검붉은색 → **舌質 深絳**.
- 피 3곳 = **動血(出血) 3종**: ① 콧구멍 피 = **衄血**, ② 손에 쥔 피 묻은 수건(입가 높이) = **吐血/咯血**, ③ 엉덩이 옆 바닥의 피 젖은 천 = **便血·尿血**(下部 출혈).
- 배경: 창밖 초승달·어두운 방 = **身熱夜甚**(營血分 공통, 熱이 陰分에 있음).
- 바닥 종이 위 소품 2종: 검은 뿔 = **犀角**, 검붉은 둥근 절편 약 8조각 = **生地黃** → **犀角地黃湯**(凉血散血; 葉天士 「入血就恐耗血動血, 直須凉血散血」). 牧丹皮·赤芍은 안 보임(이웃 띠 몫이거나 생략).
- 관계: 띠 안 인물 1명뿐 → 인물 간 관계 없음. 「가장 깊은 구석」이 衛→氣→營→血 중 마지막·최심 단계임을 나름.

**③ 잔결**: 바지 무릎의 **기운 헝겊 2장**(補? 의미 불명 — 陰血 耗傷의 「해어짐」일 수도), 짚신 1켤레, 상투 — 뜻 없는 소품으로 봄. 피 묻은 바닥 천이 손 밑에 놓인 위치가 다소 작위적(下血 표지로 끼워 넣은 흔적). 약 절편 수(≈8)는 사실을 나르지 않는 듯.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원**: **衛氣營血辨證** 85% (1단계 유지). 사전의 「地黃 = 검붉은 뿌리 조각」이 바닥 절편과 정확히 맞아 **犀角地黃湯 → 血分**이 굳어짐. 2순위 **血熱證**/火邪 10%.

**② 인물(1명) — **血分證** (熱盛動血 + 擾心)**
- **血 = 붉은 것**이 세 자리에 붙음 → 자리 글자와 합쳐 읽힘: **鼻**(열린 콧구멍)+血 = **衄血** · 손에 쥔 천+血(입 높이, **口** = 어두운 타원 구멍) = **吐血** · **下**(바닥으로 쏟아짐)+血 = **便血·尿血**. 셋 = **迫血妄行 動血**.
- **舌 = 벌린 입 안의 혀**, 갈림 「혀가 보이면 **心**」 → 熱이 **心神을 擾亂**(躁擾不安·神昏譫狂; 떨림선과 합치). 혀 색 자체는 **深絳**.
- 살갗 자색 반점: 갈림 「살갗 위 얼룩은 瘀가 아니다 — 그 자리의 색」 → **斑疹(紫黑) 密布/顯露**로 읽음(瘀 아님).
- 바닥: **地黃**(≈8조각) + 검은 뿔(사전 외 = **犀角**) → **犀角地黃湯 凉血散血**.
- 배경: 방 안 가장 깊은 구석 = **內·裏**(담·문 안쪽) → 衛氣營血 중 **最深層**; 초승달 밤 = **身熱夜甚**(사전 외).
- 관계: 띠 안 인물 1명 → 인물 간 관계 없음.

**판정**: 사전 어휘로 1단계와 같은 결론이 더 단단히 풀림(地黃 확정, 혀→心 추가, 반점≠瘀 정리). 뒤집힌 것은 없음.

**③ 잔결**: ① 피 묻은 천 두 장이 「천 위의 검붉은 덩이 = **瘀**」로도 읽힐 여지 — 그러나 색이 선홍·액상이라 **血**로 판정(血分의 「散血」이 瘀를 겨냥한다는 점과 겹쳐 애매). ② 犀角·초승달·떨림선은 사전에 없는 기호. ③ 바지의 기운 헝겊 2장·짚신·상투 — 사전상 補(국물 그릇)·傷·久 어느 것도 아님 → 뜻 없는 소품.
