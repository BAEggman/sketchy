# 901 판독 (F4)

## 1단계 — 생판 (사전 없이 그림만)

**① 판 표제어**
- 1순위 **衛氣營血辨證(葉天士 『溫熱論』, 溫病)** — 85%
- 2순위 **溫病 舌診·斑疹(舌色 淡紅→紅→絳→紫, 斑疹 隱→顯)** — 8%
- 근거: 왼쪽→오른쪽으로 네 사람, 햇빛 든 열린 문(바깥=表)에서 달 뜬 어두운 구석(속=深)으로 빛이 줄어듦 = 淺→深 傳變 4단계. 바닥 쟁반 약재가 각 단계 대표방(銀翹散·白虎湯·犀角地黃湯)과 맞물림.

**② 인물별 (왼쪽부터)**
1. **衛分證** — 6개: 열린 문·바깥 햇빛(表·衛, 病位 最淺) / 목을 움켜쥠(咽喉腫痛) / 입김 뭉게(咳嗽) / 머리 옆 떨림선(微惡風寒 또는 頭痛) / 혀끝·가장자리만 붉음(舌邊尖紅, 苔薄) / 바닥 쟁반 인동꽃·개나리가지(金銀花·連翹 → **銀翹散**, 辛涼解表).
2. **氣分證** — 7개: 붉은 얼굴·붉은 가슴배(壯熱·面赤) / 튀는 땀방울(大汗) / 물사발 벌컥(大渴引飮) / 옷섶을 젖힘(不惡寒反惡熱) / 누런 혀(苔黃燥) / 쟁반의 흰 돌덩이(石膏) / 흰 쌀알(粳米) → **白虎湯**. 즉 四大 중 大熱·大汗·大渴 3개(脈洪大는 안 보임).
3. **營分證** — 5개: 진홍 혀(舌紅絳) / 가슴에 옅은 붉은 점(斑疹隱隱) / 부릅뜬 눈·눈밑 그늘(心煩不寐) / 달 창으로 뻗은 손(身熱夜甚; 또는 躁擾·譫語) / 물사발 없음(口反不甚渴, 추정).
4. **血分證** — 8개: 온몸 보라 피부+짙은 반점 빽빽(斑疹顯露·紫黑) / 짙은 보랏빛 혀(舌深絳·紫) / 코피(衄血) / 피 묻은 수건(吐血·咯血) / 바닥 손밑 핏자국(便血 등 출혈) / 몸 떨림선·벽에 기대 늘어짐(動風抽搐·神昏) / 검은 뿔(犀角, 현행 水牛角) / 검붉은 저민 뿌리(生地黃) → **犀角地黃湯**(涼血散血).

**③ 잔결**
- 인물3 앞 바닥이 비어 있음 — 營分 대표방(淸營湯) 소품이 없음(위 셋과 비대칭).
- 白虎湯·犀角地黃湯 모두 4味 중 2味만 그림(知母·甘草, 赤芍·牧丹皮 없음).
- 인물3의 쳐든 손: 달 창 지시인지 譫語·躁擾인지 갈림.
- 바지의 기운 천 조각(인물1·3·4)·인물1 머리 떨림선은 뜻 미상.
- 프레임 잘림·이어붙인 흔적은 뚜렷하지 않음(빛이 문→달창으로 자연스럽게 이어짐).

## 2단계 — 계통 (사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **衛氣營血辨證(葉天士 『溫熱論』)** — 90% (사전으로 表·氣·淸·地黃이 맞물려 오히려 굳어짐)
- 2순위 **溫病 舌診·斑疹(舌色 淡紅→紅→絳→紫)** — 6%

**② 인물별 (왼쪽부터)**
1. **衛分證** — 6개: 열린 문 밖 = **表**(衛=表) / 입에서 나는 서린 흰 김 = **氣**(肺衛之氣 → 咳嗽) / 목 움켜쥠(咽痛 — 痛 쇠못·腫 없음, 몸짓만) / 머리 떨림선(微惡風寒 추정 — 惡 가리개·寒 눈송이 없음) / 舌(邊尖紅) / 金銀花+連翹(**銀翹散**, 사전 외 약재 식별).
2. **氣分證** — 7개: 붉은 몸(壯熱 — 熱 불꽃은 없음, 살갗 색만) / 땀방울 = **汗**(大汗) / 맑고 찬 물 한 사발 = **淸**(大渴 + 「到氣才可淸氣」 치법 겹침) / 옷 젖힘(反惡熱) / 혀 위 노란 이끼 = **苔**(黃苔) / 石膏 + 粳米(**白虎湯**).
3. **營分證** — 4개: 舌絳 / 가슴 옅은 붉은 점(斑疹隱隱) / 크게 뜬 눈 = **目**(心煩不寐) / 달 창으로 뻗은 손(身熱夜甚; 「透熱轉氣」로도 읽힘). 무대상 더 안쪽 = **內**.
4. **血分證** — 8개: 살갗 보라 반점(사전 갈림대로 瘀 아님 → 그 자리의 색 = 斑疹 紫黑 顯露) / 舌紫絳 / 열린 콧구멍+붉은 것 = **鼻**+**血**(衄血) / 피 수건(吐·咯血) / 바닥으로 흘러내린 피(**下** — 下血; 뒷간통 없어 便血 확정은 못함) / 떨림·늘어짐(動風·神昏) / 검은 뿔(犀角) + 검붉은 뿌리 조각 = **地黃** → **犀角地黃湯**(涼血散血). 가장 깊은 어두운 구석 = **裏**.

**③ 잔결**
- 인물3 앞 처방 소품 없음(淸營湯 빈칸) — 1단계와 같음.
- 사전 갈림 누수 위험: ⓐ「舌 = 혀가 보이면 心」을 그대로 쓰면 네 사람 모두 心이 됨 — 이 판에서 혀는 舌診이지 開竅 아님. ⓑ 地黃 조각이 천 위에 놓여 「천 위 검붉은 알갱이 = 瘀」와 샐 수 있음(둥근 저민 뿌리라 地黃 우세). ⓒ 네 사람 모두 입을 크게 벌려 溫病 무대에서 「큰 입 = 吳」(吳鞠通·吳又可)로 오독될 여지. ⓓ 출렁여 튀는 물사발이 「盛」으로도 읽힘.
- 사전 기호 부재: 熱(불꽃)·寒/惡·痛·風 없음 → 惡寒·咽痛·動風은 몸짓·떨림선에만 의존.
- 이어붙임·잘림 흔적 없음.
