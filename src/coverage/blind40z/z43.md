# z43 판독

## 1단계 — 생판 (사전 없이)

**① 단원**: **藏象(五臟·十二官 — 靈蘭秘典論/六節藏象論)** 50%. 차순위 **方劑 君臣佐使** 20%, **傷寒 少陰病(溫裏)** 15%, **本草總論** 15%. 배경 전체가 百子櫃(약장)라 약방 무대인 것은 확실하나, 인물 색(赤·靑·黑)이 臟 배당과 정확히 맞아 藏象을 1순위로 둔다.

**② 인물**
- 붉은 곤룡포·익선관의 임금 = **心 — 君主之官 神明出焉**. 赤=火. 둥근 편(片)을 입 앞에 들고 맛봄 = 心開竅於舌(舌能知五味). 그 앞 장작불 위 끓는 솥 = 心屬火·陽中之太陽(夏). 위 선반 김 나는 사발+걸린 수건 = 汗爲心液. 고추 접시 = 火/熱(心惡熱?).
- 녹색 鱗甲 장수 = **肝 — 將軍之官 謀慮出焉**. 靑=木. 곁의 잘린 무에서 핏방울 = 肝藏血.
- 탁자 밑 검은 잠수복 사람, 눈 감고 웅크려 눈(雪) 위에 잠 = **腎** — 黑·水(잠수)·冬·寒, 웅크린 잠 = 主蟄·封藏之本. 손발 끝 청색 = 寒. 머리 뒤 붉은 빛 = 命門火? (불확실)
- 왼쪽 물웅덩이 속 회색 혹 달린 덩이 = 水/鹹 → 腎 소품(조개 또는 鹽附子로 보임).

**관계**: 솥 밑 장작(木)이 불(火)을 지핌 = **木生火 — 肝은 心의 母**; 心主血·肝藏血 협동. 임금(위)–잠수부(아래) 상하 배치 = **心腎相交·水火旣濟**. 잿더미 = 火生土?

**③ 잔결**: 열린 찬장에서 쏟아진 눈덩이(출처 불명), 잠수부 고글, 회색 덩이 정체(조개/附子), 무의 피가 肝인지 다른 사실인지, 고추·잿더미의 臟 귀속 불명. 오른쪽 끝 붉은 옷은 이웃 띠 인물.

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**① 단원**: **治則·治法(寒者熱之·溫補 — 至眞要大論 계열)** 35%. 차순위 **病機(寒熱·內生五邪)** 30%, **藏象** 20%, **宣明五氣** 15%. 약장 무대 + 치료 어휘(熱·補·溫·辛)가 「병든 腎」 위에 몰려 있어 治法 쪽으로 옮긴다. 인물 셋의 臟 배당(心·肝·腎)은 1단계와 같고 사전으로 확정.

**② 인물**
- **心**(붉은 곤룡포 임금): 바로 앞 살아 있는 불꽃 = 熱, 솥에서 곧게 솟는 흰 김 = 氣(+上) → 心屬火 / 少火生氣. 손의 노란 뿌리 조각은 미등재(地黃은 「검붉은」이라 미달). 舌은 입이 닫혀 성립 안 함 — 1단계 「開竅於舌」 철회.
- **肝**(초록 비늘갑옷 장군): 잘린 뿌리 밑 붉은 방울 1 = 血 → 肝藏血.
- **腎**(잠수부): 열린 찬장 **문 안쪽**에서 밀려 나와 몸 밑에 밴 서리 = **內寒**(寒 갈림), 손발 끝 검푸름 = **厥**(손·발 2쌍), 탁자 밑에 가라앉음 = 下, 웅크림 = 收引 → 腎陽虛 內寒·厥冷(諸寒收引 皆屬於腎).
- 소품: 접시 고추 2개 = **辛**(1단계 「火」 철회), 선반의 찰랑한 따뜻한 국 사발 1 = **補**, 곁 수건 = 溫?(김이 천에서 오르지 않아 약함), 잿더미 = 衰?(접시 없어 鹹은 미달), 장작 4개.

**관계**: 心의 불(熱)이 腎의 서리(內寒) 바로 위에 놓임 = **寒者熱之 / 益火之源以消陰翳**, 心火下降溫腎(心腎相交). 心–肝은 血 방울이 肝 쪽에 있어 心主血·肝藏血로 읽히나 약함(장작=木生火는 미등재).

**③ 잔결**: 물웅덩이 속 회색 혹 덩이(痰 「끈적한 회백색 덩이」치고는 단단한 꼴 — 돌이면 腎脈石?, 산 불 곁 고인 물이면 陰?) 미결. 잠수부 머리 뒤 붉은 빛+팔·정강이의 붉은 기(假熱·戴陽인지 이웃 띠의 빛인지) 불명. 뿌리(무/生地黃?) 미등재. 탁자 위 세로 이음선(x≈450)에서 탁자·찬장이 끊김 — 구역 경계 또는 이어 붙인 흔적.
