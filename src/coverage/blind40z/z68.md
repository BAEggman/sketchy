# z68 판독 기록

## 1단계 — 생판 (사전 없이 그림만)

**① 단원 1순위: 君臣佐使 / 神農本草經 三品(本草·方劑 總論)** — 40%. 차순위 **藥物 七情(單行·相須·相使·相畏·相惡·相反·相殺)** 20%, **한국의학사(세종 鄕藥)** 15%. 근거: 배경 전체가 百子櫃 藥欌 → 본초·방제 영역, 인물이 왕·장수·농부·선비로 「신분 위계」를 이룸 → 藥을 君·臣·佐·使 위계로 비유하는 장면으로 읽힘.

**② 인물(띠 가운데 둘 + 가장자리 둘)**
- 곤룡포·익선관 왕(가운데 왼쪽) = **君(上品)**. 용 흉배 = 天子 → 「上藥 120종 爲君, 主養命以應天, 無毒 久服不傷人」. 앞의 잔뿌리 달린 인삼 = 上品 대표(人參), 붉은 즙 그릇 = 上品 첫머리 丹砂(붉음)로 추정.
- 밀짚모자 농부(가운데 오른쪽, 갓 캔 풀뿌리를 쥠) = **佐使(下品)**. 흙에서 캔 풀 = 「下藥 125종 爲佐使, 主治病以應地, 多毒 不可久服」. 앞의 대나무통에서 물이 탁자 아래로 쏟아짐 = 「下」(아래로 내려감·瀉下).
- (왼쪽 끝, 잘림) 녹색 갑옷 장수 = **臣(中品)** 「中藥 120종 爲臣, 主養性以應人」 — 앞의 피 흘리는 잘린 뿌리(핏방울 4)는 뜻 미상.
- (오른쪽 끝, 칸막이 너머) 갓·도포 선비 + 사람꼴 마른 뿌리 + 울타리 = 이웃 장면 몫, 「使(引經報使: 경계를 넘는 사신)」 정도로만 추정.
- 바닥의 젖은 발자국 행렬(약 10개, 왼→오른쪽) = 行(單行?) 또는 應地.
- **관계(왕↔농부)**: 위계의 맨 위와 맨 아래 — 上(君·天)과 下(佐使·地)의 대비, 「主病之謂君, 佐君之謂臣, 應臣之謂使」. 왕+농부를 한 사람으로 묶으면 **神農(炎帝, 임금이자 농부)** → 神農本草經 365종(120+120+125).

**③ 뜻 모를 것·어색한 것**: 잘린 뿌리에서 피가 나는 것(相殺? 止血? 當歸頭?), 붉은 즙 그릇의 정체, 농부 뒤 약장 큰 문 하나가 열린 것과 아래 찬장 문이 열린 것(開?), 젖은 발자국의 출발점 불명, 칸막이와 울타리가 이중으로 선비를 막는 것(相反·相惡?), 서랍 이름표는 판독 불가 의사문자. 이어 붙인 흔적은 칸막이 선(x≈390~450) 좌우의 장면 단절 정도.

## 2단계 — 계통 (사전 요약을 읽은 뒤 다시 판독)

판정: 사전으로 **인물 넷이 五臟으로 확정**된다(초록 갑옷 장군=肝, 붉은 곤룡포 임금=心, 노란 밀짚모자 농부=脾, 흰 도포·갓 재상=肺; 옷차림은 사람 표지일 뿐). 1단계의 君臣佐使·三品 읽기는 버린다. 木→火→土→金 상생 순으로 늘어서 있으니 腎은 오른쪽 이웃 띠 몫으로 보인다.

**① 단원 1순위: 藏象(五臟의 생리) — 六節藏象論 「五臟 〇〇之本」** 45%. 근거: 藥欌(서랍마다 갈무리 = 藏)이 무대이고, 네 臟 앞에 **뿌리(本)가 하나씩, 모두 4개** 놓여 있다. 차순위 **血·津液과 臟腑(心主血·肝藏血·脾統血·運化水液)** 25%, **治則 補虛瀉實** 15%.

**② 인물·소품**
- **心(임금)** — 잔뿌리가 성한 싱싱한 뿌리 = 「心者 生之本, 神之變」. 붉은 즙이 가득 찬 그릇 = 補-b(血로 채워 줌) → 「其充在血脈」, 곧 心主血脈.
- **脾(농부)** — 갓 캔 뿌리를 두 손에 쥠(수확) = 「倉廩之本, 營之居」. 앞의 대나무 통(그릇)이 비면서 물이 탁자 아래로 쏟아짐 = 瀉-b + 下 → 「名曰器, 轉味而入出」, 곧 水濕을 덜어 내리는 運化.
- (왼쪽 끝) **肝(장군)** — 잘린 뿌리 머리에서 피(핏방울 4) = 本 + 血 → 「罷極之本 … 以生血氣」, 곧 肝藏血.
- (오른쪽 끝) **肺(재상)** — 울타리 안의 마른 뿌리 = 「氣之本, 魄之處」. 울타리는 겉을 둘러막는 「其充在皮」로 추정. 칸막이는 사전의 惡(가리개)일 수 있으나, 막아 선 해로운 것이 보이지 않는다.
- **관계(心→脾)**: 火生土, 곧 心이 脾의 母다. 같은 계산대에서 血을 채우는 心과 水를 덜어 내는 脾가 맞서 있어 「心主血 ↔ 脾 生化之源·運化」를 보여 준다.

**③ 잔결**: 바닥을 가로지르는 물 발자국 줄(약 12개)은 사전에 없다. 陽卦·陰卦는 八卦 병풍 무대 전용이고 문으로 가는 줄도 아니므로 해당하지 않는다. 아래 찬장 문은 열렸으나 비어 있어(가마니 없음) 藏은 아니다. 「뿌리 = 本」은 사전에 없는 내 추정이다. 피를 흘리는 쪽이 같은 뿌리를 둘로 자른 머리 조각뿐인 까닭은 풀리지 않는다.
