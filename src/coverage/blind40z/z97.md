# z97 판독

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원 1순위: 臟象(五臟 — 肺·脾) 35%.** 차순위 **氣의 생성·升降出入** 25%, **四象醫學**(李濟馬 차림 + 人蔘·熟地黃) 15%, **補益方(兩儀膏·瓊玉膏류)** 10%.

**② 인물**
- 왼쪽 **흰 도포·검은 갓 선비 = 肺**. 흰 옷 = 白(金). 넓은 갓 챙 = 덮개 = **肺爲華蓋**(가장 위에서 덮음). 그를 둘러싼 나무 울타리(앞 말뚝 6개 + 옆·뒤로 이어짐) = 衛外·藩籬 = **肺主皮毛, 衛氣를 宣發해 겉을 지킴**. 갓끈·수염의 검정은 아래의 腎(金生水, 肺爲氣之主·腎爲氣之根) 쪽으로 이어지는 듯하지만 확실하지 않다.
- 오른쪽 **노란 옷·밀짚모자 아이 = 脾**. 노랑 = 土. 도르래(=樞)에 걸린 줄을 아래로 당겨 묶은 자루(=水穀精微)를 위로 올린다 = **脾主升淸·升擧**. 줄을 내리면 짐이 오르는 장치라서 **脾升胃降, 中焦는 升降의 樞紐**라는 뜻이 함께 실린다.
- 소품(카운터): **人蔘**(흙 묻은 뿌리. 흙 = 土. 補脾益肺·大補元氣. 두 인물을 함께 보함), **熟地黃**(검고 윤기 나는 덩이. 黑 = 腎, 補血·塡精), **꿀 숟가락**(甘 = 脾의 맛. 補中·潤肺·緩急). 배경 百子欌은 약방이라는 무대다.
- **관계**: 아이가 자루를 선비 쪽 위로 올림 = **脾氣散精, 上歸於肺**(素問 經脈別論) = 土生金·培土生金. 脾에서 올린 水穀之氣와 肺가 받은 淸氣가 합쳐 後天之氣(宗氣)가 된다.

**③ 잔결**: 서랍 이름표는 가짜 글자라 읽을 수 없다. 왼쪽 아래 바닥의 젖은 맨발 자국은 이웃 띠의 몫이거나 濕(아래부터 받음)으로 보인다. 선비 칸(百子欌 배경·낮은 바닥)과 아이 칸(흰 회벽·높은 선반)은 배경과 지면 높이가 달라 **이어 붙인 흔적**이 보인다. 아이 발치 선반 위로 갈색 덩이 끝이 살짝 비친다(熟地黃이 복제된 이음 자국). 熟地黃이 누구 몫인지는 불분명하다. 카운터 앞면과 바닥은 비어 있다.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원 1순위: 五臟苦欲補瀉(藏氣法時論 — 五味로 五臟을 補瀉) 30%.** 차순위 **宣明五氣**(五味所入·五臟所惡) 20%, **臟象 脾·肺** 20%, **本草 歸經·五味** 15%. 사전으로 두 인물이 肺·脾로 확정되지만, 이 둘은 여러 판에 두루 나오는 인물이라 단원을 정하지는 못한다. 단원을 가르는 것은 소품 글자(甘·補-b·收·地黃)다.

**② 인물**
- **흰 도포 재상 = 肺**(확정). 사전 규칙상 사람이 쓴 갓은 옷차림일 뿐 太도 아니고 1단계에서 읽은 華蓋도 아니다. 1단계의 華蓋 독해는 철회한다. 그를 둘러싼 울타리는 **惡**(해로운 것과 사람 사이를 막은 가리개)일 때만 뜻을 진다. 이 경우 **肺惡寒**이 되는데, 띠 안에는 막을 대상(눈송이 = 寒)이 없다. 왼쪽 이웃 띠에 있다면 성립하고, 없다면 「담 안쪽 = 內」에 그친다.
- **노란 밀짚모자 농부 = 脾**(확정. 그림은 소년이다). 그가 끌어올리는 **아가리를 끈으로 조인 삼베 자루 하나 = 收**이고, 곧게 위로 솟으니 **上**이 더해진다. 「脾가 收를 올린다」는 바로 읽히지 않는다. 가장 나은 풀이는 五化 순서 化(脾·土)→收(肺·金), 곧 土生金이다. 1단계의 「脾主升淸·升擧」는 사전 밖 독해로 남는다.
- 소품: **꿀 숟가락 = 甘**이다. 가득 차 넘치는 그릇이므로 **補-b**(채워 주는 것 = 甘)가 겹쳐 **脾 — 甘入脾·脾欲緩 急食甘以緩之·甘補之(苦瀉之)**가 된다. **검붉은 뿌리 조각 = 地黃**은 사전에 있는 글자지만 이 띠에서 누구 몫인지 불분명하다. **흙 묻은 人蔘**은 사전에 없어 1단계 그대로 補脾益肺로 읽는다.
- **관계**: 脾(土)가 收를 金 쪽으로 넘김 = **土生金(母子)**. 人蔘이 두 사람 사이에 놓여 脾·肺를 함께 補한다.

**③ 잔결**: **收 자루를 脾가 끌어올림**(肺欲收와 자리가 엇갈린다). 오른쪽 이웃(心苦緩 急食酸以收之?)의 몫일 수 있다. 울타리가 惡이라면 띠 안에 해로운 것이 없다. **地黃**과 **人蔘**이 왜 여기 있는지 사전으로 풀리지 않는다. 바닥의 젖은 발자국은 八卦 무대가 아니므로 陽卦·陰卦가 아니고, 누구의 발밑도 아니므로 內濕도 아니다(이웃 몫). 선비 칸과 소년 칸은 배경(百子欌·회벽)과 지면 높이가 달라 이은 흔적이 있다.
