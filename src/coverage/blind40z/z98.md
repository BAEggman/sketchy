# z98 판독

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원**: **臟象(五臟 — 脾·肺)** 40% / 차순위 **氣(精氣神 — 氣의 升降·衛)** 25%, **補氣藥(人蔘·黃芪·飴糖·蜂蜜)** 20%. 배경 약장(百子櫃)은 무대(한약방)일 뿐 단원 표지로 보지 않음.

**② 인물**
- 오른쪽 노란 옷 + 밀짚 삿갓 소년 = **脾(土)**. 노랑=色黃, 농부 삿갓=土·倉廩之官(곡식 자루), 도르래로 자루를 끌어올림=脾主升淸·升擧(내장 하수 방지), 줄 두 가닥 오르내림=脾升胃降·氣機升降의 樞紐(도르래=樞). 앞의 엿(飴)·꿀 숟가락=味甘(甘入脾), 숟가락에서 흘러 고인 꿀=在液爲涎. 자루 1개·도르래 1개·줄 2가닥.
- 왼쪽 갓 쓰고 흰 도포·염소수염 선비 = **肺(金)**. 흰옷=色白, 상투 갓·선비=相傅之官(治節), 앞 울타리(앞 말뚝 6개 + 뒷울타리로 둘러쌈)=衛外·皮毛가 몸의 藩籬, 수염=其華在毛. 앞 흙 묻은 人蔘(人形 뿌리)=補脾益肺.
- 관계: 흙 위 인삼이 선비 앞에 = **培土生金(土生金, 脾는 肺의 母)**; 脾가 끌어올린 精이 위로=脾氣散精 上歸於肺; 둘이 합쳐 宗氣(肺 淸氣+脾 水穀之氣).

**③ 뜻 모를 것·어색한 것**: 약장 서랍 수(3열×6행 남짓)는 의미 미상. 엿 덩어리 왼끝의 접힌 주름(입술? 其華在脣?) 불확실. 엿·숟가락 둘레의 흰 테두리 점들 = 오려 붙인 흔적. 약장 배경이 소년 머리 뒤에서 끊기고 맨 회벽으로 바뀜 = 두 장면 이음선. 바닥 왼아래 은빛 젖은 발자국·왼쪽 끝 기둥은 이웃 띠 몫.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원**: **臟象(五臟 系統 — 肺·脾)** 45% / **五行 相生(培土生金)** 20% / **藏氣法時論 五臟苦欲補瀉** 15%. 사전으로 인물 둘은 확정됐지만, 판 전체 문법(약방 계산대에 臟마다 놓인 것)은 사전만으로 갈리지 않는다.

**② 인물(사전으로 확정)**
- 노란 밀짚모자 농부 = **脾** (옷 노랑 = 五色 黃). 삿갓 모양은 다시 읽지 않음 → 1단계의 「삿갓=土·농부」 철회. 끈으로 아가리 조인 삼베 자루 1개 = **收**. 그것을 도르래로 끌어올림 = 脾氣主升·升擧(내려앉지 않게 붙들어 올림). 나무 숟가락에 가득 찬 꿀 = **甘**(補-b: 甘으로 채움 → 甘入脾·甘補). 반들반들 닫힌 윤곽의 도톰한 덩이 = **肌**(脾主肌肉) + 광택 **華**, 왼끝 어두운 타원 구멍 = **口**(舌 갈림: 구멍만 보이면 脾) → 開竅於口·其華在脣.
- 흰 도포·검은 갓 재상 = **肺** (흰 = 五色 白). 갓은 옷차림이라 太·華蓋로 읽지 않음 → 1단계의 「갓=華蓋」 철회. 둘러친 울타리 = 담 → 肺가 **담 안쪽(內)**. 사전의 惡(가리개)은 「해로운 것」이 맞은편에 있어야 하는데 앞에는 인삼뿐이라 조건 불충족.
- 관계: 脾가 金의 化인 **收**를 위로 올려 보냄 + 흙 위 인삼이 肺 앞 = **土生金(脾=母 → 肺=子), 培土生金**; 脾氣散精 上歸於肺.

**③ 남는 것**: 인삼(사전에 없음 — 새 글자? 補氣·補脾益肺), 도르래(사전에 없음, 升), 울타리(惡/內 사이 미정), 숟가락 밖으로 고인 꿀(盛? 涎?), 脾 농부가 소년 크기로 작아짐(「크기 바뀜이 사실을 진다」면 子?), 엿·숟가락 둘레 흰 테 = 오려 붙인 흔적, 약장↔회벽 이음선.

**판정**: 사전 어휘로 인물·소품 4개(脾·肺·收·甘·肌/口)가 확정돼 1단계보다 잘 풀린다. 다만 收가 肺의 것인데 脾가 끌어올리는 구도라 「升擧」인지 「土生金」인지는 둘 다 남긴다.
