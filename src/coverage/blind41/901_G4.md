# 901 판독 (G4)

## 1단계 — 생판 (사전 없이)

**① 판 표제어**
- 1순위 **本草 총론 — 藥物 配伍(七情·十八反·十九畏)와 藥性** (40%)
- 2순위 **方劑 총론 — 君臣佐使(+炮製·煎服法)** (30%)
- 근거: 약방(百子櫃) 무대에 인물이 왕(익선관 홍룡포)·선비(갓)·장수(투구)·일꾼(밀짚모자) 네 신분 → 君·臣·佐·使. 바닥에 人參 상대 금기 3종(藜蘆 X·五靈脂 O·萊菔).

**② 인물별 (왼쪽부터)**
1. 밀짚모자 일꾼(인삼 쥠) — **使/單行(人參)**: 탁상 큰 인삼 1 → 獨參湯(單行).
2. 갓 선비(인삼 쥠, 손 주인 왕과 모호) — **臣/相須**: 같은 인삼을 여럿이 듦(동류 相須), 꿀단지+국자 → 甘·調和/蜜.
3. 볼 붉은 왕 — **君**: 검은 액체 잔 → 酒(얼굴 붉음)·酒製.
4. 검은 뿌리 쥔 왕 — **炮製**: 젖은 검은 덩이(泡·漂, 附子 減毒) / 불 위 솥(煮·炒, 장작 4) / 회색 재 더미(煅·炒炭) — 3가지 처리.
5. 녹색 갑옷 장수 — **佐(佐制)**: 소품 없음.
6. 왕(빈손) — **君**: 소품 없음.
7. 잎 달린 흰 뿌리 쥔 일꾼 — **相惡(人參惡萊菔子)**: 자른 무에서 붉은 즙(효능 손상)·잔뿌리 흰 뿌리(人參/生地)·붉은 액체 그릇·대나무통 물 쏟음(降/下).
8. 울타리 뒤 선비 — **禁忌**: 울타리 = 금지.
9. 도르래로 자루 올리는 일꾼 — **使(引經·升)**: 흙 묻은 마른 뿌리(生藥)·윤나는 적갈색 뿌리(紅參/熟地 蒸製)·꿀 숟가락(蜜炙).
- 선반: 김 나는 탕 그릇+수건 → 溫服·取汗.
- 바닥: X 친 검은 뿌리+연기 → **十八反(藜蘆)**, 원 안 날다람쥐+똥 4알 → **十九畏(人參畏五靈脂)**, 눈/소금 위 쓰러진 검은 복면·고글 인물(붉은 열기) → 毒이 꺾임(相殺?)·寒熱.

**③ 잔결**
고글 쓴 검은 잠수복 인물·눈밭·열린 아래 찬장과 발자국 약 12개가 뜻 불명. 4번째 칸 장수·6번 왕 빈손. 위쪽 서랍 하나 열림. 2번 인삼 쥔 손 주인 모호. 중앙 탁자 이음선(x≈1040)과 칸막이 2장 → 4구역 이어 붙임 흔적. 도르래 줄이 상단 프레임에 잘림.

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**바뀐 점**: 옷차림은 君臣佐使가 아니라 五臟(사전: 옷 모양을 다른 글자로 다시 읽지 말 것). 장군=肝, 임금=心, 밀짚 농부=脾, 흰 도포 재상=肺, 바닥에 누운 잠수복·고글=腎. 1단계의 君臣佐使 해석은 버린다. 장부 인물이 약재를 쥔 꼴이 되므로 「약이 어느 장으로 들어가나」, 곧 歸經으로 더 잘 풀린다.

**① 판 표제어**
- 1순위 **本草 총론 — 性味·歸經(+升降·配伍禁忌)** (45%)
- 2순위 **補益藥 人參·地黃(生/熟)의 性味歸經 비교** (25%)

**② 인물별 (왼쪽부터)**
1. 脾(농부) — **人參 歸脾**: 쥔 인삼, 탁상 인삼 1.
2. 肺(재상) — **人參 歸肺**: 인삼(쥔 손 주인 모호), 꿀단지 = 甘.
3. 心(임금, 볼 붉음) — **人參 歸心·微苦**: 검은 커피 잔 = 苦. 1~3을 합치면 人參 = 甘·微苦, 歸 脾·肺·心(3경).
4. 心(임금) — **地黃 歸心**: 쥔 검붉은 뿌리 = 地黃. 젖은 검은 덩이(黑+津 = 蒸해 검어진 熟地?), 솥 = 불꽃 熱+김 氣+찬 죽(補) → 蒸製, 회색 더미(접시 없음 → 鹹 조건 불충족, 재 = 衰?).
5. 肝(장군) — **歸肝**: 소품 없음.
6. 心(임금) — **歸心**: 소품 없음.
7. 脾(농부, 잎 달린 생뿌리) — **鮮地黃 = 凉血·生津**: 자른 뿌리 붉은 방울 = 血, 붉은 그릇 = 血, 대통에서 쏟아지는 맑은 물 = 津+下(瀉-b?). 5·6과 합치면 歸 心·肝.
8. 肺(재상, 울타리 안쪽) — **內**: 담 안쪽 = 內(갈림: 담이면 內).
9. 脾(농부, 도르래) — **上(升)·收**: 끈 조인 삼베 자루 = 收를 위로 올림. 탁상: 흙 묻은 마른 뿌리(生), 윤나는 검붉은 덩이 = 地黃(熟), 꿀 숟가락 = 甘 → 熟地黃 味甘.
10. 腎(잠수부, 누움) — **歸腎**: 눈·얼음 위(寒/陰) + 몸의 붉은 기운(熱·血?) → 腎에 열을 넣음(滋陰/溫腎?), 젖은 발자국 줄이 열린 찬장 문으로(門·內).
- 선반: 김 나는 국 사발 = 補+氣, 수건(김 없음 → 溫 아님).
- 바닥 사전 밖: X 친 검게 탄 뿌리+연기(十八反 藜蘆? 衰?), 원 속 날다람쥐+똥 4알(十九畏 五靈脂).

**③ 잔결**
날다람쥐·X 뿌리는 사전에 없는 신규 기호다. 3번 임금의 붉은 볼, 9번 收 자루를 끌어올리는 뜻(升 하나인지), 회색 더미(鹹·재), 腎의 붉은 기운이 갈리지 않는다. 心이 3명, 脾가 3명이라 장부를 고르는 기준이 흔들린다. 4구역 칸막이·탁자 이음선이 보이고, 위쪽 서랍 하나와 아래 찬장 문이 열려 있다.
