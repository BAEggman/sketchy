# 901 판독 (H4)

## 1단계 — 생판 (사전 없이)

**① 판 표제어**
- 1순위: **補虛藥(補益藥) — 補氣·補血 대표약 4味(人蔘·地黃·當歸·黃芪)** (55%)
- 2순위: **氣血雙補 方劑 구성약(八珍湯·十全大補湯)** (15%)
- 근거: 약재방 계산대 4칸에 뿌리약 4종, 인물 옷색이 五色(황·백·적·청·흑) = 脾·肺·心·肝·腎(倉廩·相傅·君主·將軍·作強之官)으로 읽혀 각 칸 인물 = 歸經.

**② 인물·구역 (왼→오)**
- [칸1] 농부1(黃=脾)·선비1(白=肺)·뺨 붉은 왕1(赤=心): **人蔘** — 歸經 脾·肺·心 3개, 꿀단지=甘, 작은 검은 잔=微苦(味 2), 왕의 붉은 뺨=微溫, 인삼 3뿌리=大補元氣. 바닥: 연기 나는 검은 뿌리 ✕=**藜蘆 反(十八反)**, 날다람쥐+똥 ○=**五靈脂 畏(十九畏)**.
- [칸2] 왕2(心)가 검고 비틀린 마른 뿌리 듦: **地黃(生→熟)** — 솥에 찜(蒸, 酒蒸·九蒸九曬)→물기 젖은 검은 덩이=熟地黃(滋陰·滋膩), 회색 더미=砂仁(膩 방지) 또는 炭. 바닥의 흑의 잠수부(黑=腎): 눈밭에 잠든 채 손바닥·발바닥·몸에서 붉은 열=五心煩熱·骨蒸, 잠자며 젖음=盜汗, 젖은 발자국 떠남=遺精/津液 유실 → 肝腎陰虛(熟地 적응증).
- [칸3] 장군(靑=肝)·왕3(心)·농부2(脾, 잎 달린 흰 뿌리 全草): **當歸** — 歸經 肝·心·脾 3개; 잘린 머리토막 피 흘림=歸頭(止血), 몸·꼬리토막=歸身·歸尾(補血·活血), 붉은 피 사발=補血, 대나무관 물 쏟음=潤腸通便.
- [칸4] 울타리 뒤 선비2(肺)·도르래로 자루 올리는 소년농부3(脾): **黃芪** — 歸經 脾·肺 2개, 울타리=益衛固表(止汗), 도르래 들어올림=升陽擧陷, 흙 묻은 뿌리=生用, 윤나는 적갈색 덩이+꿀숟갈=蜜炙(炙黃芪 補中).
- 상단 선반: 김 나는 탕약 사발+수건 = 湯劑/補藥(溫服?).

**③ 잔결**: 칸2–3 사이 계산대 이음 선(장군이 이음선 위에 서서 地黃·當歸 어느 쪽 歸經인지 모호), 회색 더미 뜻 불명(砂仁/炭/白髮), 윤나는 적갈색 덩이(炙黃芪? 肉桂? 阿膠?) 불명, 열린 장 서랍문·계산대 아래 열린 문 뜻 불명, ✕와 ○의 구분 의미(反 vs 畏?) 불분명. 프레임 잘림 없음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

사전이 1단계의 인물 읽기를 그대로 확인함(장군=肝·임금=心·농부=脾·흰 도포 재상=肺·잠수부=腎). 새로 풀린 것: 꿀단지=甘, 질그릇 잔 검은 커피=苦, 상단 찰랑 국물 사발=**補**(김=氣), 임금이 쥔 검붉은 뿌리 조각=**地黃**(확정), 붉은 것=血, 가득 찬 그릇=補-b, 끈 조인 삼베자루=收, 두 배 큰 것=大, 손·발바닥 붉음=五心煩熱(사전 각주가 직접 언급).

**① 판 표제어**
- 1순위: **補益藥(補虛藥) — 人蔘·地黃·當歸·黃芪, 각 칸 인물=歸經** (70%) — 상단 「補」 사발이 단원 표지.
- 2순위: **氣血雙補 方藥(八珍·十全大補 계열) 구성약** (10%)

**② 인물·구역 (왼→오)**
- 칸1 농부(脾)·재상(肺)·붉은뺨 임금(心) = **人蔘**: 歸脾·肺·心 3, 味 甘(꿀단지)·苦(커피잔) 2, 탁자 인삼이 쥔 것의 두 배=大 → 大補元氣. 바닥 ✕ 연기 나는 검은 뿌리=藜蘆 反, ○ 날다람쥐 똥=五靈脂 畏(○는 「현대엔 병용 예 있음」일 수도).
- 칸2 임금(心) = **地黃**: 검붉은 뿌리 조각(사전 확정)을 心이 쥠=歸心, 불꽃(熱)+김(氣) 솥=蒸製→熟, 물방울(津)·고인 물(陰) 젖은 검은 덩이=滋陰·生津. 바닥 잠수부(腎): 손발바닥 붉음=五心煩熱, 밑의 눈이 녹아 줄어듦=陰 消耗 → 腎陰虛 = 地黃 歸腎·滋腎陰.
- 칸3 장군(肝)·임금(心)·농부(脾, 當歸 全草) = **當歸**: 歸肝·心·脾 3, 잘린 뿌리에서 흐르는 血=活血, 붉은 것 가득 찬 사발(補-b)=補血, 대나무관 물이 아래로 쏟아짐(下·通)=潤腸通便(또는 瀉-b 利水).
- 칸4 재상(肺, 울타리 안)·소년농부(脾, 도르래) = **黃芪**: 歸肺·脾 2, 담 안에 감싼 肺=益衛固表, 收 자루를 끌어올림=升陽擧陷+收(斂汗·固攝), 꿀숟가락=甘.
- 상단: 국물 사발=補(+김=氣), 곁 수건=溫(김 닿는 천이면) → 溫補?

**③ 잔결**: 잿빛 더미·윤나는 검붉은 덩이(칸4)·젖은 발자국 줄·열린 서랍문/계산대 문 2곳·임금1 붉은 뺨은 사전에 없어 뜻 불명. 칸2–3 계산대 이음선에 장군이 걸쳐 서서 地黃(肝腎)·當歸(肝心脾) 중 어디 몫인지 갈림. 사전 어휘로 地黃 칸과 味·補가 풀려 1단계보다 확실히 잘 읽힘. 프레임 잘림 없음.
