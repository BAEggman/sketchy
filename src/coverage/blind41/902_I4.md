# 902 판독 — I4

## 1단계 — 생판 (사전 없이)

**① 판 표제**
- 1순위 **本草總論 — 配伍(七情)·用藥禁忌(十八反·十九畏)·炮製·煎服法** (40%)
- 2순위 **補氣藥 — 人蔘 중심 각론(人蔘·附子·黃芪/地黃 配伍)** (25%)
- 근거: 百子欌 약방 무대, 인삼 4뿌리 + 인삼의 금기 짝(藜蘆 X·五靈脂 ○·무)이 한 판에 몰림, 날것/찐것/꿀 바른 것 대비.

**② 인물 (왼→오, 9명)**
1. 밀짚모자 농부·인삼 들고, 앞 통인삼, 발밑 연기 나는 검은 잔털뿌리에 붉은 X → **相反(人蔘 反 藜蘆, 十八反)** — 2개.
2. 갓 쓴 선비·인삼, 앞 꿀단지, 발밑 날다람쥐+똥 붉은 원 → **十九畏(人蔘 畏 五靈脂)** — 3개(인삼·甘味·五靈脂).
3. 볼 붉은 왕·인삼, 앞 검은 탕 한 잔 → **單行(獨蔘湯·大補元氣)** — 3개(君·元氣회복 홍조·단방 한 잔).
4. 왕·생강편 들고, 앞 물에 젖은 혹 달린 검은 덩이뿌리(附子/烏頭)·고추 종지·불 위 솥 → **相殺·相畏(生薑이 毒을 누름) + 先煎·久煎** — 4개(생강·浸泡·辛熱·久煎).
5. 녹색 갑옷 무장, 앞 회색 부순 더미, 발밑 검은 잠수복 사내가 눈밭에 엎드림(머리·팔꿈치·무릎 붉고 손발 파람) → **附子 回陽救逆(亡陽·四肢厥冷, 亂世良將)** — 3개.
6. 왕, 앞 잎 달린 무 반토막 + 잔뿌리 흰 뿌리 반토막, 그 사이 핏방울 → **相惡(人蔘 惡 萊菔)** — 2개.
7. 농부·잎 달린 생뿌리 다발, 앞 붉은 즙 사발·물 쏟는 대통 → **鮮品 搗汁·沖服(竹瀝 등)** — 3개.
8. 울타리 뒤 선비, 앞 흙 묻은 마른 뿌리 → **生用(날것) / 固表(屛風)** — 2개.
9. 도르래로 자루 끌어올리는 소년, 앞 윤나는 적갈색 찐 뿌리·꿀 숟가락 → **炮製(蒸·蜜炙)·升擧** — 3개.

**③ 잔결**
- 중앙 선반의 김 나는 사발+걸린 수건(另煎? 包煎? 溫服?) 뜻 미상.
- 붉은 X(藜蘆)와 붉은 ○(五靈脂)의 구분 기준 미상.
- 위 열린 서랍, 아래 열린 찬장문에서 오른쪽으로 이어지는 젖은 발자국 뜻 미상.
- 회색 더미(灰·鹽·打碎 광물?) 미정. 중앙 카운터 x≈1045 이음선에서 두 판이 이어붙은 듯. 왕이 셋이라 인물-표제 대응이 겹침.

## 2단계 — 계통 (사전 적용 후 재판독)

사전의 핵심: 인물 = 五臟(농부 脾·재상 肺·임금 心·장군 肝·잠수부 腎), 꿀단지 = 甘, 질그릇 검은 커피 = 苦, 접시 고추 = 辛, 불꽃 = 熱, 붉은 것 = 血, 찬 국 사발 = 補, 가득 찬 그릇 = 補-b. 이렇게 읽으면 **약재를 쥔 장부 = 歸經**이 되어 1단계의 「七情 줄세우기」보다 훨씬 깔끔하게 풀린다. 1단계 답은 버린다.

**① 판 표제**
- 1순위 **溫補 대표약 각론 — 人蔘·附子·當歸·黃芪의 性味·歸經·效能** (55%)
- 2순위 **本草 藥性論 — 性味(五味)·歸經·炮製** (25%)
- 근거: 한가운데 선반의 김 오르는 국 사발 = 補(옆 수건 = 溫?)이 판 깃발. 칸마다 약 하나, 그 약의 歸經 장부가 서 있음.

**② 인물 (왼→오)**
1. 농부(脾) **人蔘 歸脾經** — 3개: 人蔘(쥔 것·통인삼), 歸脾, 발밑 검은 잔털뿌리 X = 反藜蘆.
2. 재상(肺) **人蔘 歸肺經** — 3개: 歸肺, 꿀단지 = 甘, 날다람쥐 ○ = 畏五靈脂.
3. 임금(心) **人蔘 歸心經** — 3개: 歸心, 커피 잔 = (微)苦, 홍조 = 補心氣(추정).
4. 임금(心) **附子 歸心經** — 5개: 附片, 젖은 혹 달린 덩이뿌리(附子·浸漂), 고추 = 辛, 솥 밑 불꽃 = 大熱(先煎·久煎), 회색 굵은 더미 = 鹽附子?
5. 잠수부(腎) **附子 歸腎經·回陽救逆** — 3개: 歸腎, 몸 밑에 밴 눈·서리 = 內寒, 검푸른 손발 끝 = 厥(四肢厥冷).
6. 장군(肝) **當歸 歸肝經** — 2개: 歸肝, 잎 달린 뿌리머리 토막 + 핏방울 = 血(歸頭?).
7. 임금(心) **當歸 歸心經·補血** — 2개: 歸心, 붉은 것이 가득 찬 사발 = 補-b 補血.
8. 농부(脾) **當歸 歸脾經** — 3개: 歸脾, 잎 달린 全當歸, 대통 물이 모서리 아래로 쏟아짐 = 下(潤腸通便).
9. 재상(肺) **黃芪 歸肺經·益衛固表** — 3개: 歸肺, 울타리 = 바깥을 막는 가리개(固表), 흙 묻은 生黃芪 = 生用.
10. 소년 농부(脾) **黃芪 歸脾經·升陽擧陷** — 4개: 歸脾, 도르래로 끌어올림 = 升擧, 검붉게 윤나는 뿌리 + 꿀 숟가락 = 蜜炙(炙黃芪), 甘.

**③ 잔결**
- 붉은 X·붉은 ○는 사전에 없다(反/畏 구분 기준 추정).
- 자루는 사전상 收인데 도르래로 들려 升과 부딪친다. 검붉은 뿌리는 사전상 地黃인데 꿀 숟가락이 붙어 炙黃芪로 읽힌다.
- 회색 더미는 접시가 없어 鹹 꼴이 아니다. 수건에는 김이 없어 溫 꼴이 덜 갖춰졌다.
- 附子의 歸脾 장부가 없고, 잠수부의 붉은 기운(머리·팔꿈치·무릎)은 사전에 없다.
- 열린 찬장문과 그 앞의 젖은 발자국 줄, 위쪽의 열린 서랍은 뜻을 알 수 없다(附子 走而不守?).
- 중앙 카운터 x≈1045에 이음선이 있다.
