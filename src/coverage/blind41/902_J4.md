# 902 판독 (J4)

## 1단계 — 생판 (사전 없이)

**① 판 표제어**
- 1순위: **補虛·溫裏 대표약 4종 각론(人蔘·附子·當歸·黃芪) — 歸經·효능·금기** (40%)
- 2순위: **本草總論(藥性理論: 歸經·配伍禁忌·炮製·升降浮沈)** (30%)
- (참고 3순위: 五參 配 五臟 — 黃參=人參·白參=沙參·赤參=丹參·黑參=玄參, 15%)
- 근거: 약장(百子櫃) 배경, 인물이 색·신분으로 五臟을 고정(노랑 농부=脾, 흰 선비=肺, 붉은 임금=心, 녹색 장군=肝, 검은 잠수부=腎) → 인물 = 歸經으로 읽힘. 칸막이로 3대(중앙대는 이음매로 2분) = 4구역.

**② 구역·인물별 (왼쪽부터)**
- A구역(농부·선비·임금, 셋 다 인삼을 듦) = **人蔘** — 歸 脾·肺·心(3). 꿀단지=甘, 검은 사발=微苦(또는 차 忌). 바닥: X 친 검은 털뿌리+연기=反 藜蘆, 빨간 원 속 날다람쥐+똥=畏 五靈脂. 임금 홍조=大補元氣(?). → 사실 6개.
- B구역(약편을 맛보는 임금) = **附子** — 歸 心(+아래 잠수부=腎). 혹 달린 검은 덩이뿌리+물웅덩이=鹽附子 浸漂, 화로 위 냄비=先煎·久煎(補火), 고추=辛·大熱, 회색 모래더미=砂燙 炮製, 임금이 편을 씹음=口嘗 無麻感 확인. 잠수부(검정·얼음 위 웅크림·눈 감음·손발 청색)=亡陽/少陰 厥逆 蜷臥 但欲寐 → 回陽救逆. → 7개.
- C구역(장군·임금·당귀 풀 든 농부) = **當歸** — 歸 肝·心·脾(3). 잎줄기 달린 잘린 머리+핏방울=歸頭 止血, 꼬리 많은 몸통=歸身 補血·歸尾 破血, 붉은 국 그릇=補血, 대통에서 쏟아지는 물=潤腸通便. → 7개.
- D구역(울타리 뒤 선비·도르래 줄 당기는 아이) = **黃芪** — 歸 肺·脾(2). 울타리=益衛固表(止汗), 자루를 끌어올림=升陽擧陷, 꿀 숟가락=蜜炙(炙黃芪 補中益氣), 윤나는 갈색 덩이=炙品(또는 紅蔘?), 흙 묻은 뿌리=生用(?). → 5~6개.

**③ 잔결**
- 뜻 미상: 맨 위 선반의 김 나는 사발+수건, 회색 더미(모래/재), 열린 찬장 문+물 발자국, 잠수부 머리의 붉은 빛, 윤나는 적갈색 덩이(紅蔘? 熟地?), 빨간 원(O)이 '畏'인데 금기 표시가 X와 달라 어색.
- 장군이 B/C 경계에 서서 소속 모호. 중앙 카운터 x≈1045에 세로 이음매(상판·앞판까지 직선) — 이어 붙인 흔적 가능. 프레임 잘림 없음.

## 2단계 — 계통 (blind6 사전 어휘로 재판독)

**① 판 표제어**
- 1순위: **補益·溫補 要藥 각론 — 人蔘(補氣)·附子(溫陽)·當歸(補血)·黃芪(升陽固表)의 歸經·性味·효능** (50%)
- 2순위: **本草 藥性論(五味·歸經·配伍禁忌·炮製)** (25%)
- 사전으로 굳어진 것: 다섯 인물 = 五臟 확정(장군 肝·임금 心·농부 脾·재상 肺·잠수부 腎) → 인물 = 歸經 독법이 A·C구역에서 정확히 맞음. 맨 위 선반 = 찰랑찬 따뜻한 국(補)+서린 김(氣)+곁의 천(溫) → 판 머리말 「溫補/補氣」.

**② 구역·인물별**
- A **人蔘**: 농부=脾·재상=肺·임금=心 각자 인삼 → 歸 脾肺心(3). 나무국자 꿀단지=**甘**, 김 없는 질그릇 검은 커피=**苦** → 性味 甘·微苦(2, 사전과 정확히 일치). 바닥 X 藜蘆=反, O 五靈脂=畏(2). → 7개.
- B **附子**: 임금(心)이 편을 맛봄. 접시 위 고추=**辛**, 불꽃=**熱**(大熱), 김=氣, 회색 굵은 알갱이 더미=소금(鹹 꼴이나 접시 없음 → 鹽附子 재료로 읽음)+물에 담긴 혹 덩이=鹽附子 浸漂·先煎. 잠수부=**腎**, 검푸른 손발=**厥**, 눈밭=寒, 웅크려 누움 → 亡陽 寒厥 回陽救逆(歸 心·腎). → 7~8개.
- C **當歸**: 장군=肝·임금=心·당귀풀 든 농부=脾 → 歸 肝心脾(3). 붉은 국 가득한 그릇=**補-b(血)**=補血, 잘린 머리+붉은 방울=**血**(歸頭 止血/頭身尾), 속 빈 대통(**通**)에서 맑은 물(**津**)이 아래로 쏟아짐(**下**) → 潤腸通便. → 7개.
- D **黃芪(?)**: 재상=肺·소년 농부=脾 → 歸 肺脾(2). 아가리 묶은 삼베 자루=**收**를 도르래로 끌어올림(上) → 升陽擧陷+斂汗, 재상 앞 울타리=**惡**(가리개)·또는 담 안(內)=衛表 固護, 꿀 숟가락=甘/蜜炙. 단, 윤나는 **검붉은 뿌리 조각=地黃**(사전 등재) + 흙 묻은 생뿌리=生地黃 → 熟地黃 가능성과 충돌. → 5~6개.

**③ 잔결**
- D구역: 地黃 기호가 黃芪 독법(肺·脾 인물)과 어긋남 — 미해결. 꿀이 단지 아닌 숟가락(甘 변형?).
- 회색 더미가 鹹의 「접시 위」 조건 불충족. 藜蘆·五靈脂·X/O 표지는 사전 밖.
- 열린 찬장 문(門/內?)+물 발자국 줄, 잠수부 머리·팔꿈치의 붉은 빛, A 임금 홍조(面은 광택만이라 해당 없음) — 뜻 미상.
- 중앙 카운터 세로 이음매(이어붙임 의심), 장군의 구역 소속 모호. 프레임 잘림 없음.
- 판정: 사전 어휘로 人蔘(甘·苦)·當歸(補血·津·通·下)·腎厥은 더 잘 풀림. 1단계 골격 유지, 확신 상승.
