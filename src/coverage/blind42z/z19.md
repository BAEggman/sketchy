# z19 판독

## 1단계 — 생판 (사전 열기 전, 그림만)

**① 단원** — **本草: 瀉下藥(攻下藥)** 55% / 차순위 **方劑 총론·煎藥法(先煎·後下)** 30% / **本草 淸熱藥** 10%.

**② 인물·소품·배경**
- 인물 1명(띠 왼쪽 가운데): 정수리 상투, 회청 저고리, 황토색 바지의 노인. 표제어 **大黃**(또는 대황을 달이는 사람). 노란 조각을 **이미 김이 오르는 탕관**에 떨어뜨리는 동작 = **大黃 後下**(마지막에 넣어 짧게 달여야 攻下力이 셈).
- 선반 위 통나무 2개(큰 것 1·작은 것 1, 단면이 샛노람) = 「큰(大)+노랑(黃)」 → **大黃**(조각의 출처).
- 탕관 2개 대비: 왼쪽(맑은 갈색·김) = 後下·短煎 → 瀉下 강 / 오른쪽(새까만 탕 속 노란 조각, 김 없음) = **久煎하면 瀉下力 약화**(또는 熟大黃 = 緩下). 화로 2·장작불 2.
- 선반 오른쪽 사발 1(검은 탕) = 완성된 湯劑, 혹은 沸湯泡服.
- 배경: 약장(百子櫃) 서랍 하나가 빠진 구멍에서 흙(土=腸胃)이 쏟아져 울타리를 부숨(왼 5·오른 3개 판, 부러진 가로대 1) = **破癥瘕積聚·推陳致新**(묵은 것을 밀어냄). 흙 속 자갈 = **燥屎**. 걸린 빗자루 1 = **蕩滌腸胃**.
- 관계: 사람이 1명뿐 — 실질 관계는 두 탕관 사이: 같은 약이 **煎法(後下 vs 久煎)에 따라 효력이 갈린다**.

**③ 어색·잔결** — 인물 성별 모호(상투+바지면 남자인데 얼굴이 여성적); 오른쪽 검은 탕이 久煎인지 熟大黃(酒蒸)인지 大黃炭인지 갈림; 사발의 역할(泡服?) 불분명; 오른쪽 가장자리 경사 지붕 기둥은 이웃 띠 몫으로 보임; 마른 풀 포기는 뜻 없음(燥?).

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원** — **本草: 瀉下藥(攻下藥)** 65% (사전으로 大·苦·瀉가 맞물려 오름) / **方劑 총론·煎藥法** 20%.

**② 다시 읽기**
- 통나무 2개 = **大**(같은 것 둘이 나란한데 하나가 두 배) + 샛노란 단면(黃) → **大黃** 확정. 1단계의 말장난 추정이 사전 항목으로 뒷받침됨.
- 선반 사발의 김 없는 검은 액체 = **苦**(질그릇 사발의 검은 커피, 김 없음 = 온전한 꼴) → 大黃 **味苦**. 1단계의 「완성 湯劑」는 버림.
- 걸린 짚 빗자루(손잡이 있고 이삭 없음 → 收 볏단 아님) = **瀉** → 瀉下·瀉火.
- 빠진 서랍(빈 그릇)에서 흙·자갈이 쏟아짐 = **瀉-b**(덜어낸 것 = 묵은 흙·자갈 = 積滯·燥屎) + **下**(아래로 쏟아짐) + 어두운 구멍 = **竅** → 下竅를 열어 **攻積導滯·通便**. 부서진 울타리로 안팎이 한 덩어리 = **通**(通腑).
- 인물 1명: 五行 다섯 인물(밀짚모자 등)이 아니므로 옷 색은 뜻을 안 짐 → 표제어는 **大黃 煎法**의 손. 끓는(김=氣 서린) 탕에 노란 조각을 넣음 = **後下**.
- 탕관 2개: 왼쪽 後下(김 = 氣 살아 있음, 瀉下力 강) / 오른쪽 검게 졸고 김 없음 = 오래 달여 氣가 빠짐 → **久煎하면 瀉下力 약화**(단 사전의 「久 = 셋 포갬」은 없음 — 약한 추정). 장작불 2 = 熱이라기보다 달임 불.
- 관계: 같은 大黃이 **煎法에 따라 효력이 갈림(後下 vs 久煎)**.

**③ 잔결** — 大黃의 **性寒**을 질 눈송이(寒)가 이 띠에 없음(이웃 띠 몫?); 자갈은 사전에 없음(燥屎 추정); 부서진 울타리를 傷으로 읽을지 通으로 읽을지 갈림(울타리는 사전 사물 아님 → 通 채택); 오른쪽 탕관이 久煎인지 熟大黃인지 미확정; 마른 풀 포기 뜻 없음.
