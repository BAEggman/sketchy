# z20 판독 (blind42z)

## 1단계 — 생판 (사전 없이)

**① 단원**: **本草 — 瀉下藥(攻下藥)** 55% / 차순위 **本草 — 淸熱(苦寒)藥** 20%. 배경 전체가 약장(百子櫃)이라 본초 단원은 확실하고, 띠의 사실들이 모두 「대황」 한 약으로 수렴한다.

**② 인물과 소품**
- 띠 안 인물은 1명: 쪽(상투)머리 노인, 회청 저고리·황토색 바지. 표제어 **大黃**을 달이는 사람으로 읽는다. 끓는 탕관(김 남)에 노란 절편을 *지금* 넣는 동작 = **後下**(대황은 공하용이면 나중에 넣음).
- 곁의 탕관 2개(셀 것: 2) = 煎法 대비. 왼쪽(호박색 탕, 이제 투입) = 後下 → 瀉下力 강. 오른쪽(검게 우러난 탕 속 노란 조각, 김 없음) = 久煎 → 瀉下力 약화(또는 검게 쪄 낸 **熟大黃** = 瀉下 완화·活血).
- 노란 단면의 통나무 2토막(큰 것·작은 것) = 약재 본체 **大黃**(黃의 색; 큰 토막 = 「大」). 2차 후보 **黃柏**(나무 껍질·노랑).
- 검은 탕 한 사발 + 눈송이 = 성미 **苦寒**(寒).
- 약장 서랍 한 칸이 뚫려 흙더미·돌이 쏟아져 나오고 울타리가 부서짐 = **攻積導滯·破癥瘕積聚**, 장군 대황의 **斬關奪門**(관문을 부수고 뚫음). 흙(土) = 脾胃·腸, 돌덩이 = 燥屎/積滯.
- 걸린 빗자루 = 本經 「**蕩滌腸胃, 推陳致新**」.
- 관계: 인물↔두 탕관 = 같은 약도 넣는 시점(後下 vs 久煎)에 따라 효력이 갈린다. 노인(陳)이 새 절편(新)을 넣는 것 = 推陳致新 겹침 가능.

**③ 잔결**: 눈송이는 손그림이 아닌 아이콘을 덧붙인 듯 화풍이 다름(이어 붙인 흔적). 인물 성별·머리(상투/쪽) 모호. 울타리 말뚝 수(좌5·우3~4)의 뜻 불명. 흙더미 위 풀포기 뜻 불명. 오른쪽 탕관 위에 김이 없음.

## 2단계 — 계통 (blind6 사전으로 다시 읽기)

**① 단원**: **本草 — 瀉下藥(攻下藥)** 70% (통합판이 「本草 寒涼(淸熱·瀉下)」일 가능성 20%). 사전 어휘로 1단계보다 더 단단히 풀린다 — 표제 **大黃**이 글자 단위로 조립된다.

**② 다시 읽기**
- 통나무 2토막: 「**大** = 같은 것 둘이 나란한데 하나가 두 배」 + 노란 단면(黃) → **大黃** 확정(1단계의 黃柏 후보 탈락).
- 검은 액체 질그릇 사발, 김 없음 = 「**苦**」(김 없는 검은 커피가 온전한 꼴). 곁 눈송이 = **寒**. 사람 곁이 아니라 사발 곁이라 병표지가 아니며, 갈림의 外寒/裏寒도 아니고 약성 → 性味 **苦寒**.
- 걸린 손잡이 달린 짚 빗자루 = 「**瀉**」(收의 볏단과 갈림 확인: 손잡이 있음). 1단계의 蕩滌 읽기는 瀉 한 글자로 정리됨.
- 약장 서랍 구멍(빈 그릇)에서 흙·돌이 쏟아져 담 밖으로 넘침 = 「**瀉-b**」(덜어낸 것 = 흙·돌 = 腸胃의 積滯·燥屎) + 「**下**」(쏟아짐) → **瀉下 攻積**. 담 안쪽(內)→바깥(外)으로 밀어냄 = 裏實을 밖으로. 부서진 울타리는 「破(積)·斬關奪門」으로 남지만 사전 미등재.
- 인물(1명, 오행 다섯 인물 아님 — 옷은 기호 아님): 표제어 **大黃 後下**. 이미 끓어 김(**氣**)이 오르는 탕관에 노란 절편을 떨어뜨림 = 「下」 → 나중에 넣어야 瀉下力이 산다.
- 오른쪽 탕관(김 없음, 검게 우러난 탕 속 조각) = 함께 오래 달인 것 → 瀉下力 약화(熟大黃 쪽). 두 탕관 크기는 같아 「大」가 아님. 화로 불꽃 = 熱(瀉熱)일 수 있으나 달이는 데 필요한 불이라 약하게만 본다.
- 관계: 띠 안 인물은 1명이라 인물 간 관계 없음. 인물↔두 탕관 = 같은 大黃이 煎法(後下 vs 久煎)에 따라 효력이 갈림.

**③ 잔결**: 눈송이가 아이콘처럼 화풍이 다름(덧붙임 흔적). 부서진 울타리·흙더미 위 풀포기는 사전에 없는 기호(傷은 「그 글자 사물」이 깨져야 하는데 담은 內·外 글자라 맞지 않음). 오른쪽 탕관의 뜻(久煎인지 熟大黃인지)이 한 가지로 고정되지 않음.
