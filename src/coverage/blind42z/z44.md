# z44 판독

## 1단계 — 생판 (기호 사전 없이)

**① 단원**: **本草 總論 — 配伍 七情·用藥禁忌(十八反·十九畏)** 1순위 (35%). 차순위 **本草 各論(補氣藥: 人參 중심)** 20%, **方劑 總論(君臣佐使·劑型·用量)** 15%. 근거: 배경이 백자장(藥欌) 약방, 탁자 위 약재·저울추, 탁자 밑 붉은 X(금기).

**② 인물과 소품**
- 왼쪽 밀짚모자·갈색 저고리 농부 = **神農**(嘗百草, 本草의 시조; 『神農本草經』 365種 — 上120·中120·下125) 또는 **臣·佐使**(下品, 아랫사람). 흰 알 하나를 들고 있음.
- 오른쪽 갓·흰 도포 선비 = **君**(上品 — 養命·無毒) 또는 **醫(用藥者)**. 같은 흰 알 하나.
- 관계: 둘이 나란히 **같은 흰 알 1개씩** 들어 보임 → **相須**(같은 계열 두 약을 함께 써 효능 증강). 신분 차(선비>농부)를 읽으면 **相使**(主藥 + 輔藥).
- 탁자 왼쪽 흰 뿌리(蘆頭 있음, 표면 검은 점) = **人參**; 곁에 흩어진 검은 알갱이 = **五靈脂** → 十九畏 「人參最怕五靈脂」(相畏). (무 모양으로 보면 萊菔+萊菔子 → **人參惡萊菔子**, 相惡의 교과서 예.)
- 저울추가 짓누르는 깃꼴 푸른 잎 = 눌러 억제 → **相畏·相殺**(한 약이 다른 약의 毒을 누름) 또는 **劑量(用量)**.
- 접시 위 흰 공 + 회색 가루 = **丸·散** 劑型? (또는 砒霜·芒硝류 광물)
- 탁자 밑 검은 수염뿌리 + 피어오르는 검은 연기 + 붉은 X = **藜蘆**(十八反 「諸參辛芍叛藜蘆」) → **相反**(합하면 毒 발생 = 연기), 금기라서 바닥에 버림.
- 배경 약장 = 本草/약방 무대.

**③ 잔결**: 두 사람의 흰 알(달걀? 조약돌? 흰 飮片?) 정체 불명. 흰 뿌리 표면의 검은 점이 무늬인지 씨인지 모호. 저울추와 잎의 결합이 억지스러움. 왼쪽 가장자리 칸막이 너머 잘린 물체, 오른쪽 돌화덕(위에 갈색 덩이)은 이웃 띠 몫. 이어 붙인 솔기는 뚜렷하지 않음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원**: **本草 各論 — 補氣藥(人參: 補脾益肺)** 1순위 (45%). 차순위 **化痰止咳平喘藥**(脾=生痰之源·肺=貯痰之器, 降, 鹹味軟堅) 25%, **本草 總論(五味·升降·歸經·十八反)** 20%. 사전으로 두 인물이 臟으로 확정되면서 1단계의 神農/君 읽기는 버린다.

**② 인물과 소품**
- 노란 밀짚모자 농부 = **脾**(옷도 황갈 = 黃). 흰 납작 타원(飮片 조각) 1개.
- 흰 도포·검은 갓 재상 = **肺**(갓은 옷차림일 뿐, 太 아님). 같은 흰 조각 1개.
- 관계: 탁자 위 흰 뿌리에서 나온 **같은 조각을 脾·肺가 하나씩** 쥠 → 그 약이 **脾·肺 두 經에 들어감(歸脾肺經) = 補脾益肺**. 脾(土)→肺(金) 母子이니 **培土生金**도 함께 나름.
- 흰 뿌리(蘆頭 달린 원뿌리) = **人參**(大補元氣·補脾益肺). 곁의 검은 알갱이 = **五靈脂**(十九畏 「人參最怕五靈脂」).
- 탁자 밑 검은 수염뿌리 + 연기 + 붉은 X = **藜蘆** → 十八反 「諸參辛芍叛藜蘆」(人參 反藜蘆, 동용 금기).
- 깃꼴 잎을 내리누르는 저울추 = 사전의 **降**(누르는 추) → 降氣·降逆; 잎은 葉類 약재(蘇葉·艾葉?) 미확정.
- 접시 위 회색 굵은 알갱이 = **鹹**(굵은 소금); 곁의 흰 공 = 단단한 덩이 → **鹹能軟堅**(또는 鹽炙 → 入腎). 흰 공을 **痰**(회백색 덩이)으로 보면 鹹寒 化痰軟堅.
- 배경 약장 = 本草 무대.

**③ 잔결**: 降(저울추+잎)·鹹(소금+흰 공) 두 묶음은 人參 줄거리에 안 붙음 — 이웃 약재 몫이거나 다른 개념. 흰 뿌리 표면의 검은 점과 번들한 검은 방울이 五靈脂인지 腎(黑)을 덧붙인 것(山藥: 脾肺腎)인지 갈림. 쥔 흰 타원이 飮片인지 痰인지(痰이면 生痰之源·貯痰之器) 모호. 검은 뿌리의 연기가 毒인지 燒炭인지 미확정. 솔기 흔적은 없음.
