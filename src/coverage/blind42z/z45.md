# z45 판독

## 1단계 — 생판 (기호 사전 없이)

**① 단원 1순위: 本草 — 化痰藥(溫化寒痰 半夏 / 淸化熱痰 貝母 묶음)** 45% · 2순위 **本草總論 — 七情配伍·十八反** 30%. 배경 전체가 藥欌(백味櫃)이라 본초판인 것은 확실, 띠 안의 소품이 半夏·生薑·烏頭로 모여 있다.

**② 인물·소품**
- 왼쪽 밀짚갓·갈색 무명옷 농부, 오른쪽 갓·흰 도포 선비가 **똑같은 흰 타원 조각**을 하나씩 들어 보인다 → 1순위 **貝母** 두 갈래: 선비 = **川貝母**(곱고 비쌈, 甘·微寒, 潤肺 — 虛勞久咳), 농부 = **浙貝母**(흔하고 큼, 苦寒, 淸熱散結 — 風熱·痰火·瘰癧). 2순위는 **半夏·天南星** 짝.
- 관계: 같은 물건을 나란히 들어 보임 = 「같은 약(化痰止咳), 다른 산지·등급」, 둘 다 아래 烏頭와 반(反).
- 탁자 왼쪽 흰 덩이줄기 4개(온전 3 + 반 쪼갠 1): 꼭대기 줄기 흔적·잔점 = **半夏**. 얼굴처럼 검은 눈물·침을 흘림 = **生半夏 有毒**(戟人咽喉·舌麻); 쪼갠 단면이 희고 분질.
- 접시: 깨끗한 흰 공 + 노란 **生薑** 편 3쪽 → 生薑이 半夏 毒을 누름(**相畏·相殺**, 薑半夏), 또는 小半夏湯 止嘔. 흰 공은 해독된 半夏(또는 白礬).
- 갈래 잎 위 검은 추(秤錘) → 무게로 누름 = **降逆止嘔**(1순위) / 沈降·劑量(대안). 잎은 紫蘇葉이면 半夏厚朴湯.
- 바닥: 검은 뿌리(烏=검정, 머리 관+잔뿌리)에 빨간 X, 연기 → **烏頭**, **十八反 「半蔞貝蘞芨攻烏」**: 半夏·貝母 모두 烏頭와 함께 쓰면 안 됨(연기 = 毒 상승).

**③ 잔결**: 추+잎의 뜻 불확정; 흰 공 정체(달걀·白礬·半夏) 모호; 두 사람이 든 흰 조각이 무슨 약인지 그림만으로는 확정 불가; 농부/선비 구분이 나르는 사실 불명. 오른쪽 돌 조리대·왼쪽 칸막이는 이웃 띠 몫. 이어 붙인 흔적은 안 보임.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 단원 1순위: 本草 — 化痰止咳平喘藥 중 溫化寒痰藥, 띠 표제 = 半夏** 60% · 2순위 **本草總論 — 七情·十八反** 20%. 사전으로 두 사람이 臟으로 풀리면서 「貝母 두 갈래」 읽기는 버린다 — 띠 전체가 半夏 한 약의 초상이다.

**② 인물·소품**
- 노란 밀짚모자 농부 = **脾**, 흰 도포·검은 갓 재상 = **肺**(옷·모자 모양은 인물 지시일 뿐). 둘이 **같은 흰 타원 조각(半夏片)**을 하나씩 들어 보임 → **半夏 歸經 脾·(胃)·肺**. 脾 = 燥濕化痰(脾爲生痰之源), 肺 = 化痰止咳(肺爲貯痰之器).
- 관계: 母子(土生金)인 두 臟이 나란히 같은 약을 쥠 = 한 약이 생담처·저담처 두 곳을 함께 다스림. (흰 조각을 痰으로 보면 「脾生痰·肺貯痰」 자체를 나르나, 사전의 痰은 끈적한 회백 덩이라 2순위.)
- 탁자 흰 덩이줄기 4개(온전 3 + 쪼갠 1) = **半夏**, 검은 침·눈물 = **生半夏 有毒**(戟人咽喉). 온전한 셋이 한데 모임 → 사전의 「久」(셋 포갬)라면 **六陳之一**(陳久者良), 다만 「포갬」이 약해 조건부.
- 잎 위를 내리누르는 저울추 = 사전 **降** 확정 → **降逆止嘔**.
- 접시: **生薑** 편 3쪽 + 독 흘림 없는 흰 공 = 生薑이 半夏 毒을 누름(**半夏畏生薑 / 生薑殺半夏毒**, 薑半夏·小半夏湯).
- 바닥 검은 뿌리 + 빨간 X + 검은 연기 = **烏頭**, **十八反(半蔞貝蘞芨攻烏)**. 연기는 흰 김(氣)이 아니라 검으니 毒 증가.

**③ 잔결**: 추 밑 갈래 잎이 무엇인지 사전에 없음(降의 받침인지 紫蘇葉인지); 추가 두 臟 사이 한복판에 있어 「中」/胃로 읽힐 여지; 흰 공 정체(해독 半夏·白礬·달걀) 불확정; 消痞散結·外用消腫은 띠 안에 담당 소품 없음. 이어 붙인 흔적 없음.
