# z69 판독

## 1단계 — 생판 (사전 보기 전)

**① 단원** — 1순위 **本草 補氣藥(健脾益氣: 人蔘·白朮·茯苓·甘草 = 四君子 구성)** 45%. 2순위 **炮製(修治) — 蒸·炒** 35%. 부엌 부뚜막(土=中焦 脾)·흙·노란빛(土色·甘味)·흰 김(肺·氣)이 한 판 전체를 「脾肺로 들어가 氣를 보한다」로 묶는다. 한편 찜통과 볶음솥이라는 두 동작만 보면 수치법(蒸=水火共制, 炒=火制) 단원으로도 읽힌다.

**② 인물·소품**
- 가운데 인물(회색 저고리, 상투, 무표정한 선비 꼴, 나무 주걱으로 볶음) → **白朮**(2순위 **甘草**). 노란 조각 약 9쪽(큰 것 6, 작은 것 3)을 솥에서 볶음 = **炒白朮/土炒白朮**(볶아 써서 健脾止瀉 기운을 키움). 밑의 장작불 = 溫性. 이 인물이 甘草라면 솥 안 짙은 갈색 국물 = 꿀 → **炙甘草**(蜜炙, 補中益氣).
- 왼쪽 흙 묻은 뿌리 → **人蔘**(사람 꼴 뿌리, 蘆頭, 잔뿌리 여러 가닥). 흙 = 생것(水蔘)/土=脾. 찜통 곁에 놓임 = 蒸해서 **紅蔘**으로 만든다.
- 대나무 찜통(2단, 뚜껑 열림, 흰 덩이 약 3개, 김이 크게 솟음) → 흰 덩이 = **茯苓**(白·淡滲) 또는 그냥 「蒸」. 위로 솟는 흰 김 = 氣를 위로 올림(升)·肺(白).
- 배경: 돌 부뚜막(竈) = 土 = 脾胃, 나무 마루.
- **관계**: 한 인물이 人蔘·찜통(茯苓)·볶는 조각(甘草)과 한 부뚜막에 함께 있음 = 人蔘+白朮+茯苓+甘草 **四君子湯**의 네 君子, 人蔘+白朮 **相須**(補氣健脾를 서로 키움).

**③ 뜻 모를 것·이음 흔적**
- 노란 조각 개수(9쪽?)가 무엇을 세는지 모르겠다.
- 왼쪽 가장자리 흰 천(이웃 인물 옷)·오른쪽 끝 쇠 석쇠(이웃 띠 몫, 烘焙/炙?)는 무시.
- 왼쪽 나무 기둥이 띠 위쪽에서 끊기고, 부뚜막 상판 오른쪽 끝에 회색 얼룩—이음 흔적일 수 있음. 인물 볼에 붉은 기 없는 회색 일색이라 색이 나르는 사실이 있는지 불명.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원** — **本草 補益藥(補氣)** 55%로 올림. **炮製** 25%로 내림. 사전에 蒸·炒 같은 수치 기호는 없는데, 이 판의 큰 덩이들이 등재 글자로 풀린다: 서린 흰 김 = **氣**, 그릇에 가득 담긴 것 = **補-b**(담긴 것이 채워 주는 것), 불꽃 = **熱/陽**. 그래서 「무엇을 어떻게 보하나」를 나르는 판으로 읽는 편이 맞다.

**② 인물·소품**
- 가운데 인물 → **人蔘**(1순위; 사람=人 + 손 닿는 곳의 흙 묻은 뿌리=蔘). 1단계의 白朮은 2순위로 내리고, 炙甘草·黃芪는 3순위. 회색 저고리·상투는 五色도 등재 기호도 아니라서 이름을 지지 않는다.
- 찜통(그릇) 가득 김이 서려 솟음 = 補-b(담긴 것 = 氣) → **大補元氣/補氣**. 흰빛 → **益肺**(추정). 찜통과 뿌리를 나란히 둠 = 蒸해서 **紅蔘**.
- 볶음솥(그릇)에 따뜻한 국물과 노란 조각이 찰랑 참 = **補**(+補-b: 담긴 것이 노란색=土色 → **補脾**, 추정). 나무 주걱이 꽂힘 = **甘**(꿀단지)에 기댄 읽기지만 단지가 아니고 꿀색도 아니라 약함.
- 솥 밑 장작불 = 熱/陽. 사전의 溫 기호(김 나는 천)는 없어서 「微溫」은 기호로 확정되지 않는다.
- 부뚜막·흙 = 土(脾). 등재 기호는 아니고 1단계 추정을 그대로 씀.
- **관계**: 그릇 두 개(김 찜통 · 노란 볶음솥)를 한 사람이 함께 다룸 = 두 장부를 함께 보함, 곧 **補脾益肺**. 왼쪽 이웃 띠 끝의 흰 옷 = 흰 도포 재상(肺)일 수 있어 歸肺를 받쳐 줌. 다만 이웃 띠 몫이라 확정하지 않음.

**③ 잔결** — 인물 이름을 지는 등재 기호가 없다(人蔘은 뿌리 실물에 기댐). 찜통 속 흰 덩이 3개는 포개지지 않아 久가 아니어서 뜻이 없다. 노란 조각 약 9쪽의 개수도 뜻이 없다. 불(熱)이 「微溫」보다 세다. 甘은 꿀단지 꼴이 아니라 확정할 수 없다.
