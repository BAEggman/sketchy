# z94 판독

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원** 1순위 **本草 — 補益藥·溫裏藥(補溫)** 45% / 2순위 **炮製 火製法(炙·煅·淬)** 30% / 3순위 **五行 火(炎上·焦·赤)** 15%.

**② 띠 한가운데** — 사람이 없다. 띠는 판의 오른쪽 끝(오른쪽 테두리가 보임)이고, 돌 부뚜막 위 소품 넷이 인물 노릇을 한다. 왼쪽 끝의 회색 소매·손은 이웃 띠 몫.
- 석쇠 위에서 격자무늬로 노릇하게 구워진 빵 한 조각 + 그 밑의 은근한 숯불 = **炙(蜜炙)** → **炙甘草/炙黃芪**: 甘溫으로 補中益氣. 숯불은 文火.
- 꿀이 넘쳐흐르는 나무 숟가락 = **蜂蜜**: 蜜炙의 보조 재료. 甘은 補하고 緩한다(補中·潤燥·緩急止痛·解毒).
- 불길이 활활 솟는 장작불 속 붉은 고기 덩이 = 肉+火 → **肉桂** 補火助陽·引火歸原(덩이가 부뚜막 불 속, 곧 '근원'에 들어가 있음). 또는 炙 자의 꼴(月+火). 장작불은 武火.
- 흰 사발 속 붉은 물 = 血 → 肉桂의 溫經通脈 또는 補血. (술·식초라면 酒炙·醋淬)
- 배경의 돌 부뚜막(아궁이) = 下焦의 命門火 자리. 竈心土(伏龍肝)를 가리킬 가능성도 약하게 있음.
- 관계: 약한 숯불과 센 장작불이 나란히 있음 = 甘溫 補氣藥(溫)과 辛熱 溫裏藥(熱)의 등급 차이. 두 불 사이의 꿀 숟가락 = 甘으로 緩和함(甘草·蜂蜜이 附子·烏頭의 毒과 燥烈을 누그러뜨림).

**③ 잔결** 붉은 덩이가 고기인지 광석인지 모호하다(광석이라면 煅이고 赭石·朱砂 계열). 붉은 물이 피인지 술·식초인지도 모호하다. 굳이 '빵'인 이유를 모르겠다(甘草片인지 黃芪片인지). 띠 위쪽 절반은 빈 벽이다. 이어 붙인 흔적은 보이지 않는다.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽음)

**① 단원** 1순위 **本草 — 補益藥·溫裏藥(補溫)** 50% / 2순위 **火熱(六淫 火·熱盛動血)** 25% / 3순위 **炮製(蜜炙)** 15%. 사전으로 읽으니 토큰이 甘·熱(陽)·血·補-b로 깔끔하게 떨어져서 '補 + 溫' 쪽이 굳어진다. 炮製로 읽을 근거는 약해진다(煅·淬를 가리키는 기호가 없음).

**② 띠 한가운데** — 여전히 사람이 없다. 왼쪽 끝 회색 소매는 五色 인물이 아니고 이웃 띠 몫이다.
- 나무 숟가락의 꿀 = **甘**(꿀단지의 줄임꼴): 補益藥의 味는 甘이다. 석쇠 빵 곁에 놓여 있어 甘+炙 → **炙甘草(蜜炙)** 로도 읽힌다. 꿀이 숟가락 밖으로 넘친 것은 盛일 수 있다(갈림 미정).
- 장작불의 불꽃 = **熱**, 불 = **陽**. 그 속의 붉은 덩이 = **血**(붉은 것). 닫힌 윤곽의 살덩이로 보면 肌가 되는데, 그렇다면 '肉' 쪽이다. 따라서 **溫裏藥 辛熱 / 補陽(補火助陽)** 이고, 덩이가 肉이면 **肉桂**(補火助陽·溫通經脈)이다.
- 흰 사발에 가득 찬 붉은 물 = **補-b**(가득 담긴 것을 채워 줌) + 血 → **補血**. 김이 오르지 않아 '따뜻한 국물'(補)과는 어긋나므로 補-b로 읽는다.
- 석쇠 밑에서 타다 남은 숯 = 衰(타다 남아 작아진 것)일 수 있다 → 火衰·陽衰. 이것이 溫裏·補陽이 필요한 이유가 된다.
- 관계: 甘(꿀) + 熱(불) = **甘溫/甘熱** → 補氣·補陽·溫裏의 공통 性味. 불 곁의 血 사발 = **陽生陰長·溫經으로 血을 돕는 것**(肉桂를 소량 넣어 氣血을 鼓舞함). 꺼져 가는 숯(衰)과 센 불(熱)이 나란한 것 = 陽衰를 補火로 되살리는 관계.

**③ 잔결** 석쇠와 빵은 사전에 없다. 붉은 덩이가 血인지 肌인지 갈린다. 꿀이 넘친 것이 盛인지 그냥 붓는 몸짓인지 모르겠다. 사발에 김이 없어 補인지 補-b인지 애매하다. 숯이 衰인지 그냥 文火인지 미정이다. 띠 위쪽 절반은 빈 벽이고, 이음 흔적은 없다.
