# blind43 / 901 — L4 판독

## 1단계 — 생판 (사전 열기 전, 확정)

① 판 표제어
- 1순위 **炮製(修治) — 水製·火製·水火共製** (55%)
- 2순위 **本草 總論(採集·貯藏·炮製·配伍·禁忌·用量·煎法)** (30%)
- (3순위 **人蔘/地黃 같은 한 약재의 加工 형태 비교** 10%)

② 인물·구역 (왼→오)
- 인물1 (좌, 회색 저고리·상투, 약탕관 앞) — **煎藥法 / 水製·煮** : ⓐ 노란 단면 통나무 1 + 잘린 토막 1 → 切製(飮片 썰기) ⓑ 검은 액체 찻사발 1 → 輔料(酒·醋) 혹은 완성 湯液 ⓒ 김 나는 약탕관에 노란 조각을 막 떨어뜨림 → **後下** ⓓ 둘째 약탕관은 검게 졸아든 물 속에 노란 조각이 이미 잠김 → 先煎/久煎 대비(대황 後下면 瀉下力 유지, 오래 달이면 약해짐) ⓔ 화로 2개 → 문화·무화? (약탕관 2개 = 2가지 煎法)
- 인물2 (농부, 밀짚모자·갈색옷) — **採集/産地(藥農)** : 흰 타원체 1개를 들어 보임 → 약재 원물 감별? 표제어 확신 낮음.
- 인물3 (선비, 갓·흰 도포) — **配伍(相須) / 用藥禁忌** : 농부와 똑같은 흰 타원체 1개 → 같은 것끼리 짝(相須). 탁자 소품 ⓐ 검은 반점·검은 방울 흩어진 흰 뿌리 → 무(萊菔)·씨? = 人蔘惡萊菔子(相惡)? ⓑ 잎 위 쇠추(分銅) → 用量(劑量) 혹은 壓搾(製霜) ⓒ 접시의 달걀 1 + 소금 더미 1 → 輔料(鹽炙 등) ⓓ 탁자 아래 검은 연기 + 붉은 X 친 새까만 뿌리 → 炒炭 '存性' 위반(태워 재가 되면 안 됨) 혹은 十八反류 금기.
- 인물4 (우, 회색·상투, 웍) — **火製(+水火共製)** : ⓐ 대나무 찜기+김(흰 덩이 3~4) + 흙 묻은 인삼 1 → 蒸(紅蔘) ⓑ 웍에 노란 편 약 10여 개 볶기 → 炒 ⓒ 석쇠 위 납작한 덩이 1 → 炙/焙(烘焙) ⓓ 꿀 숟가락 1 → 蜜炙 ⓔ 불 속 붉은 육면체 광물 1 → 煅 ⓕ 붉은 액체 사발 1 → 醋淬(煅淬).
- 배경: 약장(百子櫃) 1면, 서랍 하나 빠진 구멍, 부서진 울타리 + 흙더미, 매달린 빗자루 1 → 淨選(刷·簸)/貯藏 손상(防蟲·防鼠?).

③ 잔결
- 농부·선비가 같이 든 흰 타원체(달걀? 茯苓편?)의 뜻 불명. 쇠추가 잎을 누르는 의미 불명. 약장 서랍 구멍 + 부서진 울타리·흙더미가 왜 약방 안에 있는지 어색. 왼칸과 가운데칸 사이 세운 칸막이 판이 이음매처럼 보임(구역 경계). 프레임 잘림 없음.

## 2단계 — 계통 (blind6_사전요약 어휘로 재판독)

사전으로 풀린 것: 짚 빗자루=**瀉**, 김 없는 질그릇 사발의 검은 액체=**苦**, 꿀 숟가락=**甘**, 접시 위 굵은 소금=**鹹**, 내리누르는 쇠추=**降**, 흰 김=**氣**, 불꽃=**熱**, 붉은 액체=**血**(혹은 醋), 밀짚모자 농부=**脾**, 흰 도포·갓 재상=**肺**, 같은 통나무 둘 중 하나가 두 배=**大** → 노란 단면과 합쳐 **大黃**. 세운 칸막이=**惡**(가리개) 가능성. 五味 중 酸(매실)·辛(고추)은 판에 없음 → 五味 판은 아님.

① 판 표제어
- 1순위 **本草 總論 — 炮製·煎法과 藥性(性味·升降·歸經)의 변화** (50%)
- 2순위 **炮製(火製·水火共製·加輔料)** (30%)
- (3순위 藥性理論 단독: 五味·升降浮沈·歸經 15%)

② 인물·구역 (왼→오)
- 인물1 (좌, 회색·상투) — **大黃 / 煎法(後下)** : ⓐ 大+黃 통나무 = 大黃 ⓑ 苦(검은 사발) = 苦寒 ⓒ 瀉(빗자루) = 瀉下 ⓓ 끓는 탕관에 막 넣음 = **後下** ⓔ 둘째 탕관 검게 졸아 잠김 = 久煎하면 약효(瀉下力) 변함 ⓕ 부서진 울타리 밖으로 밀려나온 흙더미·약장 구멍 = 蕩滌·推陳致新(積滯 배출) — 6개.
- 인물2 (脾 농부) — **歸經: 脾** : 흰 편 1 쥠 → 脾에 드는 약(山藥류?) ; 곁 칸막이 = 惡(?) — 1~2개.
- 인물3 (肺 재상) — **歸經: 肺 / 輔料·禁忌** : ⓐ 같은 흰 편 → 脾·肺 공통 歸經 ⓑ 잎을 누르는 추 = 降(가벼운 잎도 降) ⓒ 소금 = 鹹 → 鹽製(入腎·下行) + 달걀 ⓓ X 친 검은 뿌리 + 검은 연기 = 炒炭 存性 위반(혹은 地黃 금기) ⓔ 검은 점 흰 뿌리 = ? — 4~5개.
- 인물4 (우, 회색·상투) — **火製·水火共製** : ⓐ 氣(김)+찜기+흙 묻은 人蔘 = 蒸 → 紅蔘 ⓑ 웍의 노란 편 10여 개 = 炒 ⓒ 석쇠 위 판 = 炙 ⓓ 꿀(甘) = 蜜炙(炙甘草) ⓔ 熱 속 붉은 광물 = 煅 ⓕ 붉은 사발 = 淬(醋淬) 혹은 血 — 6개.

③ 잔결
- 脾·肺가 든 흰 편, 소금 곁 달걀, 검은 점 흰 뿌리, X 뿌리의 정체는 사전으로도 안 풀림. 붉은 사발이 血인지 醋인지 갈림 불명. 칸막이가 惡 가리개인지 구역 이음매인지 모호. 실내 약장 앞 부서진 울타리·흙더미 어색. 프레임 잘림 없음.
- 판정: 사전 어휘로 왼쪽 구역(大黃·苦·瀉)과 두 인물(脾·肺)이 확실히 더 잘 풀렸고, 오른쪽 炮製 도구는 사전 밖이라 1단계 읽기 그대로.
