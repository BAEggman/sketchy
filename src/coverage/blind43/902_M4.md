# 902 판독 — M4

## 1단계 — 생판 (사전 없이 그림만)

**① 판 전체 표제어**
- 1순위: **本草總論 — 藥을 다루는 법 (炮製·配伍七情·煎服法)** — 45%
- 2순위: **炮製 (修治·水製·火製·水火共製)** — 30%
- (3순위 참고: **七情配伍·用藥禁忌** 15%)
- 근거: 배경이 약장(百子欌) 달린 약방 부엌. 오른쪽은 찌고·볶고·굽고·달구는 조리대, 가운데는 약재 짝짓기 탁자, 왼쪽은 약탕관 두 개.

**② 인물(구역)별 — 왼쪽부터**
1. **왼쪽 여인 — 煎藥法(用法)**: 질그릇 약탕관(砂鍋, 鐵器 아님) 2개가 각자 작은 화로 위에 올라 있음(문火). 김 나는 탕관에 노란 조각을 손으로 넣음 → **後下**. 선반 위 잘린 노란 통나무 → **大黃**(切製·切片)로 읽힘(大黃 後下). 둘째 탕관은 검게 졸은 찌꺼기에 노란 조각이 떠 있음 → 오래 달이면 효력이 줄어듦(久煎/二煎·藥渣). 검은 액이 담긴 사발 → 완성된 湯液·복용. 사실 약 5개.
2. **농부(삿갓)** + 3. **선비(갓)** — 둘이 똑같은 흰 알을 하나씩 들고 마주 봄 → 같은 계열 약 둘을 함께 써서 효과를 키우는 **相須**(신분 차이를 主·輔로 보면 **相使**). 사실 1~2개.
   - 가운데 탁자: 꼭지 달린 흰 무(萊菔) 4개(1개는 반으로 갈림)에서 검은 씨·즙이 흘러나옴 → **萊菔子**. 탁자 아래 바닥에서 검게 타 연기가 나는 인삼에 붉은 X 표시 → **人蔘 惡 萊菔子(相惡)**, 즉 효능이 사라짐. 접시 위 흰 덩이와 노란 편 3~4장 → **半夏 + 生薑 (相畏·相殺)**. 쑥 모양 잎을 누르는 저울추 → 用量인지 制(누름)인지 미상. 사실 약 3개.
4. **오른쪽 요리사 — 炮製(火製·水火共製)**: 김 나는 대나무 찜기 → **蒸**(흰 덩이). 흙 묻은 생인삼 → 修治(純淨·去土)이거나 蒸製해 紅蔘을 만드는 재료. 웍에 노란 편 → **炒(炒黃)**. 석쇠 위 납작한 편과 꿀 숟가락 → **蜜炙**. 장작불 속 붉은 덩이 → **煅**(代赭石류). 붉은 액 사발 → **淬**(醋淬). 사실 6개.

**③ 잔결**
- 뜻 모를 것: 약장 앞 **부서진 울타리 + 흙더미 + 빠진 서랍 한 칸**(土? 壁土炒? 去土?), **걸린 빗자루**(純淨/修治?), **잎 위 저울추**.
- 이어 붙인 흔적: x≈1050–1100에서 약장 배경이 끊기고 오른쪽은 민벽과 돌부뚜막으로 바뀜. 바닥 재질도 달라서 두 장면을 붙인 것처럼 보임. 왼쪽과 가운데 사이 나무 칸막이도 구획선 역할을 함.
- 프레임 잘림: 없음. 다만 오른쪽 테두리 밖에 흰 여백이 넓음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽음)

**① 판 전체 표제어 (수정)**
- 1순위: **補益藥(補氣藥 중심) — 甘溫·主歸脾肺·人蔘/甘草의 炮製와 禁忌** — 40%
- 2순위: **本草總論 (藥性 四氣五味·升降·歸經·補瀉 + 炮製 + 配伍禁忌 + 煎法)** — 35%
- 판정: 사전으로 읽자 가운데 두 사람이 **노란 밀짚모자 농부 = 脾**, **흰 도포·검은 갓 재상 = 肺**로 확정됨. 여기에 꿀 = **甘**, 서린 흰 김 = **氣**, 찰랑이는 따뜻한 국물 = **補**, 불꽃 = **熱**이 더해지면 補氣藥 총설인 「甘溫, 脾肺로 들어가 氣를 補한다」가 그대로 나옴. 1단계의 炮製·總論 읽기보다 잘 풀림. 다만 왼쪽의 苦·大(黃)와 걸린 빗자루(瀉)는 補氣 하나로 다 묶이지 않아서 總論을 2순위로 남김.

**② 인물(구역)별 — 왼쪽부터**
1. **여인(오행 인물 아님) — 補湯 달이기**: 넘칠 듯 찬 따뜻한 국물에 흰 김이 오르는 탕관 = **補+氣**. 그 안에 노란 편을 넣음(黃芪 補氣 / 1단계의 後下). 노란 통나무 두 토막은 하나가 둘째의 약 두 배 크기 = **大** → 大黃 쪽으로 갈림(조건이 맞는지 애매함). 김 없는 검은 액이 담긴 질그릇 사발 = **苦**(사전 정의와 정확히 맞음). 김 없이 검게 졸아든 둘째 탕관 = 苦 또는 久煎. 사실 4~5개.
2. **농부 = 脾**, 3. **재상 = 肺**: 둘이 같은 흰 타원을 하나씩 듦 → 한 약이 **脾·肺 두 經**에 함께 들어감(人蔘·山藥 등 補氣藥의 歸經). 흰 덩이를 **痰**(회백색 덩이)으로 보면 脾生痰·肺貯痰으로 갈리지만 끈적함이 없어 약함.
   - 탁자: 잎을 내리누르는 저울추 = **降**(降逆 계열 약 또는 肺의 肅降). 흰 무(또는 半夏)와 거기 붙은 검은 점·즙(萊菔子). 生薑 편 + 흰 덩이 접시(半夏–生薑 相殺). 바닥에 타다 남은 검은 인삼과 회색 연기, 붉은 X = **衰** → **人蔘 惡 萊菔子**로 補氣 효능이 꺼짐(反藜蘆 가능성도 있음). 사실 4개.
4. **요리사(오행 인물 아님) — 炮製**: 찜기에서 크게 서린 흰 김 = **氣** + 흙 묻은 생인삼 → 人蔘 **大補元氣**, 쪄서 紅蔘. 웍의 노란 편 → 炒白朮(또는 炮薑). 석쇠 위 편 + 꿀 숟가락 = **甘** → **炙甘草·蜜炙黃芪**(甘溫 강화). 큰 불꽃 속 붉은 덩이 = **熱**(+血/肉) → 溫裏·補陽(肉桂·附子류). 붉은 액 사발 = **血**(氣生血 / 補血). 사실 6개.

**③ 잔결**
- 걸린 짚 빗자루 = 사전상 **瀉**. 補 판에 瀉를 걸어 둔 것인데, 「補하라, 瀉하지 말라」는 뜻인지 단정하기 어려움.
- 부서진 울타리 + 흙더미 + 빠진 서랍 구멍: 담(內/外)이 **傷**한 것인지, 土(土炒白朮)인지, 竅인지 여전히 미상.
- 노란 통나무의 **大** 조건(정확히 두 배인지)이 애매하고, 大黃이면 補 판과 어긋남.
- x≈1050–1100에서 약장 배경이 민벽과 돌부뚜막으로 끊김 → 이어 붙인 흔적. 프레임 잘림은 없음.
