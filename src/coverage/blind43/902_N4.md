# 902 판독 — N4

## 1단계 — 생판 (사전 없이 그림만)

**① 판 표제어**
- 1순위 **본초 총론(中藥總論) — 炮製·配伍(七情)·煎服法** (55%)
- 2순위 **炮製(修治)法 — 火製·水火共製** (25%) / 3순위 **半夏 단일 약물판**(10%)

배경 전체가 약장(百子欌) 앞 탕제실·부엌이고, 왼쪽→오른쪽으로 「달이기 → 배합 → 굽고 찌기」가 이어져 본초 총론의 세 꼭지를 한 장에 묶은 것으로 읽었다.

**② 인물(구역)별 — 왼쪽부터**
1. **회색 저고리 여인 — 煎藥法** (사실 4): 질그릇 탕관 2개가 화로 위(=砂罐 사용, 금속기 피함) / 끓는 첫 탕관에 노란 조각을 나중에 넣음(=後下) / 둘째 탕관은 진하게 우러남(=頭煎·再煎, 2번 달임) / 노란 속 통나무 2토막(=切片 修治, 또는 大黃) / 검은 탕약 한 잔(=湯劑 복용).
2. **밀짚모자 농부** · 3. **갓 쓴 선비 — 配伍 七情** (함께 읽음, 사실 5): 두 사람이 똑같은 흰 조각을 하나씩 듦(=相須, 같은 류 두 약이 효능 증강) / 흰 둥근 덩이 3개+반쪽 1개, 검은 즙이 흘러내림(=半夏, 생용 有毒; 반쪽=「半」) / 접시에 흰 덩이+노란 편 3쪽(=半夏畏生薑·生薑殺半夏毒 → 相畏·相殺) / 쑥 같은 잎을 쇠추가 누름(=相惡? 또는 用量·劑量) / 탁자 아래 검게 탄 뿌리에 빨간 X·연기(=烏頭, 十八反 半夏反烏頭 → 相反; 혹은 炒炭 存性 실패).
4. **오른쪽 회색 옷 요리사 — 炮製(火製·水火共製)** (사실 6): 흙 묻은 생뿌리(=생용·淨制 去土) / 대나무 찜기에 흰 덩이 김(=蒸) / 웍에 노란 편 약 8쪽 볶음(=炒) / 석쇠 위 납작 덩이+꿀 숟가락(=蜜炙·煨) / 불 속 빨간 덩이(=煅) / 빨간 액 그릇(=醋淬 또는 朱砂 水飛).

**③ 잔결**
- 약장 아래 서랍 하나가 빠진 구멍 + 부서진 울타리 + 흙더미(쥐구멍? 陳壁土·土炒?) 뜻 모름. 걸린 빗자루(淨選?)도 모호.
- 쇠추+잎의 짝이 불분명. 흰 조각을 든 두 사람의 「같은 물건」이 相須인지 相使인지 갈림.
- 오른쪽 구역은 약장이 끝나고 민무늬 벽·돌 부뚜막으로 재질이 바뀜 — 이어 붙인 흔적 가능. 프레임 잘림은 없음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **본초 총론 — 用藥法(煎服法·配伍禁忌·炮製) + 升降浮沈·歸經, 예시약 大黃·半夏** (55%)
- 2순위 **본초 각론 통합 — 瀉下藥 大黃 · 化痰藥 半夏 · 炮製** (30%)

사전으로 읽으니 1단계보다 더 잘 풀린다. 노란 통나무 두 토막의 크기가 2배 차이 나는 것이 **大**(같은 것 둘, 하나가 두 배)+노란 속 = **大黃**으로 풀리고, 농부·재상이 **脾·肺**로 확정되어 흰 조각이 「歸經」 표지가 된다. 1단계에서 相須로 본 것은 철회한다.

**② 인물(구역)별 — 왼쪽부터**
1. **회색 여인 — 大黃 煎法(後下)** (사실 6): 大+黃 통나무 = 大黃 / 질그릇 잔 검은 액(김 없음) = **苦** → 大黃 味苦 / 걸린 짚 빗자루 = **瀉** / 깨진 울타리 밖으로 쏟아진 흙 = **下**(+傷) → 瀉下攻積 / 끓는 탕관에 편을 뒤늦게 넣음 = 後下 / 진하게 오래 끓은 둘째 탕관 = 久煎하면 瀉下力 약화.
2. **노란 밀짚모자 농부 = 脾** (사실 1): 흰 半夏편을 듦 = 半夏 歸脾經.
3. **흰 도포·갓 재상 = 肺** (사실 1): 같은 흰 편 = 半夏 歸肺經.
 (가운데 탁자, 두 사람 공통 사실 6): 반쪽 난 흰 덩이 = **半**夏 / 셋 포갠 덩이 = **久** → 半夏는 陳久者良(六陳) / 검은 즙 방울 = 生半夏 有毒(또는 下) / 접시 半夏+생강 3쪽 = 半夏畏生薑·生薑殺半夏毒(相畏·相殺, 薑製) / 잎을 누르는 저울추 = **降** → 降逆止嘔, 질 가벼운 잎과 대비해 「質重沈降」 / 검게 탄 뿌리에 빨간 X = 烏頭, 十八反 半夏反烏頭.
4. **회색 요리사 — 炮製** (사실 7): 흙 묻은 생뿌리 = 生用·淨制 / 찜기 흰 **김(氣)** = 蒸(水火共製) / 웍 = 炒 / 석쇠+꿀(**甘**) = 蜜炙 / 불 속 붉은 덩이(**熱**·赤) = 煅 / 붉은 액 사발 = 淬(醋) 또는 **血**(炒炭止血?) / 김 오름·추 누름·즙 떨어짐이 판 전체의 升·降·沈을 함께 짐.

**③ 잔결**
- 약장 서랍 하나 빠진 구멍은 사전 어휘로도 안 풀림(藏의 곳간 가마니와 다름).
- 쇠추 밑 잎의 정체(艾葉? 紫蘇?)가 모호해 「降逆」과 「質重沈降」 중 하나로 못 가름.
- 붉은 사발: 血(사전)인지 醋淬(炮製)인지 갈림. 大黃의 「寒」(눈송이)이 없음.
- 오른쪽은 약장 배경이 x≈1090에서 끊기고 민벽·돌 부뚜막으로 바뀜 — 이어 붙인 흔적 의심. 프레임 잘림 없음.
