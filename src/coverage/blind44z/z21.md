# z21 판독

## 1단계 — 생판 (사전 없이 그림만)

**① 단원**: **補益(補氣) — 補氣劑·補氣藥** 55% / 차순위 **本草 補藥(補溫)** 25%, **方劑 總論(君臣佐使)** 10%.

**② 인물·소품**: 띠 안에 인물은 **없다**. 사람 대신 「무대 소품」만 있다.
- 선반 위 화분 4개(왼→오): 매화·난초·국화·대나무 = 梅蘭菊竹 **四君子** → 처방명 **四君子湯**의 말장난. 화분 수 4 = 구성약 4味.
- 쟁반(칸막이 4칸) 위 약재 4개: 뿌리째 인삼 = **人蔘**(君, 大補元氣·補脾益肺), 갈색 덩이뿌리 = **白朮**(臣, 健脾燥濕), 흰 솜뭉치 같은 덩이 = **白茯苓**(佐, 健脾滲濕), 노란 막대 = **甘草**(使, 益氣和中·調和諸藥). 사실: 四君子湯 = 人蔘·白朮·茯苓·甘草 4味, 君臣佐使 각 1.
- 가운데 김 나는 국그릇 = **湯**(湯劑, 煎服). 국 속 초록 건더기는 生薑·大棗를 넣어 달이는 것일 수도(약함).
- 배경: 나무 기둥·선반·칸막이 있는 부엌/약방 칸 = 脾胃(중초·음식) 무대 → 主治 **脾胃氣虛**(面色萎白·語聲低微·食少便溏) 연상.
- 관계: 선반(四君子 4화분)과 쟁반(약 4味)이 위아래로 1:1 대응 → 「네 군자 = 네 약」, 즉 이름과 구성의 대응. 인삼이 쟁반 맨 앞·가장 크게 = 君藥.

**③ 뜻 모를 것·이음 흔적**: 인물 부재(통합판의 다른 칸에 인물이 있는지 불명). 오른쪽 세로 칸막이 판자 = 이웃 띠와의 이음매/칸 구분. 오른쪽 아래 둥근 그릇(테두리만 보임)은 이웃 띠 몫. 화분 색(테라코타·베이지·주황·회색)은 의미 불명. 국 속 초록 조각의 정체 불명.

## 2단계 — 계통 (blind6 사전요약 적용 후 재판독)

**① 단원**: **補氣 — 本草 補益藥(補氣藥)·補氣劑** 65% / 차순위 **方劑 補益劑(四君子湯)** 25%. 사전 어휘가 「補氣」를 글자 그대로 써 주어 1단계보다 확신이 오른다.

**② 인물·소품**: 인물은 여전히 **없다**(사전의 오행 인물 — 밀짚모자 농부=脾 등 — 도 안 나온다).
- 가운데 국그릇: 사전 **補 = 그릇에 찰랑찰랑 찬 따뜻한 국물**, 그 위 **氣 = 서린 흰 김** → 그릇+김 = **補氣**(이 띠의 표제 효능). 補-b(가득 담긴 것=채워 주는 것)로 읽어도 「氣를 채움」.
- 선반 梅蘭菊竹 4화분 = **四君子** → **四君子湯**(補氣의 基本方). 사전에 없는 말장난 소품이지만 뜻이 하나로 닫힌다.
- 쟁반 4칸 약재 = **人蔘**(君·大補元氣)·**白朮**(臣·健脾燥濕)·**白茯苓**(佐·滲濕健脾)·**甘草**(使·益氣和中) = 4味. 사전 글자가 아니라 실물 약재 그림으로 읽는다(甘草에 甘=꿀단지 기호 없음).
- 관계: 선반(이름 四君子) ↔ 쟁반(구성 4味) ↔ 가운데 補氣 국 = 「처방명–구성–효능」 세 층. 인삼이 가장 크고 앞 = 君藥. 主治 脾胃氣虛는 무대(부엌)로만 암시, 脾 인물은 없다.

**③ 잔결**: 흰 덩이가 사전 **痰 = 끈적한 회백색 덩이**로 오독될 위험(그림은 솜처럼 희고 보송해 茯苓 쪽). 국그릇이 인삼과 白朮 「둘 사이의 한복판」이라 **中**(→補中益氣)로 읽힐 여지가 있으나 갈림(가구 위=官)에 막혀 채택 안 함 — 노란 막대가 黃芪라면 補中益氣湯 쪽으로 흔들림. 오른쪽 칸막이 판자 = 이웃 띠 이음매, 오른쪽 아래 둥근 그릇 테두리 = 이웃 몫. 화분 색·국 속 초록 건더기 의미 불명.
