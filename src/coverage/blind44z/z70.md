# z70 판독

## 1단계 — 생판 (사전요약 열기 전 확정)

**① 단원 1순위**: **本草 — 藥性(四氣: 熱·溫·平) / 溫裏藥** (40%). 2순위 **煎藥·服藥法** (20%), 3순위 **本草 修治(炒炭·炮)** (15%).

**② 인물·소품**
- 띠 안 인물은 왼쪽 가장자리의 검은 옷 인물 1명뿐(머리는 왼쪽 이웃 띠). 표제어 **溫裏藥(附子·肉桂·乾薑)** 또는 **熱性**.
  - 손에 든 흰 사발: 계피 막대 2개 = **肉桂(桂)**, 검은 울퉁불퉁 덩이 1개 = **附子**, 붉게 달아오른 둥근 조각 2~3개 = **乾薑** 편, 검은 숯 막대 1개 = 炮/炭(불에 굽는 修治) — 셋이 합쳐 「大熱·回陽·溫中」 3味.
  - 붉은 불씨와 김 = 성질 **大熱**(辛熱), 검은 옷 = 黑→**腎**(腎陽을 덥힘, 歸腎經)로 읽음.
- 가운데 놋쇠 저울(빈 접시 둘, 수평) = **平性**(寒熱 치우침 없음) 또는 稱量·劑量.
- 아래 탁자: 눈금 새긴 잔 3개 중 주황 토기 1잔만 검은 탕약으로 가득, 흰 사발 2개는 엎어둠 = 한 첩을 셋으로 나눠 따뜻하게 한 번에 1잔 = **分溫三服**(「溫服一升」).
- 배경: 나무 기둥·문틀 = 약방.
- **관계**: 뜨거운 그릇이 수평 저울 바로 위에 있으나 올리지 않음 → 「熱(치우침) ↔ 平(균형)」 대비, 熱藥이 탕약(溫服)으로 이어지는 흐름.

**③ 어색한 것**: 왼쪽 위 가장자리 회색 원반(머리 장식? 동전?) 뜻 불명. 숯 막대와 附子 덩이 구분 모호. 저울 접시가 비어 있어 무엇을 다는지 없음. 엎어진 흰 사발 2개는 「분복」 외 다른 뜻일 수 있음. 저울 탁자와 아래 컵 탁자가 원근이 겹쳐 두 판을 이어 붙인 듯. 오른쪽 문틀은 가장자리에서 잘림.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원 1순위**: **本草 — 補陽·溫裏(腎陽을 덥혀 채움)** (45%). 2순위 **五臟苦欲補瀉(臟氣法時論: 腎 用苦補之)** (20%), 3순위 **方劑 腎氣丸(少火生氣)** (15%).

**② 인물·소품**
- 검은 옷 인물 = 왼쪽 가장자리의 회색 둥근 렌즈가 **고글**로 읽힘 → 검은 잠수복 잠수부 = **腎**(1단계의 「黑→腎 추정」이 사전으로 확정).
- 손의 사발 = **補-b**(그릇에 가득 담긴 것 = 그 사람에게 채워 주는 것). 담긴 것: 불씨(**陽·熱**) + 위로 서린 흰 김(**氣**) + 계피 막대 2개(肉桂/桂) + 검붉은 둥근 조각 2~3개(**地黃** = 검붉은 뿌리 조각) + 검은 덩이 1(附子 또는 熟地黃) → 腎에 陽氣(火)를 채움 = **補腎陽·補火助陽**; 地黃 위의 작은 불에서 氣가 오르는 꼴은 「陰中求陽·少火生氣」(腎氣丸식)로 읽힘.
- 가운데 저울: 양팔이 수평으로 멎음 → **和**(降 추 없음). 補하되 陰陽을 맞춘다(調和) 또는 平.
- 아래 주황 질그릇 잔의 검은 액체(김 없음) → **苦**. 1단계 「分溫三服」은 철회.
- 엎어진 흰 사발 2개: 사전에 없음(惠는 받아 드는 손이 있어야 함) — 뜻 불명.
- **관계**: 腎이 補 사발을 和 저울 접시 바로 위에 들고, 그 아래에 苦 잔 → 「腎은 덥혀 채우되(補陽) 치우침 없이 和, 苦는 腎을 堅·補」(腎欲堅, 用苦補之)로 묶임.

**③ 잔결**: 사발 속 검붉은 덩이가 **瘀**(그릇 위 검붉게 굳은 덩이) 갈림과 겹쳐 地黃/瘀/숯 구분이 흔들림. 엎어진 흰 사발 2개와 눈금의 뜻 미상. 苦 잔·和 저울과 腎 사발의 연결이 약해 이웃 띠 소속일 수 있음. 저울 탁자와 아래 잔 탁자의 원근 겹침(이음매 의심).
