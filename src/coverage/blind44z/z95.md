# z95 판독 (blind44z)

## 1단계 — 생판 (사전 열기 전, 확정)

**① 단원**: **六經辨證(傷寒 六經病)** 55% / 차순위 **問診·切診(痛症·腹診 — 脇痛)** 20%, **病因病機(七情 怒→脇痛)** 10%.
띠는 판의 오른쪽 끝(액자 오른 테두리+흰 여백, 맨 끝에 분홍 2px 세로줄)이다.

**② 인물 (가운데 1명뿐)** — **少陽病**
- 문간: 바깥(하늘·마당·기와집 = 表)과 안(방바닥 = 裏) 사이 문틀 안에 서 있음 → **半表半裏**. 문짝 경첩 2개가 또렷 → **少陽爲樞**(開·闔·樞 중 '지도리'). 두 발은 아직 문지방 바깥, 넘으려는 찰나 → 表에서 裏로 넘어가는 길목(傳變의 경계).
- 두 손으로 아래 갈비 밑(그의 왼쪽 옆구리~명치)을 움켜쥐고 붉은 통증 번짐 → **胸脇苦滿 / 脇下痞硬**.
- 찡그려 감은 눈 → **目眩**, 이 악문 입 → **口苦·咽乾** (少陽 提綱 3증).
- 문을 드나드는 동작 → **往來寒熱**.
- 곁 소품: 문 안쪽 구석에 노끈으로 묶은 **땔나무 단(柴)** → **柴胡 → 小柴胡湯**(和解法). 노끈 한 묶음(2~3바퀴).
- 배경: 한 짝만 열린 문(나머지 한 짝 없음) = 반쯤 열린 지도리.
- 관계: 한 사람뿐이라 인물 간 관계는 없음. 사람(少陽證)과 그 발치의 柴 단 = "少陽病엔 柴胡劑로 和解", 문지방 = 表裏의 경계.

**③ 뜻 모를 것·어색한 것**
- 왼쪽 아래 낮은 탁자 위 흰 단지 2개(하나는 입이 넓은 항아리)와 탁자 모서리의 나무 토막 — 왼 이웃 띠에서 넘어온 것으로 보이나 약탕기/嘔(心煩喜嘔)일 가능성.
- 땔감이 방 안 문턱 구석에 놓인 것이 어색(불 때는 자리 아님) — 釜底抽薪(下法)으로 읽힐 여지.
- 바지 겨자색(黃)·저고리 회색의 뜻 불명. 바닥의 밝은 네모 햇빛 얼룩 2곳 뜻 불명.
- 오른쪽 끝 분홍 세로선 = 이어 붙인/잘라낸 흔적.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원**: **六經辨證** 60% (↑) / **八綱辨證의 表裏(半表半裏證)** 20% / 問診·切診 10%.
사전에 六經 이름 글자는 없지만 무대 글자가 1단계 독법을 그대로 받쳐 준다.

**② 인물** — **少陽病(半表半裏)**
- 문틀 = **門**(작은 문간). 문 밖 마당·기와집 = **表**(문 밖), 방바닥 쪽 = **內**(문 안쪽), 사람이 그 둘 사이 문간 한복판 = **中**(「둘 사이의 한복판」, 몸 위가 아니라 무대 위의 中) → 表와 裏 사이 = **半表半裏**. 경첩이 또렷한 문 = 樞(사전에 없음, 1단계 유지).
- 옆구리의 붉은 번짐: 사전 갈림상 살갗(옷) 위 얼룩은 瘀가 아니고 **그 자리의 색** → 자리 표지 = 脇 → **胸脇苦滿**. 쇠못이 없어 사전의 **痛** 글자는 쓰이지 않았고, 통증은 몸짓으로만 전함.
- 감은 눈은 사전의 **目**(크게 뜬 눈)의 반대, 앙다문 입은 **口**(어두운 타원)가 아님 → 目眩·口苦·咽乾은 글자로 확정되지 않음(1단계 독법 철회, 약한 몸짓 수준). 苦(검은 커피)·燥도 없음.
- 묶은 땔나무: 이삭이 없어 **收**(볏단) 아님, 손잡이 없어 **瀉**(짚 빗자루) 아님, **典藥**(약봉지 다발) 아님 → 사전 밖 글자 **柴** = 柴胡 → **小柴胡湯**. 문 안쪽(內)에 놓임 = 안에서 기다리는 처방.
- 관계: 인물은 1명. 사람↔문간 = 「表와 裏 사이의 中」 = 少陽은 太陽(表)·陽明(裏) 사이의 지도리. 사람↔柴 = 少陽 主方 柴胡劑(和解; 사전의 **和** 저울은 이 띠에 없음).

**③ 잔결**
- 배경 기와지붕 건물이 사전의 **寺**(기와지붕 절 한 채)로 샐 수 있음 — 절이라는 표지가 없어 寺로 읽지 않음.
- 왼쪽 흰 단지 2개·탁자 토막은 이웃 띠 몫으로 보이며 사전 글자(會·大·補)에 걸리지 않음.
- 겨자색 바지: 다섯 인물(五色 옷)이 아니라 일반인이므로 색을 읽지 않음.
- 오른쪽 끝 분홍 2px 세로선 = 잘라 붙인 흔적.
