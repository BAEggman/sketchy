# 901 판독 (O4)

## 1단계 — 생판 (사전 열기 전)

① 판 표제어
- 1순위 **補益劑(보익제) — 補氣·補血·氣血雙補·補陰補陽 方劑** (60%)
- 2순위 **本草 補益藥 + 溫裏藥(藥性 寒熱)** (20%) / 3순위 藥性 四氣(寒熱溫涼平) (10%)

② 구역·인물 (왼쪽부터)
1. **왼쪽 선반+네모 쟁반 = 四君子湯** — 선반 화분 4개 梅·蘭·菊·竹 = 「四君子」 말장난(→처방명). 쟁반 4약: 인삼(人蔘)·갈색 덩이(白朮)·흰 덩이(白茯苓)·노란 막대(甘草) + 김 나는 국그릇 = 湯劑. 사실 6개(방명, 구성 4, 탕제/補氣).
2. **가운데 네모 쟁반 = 四物湯** — 검붉은 뿌리(熟地黃)·주황 갈래 뿌리(當歸)·흰 원판(白芍)·주름진 연노랑 덩이(川芎) + 붉은 액체 그릇 = 血 → 補血. 사실 5개. 단, 연노랑 굽은 조각이 하나 더 있어 약이 5점.
3. **인물1: 검은 잠수복 사내 = 腎(黑·水)** — 왼손 얼음그릇: 붉은 알 **6알** + 붉은 막대 = **六味地黃丸**(補腎陰, 寒 쪽). 오른손 불그릇: 계피 막대 **2개(肉桂)** + 검은 덩이(附子) + 붉은 숯불 = 六味에 桂·附 더한 **腎氣丸(八味)** → 補腎陽(溫). 사실 4~5개.
4. **천칭(양 접시 수평)** — 氣血雙補 또는 陰陽平補(平) 1개.
5. **아래 둥근 쟁반 + 빛나는 진주 = 八珍湯** — 진주=珍, 위 두 쟁반 약이 한데 모임(四君+四物=氣血雙補). 약 **7점**+진주. 사실 3개.
6. **인물2: 문으로 들어오는 배 움켜쥔 환자 = 虛證/腹痛** — 이를 악물고 복부(붉은 통증 표시) 움켜쥠 → 中焦虛寒 腹痛(小建中湯·理中湯 류?) 또는 補益劑의 대상인 虛證. 사실 1~2개.
7. **문 곁 끈으로 묶은 나무 다발 = 黃芪 다발?** → 八珍+黃芪+肉桂 = 十全大補湯 추정(불그릇 肉桂와 짝). 1개.
8. **작은 탁자: 눈금 있는 토기잔(검은 탕액) 1 + 엎은 그릇 2** — 煎法·服法(3분 중 1? 日三服?) 추정, 확신 낮음.

③ 잔결
- 八珍湯이면 8약이어야 하나 둥근 쟁반은 7점+진주 — 노란 막대(甘草)가 안 보임.
- 四物 쟁반에 약 5점(4물보다 1개 많음).
- 얼음그릇 붉은 막대·엎은 그릇 2개·나무 다발 뜻 불확실. 환자 복통이 어느 방제를 가리키는지 단서 부족.
- 프레임 잘림: 오른쪽 아래 나무 다발이 프레임 끝에서 잘림. 가운데 칸막이 판자가 선반을 가로막아 이음 흔적처럼 보임(경미).

## 2단계 — 계통 (사전요약 적용)

① 판 표제어
- 1순위 **補益 — 補氣·補血·氣血雙補·補陰·補陽(補益劑 대표방: 四君子·四物·八珍·六味/腎氣)** (70%)
- 2순위 **本草 補益藥 + 溫裏藥(補·溫)** (20%)
사전이 1단계 해석을 대부분 굳혀 준다: 김(氣)+국물 그릇(補)=補氣, 붉은 것(血)+가득 찬 그릇(補-b)=補血, 잠수부=腎, 얼음은 살아 있는 불과 맞대어 있으므로 陰(갈림 조건 충족).

② 구역·인물 (왼쪽부터)
1. **四君子湯(補氣)** — 梅蘭菊竹=四君子(사전 밖 말장난), 人蔘·白朮·白茯苓·甘草 4약, 김 서린 따뜻한 국물=氣+補. 사실 6개.
2. **四物湯(補血)** — 검붉은 뿌리=**地黃**(사전 확정)·當歸·白芍·川芎 4약 + 붉은 액체 가득 찬 그릇=血+補-b. 사실 5개.
3. **인물1 잠수부 = 腎** — 얼음그릇(陰)에 地黃 막대+붉은 알 6=**六味地黃丸 → 補腎陰**; 불그릇(陽)에 肉桂 2+附子 → **腎氣丸 → 補腎陽**; 불 위 김=氣(陽氣). 두 그릇 다 가득 참=補-b. 사실 5개.
4. **둥근 쟁반+빛나는 진주 = 八珍湯(氣血雙補)** — 두 쟁반 약이 한 그릇 안에 모임(會), 진주=珍(사전의 華=빛나는 것과도 겹침). 사실 3개.
5. **수평 천칭 = 和** — 갈림 조건(수평으로 멎음) 충족 → 氣血(陰陽) 調和·雙補. 사실 1개.
6. **작은 탁자** — 김 없는 질그릇 잔의 검은 액체=**苦**(사전 확정). 셋 중 하나만 참 → 虛(1/3)일 수도. 補益 단원 안에서 苦가 무엇인지(苦寒 滋陰降火? 補劑 금기?) 미해결. 사실 1~2개.
7. **인물2 환자** — 문 밖→문 안(外→內/表→裏), 몸 한복판 움켜쥠=中 → 中焦 虛(寒) 腹痛 → 補中·溫中 대상. 쇠못·병표지 없음 → 사전상 痛·병표지 아님, 배의 붉은 얼룩은 瘀가 아니라 그 자리 색. 사실 2개.
8. **묶은 나무 다발** — 손잡이·이삭 없음 → 瀉·收 아님, 사전 밖. 黃芪 다발(十全大補) 또는 땔감(益火之源) 추정. 사실 1개(불확실).

③ 잔결
- 八珍 쟁반 7점+진주(甘草 막대 없음), 四物 쟁반 5점 — 개수 불일치.
- 苦 잔+엎은 빈 그릇 2, 나무 다발, 환자 복통의 표적 방제 — 사전으로도 안 풀림.
- 나무 다발 프레임 오른쪽 잘림. 이어 붙인 흔적은 뚜렷하지 않음.
- 판정: 사전 어휘로 補氣·補血·陰陽 축이 확정돼 1단계보다 잘 풀림.
