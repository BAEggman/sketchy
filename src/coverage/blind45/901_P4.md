# 901 판독 (P4)

## 1단계 — 생판 (사전 어휘 없이)

**① 판 표제어**
- 1순위: **補益劑(방제학) — 補氣·補血·氣血雙補·補陰/補陽 + 사용주의** (60%)
- 2순위: **本草 補虛藥 + 溫裏藥(補·溫)** (20%) / 3순위: 十全大補湯 계열 한 방 풀이 (10%)

**② 구역·인물 (왼→오)**
1. 왼쪽 선반+쟁반 — **四君子湯**: 화분 4개 梅·蘭·菊·竹 = "四君子"(방명). 쟁반 속 人蔘(뿌리)·白朮(갈색 덩이)·茯苓(흰 덩이)·甘草(노란 막대) = 4味, 김 나는 국그릇 = 湯劑. → 補氣 기본방 (6개).
2. 가운데 4칸 쟁반 — **四物湯**: 붉은 피 그릇 = 血 → 補血. 검붉은 뿌리 = 熟地黃, 주황 뿌리 = 當歸, 흰 원판 = 白芍, 물결 조각 = 川芎 (5개). 오른쪽 아래 굽은 담황 조각 1개는 남음.
3. 앞 둥근 쟁반 — **八珍湯**: 가운데 빛나는 진주 = 珍, 왼쪽·가운데 쟁반 약이 한데 모임 = 四君+四物 → 氣血雙補 (3개). 단 보이는 약은 7개(甘草 막대·茯苓 흰 덩이 안 보임).
4. 인물1 검은 잠수복 사내 — **腎의 補陰·補陽(六味地黃丸 / 腎氣丸)**: 검은색·물속 = 水·腎. 왼손 얼음 그릇 붉은 알 6개 = 六味, 寒·陰 → 補陰. 오른손 불 그릇 계피 2개 = 肉桂, 숯·붉은 조각 = 附子 → 補陽, 桂附 더하면 腎氣丸. 두 손 = 陰陽 나눔 (5개). (대안: 계피 = 十全大補湯의 肉桂)
5. 저울 — 빈 접시 두 개가 평형 = 陰陽 평형 / 平補 / 虛實 가리기 (1개, 불확실).
6. 인물2 문으로 들어오는 환자 — **補益劑 사용주의**: 배를 움켜쥔 통증, 문턱 = 邪가 남았을 때 補하면 閉門留寇 / 脾胃 허약하면 虛不受補. 장작 묶음 = 文火久煎. 검은 탕 한 잔 + 엎어 둔 빈 그릇 2개 = 空腹(식전) 복용 (4개).

**③ 잔결**: 가운데 쟁반의 5번째 굽은 조각 정체 불명. 앞 둥근 쟁반이 八珍인데 7味뿐. 얼음 그릇의 붉은 막대가 무엇인지 모름. 저울이 비어 있어 뜻이 약함. 선반과 카운터 사이 세로 칸막이판이 어색함. 오른쪽 가장자리에 2px 분홍 세로줄(이어 붙인 흔적 또는 인코딩 잔흔). 앞 쟁반 받침과 장작 묶음이 프레임에 잘림.

## 2단계 — 계통 (사전요약 어휘로 다시 읽기)

사전으로 더 잘 풀린다. 잠수부 = 腎으로 확정되고, 補(찰랑이게 찬 국물)·氣(김)·血(붉은 것)·陰(산 불과 맞댄 얼음)·陽(불)·和(수평 저울)·地黃(검붉은 뿌리)·門·苦가 맞물린다.

**① 판 표제어**
- 1순위: **補益劑 — 補氣(四君子湯)·補血(四物湯)·氣血雙補(八珍湯)·補腎陰/補腎陽(六味地黃丸·腎氣丸) + 사용주의** (70%)
- 2순위: **補虛藥 4분류(補氣·補血·補陰·補陽, 本草)** (15%)

**② 구역·인물 (왼→오)**
1. 왼쪽 쟁반 — **補氣 / 四君子湯**: 김이 서린 찬 국물 = 補 + 氣 → 補氣. 화분 梅蘭菊竹 = 四君子, 人蔘·白朮·茯苓·甘草 4味 (6개).
2. 가운데 쟁반 — **補血 / 四物湯**: 붉은 국물을 가득 담은 그릇 = 補 + 血 → 補血. 검붉은 뿌리 = 地黃(熟地黃), 當歸·白芍·川芎 (5개).
3. 앞 둥근 쟁반 — **氣血雙補 / 八珍湯**: 진주 = 珍, 한 쟁반에 다 담김 = 會 → 四君+四物 (3개).
4. 인물1 잠수부 = **腎(補腎陰·補腎陽)**: 얼음 그릇이 산 불그릇과 맞대 있음 = 陰, 담긴 것 = 地黃 막대 + 붉은 알 6개 → 補腎陰, 六味地黃丸. 불그릇 = 陽, 肉桂 2개 + 검은 덩이(附子)에 김(氣) → 補腎陽, 桂附를 더한 腎氣丸 (6개).
5. 저울 — 양팔이 수평 = **和** → 陰陽 조화 / 陰中求陽 (1개, 자리가 애매함).
6. 인물2 환자 — **補益劑 사용주의**: 門(문틀)을 밖에서 넘어옴 = 表邪 미해 → 閉門留寇. 배를 움켜쥠 + 엎어 둔 빈 그릇 2개(받지 못함) → 脾胃가 약하면 虛不受補. 질그릇 검은 잔 = 苦. 장작 = 文火久煎 (4~5개).

**③ 잔결**: 장작 묶음은 사전에 없음(瀉 짚 빗자루와 비슷하나 짚·손잡이 없음). 엎은 빈 그릇은 瀉-b(쏟아진 내용물)가 아니라 사전 밖. 苦 잔이 補益劑의 어느 사실을 나르는지 연결 약함. 진주의 빛 = 華로 겹쳐 읽힐 수 있음. 환자 배의 붉은 얼룩은 瘀가 아니고(살갗 위 색) 痛 쇠못도 없음. 가운데 쟁반 5번째 조각 정체 불명. 둥근 쟁반 7味(八珍인데 甘草·茯苓 결). 화분 4개는 사전 밖 말장난. 오른쪽 가장자리 2px 분홍 세로줄, 프레임 잘림(앞 쟁반 받침·장작).
