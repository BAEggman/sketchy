# 902 판독 (Q4)

## 1단계 — 생판 (사전요약 열기 전 확정)

**① 판 표제어**
- 1순위: **補益劑 — 補氣(四君子湯)·補血(四物湯)·氣血雙補(八珍湯) + 補陰/補陽** (70%)
- 2순위: **補益·溫裏(本草/方劑의 補와 溫 — 寒熱 대비)** (20%)
- 기타: 藥性 四氣(寒·熱·平) 10%

**② 구역·인물 (왼쪽부터)**
1. 왼쪽 선반+쟁반① — **四君子湯(補氣)**: 선반 화분 梅·蘭·菊·竹 4개 = "四君子" 이름 말장난. 쟁반 4약: 산삼 뿌리=人蔘, 갈색 덩이=白朮, 흰 덩이=白茯苓, 노란 막대=甘草(4味). 김 나는 국그릇=湯(달임) 또는 生薑·大棗.
2. 가운데 쟁반② — **四物湯(補血)**: 검붉은 뿌리=熟地黃, 주황 갈래뿌리=當歸, 흰 원판=白芍藥, 물결 절편=川芎(4味). 붉은 액체 그릇=血 → 補血. 오른쪽 아래 칸은 갈색 원만 있는 빈칸(뜻 불명).
3. 인물1 잠수부(검은 잠수복·물안경) — **補陰 vs 補陽(腎陰·腎陽)**: 검정+물 = 水·腎. 왼손 얼음 그릇: 붉은 열매 6알(六味? 山茱萸)+붉은 막대(牡丹皮?) → 寒涼 滋陰(六味地黃丸). 오른손 불 그릇: 계피 막대 2=肉桂, 숯 같은 검은 덩이=附子, 숯불=溫熱 → 桂附 = 補陽/溫裏(腎氣丸·八味). 肉桂는 十全大補湯 가미(黃芪·肉桂)로도 읽힘.
4. 저울(가운데) — **평형 = 氣·血 균형 → 氣血雙補** (또는 平性).
5. 아래 둥근 쟁반 — **八珍湯(氣血雙補)**: 쟁반①②의 8약(人蔘·白朮·茯苓·甘草·熟地黃·當歸·白芍·川芎)이 한 쟁반에 모이고 가운데 빛나는 진주=「珍」. 8개.
6. 인물2 문으로 들어오는 환자(회색 저고리·노란 바지) — **中焦虛寒 腹痛 → 溫裏(理中湯/小建中湯)**: 윗배를 움켜쥐고 붉은 통증선, 이를 악묾. 밖에서 들어옴 = 寒邪 直中? 노란 바지 = 脾土?
7. 오른쪽 아래 탁자 — 검은 탕 1잔+빈 사발 2(3그릇 = 一日三服?)+잔가지 다발(桂枝? 땔감=煎藥 火候). 뜻 확정 못함.

**③ 잔결**
- 쟁반② 빈 칸의 갈색 원(지운 자국 같음).
- 아래 쟁반 노란 막대(甘草) 주위 들쭉날쭉 스케치 선·갈색 얼룩 = 덧붙이거나 지운 흔적.
- 얼음 그릇의 붉은 막대, 오른쪽 아래 그릇 3개·잔가지 다발 뜻 모름. 환자의 노란 바지 의미 불확실.
- 프레임 잘림 없음(잔가지 다발만 오른쪽 아래 테두리에 닿음).

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위: **補益 — 補氣(四君子)·補血(四物)·氣血雙補(八珍)·補腎陰/補腎陽(六味↔腎氣)** (85%)
- 2순위: **補益 + 溫裏(本草 補·溫 단원)** (10%) · 藥性 寒熱 5%
- 판정: 어휘로 더 잘 풀린다. 쟁반 두 개의 그릇이 補·補-b 문법과 정확히 맞고, 잠수부가 腎으로 확정되어 1단계의 「寒熱 대비」 추정이 「腎陰·腎陽 補」로 좁혀졌다.

**② 구역·인물 (왼쪽부터)**
1. 선반+쟁반① — **補氣 = 四君子湯**: 김 오르는 따뜻한 국 = 補(국물)+氣(서린 김) → 補氣. 梅蘭菊竹 = 「四君子」(사전 밖 말장난), 人蔘·白朮·茯苓·甘草 4味. 6개.
2. 쟁반② — **補血 = 四物湯**: 붉은 것이 가득 찬 그릇 = 補-b(담긴 것=血) → 補血. 검붉은 뿌리 = 地黃(사전 등재 → 熟地黃 확정), 當歸·白芍·川芎. 5개.
3. 인물1 검은 잠수복·후드·고글 = **腎** (사전 확정) — 얼음 그릇이 살아 있는 불 그릇과 맞대어 있으므로 얼음 = 陰 → 가득 찬 그릇(補-b) = **補腎陰**: 검붉은 막대 = 地黃 + 붉은 열매 6알(山茱萸/「六味」) → 六味地黃丸. 불 그릇 = 陽 → **補腎陽**: 肉桂 2 + 검은 덩이 附子 → 桂附 = 腎氣丸(六味+桂附). 7개.
4. 저울 — 양팔이 수평으로 멎음 = **和** (갈림 조건 충족). 陰陽·氣血을 고르게 함(補의 목표). 1개.
5. 아래 둥근 쟁반 — **氣血雙補 = 八珍湯**: ①+②의 8味가 한 그릇에(會) + 빛나는 진주(珍). ⚠ 사전상 「빛나는 것 = 華」와 샐 수 있으나 8味와 묶이면 珍이 자연스럽다. 2개.
6. 인물2 문으로 들어서는 환자 — **腹痛(표제 미확정)**: 사전의 痛(쇠못)·寒(눈송이)·五色 인물 표지가 없음 → 장부·병인을 지정하지 못함. 문 밖→문 안 = 外→內 정도. 1개.
7. 오른쪽 아래 탁자 — 김 없는 질그릇 잔의 검은 액체 = **苦**(사전 정확 일치). 엎어 둔 빈 사발 2·잔가지 다발은 사전에 없음(瀉-b는 쏟아진 내용물이 없어 불성립, 瀉 빗자루는 손잡이 없어 불성립). 苦 1개 + 미상 2.

**③ 잔결**
- 쟁반② 빈 칸의 갈색 원(지운 자리).
- 아래 쟁반 甘草 막대 주위 들쭉날쭉 선·갈색 얼룩 = 덧붙인/지운 흔적.
- 환자와 오른쪽 아래(苦·엎은 사발·잔가지)가 보익 계통과 연결되지 않음 — 補益 금기(脾胃虛·實證에 補 → 虛不受補?) 또는 溫裏(桂枝?) 추정만 가능.
- 그림 오른쪽 끝 세로 분홍 선(가장자리 흔적).
