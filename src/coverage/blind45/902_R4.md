# 902 판독 R4

## 1단계 — 생판 (사전 없이)

**① 판 표제어**
- 1순위: **補益劑 — 補氣(四君子湯)·補血(四物湯)·氣血雙補(八珍湯)** (55%)
- 2순위: **本草·方劑의 「補·溫」 묶음(補益 + 溫裏/寒熱藥性)** (25%) — 그 밖에 方劑總論(劑量·煎服法) 가능성 약간.

**② 구역·인물별 (왼쪽부터)**
1. **왼쪽 선반+쟁반 — 四君子湯**: 화분 4개 梅·蘭·菊·竹 = 「四君子」 말장난 → 처방명. 쟁반의 인삼(人蔘)·갈색 덩이(白朮)·흰 덩이(白茯苓)·노란 막대(甘草) = 구성 4味, 김 나는 국그릇 = 湯(劑型·煎劑). → 6개.
2. **가운데 쟁반 — 四物湯**: 검붉은 뿌리(熟地黃)·주황 갈래뿌리(當歸 또는 川芎)·물결 절편(川芎 또는 當歸)·흰 원판(白芍藥) 4味 + 빨간 액체 그릇 = 血(補血). 오른쪽 아래 칸 한 자리는 빈 얼룩. → 5개.
3. **잠수복 인물(중앙) — 寒熱 藥性(四氣)**: 왼손 얼음그릇(고드름) = 寒涼藥(붉은 알 7개 + 붉은 막대: 丹參·赤芍류 寒性 紅藥?), 오른손 김·불씨 그릇 = 溫熱藥(계피 2개 = 肉桂/桂枝, 검은 덩이 = 炮附子, 붉은 숯 = 火). 잠수(潛·沈) = 裏/沈降? 뜻 확정 못 함. → 3~4개.
4. **천칭** — 두 접시 비어 수평 = 平(平性) 또는 劑量·稱量. → 1개.
5. **아래 둥근 쟁반 — 八珍湯**: 위 두 쟁반 8味(人蔘·白朮·茯苓·甘草·熟地·當歸·川芎·白芍)가 한 접시에 합쳐짐 + 가운데 빛나는 진주 = 「珍」 → 八珍湯 = 四君子+四物, 氣血雙補. → 3개.
6. **문간 환자(오른쪽)** — 배(명치·위완)를 움켜쥐고 붉게 아픔 = 脘腹痛(裏寒 腹痛/脾胃虛) → 溫裏·補氣의 적응증. 곁 탁자: 짙은 탕약 잔 = 湯藥 服用, 엎어진 빈 그릇 2개 = 空腹服 또는 2회 분복, 묶은 장작 = 煎藥 불(火候) 또는 「柴」. → 4개.

**③ 잔결**
- 가운데 쟁반 오른쪽 아래 칸에 둥근 갈색 얼룩(지운 소품 자국).
- 아래 둥근 쟁반 오른쪽 가장자리에도 큰 갈색 지운 자국, 노란 막대(甘草) 둘레에 떨림선 — 덧그린 흔적.
- 잠수복 인물은 장면(한옥 약방)과 이질적, 뜻 미확정. 얼음그릇의 붉은 막대·붉은 알 정체 불명.
- 프레임 잘림은 없음(오른쪽 장작 다발이 테두리에 닿음).

## 2단계 — 계통 (사전요약 읽은 뒤)

**① 판 표제어**
- 1순위: **補益 — 補氣·補血·氣血雙補·補陰·補陽 (四君子湯·四物湯·八珍湯·六味/八味地黃丸)** (65%)
- 2순위: **補瀉 治法 — 虛則補之 ↔ 實則瀉之 (가운데 和)** (20%)
- 사전으로 풀리는 정도가 1단계보다 훨씬 낫다. 수수께끼였던 잠수부(=腎)와 천칭(=和)이 풀리고, 오른쪽 구석이 「瀉」 쪽 대비로 읽힌다.

**② 구역·인물별 (왼쪽부터)**
1. **왼쪽 선반+쟁반 — 補氣(四君子湯)**: 梅蘭菊竹 = 四君子. 人蔘·白朮·茯苓·甘草 4味. 김 오르는 따뜻한 국그릇 = 補(따뜻한 국물)+氣(흰 김) → 「補氣」. → 6개.
2. **가운데 쟁반 — 補血(四物湯)**: 검붉은 뿌리 = 地黃(사전 확정)·當歸·川芎·白芍藥 4味. 빨간 액체 가득한 그릇 = 補-b(가득 담김)+血(붉은 것) → 「補血」. → 5개.
3. **잠수부 = 腎 — 補腎陰·補腎陽**: 얼음그릇이 살아 있는 불 그릇과 맞대어 있으므로 갈림 조건이 충족되어 陰이고, 불 그릇은 陽이다. 둘 다 가득 차 補-b → 腎陰·腎陽을 채움. 얼음그릇 속 붉은 알 **6개**(山茱萸?) + 검붉은 막대(地黃 조각) = **六味地黃丸**(補腎陰). 불 그릇의 계피 2(肉桂)·검은 덩이(附子)·김(氣) = 六味+桂附 = **八味(腎氣丸)**(補腎陽·補火). → 7개.
4. **천칭 — 和**: 양팔이 수평으로 멎어 있다 → 和(陰陽 調和, 또는 補瀉 사이의 和法). → 1개.
5. **아래 둥근 쟁반 — 八珍湯**: 위 두 쟁반의 8味가 한 접시에 모였다 = 四君子+四物. 빛나는 진주 = 「珍」(사전상으로는 華=빛나는 것과 겹친다) → 氣血雙補. → 3개.
6. **문간 환자 — 瀉(實則瀉之) 쪽 대비**: 작은 문간 = 門(밖→안). 배를 움켜쥔 붉은 얼룩은 그 자리의 색이지 瘀가 아니다 → 腹痛(實). 질그릇 잔에 김 없는 검은 액체 = 苦(온전한 꼴). 묶은 잔가지 다발 = 瀉(빗자루, 60%)/땔나무(40%). 엎어진 빈 그릇 2개 = 瀉-b의 「텅 빈 그릇」만 있고 흘러넘친 내용물은 없다(불완전) → 苦泄·瀉下. → 4~5개.

**③ 잔결**
- 가운데 쟁반 오른쪽 아래 칸과 둥근 쟁반 오른쪽 가장자리에 지운 갈색 얼룩 2곳이 있다. 둥근 쟁반의 노란 막대에는 떨림선이 있어 덧붙인 흔적으로 보인다.
- 장작/빗자루 다발은 손잡이도 이삭도 없어 瀉와 收 어느 쪽인지 애매하다. 빈 그릇 2개의 뜻도 미확정(瀉-b 불완전 또는 虛).
- 진주는 사전에 없다(八珍의 珍인지 華인지). 프레임 잘림은 없다.
