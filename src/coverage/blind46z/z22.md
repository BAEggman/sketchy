# z22 판독 (blind46z)

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원**: **七情(情志內傷)의 氣機 변화 — 「百病生於氣」 九氣**(素問·擧痛論) 80%. 차순위 **內傷病因 총론** 15%.

**② 인물·소품·배경**
- 왼쪽 인물 = **怒(怒則氣上)**. 상투 자리에서 김 기둥 1줄이 수직으로 치솟음 → 氣가 위로 거슬러 오름(氣上). 얼굴 시뻘겋고 눈썹 치켜뜸 → 面紅目赤, 血이 氣를 따라 위로(甚則嘔血). 두 주먹 꽉 쥠 → 怒 = 肝(木)의 志, 怒傷肝. 상투가 없고 그 자리가 분출구 → 머리 꼭대기(巓頂)로 몰림.
- 오른쪽 인물 = **喜(喜則氣緩)**. 눈 감고 활짝 웃음, 볼 발그레 → 喜 = 心(火)의 志, 心其華在面. 김이 목깃(가슴 위)에서 좌우 2줄로 **수평으로 느슨하게** 흘러 퍼짐 → 氣緩(心氣渙散, 지나치면 神不守舍). 손바닥 편 채 늘어뜨림 → 이완. 상투 단정 → 위로 솟지 않음.
- 배경: 붉은 토담 + 이엉 지붕 → 붉은색 = 火·心? (확신 낮음). 두 사람 같은 옷·같은 자세 = 한 계열(감정 연작)의 구성원.
- **관계**: 같은 김(氣)을 한 사람은 **세로 위로**, 한 사람은 **가로로 흩어지게** → 감정마다 氣의 방향이 다르다(上 vs 緩)는 대비. 좌→우 순서 怒→喜는 擧痛論 나열 순서(怒·喜·悲·恐…)이자 木生火(肝→心) 상생 순서와 일치 → 다음 띠에 悲(氣消)·恐(氣下)가 이어질 것.

**③ 잔결**: 왼쪽 가장자리 초가 정자(기둥·평상)는 뜻 미상 — 왼쪽 이웃 띠 몫일 가능성. 오른쪽 끝 회색 옷자락 한 줄 = 다음 인물(무시). 喜의 김이 귀가 아니라 목깃에서 나오는 점이 조금 애매(가슴=心으로 읽음). 이어 붙인 흔적(담장 높이 불연속 등)은 찾지 못함.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원**: **九氣(百病生於氣) — 七情內傷의 氣機失調** 85%. 사전에 上·下·散·收가 따로 등재돼 있어 「氣 + 방향 글자」로 九氣(怒上·喜緩·悲消·恐下·寒收·炅泄·驚亂·勞耗·思結)를 줄줄이 세우는 판으로 읽힌다. 차순위 **七情 단독** 10%.

**② 인물·소품·배경**
- 왼쪽 = **怒則氣上**. 흰 김 = 氣, 「머리 꼭대기로 곧게 솟음」 = 上 → 글자 그대로 「氣上」. 1단계보다 확실해짐. 붉은 얼굴엔 광택이 없어 面 글자가 아님(얼굴색은 望色 판 전담) → 성난 표정의 연출일 뿐, 血 글자로 따로 세지 않음. 주먹·노려보는 눈은 怒의 연기.
- 오른쪽 = **喜則氣緩**. 같은 흰 김(氣)이 목깃에서 좌우로 느슨히 퍼짐. 「사방으로 흩어져 날림」(散)에 가깝지만 두 갈래뿐이고, 한쪽으로 눕는 風도 아님 → 사전에 없는 **緩**(풀어져 퍼짐, 神憚散)으로 판정.
- 두 사람 옷은 회색 저고리·누런 바지 → 오행왕국 다섯 인물(肝 장군·心 임금)이 아님 → 옷 색을 五色으로 읽지 않음. 怒傷肝·喜傷心은 그림에 실리지 않음.
- 배경: 정자·평상과 같은 쪽, 담 앞 마당에 섬 → 「담 안쪽」 = **內** → 七情은 內因(內傷)이라는 공통 사실. 다만 담 어느 쪽인지 단정하기 어려움(확신 60%).
- **관계**: 같은 氣 글자를 방향만 바꿔 실었다. 감정이 다르면 氣機 방향이 다르다(上 vs 緩). 나란히 선 순서 怒→喜 = 擧痛論 나열 순서.

**③ 잔결**: 緩은 사전에 없음(散과 風 사이). 붉은 토담이 「붉은 것 = 血」로 오독될 위험이 있음. 왼쪽 끝 이엉 정자 지붕은 「넓게 펼친 차양 = 廣」과 헷갈릴 수 있음(이웃 띠 몫으로 봄). 붉은 얼굴·볼은 광택이 없어 글자가 아닌 연출.
