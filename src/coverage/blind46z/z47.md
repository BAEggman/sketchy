# z47 판독 (blind46z)

## 1단계 — 생판 (사전 열기 전)

① 단원: **九氣(百病生於氣·素問 擧痛論)** 60% / 차순위 **七情內傷(七情致病의 氣機)** 30%

② 인물 (같은 차림의 한복 남자 둘, 붉은 흙담·초가 담장 앞)
- 왼쪽 = **悲則氣消**: 눈물을 흘리는 슬픈 얼굴(悲). 가슴 깃 아래에서 발끝까지 몸이 반투명하게 비치며 흐릿한 흰 기둥처럼 빠져 사라진다 → 氣가 소모·소실됨(氣消). 가슴(上焦·肺 자리)에서 시작 → 悲則心系急·肺布葉擧·上焦不通·營衛不散·熱氣在中 故氣消.
- 오른쪽 = **恐則氣下**: 눈을 크게 뜨고 입 벌린 공포의 얼굴, 이마 땀 한 방울, 눈 밑 거뭇함(腎色 黑?). 두 손으로 무릎을 짚고 무릎이 꺾여 주저앉으려 함, 가랑이에서 땅으로 세로 줄이 쏟아지고 발밑에 먼지가 인다 → 氣가 아래로 가라앉음(氣下). 恐則精却 → 上焦閉 → 下焦脹; 무릎 꺾임 = 恐傷腎·骨痠痿, 바지 무릎의 짙은 얼룩 = 二便失禁 암시.
- 관계: 擧痛論 九氣 순서에서 悲消(3)·恐下(4)가 이웃 → 판 위에서도 나란함. 悲=肺(金)→恐=腎(水) 金生水. 둘 다 氣가 줄고 내려가는 「虛 쪽」 九氣(怒上과 대비). 이 띠는 9개 중 2개를 나른다.
- 배경 담장 = 같은 무대(공통 배경, 별도 사실 불명).

③ 잔결: 좌우 가장자리 담에 붙은 흰 뭉게 뭉치(이웃 띠 몫, 왼쪽은 큰 뭉치+검은 호, 오른쪽은 여러 높이로 흩어진 작은 뭉치). 오른쪽 인물 이마의 땀 한 방울과 눈 밑 그늘은 뜻이 확정 안 됨. 왼쪽 반투명 기둥이 「消」인지 「下」인지 애매. 이어 붙인 흔적은 안 보임.

## 2단계 — 계통 (blind6_사전요약 적용)

① 단원: **九氣(百病生於氣)** 70% — 사전의 氣 = 「서린 흰 김」으로 왼쪽 반투명 기둥과 좌우 가장자리 뭉치가 모두 氣로 풀리므로, 판 전체가 「七情 등 → 氣의 움직임」을 다루는 九氣판임이 굳어진다. 차순위 **七情內傷** 25%.

② 인물
- 왼쪽 = **悲則氣消**: 가슴에서 빠져나와 몸을 비우며 바닥까지 흐려지는 흰 김 = 氣가 사라짐(消). 눈물(맑은 물방울 = 津 사전어와 겹침)은 悲 표정으로 읽음.
- 오른쪽 = **恐則氣下**: 사전 下 = 「아래로 가라앉거나 쏟아짐」 — 가랑이에서 땅으로 쏟아지는 줄 + 꺾여 주저앉는 무릎 = 下. 크게 뜬 눈은 目, 이마 방울은 汗 사전어와 겹치나 놀람 표정으로 읽음. 恐傷腎·精却·下焦脹.
- 배경: 담 앞 = 內(담 안쪽)라면 七情 = 內因(內傷)을 싣는다(약하게).
- 관계: 擧痛論 순서 3·4 연속, 金(肺·悲)→水(腎·恐) 母子. 가장자리 뭉치 = 이웃 氣(왼쪽 큰 뭉치 喜緩?, 오른쪽 여러 높이로 흩어진 뭉치 = 散 → 驚則氣亂? 또는 寒收).

③ 잔결: 왼쪽 흰 김이 바닥까지 흘러내려 사전 下(가라앉음)로도 읽혀 오른쪽 「氣下」와 충돌함 — 消를 나르는 전담 기호가 사전에 없다. 오른쪽 이마의 땀(汗)·크게 뜬 눈(目)·왼쪽 눈물(津)이 사전어와 겹쳐 덤 사실(炅則氣泄의 汗 등)로 샐 수 있음. 바지 무릎의 짙은 얼룩은 요강(小便)이 없어 失禁으로 확정되지 않음.
