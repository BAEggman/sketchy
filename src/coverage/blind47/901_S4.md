# 901 판독 (S4)

## 1단계 — 생판 (사전 어휘 없이)

**① 판 표제어**
- 1순위: **七情內傷의 氣機失調 — 『素問·擧痛論』 九氣 중 情志 六氣(怒上·喜緩·悲消·恐下·驚亂·思結)** (85%)
- 2순위: **七情과 五臟 (五志傷臟: 怒傷肝·喜傷心·悲傷肺·恐傷腎·思傷脾)** (10%)
- 근거: 같은 옷차림의 한 사람이 감정만 바꿔 6번 서 있고, 각자 몸 둘레의 김(氣)이 방향만 다르다. 순서가 擧痛論 원문 「怒則氣上, 喜則氣緩, 悲則氣消, 恐則氣下, (寒收·炅泄), 驚則氣亂, (勞耗), 思則氣結」에서 寒·炅·勞를 뺀 순서와 정확히 같다.

**② 인물별 (왼쪽부터)**
1. **怒則氣上** — 정수리에서 김이 곧게 위로 치솟음(氣上·氣逆 1), 붉은 얼굴(面赤 = 氣逆, 甚則嘔血 쪽 1), 쥔 주먹·찌푸린 눈썹(怒 1). → 3개
2. **喜則氣緩** — 웃는 얼굴(喜 1), 목·가슴께에서 김이 양옆으로 느슨하게 2줄 퍼져 나감(氣緩 = 志達·營衛通利, 기가 풀려 흩어짐 1), 힘 뺀 손(緩 1). → 3개
3. **悲則氣消** — 눈물 두 줄(悲 1), 몸통 위를 덮고 발밑까지 흘러내리며 몸을 흐리게 지우는 흰 김의 막(氣消 = 기가 사그라짐 1), 가슴(上焦)부터 덮여 肺·上焦 쪽 암시(1, 약함). → 3개
4. **恐則氣下** — 겁에 질린 입·식은땀 한 방울(恐 1), 무릎 굽혀 주저앉음(氣下·精卻 1), 바지 다리에서 땅으로 줄줄 흐르는 물줄기와 발밑 웅덩이·무릎 뒤 젖은 얼룩(二便失禁/遺尿 1). → 3개
5. **驚則氣亂** — 눈 휘둥그레·벌린 입·들어 올린 손(驚 1), 몸 사방으로 방향 없이 튀는 김 약 10덩이(氣亂 = 心無所倚·神無所歸·慮無所定 1). → 2개
6. **思則氣結** — 턱 괸 손·팔짱(思 1), 머리 위 실타래처럼 묶인 매듭 구름과 그 꼬리가 정수리로 이어짐(氣結 = 心有所存·神有所歸·正氣留而不行 1), 내리뜬 눈(1). → 3개

**③ 잔결**
- 왼쪽 초가(마루 달린 집)는 왼쪽 프레임에 잘려 있고 뜻을 모르겠다(배경일 수도).
- 붉은 담장(위에 짚 이엉)은 전 인물 공통 배경 — 心(七情은 모두 心에서) 암시일 수도 있으나 불명.
- 七情 중 **憂**가 없고, 九氣 중 寒收·炅泄·勞耗 3기도 없다(의도적 생략으로 보임).
- 장부 표지(肝·心·肺·腎·脾)가 될 소품은 보이지 않는다. 이어붙인 흔적은 못 찾았다.

## 2단계 — 계통 (사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위: **七情內傷의 氣機失調 — 擧痛論 九氣 중 情志 六氣(怒上·喜緩·悲消·恐下·驚亂·思結)** (92%)
- 2순위: **七情 = 內因 病因 총론 (五志傷臟 포함)** (5%)
- 사전으로 더 잘 풀리는 것: 흰 김이 모두 「氣」로 확정되고, 인물들이 초가 마당 안, 담 앞에 서 있어 「內 = 담 안쪽·문 안쪽」. 그래서 이 감정들이 **안에서 생긴 內傷**이라는 사실이 배경에 실린다(1단계에서 못 풀던 초가·담이 풀림). 다섯 臟 인물(장군·임금·농부·재상·잠수부)과 五色 옷이 하나도 없다. 그래서 五志傷臟의 장부 배당은 이 판에 없다고 본다. 2순위는 낮아진다.

**② 인물별 (왼쪽부터)**
1. **怒則氣上**: 정수리에서 곧게 솟는 흰 김 = 氣+上(氣上). 붉은 얼굴은 「血 = 붉은 것」으로 읽으면 피가 氣를 따라 오름(氣逆·甚則嘔血)이다. 다만 얼굴색은 望色 전담이라 약하게 잡는다. 주먹·찌푸림 = 怒. → 3개
2. **喜則氣緩**: 웃음 = 喜. 양옆으로 느슨히 풀려 흐르는 김 두 줄 = 氣가 풀림(緩). 두 줄을 營·衛로 보면 「營衛通利」인데, 이건 추정이다. → 2개(+1 추정)
3. **悲則氣消**: 눈물 = 悲. 몸을 덮고 엷어지며 흘러내리는 김 막 = 氣가 사그라짐(消). → 2개
4. **恐則氣下**: 질린 얼굴 = 恐. 다리 사이로 땅까지 쏟아지는 흰 줄은 「下 = 쏟아짐」+「氣」, 곧 氣下다. 요강(小便)이 없으므로 1단계의 「遺尿·二便失禁」은 내린다. 주저앉음은 精卻·下焦 쪽(약). 이마 땀방울 = 「汗」 기호다(驚恐 汗出로 읽힐 수 있으나 불명). → 3개
5. **驚則氣亂**: 휘둥그런 눈·든 손 = 驚. 몸 사방으로 튀는 김 약 10덩이 = 「散」 기호+氣. 사전에는 亂 전담 기호가 없어 散과 겹친다. 그래도 표정으로 氣亂이 된다. → 2개
6. **思則氣結**: 턱 괸 손·팔짱 = 思. 머리 위에 매듭으로 묶인 김 = 氣結. 꼬리가 정수리로 이어진 것은 心有所存·神有所歸, 곧 氣가 머물러 돌지 않음(正氣留而不行)이다. → 3개

**③ 잔결**
- 초가는 왼쪽 프레임에 잘렸지만, 「內(문·담 안쪽)」 무대로 뜻이 풀린다. 붉은 담 색은 여전히 뜻이 불명이다(心 임금 기호는 아님).
- 기호가 충돌한다. ⑤驚의 사방 김은 「散」으로, ③悲의 흘러내리는 김막은 「下」로 오독될 위험이 있다(④와 겹침).
- ④의 땀방울(汗)과 ③의 눈물, ④·⑤의 벌린 입(口)·크게 뜬 눈(目)은 표정인지 기호인지 불명이다.
- 七情의 憂와 九氣의 寒收·炅泄·勞耗가 없다(의도적 생략으로 보임). 이어붙인 흔적은 없다.
