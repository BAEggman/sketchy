# 901 판독 (T4)

## 1단계 — 생판 (사전 없이)

**① 판 전체 표제어**
- 1순위 **七情 致病 — 氣機失調 (「百病生於氣也」, 怒上·喜緩·悲消·恐下·驚亂·思結)** — 85%
- 2순위 **素問 擧痛論 九氣** (그중 情志 6氣만 그림, 寒收·炅泄·勞耗 빠짐) — 10%
- 나머지 5%: 七情傷五臟(怒傷肝 등) 쪽으로 읽힐 여지

**② 인물별 (왼쪽부터) — 같은 옷·같은 머리의 동일 인물 6명, 표정과 기운(김)의 방향만 다름**
1. **怒則氣上** — 붉은 얼굴(面赤, 血菀於上)·찡그린 눈썹·움켜쥔 두 주먹(怒), 정수리에서 위로 곧게 솟는 김 기둥 1줄 + 끝의 구름(氣上逆). 사실 3개.
2. **喜則氣緩** — 눈 감고 활짝 웃음(喜), 양 어깨에서 옆으로 느슨하게 풀려 나가는 김 2줄(氣緩·氣渙散, 志達). 사실 2개.
3. **悲則氣消** — 눈물 두 줄·처진 입(悲), 몸통과 다리가 반투명해지며 김이 흘러내려 사라짐(氣消, 몸이 지워짐). 사실 2개.
4. **恐則氣下** — 겁에 질린 큰 눈·벌린 입·관자놀이 식은땀 1방울(恐), 무릎이 꺾여 주저앉는 자세(下), 가랑이 사이로 땅까지 떨어져 고이는 김/물줄기(氣下·精却, 遺尿 연상 → 恐傷腎). 사실 3개.
5. **驚則氣亂** — 휘둥그런 눈·벌린 입·두 손을 들어 놀람(驚), 몸 사방으로 제각각 터져 나가는 김 덩이 약 8~9개(氣亂, 무방향). 사실 2개.
6. **思則氣結** — 턱 괴고 팔짱, 시선 아래(思), 머리 위에 엉켜 뭉친 매듭 구름 1개(氣結). 사실 2개.

배경: 왼쪽 초가 정자(마루 딸림), 붉은 담장 + 이엉 지붕 + 아래 돌 기단, 흰 마당. 한의학 사실은 읽히지 않음(무대 배경으로 봄).

**③ 잔결**
- 七情 중 **憂**가 없음(悲에 합쳐 6인으로 처리한 듯). 九氣로 보면 寒·炅·勞 3氣도 없음.
- 왼쪽 초가가 프레임에 잘림(지붕·기둥 반쪽). 붉은 담장·초가의 뜻 불명.
- 3번의 아래로 흐르는 김은 4번 「氣下」와 방향이 겹쳐 혼동 소지.
- 이어 붙인 흔적은 보이지 않음(한 장 생성으로 보임).

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 전체 표제어**
- 1순위 **七情 內傷 — 情志가 氣機를 어지럽힘 (怒則氣上·喜則氣緩·悲則氣消·恐則氣下·驚則氣亂·思則氣結)** — 88%
  - 사전 「氣 = 서린 흰 김」으로 여섯 사람의 김이 모두 氣임이 확정 → 판 주제가 「情 → 氣의 움직임」임이 1단계보다 단단해짐.
  - 사전 「內 = 담 안쪽」: 여섯 사람이 붉은 담 **안쪽** 마당(초가 정자까지 담 안)에 서 있음 → 七情은 **內因·內傷**이라는 사실 1개를 배경이 나름. 1단계에서 뜻 모를 배경이던 담이 풀림.
- 2순위 **素問 擧痛論 九氣(百病生於氣)의 情志 6氣** — 9%

**② 인물별 (왼쪽부터)** — 모두 같은 회색 저고리·황토 바지: 오행 다섯 인물(五色 옷)이 아니므로 臟 인물로 읽지 않음.
1. **怒則氣上** — 「上 = 머리 꼭대기로 곧게 솟음」+「氣 = 흰 김」이 정확히 맞물림(氣上). 붉은 얼굴·주먹 = 怒. 붉은 얼굴은 「面」 갈림상 얼굴색은 望色 전담이라 별도 글자로 세지 않음(血菀於上로 읽고 싶으나 보류). 사실 2개(+보류 1).
2. **喜則氣緩** — 웃음 = 喜, 양 어깨에서 **양옆으로** 느슨히 풀려 나가는 김 = 氣緩. 「風 = 한쪽으로 눕고 옆으로 흘러 날림」은 한쪽이 아니라 양쪽이라 해당 없음. 緩 전담 글자는 사전에 없음. 사실 2개.
3. **悲則氣消** — 눈물(「津 = 맑은 물방울」로도 읽힘 → 悲에 泣涕), 몸이 반투명하게 지워짐 = 氣消. 단 김이 **아래로 흘러내려** 「下」 글자와 겹침 → 4번과 혼동 위험. 消 전담 글자 없음. 사실 2개.
4. **恐則氣下** — 「下 = 아래로 가라앉거나 쏟아짐」: 주저앉는 무릎 + 가랑이로 쏟아져 땅에 고이는 김 = 氣下 확정. 관자놀이 땀방울 = 「汗」. 사실 3개.
5. **驚則氣亂** — 놀란 얼굴 = 驚, 사방으로 제각각 터지는 김 덩이 약 9개. 그러나 사전으로는 「散 = 사방으로 흩어져 날리는 것」에 그대로 걸려 **「驚則氣散」**으로 읽힘 → 교과서 「氣亂」과 어긋남. 亂 전담 글자 없음. 사실 2개.
6. **思則氣結** — 턱 괴고 팔짱 = 思, 머리 위에 크게 뜬 엉킨 김 매듭 = 「병표지」로 그 사람의 병증 = 氣結. 「痰 = 끈적한 회백색 덩이」와 닮을 수 있으나 김의 소용돌이라 痰 아님. 사실 2개.

**③ 잔결**
- 사전에 있는 방향 글자는 **上·下·散** 셋뿐 — 緩·消·亂·結은 전담 기호가 없어 표정으로만 풀림. 특히 5번이 「散」으로 오독될 소지(驚則氣亂 ↔ 散)가 가장 큼, 3번의 흘러내리는 김은 「下」와 겹침.
- 七情 중 **憂**(또는 悲·憂 합침) 표시 없음. 九氣의 寒收·炅泄·勞耗도 없음.
- 4·5번 벌린 입이 「口 = 어두운 타원 구멍」/「舌」 갈림으로 새어 읽힐 위험(脾·心으로 오독).
- 왼쪽 초가 정자가 프레임에 잘림. 이어 붙인 흔적은 없음.
- 판정: 사전 어휘로 1·4번(上·下)과 배경(內)은 더 잘 풀리고, 5번은 오히려 나빠짐(散 오독).
