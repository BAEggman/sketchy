# z23 판독

## 1단계 — 생판 (사전 없이)

① 단원 1순위 **痰飮(병리산물성 病因: 痰飮·瘀血·結石)** — 확신 35%. 차순위 **六淫 寒邪**(25%), **病機十九條 「諸病水液 澄澈淸冷 皆屬於寒」**(20%), **宣明五氣 五液(脾爲涎)**(10%).

② 인물은 띠 가운데 한 명뿐(상투, 회색 저고리, 황토색 바지, 맨발).
- 표제어 **痰飮**. 입에서 맑은 물줄기를 쏟음 = 淸稀者爲飮(맑고 묽은 것은 飮), 寒飮 嘔吐淸水. 목덜미·어깨 위 살빛 둥근 혹 = 有形之痰(痰核·瘰癧·癭瘤) — 稠濁者爲痰. 혹(痰)과 물줄기(飮) 두 가지가 한 몸에 붙어 「痰과 飮은 한 뿌리, 질의 차이」를 나름.
- 두 손으로 가슴(흉골·명치)을 움켜쥠 = 飮停胸脇·胸悶·胸痛(懸飮 「咳唾引痛」 또는 支飮 胸膈).
- 허리를 굽히고 몸을 웅크림 = 寒의 收引, 冷한 통증.
- 맨발로 젖은 흙바닥 = 濕은 아래로부터(傷於濕者 下先受之), 바닥 물웅덩이 큰 것 1 + 작은 것 3~4 = 水濕 정체.
- 배경 흙담(토벽, 지붕은 짚) 두 면이 모서리를 이룸 = 土=脾 → 脾爲生痰之源, 脾失健運 → 水濕 停聚.
- 바닥에 떨어진 대나무 담뱃대(마디 3, 대통 1), 그 밑에 물이 고임 = 관(管)=水道 → 三焦 水道 不利 → 水飮.
- 관계: 인물 1명이라 인물 간 관계 없음. 혹(痰)↔물줄기(飮)가 한 몸에서 나오는 짝이 관계 사실을 대신함.

③ 뜻 모를 것: 목덜미 살빛 혹(사람 머리처럼 보이기도 함 — 이어 붙인 흔적 의심), 담뱃대 왼쪽의 검은 꾸불꾸불한 줄 2가닥(재·담뱃진? 벌레?), 오른쪽 가장자리 아래 붉은 얼룩(이웃 띠 — 瘀血일 가능성), 오른쪽 가장자리 위쪽 검은 세로 막대(이웃 띠 몫).

## 2단계 — 계통 (blind6 사전으로 다시 읽기)

사전으로 다시 보니 1단계의 두 기둥이 무너진다. **寒 = 눈송이**인데 눈송이·성에·서리가 하나도 없으니 寒 판독(六淫 寒·「水液澄澈淸冷→寒」)은 근거가 없다. **痰 = 끈적한 회백색 덩이**인데 목덜미 혹은 살빛이라 痰이 아니다. 대신 사전 항목 세 개가 정확히 걸린다.
- 두 맨발 밑에서 넓게 번진 검은 젖은 얼룩(빗금이 들어간 축축한 자국) = **內濕 = 자기 발밑에서 배어 나오는 진창 → 脾**(갈림 조건 「자기 발밑」 충족. 길이나 비가 아니니 外濕이 아님).
- 목덜미·어깨 위의 반들반들하고 팽팽한 살빛 혹 = **腫 = 부풀어 팽팽해진 곳**(윤곽이 닫힌 살덩이라 肌로도 읽히지만, 광택이 돌 만큼 팽팽하니 腫 쪽).
- 두 손으로 가슴~명치를 눌러 쥐고 몸을 웅크림 = 그득히 막힌 **滿**(脹滿·痞滿). 몸 한복판을 쥐었으니 **中**(中焦)이 겹침.
→ 濕 + 腫 + 滿 = 「**諸濕腫滿 皆屬於脾**」. 단원 1순위 **病機十九條** 35%. 차순위 **藏象 脾**(口=脾竅 · 맑은 물줄기=涎 · 肌 · 脾惡濕) 25%, **六淫 濕邪**(濕阻氣機 胸悶 · 下先受之) 20%.
- 입(어두운 타원 구멍 = 口, 혀는 안 보이니 脾 쪽)에서 쏟아지는 맑은 물줄기와 방울 = 津·涎. 땅으로 쏟아짐 = 下. 「水濕이 넘친다」는 濕의 보강이고, 「脾爲涎」을 겹쳐 실음.
- 흙담 두 면 안쪽 모서리에 갇혀 섬 = **內**(담 안쪽) → 內濕·內生을 거듦. 흙(土)이 무대 전체 = 脾土.
- 관계: 인물은 1명. 濕(발밑)이 먼저 있고 그 결과로 腫(혹)·滿(가슴)이 생겼다는 인과 = 「濕이 脾를 막아 腫滿이 된다」.

③ 잔결: 담뱃대(마디 3·대통 1, 밑에 물 고임)와 그 곁 검은 꾸불꾸불한 줄 2가닥은 사전에 없음(管=脘? 蛔? — 판정 못 함). 가슴 쥔 손이 滿인지는 사전 항목이 없어 추정. 혹은 腫/肌 사이에서 갈림. 오른쪽 가장자리 붉은 얼룩·검은 막대는 이웃 띠 몫.
