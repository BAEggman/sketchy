# z48 판독 (blind48z)

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원**: **病因 — 病理産物性 病因(痰飮·瘀血·結石)** 1순위, 55%. 2순위 **血의 病機(血瘀·出血)** 25%, 3순위 **氣血辨證 血瘀證** 15%. 이 띠의 표제어는 **瘀血**(이웃 띠에 痰飮·結石이 있을 것으로 추정).

**② 인물·소품·배경**
- 인물 1명(띠 중앙, 회색 저고리·노랑 바지·흰 버선) = **瘀血**.
  - 얼굴 전체가 자주빛·눈가 멍 → 面色紫暗/黧黑, 口唇·爪甲 靑紫(紫紺).
  - 가슴 옆구리에 박힌 쇠못 1개 → **刺痛**, 못이 한 자리에 박혀 안 움직임 → **痛處固定**(拒按·夜間加重 포함 추정).
  - 못 둘레 자줏빛 번짐 → 皮膚 瘀斑·瘀點.
  - 손으로 가슴·배를 감싸 누름 → 腫塊(癥積) 固定不移 또는 拒按.
  - 손에 든 검붉은 덩어리 1개 → **出血 시 血色紫暗·夾有血塊**.
- 소품: 도랑(물길) = 脈道. 안에 검붉은 덩어리 **5개**가 걸려 물길을 막음 → **血行不暢, 阻滯於脈道**(脈澁 포함). 둑 밖으로 넘친 피 웅덩이 + 인물 발이 그 피를 밟음 → **離經之血 積存體內** = 瘀血의 또 다른 형태 / 瘀血阻絡 → 血不循經 → 出血.
- 5개 = 瘀血 형성 원인 5(氣虛·氣滯·血寒·血熱·外傷出血)로 추정(확신 낮음).
- 배경: 흙담·마른 들판·흰 하늘 — 의미 미상.

**관계**: 인물(환자)이 자기 脈道(도랑)에서 나온 덩어리를 손에 들고 서 있음 → 瘀血은 病理産物이면서 다시 新病의 原因(第二病因)이 됨. 도랑 안(血瘀脈內)과 도랑 밖(離經之血)의 대비 → 瘀血 정의의 두 갈래.

**③ 뜻 모를 것·어색함**: 흙담의 「F」 비슷한 금(글자 기호인지 균열인지 불명). 오른쪽 끝 초가 처마·기둥·항아리 — 이웃 띠 몫으로 보이나 항아리는 痰飮(물 고임) 띠와 이어질 수도. 도랑 상류 물은 맑은 회색인데 하류도 그대로 맑아 「瘀血不去 新血不生」은 나르지 않는 듯. 이음 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽음)

**① 단원**: **病因 — 病理産物(痰飮·瘀血)** 1순위 60%(사전에 痰·瘀가 짝 글자로 등재돼 있어 오히려 굳어짐). 2순위 **望色(靑·黑色 主 痛·瘀血)** 15% — 사전이 「얼굴색은 望色 판 전담」이라 해서 올렸으나 손까지 자줏빛이고 도랑 장면이 형성기전이라 내림. 띠 표제어 **瘀血** 유지.

**② 다시 읽기**
- 손에 쥔 검붉은 덩이 = 사전 **瘀**(몸 밖에 나온 굳은 덩이) 확정 → 出血 夾 血塊·紫暗.
- 도랑 덩이 **5개** = 瘀 ×5, 물길(脈) 막음 → 瘀阻脈道·血行不暢(脈澁). 둑 밖 붉은 웅덩이 = **血**(붉은 것) → 血溢脈外 = 離經之血. 안(脈內 停滯)·밖(離經) 두 갈래 정의는 그대로.
- 쇠못 1개 = 사전 **痛** → 疼痛; 한 자리에 박혀 → 痛處固定(刺痛).
- 못 둘레 자줏빛 = 갈림 적용: **살갗 멍은 瘀가 아님** → 1단계의 「瘀斑」 철회, 「아픈 자리의 색이 紫暗」으로만 읽음.
- 얼굴·두 손의 자줏빛 잿빛 = 面 글자 아님(광택 없음), 색 자체 → 面色·爪甲 紫暗(紫紺).
- 5개의 수는 사전으로도 안 풀림(형성원인 5 또는 致病特點 5 추정 유지).

**관계**: 인물 1명뿐. 같은 瘀 글자가 도랑(脈) 안과 사람 손에 동시에 있음 → 脈 안에 막힌 瘀가 피를 밖으로 밀어내고(出血), 나온 피가 다시 瘀가 되어 사람을 아프게 함 = 瘀血은 病理産物이면서 第二病因(瘀阻→出血→瘀의 순환).

**③ 잔결**: 도랑·물길에 해당하는 사전 글자가 없어 「脈」은 사전 밖 추정. 둑을 넘는 피가 사전 **盛**(넘쳐 흘러나옴)과 샐 수 있음(血盛·迫血妄行으로 오독 위험 — 불꽃이 없어 배제). 도랑 물이 붉지 않은 회백색이라 무엇을 나르는지 불명(津?). 담의 「F」 금·오른쪽 끝 초가·항아리는 미상 또는 이웃 띠 몫.
