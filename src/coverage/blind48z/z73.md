# z73 판독

## 1단계 — 생판 (사전 보기 전)

**① 단원**: **病因 — 內傷(不內外因) 중 飮食失宜·勞逸失度** 1순위 (70%). 2순위 **宣明五氣 五勞所傷**(久臥傷氣·久坐傷肉) (15%), 3순위 **消渴(三消)** (5%).

**② 인물·소품**
- 왼쪽 배불뚝이 사내(마루에 앉음) = **過飽(飮食自倍)**. 빈 사발 탑 3줄(약 13·9·7개)+앞에 1개, 마루 밑 놋/나무 그릇 4개, 옆 항아리·단지 = 먹은 양이 넘침 → 「飮食自倍, 腸胃乃傷」, 脘腹脹滿(불룩한 배), 비만·痰濕 소인.
- 가운데 갈비뼈 드러난 마른 사내(마루에 앉음) + 빈 사발 **1개** = **過飢(飢餓)** → 氣血生化之源 부족 → 消瘦·正氣虛.
- 방 안 이불 위에 누워 자는 사람 = **過逸(安逸)** → 「久臥傷氣」, 氣血 운행 不暢·脾胃 약화.
- 마당에 엎어진 사내: 땀방울·입가 물웅덩이(땀/침), 발치에 터진 곡식 자루, 옆 섬돌 = **過勞(勞力過度)** → 「勞則氣耗, 喘息汗出, 外內皆越」.
- 배경 초가·마루 = 일상 생활(內傷의 무대), 왼쪽 밭·울타리 = 농사일(勞力의 출처).

**관계**: 뚱보↔마른이 = 飢·飽 양극이 모두 脾胃를 상함(飮食不節의 두 갈래). 누운이↔엎어진이 = 逸·勞 양극(過逸도 過勞도 病因). 2×2 대칭으로 「지나침과 모자람 모두 병」을 나름.

**③ 잔결**: 사발 개수(약 29+α)가 특정 숫자를 나르는지 불명. 섬돌이 무거운 돌(擧重)인지 그냥 댓돌인지 모호. 입가 물웅덩이가 땀인지 침(涎)·구토인지 불분명. 기둥 좌우 마루 높이가 달라 이어 붙인 듯.

## 2단계 — 계통 (사전 읽은 뒤)

**① 단원**: **病因 — 飮食失宜·勞逸失度** 유지 (65%). 久 글자가 약하게 보여 **宣明五氣 五勞所傷** 20%로 올림. 오행왕국 인물(장부 의인화)이 하나도 없어 장부 판은 아님.

**② 사전 어휘로 다시 읽기**
- 배불뚝이 = **過飽**: 팽팽한 배 = **實**(팽팽하게 찬 것)·**肌**(도톰히 솟은 살덩이). 빈 사발 탑 = 먹어 치운 양(補 아님 — 국물 없음). 마루 밑 갈색 그릇 3개 포갬 = **久**?(약함).
- 마른이 = **過飢**: 뚱보의 약 1/3로 줄어든 몸 = **虛**, 곁의 빈 사발 1개 = 채울 것 없음 → 氣血生化 부족.
- 방 안 누운이 = **過逸**: 문 안쪽 = **內**, 곁 선반의 갠 이불 포갬(2~3장) = **久** 가능 → 「久臥傷氣」.
- 엎어진이 = **過勞**: 얼굴 땀방울 = **汗**, 입가 맑은 물웅덩이 = **津** → 「喘息汗出, 外內皆越」. 발치의 끈 조인 삼베 자루 = **收** 꼴인데 터져 곡식이 쏟아짐(**傷**+**下**) → 거두어 두지 못하고 새어 나감 = 「勞則氣耗」. 문 밖 마당 = **外**.

**관계**: 뚱보↔마른이 = 같은 자세 두 사람이 **實↔虛**(飽는 食積 實, 飢는 氣血 虛 — 둘 다 脾胃 손상). 누운이(內)↔엎어진이(外) = **逸↔勞**(逸은 氣滯·傷氣, 勞는 氣耗). 사전 어휘가 1단계 뜻을 바꾸지 않고 虛實·氣耗 쪽을 더 또렷하게 함.

**③ 잔결**: 久(셋 포갬)가 그릇 3개·이불 2~3장에 희미하게만 있어 五勞所傷 여부를 못 가름. 흰 사발 탑 3줄(약 30개)은 사전에 없는 소품(그냥 「많이 먹음」). 섬돌은 사전 글자 없음 — 뜻 불명. 마른이가 셋 중 가운데(**中**?)인지는 몸 위 표지가 없어 판정 불가.
