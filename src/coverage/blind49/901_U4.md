# 901 판독 (U4)

## 1단계 — 생판 (사전요약 열기 전 확정)

**① 판 표제어**
- 1순위 **病因 — 내상·병리산물성 병인(飮食失宜·勞逸失度·痰飮·瘀血)** 75%
- 2순위 **病理産物(痰飮·瘀血)과 생활 병인(飮食·勞倦) = 不內外因/기타 병인** 15%
- 무대: 흙담 마당(좌, 병리산물) + 초가 툇마루(우, 飮食·勞逸) 두 구역.

**② 인물별 (왼쪽부터)**
1. 목혹·물 토하는 사내 — **痰飮**. 목 옆 둥근 혹 = 痰核·癭瘰(痰은 經絡·皮下에 맺힘), 가슴 움켜쥠 = 胸悶·心悸(痰阻心肺), 입에서 쏟아지는 맑은 물 = 嘔吐淸水痰涎(飮停胃), 땅의 물웅덩이 = 水濕 정체, 대나무 곰방대 = (불명; 「담배→痰」 말장난 혹은 水道 대롱 추정). 사실 4~5개.
2. 보랏빛 얼굴 사내 — **瘀血**. 얼굴·손 紫暗 = 靑紫色, 어깨 박힌 못 = 刺痛·痛處固定, 손의 검붉은 덩이 = 血塊(腫塊), 도랑(脈道)에 걸린 핏덩이 5개 = 脈中 瘀阻, 도랑 밖으로 번진 피 = 離經之血·出血. 사실 5개.
3. 배불뚝이 — **飮食過飽(飮食自倍 腸胃乃傷)**. 그릇탑 3개 = 과식, 부른 배 = 食積·脘腹脹滿, 독·항아리 = 肥甘/酒 과다(생痰濕) 추정. 사실 2~3개.
4. 갈비뼈 드러난 마른 사내 — **飢餓·飮食不足**. 빈 그릇 1개 = 攝食 부족, 뼈만 남음 = 氣血生化之源 부족→消瘦. 사실 2개.
5. 방 안에 누운 사내 — **過逸(久臥傷氣)**. 사실 1개.
6. 엎어진 땀범벅 사내 — **勞力過度(勞則氣耗)**. 땀·웅덩이 = 喘息汗出, 터진 곡식 자루·쏟아진 낟알 = 氣(精) 耗散, 뒤의 무거운 돌 = 擧重 과로. 사실 3개.

**③ 잔결**
- 하단 땅에 x≈1020 세로 실선 — 좌(마당)·우(초가) 두 판을 이어 붙인 흔적.
- 우상단 초가지붕이 프레임에 잘림.
- 곰방대 뜻 불명. 痰飮 사내만 맨발(水濕 하부? 불명).
- 房勞(성생활 과도) 인물은 안 보임 — 쏟아진 낟알을 精 누설로 읽으면 6번이 겸할 수도 있음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **病因 — 內傷(飮食失宜·勞逸失度) + 病理産物性 병인(痰飮·瘀血)** 80% — 온 무대가 흙담 안쪽·문 안쪽(內 = 담 안쪽)이라 「內傷」 쪽이 한 칸 더 굳어짐.
- 2순위 **氣血津液 病機(痰飮·瘀血 생성과 증상) + 飮食·勞倦** 10% / 3순위 宣明五氣 五勞所傷(久臥傷氣·久坐傷肉) 5%.

**② 인물별 (왼쪽부터)**
1. **痰飮** — 회백색 끈적한 줄기 토물·바닥 웅덩이 = 痰(사전 「끈적한 회백색」) → 嘔吐痰涎·飮停於胃; 목 옆 팽팽한 혹 = 腫(·肌) → 痰核·瘰癧·癭(痰은 皮下·經絡에도 맺힘); 가슴 움켜쥠 = 胸悶(痰阻心肺); 흩어지는 방울 = 津의 정체. 곰방대 = 사전에 없음(「담배→痰」 말장난 추정, 미확정). 사실 4개.
2. **瘀血** — 쇠못 하나 = 痛 → 刺痛·痛處固定(확정); 손에 쥔 검붉은 덩이 = 瘀 → 血塊·腫塊; 도랑의 검붉은 덩이 5개 = 瘀(몸 밖 덩이) → 脈道 瘀阻; 도랑 밖으로 번진 붉은 것 = 血 → 出血(離經之血). 얼굴·손의 자줏빛은 「살갗 위 얼룩은 瘀가 아님」 갈림대로 瘀가 아니라 그 자리 색 → 面色·爪甲 紫暗(望色). 사실 5개.
3. **飮食過飽(食積)** — 빈 그릇 탑 3줄(10여 개씩) = 다 먹어 치운 과식; 팽팽한 배 = 實(·腫) → 脘腹脹滿·食積 實證; 항아리·독 = 무표지(甘 꿀단지 아님 — 국자 없음). 그릇탑은 「셋 포갬=久」보다 훨씬 높아 久로 읽지 않음. 사실 2개.
4. **飢餓(飮食不足)** — 빈 사발 하나 = 못 먹음; 살이 삼분의 일로 준 몸 = 虛 → 氣血生化 부족·消瘦. 사실 2개.
5. **過逸(安逸·久臥傷氣)** — 문 안쪽(內) 이부자리에 드러누움. 사실 1개.
6. **勞力過度(勞則氣耗)** — 얼굴 땀방울 = 汗 → 喘息汗出; 끈으로 조인 삼베자루 = 收가 터짐(傷) + 낟알이 흩어짐(散) → 氣가 거두어지지 못하고 耗散; 뒤의 큰 돌덩이 = 擧重(무표지); 입가 물웅덩이 = 津. 사실 3개.

**③ 잔결**
- 하단 땅 x≈1020 세로 실선 = 좌(흙담 골목)·우(초가) 이어 붙인 흔적.
- 우상단 지붕 프레임 잘림.
- 곰방대·痰飮 사내 맨발·⑥의 돌덩이·③의 항아리 — 사전 어휘로도 안 풀림.
- 판정: 사전 어휘는 痛(못)·瘀(덩이)·血·汗·收→散·虛·實을 확정해 1단계 해석을 보강했고, 자주빛 피부는 瘀가 아니라 望色이라는 갈림만 교정. 표제어 자체는 바뀌지 않음.
