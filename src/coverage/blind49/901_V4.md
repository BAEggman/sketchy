# 901 판독 (V4)

## 1단계 — 생판 (사전 열기 전 확정)

**① 판 표제어**
- 1순위: **病因 — 六淫·七情 밖의 病因 묶음 (病理產物性 病因 痰飮·瘀血 + 飮食失宜 + 勞逸失度)** (65%)
- 2순위: **不內外因 (三因學說)** (20%) — 나머지 15%는 「病理產物(痰飮·瘀血) 致病特點」 단독판 가능성.
- 근거: 왼쪽 흙담 마당 = 몸 안에서 생긴 찌꺼기(물·핏덩이), 오른쪽 초가 마루 = 생활(먹기·눕기·일하기). 두 무대가 한 장에 이어져 있음.

**② 인물별 (왼쪽부터)**
1. 허리 굽힌 남자 — **痰飮**. ⓐ 맑은 물을 토함 = 痰飮 停胃 → 嘔吐淸水·痰涎. ⓑ 두 손으로 가슴 움켜쥠 = 痰阻胸肺 → 胸悶·咳喘. ⓒ 목덜미 혹 = 痰이 經絡·皮下에 머묾 → 瘰癧·痰核·癭瘤. ⓓ 바닥 물웅덩이 = 飮은 淸稀. (4개)
2. 보랏빛 남자 — **瘀血**. ⓐ 얼굴·손 紫暗 = 面色黧黑·脣甲靑紫. ⓑ 어깨에 박힌 못 = 刺痛·痛處固定(拒按). ⓒ 손에 든 핏덩이 = 腫塊(癥積, 단단하고 움직이지 않음). ⓓ 물길을 막은 핏덩이 **5개** = 出血 紫暗 夾血塊 / 血行 阻滯(離經之血). ⓔ 발밑 번진 피 = 出血. (5개)
3. 배불뚝이 — **飮食過飽(飢飽失常 중 飽)**. ⓐ 불룩한 배 = 暴飮暴食 → 脘腹脹滿·食積·脾胃損傷. ⓑ 사발 더미 3줄(십수 개) = 과식. ⓒ 옆 항아리·작은 잔 = 嗜酒(飮食偏嗜) 가능. (2~3개)
4. 앙상한 남자 — **飮食不足(飢)**. ⓐ 갈비뼈 드러난 몸 = 氣血生化之源 부족 → 消瘦·正氣虛. ⓑ 빈 사발 **1개** = 먹을 것 부족. (2개)
5. 방 안에 누운 남자 — **過逸**. ⓐ 대낮에 이부자리에 누움 = 久臥傷氣·安逸過度 → 氣血 不暢·脾胃 기능 저하. (1개)
6. 엎어진 남자 — **過勞(勞力過度)**. ⓐ 땀방울·바닥 침/땀 웅덩이 = 勞則氣耗 → 喘息汗出. ⓑ 터져 쏟아진 곡식 자루 = 무거운 짐(勞力) + 氣가 새어 나감(氣耗). ⓒ 뒤 네모 돌 = 무거운 돌 들기(擧重)? (2~3개)

**③ 뜻 모를 것·어색한 것**
- 바닥의 대나무 곰방대(웅덩이 위, 옆에 끊어진 끈) — 담배? 竹(竹瀝)? 뜻 모름.
- 마당 물길 = 맑은 물에 핏덩이 → 津血同源·痰瘀互結 뜻인지, 단지 「脈 막힘」인지 불분명.
- 네모 돌(섬돌인지 擧重石인지 모호), 마루 왼쪽 항아리·바가지들.
- 담벼락의 「F」 같은 낙서(x≈990) — 의미 없는 흔적인지 글자인지 모름.
- **이어 붙인 흔적**: x≈1020 부근 마당 바닥을 세로로 가르는 가는 선 — 왼쪽(흙담 마당)과 오른쪽(초가) 두 그림을 맞붙인 경계로 보임. 프레임 잘림은 없음(초가 지붕 오른쪽 끝만 판 밖으로 나감).

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위: **病因 — 內傷·病理產物性 病因 (痰飮·瘀血 + 飮食失宜 + 勞逸失度)** (70%) — 사전의 「內 = 담 안쪽」이 무대 전체(흙담 안 마당 + 집 안)에 걸려, 밖에서 들어온 邪(六淫)가 아니라 안에서 생긴 病因이라는 읽기를 굳혀 준다.
- 2순위: **不內外因 (三因學說의 飮食勞倦 쪽)** (15%).

**② 인물별 (왼쪽부터)**
1. **痰飮** — 회백색 끈적한 토물 = 痰 → 痰飮停胃·嘔吐痰涎 / 가슴 움켜쥠 → 痰阻胸肺·胸悶 / 목덜미 혹 = 腫 → 痰核·瘰癧(痰이 經絡·皮下에 머묾) / 잿빛 웅덩이 = 飮(淸稀). **4개**. 곰방대는 사전에 없음.
2. **瘀血** — 어깨의 쇠못 하나 = 痛 → 刺痛·痛處固定 / 손에 쥔 검붉은 덩이 = 瘀 → 腫塊(癥積) / 물길 속 검붉은 덩이 **5개** + 붉은 번짐 = 瘀 + 血 → 出血 紫暗 夾血塊, 물길이 막힘 = 不通(不通則痛) / 얼굴·손 보랏빛 = 面色黧黑·脣甲靑紫(갈림: 살갗의 멍은 瘀가 아니라 그 자리의 색 — 望色 몫). **4개**.
3. **飮食過飽** — 팽팽한 배 = 實 → 食積·脘腹脹滿 / 흰 사발 3줄 더미(각 10개 남짓) = 過食. 사전의 久(셋 포개짐)와 닮았으나 수가 많아 久로는 약함. 항아리·잔에는 국자·검은 커피가 없어 甘·苦가 아님 → 偏嗜 읽기는 철회. **2개**.
4. **飮食不足(飢)** — 빈 사발 1개(惠·瀉-b 조건 없음) = 먹을 것 없음 / 갈비·무릎이 드러남 = 骨, 살이 빠짐 → 氣血生化之源 부족·消瘦. (앉아 있는 마른 몸 = 久坐傷肉 가능성은 久 표지가 없어 보류) **2개**.
5. **過逸** — 문 안쪽(內) 이부자리에 누움 + 방 선반 위 **3겹** 포갠 이불/책 = 久 → **久臥傷氣**. **1개**(久 표지 덕에 「오래 누움」까지 읽힘).
6. **過勞(勞力過度)** — 얼굴의 땀방울 = 汗 → 喘息汗出 / 끈으로 아가리 조인 삼베 자루 = 收인데 터져 곡식이 흩어짐 = 收가 傷함 + 散 → 氣가 갈무리되지 못하고 새어 나감 = **勞則氣耗**(外內皆越) / 입가 맑은 물웅덩이 = 津이 샘. **3개**.

**③ 남는 것**
- 대나무 곰방대 — 사전에도 없어 끝까지 뜻 모름(쓰레기 소품 의심).
- 사발 더미가 久인지 多食인지 갈림 불명확. 네모 돌(섬돌/擧重石) 뜻 모름. 「F」꼴 담벼락 낙서.
- x≈1020 마당 바닥 세로선 = 왼쪽(흙담 마당)·오른쪽(초가) 두 장을 이어 붙인 흔적. 프레임 잘림 없음.
- 판정: 사전 어휘로 더 잘 풀린 곳은 6번(收 자루 → 氣耗)과 5번(久 → 久臥傷氣), 1단계의 偏嗜(항아리) 읽기는 사전으로 반박됨. 표제어 자체는 1단계와 같다.
