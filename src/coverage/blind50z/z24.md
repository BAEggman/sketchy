# z24 판독

## 1단계 — 생판 (사전 없이 그림만)

**① 단원** — 1순위 **七情(內傷病因)** 55%. 2순위 **內傷病因 통합(七情·瘀血)** 25%, 3순위 **五行 相乘(木乘土)** 10%.

**② 인물·소품**
- 성난 사내(띠 오른쪽 가운데) = **怒**. 몸·소매·바지에서 김이 솟아 담 위까지 치솟음 = 怒則氣上(氣逆). 입 벌려 고함 + 소리선 = 肝의 聲 「呼」, 怒傷肝. 푸른 저고리(靑=肝木) 아래 누런 바지(黃=脾土) → 위의 木이 아래 土를 누름 = 肝氣橫逆犯脾(木乘土). 손의 비(빗자루)는 땅을 쓸어 내림 = 「怒則氣逆, 甚則嘔血及飧泄」의 **飧泄**(또는 肝主**疏泄**의 '쓸어 트임'). 셀 만한 개수 소품은 없음.
- 검은 가시덤불(띠 왼쪽) = **瘀血**. 가시 = 刺痛, 땅에 뿌리박힘 = 痛處固定不移, 먹빛 검정 = 色紫黯, 얽힌 가지 = 癥積(덩이). 2순위 해석: 가지가 얽힌 덤불 = **氣鬱(氣滯)**.
- 배경: 이엉 얹은 황토 담 = 土(脾) 또는 판 공통 배경(띠 고유 사실은 약함).
- **관계**: 사내가 덤불을 향해 고함 → 怒로 氣가 막히고 거슬러 血이 엉김 = 氣滯血瘀(氣爲血帥). 七情이 내상 병인으로 瘀血을 만든다는 인과.

**③ 어색한 것·이음 흔적**
- 덤불만 채색 없는 먹 실루엣이라 나머지 수채 화풍과 따로 놂 — 다른 장면을 이어 붙인 흔적 의심.
- 황토 담이 가운데(덤불 위)에서 색조가 위아래 두 층으로 갈리고, 오른쪽 이엉은 김에 가려 끊김.
- 비의 뜻(飧泄/疏泄/風) 확정 불가. 김이 큰 뭉게구름형과 실 김형 두 종류로 섞임.

## 2단계 — 계통 (사전요약 어휘로 다시 읽기)

**① 단원** — **七情** 65%로 올림. 사전으로 사내의 두 소품이 정확히 풀려 「怒則氣逆, 甚則嘔血及飧泄, 故氣上矣」(素問 擧痛論) 한 문장으로 이어진다. 2순위 **內傷病因 통합(七情·痰瘀)** 20%, 3순위 **本草②(瀉·修治의 蒸)** 5%.

**② 인물·소품 재판독**
- 성난 사내 = **怒**. 몸에서 피어 머리 위·담 위까지 치솟는 흰 김 = 氣(서린 흰 김) + 上(머리 꼭대기로 솟음) → **怒則氣上**. 손잡이 달린 짚 빗자루 = 瀉(갈림 확인: 이삭·묶은 허리 없는 볏단이 아니라 손잡이 달린 빗자루) → 「甚則…**飧泄**」. 벌린 입 속 붉은 혀 = 고함(肝聲 呼). 사전상 혀가 보이면 心이라는 갈림이 있으나, 이 판은 開竅 판이 아니므로 적용하지 않음(굳이 붉음=血로 읽으면 **嘔血**, 약함). 사내는 오행왕국 다섯 인물이 아닌 평범한 백성이므로 저고리·바지 색(靑·黃)으로 木乘土를 읽은 1단계 해석은 철회.
- 검은 가시덤불: 사전 미등재. 瘀는 「몸 밖의 검붉게 굳은 덩이」, 痛은 「쇠못 하나」여서 가시·검정을 瘀血·刺痛으로 읽은 1단계 해석은 사전과 맞지 않아 강등. 남는 후보는 얽힌 가지 = 氣結/鬱. 다만 왼쪽 이웃 띠(**思則氣結**) 몫일 수 있음.
- 황토 담: 內 = 담 안쪽. 마당 안에서 비질함 → 七情은 **內傷**(판 공통 배경).
- **관계**: 사내가 덤불(木)을 향해 고함 → 怒傷肝(약). 사전으로 확정되는 관계 사실은 없음.

**③ 잔결** — 검은 실루엣 덤불만 화풍이 다르고 사전에도 없어 정체가 불명(이어 붙인 흔적). 김이 곧은 기둥이 아니라 뭉게구름이라 上의 꼴이 약함. 嘔血을 나르는 붉은 것(血)은 따로 없음.
