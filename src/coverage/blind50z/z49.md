# z49 판독

## 1단계 — 생판 (사전 보기 전, 확정)

**① 단원**: **病因 — 勞逸(勞倦·房勞)** 50% / 2순위 **病機 虛實(邪正盛衰)** 25% / 3순위 **陰陽失調(陰陽兩虛)** 15%.

**② 인물·소품**
- 중앙 남자(오른쪽) = **房勞過度 → 腎精虧損**. 반쯤 감긴 눈·눈밑 그늘·처진 어깨·늘어뜨린 손 = 精神萎靡·神疲乏力. 지팡이 1 = 腰膝酸軟(骨·腎 약화), 「半百而衰」의 늙음.
- 해·달 깃발(위 해 1·아래 달 1, 가로선으로 위아래 둘로 나뉨) = 陰陽 → 陰陽交合=房事. 깃대가 남자와 왼쪽 인물 사이 경계에 꽂힘.
- 발치 김 나는 누런 그릇 1 = 술(以酒爲漿, 醉以入房) — 또는 補養 탕.
- 검게 탄 마른 가지 1(잎 뭉치 3~4) = 검정=腎, 마름=精竭(以欲竭其精). 그 위로 가늘게 오르는 연기 한 줄 = 耗散其眞 / 陰虛로 뜬 虛火(相火妄動).
- 배경: 흙담·초가 이엉·아래 벽돌 = 판 공통 배경(土=脾? 약함).

**관계**: 왼쪽 반쯤 잘린 인물(빗자루+뭉게 김) = 勞力過度 — 「勞則喘息汗出, 外內皆越, 故氣耗」(김=땀·氣 빠짐). 오른쪽 = 房勞. 깃대를 경계로 **過勞의 갈래(勞力 → 氣耗 / 房勞 → 腎精耗)**가 나란히, 결국 둘 다 虛로 귀결. 虛實로 읽으면 왼쪽 빗자루=瀉(實), 오른쪽 탕그릇=補(虛).

**③ 잔결**: 그릇이 술인지 탕약인지 갈리지 않음. 탄 가지+연기가 「불 꺼짐(陽虛)」인지 「마름+虛火(陰虛)」인지 모호. 깃발이 왜 하필 깃발(旗)인지 글자 몫 불명. 왼쪽 인물은 잘려 표제어 판단 불가.

## 2단계 — 계통 (blind6 사전 적용 후)

**① 단원**: **病機 — 邪正盛衰(虛實)** 45% / **八綱 虛實(陰陽=總綱)** 25% / **治則 補虛瀉實·扶正祛邪** 15% / 1단계의 **勞逸** 10%로 내림. 사전으로 盛·衰·補·瀉 네 글자가 한 띠에 짝지어 서므로 「房勞」보다 「虛實」이 훨씬 잘 풀린다.

**② 인물·소품**
- 오른쪽 남자 = **虛(精氣奪則虛)**. 검게 타다 남은 작은 가지 1 = **衰**(타다 남아 작아진 것), 그 위로 오르는 흰 김 한 줄 = **氣** → 正氣衰. 발치의 따뜻한 국물이 찰랑 찬 그릇 1 = **補**, 그 위 김 = 氣 → 補氣 = 「虛則補之」. 지팡이·처진 눈·늘어뜨린 손은 사전 밖이나 虛의 모습을 거든다.
- 왼쪽(잘린) 인물 = **實(邪氣盛則實)**. 몸을 감싸 넘쳐 흐르는 흰 김 뭉게 = **盛**+氣, 손잡이 달린 짚 빗자루 = **瀉**(볏단 아님) → 「實則瀉之」.
- 깃발: 해 = **陽**, 달 = 사전 미등재(陰으로 짐작) → 陰陽. 두 인물 사이에 높이 걸린 깃발 = 陰陽이 虛實 위를 거느림(八綱 總綱) 또는 다음 개념 **陰陽失調**로 넘어가는 표지.

**관계**: 두 사람의 옷(회청 저고리·황토 바지)이 같다 → 한 사람의 두 상태. 盛↔衰 = 邪正盛衰가 虛實을 정함, 瀉↔補 = 그에 맞선 치법. 1단계의 勞力/房勞 대비는 사전 어휘로는 근거가 사라짐(빗자루는 노동이 아니라 瀉).

**③ 잔결**: 달은 사전에 없어 陰 확정 불가. 김이 탄 가지에서 오르는 것이 「氣衰」인지 「陽(불)衰」인지 갈림 없음. 김 줄이 구불어 머리까지 곧게 솟지 않으니 上은 아님. 지팡이·흙담·초가 이엉은 사전 밖(무대 공통으로 봄). 虛 전담 기호(삼분의 일로 준 것)는 이 띠에 안 보임.
