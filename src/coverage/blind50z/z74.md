# z74 판독

## 1단계 — 생판 (사전 없이)

**① 단원**: **八綱(虛實·寒熱) — 腹痛 按診 감별** 1순위 (35%). 차순위 **脾胃(中焦)** 20%, **飮食勞逸(飮食不節)** 15%. 근거: 두 사람 모두 배를 드러내고 손을 얹은 「배 만지기」 대비가 띠의 주제이고, 노란 흙담·초가(土)가 중초 무대를 깐다.

**② 인물·소품**
- 왼쪽 인물 = **實**(또는 **寒實**). 회청색(찬 색) 두루마기, 이맛살을 찌푸리고 한 팔로 제 몸을 감싸 움츠림(畏寒·蜷縮), 다른 손은 팽팽하게 부풀어 번들거리는 큰 배를 옆에서 받쳐 감쌈 → 腹脹滿·疼痛, 누르지 못하게 감싸는 몸짓 = **拒按**. 곁 소품 무쇠솥 1개 + 뚜껑 1개(벗겨져 바닥에 놓임), 솥은 비었고 아궁이 불 없음 → (가) 솥을 다 비웠다 = 過食·食積 → 腹脹(實), (나) 불 꺼진 찬 솥 = 中焦(胃=釜) 寒. 두 풀이가 겹쳐 「寒實/食積 腹滿」.
- 오른쪽 인물 = **虛**. 황토색(土=脾) 두루마기, 살찐 몸, 눈 감고 편안한 미소, 두 손바닥으로 부드럽고 작은 배를 지그시 누름 → **喜按**(按之痛減). 곁 소품 인삼 1뿌리(잔뿌리 여럿) → 補氣·補脾, **虛則補之**. 살찐 몸 = 肥人氣虛(가능).
- 배경: 초가지붕 얹은 흙담·흙바닥 = 土 → 脾胃·中焦(복부 무대).

**관계**: 둘이 나란히 같은 「배에 손 얹기」를 다르게 함 → 腹痛 喜按은 虛, 拒按은 實(按之不痛爲虛, 痛者爲實). 소품 대비 = 실은 덜어내고(솥 비우기/食積 消導), 허는 채운다(인삼) → 虛補實瀉.

**③ 잔결**: 왼쪽 인물의 「제 몸 감싸 움츠림」은 實보다 寒(畏寒)을 말하는 듯해 표제어가 寒/實 사이에서 갈림. 솥 뚜껑이 따로 벗겨 놓인 이유(열림=?) 불명. 왼쪽 가장자리에 회청색 옷자락이 잘려 있음(이웃 띠 몫). 이어 붙인 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (blind6 사전 적용)

**① 단원**: **八綱 虛實 — 虛實眞假(大實有羸狀·至虛有盛候)** 1순위 (45%). 차순위 **腹診(腹滿 按之 虛實)** 20%. 사전으로 1단계의 「虛 대 實」이 굳고, 「寒」 갈래는 떨어진다.

**② 다시 읽기**
- 왼쪽 = **實**, 정확히 **大實有羸狀**. 번들거리게 팽팽한 배 = 實(「팽팽하게 찬 것」; 腫과 겹치나 몸통 한복판이라 實). 나란한 두 배 중 이쪽이 약 두 배 = **大** → 「大實」. 그런데 얼굴은 여위고 찌푸렸고 제 몸을 감싸 움츠림 = 겉은 허약해 보이는 **羸狀**. 사전에 눈송이·성에가 없으므로 이 움츠림은 寒이 아니라 「겉보기 허약」으로 읽는 편이 맞다. 빈 무쇠솥(뚜껑 벗김) = 瀉-b의 「텅 빈 그릇」 반쪽 — 넘친 내용물이 없어 무엇을 덜었는지는 안 나름; 문자대로는 食積(다 먹어 비운 솥) → 실증의 원인.
- 오른쪽 = **虛**, 정확히 **至虛有盛候**. 황토색 옷에 몸 전체가 부풀어 듬직하고 낯이 편안함 = 겉은 성한 **盛候**. 그러나 두 손으로 배 **한복판(中, 「몸 위에서는 中」)**을 지그시 누름 = 喜按, 곁의 인삼 1뿌리(사전 밖, 문자대로 補氣·補中) = 속은 虛라 補해야 함. 사전의 虛(1/3로 줄어든 것)는 그림에 없어 虛는 몸짓+인삼이 진다.
- 배경 흙담·초가: 사전상 內/外(담 안·밖)일 수 있으나 문이 없어 어느 쪽인지 판정 불가 → 무대로만 읽음.

**관계**: 겉과 속이 엇갈린 거울 쌍 = **虛實眞假** — 여위어 보이는 쪽이 大實, 살쪄 보이는 쪽이 至虛. 가르는 기준은 배를 누를 때의 반응(喜按=虛, 拒按=實) → 虛則補(인삼)·實則瀉(빈 솥).

**③ 잔결**: 사전으로 끝내 안 풀리는 것 — 빈 솥(넘친 내용물 없음), 인삼(등재 없음), 1/3 축소물 부재. 담의 內/外 미정. 이어 붙인 흔적 없음. 판정: 사전 어휘가 1단계보다 낫다(大 덕에 「大實」이 서고 寒 오독이 걷힘).
