# z75 판독

## 1단계 — 생판 (사전 열기 전 확정)

① 단원 1순위: **六經(傷寒 六經病) — 太陰 부분** 40%. 대안 **問診切診(腹診 虛實·喜按/拒按)** 25%, **飮食勞逸(飢飽·過逸)** 20%.

② 인물
- 왼쪽 청회색 도포 사내 = **太陰病**. 한 팔로 제 어깨를 감싸 움츠림(臟寒·畏寒, 「以其藏有寒故也」) / 다른 손으로 팽팽하게 번들거리는 큰 배를 받침, 찡그림(腹滿·時腹自痛) / 발밑 엎어진 무쇠솥 1개와 열린 뚜껑, 덩어리째 쏟아진 갈색 음식(食不下·吐, 소화 안 된 宿食). 提綱 「腹滿而吐, 食不下, 自利益甚, 時腹自痛」 5증 중 腹滿·吐/食不下·腹痛 + 臟寒 4가지가 그려짐(自利는 안 보임).
- 오른쪽 황색 도포 사내 = **理中湯(人蔘湯)·溫中補虛 / 虛證 喜按**. 온몸이 둥글게 살찜, 두 손바닥으로 배를 지그시 누르며 미소(喜按=虛, 편안) / 발 앞 人蔘 1뿌리(補氣健脾, 理中丸 구성약) / 노란 옷 = 土·脾.
- 배경: 황토 흙담 + 초가 이엉 + 아래 벽돌 = 土(脾胃·中焦), 太陰 濕土. 하늘은 빈 여백.
- 관계: 같은 脾土 무대에서 왼쪽 「病(臟寒 腹滿)」 → 오른쪽 「治(當溫之, 人蔘湯) 뒤 평온」. 또는 腹滿 虛實 대비 — 식적·팽팽한 배·고통=拒按 實 vs 부드러운 배·누르면 좋음·인삼=喜按 虛. 「實則陽明, 虛則太陰」의 짝일 가능성도 있음.

③ 잔결: 왼쪽 사내의 「추위 몸짓(虛寒)」과 「팽팽한 배+쏟아진 음식(實)」이 한 몸에 겹쳐 虛인지 實인지 갈림. 인삼 수염 왼쪽 끝에 흐릿한 흰 번짐(이어 붙인 흔적 가능). 왼쪽 가장자리 청색 옷자락은 이웃 띠 몫. 상단 1/4 하늘이 비어 소품 없음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

① 단원 1순위: **六經 — 陽明(實)·太陰(虛) 짝** 35%. 대안 **虛實·補瀉 治則(實則瀉之/虛則補之)** 30%, **問診切診(按腹 虛實)** 15%.

② 사전 어휘 대입
- 왼쪽 사내의 팽팽하게 부푼 배 = **實**(팽팽하게 찬 것; 腫으로도 읽히나 몸통 전체라 實 우선). 발밑 무쇠솥은 거의 비었고 내용물이 밖으로 쏟아짐 = **瀉-b**(텅 빈 그릇+흘러넘친 내용물 = 그 사람에게서 덜어낸 것), 넘친 것이 덩어리진 음식 → 덜어낼 것은 「胃 속 宿食(燥屎)」. 쏟아짐 자체는 **下**. 그래서 왼쪽 = **陽明 胃家實 → 下法(承氣)** 또는 **食積 實證 → 消導·瀉**. 사전의 寒은 눈송이·성에·서리뿐이라 움츠린 몸짓은 寒 글자가 아님 → 생판에서 읽은 「臟寒」은 근거가 약해짐.
- 오른쪽 황색 도포 사내: 사전 기호가 없다(虛=1/3로 줄어듦, 補=따뜻한 국물 그릇 둘 다 없음). 남는 것은 사전 밖 일반 독해 — 人蔘 1뿌리(補氣·理中湯=人蔘湯), 두 손으로 지그시 누르는 부드러운 배(喜按=虛), 황색=土(太陰 濕土·脾). → **太陰 虛寒 → 溫補(理中)**. 도톰한 몸은 **肌**(脾主肌肉)로도 읽힘.
- 배경 황토 흙담 = 土(脾胃). 두 사람이 같은 쪽에 서 있어 內/外 구분은 안 짐. 두 사람 사이 한복판(中)은 비어 있음.
- 관계: 같은 土 담 앞의 두 사람 = 脾胃 表裏, 「實則陽明 虛則太陰」. 왼쪽은 덜어내고(瀉), 오른쪽은 채운다(補) — 實則瀉之·虛則補之 대비.

③ 판정: 사전 어휘로 왼쪽은 더 잘 풀린다(實+瀉-b로 「실증, 덜어낼 것=음식」이 분명). 오른쪽은 사전 기호가 하나도 없어 인삼·몸짓 같은 일반 독해에 기댄다. 잔결 — 왼쪽 청회색 옷+움츠림이 陽明(不惡寒反惡熱)과 맞지 않음. 솥 바닥에 남은 건더기가 있어 「텅 빈」 조건이 덜 참. 인삼 수염 왼쪽 끝의 흐릿한 흰 번짐은 서린 김(氣)이라기엔 형태가 없어 지운 흔적 같음.
