# 901 판독 (W4)

## 1단계 — 생판 (사전 정보 없이 그림만)

**① 판 표제어**
- 1순위: **虛實 — 邪正盛衰에 따른 虛實(實·虛·虛實眞假)** (55%)
- 2순위: **八綱辨證(陰陽 총강 아래 虛實·寒熱)** (20%) / 3순위 **治則 補虛瀉實·塞因塞用** (10%)
- 근거: 같은 토담 앞 남자 넷이 「큰 가시덤불+빗자루」↔「작은 가시가지+국그릇」, 「진짜 부른 배+빈 솥」↔「부풀린 도포+인삼」으로 두 쌍의 대비를 이룬다. 위쪽 해(위)·달(아래) 깃발은 陰陽 총강으로 읽었다.

**② 인물별 (왼쪽부터)**
- 인물1 **實證(邪氣盛則實)** — 4개: 앞의 거대한 검은 가시덤불=邪氣 盛 / 고함치며 힘찬 자세=正氣 아직 실함(聲高氣粗) / 온몸을 감싼 자욱한 김=邪正相爭 격렬·壯熱 / 빗자루로 쓸어냄=瀉法(實則瀉之·祛邪).
- (깃발) 해 위·달 아래=陰陽(陽上陰下), 八綱의 總綱. 깃대 밑에 말뚝이 하나 더 박힘.
- 인물2 **虛證(精氣奪則虛)** — 4개: 지팡이·처진 어깨·감은 눈=正氣虛(神疲乏力) / 발 앞 작은 가시 잔가지=邪氣도 미약 / 가는 김 한 줄=相爭 미약(虛熱?) / 김 나는 국그릇=補法(虛則補之·扶正).
- 인물3 **眞實假虛(大實有羸狀)** — 3개: 실제로 크게 부른 배=眞實(腹滿·積滯) / 팔을 감싸 움츠린 자세·찌푸린 얼굴=겉의 羸狀(假虛) / 뚜껑 열린 빈 무쇠솥=속을 비워냄=攻下·瀉(또는 胃中空虛—중의적).
- 인물4 **眞虛假實(至虛有盛候)** — 4개: 풍선처럼 부푼 노란 도포=겉의 盛候(假實), 노랑=脾土 / 도포 안 실제 배·다리는 보통 크기=속은 虛 / 두 손을 배에 얹음=喜按(虛) / 인삼=補(塞因塞用).

**③ 잔결**
- 가시덤불·잔가지만 수채 위에 새까만 실루엣이라 붙여 넣은 듯 이질적. 덤불 왼쪽 끝은 프레임에 살짝 잘림.
- 깃대 밑의 두 번째 말뚝은 뜻 불명.
- 인물3의 솥이 '빈 위장(虛)'인지 '비워내기(瀉)'인지 두 갈래로 읽혀 인물3·4의 眞假 배정이 서로 뒤바뀔 위험이 있다.
- 인물2 옆 김 한 줄은 땅(잔가지)에서 오르는지 국에서 오르는지 출처가 애매하다.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위: **虛實 — 邪正盛衰(邪氣盛則實·精氣奪則虛)과 虛實眞假** (65%)
- 2순위: **補瀉 治則(實則瀉之·虛則補之, 扶正祛邪)** (15%)
- 판정: 사전으로 보니 1단계 읽기가 더 단단해졌다. 짚 빗자루=瀉, 따뜻한 국그릇=補, 흰 김=氣, 넘쳐 흐름=盛, 팽팽하게 찬 것=實, 줄어든 것=虛가 모두 등재 기호다. 인물1·2가 「盛+瀉」↔「虛+補」의 짝이 되고, 인물3에서 實이 따로 나온다. 다만 인물4는 사전 기호가 거의 없어 상식(인삼)에 기대야 한다.

**② 인물별 (왼쪽부터)**
- 인물1 **實證(邪氣盛則實)** — 4개: 온몸에서 넘쳐 흘러나오는 흰 김=氣+盛(邪正 모두 성해 격렬히 다툼) / 큰 가시덤불=邪氣 성함(사전 미등재, 관례로 읽음) / 짚 빗자루=瀉 / 고함·부릅뜬 눈=聲高氣粗, 正氣 아직 실함.
- (깃발) 해=陽(사전), 달은 사전에 없음(陰=얼음). 관례상 陰陽 總綱 표지로 읽었고 특정 인물의 병표지는 아니다.
- 인물2 **虛證(精氣奪則虛)** — 4개: 가늘게 줄어든 김 한 줄=氣가 줄어듦=氣虛 / 타다 남은 듯 작고 검은 잔가지=衰(邪도 쇠약) / 찰랑이는 따뜻한 국그릇=補 / 지팡이·처진 몸=神疲乏力.
- 인물3 **眞實假虛(大實有羸狀)** — 3개: 팽팽하게 찬 배=實(사전, 眞實) / 움츠려 팔을 감싸고 찌푸림=겉의 羸狀 / 뚜껑 연 빈 솥=비워 냄(瀉 쪽). 흘러넘친 내용물이 없어서 瀉-b로는 불완전하다.
- 인물4 **眞虛假實(至虛有盛候)** — 4개: 보통보다 크게 부푼 노란 도포(크기가 바뀐 옷이 사실을 진다)=겉의 盛候 / 도포 속 실제 몸은 보통=속은 虛 / 인삼=補(사전 미등재) / 배에 얹은 두 손=喜按.

**③ 잔결**
- 달·가시덤불·인삼·무쇠솥은 사전에 없다. 사전의 補는 국그릇이라 인삼과 補 기호가 둘로 겹친다.
- 빈 솥이 瀉-b 정의(빈 그릇+쏟아진 내용물)를 반만 채워서 인물3·4의 眞假 방향이 뒤집힐 여지가 남는다.
- 깃대 밑 두 번째 말뚝은 뜻 불명이다.
- 가시덤불만 검은 실루엣이라 붙여 넣은 티가 나고, 왼쪽 끝이 잘렸다.
