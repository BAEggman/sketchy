# 901 판독 (X4)

## 1단계 — 생판 (사전 없이, 그림만)

**① 판 표제어**
- 1순위 **陰陽失調 — 陰陽偏盛偏衰 네 갈래(陽盛則熱·陰虛則熱·陰盛則寒·陽虛則寒)** (45%)
- 2순위 **八綱 중 寒熱·虛實 (虛實眞假 포함)** (25%)
- 근거: 해(위)·달(아래) 깃발 = 陰陽(陽上陰下)이 판 전체를 이끌고, 그 아래 네 사람이 「센 열 / 가는 열 / 웅크린 냉 / 부은 냉」으로 갈림.

**② 인물별 (왼→오)**
- **깃발(구역)**: 붉은 해 위·푸른 달 아래 = 陰陽 2요소, 陽在上 陰在下. 장대가 1번과 2번 사이를 가름.
- **인물1 = 陽盛則熱(實熱)** — 5개: 온몸을 감싼 짙은 김 = 壯熱 / 소리치는 입·소리선 = 煩躁·聲高氣粗(實) / 성난 붉은 얼굴 = 面赤 / 빗자루 = 瀉(實則瀉之·熱者寒之) / 빽빽한 검은 가시덤불 = 邪氣盛(또는 陽勝則陰病으로 그을린 陰).
- **인물2 = 陰虛則熱(虛熱)** — 4개: 땅에서 오르는 가는 김 한 줄 = 微熱·虛熱 / 처진 눈·지팡이·구부정 = 虛(神疲·羸瘦) / 시든 가는 가지 = 陰液 마름 / 김 나는 작은 국그릇 = 滋陰·補(또는 줄어든 陰液). 대안 독해: 가시덤불의 잔가지를 쥔 허약자 = 大實有羸狀.
- **인물3 = 陰盛則寒(實寒)** — 4개: 제 몸 끌어안기 = 畏寒·寒主收引 / 부푼 배 = 腹脹滿 / 찡그림 = 寒則痛 / 뚜껑 열린 빈 검은 무쇠솥 = 불 꺼진 솥, 寒(대안: 빈 속 = 至虛有盛候). 푸른 도포 = 寒色.
- **인물4 = 陽虛則寒(虛寒)** — 4개: 퉁퉁 부은 몸 = 虛胖·水濕停留 / 배를 감싸 누르는 두 손 = 喜溫喜按 / 감은 눈·잠잠한 표정 = 靜(陰) / 인삼 뿌리 1개 = 補氣(虛則補之). 노란 도포 = 脾土 또는 萎黃.

**③ 잔결**
- 왼쪽 가시덤불이 판 왼끝에서 잘림. 2번 곁 김 줄기는 출처(불·그릇) 없이 땅에서 솟음 — 뜻이 약함. 3번 솥 뚜껑이 따로 떨어져 있음(「열림/빔」을 노린 듯하나 확정 못 함). 4번의 미소는 「虛寒」과 어긋나 「건강한 사람(陰平陽秘)」으로도 읽힘. 이어 붙인 흔적은 뚜렷하지 않음(담장·벽돌선 연속).

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**판정 변화**: 판 위에 熱(불꽃)·寒(눈송이)·陰(얼음) 글자가 하나도 없다. 1번을 감싼 것은 「서린 흰 김 = 氣」이지 熱이 아니다. 따라서 1단계의 陰陽失調(寒熱) 독해는 근거를 잃는다. 대신 瀉(짚 빗자루)·補(따뜻한 국물 그릇)·虛(줄어든 것)·實(팽팽하게 찬 것)이 정확히 맞물려 판이 「虛實」로 풀린다. 사전 어휘로 더 잘 풀린다.

**① 판 표제어**
- 1순위 **虛實 — 邪正盛衰(邪氣盛則實·精氣奪則虛) + 虛實眞假, 實則瀉之·虛則補之** (55%)
- 2순위 **八綱辨證(陰陽 總綱 아래 虛實綱)** (20%)

**② 인물별 (왼→오)**
- **인물1 = 實(邪氣盛則實)** — 4개: 몸 밖으로 넘쳐 흐르는 흰 김 = 氣+盛 → 氣盛·邪盛 / 손잡이 달린 짚 빗자루 = 瀉(갈림 확인: 이삭 없는 손잡이 빗자루 → 收 아님) → 實則瀉之 / 고함치는 벌린 입 = 聲高氣粗(實의 聞診) / 빽빽한 검은 가시덤불 = 우거진 邪(미등재, 추정).
- **깃발(구역)** — 해 = 陽(등재), 달 = 陰(미등재·추정). 實인 1번과 虛인 2번 사이에 꽂혀 「實屬陽·虛屬陰」 또는 八綱 總綱(陰陽)을 나름. 2개.
- **인물2 = 虛(精氣奪則虛)** — 4개: 1번의 큰 김이 가는 한 줄로 줄어듦 = 虛+氣 → 氣虛·精氣奪 / 덤불이 잔가지 하나로 줄어듦 = 虛(또는 衰: 타다 남은 듯 검고 작음) / 따뜻한 국물 그릇 = 補 → 虛則補之 / 지팡이·처진 눈·구부정 = 神疲·羸弱(虛의 겉).
- **인물3 = 至虛有盛候(眞虛假實)** — 3개: 팽팽하게 부푼 배 = 實·腫 → 겉으로 드러난 盛候(腹脹滿) / 뚜껑을 열어 보인 텅 빈 솥 = 속은 빔 → 至虛(瀉-b의 「밖으로 넘친 내용물」이 없으므로 瀉 아님) / 배를 누르는 손·움츠린 몸 = 喜按·怯 → 虛의 증거.
- **인물4 = 塞因塞用(虛性 脹滿에 補)** — 3개: 인삼 1뿌리 = 補氣(사전의 補와 다른 꼴, 미등재) / 크게 부푼 몸과 배 = 塞(실해 보이는 겉) / 배를 감싼 두 손·편안한 미소 = 補한 뒤 편안해짐. 대안: 正氣充盛(實은 正盛이 아니라 邪盛임을 대비).

**③ 잔결**
- 검은 가시덤불은 사전 미등재이고 왼끝에서 잘림. 달은 미등재(陰의 등재 글자는 얼음·고인 물). 인삼은 사전의 補(국물 그릇)와 겹치는 두 번째 補 표기라 2번·4번의 補가 구별되지 않음. 3번 솥은 빈 그릇이라 瀉-b와 헷갈릴 소지(넘친 내용물 없음으로 가름). 2번 곁 김 줄기는 출처 없이 땅에서 솟음. 이어붙인 흔적은 없음.
