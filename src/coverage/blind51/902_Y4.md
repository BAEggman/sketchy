# 902 판독 (Y4)

## 1단계 — 생판 (사전 없이)

**① 판 표제어**
- 1순위: **내상 병인 — 七情·飮食·勞逸** (55%)
- 2순위: **八綱 虛實 (實證·虛證, 虛實眞假)** (30%)
- 근거: 같은 담장 앞에 네 사내가 나란히 서서 성냄 → 처짐 → 과식 → 비만·안일 순으로 이어진다. 감정·기운·음식·한가함이 차례로 나오는 흐름이다.

**② 인물별 (왼쪽부터)**
- 구역0 (화면 왼쪽 끝, 검은 가시덤불): 인물이 없다. 木·肝(怒傷肝)의 표지이거나 邪氣로 보이나 뜻은 미상이다.
- 인물1: **怒 (怒則氣上)**. 사실 3개: 입 벌려 고함침 = 怒 / 온몸을 감싸고 위로 치솟는 흰 김 = 氣上·氣逆 / 아래를 쓰는 빗자루 = 瀉 또는 飧泄(怒則氣逆, 甚則…飧泄)일 것으로 추정.
- 깃발 (인물1과 인물2 사이): 위에 붉은 해, 아래에 푸른 초승달 = 陽/陰(晝夜). 「暴怒傷陰·暴喜傷陽」을 가리킬 가능성이 있다. 사실 1개.
- 인물2: **悲 (悲則氣消)**, 또는 **勞 (勞則氣耗)**. 사실 4개: 처진 눈썹과 울상 = 悲 / 지팡이 = 勞倦·氣虛 / 가늘게 흩어지는 김 한 줄 = 氣消·氣耗(汗出, 外內皆越) / 김 나는 묽은 미음 그릇 = 조리·脾胃 보양. 발치의 꺾인 가시 잔가지는 덤불(木)이 꺾인 것으로 보여, 悲勝怒(金克木)를 뜻할 수 있다(미상).
- 인물3: **飮食不節 — 過飽·食積**. 사실 3개: 뚜껑이 벗겨진 채 엎어진 솥과 쏟아진 음식 = 暴飮暴食(飮食自倍 腸胃乃傷) / 터질 듯한 배 = 脘腹脹滿 / 어깨를 감싸 움츠림 = 寒(生冷 과식?).
- 인물4: **過逸 (安逸)**. 사실 3개: 비대한 몸과 만족한 얼굴 = 安逸·肥胖 / 누런 옷 = 土·脾(脾失健運, 濕) / 발치의 인삼 = 補氣(逸則氣虛 또는 過補).

**③ 잔결**
- 가시덤불과 잔가지, 빗자루의 뜻이 확정되지 않는다.
- 깃발이 인물1과 인물2 사이에 있어 어느 쪽 소품인지 애매하다.
- 인물3의 어깨 감싸기(寒?)와 인물4의 인삼은 근거가 약하다.
- 담장 이엉 윗선이 깃대 좌우로 미세하게 어긋난다. 이어 붙인 흔적이 약하게 의심된다.
- 프레임 잘림은 없다. 덤불이 왼쪽 가장자리에 닿는 정도다.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽음)

**① 판 표제어**
- 1순위: **虛實 (邪氣盛則實·精氣奪則虛 + 虛實眞假)** (60%)
- 2순위: **治則 — 補虛瀉實·正治/反治 (塞因塞用·通因通用)** (25%)
- 1단계의 **七情·飮食·勞逸**은 10%로 내린다.
- 근거: 사전에서 짚 빗자루 = 瀉, 찰랑한 따뜻한 국물 그릇 = 補, 쏟아진 그릇 = 瀉-b다. 판 전체가 補와 瀉로 갈리므로, 감정이 아니라 虛와 實을 묶는 판으로 읽힌다.

**② 인물별 (왼쪽부터)**
- 구역0 (큰 검은 가시덤불): 사전에 없는 기호다. 해치는 것이 무성하다는 뜻으로 보아 邪氣盛으로 추정한다.
- 인물1: **實證 (邪氣盛則實)**. 사실 4개: 온몸에 크게 서린 흰 김 = 氣 盛(邪正相爭이 격렬함) / 고함 = 聲高氣粗 / 짚 빗자루 = 瀉 → 實則瀉之 / 곁의 큰 가시덤불 = 邪盛.
- 깃발: 해 = 陽(위), 달 = 陰(아래)이다. 八綱의 總綱인 陰陽으로 읽힌다. 사실 1개, 귀속은 애매하다.
- 인물2: **虛證 (精氣奪則虛)**. 사실 4개: 가는 김 한 줄 = 줄어든 氣(虛) → 精氣奪 / 김 나는 찰랑한 국물 그릇 = 補 → 虛則補之 / 지팡이와 처진 얼굴 = 神疲乏力·聲低 / 작게 꺾인 가시 잔가지 = 邪가 작아짐(虛 = 줄어든 것).
- 인물3: **大實有羸狀 (眞實假虛)**. 사실 3개: 팽팽한 배 = 實(食積) / 어깨를 감싸 움츠리고 찡그림 = 羸狀(겉보기 虛) / 뚜껑이 벗겨진 채 엎어져 음식을 쏟은 솥 = 瀉-b(음식을 덜어냄) → 瀉下. 通因通用일 수도 있다.
- 인물4: **至虛有盛候 (眞虛假實)**. 사실 4개: 비대한 몸 = 盛候(겉보기 實) / 누런 옷 = 黃·脾 → 脾虛 / 두 손으로 배를 누르며 편안한 얼굴 = 喜按(虛) / 인삼 = 補氣 → 塞因塞用.

**③ 잔결**
- 가시덤불, 잔가지, 달, 인삼은 모두 사전에 없다. 인삼은 補 기호(국물 그릇)와 꼴이 다르다.
- 솥은 瀉-b와 盛(넘쳐 흘러나옴) 사이에서 갈리고, 깨지지 않았으므로 傷은 아니다.
- 인물4의 누런 옷은 五行왕국 인물의 옷이 아니어서, 五色 규칙을 그대로 적용할지 애매하다.
- 이엉 윗선이 깃대 좌우로 미세하게 어긋난다. 그 밖의 프레임 잘림은 없다.
- 사전 어휘로 읽으니 1단계보다 소품 귀속이 더 잘 풀린다.
