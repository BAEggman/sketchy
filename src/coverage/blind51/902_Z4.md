# 902 판독 (Z4)

## 1단계 — 생판 (사전 어휘 없이)

**① 판 표제어**
- 1순위: **陰陽偏盛偏衰 = 寒熱×虛實 (實熱·虛熱·實寒·虛寒)** — 50%
  해·달 깃발(陰陽 總綱) 아래 네 사람이 2×2로 갈린다: 왼쪽 둘은 김(熱)의 굵기로, 오른쪽 둘은 추위 자세(寒)로, 그리고 사람마다 瀉 도구(빗자루·엎은 솥)/補 도구(국그릇·人蔘)가 번갈아 놓여 實·虛·實·虛.
- 2순위: **病因 — 七情(怒)·勞倦·飮食·過逸** — 20%
  성난 고함(怒), 지팡이 짚은 피로(勞), 부른 배와 쏟아진 솥(飮食), 살찐 한가한 사람(逸)으로도 읽힌다.

**② 인물별 (왼쪽부터)**
- 깃발(구역 표지): 해(위)·달(아래) 두 칸 = 陰陽 / 晝夜.
- 인물1 **實熱(陽盛則熱)** — 4개: 온몸을 감싼 뭉게 김 = 壯熱·外熱 / 고함·성난 눈 = 煩躁·亢奮(실증의 有餘) / 빗자루 = 瀉(實則瀉之, 淸熱) / 무성한 검은 가시덤불 = 邪氣盛.
- 인물2 **虛熱(陰虛則內熱)** — 4개: 땅에서 오르는 가는 한 줄 김 = 微熱·潮熱 / 지팡이·처진 어깨·감은 눈 = 精氣奪則虛(勞倦) / 바싹 마른 잔가지 = 不足·枯(陰液 소모) / 김 나는 묽은 국 한 그릇 = 補(滋陰·穀氣 부족).
- 인물3 **實寒(陰盛則寒)** — 4개: 제 팔을 끌어안음 = 惡寒·寒慄 / 팽팽히 부푼 붉은 배 = 腹脹·冷痛拒按 / 찌푸려 감은 눈 = 痛 / 엎어진 검은 솥·쏟아진 건더기 = 寒積·食積(有餘) → 瀉下.
- 인물4 **虛寒(陽虛則寒)** — 3개: 두툼한 솜 도포 = 畏寒(得溫則減) / 배를 살살 쓰다듬음 = 喜溫喜按 / 人蔘 = 溫補·補氣. (편안한 얼굴, 노란 옷 = 脾土? 미확정)

**③ 잔결**
- 깃대가 판 중앙이 아니라 인물1·2 사이에 서서 「熱 쪽 구역 표지」인지 판 전체 표지인지 애매.
- 인물2의 김이 몸이 아니라 땅에서 따로 오름; 검은 잔가지의 뜻 불확실(덤불의 축소판 = 邪微?).
- 빗자루의 뜻(瀉/風/掃除) 단정 못함. 인물4만 노란 긴 도포 — 색의 뜻 미상.
- 왼쪽 가시덤불이 판 왼끝에서 잘림. 人蔘 왼쪽 끝에 회색 번짐 얼룩. 이어 붙인 솔기는 보이지 않음(담장·초가 이엉 연속).

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**판정**: 1단계의 寒熱 축은 무너진다. 사전에서 熱 = 불꽃·寒 = 눈송이인데 판에 둘 다 없고, 흰 김은 熱이 아니라 **氣**다. 남는 것은 실·허 축과 補·瀉 도구의 번갈음이다. 짚 빗자루(瀉), 찰랑찬 따뜻한 국(補), 텅 빈 솥 + 넘쳐 쏟아진 음식(瀉-b)이 사전과 그대로 맞물려 사전으로 더 잘 풀린다.

**① 판 표제어**
- 1순위: **虛實 (邪正盛衰: 邪氣盛則實·精氣奪則虛 + 虛實眞假 + 實瀉虛補)**: 55%
- 2순위: **陰陽失調 (偏盛·偏衰)**: 20%. 해(陽)·달(陰) 깃발과 盛·衰 기호가 있어서, 病機 단원 안의 다른 꼭지와 묶인 통합판일 가능성.

**② 인물별 (왼쪽부터)**
- 깃발: 해 = 陽, 달 = 陰(달은 미등재) → 陰陽 總綱(實은 陽, 虛는 陰 쪽).
- 인물1 **實 (邪氣盛則實)**, 3개: 몸에서 넘쳐 흘러나오는 흰 김 = 氣+盛(邪氣盛) / 짚 빗자루 = 瀉(實則瀉之) / 무성한 검은 가시덤불 = 有餘(邪, 미등재). 부릅뜬 눈·고함은 실증의 亢奮이다.
- 인물2 **虛 (精氣奪則虛)**, 4개: 타다 남아 작아진 검은 잔가지(덤불이 줄어든 꼴) = 衰·虛 / 거기서 오르는 가는 김 한 줄 = 氣의 衰 / 찰랑찬 따뜻한 국 = 補(虛則補之) / 지팡이·처진 몸 = 虛弱.
- 인물3 **大實有羸狀 (眞實假虛)**, 3개: 팽팽하게 찬 배 = 實 / 웅크려 제 몸을 끌어안은 자세·찡그린 얼굴 = 羸狀(겉으로만 虛) / 텅 빈 솥 + 넘쳐 쏟아진 음식 = 瀉-b(덜어낼 것 = 食積 → 攻下).
- 인물4 **至虛有盛候 (眞虛假實)**, 3개: 곁사람보다 배로 큰 몸집과 부푼 도포 = 盛候(겉으로만 實) / 두 손으로 배를 살살 누름 = 喜按(속은 虛) / 人蔘 = 補氣(미등재, 상식 풀이).

**③ 잔결**
- 미등재 소품이 있다. 달, 가시덤불, 人蔘은 補인데 사전의 補(국그릇)와 다른 사물이다.
- 인물4만 노란 도포를 입었다. 五色 규칙은 五行 다섯 인물에만 적용되지만, 독자가 脾로 오독할 위험이 있다.
- 인물3·4는 「같은 종류 둘 중 하나가 두 배」라서 사전의 大와 겹친다. 그러면 大가 인물4에 붙어 大實(인물3)과 엇갈린다.
- 인물3의 배는 實(팽팽히 참)인지 腫(부풀어 팽팽)인지 갈린다.
- 인물3의 끌어안기는 눈송이가 없어 寒으로 확정되지 않는다.
- 깃대가 판 중앙이 아닌 인물1·2 사이에 있다.
- 덤불이 왼쪽 끝에서 잘렸고, 人蔘 왼쪽에 회색 번짐이 있다. 이어 붙인 솔기는 없다.
