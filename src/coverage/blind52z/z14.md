# z14 판독

## 1단계 — 생판 (사전 보기 전, 확정)

**① 단원** — **陰陽失調 · 陰陽偏盛(陽盛則熱 / 陰盛則寒)** 55%. 차순위 **陰陽偏衰(陰虛則熱 / 陽虛則寒)** 20%, **八綱 寒熱** 15%, **病機 총론(邪正盛衰 포함)** 10%.

**② 인물**
- 왼쪽 사내 — **陽盛則熱(實熱)**. 앞에 큰 화로 1(불길 큼 = 陽 偏盛), 곁에 얼음 1덩이뿐(= 陰이 줄어듦 → 「陽勝則陰病」). 맨발·다리 벌리고 무릎 세운 느긋하게 펼친 자세 = 열은 흩어지고 위로 오름(옷을 벗고 몸을 펼침). 얼굴은 멀쩡함 = 실증이지만 정기는 아직 버팀.
- 오른쪽 사내 — **陰盛則寒(實寒)**. 작은 화로 1(陽이 줄어듦 → 「陰勝則陽病」), 곁에 얼음 4덩이(1+1+2를 쟁반 위에 쌓음, 뒤에 하나 더 숨었을 수 있음) = 陰 偏盛. 맑은 콧물 줄줄 = 「諸病水液澄澈淸冷皆屬於寒」. 두 손으로 배를 감쌈 = 寒性凝滯 → 痛(腹痛). 웅크린 몸·발목 흰 행전 = 寒性收引, 따뜻하게 감쌈.
- 바닥 아래 놋요강(누런 물) = 小便黃赤(熱). 나무통 속 갈색 덩이 = 大便燥結(熱) 또는 숯(땔감).
- 기와집 마루 = 한 몸(같은 방에 둘이 마주 놓임).

**관계** — 둘은 거울짝. 불:얼음 비율이 서로 뒤집혀 있다 = 陰陽은 서로 제약(對立制約)하므로 한쪽이 盛하면 다른 쪽이 病든다(「陽勝則陰病，陰勝則陽病；陽勝則熱，陰勝則寒」, 素問·陰陽應象大論).

**③ 잔결** — 큰 불 옆 얼음 1덩이가 녹지 않음(어색). 나무통 속 덩이가 대변인지 숯인지 불분명. 놋요강·나무통이 마루 밑 땅에 놓여 두 사람 중 누구 몫인지 애매. 누런 얼룩 흙벽 뜻 불명. 오른쪽 기둥 너머로 집이 이어짐(이웃 띠 몫). 이어 붙인 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원** — **陰陽失調 · 陰陽偏盛偏衰** 65%. 두 화로 모두 살아 있는 불이라 얼음 = 陰(갈림 조건 충족), 불 = 陽. 거기에 盛(넘침)·衰(타다 남아 작음)이 얹혀 「陰陽盛衰」가 글자로 읽힌다. 차순위 **邪正盛衰(實熱 ↔ 虛寒)** 25%, **八綱 寒熱** 10%.

**② 인물**
- 왼쪽 사내 — **陽盛則熱(實熱, 陽勝則陰病)**. 화로 위로 넘쳐 치솟는 불길 = 陽 + 盛. 곁의 얼음(陰)은 1덩이뿐 = 陽이 盛하자 陰이 줄어듦. 두 화로가 나란한데 하나가 두 배 이상 = 大(大熱·壯熱 덧뜻일 수 있음). 汗·面 광택은 없음.
- 오른쪽 사내 — **陽衰(陽虛則寒) → 陰이 상대적으로 盛(虛寒)**. 타다 남아 작아진 불 = 陽 + 衰. 얼음 4덩이(陰)가 쟁반 위에 쌓였지만 넘치지는 않으므로 盛 글자는 아님 → 「陽虛則陰盛」. 콧구멍(鼻)에서 맑은 물방울(津) = 淸涕. 손을 몸 한복판에 얹음 = 中(中焦·裏) → 中寒/裏寒 쪽. 쇠못이 없으니 사전상 痛 글자는 아님. 담 안쪽(內)에 앉음 → 「陰盛則內寒」 덧뜻 가능.
- 놋요강 = 小便, 색 누렇다 → 小便黃(熱, 왼쪽 몫으로 보임). 손잡이 나무통 = 大便, 덩이진 갈색 → 大便(오른쪽 아래, 뜻은 미확정).

**관계** — 같은 방의 거울짝: 한쪽은 陽이 盛, 한쪽은 陽이 衰. 陰陽의 對立制約 — 한쪽이 盛하면 짝이 줄어든다(「陽勝則陰病，陰勝則陽病；陽勝則熱，陰勝則寒」 素問·陰陽應象大論 / 「陽虛則外寒，陰虛則內熱，陽盛則外熱，陰盛則內寒」 素問·調經論). 實熱(盛) ↔ 虛寒(衰)의 대비이기도 하다.

**③ 잔결** — 사전으로 더 잘 풀림: 1단계의 「陰盛則寒」은 「陽衰(陽虛則寒)」로 고친다(작은 불 = 衰). 남는 것: 大便통 속 덩이가 溏인지 燥인지 꼴이 사실을 못 짐. 요강의 양(꽤 참)과 색(누렇다)이 엇갈려 短赤인지 애매. 배 감싼 손짓·흰 행전·누런 얼룩벽은 사전 밖. 큰 불 곁 얼음이 녹지 않음. 大(두 배 화로)와 盛이 한 소품에 겹침. 이어 붙인 흔적은 없음.
