# z88 판독

## 1단계 — 생판 (사전 열기 전 확정)

① 단원: **陰陽失調(病機 — 陰陽亡失)** 55% / 2순위 **八綱辨證 陰陽綱(亡陰·亡陽)** 25% / 3순위 **問汗(汗證)** 10%

② 띠 가운데 인물 2명 (한옥 마루, 처마 오른끝)
- 왼쪽 회색 옷 사내 = **亡陽**: 잿빛 얼굴(面色蒼白), 이마의 식은땀(冷汗淋漓), 처진 눈·고개(精神萎靡), 옷을 여며 껴입음(畏寒·蜷臥), 잿빛 손(四肢厥冷). 곁의 흰 사발 = 人蔘 + 갈색 덩이뿌리(附子) 2味 → **參附湯**(回陽救逆).
- 오른쪽 웃통 벗은 사내 = **亡陰**: 웃통 벗음(身熱·惡熱), 어깨·팔 붉게 달아오름, 가슴의 땀(汗熱而粘), 벌린 입(口渴·煩躁·氣促), 꼿꼿이 깨어 있음(手足溫·煩躁). 곁 = 붉은 열매 송이 2 + 낱알 1(**五味子**), 놋그릇의 맑은 물(津液/口渴喜冷飮 또는 麥門冬 대역) → **生脈散**(人蔘·麥門冬·五味子, 益氣斂陰).
- 가운데 등잔: 기름(陰)이 불꽃(陽)을 먹여 살림 — 기름 다하면 불 꺼짐 = 陰陽互根, 가늘게 흔들리는 불꽃 = 陽氣欲脫.
- 관계: 둘 다 大汗 — 亡陰·亡陽 모두 大汗出이 공통, 땀의 冷/熱·粘/稀로 감별. 등잔 하나를 사이에 두고 나란함 = 亡陰하면 곧 亡陽이 따르고(陰亡陽無所依) 그 역도 같다(互根 → 繼發·並見).

③ 잔결: 덩이뿌리 옆 튀는 물방울 3개(附子 맞나, 즙 많은 生地黃인가 불명) / 놋그릇 흰 액체의 몫 불확정 / 등잔 연기선이 왼쪽 인물 무릎으로 이어짐 / 집이 띠 오른쪽에서 끝나고 그 너머는 빈 여백(판의 오른끝일 가능성) / 왼쪽 기둥·지붕은 왼쪽 띠로 이어짐. 이음 자국은 뚜렷하지 않음.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

① 단원: **陰陽失調(陰陽亡失 / 차순 陰陽偏衰)** 60% — 등잔이 陽(살아 있는 불)과 陰(졸아든 기름)을 한 그릇에 담아 陰陽 틀을 굳힘. 2순위 **八綱 寒熱·虛實** 20%, **問汗** 10%.

② 인물 2명
- 왼쪽 = **亡陽**(차순 **陽虛 自汗**): 이마 땀방울 = **汗**. 앞의 흰 사발 = **補-b**(담긴 것 = 人蔘 + 덩이뿌리 → 채워 줄 것은 氣·陽). 덩이뿌리 옆 맑은 방울 = **津**. 덩이뿌리가 사전의 **地黃**(검붉은 뿌리 조각)이면 氣陰 補로 갈리나, 그림은 회갈색 통덩이라 地黃 판정이 약하고 附子(參附湯) 쪽이 낫다. 잿빛 얼굴·처진 눈꺼풀·다물지 못한 입은 사전 **善惡**의 惡色 묘사와 같지만 쌍둥이 조건이 아니라 적용 불가. 손은 잿빛일 뿐 검푸르지 않아 **厥** 미달.
- 오른쪽 = **亡陰**(차순 **陽盛/陰虛 熱**): 가슴 땀 = **汗**. 놋그릇 맑은 물 = **淸**(熱者淸之, 또는 口渴喜冷飮). 붉은 열매 송이 2 + 낱알 1 = 사전대로면 **血**(붉은 것), 본초로는 **五味子**(生脈散·斂汗) — 사전엔 五味子가 없다.
- 관계: 둘 다 **汗** — 땀이 공통, 冷熱로 가름. 두 사람 **사이 한복판**(中)에 놓인 등잔 = 陽(불꽃)이 陰(기름)에 기대 탐 → 陰竭하면 陽脫(互根: 亡陰↔亡陽 繼發). 보·청 대비 = 왼쪽 補, 오른쪽 淸.

③ 판정: 사전 어휘(汗·補·淸·陽/陰·津)는 1단계 읽기를 뒷받침할 뿐 뒤집지 않는다. 다만 參附湯·生脈散을 가리키는 人蔘·附子·五味子는 사전 밖 본초 지식에 기댄다. 잔결: 두 사람이 앉아 담담해 「亡」의 위급함(누움·脈微欲絶)이 약함 → 偏衰와 갈림 / 붉은 열매 血 vs 五味子 / 厥 미달 / 등잔 연기선의 몫 불명.
