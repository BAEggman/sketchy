# 901 판독 (A5)

## 1단계 — 생판 (사전 없이)

**① 판 표제어**
- 1순위 **陰陽失調** (病機: 陰陽偏盛 → 偏衰 → 格拒 → 亡失) — 75%
- 2순위 **八綱 寒熱辨證** (寒熱의 虛實 + 寒熱眞假 + 亡陰亡陽) — 20%

**② 인물 (왼→오, 기둥 셋으로 4칸, 칸마다 2인)**

[1칸 — 偏盛]
1. **陽偏盛 (陽勝則熱·實熱)** — 큰 불 화로(陽 과잉), 곁 얼음 한 덩이 정상크기(陰은 그대로), 느긋이 기댄 건장한 자세(實). 아래 놋요강의 누런 소변(小便黃赤). 3~4개.
2. **陰偏盛 (陰勝則寒·實寒)** — 얼음 5덩이 무더기(陰 과잉), 작은 불 정상(陽 그대로), 배 움켜쥠(寒凝腹痛), 맑은 콧물·눈물(淸稀 분비물), 발에 버선(畏寒). 나무통의 덩어리 똥은 귀속 불확실. 5개.

[2칸 — 偏衰]
3. **陽偏衰 (陽虛則寒·虛寒)** — 불 꺼진 화로(숯만, 陽 부족), 얼음 정상크기(陰 그대로), 옷 껴입고 기운 없음, 손에 둥근 갈색 조각+붉은 막대(附子片·肉桂 = 溫陽藥으로 읽음), 아래 뚜껑 열린 놋단지의 맑은 소변(小便淸長). 5개.
4. **陰偏衰 (陰虛則熱·虛熱)** — 얼음이 녹아 쟁반에 작은 조각만(陰 부족), 작은 불 정상(陽 그대로), 갈비뼈 드러난 마른 몸(消瘦), 웃통 벗음(虛熱), 손에 붉은 열매(枸杞子/山茱萸 = 滋陰). 5개.

[3칸 — 格拒·眞假]
5. **眞熱假寒 (陽盛格陰)** — 겉은 오색 솜이불 칭칭(假寒: 欲得衣被), 등 뒤 문틈 속 붉은 불씨(속은 熱), 앞의 시커멓고 단단한 똥덩이(燥屎·大便秘結 = 眞熱 근거). 3개.
6. **眞寒假熱 (陰盛格陽)** — 웃통 벗고 이불 걷어참(假熱: 揭去衣被), 곁 문짝에 눈송이(속은 寒), 엎어진 솥에서 쏟아지는 묽은 죽(下利淸穀 = 眞寒 근거), 뚜껑 굴러감. 3~4개.

[4칸 — 亡失]
7. **亡陽** — 창백한 얼굴·흰 손(面色蒼白·肢冷), 이마의 식은땀(冷汗淋漓), 꺼져가는 등잔불(陽氣 欲脫), 그릇 속 人蔘+附子(參附湯). 5개.
8. **亡陰** — 붉은 몸 전신 땀(熱汗·汗出如油), 입 벌림(口渴·氣促), 물 사발(口渴喜飮/陰液), 붉은 열매 송이(五味子 → 生脈散 斂陰). 4개.

**③ 잔결**
- 1칸 아래 나무통의 갈색 덩어리(똥? 밤?) — 실열의 便秘인지 실한의 무엇인지 귀속 불명.
- 3인 손의 갈색 원반+붉은 막대가 무슨 약재인지 확정 어려움.
- 7·8 사이 등잔이 누구 것인지 경계 애매. 프레임 잘림·이어붙임 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어** — 사전으로 더 잘 풀린다. 4칸 = 偏盛 / 偏衰 / 格拒 / 亡失.
- 1순위 **陰陽失調** — 85%
- 2순위 **八綱 寒熱辨證 (寒熱虛實·寒熱眞假)** — 10%

**② 인물**
1. **陽偏盛(陽勝則熱)** — 불=陽, 화로 밖까지 넘친 불꽃=盛 → 陽盛 / 살아 있는 불 곁 얼음=陰, 정상 크기(陰은 아직 안 줄어듦) / 요강(小便): 적고 누렇다 → 小便短赤. 3개.
2. **陰偏盛(陰勝則寒)** — 살아 있는 작은 불 곁 얼음 5덩이 무더기 → 陰盛, 작은 불(陰勝則陽病) / 배 움켜쥠(腹冷痛) / 맑은 물방울 콧물·눈물=津 → 분비물 淸稀 / 버선(畏寒) / 뒷간통(大便) 덩이똥 — 귀속 애매. 5개.
3. **陽偏衰(陽虛則寒)** — 타다 남은 숯·꺼진 화로=衰 → 陽虛 / 꺼진 불 곁 얼음은 陰이 아니라 傷陽의 결과 → 虛寒 / 손의 附子片·肉桂(益火之源) / 요강: 많고 맑다 → 小便淸長. 4개.
4. **陰偏衰(陰虛則熱)** — 살아 있는 불 곁 얼음이 1/3로 줄어든 조각=虛 → 陰虛, 불은 그대로 → 상대적 陽亢 / 갈비뼈 드러난 消瘦 / 웃통 벗음(虛熱) / 손의 붉은 열매(山茱萸·枸杞 = 壯水之主; 「붉은 것=血」이면 陰血). 4개.
5. **眞熱假寒(陽盛格陰)** — 병표지 불꽃이 닫힌 문틈에서 새어 나옴 = 內(문 안쪽)+熱+格 / 솜이불 칭칭(겉으로 寒) / 바닥의 검고 굳은 덩이(燥屎 → 眞熱, 사전 미등재). 3개.
6. **眞寒假熱(陰盛格陽)** — 곁에 뜬 눈송이 병표지 = 寒 / 웃통·이불 걷어참(겉으로 熱) / 엎어진 솥에서 아래로 쏟아진 묽은 죽 = 下+瀉-b → 下利淸穀. 3개.
7. **亡陽** — 이마 땀방울=汗(冷汗) / 창백한 얼굴·흰 손(肢冷) / 타다 남아 작아진 등잔불=衰 → 陽氣 欲脫 / 그릇에 가득 담긴 人蔘+附子 = 補-b → 參附湯. 4개.
8. **亡陰** — 온몸 땀방울=汗(熱汗·汗出如油) / 벌린 입(口渴·氣促) / 맑은 물 한 사발=淸(喜冷飮) — 또는 「졸아드는 고인 물=陰」 / 붉은 열매 송이(五味子 → 生脈散 斂陰). 4개.

**③ 잔결**
- ⚠ 5·6의 이불 단서가 古典 기준과 거꾸로다: 傷寒論 11조 「身大熱 反欲得衣者 熱在皮膚 寒在骨髓; 身大寒 反不欲近衣者 寒在皮膚 熱在骨髓」 — 衣被를 원함=眞寒, 걷어참=眞熱. 그림은 이불을 「겉모습」으로 써서 다른 소품(문틈 불·燥屎 / 눈송이·下利)과 충돌. 이 기준을 아는 독자는 5=眞寒, 6=眞熱로 뒤집어 읽을 위험.
- 눈송이는 사전 갈림상 外寒인데 6의 뜻은 裏寒 — 성에(裏寒)·서리(內寒)가 맞다. 문틈에 걸쳐 格으로도 애매하게 읽힘.
- 5 앞 검은 덩이: 뒷간통이 아니라 大便으로 확정 불가(瘀 조건 「그릇·천 위」에도 안 맞음).
- 1칸 뒷간통 귀속(1인 秘結? 2인?) 불명. 1·2 화로 크기 대비가 「大」로 오독될 여지.
- 등잔은 7·8 사이 한복판(中) — 亡陽 소품인지 陰陽離決 공용인지 애매. 프레임 잘림·이어붙임 흔적 없음.
