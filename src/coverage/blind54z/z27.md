# z27 판독 (blind54z)

## 1단계 — 생판 (사전 보기 전 확정)

**① 단원**: **氣의 失常(氣虛·氣機失調)** — 病機 중 精氣血津液 失常의 「氣」 부분. 확신도 75%. 차순위 **氣機失調(滯·逆·陷·閉·脫)** 단독.

**② 인물(같은 상투·같은 옷의 한 사람이 좌→우 네 번 등장)**
- 1번 **氣虛**: 창백·처진 눈·힘없이 선 자세 = 神疲乏力·少氣懶言·面色淡白. 몸 윤곽을 따라 얇게 피어오르는 흰 기운 = 얇아진 衛氣막(易感·自汗). 차순위 **氣脫**(몸 밖으로 새는 기운).
- 2번 **氣滯**: 문틀 한가운데 끼어 찡그리고 한 손은 옆구리·복부, 한 손은 허리 = 脹·悶·痛, 부위가 옮겨 다니는 竄痛. 등 뒤로 뭉쳐 쌓인 김 = 기가 흐르지 못하고 몰림. 문틀(門)은 **氣閉**의 「閉」를 겸할 수도.
- 3번 **氣逆**: 고개를 젖히고 누런 토물 = 胃氣上逆(嘔吐·噯氣·呃逆). 김 줄기 3갈래(머리 왼쪽·입에서 뿜는 줄기·목 오른쪽) = 氣逆의 3臟 **肺(咳喘)·胃(嘔吐)·肝(頭痛·眩暈·昏厥)**. 머리 위 작은 김 덩이 = 상부로 치솟음.
- 4번 **氣陷**: 땅 구덩이로 무릎까지 빠짐 = 下陷, 두 손으로 불룩한 배를 받침 = 脘腹墜脹·內臟下垂(胃下垂·脫肛·子宮脫垂). 中氣(脾) 下陷.
- 배경: 누런 흙담·초가 이엉·흙바닥 = 土 → 中焦 脾胃가 升降의 樞紐.

**관계**: 한 사람의 네 모습 = 氣虛가 바탕이 되어 氣機失調로 번짐(虛→滯, 虛→陷: 氣陷은 氣虛의 진행형). 가운데 셋은 방향으로 대비 — 제자리 막힘(滯)·위로(逆)·아래로(陷) = 升降出入 이상.

**③ 어색한 것**: 벽 없이 홀로 선 문틀(門→閉?), 4번은 가라앉는데 김은 구덩이에서 위로 솟음(방향 모순), 3번 머리 위 작은 김 덩이의 몫 불명, 오른쪽 끝 돌담은 흙담과 재질이 달라 이웃 띠 몫/이음 흔적.

## 2단계 — 계통 (blind6 사전 어휘로 다시 읽기)

**① 단원**: **氣의 失常 — 氣機失調(+氣虛)** 유지, 확신도 80%. 「氣 = 서린 흰 김」이 네 사람 모두에 붙어 있어 주어가 氣로 확정되고, 上·下·門이 그 氣의 「움직임 이상」을 갈라 준다.

**② 인물**
- 1번 **氣虛**: 몸 윤곽 전체를 감싼 얇은 흰 김(氣) + 창백·처진 눈꺼풀. 단 사전의 虛(1/3로 줄어든 것)도, 汗(땀방울)도 없어 기호만으로는 虛·脫이 갈리지 않음. 땀·주저앉음이 없으므로 **氣脫**보다 氣虛 쪽.
- 2번 **氣閉**(1단계 氣滯에서 바꿈): 등록 기호 「門 = 작은 문간(문틀)」 + 문 안쪽(內)을 꽉 메운 뭉친 김 = 氣가 안에 갇혀 밖으로 나가지 못함(閉 = 門). 옆구리를 움켜쥔 몸짓 = 閉阻로 생긴 絞痛(痛 기호인 쇠못은 없음). 차순위 **氣滯**(심해지면 閉가 됨).
- 3번 **氣逆**: 입에서 비스듬히 위로 뿜는 김·머리 옆으로 솟는 김 = 「上」 → 氣上. 누런 토물 = 胃氣上逆(嘔吐). 김 3갈래는 肺·胃·肝 氣逆으로 읽고 싶지만, 臟 기호(오행 다섯 인물)가 없어 개수가 사실을 나르는지는 확증할 수 없음.
- 4번 **氣陷**: 땅으로 빠져 가라앉음 = 「下」 → 氣下陷. 두 손으로 받친 팽팽한 배(腫·實의 팽팽함) = 脘腹墜脹·內臟下垂.

**관계**: 같은 사람 넷 = 한 몸에서 일어나는 氣 병기의 갈래. 3번(上)·4번(下)이 나란히 서서 升降 이상(逆=지나치게 오름 / 陷=오르지 못하고 꺼짐)의 대비를 이루고, 2번(門)은 出入 이상(氣閉 = 나가지 못함). 맨 앞 1번(氣虛)이 바탕이 되어 陷으로 이어진다(氣陷은 氣虛가 심해진 것).

**③ 잔결**: 1번은 虛·汗 기호가 없어 虛인지 脫인지 그림만으로 정해지지 않음. 2번 문틀은 閉로 읽어야 기호가 일을 하지만, 몸짓은 滯(脹痛)에 더 가까움. 4번 김이 구덩이에서 위로 솟음(下와 반대 방향). 누런 토물은 사전에 없는 기호. 오른쪽 끝 돌담은 이웃 띠 몫.
