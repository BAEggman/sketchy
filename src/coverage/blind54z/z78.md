# z78 판독

## 1단계 — 생판 (사전 없이)

**① 단원**: **氣血失調 중 血失調**(血虛·血瘀·血熱/出血) 1순위 65% · 2순위 **病機(血의 병리)** 일반 20% · 3순위 **瘀血(병리산물)** 10%.

**② 인물 3명 + 발밑 도랑 3줄(도랑 = 脈/血府)**
- 왼쪽 **血虛**: 얼굴이 창백·누르스름(面色無華/萎黃), 눈꺼풀 처지고 힘없음(頭暈·疲倦). 한 손으로 다른 손목을 감싸고 손가락을 벌려 떪 → 肢體麻木·震顫(血不養筋). 발밑 도랑은 말라 갈라지고 붉은 실줄 몇 가닥만 흐름 → 脈道 不充(脈細).
- 가운데 **血瘀**: 이를 악문 통증 얼굴, 얼굴 그늘이 거무스름(面色黧黑?). 오른손으로 배의 덩어리를 움켜쥠(떨림선) → 腫塊·拒按, 왼손이 옆구리에 못을 박아 쥠 → 刺痛·痛有定處. 도랑 속 검붉은 덩어리 2무더기(위 2덩이, 아래 3덩이) + 도랑 밖 검은 점·덩이 → 혈이 막혀 뭉침, 離經之血도 瘀가 됨.
- 오른쪽 **血熱(→出血)**: 무표정·꼿꼿. 도랑 피가 끓어(거품) 불꽃 4~5개와 함께 도랑 밖으로 넘쳐 흥건 → 血熱 迫血妄行 → 出血(血溢脈外). 곁의 붉은 피 담긴 항아리 → 피를 끓이는 솥(煎熬)?
- 배경: 초가지붕 흙담·자갈 기단 — 무대.

**관계**: 같은 옷 세 사람·세 도랑을 나란히 → 血의 세 이상(양 不足 / 운행 不暢 / 熱로 妄行). 가운데 瘀가 좌우를 이음: 血虛致瘀, 血熱煎熬致瘀, 出血 後 離經之血 → 瘀.

**③ 잔결**: 오른쪽 인물 자체에 熱 표지(面紅·煩躁)가 없음. 항아리의 몫이 불분명(煎熬? 出血 받아 둔 것?). 맨 왼쪽 돌담은 이웃 띠 몫. 도랑 피 흐름 방향 표지 없음.

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**① 단원**: **氣血失調 중 血失調** 70% (사전으로 血·瘀·熱·痛·虛·盛이 모두 확정돼 1단계보다 올림) · 2순위 **精氣血津液 失調** 20%.

**② 다시 읽기** — 도랑 속 붉은 것 = **血**(사전), 세 도랑이 세 사람 각자의 血.
- 왼쪽 **血虛**: 도랑 피가 실줄로 줄어듦 = **虛**(삼분의 일로 줄어든 것) → 血虛. 도랑 바닥이 갈라짐 = **燥**(갈라진 땅) → 血虛生燥(血燥). 얼굴에 광택 없음 = **華** 결여 → 面色無華(얼굴색 자체는 望色 판 몫이라 보조로만). 떨며 비비는 손 → 麻木·震顫(사전 글자 아님, 1단계 그대로).
- 가운데 **血瘀**: 도랑 안 검붉게 굳은 덩이 = **瘀**(위 2·아래 2~3덩이) + 도랑 밖 덩이 1·점 4~5개 = 脈 밖의 瘀(離經之血). 옆구리에 박힌 쇠못 **하나** = **痛** → 瘀血 → 痛(不通則痛, 刺痛·痛有定處). 배를 움켜쥔 손 → 腫塊·拒按 후보(사전의 **腫**만큼 부풀지 않아 약함).
- 오른쪽 **血熱**: 불꽃 5개 = **熱**, 도랑 밖으로 흘러넘침 = **盛** → 血熱 熱盛 → 迫血妄行·出血(血溢脈外). 거품 = 끓음(煎熬). 곁 항아리에 가득 찬 붉은 것 = **補-b**(그 사람에게 채우는 것 = 血)로 읽히나 血熱 인물 곁이라 뜻이 맞지 않음 → **實**(찬 것)로 읽어 「血熱 = 實」 대 「血虛 = 虛」 대비일 가능성.
- 세 사람 중 가운데 = **中** 글자가 걸리나, 몸 위가 아니라 사람 배열이라 이 판에선 과독으로 판정.

**관계**: 같은 세 사람 + 같은 세 도랑 = 血失調의 세 꼴을 量(虛·줄어듦) / 運行(瘀·막힘) / 熱(盛·넘침)으로 대비. 가운데 瘀가 좌우를 잇는 결과물: 血虛致瘀·血熱煎熬致瘀·出血 後 離經之血 → 瘀. 사전이 1단계 읽기를 뒤집지 않고 확정해 줌(오른쪽 = 「血熱」보다 「血熱→出血(盛)」 쪽이 더 정확).

**③ 잔결**: 항아리의 글자가 갈림 없이 둘(補-b/實)로 갈려 확정 불가. 오른쪽 인물 몸에 熱 표지 없음(불꽃은 도랑에만). 왼쪽 도랑의 갈라짐(燥)이 의도인지 마른 바닥 묘사인지 불분명. 맨 왼쪽 돌담은 이웃 띠 몫.
