# z79 판독

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원**: **氣血失常(血의 失常)** 1순위, 65%. 띠 자체는 「血의 病機」 셋 — 血虛·血瘀·血熱(出血). 통합판 전체는 氣 쪽(氣虛·氣滯·氣逆…)과 묶인 **氣血失調** 판으로 본다. 2순위 **病機學說 총판**(20%).

**② 인물·소품**
- 왼쪽 사내 = **血虛**. 얼굴이 누렇고 푸르스름하게 창백하다(面色淡白·萎黃). 눈꼬리가 처졌다(頭暈·眼花). 두 손을 힘없이 늘어뜨려 떤다(手足麻木, 血不養筋). 발 앞 도랑은 거의 말라 실핏줄 하나만 흐른다 = 脈道不充, 血이 모자라 脈을 채우지 못함.
- 가운데 사내 = **血瘀**. 옆구리에 못이 박혔고 배를 움켜쥐고 이를 악문다 = 刺痛, 못이 한 자리에 박힘 = 痛處固定·拒按. 얼굴빛이 어둡다(面色晦暗). 도랑 안의 검붉은 덩어리 2개와 밖의 작은 덩어리 1개(셋) = 血塊·瘀阻脈道, 색 紫暗.
- 오른쪽 사내 = **血熱(→出血)**. 도랑이 끓어 거품이 일고 불꽃이 4개쯤 솟으며 밖으로 넘친다 = 熱迫血行, 血行加速, 溢出脈外(出血).
- 놋(황금빛) 단지 = 피가 담겨 있고 뚜껑이 벗겨졌다. 노랑=土=**脾統血**이고, 뚜껑이 열린 것은 統攝 실패, 곧 **氣不攝血**(出血의 두 번째 원인)으로 읽는다(확신 낮음).
- 배경: 이엉을 얹은 흙담은 무대를 나눌 뿐 뜻은 약하다.

**관계**: 세 사람이 나란히 서서 도랑 셋(血脈)을 하나씩 맡는다. 같은 脈 안에서 血이 「모자람(虛) – 막힘(瘀) – 넘침(熱·妄行)」으로 갈린다. 量의 이상(血虛)과 運行의 이상(血瘀·出血)이 血失常의 두 축이다. 瘀와 出血은 서로 원인이 될 수도 있다(離經之血 = 瘀血).

**③ 잔결**: 오른쪽 사내는 血熱인데도 얼굴이 담담하다(面紅·心煩이 빠졌다). 놋단지의 뜻은 분명하지 않고, 血寒을 맡은 인물은 없다. 왼쪽 끝 돌기둥 담은 띠 경계 표지거나 이웃 띠 몫으로 보인다. 오른쪽 단지 아래 흙담 이음매가 약간 어긋난다.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 단원**: **氣血失常(血의 失常)** 70%. 사전 글자가 1단계 해석을 그대로 받쳐 주고, 바뀐 것은 없다. 2순위 **病機學說 총판**.

**② 글자로 다시 읽기**
- 왼쪽 = **血虛**. 도랑 속 붉은 것(血)이 폭의 1/3도 안 되는 실줄로 줄었다 = 虛. 그래서 血虛, 脈道不充이다. 얼굴빛은 사전상 望色 판 전담이므로 글자로 읽지 않는다. 처진 손도 증상 묘사일 뿐이다. 爪·筋 글자는 없다.
- 가운데 = **血瘀**. 살에 박힌 쇠못 하나 = 痛(1). 몸 밖 도랑 안에서 검붉게 굳은 덩이 = 瘀이고, 도랑 안 2·밖 1로 셋이다. 살갗 위의 얼룩이 아니므로 갈림 조건을 통과한다. 합치면 「瘀血 → 不通則痛」, 刺痛·痛處固定이다. 「셋 중 가운데 = 中」 갈림은 사람 배열에 걸릴 수 있지만 이 판에서 붙는 뜻이 없어 읽지 않는다.
- 오른쪽 = **血熱(→出血)**. 불꽃 = 熱(4개쯤), 붉은 것 = 血, 넘쳐 흘러나옴 = 盛. 熱盛이 血을 몰아 脈 밖으로 넘치게 한다(血熱妄行·血溢脈外). 그릇이 비지 않았으므로 瀉-b가 아니다.
- 놋단지: 그릇에 가득 담긴 붉은 것 = **補-b**, 곧 「血을 채움」(補血)이다. 넘치지 않아 瀉-b가 아니다. 뚜껑을 벗겨 내용물을 보인 꼴이다. 1단계의 脾統血(노랑=土) 해석은 사전에 근거가 없어 버린다.

**관계**: 같은 脈(도랑) 셋에서 血이 虛(줄어듦)·瘀(막힘)·盛(넘침)으로 갈린다. 量의 이상과 運行의 이상, 곧 血失常의 갈래다. 세 이상은 서로 꼬리를 문다. 血虛致瘀, 血熱煎熬成瘀가 있고, 넘친 離經之血은 다시 瘀가 된다.

**③ 잔결**: 補血 단지가 血虛(왼쪽)가 아니라 血熱 사내 곁에 있다. 血熱의 治는 凉血이라 자리가 어긋나며, 오른쪽 이웃 띠 몫일 수 있다. 血熱 사내는 얼굴이 담담해 병표지가 몸에 없고 도랑에만 있다. 血寒(눈송이)은 이 띠에 없다. 왼쪽 끝 돌담 기둥은 글자가 없는 경계물이다.
