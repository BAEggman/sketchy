# 901 판독 (E5)

## 1단계 — 생판 (사전요약 열기 전 확정)

**① 판 표제어**
- 1순위 **氣血失調(기의 失常 + 혈의 失常)** — 85%
- 2순위 **氣血津液辨證(氣病·血病 辨證)** — 10%
- 근거: 같은 옷차림의 7인이 돌기둥(담) 하나로 좌4·우3으로 갈린다. 왼쪽 4인은 모두 하얀 김(氣)을 두르고, 오른쪽 3인은 발 앞에 붉은 도랑(脈道/血)을 하나씩 가진다 → 左=氣, 右=血.

**② 인물별 (왼쪽부터)**
1. **氣虛**(2순위 氣脫) — 3개: 몸 둘레로 얇게 번져 나가는 흰 김 = 기가 흩어져 固攝 못 함(自汗); 처진 눈·힘 빠진 선 자세 = 神疲乏力·少氣懶言; 창백한 얼굴.
2. **氣滯**(2순위 氣閉) — 3개: 문틀 안에 끼어 못 나감 = 氣機 막힘; 김이 몸 뒤·옆에 뭉쳐 갇힘 = 기가 정체; 옆구리·배를 움켜쥔 찡그림 = 脹痛(脇肋·脘腹).
3. **氣逆** — 3개: 위를 향해 입으로 김을 뿜음 = 上逆; 노란 토물 = 胃氣上逆(嘔吐·噯氣); 가슴·목깃에서 김이 솟음 = 肺氣上逆(咳喘). 고개를 젖힌 자세 = 肝氣上逆(頭暈) 가능.
4. **氣陷** — 3개: 무릎까지 땅 구멍에 빠짐 = 下陷; 김이 아래로 흘러 땅에 박힘 = 中氣 下陷; 아랫배를 받쳐 든 자세 = 小腹 墜脹(內臟下垂·脫肛 연상).
- (돌기둥) 氣/血 경계 표지.
5. **血虛** — 3개: 누르스름·푸르스름한 창백한 얼굴 = 面色 萎黃/蒼白; 떨리는 두 손 = 手足 麻木·震顫(血不養筋); 발 앞 도랑에 실핏줄만 남은 마른 바닥 = 脈道 不充(脈細).
6. **血瘀** — 4개: 손에 쥔 못(가시)으로 옆구리 찌름 = 刺痛; 한 곳을 움켜쥠 = 痛處固定; 도랑 안 검붉은 덩어리 2 = 血塊·紫暗; 도랑 밖으로 튄 덩어리 = 離經之血도 瘀血.
7. **血熱(→出血)** — 3개: 도랑에 불꽃 = 血分 熱; 거품 내며 끓어 넘침 = 血行 加速; 도랑 밖으로 범람 = 迫血妄行→出血. 곁의 붉은 피 항아리 = 出血(吐·衄血 받아 둔 것?) 추정.

**③ 잔결**
- 오른쪽 아래 피 웅덩이가 x≈2018px에서 수직선으로 잘리고 그 오른쪽은 빈 바탕 띠 → 프레임 이어 붙임/패딩 흔적.
- 화면 위 약 18%가 빈 하늘(여백 과다, 확장 흔적 가능).
- 피 항아리 뜻 불명. 문틀(氣滯 vs 氣閉) 모호. 7번 얼굴이 평온해 熱 징후(面赤·心煩) 없음. 1번 흰 기운은 氣虛·氣脫 사이에서 갈림.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **氣血失調** — 90% (氣=서린 흰 김이 왼쪽 4인에만, 血=붉은 것이 오른쪽 3인에만 → 좌우 이분이 사전으로 확정됨)
- 2순위 **氣血辨證(氣病·血病)** — 7%

**② 인물별 (왼쪽부터)**
1. **氣虛**(65%, 2순위 氣脫) — 2개: 氣(흰 김)가 몸 윤곽에 얇게 서림 + 처진 눈·힘 빠진 자세(神疲乏力). 사전의 虛(1/3로 줄어듦)·散(사방으로 날림) 기호는 둘 다 없음 → 표정으로만 虛를 읽게 됨. 氣脫이면 散이 있어야 하는데 없으므로 氣虛 쪽.
2. **氣滯**(55%, 2순위 氣閉 40%) — 3개: 氣(김)가 몸 뒤에 뭉쳐 못 빠져나감 = 정체; 門(문틀) = 氣의 出入 통로가 막힘(3번 上·4번 下와 함께 升降出入 세트); 옆구리·배 움켜쥔 찡그림 = 脹痛. 痛 기호(쇠못)는 없음. 門 글자가 閉(門+才)를 끌어당기지만 문짝이 없는 열린 문틀이라 閉로 확정 못 함. 格(막은 문틈으로 밀려 나감)은 닫힌 문이 없어 해당 없음.
3. **氣逆** — 3개: 氣가 입에서 거꾸로 위로 뿜어짐 + 가슴깃에서 위로 솟은 두 줄기(上逆, 肺氣上逆 咳喘); 노란 토물이 입에서 흘러내림 = 胃氣上逆 嘔吐; 머리 위 작은 김뭉치 = 上(머리로 솟음)·頭暈 가능.
4. **氣陷** — 3개: 下(아래로 가라앉음) = 땅 구멍에 무릎까지 빠짐; 氣가 아래로 흘러내려 땅에 박힘 = 中氣下陷; 받쳐 든 아랫배 = 小腹墜脹·內臟下垂.
- (돌담 기둥) 氣/血 칸막이.
5. **血虛** — 3개: 血(붉은 것)이 도랑 바닥에 실금처럼 줄어듦 = 虛(줄어든 것) → 脈道 不充·脈細; 창백·누런 얼굴 = 面色 蒼白/萎黃(얼굴색은 面 기호 아님 — 望色 판 관례대로 색 자체로만); 떨리는 두 손 = 麻木·震顫(血不養筋).
6. **血瘀** — 4개: 瘀 = 도랑 안 검붉게 굳은 덩이 2 + 밖으로 튄 덩이 1·알갱이 몇(몸 밖·그릇 안이라 갈림 조건 충족); 痛 = 살에 박힌 쇠못 하나 → 刺痛; 한 점 움켜쥠 = 痛處固定; 덩이로 막혀 느린 흐름 = 血行 不暢.
7. **血熱** — 3개: 熱 = 핏물 위 불꽃; 盛 = 도랑 밖으로 넘쳐 흘러나옴 → 迫血妄行·出血; 거품 내며 끓음 = 血行 加速. 곁 피 항아리는 사전상 補-b(가득 담김=채워 줌)나 會(담긴 것=血會)로 읽히는데 둘 다 血熱과 안 맞음 → 뜻 불명.

**③ 잔결**
- 오른쪽 아래 피 웅덩이가 x≈2018px 수직선으로 잘리고 오른쪽 띠는 빈 바탕(밝기 241 고정) → 패딩·이어붙임 흔적.
- 위쪽 약 18% 빈 하늘.
- 사전 충돌 위험: 피 항아리(補-b/會), 4번 팽팽히 부푼 배(實·腫으로 오독 가능 — 氣陷은 虛證), 돌담 기둥(內/外로 오독 가능), 3번 벌린 입(舌이 보이면 心 — 입속은 어두워 口 정도), 2번 문틀(門 → 閉/格 견인).
- 1단계 대비 변화: 표제·인물 7개 판정은 동일. 사전으로 6번(瘀·痛)·4번(下)·7번(熱·盛)·5번(虛)이 기호로 확정됐고, 1번·2번은 여전히 표정 의존.
