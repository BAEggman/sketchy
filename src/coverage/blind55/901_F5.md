# 901 판독 (F5)

## 1단계 — 생판 (사전 어휘 없이)

① 판 표제어: 1순위 **氣血失常(氣病·血病 病機)** 88% / 2순위 **氣血辨證** 10%. 같은 옷차림 7인을 돌기둥 담이 4:3으로 가른다 — 왼쪽 4인은 흰 김(氣)만, 오른쪽 3인은 발밑 도랑(脈道)의 피만 다룬다.

② 인물별 (왼쪽부터)
- 인물1 **氣虛** — 창백·처진 눈의 무기력한 얼굴(神疲乏力·少氣懶言), 몸을 감싼 희미하게 흩어지는 김(氣가 약해 새어 나감). 2개.
- 인물2 **氣滯** — 문틀(막힌 통로)에 끼어 김이 몸 둘레에 갇힘(氣機鬱滯), 찡그리며 옆구리·배를 움켜쥠(脇肋·腹部 脹痛). 2~3개.
- 인물3 **氣逆** — 고개 젖히고 입에서 김이 위로 뿜어짐(上逆), 누런 토물(嘔吐·噯氣), 어깨에서도 김이 솟음. 3개.
- 인물4 **氣陷** — 땅 구덩이에 무릎까지 빠져 듦(下陷), 불룩한 아랫배를 받쳐 듦(小腹墜脹·臟器下垂). 2개.
- (가름) 돌기둥 담: 氣病/血病 경계.
- 인물5 **血虛** — 창백·누르스름한 얼굴(面色淡白/萎黃), 떨리는 손(手足麻木), 발밑 도랑에 피가 실처럼만 흐름(脈道 不充). 3개.
- 인물6 **血瘀** — 손에 쥔 쇠못이 배에 박힘(刺痛·痛處固定), 가슴을 움켜쥠, 도랑 속 검붉은 덩어리 2개 + 밖으로 튄 작은 덩이 1(瘀塊·紫黯). 3개.
- 인물7 **血熱(迫血妄行·出血)** — 도랑 피가 불꽃 위에서 부글부글 끓어 넘쳐 밖으로 번짐(血熱→血溢脈外), 옆 항아리에 담긴 피(出血量? 뜻 불확실). 2~3개.

③ 잔결: 인물7은 얼굴이 평온해 표정 단서 없음. 핏항아리는 뜻 모름(出血 모음? 血液 저장?). 오른쪽 아래 모서리에 흰 사각 띠가 피웅덩이를 잘라 이어 붙인 흔적. 위쪽 1/6이 빈 하늘(여백 확장 흔적 가능). 氣脫·氣閉·血寒은 보이지 않음.

## 2단계 — 계통 (사전 어휘로 다시 읽기)

① 판 표제어: 1순위 **氣血失常(氣의 失常 + 血의 失常)** 90% / 2순위 **氣血辨證(氣病·血病 辨證)** 8%. 사전의 「氣 = 서린 흰 김」「血 = 붉은 것」이 왼쪽 넷 / 오른쪽 셋을 그대로 가른다. 돌기둥 담은 사전 어휘가 아니라 「氣 구역 | 血 구역」 가름표로 읽는다(「中 = 둘 사이의 한복판」으로 읽을 만한 자리는 아님).

② 인물별 (왼쪽부터)
- 인물1 **氣虛** — 몸을 감싼 김이 가늘고 옅음(「虛 = 줄어든 것」 + 氣), 창백·처진 눈(神疲乏力). 2개.
- 인물2 **氣滯**(대안 **氣閉** 35%) — 「門 = 문틀」 안에 서서 김이 몸 둘레에 갇힘: 門에 막힌 氣 = 鬱滯(문=閉 자형까지 읽으면 氣閉). 옆구리·배를 움켜쥠(脇腹 脹痛). 문틀은 열려 있고 사람이 깨어 있어(昏厥 없음) 氣滯 쪽이 더 맞음. 2개.
- 인물3 **氣逆** — 「上 = 곧게 솟음」: 입에서 김이 위로 뿜어짐, 머리 옆·어깨에서도 김이 솟음; 누런 토물 = 胃氣上逆(嘔吐·噯氣), 입 김 = 肺氣上逆(咳喘), 젖힌 머리 곁 김 = 肝氣上逆(頭痛·眩暈) 가능. 2~3개.
- 인물4 **氣陷** — 「下 = 아래로 가라앉음」: 구덩이에 무릎까지 빠짐, 불룩한 아랫배를 받쳐 듦(墜脹·臟器下垂). 2개.
- 인물5 **血虛** — 도랑(脈道) 피가 실 한 줄로 줄어듦(「虛」+「血」), 창백·누르스름한 얼굴(색은 望色 판 전담이나 사실로는 面色淡白·萎黃), 떨리는 손(手足麻木). 3개.
- 인물6 **血瘀** — 「痛 = 살에 박힌 쇠못 하나」: 배에 박힌 못 = 刺痛(한 자리 고정), 「瘀 = 몸 밖의 검붉게 굳은 덩이」: 도랑 속 덩이 2 + 밖 1(瘀塊·紫黯). 가슴을 움켜쥠(痛處 拒按). 3개.
- 인물7 **血熱(迫血妄行)** — 「熱 = 불꽃」이 핏물 위에서 타며 부글부글 끓음 = 血分有熱, 「盛 = 넘쳐 흘러나옴」: 도랑 밖으로 번진 피 = 熱盛 → 血溢脈外(出血). 2개.

③ 잔결: 인물7 곁 핏항아리 — 「會 = 담는 것 안에 담긴 것」이나 「補-b = 그릇에 가득 담긴 것(血을 채워 줌)」로 걸리지만 血熱 인물과 맞지 않아 뜻 미정(엉뚱한 자리의 血虛용 補血 소품일 가능성). 인물7 얼굴은 표정 단서 없음. 오른쪽 아래 모서리의 흰 사각 띠가 피웅덩이를 잘라 냄(이어 붙인 흔적). 위 1/6 빈 하늘(여백 확장 흔적 가능). 氣脫·血寒 자리는 없음. 사전 어휘로 1단계 해석이 거의 그대로 확인되고(痛·瘀·熱·盛·上·下·虛가 정확히 들어맞음), 인물2만 門 때문에 氣閉 가능성이 새로 열림.
