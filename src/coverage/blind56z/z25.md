# z25 판독

## 1단계 — 생판 (사전 보기 전)

**① 단원**: **宣明五氣 — 五惡**(肝惡風·心惡熱·脾惡濕) 45% / 대안 **五行 五臟配屬**(五色·五氣) 20%, **藏象 十二官**(君主·將軍·倉廩) 20%, **陰陽失調 — 戴陽(面赤如妝)** 10%.

**② 인물·소품**
- 왼쪽 녹색 비늘갑옷 무장 = **肝(將軍之官)**. 갑옷 녹색 = 靑(木). 투구의 붉은 술과 끈만 옆으로 날림 = 風 → **肝惡風**. 눈 밑이 처진 지친 얼굴 = **肝者罷極之本**. 쥔 주먹·짚신·녹색 팔토시 = 筋(肝主筋, 久行傷筋)일 수 있음.
- 가운데 홍룡포 임금 = **心(君主之官)**. 붉은 옷 = 赤(火). 양 볼의 동그란 홍조 = 面赤(心 其華在面), 손을 가슴에 얹음 = 心의 자리(胸中)·心煩. 곁의 무쇠 난로(불창 3칸)는 熱이고, 괴로운 표정과 함께 **心惡熱**을 나름.
- 오른쪽 가장자리 소년(몸 오른쪽이 잘림) = **脾**. 노란 삿갓·노란 바지 = 黃(土), 농사꾼 = 土. 맨발로 흙탕물 웅덩이를 디딤 = 濕 → **脾惡濕**. 뒤의 빗장 걸린 곳간 문 = 倉廩之官.
- 배경 침상 = 臥. 人臥血歸於肝인지 久臥傷氣인지 불명.

**관계**: 녹→적→황이 왼쪽에서 오른쪽으로 놓여 **木→火→土 相生** 순서가 됨. 무장과 임금 사이의 난로(땔감을 태움) = 木生火. 將軍과 君主는 十二官의 위계를 나름. 五惡이라면 이웃 띠에 肺惡寒·腎惡燥(흰옷·검은옷 인물)가 있을 것으로 봄.

**③ 잔결**: 난로 불창 III(3칸)의 숫자 뜻 불명. 침상이 누구 몫인지 불명(무장과 임금 사이). 왼쪽 흙벽의 금·떨어진 회벽(燥?)도 뜻 불명. 소년은 무덤덤해서 '싫어함(惡)'이 표정에 없음. 임금 볼의 동그란 연지 홍조는 面赤如妝(戴陽)으로도 읽혀 단원이 갈림. 이어 붙인 흔적은 뚜렷하지 않고, 소년만 가장자리에서 잘림.

## 2단계 — 계통 (사전 요약 읽은 뒤)

**① 단원**: **內生五邪**(病機: 風氣內動·火熱內生·濕濁內生 …) 50% / **五行 五臟配屬**(五氣) 20%, **宣明五氣 五惡** 15%, **六淫** 10%. 사전의 惡은 '해로운 것과 사람 사이에 세운 가리개'인데 이 띠에는 가리개가 없어서 五惡 읽기가 크게 약해졌다. 반대로 濕의 갈림 조건(자기 발밑에서 배어 나오면 **內濕(脾)**)이 정확히 맞아서, 「內」 계열 읽기로 옮겼다.

**② 인물·소품**
- 초록 비늘갑옷 장군 = **肝**. 갑옷 모양은 인물 표지일 뿐이다. 보통과 달라진 것은 투구 술·끈만 옆으로 흘러 날리는 것 = **風**. 임금 수염 등 주변은 날리지 않으므로 바람이 그 사람에게서만 이는 것 → **肝風內動(風氣內動)**.
- 붉은 곤룡포 임금 = **心**. 난로 문 안쪽에서 타는 불 = 熱(불꽃) + 內(문 안쪽) → **火熱內生(心火)**. 임금 + 가슴 한복판에 얹은 손 = **心煩**(사전 갈림 그대로).
- 노란 밀짚모자 농부(가장자리) = **脾**. 자기 맨발 밑에서 배어 나온 흙탕 = **內濕** → **濕濁內生(脾失健運)**. 빗방울 물결이 없으니 外濕은 아니다.
- 이웃 띠에는 內燥(밑동까지 마른 물독)과 內寒(밑에서 밴 서리)를 진 肺·腎이 올 것으로 본다.

**관계**: 肝·心·脾가 五色 순서(木→火→土)로 늘어서 내생오사를 五行 순서로 장부에 배당한다. 난로(熱)가 장군과 임금 사이에 놓여 熱極生風·風火相煽을 나를 수도 있으나 약하다. 木生火 읽기는 사전상 근거가 없다.

**③ 잔결**: 침상(臥)은 사전에 없는 사물이라 뜻 불명. 임금 볼의 동그란 홍조는 사전상 얼굴색이 望色 판 전담이므로 이 판의 글자가 아닌 군더더기다(面赤으로 덧읽힘). 난로 불창 III 3칸은 久(포갬)·中(셋 중 가운데)에 맞지 않아 무의미하다. 왼쪽 흙벽의 금은 '갈라진 땅(燥)'이 아니라 벽이라 뜻이 없다. 지친 두 얼굴(虛?)도 사전 글자가 아니다. 이어 붙인 흔적은 없다.
