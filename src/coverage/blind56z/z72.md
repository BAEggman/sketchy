# z72 판독

## 1단계 — 생판 (사전 열기 전 확정)

① 단원: **六淫** (55%) / 2순위 **五行 歸類(五色·五氣·五季)** (30%) / 3순위 病因 총론.

② 인물 (왼→오)
- 누런 저고리·바지, 밀짚모자, 맨발로 진흙 웅덩이에 선 농부 소년 = **濕**. 황색·농사 = 土·脾·長夏(濕易困脾). 젖은 땅에 발만 잠김 = 濕性趨下(傷於濕者 下先受之). 곁 물통의 탁한 누런 액체 = 濕性重濁(小便渾濁·大便溏泄 등 배설물 탁함).
- 흰 도포·흑립 선비 = **燥**. 흰옷 = 金·肺·秋(燥易傷肺). 손에 든 바싹 마르고 쭈글쭈글 갈라진 천 = 燥性乾澁(皮膚·口鼻乾燥). 발치에 금 가서 쓰러진 빈 항아리 + 떨어진 뚜껑 = 津液이 말라 그릇이 갈라짐(燥勝則乾, 燥易傷津).
- 성에·고드름이 엉긴 검은 잠수복·고글 차림 사내 = **寒**. 검정·물질 = 水·腎·冬. 성에·고드름 = 寒性凝滯, 몸을 꽉 조이는 옷·움츠린 자세 = 寒性收引, 허리·무릎 두 곳을 짚음 = 凝滯則痛(腰膝冷痛·痛痹), 陰邪傷陽.
- 선비와 잠수부 사이 물통의 갈색 덩어리 = 燥 쪽이면 乾結된 대변(燥結), 寒 쪽이면 凝結.

관계: 黃→白→黑 = 土→金→水 상생 순 = 長夏→秋→冬 계절 순(六淫을 계절 배속 순으로 세움). 濕(젖은 발)↔燥(마른 천) 대비, 왼쪽 물통(묽은 액체)↔오른쪽 물통(굳은 덩어리) = 濕 묽음 vs 燥·寒 굳음.

③ 잔결: 고글(잠수 표지 외 뜻 불명), 갈색 덩어리 물통의 귀속(燥/寒) 모호, 항아리 뚜껑 분리의 뜻 불명, 선비의 천이 왜 노란색인지. 기와 담장 배경은 연속, 뚜렷한 이음 흔적 없음.

## 2단계 — 사전(blind6_사전요약) 적용

① 단원: **內生五邪** (65%) / 2순위 **五行 歸類(五臟-五氣)** (15%) / 3순위 六淫(臟 손상 배속) (10%). 근거: 세 기후 표지가 모두 사전의 「內」 갈림형(자기 발밑 진창=內濕, 마른 물독=內燥, 몸에서 밴 서리=內寒)으로 그려졌다. 宣明五氣 所惡(肺惡寒·腎惡燥)와는 배속이 어긋나고 「惡=가리개」도 없어 탈락.

② 인물 — 사람은 기후가 아니라 臟(오행왕국)이다. 옷·모자 모양은 다시 읽지 않는다.
- 노란 밀짚모자 농부 = **脾** → **內濕(濕濁內生)**: 진창이 길이 아니라 자기 발밑에서 배어 남(內濕=脾). 곁의 손잡이 나무 뒷간통(大便)에 묽은 누런 물 = 濕 → 大便溏泄.
- 흰 도포·검은 갓 재상 = **肺** → **內燥(津傷化燥)**: 손에 쥔 마른 잎 = 燥. 발치의 금 가 쓰러진 빈 물독 = 밑동까지 마른 물독(內燥)이자 깨진 그릇(傷) — 津을 담던 독이 깨져 마름 = 津傷化燥. 곁 뒷간통의 굳은 갈색 덩이 = 大便乾結(燥 → 肺·大腸).
- 검은 잠수복·후드·고글 잠수부 = **腎** → **內寒(寒從中生)**: 눈송이가 아니라 몸 표면에서 배어 엉긴 서리·고드름 = 內寒(腎陽虛). 허리·무릎을 짚음 = 腰膝(腎之府) 冷痛·酸軟.

관계: 脾→肺→腎 = 土生金·金生水 상생 순으로 臟을 세우고 각 臟에 그 臟이 낳는 內邪를 붙임(이웃 띠에 肝-內風·心-內火 추정). 두 뒷간통이 나란히 濕=溏(묽음) ↔ 燥=結(굳음) 대비.

③ 잔결: 서리가 「밑에서 밴」 것인지 「안쪽 성에(裏寒)」인지 그림만으로 가르기 어렵다. 허리·무릎 짚는 손짓은 사전에 없고 痛(쇠못)도 없음 — 腰膝 위치까지만 읽힘. 물독 뚜껑 분리·파편은 傷/燥 중복 기호. 寒從中生의 脾陽 몫은 그려지지 않음. 이음 흔적 없음.
