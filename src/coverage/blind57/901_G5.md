# 901 판독 (G5)

## 1단계 — 생판 (사전 어휘 없이)

**① 판 표제어**
- 1순위 **五行 歸類(五臟 配屬)** — 木火土金水 다섯 사람을 靑·赤·黃·白·黑 옷으로 칠하고, 각자에 五氣(風·熱·濕·燥·寒)를 하나씩 붙였다 (70%)
- 2순위 **宣明五氣(五惡·五勞)** (15%) — 다만 그림은 金=燥, 水=寒으로 그려서 五惡의 「肺惡寒·腎惡燥」 뒤바뀜과 맞지 않는다. 그래서 2순위로 낮춘다.
- 인물을 왼쪽부터 늘어놓은 차례가 木→火→土→金→水 **相生 순서**이고, 土에 해당하는 농부가 가운데 대문 앞(中央)에 선다.

**② 인물별 (왼쪽부터)**
1. 녹색 갑옷 장수 → **肝(木)** — 6개: 靑色 / 將軍之官(갑옷·투구) / 투구의 붉은 술이 바람에 날림 = 風 / 짚신 = 筋·久行傷筋(약함) / 쥔 주먹 = 怒(약함) / 지친 얼굴 + 뒤의 침상 = 罷極之本 또는 「臥則血歸於肝(肝藏血)」
2. 붉은 곤룡포 임금 → **心(火)** — 5개: 赤色 / 君主之官 / 가슴에 얹은 손 = 心의 자리·神明 / 붉은 뺨 = 其華在面·面赤 / 붉은 창이 셋 달린 무쇠 난로 = 熱(暑)
3. 밀짚모자 농부 → **脾(土)** — 5개: 黃色 / 가운데 대문 앞 = 土居中央 / 농사 = 倉廩之官·稼穡 / 맨발로 흙탕물을 밟음 = 濕 / 노란 액체가 든 나무통 = 甘(꿀물?) 또는 涎(약함)
4. 흰 도포 선비 → **肺(金)** — 4개: 白色 / 相傅之官(선비) / 바싹 마르고 구겨진 누런 천 = 燥 / 금 가고 뚫린 항아리와 따로 떨어진 뚜껑 = 燥裂, 華蓋, 金破不鳴 가운데 하나(뜻 불확정)
5. 서리 앉은 검은 잠수복 사람 → **腎(水)** — 5개: 黑色 / 물속 사람 = 水 / 서리·고드름 = 寒 / 허리에 짚은 손 = 腰者腎之府 / 무릎에 짚은 손 = 腎主骨(膝). 고글(瞳子=水輪?)과 오른쪽 통의 갈색 덩어리(밤=栗? 메주=豆?)는 뜻이 정해지지 않는다.

**③ 잔결**
- 갈색 덩어리가 담긴 나무통이 선비와 잠수부 사이에 있다. 누구의 소품인지, 무엇을 뜻하는지 모르겠다.
- 노란 액체 통이 농부와 선비 사이에 있다. 濕의 물인지, 甘인지, 涎인지 정할 수 없다.
- 깨진 항아리와 뚜껑이 金의 소품인지 水(封藏 실패)의 소품인지 갈린다.
- 장수와 임금 얼굴이 둘 다 시무룩해서 五志(怒·喜)가 읽히지 않는다.
- 프레임 잘림이나 이어 붙인 흔적은 눈에 띄지 않는다. 다만 가운데 대문 좌우의 담과 지붕이 대칭으로 반복되어 합성한 것처럼 보이는 정도다.

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **內生五邪(風·火·濕·燥·寒이 몸 안에서 생김)** (80%)
  - 무대 전체가 문을 닫은 담장 안마당이다(內 = 담 안쪽·문 안쪽).
  - 사전의 갈림 세 개가 그대로 맞아떨어진다. 자기 발밑 진창 = 內濕, 바닥까지 마른 물독 = 內燥, 몸에서 배어 나온 서리 = 內寒.
  - 1단계에서 「五氣 배속이 五惡과 어긋난다」고 본 것은 사실 金=燥, 水=寒이라는 內生五邪의 臟 배속이었다. 그래서 1단계 2순위(宣明五氣)는 버린다.
- 2순위 **五行 歸類 — 五臟과 天之五氣(風熱濕燥寒)의 通應** (15%)
- 옷의 모양(갑옷·곤룡포·밀짚모자·도포·잠수복)은 인물을 가리킬 뿐이다. 그래서 1단계에서 읽었던 將軍之官·君主之官·倉廩之官·相傅之官과 고글은 철회한다.
- 다섯 사람을 늘어놓은 차례는 木火土金水다.

**② 인물별 (왼쪽부터)**
1. 장군 = **肝 → 內風(風氣內動)** — 3개: 靑 / 투구 술이 옆으로 흘러 날림 = 風 / 담 안 = 內. 처진 한쪽 눈과 쥔 두 주먹은 口眼喎斜·兩手握固(中風 閉證)로 볼 여지가 있지만 사전 밖이라 약하다.
2. 임금 = **心 → 內火(火熱內生)** — 3개: 赤 / 닫힌 무쇠 난로 속에서 타는 불 = 안의 熱 / 가슴 한복판에 얹은 손 = 心煩(사전의 「임금 + 가슴 한복판」). 붉은 뺨 = 面赤은 사전상 望色 판이 맡는 것이라 보류한다.
3. 농부 = **脾 → 內濕(濕濁內生)** — 2개: 黃 / 자기 발밑에서 번진 진창 = 內濕. 노란 탁수가 그득한 통은 濕濁으로 보이지만 약하다.
4. 재상 = **肺 → 內燥(津傷化燥)** — 3개: 白 / 바닥까지 비어 금 가고 깨진 물독 = 內燥이면서 傷(깨져 못 쓰게 됨) → 「津이 傷하여 燥로 化함」 / 마른 잎처럼 바스러진 마른 천 = 燥(겹침).
5. 잠수부 = **腎 → 內寒(寒從中生)** — 2개: 黑 / 옷 위로 배어 나온 서리와 고드름 = 內寒(눈송이가 아니므로 外寒이 아니다). 허리와 무릎을 짚은 손 = 腰膝冷痛(腎陽虛)으로 읽히지만 사전 밖이다.

**③ 잔결**
- 갈색 덩어리가 담긴 통(재상과 잠수부 사이): 어느 글자에도 맞지 않는다. 보통 그릇이면 補-b(채우는 것)일 텐데 담긴 것이 무엇인지 모른다.
- 마당 한가운데 놓인 침상: 사전에 없다. 血虛生風인지 臥인지 정할 수 없다.
- 물독에서 떨어진 뚜껑과 노란 탁수 통은 뜻이 약하다.
- 노란 탁수 통 밑동이 농부의 진창 가장자리에 걸쳐 있다. 그래서 진창이 「자기 발밑에서」 나온 것인지 「통에서 쏟아진 것」인지 살짝 흐려진다.
- 잘림이나 이어 붙인 흔적은 없다.
