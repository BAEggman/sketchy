# 901 판독 (H5)

## 1단계 — 생판 (사전요약 열기 전)

**① 판 표제어**
- 1순위 **五臟 五行配屬 — 五色·五氣(風·熱·濕·燥·寒)** (55%)
- 2순위 **宣明五氣 「五臟所惡」(心惡熱·肝惡風·脾惡濕…)** (25%) / 3순위 **靈蘭秘典 十二官(將軍·君主·倉廩·相傅·作強)** (15%)
- 근거: 다섯 인물의 옷색이 왼쪽부터 靑·赤·黃·白·黑로 정렬, 각자 곁에 기후 하나(바람·난로·진창·마른것·서리).
  단, 肺=燥·腎=寒 배치는 宣明五氣 원문(肺惡寒·腎惡燥)과 어긋나고 陰陽應象(在天爲燥/寒)과 맞음 → 1순위를 五行配屬 쪽으로.

**② 인물별 (왼→오)**
1. 녹색 갑옷 무장 → **肝** : 靑(木) / 장수=將軍之官 / 투구 붉은 술이 바람에 날림=**風** / 처진 눈=目? / 짚신·행전=久行傷筋? / 뒤 침상=人臥血歸於肝(肝藏血)? — 확실 3, 추정 3
2. 붉은 곤룡포 임금 → **心** : 赤(火) / 임금=君主之官 / 숯난로(창살 3칸 벌겋게)=**熱** / 가슴에 손=心位·心悸 / 붉은 뺨=其華在面·面赤 / 용보 3곳(가슴·양어깨) — 확실 3, 추정 2
3. 밀짚모자 황색옷 소년 → **脾** : 黃(土) / 맨발로 진흙 물웅덩이=**濕** / 농부=倉廩之官 / 노란 액체 통=涎? 혹은 甘(꿀)·稷粥? / 가운데 자리·뒤 대문=中央土 — 확실 2, 추정 3
4. 흰 도포 갓 선비 → **肺** : 白(金) / 선비(관리)=相傅之官 / 손에 바싹 마른 누런 천=**燥**(또는 涕 손수건) / 금 가고 구멍 난 항아리=嬌臟 / 떨어진 뚜껑=華蓋 — 확실 2, 추정 3
5. 서리 덮인 검은 잠수복 → **腎** : 黑(水) / 성에·고드름=**寒** / 손을 허리에=腰者腎之府 / 무릎 짚음=腎主骨 / 잠수부=水 / 옆 갈색 덩이 통=栗(腎之果)? — 확실 3, 추정 2

**③ 잔결**
- 뜻 모를 소품: 노란 액체 통(소년 옆), 갈색 덩이 통(선비·잠수부 사이 — 소속 불명), 침상(무장·임금 사이 — 소속 불명).
- 어색함: 肺·腎에 燥·寒 배치가 宣明五氣 五惡과 반대.
- 프레임 잘림·이어붙인 흔적: 뚜렷한 것 없음. 배경 좌우 담장 대칭은 자연스러움.

## 2단계 — 계통 (사전요약 적용 후)

**① 판 표제어**
- 1순위 **內生五邪(風·寒·濕·燥·火 內生)** (70%)
- 2순위 **五臟 五行配屬 — 五色·五氣** (15%) / 3순위 宣明五氣 五臟所惡 (5%)
- 근거: 무대 전체가 담·닫힌 대문 안쪽 = **內**. 사전 갈림이 셋이나 「內」로 떨어짐 — 자기 발밑 진창=內濕(脾), 밑동까지 마른 물독=內燥, 몸에 밴 서리=內寒. 여기에 닫힌 난로 속 불(內火)과 옆으로 날리는 술(內風)이 더해져 다섯 邪가 다섯 臟에 하나씩 붙음. 1단계에서 걸렸던 「肺=燥·腎=寒이 宣明五氣와 반대」가 內生五邪로는 그대로 맞아서 풀림. 옷 모양(갑옷·곤룡포·갓)은 인물 지시일 뿐이라 1단계의 十二官 읽기는 철회.

**② 인물별 (왼→오)**
1. 초록 갑옷 장군=肝 → **風氣內動(肝風內動)** : 옆으로 흘러 날리는 술=風 / 그 술이 붉음=血? → 血虛生風(또는 熱極生風) 하위형 추정 — 확정 2, 추정 1
2. 곤룡포 임금=心 → **火熱內生** : 닫힌 무쇠난로 속 불꽃=熱·火(안쪽) / 가슴 한복판에 손=心煩(사전: 임금+가슴 한복판) / 광대만 붉음=顴紅 → 陰虛火旺? (얼굴색은 望色 판 전담이라 약하게) — 확정 3, 추정 1
3. 밀짚모자 농부=脾 → **濕濁內生** : 자기 발밑에서 배어 나온 진창=內濕(脾) / 누렇고 탁한 물이 가득한 통=濁? (補-b로 읽으면 「채워 줌」이라 갈림 미결) / 다섯 중 한복판=中? — 확정 2, 추정 2
4. 흰 도포 재상=肺 → **津傷化燥** : 밑동까지 마른 물독=內燥 / 그 독이 깨져 못 씀=傷 → 「津傷」 / 손에 쥔 바싹 마른 누런 잎(천)=燥 — 확정 3
5. 잠수부=腎 → **寒從中生(內寒)** : 겉에 눈송이 아닌, 몸에서 밴 서리·고드름=內寒 / 허리·무릎을 짚음=腰膝(사전 밖, 腎陽虛 腰膝冷 정도로) — 확정 2, 추정 1

**③ 잔결**
- 사전에 없는 소품: 肝·心 사이 침상(臥? 肝藏血?), 肺·腎 사이 갈색 덩이가 담긴 나무통(補-b라면 무엇을 채우는지 불명, 地黃의 검붉은 색도 아님), 떨어진 항아리 뚜껑.
- 노란 물통이 補-b(채움)인지 濁(탁함)인지 갈림이 그림만으로 안 갈림.
- 프레임 잘림·이어 붙인 흔적은 여전히 없음.
- 판정: 사전 어휘로 훨씬 잘 풀린다 — 1단계의 「五行配屬」은 겉(옷색)만 읽은 것이었고, 소품의 갈림(內-)이 실제 표제를 진다.
