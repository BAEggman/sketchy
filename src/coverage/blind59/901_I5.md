# 901 판독 — I5

## 1단계 — 생판 (사전 열기 전 확정)

**① 판 표제어**
- 1순위: **病機의 眞假 — 虛實眞假 + 寒熱眞假(陰陽格拒)** (45%)
- 2순위: **陰陽失調(陰陽格拒 중심)** (25%) / 3순위 邪正盛衰(虛實病機) 15%
- 근거: 초가 한 채를 기둥으로 4칸 나눔. 오른쪽 두 칸은 "손에 든 것(속) ↔ 허공의 것(겉)"이 정반대 — 眞假 구도가 뚜렷. 왼쪽 두 칸은 거의 같은 인물·선반·빗자루에 가시덤불 크기와 그릇 위치만 다른 짝 → 虛實 쪽 짝으로 읽음.

**② 칸별(왼→오)**
- 칸1: **眞實假虛(大實有羸狀)** — 4개. ⓐ 사람을 반쯤 가리는 큰 검은 가시덤불 = 邪氣盛(實), 집 밖 바위까지 뻗음 ⓑ 선반 위칸 2개가 비어 겉보기 虛 ⓒ 김 나는 그릇 1(가운데)·빈 그릇 1(아래) = 正氣는 아직 남음 ⓓ 빗자루 = 瀉法(쓸어냄).
- 칸2: **眞虛假實(至虛有盛候)** — 3개. ⓐ 바닥에 앙상한 작은 가시가지 = 邪 미약 ⓑ 맨 위 김 나는 가득 찬 그릇 = 겉의 盛候 ⓒ 그 아래 빈 그릇 = 속은 虛. (빗자루는 칸1과 같아 뜻 미상 — 假實에 속아 瀉하면 안 된다는 경고?)
- 칸3: **眞寒假熱(陰盛格陽)** — 3개. ⓐ 가슴에 안은 그릇 가득 흰 눈 = 속 眞寒 ⓑ 몸 밖 허공의 불꽃 = 겉으로 밀려난 假熱(浮陽) ⓒ 탁자 위 보자기 덮은 그릇 = 眞象이 가려짐(假象이 덮음).
- 칸4: **眞熱假寒(陽盛格陰)** — 4개. ⓐ 그릇 가득 붉은 숯 ⓑ 가슴·배의 붉은 빛 = 胸腹 灼熱(眞熱) ⓒ 머리 위 눈송이 = 겉 假寒(四肢厥冷) ⓓ 빈 그릇에서 넘쳐 녹아 바닥 밖까지 흘러내린 눈 = 陰이 밖으로 밀려남(格陰).
- 배경: 집 뒤 거대한 회색 바위산(뜻 미상), 지붕 하나 = 한 단원.

**③ 잔결**
- 칸1 선반 맨 위칸에 푸르스름한 문질린 얼룩(지운 흔적 의심).
- 칸3|칸4 사이 기둥만 굵고 둥글며 주춧돌에 깨진 글자 같은 낙서.
- 칸1·칸2 인물이 자세·옷까지 복제에 가까움.
- 바위산 꼭대기가 프레임 위에서 잘림. 칸1 덤불 아래 마른 풀이 마루 밑으로 비죽.

## 2단계 — 계통 (사전요약 어휘로 다시 읽기)

결정적 열쇠: 瀉 = 짚 빗자루, 補 = 찰랑 찬 따뜻한 국, 官 = 3층 선반장 가운데 층(위=母·아래=子), 補-b/瀉-b = 가득 찬 그릇/빈 그릇+쏟음, 병표지 = 곁에 크게 뜬 불꽃·눈송이, 그리고 "舍岩의 格(그릇·선반)" 언급. 1단계의 眞假 독해는 버린다 — 이 어휘로 훨씬 깔끔하게 풀린다.

**① 판 표제어**
- 1순위: **舍岩鍼法 四格(正格·勝格·寒格·熱格)** (85%)
- 2순위: **補瀉 원칙(虛則補其母·實則瀉其子 + 官經 조절)** (8%)

**② 칸별(왼→오)** — 인물 옷이 五行 인물이 아닌 평복 → 특정 經이 아닌 일반론.
- 칸1: **勝格(補官瀉子, 實證)** — 4개. ⓐ 빽빽한 큰 가시덤불 = 實 ⓑ 가운데 층(官)의 김 나는 국 = 補官 ⓒ 아래 층(子) 빈 그릇 + 짚 빗자루 = 瀉子 ⓓ 위 층(母)은 비어 손대지 않음.
- 칸2: **正格(補母瀉官, 虛證)** — 4개. ⓐ 덤불의 1/3로 줄어든 앙상한 가지 = 虛 ⓑ 위 층(母) 김 나는 국 = 補母 ⓒ 가운데 층(官) 빈 그릇 + 빗자루 = 瀉官 ⓓ 아래 층(子) 비움.
- 칸3: **熱格(補水瀉火)** — 3개. ⓐ 곁에 뜬 불꽃 = 병표지 熱證 ⓑ 산 불과 맞댄 그릇 가득 흰 눈·얼음 = 陰(水)을 채움 → 補水 ⓒ 보자기 덮은 그릇 = 瀉火 의도로 추정(사전 문법 밖, 약함).
- 칸4: **寒格(補火瀉水)** — 4개. ⓐ 머리 곁 눈송이 = 병표지 寒證 ⓑ 그릇 가득 붉은 숯 = 補火(補-b) ⓒ 가슴의 붉은 온기 = 火가 채워짐 ⓓ 빈 그릇 + 넘쳐 녹아 흘러내린 눈 = 瀉-b → 瀉水.

**③ 잔결**
- 칸3 보자기 그릇은 瀉-b(빈 그릇+쏟음) 꼴이 아니라 瀉火가 사전대로 안 읽힘 — 칸4와 짝이 깨짐.
- 칸4 눈송이는 갈림상 "外寒"으로 읽힐 수 있음(병표지 규칙으로 寒證이 이기지만 헷갈림).
- 칸1 위 층(母)의 푸르스름한 지운 얼룩 — 母 그릇을 지운 흔적으로 보임.
- 칸3|칸4 기둥만 굵고 주춧돌에 깨진 글자 낙서. 배경 바위산은 艮(배경 산)으로 오독될 여지.
- 칸 순서가 勝·正·熱·寒으로 교과서 순(正·勝·寒·熱)과 다름. 가시덤불 자체는 사전에 없는 사물(크기 대비로만 實/虛).
