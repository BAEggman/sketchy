# 901 판독 (J5)

## 1단계 — 생판 (사전요약 열기 전 확정)

**① 판 표제어**
- 1순위 **虛實眞假·寒熱眞假 (假象 病機 — 大實有羸狀/至虛有盛候/眞寒假熱/眞熱假寒)** 50%
- 2순위 **陰陽失調(陰陽格拒) + 邪正盛衰(虛實) 혼합판** 25%
- 근거: 초가 한 채를 기둥으로 4칸 나눔. 왼쪽 두 칸(정면 인물·선반·빗자루)은 짝, 오른쪽 두 칸(옆얼굴로 마주 봄)은 짝. 오른쪽 짝은 「손에 든 것(속) ↔ 앞에 떠 있는 것(겉)」이 정반대.

**② 인물별 (왼→오)**
1. 인물1 **眞實假虛(大實有羸狀)** — 크고 무성한 검은 가시덤불(邪 盛 = 실) 1, 3단 선반: 맨 위 칸 빔(겉은 허해 보임)·가운데 김 나는 가득 찬 그릇(속은 실)·아래 빈 그릇 → 그릇 2·빈칸 1, 빗자루 1(祛邪·瀉), 바깥 큰 회색 바위(실한 덩어리?). 사실 4개.
2. 인물2 **眞虛假實(至虛有盛候)** — 바닥 틈에서 난 작고 마른 가지 1(邪는 미약), 선반: 위 칸 김 나는 가득 찬 그릇(겉의 盛候)·가운데 빈 그릇(속은 허)·아래 칸 빔, 빗자루 1(여기선 瀉 금기?). 인물1과 위아래 배치가 거울처럼 뒤집힘. 사실 3개.
3. 인물3 **眞寒假熱(陰盛格陽)** — 손(몸 중심)에 흰 눈/얼음 수북한 그릇 = 속의 眞寒, 얼굴 앞에 뜬 불꽃 = 겉의 假熱, 탁자 위 삼베로 덮은 그릇 = 속에 갇힌(格拒된) 본질·감춰진 진상. 사실 3개.
4. 인물4 **眞熱假寒(陽盛格陰)** — 손에 붉은 숯불 그릇 + 가슴의 붉은 광채 = 裏의 眞熱, 얼굴 앞 눈송이 = 겉의 假寒, 탁자 위 빈 그릇과 녹아 탁자 끝·마루 끝·처마 밖으로 흘러내리는 눈 = 四肢(말단) 厥冷 / 熱深厥深, 녹아 없어질 거짓 한기. 사실 4개.

**③ 잔결**
- 인물1 선반 맨 위 칸에 가로로 번진 흐릿한 얼룩 — 소품을 지운(인페인팅) 흔적.
- 큰 바위 꼭대기가 화면 위에서 잘림. 바위의 뜻 불명(實? 배경?).
- 3칸·4칸 사이 굵은 기둥 주춧돌에 알아볼 수 없는 가짜 글씨(«lar … ŋd»).
- 1·2칸 빗자루와 빈/찬 그릇이 거의 같아 두 칸 구별이 가시덤불 크기와 그릇 높이 순서뿐 — 약한 대비. 3칸 흰 더미는 소금·쌀로도 읽힐 수 있음.

## 2단계 — 계통 (사전요약 어휘로 다시 읽기)

결론: 어휘로 훨씬 잘 풀린다. 1단계의 「眞假」는 틀렸다고 판정.

**① 판 표제어**
- 1순위 **舍岩鍼法 四格(正格·勝格·寒格·熱格)** 85% — 초가(舍) 뒤 거대한 바위(岩) = 舍岩. 사전의 「舍岩의 格(그릇·선반)」, 官 = 3층 선반장 가운데 층(위=母·아래=子), 補 = 김 나는 찬 국, 瀉 = 짚 빗자루, 瀉-b = 빈 그릇+넘친 내용물, 병표지 = 곁에 크게 뜬 불꽃·눈송이가 모두 맞물린다. 4칸 = 4格.
- 2순위 **補母瀉子·補瀉 원칙(虛則補其母 實則瀉其子)** 8%

**② 인물별 (왼→오)**
1. 인물1 **勝格(實證)** — 빽빽하게 찬 가시덤불 = 實; 가운데 층(官)의 김 나는 국 = 補官; 아래층(子)의 빈 그릇 + 그 앞 빗자루 = 瀉子; 위층(母)은 비움. 사실 3개.
2. 인물2 **正格(虛證)** — 1칸 덤불이 1/3로 줄어든 마른 가지 = 虛; 위층(母)의 김 나는 국 = 補母; 가운데 층(官)의 빈 그릇 + 그 층에 걸친 빗자루 = 瀉官; 아래층(子)은 비움. 사실 3개.
3. 인물3 **寒格(熱證에 補水瀉火)** — 곁에 뜬 불꽃 = 병표지 熱證; 손에 든 얼음·눈 가득한 그릇 = 補-b로 水(陰)를 채움(살아 있는 불과 맞대어 있으니 陰); 탁자 위 삼베 덮은 그릇 = 瀉火로 추정(약함). 사실 2~3개.
4. 인물4 **熱格(寒證에 補火瀉水)** — 곁의 눈송이 = 병표지 寒證; 손의 숯불 그릇(가슴까지 붉은 온기) = 補火(陽=불); 탁자 위 텅 빈 그릇 + 넘쳐 마루 밖으로 흘러내린 눈 녹은 물 = 瀉-b로 水를 덜어냄. 사실 3개.
- 3·4칸은 기둥을 사이에 두고 마주 보는 寒/熱 한 쌍, 1·2칸은 정면을 보는 虛/實 한 쌍. (교재에 따라 寒格·熱格 이름 방향이 반대인 경우가 있어 「補水瀉火 / 補火瀉水」 기전으로 고정해 읽음.)

**③ 잔결**
- 3칸의 瀉火가 瀉-b(빈 그릇+넘침) 꼴이 아니라 삼베 덮은 그릇이라 뜻 불명 — 4칸과 비대칭.
- 1·2칸은 빈 그릇과 빗자루가 瀉를 이중으로 나르고, 3·4칸엔 빗자루가 없음 — 문법 혼용.
- 1칸 위층(母) 칸에 지운 자국 같은 가로 얼룩(이어 붙인/인페인팅 흔적).
- 바위 꼭대기 프레임 잘림, 주춧돌의 가짜 글씨, 4칸 가슴의 붉은 빛이 血로 오독될 여지. 인물이 모두 같은 옷이라 어느 經(臟)의 格인지는 지정되지 않음(통합판이라 의도적일 것).
