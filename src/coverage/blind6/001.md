# blind6 / 001 판독 기록

## 1단계 — 생판 (사전 없이, 그림만)

### ① 소품 전수와 나르는 사실
- 무대: 연녹색 상자방(벽 3면·바닥), 가구 없음. 화면 전체가 청록 톤 → 靑=木=肝=春.
- 인물 1명: 초록 비늘갑옷(어린갑)·초록 투구(꼭대기 침 1, 테 리벳 5, 돔 이음선 2)·목가리개 천·콧수염+턱수염의 장군 → 肝者將軍之官. 갑(甲)=甲乙木으로 겹쳐 읽힘.
- 눈: 크게 뜨고 또렷, 흰자·하이라이트 있음 → 肝開竅於目.
- 오른팔(그림 왼쪽) 늘어뜨림: 회색 소매 걷어 올림, 팔뚝에 Y자로 갈라지는 갈색 힘줄 3~4가닥 도드라짐, 손등에도 힘줄 3줄 → 肝主筋(혈맥으로도 읽힘).
- 왼손(그림 오른쪽) 어깨 높이로 들어 손가락 5개 펼침, 손톱 5개 검붉음. 오른손 손톱 5개도 검붉음(합계 10). 발톱은 무색 → 其華在爪, 爪爲筋之餘. 손 크기 = 얼굴 폭의 약 1배(과장 없음).
- 창: 오른쪽 위, 여닫이 한 짝(3칸)이 밖으로 열림. 창밖 나무: 잎 거의 없는 가지에 연두 새잎 약 20장 안팎 → 초봄·木의 生發·肝通於春氣. 열린 창 = 疏泄·條達.
- 하의: 회색 바지·회색 각반·새끼줄 짚신.

### ② 표제어
- 1순위 **肝(간)의 藏象 총론 — 將軍之官·主筋·其華在爪·開竅於目·色蒼·通於春氣** … 80%
- 2순위 **五行 木(목) 계통표(東方·春·靑·肝·筋·目·爪)** … 12% (風·酸·怒가 없어 약함)

### ③ 뜻 모를 소품·어색·잘림
- 손톱 검붉은 색: 홍윤(정상)인지 자색(병색)인지 불명.
- 든 손: 엄지가 바깥(손바닥 방향)인데 손톱·손등 힘줄이 보임 — 해부학적 모순(손톱 노출용 작화로 보임).
- 수염·회색 바지·각반·짚신·투구 리벳 5개·꼭대기 침: 의미 불명(의상?).
- 새잎 약 20장: 개수에 뜻이 있는지 불명.
- 프레임 잘림 없음(전신·창 온전).

## 2단계 — 계통 (blind6_사전요약 적용 후)

### ① 사전 어휘로 재판독
- 초록 비늘갑옷 장군 = **肝** (등재 기호 그대로).
- 걷어올린 맨팔뚝(=充) 위에 도드라진 갈색 힘줄 다발(=筋) → **其充在筋**. 1단계의 '主筋'이 '充'으로 정밀화됨.
- 손톱(=爪) 10개에 붉은 색(=血)·광택(=華) → **其華在爪** (붉음은 肝藏血이 爪를 기른다는 뜻으로 겹침).
- 온통 초록(갑옷·투구·벽) → **其色蒼**.
- 열린 창으로 안과 밖이 한 덩어리로 이어짐(=通) + 창밖 새잎 돋는 나무(=春) → **通於春氣**. 1단계의 '열린 창=疏泄'보다 이 풀이가 정확.
- 크게 뜬 눈(=目) → 開竅於目 보조 가능(조문 밖).
→ 네 구절이 素問 六節藏象論 肝 조문 「其華在爪, 其充在筋, 其色蒼, 通於春氣」와 정확히 맞물림. 사전에 '充=걷어올린 맨팔뚝 위에 더해진 것'이 따로 등재된 것 자체가 이 책이 六節藏象論의 「其充在X」 정식을 쓴다는 증거. 1단계보다 이 어휘로 더 잘 풀림.

### ② 표제어
- 1순위 **肝 — 素問 六節藏象論 「其華在爪·其充在筋·其色蒼·通於春氣」** … 88%
- 2순위 **肝 藏象 총론(陰陽應象大論 계열: 生筋·竅目·色蒼)** … 10%

### ③ 잔결
- 미표시 구절: 罷極之本·魂之居·以生血氣(氣=흰 김 없음)·味酸(매실 없음)·陽中之少陽(해 없음) — 조문의 절반만 그린 판인지, 후속 판이 있는지 불명.
- 손톱 검붉음: 華(광택) vs 血(붉음) 이중 판독.
- 눈: 六節藏象論에는 目이 없어 얼굴 기본형인지 開竅於目인지 불명.
- 수염·회색 하의·짚신·투구 리벳 5·침: 사전에 없음, 의상으로 처리.
- 손 방향 모순, 새잎 약 20장의 개수 의미 불명. 잘림 없음.
