# blind6/002 판독 기록

## 1단계 — 생판 (사전 없이 그림만)

### ① 소품 전수와 나르는 사실
1. **이정표(왼끝)** — 빈 화살판 7개(우3·좌4), 글자 없음. 「사방으로 반포·유통」 정도로 읽힘. 7이라는 수는 의미 미상.
2. **단 위의 푸른 관복 스승 + 죽간 두루마리** — 아이 **6명**(앞줄3·뒷줄3, 회백색 소복)에게 책을 펼쳐 읽어 줌 → 「관(官)이 펴낸 책을 널리 가르침/반포」. 국가 편찬 본초(新修本草 頒行) 또는 太醫署(의학 교육) 후보.
3. **버드나무 + 거대 둥지 + 알 6개**(줄무늬·점박이·청록무늬 등 제각각) + 둥지에 기댄 상투 선비 — 둥지 = 巢, 갖가지 무늬 알 = 「諸病」의 근원(源) → **巢元方 『諸病源候論』**. 6은 「大業 6년(610) 편찬」 가능성만 있고 불확실.
4. **나무 꼭대기의 민머리 승려 + 흰 천 5장**(좌2·아래1·우2) 널기, 손에 천 한 장 — 버드나무(楊) 위(上)의 착한 승려(善) + 흰 무명(素) → **楊上善 『黃帝內經太素』**. 5장의 수는 미상.
5. **소년 + 보물상자 2개**(닫힌 것 1, 날개 달려 열린 금화 상자 1, 바닥 금화 3~4닢) — 孫(손자=아이) + 千金(금화) + 翼(날개) → **孫思邈 『備急千金要方』·『千金翼方』**. 「人命至重 有貴千金」.
6. **성루 위 왕 + 횃불 + 죽간** — 王 + 燾(灬 불) + 臺(누대) → **王燾 『外臺秘要』**. 뒤의 황금 기와 궁궐 = 唐 황실(弘文館 서고에서 편찬).
7. **얼음덩이 3개 책상에 앉아 붓으로 죽간에 쓰는 왕 + 두루마리 9~10권 + 빈 팻말 3개** — 王 + 冰 → **王冰 『素問』 次注**(붓 = 注, 팻말 = 주석 표찰). 두루마리 뭉치는 24卷·81篇 재편 정도로 읽힘. 3·9라는 수는 확정 못 함.
8. **홍예 돌다리 1 + 운하 물길** — 隋의 大運河·趙州橋(李春) = 「隋」 시대 표지.
9. **홍문 패루(붉은 문 열림) + 성벽** — 관청·황실 경계(門·城).
10. **A자 입간판 + 도기 그림 3점**(항아리·단지·사발) — 陶/甄(질그릇) + 圖 → **甄權 『明堂人形圖』** 또는 陶弘景 『本草經集注』(新修本草의 저본) 후보.
11. 기와집·소나무 등은 배경.
- 크기 대비: 둥지가 사람 머리의 ≈4배, 알 하나가 사람 머리 ≈1배, 얼음 책상 = 왕 키의 ≈1.2배.

### ② 표제어
- **1순위: 隋唐 의학사(수·당 의가와 저작 — 巢元方·楊上善·孫思邈·王燾·王冰·新修本草)** — 70%
- **2순위: 扁鵲(둥지=鵲, 알 6개=六不治)** — 10% (王+冰, 王+燾+臺, 孫+千金+翼 세 겹 말장난이 정확히 맞아 1순위가 훨씬 강함)
- 기타: 藏象 腎(水火之宅, 두 왕=火·水) 5%.

### ③ 뜻 모를 소품·어색·잘림
- 이정표 화살 7개: 수의 뜻 모름(頒行 사방? 王冰 七篇大論?).
- 아이 6명·알 6개·천 5장·얼음 3덩이: 수치 대응 미상.
- 입간판의 도기 3점: 甄權인지 陶弘景인지 미확정.
- 승려가 천을 「꿰매는」 것인지 「너는」 것인지 불명 → 續斷(藺道人) 대안 가능.
- 붉은 문 옆의 격자 틀(가마인지 담장인지) 미완성 형태 — AI 잡소품으로 보임.
- 프레임 잘림: 오른끝 얼음왕 정자와 기둥 팻말이 잘림, 아래쪽 다리·기와 잘림, 위쪽 궁궐 지붕 살짝 잘림.

## 2단계 — 계통 (사전요약의 「글자 = 사물」 어휘로 재판독)

사전에서 이 판에 직접 걸리는 기호: **王 = 왕관**(張·李·吳와 함께 성씨 기호 계열), **陰 = 얼음 덩이**, **熱 = 불꽃 / 陽 = 불**, **外 = 담 바깥**, **門 = 문간**, **通 = 안팎이 이어짐**, **久 = 같은 것 셋 포갬**, **大 = 나란한 둘 중 하나가 두 배**, **太 = 테 넓은 큰 갓**(이 판에 없음), **寺 = 기와 절 한 채**, **膈 = 기둥 넷 사이 흰 천**(형태 불일치). 나머지(둥지·알·날개 상자·죽간·입간판·다리)는 사전에 없는 새 기호 → 이 판에서 처음 등재되는 이름 말장난으로 읽힘.

### ① 재판독
1. **왕관 둘 = 王씨 둘**(사전의 성씨 기호). ▸ 성벽 「담 바깥(外)」 누대(臺) 위 + 불(燾의 灬) + 죽간 → **王燾 『外臺秘要』**(1단계 유지, 확신 상승). ▸ 얼음(冰) 책상 + 붓(注) + 두루마리 9~10권 + 빈 팻말 3 → **王冰 『素問』 次注·七篇大論 보입**. 다만 사전상 얼음 덩이 = 陰이므로 「王+陰」으로 오독될 여지가 있음 — 여기서는 이름 글자 冰의 직역으로 판정. 얼음 3덩이 = 久(12년 걸린 편찬)로 읽을 수도 있음.
2. **소년 + 상자 2(날개 1) + 금화** → 孫(아이) + 千金 + 翼 = **孫思邈 千金要方·千金翼方**(유지). 열린 붉은 문(門) 밖에 서 있음 = 출사하지 않은 在野(隋文帝·唐太宗 부름 사양)로 부가 해석 가능.
3. **둥지 + 갖가지 무늬 알 6 + 선비** → **巢元方 『諸病源候論』**(유지; 諸病의 源). 알 6 = 大業 6년(610) 편찬 후보.
4. **버드나무 꼭대기 승려 + 흰 천 5** → 楊(버들)+上(꼭대기)+善(승려) + 素(흰 명주) = **楊上善 『黃帝內經太素』** 유지. 단 사전의 太(큰 갓)가 없고 승려 눈이 감겨 있어 **鑑真**(실명·東渡) 대안 25%, 흰 천 = 붕대·續斷으로 보면 **藺道人 『理傷續斷方』** 15%.
5. **관복 스승 + 죽간 + 아이 6 + 사방 이정표 7** → 太 갓이 없으므로 太醫署보다는 **국가 반포 『新修本草』(蘇敬 등, 659)** 쪽으로 기움: 관이 펴 읽어 사방(頒行天下)에 보임. 아이 6·화살 7의 수는 여전히 미상.
6. **A자 입간판 + 항아리·단지·사발 그림 3** → 메뉴판 꼴이라 **孟詵 『食療本草』**(식치) 1순위, 陶(本草經集注 저본)+圖(藥圖)·甄權 圖는 2순위.
7. **운하 + 홍예 돌다리**(안팎을 잇는 물길 = 通) → 隋 大運河(通濟渠)·趙州橋 = 隋 시대 표지. **황금 기와 궁궐** = 唐 황실(弘文館). 붉은 문 옆 흰 깃발 윤곽은 뜻 없는 잡소품.

### ② 표제어
- **1순위: 隋唐 의학사 — 巢元方·楊上善·孫思邈·新修本草·王燾·王冰(+食療本草)** — 80% (성씨 기호 王=왕관이 두 王씨를 정확히 찍어 주고, 나머지는 사전에 없는 새 이름 기호라 계통어휘로 더 잘 풀림)
- **2순위: 扁鵲(둥지=鵲·알 6=六不治)** — 5% (왕관 둘·날개 상자·얼음이 설명되지 않음)
- 藏象 腎(水火) 후보는 사전의 腎=잠수부·心=붉은 곤룡포가 모두 없어 폐기.

### ③ 남는 의문
- 이정표 화살 7·아이 6·흰 천 5·두루마리 9의 수 대응 미확정(七篇大論·大業6년·81篇=9×9 등은 추정).
- 얼음 덩이가 사전상 陰이라 王冰과 충돌 — 이 판이 「冰」을 새로 등재하는 것인지 확인 필요.
- 승려의 정체(楊上善/鑑真/藺道人)와 입간판의 정체(食療/藥圖)는 사전으로 확정 불가.
- 잘림·잡소품은 1단계와 동일(오른끝 정자·팻말, 아래 다리, 문 옆 흰 깃발 윤곽).
