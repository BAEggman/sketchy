# blind6 / 003 판독

## 1단계 — 생판 (그림만)

① 소품 전수
- 해: 상단 중앙, 두 탑 사이. 광선 16개(등간격). 지름은 사람 머리의 약 1.5배. → 熱·暑·陽.
- 성벽: 왼쪽 탑(총안 4)·오른쪽 탑(총안 4)·좌우 낮은 성벽·뒤쪽 먼 성벽. 회색 돌. 장면은 성 안마당. → 城=胃家? 두 탑 사이의 해=「兩陽合明」(陽明)?
- 왼쪽 남자(청회색 도포, 가슴 풀어헤침): 얼굴 붉음, 눈 감음, 머리 주위 땀 약 9방울+가슴·팔 약 5방울. 머리만 한 갈색 물항아리(머리의 약 1.3배)를 기울여 들이키는데 입에서 물이 턱·가슴으로 흘러넘치고, 뻗은 오른팔 손목(寸口 자리)에서 굵은 물줄기가 쏟아짐(입 줄기의 약 2배). 나무 의자, 샌들. 발밑은 판석 포장(石→石膏?). → 大熱·大汗·大渴·脈洪大 = 白虎湯 四大證. 풀어헤친 가슴 = 惡熱.
- 오른쪽 남자(황토색 도포·붉은 깃): 얼굴 붉음, 눈 질끈, 이 악묾. 땀은 튀는 큰 방울 5(좌3·우2)+얼굴 약 5+손등 1~2. 두 손으로 맨살의 팽팽한 둥근 배(머리의 약 1.5배, 배꼽 보임)를 움켜쥠. 발밑은 갈라진 마른 황토. 옆에 뚜껑·고리·걸쇠 달린 회색 쇠솥(머리 크기). → 腹滿硬痛·潮熱汗出(手足汗)·燥屎·便秘, 솥=承氣湯 또는 닫힌 변기. 노란 옷=大黃?
- 바닥: 왼쪽 55% 판석, 오른쪽 45% 갈라진 땅. 손목 물줄기는 갈라진 땅에 닿지 않고 경계에 떨어짐(津液이 새어나가 胃腸이 마름).

② 표제어
- 1순위 **陽明病 — 經證(白虎湯證) 대 腑證(承氣湯證)** 60%
- 2순위 **溫病 氣分證(白虎湯證·承氣湯證)** 15% / 3순위 **暑病·中暑** 10% / 4순위 **消渴** 5%

③ 잔결
- 손목 물줄기가 洪脈인지 「마셔도 곧장 새는 물」(渴不解·飮一溲一)인지 애매. 항아리 밑바닥이 뚫린 고리처럼 그려짐(밑 빠진 독?). 솥이 밥솥인지 변기인지 불명, 걸쇠의 뜻 불명. 성벽·좌우 벽은 프레임에서 잘림(의미 없음). 눈에 띄는 잘림 없음. 광선 16·땀 방울 수는 장식으로 보임.

## 2단계 — 계통 (사전 어휘로 재독)

① 소품 재판독
- 성 안 = **裏**(사전: 裏=성 안). 해 = **陽**. 불꽃이 없으니 熱 자체보다 「陽·裏」가 표제.
- 팽팽하게 찬 배 = **實**(팽팽하게 찬 것) → 「胃家實」. 못이 없으니 痛이 아니라 滿·實.
- 갈라진 땅 = **燥** → 胃中乾燥·燥屎.
- 살갗의 방울 = **汗**. 튀는 큰 방울이 얼굴 방울의 2배 → 「大」汗 가능.
- 맑은 물 = **津**. 손목에서 아래로 쏟아짐 = **下**, 입에서 넘침 = **盛** → 津液이 밖으로 쏟아져 나감(亡津液). 1단계의 洪脈 읽기는 脈 기호가 없으므로 후순위.
- 회색 뚜껑 솥 = **小便=요강**(사전) → 小便數·利小便. 승기탕 솥이 아님.
- 항아리 = 물 마심(渴). 淸(맑은 물 한 그릇)으로 읽을 수도 있으나 쏟으며 마시므로 渴.
- 두 남자 사이 한복판·두 탑 사이의 해 = **中**? → 「胃中」乾燥와 호응 가능.

② 표제어
- 1순위 **陽明病(胃家實) — 太陽病에 發汗·下·利小便 → 亡津液 → 胃中乾燥 → 轉屬陽明** 65%
  (傷寒論 「何緣得陽明病?… 此亡津液, 胃中乾燥, 因轉屬陽明. 不更衣, 內實, 大便難者, 此名陽明也」: 汗=땀, 下=손목 물줄기, 利小便=요강, 亡津液=쏟아지는 津, 胃中乾燥=갈라진 땅, 內實=팽팽한 배, 裏=성 안, 陽=해)
- 2순위 **暑邪(暑爲陽邪·傷津耗氣)** 12% — 해·땀·갈라진 땅·요강(尿短)은 맞지만 濕(진창)이 없고 氣(흰 김)도 없으며 팽팽한 배가 남음.
- 3순위 八綱 **裏實熱證 / 「邪氣盛則實」** 10%.

③ 판정과 잔결
- 어휘로 읽으면 성(裏)·배(實)·땅(燥)·솥(小便)·물(津·下·盛)이 모두 풀려 1단계보다 낫다. 두 처방 대비(白虎/承氣)보다 「陽明病 성인·제강」 한 판으로 읽힌다.
- 잔결: 손목 물줄기가 「下(瀉下)」인지 「汗如水」인지 확정 불가(瀉=빗자루가 없음). 大便(뒷간통) 기호 부재 — 燥로 대신한 듯. 두 탑=陽明(兩陽合明)은 미등재 추정. 항아리 밑 뚫린 고리, 솥 걸쇠는 여전히 뜻 모름. 광선 16·땀 방울 수는 의미 없어 보임.
