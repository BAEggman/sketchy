# blind6 / 004 판독 기록

## 1단계 — 생판 (사전 기호 없이 그림만)

### ① 소품 전수 + 나르는 사실(추정)
무대는 L자 청회색 돌 카운터(안쪽 모서리)와 앞쪽 나무 장(앞면에 반짝이 1). 약방/식당 카운터 장면.
1. **밀짚모자 농부**(젊음, 갈색 옷·앞치마) — 빈 흰 사발을 코앞에 듦 → 「냄새 맡기/마시기」(矯臭矯味·복용?) 또는 神農.
2. **흰 사제복 성직자**(회색 머리, 로만칼라) — 반달꼴 옅은 조각(만두/떡/성체) 1개 듦 → 「麵裹(반죽에 싸기)」·복용하기 쉬운 형태? 또는 淡·白.
3. 두 사람 사이 **김 1줄기** → 蒸(찜)·溫.
4. **노란 액체 사발 + 옅은 원판 1** → 蜜炙(꿀) 또는 酒製(黃酒).
5. **회색 사발 흰 액체 + 같은 원판 1** → 鹽水炙·米泔水·水飛(수제). 같은 조각을 액체만 바꿔 담근 대비 = 液體輔料 2종.
6. **흰 찐빵에 남색 열매 7개** + 남색 즙방울 5 → 黑豆汁·발효(神麴/淡豆豉)? 뜻 불확실.
7. **붉은 고추 1** → 辛·薑炙(薑汁).
8. **베이지 종이/천 1장**(구겨짐) → 紙裹煨(종이에 싸 굽기)·包煎.
9. **회색 바위 1 부서짐, 파편 10여** → 煅(불에 구워 부스러짐)·打碎先煎·散.
10. **붉은 X 아래 옅은 둥근 덩이 1 + 검은 곰보 덩이 1** → 生/炭 대비의 금지(炭 過度 灰化 X) 또는 忌火, 또는 두 약 相反(半夏×烏頭).
11. **검은 연기 1줄기** → 炒炭·毒.
12. **풀 사발 위 쇠 저울추 1**(풀 2배 크기, 눌림선) → 壓榨 去油(製霜)·용량(秤錘)·質重 沉降 vs 質輕 升浮.
13. 나무 장 반짝이 → 貯藏 편리.

### ② 표제어
- 1순위 **炮製法(修治·水製·火製·水火共製) 총론** — 40%. 꿀/소금물 사발=炙, 김=蒸, 종이·만두=煨, 바위=煅, 연기=炒炭, 추=壓榨, 풀=發芽, 빵=發酵까지 거의 전 소품이 포제 기법 하나씩과 맞아떨어짐.
- 2순위 **煎服法(先煎·包煎·後下·烊化·服藥時間)** — 20%. 바위=先煎, 천=包煎, 풀=後下, 김=溫服, 고추=辛辣 忌, 두 사람 식사=飯前/飯後.
- 3순위 七情配伍·十八反(X 쌍=相反, 연기=毒) 12%, 4순위 消食藥(신부=神, 빵=麴, 새싹=麥芽, 막=雞內金) 8%.

### ③ 뜻 모를 것·어색·잘림
- 남색 열매 박힌 흰 빵과 즙방울: 무엇을 나르는지 가장 불명.
- X 밑 두 덩이의 정체(生/炭? 半夏/烏頭? 蘿蔔/五靈脂?)와 연기의 출처(검은 덩이인지 뒤쪽 화덕인지) 불명.
- 저울추가 풀 위에 있는 이유(누르기인지 무게인지) 이중 해석.
- 농부와 신부가 누구를 나르는지(神農/陶弘景? 生/熟? 복용자?) 불명.
- 프레임 잘림: 없음. 검은 연기 상단이 위 테두리에 닿을 뿐.

## 2단계 — 계통 (사전요약 어휘로 다시 읽기)

### ① 소품 재판독
사전의 「글자 = 사물」이 그림의 절반 이상을 직접 푼다.
1. 노란 밀짚모자 농부 = **脾**. 빈 흰 사발을 듦 → 食少·脾虛(받아 드는 빈 사발=惠와 닮았으나 한 사람뿐).
2. 흰 도포 재상 = **肺**. 손의 옅은 조각은 원판의 ⅓ 크기 → 虛(삼분의 일로 줄어든 것)=肺氣虛로 읽힘.
3. 두 사람 사이 흰 김 = **氣**, 위치가 「둘 사이의 한복판」= **中**, 곧게 솟음 = **上** → 脾에서 上輸된 氣가 肺로 오름(脾為生氣之源·肺為主氣之樞).
4. 노란 국물이 찰랑한 사발 = **補**(꿀빛이면 **甘**=脾之味 겸용) → 培土生金.
5. 회색 사발의 맑은 물 = **淸** → 肺가 들이쉬는 淸氣(氣의 두 재료: 水穀精氣+淸氣).
6. 흰 찐빵 = 痰(끈적한 회백색 덩이) 또는 肌(도톰한 살덩이)+검푸른 알(瘀?) 7개·즙 5방울 → 「脾為生痰之源 肺為貯痰之器」로 읽히나 알의 뜻은 미확정.
7. 붉은 고추 = **辛** = 肺之味.
8. 베이지 천 1장 = 溫(김 나는 따뜻한 천)이라기엔 김이 빵 위에 있음 → 皮(肺主皮毛) 쪽으로 보되 불확정.
9. 회색 덩이가 사방으로 날림 = **散** → 肺 宣發(脾氣散精, 上歸於肺).
10. 풀 위의 저울추 = **降** → 肺 肅降(下輸). 풀은 미등재 기호(升?).
11. 붉은 X 밑 옅은 덩이+검은 곰보 덩이+검은 연기 → 「土不生金」또는 焦·衰의 금지. 검은 연기는 熱(불꽃)과 달라 미확정.
12. 나무 장의 반짝임 = **華**(脾 華在唇·肺 華在毛의 총칭?) — 붙은 자리가 어색.

### ② 표제어
- 1순위 **肺·脾 상호관계(氣의 生成·水液代謝·痰의 생성·培土生金)** — 45%. 脾·肺 두 인물만 등장하고 氣·中·上·淸·補·散·降·辛·甘이 한 관계 단원의 사실들과 1:1로 맞음.
- 2순위 **補中益氣湯** — 25%. 補(국물)+中(한복판)+氣(김)가 등재 기호 그대로이고 脾肺氣虛·下陷(추)·甘溫除熱(꿀+X+연기)까지 읽히나, 益·李(자두)가 없고 補 사발과 김이 한 무리로 묶여 있지 않음.
- 1단계의 炮製 가설은 이 어휘로 읽으면 근거를 잃음(꿀=甘/補, 바위=散, 추=降이 모두 다른 뜻으로 등재).

### ③ 잔결
- 찐빵의 검푸른 알 7개와 남색 즙 5방울: 瘀·陰 어느 쪽도 색이 어긋남. 미해독.
- X 밑 두 덩이의 정체와 연기의 뜻(熱? 苦=검은 커피?) 미확정.
- 풀(저울추 밑)·베이지 천·나무 장은 미등재 소품. 華가 왜 장에 붙었는지 불명.
- 프레임 잘림 없음.
