# blind6 / 005 판독

## 1단계 — 생판 (사전 없이 그림만)

### ① 소품 전수와 나르는 사실
1. **검은 전신 잠수복 인물 1명** (후드·물안경 착용, 노년 주름, 무표정) — 검정=黑(水의 색), 잠수=水·潛·伏, 머리·양어깨에 눈 3덩이 쌓임.
2. **입김 1개** — 寒(추위) 또는 호흡(腎主納氣).
3. **눈 내림·눈밭** — 冬(겨울), 寒.
4. **얼음판 + 균열 3~4줄** — 水氷地坼 / 寒性凝滯. 인물이 얼음 위에 서 있음.
5. **초가집 1채** (흙벽·기둥·초가지붕) — 집=室·家.
6. **열린 나무문 1짝** — 창고문. 藏의 문(開?).
7. **창고 안 자루더미 2열 약 13~15개** (좌 6~7, 우 7~8) — 藏(冬藏·閉藏·藏精). 높이는 인물의 1/2 가량.
8. **소반 1 + 붉은 질그릇 1 + 흰 결정 가루(소금) 수북** — 鹹味(水의 味). 소반 높이 ≈ 인물 무릎 아래(1/5).
9. **벽에 기댄 판자 1개** (위 끝에 구멍) — 뜻 불명(骨?·노?).
10. 눈송이 다수(셀 수 없음).

### ② 표제어
- 1순위 **腎 / 水行 배속** (北方·冬·寒·水·鹹·黑·藏 — 陰陽應象大論 "北方生寒, 寒生水, 水生鹹, 鹹生腎") — **50%**
  근거: 검정옷(黑)·얼음(水)·눈/입김(寒·冬)·소금(鹹)·창고자루(藏·封藏之本·腎者主蟄)·잠수(腎主水, 숨참기=納氣).
- 2순위 **冬三月 閉藏 양생 (素問·四氣調神大論)** — **25%**
  근거: 水氷地坼(얼음 균열)·閉藏(가득 찬 창고)·無泄皮膚(전신을 봉한 잠수복)·使志若伏若匿(잠수부)·無擾乎陽(입김).
- 3순위 寒邪(六淫) 10% / 鹹寒 약재(玄參·芒硝) 10%.

### ③ 뜻 모를 소품·어색·잘림
- 벽에 기댄 구멍 뚫린 판자: 용도 불명.
- 그릇이 **붉은색**인 이유 불명(火·心과의 관계? 鹹走血?).
- 閉藏이라면 창고문이 **열려 있는** 것이 어색(무대 노출용?).
- 자루 수 13~15로 정확히 셀 수 없음(겹침). 판자 옆 기둥과 문틀 사이 벽 깨짐선 다수(장식인지 기호인지 불명).
- 프레임 잘림: 초가지붕 오른쪽 끝과 오른쪽 벽이 화면 밖으로 잘림, 왼쪽 눈밭·얼음 경계도 잘림.
- 인물이 왜 굳이 "잠수부(해녀)"인지, 얼음 위에서 잠수를 못 하는 모순(물이 얼어 잠수 불가=水 기능 정지?).

## 2단계 — 계통 (사전요약의 「글자=사물」 어휘로 재판독)

### ① 소품 → 등재 기호
1. 검은 잠수복·후드·고글 잠수부 = **腎** (오행왕국 다섯 인물 중 하나 — 1단계의 "잠수부 의문" 해소).
2. 입에서 서린 흰 김 = **氣** → 腎氣 / 腎主納氣 / "通於冬氣"의 氣.
3. 눈송이(다수) = **寒** → 冬·寒. 머리·양어깨의 눈 3덩이 = 寒이 腎에 닿음(久는 아님: 포개지지 않음).
4. 얼음판 = **陰** (얼음 덩이) → 腎主水·陰中之少陰. 균열 3~4줄은 **燥**(갈라진 땅)로도 읽힘 → 腎苦燥/腎惡燥 가능성.
5. 문 열린 곳간 안 가마니 약 13~15개 = **藏** (등재 기호 그대로: 문 열린 곳간+쌓인 가마니) → 腎藏精·封藏之本·精之處. 열린 문은 어색한 것이 아니라 기호의 일부이며, 안팎이 이어진 것은 **通**(通於冬氣), 문틀은 **門**.
6. 굵은 소금 수북 = **鹹** → 在味爲鹹·鹹入腎. 붉은 그릇 = **血**? → 鹹走血/鹹傷血(부속 사실) 가능.
7. 벽에 기댄 판자(곧은 능선+끝의 구멍) = **骨**? → 腎主骨·其充在骨(색이 흰 뼈가 아니어서 불확실).
8. 초가집·소반 = 사전에 없음(무대 장치).

### ② 표제어
- 1순위 **腎 — 장상 배속 총론판 (封藏之本·藏精 / 主水(陰) / 通於冬氣·寒 / 在味爲鹹 / 在色爲黑 / 氣·納氣 / 主骨)** — **65%**
  등재 기호 腎·藏·鹹·寒·氣·陰(+骨·通·門)이 한 무대에 모였고 虛·傷·盛·衰 등 병기 기호는 없어 병증판이 아닌 생리·배속판.
- 2순위 **六節藏象論 腎 조문("腎者主蟄, 封藏之本, 精之處也, 其華在髮, 其充在骨, 爲陰中之少陰, 通於冬氣")** — **20%**
  藏(封藏)·가마니(精之處)·판자(骨)·얼음(陰)·열린문+눈+김(通於冬氣)이 조문 순서와 잘 맞음. 다만 소금(鹹)은 이 조문에 없음.
- 3순위 冬三月 閉藏 10% / 命門(難經36難: 右門·藏精·原氣) 5%.
- 판정: 1단계 답(腎/水行)이 유지되며, 사전 어휘로 잠수부·열린 문·김·얼음이 모두 등재 기호로 풀려 확신 상승.

### ③ 잔결
- 판자 = 骨인지 미확정(흰색 아님·뼈 혹 대신 구멍). 붉은 그릇 = 血 기호인지 단순 질그릇인지 미확정. 얼음 균열 = 燥인지 단순 얼음 묘사인지 미확정.
- 髮·耳·恐·唾 등 腎의 나머지 배속 기호는 없음(후드가 귀·머리카락을 덮음).
- 자루 수 13~15(겹쳐 정확 불가). 초가지붕 우측·오른쪽 벽 프레임 잘림.
