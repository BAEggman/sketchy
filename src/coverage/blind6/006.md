# blind6 / 006 판독

## 1단계 — 생판 (그림만)

① 소품 전수
- 비: 화면 전체에 세로 빗줄기(셀 수 없음). 삿갓 챙에 튀는 물방울 표시 3, 양 어깨에 각 2 → 外濕(淋雨), 濕은 陰邪.
- 노란 밀짚 삿갓 1(챙 폭≈어깨폭 1.1배), 그 밑에 검은 머리띠 → 머리를 덮음=頭重如裹, 黃=脾.
- 남자 1, 정중앙 정면·무표정·빈손. 노란 저고리(회색 동정, 고름 매듭 1)·노란 바지(걷어올림) → 黃色=脾·土, 中央=土.
- 맨발 2가 흙탕물 웅덩이 안 → 濕性趨下·傷於濕者 下先受之(涉水).
- 갈색 진흙·탁한 물 → 濕性重濁.
- 땅에서 피어오르는 흰 안개 2덩이(좌하·우하) → 霧露, 濕氣 蒸騰.
- 보리밭(긴 까끄라기 이삭 수십, 황록색으로 익어감) → 長夏·장마철=濕의 主氣, 穀=脾胃 運化.
- 갈색 항아리 1(높이≈사람 키의 1/5), 낮은 나무 상(다리 3개 보임, 높이≈무릎) 위, 나무 주걱 1 꽂힘, 호박색 끈적한 시럽이 넘쳐 4줄기(좌3·우1) 흘러내림 → 甘(甘入脾), 넘침=中滿(甘者令人中滿), 끈적임=濕性黏滯.
- 잿빛 하늘 → 濕爲陰邪.

② 표제어
- 1순위 **濕邪(六淫의 濕)** 65% — 陰邪(잿빛 비)·重濁(흙탕)·黏滯(끈적 시럽)·趨下(맨발 웅덩이)·困脾(노란 옷) 다섯 성질이 소품 하나씩과 짝.
- 2순위 **脾·土(長夏)** 25% — 中央·黃·甘·濕·長夏·穀의 土行 축.
- 기타: 黃疸·濕困脾胃 5%, 飴糖·麥芽 5%.

③ 뜻 모를 것·어색·잘림
- 항아리에 꽂힌 나무 주걱의 뜻 불명. 삿갓 밑 검은 띠 불명. 저고리 배 부분의 어두운 얼룩(젖음? 음영?). 시럽 항아리를 비 맞는 야외에 둔 이유(甘+濕→內濕?). 밭이 좌우 프레임에 잘리나 의미 없음. 빗줄기·이삭은 셀 수 없음.

## 2단계 — 계통 (사전 어휘로 재판독)

① 소품 재판독
- 노란 밀짚모자 농부 = **脾** 그 자체(사전 등재 인물). 전신 노랑 = 黃, 화면 한복판 = 中(央).
- 부슬비·안개·진창이 세 가지 다 있음 = 사전의 **外濕** 세트 정확히 일치. 발밑 웅덩이·진흙은 「발밑에서 배어 나오는 진창」= **內濕**으로도 읽힘 → 비는 밖에서 脾를 치고, 진창은 脾의 발밑에서 남.
- 나무 국자가 꽂힌 꿀단지 = **甘**(사전 정의와 글자 그대로 일치). 1단계의 「끈적=黏滯」는 폐기. 넘쳐 흐름은 「盛=넘쳐 흘러나오는 것」과 겹쳐 甘의 盛(과다)일 수 있으나, 꿀을 보이게 하려는 장치일 수도 있음.
- 흙탕·밭 = 土(地). 보리밭은 사전에 없음 — 土가 낳는 穀·長夏 배경으로 추정.
- 흰 안개는 사전상 「氣=서린 흰 김」과도 겹치나, 비·진창과 한 묶음이므로 濕(안개)로 우선 읽음.
- 삿갓은 「太=테 넓은 큰 갓」과 형태가 겹치지만 脾 농부의 기본 복장이므로 太陰 암시는 낮게 봄.

② 표제어
- 1순위 **脾 — 五行 土行 계통(中央·濕·土·甘·黃)** 45% — 「中央生濕 濕生土 土生甘 甘生脾 … 在色爲黃 在味爲甘」: 한복판의 脾, 비(濕)→진창·밭(土)→꿀(甘)→농부(脾), 온통 노랑(黃)이 한 판에 다 놓임.
- 2순위 **脾惡濕·濕困脾/脾虛生濕(外濕·內濕)** 30% — 外濕 세 기호가 脾를 적시고 內濕 기호가 脾 발밑에서 배어 나옴; 꿀단지는 「甘生脾/과식 甘→濕」 보조.
- 기타: 濕邪 단독 10%(사전상 濕은 비·안개·진창 하나로 충분해 黏滯·趨下 소품이 사라짐), 太陰濕土 5%, 脾苦濕·甘補之(藏氣法時論) 5%.

③ 남는 것
- 보리밭(사전 미등재: 土·穀·長夏 중 무엇인지), 꿀 넘침이 盛인지 단순 표시인지, 안개가 氣인지 濕인지, 삿갓 밑 검은 띠, 저고리 배의 어두운 얼룩. 잘림 없음. 수: 시럽 줄기 4, 삿갓 물방울 3, 어깨 각 2, 상 다리 3 보임.
