# blind6 / 007.png 판독

## 1단계 — 생판 (그림만 읽음)

### ① 소품 전수와 나르는 사실
1. **붉은 벽돌담** — 무대 전면을 가득 채움. 문·창·틈 없음, 글자 없음. 배경(乾血 / 腠理 / 營·城 후보).
2. **갑옷 병사 2인** — 완전히 같은 인물의 복제. 우측이 좌측의 약 1.3~1.4배(투구꼭지~허리띠 450px : 600px).
3. **비늘갑옷(魚鱗甲)** — 가슴·배·어깨·치마 전부 비늘. 피부가 갑옷비늘처럼 거칠어짐 = 肌膚甲錯.
4. **투구** — 정수리 뾰족침 1개.
5. **들어올린 손(각자 왼손)** — 손가락 5개 활짝(좌측 병사 5개 확인, 우측은 4개+새끼손가락이 프레임에 잘림). 「五」 또는 건강한 쪽 손.
6. **늘어뜨린 오른팔** — 근육이 빠져 힘줄·뼈가 드러남(羸瘦·枯). 두 병사 모두 동일.
7. **큰 병사 두 정강이** — 뼈만 남음(骨). 작은 병사 정강이는 매끈한 정상 피부.
8. **허리띠 + 배 앞의 뾰족 앞치마판** — 帶 / 腹.
9. **두 눈** — 검은 동자가 또렷, 눈썹 짙음(兩目黯黑?). 표정은 옅은 미소.
10. 발 없음(아래 프레임 잘림). 우하단 반짝 워터마크(소품 아님).

### ② 표제어
- 1순위 **大黃䗪蟲丸證(虛勞 — 五勞虛極羸瘦·肌膚甲錯·兩目黯黑·內有乾血)** 40%
  근거: 손가락 5=五勞, 마른 팔다리=虛極羸瘦, 비늘갑옷=肌膚甲錯, 검은 눈=兩目黯黑, 마른 붉은 벽돌=內有乾血, 배판=腹滿.
- 2순위 **偏枯(半身不遂) — 金匱 中風 「半身不遂 / 但臂不遂者 此爲痹」** 25%
  근거: 한쪽 팔만 늘어져 마름(偏). 작은 병사=팔만(但臂不遂=痹), 큰 병사=팔+다리(半身不遂=中風)로 읽을 수 있음. 단 큰 병사는 두 다리가 다 뼈라서 「半身(반쪽)」과 어긋남.
- 3순위 五勞所傷 중 久立傷骨(서 있는 파수병·뼈 다리) 10%, 痿證(治痿獨取陽明) 10%.

### ③ 뜻 모를 소품·어색한 것·잘림
- 병사 2인의 **크기 차이**가 무엇을 나르는지(大/小? 경중? 大黃의 「大」?) 불명.
- 투구 뾰족침의 의미 불명. 담이 배경인지 소품인지 불명.
- 한쪽 팔만 마른 것(偏 신호)과 큰 병사 두 다리가 모두 뼈인 것이 서로 충돌.
- 우측 병사 새끼손가락·양 병사 발이 프레임에 잘림. 위 첫 벽돌줄도 잘림.

## 2단계 — 계통 (blind6_사전요약 어휘로 재판독)

### ① 소품 → 기호
1. **초록 비늘갑옷 장군 2인** = 사전 「肝 = 초록 비늘갑옷을 입은 장군」. 갑옷은 병증(甲錯)이 아니라 인물 표지. 같은 것 둘이 나란한데 하나가 큼(약 1.4배, 두 배엔 못 미침) = **大**.
2. **들어올린 손의 손톱 5개(끝마다 광택점)** = 爪 + 華 → **其華在爪**. 5는 손가락 수일 뿐 「五」로 읽을 근거 약함.
3. **걷어올린 소매 아래 맨팔뚝에 도드라진 갈색 힘줄 다발** = 「充 = 걷어올린 맨팔뚝 위에 더해진 것」 + 「筋 = 갈색 힘줄 다발」 → **其充在筋**. 1단계의 「마른 팔(羸瘦·偏枯)」은 오독 — 병이 아니라 전시대.
4. **크게 뜬 눈(하이라이트)** = 目 → **肝開竅於目**.
5. **큰 장군의 흰 뼈 정강이(곧은 능선·끝의 뼈 혹)** = 骨. 작은 장군엔 없음 → 大 쪽에만 骨.
6. **붉은 벽돌담** = 「血 = 붉은 것」(肝藏血·以生血氣) 또는 무대의 內/外(담 안쪽·바깥). 확정 못 함.
7. 투구 뾰족침 = 「上 = 머리 꼭대기로 곧게 솟음」일 수도 있으나 장군 복장 기본형일 가능성이 큼.

### ② 표제어
- 1순위 **肝(藏象) — 素問 六節藏象論 「肝者 罷極之本 … 其華在爪, 其充在筋, 以生血氣」 + 開竅於目** 60%
  근거: 華·充·爪·筋·骨·肌·皮·毛·髮·面이 전부 사전에 있음 = 이 책에 六節藏象論 華/充 연작이 있고, 이 판은 그중 肝 판. 손톱=華在爪, 맨팔뚝 힘줄=充在筋, 붉은 담=生血氣, 큰 눈=開竅於目.
- 2순위 **靈樞 本藏 「肝小·肝大」(粗理者肝大 · 肝應爪 · 視其外應以知其內藏)** 15%
  근거: 大 기호 + 담 바깥(外) + 손톱(肝應爪) + 굵은 벽돌(粗理). 단 筋·目·骨이 안 풀림.
- 3순위 素問 痿論 筋痿(肝)/骨痿 대비 10%.
- 1단계 후보(大黃䗪蟲丸·偏枯)는 사전 어휘로 보면 「肝 장군의 전시 소품」을 병증으로 오독한 것 → 폐기.

### ③ 잔결
- **大**(크기 차)와 **큰 장군에만 있는 骨 다리**가 무엇을 나르는지 미해결(肝은 筋 주관, 骨은 腎). 「大骨」·「肝大」·「筋骨」 어느 쪽도 확정 불가.
- 벽돌담이 血인지 內/外 무대인지 불명. 투구침 上 여부 불명.
- 우측 장군 새끼손가락·양쪽 발·위 첫 벽돌줄 프레임 잘림. 우하단 워터마크.
