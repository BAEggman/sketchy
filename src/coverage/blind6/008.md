# blind6/008 판독

## 1단계 — 생판 (사전 자료 없이 그림만)

### ① 소품 전수와 나르는 사실
1. 중년 남자(청록 스웨터·황갈 바지·회색 구두) — 환자 1인, 걸상에 앉음.
2. 얼굴 홍조(이마·양볼·코 주황) — 發熱.
3. 땀방울 2개(왼볼 옆으로 튐) — 汗出, 소량 → 「無汗或有汗不暢」의 有汗 쪽.
4. 양팔 떨림선 ≈10줄(어깨·팔꿈치·손목) — 惡寒/惡風(微惡風寒).
5. 왼주먹 입가 — 咳嗽.
6. 오른손 목젖 움켜쥠, 목 힘줄 — 咽痛.
7. 혀: 길이가 머리높이의 0.7배(정상 내민 혀의 ≈4배). 가운데 희끄무레(苔薄白), 가장자리·끝 선홍(舌邊尖紅). 이 판의 최대 소품.
8. 치켜뜬 눈·찌푸린 눈썹 — 煩·불안(부가).
9. 탁자 위 꽃 두 가지: 인동덩굴꽃(金銀花) 4~5송이, 흰꽃·노란꽃 혼재(=金·銀) + 마주난 잎 2장; 개나리(連翹) 1가지, 정면 꽃 7 + 측면 2 + 봉오리 3 ≈ 12개 단위.
10. 왼쪽 문틀 + 흰 커튼(고리 4개, 닫힘) — 바깥 가리개 = 表/衛分, 또는 「透表」의 무대.
11. 나무 걸상(4다리)·탁자(4다리) — 장치.

### ② 표제어
- 1순위 **銀翹散**(溫病條辨·吳鞠通, 辛涼平劑) — 80%. 근거: 金銀花+連翹 두 군약이 탁자 위, 발열·미오풍한·유한불창·해수·인통·설첨홍 태박백이 몸 전체에 분산 배치.
- 2순위 **風溫初起 衛分證(風熱犯衛)** — 12%. 꽃이 처방이 아니라 「위분증의 대표약」 힌트일 가능성.
- 3순위 桑菊飲 3%(상엽·국화가 없어 약함).

### ③ 뜻 모를 소품·어색·잘림
- 커튼 고리 4개의 뜻 불명(衛氣營血 4단계? 上焦篇 제4조? 단순 장식?).
- 탁자 다리 사이 회색 얼룩(잔상성 흔적, 소품 아님으로 판정).
- 개나리 꽃잎이 5장으로 그려짐(실물 4장) — 식별에는 지장 없음.
- 프레임 잘림 없음(개나리 가지 끝·커튼 밑단 모두 액자 안).
- 두통·구갈(頭痛口渴)은 소품이 없음 → 빠진 조문.

## 2단계 — 계통 (사전요약 어휘로 다시 읽음)

### ① 소품 재판독
1. 왼쪽 문틀 = **門**, 문 밖 = **表**. 문틀 안에 드리운 흰 커튼 = **惡**(해로운 것과 사람 사이에 세운 가리개) → 「表의 사기(風寒)에 대한 惡」= **惡風寒**. 양팔 떨림선 ≈10줄이 같은 뜻을 몸에서 되풀이. 커튼이 얇고 희고 4고리뿐 → 微惡風寒으로 읽힘.
2. 얼굴 주황 = 사전의 **面**(이마·광대·콧대에 얹힘) 자리에 붉은 기 → 面赤·發熱. 다만 이 책의 熱 기호(불꽃)는 없음.
3. 땀방울 2개 = **汗**, 소량 → 有汗不暢.
4. 벌린 입(어두운 타원) = **口**, 그 안의 혀 = **舌**. 혀 가장자리·끝의 붉음 = **血**(붉은 것) → 舌邊尖紅. 가운데 희끄무레 = 苔(薄白). 혀 길이 ≈4배 = 이 판의 주역 소품.
5. 크게 뜬 눈 = **目** — 표정용, 조문 대응 없음.
6. 탁자 위에 화병 없이 흐트러져 놓인 꽃 두 줄기 = **散**(흩어진 것) → 산제(散劑). 금은화(백·황 4~5송이+잎 2)=**銀**, 개나리 1가지(≈12단위)=**翹** → 새 등재 기호 「金銀花·連翹」.
7. 오른손 목 = 咽, 왼주먹 입가 = 咳 — 사전의 痛(쇠못)이 없어 「咽痛」은 몸짓으로만 나름.
8. 걸상·탁자 = 장치.

### ② 표제어
- 1순위 **銀翹散** — 85%. 계통 어휘로 「銀+翹+散」이 탁자 위에 그대로 조립되고, 커튼(惡)+문(表)+떨림 = 微惡風寒, 面赤=發熱, 汗 소량, 舌邊尖紅·苔薄白, 咽·咳가 방제학 조문 순서대로 배치됨. 1단계보다 커튼이 풀려 확신 상승.
- 2순위 **風溫初起 衛分證(辛涼平劑證)** — 10%.
- 3순위 桑菊飲 2%.

### ③ 잔결
- 커튼 고리 4개: 사전에 수 기호 없음. 溫病條辨 上焦篇 제4조(風溫·溫熱·溫疫·冬溫 4종 → 銀翹散) 암시 가능성만 기록.
- 熱(불꽃)·痛(쇠못)·燥 기호 부재 → 發熱·咽痛·口渴이 계통 기호 대신 표정·몸짓으로 처리됨(사전과 어긋남).
- 頭痛 소품 없음. 탁자 다리 사이 회색 얼룩은 잔상. 잘림 없음.
