# blind6 / 009 판독

## 1단계 — 생판 (사전 없이 그림만)

**① 소품 전수·나르는 사실**
- 무대: 회색 석벽 지하실(감옥풍) 모서리, 돌바닥. 벽감 위 기름등잔 1개·불꽃 1개(작음, 연기 한 가닥) — 두 사람 사이 한복판 위. 돗자리 2장.
- 왼쪽(누운 사람): 옆으로 웅크려 누움(蜷臥) · 베개 1 · 두꺼운 이불로 온몸 덮음(畏寒喜溫) · 얼굴 청회색·눈 감김·입 처짐(面色蒼白·神疲·但欲寐) · 몸 둘레 떨림선 4쌍(惡寒) · 손 청백색에 서리 줄기 3, 맑은 물 흘러 방울 2~3(肢冷+冷汗淋漓 / 분비물 清稀) · 드러난 발 청색(四肢厥冷).
- 오른쪽(무릎 꿇고 앉은 사람, 눕지 못함=不得臥·失眠): 눈 크게 뜨고 눈밑 검음(煩躁·不寐) · 광대에 붉은 원 2(顴紅·面赤) · 혀 내밀어 입술 핥음(口乾咽燥·口渴) · 손바닥 2 위로, 붉음 + 가슴에서 열기선 4(五心煩熱·內熱) · 이불 없음(惡熱) · 마르고 수염(消瘦). 앉은 키 ≈ 누운 사람 길이의 1.1배, 등잔은 사람의 1/6.

**② 표제어**
- 1순위 **陽虛證 vs 陰虛證(虛寒·虛熱 대비)** 40% — 왼쪽은 畏寒肢冷·蜷臥·面白·自汗·神疲, 오른쪽은 顴紅·五心煩熱·口乾·失眠·消瘦로 두 증후군 목록이 거의 완전 대응.
- 2순위 **寒證 vs 熱證(八綱 寒熱辨證)** 30% — 惡寒喜溫·肢冷·清稀 대 煩躁·面赤·口渴로도 읽힘.
- 3순위 少陰病 寒化(但欲寐·四逆)·熱化(心煩不得臥) 15%. 등잔은 陰陽 등불 비유(기름=陰·불꽃=陽)로 추정.

**③ 뜻 모를·어색·잘림**
- 감옥 배경이 나르는 뜻(裏? 虛=빈 방? 少陰=어둡고 깊은 곳?) 불명. 등잔이 왜 두 사람 사이 중앙인지 불명. 손의 흐르는 물이 冷汗인지 녹는 서리인지 애매. 우하단 흰 네모별 = 생성 워터마크(소품 아님). 프레임 잘림 없음. 오른쪽 인물 발이 가려져 足心熱 확인 불가.

## 2단계 — 계통 (사전요약 어휘로 재판독)

**① 소품 재판독**
- 등재 기호가 그대로 맞는 것: **厥**=검푸르게 언 손발 끝 → 왼쪽 손·발(手足厥冷 확정). **陰**=얼음 덩이 → 왼쪽 손의 서리(陰盛·陰寒). **汗**=살갗에 맺힌 땀방울 → 손등 물줄기·방울(冷汗). **下**=아래로 쏟아짐 → 방울 낙하. **裏**=속·성 안 → 석벽 밀실(裏證 무대). **陽**=불 → 등잔불, **衰**=타다 남아 작아진 것 → 작은 불꽃(陽衰 암시), **中**=둘 사이 한복판 → 두 사람 사이의 등잔. **目**=크게 뜬 눈, **舌**=벌린 입 안의 혀, **面**=광대 위 광택 → 오른쪽 인물의 目·舌紅·顴紅.
- 어긋나는 것: 사전의 **寒**=눈송이, **熱**=불꽃(사람 몸에), **虛**=1/3로 줄어든 것이 그림에 없음. 떨림선·열기선은 등재 기호 아닌 일반 표현.

**② 표제어(재판정)**
- 1순위 **陽虛證 vs 陰虛證(虛寒·虛熱)** 40% — 사전 어휘(厥·陰·汗·裏·目·舌·面)가 1단계 판독을 뒷받침하나 虛 기호가 없어 확신은 그대로. 극단형 亡陽(冷汗淋漓·厥冷) vs 亡陰(手足溫·面赤·煩躁)도 같은 축(10%).
- 2순위 **寒證 vs 熱證(寒熱辨證 / 넓게 陰證·陽證)** 25%.
- 3순위 **寒厥 vs 熱厥(素問 厥論: 陽氣衰於下則寒厥, 陰氣衰於下則熱厥)** 15% — 등재 기호 厥과 오른쪽 손바닥 열(手足熱)·등잔 衰가 이 축으로도 묶임. 다만 熱厥의 핵심인 足下熱을 안 그렸으므로 1순위로 올리지 않음.
- 판정: 사전 어휘로 소품 뜻은 더 선명해졌지만(厥·裏·汗 확정) 표제어 1순위는 바뀌지 않음.

**③ 잔결**
- 등잔의 정체(陽衰 표지인지 조명인지) 불명. 감옥=裏로 읽히나 그것이 표제어에 들어가는지 불명. 오른쪽 발 가려짐. 우하단 워터마크. 잘림 없음. 수: 떨림선 4쌍·열기선 4·방울 2~3·광대원 2·등잔 1·돗자리 2.
