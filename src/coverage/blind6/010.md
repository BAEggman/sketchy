# blind6 / 010 판독

## 1단계 — 생판 (그림만 보고)

### ① 소품 전수와 각각이 나르는 사실
1. **조선 임금 1인** — 익선관(검정, 날개 2개 위로) + 붉은 곤룡포 + 검은 목화. 얼굴은 만원권 세종 초상풍(콧수염+턱수염). → 君主之官 = 心 (心者 君主之官 神明出焉).
2. **내민 혀 1개** — 붉고 정상 설질, 병적 소견 없음. → 心開竅於舌.
3. **걷어 올린 오른팔(관객 왼쪽)의 혈관 그물** — 팔꿈치까지 소매를 걷어 맨팔, 손등·손가락까지 가지 치는 혈관이 그려짐. 반대팔은 소매 그대로(비대칭 강조). → 心主血脈 / 在體合脈 / 其充在脈.
4. **붉은 곤룡포 + 연적색(분홍) 벽·천장** — 방 전체가 붉은 계열. → 在色爲赤 / 火 / 南方.
5. **얼굴** — 양볼 광택 하이라이트 2곳, 눈 크게 뜨고 눈썹 올린 활기찬 표정. → 其華在面 (혹은 藏神·在志爲喜).
6. **용보 3개 보임** (가슴 1 + 양어깨 2, 등은 안 보임) — 왕 신분 표지. 개수 의미 미상.
7. **창 1개(양쪽 문짝 활짝 열림) + 창밖 나무 1그루(녹색)** — 열린 창 = '開竅'의 시각화? 나무 = 木(肝, 心의 母; 木生火)? 미상.
8. 회색 바닥, 검은 목화 1켤레 — 배경, 사실 미상.
크기: 인물이 화면 높이 약 85%, 창은 인물 키의 약 1/3, 혈관 팔 노출 길이는 상완 제외 전완+손(반대팔의 소매 길이와 동일).

### ② 표제어
- 1순위 **心(심장의 생리·오행 배속: 君主之官·主血脈·開竅於舌·其華在面·色赤)** — 80%
- 2순위 **手少陰心經**(팔 안쪽 혈관 = 유주, 挾咽·繫目系를 혀·눈으로) — 10%
- 기타: **세종(조선 의학사·鄕藥集成方/醫方類聚)** 5%, **舌診** 5%

### ③ 뜻 모를 소품·어색한 것·프레임 잘림
- 창밖 나무: 木/肝 암시인지 단순 배경인지 불명. 열린 창도 開竅 기호인지 배경인지 불명.
- 용보 3개: 계수 의미 없음(표준 곤룡포는 4개, 등 1개는 시야 밖).
- 혀가 정상색·정상형으로 '설진' 아닌 '舌=心竅' 기호로 읽힘.
- 프레임 잘림: 없음(익선관 날개 끝이 상단에 가깝지만 온전). 인물·창·방 모두 완전.

## 2단계 — 계통 (blind6_사전요약 어휘로 재판독)

### ① 소품 전수와 사실 (사전 기호로 치환)
1. **붉은 곤룡포 임금 = 心** — 표제 인물 확정(사전 등재 기호 그대로).
2. **얼굴의 광택(양볼·콧대) = 華 + 面** — "이마·광대·콧대에 얹힌 광택 = 面", "빛나는 것·광택 = 華" → **其華在面**.
3. **걷어올린 맨팔뚝 위의 붉은 혈관 그물 = 充 + 血脈** — "걷어올린 맨팔뚝 위에 더해진 것 = 充", "붉은 것 = 血" → **其充在血脈**. 반대팔이 소매를 내린 채인 것은 '더해진 것'을 한쪽에 집중시킨 비대칭 표기.
4. **벌린 입(어두운 타원 구멍 = 口/竅) 안의 혀 = 舌** — "열린 어두운 구멍 = 竅", "벌린 입 안의 혀 = 舌" → **開竅於舌(在竅爲舌)**. 혀에 이끼(苔) 없음 → 설진 판이 아님.
5. **활짝 열린 창(안과 밖이 한 덩어리로 이어짐 = 通) + 창밖 잎 무성한 초록 나무(여름 = 夏)** → **通於夏氣**. 1단계에서 '배경'으로 남겼던 창·나무가 이 어휘로 정확히 풀림.
6. **크게 뜬 눈 = 目** — 사전상 目이나 心 藏象 문구에 目은 없음. '神之變也/神明出焉'의 표정 표현이거나 단순 표정으로 판정(미확정).
7. 연적색 벽·붉은 곤룡포 = 血/赤 계열 색 배경; 용보 3개·목화 = 신분 표지(사실 없음). 해(陽)·불꽃(熱)은 없음 → '爲陽中之太陽'은 미표기.
크기: 인물 85%·창 1/3 (1단계와 동일).

### ② 표제어
- 1순위 **心의 藏象(素問·六節藏象論: 其華在面·其充在血脈·通於夏氣 + 開竅於舌)** — 90%. 華·充·通 세 전담기호가 한 판에 모두 쓰여 六節藏象論 정형구 "其華在○·其充在○·通於○氣"를 그대로 나른다.
- 2순위 **心의 오행 배속 일반(陰陽應象大論·五藏生成: 在體爲脈·在竅爲舌·在色爲赤)** — 7%. 같은 心 주제이나 充·通 기호를 설명 못 함.
- 기타: **手少陰心經** 3%.
- 판정: 1단계 1순위(心 생리 일반)보다 2단계 어휘로 훨씬 정밀하게 풀린다. 사전 어휘가 이 판에 더 잘 맞음.

### ③ 잔결
- 크게 뜬 눈(目)의 담당 사실 불명(神 표현 추정).
- 陽中之太陽·生之本 구절은 소품 없음(해·불꽃 부재).
- 프레임 잘림 없음. 수 오류 없음(용보 3개는 시야 한계).
