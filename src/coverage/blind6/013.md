# blind6 / 013 판독 기록

## 1단계 — 생판(그림만)

**① 소품 전수 → 나르는 사실**
- 벽화 다섯 짐승(虎·鹿·熊·猿·鶴 순, 5마리) → 五禽戲(虎鹿熊猿鳥 순서 그대로).
- 칼 1 + 김 오르는 사발 1을 든 백의 인물 → 마취탕(麻沸散)을 먹인 뒤 칼로 째는 외과수술.
- 황금갑옷·붉은 망토 장군 + 머리에 광채 난 암탉 1 → 미확정(關羽=羽·새? / 太尉 黃琬=黃·금빛 갑옷? / 五禽의 「禽」?).
- 흰 깃발 밭 약 40개(5줄 안팎) → 군영(關羽 진중 수술) 또는 夾脊穴(34혈과 개수 불일치).
- 왕관·주황옷·금메달 임금 + 아이, 화로(붉은 조각 4~5), 옆 죽간 2(펼친 것 1·묶음 1) → 曹操(魏王)·曹沖, 靑囊書 소각(索火燒之), 曹沖 죽자 「吾悔殺華佗」.
- 빈 비석 1 → 華佗 옥사.
- 비석 옆 죽간 2뭉치 → 三國志·後漢書 두 史書에 立傳.
- 활 멘 남자 1 + 사다리 1 → 미확정(樊城 공성·독화살→刮骨療毒 배경? / 張=弓+長?).
- 문 열린 곳간 위 둥근 가마니 7(위3·아래4) → 미확정(고향 沛國 譙? 灸 每處 七八壯?).
- 석상 2(밖: 노인·책·등의 깃발 4 / 안: 젊은이·책·금메달) → 陳珪 擧孝廉·黃琬 辟 → 皆不就(돌=응하지 않음)? 또는 關公讀春秋像.
- 통나무를 두 손으로 멘 수염 남자 + 허리춤 붉은 꽃무늬 주머니, 뒤에 덩굴 벽 → 樊阿의 漆葉靑黏散(漆나무·靑黏 덩굴)? 또는 董奉(董=艹+重, 杏花)?
- 이정표 팻말 6 → 遊學徐土·벼슬 거절·유랑, 또는 歸家(思歸).
- 금메달 3(안쪽 석상·장군·왕) → 공통점 미상(추천·召命 표시?).

**② 표제어** 1순위 **華佗**(85%) — 五禽戲 벽화·마취+칼·曹操·소각 죽간·비석이 한 줄로 읽힘. 2순위 **建安三神醫(張仲景·華佗·董奉) 군상**(10%) — 활(張)·통나무+덩굴(董奉)까지 인물로 보면.

**③ 어색·잔결** 장군이 든 광채 암탉의 뜻이 가장 불명. 깃발 수(~40)가 34(夾脊)와 안 맞음. 석상 2의 정체와 금메달 3의 공통점 미상. 활+사다리 조합, 통나무, 가마니 7개의 의미 미확정. 프레임: 우측 이정표 팻말 끝이 화면 가장자리에 닿아 살짝 잘림.

## 2단계 — 계통(사전 어휘로 재판독)

사전에서 잡힌 기호: **王=왕관**(임금), **張=등에 멘 활**(활 남자), **華=빛나는 것·광택**(암탉 머리 광채), **倉·藏=곳간 안 가마니**(석상이 선 곳간), **風=한쪽으로 눕고 옆으로 날리는 것**(깃발 밭), **氣=흰 김·補=따뜻한 국물**(사발), **熱=불꽃**(화로), **李=허리춤 자두**(통나무 남자 허리춤), **太=테 넓은 큰 갓**(바깥 석상의 갓, 반확신). **吳=큰 입**은 못 찾음.

**① 재판독**
- 광채(華) 나는 새를 「지고 든」(佗=짐 지다/타조 鴕 음차) 장군 → 이름 rebus **華佗**; 장군 몸은 曹操 진영(常在左右) 또는 關羽(羽=새)의 刮骨療毒.
- 王(왕관)+아이+熱(화로)+죽간 → 曹操(魏王)·曹沖·靑囊書 소각. (王叔和로도 읽히나 소각·아이는 華佗 쪽.)
- 깃발 밭=風, 王 바로 앞에 깔림 → 曹操의 **頭風**(佗針鬲 隨手而差). 개수는 「많이·반복」 정도.
- 활=張 → **張仲景**과 同時代(建安) 표시; 옆 비석·죽간=死後 史書 立傳.
- 김(氣)·국물(補) 사발+칼 → 麻沸散 복용 후 외과수술(腸 절제 봉합).
- 곳간(倉/藏)+太 갓 석상 → 太尉 黃琬 辟, 沛相 陳珪 擧孝廉(안쪽 금메달)→皆不就; 돌=응하지 않음.
- 허리춤 자두(李)+통나무+덩굴 → 제자 **李當之**(藥錄) 쪽으로 이동(1단계 樊阿·董奉 철회); 덩굴은 樊阿 漆葉靑黏散 여지.
- 이정표 → 妻病 핑계 歸家·不返 → 하옥.
- 五禽 벽화 → 五禽戲(吳普 계승).

**② 표제어** 1순위 **華佗**(80%) — 華(광택)+지고 든 새의 rebus가 잡혀 1단계보다 근거는 늘었으나, 張·王·李가 성씨 기호로 동시에 서 있어 2순위 **東漢末 醫家 군상(張仲景·華佗·王叔和/曹操·李當之)**(15%)을 배제 못 함. 3순위 傷寒論 전승사(張→戰亂→王叔和 撰次) 5%.

**③ 잔결** 吳(큰 입) 부재 → 吳普 미표시. 장군 본체의 정체(黃琬/關羽/曹操軍) 미확정. 사다리·가마니 7·금메달 3의 뜻 미상. 자두인지 꽃무늬 주머니인지 해상도 한계. 우측 이정표 프레임 잘림.
