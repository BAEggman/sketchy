# 014 판독 기록

## 1단계 — 생판 (그림만)
① 소품 전수
- 개울 1줄기(좌상 발원→우하 베틀) + 흰 김 뭉치 ≈10 = 몸속 한 물길(一氣/津液 흐름)
- 왕관 소년 A(발원지, 두 손으로 물머리 집음) + 빈 나무 표지판 1 = 근원·主
- 땅구멍 색 연기 4(적·청·황·녹, 오색이면 5여야) + 별똥별 4(꼬리 4) + 녹색 연기를 코로 빨며 우는 큰입 소년 = 五味/五氣 入鼻, 눈물(泣)
- 잎옷 소녀 + 대나무 발 4장(위 2 말아올림=열림, 아래 2 내림=닫힘, 손으로 조절) + 빈 흰 깃발 1 + 김 = 腠理 開閉 → 汗出
- 진흙 거품 웅덩이 + 김 + 눈송이 ≈10 = 天寒 → 溺與氣 / 淖澤
- 독 5개 3단 폭포(위→가운데 기울어짐→아래, 넘쳐 웅덩이) + 밑독 잡고 소리치는 큰입 소년 = 腸胃充郭·胃緩氣逆→唾 / 中焦受氣取汁
- 왕관 소년 B + 베틀 + 개울이 색실 5~6가닥으로 갈려 무지개 천 = 한 물길이 여러 이름으로 갈림(各走其道/六名), 脈(壅遏)
② 표제어: 1순위 **靈樞·五癃津液別(液別為五: 汗·溺·泣·唾·水脹)** 40% / 2순위 **靈樞·決氣(六氣: 精·氣·津·液·血·脈, 一氣→六名)** 30% / 3순위 津液 대사 총론(三焦 水道) 15%
③ 뜻 모를·어색·잘림: 빈 표지판·빈 깃발(글자 없음), 왕관 둘의 정체, 잎옷의 뜻, 색 연기 4색·별 4개·독 5개의 수, 별똥별 꼬리가 상단 프레임 밖으로 잘림.

## 2단계 — 계통 (사전 적용 후)
사전: 王=왕관, 吳=얼굴 절반 큰 입, 寒=눈송이, 濕=진창, 氣=흰 김, 溫=김 오르는 따뜻한 천, 鼻=열린 콧구멍, 下=쏟아짐. 성씨 기호(王·張·李·吳)가 등재돼 있으므로 인물(의사학) 판으로 재판독 → 1단계 津液 판독은 철회.
① 소품 재판독
- 왕관 A=王, 개울 발원지(거슬러 오른 상류) + 표지판(道) = **王履(王安道)《醫經溯洄集》** — 溯洄=상류로 거슬러감, 「溫病不得混稱傷寒」
- 별똥별(天) + 땅구멍 색연기 4(地) = 天地間 別有一種 異氣(戾氣·雜氣, 색이 제각각=氣不一 病種種), 열린 콧구멍 흡입 = 邪從口鼻而入, 큰 입=吳 → **吳有性(吳又可)《溫疫論》**(邪伏膜原·達原飲)
- 잎옷=葉, 발 4장 = 衛·氣·營·血 4층(위 2 걷힘=表, 아래 2 내림=裏), 김=氣, 흰 깃발=營(진영 깃발)/指南 → **葉天士《溫熱論》** 衛氣營血辨證(在衛汗之·到氣清氣·入營透熱轉氣·入血涼血散血, 溫邪上受 首先犯肺 逆傳心包)
- 눈송이(사전 寒, 이름 雪) + 진창(濕) + 김(熱) → **薛雪(薛生白)《濕熱條辨》** 濕熱病(始惡寒 後但熱不寒 = 눈 뒤에 김)
- 독 3단 위→中→아래(下=쏟아짐) = 三焦, 큰 입=吳(溫病由口鼻而入) → **吳鞠通(吳瑭)《溫病條辨》** 三焦辨證(始上焦 終下焦; 治上焦如羽·中焦如衡·下焦如權)
- 왕관 B=王, 베틀=經緯, 김 오르는 천=溫 → **王孟英(王士雄)《溫熱經緯》**(經=內經·仲景, 緯=葉·薛 諸家; 霍亂論)
- 개울 전체 = 溫病學 源流(王履에서 발원해 王孟英이 짜냄), 무지개 실 = 諸家 학설의 直緯
② 표제어: 1순위 **溫病學派 계보·溫病學 發展史(王履→吳有性→葉天士→薛雪→吳鞠通→王孟英)** 85% / 2순위 **溫病 辨證 체계 비교(衛氣營血·三焦·濕熱)** 10%
③ 잔결: 빈 표지판(道?)·빈 깃발(營? 指南?) 글자 미확정, 독 5개·별 4개·연기 4색의 수 의미 미상, 눈송이가 사전상 寒이라 薛雪 명패로 쓰면 규칙 충돌(葉=잎옷, 雪/薛=눈송이는 이 판 신규 등재 필요), 劉完素(六氣皆從火化)·余霖 등 계보 인물 부재, 별똥별 꼬리 상단 잘림.
