# blind6 / 016 판독 기록

## 1단계 — 생판 (그림만)

① 소품 전수와 나르는 사실
- 웃통 벗은 남자 1명: 상반신 전체가 벌겋게 달아오름, 정수리 위 붉은 열기선 3줄, 얼굴·머리에 땀방울 3~4개 → 上熱(面赤·煩熱·汗出)
- 흰 김 2군데(컵 옆, 오른 어깨 위로 솟음) → 열기·기운이 위로 치솟음(氣上撞心)
- 오른손으로 잔을 들어 마심(갈색 음료, 김) → 消渴(목말라 자꾸 마심)
- 왼손으로 가슴 한복판을 누름, 가슴에 불꽃 4~5가닥 → 心中疼熱
- 하반신: 반바지 밑단부터 발끝까지 푸른 얼음·서리 결정(별 모양 6~7개) → 下寒·手足厥冷(臟寒). 상체 붉기 : 하체 푸르기 = 몸이 허리선에서 정확히 반반
- 발밑 맑은 물웅덩이 1 + 튄 물방울 1 → 下利(久利·利不止) 또는 찬물
- 모래시계 1개, 모래 절반쯤 내려감 → 時(時煩·須臾復止, 간헐성)
- 회충 1마리, 쓰러진 유리병 아가리에서 기어나오며 웃음 → 吐蛔·蛔厥·蛔聞食臭出
- 그릇 1개, 갈색 곡식 알갱이(밥/콩) 가득 → 食(飢而不欲食·得食而嘔)

② 표제어
- 1순위 **烏梅丸證(厥陰病 寒熱錯雜·蛔厥, 傷寒論 326·338조)** — 50%
- 2순위 **厥陰病 提綱(326조: 消渴·氣上撞心·心中疼熱·飢而不欲食·食則吐蛔·下之利不止)** — 35%
- 기타 上熱下寒證 일반 — 15%

③ 뜻 모를 소품·어색·잘림
- 유리병의 정체 불명(膈? 약병=丸? 꿀단지?).
- 모래시계가 時煩인지 久利인지 苦酒漬一宿인지 미확정.
- 烏梅丸이라면 烏梅(매실)·丸이 없음 → 처방보다 병증 판일 수도.
- 그릇 내용물이 밥인지 콩인지 매실인지 모호. 프레임 잘림 없음.

## 2단계 — 계통 (사전 어휘로 재독)

① 소품 재판독
- 파랗게 언 발끝 = **厥**, 발밑 고인 물 = **陰** → 두 소품이 나란히 「厥陰」을 이룸(판의 이름표). 다리의 별 모양 결정 = 눈송이 = **寒**.
- 가슴 불꽃 = **熱**, 정수리로 곧게 솟는 붉은 선 = **上**, 어깨·컵 옆 흰 김 = **氣** → 「氣上撞心」·「心中疼熱」·「上熱下寒」이 사전 그대로 읽힘. 손으로 누른 한복판 = 中.
- 땀방울 = **汗**.
- 김 나는 갈색 잔 = 사전상 **苦**(김 나는 검은 커피). 마시는 동작은 消渴로 읽히나, 사전 독자는 苦(苦酒漬烏梅? 黃連·黃柏의 苦寒?)로 겹쳐 읽을 수 있음 — 충돌 소지.
- 회충 = 蛔(사전 미등재, 그림 그대로). 언 발(厥) 바로 옆에 둠 → 「蛔厥」.
- 밥그릇 = 食(미등재). 酸=초록 매실이 아니므로 烏梅는 아님. 補(국물 찬 그릇)도 아님.
- 모래시계 = 時(미등재). 久=셋 포개진 것이 없으므로 「久利」는 아님 → 時煩·須臾復止 또는 欲解時.
- 유리병: 甘(꿀단지)이려면 국자, 膈이려면 흰 천이어야 하므로 둘 다 아님 → 미등재 소품.

② 표제어
- 1순위 **厥陰病 提綱(傷寒論 326조 — 厥陰之爲病 消渴·氣上撞心·心中疼熱·飢而不欲食·食則吐蛔·下之利不止)** — 55%. 근거: 厥+陰 합성 이름표가 판 하단 한가운데, 提綱 여섯 증상이 소품으로 전부 대응, 烏梅·丸 부재.
- 2순위 **烏梅丸(蛔厥, 338조)** — 35%. 근거: 蛔+厥 나란함, 모래시계=時煩, 밥그릇=得食而嘔·蛔聞食臭出.
- 1단계 1순위(烏梅丸證)를 내리고 提綱을 올림.

③ 잔결
- 유리병(회충이 나온 곳) 미등재·의미 불명.
- 잔=苦 충돌(消渴 의도라면 맑은 물=津으로 그렸어야).
- 붉은 상체가 血(붉은 것)로 오독될 여지. 모래시계 의미(時煩/欲解時) 미확정. 잘림 없음.
