# blind6 / 017 판독 기록

## 1단계 — 생판(사전 없이 그림만)

① 소품 전수
- 뿔 1개: 밑동이 빈 소뿔꼴 큰 뿔(뿌리 조각 대비 약 8~10배) → 犀角(水牛角 대용)
- 검붉은 둥근 뿌리 단면 약 10조각(동심 무늬) → 涼血 약재(赤芍 또는 生地黃, 미정)
- 내민 혀: 짙은 자줏빛, 이끼 없음 → 舌質深絳(紫絳)·無苔
- 오른쪽 콧구멍 코피 1줄기 → 衄血
- 입가의 피 묻은 손수건 1 → 吐血·咯血
- 가슴·양팔 자흑색 반점 수십 개 → 斑疹紫黑·密布
- 땀방울 2~3, 붉은 머리칼 → 身熱·汗出
- 반쯤 감긴 흐린 눈, 눈밑 그늘 → 神昏·譫妄(昏憒)
- 쳐든 주먹과 떨림선 3곳(어깨·팔꿈치·다리) → 躁擾不安·抽搐(熱極動風)
- 돌벽 방에 벽 기대 주저앉음 → 위중·가장 깊은 층
- 초록 셔츠·황토 바지·회색 구두 2 → 의미 미상

② 표제어
- 1순위 **犀角地黃湯 — 溫病 血分證(熱入血分·耗血動血)** 80%
- 2순위 **淸營湯(營分證)** 10% — 舌絳·斑疹은 맞으나 출혈이 뚜렷해 營分보다 血分
- 그 밖에 化斑湯(氣血兩燔) 5%, 羚角鉤藤湯(뿔=羚羊角+떨림) 5%

③ 불명·어색·잘림
- 뿔이 무소뿔이 아니라 소뿔 모양(犀角/水牛角/羚羊角 중 어느 것인지 그림만으론 애매)
- 붉은 뿌리 조각이 어느 약재인지 미정, 처방 네 약 중 둘만 보임
- 우하단 별 반짝(✦) 의미 불명, 초록 옷 색 의미 불명
- 잘림: 책상 왼쪽 가장자리가 프레임에 잘리나 정보 손실 없음

## 2단계 — 계통(사전 어휘로 재판독)

① 사전으로 확정된 것
- 「地黃 = 검붉은 뿌리 조각」이 등재어 → 책상 위 조각은 **生地黃**으로 확정. 뿔(犀角)+地黃이 나란히 놓여 처방 이름 **犀角地黃**을 책상이 그대로 철자함
- 「血 = 붉은 것」: 코피·손수건 피·반점이 모두 血 → 衄血·吐血·發斑 = 動血
- 「鼻 = 열린 콧구멍」+붉은 것 = 鼻衄 / 「舌 = 벌린 입 안의 혀」에 「苔 = 이끼」가 없음 → 舌絳無苔
- 「汗 = 살갗 땀방울」→ 汗出(身熱)
- 「裏 = 성 안」: 돌벽 성 안쪽 방이 裏, 곧 衛氣營血 중 가장 깊은 血分 층을 무대로 나타냄
- 반점은 「瘀 = 굳은 덩이」가 아니라 평평한 붉은 얼룩 → 斑(발진)으로 읽음
- 떨림선·주먹은 사전 미등재 → 躁擾·如狂·動風 정도로 읽되 확정 보류
- 우하단 ✦은 「華 = 빛나는 것」과 겹치나 놓인 자리·맥락상 생성 워터마크로 판단, 소품 아님

② 표제어
- 1순위 **犀角地黃湯 — 熱入血分證(斑色紫黑·吐衄·舌絳·譫語)** 90%
- 2순위 **血分證 총론(衛氣營血辨證의 血分)** 5% — 같은 무대를 개념 판으로 읽는 경우
- 淸營湯·化斑湯은 지황 확정으로 사실상 탈락(각 2~3%)

③ 잔결
- 「熱 = 불꽃」이 없음 — 熱入血分의 熱이 기호로 서지 않고 땀·붉은 머리로만 암시됨
- 초록 셔츠는 「肝 = 초록 비늘갑옷 장군」과 색만 겹침(血分→肝 힌트인지 우연인지 미정)
- 처방의 赤芍·丹皮는 그려지지 않음(이름 두 약만 등재)
- 떨림(動風/躁擾)과 흐린 눈(神昏)은 전담 기호가 없어 독자마다 읽기가 갈릴 수 있음
