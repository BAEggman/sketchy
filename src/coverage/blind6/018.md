# blind6 / 018 판독

## 1단계 — 생판 (사전 미열람)

### ① 소품 전수와 나르는 사실
1. 밤하늘 + 별 다수 — 夜·陰.
2. 그믐 초승달 1개(왼쪽이 밝은 하현 쪽, 달무리 있음) — 月·陰(陰이 다한 달).
3. 왼쪽 병풍 4폭: 먹구름 + 번개 1줄기 — 雷·電·驚(놀람)·震.
4. 오른쪽 병풍 4폭: 버드나무 + 풀밭(봄 풍경) — 柳·木·風·巽. 병풍 합계 8폭.
5. 소년: 삭발, 청록 상의, 회색 바지, **맨발**, 성난 얼굴, 주먹 쥠, 오른발을 위로 차 올림(궤적 4줄) — 足·動·怒·握·寒(맨발).
6. 소녀: 쪽머리+붉은 끈, 황색 저고리, 붉은 치마·띠, 흰 버선+짚신, 성난 얼굴, 주먹, 기마자세, 두 손바닥으로 바람을 밀어냄(바람줄기 2) — 手·風·熱(赤)·土(黃).
7. 중앙 소용돌이: 청회색 바람 5~6가닥이 붉은 핵 1개를 감쌈 — 風+火(熱) 또는 痰+熱.
8. 바닥의 둥근 거울(금속 테, 반사면) 1개, 소년 발치 쪽 — 鏡·明·水.
9. 발자국: 왼쪽 청록 1개, 오른쪽 붉은 1개, 서로 마주 봄 — 靑/赤(木/火, 寒/熱). 인물 크기 1:1, 병풍 4:4.
10. 무대 전체가 구름 위에 떠 있음 — 天上·雲.

### ② 표제어
- 1순위 **급경풍(急驚風) — 四證 痰·熱·驚·風** (30%): 번개=驚, 바람·버들=風, 소용돌이 연기=痰, 붉은 핵=熱, 아이 둘=小兒, 거울=鏡(경) 음가 보강, 병풍 8폭=八候. 왼쪽 청색·맨발·먹구름 소년=慢驚風(陰·寒·虛), 오른쪽 홍색 소녀=急驚風(陽·熱·實)의 감별로도 읽힘.
- 2순위 **음양학설 — 대립·호근·소장·전화** (20%): 남/여, 어둠/밝음, 청/적, 발/손, 두 색 소용돌이=交感·互根, 초승달=消長, 거울=轉化.
- 3순위 궐음풍목(厥陰風木)/팔괘 震·巽 "雷風相薄" (15%): 발차기=厥?, 그믐달=陰盡, 바람+버들=風木, 번개=相火.

### ③ 뜻 모를 소품·어색한 것·프레임
- 거울이 鏡인지 물(水)인지 눈(目)인지 불명. 구름 위 무대·달무리의 뜻 불명.
- 소녀의 황색 저고리(土)와 붉은 발자국(火)이 충돌. 배경 병풍(번개/버들)이 앞 인물의 속성인지 상대의 속성인지 불명.
- 프레임 잘림 없음(오른쪽 병풍 끝이 가장자리에 근접하나 온전).

## 2단계 — 계통 (사전요약 열람 후)

### ① 사전 어휘로 다시 읽은 소품
1. 병풍 2틀 = **惡**(해로운 것과 사람 사이에 세운 가리개) — 오른쪽 가리개 너머 버들가지·소녀 치맛자락·바람줄기가 한쪽으로 눕고 옆으로 흘러 날림 = **風** → 惡風. 왼쪽 가리개 너머 먹구름·번개 = 惡+?(번개는 미등재 — 눈송이가 없어 寒으로 읽히지 않음).
2. 소용돌이가 두 아이 사이 정확히 한복판 = **中** → 中風. 소용돌이의 서린 흰 김 = **氣**, 그 속 붉은 핵 = **血**(붉은 것)/熱 → 氣가 血을 감쌈 = 衛(밖)·營(안). 사방으로 흩어지는 가닥 = 散.
3. 바닥의 얕은 쟁반의 고인 물 = **陰**(졸아드는 고인 물) — 淸(맑고 찬 물 한 그릇)일 가능성도 있음. 소용돌이가 이 물 위에서 발차기 궤적을 따라 떠오름 = 陽浮·陰弱.
4. 두 아이 싸움 = 不和/正邪相爭; 청록·붉은 발자국 1개씩 = 中의 양 끝점(둘 사이 한복판 측정). 소년 발끝은 살색(厥 아님).
5. 아이·달·밤하늘·구름 무대·번개는 사전 미등재 — 무대 관습 또는 이 판의 신규 기호.

### ② 표제어
- 1순위 **태양중풍(太陽中風)·계지탕증 — 惡風·營衛不和** (35%): 惡+風=惡風, 中+風=中風, 氣(衛)가 血(營)을 감싼 소용돌이=營衛, 두 아이 다툼=衛強營弱·不和, 붉은 핵=翕翕發熱, 졸아드는 고인 물=陰弱(汗自出), 떠오르는 궤적=陽浮. 왼쪽 가리개는 嗇嗇惡寒 자리로 보이나 寒 기호가 없음.
- 2순위 **풍기내동(內風) / 외풍·내풍** (25%): 담 바깥(外)의 버들=外風, 담 안 한복판의 소용돌이=內風, 고인 물(陰)·붉은 것(血) 위에서 일어나는 바람=陰虛風動·血虛生風, 위로 차올림=上.
- 3순위 급경풍(1단계 1순위) 15%로 하향: 아이·번개 외에 惡·中·氣 기호를 설명하지 못함.

### ③ 잔결·어색한 것
- 왼쪽 가리개의 먹구름·번개가 무엇을 막는지 미확정(寒이면 눈송이가 있어야 함) — 이 판의 신규 기호로 보임.
- 밤하늘·그믐달·구름 위 무대의 뜻 미확정(陰弱 보강인지 무대 관습인지). 汗(땀방울)·脈 기호 없음. 아이가 小兒인지 기본 배우인지 불명. 프레임 잘림 없음.
