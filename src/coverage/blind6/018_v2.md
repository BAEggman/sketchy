# blind6/018 판독 v2

## 1단계 — 생판 (사전 없이, 그림만)

① 소품 전수와 나르는 사실
- 구름 위에 뜬 무대·밤하늘·초승달·별: 밤(陰의 시간대)이라는 배경 표지. 무대 공통 장식인지 사실을 나르는지 미상.
- 왼쪽 병풍: 먹구름+번개 → 雷·電(폭풍). 소년 쪽 배경 = 외부에서 오는 세찬 기운(外風·雷).
- 소년: 삭발, 청록 도포, 회색 바지, 맨발, 성난 얼굴, 왼주먹 쥠, 오른발로 세게 참 → 발차기 = 動(風勝則動·風性主動), 청색 = 木·肝, 怒 = 肝의 志, 握(주먹) = 肝의 變動.
- 중앙 회오리(청록 바깥 + 적색 심): 風邪 자체. 적·청이 섞임 = 風이 다른 邪(寒·熱)를 끼고 감(風爲百病之長), 두 아이 기운이 맞부딪힘(相搏).
- 바닥의 둥근 거울: 잔잔한 水面 또는 鏡. '相'(맞비춤)의 표지인지 水(風水相搏)인지 目·眩(諸風掉眩)인지 미상.
- 오른쪽 병풍: 수양버들+풀밭 → 木, 바람에 흔들리는 나무(風木·肝).
- 소녀: 낭자머리+붉은 댕기, 황색 저고리, 붉은 치마(바람에 날림), 버선+신, 팔짱으로 바람을 막거나 맞받음, 넓은 보폭 → 惡風(바람을 꺼려 막음) 혹은 맞상대(相搏).
- 발자국: 소년 앞 청색, 소녀 앞 적색 → 청실홍실식 男·女 표지 또는 足(발 경락) 색표지.

② 표제어
- 1순위 **六淫 風邪의 性質(風性主動·善行數變·風爲百病之長·風氣通於肝)** — 40%
- 2순위 **八卦 震(雷·長男·足·動)과 巽(風·木·長女·股·入)의 대립 = 雷風相薄(說卦傳)** — 35%. 소년=長男·震爲足=발차기, 소녀=長女·巽爲股=넓은 보폭, 병풍=雷/風木이 딱 맞아 무시 못 함.

③ 미상·어색·잘림
- 미상: 바닥 거울(최대 미상), 초승달·별(밤 표지?), 구름 무대(공통 장식?), 발자국 색, 회오리 속 적색 심.
- 어색: 소년은 맨발, 소녀는 버선+신 — 신발 유무가 의도인지 불명. 소녀 손에서도 바람선이 나와 누가 바람을 내는지 애매.
- 잘림: 소녀 치마 끝이 오른쪽 프레임에 닿을 듯함(경미). 그 외 잘림 없음.

## 2단계 — 계통 (사전요약 적용 후 재판독)

① 소품 전수와 나르는 사실 (사전 기호 대조)
- 4폭+4폭 병풍 무대 = 사전 「八卦 = 마주 본 두 폭이 한 쌍」. 그러므로 이 판은 八卦 마주봄 판이고, 왼쪽 병풍(먹구름+번개=雷)과 오른쪽 병풍(버들=木·風)이 한 쌍 → 震(雷) ↔ 巽(風). 先天八卦의 마주보는 짝 「雷風相薄」.
- 소년 = 震의 사람: 長男(震一索而得男). 맨발로 발을 차 올림 = 「震爲足」, 발차기 = 「震, 動也」, 성난 결단 = 「震爲決躁」. 청록 옷 = 「震爲蒼筤竹」의 蒼.
- 소녀 = 巽의 사람: 長女(巽一索而得女). 넓은 보폭으로 넓적다리를 드러냄 = 「巽爲股」, 치마와 버들가지가 한쪽으로 눕고 옆으로 흘러 날림 = 사전 「風」 기호 = 「巽爲風·爲木」, 팔짱으로 파고드는 바람 = 「巽, 入也」.
- 중앙 회오리(둘 사이의 한복판) = 사전 「中 = 둘 사이의 한복판」. 두 아이의 기운(소년의 발차기 궤적·소녀의 손 바람선)이 한복판에서 맞부딪힘 = 相薄(서로 맞닿아 밀어붙임).
- 바닥 거울: 사전 미등재. 두 사람을 맞비추는 얇은 원판 → 「相」(맞비춤) 또는 「薄」(얇음)의 새 기호일 가능성. 이 판이 새로 등재하려는 기호로 보임.
- 청·적 발자국: 사전 미등재. 각각 한 발씩 → 소년(陽卦 震)·소녀(陰卦 巽) 자리표시, 또는 一索(첫 획)의 표지 추정.
- 밤하늘·초승달: 사전 미등재. 「坎爲月」과 무관하고 八卦 무대의 배경 시간(陰)일 가능성. 구름 위 무대: 八卦 무대 공통 장치로 추정.

② 표제어
- 1순위 **雷風相薄 — 八卦 震(雷·長男·足·動) ↔ 巽(風·木·長女·股·入)의 마주봄 (說卦傳 「天地定位, 山澤通氣, 雷風相薄, 水火不相射」)** — 60%. 1단계에서 2순위였던 읽기가 「八卦 = 4+4 병풍 마주봄」 기호로 확정되었고, 맨발/버선의 어색함도 足·股 대비로 풀렸다.
- 2순위 **中風·風邪中人 — 둘 사이 한복판(中)의 風, 소녀 곁의 회오리를 병표지(風)로 읽는 경우** — 20%. 그러나 寒·熱·汗 기호가 없고 八卦 무대와 어긋나 후순위.
- (변형) 같은 震·巽 축에서 「雷以動之, 風以散之」로 읽을 수도 있으나 대결 구도상 相薄이 우선.

③ 미상·어색·잘림
- 미상: 거울(相/薄/水 중 무엇인지), 발자국 청·적, 초승달·별, 회오리 속 적색 심(雷의 火性? 血?).
- 어색: 소녀 손에서도 바람선이 나와 風의 발원이 巽(소녀)인지 발차기(소년)인지 겹침 — 상호 밀어붙임(相薄) 표현으로 보면 오히려 정합.
- 잘림: 없음(치마 끝 경미 접촉만).
