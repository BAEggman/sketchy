# blind6 / 024 판독 기록

## 1단계 — 생판 (그림만)

**① 소품 전수와 나르는 사실**
- 흰 한복 남자 1: 반듯이 누움, 두 팔 몸에 붙임, 두 발 모음, 신발(2) 신은 채 → 卒倒·不省人事(시신처럼 뉘어진 자세 = 狀若尸)
- 눈 감음(양쪽) → 目合·昏不知人
- 입에서 굵은 흰 띠가 베개·요를 넘어 바닥까지 → 물방울 1 + 회색 웅덩이 1 → 口吐涎·痰涎壅盛(웅덩이는 遺尿 가능)
- 망건·상투, 갓 1개 발치 바닥에 벗어 둠 → 선비·貴人, 갑작스런 卒中
- 허리띠 매듭 1, 요 1, 베개 1 → 臥
- 오른쪽 널문 1 + 문틈에서 벽·바닥 따라 흐르는 흰 기운 → 머리맡 흰 뭉치 1(손 밑) → 賊風·虛邪가 臥處에 침입(臥而當風) / 또는 鼻鼾
- 술 달린 자루 3개 포갬, 가운데 자루 터져 검붉은 콩(팥·黑豆)이 쏟아짐 → 개수 3(三), 豆(黑豆·赤小豆), 漏泄
- 회색 빈 방(空屋), 우하단 희미한 ✦ 1

**② 표제어**
- 1순위 **中風(卒中·中臟腑: 昏不知人·口吐涎, 賊風 침입)** — 35%
- 2순위 **尸厥·卒死(狀若尸)** — 15%
- 그 밖: 中風 脫證 五絕(目合·口開·手撒·鼻鼾·遺尿) 10%, 蛔厥·烏梅丸(입의 띠=蛔, 자루 3=烏梅三百枚) 5%

**③ 뜻 모를 것·어색·잘림**
- 콩자루 3개가 무엇을 나르는지 불명(黑豆? 三化湯·三生飲의 三?), 갓을 벗어 둔 뜻, 손 밑 흰 뭉치가 바람인지 코골이·솜인지 불명, 우하단 ✦ 정체 불명.
- 프레임 잘림: 오른쪽 문이 절반만 보임. 왼쪽 벽·천장은 텅 비어 소품 없음.

## 2단계 — 계통 (사전 어휘로 재독)

**① 소품 → 글자**
- 같은 자루 3개 포갬 = **久** / 가운데 자루가 터져 못 쓰게 됨 = **傷**(셋 중 가운데 = **中**) / 콩이 아래로 쏟아짐 = **下**(넘쳐 나옴 = 盛) / 문 열린 곳간의 곡식 가마니 = **藏** 후보
- 손 밑 서린 흰 김 뭉치 + 문가 벽을 타고 흩어져 나가는 김 = **氣**(사방으로 날림 = 散 → 氣가 새어 나감). 눈송이 없음 → 寒 아님, 불꽃 없음 → 熱 아님. 「한쪽으로 눕고 옆으로 날리는 것」은 없어 風 기호는 약함.
- 흰 도포 남자 = **肺**(재상) 후보. 눈 감고 누움·입가 침 = 臥·寐(만화의 숙면 기호). 갓 = 太 기호이나 머리에서 벗겨져 바닥에 있음 → 臥의 보조, 太 뜻은 미상.
- 입에서 떨어지는 맑은 물방울 = **津**, 바닥 고인 물 = 陰(졸아드는 고인 물) 또는 內濕. → 氣가 상하여 津을 붙들지 못함(氣不攝津: 流涎·遺尿)으로도 읽힘.
- 문 안쪽 = 內, 문 = 門. ✦ = 華(빛나는 것)? 확정 못 함.

**② 표제어**
- 1순위 **久臥傷氣**(素問·宣明五氣 五勞所傷: 久視傷血·久臥傷氣·久坐傷肉·久立傷骨·久行傷筋) — 60%. 「久(자루 셋 포갬)+臥(누운 남자)+傷(터진 자루)+氣(흰 김이 문으로 흩어져 나감)」 넷이 정확히 맞고, 肺(흰 도포)는 氣를 주관하는 주인공.
- 2순위 **中風 中臟(邪入於藏 → 舌難言·口吐涎, 入府 → 不識人)** — 15%. 「中(셋 중 가운데)+藏(문 열린 곳간의 곡식 가마니)+口吐涎(침)+目合」은 맞으나, 자루가 '터진'(傷) 이유와 흰 김(氣)이 설명되지 않음.
- 그 밖: 氣虛不攝津(流涎·遺尿) 10%, 1단계의 尸厥은 사전 기호와 맞지 않아 철회.

**③ 잔결**
- 갓(太)이 머리가 아닌 바닥에 있는 뜻, 웅덩이가 陰인지 內濕인지 단순 침인지, ✦(華?)의 뜻이 미확정. 프레임 잘림은 오른쪽 문 절반뿐.
