# blind6 / 025 판독

## 1단계 — 생판 (그림만)

**소품 전수와 사실**
- 돌벽 지하실 무대 → 차가운 곳(寒·裏).
- 큰 갈색 덩이뿌리 1개 + 옆에 붙은 작은 덩이 1개(모근 1/3 크기) = 모근에 "붙은(附) 자근" → 附子·烏頭. 덩이 온몸의 검은 광택 구슬 약 40개 + 탁자에 떨어진 것 6~7개 = 독(有毒) 또는 烏(검음). 덩이 위 큰 불꽃 = 大熱·炮. 검은 연기 1줄기 위로 곧게 = 烏頭/독기.
- 붉은 고추 1 = 辛. 노란 방울 1 = 甘(꿀). 흰 마늘형 구근 1 = 蔥白(白通湯) 또는 蒜=散(散寒) 말장난.
- 유리등피 등잔 1, 불꽃은 큰 불의 1/5 이하 = 命門火 미약·亡陽(꺼져가는 불).
- 붉은 곤룡포·왕관 임금(용무늬 3) = 부자(富者=附子) 말장난 또는 君火·心, 손에 검은 원판(附子片·附子餅) 1개.
- 검은 잠수복 인물 엎드려 눈감음, 손 2개 검푸르고 붉은 반점 = 四肢厥逆·但欲寐(亡陽). 흰 깔개 = 눈·寒.
- 앞쪽 솥 1, 흰 알갱이 15~20개 끓음, 아래 불 = 先煎·久煎(독 감소) 또는 湯.

**표제어**: 1순위 **附子(부자)** 60% / 2순위 **四逆湯·少陰病 寒化(亡陽證)** 20% / 3순위 烏頭 10%.

**모호·어색·잘림**: 솥 속 흰 알갱이 정체(附片? 떡? 丸?), 임금이 든 검은 원판, 마늘의 정체, 손의 붉은 반점(血? 회양?). 잘림: 오른쪽 임금 어깨·도포, 왼쪽 환자 다리, 아래 솥불, 위 연기 끝.

## 2단계 — 계통 (사전요약 적용)

사전으로 두 인물이 확정된다: 붉은 곤룡포 임금 = **心**, 검은 잠수복 잠수부 = **腎**. 心·腎이 한 판에 서 있으니 축은 心腎=少陰이며, 돌벽 성 안 = 裏 → 무대는 **溫裏藥** 장. 고추 = 辛, 꿀방울 = 甘, 덩이 위 불꽃 = 熱(솥 밑 작은 불과 나란히 하나가 배 이상 → 大熱): 辛·甘·大熱 = 附子 성미. 검은 구슬이 사방으로 튀어 떨어짐 = 散(散寒), 손발 끝 검푸름 = 厥(四肢厥逆) → 回陽救逆. 솥 = 찰랑찰랑 따뜻한 국물 = 補, 그 밑 불 = 火 → 補火助陽. 등잔의 작은 불 = 타다 남은 衰(命門火衰·亡陽 직전). 검은 연기 곧게 솟음 = 上(독기·烏). 임금 손의 검붉은 뿌리조각은 사전상 地黃과 닮으나 문맥상 炮附子片(黑順片)으로 읽힘. 결론은 1단계 유지·강화.

**표제어**: 1순위 **附子(溫裏藥·辛甘大熱·歸心腎·回陽救逆·補火助陽·散寒止痛·先煎)** 70% / 2순위 **四逆湯·少陰病 寒化證** 15% / 3순위 烏頭 8%.

**모호·잔결**: 歸經의 脾(노란 밀짚모자 농부) 부재, 마늘형 구근(蔥白?) 무사전, 솥 속 흰 알갱이(회백 덩이=痰과 혼동 가능) 무사전, 有毒 기호 미등재(검은 구슬·연기로 추정), 임금 손 원판(附子片 vs 地黃) 양의성.
