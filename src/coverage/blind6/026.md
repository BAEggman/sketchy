# blind6 / 026 판독 기록

## 1단계 — 생판 (그림만)

**① 소품 전수와 나르는 사실**
- 문 2짝(좌·우, 둘 다 열림) — 두 사례를 나란히 대비하는 무대. 사람은 둘 다 문지방 위.
- 좌 문 가장자리 불꽃 1 = 몸 겉이 크게 덥다(身大熱). 우 문 가장자리 눈송이 1 = 몸 겉이 크게 차다(身大寒). 크기 1:1 거울.
- 좌 남자: 얼굴 붉음(面赤)·관자놀이 땀방울 1(汗)·턱밑은 창백. 큰 모피 외투(몸집만 함)를 스스로 두름 = 덥다면서 오히려 옷을 찾음(反欲得衣). 손 하나는 푸르게 창백(속은 참).
- 우 남자: 얼굴 담담, 가슴 통째로 붉음(속이 뜨거움), 양손·양발 푸르스름(수족냉). 이불을 바닥에 벗어 던짐(1) + 가슴 풀어헤침 = 춥다면서 옷·이불을 마다함(反不欲近衣). 한 발을 문밖으로 내딛음.
- 좌 바닥: 검은 덩이 1 + 작은 검은 점 5 = 대변? 탄 숯? 우 바닥: 뚜껑 벗겨진 검은 솥 1(덩이의 약 2배) = 요강(小便)? 속이 끓어 뚜껑이 열린 것?

**② 표제어**
- 1순위: **傷寒論 11條 「病人身大熱 反欲得衣者 熱在皮膚 寒在骨髓 / 身大寒 反不欲近衣者 寒在皮膚 熱在骨髓」** — 85%
- 2순위: **寒熱眞假(眞寒假熱·眞熱假寒)** 감별 — 65% (같은 판의 개념 이름일 가능성 큼)

**③ 뜻 모를 것·어색·잘림**
- 검은 덩이(대변인지 숯인지)와 뚜껑 열린 솥의 의미 미확정.
- 좌 남자 손 색이 한쪽은 분홍·한쪽은 푸름(생성 오류인지 의도인지). 우 남자가 다리를 든 동작(문밖으로 나가는 것인지 이불을 차는 것인지).
- 프레임 잘림 없음.

## 2단계 — 계통 (사전 어휘로 재판독)

**① 소품 재판독**
- 門 = 문틀, 表 = 문 밖, 內 = 문 안쪽, 皮 = 면 위 색 경계선(문 가장자리 푸른 띠). 불꽃(熱·陽)과 눈송이(寒)가 모두 그 띠 위에 얹힘 = **熱在皮膚 / 寒在皮膚**.
- **格 = 막은 문틈으로 밀려 나가는 것** — 우 남자가 문틈으로 밀려 나가는 자세 = 格. 좌는 불꽃(陽)이 문틈으로 밀려나감 = **陰盛格陽**, 우는 눈송이(寒·陰)가 문틈으로 밀려나감 = **陽盛格陰**.
- 厥 = 검푸르게 언 손발 끝 → 우 남자 양손·양발(四肢厥冷), 좌 남자 한 손. 面 = 광대 광택 → 좌 面赤(戴陽). 汗 = 땀방울 1.
- 검은 덩이 + 불티 점 = **衰(타다 남아 작아진 것)** — 문 안쪽 불이 다 탄 재 = 陽衰·寒在骨髓(瘀의 검붉은 덩이일 가능성 낮음). 뚜껑 벗긴 솥 = **요강 = 小便** 신호(우: 小便短赤 쪽) 또는 속이 끓어 뚜껑 열림(熱在骨髓).
- 骨髓를 나르는 전담 기호(骨=흰 뼈)는 없음 — '문 안쪽(內)'이 骨髓 자리.

**② 표제어**
- 1순위: **寒熱眞假 — 陰盛格陽(眞寒假熱) · 陽盛格陰(眞熱假寒)** — 85%
- 2순위: **傷寒論 11條 (熱在皮膚寒在骨髓 / 寒在皮膚熱在骨髓)** — 75% (출전 겸 같은 판의 부제)
- 1단계와 실질 동일, 格 기호가 확인되어 '格陽·格陰' 이름이 앞으로 감.

**③ 남는 것**
- 검은 덩이가 衰(재)인지 大便인지 여전히 미확정(大便 전담기호는 나무 뒷간통이라 불일치).
- 솥이 요강(小便)인지 단순 솥인지, 빈 채라 小便 색·양이 없음.
- 좌 남자 손 색 불일치. 잘림 없음.
