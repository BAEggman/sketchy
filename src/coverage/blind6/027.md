# blind6/027 판독 기록

## 1단계 — 생판 (그림만)

① 소품 전수와 나르는 사실
- 돌 아치 성문 1: 사람이 문간 한복판에 서 있음. 좌=성 안(벽등·복도), 우=성 밖(하늘) → 안팎의 경계 = 半表半裏.
- 아치 꼭대기 고리 1 + 수직 줄 1 + 둥근 추 1: 줄이 화면을 정확히 1:1로 가름 → 「半」. 추는 좌우로 오가는 것 → 「往來」. 고리 = 지도리(樞).
- 좌반(따뜻한 황갈색): 벽등 1(불 켜짐), 붉은 얼굴, 땀방울 약 8개, 주황 옷 → 發熱·汗出.
- 우반(푸른 회색): 창백한 얼굴, 회청색 옷, 떨림선 약 6곳(팔·허리·다리·발), 이를 악문 표정 → 惡寒·寒戰.
- 오른손을 오른쪽 늑골 아래(우측 脇下)에 댐 → 胸脇苦滿.
- 왼손으로 왼눈을 가리고 비빔 → 目眩.
- 짚신 2, 양쪽 성벽 성가퀴 → 몸의 방어선(城). 좌상 하늘 어둡고 우상 밝음 → 밤/낮?

② 표제어
- 1순위 **少陽病(小柴胡湯證·半表半裏證)** — 往來寒熱·胸脇苦滿·目眩·半表半裏 (65%)
- 2순위 **往來寒熱**(問診 寒熱 네 유형 중 하나) (20%) / 3순위 **瘧疾**(추=시계추 → 休作有時) (10%)

③ 뜻 모를 것·어색·잘림
- 벽등이 「熱」 표지인지 「裏(성 안)」 표지인지 이중.
- 추가 「흔들림(往來)」인지 「시계추(주기)」인지 「저울추」인지 불명.
- 우측 눈가 물방울 2개가 땀인지 눈물인지.
- 밤/낮 하늘 차이가 별도 사실을 나르는지 불명.
- 口苦·咽乾·喜嘔·不欲飲食·脈弦 소품 없음. 잘림: 좌우 성벽 가장자리(무해).

## 2단계 — 계통 (사전 어휘로 재독)

① 사전 어휘로 다시 읽은 소품
- 裏 = 「성 안」, 表 = 「문 밖」, 內 = 「문 안쪽」, 外 = 「담 바깥」: 좌(벽등·복도) = 裏, 우(하늘) = 表. 정본대로 성곽·문으로 그린 表裏 구도.
- 中 = 「둘 사이의 한복판」: 수직 줄이 表·裏 딱 한복판을 긋고 사람이 거기 서 있음 → 表와 裏의 中 = 半表半裏. 1단계 판정과 일치.
- 熱 = 「불꽃」: 벽등 불꽃이 裏(성 안) 쪽에 있음 → 熱. 汗 = 「살갗의 땀방울」: 같은 쪽 땀방울 약 8개 → 汗出. 둘 다 정본 기호.
- 寒 = 「눈송이」: 눈송이가 없다. 우반의 寒은 떨림선·회청색으로만 표현 → 정본 기호 이탈(직관으로는 읽힘).
- 門 = 「작은 문간」: 여기서는 큰 성문. 표리 경계라는 뜻은 통하지만 「몸의 어느 문」 기호로는 쓰이지 않음.
- 痛(쇠못) 없음 → 옆구리 손은 脇痛이 아니라 苦滿. 實(팽팽히 찬 것)도 없어 몸짓 전용.
- 口(어두운 타원)·苦(검은 커피) 없음 → 口苦 미부호화. 目(크게 뜬 눈) 없음 → 目眩은 눈 가린 몸짓뿐.
- 추·줄·고리는 사전에 없음 → 이 판의 신규 기호(往來 = 흔들리는 추 / 樞 = 고리). 降(저울추)로 오독될 위험 있음.

② 표제어
- 1순위 **少陽病(半表半裏證·小柴胡湯證)** — 表(문 밖)와 裏(성 안)의 中에 선 사람 + 往來寒熱 + 胸脇苦滿 (70%; 表裏 기호가 정본과 맞아 소폭 상향)
- 2순위 **表寒裏熱(寒包火)** — 글자 그대로 裏=熱·汗, 表=寒으로 읽힐 수 있음 (15%; 추의 往來와 문간 위치가 이를 누름)
- 3순위 **瘧疾** (10%)

③ 잔결
- 寒 눈송이 부재, 口苦·咽乾 미부호화(提綱 3증 중 目眩만 몸짓), 喜嘔·不欲飲食·脈弦 없음.
- 추의 뜻(往來/樞/시계추) 미등재, 눈가 물방울(땀/눈물), 밤/낮 하늘 차이 미해결.
- 잘림: 좌우 성벽 가장자리만(무해).
