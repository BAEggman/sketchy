# blind6 / 028 판독 (그림 Read 3회 · 사전 Read 1회)

## 1단계 — 생판 (그림만)

① 소품 전수와 나르는 사실
- 3층 나무 선반장 1채. 가운데 층 오른칸은 비어 있음.
- 맨 위층: 낡아 해진 옛 책 2권(낱장 뭉치 1 + 해진 장정본 1) → 굽이치는 청회색 리본 화살표 1 → 파도무늬 남색 새 책 1권(제첨 공백, 오른쪽 실매기 5바늘 = 조선식 오침 장정). = 옛 의서 여럿을 모아 새 의서 한 권으로 편찬(集成·類聚·계승).
- 가운데 층 왼칸: 손잡이 달린 흰 구급함(적십자 1)에 금메달 1(주황 리본). = 의서·구급 + 으뜸/최초/공인.
- 아래층 왼칸: 번개 무늬 회색 책 1권(急·응급) + 핀셋 무늬 흰 책 1권(외과·治腫 또는 採取).
- 아래층 오른칸, 열린 서랍 2: ㉠약초 서랍 — 끈으로 묶은 마른 풀 다발 2, 초록 가지 1, 갈색 뿌리·조각 4~5, 늘어진 덩굴 1(= 가공 안 한 자생 약재 = 鄕藥·본초). ㉡색인 서랍 — 작은 책/카드 약 25~30장을 4~5색으로 줄지어 꽂음(= 분류·유취·색인, 여러 권).
- 오른쪽: 붉은 곤룡포(가슴·양어깨 금룡 보 3)·익선관의 임금 1, 입 벌리고 검지로 색인 서랍을 가리킴(= 왕명·편찬 지시).

② 표제어
- 1순위 **조선 전기 관찬 의서 편찬(세종대 향약집성방·의방유취)** 50% — 임금=왕명, 옛 책→새 책=집성, 약초=향약, 색인 서랍=類聚, 번개=구급방류.
- 2순위 **동의보감(허준) 편찬** 25% — 옛 책→새 책, 금메달=세계기록유산, 약초=탕액편, 5색 카드=5편으로도 읽힘.

③ 잔결
- 남색 책의 파도무늬 뜻 모름(東海? 寶鑑?). 핀셋 뜻 불확실. 금메달이 ‘최초(最古)’인지 ‘최고 권위’인지 모호.
- 가운데 층 오른칸이 빈 것이 의도인지 불명. 서랍 2개가 선반 앞에 떠 있는 원근이 어색. 프레임 잘림은 없음.

## 2단계 — 계통 (사전 반영)

사전에서 걸리는 글자: 붉은 곤룡포 임금 = 心 · 官 = 3층 선반장의 가운데 층 · 傷 = 깨져 못 쓰게 된 물건 · 典藥 = 끈으로 묶은 약봉지 다발 · 會 = 담는 것 안에 담긴 것.

① 다시 읽기
- 선반은 정확히 3층이므로 가운데 층 = **官**. 그 官 층에 적십자 의서+금메달 → 官이 낸(官撰) 으뜸 의서, 또는 醫官.
- 임금은 사전대로면 心이나, 소품이 전부 책·약재·서랍이고 心 축(神·血脈·舌·面)이 하나도 없음 → 여기서는 글자가 아닌 실물 임금(王命)으로 판정. 다만 心 기호와 정면 충돌.
- 맨 위 해진 책 2권 = 傷(못 쓰게 된 것) → 散佚·훼손된 옛 의서를 새 조선본(오침 5바늘)으로 集成.
- 약초 서랍의 끈 묶은 다발 2는 典藥 기호와 겹쳐 보이나 봉지가 아닌 생약재이므로 鄕藥으로 유지. 서랍(담는 것 안의 것)=會는 뜻이 이어지지 않아 채택 안 함.
- 번개·핀셋·금메달·파도무늬는 사전에 없는 신규 기호.

② 표제어
- 1순위 **조선 전기 관찬(官撰) 의서 편찬 — 세종대 향약집성방·의방유취** 55% (임금=왕명 → 官층=관찬 → 傷책→새책=집성, 약초=향약, 색인=類聚)
- 2순위 **동의보감(허준) 편찬** 25%
- 3순위 **의방유취 단독** 10%

③ 잔결
- 임금 기호가 心과 충돌(사전 독자는 心으로 먼저 읽음) — 실물 임금용 별도 표지(王=왕관 등)가 없음.
- 파도무늬·핀셋·번개·금메달은 미등재라 뜻 확정 불가. 官층 오른칸 공백이 ‘빠진 관서/책’인지 불명.
