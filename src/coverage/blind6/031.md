# blind6 / 031 판독 기록

## 1단계 — 생판(사전 없이 그림만)

**① 소품 전수와 나르는 사실**
- 검은 갓 1개(테 넓음) — 조선 선비·관리 → 東醫(한국) 인물 또는 '관(官)' 표지.
- 흰 도포(넓은 소매) — 白色 → 金·肺.
- 오른손을 가슴 한복판에 펴서 얹음 + 손 둘레 흰 빛살 6~8가닥 — 胸中·肺 부위 강조(肺主氣·宗氣) 또는 心(神明).
- 왼팔 소매를 팔꿈치 위까지 걷어 맨팔뚝·손목 노출, 팔은 늘어뜨림 — 皮(肺主皮毛) 또는 寸口·肺經 전완 유주.
- 회색 턱수염·콧수염, 노인 얼굴(잔잔한 표정) — 毛(其華在毛)·老.
- 창문 1개(덧문 밖으로 열림) 너머 붉은 단풍나무 1그루, 떨어지는 잎 4~5장 — 秋(在季爲秋)·燥·收.
- 허리끈(세조대) 1, 버선·신 1켤레 — 장식(사실 없음).
- 빈 회색 상자형 방 — '방(오장의 방)' 무대.

**② 표제어**
- 1순위 **肺(폐) — 五臟 폐의 방(白·秋·胸中·皮毛·相傅之官)** 40%
- 2순위 **手太陰肺經**(가슴에서 팔뚝으로 내려가는 유주) 20%
- 3순위 李濟馬·太陽人(갓·흰 도포·수염 인물, 가슴=肺大) 15%

**③ 뜻 모를 것·어색·잘림**
- 소매를 왼팔만 걷은 이유, 손 둘레 빛살이 통증인지 기운인지 불명. 세조대·갓의 뜻 불명(갓이 黑=水라면 어긋남). 폐 판이라기엔 코·콧물·울음·매운맛·말 등 소품이 없어 몹시 성김. 프레임 잘림 없음(전신·창·방 모두 안에 있음).

## 2단계 — 계통(사전요약 적용 후)

**① 소품 재판독**
- 흰 도포 재상 = **肺**(사전 등재 전담 기호) — 1단계 1순위 확정.
- 테 넓은 큰 갓 = **太** → 肺와 묶여 '太陰'(陽中之太陰 / 手太陰).
- 걷어올린 맨팔뚝 = **充**의 바탕 → 「其充在皮」(皮=살갗·소매 경계선 한 줄로 읽힘).
- 손 둘레 흰 빛살 = **氣**(서린 흰 김) 가슴에 → 「氣之本」 / 또는 **華**(광택).
- 은빛 수염 = **毛** → 「其華在毛」(華는 손의 광택이 대신하는 듯).
- 창밖 가을 단풍·낙엽 = 秋·**燥**(마른 잎) → 「通於秋氣」.
- 상자형 방 = 오장다섯방의 '폐의 방'. 세조대·버선·신 = 장식.

**② 표제어**
- 1순위 **肺의 藏象 — 六節藏象論 「肺者 氣之本 魄之處也 其華在毛 其充在皮 爲陽中之太陰 通於秋氣」** 55%
- 2순위 **手太陰肺經**(太 갓 + 肺 재상 + 팔뚝 유주) 15%
- 1단계 3순위(李濟馬)는 사전상 근거 없어 폐기.

**③ 잔결·어색**
- 갓이 재상의 기본 복식인지 太 기호인지 판별 불가(앞 판 폐 재상의 복식을 모름).
- 充은 '맨팔뚝 위에 더해진 것'이어야 하는데 더해진 것이 안 보임 — 바탕만 있음.
- 陽(해·불)·陰(얼음·고인 물) 기호가 없어 '陽中之太陰'이 완성되지 않음. 魄 기호 없음.
- 손의 빛살이 氣(김)인지 華(광택)인지 갈림. 프레임 잘림 없음.
