# blind6 / 032 판독 기록

## 1단계 — 생판 (그림만, 사전 미열람)

① 소품 전수
- 구름 위 널판 무대 1 · 밤하늘 배경(별 다수, 초승달 1 — 여인 쪽 우상단)
- 좌 병풍 4폭: 낮의 푸른 하늘·흰 구름 = 天·陽·晝
- 우 병풍 4폭: 황금 가을 들판·구릉 = 地·陰·秋收(殺)
- 남자 1(좌): 상투·높은 이마, 머리가 여자 머리의 약 2배, 청록 도포, 拱手로 허리 굽힘 = 男·陽·氣, 上
- 여자 1(우): 쪽머리, 황토 옷·허리띠, 만삭 배, 合掌으로 허리 굽힘 = 女·陰·血, 有子·生
- 남자 발자국 2(짙은 청록, 무대 좌단, 발끝 중앙 향함) · 여자 발자국 2(붉음, 무대 우단, 발끝 중앙 향함) = 左右·道路, 赤=血
- 둥근 거울(또는 물그릇) 1, 두 사람 사이 한복판 바닥 = 應象·反照·水
- 둘 다 흰 버선+짚신(정상 발)

② 표제어
- 1순위 **素問·陰陽應象大論** — 「天地者 萬物之上下也, 陰陽者 血氣之男女也, 左右者 陰陽之道路也, 水火者 陰陽之徵兆也」(+「變化之父母·生殺之本始」: 잉태=生·父母, 추수 들판=殺) **45%**
- 2순위 **難經 19難 男女脈** — 男脈在關上(큰 머리·상투)·女脈在關下(만삭 배=尺脈恒盛), 거울=反(男得女脈·女得男脈), 左得之病在左·右得之病在右(발자국), 靑옷=寅木·가을=申金 **25%**
- 기타: 陰陽別論 「陰搏陽別 謂之有子」 10% · 脈經 태맥 左男右女 10%

③ 뜻 모를 것·어색·잘림
- 火가 없음(水火 짝 불완전) · 초승달의 역할(陰 분위기? 月事? 申月?) · 남자 머리 과장·높은 이마 · 두 사람의 절이 무슨 동사인지(應? 順? 反?) · 발자국이 바깥→중앙으로 수렴하는 방향 · 병풍 4폭씩이 개수 정보인지
- 프레임: 좌·우·아래 가장자리의 구름만 잘림, 핵심 소품 잘림 없음

## 2단계 — 계통 (사전요약 적용 후)

사전 어휘로 다시 읽음: 붉은 발자국 = **血**(붉은 것) 확정 → 여인 = 血. 상투 = **上**(머리 꼭대기로 곧게 솟음) → 남자 = 上. 만삭 배 = **實**(팽팽하게 찬 것)에 가까움. 바닥 원반은 '거울'이 아니라 **陰**(고인 물) 또는 **淸**(맑은 물 한 그릇)으로 읽히고, 자리가 **中**(둘 사이의 한복판). 흰 구름(좌 병풍·무대 밑) = **氣**(서린 흰 김) 가능 → 남자 = 氣. 남자 머리가 여자의 두 배 = **大**. 짙은 청록 발자국은 사전상 **厥**(검푸르게 언 손발 끝)로 오독될 수 있으나 실제 발은 멀쩡한 버선발이라 '자취(道路)'로 판정. 병풍은 사전의 惡(가리개)와 겹치나 막는 해로운 것이 없어 天·地 배경(신규 기호)으로 판정. 해·불(陽)이 없는 밤 — 陽이 자리를 비움.

① 재판독
- 天(하늘 병풍)+上(상투) / 地(들판 병풍)+下(처진 배·바닥의 붉은 자취) → 「天地者 萬物之上下也」
- 남=氣(흰 구름)·여=血(붉은 발자국) → 「陰陽者 血氣之男女也」
- 좌·우 발자국 = 道路 → 「左右者 陰陽之道路也」
- 中의 고인 물 = 水(陰) → 「水火者 陰陽之徵兆也」(火 결손)
- 서로 절함 = 應, 물면에 비침 = 象 → 편명 陰陽應象

② 표제어
- 1순위 **素問·陰陽應象大論**(위 4구 + 變化之父母·生殺之本始) **50%** — 사전이 血·上·氣·中을 뒷받침하여 소폭 상승
- 2순위 **素問·厥論 寒厥·熱厥** — 청록 자취=寒厥(從五指而上於膝), 붉은 자취=熱厥(起於足下), 두 병풍=春夏/秋冬, 고인 물=陰氣獨在·精氣溢下, 부른 배=飽, 밤·남녀=入房 **20%**
- 기타: 陰陽別論 「陰搏陽別 謂之有子」(陰=고인 물, 陽 부재=別, 만삭=有子) 15% · 難經 19難 10%(거울이 '물'로 읽혀 反 근거 약화, 하락)

③ 잔결
- 火 부재 · 남자 발자국이 氣(흰 김)가 아니라 청록인 점 · 달의 역할 · 절의 동사(應/順/反) 미확정 · 만삭이 父母·生인지 實·飽인지 · 병풍이 惡(가리개)로 오독될 여지
- 프레임 잘림: 1단계와 동일(가장자리 구름만)
