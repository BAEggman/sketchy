# 032 판독 v2 (생판 → 계통)

## 1단계 — 생판 (그림만)

① 소품 전수 → 사실
- 왼쪽 4폭 병풍 = 낮 하늘·흰 구름 → 天(積陽爲天·淸陽爲天)
- 오른쪽 4폭 병풍 = 가을 황금 들판·언덕·길 → 地(積陰爲地·濁陰爲地), 秋·收
- 청록 도포·상투·큰 이마 남자, 공수(拱手)로 읍 → 男=陽=天(天玄), 氣
- 황토 옷 임신부, 합장으로 읍 → 女=陰=地(地黃), 血, 陰成形·有子
- 둘이 마주 절(교배) → 陰陽 交感·和(陰陽和 故能有子)
- 바닥 한복판 둥근 거울(또는 물 쟁반) → 象(應象) 또는 水(水火者 陰陽之徵兆)
- 왼쪽 초록 발자국(안쪽 향함) → 左=陽의 길, 氣 / 오른쪽 붉은 발자국 → 右=陰의 길, 血 (左右者 陰陽之道路也·血氣之男女也)
- 밤하늘 초승달·별 → 月=陰, 夜 / 구름 위의 무대 → 天上·雲
- 흰 버선 → 足

② 표제어: 1순위 **陰陽應象大論 총론(天地·男女·左右·水火)** 40% / 2순위 **上古天眞論 天癸·陰陽和 故能有子** 25%

③ 뜻 모를 것: 거울인지 물 쟁반인지, 발자국이 왜 초록·붉음인지(氣·血 추정), 병풍은 낮인데 배경은 밤인 이유, 남자 머리(이마)의 과장. 프레임: 아래쪽 구름 잘림, 왼쪽 위 초록 발자국 번짐(이중 흔적), 붉은 발자국이 병풍 다리께에 걸림. 글자 없음.

## 2단계 — 계통 (사전 적용)

① 재판독
- 사전 끝 항목 「八卦 = 4폭+4폭 병풍 무대(마주 본 두 폭이 한 쌍)」이 이 그림 무대 그대로 → 이 판은 八卦 판. 왼쪽 4폭=하늘=乾 쪽, 오른쪽 4폭=땅=坤 쪽이 마주봄 → 天地定位(乾坤 한 쌍)
- 큰 머리 남자 = 乾爲天·爲父·爲首(說卦傳) / 배 부른 여자 = 坤爲地·爲母·爲腹 → 乾坤=父母, 임신=六子(震巽坎離艮兌)를 낳을 母
- 색: 남자 짙은 청록·밤하늘=天玄, 여자 황토·들판=地黃 → 天玄地黃
- 거울 = 「中 = 둘 사이의 한복판」 표지 → 八卦 한가운데 太極(또는 中男·中女 坎離 자리); 달을 비추는 물이면 坎(水·月)
- 붉은 발자국 = 「血 = 붉은 것」 → 坤(女)=血 / 초록 발자국은 사전 무등재(氣는 흰 김이므로 氣 아님) → 震爲足·蒼(長男)일 가능성
- 사전상 陰=얼음·陽=해불이 없으므로 이 판은 陰陽 기호판이 아니라 乾坤 기호판
- 「會 = 담는 것 안에 담긴 것」이 임신 배에 겹칠 수 있음(母 속의 子)

② 표제어: 1순위 **八卦 — 乾坤(天地定位: 乾=天·父·首, 坤=地·母·腹)** 55% / 2순위 **陰陽應象大論 총론(天地·血氣之男女·左右道路)** 20%

③ 잔결: 발자국 두 색의 확정 의미(震/坎인지 氣/血인지), 거울이 太極인지 坎(水·月)인지, 초승달의 전담 사실, 각 폭이 개별 괘를 나르는지(두 병풍 모두 단일 풍경이라 폭별 구분 불가). 프레임 잘림은 1단계와 같음.
