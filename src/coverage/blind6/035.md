# blind6 / 035 판독

## 1단계 — 생판 (그림만)

**① 소품 전수와 나르는 사실**
1. 검정 잠수복·후드·고글·오리발의 잠수부 1명(정중앙, 두 손을 좌우로 벌림) — 검정·물 → 水/北方/腎, 또는 「潛(잠수)」·玄武 후보. 좌우 손이 각각 寒·熱을 들어 대비 구조.
2. 왼손: 서리·고드름이 낀 얼음 사발 1개(깊은 사발, 오른쪽 접시보다 약 1.3배 큼) — 寒·陰(滋陰·凉).
3. 사발 속 흰 액체(우유·쌀뜨물·소금물?) — 冷服 또는 淡鹽湯 송하(?), 뜻 불명.
4. 사발 속 붉은 환약 6알(3+3, 절취선) — 六味.
5. 사발에 꽂힌 검붉은 뿌리 1개(길이 ≈ 환약 지름의 3배, 끝에 잔뿌리 3가닥) — 地黃(君藥 熟地黃 8兩) 또는 知母·人蔘 후보.
6. 오른손: 얕은 붉은 접시 1개 위 붉은 환약 6알(3+3) — 왼쪽과 동일한 六味 기본방.
7. 끈으로 묶은 계피 묶음 1다발(6~7가닥, 껍질 말린 끝) — 桂枝/肉桂.
8. 회색 각진 돌덩이 1개(계피 묶음과 같은 크기) — 附子(炮附子 검회색 덩이) 또는 광물약(石膏·牡蠣·磁石).
9. 불꽃 1개(접시 높이와 같음) — 熱·陽(溫補腎陽·命門火). 오른쪽 6+2 = 8 → 八味.
10. 흰 김 3가닥(불꽃의 2배 높이로 솟음) — 氣(少火生氣·氣化) 또는 蒸(炮製).
11. 연두색 빈 방 — 무대 배경(靑? 뜻 불명).

**② 표제어**
- 1순위 **八味地黃丸(金匱腎氣丸) ↔ 六味地黃丸 대비(腎陽虛·腎陰虛 처방)** — 45%
- 2순위 **腎 = 水火之宅(眞陰·眞陽)·命門(難經36難 左腎右命門)** 藏象 — 25%
- 3순위 白虎·眞武·朱雀·靑龍 四神方 / 生地黃(寒)·熟地黃(蒸) 炮製 대비 — 10%

**③ 불명·어색·잘림**
- 회색 돌 정체(附子인지 광물약인지) 불명. 흰 액체 의미 불명. 뿌리가 왼쪽에만 있는 이유 불명. 잠수부 자체가 腎인지 潛·玄武인지 확정 못 함. 오리발 아래끝이 프레임 하단에 살짝 잘림. 연두색 벽 뜻 없음.

## 2단계 — 계통 (사전 어휘로 재판독)

**① 소품 재판독**
- 잠수부 = **腎**(사전 확정: 검은 잠수복·후드·고글). 무대 주인공은 장부 腎이고, 두 손이 腎의 두 면을 듦.
- 왼손 얼음 사발 + 고인 흰 물 = **陰**(사전: 얼음 덩이·고인 물) → 腎陰. 검붉은 뿌리 = **地黃**(사전 확정) → 地黃丸의 이름표·君藥 熟地黃. 붉은 환 6알 = 六味(사전상 血=붉은 것이나 알약 형태·개수 6이 우선) → **六味地黃丸(滋補腎陰)**.
- 오른손 불꽃 = **熱/陽**(사전) → 腎陽·命門火. 흰 김 3가닥 = **氣**(사전: 서린 흰 김) → 腎 + 氣 = **腎氣丸** 이름 자체·少火生氣. 동일 환 6알 + 계피 묶음(桂枝, 신규) + 회색 돌(附子 추정, 신규) = 6+2 = **八味地黃丸(金匱腎氣丸, 溫補腎陽)**.
- 구조: 六味 기본 6알이 양쪽에 똑같이 놓여 「八味 = 六味 + 桂·附」(錢乙이 桂附를 빼 六味를 만든 계보)를 한눈에 나름. 사전의 淸(맑고 찬 물 한 그릇)·補(찰랑 찬 국물)와도 왼쪽 사발이 겹치나, 얼음이 있으므로 陰이 주 기호.

**② 표제어**
- 1순위 **六味地黃丸(補腎陰) ↔ 八味地黃丸=金匱腎氣丸(溫補腎陽) 대비 — 腎陰虛·腎陽虛 처방 짝** — 60%
- 2순위 **腎 — 水火之宅·眞陰眞陽 / 腎陽 氣化(腎氣)** 藏象 개념판 — 20%
- 3순위 左歸丸·右歸丸(좌우손 대비) — 10%

**③ 잔결**
- 회색 돌은 사전에 없어 附子로 추정할 뿐(痰=회백 덩이와 혼동 여지). 흰 액체(淡鹽湯 송하? 우유=小兒 錢乙?) 여전히 불명. 地黃 뿌리가 왼쪽에만 있어 오른쪽도 地黃丸임은 6알 동일성으로만 추론. 오리발 하단 살짝 잘림. 1단계 판정과 큰 방향은 같으나 잠수부=腎·뿌리=地黃·김=氣가 사전으로 확정되어 확신도 상승.
