# 036 판독 기록 (생판 → 계통)

## 1단계 — 생판 (그림만)

**① 소품 전수·나르는 사실**
- 상투 튼 사내 3명 = 혈(血) 병리의 세 환자, 왼→오른쪽 순서로 셋.
- 좌: 바닥이 드러난 마른 개울 — 회색 돌멩이 약 15개 사이로 실처럼 가는 연붉은 물 = 血이 부족해 강바닥이 드러남(血虛). 오른손으로 왼손목을 잡고 문지름 + 손가락 둘레 떨림선 = 手足麻木·震顫(血不榮筋). 처진 표정 = 피로·面色不華.
- 중: 유일하게 황토색 저고리·회색 바지, 얼굴 찡그리고 어깨를 움켜쥠 = 刺痛·固定痛. 어깨 위 회색 돌덩이 1개에서 피가 뚝뚝 = 腫塊(癥積)·瘀血. 발밑 개울은 상류가 검고 검은 핏덩이 1개 = 血色紫黯·血塊.
- 우: 넓게 퍼진 핏물 웅덩이(좌측 개울 폭의 약 2배) + 피 분수 1개가 위로 솟고 그 위에 흰 김·거품 = 迫血妄行(끓어 넘침). 청동 대야 1개에 선홍색 피가 찰랑 = 出血·血色鮮紅. 표정 평온·정지 자세.

**② 표제어**
- 1순위 **血의 病理 3종 — 血虛·血瘀·血熱(妄行→出血)** 70%
- 2순위 **出血의 3대 病機(氣不攝血·瘀血阻絡·血熱妄行)** 15% / 3순위 血病辨證(血虛證·血瘀證·血熱證, 血寒證 결) 10%

**③ 뜻 모를 것·어색·잘림**
- 중간 인물만 황토색 옷 — 색 대비의 의미 불명. 우측 인물이 열증인데 얼굴 붉음·땀 없이 평온함. 좌측 손동작이 '저림'인지 '추워서 비빔(血寒)'인지 모호. 분수 위 흰 거품이 열기인지 단순 물보라인지 불명. 프레임 잘림 없음.

## 2단계 — 계통 (사전 어휘로 재판독)

**① 사전으로 다시 읽기**
- 血 = 붉은 것 → 세 개울 모두 血. 虛 = 삼분의 일로 줄어든 것 → 좌측의 실개울(우측 웅덩이의 1/3 이하) = **血虛** 확정. 瘀 = 검붉게 굳은 덩이 → 중간 개울의 검은 핏덩이 = **血瘀** 확정. 盛 = 넘쳐 흘러나오는 것 → 우측의 넘쳐 퍼진 웅덩이·솟는 분수 = 血이 경맥 밖으로 넘침 = **出血(離經之血)**, 대야에 담긴 선홍혈 = 밖으로 나온 피(會=담긴 것 아님, 단순 수집).
- 熱 = 불꽃인데 우측에 불꽃이 없음 → 1단계의 '血熱' 판정은 사전상 근거 약함. 우측 분수 위 흰 김은 사전상 氣(서린 흰 김)와 충돌 — 氣隨血脫로도 읽히나 좌·중에 氣 기호가 없어 전체 축은 氣血관계가 아니라 血 단독 축.
- 痛 = 쇠못이어야 하나 중간 인물 어깨는 돌덩이 → 痛보다 腫塊(固定不移의 덩어리)로 읽음. 厥(검푸른 손끝)이 아니므로 좌측 손은 血寒이 아니라 麻木.

**② 표제어**
- 1순위 **血의 失常 3종 — 血虛·血瘀·出血(우측에 血熱이 겹쳐 있을 수 있음)** 60%
- 2순위 **血病辨證 — 血虛·血瘀·血熱妄行** 25% / 3순위 氣隨血脫(흰 김=氣) 5%

**③ 잔결**
- 우측의 흰 김이 '끓음(熱)'인지 '氣'인지 사전상 결정 불가 — 불꽃이 없어 熱 표기 결손. 중간 인물의 황토색 옷·어깨 돌덩이는 사전 미등재. 좌측 손 떨림선은 麻木/震顫 어느 쪽인지 기호가 없음. 프레임 잘림 없음.
