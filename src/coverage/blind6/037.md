# blind6 037 판독 기록 (2026-09-02)

## 1단계 — 생판 (그림만)

**① 소품 전수·사실**
- 인물 2: 왼쪽 청록 저고리, 바로 서서 평온 / 오른쪽 황토 저고리, 허리 굽혀 두 손으로 배를 감싸고 눈감고 찡그림, 콧구멍 둘에서 맑은 콧물 두 줄기가 입술 아래까지 흐름(확대로 콧구멍 기원 확인).
- 불 2: 왼쪽 큰 불(사람 키의 약 절반, 장작 3) / 오른쪽 작은 불(장작 2) — 약 3배 차.
- 얼음 2: 오른쪽 큰 얼음기둥 / 왼쪽 작은 얼음 한 조각 — 약 3배 차. 각 쌍은 큰 것 발치에 작은 반대 원소가 교차로 붙음.
- 붉은 질항아리 1(노란 탁한 액체 2/3) = 小便短黃. 나무 대접 1의 갈라진 갈색 덩이 1 = 大便乾結. 모두 맨발·상투.
- 축: 왼쪽 = 큰 불+작은 얼음 = 陽盛(陰 부족) → 熱 → 二便 熱象 / 오른쪽 = 큰 얼음+작은 불 = 陰盛(陽 부족) → 寒 → 分泌物 清稀(鼻流清涕)·腹痛·蜷縮(寒主收引).

**② 표제어**
- 1순위 **八綱 寒熱辨證(寒證 vs 熱證 감별)** 50%
- 2순위 **陰陽偏盛 病機(陽盛則熱·陰盛則寒, 素問·陰陽應象大論)** 25%
- 3순위 治則 寒者熱之·熱者寒之(발치의 작은 반대 원소를 '약'으로 읽을 경우) 10%

**③ 뜻 모를·어색·잘림**
- 왼쪽 인물이 熱證인데 面赤·汗·口渴 등 몸의 표지가 전혀 없고 평온 — 열상이 二便 소품에만 실림.
- 옷 색이 거꾸로(熱쪽 청록, 寒쪽 황토). 갈색 덩이가 大便인지 흙덩이·떡인지 모호. 콧물이 언뜻 입에서 흐르는 침처럼 보임.
- 발치의 작은 원소가 '남은 것'인지 '치료약'인지 미정. 프레임 잘림 없음.

## 2단계 — 계통 (사전 반영)

사전 재독: 얼음 덩이 = 陰(寒의 정식 부호 눈송이는 없음), 불 = 陽/熱, 虛 = 삼분의 일로 줄어든 것, 燥 = 갈라진 땅, 小便 = 요강, 大便 = 손잡이 뒷간통(없음), 痛 = 쇠못(없음), 內/外 = 담(없음), 盛 = 넘침·實 = 팽팽(둘 다 없음).

**① 소품 재판독**
- 두 불·두 얼음은 '같은 것 둘이 나란한데 하나가 약 3배' → 작은 쪽이 虛. 왼쪽 = 陽(큰 불) + 陰虛(얼음 1/3) → 熱 / 오른쪽 = 陰(큰 얼음) + 陽虛(불 1/3) → 寒. 눈송이가 없으므로 축은 寒熱 자체가 아니라 陰陽의 盛衰.
- 노란 액체 항아리 = 요강 = 小便黃(熱) [대안: '졸아드는 고인 물' = 陰虛 중복 부호].
- 나무 대접의 갈라진 덩이 = 燥(갈라진 땅) → 陰虛·熱 → 燥 [뒷간통이 아니므로 大便乾結보다 燥 우선].
- 맑은 콧물 = 津이 맑게 새어 나옴 → 水液 澄澈清冷 → 寒(陽虛). 배를 감싼 굽은 자세 = 寒의 收引(못이 없어 痛 부호는 아님).

**② 표제어**
- 1순위 **陰陽失調 — 陰陽偏盛偏衰(陽盛陰虛則熱·陰盛陽虛則寒)** 45%
- 2순위 **八綱 寒熱辨證(熱證: 小便黃·燥 / 寒證: 清涕·腹痛蜷縮)** 30%
- 3순위 素問·調經論 「陽虛則外寒, 陰虛則內熱」 10% (內外를 나르는 담이 없어 감점)

**③ 잔결**
- 큰 불·큰 얼음이 盛(넘침)·實(팽팽)의 정식 부호가 아니어서 '偏盛'인지 단순 정상 대비인지 미정 → 偏盛과 偏衰 중 어느 쪽이 표제인지 확정 불가.
- 왼쪽 인물의 몸 표지 부재는 그대로. 갈색 덩이(燥 vs 大便) 이중 해석. 항아리가 정식 요강 모양인지 애매. 프레임 잘림 없음.
