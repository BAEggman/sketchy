# 038 판독 기록

## 1단계 — 생판 (그림만, 사전 없이)

### ① 소품 전수 · 나르는 사실
- 은색 리벳 천막 4동이 좌→우 한 줄(군영 무대). 천막마다 빈 간판 1, 사이·끝에 흰 깃발 3.
- 천막1: 굴뚝 5개에 불꽃 5 + 앞마당 큰 불(소방관 키의 약 2배). 빨간 헬멧 소방관이 돌우물에서 호스로 물을 뿌림 → 壯熱을 찬물로 끔(淸熱), 돌우물=石(石膏?)·渴.
- 천막2: 창에서 한 사람이 파란 옷·노란 새·그릇·상자를 밖으로 내던지고, 아래서 한 사람이 빗자루로 쓸어 먼지구름 → 밖으로 내보냄(發散·汗)·청소(淸).
- 천막3: 낮은 흙담이 둘러싼 진영, 지붕 위 풀 돋음, 담 안 화덕(속불)에서 여인이 빵을 굽고 광주리 2 → 담으로 둘린 營, 갇힌 열, 지붕 풀=隱隱한 斑疹.
- 천막4: 밤하늘(초승달·별), 붉은 두건 여인이 촛불 들고 문 앞, 문에서 붉은 물줄기가 흘러나옴 → 夜甚·不寐(촛불)·動血(출혈).
- 중앙 4갈래 이정표 = 네 단계(分). 분홍 화살표가 천막3 아래에서 왼쪽(천막2 쪽)으로 = 속의 열을 바깥 단계로 되돌림(透熱轉氣).
- 우하 개울가 책상의 학자: 손에 잎 달린 풀가지, 옆에 빈 격자판(표) → 잎=葉天士, 격자=溫熱論 조문.

### ② 표제어
- 1순위 **衛氣營血辨證(葉天士 溫熱論 — 在衛汗之·到氣淸氣·入營透熱轉氣·入血涼血散血)** 60%
- 2순위 **四氣調神(봄 發陳·여름·가을·겨울 閉藏 四時 양생)** 15% / 熱入血室 5%

### ③ 뜻 모름 · 어색 · 잘림
- 좌→우 순서가 氣(불)·衛(내던짐)인지 衛·氣인지 어긋남. 굴뚝 불꽃 5개, 흰 깃발 3, 빈 간판 4, 빵·광주리·돌우물의 약재 대응, 분홍 화살표의 깃털 무늬 모두 불명. 우측 학자·표지판·개울이 프레임에 잘림.

## 2단계 — 계통 (사전 적용 후)

### ① 소품 재판독
- 사전 直讀: 熱=불꽃, 淸=맑고 찬 물, 瀉=짚 빗자루, 散=사방으로 흩어져 날리는 것, 下=아래로 쏟아짐, 內=담 안쪽, 血=붉은 것, **李=허리춤 자두, 張=등에 멘 긴 활**. 확대해 보니 천막3 여인 허리춤에 보라 자두 2알, 책상 학자 등에 긴 활+화살통이 분명.
- 무대: 쇠(金) 천막(유목 元) 군영 = **金元**. 4갈래 이정표 = 네 갈래 학파.
- 천막1 **劉完素 寒涼派**: 굴뚝 불꽃 5 = 五志過極皆爲熱, 큰 불(2배) = 火熱論(六氣皆從火化), 돌우물 찬물 호스 = 寒涼藥으로 淸熱.
- 천막2 **張從正 攻邪派 汗吐下**: 창밖으로 내던짐 = 吐, 흩날리는 옷·새 = 散(汗), 떨어지는 상자·짚 빗자루 = 下·瀉. 邪去則正安.
- 천막3 **李杲 補土派**: 자두 = 李, 흙담 = 土·담 안쪽 = 內傷(脾胃論), 화덕·빵 = 脾胃 甘溫補中, 지붕 위 돋는 풀 = 升陽(升麻·柴胡).
- 천막4 **朱震亨 養陰派**: 붉은 옷 = 朱, 문 앞 붉은 개울 = 丹溪, 밤·초승달(차지 않은 달) = 陰常不足, 어둠 속 촛불 = 相火(陽常有餘·相火妄動).
- 우하 **張元素 易水學派**: 활 = 張, 개울 = 易水, 격자판 = 臟腑用藥·藥類法象 표, 손의 약초 = 歸經·引經報使. 분홍 화살(張의 화살)이 천막3 李杲로 날아감 = 師承(李杲는 張元素 제자).

### ② 표제어
- 1순위 **金元四大家(劉完素·張從正·李杲·朱震亨) + 張元素 易水學派 師承** 85%
- 2순위 **衛氣營血辨證** 5% (1단계 판독은 철회 — 李·張 기호가 결정적)

### ③ 잔결 · 어색 · 잘림
- 흰 깃발 3, 빈 간판 4, 천막3 앞 검붉은 열매 광주리·담 위 광주리, 천막2 창의 노란 새, 천막1 돌우물(河間?)의 뜻 미확정. 천막2 문 옆 긴 막대가 활(張)인지 불명. 우측 책상 옆 표지판·개울이 프레임에 잘림.
