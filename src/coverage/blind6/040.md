# 040 판독 기록 (blind6)

## 1단계 — 생판 (그림만, 사전 없이)

**① 소품 전수와 나르는 사실**
- 벽돌 부뚜막의 불꽃(장작 3개) + 세발 가마솥 위 시루, 흰 떡 8~9개, 흰 김이 솥 높이의 3~4배로 천장까지 곧게 솟음 → 불=命門火/火熱, 따뜻함=溫補, 물→김=氣化. 8개면 八味丸.
- 등에 긴 활을 멘 남자, 눈 크게 뜨고 입 벌려 놀람, 지게에 책 두 더미(좌 7·우 6권쯤) → 弓=張, 놀람(驚)=景, 책산=岳/全書.
- 도포 선비가 3층 장(위 빈 선반·가운데 고리문·아래 칸)을 들어 옮김 → 분류(綱目/類經)·摘要?
- 앞치마 장인, 창문 바로 아래서 긴 판자에 칼로 홈 파기, 옆 바구니 자두 12개쯤+송이 4알, 붓통·망치·끌·나무쐐기·돗자리 → 자두=李, 木+日=杲 / 긴 목재=梴 / 판각=梓.
- 색동저고리·붉은 바지 아이, 물총의 붉은 물줄기가 바닥의 검은 구슬 1개를 맞힘(물방울) → 아이=孫, 赤水+玄珠.
- 문 밖 초록 저고리 여인(이마 땀 1방울), 노란 판자 X로 문 봉쇄, 뒤 벽돌담 → 陰·外·女科?, X=非/禁.
- 항아리 3(큰 것 1·중 1·작은 것 1, 짚단·막대다발 꽂힘), 바닥 책 3권 포갬, 국자·바가지, 뚜껑솥, 찜판 2단.

**② 표제어**
1순위 **明代 溫補學派·命門說(薛己·孫一奎·趙獻可·張景岳·李中梓)** 40% / 2순위 **金元四大家(劉完素·張從正·李東垣·朱丹溪)** 25% / 3순위 張仲景 傷寒·金匱 전승사(金匱=장, 湯液=솥, 판각=校正醫書局) 12%.

**③ 뜻 모를 것·어색·잘림**
빈 장을 왜 드는지, 노란 X의 뜻, 여인 정체, 항아리 3·책 3권의 수, 부엌 잡기(국자·바가지·뚜껑솥·찜판), 망치·끌·쐐기. 잘림: 우측 항아리·문틀, 좌하 멍석, 좌상 굴뚝, 하단 독들.

## 2단계 — 계통 (사전 적용 후)

**사전으로 다시 읽은 어휘**: 활=張(확정), 자두=李(확정), 흰 김=氣, 불꽃=熱, 곧게 솟음=上, 넘침=盛, 회백색 덩이=痰(시루 떡), 셋 포갬=久(책 3권), 3층장 가운데=官(선비), 문 밖·담 밖=表·外(여인), 땀방울=汗(여인·활남자), 막은 가리개=惡(노란 X), 막힌 문틈으로 밀려나감=格(여인), 짚 빗자루=瀉(항아리 짚단), 붉은 것=血(물줄기), 검붉은 덩이=瘀(검은 구슬), 쏟아짐=下(물줄기), 졸아드는 물=陰(구슬 옆 물방울), 크게 뜬 눈=目, 큰 입=吳(활남자 입—張과 충돌).

**① 다시 읽은 사실**
- 활 남자 = **張從正**: 놀람=驚者平之, 땀(汗)·벌린 입(吐)·짚빗자루(瀉下)/물줄기 下 = 汗吐下 三法, 책더미=儒門事親, 문 밖으로 밀려난 여인(格·惡·表)=邪去則正安.
- 부엌 = **劉完素**: 불(熱)에서 흰 김(氣)이 곧게 솟음=六氣皆從火化, 흰 떡=素.
- 자두 장인 = **李東垣**: 창(日)+판자(木)=杲, 흙벽 곁 판자 수리=補土, 집 안(內)의 깨진 판(傷)↔밖 여인(外)=內外傷辨惑論.
- 붉은 아이 = **朱丹溪**: 붉은 물줄기=丹溪, 큰 불·넘치는 김(盛)=陽有餘, 졸아든 물방울=陰不足; 떡=痰論.
- 선비+官장 = 미상(儒門의 儒/太醫 벼슬/張元素).

**② 표제어**
1순위 **金元四大家(劉完素·張從正·李東垣·朱丹溪)** 45% / 2순위 **張從正 攻下派(汗吐下·儒門事親·驚者平之)** 20% / 3순위 溫補學派 15%. 1단계 1순위는 '놀람=景'이라는 음차에 기댔는데 사전은 뜻그림 체계라 철회.

**③ 잔결**
선비와 3층장(官)의 주인, 검은 구슬(瘀인지 玄珠인지), 활남자의 큰 입(吳로 오독 위험), 책 3권(久인지 三法인지), 항아리 3과 막대다발, 국자·바가지·뚜껑솥·찜판, 망치·끌·쐐기. 잘림은 1단계와 같음.
