# 042 판독 기록

## 1단계 — 생판 (그림만)

① 소품 전수
- 잿빛 빈 방(벽 3면·문·창 없음) 안에 나무 긴의자 1개(다리 4). 앉은 사람 3 + 무릎 꿇은 사람 1 = 4인, 전원 회색 옷·상투·맨발(발 8).
- 좌: 살찐 남자, 얼굴이 종잇장처럼 희고 볼이 팽팽히 부풂, 눈은 실눈 → 面色㿠白·肥白·氣脹(氣虛/痰濕/氣).
- 중: 마른 창백한 여인(몸통 폭이 양옆 남자의 1/2~1/3), 흰 천 1장에 붉은 핏자국 1덩이(주변 잔방울 3~4)를 아랫배 앞에 펴 보임, 눈은 뜸 → 出血(咳血 또는 經血·漏下)·失血·血.
- 우: 살찐 남자, 살빛이 누렇고 번들거림, 입술 청록, 눈 감음 → 面黃·汗/水·唇青·目瞑(浮腫·亡陽·瘀血·津液).
- 앞: 등 돌리고 정좌한 젊은이 — 셋을 살피는 의사(望診)·심판.

② 표제어
- 1순위 **氣·血·津液(氣血水) 辨證** — 좌 氣, 중 血, 우 水. 35%
- 2순위 **血證(失血)의 病機** — 氣不攝血(白胖)·出血(中)·瘀血/亡陽(唇青·汗). 25%
- 3순위 **虛勞(金匱)** — 「面色白·時目瞑·兼衄」「婦人半產漏下」. 15%

③ 어색·잘림: 두 남자가 왜 살쪘는지, 왼쪽의 부푼 볼, 오른쪽의 청록 입술·감은 눈의 뜻, 핏자국 출처(咳血/經血), 무릎 꿇은 이의 정체, 처방·약재 소품 전무. 무릎 꿇은 이의 발이 아래 테두리에 닿아 살짝 잘림, 오른벽이 프레임 밖으로 이어짐.

## 2단계 — 계통 (사전 어휘로 재판독)

① 소품 재판독
- 붉은 핏자국 = **血**(그림에서 유일한 붉은 것). 
- 가운데 마른 여인 = **虛**(같은 것 셋 중 1/3로 줄어든 것) + **中**(셋 중 가운데) → 血을 든 虛한 이 = **血虛**.
- 오른쪽 이마·광대·콧대의 광택 = **面** → 面+누런 살빛 = 面色萎黃. 왼쪽 흰 얼굴 = 面色淡白. 두 얼굴빛이 血虛의 대표 面色 두 가지.
- 양옆 팽팽히 찬 남자 둘 = **實**(팽팽하게 찬 것) — 虛(중)와 實(좌우)의 대비. 부푼 살 = 肌.
- 여인만 눈을 뜸 = **目**(血虛의 目眩·眼花 자리?). 청록 입술 = 唇淡 의도로 보이나 미등재(厥은 손발 끝이므로 아님). 벽 안 = 內/裏(약). 氣(흰 김)·津(물방울)·汗(땀방울) 기호는 없음 → 1단계 氣血水 읽기 철회.

② 표제어
- 1순위 **血虛** — 血+虛 직접 기호, 좌우 淡白·萎黃 面色. 50%
- 2순위 **虛實 辨證(八綱)** — 實 둘 사이의 虛, 심판이 가림. 20%
- 3순위 **血證·亡血** 15%

③ 잔결: 남자 둘의 비만·부푼 볼이 實인지 腫·肌인지 불명, 청록 입술과 감은 눈의 코드 부재, 핏자국의 출처(經血 量少면 血虛 의도), 무릎 꿇은 이의 역할(의사=독자 대역 추정), 하단 발·오른벽 잘림.
