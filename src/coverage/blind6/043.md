# blind6 / 043 판독 기록

## 1단계 — 생판(그림만)

① 소품 전수·나르는 사실
- 왼쪽 큰 가시덤불(사람 키와 같은 높이, 왼쪽 프레임에 잘림, 가시 무수): 木/肝 소속물 또는 급박·얽힘(急·鬱)·실(實). 성난 남자의 왼손이 이것을 움켜쥠 → 肝「在變動爲握」.
- 청록 옷 남자, 상투, 입 크게 벌려 고함, 찡그린 눈: 蒼色+呼+怒 = 肝(木)의 色·聲·志.
- 오른손에 곧추 든 짚·대 빗자루(키의 2/3): 散/疏/除(쓸어냄).
- 한복판 장대에 걸린 글자 없는 흰 천 깃발(바람 없이 축 늘어짐): 白=金/肺 또는 표제 빈자리.
- 회색 저고리+붉은 띠·붉은 바지 남자, 눈꺼풀 처지고 입꼬리 내려간 슬픈 얼굴: 悲/憂(肺, 붉은색은 心 혼입).
- 그 왼손의 가시잎 가지(엉겅퀴꼴) 1 + 발치에 떨어진 같은 가지 1 = 2개: 薊(大薊·小薊)?·刺·辛?
- 오른쪽 위에서 들어온 국자(손잡이 프레임 밖)가 황금색 걸쭉한 액체를 작은 사발에 쏟고, 사발이 넘쳐 땅에 흐름: 蜜/膏=甘·補, 넘침=溢·過.
- 두 사람 모두 맨발, 흙바닥, 장대 밑 풀.

② 표제어
- 1순위 **肝(木)의 五行 배속 계통 — 素問·陰陽應象大論 東方 단락(在聲爲呼·在變動爲握·在志爲怒, 怒傷肝·悲勝怒)** 40% : 고함(呼)+움켜쥠(握)+성냄(怒)의 청록 남자 = 肝, 슬픈 남자 = 悲勝怒.
- 2순위 **素問·藏氣法時論 肝條 — 肝苦急 急食甘以緩之 / 肝欲散 急食辛以散之** 30% : 얽힌 가시=急, 꿀=甘, 처진 남자=緩, 빗자루=散, 가시잎=辛.
- 3순위 虛實補瀉(實則瀉之·虛則補之) 15%.

③ 뜻 모를 것·어색·잘림: 빈 흰 깃발의 뜻, 엉겅퀴 가지 2개(왜 하나는 땅에), 슬픈 남자의 붉은 띠·바지(心 색이 왜 섞였나), 사발이 넘치는 이유. 잘림: 국자 손잡이(우상단 밖, 붓는 주체 없음), 가시덤불 왼쪽 가장자리.

## 2단계 — 계통(사전 어휘로 재독)

① 등재 기호로 확정되는 것
- 짚 빗자루 = **瀉**(확정). 국자로 쏟는 꿀 = **甘**(확정). 찰랑찰랑 찬 사발 = **補**, 넘쳐 흐름 = **盛**(둘 중 하나 또는 겹침). 두 사람 사이 한복판 장대 = **中**(둘 사이의 한복판) 가능. 쏟아짐 = 下 가능.
- 미등재(이 판이 새로 세우는 기호): 성내며 고함치는 남자 = 怒(呼), 축 처진 남자 = 悲/緩, 가시덤불 = 急·邪·實의 후보, 가시잎 가지 = 傷(부러진 것)·虛의 후보, 빈 흰 천 = 미확정. 肝(초록 갑옷 장군)·心(붉은 곤룡포)·脾(밀짚모자)는 없고 옷 색(청록·붉은 띠)만 남아 있어 인물은 장부 인격이 아니라 환자다. 氣(흰 김)·散(흩날림)·酸(매실)·辛(고추)이 없으므로 1단계의 「肝欲散·辛補酸瀉」 「怒則氣上」 계열은 탈락.

② 표제어(재판정)
- 1순위 **虛實·補瀉 — 實則瀉之(성내어 고함치는 實證 환자+가시덤불에 빗자루=瀉) / 虛則補之(처진 虛證 환자에 꿀로 채우는 사발=補), 靈樞·本神「肝(氣)實則怒 / 心(氣)虛則悲」 겸 素問·通評虛實論「邪氣盛則實, 精氣奪則虛」** 40% : 등재 기호 瀉·補가 양쪽에 정확히 하나씩 놓였고, 怒=實(청록=肝)·悲=虛(붉은 띠=心)로 감정까지 맞물림. 가시덤불=邪氣盛, 부러진 가지=精氣奪(傷).
- 2순위 **急↔緩 — 「肝苦急, 急食甘以緩之」(素問·藏氣法時論) = 甘緩** 25% : 급한 사람(고함·가시 얽힘)=急, 꿀(甘)을 붓자 느슨해진 사람=緩. 다만 瀉 빗자루가 남아 설명이 안 됨.
- 3순위 陰陽應象大論 怒傷肝·悲勝怒 15% (1단계 1순위에서 강등: 握·呼를 세우는 등재 기호가 없고 補瀉·甘이 설명되지 않음).

③ 잔결: 빈 흰 깃발(등재 없음, 표제 빈자리로 추정), 엉겅퀴 가지 2개의 정체(傷인지 薊인지 虛인지), 補와 盛이 한 사발에 겹친 모순(채움인지 넘침인지), 국자 손잡이 프레임 잘림.
