# 044 판독 기록

## 1단계 — 생판 (그림만)

**소품 전수와 나르는 사실**
- 이글거리는 해 1개(화면 위 한복판, 광선이 위 테두리에 닿음) → 여름 볕·暑熱.
- 사람 주위의 주황 불꽃형 아지랑이 약 7줄(머리 좌우·어깨 위·허리 왼쪽·오른 다리 옆) → 身熱·炎熱이 온몸 사방으로.
- 상투 튼 중년 남자 1명: 얼굴·가슴 붉음(面赤·胸紅), 눈 찡그리고 입 벌림(헐떡임·口渴), 가슴 풀어헤침(心煩·胸悶).
- 땀방울 수십 개(얼굴·목·가슴·팔), 손끝·소매·바짓단에서 떨어지는 물방울 7~8개 → 大汗·汗大泄.
- 나무 지팡이 1개에 몸을 기댐, 왼손은 배를 누름 → 乏力·無氣以動·脘腹 불편.
- 바지 무릎 기움질 2곳(+소매 1곳), 하반신에 진흙 → 濕이 아래에 붙음, 가난한 농부·길손.
- 발밑 물웅덩이 1곳, 진창길, 오른쪽 땅에서 오르는 흰 김 → 濕·濕熱 蒸騰.
- 초가집 1채·굽은 흙길·누런 잎 나무 1그루 → 시골·長夏, 日中에 밖에서 일하거나 걷는 사람.

**표제어**
- 1순위: **暑邪(六淫 暑의 성질·致病 특징 — 陽邪炎熱·升散·傷津耗氣·多挾濕)** 55%
- 2순위: **中暑·中熱(陽暑, 動而得之 — 行人·農夫가 日中勞役에 얻음, 汗大泄·無氣以動)** 25% (3순위 東垣 淸暑益氣湯證 10%)

**뜻 모름·어색·잘림**
- 누렇게 물든 나뭇잎이 계절(長夏) 표시인지 장식인지 불명. 오른쪽 흰 김이 濕蒸인지 다른 뜻인지 불명. 배를 누르는 손이 嘔惡·泄瀉를 뜻하는지 단순 탈진 자세인지 불명. 해 광선이 위 테두리, 나무가 왼 테두리, 초가가 오른 테두리에 닿아 살짝 잘림.

## 2단계 — 계통 (사전 어휘로 재판독)

**소품 재판독**
- 해 = 陽 → 暑爲陽邪. 주황 불꽃 약 7줄 = 熱, 머리 위로 솟고(上·升) 사방에 흩어짐(散) → 其性炎熱·升散.
- 살갗의 땀방울 = 汗(多汗); 손끝·소매에서 떨어지는 맑은 물방울 = 津이 새어 나감 → 傷津.
- 오른쪽에서 흩어져 날리는 흰 김 = 氣가 散하여 빠져나감 → 耗氣(氣隨汗泄). 지팡이는 사전 밖 자연기호로 乏力·氣虛를 보강.
- 진창길·진흙 묻은 하반신 = 外濕(진창 길) → 暑多挾濕; 濕이 아래에 붙어 몸이 무거움. 발밑 고인 물은 內濕 또는 '졸아드는 고인 물=陰'(傷陰)으로도 읽혀 애매.
- 벌린 어두운 입 = 口(口渴·口開), 광택 있는 붉은 얼굴 = 面赤. 초가·흙길·기운 옷은 사전 밖 배경으로 農夫·行人.
- 나무와 초가 사이 한복판에 선 사람 = 中(둘 사이의 한복판)일 가능성 → 中暑·中暍의 中일 수 있으나 같은 물건 둘이 아니라 약함.

**표제어**
- 1순위: **暑邪(暑淫) — 陽邪炎熱·升散·傷津耗氣·多挾濕** 65% (사전 기호 陽·熱·汗·津·氣·濕 여섯이 暑의 특징 넷에 정확히 대응)
- 2순위: **中暑·中熱(陽暑, 動而得之)** 20% (3순위 淸暑益氣湯證 10%)

**뜻 모름·어색·잘림**
- 흰 김이 氣(김)인지 濕(안개)인지 이중 해석 가능. 발밑 웅덩이가 濕인지 陰인지 애매. 누런 잎(燥의 마른 잎?)은 계절 장식으로 보고 보류. 기움질 헝겊이 傷(깨진 물건)인지 가난 표시인지 불명. 잘림은 1단계와 같음.
