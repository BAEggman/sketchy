# 045 판독 v2 (그림 Read 2회 — 원본 1회 + 확대 몽타주 1회 / 사전 Read 1회)

## 1단계 — 생판 (사전 없이 그림만)

### ① 소품 전수와 나르는 사실
1. 밤하늘·별·초승달(오른쪽 하늘) — 夜·陰, 달=水 쪽 표지(坎爲月?)
2. 구름 위에 뜬 나무 무대 — 한 판의 무대, 구름=雲
3. 왼쪽 4폭 병풍(강물 그림) — 水 진영
4. 물총에서 나와 왼쪽 밖으로 빠지는 물줄기 — 水가 왼쪽으로 흐름
5. 큰 귀 소년(귓구멍 검게 열림) — 腎開竅於耳 / 坎爲耳
6. 물총 — 腎主水, 水
7. 소년의 회흑색 옷 + 검은 발자국(중앙을 향함) — 水色 黑, 서로를 향해 걸어옴
8. 오른쪽 4폭 병풍(불꽃 그림) — 火 진영
9. 횃불에서 나와 오른쪽 밖으로 빠지는 불줄기 — 火가 오른쪽으로 흐름
10. 크게 뜬 눈의 여인(쪽머리) — 目; 心은 舌이므로 어긋남 → 離爲目이면 맞음
11. 횃불 — 心主火, 火
12. 주홍 옷 + 붉은 허리띠 + 붉은 발자국(중앙을 향함) — 火色 赤
13. 중앙 바닥의 둥근 거울 — 水火가 만나는 자리? 明? 뜻 불명
14. 소년(남)=水, 여인(여)=火 — 男陽女陰과 반대 → 坎中男·離中女 배정으로만 설명됨

### ② 표제어
- 1순위 **坎·離(八卦의 水火 한 쌍: 坎爲耳·中男·月 / 離爲目·中女)** — 45%
- 2순위 **心腎相交(水火旣濟) 또는 心腎不交** — 30% (귀=腎, 불=心, 밤=不寐)
- 그 밖 **水火者陰陽之徵兆也(陰陽)** — 15%

### ③ 뜻 모를 소품·어색·프레임 잘림
- 중앙 거울: 무엇을 나르는지 확정 못 함(明·交點·太極 중 택일 불가).
- 발자국: 五行색(黑·赤)은 읽히나 '서로를 향해 걸어옴'이 相交인지 단순 진영표시인지 모름.
- 어색: 물줄기·불줄기가 서로 등지고 바깥으로 흐르는데 발자국은 마주 향함 → 交/不交 판정 흔들림. 초승달이 火 쪽 하늘에 떠 있음.
- 잘림: 물줄기 왼쪽 끝·불줄기 오른쪽 끝·구름 아랫단이 프레임 밖.

## 2단계 — 계통 (사전 적용 후)

### ① 소품 → 사전 기호 재판독
- **4폭+4폭 병풍이 마주 본 무대 = 八卦 마주봄** — 판 전체가 八卦 판. 왼쪽 병풍=水(坎), 오른쪽 병풍=火(離)의 한 쌍(先天 對待 坎↔離).
- 큰 귀(옆으로 돌려 귓구멍 검게 열림) = **耳** → 說卦 坎爲耳. 크게 뜬 눈 = **目** → 離爲目.
- 소년/여인 = 坎 中男 / 離 中女. 중앙 둥근 것 = **中(둘 사이의 한복판)** 자리 → '中'男·'中'女 표지로 읽힘.
- 횃불·불줄기 = 陽(해 또는 불)/熱 기호이나 八卦 무대 위이므로 離의 火. 물총·강물 = 坎의 水(사전의 陰 기호인 얼음·고인 물이 아니므로 陰陽판 아님).
- 검은 옷·검은 발자국 = 坎(北·冬·黑), 주홍 옷·붉은 발자국(血=붉은 것 아님, 방위색) = 離(南·夏·赤). 발자국이 마주 향함 = '마주봄' 규약.
- 초승달·구름 = 坎爲月, 雲(需·屯의 坎). 붉은 곤룡포 임금(心)·잠수부(腎)가 없으므로 心腎 판이 아님. 濟(밧줄) 기호도 없어 旣濟·未濟 판도 아님.

### ② 표제어
- 1순위 **坎·離 마주봄 — 坎水(耳·中男·月) 對 離火(目·中女)** — 80%
- 2순위 **水火者陰陽之徵兆也(陰陽판)** — 10%
- 3순위 **心腎相交** — 5%

### ③ 남는 의문·어색·잘림
- 중앙 거울의 정체: '中' 자리 표지는 확실하나, 거울(華=광택→離 明?)인지 고인 물·얼음판(陰→離中虛)인지 사물 자체가 미등재 — 잔결.
- 초승달이 離(火) 쪽 하늘에 떠 있고, 물줄기·불줄기는 바깥으로 등짐 — 마주봄 규약과 결이 어긋남(사소).
- 잘림: 물줄기·불줄기 양끝, 구름 아랫단(의도된 배너 잘림으로 판정).
