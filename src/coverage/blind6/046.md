# 046 판독 기록 (blind6)

## 1단계 — 생판 (그림만)

**① 소품 전수·나르는 사실**
- 무대: 왼쪽 아래→오른쪽 위로 흐르는 물길(시간축) 위에 흰 빈 깃발 7개(=7칸). 좌 3칸은 건너편 기슭, 4칸째는 물 위의 배, 우 3칸은 이쪽 기슭.
- 1칸: 소머리 모자 소년(牛首=神農) · 씨앗을 흩뿌림(嘗百草·藥物 수재) · 바구니 3개(三品 분류) · 금메달(最古 本草書).
- 2칸: 물레 위 큰 항아리 + 옆의 작은 단지(큰 것이 약 2배 = 365→730 배증) · 붓 두 자루, 오른손 붉은 붓·왼손 검은 붓(朱墨分書: 本經은 朱, 別錄은 墨) → 陶(도자기)=陶弘景.
- 3칸: 붉은 관복·날개 사모의 관리, 두루마리(勅撰), 초록 상자(?), 뒤에 3층 기와 궁전(朝廷·官修) · 금메달(세계 最初 國定藥典).
- 4칸: 물 위의 배, 뚜껑 열린 보물상자에 금화 반짝(開+寶 = 開寶).
- 5칸: 펼친 두꺼운 책을 가위로 오려냄, 바닥에 낱장 3장(經史에서 발췌·證類/刪定).
- 6칸: 책더미 2탑(좌 6권·우 5권 남짓)+펼친 책, 칸 나뉜 상자(3×3 안팎)에 쪽지 분류(綱·目 분류, 참고서 800여 가).
- 7칸: 사람 없이 탁자 위 초록 옥도장 하나(官印=국가 공인 / 끝맺음 낙관).

**② 표제어**
- 1순위 **歷代 本草書 계보(本草學史: 神農本草經→本草經集注→新修本草→開寶本草→證類本草→本草綱目→末칸)** 60%
- 2순위 **中國→韓國 醫學 傳來史(배=東傳, 우측 기슭=韓國 醫書 편찬: 醫方類聚·東醫寶鑑)** 20%

**③ 뜻 모를 것·어색함·잘림**
- 3칸 초록 상자 정체 불명(印盒? 藥圖함?). 4칸이 굳이 배 위에 있는 이유 불명(千金=금화 상자로 읽힐 여지). 6칸 인물이 단발·양복풍으로 근대인처럼 보여 어색. 7칸 도장만 있는 빈 탁자 뜻 불명. 깃발 7개 전부 백지. 프레임 잘림 없음.

## 2단계 — 계통 (사전 적용 후)

**사전 어휘로 재독**
- 배 = 藥(배 모양 약연) → 4칸의 배는 "이것은 藥書(本草)"라는 표지. 열린 상자(開)+보물(寶)+藥(배) = **開寶本草**로 굳어짐(海藥本草는 차순위).
- 大 = 같은 것 둘 중 하나가 두 배 → 2칸 큰 항아리/작은 단지 = 弘(大)·倍增 → 陶+弘+朱墨 두 붓 = **陶弘景 本草經集注**(730종) 확정.
- 寺 = 기와지붕 건물 → 3칸 궁전은 官署 표지 → 官修 = **新修本草(唐本草, 659)**, 메달=세계 최초 국정 약전.
- 散 = 사방으로 흩어지는 것 → 1칸 씨앗 흩뿌림은 '흩어짐'이 아니라 아래로 쏟는 播種(농=神農)으로 유지. 바구니 3 = 三品.
- 王(왕관)·李(허리춤 자두)·張(활) 표지는 그림에 없음 → 6칸을 李時珍으로 못 박을 전담 기호가 빠져 있음. 그래도 책더미(參考 800餘家)+칸막이 상자(16部 60類 綱目)로 **本草綱目**이 최적.
- 5칸 가위·낱장 3장은 사전 기호와 무관 — 經史 발췌의 **證類本草**(唐愼微)로 유지, 紹興校定·本草衍義는 차순위.
- 7칸 사람 없는 탁자 위 옥도장 = 남겨진 물건(遺) → **本草綱目拾遺** 또는 국가 공정서(現代 藥典) 두 갈래로 미결.

**② 표제어**
- 1순위 **歷代 本草書 계보 — 神農本草經(365·三品)→本草經集注(730·朱墨分書)→新修本草(官修·最初 藥典)→開寶本草→證類本草→本草綱目→(拾遺/藥典)** 72%
- 2순위 **王朝別 醫學史 통사(唐 官署·宋 校正·明 類書·淸 御纂)** 15%

**③ 잔결**
- 3칸 초록 상자, 7칸 도장, 6칸의 李 표지 부재, 5칸 낱장 3장의 셈값이 미확정. 깃발 7장 백지는 사전에도 없어 칸 표지(왕조명 자리)로만 읽음. 잘림 없음.
