# 049 판독 기록 (blind6)

## 1단계 — 생판 (그림만)

**무대**: 4칸 격자, 칸마다 「촌구 진맥」 장면 — 환자 팔 1 + 진맥 손 1(검지·중지 2지로 누름), 팔뚝 위 파란 물길 = 脈의 흐름. 소매끝 색이 칸마다 다름(청록·금황·적갈·회색).

① 소품 전수
- 좌상(청록 소매): 실 한 가닥 같은 가는 물줄기 1(폭이 우상의 약 1/5) → 「細如線」 → **細脈**(70%; 微脈 가능).
- 우상(금황 소매): 폭 최대의 넘실대는 강물, 손가락 밑에서 불룩 솟았다가 손목 쪽으로 가늘어짐 → 「來盛去衰」; 진맥 손 둘레 떨림선 3~4개 → 손가락을 밀어올림(浮大有力); 환자 팔 피부만 붉은 톤 → 熱盛 → **洪脈**(85%).
- 좌하(적갈 소매): 물길 속 진주알 약 10개가 줄지어 굴러감 → 「如盤走珠·往來流利」 → **滑脈**(95%).
- 우하(회색 소매): 대나무 갈퀴(가지 4, 손잡이 끝이 대나무 섬유)로 물길을 긁음 → 「輕刀刮竹」; 물길에 회색 자갈·모래 20여 알이 흩어져 흐름이 끊김 → 「如雨沾沙·往來艱澀」 → **澀脈**(95%).
- 구성 논리: 洪↔細(脈幅), 滑↔澀(流利度) — 脈形 두 쌍.

② 표제어: 1순위 **洪·細·滑·澀 4맥 — 脈形(굵기·유리도) 대비판** (75%) / 2순위 **滑脈·澀脈 對比(28맥 각론)** (15%).

③ 잔결: 소매 색 4종의 뜻(主病 색? 오행?) 불명 · 진주 개수(10?)의 의미 불명 · 갈퀴가 '칼(刀)'이 아니라서 刮竹인지 沙인지 이중 · 진맥이 2지(촌관척 3지가 아님). 프레임 잘림 없음.

## 2단계 — 계통 (사전 적용)

사전에 脈 전용 기호는 없으나, 다음이 직접 맞물림.
- 盛 = 「넘쳐 흘러나오는 것」, 衰 = 「타다 남아 작아진 것」 → 우상의 넘치는 강물 + 손가락 뒤 가늘어짐 = 정확히 「來盛去衰」 → **洪脈** 확정(90%). 환자 살갗 붉음 = 血/熱 계열 색.
- 虛 = 「삼분의 일로 줄어든 것」, 陰 = 「졸아드는 고인 물」 → 좌상의 졸아든 실물줄기 = 細脈主 氣血兩虛 → **細脈**(75%).
- 痰 = 「끈적한 회백색 덩이」 → 우하의 회색 알갱이를 痰으로 읽을 위험 있음. 그러나 각지고 딱딱한 자갈이고 대나무 긁개와 짝이므로 「刮竹·沾沙」의 沙로 판정 → **澀脈** 유지(90%). 다만 瀉 = 「짚 빗자루」와 이 대나무 갈퀴가 헷갈릴 수 있음(손잡이 끝 섬유 다발) — 사전을 배운 독자는 '瀉'로 오독할 소지.
- 血 = 「붉은 것」 → 좌하 적갈 소매 = 滑脈의 血(妊娠·實熱) 암시 가능성. **滑脈**(95%).
- 소매 색 4종은 여전히 사전에 없음. 추정: 主病 색(細=濕/虛 청록, 洪=陽 금황, 滑=血 적, 澀=血少·瘀 회).

② 표제어: 1순위 **洪·細·滑·澀 4맥 — 脈形 대비판(來盛去衰 · 細如線 · 盤走珠 · 刮竹沾沙)** (80%) / 2순위 **28맥 각론 — 滑·澀 對比(+洪·細)** (12%).

③ 잔결: 소매 색 코드 미등재 · 진주 10개 의미 불명 · 우하 회색 알갱이(沙 vs 痰)와 대나무 갈퀴(刮竹 vs 瀉 빗자루) 이중 판독 위험 · 2지 진맥. 잘림 없음.
