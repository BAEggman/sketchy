# blind6 / 050 판독 기록

## 1단계 — 생판 (그림만)

**① 소품 전수와 나르는 사실**
1. 중앙 아이가 두 손으로 머리 위로 치켜든 **황금 손거울**(머리의 약 2배, 입을 얼굴 절반만큼 벌림) → 金+鑑 = 金鑑(寶鑑)
2. 그 앞 **옥(비취) 용 조각상** — 옥 받침대·주황 방석 위 → 玉龍 / 용=황제·어명(欽定)
3. 뒤편 **흰 빈 깃발 밭** — 약 40개(±5), 격자로 정렬, 글자 없음 → 白·素·條·陳列… 뜻 미상
4. 오른쪽 **왕관 아이**(금관·붉은 보석, 능글 표정) → 王/皇
5. 그 아이가 **뿌리째 뽑은 나무** + 흙더미, 뒤에 선 나무 1그루(둘=林) → 林+改(뽑아 고침)
6. 같은 아이가 펼쳐 든 **해부도 두루마리**(장부·골격) → 臟腑圖/圖經
7. 연못의 **황금 거북 + 뿔(犀角) 모양 촛대 + 촛불** → 金鰲+犀燭+源流(물)
8. 왼쪽 **노래하는 아이**(음표 4~5개) + **진열대의 책 3권**(흰·파랑·빨강) → 歌/誦 + 三 + 陳列
9. 왼쪽 건물의 **빈 흰 현판** → 미상(門·白·指南?)
10. 배경 청기와 건물 3채·담장 → 무대(堂/院)

**② 표제어**
- 1순위 **淸代 醫學史(주요 의서·의가: 吳謙 醫宗金鑑·王淸任 醫林改錯·沈金鰲 雜病源流犀燭·陳修園 醫學三字經)** — 50%. 근거: 金鑑=황금거울, 王+林+臟腑圖+뽑기=醫林改錯, 金鰲(황금거북)+犀燭(뿔촛대)+源流(연못)=雜病源流犀燭, 노래+책3=三字經, 옥용 방석=乾隆 欽定.
- 2순위 **東醫寶鑑(許浚)** — 20%. 근거: 寶鑑 거울, 거북=龜巖, 왕관=宣祖/光海君, 해부도=內景篇, 뽑은 풀=鄕藥, 책3=諺解 3書. 그러나 뿔촛대·林을 설명 못 함.
- 기타: 黃帝內經(황금관=黃帝, 흰 깃발=素+벌린 입=問, 거북=靈) 10%, 針灸歌賦(玉龍+歌=玉龍歌, 거북+빛=靈光賦) 10%.

**③ 뜻 모를 소품·어색한 것·프레임 잘림**
- 흰 깃발 밭: 개수·색이 무엇을 세는지 미상(條/經緯/白/衆 후보).
- 빈 현판: 글자 없음 — 장식인지 기호인지 불명.
- 옥용이 「玉龍」인지 「임금·어명」인지 이중 해석.
- 잘림: 오른쪽 건물·현판 두루마리 오른끝, 왼쪽 진열대 아래·왼쪽 처마가 프레임에 걸림. 가운데 아이 허리춤의 작은 노란 장식은 판독 불가.

## 2단계 — 계통 (사전 어휘로 재독)

사전에서 맞아든 기호: **王=왕관**(오른쪽 아이), **吳=얼굴 절반만 한 큰 입**(거울 든 가운데 아이 — 입이 얼굴 절반), 門=문간(왼쪽 현판 달린 문기둥?), 熱=불꽃(촛불), 寺/기와지붕(배경). 龍·거북·깃발·거울·나무는 사전에 없어 이 판이 새로 여는 기호.

**① 소품 재독**
1. 큰 입(吳) + 황금거울(金鑑) = **吳謙 醫宗金鑑**(1742) — 옆 옥용·방석 = 乾隆帝 欽定(어명 편찬).
2. 왕관(王) + 나무 둘(林) + 뿌리째 뽑음(改錯) + 해부 두루마리(親見改正臟腑圖) = **王淸任 醫林改錯**(1830); 흙더미=의총(義塚) 관찰 암시 가능.
3. 황금거북(金鰲) + 뿔촛대(犀燭) + 연못(源流) = **沈金鰲 雜病源流犀燭**(1773).
4. 진열대(陳列=陳) + 책 3권(三字) + 노래(誦·歌括) = **陳修園 醫學三字經**(1804). 단, 이 아이 입도 크므로 吳鞠通(溫病條辨: 三焦 3편+條=깃발) 이중해석 여지.
5. 흰 깃발 밭(약 40) = 조례(條)·경위(經緯) 격자 → 溫病條辨(吳鞠通)/溫熱經緯(王孟英) 후보, 또는 白=薛生白 — 미확정.
6. 빈 현판 = 門(醫門法律 喩嘉言?) 또는 장식 — 미확정.

**② 표제어**
- 1순위 **淸代 醫學史 — 吳謙·王淸任·沈金鰲·陳修園(+乾隆 欽定, 溫病 계열)** — 65%. 사전의 王·吳 두 기호가 1단계 추정을 그대로 떠받침.
- 2순위 **醫宗金鑑(吳謙) 단독 표제** — 15%(나머지 소품을 시대 배경으로 볼 때). 東醫寶鑑은 吳·王+林을 설명 못 해 5%로 강등.

**③ 잔결**
- 흰 깃발 밭이 어느 책(條辨/經緯)인지, 노래 아이가 陳修園인지 吳鞠通인지, 빈 현판의 의미 — 세 가지가 미확정. 옥용의 「龍=隆(乾隆)」 독법은 사전 미등재 추정.
