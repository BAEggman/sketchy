# blind6/051 판독 기록

## 1단계 — 생판 (그림만, 사전 없이)

① 소품 전수와 나르는 사실
- 흰 도포·흰 세조대·검은 갓·수염의 선비 1인, 표정 평온 → 白(金의 色)·秋의 인물. 갓·수염은 인물 표지로만 읽힘
- 왼손의 낫(쇠날) 1자루 → 金(五行 金)·肅殺·秋刑·收割
- 볏단 6묶음(좌3·우3, 양끝 둘은 프레임에 잘림, 새끼로 허리 묶음) → 秋收·收斂(容平)·稻
- 소반 위 접시의 붉은 고추 3개(4개 가능) → 辛味
- 쩍쩍 갈라진 마른 땅(가뭄) → 燥(西方生燥)
- 갈색 낙엽: 공중 8장 + 땅 3장 = 11장(단풍형 2·타원형 9) → 秋·落葉
- 세로 하강선 9~10줄(잎 없는 자리에도 그어짐) → 下降·肅降 또는 天氣以急
- 오른손 주먹, 땅의 작은 돌 몇 개 → 뜻 불명

② 표제어
- 1순위 **五行 金(秋)의 배속 — 秋·燥·金·辛·白·收** (素問 陰陽應象大論 「西方生燥 燥生金 金生辛 辛生肺」 / 金匱真言論 「西方白色 … 其味辛 其類金 其穀稻」) 55%
- 2순위 **燥邪(秋燥)** 20% / 3순위 四氣調神大論 「秋三月 此謂容平」(닭·飧泄 없음) 15%

③ 뜻 모를 것·어색함·잘림
- 갓·수염·주먹 쥔 오른손의 뜻 불명. 붉은 고추는 火(赤)로 오독될 여지. 하강선은 비(雨)로 오독 가능(가뭄 땅과 모순). 볏단 좌우 끝 두 묶음 프레임 잘림. 우하단 희미한 워터마크 무늬(소품 아님).

## 2단계 — 계통 (사전 어휘로 재판독)

① 소품 재판독
- 흰 도포 재상 = **肺**(사전 등재) — 인물이 곧 肺, 흰 옷은 白色도 겸함
- 머리의 테 넓은 갓 = **太**(사전 등재) → 흰 옷(白)과 합쳐 太白(「上為太白星」)로 읽힘
- 갈라진 땅 + 마른 잎 = **燥**(사전이 두 기호를 모두 燥로 등재 → 확정)
- 접시 위 붉은 고추 = **辛**(사전 등재, 火 아님)
- 낫 = 金(신규 기호: 「其類金」)
- 볏단 6 = 稻·秋收(신규: 「其穀稻」). 사전의 收(조인 삼베 자루)와는 다른 형태
- 낙엽·하강선: 옆으로 흐르지 않고 곧게 떨어지므로 風 아님 → 下(가라앉음)+燥의 마른 잎. 하강선 9~10줄은 「其數九」 가능성만 기록
- 降(저울추)·收(자루)·鼻·皮毛 기호는 없음

② 표제어
- 1순위 **肺(金)의 五行 歸類 — 肺·白·辛·金·稻·燥·太白** (素問 金匱真言論 「西方白色 入通於肺 … 其味辛 其類金 … 其穀稻 … 上為太白星」 + 陰陽應象大論 「西方生燥」) 50%
- 2순위 **秋燥·燥邪 犯肺** 20% (인물이 건강·평온하고 傷·津 기호가 없어 생리 배속 쪽이 우세)
- 3순위 **秋** 계절 기호 등재판(낙엽·추수·낫) 15%

③ 잔결
- 其畜馬(말)·開竅於鼻·皮毛·其音商·其臭腥 부재. 갓=太의 용처(太白 vs 太陰) 미확정. 하강선 9~10줄·낙엽 11장이 어느 수를 나르는지 불명. 고추 3 또는 4. 프레임 잘림은 1단계와 같음.
