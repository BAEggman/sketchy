# 052 판독 v2 (그림 Read 3회 · 사전 Read 1회)

## 1단계 — 생판 (그림만)

① 소품 전수
- 가운데 굵은 나무 기둥: 무대를 좌·우 두 장면으로 가름(같은 환자의 두 상황).
- 왼쪽 위 공중의 불꽃: 겉으로 드러난 熱(身熱·面赤).
- 왼쪽 병자(여윈 얼굴·눈 밑 그늘)가 품에 안은 사발 가득한 눈·얼음: 속의 寒(裏寒).
- 왼쪽 상 위 천을 씌워 끈으로 묶은 단지: 닫힘·격(格)—陽이 밖에 밀려나 못 들어옴(格陽), 또는 戴陽(머리에 얹은 천).
- 오른쪽 위 눈송이(프레임에 잘림): 겉의 寒(惡寒·사지냉).
- 오른쪽 병자가 안은 사발 가득한 벌건 숯, 가슴이 붉게 비침: 속의 熱(胸腹灼熱).
- 오른쪽 상 위 텅 빈 사발 + 상에서 바닥으로 흘러내린 흰 거품 웅덩이(맨발 옆): 陰이 밖으로 밀려나감(格陰於外)→발끝의 冷.
- 양쪽 맨발: 四肢.

② 표제어
- 1순위 **寒熱眞假(眞寒假熱·眞熱假寒 = 陰盛格陽·陽盛格陰)** 60%
- 2순위 **寒熱錯雜(表熱裏寒·表寒裏熱 / 上熱下寒·上寒下熱)** 25%
- 좌우 배정은 '안은 것=裏·眞'으로 읽어 왼쪽=眞寒假熱, 오른쪽=眞熱假寒으로 잡았으나, '손에 든 것=四肢·假'로 뒤집어 읽을 여지가 반반이다.

③ 뜻 모를·어색·잘림
- 밀봉 단지의 정확한 뜻 불명(便秘? 戴陽? 格?). 흰 거품이 下利淸穀인지 陰이 쏟아진 것인지 불명.
- 기둥이 단순 분할인지 '格'의 벽인지 불명. 눈송이 우측 절반과 아래쪽 상다리·거품 밑동이 프레임에 잘림.

## 2단계 — 계통 (사전 적용)

사전을 적용하면 1단계의 '眞·假' 축은 무너진다.
- **병표지** = 사람 곁에 크게 떠 있는 표지 → 불꽃(熱)=왼쪽 병자의 병증은 **熱證**, 눈송이(寒)=오른쪽 병자의 병증은 **寒證**. 겉·속의 대비가 아니라 '이 사람의 병'이다.
- **補-b**(그릇에 가득 담긴 것 = 채워 주는 것) → 왼쪽 熱證 병자에게 얼음 덩이(陰)를 가득 채워 줌 = **補陰**; 오른쪽 寒證 병자에게 불(陽)을 가득 채워 줌 = **補陽·益火**. 사전에 따로 있는 淸(맑고 찬 물 한 그릇)·溫(김 나는 따뜻한 천)이 아니라 陰·陽 자체를 담았으므로 淸熱·溫散이 아닌 補陰·補陽이다.
- **瀉-b**(텅 빈 그릇 + 밖으로 쏟아져 흘러넘친 내용물 = 덜어낸 것) → 오른쪽 빈 사발과 바닥으로 쏟아진 흰 얼음 슬러시 = 寒證 병자에게서 **陰을 덜어냄 = 消陰翳**.
- 왼쪽 밀봉 단지: 사전에 직접 항목은 없으나(가장 가까운 것은 收의 '끈으로 조인 아가리'), 오른쪽 瀉-b와 짝을 이루어 '쏟지 않고 가두어 둠' = 陽을 억누름 = **制陽光**으로 읽힌다.
- 厥(검푸른 손발 끝)이 없으므로 四肢厥冷 즉 眞熱假寒의 근거가 없다. 기둥은 두 치법을 가르는 무대 분할(中).

① 소품 전수(재판독): 불꽃=熱證 표지 / 눈송이=寒證 표지 / 얼음 가득 사발=補陰(壯水之主) / 숯 가득 사발=補陽(益火之源) / 빈 사발+쏟아진 얼음=瀉陰(消陰翳) / 밀봉 단지=制陽(制陽光) / 기둥=좌우 분할.

② 표제어
- 1순위 **陽病治陰·陰病治陽 — 壯水之主 以制陽光 / 益火之源 以消陰翳 (陰虛則熱·陽虛則寒의 치법)** 60%
- 2순위 **正治法 寒者熱之·熱者寒之 (陰陽偏盛偏衰 치료원칙 일반)** 25%
- 1단계의 寒熱眞假는 8%로 내린다.

③ 잔결
- 밀봉 단지는 사전 미등재 기호라 '制'로 읽은 것은 추정이며 收로 오독될 여지가 있다. 虛(삼분의 일로 줄어든 것) 표지가 없어 虛熱·虛寒임은 補-b로만 간접 추정된다. 눈송이·상다리·거품 밑동의 프레임 잘림은 판독에 지장 없다.
