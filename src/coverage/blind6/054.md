# 054 판독

## 1단계 — 생판 (사전 없이, 그림만)

① 소품 전수와 나르는 사실
- 천장 먹구름 1 + 곧게 떨어지는 빗줄기 1가닥(우산 위에서 작은 물튀김) → 위에서 내려오는 濕邪(外濕·雨濕), 우산에 막힘.
- 기름종이 우산 1(오른손, 머리 위) → 濕을 막음 = 脾惡濕(喜燥惡濕).
- 노란 밀짚 삿갓 1 + 황토색 저고리·고름 → 黃=脾·土(脾在色爲黃).
- 가부좌 좌선 자세 → 思(脾在志爲思).
- 입가 맑은 침 한 방울 1 → 涎(脾在液爲涎).
- 깔고 앉은 붉은 방석 1(깨끗) + 오른쪽 쌓인 붉은 방석 3(회흑색 곰팡이 얼룩 각 1, 총 3) = 방석 4 → 脾主四肢(4)·肌肉, 濕이 肌肉을 상함.
- 맨발 2, 회색 바닥, 상자형 무대.

② 표제어
- 1순위 **脾의 생리특성 — 脾惡濕(喜燥惡濕)·在液爲涎·在色爲黃·在志爲思** 55%
- 2순위 **濕邪의 성질과 병증 — 外濕(冒雨·居處潮濕)→濕困脾, 濕性黏滯·重濁·趨下** 30%

③ 불명·어색·잘림
- 곰팡이 방석이 왜 3개인지, 왜 붉은지 불명. 우산과 삿갓이 비 가리개로 이중인 이유 불명. 스님풍 옷·맨발의 뜻 불명. 빗줄기가 부슬비가 아닌 한 가닥 물줄기인 점 어색. 프레임 잘림 없음.

## 2단계 — 계통 (사전 적용 후)

① 사전 어휘로 다시 읽음
- 노란 밀짚모자 농부 = **脾**(확정).
- 먹구름 빗줄기 = **濕**(外濕=부슬비).
- 사람과 비 사이에 세운 우산 = **惡**(해로운 것과 사람 사이의 가리개) → 「**脾惡濕**」(五臟所惡).
- 같은 방석 셋 포개짐 = **久**. 곰팡이로 못 쓰게 된 방석 = **傷**. 방석 위에 앉음 = 坐. 도톰한 방석 = 肉(肌肉, 脾主肉) → 「**久坐傷肉**」(五勞所傷).
- 입가 맑은 물방울 = 津 계열 → 脾의 液 = 涎 → 「**脾爲涎**」(五臟化液).
- 세 조문이 모두 『素問·宣明五氣』의 脾(土) 항목. 상자 무대 = 脾의 방(오장다섯방).
- 1단계의 '방석 4=四肢', '곰팡이=濕이 肌肉 상함', '좌선=思'는 철회. 셋 포갠 것은 개수 4가 아니라 久 기호이고, 앉은 자세는 思가 아니라 坐.

② 표제어
- 1순위 **脾惡濕 — 『素問·宣明五氣』 脾 조문 묶음(五臟所惡 脾惡濕 · 五臟化液 脾爲涎 · 五勞所傷 久坐傷肉)** 70%
- 2순위 **脾主肌肉·脾爲生痰之源(濕久成痰 — 방석 얼룩을 痰으로 읽을 경우)** 20%

③ 잔결
- 涎·坐·肉의 전담 기호가 사전에 없음(涎은 津의 맑은 물방울로, 肉은 肌 '도톰한 살덩이'로 방석을 대신 읽음). 방석 얼룩이 傷(못 쓰게 됨)인지 痰(끈적한 회백색 덩이)인지 두 갈래. 빗줄기가 부슬비가 아닌 곧은 한 줄기라 下(쏟아짐)가 겹쳐 읽힐 여지. 프레임 잘림 없음.
