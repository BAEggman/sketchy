# 055 판독 기록 (blind6)

## 1단계 — 생판 (그림만)

**① 소품 전수·사실**
- 무대: 상자형 방. 왼쪽 창은 활짝 열려 커튼봉만 남고, 바람 소용돌이 3줄이 창→남자 머리→사발→여자 얼굴로 흐른다. 오른쪽 창의 커튼 1장은 옆으로 눕게 날려 여자 얼굴을 덮친다.
- 왼쪽 남자(체구 = 여자의 약 1.5~2배, 배가 팽팽): 얼굴·팔 전체 붉음(滿面通紅) / 튀어 날리는 땀방울 6개(大汗) / 맑은 물 한 사발을 들이켬(大渴·喜冷飲) / 접부채 1(惡熱) / 신 신은 발 / 바닥에 벗어 던져 흠뻑 젖은 이불 1(去衣被·汗出濕衣) / 열린 창 곁(喜涼).
- 오른쪽 여자(마름): 얼굴 창백 + 두 볼 붉은 원 2(面白顴紅) / 살갗에 맺힌 땀 2방울(微汗·盜汗) / 두 손바닥을 위로 펼쳐 보임(手心) / 맨발 2에 김 3줄(足心熱) → 五心煩熱 / 물 없음(不欲飲) / 옷을 여미고 지친 표정(神疲) / 바람에 찡그림(惡風).
- 대비: 땀 6 : 2(약 3배), 땀방울 크기 약 2배, 체구 약 2배, 붉음=온 얼굴 : 두 볼.

**② 표제어**
- 1순위 **實熱證 vs 虛熱證(陰虛內熱) 감별** — 55%
- 2순위 **八綱 虛實辨證(實證 vs 虛證)** — 20%
- 3순위 傷寒論 陽明外證(汗自出·反惡熱·大渴) vs 太陽中風(汗出惡風) — 10%

**③ 뜻 모를·어색·잘림**
- 젖은 이불: 땀에 젖은 이불인지, 고드름 진 찬 수건(喜冷)인지 불명.
- 여자 발치 김: 足心熱로 읽었으나 바닥에서 솟아 어색. 바람 소용돌이 3줄의 개수 의미 불명. 커튼 뒤 닫힌 창(거울?) 용도 불명. 프레임 잘림 없음, 글자 없음.

## 2단계 — 계통 (사전 적용 후)

**① 사전 어휘로 다시 읽음**
- 汗=살갗에 맺힌 땀방울: 두 사람 모두 등재 기호 汗 → 판의 공통축은 「汗出」.
- 大=같은 것 둘 나란한데 하나가 두 배: 남자 땀방울이 여자의 두 배 → **大汗**; 체구도 두 배.
- 惡=해로운 것과 사람 사이에 세운 가리개 + 風=옆으로 눕게 날리는 것: 창(바람)과 여자 사이의 옆으로 날린 커튼 = **惡風**(등재 복합기호, 판의 가장 의도적인 소품). 남자 창엔 가리개 없음 → 不惡風寒.
- 實=팽팽하게 찬 것: 남자의 팽팽한 배 → **實**. 虛=삼분의 일로 줄어든 것: 여자 땀 2개 = 남자 6개의 1/3 → **虛(汗)**.
- 淸=맑고 찬 물 한 그릇: 남자 사발 그대로 → 喜冷飲(大渴).
- 熱=불꽃·寒=눈송이가 하나도 없음 → 寒熱축이 아니라 虛實축(둘 다 열형)임을 시사. 血=붉은 것(남자 온몸 붉음)은 面赤으로 유지. 발치 김은 氣(흰 김)로도 溫(김 나는 천)으로도 딱 맞지 않아 足心熱 유지.

**② 표제어**
- 1순위 **八綱 虛實辨證 — 實證 vs 虛證(열형: 實熱 vs 虛熱·陰虛)** — 50%
- 2순위 **傷寒論 汗出 감별: 太陽中風(汗出惡風) vs 陽明病外證(汗自出·不惡寒反惡熱·大渴)** — 25% (惡風·汗·淸이 모두 등재 기호라 상승)
- 3순위 汗證 虛實(自汗·盜汗 vs 實熱汗) — 10%

**③ 잔결**
- 젖은 이불이 陰(얼음 덩이)인지 汗濕衣被인지 여전히 불명. 부채·손바닥·볼 붉음·발치 김은 미등재 기호. 프레임 잘림 없음.
