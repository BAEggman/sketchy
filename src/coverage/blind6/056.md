# 056 판독 기록

## 1단계 — 생판 (그림만 읽음)

① 소품 전수와 나르는 사실
- 좌상 가죽 풀무(적갈색) 1개: 바람을 불어넣는 도구 → 氣를 넣음 = 補氣. 바로 아래 왼쪽 상자와 짝.
- 우상 붉은 액체가 가득 찬 청회색 사발 1개: 붉음 = 血 → 補血. 아래 오른쪽 상자와 짝.
- 왼쪽 2×2 상자(4칸): 사람 모양 인형(=人蔘, 사람꼴) · 울퉁불퉁 흰 덩이(=白朮) · 흰 솜구름 덩이(=白茯苓) · 노란 막대(=甘草) → 4味 = 四君子湯(補氣).
- 오른쪽 2×2 상자(4칸): 검고 윤나는 덩이(=熟地黃) · 잔뿌리 많은 뿌리(=當歸) · 흰 원반 절편(=白芍藥) · 꼬이고 마디진 주황 뿌리(=川芎) → 4味 = 四物湯(補血).
- 아래 칸 없는 큰 쟁반 1개: 위 8가지가 전부 한데 담김 → 4+4=8味 合方. 쟁반은 상자 하나보다 조금 크나 두 배는 아님.

② 표제어
- 1순위 **팔물탕(八物湯)=팔진탕(八珍湯)** — 四君子湯+四物湯, 氣血雙補. 85%
- 2순위 **십전대보탕(十全大補湯)** — 같은 계열이나 黃芪·肉桂가 없고 8味에서 멈춤. 8% (그 외 "四君子·四物 병렬" 개념 7%)

③ 뜻 모름·어색·잘림
- 풀무가 氣의 기호인지 별개 소품인지 그림만으로는 확정 못 함(위치로 補氣라 읽음).
- 흰 덩이 둘 중 어느 쪽이 白朮·茯苓인지 서로 바뀔 수 있음. 흰 원반은 白芍藥 외 山藥 가능성.
- 검은 덩이는 熟地黃인지 그냥 돌인지 색만으로 애매.
- 薑·棗 가미 없음. 프레임 잘림 없음.

## 2단계 — 계통 (사전요약 적용 후 재판독)

① 사전 대조
- 血=붉은 것, 補=그릇에 찰랑찰랑 찬 따뜻한 국물 → 우상 사발은 補+血 = 補血로 정확히 읽힘(사전 일치).
- 氣=서린 흰 김 → 좌상 풀무는 사전 미등재 기호. 사전대로라면 補氣는 "김 오르는 국물 사발"이어야 하나 풀무로 대체됨. 補氣 상자 위에 놓인 위치로 뜻은 통하지만 사전 어휘로는 못 읽는 소품.
- 地黃=검붉은 뿌리 조각 → 오른쪽 상자의 덩이는 검붉음이 아니라 검정·광택. 熟地黃(炮製 후 흑색)으로 읽되 사전 색과 어긋남. 瘀(검붉게 굳은 덩이)와 혼동 여지가 있으나 처방 문맥상 熟地黃.
- 會=담는 것 안에 담긴 것 → 아래 쟁반이 두 방의 8味를 한 그릇에 담음 = 두 처방의 合(會) → 八物湯 구성 원리.
- 人蔘·白朮·茯苓·甘草·當歸·川芎·芍藥은 사전 미등재 → 형태 직독(사람꼴=人蔘, 꼬인 마디=川芎 등) 그대로 유지.

② 표제어
- 1순위 **팔물탕(八物湯)/팔진탕(八珍湯)** 88% — 補氣(四君子)+補血(四物)=氣血雙補 축이 사전 어휘(補·血·會)로도 성립. 1단계 판정 유지.
- 2순위 **십전대보탕(十全大補湯)** 6% — 十全 표지(黃芪·肉桂·개수 10) 전무.

③ 잔결
- 풀무=補氣가 사전에 없음(氣는 흰 김이어야 함). 地黃 색 불일치(검붉음→검정). 白朮/茯苓 배정 상호 교환 가능. 잘림 없음.
