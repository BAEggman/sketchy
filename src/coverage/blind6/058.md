# 058 판독 (blind6)

## 1단계 — 생판 (그림만)

① 소품 전수
- 초록 비늘갑옷·초록 투구(창끝+검은 술 1)의 장군 1명, 정면 직립, 맨손·맨발(손톱·발톱 노출, 손은 편 상태), 검은 턱수염, 회색 속옷·치마 → 肝者將軍之官(靈蘭秘典論); 색 青; 비늘갑옷=甲(甲乙木); 맨손발=其華在爪(?).
- 분홍 5판화 꽃나무 5그루(왼쪽 3, 오른쪽 2)가 모두 오른쪽으로 휘고, 꽃잎 약 25장이 옆으로 흘러 날림, 하늘의 바람 줄 → 東方生風·在天為風, 계절 春.
- 초록 언덕 2~3겹 → 東方·木 배경.
- 오른쪽 나무 탁자 1 + 나무 접시 1 + 초록 풋매실 9개(9의 뜻 불명, 肝數 8과 불일치) → 木生酸·在味為酸.
- 앞쪽 이랑 두 줄의 새싹 약 20포기(밀싹/부추 모양) → 春生·生發, 혹은 其穀麥/其菜韭.
- 탁자 오른쪽 땅의 흰 반짝임 2개 → 미상.

② 표제어: 1순위 **肝 — 將軍之官, 木·東方·風·青·酸·春 배속**(靈蘭秘典論+陰陽應象大論 「東方生風 風生木 木生酸 酸生肝」) 85%. 2순위 **오행 木行 총론(春·風·青·酸·生)** 55%. 3순위 望梅止渴(장군+청매) 10%.

③ 뜻 모를 것: 투구 술·턱수염·회색 치마·땅의 반짝임 2·열매 9개·새싹 종류. 어색: 肝의 體內 배속(目·筋·怒·魂·淚·呼·握)이 전혀 없고 장군의 눈·주먹이 평범함. 프레임 잘림: 맨 왼쪽 꽃나무 가지가 왼쪽 틀에 잘림, 나머지 온전.

## 2단계 — 계통 (사전 적용)

사전 어휘: 肝=초록 비늘갑옷 장군 ✓ / 酸=접시 위의 초록 매실 ✓ / 風=한쪽으로 눕고 옆으로 흘러 날리는 것 ✓(나무가 한쪽으로 눕고 꽃잎이 옆으로 흐름; 사방으로 흩어지는 散이 아님) / 爪=손톱(맨손발에 보이나 강조 없음) / 華=빛나는 것(탁자 옆 반짝임 2개가 華일 수 있으나 爪와 떨어져 있어 불명).

① 재판독: 장군(肝)이 무대 주인공이고, 그 곁에 風(휘는 꽃나무·날리는 꽃잎)과 酸(접시 위 초록 매실)이 전담기호로 놓임. 초록 언덕·꽃나무·새싹 이랑은 春·木·生의 무대 배경(전담기호 없음). 장군 자체가 肝 글자이므로 「將軍之官」을 따로 가르치는 판은 아니고, 肝에 배속되는 외계 항목(氣=風, 味=酸, 時=春, 色=青)을 한 판에 모은 것으로 읽힘. 나무 탁자·나무 접시는 木 재질의 소품.

② 표제어: 1순위 **肝의 오행(木) 배속 — 風·酸·青·春** (陰陽應象大論 「東方生風 風生木 木生酸 酸生肝」) 90%. 2순위 **金匱真言論 東方靑色 入通於肝(春·風·酸)** 70%. 1단계의 「將軍之官」 단독 표제는 40%로 내림(謀慮를 나르는 소품이 없음).

③ 잔결: 새싹 이랑이 春/生/麥/韭 중 무엇인지 사전에 없음; 매실 9개의 수는 무의미로 판정; 땅의 반짝임 2개(華?)·투구 술·턱수염·회색 치마는 여전히 불명; 目·筋·怒 등 체내 배속은 이 판에 없음. 프레임: 맨 왼쪽 꽃나무만 살짝 잘림.
