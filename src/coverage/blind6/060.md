# 060 판독 기록 (blind6)

## 1단계 — 생판 (사전 없이 그림만)

**① 소품 전수·나르는 사실**
- 세로 분할선 1 → 좌·우 두 조건의 대비 프레임.
- 흰 도포·검은 갓 선비 2인(동일 인물, 맨발) → "같은 것을 두 조건으로" 비교. 갓·수염·차림 완전 동일.
- 4단 목제 선반장 1(맨 위 판은 양쪽 모두 빈칸, 실질 3단) → 上·中·下 3층 위계. 좌우 모두 김 그릇이 빗자루 그릇 바로 위에 놓이고, 오른쪽이 왼쪽보다 **정확히 한 층 위**.
- 김 오르는 죽(국) 그릇 2(김 세 가닥씩) → 溫熱·湯·啜熱粥 계열. 좌: 中단, 우: 上단.
- 빈 그릇에 꽂힌 짚 빗자루 2 → 쓸어냄(掃·散·去沫·泄). 좌: 下단, 우: 中단.
- 왼쪽 인물 옆 뿌리박힌 가시 마른 덤불 1(잎 없음) → 麻黃 관목 또는 刺·痛·寒.
- 오른쪽 인물 발밑 떨어진 마른 가지 1 → 枝(桂枝) 또는 바람에 꺾임(風).

**② 표제어**
- 1순위 **桂枝湯證(太陽中風) 對 麻黃湯證(太陽傷寒) 대비** — 30%. 근거: 떨어진 가지=桂枝, 가시덤불=麻黃/身疼, 열죽=啜熱稀粥, 쌍둥이=둘 다 太陽表證, 한 층 차이=桂枝의 지위(君→臣).
- 2순위 **三焦 병위의 上下 이동(溫病 順傳 또는 上熱下寒의 위치 비교)** — 25%. 김=熱, 빗자루=泄·瀉, 3층=上·中·下焦.
- 3순위 升降 치법(升提 對 沈降) — 15%.

**③ 뜻 모를 것·어색·잘림**
- 빗자루를 왜 빈 그릇에 꽂았는지 불명(빈 그릇=虛? 쓸어냄=瀉?).
- 죽 그릇이 약 재료인지 복약법(啜粥)인지 결정 불가 → 1순위 확신 낮음.
- 두 인물이 완전히 동일해 좌우 인물 차이를 식물에만 의존.
- 왼쪽 덤불이 좌측 프레임에 잘림, 선반 다리가 하단 프레임에 닿음(경미).

## 2단계 — 계통 (사전 어휘로 재판독)

사전 대조: 補=그릇에 찰랑찰랑 찬 따뜻한 국물, 瀉=짚 빗자루, 官=3층 선반장의 가운데 층, 肺=흰 도포 재상, 太=테 넓은 큰 갓, 風=한쪽으로 눕고 옆으로 흘러 날리는 것. 1단계는 소품 어휘를 전부 잘못 읽었으므로 폐기.

**① 소품 전수·사실**
- 흰 도포 재상 2 = **肺**(같은 肺經의 두 상태). 갓 = 太(太陰肺經·太淵/太白 힌트, 양쪽 동일이라 변별 없음).
- 3층 선반장 = 母(上)·**官**(中)·子(下) 위계(官=가운데 층 확정, 上=母·下=子는 추정).
- 따뜻한 국물 그릇 2 = **補**, 짚 빗자루 2 = **瀉**.
- 우측: 補 母단 + 瀉 官단 = **補母瀉官 = 正格**(虛證). 肺正格이면 補 太白·太淵(土), 瀉 少府·魚際(火).
- 좌측: 補 官단 + 瀉 子단 = **補官瀉子 = 勝格**(實證). 肺勝格이면 補 少府·魚際(火), 瀉 尺澤·陰谷(水).
- 우측 발밑에 눕고 흘러난 가지 = **風** → 正格(肺虛·傷風 계열) 쪽 병인 표지.
- 좌측 가시덤불 = 미등재 기호. 燥(마른 잎)나 痛(쇠못)의 변형으로 보이나 확정 불가.
- 세로 분할선 = 두 격 대비(中=둘 사이 한복판일 가능성).

**② 표제어**
- 1순위 **사암침법 正格·勝格의 補瀉 원리(補母瀉官 / 補官瀉子) — 肺正格·肺勝格** — 60%.
- 2순위 **五行 母子補瀉 총론(虛則補其母·實則瀉其子)** — 25%.

**③ 잔결·어색**
- 왼쪽 가시덤불의 글자 미확정(燥·痛·寒 중 어느 것도 사전형과 정확히 일치하지 않음).
- 선반 上단=母·下단=子가 이 요약에 등재돼 있지 않아 官 한 층만으로 추정함.
- 왜 빗자루가 그릇에 담겼는지(瀉의 그릇=穴 용기?)는 여전히 불명.
- 인물이 肺인지 太인지 이중 독법 가능(흰 도포+갓 동시 착용).
