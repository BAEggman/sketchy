# blind6 / 061 판독 기록

## 1단계 — 생판 (그림만)

① 소품 전수와 나르는 사실(가설)
- 갈래진 물길 5줄 이상(연푸른 큰 강 1·검푸른 강 1·실개천 3) = 水道·決瀆 → 三焦(決瀆之官 水道出焉)
- 먹구름 3덩이·번개 3줄·비 = 上焦如霧 / 「三」
- 상투·흰 머리띠 사내, 화로 불꽃 + 집게로 물통에 담금 → 흰 김 1 = 中焦如漚(腐熟水穀·蒸津液)
- 나룻배 1척(조개·파·버섯 가득, 검푸른 강 위) = 水穀之道路(飮入於胃)
- 뜰채 든 소년, 개천에 떠내려오는 종이 2장·돌 5~6개를 건짐 = 下焦 分別淸濁·濟泌別汁
- 기와집 1채(처마에 통발 1·흰 깃발 1) + 평상 위 빈 사발 10개(5+5) = 膀胱 州都之官 津液藏焉
- 밥상 5첩(국 1·나물 4) = 上焦開發 宣五穀味
- 여인(주황 저고리·흰 앞치마), 뿌리 달린 미나리풍 다발 2; 옆 실개천에 둥근 물풀 잎 2 = 水芹·浮萍(利水)?
- 빈 간판 2(큰 것·작은 것)·마을·논밭 = 有名而無形(難經)?

② 표제어
- 1순위 **三焦 — 決瀆之官·水道出焉, 上焦如霧·中焦如漚·下焦如瀆, 水穀之道路** 50%
- 2순위 **津液(水液) 代謝 — 脾轉輸·肺通調水道·腎氣化·三焦·膀胱** 25% (3순위 金匱 水氣病 五水 10%)

③ 뜻 모를 것·어색·잘림
- 빈 간판 2·흰 깃발 2의 뜻 불명. 사내가 왜 대장장이(담금질)인지, 가슴의 둥근 패, 배에 실린 조개, 사발이 하필 10개, 여인 나물의 정체(미나리/인삼) 불명.
- 프레임 잘림: 좌하 기와집 왼쪽, 우상 물길, 우하 실개천이 화면 밖으로 나감.

## 2단계 — 계통 (사전 어휘로 재독)

사전 대조: 빈 사발=惠, 물에 드리워 건져 올림=濟, 배(약연)=藥, 같은 것 둘 중 하나가 두 배=大, 흰 김=氣, 불꽃=熱, 끈으로 묶은 약초 다발≈典藥, 기와집≈寺, 비≈濕. 이 어휘군은 장부생리가 아니라 **한의학사(의서·기관)** 판의 문법이다. 1단계 三焦설은 철회한다.

① 재독
- 좌상 마을·논밭 = 鄕(村) → 그 앞 강을 내려오는 약재 실은 배 = 藥 ⇒ **鄕藥**
- 개천에서 뜰채로 건지는 소년 = 濟 → 바로 옆 여인의 뿌리 달린 生약초 2다발 = 生 ⇒ **濟生**(濟生院 1397 태조, 1406 醫女 양성, 1460 惠民局 병합)
- 떠내려오는 종이 2장 = 方, 뜰채로 모음 = 集(成) ⇒ **集成方**
- 빈 사발 10개 = 惠 ⇒ 惠民(局) — 『鄕藥惠民經驗方』/惠民局 병합의 표지
- 번개 3줄 = 三 ⇒ 『三和子鄕藥方』(원천 의서) 또는 三醫司
- 대장장이(金·熱·氣) = 金 성(金希善) 또는 炮製法
- 간판 1:2 = 大 (『鄕藥救急方』의 大藏都監? 미확정)
- 밥상 5첩·통발·흰 깃발 2·가슴 패 = 미해독

② 표제어
- 1순위 **『鄕藥濟生集成方』(1399, 濟生院·權仲和·金希善, 30권) — 鄕藥 의서 계보** 40%
- 2순위 **『鄕藥集成方』(1433, 世宗·兪孝通·盧重禮·朴允德 3인) / 鄕藥 계보 전체(救急方→三和子→惠民經驗→濟生集成→採取月令→集成方)** 30%
- 3순위 조선 의료기관(三醫司·濟生院·醫女) 15%

③ 잔결
- 5첩 밥상(食療? 本草?), 처마의 통발, 흰 깃발 2, 사내 가슴의 패, 大 간판의 대상, 번개 3의 대상이 미해독. 여러 갈래 물길은 사실 운반이 아니라 濟의 무대(물)로 판단. 조개 배는 藥의 강조로 읽었으나 鹹(소금 접시)과 무관함은 확인.
