# 062 판독 기록 (생판 → 계통)

## 1단계 — 생판 (그림만)

### ① 소품 전수와 나르는 사실
- 붉은 곤룡포·익선관 임금 1명: 회전 게시판을 손가락으로 가리킴 → 왕명·국가 주도.
- 회전 게시판 1개(화살표 2개로 두 면이 번갈아 돎): 약절구·공이 / 두 손으로 받쳐 든 불빛 → 제약(藥)과 구료(활인)라는 두 기능, 또는 두 이름의 교체.
- 지붕 위 왕관 3개(왼쪽 삼문 건물·그 뒤 건물·정자 뒤 건물) → 왕실·국가(관립) 기관 3곳.
- 정자에서 책 읽는 여인 2명 + 돗자리에 앉은 아이 7명 → 의학 교육(의녀 교육?).
- 중앙 청기와 2층 관청 1채: 현수막 2장(검은 갓+패 / 기와건물 그림, 갓 쪽이 약 2배 큼), 사다리 1.
- 중앙 매약소 1: 간판(국자로 사발에 부어 주는 손 + 끈으로 묶은 약꾸러미), 사다리 위에서 새 종이를 붙이는 남자 1, 점원 1, 줄 선 백성 약 10명(색옷), 자물쇠 달린 큰 궤 1(안에 자루 약 7, 바닥 1, 받아 든 것 2) → 서민에게 약·구휼품을 나눠 줌.
- 오른쪽 개방 곳간 1: 뿌리·열매 담긴 바구니 약 10개, 흰옷 백성 5명(사다리 오르는 이·문간·갓 쓴 이·걷는 이·소녀), 사다리 1, 웅크린 검은 작은 형체 1 → 약재 저장·시장(민간).
- 배경: 담·솟을대문 2·기와집 다수·나무 1.

### ② 표제어
- 1순위 **조선시대 의료기관(삼의사 내의원·전의감·혜민서 + 활인서·의녀)** 45%
- 2순위 **혜민서(惠民署)** 25% / 3순위 **의녀 제도** 15%

### ③ 뜻 모를 것·어색·잘림
- 회전 화살표의 뜻(교대? 개칭?), 갓 밑에 매달린 패, 손 위의 불빛, 궤의 자물쇠, 사다리 위 흰옷 남자가 지붕에서 하는 일, 웅크린 검은 형체, 아이 7·줄 10·바구니 10의 수 의미 불명.
- 프레임 잘림: 좌하 건물, 우하 건물, 중앙 관청 지붕 꼭대기, 우상 건물, 좌측 가장자리 건물.

## 2단계 — 계통 (사전 어휘로 재판독)

### ① 소품 재해석
- 왕관 3 = 王×3 → 국가(왕립) 의료기관 세 곳(또는 세 임금의 치세).
- 임금이 가리킨 게시판: 약절구 ≈ 藥(약연), 두 손으로 감싼 등불 = **保命** → 왕실 약·생명 보전 기관(상약국/내약방→내의원); 화살표 = 명칭이 번갈아 바뀜(상약국↔봉의서식 개칭).
- 중앙 관청 현수막: 큰 갓 = **太**, 그 아래 패 ≈ 官(3층 선반장?)·둘째 현수막의 기와건물 ≈ 寺, 두 현수막 크기 2배 = 大 → 太醫監(↔典醫寺) 계열의 중앙 의료행정·교육 관청; 정자의 여인 2·아이 7 = 그 교육 기능(조선이면 의녀).
- 매약소 간판: 받아 드는 사발 = **惠**, 끈 묶은 약꾸러미 = **典藥**, 줄 선 백성 = 民 → **惠民典藥局/惠民局(→혜민서)**; 새 종이를 붙이는 남자 = 개칭 장면.
- 자물쇠 궤에 쌓인 자루 = 藏/倉(곳간 가마니)·寶(기금) → 구휼 재원(제위보?) 혹은 약재 창고; 끈 조인 자루 = 收와 혼동 주의.
- 오른쪽 바구니 곳간 = 藏(문 열린 곳간의 저장물) → 약재 저장·민간 약재. 흰옷 인물은 肺(재상)가 아니라 백성.

### ② 표제어
- 1순위 **고려 의료기관 — 태의감(太)·상약국(藥·保命)·혜민국/혜민전약국(惠·典藥)·(동서대비원·제위보)** 40%
- 2순위 **조선 전기 의료기관 — 전의감·혜민서·활인서(保命≈活人)·내의원·의녀** 35%
- 3순위 **혜민국→혜민서 개칭사** 10%

### ③ 잔결
- 太(갓)·典藥은 고려를, 곤룡포·의녀·活人류 등불은 조선을 가리켜 시대가 갈림. 왕관 3의 정체(기관 3 vs 임금 3), 濟(밧줄) 부재로 제위보·제생원 확정 불가, 갓 밑 패=官 여부, 오른쪽 사다리 남자·검은 형체 미해독. 잘림은 1단계와 같음.
