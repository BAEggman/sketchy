# 064 판독 기록 (blind6)

## 1단계 — 생판 (그림만)

① 소품 전수와 사실
1. 임금 1인(화면 정중앙): 붉은 곤룡포, 익선관(날개 2), 용보 3개(가슴·양어깨), 뒷짐, 검정 목화 → 君主(君主之官=心) / 君藥 / 君火 / 王 후보.
2. 곡식밭(배경 전체): 고개 숙인 황금 이삭 약 10개(좌 5·우 5), 초록 잎, 좌우 프레임에서 잘림 → 稻·粳米·穀(黍?) / 가을 수확 / 脾胃·倉廩.
3. 해(우상단): 광선 14~16줄 → 陽·火·夏·熱 / 「君火以明」.
4. 아지랑이(밭 위 하늘): 가는 물결선 13~14줄(좌 6~7·우 7) → 熱·暑·蒸(김).
5. 사발 1개(임금 오른쪽 아래): 붉은 흙사발에 검은 액체, 김 3줄, 다리 넷 소반 위 → 湯(藥) / 苦 / 大渴.
6. 색: 붉은 옷=赤·火, 모래빛 땅=土.

② 표제어
- 1순위 **心 — 君主之官, 火 왕국의 오행 대응(赤·夏/熱·穀黍·苦·焦)** 35%
- 2순위 **君火(少陰君火, 「君火以明」)** 20% / 3순위 **暑溫·陽明熱證 → 白虎湯(粳米)** 15%

③ 뜻 모를·어색·잘림
- 곡식이 기장(黍)이 아니라 벼로 보임(心의 곡식 黍와 어긋남). 아지랑이가 熱인지 汗의 김인지 불명. 뒷짐 자세 의미 불명. 여름 해 vs 가을 이삭의 계절 모순. 밭 좌우 잘림. 우하단 AI 워터마크 별 무늬(소품 아님).

## 2단계 — 계통 (사전 적용)

사전 대조: 붉은 곤룡포 임금=心 ✓ / 苦=김 나는 검은 커피 ✓ / 陽=해 ✓ / 熱=불꽃(없음) / 氣=서린 흰 김(형태 다름) / 倉·藏=곳간 가마니(밭 아님) / 王=왕관(없음) / 補=따뜻한 국물 그릇.

① 재판독
1. 임금 = **心** 확정. 왕관이 없으니 王(성씨)·君藥 독법은 폐기.
2. 해 = **陽** → 心은 陽(火)의 장, 「陽中之太陽」·心主夏.
3. 김 나는 검은 사발 = **苦** → 苦入心 / 心 在味為苦.
4. 황금 이삭 밭 = 心의 五穀 **黍**(기장) 추정. 벼(稻)라면 肺의 곡식이라 불일치.
5. 밭 위 아지랑이 = 사전 미등재. 熱(불꽃) 아니고 氣(흰 김)와도 다름 → 心의 五氣 熱(暑)·夏氣를 나르는 임시 기호로 추정.

② 표제어
- 1순위 **心의 五行 배속 — 味 苦·穀 黍·氣 熱(暑)·時 夏·色 赤, 陽(火)의 장** 45%
- 2순위 **陰陽應象大論 南方 연쇄(南方生熱→熱生火→火生苦→苦生心→心生血→血生脾)** 20% — 해→아지랑이→苦 사발→임금→붉은 옷(血)→밭(脾土) 순서로 읽힘
- 3순위 **火生土(心→脾 母子 관계)** 10%
- 1단계 대비: 心 독법은 사전으로 확정(임금=心, 사발=苦, 해=陽). 白虎湯·君火 후보는 근거 소품(왕관·불꽃·湯 기호) 부재로 탈락.

③ 잔결
- 아지랑이 미등재(熱=불꽃 규약과 충돌, 판독 근거 약함). 벼/기장 구별 불가. 苦 사발이 補(따뜻한 국물)로 오독될 여지. 뒷짐 의미 불명. 舌·面·汗·脈·喜 등 心 생리 소품 전무 → 生理 판이 아닌 배속표 판으로 판정. 밭 좌우 잘림, 워터마크.
