# 065 판독 기록 (블라인드 6차)

## 1단계 — 생판 (그림만 읽음)

**① 소품 전수와 나르는 사실** (세로 막대로 좌·우 두 무대 대비)
- 좌: 살찐 남자 1(형체비만 — 肥人多痰) / 오른손으로 머리 짚고 눈 감음(頭暈目眩·頭重) / 입에서 나무 사발로 흘러내리는 흰 끈적 액 — 사발 넘침(嘔吐痰涎·痰多) / 목 옆 혹 1개(痰核·癭瘤) / 볼 홍조(痰熱? 불확실) / 왼쪽 아래 넘어진 붉은 흙독 1개에서 회색 진흙이 쏟아져 웅덩이 1개(水液停聚 → 痰濁 형성) / 회청색 옷(痰濁 색).
- 우: 마른 남자 1(消瘦·肌膚甲錯) / 온몸·손발·입술이 검자주색(面色黧黑·唇甲靑紫) / 왼손으로 가슴·옆구리 눌러 잡음(刺痛·固定不移·拒按) / 오른팔에 자반 3~4곳(皮下瘀斑) / 축 늘어진 오른팔(麻木) / 오른쪽 아래 도랑에 검은 물이 흐르고 그 가운데 검은 더미 위에 붉은 실뭉치 1개가 물길을 막음(血脈瘀阻·血塊) / 좌우 체폭 대비 약 2배(肥 vs 瘦).

**② 표제어**
- 1순위: **痰飮과 瘀血 — 病理産物 두 가지의 대비(痰證 vs 血瘀證)** 60%
- 2순위: **胸痺의 痰濁閉阻 vs 心血瘀阻** 20% (우측 가슴 움켜쥠 때문에) / 차순: 肥人多痰·瘦人多瘀 체질 대비 10%

**③ 뜻 모를 소품·어색·잘림**
- 붉은 흙독의 정체(脾胃? 津液 저장?)와 왜 넘어져 있는지 / 나무 사발의 역할(단순 받침인지) / 목 혹이 痰核인지 癭瘤인지 / 좌 볼 홍조의 뜻 / 우측 초록 저고리·노란 바지 색이 뜻을 나르는지 / 우측 배경의 흐릿한 회색 얼룩 / 붉은 실뭉치가 血塊인지 실인지.
- 잘림: 좌하 흙독이 왼쪽 틀에, 우하 도랑이 오른쪽·아래 틀에 걸려 잘림.

## 2단계 — 계통 (사전 어휘로 재판독)

**① 소품 재해석**
- 痰 = 끈적한 회백색 덩이 → 좌 입에서 흘러내리는 흰 끈적 액과 흙독에서 쏟아진 회색 진흙 웅덩이가 모두 痰. 사전의 「內燥 = 밑동까지 마른 물독」에서 물독은 津液 창고이니, 넘어진 물독이 회백 덩이를 쏟는 것은 津液이 停聚해 痰으로 변한 것 = **痰飮 생성**(下 = 아래로 쏟아짐, 盛 = 넘쳐 흘러나옴 → 痰盛). 사발 넘침도 痰盛. 목 혹 = 腫(부풀어 팽팽) + 痰 = 痰核. 살찐 몸 = 實(팽팽히 찬 것)·肥人多痰.
- 血 = 붉은 것, 瘀 = 검붉게 굳은 덩이 → 우 도랑 속 검붉은 더미(瘀) 위의 붉은 실뭉치(血) = **瘀血**이 血脈(도랑)을 막음. 검자주 피부·자반 = 瘀의 색이 皮(면 위 색 경계)로 드러남 = 瘀斑. 마른 몸 = 虛(줄어듦) → 內有乾血·肌膚甲錯. 두 몸 폭 2배 = 大 규칙의 肥·瘦 대비.
- 사전에 없는 새 사물: 도랑(血脈·經脈 유로), 넘어진 흙독(痰飮의 근원). 이 판이 등재하는 셈.

**② 표제어**
- 1순위: **痰飮과 瘀血 — 病理産物(痰·瘀)의 형성과 병증 특징 대비** 75%
- 2순위: **瘀血證(乾血·血脈瘀阻)** 단독 판 15% / 차순: 痰證 vs 血瘀證 감별(氣血津液辨證) — 1순위와 사실상 동일 축.

**③ 남은 의문·어색·잘림**
- 우측 가슴 움켜쥠에 사전의 痛 기호(쇠못)가 없어 刺痛·固定痛이 기호로 확정되지 않음. 검푸른 손발 끝은 사전상 厥과 겹쳐 오독 소지(여기서는 전신 瘀 색으로 판정). 사발 가득 찬 모습이 補(찰랑찰랑 찬 국물)와 혼동될 수 있음. 초록 저고리(肝?)·노란 바지(脾?)·좌 볼 홍조·우 배경 회색 얼룩은 뜻 미상.
- 잘림: 좌하 흙독·우하 도랑이 틀에 걸려 잘림(1단계와 동일).
