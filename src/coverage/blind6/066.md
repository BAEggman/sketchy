# 066 판독 기록

## 1단계 — 생판 (그림만)

**① 소품 전수·사실**
- 무대: 돌판 5장(위 단) + 나무 선반(아래 단). 돌판 5 = 처리법 5가지, 선반 5 = 완제품·보조재.
- 돌판1: 흙 묻은 생강 모양 생뿌리 1개 + 검남색 물방울 ~15개 → 갓 캔 生藥을 씻거나 액체(酒·黑豆汁?)로 적심(淨制·水製).
- 돌판2: 대나무 찜통 1 + 큰 흰 김, 안에 검붉은 윤나는 덩이 → 蒸法(수화공제). 熟地黃·制何首烏 꼴.
- 돌판3: 쇠 프라이팬 1, 약한 불(작은 화구), 황금색 절편 7장(±1) → 炒法(火製). 곁에 접힌 흰 천 1장(뜻 모름).
- 돌판4: 숯불 위에 직접 얹은 주황 덩이 4개 + 꿀 흐르는 나무 숟가락 1 → 蜜炙(炙法). 直火라 煨로도 읽힘.
- 돌판5: 돌덩이 1개를 통째로 태우는 큰 불(돌판4 불꽃의 약 3배, 돌판3 불의 5배 이상) + 붉은 액체 웅덩이 1 → 煅法(武火) + 淬(醋淬?). 불 세기 炒<炙<煅 3단계.
- 선반: 점적병(짙은 액체) 1 + 베이지 절편 조각 5 → 액체 보조재(酒·醋·薑汁·鹽水)와 切製 음편 / 황갈색 윤나는 덩이 사발(炒焦 또는 蜜炙品) / 연노랑 칩 나무사발(炒黃) / 검갈색 덩이 구리쟁반(炒炭 또는 熟地黃) / 자적색 가루 쇠컵(煅 후 研末? 硃砂 水飛?). 색 3단계 노랑→황갈→검정 = 炒黃·炒焦·炒炭.

**② 표제어**
- 1순위 **炮製法 총론(修治·水製·火製·水火共製)** — 洗/潤·蒸·炒·炙·煅(淬) 다섯 방법 55%
- 2순위 **火製法(炒黃·炒焦·炒炭 3단계 포함, 炙·煅)** 25% / 3순위 熟地黃·何首烏 炮製 10%

**③ 잔결**
- 돌판3 접힌 흰 천(濕紙煨? 행주?), 돌판1 검남색 방울(물? 黑豆汁? 酒?), 돌판5 붉은 웅덩이(醋? 血?), 점적병 액체 정체, 쇠컵 자적 가루 정체. 프레임 잘림 없음(우하단 희미한 마름모 자국뿐).

## 2단계 — 계통 (사전 어휘로 재독)

사전의 「地黃 = 검붉은 뿌리 조각」「氣 = 흰 김」「甘 = 나무 국자 꽂힌 꿀」「溫 = 따뜻한 천」「熱/陽 = 불꽃」「血 = 붉은 것」으로 다시 읽으면 뜻 모르던 소품이 대부분 풀린다.

**① 소품 재판독**
- 돌판1 흙 묻은 생뿌리 = 갓 캔 生地黃(鮮地黃), 방울 = 酒(酒拌) 또는 물 → 돌판2 찜통의 검붉은 뿌리 조각 = 地黃을 蒸하여 **熟地黃** 만드는 장면(生→熟, 藥性 改變). 큰 흰 김 = 氣(蒸氣).
- 돌판3 炒 + 접힌 천 = 溫 → 「炒하면 藥性이 緩和·溫化」.
- 돌판4 直火 + 꿀 국자 = 甘 → **蜜炙**(甘하게 하여 補益·潤肺 增強).
- 돌판5 광물 煅(큰 불 = 熱·陽 최강) + 붉은 것 = 血 → 煅炭·煅 광물의 **收斂止血** 효능(또는 醋淬).
- 선반: 구리쟁반의 검붉은 뿌리 조각 = 熟地黃 완제품, 연노랑 칩 = 炒黃, 황갈 덩이 = 炒焦/蜜炙品, 자적 가루 = 煅 후 研末(硃砂 水飛 가능), 점적병 = 액체 보조재, 조각 = 切製 음편.

**② 표제어**
- 1순위 **炮製法 총론 — 洗潤·蒸(地黃 예시)·炒·蜜炙·煅(淬)의 다섯 방법과 炮製에 따른 效能 변화** 60%
- 2순위 **火製法(炒·炙·煅)과 炒의 3단계** 20% / 3순위 **熟地黃 炮製(酒蒸·九蒸九曬)** 15%

**③ 잔결**
- 돌판1 방울의 액체(酒/黑豆汁/물)와 점적병 내용물은 사전에도 없어 미확정. 접힌 천은 사전의 溫과 달리 김이 없어 溫 판정 70%. 쇠컵 자적 가루는 여전히 불명(硃砂·煅赭石·血竭 중 하나). 프레임 잘림 없음.
