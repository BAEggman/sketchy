# 068 판독 기록 (blind6)

## 1단계 — 생판 (그림만 읽음)

**① 소품 전수·나르는 사실** — 4칸 2×2, 상투 튼 같은 남자가 네 가지 상태로 나뉨.
- 좌상: 팽팽히 부른 배를 두 손으로 감싼 뚱뚱한 남자, 입에서 흰 김 한 줄기(트림·噯氣), 찡그린 얼굴(惡食). 옆에 빈 그릇 무더기 — 5더미×4~5개 + 낱개 1 = 약 20개(먹은 양) → **過飽**(飮食自倍 腸胃乃傷, 脘腹脹滿·噯腐).
- 우상: 갈비뼈 6~7줄 드러난 야윈 남자(몸통 두께가 좌상 남자의 1/3), 빈 항아리 1개를 들여다봄 → **過飢**(먹을 것 없음, 氣血生化不足·形瘦).
- 좌하: 등에 장작단(통나무 15개 안팎, 밧줄 2줄)을 지고 네 발로 기며 땀방울 10여 개, 우는 얼굴, 흔들림 선; 바닥에 흩어진 장작 좌 3·우하 3 → **過勞**(勞力過度, 勞則喘息汗出·氣耗).
- 우하: 살찐 남자가 마당 돗자리 위에 목침 베고 한 무릎 세우고 눈 감고 누움 → **過逸**(安逸過度, 氣血不暢·脾胃弱·久臥傷氣).
- 네 칸 모두 담·문간·주춧돌이 배경(같은 집 마당).

**② 표제어** — 1순위 **飮食·勞逸 失宜(病因: 過飽·過飢·過勞·過逸)** 65%. 2순위 **內傷(飮食傷·勞倦傷, 東醫寶鑑 內傷門)** 20%. 3순위 五勞所傷(久臥傷氣) 5%.

**③ 뜻 모를 것·어색함·잘림** — 그릇 개수를 정확히 셀 수 없음(20개 안팎, 의도 개수 불명). 우상 항아리가 비었는지는 직접 안 보이고 자세로 짐작. 좌하 바닥의 흩어진 장작은 배경인지 기호인지 불명. 우하는 낮잠인지 병으로 누운 것인지 모호(눈 감음만 있고 병색 없음). 잘림: 좌상 그릇 더미 왼쪽 가장자리·우하 발끝이 프레임에 닿음. 특정 인물 표지(옷·소품) 없음.

## 2단계 — 계통 (사전 어휘로 다시 읽음)

**① 소품 재판독**
- 담 안쪽·문 안쪽 마당(네 칸 공통) = **內** → 外感이 아닌 **內傷** 무대. 문간 = 門(배경).
- 좌상 팽팽히 찬 배 = **實**, 입의 흰 김 = **氣**(噯氣·氣 새어나감), 그릇이 넷·다섯씩 포개짐 = **久**(오래 거듭된 과식) → 飮食傷(傷食, 實).
- 우상 몸이 좌상의 1/3로 줄어듦 = **虛**, 빈 사발 한 개(惠의 '빈 사발' 요소) = 먹을 것 없음 → 過飢 → 虛.
- 좌하 살갗의 땀방울 = **汗** → 勞則喘息汗出·氣耗(擧痛論). 장작단·네발 기기 = 勞(사전 미등재 새 소품).
- 우하 돗자리 누움 = 逸(사전 미등재). 뱃살 = 肌(도톰한 살덩이)로도 읽힘.
- 傷 기호(깨진 물건)는 어느 칸에도 없음 — 좌하 흩어진 장작은 傷으로 읽기엔 부족.
- 인물 기호(李·張·吳·오행 다섯 인물)가 전혀 없음 → 인물판이 아니라 개념판.

**② 표제어** — 1순위 **內傷 病因: 飮食(飢飽失常)·勞逸(過勞·過逸) 失度** 70% — 사전의 內·實·虛·汗·久가 1단계 판정을 그대로 뒷받침하고, 담 안쪽 배경이 '內傷'이라는 상위 틀을 추가로 준다. 2순위 **飮食傷·勞倦傷(東醫寶鑑 內傷門 二因, 東垣 飮食失節·勞役過度)** 20%. 3순위 五勞所傷 5%. 1단계와 축이 같으며 이름만 內傷 틀로 격상.

**③ 남는 것** — 勞(장작단)·逸(돗자리 낮잠)·飢(빈 항아리+갈비뼈)·飽(포개진 빈 그릇+팽팽한 배)는 사전에 없어 이 판이 새로 등재하는 기호로 보임. 좌상 김이 氣의 '새어나감'인지 단순 트림인지, 포개진 그릇이 久(장기)인지 단순 다량인지 판별 불가. 傷 자체를 그린 소품이 없어 '傷'은 문맥으로만 읽힘. 잘림은 1단계와 같음.
