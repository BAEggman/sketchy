# 069 판독

## 1단계 — 생판 (그림만)

① 소품 전수
- 왼쪽 남자: 얼굴 회백색·눈 감음·고개 떨굼, 청록 저고리, 땀방울 굵고 성김(얼굴 약 6알, 구슬 같음), 손발 창백 → 冷汗·面色蒼白·精神萎靡·四肢冷.
- 오른쪽 남자: 얼굴 붉음·입 벌려 헐떡임, 황갈 저고리, 땀이 옷까지 줄줄(20알 이상, 왼쪽의 약 3~4배, 기름처럼 끈적), 발바닥 붉음 → 熱汗·面赤·氣粗·手足溫.
- 왼쪽 등잔: 불꽃이 콩알만 하고 연기만 오름 → 油盡燈枯, 陽氣 꺼지기 직전.
- 오른쪽 사발: 물이 바닥에 조금 → 口渴喜飮·진액 고갈.
- 왼쪽 앞 나무대접: 人蔘 1뿌리 + 검은 혹덩이 1개(附子로 읽음) + 검은 즙 한 방울 → 蔘附湯.
- 오른쪽 앞 붉은 열매 1개: 위에 커피콩(苦)·자주 매실(酸)·꿀방울(甘)·소금더미(鹹)·고추(辛) = 五味 다섯 → 五味子(生脈散 계열, 斂汗生津).

② 표제어
- 1순위 **亡陽·亡陰 鑑別** (左 亡陽=冷汗·蒼白·蔘附湯 / 右 亡陰=熱汗·面赤·渴·五味子) — 65%
- 2순위 **自汗(陽虛)·盜汗(陰虛)** — 20% (왼쪽이 눈 감고 등잔 켠 밤이면 盜汗으로도 읽힘)

③ 뜻 모름·어색·잘림
- 검은 혹덩이가 附子인지 熟地黃인지 불명. 붉은 열매 왼쪽 아래 갈색 부스러기 1개 정체 불명(6번째 맛?). 생맥산이라면 麥門冬이 없음. 프레임 잘림 없음.

## 2단계 — 계통 (사전 어휘로 재독)

사전 대입: 汗=땀방울(양쪽 모두), 陽=불→등잔불, 衰=타다 남아 작아진 것→콩알 불꽃 = **陽衰/亡陽**. 陰=졸아드는 고인 물→오른쪽 사발의 바닥물 = **陰 고갈/亡陰**. 苦=검은 커피(커피콩), 甘=꿀(꿀방울), 辛=붉은 고추, 鹹=굵은 소금, 酸=매실(자주색이라 초록 매실과는 어긋남) → 붉은 열매 하나에 五味가 다 얹힘 = **五味子** 확정. 地黃=검붉은 뿌리 조각이 등재돼 있어 대접의 검은 혹덩이는 熟地黃일 가능성이 생기지만, 창백·냉한 쪽에 人蔘과 함께 놓인 점은 蔘附湯(附子)이 더 자연스러움. 厥=검푸른 손발 끝은 등재돼 있으나 왼쪽 손발은 창백만 하고 검푸르지 않음 → 四肢厥冷을 정식 기호로 쓰지 않은 잔결. 熱=불꽃은 오른쪽에 없고 붉은 피부로만 표현.

① 소품: 등잔(陽+衰) / 사발 바닥물(陰 졸아듦) / 땀(汗, 6알 대 20알+) / 人蔘+附子(蔘附湯) / 五味子(五味 다섯 얹힌 붉은 열매).
② 표제어
- 1순위 **亡陽·亡陰 鑑別(汗의 감별 — 冷汗·汗出如珠 vs 熱汗·汗出如油)** — 70%
- 2순위 **陽虛·陰虛(自汗·盜汗)** — 15%
③ 잔결: 麥門冬 부재로 生脈散이 완성 안 됨, 검은 혹덩이 附子/地黃 양립, 厥 기호 미사용, 酸이 초록 매실 아닌 자주 열매, 五味子 위 갈색 부스러기 1개 정체 불명. 잘림 없음.
