# blind6 / 070 판독 기록

## 1단계 — 생판(그림만)

① 소품 전수와 나르는 사실
- 온 바닥과 둑 절벽의 갈라진 마른 땅 → 燥의 본성 乾澀·乾裂(燥性乾澀, 易傷津液).
- 왼쪽으로 굽어 사라지는 말라붙은 개울길 → 물(津液) 고갈.
- 빈 나무 물통(쇠테 2줄, 바닥까지 텅 빔) → 津液 없음.
- 갈라지고 테두리 한 조각 깨진 화분 속 시든 식물 1그루 → 傷津·枯痿, 화분 금은 皮膚皸裂 대응.
- 갈잎 낙엽 1장, 갈색으로 물든 나무 1그루, 뿌연 회색 하늘 → 秋(燥의 主氣), 열·한 표지 없음.
- 둑 위 초가집 1채 → 배경(뜻 불명).
- 상투 튼 남자: 갈비뼈 드러난 마른 몸(形體消瘦), 얼굴·팔·손에 땅과 같은 금 무늬(皮膚乾澀), 마른 입술·벌린 입(口乾), 찡그린 채 오른손을 가슴에 누름(肺 손상·乾咳, 燥易傷肺), 늘어진 왼팔, 맨발, 팔꿈치 해진 소매, 바지 헝겊 2장(청록·적갈).

② 표제어: 1순위 **燥邪(六淫의 燥, 燥淫)** 70% / 2순위 **津液虧虛(傷津)·肺燥(秋燥)** 20% / 기타 肺痿·肺陰虛 10%.

③ 뜻 모를 것·어색·잘림: 초가집, 바지 헝겊 2장의 색, 맨발, 적갈 허리띠, 물통의 쇠테 2줄은 뜻 미상. 熱·寒 표지가 없어 溫燥·涼燥 구분 불가. 프레임: 나무 꼭대기가 상단에 닿고 초가집이 오른쪽 가장자리에 잘림(경미).

## 2단계 — 계통(사전 어휘로 재독)

① 소품 재판독
- 갈라진 땅 + 마른 잎 = 사전 그대로 **燥**. 낙엽 1장이 「마른 잎」 기호, 땅 전체가 「갈라진 땅」 기호.
- 초가집이 앉은 흙둑 = 담, 남자·물통·화분은 모두 담 바깥 = **外** → 이 판은 外燥(外感 燥邪) 무대. 남자는 흰 도포 재상(肺)이 아니므로 장부 의인화가 아니라 환자.
- 바닥까지 마른 나무 물통 ≈ 「밑동까지 마른 물독」(內燥) 기호와 닮음 — 재질이 물독이 아니라 물통이라 內燥 병발 표시인지 단순 津液 고갈인지 불확실.
- 깨진 화분 = **傷**(깨져 못 쓰게 된 물건), 그 안의 시든 식물 = 燥에 마른 것 → 燥易傷津(液)로 읽힘.
- 벌린 입의 어두운 타원 = **口** + 燥 → 口乾·唇燥. 피부의 금 무늬는 燥 기호를 살갗에 옮긴 것 → 皮膚乾澀.
- 가슴에 얹은 손: 사전 기호 없음(痛의 쇠못 없음) → 자연 독법으로 肺·乾咳(燥易傷肺).
- 風(눕고 날림)·熱(불꽃)·寒(눈송이)·濕(진창) 기호 전무 → 순수 燥 단독, 溫·涼 미표시.
- 눈은 반쯤 감겨 目 아님, 虛(삼분의 일)·久(셋 포갬) 기호 없음.

② 표제어: 1순위 **燥邪(外燥) — 燥性乾澀·易傷津液·易傷肺** 80% / 2순위 **內燥·津液虧虛(傷津 결과)** 12% / 기타 秋燥(溫病) 8%. 1단계 판정을 유지하되 사전의 「담 바깥=外」로 外燥가 확정되어 확신 상승.

③ 잔결: 나무 물통이 內燥 기호(물독)와 동일한지 미확정. 헝겊 2장·맨발·허리띠·쇠테 2줄·초가집 세부(창 수 등)는 사전에 없어 뜻 미상(장식으로 추정). 프레임 잘림은 경미.
