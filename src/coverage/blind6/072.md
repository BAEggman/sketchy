# 072 판독

## 1단계 — 생판(그림만)

① 소품 전수와 나르는 사실
- 왼쪽 남자(1): 상투, 청록 도포, 여윈 얼굴·팔다리, 근심 표정, 뒤로 기대 반쯤 누움(倦怠·無力), 팔짱(拒按 또는 惡寒), 배만 둥글고 팽팽하게 튀어나옴(腹脹·腹大, 배꼽 노출), 신 2짝. → 四肢瘦削+腹大 = 脹滿 환자.
- 오른쪽 남자(1): 상투, 황금색 도포가 풍선처럼 부풀어 몸집이 왼쪽의 약 2배, 팔꿈치 둘·옆구리에 움직임 선 3묶음(지금 부풀어 오르는 중), 두 손으로 제 배를 감싸 누름(喜按), 배꼽 노출, 웃는 얼굴, 흰 바지·검은 신. → 氣가 차서 건강해진 사람(補의 결과) 또는 氣脹.
- 무쇠 솥(1): 발 3, 고리 손잡이 1, 뚜껑을 열어 옆에 기대 놓음, 아가리는 검은 타원. 불·김·국물 없음. → 湯(煎藥) 또는 鐵器.
- 인삼 뿌리(1): 蘆頭(머리)·팔 2·다리 2의 사람 꼴, 잔뿌리 4~5, 오른쪽 남자 발치에 누움. → 人蔘.
- 크기 대비: 오른쪽 남자 폭 ≈ 왼쪽의 2배 / 왼쪽 배 ≈ 얼굴의 1.5배 / 솥 높이 ≈ 왼쪽 남자 앉은키의 1/2.

② 표제어
- 1순위 **人蔘(補氣·補脾)** — 야윈 腹脹 환자 → 인삼 달인 탕 → 氣가 가득 차 두 배로 부푼 사람. 大補元氣·補脾益肺(氣虛·脾虛腹脹 主治). 40%
- 2순위 **塞因塞用(脾虛脹滿에 補法)** — 脹滿(塞)에 補藥(塞)을 쓰는 反治法. 30%
- 3순위 **鼓脹(腹大肢瘦)** 15% / **厚朴生薑半夏甘草人蔘湯(汗後腹脹滿)** 10%

③ 뜻 모를 것·어색한 것·프레임 잘림
- 솥에 불·김·국물이 전혀 없음 — 煎藥 장면인지, 忌鐵器 같은 금기 표시인지 판단 불가.
- 오른쪽 남자는 옷만 부풀고 배는 맨살로 열려 있음(옷이 풍선) — 補氣의 결과인지 氣脹인지 모호.
- 왼쪽 팔짱: 拒按(實)인지 惡寒인지. 오른쪽 손이 과장되게 큼.
- 프레임 잘림 없음(소품 전부 화면 안).

## 2단계 — 계통(사전 적용 후)

사전에서 맞아떨어진 글자: 「大 = 같은 종류 둘이 나란한데 하나가 두 배」 — 같은 차림의 두 남자, 오른쪽이 두 배 → **大**. 「實·腫 = 팽팽하게 찬·부푼 것」 — 왼쪽 배와 오른쪽 옷. 「補 = 그릇에 찰랑찰랑 찬 따뜻한 국물」 — 솥이 근사치(국물·김은 안 보임). 「口 = 어두운 타원 구멍」 — 솥 아가리(우연일 수도). 반면 氣(흰 김)·虛(1/3로 줄어듦)·寒(눈송이)·痛(쇠못) 글자는 없음 → 두 남자의 크기차는 虛(1/3)가 아니라 大(2배)로 읽어야 한다. 1단계에서 "부풀어 오름=氣"로 본 것은 사전상 근거가 없고, 大 글자가 정식 근거다.

다시 읽기: 人蔘 + 大 + 補(솥) + 몸집이 두 배로 부풀어 오름 = **人蔘 大補元氣**. 왼쪽 야윈 腹脹 남자 = 脾氣虛(補脾益肺)의 主治 장면, 솥 = 탕(獨參湯) 또는 煎法.

① 소품별 사실: 두 남자 크기차 = 大 / 사람 꼴 뿌리 = 人蔘 / 솥 = 補·湯 / 오른쪽 부풀어 오름 = 補元氣의 효과(實·腫) / 왼쪽 팽팽한 배 = 脾虛脹滿 主治 / 솥 발 3 = 歸經 셋(脾·肺·心)? / 인삼 팔다리 4·잔뿌리 4~5(의미 미확정).
② 1순위 **人蔘 — 大補元氣(補脾益肺)** 45% / 2순위 **塞因塞用(脾虛腹脹에 補法)** 20% / 3순위 **鼓脹(腹脹身皆大·色蒼黃 — 청록·황금 옷)** 15% / **大建中湯(人蔘·出見有頭足)** 10%.
③ 잔결: 補의 정식형(찰랑이는 국물)이 아니라 뚜껑 연 검은 빈 솥이라 補인지 湯·鐵器인지 미확정. 元氣를 나르는 글자(흰 김)가 없음. 왼쪽 배가 왜 팽팽한지(脾虛 主治인지 實證 忌用 경고인지) 미확정. 청록·황금 옷 색(蒼黃)이 鼓脹 단서인지 우연인지.
