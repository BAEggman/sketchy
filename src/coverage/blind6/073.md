# blind6 / 073.png 판독 기록

## 1단계 — 생판(그림만)

① 소품 전수·나르는 사실
- 돌문틀+반쯤 열린 나무문(판 8개, 경첩 2개), 문지방에 선 남자 → 문 안팎 경계의 '반쯤' = 半表半裏, 경첩 = 樞(少陽爲樞).
- 남자(가운·슬리퍼): 오른손으로 명치~옆구리 움켜쥠, 눈 꼭 감고 입 다문 찡그림 → 胸脇苦滿, 默默(말없음)·心煩, 눈 감음 = 目眩(추정).
- 벽의 추(펜듈럼) 1개가 왼쪽 불꽃 1·오른쪽 눈꽃 1 사이를 왕복(양쪽 운동선) → 往來寒熱.
- 발치 작은 잔(검은 액체)+방울 1 → 쓴 것 = 口苦(방울 하나 = 咽乾?).
- 받침대 쟁반 위 약재 3: 회색 잔뿌리 뿌리(柴胡), 노란 속 빈 뿌리(黃芩·枯芩), 흰 구근(半夏) → 小柴胡湯 주약 3.
- 천칭저울 1대, 수평 → 和解(균형).
- 바닥 엎어진 그릇 3(쇠대야·갈색 항아리·손잡이 잔) → 嘔(대야), 不欲飲食(빈 밥그릇·잔) 또는 汗吐下 三禁의 버림.
- 왼쪽 바닥 접힌 청록 수건 1 → 汗(발한 도구 버림?) 미확정.

② 표제어
- 1순위 **少陽病·小柴胡湯證**(往來寒熱·胸脇苦滿·默默不欲飲食·心煩喜嘔, 半表半裏 → 和解) 70%
- 2순위 **少陽病 治禁(禁汗吐下)/和解法** 12%, 3순위 瘧(寒熱往來) 8%

③ 뜻 모를 것·어색·잘림
- 수건의 뜻(汗? 이불? 도어매트?) 불명. 갈색 항아리(밥그릇/요강?), 손잡이 잔(음료/변통?) 정체 불명. 흰 구근(半夏 vs 마늘), 회색 뿌리(柴胡 vs 桔梗) 확정 불가. 잔 위 방울(어두운 색) 용도 불명. 문 판 8개가 수치(柴胡 八兩?)인지 장식인지 불명. 목욕가운·슬리퍼가 단순 '환자' 표지인지 불명. 프레임 잘림 없음.

## 2단계 — 계통(사전 어휘로 재독)

사전 대조: 熱=불꽃·寒=눈송이 → 추가 그 둘 사이를 오감 = **往來寒熱** 확정(降=내리누르는 저울추와는 달리 좌우 운동선). 表=문 밖·裏=속·內=문 안쪽·中=둘 사이 한복판 → 문지방에 선 남자 = **半表半裏** 확정, 경첩 = 樞. 和=수평으로 멎은 양팔 저울 → **和解**(和解少陽) 확정. 苦=김 나는 검은 커피 → 발치 검은 잔 = **口苦**(단, 김 대신 방울 1 → 咽乾 겸 표기로 추정, 津=맑은 방울과는 색이 달라 津 아님). 痛=쇠못이 없으므로 움켜쥔 손은 痛이 아닌 **苦滿**(胸脇苦滿)으로 읽힘. 口=어두운 타원 구멍이 없고 입을 다물었으니 **默默**. 目=크게 뜬 눈이 아니라 감은 눈 → 目眩 암시(사전 외). 汗=살갗 땀방울이 없으므로 수건은 汗 기호가 아님 → 미등재 소품. 便=大便 손잡이 통·小便 요강 기준으로 보면 바닥의 갈색 항아리=요강(小便), 손잡이 잔=변통(大便)일 가능성 → 대야(吐)와 함께 **汗·吐·下 三禁**(바닥에 버려짐)으로 읽히며, 이 경우 수건=汗 도구가 됨. 대안은 默默不欲飲食·喜嘔(빈 그릇·대야). 약재 3종은 사전 미등재 → 자연 형태로 柴胡·黃芩·半夏.

② 표제어
- 1순위 **少陽病(小柴胡湯證: 往來寒熱·胸脇苦滿·默默·口苦, 半表半裏·和解)** 85%
- 2순위 **小柴胡湯(方)·少陽三禁(禁汗吐下)** 10%

③ 잔결
- 수건·바닥 그릇 3의 확정 코드 없음(三禁 vs 不欲飲食). 잔 위 어두운 방울의 뜻(咽乾?) 불명. 문 판 8개 수치 여부 불명. 프레임 잘림 없음.
