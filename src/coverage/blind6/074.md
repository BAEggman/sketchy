# 074 판독

## 1단계 — 생판 (그림만)

① 소품 전수
- 석조 성벽·성루 3곳(좌·중·우 톱니 흉벽) = 몸의 체표·성곽(衛外). 아치형 나무 대문(문짝 2·쇠고리 2·굳게 닫힘) = 腠理·汗孔, 두 사람은 그 앞(밖)에 섬 = 표증.
- 바람: 굵은 소용돌이 약 6가닥 + 나선 2개, 양쪽 모두를 휘감음 = 風邪·惡風.
- 왼쪽 남자: 얇은 회청 홑옷이 앞이 헤벌어진 채 펄럭임 = 表虛·腠理疏; 이마·볼 땀방울 4개 = 自汗出; 눈 감고 찡그림 = 惡風; 뒷목 잡음 = 頭項強痛; 맨발 샌들 = 가벼운 차림; 손에 적갈색 잘린 잔가지 다발 약 7개 = 桂枝 → 桂枝湯.
- 오른쪽 남자: 두툼한 황갈 솜옷+붉은 목도리+허리띠+가죽 장화 = 惡寒(중무장); 팔·양다리 곁 떨림선 3곳 = 寒戰·身疼; 얼굴에 땀 없음 = 無汗; 뒷목 잡음 = 項強; 손에 녹색 마디 줄기 다발 약 5개 = 麻黃 → 麻黃湯.
- 두 사람 공통: 양 팔뚝(손목~팔꿈치)에 푸른 물막 → 공통 脈浮(맥이 물처럼 겉에 뜸)로 읽힘. 옷 두께 대비 오른쪽이 왼쪽의 약 3배.
- 우하단 흐린 반짝이 1개 = 의미 미상(눈송이?).

② 표제어
- 1순위 **太陽病 中風(桂枝湯證·表虛) vs 傷寒(麻黃湯證·表實) 감별** — 70%
- 2순위 **太陽病 提綱(脈浮·頭項強痛·惡寒)** — 15% / 3순위 **營衛不和(桂枝湯)** — 10%

③ 뜻 모를 것·어색한 것
- 푸른 팔뚝 막: 땀이면 無汗인 오른쪽에 있을 리 없음 → 脈浮 추정이나 확정 못함.
- 닫힌 대문 하나뿐 → 中風(腠理開)·傷寒(腠理閉) 구분 표지 없음.
- 脈 緩·緊 구분 표지 없음, 寒(눈송이·얼음) 표지 없음(우하단 반짝이가 그것인지 너무 흐림).
- 프레임 잘림: 없음(성벽 좌우가 테두리에 걸치나 배경).

## 2단계 — 계통 (사전 어휘로 재독)

① 사전 어휘로 다시 읽은 소품
- 表 = 문 밖: 두 사람이 닫힌 성문 밖에 섬 → 표증 확정(裏 = 성 안). 門은 몸에 얹지 않았으니 汗孔 표지가 아니라 表/裏 경계.
- 風 = 옆으로 흘러 날리는 것: 소용돌이+왼쪽 옷자락이 옆으로 날림 → 왼쪽이 中風·惡風.
- 汗 = 살갗의 땀방울: 왼쪽 4개(汗出), 오른쪽 0(無汗) — 감별 핵심.
- 實 = 팽팽하게 찬 것: 오른쪽 솜옷이 팽팽 → 表實(麻黃湯證). 虛: 왼쪽 홑옷 헐거움 → 表虛(桂枝湯證). 두께 대비 약 3배.
- 惡 = 해로운 것과 사람 사이의 가리개: 오른쪽 목도리·솜옷이 寒과 사람 사이 가리개 → 惡寒.
- 충 = 맨팔뚝 위에 더해진 것: 두 사람 다 소매 걷은 팔뚝에 푸른 물막 — 사전에 脈·浮 항목이 없어 "팔뚝(촌구)에 뜬 물 = 脈浮"로 읽되 공통 표지로만 봄.
- 桂枝·麻黃은 사전 밖 신규 사물(적갈 잔가지 7·녹색 마디 줄기 5).

② 표제어
- 1순위 **太陽病 中風(桂枝湯證·表虛) vs 傷寒(麻黃湯證·表實) 감별** — 75%
- 2순위 **太陽病 提綱(脈浮·頭項強痛·惡寒)** — 10% / 3순위 **營衛不和** — 5%

③ 잔결
- 太 = 큰 갓, 陽 = 해가 없어 「太陽」 이름표는 그림에 없음(表·項強·惡寒으로 유추만).
- 寒 = 눈송이가 오른쪽에 없음(우하단 흐린 반짝이가 눈송이라면 너무 작음) → 傷寒의 寒이 옷·떨림으로만 표현됨.
- 痛 = 쇠못이 없어 「頭項強痛」이 아니라 「項強」까지만 읽힘.
- 푸른 팔뚝 막은 사전 미등재 기호(陰=얼음과 혼동 여지) → 脈浮 여부 확정 불가, 緩·緊 구분 없음.
