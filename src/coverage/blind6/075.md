# 075 판독 기록 (blind6)

## 1단계 — 생판 (그림만 읽음, 다른 자료 미열람)

① 소품 전수와 나르는 사실
- 무대: 상자형 방. 왼쪽 벽에 유리 낀 문 1짝이 바깥쪽으로 열려 있음 → 밖에서 바람이 방 안으로 듦.
- 커튼봉 1개(양끝 장식) + 회록색 커튼 1장(고리 약 7개)이 오른쪽으로 크게 눕듯 날림 → 바람(風)이 방을 가로지름.
- 같은 얼굴·같은 옷(붉은 스웨터·황갈 바지·회색 구두)의 남자 3명, 피부는 모두 청회색.
  - 남1(왼쪽): 고드름 8~10개 달린 흰 숄을 두 손으로 꽉 여밈, 머리·어깨 옆 떨림선, 얼굴에 땀방울 1~2 → 惡寒·寒戰(震顫), 땀.
  - 남2(가운데): 눈 감고 찡그림, 관자놀이 땀 1, 두 손으로 배를 감쌈, 배꼽 자리에 쇠못 1개 박힘 → 통증(腹痛/體痛)·냉한.
  - 남3(오른쪽): 팔을 내린 채 뻣뻣이 직립, 눈 크게 뜨고 동공 작음(直視), 입 꾹 다묾 → 強直(項強)·口噤·直視.
- 아이 1명(어른의 약 절반 남짓 크기, 붉은 상의·청회 바지·적갈 신발): 고개 뒤로 젖힘, 눈 위로 치뜸, 입 벌림, 주먹 쥔 팔 굽힘, 다리 벌림 → 角弓反張·抽搐·目上視.
- 아이 발치에 흰 파편 7조각(깨진 유리/그릇) → 깨짐(破).

② 표제어
- 1순위 **破傷風** 30% — 깨진 파편(破)+몸에 박힌 못(傷)+바람(風)의 낱말 분해에, 증상 열이 惡寒(초기)→상처 통증→口噤·項強·直視→角弓反張·抽搐으로 이어짐.
- 2순위 **痙病(金匱要略 痙濕暍病篇 — 剛痙·柔痙)** 25% — 惡寒(剛)/汗出(柔) 대비, "瘡家 身疼痛 汗出則痙", 頸項強急·卒口噤·背反張.
- 그 외: 六淫 寒邪(傷陽·凝滯→痛·收引→拘急) 20%, 風邪(開泄→汗·惡風, 主動→震顫·項強·抽搐) 15%. 첫인상은 이쪽이었으나 바닥 파편과 못을 설명하지 못해 내림.

③ 뜻 모를 것·어색한 것·잘림
- 전원 청회색 피부가 寒 표지인지 이 책의 기본 인물색인지 모름.
- 남1이 惡寒(고드름)과 땀을 동시에 가짐 — 無汗/有汗 대비가 안 읽힘.
- 파편이 유리인지 얼음인지 이(齒)인지 불명(齘齒 가능성).
- 왜 네 번째 인물만 아이인지(小兒/작음/驚), 커튼 고리 수(약 7)에 뜻이 있는지 불명.
- 프레임 잘림: 없음. 문의 바깥쪽 가장자리가 남1 뒤에 가려짐.

## 2단계 — 계통 (사전요약 적용 후 재판독)

사전 대응
- 風 = 한쪽으로 눕고 옆으로 흘러 날리는 것 → 커튼. 傷 = 터져·깨져 못 쓰게 된 물건 → 바닥 파편. 痛 = 살에 박힌 쇠못 하나 → 남2의 못(상처가 아니라 '통증' 부호). 汗 = 살갗의 땀방울 → 남1·남2. 惡 = 해로운 것과 사람 사이의 가리개 → 남1의 숄(문으로 드는 바람·냉기를 막음) = 惡寒/惡風. 門·表/內 → 열린 문으로 外風이 內로 침입. 目 = 크게 뜬 눈 → 남3의 直視. 口 = 어두운 타원 구멍 → 아이의 벌린 입. 上 = 머리 꼭대기로 솟음 → 아이의 치뜬 눈(目上視). 大 = 같은 종류 둘 중 하나가 두 배 → 어른 옆의 아이. 中 = 같은 것 셋 중 가운데 → 남2가 中으로도 읽힘.
- 寒은 사전상 '눈송이'인데 눈송이는 없고 고드름(얼음 = 陰 계열)뿐 → 寒邪 판일 가능성 하락. 피부색 항목은 사전에 없음 → 기본 인물색으로 판정.

① 재판독: 오른쪽 끝에 傷(파편)과 風(커튼)이 나란히 놓여 "傷+風"이 조립되고, 문(門)으로 바람이 內로 들어오는 무대 = 상처로 風邪가 침입하는 그림. 세 남자는 증상 열 — 惡寒·땀(초기), 痛(상처 통증)·땀, 口噤·項強·直視 — 이고 아이는 角弓反張·目上視·抽搐.

② 표제어
- 1순위 **破傷風** 35% — 傷+風 부호 결합, 外風 침입 무대, 惡寒→통증→牙關緊閉·項強→角弓反張의 경과.
- 2순위 **痙病(金匱 痙濕暍病 — 剛痙·柔痙)** 30% — 傷 = 瘡家, 痛 = 身疼痛, 汗 = 汗出則痙, 風 = 風病, 惡寒 = 剛痙, 項強·口噤·背反張. 다만 남1에 땀이 있어 剛(無汗)/柔(有汗) 대비가 흐림.
- 3순위 傷寒論 太陽病 綱領(中風·傷寒) 15% — 中(세 명 중 가운데)+風, 傷+寒으로 읽을 수는 있으나 부호가 멀리 떨어져 약함. 六淫 風邪 10%.

③ 잔결·어색·잘림
- 고드름을 寒(눈송이) 아닌 陰(얼음)으로 써야 하는지, 惡寒 표기 방식이 사전에 없어 미확정.
- 남1의 惡寒+汗 동거, 아이 크기가 大 장치인지 小兒인지, 커튼 고리 수의 뜻은 여전히 불명.
- 프레임 잘림 없음.
