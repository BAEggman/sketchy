# 076 판독 (blind6)

## 1단계 — 생판 (그림만)

① 소품 전수 → 사실
- 회색 하늘·부슬비, 온몸이 젖어 뚝뚝 듣는 사내 1 = 冒雨(외습 병인), 濕은 陰邪(어둡고 흐림).
- 진창길·발밑 흙탕 웅덩이 1 = 涉水. 초가집 처마 물방울·이끼 낀 흙담 = 居處潮濕.
- 무릎 아래 두 다리에 두껍게 눌어붙어 흘러내리는 진흙(양다리 2) = 濕性重濁(무겁고 탁함)·黏滯(끈적하게 달라붙음)·趨下(하체에 몰림).
- 무릎 헝겊 덧댐 2개(좌 회색·우 갈색) = 관절 병소, 오래 끌어 기움(纏綿).
- 구부정한 허리·축 늘어진 왼팔·찡그린 얼굴 = 身重·困倦·四肢困重. 오른손이 배를 누름 = 濕困脾 → 脘腹脹滿.
- 넘어져 갈색 탁한 액체를 쏟는 항아리 1 = 濁한 배설물(濡瀉·小便渾濁) 또는 水濕이 담기지 못하고 넘침.
- 잎에서 물이 듣는 곧게 선 나무 1 = 바람 없음(風 아님, 濕 단독).

② 표제어: 1순위 **濕邪(六淫의 濕)의 성질과 致病 특징 — 外濕(冒雨涉水·居處潮濕)** 72%. 2순위 **濕性趨下·「傷於濕者 下先受之」** 15%. 3순위 濕痹(著痹) 8%.

③ 불명: 항아리 액체 정체(술·설사·탁뇨?), 가슴을 풀어헤친 뜻(皮肉筋脈?), 왼팔 늘어짐·오른팔 오그림의 비대칭(痿/拘?), 나무의 역할. 프레임: 나무 윗부분 잘림, 항아리 오른쪽 흰 얼룩(제작 잔흔).

## 2단계 — 계통 (사전 적용 후)

사전 어휘로 다시 읽으면: 濕(外濕)=부슬비·안개·진창길 — 셋 다 있음. 外=담 바깥 — 사내와 항아리가 흙담 바깥에 서 있음(집은 담 안=內). 下=아래로 쏟아짐 — 넘어진 항아리가 액체를 아래로 쏟고, 진흙도 하체에만 몰림. 風=한쪽으로 눕고 날리는 것 — 나무가 곧고 물이 수직으로 들으니 風 없음. 汗=살갗의 물방울 — 얼굴·가슴의 방울은 汗出沾衣로 읽힘. 痛(쇠못)·脾(밀짚모자 농부)·便(뒷간통)·瀉(빗자루)·傷(깨진 물건: 항아리 멀쩡) 없음 → 痹·脾濕·濡瀉·傷은 표제어가 아님. 陰=고인 물 — 발밑 웅덩이가 濕爲陰邪를 거듦. 內濕(발밑에서 배어나는 진창)은 뚜렷하지 않아 外濕 단독 판.

읽힌 축은 「外濕 → 下」: 온몸이 비를 맞아도 병은 다리·발(하체)에 내려앉는다.

② 표제어: 1순위 **濕性趨下·易襲陰位 / 「傷於濕者 下先受之」(素問·太陰陽明論)** 58%. 2순위 **濕邪 총론(外濕: 陰邪·重濁·黏滯·趨下, 冒雨涉水·居處潮濕·汗出沾衣)** 28%. 3순위 濕勝則濡瀉 6%.

③ 잔결: 항아리 갈색 액체가 下(쏟아짐)인지 濁·盛(넘침)·甘(꿀)인지 사전만으로는 확정 못 함. 무릎 덧댐 2개는 사전 기호 없음(久는 셋 포갬이어야 함). 팔 비대칭(拘/痿)은 筋 기호가 없어 보류. 열린 가슴은 肌·皮 기호일 수 있으나 '地之濕氣 害皮肉筋脈'까지 읽기엔 약함.
