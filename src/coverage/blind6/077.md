# 077 판독 기록

## 1단계 — 생판(사전 없이, 그림만)

① 소품 전수
- 무대: 기와지붕 한옥·돌담·작은 대문이 있는 조선 마을 마당. 2×2 네 칸이 모두 같은 무대 → 한 표제어의 사실 넷. 상투·맨발 사내 넷(청록 저고리 2명=좌열, 겨자색 저고리·붉은 띠 2명=우열 → 두 사람 × 두 장면).
- 좌상: 힘없이 선 사내, 머리 양옆으로 김 2줄기 솟음 → 發熱(身熱) 또는 頭痛·上逆.
- 우상: 돌기둥 둘 사이에 선 사내, 두 손으로 배를 움켜쥐고 찡그림, 배에서 김 1덩이가 오른쪽으로 크게 터져 나가고 왼쪽 허리께에도 작은 김 → 腹痛·腹滿(가스·脹).
- 좌하: 허리 굽혀 입에서 물줄기·방울을 토함, 머리 뒤로 김 1줄기 → 嘔吐.
- 우하: 땅에 판 구덩이 위에 쭈그려 배를 안고, 다리 사이로 굵은 물줄기가 구덩이로 쏟아짐 → 泄瀉·下利(물 같은 변, 양이 많음=益甚).
- 약재·도구 소품이 전혀 없음 → 처방판이 아니라 병증판.

② 표제어
- 1순위 **霍亂**(嘔吐而利·發熱頭痛身疼 — 上吐下瀉) 45%
- 2순위 **太陰病 提綱**(腹滿而吐·自利益甚·時腹自痛) 20%
- 그 밖에 傷食(噯腐·腹脹·嘔吐·泄瀉), 藿香正氣散·香薷散 적응증 각 10% 안팎.

③ 불명·어색·잘림
- 김의 뜻이 熱인지 氣·汗인지 불명. 우상 배에서 옆으로 흐르는 김(가스? 腸鳴?) 불명. 저고리 두 색의 뜻 불명. 좌상 사내는 김 말고는 증상 표지가 없어 가장 약한 칸. 프레임 잘림 없음(네 칸 모두 온전).

## 2단계 — 계통(사전 적용 후)

사전 어휘: 김=氣, 불꽃=熱, 눈송이=寒, 못=痛, 머리 꼭대기로 솟음=上, 아래로 쏟아짐=下, 둘 사이 한복판=中, 넘쳐 흘러나옴=盛, 옆으로 흘러 날림=風, 담 안쪽=內, 큰 갓=太, 얼음=陰, 언 손발=厥.

① 다시 읽기
- 좌상: 氣가 머리 꼭대기로 곧게 솟음 = **氣上**(上氣·氣逆). 불꽃이 없으니 發熱이 아니다(1단계 정정).
- 우상: 돌기둥 둘 사이 = 中, 배 속 氣가 넘쳐 옆으로 흘러 나감 = **中滿·腹中雷鳴**(氣亂於腸胃). 못이 없으니 痛이 아니라 「滿而不痛」의 脹滿(1단계 腹痛 정정).
- 좌하: 吐 + 氣上 = 胃氣上逆의 **嘔吐**.
- 우하: 아래로 쏟아짐 = 下 → **下利·泄瀉**(구덩이는 뒷간통이 아니므로 便이 아니라 「下」로 읽음).
- 무대가 담 안쪽 = 內(裏, 腸胃).
- 좌열(청록)=上·吐, 우열(겨자)=中·下 → 「上吐下瀉」 축. 熱·寒·痛·太(갓)·陰(얼음)·厥이 모두 없음 → 太陰病·厥陰病, 五苓散/理中丸(熱多/寒多) 분별은 그려져 있지 않다.

② 표제어
- 1순위 **霍亂**(「嘔吐而利, 此名霍亂」 傷寒論 382 / 「亂於腸胃, 則爲霍亂」 靈樞·五亂 — 氣가 위·옆으로 亂하고 吐·下) 50%
- 2순위 **脾胃 升降失常**(胃氣上逆→嘔吐, 中氣下陷→泄瀉) 15%
- 3순위 **三焦**(上焦如霧·中焦如漚·下焦如瀆 — 좌상·우상·우하는 맞으나 좌하 嘔吐칸이 안 맞음) 8%
- 太陰病 7%(太·陰 기호가 사전에 있는데도 쓰이지 않음).

③ 잔결
- 우상의 옆으로 흐르는 氣를 風·格(문틈으로 밀려남)·腸鳴 중 무엇으로 읽어야 하는지 미확정. 좌상은 氣上 외 표지가 없어 乾嘔·噫·頭痛 어느 것인지 불명. 저고리 두 색의 뜻 없음. 잘림 없음.
