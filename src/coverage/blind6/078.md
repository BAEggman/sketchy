# 078 판독 (blind6)

## 1단계 — 생판 (그림만)

① 소품 전수
1. 닫힌 돌방(석벽 지하 감옥) 1 — 속·안의 찬 곳(裏, 陰의 장소)
2. 무릎 꿇은 중년 남자 1(황토색 도포·붉은 옷깃·샌들) — 환자. 황색 옷 → 脾(土) 암시
3. 크게 부푼 맨 배 1, 양옆 진동선 2쌍 — 腹滿(복부 창만)
4. 붉은 천 1을 오른손으로 명치에 눌러 댐 — 喜溫喜按(따뜻함·누름을 좋아함) → 虛寒
5. 찡그리고 처진 얼굴 — 腹痛·불편
6. 창문 틈 1 + 고드름 약 5개 + 눈 결정 4개 — 寒. 바깥 냉기가 안으로 들어옴
7. 쓰러진 손잡이 항아리 1 + 갈색 액체가 아래로 흘러나감 — 自利(설사) 또는 吐
8. 흰 밥이 가득 담긴 그릇 1, 손대지 않음 — 食不下(먹지 못함)

② 표제어
- 1순위 **太陰病 提綱證**(腹滿·自利·食不下·腹痛, 裏虛寒 → 當溫之·宜四逆輩) 55%
- 2순위 **理中湯證(中焦虛寒·脾陽虛)** 25%
- 3순위 附子粳米湯(밥=粳米, 腹中寒氣·嘔吐) 10%

③ 뜻 모름·어색·잘림
- 항아리가 吐인지 下利인지 하나로 못 정함
- 창문의 역할(냉기 입구 외 뜻이 있는지), 샌들·붉은 옷깃 의미 불명
- 통증 전용 기호가 없고 표정뿐
- 프레임 잘림: 창문 상단이 위 테두리에 잘림(경미), 그 외 없음

## 2단계 — 계통 (사전 적용 후)

① 소품 재판독
1. 눈송이 4 = **寒**(확정). 고드름 5 = 얼음 덩이 = **陰** → 陰+寒 = 陰寒
2. 성 안(닫힌 돌방) = **裏** → 裏寒
3. 쏟아진 항아리 = **下**(아래로 쏟아짐) + 손잡이 통·갈색 = 便에 근사 → **下利(自利)**. 上이 없으니 吐가 아님
4. 팽팽히 부푼 배 = 腫(부풀어 팽팽)의 꼴 → **腹滿**. 단 사전대로면 實(팽팽히 찬 것)로도 읽혀 虛滿과 어긋날 위험
5. 붉은 천 = **溫**(따뜻한 천)이어야 하나 사전이 요구하는 김이 없음 → 글자대로는 血(붉은 것)로 오독 가능. 천 자리가 몸통 한복판 = **中** → **溫中**
6. 밥그릇 = 補(찰랑한 국물) 아님 → **食不下**
7. 없는 것: 痛(쇠못)·太(큰 갓)·脾(밀짚모자)·汗·厥 — 황색 도포로 脾만 암시
8. 창문 = 어두운 열린 구멍(竅)이나 뜻은 바깥 寒의 유입구 → 寒邪直中(直中太陰) 암시 가능

② 표제어
- 1순위 **太陰病 提綱證**(裏·陰寒·腹滿·自利·食不下 → 溫中: 理中湯·四逆輩) 60%
- 2순위 **理中湯證 / 溫中法(중초허한)** 25%
- 3순위 裏寒證(八綱 陰證 총론) 10%

③ 잔결
- 溫의 김이 없어 붉은 천이 血로 오독될 수 있음
- 太 갓이 없어 「太陰」이 「陰」까지만 읽힘. 吐(上)·痛(못) 미표기
- 부푼 배가 實 기호와 겹침(虛滿 표기 방법 부재)
- 잘림 없음(창문 상단 경미)
