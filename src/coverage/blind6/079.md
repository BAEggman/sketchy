# 079 판독 기록 (blind6)

## 1단계 — 생판 (그림만)

**소품 전수와 사실**
- 무대가 좌·우 둘로 갈림: 좌 배경 청록, 우 배경 흰색. 탁자도 판자 두 장으로 좌·우 나뉨(2분할).
- 좌: 상투·수염, 흰 도포의 선비 1인이 둥근 나무 울타리(말뚝 약 15개) 안에 서 있음 → "가두어 지킴·둘러막음"(固·衛·防).
- 우: 노란 밀짚모자·갈색옷 일꾼 1인이 밧줄 1가닥을 당겨 도르래 2개(들보 위 활차 2)로 회색 자루 1개를 끌어올림 → "위로 들어 올림"(升·提·舉).
- 탁자 좌: 흙 묻은 생뿌리 1개(단면 노랑) → 生用. 탁자 우: 꿀을 발라 구운 뿌리 1개 + 꿀 담긴 나무 숟가락 1개 → 蜜炙. 두 뿌리 크기 거의 같음(약 1:1, 구운 쪽이 조금 김).
- 두 뿌리 사이 한가운데서 흰 김 1줄기가 위로 오름 → 가운데(中)에서 오르는 기운.
- 우하단 작은 별 표식 1개.

**표제어**
- 1순위 **黃芪(황기)의 生用·蜜炙 구분** — 生黃芪 固表止汗(울타리로 겉을 지킴), 炙黃芪 補中益氣·升陽舉陷(도르래로 들어 올림; 노란 풀모자=黃+艹). 확신 60%.
- 2순위 **甘草(감초)의 生·炙 구분** — 노란 단면·꿀=甘·구운 뿌리=炙甘草. 확신 25%. (3순위: 炮製 일반 개념 '蜜炙' 10%)

**뜻 모를 것·어색한 것·잘림**
- 좌 청록 배경과 우 흰 배경의 대비 의미 불명(生=서늘함? 단순 구분?).
- 끌어올리는 자루가 무엇을 나르는지 불명(처진 것=下陷? 단순 무게추?).
- 가운데 김이 어느 뿌리에서 나는지 모호. 우하단 별표는 의미 없는 표식으로 보임.
- 프레임 잘림: 우상단 도르래 기둥이 위 테두리에 닿을 뿐 결정적 잘림 없음. 좌 인물 다리는 울타리에, 우 인물 다리는 탁자에 가려짐(설계상).

## 2단계 — 계통 (사전 어휘로 재판독)

**사전으로 다시 읽은 소품**
- 흰 도포 재상 = **肺**. 노란 밀짚모자 농부 = **脾**. 흰 김 = **氣**, 그 김이 "둘 사이의 한복판"에서 오름 = **中** → 中氣.
- 나무 숟가락에 담긴 꿀 = **甘**(사전: 나무 국자 꽂힌 꿀단지→꿀). 구운 뿌리 위의 꿀은 蜜炙 겸 甘味 표기.
- 아가리를 끈으로 조여 맨 굵은 자루 = **收**의 등재 형태와 일치 — 농부(脾)가 그 자루를 도르래로 끌어올림 → 脾가 '收'된 것을 위로 올림 = 升提·舉陷(사전의 上·下 축: 아래로 처진 것을 위로).
- 울타리는 사전 미등재 신규 기호. 肺가 담 안에 있음(사전 內/裏 계열이나, 肺=皮毛·衛外이므로 '겉을 둘러 지킴'=固表로 읽힘). 汗(땀방울)은 그려지지 않아 '止汗'까지는 명시 안 됨.
- 좌 흙 묻은 뿌리 = 生, 우 꿀 구운 뿌리 = 炙. 무대 2분할 = 生用/炙用 대비.

**표제어(재판정)**
- 1순위 **黃芪 生用·炙用의 효능 분화**: 生黃芪 → 肺·固表(울타리 속 肺 재상), 蜜炙黃芪 → 脾·補中益氣·升陽舉陷(中에서 오르는 氣 + 脾 농부가 처진 자루를 끌어올림). 확신 70%. 사전 어휘(肺·脾·氣·中·甘·收)가 모두 黃芪 효능 문장에 정확히 맞물려 1단계보다 확신 상승.
- 2순위 **甘草 生·炙**: 꿀=甘 등재 기호가 이름 자체(甘)를 가리킬 가능성. 그러나 甘草 특유의 和(양팔 저울)·淸(찬 물)·痛(쇠못)이 전혀 없고 升提 기호가 있어 하위. 확신 15%.

**잔결**
- 회색 자루가 '收'(斂汗) 기호인지 단순히 '처진 것(下陷)'인지 확정 못 함 — 收라면 생황기 固表止汗의 收斂이 우측(脾)에 놓인 배치 어긋남.
- 좌 청록·우 흰 배경 대비는 사전에 없어 의미 미확정. 우하단 별표는 표식으로 무시.
