# 080 판독 기록 (생판 → 계통)

## 1단계 — 생판 (사전 없이 그림만)

① 소품 전수: 큰 모닥불(장작 7개, 불꽃 높이 ≈ 사람 키의 1/2)·연기기둥(화면 위로 곧게 솟아 잘림)·홍조 얼굴·부릅뜬 눈·날리는 땀방울 5개·코피 한 줄기+낙하 3방울·목의 누런 고름머리 종기 1개·양 팔뚝·얼굴의 붉은 반점(팔뚝마다 10여 개)·두 팔 치켜들고 손가락 오그린 자세·맨발로 한 발 든 뜀뛰기·갈라진 땅과 절벽·말라붙은 강바닥 길·마른 풀·가을빛 나무·초가집·기운 바지·상투·허리띠.
사실 대응: 불·연기 = 火性炎上 / 갈라진 땅·마른 강·땀 = 傷津耗氣 / 코피·반점 = 動血(衄血·發斑) / 치켜든 팔·오그린 손 = 生風(抽搐) / 부릅뜬 눈 = 擾心神(狂躁) / 목 종기 = 致腫瘍.

② 표제어: 1순위 **육음 중 화(열)사의 성질 (火熱爲陽邪·炎上·傷津耗氣·生風動血·擾心神·致腫瘍)** 70% / 2순위 **온병 혈분증(斑疹·衄血·躁狂)** 15%.

③ 뜻 모를 것·어색한 것: 가을 나무(燥와 혼동 유발)·초가집(뜻 불명)·기운 바지(장식?)·연기 상단 프레임 잘림·나무 왼쪽 위 살짝 잘림.

## 2단계 — 계통 (사전 어휘로 다시 읽음)

① 소품 재판독: 불꽃 = 熱(陽) → 火熱陽邪 / 연기 곧게 솟음 = 上 → 炎上 / 갈라진 땅·절벽 = 燥, 가을 마른 잎 나무 = 燥 → 傷津化燥 / 마른 강바닥 = 陰(졸아드는 고인 물) → 傷陰 / 땀방울 = 汗 → 汗出(傷津) / 코피 = 鼻+血 → 衄血, 붉은 반점 = 血 → 發斑, 합쳐 動血 / 목 종기 = 腫 → 腫瘍·咽喉腫 / 부릅뜬 눈 = 目, 홍조 광택 = 面 → 面紅目赤·驚狂 / 초가집 바깥의 사람과 불 = 外 → 外感 육음 / 치켜든 팔·오그린 손·한 발 뜀 = 사전 밖(抽搐·躁動) / 마른 풀 = 燥 보조 / 기운 바지·상투·허리띠 = 장식. 1단계에서 어색하다던 가을 나무는 사전의 「燥 = 마른 잎」 그대로여서 傷津 축의 정식 기호로 편입.

② 표제어: 1순위 **화(열)사의 성질 — 火熱陽邪·炎上·傷津(化燥·傷陰)·動血·致腫瘍·擾神** 85% / 2순위 **조사(溫燥)** 8%, **온병 혈분증** 7%. 불이 화면 중심에 크고 汗·腫·血 기호가 동반되므로 燥 기호 둘은 결과(傷津)로 판정.

③ 잔결: 風 기호(한쪽으로 눕고 흘러 날림)가 없어 生風이 부호화되지 않음(팔 자세만으로 추정) / 氣(흰 김) 기호 없어 耗氣 미부호화 / 外 판정 근거가 담이 아닌 절벽이라 약함 / 연기 상단 잘림.
