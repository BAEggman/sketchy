# 081 판독 기록

## 1단계 — 생판(그림만)

**소품 전수**
- 왼쪽 남자(정면·상반신 노출): 가슴 한복판에 김 서린 사발 1 → 上焦如霧(안개) / 氣.
- 배 정중선에 항아리 3개 세로 포개짐(맨 위 항아리 주둥이에서 관 하나가 가운데 항아리로 들어감) → 上·中·下 三焦, 관 = 水道(決瀆之官 水道出焉).
- 남자 옆구리(왼편 갈비 끝)에 나무 상자, 안에 흰 자루 5개 → 五穀(水穀之道路의 穀, 물은 항아리).
- 오른쪽 남자(등·같은 인물): 등에 나무 말뚝 4개로 팽팽히 당긴 흰 천 1, 천 위에 붉은 끈 뭉치 1 → 三焦 有形說(膜·網油) 또는 心包絡(막 속의 붉은 낙맥).

**표제어**
- 1순위 **三焦**(水穀之道路·氣之所終始 / 上焦如霧 / 決瀆之官) — 55%
- 2순위 **三焦·心包 表裏(有名無形의 두 부)** — 15% / 그 밖 營衛生會·決氣 六氣 각 10%.

**뜻 모름·어색·잘림**
- 등의 흰 천+붉은 뭉치가 무슨 글자인지 확정 못 함(膜? 絡? 血?). 말뚝이 왜 4개인지 모름.
- 항아리 셋을 잇는 관이 왜 맨 위→가운데만 잇는지 어색. 사발이 上焦라면 맨 위 항아리와 중복.
- 허리 아래 붉은 점처럼 보였던 것은 확대해 보니 등골 선(붉은 점 없음). 아래쪽 정강이에서 프레임 잘림, 손목·목·상배부는 빈 살.

## 2단계 — 계통(사전 어휘로 재판독)

사전 대조로 1단계는 폐기한다. 「會 = 담는 것 안에 담긴 것」이 판 전체의 골격이고, 각 소품이 「무엇이(氣·腑·臟·血) 어디에(혈자리) 담기는가」를 나른다.
- 가슴 한복판 사발 속 흰 김: 氣(서린 흰 김)가 그릇에 담김 = 會, 자리는 두 젖꼭지 사이 정중 = 膻中 → **氣會膻中**.
- 배 정중선 항아리 3개, 관이 가운데 것으로 들어감: 中 = 같은 것 셋 중 가운데, 항아리 셋 = 上脘·中脘·下脘, 빈 그릇(腑)에 담김 = 會 → **腑會中脘**.
- 옆구리 상자 속 흰 자루 5개: 藏 = 곳간 안 곡식 가마니 → 臟(자루 5 = 五臟), 상자 문틀 = 門, 자리가 11번 갈비 끝 옆구리 → **臟會章門**.
- 등에 기둥 넷 사이 팽팽한 흰 천 = 膈(사전 그대로), 그 위 붉은 것 = 血, 천 안에 담김 = 會, 등의 膈 자리 = 膈俞 → **血會膈俞**.

**표제어**
- 1순위 **八會穴(팔회혈)** — 이 판은 氣會膻中·腑會中脘·臟會章門·血會膈俞 넷 — 85%
- 2순위 **三焦(1단계 잔류)** — 5%

**잔결**
- 나머지 넷(筋會陽陵泉·脈會太淵·骨會大杼·髓會絶骨)은 이 판에 없음: 손목·목뒤(大杼)·상배부는 빈 살이고 정강이 아래는 프레임 밖(다른 판 몫으로 보임).
- 「腑」 전담 기호는 사전에 없어 '빈 항아리=腑'는 추정. 「章」 글자는 상자 자체로만 읽힘(전담 기호 미확인).
