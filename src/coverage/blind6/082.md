# 082 판독 기록 (blind6)

## 1단계 — 생판 (그림만)

**소품 전수**
- 가로 널판 6장·기둥 2개로 짠 나무 우리, 꼭대기에 나사봉 1개(압착기/수문 손잡이꼴). 널판이 깨져 그 틈으로 흙더미(자갈·풀뿌리 섞인 마른 흙)가 오른쪽 아래로 쏟아져 나옴. 우리 안쪽에도 흙이 가득.
- 노란 속살 통나무 2개, 나란히 — 큰 것이 작은 것의 약 2배.
- 질항아리 3개(가운데 1개는 물이 끓고 노란 쐐기 조각 1개, 김 3가닥; 좌·우 2개는 검은 흙덩이, 왼쪽 것엔 잔가지 3개). 밑에 화구 불꽃 2곳.
- 무대: 회색 돌벽·돌판 선반. 오른쪽 아래 별 반짝임 2개(워터마크로 보임).

**읽기** — 나무(木)가 가둔 흙(土)이 나무를 깨고 터져 나옴 = 土가 木을 되받아침. 불 위의 흙 항아리 = 火生土(土가 과잉으로 길러짐), 물 속 노란 덩이 = 土制水. 노란 속 통나무 = 土빛에 물든 木 또는 불쏘시개(木生火).

**표제어**
- 1순위 **相侮 — 土侮木(土壅木鬱)** 40%
- 2순위 **黃土湯**(黃=노란 통나무, 土=흙 항아리, 湯=끓는 솥; 깨진 우리=脾不統血) 25%
- 3순위 崩(土崩)·脾氣下陷 10%

**뜻 모름·어색·잘림** — 통나무 속이 왜 노란지(약재라면 大黃·黃芪·甘草 중 무엇인지) 불명. 흙을 불에 올리는 항아리의 의미 불명(灶心土? 火生土?). 나사봉이 압착기인지 수문인지 불명. 오른쪽 끝 항아리가 프레임에 잘림. 별 반짝임 2개는 그림 밖 표식으로 보임.

## 2단계 — 계통 (사전 적용 후)

사전의 「大 = 같은 종류 둘이 나란한데 하나가 두 배」가 노란 통나무 2개에 정확히 맞음 → 大+黃 = **大黃**. 「便 = 大便 = 손잡이 달린 나무 뒷간통」 — 나사봉(손잡이) 달린 나무통이 뒷간통, 안에 팽팽히 찬 갈색 덩이(實)가 大便. 벽이 터져 아래로 쏟아짐 = 「下 = 아래로 쏟아짐」「盛 = 넘쳐 흘러나옴」 → 瀉下·攻積(通便). 돌벽 안 무대 = 「裏」, 화구 불꽃 = 「熱」 → 裏實熱(陽明腑實)에 大黃. 끓는 물에 갓 던져 넣은 노란 쐐기(물결 고리) = 생대황 後下. 불 위의 검은 덩이 항아리 2개 = 대황炭(炒炭 止血) 또는 「瘀 = 검붉게 굳은 덩이」(逐瘀通經). 김 = 氣. 1단계의 오행 읽기는 사전 어휘로 지지되지 않아 철회.

**표제어**
- 1순위 **大黃**(瀉下攻積·裏實熱·後下·炒炭/逐瘀) 70%
- 2순위 **大承氣湯·陽明腑實證**(大=두 배 표지의 다른 해석; 단 芒硝·厚朴·枳實 부재) 15%
- 3순위 黃土湯 5% / 相侮 5%

**잔결** — 검은 덩이 항아리 2개가 瘀·炒炭·苦(검은 커피) 중 무엇인지 미확정. 항아리 셋 중 가운데 끓는 솥이 「中」 표지인지(中焦·歸經?) 불명. 흙덩이가 「燥(갈라진 땅)」=燥屎 표현인지 불명. 뒷간통이 나사 압착기로 그려진 이유 불명. 오른쪽 항아리 프레임 잘림, 별 반짝임은 무의미 표식으로 판정.
