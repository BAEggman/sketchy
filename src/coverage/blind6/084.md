# 084 판독 (blind6)

## 1단계 — 생판(그림만)

**소품 전수와 나르는 사실**
- 웃통을 젖혀 연 남자 1명: 얼굴·가슴·배가 온통 붉음 → 壯熱·面赤(身大熱). 옷을 스스로 열어젖힘 → 惡熱(不惡寒 反惡熱).
- 땀: 머리 곁으로 튀어 날리는 방울 5개(왼쪽 3·오른쪽 2) + 이마·뺨·목·가슴에 맺힌 것 10여 개 → 大汗出.
- 입을 벌리고 혀를 물그릇까지 내밀어 마심: 혀는 붉고 한가운데 노란 점박이 이끼 → 舌紅 苔黃; 혀째 물에 담그는 동작 → 大渴引飮(渴喜冷飮).
- 찡그린 눈썹·처진 눈 → 煩(煩渴).
- 갈색 질그릇 1개에 맑은 물 → 冷飮.
- 곁상 위 흰 결정질 돌 1개(낱알의 8~10배 크기) → 石膏. 그 옆 크림색 타원 낱알 약 10알 → 粳米. 두 가지 = 白虎湯 구성(石膏·知母·甘草·粳米) 중 2미.
- 나무 걸상 1·곁상 1·회색 판석 바닥·빈 배경: 장면 장식.

**표제어**
1순위 **白虎湯證(陽明經證 — 四大證: 大熱·大汗·大渴·脈洪大)** 80%
2순위 **溫病 氣分證(氣分熱盛)** 12% / 3순위 白虎加人參湯證 5%.

**뜻 모를 것·어색·잘림**
- 四大證의 넷째 脈洪大를 나르는 소품이 없음(맥·손목 표현 전무).
- 知母·甘草가 상에 없어 처방을 石膏+粳米 둘로만 지시.
- 회색 판석 바닥이 장식인지 뜻인지 불명. 프레임 잘림 없음(상 오른쪽 다리까지 안에 듦).

## 2단계 — 계통(사전 어휘로 재독)

사전으로 다시 보면 소품이 글자로 바뀐다.
- 淸 = 「맑고 찬 물 한 그릇」 → 남자가 든 질그릇의 맑은 물이 곧 **淸(淸熱)**의 치법 기호. 補(따뜻한 국물)가 아니라 淸이라는 점이 분명하다. 마시는 동작은 渴, 그릇 자체는 치법 — 한 소품이 증과 치법을 겸함.
- 汗 = 「살갗에 맺힌 땀방울」이 맞고, 몸을 떠나 날리는 방울은 津 = 「맑은 물방울」로 읽혀 **汗出 傷津**(땀으로 진액이 빠져나감)이 된다. 날려 넘쳐나는 모양은 盛(넘쳐 흘러나오는 것)과도 닿아 熱盛·汗多.
- 舌 + 苔(혀 위 이끼) → 舌紅 黃苔.
- 表 = 겉껍질을 젖혀 裏 = 속을 드러냄 → 表證 없고 **裏熱**(陽明 裏熱, 惡熱). 
- 熱 = 불꽃, 大 = 「둘 나란한데 하나가 두 배」, 氣 = 흰 김은 모두 없다. 熱은 붉은 살색으로만 나르므로 사전상 血(붉은 것)과 섞일 여지가 있고, 四大證의 大도 기호로는 안 나온다. 氣 기호가 없어 氣分證 명명은 근거가 약해짐.
- 燥 = 「갈라진 땅」: 회색 판석 바닥이 이 기호로 오독될 수 있으나 규칙적 포석이라 장식으로 판정.
- 石膏·粳米는 사전에 없고 자연물 그대로 읽힘. 甘(꿀단지) 없음 → 甘草 부재 확정.

**표제어(확정)**
1순위 **白虎湯證(陽明經證·裏熱熾盛 — 治法 淸熱生津)** 85%
2순위 **陽明經證(증후 단독)** 10% / 3순위 氣分證 5%.

**잔결**: 脈洪大 소품 없음, 知母·甘草 없음, 熱·大 기호 미사용(붉은 살과 강도로만 표현). 잘림 없음.
