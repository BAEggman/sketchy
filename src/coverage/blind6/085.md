# 085 판독 (blind6)

## 1단계 — 생판 (그림만)

① 소품 전수
- 맨벽·회색 바닥의 빈 방 1, 나무 긴 의자 1 → 진찰 무대. 앉은 환자 3(남2·여1) + 등 돌리고 무릎 꿇은 상투 남자 1 = 望診하는 의사.
- 환자A(왼): 얼굴·손·발 전신 잿빛 검정, 광택 없이 어둡고 무표정 → 面黑暗淡 = 腎陽虛·寒 (黑主腎).
- 환자B(가운데·여): 두 눈 둘레만 검게 꺼짐(目眶黑), 배가 공처럼 둥글게 부풂, 목 힘줄 드러난 여윈 얼굴 → 眼眶周圍發黑 = 腎虛水飲(부푼 배=水腫·腹水), 여성이므로 寒濕帶下의 함의.
- 환자C(오른): 얼굴·손·발 전신 자흑색(紫黑), 오른손 손가락 오그라듦, 주름진 얼굴 → 瘀血·寒凝, 痛甚為攣.
- 색 계열 2(黑·紫), 정상색 얼굴 1(여성, 눈가만 黑). 배 크기: 몸통 폭에 가까움(약 1배).
- 우하단 바닥 4각 반짝별 1개.

② 표제어
- 1순위 **黑色主病(望色) — 腎虛·寒證·水飲·瘀血·痛證** 55%
- 2순위 **靈樞·五色 「青黑為痛」 / 五色主病 중 青·黑** 25%
- (3순위: 金匱 水氣病 目下臥蠶·腹大 10%)

③ 뜻 모를 것
- 우하단 별: 용도 불명(연작 표식? 光澤?). 여성의 배가 水腫인지 妊娠인지 그림만으로 애매. 환자C의 오그라든 손이 攣을 뜻하는지 우연인지 불명. 프레임 잘림 없음(방 전체와 네 인물 모두 온전).

## 2단계 — 계통 (사전 어휘로 재독)

① 소품 재독
- 사전에 面色(黑·青)의 전담 기호는 없어 전신 색칠이 이 판의 새 기호로 읽힘. 오행왕국에서 검정=腎(잠수부)이므로 환자A의 검정 = 腎의 색 → **黑主腎虛**. 광택(面=華) 없음 → 病色(無華).
- 환자B: 目(눈) 둘레 검정 + 腫(부풀어 팽팽해진 곳)=배 → 目眶黑+水腫 = **腎虛水飲**; 셋 중 가운데(中)에 여성을 둔 것은 帶下(여성 병) 암시로 겸독.
- 환자C: 손발 끝 검푸름 = 사전의 **厥**(검푸르게 언 손발 끝) → 寒厥·血瘀로 얼굴까지 紫黑 = **寒證·瘀血**. 오그라든 손가락 = 痛甚為攣(痛의 쇠못 기호는 없으므로 약한 근거).
- 痛(쇠못)·寒(눈송이)·瘀(덩이) 기호 모두 부재 → 병기(病機)가 아니라 「얼굴빛→주병」 대응표를 세 환자로 나눈 판.
- 별: 華(빛나는 것)일 수 있으나 얼굴에서 떨어져 바닥에 있어 「얼굴에 光澤 없음」의 반대 표시로는 부자연.

② 표제어
- 1순위 **黑色主病 — 腎虛·寒證·水飲·瘀血·痛證(面黑暗淡=腎陽虛 / 眼眶黑=腎虛水飲·寒濕帶下 / 紫黑·厥=瘀血·寒)** 60%
- 2순위 **青·黑 공통 主病(寒·痛·瘀, 靈樞 青黑為痛)** 20%

③ 잔결
- 黑色 주병 중 「腎陰虛(面黑乾焦)」와 「劇痛」 담당 소품이 없음(환자 셋뿐). 우하단 별은 사전에도 없어 미해독. 배의 水腫/妊娠 구분 불가. 프레임 잘림 없음.
