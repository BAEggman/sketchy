# z25 판독

## 1단계 — 생판 (사전 없이)

**① 단원**: 1순위 **藏象 — 六腑·奇恒之府(臟腑의 형태·기능 구분)** 40%. 2순위 **精氣血津液**(우물=井→精, 붉은 가지=血, 김=氣, 항아리 물=津液, 골수=髓) 25%. 3순위 **四海**(膻中=氣海, 胃=水穀之海, 血海, 髓海) 15%.

**② 인물·소품**
- 가운데 인물(상투 튼 근육질 청년, 웃통 벗고 노란 바지, 맨발) = **胃(六腑 대표)**. 노란 바지=土, 근육=陽明 多氣多血.
  - 가슴 한가운데(膻中 자리) 김 나는 국그릇 1 = 水穀 受納·腐熟(또는 膻中 氣海).
  - 정중선 따라 쌓인 항아리 3 = 上·中·下脘(三脘) — 3개. (대안: 三焦 上中下 / 中焦如漚)
  - 맨 아래 항아리에 꽂힌 대나무 관 1 = 脘=管, 通降·傳化(대안: 下焦如瀆·水道).
  - 옆구리 문 열린 찬장 속 흰 곡식 자루 4~5 = 倉廩之官(太倉). 문이 열려 있음 = 傳化物而不藏(瀉而不藏).
- 왼쪽 배경 소품 무리(인물 없음) = **奇恒之府** 6 중 3: 돌우물 속 붉은 핏줄 가지 = 脈(血之府), 베틀 북 속 뼈 = 骨, 잘린 뼈 단면의 골수 = 髓(骨者髓之府). 셋 다 속이 빈 그릇(形似腑)에 무언가를 담아 두는(藏精, 功似臟) 모양.
- 배경 기와 돌담 = 府(관아 담장·府庫) 또는 城郭.
- **관계**: 문 열린 찬장·관으로 흘려보내는 인물(六腑: 傳化物而不藏, 實而不能滿) ↔ 닫힌 그릇에 담아 두는 소품들(奇恒之府: 藏而不瀉, 形似腑而功似臟)의 대비.

**③ 잔결**: 베틀 북이 왜 뼈를 싣는지 모름(북=北→腎? 伎巧?); 우물 속 붉은 가지가 血인지 衝脈 血海인지 불명; 대나무 관이 아래 항아리에서 위로 비스듬히 솟아 흐름 방향이 애매; 찬장 문 열림의 의도 불확실. 이음매 흔적은 뚜렷하지 않음(오른쪽 끝 바닥 얼룩은 이웃 띠 몫으로 봄).

## 2단계 — 계통 (사전요약 적용 후)

**① 단원**: **八會穴** 85% (1단계의 藏象·四海 읽기는 버림 — 사전의 杼·會·藏·中·氣로 한 줄에 풀린다).

**② 인물·소품**
- 가운데 인물 = 오행왕국 다섯 인물이 아니다(밀짚모자 없음) — **몸통 위 會穴 3개를 싣는 몸**. 몸에 얹힌 자리가 곧 혈위.
  - 가슴 한복판(두 젖꼭지 사이) 그릇에 서린 흰 김 = 氣(김)+中(몸 위 한복판)+會(담긴 것) → **氣會 膻中**.
  - 정중선 항아리 셋 중 가운데(中) + 대나무 관(管=脘) + 속 빈 항아리(腑) → **腑會 中脘**.
  - 옆구리(季脇, 11늑골 끝) 문 열린 곳간 속 가마니 = 藏(앞에 관리 없음 → 倉 아님) + 門(문간) → **臟會 章門**.
  - 노란 바지 = 혹 脾胃 — 章門=脾 募穴, 中脘=胃 募穴의 연결을 나를 수 있음(약한 근거).
- 땅 위 소품 3(몸에서 떨어진 = 사지·등의 會穴):
  - 실이 옆구멍으로 빠진 베틀북(杼) 속 흰 뼈(骨, 會) → **骨會 大杼**. 곁 뼈가 훨씬 굵어 大(둘 중 하나가 두 배)를 겸할 수 있음.
  - 잘려 골수가 드러난 뼈 = 絶(끊긴) 骨 + 髓 → **髓會 絶骨(懸鍾)**.
  - 깊은 돌우물(淵) 속 붉은 가지 핏줄(脈) → **脈會 太淵**.
- 이 띠에 8會 중 6, 나머지 **血會 膈兪·筋會 陽陵泉**은 이웃 띠 몫으로 봄.
- **관계**: 몸에 붙은 셋(臟·腑·氣 = 가슴·배 앞면 혈) ↔ 땅에 놓인 셋(脈·骨·髓 = 손목·등·종아리 혈). 나란한 두 뼈는 骨會 大杼 ↔ 髓會 絶骨 짝(骨·髓 一對).

**③ 잔결**: 대나무 관 끝이 가운데가 아닌 **맨 아래** 항아리에 꽂혀 下脘으로 샐 수 있음; 항아리 셋 포개짐은 사전상 **久**와 충돌; 김 나는 국그릇은 **補**(찰랑찬 따뜻한 국물)로 샐 수 있음; 우물 속 붉은 가지는 사전상 **血**이라 血會(膈兪)로 오독 여지 — 膈(흰 천)이 없어 脈으로 판정, 淵·太는 등재 기호 없음; 기와 담장(內?)은 뜻 미상 — 難經 45難 「熱病在內者 取其會之氣穴」을 노린 것일 수 있으나 熱 표지 없음.
