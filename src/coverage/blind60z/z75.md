# z75 판독

## 1단계 — 생판 (사전 없이)

**① 단원 1순위**: **病因 — 痰飮·瘀血·飮食·勞逸(내상·병리산물 병인)** 35% / 2순위 **氣血失常(血瘀·氣滯)** 25% / 3순위 邪正盛衰(虛實) 10%.

**② 인물·소품**
- 띠 한가운데 인물은 1명. 등을 보인 상투 남자, 맨등·맨발, 황토색 바지 + 검은 허리띠, 기와 담장을 마주 봄.
  - 표제어 **瘀血(血瘀)**. 등에 붙인 흰 천(고약/膏藥) 위의 **붉은 실 뭉치** = 血이 엉겨 뭉침(血行不暢·凝結). 천의 네 귀를 매듭 **4개**로 살에 고정 = **痛有定處**(고정통·刺痛·拒按). 자리가 등 한가운데라 背部·經絡에 막힌 것으로 읽힘(膈兪=血會 자리일 수도, 약함).
  - 황토색 바지(土色)와 검은 허리띠(水色, 허리=腎之府)는 脾·腎으로 읽을 수 있으나 확신 낮음.
- 오른쪽 위: 풀 덮인 흙무덤 위 돌사발의 **엉킨 누런 국수** = **飮食(食積·食滯)**. 흙무덤=土=脾胃가 상함. 풀(木)이 흙(土)을 덮어 木乘土(肝脾不和)일 가능성도.
- 오른쪽 아래: 나무 들보에 매단 **속이 빈 청동종** = 金=肺, 「金空則鳴」(虛로 소리 남/失音)? 뜻 불분명.
- 관계: 온전한 인물이 하나라서 인물 사이 관계는 없음. 대신 **붉은 엉킴(血)과 누런 엉킴(국수)이 짝**을 이뤄 **氣滯血瘀** 또는 「食積→瘀」를 나르는 듯.

**③ 잔결**
- 종(빈 속, 울림 표시 없음)의 뜻을 모름. 흙무덤과 담장도 왜 있는지 모름.
- 고약 천을 매듭으로 맨살에 묶은 모습이 어색함.
- 왼쪽 가장자리의 팔·손·발끝은 이웃 띠 몫(무시함). 이어 붙인 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (사전 적용)

**판정**: 사전 어휘로 훨씬 잘 풀린다. 「膈 = 기둥 넷 사이에 팽팽히 친 흰 천」과 「會 = 담는 것 안에 담긴 것」을 적용하면 1단계에서 뜻을 몰랐던 매듭 4개와 종이 설명된다. 사전에 杼(大杼)·門·中이 따로 있는 것도 이 계열과 맞는다. 1단계의 病因 판독은 버린다.

**① 단원**: **八會穴(特定穴)** 75% / 2순위 **王淸任 血府·膈下 逐瘀** 8%.

**② 인물·소품**
- 맨등 남자는 **血會 膈兪**. 견갑골 아래끝(第7胸椎) 높이의 등에 네 귀를 매어 팽팽히 친 흰 천이 **膈**이고, 그 안의 붉은 실뭉치는 **血**, 천 안에 담긴 것은 **會**다. 膈兪 자리는 第7胸椎 棘突下 旁開 1.5寸(足太陽)이다. 매듭 4개 = 기둥 넷.
- 풀 덮인 흙언덕(陵) 위 사발에 담긴 누런 가닥 다발은 **筋會 陽陵泉**(足少陽 合穴, 腓骨頭 前下方)이다. 가닥 다발 = 筋, 사발에 담김 = 會.
- 들보에 매단 종은 懸鐘이고, 그 속을 채운 흰 것은 **髓**다. 담겨 있으니 會 → **髓會 絶骨(懸鐘)**(外踝上 3寸).
- 관계: 세 소품 모두 「그릇 안에 담긴 것 = 會」 문법을 공유한다. 八會 8개 중 3개(血·筋·髓)를 나른다. 언덕이 위, 종이 아래인 세로 배치는 같은 足少陽膽經에서 陽陵泉(무릎 아래)이 懸鐘(발목 위)보다 위에 있다는 사실을 따른다. 膈兪만 몸통의 足太陽 背兪 쪽 자리다.

**③ 잔결**
- 천 위의 붉은 뭉치는 가운데가 검붉어서, 사전의 「瘀 = 천 위 검붉게 굳은 덩이」에 걸려 瘀血로 샐 수 있다.
- 누런 국수는 筋의 등재형(갈색 힘줄 다발)과 달라 飮食으로 샌다.
- 陽·泉, 絶骨을 진 소품이 없다. 懸鐘은 종 연상에만 기댄다.
- 담장과 누런 바지의 뜻은 풀리지 않는다.
