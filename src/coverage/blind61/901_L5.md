# 901 판독 (L5 · blind61)

## 1단계 — 생판 (사전요약 열기 전 확정)

**① 판 표제어**
- 1순위 **奇恒之腑(腦·髓·骨·脈·膽·女子胞) + 三焦 — 「腑」 단원 통합** (50%)
- 2순위 **三焦(上焦如霧·中焦如漚·下焦如瀆)** 단독 판 (25%) / 그 밖 **六腑 vs 奇恒之府(五藏別論)** (15%)

**② 인물·구역 (왼쪽부터; 양옆 소품은 가까운 인물에 붙여 읽음)**
- 인물1 — 정면 사내(배·陰 쪽). 표제어 **三焦** (곁 소품까지 묶으면 「奇恒之腑 ① 脈·骨·髓」). 7개
  1. 가슴의 김 오르는 흰 사발 = **上焦如霧**(上焦 = 안개·蒸氣)
  2. 명치~배꼽의 질항아리 3개 세로 쌓임 = 三焦의 「3」 / 항아리에 담가 삭힘 = **中焦如漚**
  3. 맨 아래 항아리에 꽂힌 대나무 관 = 물길·도랑 = **下焦如瀆**(水道 소통)
  4. 오른 옆구리(인체 우측 갈비 아래) 문 열린 작은 찬장 + 흰 보따리 4~5개 = 위치상 **膽**(中精之府, 精汁을 「저장」) — 혹은 「府=창고」 자체
  5. 왼쪽 마당 돌우물 + 솟는 붉은 산호가지 = **脈**(血之府, 피를 담는 우물)
  6. 북(베틀 梭) 홈에 놓인 뼈 = **骨**
  7. 단면에 흰 속이 드러난 뼈 토막 = **髓**(骨者髓之府)
- 인물2 — 뒷모습 사내(등·陽 쪽). 표제어 **女子胞(胞絡繫於腎)** 또는 **命門** 중 택일 못 함. 4개
  1. 허리(腎 높이) 네 귀를 묶어 편 흰 천 + 엉킨 붉은 실타래 = 붉은 실 = 胞絡/胞脈이 腎에 매임(**胞絡者繫於腎**) / 대안: 兩腎之間 **命門**, 혹은 膜(三焦=油膜說)
  2. 오른쪽 풀 둔덕 위 돌확 + 누런 국수 똬리 = 주름진 **腦**(髓海)
  3. 그 받침 흙둔덕 = 奇恒之腑 「地氣之所生 · 藏於陰而象於地」(五藏別論)
  4. 들보에 매단 청동 종(속이 흰색) = 뒤집은 배 모양 → **女子胞** (대안: 머리뼈 속 髓 = 腦)

**③ 잔결**
- 북(梭)이 왜 「骨」인지, 찬장 속 흰 보따리가 무엇의 개수인지 불명.
- 종 안쪽의 흰 덩어리, 돌확 위 국수의 뜻이 확정 안 됨(腦·膽·女子胞 셋 중 배정이 흔들림).
- 두 사내가 같은 사람의 앞·뒤(前後·腹背) 짝 — 腹陰背陽 대비가 의도인지 불명.
- 담장·기와 연속, 이어붙임 흔적 없음. 오른쪽 가장자리에 연분홍 세로 테 1줄(프레임 끝 잔흔?). 인물·소품 잘림 없음.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

사전의 杼(실 빠진 베틀북)·膈(네 기둥 사이 흰 천)·會(담는 것 안에 담긴 것)·藏(문 열린 곳간의 가마니)·門·中(둘 사이 한복판/셋 중 가운데)·氣(흰 김)를 대니 판 전체가 한 번에 풀린다. 1단계의 奇恒之腑는 「脈·骨·髓」라는 **담긴 내용물**만 본 오독이었다.

**① 판 표제어**
- 1순위 **八會穴** (92%) — 臟·腑·氣·血·筋·脈·骨·髓 여덟 會가 모두 나옴
- 2순위 **特定穴(要穴) 총괄 중 會穴** (5%)

**② 인물·구역**
- 인물1 — 정면 사내(가슴·배 쪽 會穴) + 왼쪽 소품. 표제어 **氣會膻中·腑會中脘·臟會章門**. 6개
  1. 두 젖꼭지 사이 한복판(中) 사발에 서린 흰 김(氣) = **氣會膻中**
  2. 세로로 포갠 질항아리 셋(속 빈 그릇 = 腑) 중 가운데(中) + 대나무 관(管=脘?) = **腑會中脘**
  3. 옆구리의 문(門) 열린 곳간 + 흰 가마니 4~5개(藏) = **臟會章門**
  4. 우물(淵) 속에 담긴 붉은 가지(脈) = **脈會太淵**
  5. 실 한 가닥 빠진 베틀북(杼) 속에 담긴 흰 뼈(骨) = **骨會大杼**
  6. 잘린(絶) 뼈 단면의 흰 골수 = **髓會絶骨**
- 인물2 — 뒷모습 사내(등 = 背兪) + 오른쪽 소품. 표제어 **血會膈兪**. 3개(고유 2 + 별명 1)
  1. 등에 네 귀 기둥으로 팽팽히 친 흰 천(膈) 위에 담긴 붉은 실타래(血), 등이라 兪 = **血會膈兪**
  2. 둔덕(陵) 위 돌샘(泉) 그릇에 담긴 누런 갈색 힘줄 다발(筋) = **筋會陽陵泉**
  3. 들보에 매단(懸) 종(鍾), 속이 흰 골수 = **髓會懸鍾**(=絶骨의 다른 이름, 인물1-6과 같은 사실)

**③ 잔결**
- 太淵의 太(테 넓은 큰 갓), 陽陵泉의 陽(해·불), 大杼의 大(두 배 짝), 章門의 章 — 표지가 화면에 없음. 자리와 나머지 글자로 메워 읽음.
- 대나무 관은 사전에 없는 소품(管=脘 추정, 군더더기일 수 있음). 항아리 셋 포갬은 사전의 久(같은 것 셋 포갬)와 겹칠 수 있음 — 「몸 위에서는 中」으로 겨우 구제됨.
- 김 오르는 사발은 補(따뜻한 국물)와도 샘. 우물의 붉은 가지는 血(붉은 것)으로도 읽혀 血會/脈會가 흔들림.
- 筋 다발이 국수·실타래처럼 그려져 腦로 오독하기 쉬움(1단계 실제 오독).
- 髓會가 두 번(絶骨·懸鍾) — 별명 이중 등재. 앞·뒤 같은 얼굴 두 사내는 善惡 쌍둥이 항목과 샐 여지(한쪽이 뒷모습이라 실제로는 안 샘).
- 이어붙임·잘림 없음. 오른쪽 끝 연분홍 세로 테 1줄.
