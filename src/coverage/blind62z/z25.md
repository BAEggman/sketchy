# z25 판독

## 1단계 — 생판 (사전 열기 전 확정)

**① 단원**: 1순위 **藏象 — 五臟의 華·充(六節藏象論)** (70%). 2순위 **五行 歸類(五臟 配屬)** (15%), 3순위 **十二官(靈蘭秘典論)** (10%).

**② 인물별**
- 왼쪽 장수(녹색 갑옷·투구) = **肝**. 장수 = 將軍之官 / 罷極之本(지쳐도 버티는 군인). 녹색 = 靑(木). 원형 배경의 싹 트는 나뭇가지 = 通於春氣(陽中之少陽). 쳐든 손의 붉은 손톱 5개 = **其華在爪**. 쳐든 팔과 가로 댄 주먹 팔뚝에 밧줄처럼 드러난 힘줄(손목 한 점에 모였다 손가락 4줄로 갈라짐) = **其充在筋**(肝主筋). 부릅뜬 눈 = 開竅於目(약함).
- 가운데 임금(곤룡포·익선관·용 흉배) = **心**. 임금 = 君主之官 / 生之本. 붉은 옷 = 赤(火). 무성한 여름 숲 배경 = 通於夏氣(陽中之太陽). 얼굴의 흰 반짝임(윤기) = **其華在面**. 가로 댄 팔뚝에 붉게 갈라진 핏줄 = **其充在血脈**(心主血脈). 벌린 입 속 붉은 혀 = 開竅於舌(약함).
- 오른쪽 농부(밀짚모자·누런 옷, 오른쪽이 잘림 — 이웃 띠와 공유) = **脾**. 농부 = 倉廩之本/倉廩之官. 누런 옷 = 黃(土). 흙벽 배경 = 通於土氣(至陰). 입술 둘레의 흰 고리 = **其華在脣四白**. 팔뚝의 둥근 살덩이 = **其充在肌**(脾主肌肉).

**관계**: 왼→오가 靑→赤→黃, 木→火→土 **相生 순서**로 서 있다 — 판 전체는 肝·心·脾·肺·腎 다섯 인물이 相生순으로 늘어선 五臟 華充판으로 추정. 장수가 임금 곁을 지키는 것 = 君主–將軍 十二官의 위계.

**③ 잔결**: 임금 손톱도 어둡게 칠해짐(爪 신호가 心에 새는 듯). 혀·눈 신호는 약해 의도인지 불확실. 원형 후광 테두리가 셋 다 같아 '통함(通於~氣)'인지 단순 액자인지 모호. 위쪽 1/4이 빈 여백.

## 2단계 — 사전 어휘로 다시 읽기

**① 단원**: **藏象 — 五臟의 其華·其充(六節藏象論)** (85%). 사전에 華(광택)·充(걷어올린 맨팔뚝 위에 더해진 것)이 따로 등재돼 있고, 세 인물 모두 「광택 하나 + 맨팔뚝 하나」의 같은 틀을 되풀이하므로 1단계보다 확신이 오른다. 2순위 **五臟 開竅(五官)** (8%).

**② 인물별** (옷 모양은 인물 지목뿐 — 장수·임금·농부를 將軍之官·君主之官·倉廩으로 다시 읽던 1단계 해석은 철회)
- 초록 갑옷 장군 = **肝**: 쳐든 손의 빛나는 붉은 손톱 5개 = 華+爪 → **其華在爪**. 가로 댄 맨팔뚝의 갈색 힘줄 다발 = 充+筋 → **其充在筋**. 싹 트는 가지 원경 = 通於春氣(陽中之少陽).
- 붉은 곤룡포 임금 = **心**: 이마·광대·콧대의 흰 광택 = 面(광택만) → **其華在面**. 맨팔뚝 위의 붉게 갈라진 줄 = 充+血(脈) → **其充在血脈**. 무성한 여름 숲 = 通於夏氣(陽中之太陽).
- 노란 밀짚모자 농부 = **脾**: 입술을 둘러싼 흰 광택 고리 = 華 → **其華在脣四白**. 맨팔뚝 위 닫힌 윤곽의 도톰한 살덩이 = 充+肌 → **其充在肌**. 흙벽 = 通於土氣(至陰).

**관계**: 옷 색 = 五色 그대로, 왼→오 靑·赤·黃 = **木→火→土 相生 순**. 세 사람이 똑같이 한 손 내보이고 한 팔 가로 대는 같은 자세 = 「臟마다 華 하나·充 하나」의 병렬 대응. 원형 창 밖으로 몸이 걸쳐 나온 구도(안팎이 한 덩어리)는 通(通於四時之氣)으로 읽힐 여지.

**③ 잔결**: 사전상 目(크게 뜬 눈)·舌(벌린 입 안의 혀 → 心)·口(脾)가 장군·임금·농부 얼굴에 모두 걸려, 開竅 신호가 華판에 섞여 읽힐 위험. 특히 농부의 脣四白 고리가 입(口)과 겹친다. 임금의 어두운 손톱은 爪로 오독될 수 있다. 계절 원경은 사전에 없는 어휘라 독자가 通으로 묶을지 미확정.
