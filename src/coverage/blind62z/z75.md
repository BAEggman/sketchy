# z75 판독

## 1단계 — 생판 (사전 보기 전)

**① 단원**: **藏象 — 六節藏象論 五臟 藏象(其華·其充·通於某氣)** 55% / 차순위 **五行 歸類(五臟 配屬)** 30%, **宣明五氣(五主)** 10%.

**② 인물 (왼→오, 土→金→水 相生 순서)**
- 왼쪽 농부(띠 왼끝에 반쯤 걸침) = **脾(土)**. 노란 저고리·밀짚모자 = 其色黃·倉廩之本(농사·곳간). 입술을 두른 흰 테 = **其華在脣四白**(=開竅於口). 팔뚝의 분홍 살덩이 = **其充在肌(脾主肉)**. 둥근 창 속 갈색 흙 = **通於土氣**(至陰).
- 가운데 갓 쓴 노선비 = **肺(金)**. 흰 도포 = 白. 크게 뚫린 검은 콧구멍 2개 = **開竅於鼻**. 털 수북한 손등 = **其華在毛**. 소매 아래 햇볕에 탄 피부와 흰 띠(탄 자국) = **其充在皮(肺主皮)**. 창 속 단풍잎(약 12장) = **通於秋氣**. 늙은 관리 모습 = 相傅之官(추정).
- 오른쪽 검은 잠수복 청년 = **腎(水)**. 검정 = 黑. 매끈한 검은 머리 = **其華在髮**. 팔뚝 속 흰 뼈 막대+둥근 뼈머리 = **其充在骨(腎主骨)**. 창 속 눈 덮인 벌판·잿빛 하늘 = **通於冬氣**. 잠수 = 主蟄·封藏(추정).
- 관계: 세 사람이 같은 높이로 팔뚝을 가로질러 내보임 = 五臟이 각각 「몸의 어느 층을 채우는가(肌→皮→骨)」를 나란히 비교. 土生金生水 相生 순서로 줄 섬 → 왼쪽 띠 밖에 肝·心이 있을 것.

**③ 잔결**: 목에 건 물안경(水 소품인지, 瞳子=腎 五輪인지 미상). 노선비가 손바닥을 들어 흔드는 동작의 뜻 미상. 위 1/4이 텅 빈 여백. 이어 붙인 흔적은 안 보임.

## 2단계 — 계통 (사전요약 읽은 뒤)

**① 단원**: **藏象 — 五臟의 其華·其充(六節藏象論, 開竅 곁들임)** 70% / 차순위 **宣明五氣 五主** 15%, **五行 歸類** 10%. 사전에 華(광택)·充(걷어올린 맨팔뚝 위에 더해진 것)·竅가 따로 등재돼 있고, 세 사람이 모두 「얼굴의 광택 + 맨팔뚝 위 덧붙인 것」을 짝으로 들고 있어 華·充 짝 판으로 읽는 것이 가장 잘 풀린다.

**② 인물**
- 노란 밀짚모자 농부 = **脾**(黃). 입술을 두른 흰 빛 테 = 華 → **其華在脣四白**. 살짝 벌린 입(혀 안 보임 → 舌 아님) = 口 → 開竅於口. 맨팔뚝 위 닫힌 윤곽 살덩이 = 肌 + 充 → **其充在肌**. 둥근 창 속 흙 = **通於土氣**.
- 흰 도포 재상 = **肺**(白; 늙은 관리·검은 갓은 옷차림일 뿐, 갓은 太 아님). 열린 검은 콧구멍 2 = 鼻·竅 → **開竅於鼻**. 들어 올린 손등의 잔털 = 毛 → **其華在毛**. 걷어올린 소매 아래 탄 자국 색 경계선 한 줄 = 皮 + 充 → **其充在皮**. 창 속 단풍 = **通於秋氣**.
- 검은 잠수복 잠수부 = **腎**(黑; 후드·고글은 옷차림 — 1단계 물안경 의문 해소). 윤이 흐르는 검은 머리 = 髮·華 → **其華在髮**. 맨팔뚝 위 흰 뼈 능선 + 끝의 뼈 혹 = 骨 + 充 → **其充在骨**. 창 속 눈벌판·잿빛 하늘 = **通於冬氣**(눈송이·얼음 없음 → 寒·陰 아님).
- 관계: 셋이 같은 높이로 맨팔뚝을 가로 내밀어 「充」을, 얼굴에 「華」를 나란히 보임 = 臟마다 밖으로 드러나는 華와 속을 채우는 充의 짝(肌·皮·骨 = 3개)을 비교. 줄 순서 脾→肺→腎 = 土生金生水 相生 차례, 왼쪽 이웃 띠에 肝(爪·筋)·心(面·血脈)이 올 자리.

**③ 잔결**: 毛는 사전상 「역광에 은빛으로 서는 잔털」인데 여기 털은 갈색 — 꼴이 약간 어긋남. 둥근 창(배경)을 通으로 읽을지 계절(氣)로 읽을지 사전에 전담 기호가 없음. 위 1/4 빈 여백. 이음 흔적 없음.
