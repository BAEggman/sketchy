# 901 판독 (M5)

## 1단계 — 생판 (사전 없이 그림만)

**① 판 표제어**
- 1순위: **藏象 — 五臟의 外候(五主·五華·五竅)** (70%)
- 2순위: **五行 配屬(五行歸類表: 五色·五時·五臟)** (20%)
- 근거: 다섯 인물이 좌→우로 靑·赤·黃·白·黑 옷, 뒤 원창(圓窓)이 春(새순)·夏(녹음)·土(흙)·秋(단풍)·冬(설무) — 五行 순서. 각 인물이 팔뚝(五主)·얼굴 한 곳(五華/五竅)을 하나씩 강조하고, 직업이 十二官(靈蘭秘典論)과 맞물린다.

**② 인물별 (왼쪽부터)**
1. 청색 갑옷 장수 — **肝(木)**: 靑甲=靑色 / 새순 돋은 가지=春 / 장수=將軍之官 / 두 팔뚝에 드러난 힘줄=肝主筋 / 붉게 칠한 손톱 5개=其華在爪 / 부릅뜬 눈=開竅於目 / 찌푸린 눈썹=怒. (7개)
2. 곤룡포 임금 — **心(火)**: 紅袍=赤 / 무성한 여름 나무=夏 / 임금·흉배 龍=君主之官 / 팔뚝의 붉은 혈관 그물=心主脈 / 번들거리는 얼굴 하이라이트=其華在面(또는 汗) / 벌린 입속 붉은 혀=開竅於舌 / 웃는 얼굴=喜·笑. (7개)
3. 밀짚모자 농부 — **脾(土)**: 황색 저고리·노란 밀짚모자=黃 / 갈색 흙 배경=土(長夏) / 농부=倉廩之官 / 팔뚝의 둥근 살덩이=脾主肉 / 입술 둘레 흰 테=其華在脣(脣四白) / 벌린 입=開竅於口. (6개)
4. 갓 쓴 흰 도포 선비 — **肺(金)**: 白袍=白 / 붉은 단풍=秋 / 선비=相傅之官 / 손~팔뚝의 햇볕 그을림 경계=肺主皮 / 손등·팔의 털=其華在毛 / 검게 칠해 강조한 콧구멍 2개=開竅於鼻. (6개)
5. 검은 잠수복 청년 — **腎(水)**: 黑 슈트=黑 / 눈·안개 덮인 겨울 풍경=冬 / 목에 건 물안경=水 / 잠수·수영 체력인=作強之官 / 팔뚝 위 흰 뼈(골두 달린 막대)=腎主骨 / 윤기 나는 검은 머리=其華在髮. 耳는 표지 없음. (6개)

**③ 잔결**
- 인물2(임금)의 손톱 끝도 검게 칠해져 있음 — 인물1의 爪 표식이 번진 것인지 뜻 불명.
- 인물5에 耳(腎開竅) 표지가 없어 五竅 한 칸 빔.
- 인물2 얼굴 흰 반점이 윤기(面)인지 땀(汗)인지 갈림.
- 그림 위쪽 약 300px가 완전 공백(캔버스 확장·이어붙임 흔적), 다섯 인물 모두 허벅지에서 아래 프레임에 잘림.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**사전으로 바뀐 점**: 옷 모양(갑옷·곤룡포·밀짚모자·도포·갓·잠수복·고글)은 인물 표지일 뿐이라 다시 읽지 않는다 → 1단계의 十二官(將軍·君主·倉廩·相傅·作強) 해석과 고글=水는 철회. 대신 다섯 명 모두 **걷어올린 맨팔뚝 위에 무언가가 더해져 있다 = 充**, 얼굴·손의 광택 = **華**. 원창의 철은 각 臟이 「通於X氣」. 脾의 원창이 長夏 풍경이 아니라 맨 흙인 것도 「通於土氣」와 정확히 맞는다. 곧 이 판은 素問 六節藏象論의 五臟 문장(其華在~, 其充在~, 通於~氣)을 옮긴 것이다.

**① 판 표제어**
- 1순위: **六節藏象論 — 五臟의 華·充·通四時氣** (75%)
- 2순위: **藏象 五臟系統 配屬(五體·五華·五竅·五色)** (20%)

**② 인물별 (왼쪽부터)**
1. 초록 갑옷 장군 = **肝**: 옷 靑 / 새순 가지 = 通於春氣 / 맨팔뚝의 도드라진 갈색 힘줄 다발 = 其充在筋 / 광택 나게 칠한 손톱 5개 = 其華在爪 / 크게 뜬 눈 = 目(竅). (5개)
2. 붉은 곤룡포 임금 = **心**: 옷 赤 / 여름 녹음 = 通於夏氣 / 맨팔뚝의 붉은(血) 갈래 혈관 = 其充在血脈 / 이마·광대·콧대 광택 = 其華在面(물방울 아님 → 汗 아님) / 벌린 입 속 혀 = 舌. (5개)
3. 노란 밀짚모자 농부 = **脾**: 옷 黃 / 흙 원창 = 通於土氣 / 맨팔뚝의 닫힌 윤곽 살덩이 = 其充在肌 / 입술 둘레 흰 테 = 其華在脣四白 / 혀 없이 열린 입 구멍 = 口(갈림: 혀 안 보임 → 脾). (5개)
4. 흰 도포 재상 = **肺**: 옷 白 / 단풍 = 通於秋氣 / 팔뚝을 가로지르는 색 경계선 한 줄 = 其充在皮 / 손등·손목 잔털 = 其華在毛 / 검게 열린 콧구멍 = 鼻. (5개)
5. 검은 잠수복 잠수부 = **腎**: 옷 黑 / 눈·안개 겨울 풍경 = 通於冬氣 / 맨팔뚝 위 곧은 흰 뼈 능선 + 끝 뼈 혹 = 其充在骨 / 윤 흐르는 검은 머리 = 其華在髮. 耳(옆으로 돌린 귀) 없음. (4개)

**③ 잔결**
- 腎에 耳 표지가 없어 竅 줄만 한 칸 빈다(六節藏象論 본문엔 竅가 없으니 目·舌·口·鼻가 덤일 수도).
- 임금 손톱 끝 5개가 검게 칠해져 爪(肝) 글자가 心 칸으로 새어 듦.
- 肺의 털이 「역광 은빛」이 아니라 갈색 털이라 毛 기호 형식과 조금 어긋남.
- 장군의 찌푸린 눈썹은 사전에 없는 표정(뜻 없음).
- 위쪽 약 300px 빈 띠(캔버스 확장 흔적)와 허벅지 아래 잘림은 그대로.
- 판정: 사전 어휘(充·華·面·肌·皮·骨·舌/口 갈림)로 1단계보다 훨씬 깔끔하게 풀린다 — 十二官 덧읽기가 사라지고 「華·充·通」 세 줄 구조가 드러남.
