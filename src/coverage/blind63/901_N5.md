# 901 판독 (N5)

## 1단계 — 생판 (사전요약 열기 전 확정)

**① 판 표제어**
- 1순위: **五臟의 外候 — 五體·五華·五竅의 五行 배속(五臟所主)** (80%)
- 2순위: **十二官(靈蘭秘典論) 五臟 직분 + 五色·五時 귀류** (12%)

다섯 인물이 같은 자세로 나란히 서고, 뒤에 계절 원판이 하나씩 붙는다. 옷 색이 靑·赤·黃·白·黑 순서이고, 팔뚝마다 筋·脈·肉·皮毛·骨이 하나씩 드러난다. 그래서 木→水 순서로 五臟 외후를 한 장에 정리한 표로 읽었다.

**② 인물별 (왼→오)**
1. **肝(木)** — 7개: 녹색 갑옷=靑 / 새순 가지=春 / 장군=將軍之官(謀慮出焉) / 진홍으로 칠한 손톱 5개=爪(其華在爪) / 손등·팔뚝 힘줄=筋(肝主筋) / 손목에 모인 힘줄 매듭=筋이 節에 모임(諸筋屬節) / 부릅뜬 눈=目(開竅於目)
2. **心(火)** — 6개: 붉은 곤룡포=赤 / 짙은 녹음=夏 / 익선관을 쓴 왕=君主之官(神明出焉) / 번들거리는 얼굴=面(其華在面) / 벌린 입속 붉은 혀=舌(開竅) / 팔뚝의 붉은 혈관 그물=脈(心主血脈)
3. **脾(土)** — 6개: 노란 저고리·밀짚모자=黃 / 흙벽 배경=土(長夏) / 농부=倉廩之官(五味出焉) / 입술을 두른 흰 테=唇(其華在唇, 唇四白) / 벌린 입=口(開竅) / 팔뚝 위 둥근 살덩이=肉(脾主肌肉)
4. **肺(金)** — 6개: 흰 도포=白 / 단풍=秋 / 갓 쓴 선비(재상)=相傅之官(治節出焉) / 검게 칠한 콧구멍 2개=鼻(開竅) / 손등·팔뚝 털=毛(其華在毛) / 팔뚝 그을림 경계=皮(肺主皮)
5. **腎(水)** — 6개: 검은 잠수복=黑 / 설원·잿빛 하늘=冬 / 물안경=水 / 수영선수=作強之官(伎巧出焉) / 윤기 흐르는 검은 머리=髮(其華在髮) / 팔뚝 속 흰 뼈=骨(腎主骨)

**③ 잔결**
- 2번 왕의 손톱이 검다. 爪 표지가 肝에서 心으로 샌 것인지, 그냥 그림이 잘못된 것인지 알 수 없다.
- 5번은 耳(開竅於耳)를 나타내는 표지가 없다. 귀가 평범하게 그려졌다.
- 3번 배경은 계절 표지 없이 흙뿐이다. 長夏를 뜻하는지 土를 뜻하는지 모호하다.
- 1번 손목의 갈색 매듭은 筋 모임으로 추정했지만 확신은 낮다.
- 4번 갓 아래 갈색 망건과 1번 투구 꼭지는 뜻이 없어 보인다.
- 화면 위쪽 약 1/4이 빈 여백이고, 인물은 모두 허리·허벅지 아래가 잘렸다.
- 원판 간격이 고르고 이어 붙인 흔적은 보이지 않는다.

## 2단계 — 계통 (사전요약 반영)

**① 판 표제어**
- 1순위: **五臟의 華·充 — 六節藏象論 藏象(其華在~·其充在~·通於~氣)** (85%)
- 2순위: **五臟 外候 귀류(五華·五體·五竅·五色·五時)** (10%)

사전의 「充 = 걷어올린 맨팔뚝 위에 더해진 것」이 판 전체를 묶는다. 다섯 사람이 모두 맨팔뚝을 내밀고, 그 위에 筋·血(붉은 핏줄)·肌·皮·骨이 하나씩 얹혀 있다. 이것은 其充在筋 / 在血脈 / 在肌 / 在皮 / 在骨이다. 「華 = 광택」 계열은 爪·面·唇四白·毛·髮로 이어진다. 원판 배경은 通於春·夏·土·秋·冬氣다. 특히 脾 뒤의 맨 흙은 長夏가 아니라 六節藏象論의 「通於土氣」로 풀린다. 옷 모양은 인물을 가리킬 뿐이라서, 1단계에서 읽은 十二官(將軍·君主·倉廩·相傅·作強)과 물안경=水는 철회한다.

**② 인물별 (왼→오)**
1. **肝** (초록 비늘갑옷 장군) — 5개: 靑 / 광택 있는 손톱=爪·華, 곧 其華在爪 / 맨팔뚝 두 곳의 갈색 힘줄 다발=充+筋, 곧 其充在筋 / 크게 뜬 눈=目(竅) / 새순=通於春氣
2. **心** (곤룡포 임금) — 5개: 赤 / 이마·광대·콧대 광택=面·華, 곧 其華在面 / 맨팔뚝 위 붉은 핏줄=充+血, 곧 其充在血脈 / 벌린 입속 혀=舌(혀가 보이므로 心) / 녹음=通於夏氣
3. **脾** (밀짚모자 농부) — 4개: 黃 / 입술을 두른 흰 테=其華在唇四白(사전에 없는 글자라 지식으로 읽음) / 걷어 올린 맨팔뚝 위 닫힌 윤곽의 살덩이=充+肌, 곧 其充在肌 / 흙 원판=通於土氣. 입은 이만 보이고 어두운 구멍이 아니어서 口(竅)는 약하다.
4. **肺** (흰 도포 재상) — 5개: 白 / 손등·손목 잔털=毛·華, 곧 其華在毛 / 맨팔뚝의 색 경계선 한 줄=充+皮, 곧 其充在皮 / 검게 열린 콧구멍 2개=鼻(竅) / 단풍=通於秋氣
5. **腎** (잠수부) — 4개: 黑 / 윤 흐르는 머리카락=髮·華, 곧 其華在髮 / 걷어 올린 맨팔뚝 위 곧은 흰 뼈 능선과 끝의 뼈 혹=充+骨, 곧 其充在骨 / 설원=通於冬氣

**③ 잔결**
- 임금 손톱이 검다. 사전에서 爪=손톱이므로 心에 爪가 붙은 것으로 오독될 수 있다(누출).
- 竅 줄이 目·舌·鼻만 서 있다. 口는 약하고 耳는 없다(귀가 정면이고 귓구멍이 열리지 않음). 이 판이 竅까지 나르려는 것인지 애매하다.
- 肺의 毛가 「역광 은빛」이 아니라 짙은 잔털이다.
- 唇四白의 흰 테는 사전에 없다.
- 肝 손목의 갈색 띠는 뜻을 알 수 없다.
- 六節藏象論의 本(生·氣·封藏·罷極·倉廩)·神魂魄精營·陰陽 배속·味는 그려지지 않았다.
- 위쪽 1/4이 여백이고 허리 아래가 잘렸다. 이어 붙인 흔적은 없다.
- 판정: 사전 어휘(充·華)로 읽는 쪽이 1단계보다 더 잘 풀린다.
