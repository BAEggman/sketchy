# 902 판독 — O5

## 1단계 — 생판 (사전요약 열기 전 확정)

**① 판 표제어**
- 1순위: **五臟의 外候 — 五體·五華·五竅(五官) 배속 (藏象 五臟系統)** — 75%
- 2순위: **五行 歸類表(五色·五季·五臟 配屬)** — 20%
- (그 밖: 宣明五氣 「五主」만으로 보기엔 華·竅까지 실려 있어 범위가 넓음 5%)

근거: 원형 후광 다섯 개가 春(새순 가지)→夏(무성한 숲)→長夏(갈색 흙)→秋(붉은 단풍)→冬(눈밭) 순, 옷이 靑·赤·黃·白·黑 순. 각 인물이 「얼굴의 구멍 하나 + 팔뚝의 조직 하나 + 손·얼굴의 겉빛 하나」를 강조 → 五竅·五體·五華 세트.

**② 인물별 (왼→오)**
1. **肝** (녹색 갑옷 장수) — 6개: 靑色(갑옷) / 春(새순) / 目(부릅뜬 눈=開竅於目) / 爪(빨갛게 칠한 손톱=其華在爪) / 筋(들어 올린 팔·가로 팔뚝에 밧줄 같은 힘줄, 손목 한 점에 모임=主筋) / 將軍之官(장수).
2. **心** (붉은 곤룡포 임금) — 6개: 赤色 / 夏(짙은 숲) / 舌(벌린 입 속 붉은 혀=開竅於舌) / 面(번들번들 빛나는 얼굴=其華在面) / 脈(팔뚝의 붉은 핏줄 그물=主血脈) / 君主之官(용포 임금).
3. **脾** (황색 옷·밀짚모자 농부) — 6개: 黃色 / 長夏·土(갈색 흙벽) / 口(벌린 입=開竅於口) / 脣(입술 둘레 흰 테=其華在脣四白) / 肉(팔뚝의 불룩한 살덩이=主肌肉) / 倉廩之官(농부).
4. **肺** (흰 도포·갓 선비) — 6개: 白色 / 秋(단풍) / 鼻(새까맣게 칠한 콧구멍=開竅於鼻) / 毛(털 수북한 손등=其華在毛) / 皮(팔뚝의 햇볕 탄 경계선=主皮) / 相傅之官(갓 쓴 선비·재상).
5. **腎** (검은 잠수복 수영인) — 6개: 黑色 / 冬(눈밭) / 耳(크게 그린 두 귀, 귓구멍 검게=開竅於耳) / 髮(윤기 나는 검은 올백 머리=其華在髮) / 骨(팔뚝 속 하얗게 빛나는 뼈=主骨) / 水(물안경·잠수복).

**③ 잔결**
- 임금 오른손 손톱 끝 4곳에 흰 별점(반짝이) — 뜻 불명(爪 표시가 아니면 생성 잡티).
- 장수 가로 팔뚝 힘줄이 손등 한 점(갈색 점)으로 모임 — 「筋이 모이는 곳」 이상의 뜻은 못 읽음.
- 화면 위 약 1/4(0–280px)이 완전 빈 바탕 — 캔버스 확장 흔적. 아래는 허벅지에서 잘림, 맨 아래 1~4px에 가로 띠.
- 인물 다섯이 같은 높이·같은 크기 후광으로 나란히 — 개별 판을 이어 붙인 느낌은 있으나 경계 이음매는 안 보임.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위: **五臟의 其華·其充·開竅 (六節藏象論 五華·五充 + 五竅)** — 85%
- 2순위: **五行 歸類(五色·五時·五竅 배속)** — 12%

판정: 사전으로 더 잘 풀린다. 다섯 인물이 모두 「가슴 앞에 가로 댄(또는 들어 올린) 걷어붙인 맨팔뚝 + 그 위에 더해진 것」을 내민다 → **充**(걷어올린 맨팔뚝 위에 더해진 것). 얼굴·손의 광택은 **華**(빛나는 것). 얼굴의 열린 구멍은 **竅**. 배경 원은 철(春·夏·土·秋·冬) = 六節藏象論의 「通於○氣」로 읽힌다(脾 배경이 長夏 풍경이 아니라 갈색 흙 = 「通於土氣」와 맞음). 옷·모자 **모양**(갑옷·용포·밀짚모자·갓·고글)은 사전 규칙상 인물 지시일 뿐이라 1단계의 「○○之官」·「水(고글)」 읽기는 철회 — 옷 **색**만 五色.

**② 인물별 (왼→오)**
1. **肝**(초록 갑옷 장군) — 5개: 蒼(옷색) / 春氣(새순) / 目(크게 뜬 눈=竅) / 其華在爪(광택 손톱) / 其充在筋(맨팔뚝 위 갈색 힘줄 다발).
2. **心**(곤룡포 임금) — 5개: 赤 / 夏氣(짙은 숲) / 舌(벌린 입 안 혀 보임 → 갈림상 心) / 其華在面(이마·광대·콧대 광택) / 其充在血脈(맨팔뚝 위 붉은 줄 그물=血).
3. **脾**(밀짚모자 농부) — 4+1개: 黃 / 土氣(갈색 흙) / 其華在脣四白(입술 둘레 흰 빛테) / 其充在肌(맨팔뚝의 닫힌 윤곽 살덩이) / (口 — 입은 살짝 벌렸으나 이가 보일 뿐 어두운 타원 구멍이 아니라 약함).
4. **肺**(흰 도포 재상) — 5개: 白 / 秋氣(단풍) / 鼻(검게 열린 콧구멍=竅) / 其華在毛(손등 잔털) / 其充在皮(들어 올린 팔뚝 위 색 경계선 한 줄).
5. **腎**(잠수부) — 5개: 黑 / 冬氣(눈밭) / 耳(귓구멍 검게 열린 귀=竅) / 其華在髮(윤이 흐르는 머리) / 其充在骨(맨팔뚝 위 흰 뼈 능선 + 끝의 뼈 혹).

**③ 잔결**
- 임금 손톱 끝 4곳의 흰 반짝이 = 사전상 「爪+華」로 읽혀 **心 其華在爪**라는 오독을 부른다(肝 글자가 心에 샘) — 지우는 게 맞음.
- 肺의 毛가 사전의 「역광 은빛 잔털」이 아니라 갈색 털 — 읽히긴 하나 華(광택)가 약함.
- 脾에는 竅(口)가 확실히 없음 — 다른 넷은 竅가 있는데 脾만 빠져 세트가 고르지 않음(六節藏象論 원문에 竅가 없으니 의도라면 나머지 넷의 竅가 군더더기).
- 腎 귀는 정면 그대로(옆으로 돌리지 않음), 귓구멍만 검게 — 경미.
- 화면 위 1/4 빈 바탕(캔버스 확장), 아래는 허벅지에서 잘림, 맨 아래 가는 가로 띠. 이음매 흔적은 없음.
