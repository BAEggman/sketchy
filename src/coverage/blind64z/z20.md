# z20 판독 (blind64z)

## 1단계 — 생판 (그림만)

**① 단원**: **宣明五氣**(素問·宣明五氣篇: 五液·五惡·五勞所傷) 1순위 80%. 차순위 **五行 藏象 귀속표**, **十二官(靈蘭秘典)**.

**② 인물·소품**
- 綠室 갑옷 장수 = **肝**. 장수 자체 = 將軍之官. 두 줄기 눈물 = 肝爲淚(五液). 벽의 나무판을 손으로 밀어 막는데 바람줄과 나뭇잎(약 6장)이 들이침 = 肝惡風(五惡). 크게 내딛는 걸음과 바닥에 쌓인, 구멍 나게 닳은 짚신 3짝 = 久行傷筋(五勞). 초록 방 = 靑.
- 赤室 용포 임금 = **心**. 임금 = 君主之官. 이마 땀방울(약 6) = 心爲汗. 화로의 불 + 불 앞을 가린 그을린 세움판자 = 心惡熱(그을음 = 焦臭일 가능성). 충혈된 붉은 눈 + 책상의 책 + 바닥의 종이 더미 = 久視傷血. 붉은 방 = 赤.
- 黃室 삿갓 쓴 사내 = **脾**. 입에서 늘어진 침 = 脾爲涎. 천장 먹구름 얼룩에서 새는 물줄기를 우산이 받음 = 脾惡濕. 방석 위 가부좌 = 久坐傷肉. 노란 방·노란 옷 = 黃.

**관계**: 한 지붕 아래 칸이 왼쪽부터 木→火→土, 곧 상생 순(肝→心→脾)으로 늘어섬. 오른쪽 이웃 띠에 肺·腎 칸이 이어질 것으로 봄. 세 사람이 각자 싫어하는 기운을 문판·판자·우산으로 막는 같은 짜임 = 五惡 대구. 장수가 임금 칸 쪽으로 걸음 = 將軍이 君主를 섬김/木生火.

**③ 잔결**: 임금 하체가 살색이라 벗은 듯 보임. 판자의 그을음이 불 쪽이 아니라 임금 쪽 면에 있음. 벽에 붙은 나무판의 정체(문? 방패?)가 모호함. 사내 옷이 승복풍. 우산 오른쪽은 잘림(이웃 띠 몫). 지붕 왼끝 마감이 있어 이 띠는 통합판의 왼쪽 끝으로 봄. 이어 붙인 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (blind6_사전요약 적용)

**① 단원**: **宣明五氣**(五惡·五液·五勞所傷) 90%로 올림. 사전의 「惡 = 해로운 것과 사람 사이에 세워 막은 가리개」, 「久 = 같은 물건 셋이 포개진 것」이 세 칸에 고르게 맞아떨어진다.

**② 인물·소품** (옷 모양은 인물 지시일 뿐이라 1단계의 將軍之官·君主之官 읽기는 버림. 방·옷 색 = 五色 靑·赤·黃)
- 초록 갑옷 장군 = **肝**. 옆으로 흘러 날리는 잎(약 6장) = 風. 그것을 손으로 눌러 막은 벽판 = 惡 → **肝惡風**. 두 줄기 눈물 = **肝爲淚**. 닳아 구멍 난 짚신 3짝 포개짐 = 久 + 걸음 = **久行**(傷筋. 筋 글자인 갈색 힘줄은 그려지지 않음).
- 붉은 곤룡포 임금 = **心**. 불꽃 = 熱. 불과 임금 사이에 선 그을린 판자 = 惡 → **心惡熱**. 머리 둘레 땀방울(약 6–7) = 汗 → **心爲汗**. 닳은 책 3권이 포개진 더미 = 久, 책상의 책 = 보기, 충혈된 붉은 눈 = 目 + 血 → **久視傷血**.
- 노란 밀짚모자 농부 = **脾**. 천장 얼룩에서 떨어지는 물 = 濕(위에서 오니 外濕 쪽). 그 물을 받는 우산 = 惡 → **脾惡濕**. 입에서 늘어진 침 = **脾爲涎**. 방석 위 가부좌 = **坐**(久坐傷肉).

**관계**: 세 사람이 똑같이 「가리개로 막는다」(惡)는 짜임이 五惡의 대구를 이룬다. 칸은 왼쪽부터 木→火→土 순이고, 오른쪽 이웃 띠에 肺(惡寒·涕·久臥)와 腎(惡燥·唾·久立)이 이어질 것으로 봄. 칸마다 惡·液·勞를 하나씩 진 1장부 1칸의 표 구조다.

**③ 잔결**: 농부 칸에만 久(셋 포개짐)가 없어 「久坐」가 「坐」로만 읽힌다. 傷筋·傷肉의 筋·肌 글자가 없다. 판자의 그을음이 불 반대쪽 면에 있다. 임금 하체가 살색이라 벗은 듯 보인다. 淚·涎은 사전에 없는 글자라 그림 그대로 읽었다.
