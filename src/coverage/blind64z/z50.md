# z50 판독

## 1단계 — 생판 (사전 보기 전)

**① 단원**: **宣明五氣**(素問·宣明五氣篇) 70% / 2순위 **五行 五臟배속표** 20% / 3순위 **七情·勞逸(五勞所傷)** 10%

**② 인물** — 한 기와지붕 아래 세 칸, 칸마다 벽색 = 五色.
- 왼칸(분홍·붉은 방) 익선관·용보 붉은 곤룡포의 왕 = **心**(君主之官·火). 이마의 땀방울 = **心爲汗**(五液). 화로불 = **心惡熱**(五惡). 충혈된 눈 + 책상에서 책 보기 + 바닥의 해진 책 더미 = **久視傷血**(五勞). 세워 둔 널판자의 시커먼 그을음 = 열에 상함(또는 五臭 焦) — 불확실.
- 가운데(노란 방) 노란 갓·노란 옷의 농부 = **脾**(土). 입에서 길게 흐르는 침 = **脾爲涎**. 천장 얼룩에서 새는 빗물 + 받쳐 든 우산 = **脾惡濕**. 방석 위 가부좌 + 곁의 속이 터진 살색 방석 3장 = **久坐傷肉**.
- 오른칸(회백 방) 흰옷 차림으로 누운 사람 = **肺**(金). 코에서 바닥까지 흐르는 콧물 = **肺爲涕**. 눈송이·찬바람 = **肺惡寒**. 누운 자세 + 갈라진 베개 3개 = **久臥傷氣**.
- 관계: 왼→오 **火→土→金 相生 순서**로 칸이 이어짐. 한 지붕 = 한 몸의 五臟. 빠진 **肝(淚·惡風·久行傷筋)**, **腎(唾·惡燥·久立傷骨)**은 이웃 띠 몫으로 추정. 각 칸이 「液·惡·勞」 3항목을 똑같이 나르는 병렬 구조.

**③ 잔결**: 그을린 널판자의 뜻 불명. 흰 방 바닥의 검은 갓(腎=黑 예고? 단순히 벗어 둔 것?). 베개를 가르는 검은 균열. 왕의 하체가 맨다리처럼 살색. 세 칸의 소실점·천장 높이가 서로 달라 이어 붙인 흔적이 보임. 오른 칸 오른쪽 끝에서 눈발·인물 머리가 잘림.

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**① 단원**: **宣明五氣** 85% (「惡 = 해로운 것과 사람 사이 가리개」 어휘가 붙자 五惡이 확정됨) / 2순위 **五行 五臟배속** 12%

**② 인물** (옷 색 = 五色, 옷차림 = 인물 지시)
- 왼칸 붉은 곤룡포 임금 = **心**. 살갗의 땀방울 = 汗 → **心爲汗**. 불꽃(熱)과 임금 사이에 세운 널판자 = 惡(가리개) → **心惡熱** — 판자가 그을린 것은 열을 막아 낸 흔적이라 1단계 수수께끼가 풀림. 충혈된 눈 = 目+血, 바닥의 닳아 해진 책 무더기 = 久(닳은 무더기는 傷 아닌 久) → **久視傷血**.
- 가운데 노란 밀짚모자 농부 = **脾**. 입(口)에서 흐르는 침 → **脾爲涎**(口 = 脾竅도 함께). 천장에서 새는 빗물(外濕)과 머리 사이의 우산 = 惡 → **脾惡濕**. 가부좌(坐) + 포갠 방석 셋 = 久, 터진 살색 방석 = 肌(살덩이)+傷 → **久坐傷肉**.
- 오른칸 흰 도포 재상 = **肺**(바닥의 검은 갓은 재상 차림이 누워 벗겨진 것). 열린 콧구멍(鼻)에서 흐르는 콧물 → **肺爲涕**. 눈송이 = 寒 → **肺惡寒**. 누움(臥) + 포갠 베개 셋 = 久, 베개를 가르는 검은 균열 = 傷, 틈에서 새는 흰 김 = 氣 → **久臥傷氣**.
- 관계: 왼→오 **火→土→金 相生 순서**, 脾가 셋 중 가운데 = **中**(中央土). 세 칸 모두 「液·惡·勞」 3항목 병렬 → 宣明五氣篇의 五液·五惡·五勞所傷 세 표를 칸별로 잘라 놓은 것. 肝·腎 칸은 이웃 띠.

**③ 잔결**: 肺 칸에는 눈송이와 사람 사이 가리개(惡)가 분명치 않음 — 포갠 베개가 가리개 겸 久를 이중으로 지는 듯해 과적. 가로로 흐르는 흰 곡선이 氣(김)인지 風(옆으로 날림)인지 갈림 — 風으로 읽으면 肝惡風과 샌다. 바닥의 검은 갓이 太(사람 아닌 것 위의 갓)로 오독될 여지. 긴 기와지붕이 寺로 읽힐 여지. 임금 하체가 맨다리처럼 보임. 세 칸 소실점 불일치(이어 붙인 흔적).
