# z80 판독

## 1단계 — 생판 (그림만)

**① 단원**: **宣明五氣**(素問·宣明五氣篇 — 五液·五惡·五勞所傷) 80%. 차순위 **五臟 五行귀속표(藏象)** 15%.

**② 인물** — 한 지붕 아래 방 셋, 왼→오 노랑·흰·검정 = 土→金→水(相生 순). 띠는 다섯 방 중 끝 셋, 지붕 끝 처마가 오른쪽에서 끝남.
- 왼쪽 방(**脾**): 노란 도포·노란 갓·노란 벽. 입꼬리로 침이 줄줄 흘러내림 = **脾爲涎**. 천장 누수 + 실내 우산 = **脾惡濕**. 방석 위 책상다리 = **久坐傷肉**; 곁의 방석 3장이 해져 솜이 터짐 = 오래 앉아 '살'이 닳음.
- 가운데 방(**肺**): 흰 옷, 누워 있음 = **久臥傷氣**. 코에서 콧물이 바닥까지 = **肺爲涕**. 문틈으로 눈보라, 솜으로 틈을 막음 = **肺惡寒**. 베개 3개가 쌓여 찢어짐 = 오래 누운 소모(氣 빠짐).
- 오른쪽 방(**腎**): 검은 잠수복(水·黑). 서 있음, 몸에 거미줄까지 = **久立傷骨**. 입에서 침을 멀리 뱉어 놋 타구에 = **腎爲唾**. 갈라진 마른 벽·천장 거미줄 = 燥, 물대야·젖은 수건·잠수복으로 습기 보충 = **腎惡燥**.

**관계**: 세 방이 상생 순 土→金→水로 나란함(앞 두 방 肝·心은 이웃 띠). 涎(흘림)↔唾(뱉음)의 대비 — 둘 다 입의 액이나 脾·腎으로 갈림. 濕(왼끝)↔燥(오른끝)의 대비. 자세 坐·臥·立 셋 = 五勞 중 셋. 한 사람이 液·惡·勞 3사실씩, 3인 × 3 = 9사실.

**③ 잔결**: 가운데 바닥의 검은 **갓**(흑립) — 뜻 불명(말총=肺脈毛? 華蓋?). 가운데 베개 찢김의 검은 내용물 정체 불명. 잠수복 머리의 마스크·후드는 腎 외 사실 없어 보임. 이어 붙인 흔적은 뚜렷하지 않음.

## 2단계 — 계통 (blind6_사전요약 적용)

**① 단원**: **宣明五氣**(五藏化液·五藏所惡·五勞所傷) 88%. 인물 옷이 그대로 五色·五臟(노란 밀짚모자 농부=脾, 흰 도포 재상=肺, 검은 잠수복 잠수부=腎)이라 1단계 짐작이 사전으로 확정됨. 차순위 **藏象 五行귀속** 8%.

**② 인물**
- **脾**(농부): 입(口=어두운 구멍)에서 흐르는 침 = **脾爲涎**. 천장 물줄기(濕) + 사람과 물 사이를 막은 우산(**惡**=가리개) = **脾惡濕**. 방석 **셋 포개짐 = 久** + 앉음 + 터진 도톰한 방석(肌의 사물이 해짐) = **久坐傷肉**.
- **肺**(재상): 콧구멍에서 바닥까지 = **肺爲涕**. 문틈 눈송이 = **寒**(外寒), 문과 머리 사이에 쌓아 막은 베개·문틈 솜 = **惡** → **肺惡寒**. 베개 **셋 포개짐 = 久** + 누움 + 찢긴 틈 곁의 흰 김(氣) = **久臥傷氣**. 바닥의 갓은 재상의 옷차림(肺) — 누워서 벗어 둔 자리 바뀜, 太 아님.
- **腎**(잠수부): 입에서 뱉어 타구에 담김 = **腎爲唾**. 갈라진 벽 = **燥**, 그 위를 덮은 젖은 수건(惡=가리개)·물대야 = **腎惡燥**. 선 자세 + 몸에 친 거미줄 = **久立傷骨**(사전 글자 久·傷·骨 없음 — 자세로만 나름).

**관계**: 세 방이 五色 순 黃→白→黑 = 土→金→水 상생 차례(肝·心 방은 이웃 띠). 한 사람이 液·惡·勞 3사실, 3×3=9. 涎(흘림)↔唾(뱉음)은 같은 입의 액이 脾·腎으로 갈림, 濕↔燥 양끝 대비.

**③ 잔결**: 腎 방에만 久(셋 포개짐)·傷·骨 글자가 없어 久立傷骨이 자세에만 기댐. 肺 방 눈보라의 옆으로 흐르는 흰 줄이 **風**(옆으로 흘러 날림)으로도 읽혀 肝惡風과 샐 수 있음. 腎 방 맑은 물대야가 **淸**(맑고 찬 물 한 그릇)과 부딪힘. 가운데 베개 틈의 검은 내용물은 여전히 뜻 불명. 방석·베개의 '터짐'은 傷 갈림(닳은 무더기=久)과 겹쳐 傷을 따로 세우지 못함.
