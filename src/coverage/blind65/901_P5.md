# 901 판독 (P5)

## 1단계 — 생판 (사전 없이 그림만)

**① 판 표제어**
- 1순위 **宣明五氣 — 五藏所惡·五藏化液·五勞所傷 통합** (88%)
- 2순위 **五臟 五行配屬(藏象 五臟 歸類表)** (8%)
- 근거: 기와지붕 한 채에 방 5칸, 벽·옷 색이 靑·赤·黃·白·黑 순(木火土金水 상생순). 칸마다 「액체 하나 + 싫어하는 기후 하나 + 오래 한 자세 하나」가 똑같은 틀로 반복됨 → 《素問·宣明五氣》의 세 표를 한 장에 겹친 것.

**② 인물별 (왼→오)**
1. 녹색 방 갑옷 무사 — **肝** : ⓐ 靑색(木) ⓑ 무사=將軍之官 ⓒ 눈물 줄줄=肝爲淚 ⓓ 옆문을 밀자 바람·나뭇잎(6장 안팎) 들이침=肝惡風 ⓔ 걷는 중 + 바닥 닳아 구멍 난 짚신 3켤레=久行傷筋. **5개**
2. 붉은 방 곤룡포 인물 — **心** : ⓐ 赤색(火) ⓑ 용보 곤룡포·익선관=君主之官 ⓒ 이마 땀방울=心爲汗 ⓓ 화로 불길 + 그을린 널판=心惡熱 ⓔ 충혈된 눈으로 책 읽기 + 다 읽은 책 더미=久視傷血. **5개**
3. 노란 방 좌정 인물 — **脾** : ⓐ 黃색(土, 옷·갓·벽) ⓑ 입에서 침 흘림=脾爲涎 ⓒ 천장 얼룩에서 물이 새 우산 받침=脾惡濕 ⓓ 책상다리로 앉음 + 해져 솜 터진 방석 3장=久坐傷肉. **4개**
4. 회백 방 누운 인물 — **肺** : ⓐ 白색(金, 흰 옷) ⓑ 콧물이 바닥까지 흘러 웅덩이=肺爲涕 ⓒ 문틈으로 눈발·찬바람, 솜뭉치로 틈 막음=肺惡寒 ⓓ 누워 있음 + 터진 베개 3개=久臥傷氣. **4개**
5. 흰 방 검은 잠수복 인물 — **腎** : ⓐ 黑색(水, 잠수복=물) ⓑ 놋 타구에 침 뱉기=腎爲唾 ⓒ 갈라지고 벗겨진 벽 + 마른 수건 + 물대야=腎惡燥 ⓓ 꼼짝 않고 서 있어 몸·천장에 거미줄=久立傷骨. **4개**

**③ 잔결**
- 뜻 모를 소품: 4번 방 바닥의 검은 갓(벗어 둔 것인지 相傅之官 표지인지 불명), 4번 베개 끝 흰 토끼 얼굴, 5번 파란 수건·물대야(燥 반대 장치로만 추정), 2번 그을린 널판(熱과 중복).
- 「3개 더미」(짚신·방석·베개)가 3칸에 반복되나 숫자 3이 나르는 사실은 못 찾음 — 단순 '오래 써서 닳음' 표시로 읽음.
- 2번·4번 방 오른쪽 아래 바닥에 네모꼴 반짝이(✦) 2개 — 그림 내용과 무관, 생성 흔적 의심.
- 화면 하단 약 20%가 빈 크림색 여백, 전체 해상도 흐림(확대 업스케일 느낌). 칸 경계·지붕은 연속, 이어 붙인 솔기는 안 보임.
- 1번 방 지붕·벽 왼끝이 프레임 가장자리에 바짝 붙음(살짝 잘림).

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 판 표제어**
- 1순위 **宣明五氣 — 五藏所惡·五藏化液·五勞所傷** (93%, 상향)
- 2순위 **五臟 五行配屬(藏象 五臟 系統表)** (5%)
- 사전으로 더 잘 풀림: 「惡 = 해로운 것과 사람 사이의 가리개」가 다섯 칸 모두에 있다(문·널판·우산·문+솜·수건). 1단계에서 '그을린 널판'을 熱 중복으로 봤으나 실은 불꽃(熱)과 임금 사이의 가리개 = 惡. 「久 = 같은 물건 셋이 포개진 것」이 짚신·방석·베개 3칸에 그대로 맞음. 「닳은 무더기는 傷이 아니라 久」 규칙도 부합.

**② 인물별 (왼→오)** — 옷 모양은 인물 지목일 뿐(官 등 따로 안 읽음)
1. 초록 갑옷 장군 = **肝**(靑) : 눈물=肝爲淚 / 옆으로 날리는 잎=風 + 문을 밀어 막음(가리개)=惡 → 肝惡風 / 짚신 셋 포개짐=久 + 걷기 → 久行傷筋. **3개**
2. 붉은 곤룡포 임금 = **心**(赤) : 땀방울=汗=心爲汗 / 불꽃=熱 + 널판 가리개=惡 → 心惡熱 / 독서 + 붉은 눈=血 → 久視傷血. **3개**
3. 노란 밀짚모자 농부 = **脾**(黃) : 침=脾爲涎 / 천장 누수=外濕 + 우산 가리개=惡 → 脾惡濕 / 앉음 + 방석 셋=久 → 久坐傷肉. **3개**
4. 흰 도포 재상 = **肺**(白) : 콧물=肺爲涕 / 눈송이=外寒 + 문·솜 가리개=惡 → 肺惡寒 / 누움 + 베개 셋=久 → 久臥傷氣(벗어 둔 갓 = 자리 바뀜, 臥 보강). **3개**
5. 검은 잠수복 잠수부 = **腎**(黑) : 침 뱉기=腎爲唾 / 갈라진 벽=燥 + 수건(가리개?)·물대야 → 腎惡燥 / 서 있음 + 거미줄 → 久立傷骨. **3개**

**③ 잔결 (사전 기준)**
- 傷筋·傷肉·傷氣·傷骨의 筋·肉·氣·骨 기호(힘줄 다발·살덩이·흰 김·흰 뼈)가 없음 → 五勞의 '傷○' 뒷절반은 心(붉은 눈=血)만 글자로 실림.
- 2번 책 더미는 셋 포개짐이 아닌 흐트러진 무더기, 5번 久立은 셋 포개짐 대신 거미줄 → 久 문법 불일치.
- 5번 놋 그릇이 등재 기호 요강(=小便)과 같은 꼴, 물대야는 淸(맑고 찬 물 한 그릇)과 겹침 → 오독 위험. 수건이 가리개로 약함.
- 4번 바닥 갓은 太(사물 위 갓)와 헷갈릴 여지, 베개 끝 토끼 얼굴 미상.
- ✦ 반짝이 2개(2·4번 칸 오른쪽 아래), 하단 빈 여백, 흐린 해상도. 이어 붙인 솔기는 없음.
