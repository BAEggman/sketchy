# z21 판독 (blind66z)

## 1단계 — 생판 (사전 없이)

**① 시대**: 중국 **先秦(戰國)~前漢** / 한국 **古朝鮮·三韓(삼국 이전)** — 확신도 80%. 강 왼끝에 산·폭포(강의 발원)가 있어 말판 ①줄의 맨 앞 구간으로 본다.

**② 레인별 묶음**
- 강(本草): 소머리 사람(牛首=神農)이 금메달을 걸고 부두에 서 있고, 곁에 크기가 큰·중·소인 바구니 3개 → **神農本草經**. 금메달 = 현존 最古 本草書(「최초」), 바구니 3 = 三品分類(上·中·下品 / 君·臣·佐使, 365種). 산·폭포 = 本草 계보의 발원.
- 흙길 ① (왼쪽): 4칸 선반 — 竹簡 묶음 / 마른 풀(약초) 다발 / 사다리 / 금빛 상자. 표제어 미확정. 후보 **周禮 醫事制度**(食醫·疾醫·瘍醫·獸醫의 4分科) 또는 **馬王堆 출토 醫書**(竹簡·帛書를 漆盒에 넣어 묻음, 약초 출토). 「금 상자 = 金匱」 가능성도 있으나 시대 순서(扁鵲 앞)와 맞지 않는다.
- 흙길 ② (가운데): 까치(鵲)가 책상 위 펼친 책 곁에 앉음, 책상 위 白·赤·靑 깃발 3개 → **扁鵲(秦越人)**. 책 = **難經**(託名) · 脈診의 祖. 깃발 3 = 趙(邯鄲)·周(雒陽)·秦(咸陽)에서 帶下醫·耳目痺醫·小兒醫로 바꾼 「隨俗爲變」.
- 흙길 ③ (오른쪽): 곡식 자루가 가득한 창고(문 열림) → **倉公 淳于意**(太倉長). 史記 扁鵲倉公列傳이라 까치 바로 옆. 창고에 쌓인 자루 = **診籍**(최초 醫案, 25例)로 읽었지만 근거는 약하다.
- 거리(한국): 초가집 한 채뿐, 덧붙은 소품이 없다 → 표제어 없음. 삼국 이전의 배경으로 본다.

**③ 뜻 모를 것·흔적**: 선반의 사다리·금 상자·풀 다발은 개별 사실을 특정하지 못했다. 깃발 3색의 뜻, 흙길 뒤 성벽(長城=秦?), 창고 문이 열린 점, 바구니 뒤 검은 원통(부두 기둥으로 봄)도 그렇다. 오른쪽 끝에 이웃 띠의 초가 지붕이 잘려 있다. 이어 붙인 흔적은 보이지 않았다.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: 그대로 중국 **先秦~漢** / 한국 **古朝鮮·三韓** — 확신도 85%. 4칸 함이 四大經典(後漢 張仲景의 두 책까지 포함)을 한데 묶은 머리 칸이라, 이 띠가 ①줄의 맨 앞이라는 판단이 더 굳어졌다.

**② 레인별 다시 읽기**
- 강: 소머리 사람·금메달·바구니 3개 → **神農本草經**, 바뀐 것 없음. 사전에서 「풀 다발 = 神農本草經」으로 등재되어 있어 뜻이 서로 맞는다. 바구니는 나란히 놓였을 뿐 포개지지 않았으므로 久가 아니다. 그래서 三品分類 읽기를 유지한다.
- 흙길 ①: 2×2 네 칸 나무 함 → **四大經典** 묶음으로 확정. 칸마다 竹簡 묶음 = **黃帝內經**, 풀 다발 = **神農本草經**, 여섯 단 사다리 = **傷寒論**(六經), 금궤 = **金匱要略**. 「한 함에 작게 함께」라는 갈림 조건을 채운다. 1단계의 周禮·馬王堆 추정은 버린다.
- 흙길 ②: 까치·펼친 책·3색 깃발 → **扁鵲**·**難經**. 사전에 鵲 항목이 없어서 1단계 읽기를 그대로 둔다(깃발 = 隨俗爲變).
- 흙길 ③: 문 열린 곳간에 가마니가 쌓였고 앞에 관리가 없다. 사전의 갈림(관리가 서 있어야 倉)에 따르면 **倉이 아니라 藏**이다. 따라서 1단계의 **倉公 淳于意**는 조건을 채우지 못해 보류한다. 藏으로 읽으면 같은 줄 후보는 **中藏經**(華佗 託名)이지만, 中을 나르는 소품을 이 띠 안에서 찾지 못했다. 관리가 이웃 띠에 있다면 倉公으로 되돌아간다.
- 거리: 초가집 한 채뿐이다. 寺(기와 절)도 아니고 사전 기호도 없으므로 표제어는 없다.

**③ 남는 것**: 3색 깃발은 가운데 붉은 깃발이 더 높이 솟아 있다. 사전의 中(셋 중 가운데)에 해당하는지, 「가구 위면 官」 갈림에 걸리는지 판정하지 못했다. 까치와 소머리 사람에게는 흰 오려붙임 테두리가 둘러져 있어 합성 흔적으로 보인다. 흙길 뒤 성벽(外·裏?)은 배경으로 처리했다. 곳간이 倉인지 藏인지가 이 띠의 가장 큰 미결이다.
