# z52 판독

## 1단계 — 생판 (사전 없이)

**① 시대**: 중국 **明** / 한국 **朝鮮 전기** — 확신도 65%. 근거: 흙길 인물의 검은 오사모형 관모·단령풍 도포(明), 아래 거리 인물이 흰 바지저고리에 상투(조선 서민), 강의 「그물 = 綱目」.

**② 레인별 묶음**
- **강(본초)** — 나루 판자 위에 등을 돌린 의원(약 호리병·푸른 잎 한 줄기), 왼쪽에 풀포기를 가득 건져 올린 **그물**. 그물의 벼릿줄(綱)과 그물코(目) = **本草綱目**(李時珍). 그물이 「온갖 풀을 망라」 = 집대성 본초. 뒤 대숲은 배경으로 봄.
- **흙길 ①** — 콧수염·염소수염의 남색 도포 의가 + 곁에 묶인 **말**. 말 등의 **노란 천(黃)** 위에 침이 꽂힌 죽간 묶음 하나(鍼經=靈樞)와 끈으로 묶은 죽간 묶음 하나(素問), 말 가슴의 **금메달**. → **馬蒔**(馬玄臺): 『黃帝內經素問注證發微』·『靈樞注證發微』, 금메달 = 「靈樞를 처음으로 전편 주석」(최초).
- **흙길 ②** — 갈색 도포의 젊은 의가. 발치에 **눈송이**(雪→薛), 쌓인 **장작 묶음**(땔감=溫), 곧게 선 **사다리**(立), **가위**(외과). → **薛己**(薛立齋): 온보학파의 선구, 원래 외과 출신(『外科樞要』 등), 『內科摘要』. 차순위 **王肯堂**(목공 도구=準繩?).
- **거리 ①** — 펼친 큰 책 두 권. 왼쪽 책: 연기 나는 초가 + 약초 다발 = 시골집의 약 = **鄕藥集成方**(차순위 『村家救急方』). 오른쪽 책: 새끼리·물고기끼리·짐승끼리 무리 지어 그려짐 = 종류대로 모음 = **醫方類聚**.
- **거리 ②** — 흰옷 상투의 서민 두 사람과 기와집 두 채 → 서민 구료 기관(**惠民署**·**活人署**) 후보. 소품이 약해 확신 낮음.

**③ 잔결** — 흙길 뒤 흰 등롱 두 개(두 책? 배경?), 오른쪽 가장자리 버드나무·회색 도포 인물(이웃 띠 몫), 강 뒤 대숲의 뜻 불명. 薛己 묶음의 사다리·가위는 각각 무엇을 나르는지 확정 못함. 거리 ②의 두 사람은 말하는 소품이 없음.

## 2단계 — 계통 (사전 요약 적용 후)

**① 시대**: 중국 **明** / 한국 **朝鮮 전기(세종 무렵)** — 확신도 80%. 李·馬 기호가 「무대가 明이면」으로 모두 明 인물에 맞고, 거리의 類聚가 조선 거리의 책으로 확정돼 올라감.

**② 레인별 묶음**
- **강** — 나루의 의원 허리춤의 붉고 둥근 것은 약 호리병이 아니라 **자두 = 李**. 明 무대이므로 **李時珍**. 풀을 가득 건진 그물 = **本草綱目**(綱=벼릿줄, 目=그물코; 온갖 약물을 망라한 집대성). 1단계와 같은 표제어이나 성(李)이 기호로 확정됨.
- **흙길 ①** — 「사람 곁에 고삐로 매인 말 = 馬」, 明 무대 → **馬蒔**. 말 등의 죽간 묶음 둘(사전: 죽간 묶음 = 黃帝內經) — 침이 꽂힌 쪽 = 鍼經 = **靈樞**, 끈으로 묶은 쪽 = **素問** → 『素問注證發微』·『靈樞注證發微』. 노란 천은 黃(黃帝) 보강, 가슴의 금메달은 사전에 없으나 「靈樞 전편을 처음 주석」(최초)으로 읽음. 1단계 유지.
- **흙길 ②** — 사전으로 크게 바뀜. **눈송이 = 寒**, **작은 사다리 = 傷寒論**(四大經典의 「여섯 단 사다리」를 따로 세운 것 = 그 책 하나) → 이 사람은 傷寒論 연구가. 곁의 **가위** + 가지런히 묶은 **나무쪽 다발**(條) + 흩어진 나무쪽(뒤섞인 竹簡) = 잘라서 다시 엮음 = **錯簡重訂**. 明 무대 → **方有執** 『**傷寒論條辨**』(錯簡重訂派의 시작). 1단계의 薛己(雪→薛, 장작=溫補)는 버림. 차순위 喻昌(淸初라 무대가 늦음).
- **거리 ①** — 오른쪽 책은 한 표지에 새·물고기·네발짐승 무리 셋 = 사전 그대로 **類聚** → 조선 거리의 책이므로 **醫方類聚**(확정). 왼쪽 책은 표지에 약초 한 가지(+초가 마을) = 「그 책의 약재 = 鄕藥」 → **鄕藥集成方**(초가 = 鄕). 
- **거리 ②** — 흰옷 상투 두 사람: 사전의 惠(빈 사발)·濟(밧줄)·衆·活 어느 기호도 없음 → 표제어 없음(배경 군중 또는 이웃 띠 몫).

**③ 잔결** — 馬蒔 말 가슴의 **금메달**(사전 미등재, 「최초」 추정), 뒤 처마의 **흰 등롱 두 개**, 강 뒤 **대숲**은 여전히 뜻 불명. 方有執의 사다리는 단이 6~7개로 보여 「작은 여섯 단」과 약간 어긋남. 거리 ②의 두 사람과 기와집은 말하는 소품 없이 비어 있음. 오른쪽 끝 버드나무·회색 인물은 이웃 띠.
