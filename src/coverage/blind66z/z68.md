# z68 판독

## 1단계 — 생판 (사전 보기 전)

**① 시대**: 淸(건륭 전후 18세기) / 朝鮮 후기 — 90%. 흙길의 두 남자가 변발+장포(淸 복식), 거리는 기와집·갓·상투(朝鮮).

**② 묶음별 판독**
- **강(본초)** — 여인이 강가에 쳐 둔 큰 그물(벼릿줄=綱, 그물코=目) **바깥으로 빠져나간** 풀을 하나하나 주워 바구니에 담는다 → **本草綱目拾遺**(趙學敏, 1765): 『綱目』이 빠뜨린 약을 「주워 보탬(拾遺)」.
- **흙길 왼쪽(갈색 장포·변발)** — 엽전 꾸러미의 끈이 끊겨 동전이 흩어졌고 그 사이에 바늘이 꽂혀 있다 → 끊겨 흩어진 것(錯簡)을 바늘로 다시 꿰맴(重訂) = 傷寒 **錯簡重訂派**, 표제어 1순위 **喻昌**(喻嘉言). 대안: 「꿰다」= **尤怡 『傷寒貫珠集』**, 「錢」= **錢潢**.
- **흙길 가운데(코뿔소)** — 뿔 끝에 촛불이 타는 코뿔소 → 犀角 + 火(熱) = 溫熱, 營血分 涼血(犀角) → **葉天士 『溫熱論』**(衛氣營血).
- **흙길 오른쪽(회색 장포·변발)** — 발치의 물웅덩이에 황금빛 거북 → 물(濕)+黃(熱) = 濕熱 → **薛雪 『濕熱條辨』**. 대안: 거북=龜板(三甲復脈湯) → **吳鞠通 『溫病條辨』**.
- **거리(朝鮮)** — 갓 쓴 선비가 얼굴에 붉은 반점이 돋은 아이를 안고 있음 → 麻疹 → **丁若鏞 『麻科會通』**(1798). 마루의 김 나는 찻주전자+펼친 책 = 처방(湯)을 적은 책(같은 묶음의 곁 소품으로 봄).

**③ 잔결**
- 흰 한복·상투의 두 청년(오른쪽)은 소품이 없어 무엇을 말하는지 모름(이웃 띠 몫이거나 단순 행인?).
- 거북이 왜 황금색인지, 코뿔소가 두 남자 중 누구 몫인지 애매.
- 찻주전자+책이 독립 묶음인지 선비 곁 소품인지 불분명.
- 흙길 왼쪽 가장자리 흰 조각 = 이웃 띠에서 잘린 것(무시).

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**① 시대**: 淸 중기(18세기 중후반) / 朝鮮 후기(영·정조) — 92%. 사전의 沈金鰲(1717–1776)가 확정되면서 『綱目拾遺』(1765)·麻疹서(1798 전후)와 연대가 맞물린다.

**② 묶음별 판독**
- **강(본초)** — 사전에 그물·줍기 항목 없음. 1단계 그대로 **本草綱目拾遺**(趙學敏): 綱目(그물)에서 빠진 약을 주워 보탬.
- **흙길 오른쪽(회색 장포) + 코뿔소** — 사전이 정확히 풀어 준다. 웅덩이에 목을 길게 뺀 채 **반쯤 가라앉은(沈) 금빛 큰 자라(金鰲)** = 인명 **沈金鰲**, 뿔 끝 촛불 코뿔소 = **犀燭**, 웅덩이에서 갈래로 흘러나가는 물줄기 = **源流** → 『**雜病源流犀燭**』. 코뿔소는 가운데 떨어져 있어도 이 묶음 몫. 1단계의 葉天士·薛雪(溫熱/濕熱) 판독은 오독으로 철회. (곁 사실: 沈金鰲 = 傷寒 辨證論治派의 按因類證.)
- **흙길 왼쪽(갈색 장포)** — 엽전·바늘은 사전에 없음. 오른쪽이 傷寒 辨證論治派 인물이므로 같은 갈래의 이웃으로 다시 읽어, 엽전(錢)을 성 기호로 보아 **錢潢**(『傷寒溯源集』, 以法類證) 1순위, 꿰미(貫)+바늘(꿰다)로 보아 **尤怡**(『傷寒貫珠集』, 以法類證) 2순위. 「끊긴 줄을 다시 꿴다 = 錯簡重訂(喻昌)」은 후순위로 내림. 사전 「傷(그 사물이 깨져 못 쓰게 됨)」을 끊긴 꿰미에 대면 「傷寒」 쪽 암시는 되나 寒(눈송이)이 없어 확정 못 함.
- **거리(朝鮮)** — 사전의 小兒는 「요람에 누운 아기」라 해당 없음(어른이 안은 아이). 1단계 그대로 반점 돋은 아이 = 麻疹 → **丁若鏞 『麻科會通』** 1순위(대안 李獻吉 — 단 李=자두 기호가 없음). 김 나는 찻주전자는 사전상 氣(서린 흰 김)이나 책과 엮이는 표제어를 못 찾음.

**③ 잔결**
- 왼쪽 남자의 **바늘**(엽전 꿰미를 끊은 듯 꽂힘)은 사전으로도 안 풀림 — 성 기호인지 학설 기호인지 미정.
- 거리의 **흰 한복·상투 두 청년**은 소품이 없어 무엇을 말하는지 모름.
- **찻주전자(김)+펼친 책**이 선비 묶음인지 독립 묶음인지 불분명.
- 코뿔소가 沈金鰲와 떨어져 화면 한가운데(왼쪽 남자 쪽)에 있어 처음엔 다른 묶음으로 읽힘 — 자리 배치가 판독을 흔듦.
