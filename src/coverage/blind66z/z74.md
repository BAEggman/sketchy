# z74 판독

## 1단계 — 생판 (사전 없이)

**시대**: ⑤ 淸·근대 줄 / 조선 말기(개항기~대한제국) — 확신 85%. 근거: 흙길 위 전봇대·전선, 왼쪽 가장자리 붉은 벽돌 양옥, 아래 거리에 양복·콧수염의 서양인. 한옥·갓·도포가 함께 있어 조선 말 개항기 풍경.

**강(본초)**: 물과 초록 언덕뿐, 소품 없음 → 이 띠에서는 본초서 표제 없음.

**흙길 왼쪽**: 갓 쓴 도포 차림 사내 + 요람 속 아기가 약초 그림 두루마리(인삼 뿌리·잎 등 5점)를 들어 올림. 아기=「새로 남(新)」 또는 「어린이(幼)」, 두루마리=본초/의서. 후보 1 **吳儀洛『本草從新』**(新=아기, 本草=약초 두루마리), 후보 2 **陳復正『幼幼集成』**(소아과). 갓이 너무 조선식이라 **이제마『東醫壽世保元』**(保=아기를 업어 기름)일 가능성도 남김. 확신 낮음.

**흙길 오른쪽**: 회색 도포·검은 모자 사내, 가슴에 초록 새싹 배지, 발치에 노란 솔(브러시), 뒤로 약장(서랍장) 보이는 약방 + 파라솔 그림 간판. 노란=黃, 약방·약장=약국 운영 → **黃度淵『醫宗損益』·『方藥合編』**(1884). 새싹=약(본초), 파라솔=合(덮어 하나로)?

**거리 왼쪽**: 한옥 대문에 선 서양 신사(알렌로 추정). 간판 ① 큰 우산 아래 잔(그릇)을 받쳐 든 손 4개 = 넓게 은혜를 덮음(廣惠)/여럿(衆), ② 사람들이 밧줄 잡고 강을 건넘 = 濟. → **廣惠院→濟衆院(1885)**, 최초의 서양식 국립병원.

**거리 오른쪽**: 회색 도포 소년이 다음 대문 쪽으로 걸어감, 대문 간판에 두 사람이 장대/줄을 끄는 그림 → 구제(濟)? **廣濟院** 또는 다음 기관 — 가장자리라 판단 보류.

**잔결**: 파라솔 간판이 두 레인에 반복(같은 글자 기호인지 불명). 왼쪽 간판 아래 늘어진 검은 끈. 오른쪽 끝 분홍 복주머니(초록 글자)는 이웃 띠 몫으로 보임. 갓 쓴 조선인이 「중국 의가」 레인에 선 것 자체가 어색.

## 2단계 — 계통 (사전 어휘로 다시 읽기)

**시대**: ⑤ 淸·근대 / 조선 말~대한제국(1885~1912) — 확신 90%. 사전 어휘로 거리 간판이 근대 기관명으로 바로 풀려 시대가 굳어짐.

**강(본초)**: 소품 없음 — 변동 없음.

**흙길 왼쪽**: 사전 「小兒 = 요람에 누운 아기, 아기가 펼쳐 든 몸만 한 처방전 두루마리 = 醫方 → 『小兒醫方』」과 정확히 일치. 1단계의 新(本草從新)·幼(幼幼集成) 풀이는 버림. 갓은 사람이 쓴 것이라 太가 아니라 옷차림(조선 사람). → **崔奎憲『小兒醫方』(1912)**, 근대 소아과 전문서. 다만 한국 의서가 「중국 의가」 흙길에 놓인 점은 문법과 어긋남.

**흙길 오른쪽**: 뒤 건물 안 약서랍장 = 徐(서랍 소리), 간판의 펼친 파라솔 = 廣(넓게 펼친 차양). 사내 가슴의 새싹 = 生(五化 문법 밖이라 판 문법을 따름), 발치 노란 솔은 사전에 없음(손잡이 없는 솔이라 瀉 빗자루와도 어긋남). 淸 무대의 徐 → **徐大椿(靈胎)** 1순위(새싹=본초면 『神農本草經百種錄』?), 확신 낮음. 廣 간판이 오른쪽 가장자리에서 잘려 이웃 띠의 **廣濟院(1900)** 간판 앞머리일 가능성도 있음. 1단계 黃度淵 풀이는 근거(黃 기호)가 사전에 없어 내림.

**거리 왼쪽**: 왼 간판 = 廣(차양) + 惠(여러 손이 받아 든 빈 사발) → 廣惠院, 오른 간판 = 濟(물에 드리운 밧줄에 매달려 건져지는 사람) + 衆(한 밧줄에 여럿) → 濟衆院. 문간의 서양 신사 = 알렌. → **廣惠院→濟衆院(1885)**, 최초의 서양식 국립병원(곧 개칭). 1단계보다 훨씬 명확.

**거리 오른쪽**: 대문 간판 = 두 사람이 한 밧줄을 나란히 당김 = 同. 뒷글자는 이웃 띠로 잘림. 근대 + 同 → **同濟醫學校(1906)**, 최초의 근대식 한의학 교육기관. 걸어 들어가는 회색 도포 소년 = 학생.

**잔결**: 노란 솔·초록 새싹 배지(사전 밖), 왼 간판 밑 늘어진 검은 끈, 오른쪽 끝 분홍 복주머니(초록 글자, 이웃 띠 몫), 한국 인물·한국 의서가 중국 레인(흙길)에 선 것.
