# z86 판독 기록

## 1단계 — 생판 (사전 열기 전)

**① 시대**: ⑤줄 — 중국 **淸末·民國** / 한국 **朝鮮末·大韓帝國~日帝强占期(근대)**. 확신 92%. 근거: 전봇대·전선, 학생복(가쿠란)·중절모 양복, 붉은 벽돌 양관, 학사모 졸업생, 청진기 간판, 욱일(해 뜨는 바다) 액자.

**② 레인별 묶음**
- 강(뒤): 물과 언덕뿐. 소품 없음 → 이 띠에는 본초서 표지 없음.
- 흙길(중국) 묶음 A: 가운데 건물 간판 「펼친 우산의 살 하나를 밧줄로 물에 매어 당김」, 그 아래 회색 장포·검은 관 인물(가슴에 초록 새싹, 발밑에 금빛 솔). 뒤 건물은 약장(百子櫃) / 오른쪽 건물은 청진기 → 中藥과 西醫를 나란히 둠. 펼친 우산 = 張(펼 장) → **張錫純**《醫學衷中參西錄》(衷中參西 = 中西匯通派). 대안 **唐宗海**《中西匯通醫經精義》(물 = 匯·宗海).
- 흙길 묶음 B: 일본식 학생복·학생모 인물이 문서를 펼쳐 읽음 + 바닥의 솔(掃除) → **余雲岫** 「廢止舊醫以掃除醫事衛生之障礙案」(1929, 일본 유학 西醫). 대안 **惲鐵樵**·張錫純의 函授學校(문서 = 통신교육).
- 거리(한국) 묶음 C(왼쪽 끝, 잘림): 물속 여러 사람이 밧줄을 붙잡고 건넘 = 濟+衆 → **濟衆院**(1885, 최초 서양식 국립병원).
- 거리 묶음 D: 기와 대문 간판 「줄다리기(2:3 대립)」, 왼쪽 두루마기 한의·오른쪽 중절모 양복 양의가 문을 사이에 둠 → **漢醫學 復興論爭**(1934, 장기무 vs 정근양). 대안 **東西醫學硏究會**.
- 거리 묶음 E: 붉은 벽돌 3층 양관 + 「바다 위 해돋이」 액자 + 학사모 졸업생 둘(여성 1) + 옥상 목조 비계(공사 중) → 해 뜨는 바다 = 東洋 → **東洋醫藥大學**(최초 한의과대학, 설립). 대안: 욱일 = 일본 → **大韓醫院**(시계탑 벽돌 건물)·조선총독부의원.

**③ 잔결**: 바닥의 분홍 주머니(초록 용 무늬)와 금메달 — 의생 면허? 「최초」? 뜻 불명. 흙길 인물의 두루마기·관이 한국 거리 인물과 똑같아 국적 표지가 흐림. 왼쪽 끝 두루마리·나무 요람은 이웃 띠 몫. 옥상 비계는 공사 중인지 망루인지 애매.

## 2단계 — 계통 (blind6_사전요약 어휘로 다시 읽기)

**① 시대**: ⑤줄 근대 그대로. 한국 **大韓帝國~日帝强占期~해방 직후**, 중국 淸末·民國(이 띠에는 중국 표제어가 사실상 없음). 확신 93%.

**② 다시 읽기**
- 강: 소품 없음(변함없음).
- 흙길 뒤 간판: 펼친 차양 = **廣**(「넓게 펼친 차양」), 물에 드리운 밧줄 = **濟** → **廣濟院**(1900, 內部病院 개칭). 그 밑 약서랍장 건물(한방) / 청진기 건물(양방)이 나란함 → 한·양방 병설. 1단계의 張(우산)은 철회 — 사전의 張은 「등에 멘 활」이다. 약서랍장은 사전상 徐지만 이 무대에 맞는 徐가 없어 건물 배경(한방과)으로 본다.
- 흙길 인물: 두루마기 한의 가슴의 새싹 하나 = 生(五化 갈림: 새싹 홀로 → 판 문법) → 「醫生」. 일본식 제복·모자 관리가 문서를 읽어 줌 → **醫生規則**(1913, 한의사를 醫生으로 격하) 1순위. 대안: 廣濟院의 한의·양의 두 사람. 금빛 솔은 瀉(손잡이 달린 짚 빗자루)와 생김이 달라 미등재.
- 거리 왼끝: 한 밧줄에 여럿이 매달려 물에서 건져짐 = 濟+衆 → **濟衆院**(1885, 최초 서양식 국립병원) 확정.
- 거리 대문: 한 밧줄을 여럿이 나란히 당김 = **同**(1단계의 「대립·논쟁」은 철회). 학교식 대문 + 두루마기 한의 → **同濟醫學校**(1906, 대한의사총합소 세운 최초의 관인 한의학 교육기관). 바닥의 용무늬 주머니 = 황실 내탕금 지원, 금메달 = 「최초」로 읽힘.
- 거리 오른쪽: 수평선 위 반만 뜬 해 = **東**(陽 아님) + 바다 = 洋 → **東洋**. 학사모 졸업생 + 공사 중 비계 → **東洋大學館→東洋醫藥大學**(최초 한의과대학 설립). 중절모 양복 인물은 이 묶음 쪽으로 걷는 사람.

**③ 잔결**: 금빛 둥근 솔(사전에 없음, 瀉와 다름). 제복 모자의 초록 휘장. 廣濟院(한국 기관) 간판이 가운데 흙길 레인 건물에 걸려 레인 문법과 어긋남 — 이어 붙인 흔적 의심. 용 주머니·금메달은 사전 미등재라 추정.
