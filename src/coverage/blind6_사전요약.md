# 글자 사전 요약 (이 그림책이 앞 판들에서 등재한 전담 기호 — 글자 = 사물)

## 오행왕국 다섯 인물(장부의 의인화)
- 초록 갑옷 장군 = 肝 · 붉은 곤룡포 임금 = 心 · 노란 밀짚모자 농부 = 脾 · 흰 도포 재상 = 肺 · 검은 잠수복(후드·고글) 잠수부 = 腎

- 氣 = 서린 흰 김
- 熱 = 불꽃
- 寒 = 눈송이
- 陰 = 얼음 덩이 · 또는 졸아드는 고인 물
- 陽 = 해 또는 불
- 血 = 붉은 것
- 津 = 맑은 물방울
- 痰 = 끈적한 회백색 덩이
- 瘀 = 검붉게 굳은 덩이
- 虛 = 삼분의 일로 줄어든 것
- 實 = 팽팽하게 찬 것
- 盛 = 넘쳐 흘러나오는 것
- 衰 = 타다 남아 작아진 것
- 久 = 같은 물건 셋이 포개진 것
- 傷 = 터져·깨져 못 쓰게 된 물건
- 上 = 머리 꼭대기로 곧게 솟음
- 下 = 아래로 가라앉거나 쏟아짐
- 內 = 담 안쪽 · 문 안쪽
- 外 = 담 바깥
- 中 = 한복판 — 같은 것 셋 중 가운데 / **둘 사이의 한복판**
- 表 = 겉껍질 · 문 밖
- 裏 = 속 · 성 안
- 厥 = 검푸르게 언 손발 끝
- 爪 = 손톱
- 筋 = 도드라진 갈색 힘줄 다발
- 骨 = 흰 뼈 · 곧은 능선과 끝의 뼈 혹
- 肌 = 닫힌 윤곽으로 도톰하게 솟은 살덩이
- 皮 = 면 위의 색 경계선 한 줄
- 毛 = 역광에 은빛으로 서는 잔털
- 髮 = 윤이 흐르는 머리카락
- 面 = 이마·광대·콧대에 얹힌 광택
- 目 = 크게 뜬 눈 · 눈꺼풀 사이 열린 틈
- 舌 = 벌린 입 안의 혀
- 口 = 어두운 타원 구멍
- 鼻 = 열린 콧구멍
- 耳 = 옆으로 돌려 귓구멍이 검게 열린 귀
- 汗 = 살갗에 맺힌 땀방울
- 痛 = 살에 박힌 쇠못 하나
- 腫 = 부풀어 팽팽해진 곳
- 補 = 그릇에 찰랑찰랑 찬 따뜻한 국물
- 瀉 = 짚 빗자루
- 溫 = 김이 오르는 따뜻한 천
- 淸 = 맑고 찬 물 한 그릇
- 散 = 사방으로 흩어져 날리는 것
- 收 = 아가리를 끈으로 조여 오므린 굵은 삼베 자루 하나
- 降 = 내리누르는 저울추
- 和 = 수평으로 멎은 양팔 저울
- 會 = 담는 것 안에 담긴 것
- 華 = 빛나는 것 · 광택
- 充 = 걷어올린 맨팔뚝 위에 더해진 것
- 竅 = 열린 어두운 구멍
- 通 = 안과 밖이 한 덩어리로 이어짐
- 格 = 막은 문틈으로 밀려 나가는 것
- 王 = 왕관
- 張 = 등에 멘 긴 활
- 李 = 허리춤 자두
- 吳 = 얼굴 절반만 한 큰 입
- 肝 = 초록 비늘갑옷을 입은 장군
- 心 = 붉은 곤룡포를 입은 임금
- 脾 = 노란 밀짚모자를 쓴 농부
- 肺 = 흰 도포를 입은 재상
- 腎 = 검은 잠수복·후드·고글의 잠수부
- 苔 = 혀 위에 낀 이끼
- 倉 = 곡식 가마니가 쌓인 곳간 안
- 濟 = 물에 드리운 밧줄 / 그 밧줄에 매달려 건져 올려지는 사람
- 廣 = 넓게 펼친 차양
- 惠 = 여러 손이 받아 드는 빈 사발
- 衆 = 한 밧줄에 여럿이 매달림
- 同 = 한 밧줄을 여럿이 나란히 함께 당김
- 藥 = 배 모양 약연(藥碾)
- 保命 = 두 손으로 감싸 바람을 막은 등잔불
- 典藥 = 끈으로 묶은 약봉지 다발
- 太 = 머리에 씌운 테 넓은 큰 갓 하나
- 寺 = 기와지붕을 얹은 절 한 채
- 大 = 같은 종류의 것 둘이 나란한데 하나가 두 배
- 地黃 = 검붉은 뿌리 조각
- 惡 = 해로운 것과 사람 사이에 세워 막은 가리개
- 風 = 한쪽으로 눕고 옆으로 흘러 날리는 것
- 便 = 大便 = 손잡이 달린 나무 뒷간통 · 小便 = 요강
- 藏 = 문 열린 곳간 안에 쌓인 곡식 가마니
- 官 = 3층 선반장의 가운데 층
- 門 = 작은 문간(문틀) — 몸에 얹으면 그 자리의 문
- 杼 = 실 한 가닥이 옆구멍으로 빠져나온 길쭉한 나무 베틀북
- 膈 = 기둥 넷 사이에 팽팽히 친 흰 천(가로막)
- 濕 = 外濕 = 부슬비·안개·진창(길) · 內濕 = 발밑에서 배어 나오는 진창
- 燥 = 갈라진 땅 · 마른 잎 / 內燥 = 밑동까지 마른 물독
- 酸 = 접시 위의 초록 매실
- 苦 = 김 나는 검은 커피
- 甘 = 나무 국자가 꽂힌 꿀단지(줄여서 꿀)
- 辛 = 접시 위의 붉은 고추
- 鹹 = 접시 위의 굵은 소금
- 補-b = 그릇에 가득 담긴 것 = 그 사람에게 채워 주는 것
- 瀉-b = 텅 빈 그릇 + 그릇 밖으로 쏟아져 흘러넘친 내용물 = 그 사람에게서 덜어낸 것
- 병표지 = 사람 곁에 크게 떠 있는 표지(불꽃·눈송이 등) = 그 사람의 병증
- 八卦 = 4폭+4폭 병풍 무대(마주 본 두 폭이 한 쌍) = 八卦 마주봄
