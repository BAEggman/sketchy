# 글자 사전 요약 (이 그림책이 앞 판들에서 등재한 전담 기호 — 글자 = 사물)

> ⚠ **갈림 항목은 조건부다.** 「= 」 뒤에 **갈림**이 붙은 줄은 그 조건이 맞을 때만 그 글자다.
> 조건을 빼고 읽으면 확정 항목처럼 보여 오독한다(규칙 168).

## 오행왕국 다섯 인물(장부의 의인화)
> 다섯 인물의 **옷 색은 그대로 五色이다**(靑·赤·黃·白·黑). 옷·모자의 **모양**(갑옷·투구 · 곤룡포·익선관 · 밀짚모자 · 흰 도포·검은 갓 · 잠수복·고글)은 그 인물을 가리킬 뿐 — 떼어 다른 글자로 다시 읽지 않는다. 단 **보통과 달라진 것**(두 배로 커진 투구, 벗겨져 날아가는 모자처럼 크기·자리가 바뀐 것)은 그 바뀜이 사실을 진다.
- 초록 갑옷 장군 = 肝 · 붉은 곤룡포 임금 = 心 · 노란 밀짚모자 농부 = 脾 · 흰 도포 재상 = 肺 · 검은 잠수복(후드·고글) 잠수부 = 腎

- 氣 = 서린 흰 김
- 熱 = 불꽃
- 寒 = 눈송이 — **갈림**: 눈송이=外寒 · 안쪽 성에=裏寒 · 밑에서 밴 서리=內寒
- 陰 = 얼음 덩이 · 또는 졸아드는 고인 물 — **갈림**: **살아 있는 불과 맞대어 놓였을 때만** 얼음이 陰이다. 꺼진 불·깨진 화로 곁의 얼음은 陰이 아니다(그것은 傷陽의 결과). **불이 아예 화면에 없고 무대가 겨울이면 얼음은 陰도 寒도 아니라 凝滯다**
- 陽 = 해 또는 불 — **갈림**: 계절이 차례로 바뀌는 들판·길의 하늘에서 이글거리는 해는 그 철 = 여름(夏·暑)을 나른다(陽 중의 陽)
- 血 = 붉은 것
- 津 = 맑은 물방울
- 痰 = 끈적한 회백색 덩이
- 瘀 = 몸 밖에 나온 검붉게 굳은 덩이·알갱이(손에 쥔 것, 천·그릇 위의 것) — **갈림**: **살갗 위의 멍·얼룩은 瘀가 아니다** — 그것은 그 자리의 색이다
- 虛 = 삼분의 일로 줄어든 것
- 實 = 팽팽하게 찬 것
- 盛 = 넘쳐 흘러나오는 것
- 衰 = 타다 남아 작아진 것
- 久 = 같은 물건 셋이 포개진 것
- 傷 = 터져·깨져 못 쓰게 된 물건 — **갈림**: **그 글자의 사물이** 깨져 못 쓰게 된 것. 닳아 못 쓰게 된 물건 무더기는 傷이 아니라 久다
- 上 = 머리 꼭대기로 곧게 솟음
- 下 = 아래로 가라앉거나 쏟아짐
- 內 = 담 안쪽 · 문 안쪽
- 外 = 담 바깥
- 中 = 한복판 — 같은 것 셋 중 가운데 / **둘 사이의 한복판** — **갈림**: 가구 위에서는 官, 몸 위에서는 中. 「같은 것 셋 중 가운데」와 「둘 사이의 한복판」 둘 다
- 表 = 겉껍질 · 문 밖
- 裏 = 속 · 성 안
- 厥 = 검푸르게 언 손발 끝
- 爪 = 손톱
- 筋 = 도드라진 갈색 힘줄 다발
- 骨 = 흰 뼈 · 곧은 능선과 끝의 뼈 혹
- 肌 = 닫힌 윤곽으로 도톰하게 솟은 살덩이
- 皮 = 면 위의 색 경계선 한 줄
- 毛 = 역광에 은빛으로 서는 잔털
- 髮 = 윤이 흐르는 머리카락
- 面 = 이마·광대·콧대에 얹힌 광택 — **갈림**: **광택만** 面이다 — 얼굴색 자체는 望色 판 전담
- 目 = 크게 뜬 눈 · 눈꺼풀 사이 열린 틈
- 舌 = 벌린 입 안의 혀 — **갈림**: 혀가 보이면 心, 구멍만 보이면 脾
- 口 = 어두운 타원 구멍
- 鼻 = 열린 콧구멍
- 耳 = 옆으로 돌려 귓구멍이 검게 열린 귀
- 汗 = 살갗에 맺힌 땀방울
- 痛 = 살에 박힌 쇠못 하나
- 腫 = 부풀어 팽팽해진 곳
- 補 = 그릇에 찰랑찰랑 찬 따뜻한 국물
- 瀉 = 짚 빗자루
- 溫 = 김이 오르는 따뜻한 천
- 淸 = 맑고 찬 물 한 그릇
- 散 = 사방으로 흩어져 날리는 것
- 收 = 아가리를 끈으로 조여 오므린 굵은 삼베 자루 하나 · 들판에서는 이삭이 달린 채 허리를 묶어 세운 볏단 — **갈림**: 볏단은 이삭이 달려 있고 손잡이가 없다 — 손잡이 달린 짚 빗자루는 瀉다
- 降 = 내리누르는 저울추 — **갈림**: 저울은 뜻이 셋 — 누르는 추(降) / 수평(和) / 기욺으로 갈라 쓴다
- 和 = 수평으로 멎은 양팔 저울 — **갈림**: 양팔이 **수평으로 멎은** 저울일 때만 和 (기울면 다른 뜻)
- 會 = 담는 것 안에 담긴 것
- 華 = 빛나는 것 · 광택
- 充 = 걷어올린 맨팔뚝 위에 더해진 것
- 竅 = 열린 어두운 구멍
- 通 = 안과 밖이 한 덩어리로 이어짐
- 格 = 막은 문틈으로 밀려 나가는 것 — **갈림**: 舍岩의 格(그릇·선반)과는 다른 글자다 — 그쪽 格은 안 짓는다
- 王 = 왕관 — 성이 王이라는 것까지만 — **어느 王인지는 무대(시대·장소)가 진다**
- 張 = 등에 멘 긴 활 — 성이 張이라는 것까지만 — **어느 張인지는 무대가 진다**(明 서점↔金元은 무대로 갈린다)
- 李 = 허리춤 자두 — 성이 李라는 것까지만 — **어느 李인지는 무대가 진다**
- 馬 = 사람 곁에 고삐로 매인 말 한 마리 — 성이 馬라는 것까지만 — **어느 馬인지는 무대가 진다**
- 三峯 = 물건 위에 같은 높이로 솟은 작은 봉우리 셋(펼친 책에서 솟은 종이 팝업 등) — 호(號) 三峯까지만 — **누구인지는 무대가 진다**(고려 거리 + 맥박 물결 = 鄭道傳). 배경 산(艮)과 다르다
- 吳 = 얼굴 절반만 한 큰 입 — **갈림**: ⚠ s10p04의 兌(口)와 샌다 — 무대로 가른다
- 肝 = 초록 비늘갑옷을 입은 장군
- 心 = 붉은 곤룡포를 입은 임금 — **갈림**: 五心煩熱의 心은 손·발바닥이라 臟이 아니다(면제). 心煩은 「임금 + 그 가슴 한복판」
- 脾 = 노란 밀짚모자를 쓴 농부
- 肺 = 흰 도포를 입은 재상
- 腎 = 검은 잠수복·후드·고글의 잠수부
- 苔 = 혀 위에 낀 이끼
- 倉 = 곡식 가마니가 쌓인 곳간 안
- 濟 = 물에 드리운 밧줄 / 그 밧줄에 매달려 건져 올려지는 사람
- 廣 = 넓게 펼친 차양
- 惠 = 여러 손이 받아 드는 빈 사발
- 衆 = 한 밧줄에 여럿이 매달림
- 同 = 한 밧줄을 여럿이 나란히 함께 당김
- 藥 = 배 모양 약연(藥碾)
- 保命 = 두 손으로 감싸 바람을 막은 등잔불
- 典藥 = 끈으로 묶은 약봉지 다발
- 太 = 사람이 아닌 것(나무 꼭대기·도구) 위에 씌운 테 넓은 큰 갓 하나 — **갈림**: 사람이 머리에 쓴 갓은 太가 아니다 — 그것은 그 사람의 옷차림이다(흰 도포 재상의 검은 갓 = 肺)
- 寺 = 기와지붕을 얹은 절 한 채
- 大 = 같은 종류의 것 둘이 나란한데 하나가 두 배
- 地黃 = 검붉은 뿌리 조각
- 惡 = 해로운 것과 사람 사이에 세워 막은 가리개
- 風 = 한쪽으로 눕고 옆으로 흘러 날리는 것 — **갈림**: **옆으로** 눕고 흘러 날린다 — 비와 낙엽은 수직이라 갈린다
- 便 = 大便 = 손잡이 달린 나무 뒷간통 · 小便 = 요강 — **갈림**: 大便=나무 뒷간통 · 小便=요강. 요강은 양과 색이 사실을 진다
- 藏 = 문 열린 곳간 안에 쌓인 곡식 가마니 — **갈림**: 「앞에 누가 있는가」로 倉과 갈린다 — 관리가 서 있으면 倉
- 五化 = 한 들판 벼의 다섯 단계 — 生 갓 돋은 새싹 · 長 가슴 높이 푸른 벼(이삭이 푸르고 꼿꼿) · 化 노랗게 익어 고개 숙이는 이삭 · 收 묶어 세운 볏단 · 藏 곳간 가마니 — **갈림**: 왼쪽에서 오른쪽으로 덜 익은 것부터 차례로 늘어설 때만 五化다(새싹 하나만 따로 있으면 그 판의 문법을 따른다)
- 官 = 3층 선반장의 가운데 층 — **갈림**: 3층 선반장의 **가운데 층**. 위=母 · 아래=子
- 門 = 작은 문간(문틀) — 몸에 얹으면 그 자리의 문
- 杼 = 실 한 가닥이 옆구멍으로 빠져나온 길쭉한 나무 베틀북
- 膈 = 기둥 넷 사이에 팽팽히 친 흰 천(가로막)
- 濕 = 外濕 = 부슬비·안개·진창(길) · 內濕 = 발밑에서 배어 나오는 진창 — **갈림**: 길에 있으면 外濕, **자기 발밑에서 나오면** 內濕(脾). 빗방울이 떨어져 물결이 이는 웅덩이는 비가 고인 것 = 外濕
- 燥 = 갈라진 땅 · 마른 잎 / 內燥 = 밑동까지 마른 물독 — **갈림**: 잎이 **곧게** 떨어져 風과 갈린다. 밑동까지 마른 물독 = 內燥
- 酸 = 접시 위의 초록 매실
- 苦 = 질그릇 잔·사발에 담긴 검은 커피 — **갈림**: 김은 苦의 일부가 아니다(김 = 氣) — 김 없는 검은 커피가 苦의 온전한 꼴이다
- 甘 = 나무 국자가 꽂힌 꿀단지(줄여서 꿀)
- 辛 = 접시 위의 붉은 고추
- 鹹 = 접시 위의 굵은 소금
- 補-b = 그릇에 가득 담긴 것 = 그 사람에게 채워 주는 것 — **갈림**: **담긴 것이 무엇이냐**가 「무엇을 채우나」를 진다
- 瀉-b = 텅 빈 그릇 + 그릇 밖으로 쏟아져 흘러넘친 내용물 = 그 사람에게서 덜어낸 것 — **갈림**: **무엇이 흘러넘쳤느냐**가 「무엇을 덜어냈나」를 진다
- 병표지 = 사람 곁에 크게 떠 있는 표지(불꽃·눈송이 등) = 그 사람의 병증
- 八卦 = 4폭+4폭 병풍 무대(마주 본 두 폭이 한 쌍) = 八卦 마주봄
- 善惡 = 같은 무대에 같은 얼굴·같은 색으로 나란한 쌍둥이 두 사람 — 이마·광대·콧대에 속에서 배어 나는 광택·곧은 목·맑은 눈이면 善色(有神), 잿빛으로 뿌옇게 덮여 반사가 없고 꺾인 목·처진 눈꺼풀·다물지 못한 입이면 惡色(無神) — **갈림**: 같은 생김새(쌍둥이)·같은 색의 두 사람일 때만이다. 생김새가 다른 사람들이 밝기만 다른 같은 색이면 그 색의 하위형(예: 陽黃·萎黃·陰黃)이다
- 陽卦·陰卦 = 八卦 병풍 무대에서 사람 발밑의 푸른 발자국 = 陽卦 · 붉은 발자국 = 陰卦 — **갈림**: 八卦 병풍 무대에서 사람 발밑에 찍힌 발자국 한 짝만이다 — 그 붉은 발자국은 血이 아니다. 문 쪽으로 이어지는 발자국 줄은 이 항목이 아니다
- 四大經典 = 2×2 네 칸 나무 책함, 칸마다 다른 책의 기호가 하나씩 작게(죽간 묶음 = 黃帝內經 · 풀 다발 = 神農本草經 · 작은 여섯 단 사다리 = 傷寒論 · 작은 금궤 = 金匱要略) — 네 책을 한 이름으로 부르는 묶음 — **갈림**: 한 함의 네 칸에 **작게 함께** 들어 있을 때만 묶음 이름이다. 길 위에 따로 선 같은 기호는 그 책 하나다
- 徐 = 약서랍장(서랍 — 소리) — 성이 徐라는 것까지만 — **갈림**: 강 나루 위 **사람 곁에 따로 놓인** 약서랍장만 徐다 — 가게·건물 안에 딸린 약장은 그 집이 약방(한의)이라는 뜻이다. 어느 徐인지는 무대와 곁 소품이 진다: 곁에 뿌리째 선 약초 두 포기 한 쌍(藥對)이 있으면 徐之才 『藥對』. 徐 기호 없이 별명 소품만 있는 인물(어깨의 봉황 = 鳳)은 그 소품으로 읽는다
- 類聚 = 한 책 표지 안에 같은 종류끼리 따로 모은 무리 셋(새는 새끼리 · 물고기는 물고기끼리 · 네발짐승은 네발짐승끼리) — 갈래지어 모은 책 — **갈림**: 한 표지에 **종류가 다른 무리 셋**이 나뉘어 있을 때만 類聚다(조선 거리의 책이면 醫方類聚). 표지에 약초 한 가지만 그린 책은 그 책의 약재(鄕藥)다
- 典醫監 = 조선 관청(흰 회벽·검회색 기와) 처마 밑에 기대 세운 **간판 속의** 절(기와 절 + 돌탑 + 스님) — 절 간판 = 옛 이름 典醫寺의 寺, 그것이 조선 관청에 걸리면 典醫監 — **갈림**: 寺(실제 절 한 채)와 갈린다 — 관청 앞에 **간판으로** 걸린 절은 절이 아니라 「이름 속의 寺」다
- 犀燭 = 땅에 선 작은 코뿔소의 코뿔 끝에 꽂힌 초의 촛불
- 沈金鰲 = 물웅덩이에 목을 길게 뺀 채 반쯤 가라앉은(沈) 금빛 큰 자라(金鰲) — 사람 이름. 곁의 犀燭이 그 책 『雜病源流犀燭』, 웅덩이에서 갈래로 흘러나가는 물줄기 = 源流 — **갈림**: 금빛이라도 **자라**면 鰲, 순금 **거울**이면 鑑(醫宗金鑑) — 같은 구간에 둘이 있어도 나누지 않는다
- 小兒 = 요람에 누운 아기 — **갈림**: 요람 속 아기는 小兒(책 이름의 小兒)이지 곁에 선 어른의 아들이 아니다 — 父子는 어른과 나란히 **서 있는** 아이다. 그 아기가 펼쳐 든 몸만 한 처방전 두루마리 = 醫方 → 『小兒醫方』
- 東 = 수평선·지붕선 위로 **반만** 떠오르는 해(해돋이) — **갈림**: 陽(하늘 높이 떠 이글거리는 해·그릇 안의 불)과 갈린다 — 반만 올라온 해는 陽이 아니라 東이다(東洋)
