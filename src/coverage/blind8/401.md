# 401.png 판독 기록

## 1단계 — 생판(사전정보 없음)

### ① 소품 전수와 나르는 사실
방(1점 투시 상자) 안, 똑같은 나무 등걸상 2개에 두 사람이 마주 앉음 — **같은 「熱」인데 기전이 둘**이라는 대비 구도.

**왼쪽 남자(實·陽盛)**: ⑴ 얼굴·귀·목·팔뚝까지 온통 진홍 = 滿面通紅·身大熱(전신 표면열). ⑵ 땀방울 5개가 튀어나감 = 汗大出. ⑶ 큰 사발을 통째로 기울여 벌컥 들이킴 = 大渴引飲(喜冷飲). ⑷ 펼친 부채 = 惡熱·喜涼. ⑸ 열린 창(바람줄기 3+소용돌이 2)이 그의 등 뒤 = 바람을 반김. ⑹ 발치에 서리·고드름 덮인 이불이 걷어차여 있음 = 去衣被(不欲近衣), 찬 것을 찾음. ⑺ 비대한 체격·신발 신은 발 = 形盛·實證.
**오른쪽 여자(虛·陰虛)**: ⑻ 창백한 낯에 볼 딱 2점만 발그레 = 兩顴潮紅. ⑼ 이마 땀 4방울 + 지친 눈 = 盜汗·神疲. ⑽ 손바닥 2개를 위로 까 무릎에 얹음 = 手心熱. ⑾ 맨발 2개에서 김 3~5줄기 = 足心熱·骨蒸(「蒸」의 김). ⑽+⑾ 합쳐 **五心煩熱**. ⑿ 커튼을 봉 오른쪽 끝까지 끌어와 머리·등에 뒤집어씀 = 惡風畏寒(밖은 못 견딤). ⒀ 마르고 여윈 몸.
대비 배수: 남자의 홍조는 얼굴 전체(≈면적 10배), 여자는 광대 2점뿐. 남자는 창(外)쪽, 여자는 안쪽 벽(內)에 앉음.

### ② 표제어
1순위 **熱證의 虛實 감별 — 實熱(陽盛)證 vs 虛熱(陰虛)證** … 72%
2순위 **《素問·調經論》 「陽盛則外熱, 陰虛則內熱」** … 45%
(차순위: 남자 단독으로 보면 **陽明經證·白虎湯證(四大證)**, 여자 단독은 **陰虛發熱(骨蒸潮熱)** … 각 40%)

### ③ 뜻 모를 것·어색한 것
· 이불이 왜 굳이 「얼어 있는지」 — 단순 去衣被면 서리가 불필요. 寒(찬 것)을 글자로 세운 소품일 수 있음.
· 바람이 창→오른쪽(여자)으로 부는 방향 — 남자가 아니라 여자를 때림. 惡風을 세우려는 배치로 보이나 남자의 喜涼과 화면상 어긋남.
· 여자의 손바닥을 위로 깐 자세가 五心인지 診脈 자세인지 애매.
· 옷 색(남 黃, 여 靑+赤帶)이 五色 코드인지 단순 한난 대비인지 불명.
· 프레임 잘림: 없음(장식 테두리 안에 다 들어옴). 커튼봉만 좌우 벽에 닿아 끝남.

## 2단계 — 사전(글자=사물) 적용 후

### ① 소품 재판독 — 대부분이 등재 글자였다
· **盛**(넘쳐 흘러나오는 것) = 기울인 사발에서 넘쳐 입으로 쏟아지는 물 → **陽盛**.
· **實**(팽팽하게 찬 것) = 남자의 팽팽히 부푼 배. · **虛**(⅓로 줄어든 것) = 그 옆에 앉은 여자의 몸피(≈½~⅓).
· **大**(같은 종류 둘이 나란한데 하나가 두 배) = 똑같은 걸상 2개에 나란한 두 사람, 남자가 두 배 → 大熱·大汗·大渴의 「大」가 남자 쪽에 붙는다.
· **汗**(살갗에 맺힌 땀방울) = 여자 이마 4방울(맺힘)·남자 5방울(튀어 나감=汗大出).
· **淸**(맑고 찬 물 한 그릇) = 남자의 사발 → 喜冷飲이자 淸(熱)法.
· **惡**(해로운 것과 사람 사이에 세운 가리개) + **風**(옆으로 눕고 흘러 날리는 것: 창에서 옆으로 흐르는 바람줄기 3·소용돌이 2, 옆으로 쓸린 휘장) = 여자가 봉 끝까지 끌어와 뒤집어쓴 커튼 → **惡風**. 남자는 가리개를 치우고 창을 연다 → 不惡寒·反惡熱.
· **寒** = 밀쳐낸 이불 위의 서리·고드름 → 去衣被. ⚠ **陰(얼음)이 아니다** — 살아 있는 불이 화면에 없으므로 「陰」 갈림 조건 불충족(규칙168 함정 회피).
· **五心煩熱** = 위로 깐 손바닥 2 + 맨 발바닥 2에서 오르는 김 ≈5줄기. 사전이 「五心煩熱의 心은 손·발바닥, 臟 면제」로 못박아 두었으므로 임금(心)을 찾지 않는다.
· **內/外**(담 안쪽/바깥) = 남자는 열린 창(外)을 등지고, 여자는 안쪽 담·휘장 속(內).
· 面=광택만이므로 남자의 온몸 붉음은 「面」자가 아니라 熱의 색(望色 소관).

### ② 표제어
1순위 **陽盛(實熱)證과 陰虛(虛熱)證의 감별 — 陰陽偏勝·偏衰의 熱** … 85%
2순위 **《素問·調經論》 「陽盛則外熱, 陰虛則內熱」** … 55%
(부속: 남자=**白虎湯證 四大證**, 여자=**陰虛發熱(骨蒸潮熱·盜汗·顴紅)**)

### ③ 남은 잔결
· **熱=불꽃이 한 획도 없다** — 이 판 최대 결손. 온몸 붉음·발밑 김으로 대신 씀.
· 발에서 오르는 김이 「氣=서린 흰 김」과 샐 위험 — 가는 검은 물결선이라 氣는 아님.
· 서리 이불이 寒 세 갈림(눈송이=外寒 / 안쪽 성에=裏寒 / 밑에서 밴 서리=內寒) 어디에도 딱 떨어지지 않음.
· 淸(사발)이 치법 淸熱인지 단순 引飲인지 이중.
· 바람이 남자가 아니라 여자를 때리는 배치는 여전히 어색(惡風을 세우려는 편의로 봄).
