# 406.png 판독 기록

## 1단계 — 생판(사전정보 없음)

### ① 소품 전수와 나르는 사실
1. 배경 산줄기 3~4봉 + 초가 6~7채·기와집 1채의 마을 + 이랑진 논밭 → 「산·마을·밭」의 내륙.
2. 글자 없는 백지 입간판 1, 백지 흰 깃발 2(밭머리 1, 아래 초원 1) → 이름표가 비워진 자리.
3. 기와 처마 기둥 1 + 처마 밑 매단 망태기 1(빈 것) → 그늘에 걸어 말림·갈무리(陰乾·貯藏), 낙숫물(屋霤水).
4. 긴 평상 위 흰 사발 **10개(왼 5 + 오른 5)** → 열 가지를 갈라 담아 비교함(十).
5. 낮은 소반 1: 흰 그릇 2(밥·국) + 나물 접시 3 = 5기 → 음식·밥물(炊湯·漿水).
6. 먹구름 3 + 번개 3 + 빗줄기, **그 빗줄기 바로 아래에서 개울이 발원** → 비(雨水)가 물의 근원.
7. 상투·망건·흰 머리띠 대장장이 1: 집게로 단 쇠날을 모루에 얹고 김 한 줄기 → 쇠를 벼림(金·鍛/淬).
8. 흙 화덕 1: 위로 불꽃, 아래 아궁이 장작불, 불티 → 불(火)·끓임(熱湯).
9. 다른 물길과 색이 확연히 다른 **짙은 청록 물길 1** → 바닷물.
10. 산호 5(큰 3·작은 2) + 조개껍데기 약 18(가리비·소라·대합·고둥) 무더기, 여인 키의 약 1.3배로 과장 → 바다(碧海水)·개각류.
11. 소년 1(조끼·맨발)이 개울에서 약초를 씻음 + 소쿠리 가득한 잎·뿌리 약재 → 물로 씻는 손질(水製·洗).
12. 개울에 떠내려가는 뿌리 절편 ~5·잎 ~5, **백지 2장**, 돌멩이 ~10.
13. 한복 여인 1이 약초 한 다발을 안음 + 세워 둔 다발 1(깊게 갈라진 잎, 쑥/국화계) → 채약(採藥)·건조.
14. 오른쪽 아래 개울 속 초록 수초 섬 2.
15. 화면 전체를 갈라졌다 합치는 연한 하늘색 물길 최소 5~6갈래 → 갈래 물길(順流·逆流·急流·長流).

### ② 표제어
- 1순위 **東醫寶鑑 湯液篇 「水部」 — 藥用水(물)의 종류** … 45%
- 2순위 **本草 총론 — 藥材의 採取·乾燥·修治(炮製)·貯藏** … 25%
- (3순위 후보: 素問 異法方宜論의 五方 / 醫藥의 起源 각 10% 안팎)

### ③ 뜻 모를 소품·어색한 것·잘림
- 백지 간판 1·백지 깃발 2·물 위 백지 2 = 흰 공백 5개가 무엇의 자리인지 불명(白? 素? 이름표?).
- 대장장이의 쇠 벼림이 「물」축과 이어지지 않음(담금질 물? 금속침 제작? 火製?).
- 사발 10개가 왜 5+5로 갈렸는지 근거 없음.
- 여인의 약초 두 다발이 서로 다른 잎(하나는 결각, 하나는 넓은 잎)인데 구분 이유 불명.
- 프레임: 왼쪽 아래 한옥은 지붕·기둥만 남고 왼쪽 끝에서 잘림. 오른쪽 위 소년의 개울도 화면 밖으로 나감.


## 2단계 — 계통

### ① 소품 → 글자 대응 (사전으로 다시 읽기)
사전 어휘가 **거의 걸리지 않는다**. 걸리는 것은 둘뿐 — 대장장이 집게 끝의 흰 김 = **氣**, 화덕의 불꽃 = **熱(=陽)**.
갈림 조건으로 탈락한 것: 평상의 빈 사발 10여 개는 「여러 손이 받아 드는」 조건이 없어 **惠 아님**(그냥 갈라 담을 자리). 처마 밑 망태기는 곡식 가마니가 아니라 **倉/藏 아님**(陰乾). 소반의 국그릇은 사람에게 주는 맥락이 없어 **補 아님**. 먹구름 비는 번개 동반 폭우라 부슬비 조건을 못 채워 **外濕 아님**. 五味(매실·커피·꿀·고추·소금)도, 藥(약연)도, 오행 다섯 인물도 하나도 없다.
→ **사전이 비었다는 것 자체가 판정**이다. 이 판은 病理·治法 글자판이 아니라, 소품이 곧 사물인 **本草/湯液 계통**이다. 그렇다면 화면의 40%를 차지하며 갈라졌다 합치고, 하나만 짙은 청록(바다)인 **물길 대여섯 갈래**가 축이고, 나머지(비·처마 낙숫물·불·밥상·조개산호·쇠·돌)는 그 곁의 항목이다. 1단계 판단이 사전으로 흔들리지 않고 오히려 굳었다.

### ② 표제어
- 1순위 **東醫寶鑑 湯液篇 「水部」 — 藥으로 쓰는 물의 종류**(春雨水·屋霤水·碧海水·順流/逆流/急流/千里水·熱湯·漿水) … **52%**
- 2순위 **湯液篇 部門 분류 — 本草의 갈래(水·土·穀·菜·草木·玉石·金·蟲魚部)** … **22%**
- 3순위 **湯液序例 — 採藥·乾藥·修製(水製/火製)·煮藥法** … 15%

### ③ 남는 잔결
- 빈 간판 1·빈 깃발 2·물 위 백지 2 = 흰 공백 5. 사전에 없는 기호다. 「이름표를 붙일 자리」로 읽었으나 확증 없음.
- 대장장이가 물을 안 쓴다(담금질 통 없음). 金部/鐵漿인지 火製인지 미정.
- 사발이 10개인지 12개인지 끝내 안 세진다(10=十劑, 12=十二經水로 갈림).
