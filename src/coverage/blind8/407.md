# 407.png 판독

## 1단계 — 생판(사전 없이)

**① 소품 전수와 나르는 사실**

1. **상자형 빈 방**(천장·벽 3면·바닥, 가구 0). 안쪽으로 반쯤 열린 **문 1개**, 그 위 **가로 커튼봉 1개(커튼 없음)**.
2. **성인 남자 3명** — 얼굴·머리·붉은 스웨터·카키 바지·회색 신발이 전부 동일 → 한 사람의 세 국면.
3. **왼쪽 남자**: 고드름이 줄줄이 맺힌 **흰 천(이불)**을 뒤집어쓰고 가슴 앞에서 여밈, 좌우 **떨림선 3+3줄**, 이마 **땀 1방울**, **입술 청회색** → 惡寒·畏寒, 몸을 움츠림.
4. **가운데 남자**: 스웨터를 걷어올려 배 노출, **배꼽 바로 위**에 손바닥만 한 **청회색 멍(瘀斑)** + **쇠못 1개 박힘** + 방사형 충격선, 눈 감고 이 악묾, 땀 1방울, 손톱 자색 → **찌르는 통증·痛處固定**, 膚色紫暗.
5. **오른쪽 남자**: 손바닥 위 **검붉은 혈괴 한 움큼**(손가락 사이로 흘러내림), **양손 손톱 청자색**, **입술 청자색** → 出血이 **紫暗**하고 **血塊**를 낌, 口唇爪甲靑紫.
6. **맨 오른쪽 어린이 1명**: 성인 키의 **약 0.6배**, 같은 붉은 스웨터·회청 바지, 고개를 젖혀 **위를 올려봄**, 눈 크게 뜸.
7. 바닥 **흰 파편 7~8조각**(큰 1 + 작은 6, 깨진 사기그릇).

**② 표제어**
- 1순위 **血寒證(혈한증)·寒凝血瘀** — **55%**. 寒(얼음 천·떨림) + 冷痛(못 박힌 자암색 멍) + 血色紫暗夾塊(혈괴) + 口唇爪甲靑紫가 한 화면에 다 있다.
- 2순위 **瘀血(血瘀證)의 임상 특징** — **30%**. 刺痛·痛處固定, 出血紫暗夾塊, 唇甲靑紫는 어혈 4대 소견 그대로. 다만 「얼음」이 남는다.
- 3순위 寒邪의 致病特點(陰邪傷陽·凝滯致痛·收引) — 15%.

**③ 불명·어색·잘림**
- **커튼 없는 커튼봉**·반쯤 열린 문: 뜻 미상.
- **작아진 아이**: 收引인지 少腹의 「少」인지 결정 불가.
- **깨진 흰 파편**: 肌膚甲錯인지 단순 「깨짐」인지 미상.
- **오른쪽 아래 모서리 훼손**: 갈색 번짐 + 프레임 선 끊김, 그 자리에 못(고리?) 같은 물체 하나가 뭉개져 있음.

## 2단계 — 계통(사전 적용 후 재판독)

**① 소품 → 글자**
- 문·담 **안쪽의 방** = **內**. 문틀 = **門**.
- 옷·얼굴이 **똑같은 성인 셋** = **久**(같은 물건 셋)이자, 셋 중 **가운데**만 몸을 드러냄 → **中**(갈림 「몸 위에서는 中」 충족).
- **고드름 맺혀 얼어붙은 흰 천** = 「溫=김 오르는 따뜻한 천」의 정반대꼴 → **寒**. 살아 있는 불이 곁에 없으므로 **陰이 아니다**(갈림 준수). 六淫 寒邪 판이 아니므로 凝滯 전용으로도 읽지 않는다. 사람 곁에 **떠 있는 병표지(눈송이)는 없다** → 「그의 병증이 寒」이 아니라 글자 寒이다.
- 이마 땀방울 = **汗**.
- 배꼽 위 **자회색 반점 + 살에 박힌 쇠못 하나** = **痛**(사전 확정). 못은 박혀 고정 → 刺痛·痛處固定, 반점은 膚色紫暗.
- 손바닥의 **검붉게 굳은 덩이**(흘러내림) = **瘀**(사전 확정) → 出血 色紫暗·夾血塊.
- 두 사람의 **검푸른 손톱**·청자색 입술 = **爪** + **厥** → 口唇爪甲靑紫.
- **어른의 0.6배로 줄어든 사람** = **虛**(줄어든 것). 「하나가 두 배」로 보면 大이나 실측 1.6배라 大는 어긋난다.
- 바닥의 **깨진 흰 사기 조각** = **傷**(깨져 못 쓰게 된 물건 — 닳은 무더기가 아니므로 久 아님).

**② 표제어**
- 1순위 **瘀血(어혈) — 형성 원인과 致病 특징** — **60%**. 성인은 **虛**(氣虛)·**寒**(血寒·寒凝)·**傷**(外傷)·**久**(久病入絡), 특징은 **痛**(刺痛·痛處固定)·**瘀**(紫暗夾塊의 出血)·**厥/爪**(唇甲靑紫)·자암색 어반. 모든 소품이 빠짐없이 일한다.
- 2순위 **血寒證·寒凝血瘀** — **25%**. 寒+冷痛+紫暗夾塊+厥이 그대로 맞지만, 傷(깨진 그릇)·虛(줄어든 사람)·久(셋)가 놀아 남는다.
- 3순위 **內有久寒**(內+久+寒+厥, 當歸四逆 계열) — **8%**. 약연·약봉지 등 藥 소품이 하나도 없어 처방 판으로 보기 어렵다.

**③ 남는 것**
- **커튼 없는 커튼봉**: 膈(기둥 넷 사이 팽팽한 흰 천) 조건을 못 채운다 — 여전히 미상.
- 아이가 **위를 올려보는 시선**: 대응 글자 없음.
- **오른쪽 아래 프레임 훼손**(번짐·선 끊김)과 그 안의 못 같은 물체 1개 — 판독 불가.

**판정**: 1단계보다 낫다. 1단계에선 얼음을 「증(證) 전체」로 읽어 血寒을 1순위에 놨으나, 사전을 대면 얼음·못·덩이·손톱이 각각 독립된 글자(寒·痛·瘀·厥)이고 아이(虛)·깨진 그릇(傷)·동일인 셋(久)까지 글자로 서므로, **瘀血** 한 표제어가 판 전체를 흡수한다.
