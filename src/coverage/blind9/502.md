# blind9 / 502.png 판독

## 1단계 — 생판(사전 정보 없이 그림만)

### ① 소품 전수와 나르는 사실
- **무대**: 사방이 막힌 상자형 실내(벽 3면 + 바닥). 등장인물이 모두 한 방 안에 갇혀 있음.
- **커튼봉 1개(커튼 없음)** — 문 위 가로로 걸림. 가릴 것이 없이 휑함 → 「문호(門戶)가 열려 있다」의 배경장치로 읽힘.
- **반쯤 열린 문 1개** — 안쪽이 어둡다. 열림/새어나감.
- **성인 남자 3명(얼굴이 완전히 동일, 어깨를 맞대고 일렬)** — 반복 = 같은 사실의 세 가지 변주 또는 수 3.
  - 공통 소견 ①: **입술이 회청색(구순 청자)** — 좌·우 남자에서 명확.
  - 공통 소견 ②: **팔뚝에 검푸른 혈관이 그물처럼 도드라짐(청근 폭로, 絲狀紅縷)** — 3인 모두. 손톱도 어둡다(조갑 청자).
  - 공통 소견 ③: 이마에 **땀 1방울**(좌·중), 눈 밑 그늘, 초췌.
- **왼쪽 남자**: **하얗게 얼어붙은 담요/숄**을 뒤집어씀 — 고드름이 아래로 늘어짐. 양옆에 **떨림선 4쌍**(전율). 두 손으로 가슴 앞을 여밈. → 惡寒/畏寒, 덮어도 따뜻해지지 않음(이불 자체가 얼음) = 안에서 나오는 한(寒).
- **가운데 남자**: 옷을 걷어올려 **상복부 노출**, 배꼽 위에 **검푸른 멍(어반) 1점** + 그 한복판에 **못 1개가 박힘**. 눈 감고 찡그림. → **자통(刺痛, 如針刺)·고정불이·어반**.
- **오른쪽 남자**: 팔을 늘어뜨리고 무표정·침울, 입술 청자. → 신피핍력.
- **아이 1명**(성인 키의 약 0.55배, 어른들과 떨어져 오른쪽 구석): **고개를 뒤로 젖히고 눈을 위로 치켜뜸**, 손가락이 뻣뻣이 오그라짐, 손이 창백. → 상시(上視)·구급(拘急) 또는 경악(驚).
- **바닥의 깨진 흰 사기 조각 약 9개** — 아이 발밑에 흩어짐. 「그릇(器)이 깨졌다」 = 담을 것이 새어나감.

### ② 표제어
- 1순위: **어혈(瘀血) — 형성 원인과 증상 특징** … **45%**
  (못 = 자통, 검푸른 멍 = 어반, 구순·조갑 청자, 청근 폭로 = 교과서 어혈 4대 소견이 3인에 반복. 얼음 담요 = 血寒致瘀, 못 = 外傷致瘀, 깨진 그릇 = 離經之血)
- 2순위: **한사(寒邪)의 성질과 치병 특징** … **28%**
  (寒為陰邪易傷陽氣 = 얼음·전율·청자 / 寒性凝滯主痛 = 못·응체된 멍 / 寒性收引 = 아이의 뻣뻣한 목·손가락)
- 3순위: 혈한증(血寒證)·양허(陽虛) 15%

### ③ 뜻 모를 소품·어색한 것
- **커튼 없는 커튼봉**과 **반쯤 열린 문**의 뜻이 안 잡힘(주리 개설? 배경?).
- **깨진 흰 조각 9개**가 도자기인지 얼음인지 불명.
- **어른 3인의 얼굴이 완전히 동일**한 이유(수 3? 동일 병증? 대소를 막론하고 병상이 같음=역려?).
- **아이만 한(寒) 소견이 없음** — 병자 무리에 끼지 않는 이유 불명.
- 프레임 잘림 없음(상자 무대가 액자 안에 온전히 들어옴).

## 2단계 — 계통(글자 사전을 배우고 다시 읽음)

사전이 소품 대부분을 곧바로 글자로 바꿔 준다. 1단계의 「증상 나열」 독법은 버린다.

### ① 소품 → 글자
- **배에 박힌 쇠못 1개 = 痛** (사전 확정: 痛 = 살에 박힌 쇠못 하나). 자리는 배꼽 위 = 위완부.
- **못을 감싼 검푸르게 굳은 얼룩 = 瘀**. 瘀와 痛이 한 자리에 겹침 → 「응체가 곧 통증」이라는 인과 서술.
- **이마의 땀방울 = 汗** (좌·중 2인).
- **검푸른 손끝·손톱 = 厥** (厥 = 검푸르게 언 손발 끝). 3인 공통. 팔뚝의 푸른 그물맥은 厥의 연장(絡의 응체)으로 읽힘.
- **얼어붙은 담요 = 惡 + 얼음**. 惡 = 사람과 해로운 것 사이에 세운 가리개 → 가리개를 둘렀는데 그 가리개가 얼음 = **덮어도 줄지 않는 惡寒**. 다만 ⚠ **화면에 해도 불도 하나도 없다** → 陰의 갈림 조건에 걸려 이 얼음은 陰도 寒도 아닌 **凝滯**로 읽는 것이 사전에 충실하다. 봉에 걸려 있어야 할 천(溫 = 김 오르는 따뜻한 천)이 내려와 얼어붙은 구도.
- **얼굴이 똑같은 남자 셋 = 中의 문법**: 사전 「中 = 같은 것 셋 중 가운데, 몸 위에서는 中」. 셋을 똑같이 그린 것은 久(포개짐)가 아니라 **가운데 하나를 지목하기 위한 장치** — 실제로 가운데 남자만 배를 드러내 瘀·痛을 얹었다. → 사건이 일어나는 자리가 **中(속·한복판)**.
- **반쯤 열린 문 = 內**(문 안쪽). 인물 전원이 문 안쪽에 있음 → 이 판의 사실은 모두 **內/裏**에서 일어난다.
- **커튼 없는 커튼봉** = 溫이 걸려 있어야 할 자리가 비었음(온기의 부재).
- **깨진 흰 사발 조각 = 傷**(그 글자의 사물이 깨져 못 쓰게 된 것). 깨진 것은 그릇 → 補의 그릇(따뜻한 국물을 담아 채워 주는 것)이 깨짐 = 채워 넣을 길이 상함.
- **아이**: 어른과 나란히 세워 대소를 짓는 대조군(키 1.6배라 大로 확정하기엔 부족), 크게 뜬 눈 = 目 + 위로 치뜬 시선(上).

### ② 표제어
- 1순위: **한사(寒邪)의 응체성 — 「寒性凝滯 → 不通則痛」, 한응혈어(寒凝血瘀)** … **50%**
  (凝滯[불 없는 화면의 얼음] + 瘀[검푸른 굳은 덩이] + 痛[못]이 한 몸 한 자리에 포개짐 + 厥 + 汗)
- 2순위: **내한(內寒)·양허한증 — 「寒從中生」** … **27%**
  (內[문 안] + 中[셋 중 가운데] + 陽[해·불]이 화면에 전무 + 厥 + 冷汗 + 溫의 부재)
- 3순위: 어혈(瘀血) 자체 12% / 惡寒(表實寒) 8%

### ③ 남은 것
- **깨진 흰 사발**이 傷인 것은 확실하나 「무엇의 傷인가」가 안 잡힌다(補의 그릇? 淸의 그릇?).
- **아이**가 무슨 글자인지 사전에 없다(大를 짓기엔 배수가 부족, 병표지도 없음).
- **커튼봉**이 膈인지 溫의 빈자리인지 미결.
- 팔뚝의 푸른 그물맥은 사전의 筋(갈색 힘줄)이 아니므로 별개 기호이나 등재되어 있지 않다.
- 수 오류·프레임 잘림 없음.
