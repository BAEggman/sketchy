# 소품 수 한계 실험 — Gemini(Pro) 한 장에 소품을 몇 개까지 넣을 수 있나 (2026-10-13)

계기: 단원 통합 그림(한 단원 개념을 한 판에 최대한)을 앞두고, 「소품 7~8개를 넘기면 지시가 drift 한다」는 관찰을 실측으로 확인.

## 설계
같은 화풍(한옥 온돌방 · 잉크선+수채 · 16:9 · 글자 없음), 같은 소품 풀 16개. 각 소품은 **확인 가능한 속성 하나**를 진다 —
색(빨간 우산·보라 보자기), 정확한 개수(국화 3·촛불 2·감 5·화살 3·붓 5·손가락 3), 상태(김 한 줄기·물 절반·금 간 항아리·**거꾸로 매단 짚신**).
조건: 한 번에 6 / 9×2 / 12×2 / 16×2개, 12개를 세 구역에 배정(Z12), 6개 그림에 3개씩 편집으로 더하기(E9→E12). 모두 새 채팅.
채점: 새 판독자 둘(Opus)이 체크리스트만 보고 소품마다 ✓(속성까지 정확) / △(있으나 속성 틀림) / ✗(없음) + 중복·혼동 소품. 표본 셋은 직접 재확인(화살 수·손가락 수 일치).
원자료: `capacity_test/` (design.json · checklist.md · audit1/2.json · contact_sheet.webp)

## 해석
1. **사라지는 소품은 16개까지 하나도 없었다(✗ 0/120).** 무너지는 것은 「있느냐」가 아니라 **속성**이다 — 체감한 7~8개 drift 의 정체는 이것.
2. 속성에도 층이 있다.
   - **색·재질·사물 종류**(빨간 우산, 청화백자, 보라 보자기, 잠든 고양이, 유리병): 16개에서도 **100%**. 개수 제한 사실상 없음.
   - **작은 정확한 개수(2~3)이고 자연스러운 배치**(국화 3송이·촛불 2자루): 16개에서도 100%.
   - **정확한 개수 + 모델 습관과 어긋남**(화살 3대→2대로 짝지음, 감 5→6·7, 붓 5→4, 손가락 3→5 손 흔들기): **9개부터** 깨지기 시작해 12개 이상에서 거의 매번 하나 이상.
   - **기본값을 거스르는 상태**(짚신 거꾸로): 6개에서도 **10/10 실패**. 소품 수와 무관 — 이런 데엔 사실을 싣지 않는다(규칙 49와 같은 층).
   - **「하나만」**(학 한 마리·항아리 하나): 12개부터 **중복**이 생긴다 — Sketchy 에선 중복이 곧 개수 사실 오염·유령.
3. **3개씩 편집으로 쌓기(E)가 한 번에 그리기보다 낫다** — 12개에서 91%, 기존 소품 지워짐 0. 단 이 방은 빈 자리가 있었다. 규칙 170(s01p02, 꽉 찬 판에 하나를 더하자 赤水玄珠가 통째로 사라짐)은 **자리가 없을 때** 생긴다. 그리고 앞 단계의 오류(화살 2대)는 편집이 고치지 않고 그대로 실어 간다.
4. **구역 지정은 지켜진다(12/12)** — 정확도는 올리지 않지만 배치를 통제한다. 단원 통합판의 「개념 묶음 = 구역」 설계에 쓸 수 있다.

## 판독 쪽 한계 (blind10 재분석)
그리기와 따로, **읽기**도 소품 수에 걸린다. blind10 87판에서 행(사실) 6개 이하 판은 ✗ 2/70(3%), 7개 이상은 ✗ 5/17(29%).
그런데 소품 13~24개인 의학사 거리판(s02p01 24개·s03p01 19개 등 7판)은 전부 ✓ — 소품이 **서로 독립한 목록**(인물 하나 = 소품 하나, 길 따라 늘어섬)일 때는 많아도 읽히고,
**대비·관계를 진 판**(實↔虛, 寒格↔熱格, 溫補派처럼 한 틀로 묶여야 하는 판)은 7개를 넘기면 유령이 조립되기 쉽다(전담 기호 충돌의 조합 수가 늘어나므로).

## 결론 — 단원 통합판 작업 기준(제안)
- **한 번의 생성(또는 편집 1회)에 새 소품 ≤ 6~8개**, 그중 「정확한 개수」를 지는 소품 ≤ 2~3개, 개수는 **3 이하**만.
- 판 전체는 **16~20개까지** 가능하되 **편집 라운드로 쌓는다**: 바탕 구도에서 구역을 미리 비워 두고(빈 자리) 라운드마다 3~4개씩 → 라운드마다 규칙 170 전수 대조.
- 판을 **구역 3~4개**로 나누고 구역 하나 = 개념 묶음 하나, 구역당 소품 ≤ 5~6개 + **구역마다 틀 표지 하나**(blind10 「틀 소실」 대책과 같은 방향).
- 기본값을 거스르는 상태(거꾸로·특정 손짓·특정 방향)에 사실을 싣지 않는다. 꼭 필요하면 단독 편집 라운드로.
- 「하나만」이 중요한 소품은 생성 뒤 중복 검사를 체크리스트에 넣는다.
- 블라인드 판독은 판 전체 + **구역별 잘라 읽기** 두 단계로.
