## s12p01 靑色主病 — 「靑이 앉은 자리」를 넷 다 다르게

### 지금 무엇이 잘못됐나
- row0이 「넷 다 얼굴과 입술이 **똑같은 푸른색**」 — 靑이 균일해 배경이 됐다.
- 판독자는 남은 소품 **못(痛) + 커튼(風) + 놀란 아이(驚)**를 모아 **破傷風**을 조립했다(30→35%).
- 즉 靑은 안 읽히고 하위 사실만 읽혀 **다른 실존 병명**이 섰다.

### 수술 — 얼굴 전체를 칠하지 않고 부위를 나눈다

넷 다 **바탕은 창백한 살색**으로 두고, 靑이 **서로 다른 자리**에만 앉는다.
이러면 (a) 화면에 靑 아닌 살색이 남아 92-c를 채우고, (b) 네 靑이 서로 달라 s12p03 黃의 성공 구조와 같아진다.

| 인물 | 靑이 앉는 자리 | 지는 사실 | 근거 |
|---|---|---|---|
| 寒 | **입술과 손끝**만 靑 (말초) — 서리 낀 담요·떨림 유지 | 靑 = 寒 | 寒主收引, 말초 혈행 응체 |
| 痛 | 배에 박힌 **쇠못 둘레**의 살이 靑, 얼굴은 창백 | 靑 = 痛 | §5 「痛 = 살에 박힌 쇠못 하나」 |
| 瘀血 | **입술과 손톱이 靑紫** (脣甲靑紫) + 손에 검붉게 굳은 덩이 | 靑 = 瘀血 | 7장 병인학설 「구어에는 … **脣甲靑紫**」 · §5 「瘀 = 검붉게 굳은 덩이」 |
| 驚風(아이) | **콧대 뿌리(山根)와 눈썹 사이**만 靑 | 靑 = 驚風 | 素問·金匱眞言論 「東方靑色 … **其病發驚駭**」 |

### ★ 함께 고쳐야 할 내용 문제 — 「風」 행을 없애고 「瘀血」을 넣는다

- 표준 靑色主病은 **寒證·痛證·瘀血·驚風** 넷이다. 이 판은 **驚風 하나를 「風」과 「驚」 둘로 쪼개** 놓고 **瘀血을 빠뜨렸다.**
- 그 쪼갠 「風」(창밖 바람+커튼)이 바로 **破傷風 유령의 재료**였다. 내용 오류와 판독 실패가 **같은 뿌리**다.
- 처방: 「창밖 바람+커튼」 행을 지우고 **瘀血**(脣甲靑紫 + 검붉게 굳은 덩이)을 앉힌다. 風은 驚風 안으로 되돌린다.
- 소품 수: 4인 + 담요·못·덩이·(아이의 굳은 자세) = §1 통과.

## s12p04 白色主病 — 하위형 이름이 「白」을 안 불러 준다

### 지금 무엇이 잘못됐나
- 대비는 **이미 있다** — 입술색이 셋 다 다르다(살구빛 / 청자색 / 흰색). 그래서 92-c 위반은 s12p01보다 가볍다.
- 진짜 원인은 다른 데 있다. ✓난 s12p03과 나란히 놓으면 보인다:

| | 하위형 이름 | 이름이 색을 되불러 주나 |
|---|---|---|
| s12p03 黃 ✓ | 萎**黃** · 陽**黃** · 陰**黃** | **그렇다** — 어느 하나를 읽어도 黃으로 돌아온다 |
| s12p04 白 △ | 氣虛 · 陽虛 · 失血 | **아니다** — 失血을 읽으면 白으로 가는 길이 없다 |

- 그래서 판독자는 가장 강한 기호(**피 밴 천** = §5 血)를 물고 **血虛 50%**로 갔다. 하위형 하나가 표제어를 훔친 것이다(규칙 161).

### 수술 둘

**(가) 흰 기준자를 화면에 놓는다 — 92-c**
세 사람이 각자 얼굴 옆에 **같은 흰 사기대접**을 들어 얼굴빛과 맞대어 본다.
- 氣虛 = 대접보다 **탁하고 어둡다**(淡白無華)
- 陽虛 = 대접처럼 **번들거리는데 부어 있다**(㿠白)
- 失血 = 대접보다 **더 희다**(蒼白)
- 셋 다 같은 대접이므로 **「보통 흰색」이 화면에 있다** → 92-b/92-c의 기준자.
- ⚠ 전담 검사: 흰 사기대접은 92칸에 없다. 「빈 그릇/뒤집힌 빈 그릇」은 s15p10 過飽·過飢 전담이라 **대접은 비우지 않고 손에 든 상태**로만 쓴다.

**(나) 失血의 피를 약화한다**
- 지금 「피 한 덩이가 밴 흰 무명천」이 §5 血(붉은 것)의 가장 강한 형태라 표제어를 훔친다.
- **천은 유지하되 붉은 자국을 대접보다 작게** 하고, 그 사람의 **입술까지 흰 것**(蒼白의 확인점)을 더 크게 그린다.
- 근거: 원 설계의 why가 이미 「입술과 하안검이 색을 잃는 것이 실혈의 확인점」이라 적어 두었다 — **적혀 있는데 안 그린 것**을 그린다(규칙 169).

- **제미나이 입력창에 Enter는 전송이 아니다.** 여러 줄 텍스트는 첫 줄에서 잘려 나간다.
  → 지시는 **한 줄로** 쓰고, `execCommand('insertText')`로 넣은 뒤 **「메시지 보내기」 버튼을 click()** 한다.
- **파일 입력은 「파일 업로드」 메뉴에 hover해야 생긴다**(규칙 확인). accept="image/*"인 것을 골라야 한다.
- **제미나이 출력은 1024×1024가 천장이다**(blob 실측). 그래서 허브의 2048px는 ESRGAN 업스케일로만 얻는다.
- **Chrome 다운로드가 연결 폴더로 오지 않는다** — 다운로드 버튼도 스크립트 다운로드도 파일이 안 생겼다.
  대신 **이미지를 물리화소 1:1(1024/DPR = 465px)로 띄우고 zoom + save_to_disk**로 컨테이너에 받는다(1092px 캡처).
- base64를 JS 반환값으로 옮기는 길은 **차단**되어 있다.
