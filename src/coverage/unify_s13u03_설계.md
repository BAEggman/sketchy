# 溫病 衛氣營血 통합판 s13u03 설계 (2026-10-18)

## 틀
**나무 기둥·흙벽의 시골집 긴 방을 옆에서 자른 단면 — 왼쪽 끝은 열린 문(바깥의 환한 대낮 빛이 들어옴), 오른쪽으로 갈수록 안쪽·어둠. 오른쪽 뒤 벽의 작은 창 밖은 밤하늘과 초승달, 오른쪽 끝은 가장 깊고 어두운 구석.** 네 사람이 문가 → 한가운데 → 안쪽 → 구석에 차례로 있고, 넷 다 **혀를 크게 내밀어** 혀의 색과 이끼가 멀리서도 보인다(사전 舌·苔). 사람은 s13u01·02와 같은 마을 남자. 자리의 깊이 = 단계(衛 → 氣 → 營 → 血), 밝기 = 낮 → 밤.

## 규칙 · 메모
- 혀 넷은 같은 크기·같은 자리(입 밖으로 크게)로 놓아 색·이끼만 다르게 — 비교 칸 문법(규칙 67). 사전 舌 갈림(「혀가 보이면 心」)은 五官 판 맥락이라 넷이 나란하면 舌診으로 읽힐 것 — 잔결 후보.
- 氣分의 「옷 열어젖힘 + 물 + 땀」은 s13u01 陽明經證과 같은 꼴 — 같은 白虎湯證이므로 의도한 겹침(무대·혀 이끼로 가른다).
- 營分의 반점은 「막 돋기 시작」(몇 개·옅음), 血分은 「빽빽」 — 둘의 차이가 사실. 血 = 붉은 것(코피·피 천)은 血分에만.
- 셀 소품: 무소뿔 하나 · 석고 덩어리 하나 — 개수 사실 없음.
- 밤·초승달은 營分 자리의 창에만(身熱夜甚) — 문가의 대낮과 한 그림에 있는 것은 六淫의 사계절과 같은 문법.
