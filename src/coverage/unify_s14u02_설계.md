# 本草 ② 瀉·毒·修治 통합판 s14u02 설계 (2026-10-22)

낱장 s14p03(大黃 4) · s14p06(半夏 5) · s14p10(修治 5, 장면 14b) = 14행 → **틀 + 14행**, 한 장. s14u01(補·溫 진열대)과 같은 한약방의 **뒤편 작업 마당** — 「독하고 거친 약은 손질해서 쓴다」가 틀.

## 틀
**같은 한약방의 뒤뜰 작업 마당(앞 판 진열대 뒤로 돌아간 곳).** 왼쪽 삼분의 일은 벽을 등진 진열대 두 칸(大黃 · 半夏, 앞 판과 같은 칸막이·약장 벽), 오른쪽 삼분의 이는 돌로 쌓은 긴 작업대 위 **修治 다섯 자리가 왼쪽에서 오른쪽으로 차례**(生 → 熟 → 炒 → 炙 → 煅) — 화덕·찜통·팬·석쇠·불. 벽에 **짚 빗자루 하나**가 걸려 있다(사전 瀉 = 이 마당의 간판). 사람은 s14u01과 같은 생김새: 半夏 칸 뒤의 농부(脾)·재상(肺) 둘, 大黃 칸 곁에 약탕관에 조각을 떨어뜨리는 마을 남자 하나, 작업대에서 팬을 볶는 마을 남자 하나 — 넷.

## 규칙 · 메모
- 大黃의 「大」는 사전 大(같은 것 둘이 나란한데 하나가 두 배) 그대로 — 옆구리가 맞닿게(재작도 5차 2.0배).
- 半夏의 저울추 = 사전 降(내리누르는 추) — s13u01 少陽의 「흔들리는 추」와 갈리게 **풀을 누른 채 멈춘** 추.
- 相反 X는 s14u01 藜蘆와 같은 규격(붉은 X + 검은 연기 뿌리) — 같은 글자 같은 꼴.
- 炙(꿀 숟가락 + 구운 조각)은 s14u01 黃芪 蜜炙과 겹친다 — 라이브러리 자체의 겹침(s14p05[3] · s14p10[3]), 감사에 적는다. 여기서는 石쇠 위 「굽는 중」(修治 동작)으로, 저쪽은 「구워진 결과」(윤기 나는 뿌리)로 가른다.
- 修治 다섯은 **차례**(生→熟→炒→炙→煅)가 틀 — 사전 五化처럼 왼쪽부터.
- 셀 소품: 大黃 뿌리 둘(大) · 약탕관 둘(用法 비교) · 흰 공 하나. 개수 사실 없음.
