# 病機 ② 陰陽失調 통합판 s16u02 설계 (2026-10-23)

낱장 s16p03(偏盛 7) · s16p04(偏衰 6) · s16p05(格拒 6) · s16p06(亡失 6) = 25행 → **틀 + 24행**(s16p03[6] 八綱 배속은 틀 행으로 흡수 — 「각 방의 왼쪽 사람 = 불(陽) 쪽, 오른쪽 사람 = 얼음(陰) 쪽」). 사람 여덟 = **방 넷 × 둘**(구역 = 방, 4개 — §3 구역 수 4~6 안). 사실 24 ≤ 26.

## 틀
s16u01(의원 앞마당)의 같은 집 **안채** — 앞벽을 걷어낸 단면처럼 **방 네 칸이 나란히**(나무 기둥으로 칸막이). 같은 생김새의 마을 남자(상투·회청 저고리·황토 바지)가 칸마다 둘씩 방바닥에 앉음. 방 차례 = 교재 차례 偏盛 → 偏衰 → 格拒 → 亡失(가벼운 데서 위중한 데로). **칸마다 왼쪽 사람은 불(陽) 쪽의 일, 오른쪽 사람은 얼음(陰) 쪽의 일**(사전 陰 = 살아 있는 불과 맞댄 얼음 · 陽 = 불).

## 규칙 · 메모
- 偏盛 = **세 배로 커진 것**, 偏衰 = **삼분의 일로 줄어든 것**(사전 虛) — 두 방이 같은 화로·얼음 한 벌로 크기만 다르다(낱장 s16p03·04의 대비 그대로).
- 格 = 사전 「막은 문틈으로 밀려 나가는 것」 정본 자리. 밀려 나가는 것이 假, 방 안에 남은 쪽이 眞.
- 承氣湯 솥은 s16u01 셋째 남자 곁 솥과 **같은 꼴**(기울어 비고 내용물이 밖으로) — 감사 §3-a 「진짜 중복」은 같은 치법의 두 자리라 딥링크로 둔다(s13u01 陽明腑證까지 세 판).
- 大便乾結(감사 §3-a): 여기는 **불 곁**(實熱이 태움), s16u04 內燥는 **바닥까지 마른 물독 곁** — 같은 뒷간통, 이웃 원인으로 가른다.
- 附子는 두 번(③ 回陽 · ④ 參附湯) — 같은 꼴(검은 방울 맺힌 덩이뿌리)로 맞춘다. 人蔘(사람 모양 뿌리)은 s16u01·s14u01과 같은 꼴.
- 정확한 개수: 환약 여섯 알(六味) 하나뿐 — §3의 「≤3」을 넘으나 처방 이름이 수(六)라 둔다; 틀리면 PIL(s14u03 선례).
- 땀 둘(冷汗 구슬 ↔ 번들거리며 흐르는 끈적한 땀)이 같은 방 좌우로 대비.
- 피할 것: 등잔을 손으로 감쌈(保命) · 걷어올린 팔뚝(充) · 김(氣)을 화로에 얹지 않음.
