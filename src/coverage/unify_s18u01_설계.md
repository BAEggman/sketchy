# 舍岩鍼法 통합판 s18u01 설계 (2026-10-24)

낱장 s18p09(正格 ↔ 勝格 10) · s18p10(寒格 ↔ 熱格 7) = 17행 → **틀 + 17행**, 한 장. 사람 넷 = 두 쌍(勝格 ↔ 正格 · 熱格 ↔ 寒格). 낱장 s18p10은 「틀 소실」(MASTER §9) — 통합판 틀이 대신 진다.

## 틀
**큰 바위(岩)에 기대 지은 작은 초가집(舍)** — 이름 다리 舍岩. 집 앞면이 트여 나무 기둥으로 나뉜 칸 넷이 나란하고, 칸마다 같은 생김새의 마을 남자 하나. 날씨·계절 없음. 왼쪽 두 칸 = 「몇 번째 층에 무엇을」(母·官·子 — 正勝格), 오른쪽 두 칸 = 「무엇(오행)을 채우고 무엇을 쏟나」(寒熱格). 오른쪽 두 칸 사이 기둥은 특히 굵다(재작도 스펙 — 眞寒假熱 오독 끊기).

## 규칙 · 메모
- 사전 그대로: 官 = 3층 선반장 가운데 층(위 = 母 · 아래 = 子) · 補 = 찰랑한 따뜻한 국물 · 瀉 = 짚 빗자루 · 補-b = 그릇에 가득 담긴 것 · 瀉-b = 빈 그릇 + 밖으로 쏟아진 것 · 熱 = 불꽃 · 寒 = 눈송이 · 병표지 = 사람 곁에 크게 뜬 표지.
- 그릇 넷(①②)은 색·무늬 없는 똑같은 질그릇(p09[8] — 五色을 싣지 않는다). 빗자루는 그릇 **곁에 기대** 섬(그릇 안 아님).
- 가운데 층 하나가 ①에서는 국물, ②에서는 빗자루 — 같은 높이에 나란히 보이게(p09[7] 함정).
- ③④는 같은 얼굴·같은 옷의 거울 쌍, 표정은 둘 다 담담(증상 없음 — 겉모습이 아니라 곁에 채운 것이 격을 진다). 문틈·이불 없음(s16u02 格拒와 갈림).
- ①②의 가시덤불은 s16u01 實↔虛와 같은 꼴(딥링크) — 단원은 선반장(母官子)이 가른다.
- 셀 소품 없음. 사람 넷(「셋도 다섯도 아니고 넷」).
