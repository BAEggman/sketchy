# hist-01 漢·晉 — 설계·제작 기록 (2026-11-09)

- 장소: 한옥 서당(漢 = 「한」옥 · 經典 읽는 서당), 대청 굵은 기둥 넷 = 四大經典. 정거장 13 = 틀 + 11 + 되짚기. 카드 22장(src).
- 바탕: Gemini Argon 한 턴(`prompt_base.txt`, 2,860자) → 같은 채팅 편집 5회
  1. 원님 모자 지움(갓·모자 금지) · 앞 왼쪽 약장 하나 지움(三品 선반만 남김) · 펼친 책 → 둘로 나눠 끈으로 묶은 책
  2. 빈 액자 둘 → 셋 · 노란 옷 노인 → 손인형 · 책상 위 금메달(붉은 끈)
  3. 까치를 지붕에 납작 엎드린 꼴로(扁 = 납작할 편)
  4. 일치 검사 △ 반영: 사다리 가로대 5 → 6 시도(실패, 5 그대로) · 금 궤짝 칸막이 굵게 · 메달 키움(실패, 원반으로 읽힘)
  5. 사다리 맨 아래 가로대 하나 더(→ 6, 픽셀 단면으로 셈) · 책상 원반 지우고 앞 모서리에 노란 끈 금메달
  - 교훈: 「여섯 개로」는 안 먹고 「하나 더」는 먹는다(규칙 151과 같은 결). 금메달은 눕히면 원반·떡으로 읽힌다 — 매달아야 메달이다.
- 캡처: 1024×572 원본을 화면에 1:1로 띄워 zoom 캡처(1456×828) → 1421×793 잘라 2048×1144 LANCZOS(`src/coverage/gemini_capture.js`, 5번째 인자 sc 추가판).
