## 정거장 및 속성 매핑

### #1. 張機(字 仲景, 東漢) 『傷寒雜病論』 — 최초 임상서 · 方書之祖
- **물건**: 한옥 대청 한가운데 앉아 담요 환자에게 처방 쪽지를 건네는 의원 · 금메달
- **고리**: 한가운데(仲) 앉은 의원 = 張仲景 · 담요 = 傷寒 · 처방 쪽지 = 方書之祖 · 금메달 = 최초
  - `[이름]` 대청 한가운데 앉은 의원 → **張機** (뜻)
  - `[왕조]` 한옥 대청 마루 → **東漢** (공용 부호)
  - `[字號]` 대청 정중앙(仲) 자리와 경치 병풍(景) → **仲景** (뜻+소리)
  - `[서명]` 담요 환자와 처방 쪽지 → **『傷寒雜病論』** (공용 부호)
  - `[의의]` 책상에 매단 금메달과 처방 쪽지 → **辨證論治 확립 최초 임상서 · 方書之祖** (공용 부호)
### #2. 『傷寒論』(以六經統百病) · 『金匱要略』(千般疢難 不越三條)
- **물건**: 의원 곁 여섯 단 사다리(육각 너트) · 세 칸으로 나뉜 금 궤짝(삼지창)
- **고리**: 여섯 단 사다리+육각 너트(6) = 六經 · 세 칸 금 궤짝+삼지창(3) = 金匱 三條
  - `[서명]` 여섯 단 사다리와 세 칸 금 궤짝 → **『傷寒論』·『金匱要略』** (뜻)
  - `[기여]` 6단 사다리(六經) · 3칸 금 궤짝(三條) → **以六經統百病 · 千般疢難 不越三條** (뜻)
  - `[수]` 육각 너트(6) · 삼지창(3) → **六經(6) · 三條(3)** (공용 부호)
### #3. 華佗(字 元化, 東漢) — 麻沸散 전신마취 개복수술 · 五禽戲
- **물건**: 한옥 마루에서 가슴에 큰 붉은 꽃을 달고 끓는 사발·외과 칼을 든 의원 · 다섯 짐승 체조
- **고리**: 붉은 꽃(華) = 華佗 · 끓는 사발(沸)+칼 = 麻沸散 개복수술 · 다섯 짐승(오징어 5) = 五禽戲
  - `[이름]` 가슴에 큰 붉은 꽃(華)을 단 의원 → **華佗(元化)** (뜻)
  - `[왕조]` 한옥 마루 터 → **東漢** (공용 부호)
  - `[기여]` 끓는 마취 사발+외과 칼 · 다섯 짐승 체조 → **麻沸散 개복수술 · 五禽戲(虎鹿熊猿鳥)** (뜻)
  - `[수]` 오징어(5)와 다섯 짐승 → **五禽戲(5종 동물)** (공용 부호)
### #4. 王叔和(晉) 『脈經』 — 현존 최초 맥학 전문서 · 24脈 · 寸關尺 확정
- **물건**: 진달래 꽃떨기(晉) 위 거구의 아저씨가 아이 손목을 짚음 · 이층 버스 위 사과(24) · 금메달
- **고리**: 진달래 = 晉 · 왕만 한 아저씨 = 王叔和 · 손목 짚기 = 脈經·獨取寸口 · 버스(2)+사과(4) = 24脈 · 금메달 = 최초
  - `[이름]` 왕만 한 덩치의 아저씨 → **王叔和** (뜻)
  - `[왕조]` 발밑 분홍 진달래 꽃떨기 → **晉(西晉)** (공용 부호)
  - `[서명]` 손목 맥을 짚는 손과 맥학 책 → **『脈經』** (뜻)
  - `[의의]` 맥학 책에 매단 금메달 → **현존 최초의 맥학 전문서** (공용 부호)
  - `[수]` 이층 버스(2) 위 사과(4) → **24脈** (공용 부호)
### #5. 王叔和 — 張仲景의 『傷寒雜病論』을 정리해 『傷寒論』·『金匱要略』으로 분권
- **물건**: 거구의 아저씨가 끈으로 묶은 책 두 권을 양손에 나눠 듦
- **고리**: 책 두 권으로 나눔 = 傷寒論 + 金匱要略 분권

### #6. 葛洪(東晉) 『抱朴子』·『肘後備急方』(『肘後救卒方』) — 煉丹術·최초 구급서·儒道合一

- **고리**: 진달래 = 東晉 · 칡(葛) = 葛洪 · 통나무 껴안기 = 抱朴子 · 팔꿈치 뒤 주머니 = 肘後備急方 · 끓는 솥 = 煉丹術

  - `[서명]` 통나무(抱朴子) · 팔꿈치 뒤 주머니(肘後備急方) → **『抱朴子』·『肘後備急方』(金匱藥方)** (뜻)
