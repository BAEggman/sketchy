## 정거장 및 속성 매핑

### #1. 『劉涓子鬼遺方』(南北朝) — 귀신(鬼)이 남긴(遺) 처방(方)
- **물건**: 말랑한 줄자를 목에 감고 떠나는 도깨비 · 떨어뜨린 처방 쪽지
- **고리**: 말랑한(유연한) 줄자 = 劉涓子 · 도깨비 = 鬼 · 떨어뜨린 쪽지 = 遺方
  - `[이름]` 목에 감은 유연한 줄자 → **劉涓子(龔慶宣 정리)** (소리)
  - `[서명]` 도깨비(鬼)가 떨어뜨린 처방 쪽지(遺方) → **『劉涓子鬼遺方』** (뜻)
### #2. 『劉涓子鬼遺方』 의의 — 현존 최초의 外科(옹저·창양) 전문서
- **물건**: 처방 쪽지 옆의 은빛 외과 메스(칼)와 쪽지에 매달린 금메달
- **고리**: 외과 칼 = 外科 · 금메달 = 현존 최초
  - `[기여]` 은빛 외과 칼(메스) → **옹저·외상 치료 外科 전문** (뜻)
  - `[의의]` 처방 쪽지에 매단 금메달 → **현존 최초의 外科 전문서** (공용 부호)
### #3. 全元起(梁) 『內經訓解』(『素問訓解』) — 『素問』에 처음 주석을 달음
- **물건**: 목줄 맨 흰 양(梁) 옆에서 주석 책을 든 선생 · 전원 기립한 학생들과 넘어진 걸상 넷
- **고리**: 목줄 맨 흰 양 = 梁 · 전원 기립 = 全元起 · 쪽지 빼곡한 책 = 주석(訓解)
  - `[이름]` 한꺼번에 일어선 학생들과 넘어진 걸상(전원 기립) → **全元起** (소리)
  - `[왕조]` 선생 발밑 목줄 맨 흰 양 → **梁** (공용 부호)
  - `[서명]` 쪽지가 빼곡히 꽂힌 주석 책 → **『內經訓解』(素問訓解)** (공용 부호)
  - `[기여]` 쪽지 꽂힌 『素問』 책 → **『素問』 최초 주석(현재 실전)** (뜻)
### #4. 巢元方(隋) 『諸病源候論』(610) — 여러 병(諸病)의 근원(源)과 증후(候) 정리
- **물건**: 보라색 수국 꽃무더기(隋) 위 사람만 한 큰 새 둥지 · 무늬가 저마다 다른 알 다섯
- **고리**: 수국 = 隋 · 새 둥지 = 巢(巢元方) · 무늬 다른 알 = 諸病의 源·候
  - `[이름]` 사람만 한 새 둥지(巢) → **巢元方** (뜻)
  - `[왕조]` 둥지 밑에 맞닿은 보라색 수국 꽃무더기 → **隋** (공용 부호)
  - `[서명]` 둥지 속 무늬가 서로 다른 알들 → **『諸病源候論』** (뜻)
### #5. 『諸病源候論』 의의 — 중국 최초의 病因·病機·證候學 전문서
- **물건**: 새 둥지 테두리에 매달린 금메달
- **고리**: 둥지 금메달 = 최초의 病因·病機·證候 전문서
  - `[기여]` 무늬 다른 알들과 둥지 → **내·외·부인·소아 등 1,720론 병인·증후 체계화** (뜻)
  - `[의의]` 둥지에 매단 금메달 → **최초의 病因·病機·證候 전문서** (공용 부호)
### #6. 楊上善(隋) 『黃帝內經太素』 — 『內經』을 항목별로 나눈 최초의 분류 주석서
- **물건**: 수국 꽃무더기(隋) 위 버드나무 꼭대기에 걸린 크고 흰 갈래 천 · 가지의 금메달
- **고리**: 수국 = 隋 · 버드나무(楊) 꼭대기(上) = 楊上善 · 크고(太) 흰(素) 갈래 천 = 太素(분류) · 금메달 = 최초
  - `[이름]` 버드나무(楊)와 꼭대기(上) → **楊上善** (뜻)
  - `[왕조]` 버드나무 뿌리에 맞닿은 수국 꽃무더기 → **隋(隋·唐 초)** (공용 부호)
  - `[서명]` 꼭대기의 크고(太) 흰(素) 갈래 천 → **『黃帝內經太素』** (뜻)
  - `[기여]` 여러 갈래로 나뉜 흰 천 → **『素問』+『靈樞』를 합쳐 유별로 나눈 분류 주석** (뜻)
  - `[의의]` 버드나무 가지에 매단 금메달 → **『內經』 최초의 분류 주석서** (공용 부호)
