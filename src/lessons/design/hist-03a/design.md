## 정거장 및 속성 매핑

### #1. 孫思邈(唐) 『備急千金要方』·『千金翼方』 — 약왕(藥王)의 두 천금방
- **물건**: 알사탕 바닥(唐) 위 사막 모래 쟁반에서 낙타를 탄 아이 · 금덩이와 날개 달린 금덩이
- **고리**: 사탕 = 唐 · 아이(孫)+사막(思邈) = 孫思邈 · 금덩이 = 千金要方 · 날개 금덩이 = 千金翼方
  - `[이름]` 사막 모래 쟁반 위 낙타 탄 아이 → **孫思邈** (뜻+소리)
  - `[왕조]` 발밑 알사탕·막대사탕 → **唐** (공용 부호)
  - `[서명]` 금덩이(千金要方)와 날개 달린 금덩이(千金翼方) → **『備急千金要方』·『千金翼方』** (뜻)
### #2. 孫思邈 의의 — 중국 최초의 임상 백과전서 · 三人明堂圖 오색 채색 · 阿是穴
- **물건**: 낙타 목에 걸린 금메달 · 세 사람 몸 그림에 다섯 색 붓 칠하기 · 아픈 곳 누르기
- **고리**: 금메달 = 최초 임상 백과 · 세 몸 그림 색칠 = 三人明堂圖 채색 · 누르자 아! = 阿是穴
  - `[기여]` 세 몸 그림 채색과 아픈 점 누르기 → **三人明堂圖 경맥 오색 채색 · 阿是穴 창안 · 大醫精誠** (뜻)
  - `[의의]` 낙타 목에 매단 금메달 → **중국 최초의 임상 의학 백과전서** (공용 부호)
### #3. 甄權(唐) 『明堂人形圖』 — 고대 明堂圖(경혈도)를 교정·정리
- **물건**: 사탕 바닥(唐) 위에서 권투 장갑 낀 개가 붓으로 점 찍힌 인체 괘도를 고침
- **고리**: 사탕 = 唐 · 개(犬=견)+권투 장갑(拳=권) = 甄權 · 점 찍힌 인체 괘도 = 明堂圖 교정
  - `[이름]` 권투 장갑 낀 개 → **甄權** (소리)
  - `[왕조]` 발밑 알사탕 → **唐** (공용 부호)
  - `[서명]` 점이 찍힌 인체 괘도 → **『明堂人形圖』(明堂圖)** (공용 부호)
  - `[기여]` 붓으로 인체 괘도를 고쳐 그림 → **고대 明堂圖(경혈도) 수정·보완** (뜻)
### #4. 蘇敬(唐 659) 『新修本草』(『唐本草』) — 나라가 새로 엮은 官修 본초
- **물건**: 사탕 바닥(唐) 위에서 제복 입고 경례하는 소 · 붉은 리본과 밀랍 봉인이 붙은 새 책
- **고리**: 사탕 = 唐 · 소(蘇)+경례(敬) = 蘇敬 · 붉은 리본·밀랍 봉인 새 책 = 官修 新修本草
  - `[이름]` 제복 입고 경례하는 소 → **蘇敬(蘇恭)** (소리)
  - `[왕조]` 발밑 알사탕 → **唐(659)** (공용 부호)
  - `[서명]` 붉은 리본·밀랍 봉인이 붙은 새 본초 책 → **『新修本草』(唐本草)** (공용 부호)
### #5. 『新修本草』 의의 — 세계 최초의 국가 약전(官修本草) · 약물 844~850종 수록
