# hist-05a 本草書 계보 ① 宋 — 開寶 · 嘉祐 · 證類(唐愼微) · 政和 · 衍義(寇宗奭) — Carbon v7 설계서

- **장소**: 소나무 약초 계단밭 아랫단 — 宋(솔가지) 터 · 국가 본초 편수 차례
- **정거장 수**: 8 (내용 6)

## 정거장 및 속성 매핑

### #1. 『開寶本草』(北宋 973~974, 劉翰 등) — 宋代 국가 관찬 본초의 첫째
- **물건**: 문 위 솔가지(北宋) 아래 약초가 넘치는 열린 보물 상자 · 붉은 리본 밀랍 봉인
- **고리**: 위 솔가지 = 北宋 · 열린(開) 보물(寶) 상자 = 開寶本草 · 붉은 봉인 = 관찬
  - `[왕조]` 보물 상자 위쪽 푸른 솔가지 → **北宋(宋)** (공용 부호)
  - `[서명]` 약초가 넘치는 열린 보물 상자 + 붉은 봉인 → **『開寶本草』** (뜻)
  - `[기여]` 첫째 계단 관찬 본초 상자 → **宋 국가 본초 편찬의 첫째(목판 인쇄 시작)** (뜻)
### #2. 『嘉祐補註本草』(北宋 1057~1060, 掌禹錫·蘇頌) — 둘째, 앞 책에 주석을 보탬(補註)
- **물건**: 푸른 솔가지(北宋) 아래 큰 가위로 쪽지를 오려 책에 보태 붙이는 관리(掌禹錫)
- **고리**: 솔가지 = 宋 · 가위 = 嘉祐(소리) · 쪽지 보태 붙이기 = 補註 (+ 蘇頌 『本草圖經』)
  - `[이름]` 손바닥(掌) 문양 옷을 입은 편찬 관리 → **掌禹錫(·蘇頌 『本草圖經』)** (뜻+이야기)
  - `[왕조]` 머리 위 푸른 솔가지 → **北宋(宋)** (공용 부호)
  - `[서명]` 큰 가위(嘉祐)와 쪽지를 보태 붙인 책(補註) → **『嘉祐補註本草』** (소리+뜻)
### #3. 唐愼微(★宋) — 성씨가 唐일 뿐 宋나라 의가(사탕에 속지 말 것)
- **물건**: 발밑 솔가지(★宋) 위에서 막대사탕(이름 唐 함정)을 쥐고 돋보기로 약초를 살피는 의원
- **고리**: 발밑 솔가지 = 宋 사람(왕조 터) · 손의 막대사탕 = 성씨 唐 · 돋보기 = 삼가 살핌(愼微)
  - `[이름]` 막대사탕(唐)과 돋보기(愼微)를 든 의원 → **唐愼微** (소리+뜻)
  - `[왕조]` 발밑에 맞닿은 푸른 솔가지 → **北宋(★宋, 唐나라 아님)** (공용 부호)
### #4. 唐愼微 『經史證類備急本草』(『證類本草』) — 『嘉祐本草』+『本草圖經』 합편 · 현존 완질 최류 본초
- **물건**: 돋보기 노인 앞 『嘉祐本草』와 『本草圖經』 두 책을 하나로 묶은 큰 약초 사전
- **고리**: 글(嘉祐)과 그림(圖經)을 합친 큰 책 = 『經史證類備急本草』
  - `[서명]` 글 책과 그림 책을 하나로 합친 큰 본초 사전 → **『經史證類備急本草』(證類本草)** (뜻)
  - `[기여]` 嘉祐本草+本草圖經 결합 및 단방 수록 → **『嘉祐補註本草』와 『本草圖經』을 합쳐 글·그림 결합 완성** (뜻)
### #5. 『大觀本草』 → 『政和本草』(宋 1116, 曹孝忠) — 『證類本草』를 국가에서 교정 간행
- **물건**: 솔가지(北宋) 아래 큰 망원경(大觀)을 렌치로 고쳐 붉은 봉인을 찍는 관리(曹孝忠)
- **고리**: 큰 망원경 = 大觀(크게 봄) · 렌치로 고쳐 봉인 = 政和本草
  - `[이름]` 망원경을 교정하는 관찬 관리 → **曹孝忠(·艾晟)** (이야기)
  - `[왕조]` 발밑 푸른 솔가지 → **北宋(宋 1116)** (공용 부호)
  - `[서명]` 큰 망원경(大觀)과 교정 렌치·붉은 봉인(政和) → **『大觀本草』 → 『政和本草』** (뜻)
### #6. 寇宗奭(宋) 『本草衍義』(1116) — 약물이 특정 장부·경락으로 돌아가는 藥物歸經 이론 효시
- **물건**: 솔가지(宋) 아래 보따리를 메고 자기 집 오두막으로 걸어 돌아가는 약초
- **고리**: 솔가지 = 宋 · 집으로 돌아가는(歸) 약초 = 寇宗奭 『本草衍義』 藥物歸經 효시
  - `[이름]` 오두막 앞 본초 학자 → **寇宗奭** (이야기)
  - `[왕조]` 오두막 밑 푸른 솔가지 → **北宋(宋 1116)** (공용 부호)
  - `[서명]` 보따리 메고 집으로 돌아가는 약초 책 → **『本草衍義』** (뜻)
  - `[기여]` 제 집으로 돌아가는(歸) 약초 → **藥物歸經 이론의 시초 제시** (뜻)
