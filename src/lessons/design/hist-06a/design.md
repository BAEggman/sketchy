### #1. 劉完素(字 守眞, 號 河間, 金) 寒凉派(主火派) — 六氣皆從火化
- **물건**: 황금 광석 금광 터(金) 앞 참진주 구슬을 지키는(守眞) 사람 · 얼음 우유(劉) 끼얹기 · 불붙은 날씨 표지 여섯(육각너트 6)
- **고리**: 금광 = 金 · 참진주 지킴 = 守眞 · 얼음 우유 = 劉完素·寒凉派 · 육각너트(6)+불붙은 날씨 = 六氣皆從火化
  - `[이름]` 얼음 섞인 우유(유)를 끼얹는 사람 → **劉完素** (소리)
  - `[왕조]` 발밑 황금 광석 금광 터 → **金** (공용 부호)
  - `[字號]` 참진주 구슬을 두 손으로 지키는 방패(守眞) → **守眞(字) · 河間(號)** (뜻)
  - `[기여]` 얼음 우유 끼얹기 + 불붙은 여섯 날씨 표지 → **寒凉派(主火派) · 六氣皆從火化 · 降心火 益腎水** (뜻)
  - `[수]` 육각 너트(6) → **6(六氣)** (공용 부호)
### #2. 劉完素 — 五志過極皆爲熱甚 · 『素問玄機原病式』·『宣明論方』(病機十九條 연구)
- **물건**: 첫째 갱도 앞 오징어(5)와 불붙은 감정 가면 다섯 · 『素問玄機原病式』·『宣明論方』
- **고리**: 오징어(5)+불붙은 가면 다섯 = 五志過極皆爲熱甚 · 일렉기타+구미호(19) = 病機十九條

  - `[기여]` 불붙은 감정 가면 다섯 → **五志過極皆爲熱甚 · 運氣學說과 病機十九條 발전** (뜻)

### #3. 張從正(字 子和, 號 戴人, 金) 攻下派 — 汗·吐·下 3법으로 邪를 몰아냄(邪去則正安)
- **물건**: 금광 터(金) 둘째 갱도 앞 보라색 자와 연꽃(子和)을 찬 장정이 큰 종을 쳐 검은 사기(邪) 덩이를 쫓아냄
- **고리**: 금광 = 金 · 종(從) 치는 장정(張·正) = 張從正 · 자+연꽃 = 子和 · 사기 쫓아냄 = 攻下派 邪去則正安
  - `[이름]` 큰 종(從)을 치는 장정(張·正) → **張從正** (소리+뜻)
  - `[왕조]` 발밑 황금 광석 금광 터 → **金** (공용 부호)
  - `[字號]` 보라색 자(尺)와 연꽃(和) → **子和(字) · 戴人(號)** (소리+뜻)
  - `[기여]` 갱도에서 쫓겨 구르는 검은 덩이들(汗·吐·下) → **攻下派 · 汗·吐·下 3법 · 邪去則正安** (뜻)
  - `[수]` 삼지창(3) → **3법(汗·吐·下)** (공용 부호)

### #5. 李杲(字 明之, 號 東垣, 金) 補土派(溫補脾胃) — 內傷脾胃 百病由生 · 補中益氣湯
- **물건**: 금광 터(金) 셋째 구역 동쪽 흙담(東垣) 곁에서 자두(李)를 문 채 누런 흙(土)으로 구덩이를 메우는 사람
- **고리**: 금광 = 金 · 자두(李) = 李杲 · 동쪽 흙담(垣) = 東垣 · 흙(土)을 메움(補) = 補土派
  - `[이름]` 자두(李)를 입에 문 사람 → **李杲** (뜻)
  - `[왕조]` 발밑 황금 광석 금광 터 → **金** (공용 부호)
  - `[字號]` 해 뜨는 동쪽의 높은 흙담(東垣) → **東垣(號) · 明之(字)** (뜻)
  - `[기여]` 누런 흙으로 구덩이를 메우는 작업과 약탕 사발 → **補土派(스승 張元素) · 內傷脾胃 百病由生 · 甘溫除熱 補中益氣湯** (뜻)
### #6. 李杲 『脾胃論』·『內外傷辨惑論』·『蘭室秘藏』 — 「膽者少陽春升之氣, 春氣升則萬化安」
- **물건**: 흙담 위로 곧게 솟아오르는 푸른 봄 새싹과 두 권의 책
- **고리**: 담장(膽) 위 솟는 봄 새싹 = 膽者少陽春升之氣 · 흙 책 = 脾胃論

### #7. 朱震亨(字 彦修, 號 丹溪, ★元) 滋陰派 — 陽常有餘 陰常不足 · 相火論
- **물건**: 고개 너머 초가 원두막(★元) 아래 붉은 시내(丹溪) · 넘치는 해 물통과 거의 빈 달 물통에 물 채우기
- **고리**: 원두막 = ★元(혼자 元 사람!) · 붉은(朱·丹) 시내(溪) = 朱震亨 丹溪 · 빈 달 물통 채움 = 滋陰派

  - `[왕조]` 발밑 초가 원두막 마루 → **元(★四大家 중 유일한 元 의가)** (공용 부호)

  - `[기여]` 넘치는 해 물통과 물 채우는 빈 달 물통 → **滋陰派(養陰派) · 陽常有餘 陰常不足 · 相火論** (뜻)
