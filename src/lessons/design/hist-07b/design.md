## 정거장 및 속성 매핑

### #1. 河若愚(金) 『流注指微賦』(『자오유주침경』) — 子午流注 침법의 기원
- **물건**: 금광 바위(金) 위 물방울이 흘러 부어지는 물시계(流注) 앞에서 노래하는 사람
- **고리**: 금광 = 金 · 물 흐르는 시계 = 流注 · 두루마리 노래 = 賦(流注指微賦)
  - `[이름]` 물시계 옆 침구 의가 → **河若愚(일설 何若愚)** (이야기)
  - `[왕조]` 발밑 황금 광석 금광 터 → **金** (공용 부호)
  - `[서명]` 물 흐르는 시계(流注)와 노래 두루마리(賦) → **『流注指微賦』(子午流注鍼經)** (뜻)
  - `[기여]` 시간 눈금 물시계와 침 → **子午流注(시간 침법) 개척** (뜻)
### #2. 竇默(字 漢卿, 元) 『鍼經指南』 — 침구 가부 「標幽賦」·「通玄指要賦」 수록
- **물건**: 초가 원두막(元) 앞 한옥 기와+벼슬 홀(漢卿)을 든 사람 · 긴 침 꽂힌 나침반과 노래하는 사람
- **고리**: 원두막 = 元 · 말없이 가리킴 = 竇默 · 한옥+홀 = 漢卿 · 침 나침반 = 鍼經指南 · 노래 = 標幽賦
  - `[이름]` 입을 다문 채(默) 나침반을 가리키는 사람 → **竇默** (뜻)
  - `[왕조]` 발밑 초가 원두막 마루 → **元** (공용 부호)
  - `[字號]` 한옥 기와 모형(漢)과 벼슬아치 홀(卿) → **漢卿(字)** (소리+뜻)
  - `[서명]` 한가운데 긴 침이 꽂힌 큰 나침반 → **『鍼經指南』** (뜻)
  - `[기여]` 두루마리를 노래하는 사람 → **침구 가부 「標幽賦」·「通玄指要賦」 수록 및 유주팔법 정리** (공용 부호)
### #3. 滑壽(字 伯仁, 號 攖寧生, 元) 『十四經發揮』 — 12正經에 任·督을 더해 十四經 확립
- **물건**: 원두막(元) 옆 흰 씨앗 두 알(伯仁)을 쥐고 무지개 미끄럼틀을 타는 청록 조끼 장수 노인 · 일렉기타 위 사과(14)
- **고리**: 원두막 = 元 · 미끄럼(滑) 장수(壽) = 滑壽 · 흰 씨앗(仁) = 伯仁 · 기타(1)+사과(4) = 十四經發揮
  - `[이름]` 미끄럼틀(滑)을 타는 장수(壽) 노인 → **滑壽** (뜻)
  - `[왕조]` 미끄럼틀 아래 원두막 마루 → **元(1341)** (공용 부호)
  - `[字號]` 손에 쥔 하얀 씨앗 알맹이(백인 = 伯仁) → **伯仁(字) · 攖寧生(號)** (소리+뜻)
  - `[서명]` 일렉기타(1) 위 사과(4)와 열네 줄기 미끄럼틀 → **『十四經發揮』(·『難經本義』)** (공용 부호)
  - `[기여]` 12줄기에 앞뒤 2줄기(임·독)가 합쳐진 14줄기 → **12正經 + 任脈·督脈 = 十四經 체계 확립** (뜻)
  - `[수]` 일렉기타(1) 위 사과(4) → **14(十四經)** (공용 부호)
### #4. 滑壽 『十四經發揮』 의의 — 중국 최초의 天然色 經絡圖譜 (결정 8 확정)
- **물건**: 무지개색 미끄럼틀 꼭대기에 매달린 금메달
- **고리**: 무지개색 미끄럼틀 + 금메달 = 최초 天然色 經絡圖譜
  - `[의의]` 무지개색 미끄럼틀 꼭대기 금메달 → **중국 최초의 天然色 經絡圖譜(결정 8 · 이설 陳會)** (공용 부호)
### #5. 徐鳳(字 廷瑞, 明) 『鍼灸大全』(1439) — 금·원 침구 가부(歌賦) 수집 · 『鍼灸大成』보다 160년 
- **물건**: 붉은 등불(明) 켜진 서랍 많은 약장(徐) 위에 앉은 봉황(鳳)과 노래하는 사람
- **고리**: 붉은 등불 = 明 · 서랍(徐)+봉황(鳳) = 徐鳳 · 서랍 칸 전부(全) = 『鍼灸大全』
  - `[이름]` 서랍 약장(徐) 위 봉황(鳳) → **徐鳳(廷瑞)** (소리+뜻)
  - `[왕조]` 약장 밑 붉은 초롱 등불 → **明(1439)** (공용 부호)
  - `[서명]` 칸이 전부(全) 채워진 큰 약장 → **『鍼灸大全』** (뜻)
  - `[기여]` 약장 옆 노래 두루마리(歌賦) → **금·원 침구 가부 수집 · 자오유주와 평보평사 정리** (공용 부호)
### #6. 高武(明) 『鍼灸聚英』(·『鍼灸節要』) · 汪機(明) 『鍼灸問對』 — 명대 침구 대표 저작
- **물건**: 붉은 등불(明) 아래 꽃다발(聚英)을 든 높은 투구 무사(高武)와 마주 앉아 문답(問對)하는 물가 학자(汪機)
- **고리**: 등불 = 明 · 높은 무사(高武)+꽃다발(聚英) = 『鍼灸聚英』 · 물가 베틀(汪機)+문답 = 『鍼灸問對』
  - `[이름]` 높은 무사(高武)와 물가 베틀 학자(汪機) → **高武 · 汪機(石山)** (뜻+소리)
  - `[왕조]` 발밑 붉은 초롱 등불 → **明** (공용 부호)
  - `[서명]` 모인 꽃다발(鍼灸聚英)과 마주 보는 문답 책(鍼灸問對) → **『鍼灸聚英』(高武) · 『鍼灸問對』(汪機)** (뜻)
