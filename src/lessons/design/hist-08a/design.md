## 정거장 및 속성 매핑

### #1. 溫補學派(明) — 命門과 腎陽·脾胃를 따뜻하게 보익(교재 3인: 薛己·張介賓·趙獻可 + 통설 孫一奎·李中梓)
- **물건**: 붉은 등불(明)이 켜진 따뜻한 온돌방과 아궁이에서 구들 밑으로 퍼지는 열기
- **고리**: 등불 = 明 · 아궁이 구들 열기 = 溫補(命門火·腎陽 보익)
  - `[왕조]` 온돌방의 붉은 초롱 등불 → **明** (공용 부호)
  - `[기여]` 아궁이 불길과 따뜻한 구들장 → **溫補學派 — 脾胃·腎·命門 온보(육미·팔미환 중시)** (뜻)
### #2. 薛己(號 立齋, 明) 『內科摘要』·『外科發揮』 — 溫補學派의 선구 · 내과에 처음 「內科」 서명 사용
- **물건**: 붉은 등불(明) 아래 김 나는 하얀 백설기(薛己) 위에서 붉은 대추 알맹이만 집어내는(摘要) 의원
- **고리**: 등불 = 明 · 백설기 = 薛己(소리) · 알맹이 집어냄 = 『內科摘要』
  - `[이름]` 하얀 백설기(설기) → **薛己(立齋)** (소리)
  - `[왕조]` 소반 옆 붉은 초롱 등불 → **明** (공용 부호)
  - `[서명]` 방 안(內)에서 백설기 위 대추 요점만 집어냄(摘要) → **『內科摘要』·『外科發揮』** (뜻)
  - `[기여]` 온돌방 첫째 자리 백설기 상 → **溫補學派 선구 · 비위와 신·명문 겸보(육미·팔미 활용)** (뜻)
### #3. 張介賓(字 會卿, 號 景岳, 明) 『類經』(1624) — 『素問』·『靈樞』를 내용별 12類로 분류 주석
- **물건**: 붉은 등불(明) 아래 일렉기타(1) 위 이층 버스(2)가 선 열두 칸 책장(張)에 『內經』 책을 분류해 꽂는 사람
- **고리**: 등불 = 明 · 책장(張) = 張介賓 · 기타(1)+버스(2)+열두 칸 분류 = 『類經』(12類)
  - `[이름]` 열두 칸 책장(張) 앞 학자 → **張介賓** (소리)
  - `[왕조]` 책장 옆 붉은 초롱 등불 → **明(1624)** (공용 부호)
  - `[서명]` 항목별로 나뉜(類) 열두 칸 경전 책장 → **『類經』(·『類經圖翼』·『類經附翼』)** (뜻)
  - `[기여]` 『소문』·『영추』를 12칸에 분류 배열 → **『內經』을 내용별 12類로 재편·주석** (뜻)
  - `[수]` 일렉기타(1) 위 이층 버스(2) → **12類** (공용 부호)
### #4. 張介賓(號 景岳) 『景岳全書』 — 「陽非有餘 眞陰不足」(朱震亨 반박) · 陰中求陽 陽中求陰
- **물건**: 넘치지 않은 해 물통(陽非有餘)과 텅 빈 달 물통(眞陰不足) 옆에서 깜짝 놀라(景岳=경악) 펄쩍 뛰는 사람
- **고리**: 깜짝 놀람(경악) = 景岳(소리) · 안 넘친 해 물통 = 陽非有餘 · 빈 달 물통 = 眞陰不足
  - `[字號]` 깜짝 놀라(경악) 펄쩍 뛰는 모습 → **景岳(號)** (소리)
  - `[서명]` 경악(景岳)하는 사람 앞의 전집 책 더미 → **『景岳全書』** (소리+뜻)
  - `[기여]` 넘치지 않은 해 물통 + 빈 달 물통 → **陽非有餘 眞陰不足 · 陰中求陽 陽中求陰(좌귀·우귀)** (뜻)
