# hist-09 溫病學派 — 설계·제작 기록 (2026-11-09)

- 장소: 유리 온실 식물원 — 온실(溫室) = 溫病, 맑은(淸) 유리 안 = 淸 溫病 四大家, 유리 밖 정원 = 그 앞 사람(王履 元末明初 · 吳有性 明末). 정거장 10 = 틀 + 8 + 되짚기. 카드 13장(src).
- 吳 = 오리(吳有性 · 吳鞠通 둘 다). 衛氣營血 = 둥근 울타리 셋(파랑 衛 · 초록 氣 · 빨강 營) + 한가운데 붉은 꽃(血). 三焦 = 세로로 매단 바구니 셋(3단 선반은 hist-01 三品이라 피함).
- 바탕: Gemini Argon 한 턴(`prompt_base.txt`, 1,895자) → 같은 채팅 편집 8회
  1. 정원사 장화를 낮은 신으로(履 겹침 방지) · 공 하나로(v2) 2. 유리 상자 테 색 넣기(v3)
  3. 일치 검사 △ 반영: 빨강 상자·메달 고리(v4) → 주황이 사라짐 4. 주황 하나 더(v5) → 주황·빨강이 한 상자로 보임
  5. 유리 상자 → 동심 울타리(v6) → 또 셋으로 합쳐짐 6. 빨강 작은 고리(v7, 검사자 「세 겹으로 셀 것」)
