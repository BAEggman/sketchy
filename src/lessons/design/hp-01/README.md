# hp-01 藥性 ① 四氣五味 — 설계·제작 기록 (2026-11-10)

- 장소: 온도 다이얼 달린 다섯 맛 분식집. 벽의 반원 다이얼 = 四氣, 카운터 다섯 칸 = 五味(酸苦甘辛鹹, 木火土金水 차례 — 甘이 한가운데라 「和」). 정거장 9 · 카드 11.
- 다이얼: 진파랑 큰 눈송이(寒) · 연파랑 작은 눈송이(凉 = 微寒) · 주황 작은 불꽃(溫) · 빨강 큰 불꽃(熱). 「微」는 크기와 자리(이웃 칸)가 진다. 볕 드는 불꽃 쪽 = 陽(yyox-02 볕 = 陽과 같은 뜻).
- 治寒用熱藥 · 治熱用寒藥: 떠는 패딩 손님 + 버너 위 끓는 국 / 땀 흘리는 민소매 손님 + 얼음 빙수(얼음 = 寒 · 불 = 熱 공용). 카드 BC-4G-01은 다이얼 정거장이 지고, 손님 정거장은 카드 없이 치료 원칙만.
- 五味 다섯 칸: 레몬 + 끈 꽉 조인 물 주머니(酸收 · 收澀) / 커피 + 아래로 떨어지는 드립(苦泄) + 말라 굳은 설거지 스펀지(燥 · 堅) / 꿀이 늘어지며 천천히 그릇을 채움(甘緩 · 補 · 한가운데 和) / 양옆으로 흩날리는 고춧가루(辛散 · 橫行) / 소금 + 절여 늘어져 소금물로 처진 배추(鹹軟 · 軟堅 · 下). 五味 물건(레몬 · 커피 · 꿀 · 고추 · 소금)은 yyox-06 공용.
- 바탕: Gemini 한 턴 → 편집 4회(배추 절이기 · 행주가 종이봉투로 읽혀 두 번 바꿔 설거지 스펀지로 · 햇빛 넓히기는 실패). v5 최종.
- 일치 검사(v2): ○5 · △2 — 햇빛이 빨강 칸만 비춤(글을 맞춤: 「불꽃 쪽 끝 빨강 칸」) · 행주가 종이봉투로 읽힘(편집). 재검사(v4): 스펀지가 카스텔라로 읽힐 수 있음 → 초록 수세미 면 추가(v5).
- 남은 약점: 왼쪽 위 선반의 냄비·조리 도구, 카운터 뒤 큰 들통은 뜻 없는 배경.
