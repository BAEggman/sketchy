# hp-02 藥性 ② 升降浮沈 — 설계·제작 기록 (2026-11-10)

- 장소: 엘리베이터 있는 실내 수영장(단면). 위·아래 자리가 곧 방향. 정거장 10 · 카드 7.
- 升 · 降 = 유리 엘리베이터의 올라가는 칸 · 내려가는 칸. 浮 = 수면에 별처럼 떠서 물결을 바깥으로 퍼뜨리는 여자(上行發散). 沈 = 머리부터 내려가는 잠수부 + 물이 빨려 내려가는 배수구(下行泄利).
- 升浮 = 陽(볕 든 유리 천장 아래) · 沈降 = 陰(어둑한 깊은 물) — yyox-02 볕 = 陽과 같은 뜻.
- 氣味가 방향을 정함: 떠오르는 열기구(불꽃 = 溫熱) 바구니에 고추 · 꿀(辛甘) / 바닥에 서리 덮여 가라앉은 레몬 · 커피잔 · 소금통(酸苦鹹 · 寒凉). 五味 물건은 hp-01 · yyox-06 공용. 川芎 雙向性은 내레이션만.
- 포제 넷: 올라가는 칸의 붉은 얼굴 + 초록 술병(酒炒則升) · 생강을 쥐어짜 즙이 사방으로(薑汁炒則散) · 식초병 곁 끈 꽉 조인 가방(醋炒則斂 — hp-01 酸收의 끈 주머니와 같은 뜻) · 내려가는 칸의 소금물 양동이(鹽水炒則下行). 엘리베이터 두 칸은 升降과 酒 · 鹽水 정거장이 함께 쓴다.
- 바탕: Gemini 한 턴 → 편집 1회(벽 배출구 물줄기 지움 · 식초병 · 소금물 양동이, v2 최종).
- 일치 검사(v1): ○5 · △4 — 배출구 물줄기가 「물이 나온다」로 읽힘 · 병이 간장 · 양동이가 얼음 → 편집. 재검사(v2): 배수구 ○ · 식초병은 식용유로도 읽힘 · 소금 알갱이가 작아 그냥 물 양동이로 읽힘 — 라벨 없이는 더 못 가름, 내레이션이 이름을 진다.
