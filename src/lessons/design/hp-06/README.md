# hp-06 君臣佐使 (麻黃湯) — 설계·제작 기록 (2026-11-10)

- 장소: 조선 궁궐 어전. 높은 자리일수록 위에 선다. 쳐들어오는 얼음 귀신 = 바깥 찬 기운(風寒). 어전 전체가 麻黃湯 한 처방. 方劑 첫 과. 정거장 9 · 카드 11.
- 君: 가장 큰 왕이 마디진 초록 줄기(麻黃)로 불길을 뿜어 귀신을 곧장 겨눔(主證 직격). 臣: 계피 가지(桂枝) 든 파란 옷 대신이 왕 곁에서 돕고, 곁의 회색 도깨비(兼證)를 내려침.
- 佐 셋: 살구씨 그릇(佐助 · 杏仁) · 불길에 물 끼얹기(佐制) · 한 쟁반의 뜨거운 그릇 + 얼음 조각(反佐 · 寒熱竝用).
- 使 둘: 장작 지고 등불로 길 비추는 아이(引經報使 · 장작 = 柴胡, zds-14 땔나무와 같은 뜻) · 가마솥 젓는 아이(調和諸藥 · 甘草).
- 바탕: Gemini 한 턴 → 편집 1회(물줄기를 왕의 불길로, v2 최종).
- 일치 검사(v1): ○3 · △5 — 대신이 귀신이 아닌 도깨비를 침(글을 맞춤: 兼證을 맡는 장면) · 살구씨가 주황 덩어리 · 물줄기 방향(편집) · 크기 서열은 앞줄 아이가 커 보임(「위에 선다」로 맞춤).
- 남은 약점: 옥좌 뒤 일월오봉도(해·달)는 뜻 없는 배경. 마황 줄기가 대나무처럼 굵다.
