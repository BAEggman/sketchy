# hp-07 基本方 짝 — 설계·제작 기록 (2026-11-10)

- 장소: 선비 사랑방. 정거장 8 · 카드 11.
- 四君子湯: 매난국죽 네 폭 병풍(네 군자) + 소반 위 人參 · 白朮 · 茯苓(흰 공, hp-03) · 甘草(감초 막대). 카드는 補可去弱(十劑) · 緩方 · 『和劑局方』의 예로 묻는다 — 내레이션에 宣通泄의 짝과 『太平聖惠方』까지.

- 八珍湯: 보석 여덟 상자 = 넷 + 넷 → 氣血雙補.
- 六味地黃丸: 흰 접시 환약 여섯 + 물 주전자(補陰 · 丸劑 慢性病). 腎氣丸: 금테 궤짝(金匱 — 예약표의 金匱 = 금테 궤짝) + 계피 · 검은 덩이뿌리(附子, hp-05) · 화로(補陽 · 偶方 · 출전 명명).
- 小柴胡湯: 문지방에 걸친 섶 단(안도 밖도 아닌 半表半裏 · 和解少陽). 섶 = 柴는 zds-14 · hp-06과 같은 뜻.
