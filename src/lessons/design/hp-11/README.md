# hp-11 七情 氣機 — 설계·제작 기록 (2026-11-10)

- 장소: 희로애락 소극장 무대. 흰 옷 배우 여섯이 하늘색 풍선(= 氣, hp-05 補氣 풍선과 같은 뜻)을 하나씩 듦. 무대의 위아래 = 氣의 방향. 정거장 8 · 카드 6.
