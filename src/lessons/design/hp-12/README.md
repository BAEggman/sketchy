# hp-12 痰飮·瘀血 — 설계·제작 기록 (2026-11-10)

- 장소: 밤의 막힌 하수 처리장. 왼쪽 잿빛 찌꺼기(痰飮) · 오른쪽 검보라 피(瘀血). 병이 만든 찌꺼기가 다시 길을 막음. 정거장 8 · 카드 14.
- 痰飮: 걸쭉한 탱크(稠濁 = 痰) ↔ 맑은 탱크(淸稀 = 飮) · 양동이로 토한 덩이(有形痰) ↔ 유리관에 갇힌 덩이(無形痰) · 목에 걸린 매실(梅核氣 · 阻滯氣機) · 찌꺼기 덮인 제어실과 어지러운 운전원(蒙蔽心神). 朱丹溪 百病皆因痰作祟 · 王淸任 『醫林改錯』.
- 瘀血: 고인 검보라 피 + 금 간 관에서 샌 피(離經之血 — 唐容川) · 관 속 보라 덩이(腫塊) · 한곳에 박힌 침 + 누르려는 손에 비명 + 초승달(刺痛 · 拒按 · 夜甚) · 줄줄 떨어지는 검보라 피(紫暗有塊) · 보랏빛 입술·손(脣甲靑紫).
- 바탕: Gemini 한 턴(v1 최종, 편집 없음).
- 일치 검사(v1): ○2 · △5 — 유리관 덩이가 벽 속이 아닌 바닥 · 매실이 씨 아닌 열매 · 웅덩이에 피가 쏟아져 「고요하지」 않음 · 바늘이 못 같고 손이 쥐고 있음 → 글을 그림에 맞춤.
- 남은 약점: 바깥 손이 침을 쥐어 「찌르는」 것처럼도 보임.
