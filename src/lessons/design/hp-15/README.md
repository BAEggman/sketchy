# hp-15 陰陽失調 ① 偏盛·偏衰 — 설계·제작 기록 (2026-11-10)

- 장소: 놀이터의 시소 넷(두 줄 × 둘). 시소마다 왼쪽 빨강 해 자리 = 陽, 오른쪽 파랑 달 자리 = 陰(hist-06 해 · 달과 같은 뜻). 윗줄 = 偏盛(무게가 얹혀 내려앉음, 實), 아랫줄 = 偏衰(가벼워 들림, 虛). 정거장 9 · 카드 13.
- 陽勝則熱: 해 자리에 불덩이 쇳덩이(實熱 · 小便短赤). 陰勝則寒: 달 자리에 얼음 덩어리(實寒 · 冷痛 寒凝 · 맑은 콧물).
- 陽虛則寒: 해 자리의 담요 두른 창백한 아이 → 해 쪽이 들림(虛寒 · 小便淸長) + 금테 궤짝(金匱腎氣丸, hp-07)과 화로를 얹음(益火之源 以消陰翳 · 陰病治陽).
- 陰虛則熱: 달 자리의 깡마르고 광대 붉은 아이 → 달 쪽이 들림(虛熱 · 五心煩熱 · 顴紅) + 물과 환약 여섯(六味地黃丸, hp-07)(壯水之主 以制陽光 · 陽病治陰).
- 바탕: Gemini 한 턴 → 편집 1회(도우미가 궤짝을 내려놓게 · 아이를 깡마르게, v2 최종).
- 일치 검사(v1): ○4 · △4 — 시소 넷의 위아래는 모두 맞음. 도우미 동작 · 깡마름(편집) · 물병 · 아이 크기(글을 맞춤). 피부색: 병색은 판타지 색조라 인종과 무관. 도우미 둘이 갈색 피부인 점만 남음.
