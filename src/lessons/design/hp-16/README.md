# hp-16 眞假 — 설계·제작 기록 (2026-11-10)

- 장소: 가면무도회장. 손님 넷이 막대 가면(假)을 얼굴 옆에 듦 — 가면은 늘 진짜 얼굴(眞)과 반대. 정거장 9 · 카드 17.
- 虛實眞假(왼쪽 둘 + 가운데 의사): 늙은이 가면 뒤 근육질, 누르면 버럭(大實有羸狀 · 眞實假虛 · 拒按) / 사나운 가면 + 공기 근육 옷, 누르면 편안(至虛有盛候 · 眞虛假實 · 喜按) + 인삼(塞因塞用 · 反治 · 通因通用은 내레이션).
- 陰陽格拒(오른쪽 둘): 볼 빨간 가면 뒤 얼어붙은 몸(陰盛格陽 · 眞寒假熱 · 戴陽 · 欲近衣被) + 뜨거운 附子 국(熱因熱用 · 通脈四逆湯) / 얼음 가면 뒤 불타는 몸(陽盛格陰 · 眞熱假寒 · 熱厥 · 不欲近衣) + 얼음 그릇 대황(寒因寒用 · 承氣湯 下法 — 眞實假虛에도).
- 附子 · 大黃 · 人參은 hp-05 좌판과 같은 물건.
- 바탕: Gemini 한 턴 → 편집 1회(공기 근육 옷, v2 최종).
