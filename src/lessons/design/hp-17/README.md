# hp-17 亡陽·亡陰 — 설계·제작 기록 (2026-11-10)

- 장소: 비상 계단의 두 층계참. 초록 비상구(픽토그램만) = 亡(달아남). 땀으로 가른다. 정거장 6 · 카드 5.
- 亡陽(왼쪽): 잿빛 얼굴 · 멍한 눈 · 묽고 찬 땀과 얼음 웅덩이 · 서리 앉은 손발 · 달아나는 해 요정(陽) — 大汗淋漓 · 汗稀而涼 · 手足厥冷 · 精神淡漠 · 脈微欲絶 · 絶汗. 구조대원이 해 요정을 붙잡고 인삼 + 附子 그릇(回陽救逆 · 四逆湯 · 參附湯).
- 亡陰(오른쪽): 벌건 얼굴 · 헐떡임 · 시럽처럼 끈적한 땀 · 붉은 혀 · 따뜻한 손 · 달아나는 물방울 요정(陰) — 汗熱而黏 · 手足溫 · 喘渴煩躁 · 脈數無力 · 舌光紅無苔. 다른 구조대원이 요정을 붙잡고 환자는 生脈散 컵(益氣救陰 · 효능 명명).
