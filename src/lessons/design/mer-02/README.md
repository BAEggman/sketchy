# mer-02 十二經脈 ① 사지 六面 — 설계·제작 기록 (2026-11-10)

- 장소: 제재소 작업대의 통나무 단면 셋 — 손 달린 단면(팔) · 발 달린 단면(아래다리) · 오른쪽 단면(넓적다리). 밝은 반원 = 안쪽 陰面, 어두운 반원 = 바깥 陽面, 왼쪽 = 앞(前緣). 정거장 8 · 카드 11.
- **경락 영역 공용 인물 열둘을 여기서 정했다**(예약표 등재). 陰經 = 五臟 인물(yyox-03) + 心包 호위무사, 陽經 = 짝과 같은 색 일꾼:
  - 肺 흰 도포 흰 수염 노인 ↔ 大腸 관 청소솔 든 흰 작업복 일꾼(傳導之官)
  - 心 붉은 용포 임금 ↔ 小腸 체 든 붉은 앞치마 일꾼(受盛之官)
  - 心包 칼·방패 든 붉은 갑옷 호위무사(臣使之官) ↔ 三焦 삽 멘 주황 옷 일꾼(決瀆之官)
  - 脾 밀짚모자 노란 옷 농부 ↔ 胃 국자 든 노란 앞치마 요리사(水穀之海)
  - 肝 초록 갑옷 장군 ↔ 膽 저울 든 초록 관복 판관(中正之官)
  - 腎 검은 옷 대머리 장사 ↔ 膀胱 물지게 진 검은 옷 일꾼(州都之官)
- 손: 안 肺 · 心包 · 心 / 밖 大腸 · 三焦 · 小腸. 발: 밖 胃(앞면) · 膽(옆) · 膀胱(뒷면) / 안 8寸 아래 肝 · 脾 · 腎 → 넓적다리(8寸 위) 脾 · 肝 · 腎. 같은 색 짝 = 같은 가장자리(表裏).
