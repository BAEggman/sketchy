# mer-03 十二經脈 ② 是動·所生 — 설계·제작 기록 (2026-11-10)

- 장소: 산후조리원 신생아실(所生 = 낳은 바). 요람 일곱 = 是主에 제 이름이 아닌 일곱, 流注 차례로 大腸 · 胃 · 小腸 · 膀胱 · 心包 · 三焦 · 膽. 아빠 = mer-02 경락 공용 인물. 손님 = 心 임금 · 肺 노인. 정거장 14 · 카드 39.
- 아기가 안은 것: 땀방울(津 — 楊上善 注 津，汗也) · 핏방울(血) · 젖빛 병(液) · 활(筋 — zds-01 활시위 = 筋) · 붉은 관(脈 — zds-02 붉은 관 = 脈) · 풍선(氣) · 뼈(骨).
- 아빠의 병 = 是動 · 所生 짝 가르기: 大腸 턱 붕대 + 목(齒痛 · 頸腫 是動) ↔ 小腸 뺨 + 귀(耳聾 · 頰腫 所生) · 三焦 땀 + 눈(汗出 · 目銳眥痛) ↔ 膽 떨림 + 눈(瘧 · 目銳眥痛) · 心 가슴 + 물(嗌乾 · 心痛 是動) ↔ 心包 煩心 · 心痛 所生 · 肺 기침 + 손바닥(咳喘 · 掌中熱 所生) · 心包 손바닥 + 겨드랑이(手心熱 · 腋腫 是動) · 胃 의자 위 노래(是動) · 膀胱 머리 · 허리(頭似脫 · 腰似折 是動).
- 원문 메모(내레이션): 大腸 津은 『太素』 독법(통행본 津液) · 小腸 液 · 膀胱 筋(기출 血 표기 주의) · 頸/頰 한 글자 함정(甲乙 頰腫).
