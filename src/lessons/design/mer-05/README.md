# mer-05 五輸穴 ① 井滎兪經合의 오행 — 설계·제작 기록 (2026-11-11)

- 장소: 우물에서 바다 어귀까지 한 줄기 물길. 돌우물(井 所出) → 넘쳐 흐르는 물줄기(滎 所溜) → 바위 폭포와 웅덩이(兪 所注) → 넓은 강(經 所行) → 바다 어귀(合 所入). 정거장 10 · 카드 9.
- 두 둑: 위 = 절벽 밑 그늘 둑 = 陰經(나무 · 모닥불 · 누런 흙더미 · 금괴 · 언덕 굴 샘물 = 木火土金水) / 아래 = 볕 드는 모래 둑 = 陽經(금괴 · 물단지 · 나무 · 모닥불 · 누런 흙 언덕 = 金水木火土). 둘 다 相生 차례, 시작만 다르다(陰井木 · 陽井金). 강을 사이에 둔 같은 자리끼리 陽이 陰을 剋한다.
- 本穴: 경락 공용 인물 열둘이 제 오행 물건 곁에 선다 — 肝 大敦 · 心 少府 · 心包 勞宮 · 脾 太白 · 肺 經渠 · 腎 陰谷 / 大腸 商陽 · 膀胱 足通谷 · 膽 足臨泣 · 小腸 陽谷 · 三焦 支溝 · 胃 足三里.
- 함정 둘(바다 어귀 = 合): 붉은 배 둘 — 그늘 쪽 금관 배 = 少海(心 合水) · 볕 쪽 체 실은 배 = 小海(小腸 合土) / 언덕 샘 둘 — 그늘 쪽 노란 깃발 = 陰陵泉(脾 合水) · 볕 쪽 초록 깃발 = 陽陵泉(膽 合土 · 膽 下合穴). 少海 · 小海는 TTS에서 「적을 소 · 작을 소」로 가름.
- 바탕: Gemini 한 판 + 편집 1(강을 우물에서 시작) + 코드 두 단계(위 둑 땅색 고르기 · 그늘). prompt_base.txt 끝에 이력.
- 일치 검사: 1차 △3(우물이 시작점 아님 · 물단지가 유리 어항 · 체 배가 떠 있음) → 편집·글 맞춤 → 2~4차는 그늘 보정 흔적 지적(두 색 땅 · 파란 띠 · 농부 셔츠 번짐) → 구역 제한 색 맞춤으로 해소. 남은 것: 장군 둘레 옅은 푸른 테, 나무 그림자 청록.
