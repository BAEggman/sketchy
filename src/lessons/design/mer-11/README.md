# mer-11 舍岩鍼法 ① 正格 · 勝格 — 설계·제작 기록 (2026-11-11)

- 장소: 큰 바위에 기대 지은 초가 방(舍 = 집 · 岩 = 바위). 바위벽 앞 3단 찬장 둘 — 왼쪽 正格(虛證) · 오른쪽 勝格(實證). 칸 = 오행 관계: 위 母(生我) · 가운데 官(剋我) · 아래 子(我生). 물 채운 독 = 補 · 엎어 쏟은 독 = 瀉 · 뚜껑 = 손대지 않음.
- 왼쪽: 위 채움 · 가운데 쏟음(補母瀉官). 오른쪽: 가운데 채움 · 아래 쏟음(補官瀉子). 가운데 칸만 좌우가 뒤집힘 = 正格의 瀉 = 勝格의 補. 한 칸에 독 둘 = 自經의 그 오행 혈 + 그 오행 本經의 本穴.
- 사람: 흰 수염 노인 = 肺 예(正格 太白·太淵 / 少府·魚際, 勝格 少府·魚際 / 陰谷·尺澤). 농부 = 脾 勝格(隱白·大敦 / 商丘·經渠), 물지게꾼 = 膀胱 勝格(委中·足三里 / 束骨·足臨泣) — 약점리포트 오답 최다 둘. 나머지 경 正格 · 勝格은 정거장 2 · 3 내레이션(사용자 암기송이 따로 있음).
