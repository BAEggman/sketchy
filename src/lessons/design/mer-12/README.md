# mer-12 舍岩鍼法 ② 寒格 · 熱格 — 설계·제작 기록 (2026-11-11)

- 장소: 대장간. 화로 = 火, 담금질 물통 = 水. 왼쪽(눈 오는 창) = 寒格: 대머리 장사의 풀무로 불 키움(補火, 열두 경 전부) · 붉은 앞치마와 물지게꾼이 한 양동이로 물 퍼 버림(瀉水, 예외 0). 오른쪽(해 뜬 창) = 熱格: 노인이 물 부음(補水) · 농부가 흙 퍼냄(瀉土 — 아홉 경) · 흰 작업복 · 임금 · 주황 일꾼이 숯불 긁어냄(瀉火 — 大腸 · 心 · 三焦 셋만).
