# new-etc-01 先秦·漢 — 의학의 기원과 첫 기록 — 설계·제작 기록 (2026-11-11)

- 장소: 사극 촬영 세트장. 왼쪽 → 오른쪽 = 원시 → 殷 → 周 → 戰國 → 漢.
- 그림과 뜻:
  - 원시인이 굽고 · 씹고 · 돌연장 = 經驗說 / 가면 무당이 북 치며 춤 = 巫醫說(醫起于巫, 毉 아래 巫).
  - 무대의 성인 다섯 — 풀잎 망토 약초 씹는 神農 · 뱀 꼬리 양 모는 伏羲 · 막대 돌려 불 燧人 · 노란 옷 黃帝와 두루마리 · 긴 침의 岐伯 = 聖人創製說.
  - 殷 마당 — 거북 등딱지 = 甲骨卜辭 · 침대에 일어나 기댄 병자 = 疒(질병명 20여 종, 疾年 · 雨疾) · 심장 · 배 · 콩팥 · 창자 인체판 = 盤庚 心腹腎腸.
  - 앞줄 의사들 소품 여덟(국 · 손 모음 · 칼 · 말 · 침 · 환자 손의 뜸대 · 안마 · 부적) = 八種醫(周禮 天官 四醫 + 넷).
  - 추 달린 태극 연, 다섯 색 꼬리 = 추연 鄒衍(陰陽 + 五行).
  - 지붕에 납작 엎드린 까치 = 扁鵲, 손목 짚기 · 얼굴 · 귀 · 몸 그림 = 切脈 · 望色 · 聽聲 · 寫形(원문은 「不待」 — 글에 밝힘).
  - 얼굴 없는 두건 인물의 산 · 바다 지도 = 山海經(작자 미상, 扁鵲 저서 아님).
  - 무덤(堆) 위 돌 말(馬) · 돌 임금(王), 선만 있는 비단 = 馬王堆 帛書(脈名만, 穴名 없음, 臟腑 絡屬 체계 없음).
  - 서가의 두 쪽 난 북(반 고) = 班固 · 노란 끈 죽간 = 黃帝內經 十八卷 · 매달린 금메달 = 최초(經方 서적을 처음 수록한 목록).
- 정거장 12 · 카드 11. 八種醫 카드는 분류가 「한국 기관」이라 출전 대조 필요(과 지도 flags).
