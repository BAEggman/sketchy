# new-etc-04 方書의 계보 — 兩晉隋唐 方書 붐 → 濟生方·得效方 → 普濟方·醫方考 → 衷中參西錄 — 설계·제작 기록 (2026-11-11)

- 장소: 구호 물자 배급소(書名의 濟 · 救). 왼쪽 → 오른쪽 = 시대 차례.
- 그림과 뜻:
  - 쪽지 산에 파묻힌 관리 · 거미줄 청진기와 멈춘 시계 · 돌 삼키는 사내 = 兩晉隋唐 方書 대량 · 이론 · 진단 정체(과학기술 미발달 · 종교 미신) · 石藥服用.
  - 엄한(嚴) 일꾼 · 구명 튜브(濟生) · 그릇을 밀짚모자 농부(脾) 위로 대머리 장사(腎)에게 = 嚴用和 『濟生方』 補脾不若補腎(반대말 補腎不如補脾 = 張銳 鷄峰普濟方, 許叔微 本事方과 구별).
  - 갈라져 무너지는 땅 끝(危) 천막의 깁스 · 코에 천 대고 잠 = 危亦林 『世醫得效方』 골절 정복 · 麻醉.
  - 붉은(朱) 덮개의 가장 큰 상자 산 · 나물 자루 = 朱橚 『普濟方』 168권 최대 方書 · 『救荒本草』.
  - 칸 많은 장 · 살피는 선비(考) = 吳崑 『醫方考』.
  - 한약 단지가 중심, 청진기 · 약병을 곁들임 = 張錫純 『醫學衷中參西錄』.
- 정거장 8 · 카드 6.
- 카드 의문: UHG-039 「700여 방제를 7門」 — 醫方考는 72門(540여 방)으로 알려짐. 정답해설 2차분 76번도 같은 7門. 글에서 대조로 남김.
- 바탕: Gemini 카본(높음). v1 → v2(버림: 농부가 그릇을 건넴) → v3(일꾼이 농부 머리 위로).
- 일치 검사: v3 ○ · △(땅 끝이 벼랑보다 갈라진 땅, 다리 당기기 안 보임 → 글 맞춤) + 사실 ✗1(7門) → 글 고침.
