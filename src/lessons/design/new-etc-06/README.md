- 장소: 탈춤 놀이마당. 탈 = 감정, 탈을 든 사람 = 그 감정의 臟(경락 인물: 장군 肝 · 임금 心 · 농부 脾 · 노인 肺 · 장사 腎).
- 그림과 뜻:
  - 줄의 탈 일곱 = 喜 · 怒 · 憂 · 思 · 悲 · 恐 · 驚 / 다섯이 든 탈 = 肝怒 · 心喜 · 脾思 · 肺憂(悲) · 腎恐.
  - 금 간 간 단지 · 심장 단지 = 喜怒不節則傷臟(靈樞 百病始生).
  - 가운데 줄 차례 노인(悲) → 장군(怒) → 농부(思) → 장사(恐) → 임금(喜) → 다시 노인 = 五志相勝(각자 오른쪽 이웃을 이김, 陰陽應象大論).

  - 쪼그라든 장군 겁 · 부푼 장군 고함 = 本神 肝氣虛則恐 · 實則怒.
  - 여윈 임금 · 빠진 머리털 · 짧은 초 = 心 怵惕思慮則傷神 → 恐懼自失 · 破䐃脫肉 · 毛悴色夭.
