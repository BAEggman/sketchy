- 그림과 뜻:
  - 달력 아래: 얼음 음료 · 끝으로 밀린 뜨거운 냄비 = 用熱遠熱 / 밀려난 아이스크림 · 온천 책자 = 用寒遠寒(六元正紀大論) · 必先歲氣 無伐天和(五常政大論) → 因時制宜.

  - 포스터: 고개 넘는 버스 = 其高者 因而越之(吐) · 수문 = 其下者 引而竭之 · 가방 풀기 = 中滿者 瀉之於內(其實者 散而瀉之) — 陰陽應象大論.
  - 그림판 여덟: 사우나 汗 · 양동이 吐 · 미끄럼틀 下 · 악수 和 · 난방기 溫 · 선풍기 淸 · 조각가 消 · 밥상 補(程鍾齡 醫學心悟).
