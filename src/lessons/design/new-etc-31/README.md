# new-etc-31 三焦辨證 — 上焦 肺·心包 → 中焦 胃燥·脾濕 → 下焦 腎·肝 — 설계·제작 기록 (2026-11-11)

- 장소: 양초 공방 — 焦(불에 그을림). 3단 큰 초가 위 칸부터 타 내려와 아래 칸에서 끝남. 칸 높이 = 上 · 中 · 下焦.
- 공용: 六經 패 · 노인 肺 · 요리사 胃 · 농부 脾 · 장사 腎 · 장군 肝 · 장갑 = 手經 · 장화 = 足經(etc-14). 이 과: 보라 천에 싸인 하트 = 心包.
- 그림과 뜻:
  - 위 칸(장갑, 반쯤 녹음): 기침하는 노인 · 보름달 = 手太陰肺 / 싸인 하트 · 검은 원 = 手厥陰心包 → 溫病의 시작처.
  - 가운데 칸(장화): 마른 바닥 요리사 · 해+초승달 = 足陽明胃 燥化 / 안개 속 농부 · 보름달 = 足太陰脾 濕化.
  - 흰 호랑이 = 胃熱 陽明(白虎 · 承氣) ↔ 안개 = 脾濕 太陰(濕溫).
  - 오후 해 창 · 짙어지는 김 = 濕溫 潮熱 身熱不揚 · 午後熱甚.
  - 아래 칸(장화): 장사 · 초승달 = 足少陰腎 / 장군 · 검은 원 = 足厥陰肝 → 溫病의 종점.
  - 촛농이 위 → 가운데 → 아래 = 順傳, 始上焦 終下焦(肺→心包는 逆傳).
