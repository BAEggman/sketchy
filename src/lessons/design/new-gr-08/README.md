- 장소: 여러 등산로가 모이는 산, 여덟 칸(2줄 × 4). 산 높이 = 몸 높이. mer-04(經 → 기관 환승역)의 짝으로, 여기서는 「기관 하나에 모이는 經들」을 본다.
- 칸별 뜻:
  - 꼭대기 물장수 · 장군 · 등뼈 지팡이 사내 = 巓頂 膀胱 · 肝 · 督.
  - 기슭에 앉은 노인 · 방패병 = 頭面 못 가는 肺 · 心包. 쌍안경 임금 = 心經 目系.
  - 입술 동굴 둘레의 요리사 · 장군 + 붉은 · 보라 줄 = 繞脣口 胃 · 肝 · 衝 · 督 · 任.
  - 목구멍 협곡: 바닥의 노인 · 장사 · 요리사 = 喉嚨 肺 · 腎 · 胃. 벼랑 위 농부 = 脾 挾咽. 건너편 먼 들판 장군 = 肝 喉嚨之後.
  - 골짜기 샘을 도는 장군 · 장사 = 繞陰器 肝 · 腎.
  - 장군의 길(부엌 → 재판관 → 노인) = 肝經 胃 · 膽 · 肺.
  - 물지게 장사의 길(장군 → 노인 → 임금) + 물기둥 = 腎經 膀胱 · 肝 · 肺 · 心, 水泛 凌心 射肺.
