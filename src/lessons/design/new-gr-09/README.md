# new-gr-09 유주 원문 식별 — 한 구절로 경 맞히기 — 설계·제작 기록 (2026-11-11)

- 장소: 열두 순례길 안내소의 아홉 칸(3 × 3) 안내 그림. 칸마다 거대한 회색 돌 조각상의 몸 부위 위를 경락 인물이 순례자처럼 걷는다. 길이 지나는 표지 하나로 經을 가린다.
- 칸별 뜻:
  - 아랫니 + 뼈 둘 문 = 大腸(合谷兩骨之間 · 入下齒中 · 交人中 · 挾鼻孔).
  - 입술 한 바퀴 → 머리털 따라 이마 + 발가락 사이 틈 = 胃(環脣 · 頰車 · 客主人 · 額顱 · 中指外間).
  - 어깨뼈 자리 꺾어 돌기 → 귀 속 = 小腸(繞肩胛 · 却入耳中).
  - 눈 안쪽 → 정수리 → 귀 윗끝 = 膀胱(目內眥 · 交巓 · 耳上角).
  - 귀 뒤 → 귀 윗끝 → 광대 = 三焦(繫耳後 · 出耳上角 · 屈下頰至顴).
  - 사다리 + 정수리 악수(등뼈 지팡이) = 肝(喉嚨之後 · 頏顙 · 目系 · 會於巓).
  - 혀뿌리 장사 = 腎(挾舌本). 혀 아래 씨앗 = 脾(連舌本 散舌下).
  - 누운 팔 세 길: 엄지 쪽 노인 肺(行少陰心主之前) · 가운데로 손바닥에 든 방패병 心包 · 새끼 쪽 쌍안경 임금 心(繫目系).
  - 대나무 묶음 · 빈 대롱 · 수레 · 코끝 흰 구슬 = 攢竹 眉本 · 絲竹空 眉梢 · 頰車 牙床 · 素髎 鼻準(頏顙 = 鼻咽).
- 정거장 13 · 카드 13. 칸 차례는 流注 차례가 아니라 문항 묶음 차례다.
