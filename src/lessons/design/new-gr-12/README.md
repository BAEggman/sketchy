# new-gr-12 奇經八脈 총론 — 여덟 이름 · 正經과 다른 점 · 넘치면 받는 저수 — 설계·제작 기록 (2026-11-11)

- 장소: 골짜기를 막은 댐과 저수지. 댐 앞 물줄기들 = 十二經, 댐 = 奇經八脈(溢蓄).
- 댐 위 관리인 일곱과 댐 허리 가죽 띠 = 여덟 이름.
  - 임신부 = 任(妊), 등뼈 지팡이 = 督, 물줄기를 타고 솟는 사내 = 衝.
  - 가죽 띠 = 帶, 달/해 배지 그물 = 陰維/陽維, 달/해 배지 장대 = 陰蹻/陽蹻.
- 관제실의 뾰족 모자 노학자와 두꺼운 책 = 難經이 奇經八脈을 이름 지어 정리했다(內經엔 개별 脈만).
- 볼트 박힌 두 관 = 任 · 督만 제 穴. 민짜 관 = 나머지는 他經 穴 차용. 관 개수는 세지 않는다(그림의 관은 8개).
- 선 관들과 가로 띠 = 대부분 縱行, 帶脈만 橫行. 꼭대기에서 끝나는 관 = 如環無端 순환 없음. 임신부 = 奇恒之府 胞宮.
- 펌프가 넘친 물을 빨아 관으로 호수에 올림 · 수문이 마른 물길에 물을 쏟음 = 溢蓄 · 滲灌. 任 = 陰脈之海, 督 = 陽脈之海.
- 정거장 8 · 카드 8.
- 바탕 이력:
  - v1: 첫 생성. 왼쪽 수로의 물 방향이 모호함.
  - v2: 편집으로 펌프를 더함.
  - v3: 편집으로 흡입 호스를 더함. 수로 끝의 떨어지는 아치가 남음.
  - v4: 편집으로 열린 수로를 지우고 펌프 → 회색 관 → 호수로 바꿈. 덤 호스와 관 연장이 생김.
  - v5: 편집으로 덤 호스와 관 연장을 지움.
- 일치 검사: v3에서 ○3 · △3 · ✗1(물이 아래로 떨어짐). v4 재검사에서 △2. v5에서 덤 호스와 관 연장을 지웠다.
- 교훈:
  - 「물을 퍼 올림」 같은 방향은 열린 물길로 그리면 거꾸로 읽힌다. 닫힌 관 + 펌프 + 위 끝 물보라로 그린다.
