# new-gr-13 任 · 督 · 衝 — 一源三岐, 胞中 한 샘에서 세 갈래 — 설계·제작 기록 (2026-11-11)

- 장소: 세 갈래 분수 광장. 왼쪽 큰 칸에 무릎 꿇은 돌 조각상(옆모습), 오른쪽에 작은 칸 셋.
- 한 샘에서 세 줄기:
  - 아랫배 앞의 분홍 그릇 하나 = 胞中, 一源三岐.
  - 파랑 = 督. 꼬리뼈 → 등 → 정수리 구멍(入屬於腦) → 얼굴 앞. 등의 금빛 해 = 陽脈之海. 곁의 장사 = 腎.
  - 하양 = 任. 몸 앞 → 턱 아래(承漿). 곁의 임신부 = 任主胞胎 · 陰脈之海.
  - 빨강 = 衝. 그릇에서 솟아 터져 둘레 잔들로 = 血海 · 十二經脈之海 · 五臟六腑之海.
- 주사위(코드): 2 · 8 = 督 28穴, 2 · 4 = 任 24穴, 1 · 2 = 衝 12穴(氣衝 ~ 幽門).
- 작은 칸 셋:
  - 문 속 불에 손 쬐는 농부 + 흙 화분 새싹 = 命門 益火生土.
  - 치솟는 붉은 물 곁 배 움켜쥔 남자 = 衝 逆氣裏急.
  - 달 아래 붉은 못 뒤 다섯(임금 · 장군 · 농부 · 장사 · 임신부) = 月經은 心 · 肝 · 脾 · 腎 + 衝 · 任.
