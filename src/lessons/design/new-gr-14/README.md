# new-gr-14 帶 · 維 · 蹻 — 허리띠 · 그물 벼리 · 죽마 — 설계·제작 기록 (2026-11-11)

- 장소: 서커스 천막. new-gr-12 댐의 관리인 상징을 그대로 씀(띠 = 帶, 달/해 그물 = 陰維/陽維, 달/해 죽마 = 陰蹻/陽蹻).
- 帶:
  - 천막에서 곧게 내려온 리본을 곡예사 허리의 가죽 띠가 묶음 = 유일한 橫行 · 約束諸脈.
  - 처진 흰 가닥 = 帶下.
  - 징 셋 + 버클 채우는 초록 옷 재판관 = 膽經 帶脈 · 五樞 · 維道.
- 維:
  - 링 안쪽 무리를 감싼 남색 그물 + 가슴 통증(달) = 陰維 維絡諸陰 · 主裏 · 屬營 · 苦心痛.
  - 링 바깥 금빛 그물 + 갈색 개(해) = 陽維 維絡諸陽 · 主表 · 屬衛.
- 蹻: 죽마 광대 — 해 = 눈 뜸(寤), 달 = 눈 감고 잠(寐) = 眼瞼 開闔 · 下肢 운동 · 主一身之動靜. 陽蹻 申脈 → 風府, 陰蹻 然谷 → 睛明.
