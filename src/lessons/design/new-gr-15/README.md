- 標本 · 根結:
  - 안개 퍼지는 우듬지 = 標(經氣 확산). 금빛 수액 고인 밑동 혹 = 本(凝聚).

- 四海:
  - 머리 항아리 뽀얀 물 = 髓海 腦.
  - 풍선 구멍 = 氣海 膻中. 밖에서 펌프질하는 노인 = 肺는 氣之本.
  - 죽솥과 요리사 = 水穀之海 胃.
  - 붉은 못과 분수 = 血海 衝脈.
