# new-gr-16 合과 會 — 五輸 主治 · 下合穴(合治內府) · 交會穴 — 설계·제작 기록 (2026-11-11)

- 장소: 交會 예배당 단면. 위 스테인드글라스 다섯, 가운데 의자 넷, 아래 지하 合唱실.
- 五輸 主治(難經 68難): 우물 心下滿 · 시내 身熱 · 폭포 體重節痛 · 강 喘咳寒熱 · 바다 逆氣而泄. 물길은 mer-05의 五輸 물길 상징이다.
- 지하(下) 合唱(合) = 下合穴, 合治內府. 노란 카펫(胃經) 위에 요리사 足三里, 흰 작업복 上巨虛(大腸), 붉은 앞치마 下巨虛(小腸).
- 交會穴 의자:
  - 농부 · 장군 · 장사 = 三陰交.
  - 임신부를 더한 넷 = 關元.
  - 등뼈 지팡이 + 해 배지 여섯 = 大椎 諸陽之會. 가장 솟은 등뼈 마디 아래 = C7 아래.
  - 눈 창 곁 다섯(물장수 · 붉은 앞치마 · 요리사 · 달 · 해 죽마) = 睛明.
- 정거장 10 · 카드 8.
