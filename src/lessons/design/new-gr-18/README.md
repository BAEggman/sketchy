# new-gr-18 刺法 — 巨刺 · 繆刺 · 迎隨補瀉 · 九鍼 · 得氣 — 설계·제작 기록 (2026-11-11)

- 장소: 펜싱 경기장 다섯 칸. 刺 = 찌르기.
- 칸별 뜻:
  - 굵은 파란 선 슈트, 왼 어깨가 아프고 오른쪽 선 쪽을 찌름 = 巨刺(經脈 좌우 교차).
  - 붉은 실그물 슈트, 왼 어깨가 아프고 오른쪽 아래를 찌름 = 繆刺(絡脈 좌우 + 上下 교차). GRG-022 약점: 繆 = 絡, 巨 = 經.
  - 풍선 컨베이어 = 迎隨補瀉. 뒤따르며 밀어 부풂 = 隨 補. 맞받아 찔러 터뜨림 = 迎 瀉.
  - 피 맺힌 세모 날 침 = 鋒鍼(三稜鍼, 瀉血 · 癰腫 · 熱病). 둥근 끝으로 누름 = 鍉鍼(按脈勿陷 以致其氣).
  - 레몬 · 불꽃 · 쇠추 · 부푼 팔 = 得氣 酸 · 痲 · 重 · 脹.
- 정거장 7 · 카드 9.
