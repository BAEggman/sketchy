# new-gr-19 舍岩 ① 手太陰肺經 — 正格 · 勝格 · 寒格 · 熱格 설계서

## 1. 장소와 구역 배치 (16:9, 왼쪽 → 오른쪽)
- **장소**: 바위에 기댄 초가 1번 방(흰 수염 노인의 肺經 처방방) — `mer-11`의 바위 초가 찬장 문법과 `mer-12`의 화로·물통 문법을 한 방에 결합하고, 사용자의 암기 문장(「태백산의 태연이가 어제 소부산으로 갔다」 / 「어제 소부친 걸 보니 음곡에서 척택을 사라지게 해야겠다」)을 구체적 사물로 시각화.
- **가운데 주인공**: 흰 도포에 긴 흰 수염을 한 노인(肺 정본 인물).
- **구역 1 (왼쪽 · 正格 3단 찬장: 補母瀉官)**:
  - **위 칸 (母 = 土 · 補 = 물이 가득 찬 독 둘)**:
    - 첫째 독 위: 눈 덮인 하얀 산봉우리 모형(**太白** = 태백산, 脾經 土)
    - 둘째 독 위: 깊은 돌 우물 모형(**太淵** = 태연, 肺經 土·原穴)
  - **가운데 칸 (官 = 火 · 瀉 = 엎어져 쏟아진 독 둘)**:
    - 첫째 쏟아진 독 옆: 붉은 기와를 얹은 작은 관청 현판집 모형(**少府** = 소부, 心經 火)
    - 둘째 쏟아진 독 옆: 도마 위에 놓인 붉은 물고기 배지느러미 가장자리(**魚際** = 어제, 肺經 火)
  - **아래 칸 (子 = 水)**: 뚜껑 덮인 독 둘
- **구역 2 (가운데 오른쪽 · 勝格 3단 찬장: 補官瀉子)**:
  - **위 칸 (母 = 土)**: 뚜껑 덮인 독 둘
  - **가운데 칸 (官 = 火 · 補 = 물이 가득 찬 독 둘)**:
    - 작은 관청 모형(**少府**)과 물고기 배 가장자리(**魚際**)가 이번에는 물이 가득 찬 독 위에 놓임(正格의 瀉가 곧 勝格의 補)
  - **아래 칸 (子 = 水 · 瀉 = 엎어져 쏟아진 독 둘)**:
    - 첫째 쏟아진 독 옆: 대나무 자(尺)가 꽂힌 연못 모형(**尺澤** = 척택, 肺經 水)
    - 둘째 쏟아진 독 옆: 초승달 그늘이 드리운 바위 골짜기 모형(**陰谷** = 음곡, 腎經 水)
- **구역 3 (오른쪽 · 寒格 화로와 熱格 물통·흙더미)**:
  - **위쪽 (寒格 = 補火瀉水)**: 눈 내리는 작은 창 아래, 활활 타는 화로(補火 = **少府·魚際**)와 밖으로 물을 퍼 버리는 물통(瀉水 = **尺澤·陰谷**)
  - **아래쪽 (熱格 = 補水瀉土)**: 해 뜬 작은 창 아래, 주전자로 물을 가득 붓는 물통(補水 = **尺澤·陰谷**)과 삽으로 퍼내는 누런 흙더미(瀉土 = **太白·太淵**)
  - 노인 허리춤에 찬 벼락 모양 열쇠고리(표리 짝 大腸經 絡穴 **偏歷** — 主客原絡법 `太淵 + 偏歷`)

  - `초승달 그늘 골짜기 모형` = 陰谷
