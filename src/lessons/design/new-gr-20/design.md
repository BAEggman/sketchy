## 정거장 매핑

### #1. 大腸 正格 補(母=土) = 足三里 · 曲池 — 삼리 걸어 꼭지가 돎
- **물건**: 왼쪽 正格 찬장 위 칸(母) 물이 가득 찬 독 둘 — 삼지창(3) 이정표가 선 고갯길(족삼리) · 구부러진 연못(곡지)
- **고리**: 왼쪽 위 칸 채운 독 = 正格 補母 · 삼지창(3) 이정표가 선 고갯길(족삼리) / 구부러진 연못(곡지)
### #2. 大腸 正格 瀉(官=火) = 陽谷 · 陽谿 — 양계장의 양곡 바닥
- **물건**: 왼쪽 正格 찬장 가운데 칸(官) 엎어져 쏟아진 독 둘 — 해 비치는 밝은 골짜기(양곡) · 해 비치는 시냇물(양계)
- **고리**: 왼쪽 가운데 칸 쏟은 독 = 正格 瀉官 · 해 비치는 밝은 골짜기(양곡) / 해 비치는 시냇물(양계)
### #3. 大腸 勝格 補(官=火) = 陽谷 · 陽谿 / 瀉(子=水) = 二間 · 足通谷
- **물건**: 오른쪽 勝格 찬장 가운데 칸(官) 물이 가득 찬 독 둘 — 해 비치는 밝은 골짜기(양곡) · 해 비치는 시냇물(양계)
- **고리**: 오른쪽 가운데 칸 채운 독 = 勝格 補官 (正格의 瀉와 같은 두 혈)
### #4. 大腸 寒格(補火瀉水) = 補 陽谷·陽谿 / 瀉 二間·足通谷 (★解谿 아님)
- **물건**: 눈 오는 창 아래 풀무로 불 키운 화로(補火)와 밖으로 물 퍼내는 물통(瀉水) — 해 비치는 밝은 골짜기(양곡) · 해 비치는 시냇물(양계) · 이층 버스(2) 사이 틈새(이간) · 시원하게 뚫린 골짜기(족통곡)
- **고리**: 화로 불 키움 = 補火 · 물통 물 퍼내기 = 瀉水
### #5. 大腸 熱格(補水瀉火) = 補 二間·足通谷 / 瀉 陽谷·陽谿 (★瀉火 3경 중 하나)
- **물건**: 해 뜬 창 아래 주전자로 물 붓는 물통(補水)과 퍼내는 흙/숯불(瀉) — 해 비치는 밝은 골짜기(양곡) · 해 비치는 시냇물(양계) · 이층 버스(2) 사이 틈새(이간) · 시원하게 뚫린 골짜기(족통곡)
- **고리**: 물통 물 붓기 = 補水(寒格의 瀉와 같음) · 흙/불 퍼내기 = 瀉土(또는 瀉火)
### #6. 大腸 自經補瀉(虛 補曲池 / 實 瀉二間) · 主客原絡(主 合谷 / 客 列缺)
- **물건**: 가운데 선 흰 작업복이(가) 쥔 제 경 오수혈 모형과 표리 짝 락혈 패
- **고리**: 제 경 안에서만 보사 = 自經補瀉 · 본경 原穴 + 표리경 絡穴 = 主客原絡
