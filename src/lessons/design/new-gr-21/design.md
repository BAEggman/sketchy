# new-gr-21 舍岩 ③ 足陽明胃經 — 正格 · 勝格 · 寒格 · 熱格 — Carbon v7 설계서

- **장소**: 바위 초가 3번 방(노란 요리사 방) — 舍岩 胃經 처방방
- **정거장 수**: 8

## 정거장 매핑

### #1. 胃 正格 補(母=火) = 解谿 · 陽谷 — 양곡가의 해계모니
- **물건**: 왼쪽 正格 찬장 위 칸(母) 물이 가득 찬 독 둘 — 해 비치는 밝은 골짜기(양곡) · 풀어진 신발 끈 옆 시내(해계)
- **고리**: 왼쪽 위 칸 채운 독 = 正格 補母 · 해 비치는 밝은 골짜기(양곡) / 풀어진 신발 끈 옆 시내(해계)
### #2. 胃 正格 瀉(官=木) = 陷谷 · 足臨泣 — 함곡령 떨어져 임읍막음
- **물건**: 왼쪽 正格 찬장 가운데 칸(官) 엎어져 쏟아진 독 둘 — 움푹 꺼진 함정 골짜기(함곡) · 눈물 방울이 맺힌 언덕(족임읍)
- **고리**: 왼쪽 가운데 칸 쏟은 독 = 正格 瀉官 · 움푹 꺼진 함정 골짜기(함곡) / 눈물 방울이 맺힌 언덕(족임읍)
### #3. 胃 勝格 補(官=木) = 陷谷 · 足臨泣 / 瀉(子=金) = 厲兌 · 商陽(商丘)
- **물건**: 오른쪽 勝格 찬장 가운데 칸(官) 물이 가득 찬 독 둘 — 움푹 꺼진 함정 골짜기(함곡) · 눈물 방울이 맺힌 언덕(족임읍)
- **고리**: 오른쪽 가운데 칸 채운 독 = 勝格 補官 (正格의 瀉와 같은 두 혈)
### #4. 胃 寒格(補火瀉水) = 補 解谿·陽谷 / 瀉 內庭·足通谷
- **물건**: 눈 오는 창 아래 풀무로 불 키운 화로(補火)와 밖으로 물 퍼내는 물통(瀉水) — 해 비치는 밝은 골짜기(양곡) · 시원하게 뚫린 골짜기(족통곡) · 풀어진 신발 끈 옆 시내(해계)
- **고리**: 화로 불 키움 = 補火 · 물통 물 퍼내기 = 瀉水
### #5. 胃 熱格(補水瀉土) = 補 內庭·足通谷 / 瀉 足三里·委中
- **물건**: 해 뜬 창 아래 주전자로 물 붓는 물통(補水)과 퍼내는 흙/숯불(瀉) — 삼지창(3) 이정표가 선 고갯길(족삼리) · 시원하게 뚫린 골짜기(족통곡) · 굽힌 오금 한가운데(위중)
- **고리**: 물통 물 붓기 = 補水(寒格의 瀉와 같음) · 흙/불 퍼내기 = 瀉土(또는 瀉火)
### #6. 胃 自經補瀉(虛 補解谿 / 實 瀉厲兌) · 主客原絡(主 衝陽 / 客 公孫)
- **물건**: 가운데 선 노란 요리사이(가) 쥔 제 경 오수혈 모형과 표리 짝 락혈 패
- **고리**: 제 경 안에서만 보사 = 自經補瀉 · 본경 原穴 + 표리경 絡穴 = 主客原絡
