- **정거장 수**: 8

## 정거장 매핑

### #1. 脾 正格 補(母=火) = 大都 · 少府 — 소부에서 대도로
- **물건**: 왼쪽 正格 찬장 위 칸(母) 물이 가득 찬 독 둘 — 작은 붉은 기와 관청(소부) · 큰 성문 도읍지 모형(대도)
- **고리**: 왼쪽 위 칸 채운 독 = 正格 補母 · 작은 붉은 기와 관청(소부) / 큰 성문 도읍지 모형(대도)
### #2. 脾 正格 瀉(官=木) = 隱白 · 大敦 — 대돈 주고 은백색 말
- **물건**: 왼쪽 正格 찬장 가운데 칸(官) 엎어져 쏟아진 독 둘 — 두툼한 큰 돈주머니와 언덕(대돈) · 숨겨진 흰 은백색 말(은백)
- **고리**: 왼쪽 가운데 칸 쏟은 독 = 正格 瀉官 · 두툼한 큰 돈주머니와 언덕(대돈) / 숨겨진 흰 은백색 말(은백)
### #3. 脾 勝格 補(官=木) = 隱白 · 大敦 / 瀉(子=金) = 商丘 · 經渠
- **물건**: 오른쪽 勝格 찬장 가운데 칸(官) 물이 가득 찬 독 둘 — 봇짐 상인이 오른 언덕(상구) · 두툼한 큰 돈주머니와 언덕(대돈)
- **고리**: 오른쪽 가운데 칸 채운 독 = 勝格 補官 (正格의 瀉와 같은 두 혈)
### #4. 脾 寒格(補火瀉水) = 補 大都·少府 / 瀉 陰陵泉·陰谷
- **물건**: 눈 오는 창 아래 풀무로 불 키운 화로(補火)와 밖으로 물 퍼내는 물통(瀉水) — 작은 붉은 기와 관청(소부) · 초승달 그늘이 진 어두운 골짜기(음곡) · 큰 성문 도읍지 모형(대도) · 그늘 언덕 아래 솟는 샘(음릉천)
- **고리**: 화로 불 키움 = 補火 · 물통 물 퍼내기 = 瀉水
### #5. 脾 熱格(補水瀉土) = 補 陰陵泉·陰谷 / 瀉 太白·太谿
- **물건**: 해 뜬 창 아래 주전자로 물 붓는 물통(補水)과 퍼내는 흙/숯불(瀉) — 눈 덮인 하얀 산봉우리(태백산) · 초승달 그늘이 진 어두운 골짜기(음곡) · 그늘 언덕 아래 솟는 샘(음릉천) · 큰 시냇물과 퇴계 선생 패(태계)
- **고리**: 물통 물 붓기 = 補水(寒格의 瀉와 같음) · 흙/불 퍼내기 = 瀉土(또는 瀉火)
### #6. 脾 自經補瀉(虛 補大都 / 實 瀉商丘) · 主客原絡(主 太白 / 客 豊隆)
- **물건**: 가운데 선 노란 농부이(가) 쥔 제 경 오수혈 모형과 표리 짝 락혈 패
- **고리**: 제 경 안에서만 보사 = 自經補瀉 · 본경 原穴 + 표리경 絡穴 = 主客原絡
