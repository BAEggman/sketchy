## 정거장 매핑

### #1. 小腸 正格 補(母=木) = 後谿 · 足臨泣 — 후계자 임읍막음
- **물건**: 왼쪽 正格 찬장 위 칸(母) 물이 가득 찬 독 둘 — 눈물 방울이 맺힌 언덕(족임읍) · 뒤편으로 흐르는 시내(후계)
- **고리**: 왼쪽 위 칸 채운 독 = 正格 補母 · 눈물 방울이 맺힌 언덕(족임읍) / 뒤편으로 흐르는 시내(후계)
### #2. 小腸 正格 瀉(官=水) = 前谷 · 足通谷 — 전곡 사람들 통곡
- **물건**: 왼쪽 正格 찬장 가운데 칸(官) 엎어져 쏟아진 독 둘 — 시원하게 뚫린 골짜기(족통곡) · 앞쪽에 열린 골짜기(전곡)
- **고리**: 왼쪽 가운데 칸 쏟은 독 = 正格 瀉官 · 시원하게 뚫린 골짜기(족통곡) / 앞쪽에 열린 골짜기(전곡)
### #3. 小腸 勝格 補(官=水) = 前谷 · 足通谷 / 瀉(子=土) = 小海 · 足三里
- **물건**: 오른쪽 勝格 찬장 가운데 칸(官) 물이 가득 찬 독 둘 — 삼지창(3) 이정표가 선 고갯길(족삼리) · 시원하게 뚫린 골짜기(족통곡)
- **고리**: 오른쪽 가운데 칸 채운 독 = 勝格 補官 (正格의 瀉와 같은 두 혈)
### #4. 小腸 寒格(補火瀉水) = 補 陽谷·崑崙 / 瀉 前谷·足通谷 (★寒格에서 小腸=膀胱 동일)
- **물건**: 눈 오는 창 아래 풀무로 불 키운 화로(補火)와 밖으로 물 퍼내는 물통(瀉水) — 해 비치는 밝은 골짜기(양곡) · 시원하게 뚫린 골짜기(족통곡) · 앞쪽에 열린 골짜기(전곡) · 높고 험한 곤륜산 봉우리(곤륜)
- **고리**: 화로 불 키움 = 補火 · 물통 물 퍼내기 = 瀉水
### #5. 小腸 熱格(補水瀉土) = 補 前谷·足通谷 / 瀉 小海·足三里
- **물건**: 해 뜬 창 아래 주전자로 물 붓는 물통(補水)과 퍼내는 흙/숯불(瀉) — 삼지창(3) 이정표가 선 고갯길(족삼리) · 시원하게 뚫린 골짜기(족통곡) · 앞쪽에 열린 골짜기(전곡) · 붉은 체가 뜬 작은 바다(소장소해)
- **고리**: 물통 물 붓기 = 補水(寒格의 瀉와 같음) · 흙/불 퍼내기 = 瀉土(또는 瀉火)
### #6. 小腸 自經補瀉(虛 補後谿 / 實 瀉小海) · 主客原絡(主 腕骨 / 客 通里)
- **물건**: 가운데 선 붉은 앞치마이(가) 쥔 제 경 오수혈 모형과 표리 짝 락혈 패
- **고리**: 제 경 안에서만 보사 = 自經補瀉 · 본경 原穴 + 표리경 絡穴 = 主客原絡
