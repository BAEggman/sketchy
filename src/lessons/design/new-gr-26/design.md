## 정거장 매핑

### #1. 腎 正格 補(母=金) = 復溜 · 經渠 — 경거망동 복류이크댄스
- **물건**: 왼쪽 正格 찬장 위 칸(母) 물이 가득 찬 독 둘 — 곧게 판 물길 도랑(경거) · 되돌아 흐르는 물줄기(복류)
- **고리**: 왼쪽 위 칸 채운 독 = 正格 補母 · 곧게 판 물길 도랑(경거) / 되돌아 흐르는 물줄기(복류)
### #2. 腎 正格 瀉(官=土) = 太谿 · 太白 — 태백산 태계 선생님 꾸중
- **물건**: 왼쪽 正格 찬장 가운데 칸(官) 엎어져 쏟아진 독 둘 — 눈 덮인 하얀 산봉우리(태백산) · 큰 시냇물과 퇴계 선생 패(태계)
- **고리**: 왼쪽 가운데 칸 쏟은 독 = 正格 瀉官 · 눈 덮인 하얀 산봉우리(태백산) / 큰 시냇물과 퇴계 선생 패(태계)
### #3. 腎 勝格 補(官=土) = 太谿 · 太白 / 瀉(子=木) = 湧泉 · 大敦
- **물건**: 오른쪽 勝格 찬장 가운데 칸(官) 물이 가득 찬 독 둘 — 눈 덮인 하얀 산봉우리(태백산) · 두툼한 큰 돈주머니와 언덕(대돈)
- **고리**: 오른쪽 가운데 칸 채운 독 = 勝格 補官 (正格의 瀉와 같은 두 혈)
### #4. 腎 寒格(補火瀉水) = 補 少府·然谷 / 瀉 陰谷·少海 (★心 寒格과 동일)
- **물건**: 눈 오는 창 아래 풀무로 불 키운 화로(補火)와 밖으로 물 퍼내는 물통(瀉水) — 작은 붉은 기와 관청(소부) · 초승달 그늘이 진 어두운 골짜기(음곡) · 작은 금관이 뜬 바닷물(심소해) · 불타는 골짜기 바위(연곡)
- **고리**: 화로 불 키움 = 補火 · 물통 물 퍼내기 = 瀉水
### #5. 腎 熱格(補水瀉土) = 補 陰谷·少海 / 瀉 太白·太谿
- **물건**: 해 뜬 창 아래 주전자로 물 붓는 물통(補水)과 퍼내는 흙/숯불(瀉) — 눈 덮인 하얀 산봉우리(태백산) · 초승달 그늘이 진 어두운 골짜기(음곡) · 큰 시냇물과 퇴계 선생 패(태계) · 작은 금관이 뜬 바닷물(심소해)
- **고리**: 물통 물 붓기 = 補水(寒格의 瀉와 같음) · 흙/불 퍼내기 = 瀉土(또는 瀉火)
### #6. 腎 自經補瀉(虛 補復溜 / 實 瀉湧泉) · 主客原絡(主 太谿 / 客 飛揚)
- **물건**: 가운데 선 대머리 장사이(가) 쥔 제 경 오수혈 모형과 표리 짝 락혈 패
- **고리**: 제 경 안에서만 보사 = 自經補瀉 · 본경 原穴 + 표리경 絡穴 = 主客原絡
