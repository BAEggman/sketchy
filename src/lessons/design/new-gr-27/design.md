## 정거장 매핑

### #1. 心包 正格 補(母=木) = 中衝 · 大敦 — 대돈 주고 중고 충전기
- **물건**: 왼쪽 正格 찬장 위 칸(母) 물이 가득 찬 독 둘 — 두툼한 큰 돈주머니와 언덕(대돈) · 가운데로 솟구치는 창끝(중충)
- **고리**: 왼쪽 위 칸 채운 독 = 正格 補母 · 두툼한 큰 돈주머니와 언덕(대돈) / 가운데로 솟구치는 창끝(중충)
### #2. 心包 正格 瀉(官=水) = 曲澤 · 陰谷 — 음곡에서 곡택 소리
- **물건**: 왼쪽 正格 찬장 가운데 칸(官) 엎어져 쏟아진 독 둘 — 초승달 그늘이 진 어두운 골짜기(음곡) · 굽이진 얕은 못(곡택)
- **고리**: 왼쪽 가운데 칸 쏟은 독 = 正格 瀉官 · 초승달 그늘이 진 어두운 골짜기(음곡) / 굽이진 얕은 못(곡택)
### #3. 心包 勝格 補(官=水) = 曲澤 · 陰谷 / 瀉(子=土) = 大陵 · 太白
- **물건**: 오른쪽 勝格 찬장 가운데 칸(官) 물이 가득 찬 독 둘 — 눈 덮인 하얀 산봉우리(태백산) · 초승달 그늘이 진 어두운 골짜기(음곡)
- **고리**: 오른쪽 가운데 칸 채운 독 = 勝格 補官 (正格의 瀉와 같은 두 혈)
### #4. 心包 寒格(補火瀉水) = 補 少府·勞宮 / 瀉 曲澤·少海
- **물건**: 눈 오는 창 아래 풀무로 불 키운 화로(補火)와 밖으로 물 퍼내는 물통(瀉水) — 작은 붉은 기와 관청(소부) · 작은 금관이 뜬 바닷물(심소해) · 굽이진 얕은 못(곡택) · 일꾼들이 땀 흘리는 궁전(노궁)
- **고리**: 화로 불 키움 = 補火 · 물통 물 퍼내기 = 瀉水
### #5. 心包 熱格(補水瀉土) = 補 曲澤·少海 / 瀉 太白·大陵
- **물건**: 해 뜬 창 아래 주전자로 물 붓는 물통(補水)과 퍼내는 흙/숯불(瀉) — 눈 덮인 하얀 산봉우리(태백산) · 작은 금관이 뜬 바닷물(심소해) · 굽이진 얕은 못(곡택) · 크고 높은 구릉 언덕(대릉)
- **고리**: 물통 물 붓기 = 補水(寒格의 瀉와 같음) · 흙/불 퍼내기 = 瀉土(또는 瀉火)
### #6. 心包 自經補瀉(虛 補中衝 / 實 瀉大陵) · 主客原絡(主 大陵 / 客 外關)
- **물건**: 가운데 선 붉은 호위무사이(가) 쥔 제 경 오수혈 모형과 표리 짝 락혈 패
- **고리**: 제 경 안에서만 보사 = 自經補瀉 · 본경 原穴 + 표리경 絡穴 = 主客原絡
