## 정거장 매핑

### #1. 三焦 正格 補(母=木) = 中渚 · 足臨泣 — 임읍막음 중저가 폰
- **물건**: 왼쪽 正格 찬장 위 칸(母) 물이 가득 찬 독 둘 — 눈물 방울이 맺힌 언덕(족임읍) · 강 한가운데 작은 모래섬(중저)
- **고리**: 왼쪽 위 칸 채운 독 = 正格 補母 · 눈물 방울이 맺힌 언덕(족임읍) / 강 한가운데 작은 모래섬(중저)
### #2. 三焦 正格 瀉(官=水) = 液門 · 足通谷 — 액문 앞에서 통곡
- **물건**: 왼쪽 正格 찬장 가운데 칸(官) 엎어져 쏟아진 독 둘 — 시원하게 뚫린 골짜기(족통곡) · 물방울이 흐르는 수문(액문)
- **고리**: 왼쪽 가운데 칸 쏟은 독 = 正格 瀉官 · 시원하게 뚫린 골짜기(족통곡) / 물방울이 흐르는 수문(액문)
### #3. 三焦 勝格 補(官=水) = 液門 · 足通谷 / 瀉(子=土) = 天井 · 足三里
- **물건**: 오른쪽 勝格 찬장 가운데 칸(官) 물이 가득 찬 독 둘 — 삼지창(3) 이정표가 선 고갯길(족삼리) · 시원하게 뚫린 골짜기(족통곡)
- **고리**: 오른쪽 가운데 칸 채운 독 = 勝格 補官 (正格의 瀉와 같은 두 혈)
### #4. 三焦 寒格(補火瀉水) = 補 支溝·崑崙 / 瀉 液門·足通谷
- **물건**: 눈 오는 창 아래 풀무로 불 키운 화로(補火)와 밖으로 물 퍼내는 물통(瀉水) — 시원하게 뚫린 골짜기(족통곡) · 높고 험한 곤륜산 봉우리(곤륜) · 물방울이 흐르는 수문(액문) · 갈라진 좁은 도랑(지구)
- **고리**: 화로 불 키움 = 補火 · 물통 물 퍼내기 = 瀉水
### #5. 三焦 熱格(補水瀉火) = 補 液門·足通谷 / 瀉 支溝·崑崙 (★瀉火 3경 중 하나)
- **물건**: 해 뜬 창 아래 주전자로 물 붓는 물통(補水)과 퍼내는 흙/숯불(瀉) — 시원하게 뚫린 골짜기(족통곡) · 높고 험한 곤륜산 봉우리(곤륜) · 물방울이 흐르는 수문(액문) · 갈라진 좁은 도랑(지구)
- **고리**: 물통 물 붓기 = 補水(寒格의 瀉와 같음) · 흙/불 퍼내기 = 瀉土(또는 瀉火)
### #6. 三焦 自經補瀉(虛 補中渚 / 實 瀉天井) · 主客原絡(主 陽池 / 客 內關)
- **물건**: 가운데 선 주황 일꾼이(가) 쥔 제 경 오수혈 모형과 표리 짝 락혈 패
- **고리**: 제 경 안에서만 보사 = 自經補瀉 · 본경 原穴 + 표리경 絡穴 = 主客原絡
