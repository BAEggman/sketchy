## 정거장 매핑

### #1. 膽 正格 補(母=水) = 俠谿 · 足通谷 — 통곡하는 협계
- **물건**: 왼쪽 正格 찬장 위 칸(母) 물이 가득 찬 독 둘 — 시원하게 뚫린 골짜기(족통곡) · 양쪽 바위가 좁은 시내(협계)
- **고리**: 왼쪽 위 칸 채운 독 = 正格 補母 · 시원하게 뚫린 골짜기(족통곡) / 양쪽 바위가 좁은 시내(협계)
### #2. 膽 正格 瀉(官=金) = 足竅陰 · 商陽 — 상양한 척 규음
- **물건**: 왼쪽 正格 찬장 가운데 칸(官) 엎어져 쏟아진 독 둘 — 볕 아래 봇짐 상인(상양) · 그늘진 작은 구멍(족규음)
- **고리**: 왼쪽 가운데 칸 쏟은 독 = 正格 瀉官 · 볕 아래 봇짐 상인(상양) / 그늘진 작은 구멍(족규음)
### #3. 膽 勝格 補(官=金) = 足竅陰 · 商陽 / 瀉(子=火) = 陽輔 · 陽谷
- **물건**: 오른쪽 勝格 찬장 가운데 칸(官) 물이 가득 찬 독 둘 — 해 비치는 밝은 골짜기(양곡) · 볕 아래 봇짐 상인(상양)
- **고리**: 오른쪽 가운데 칸 채운 독 = 勝格 補官 (正格의 瀉와 같은 두 혈)
### #4. 膽 寒格(補火瀉水) = 補 陽輔·陽谷 / 瀉 俠谿·足通谷
- **물건**: 눈 오는 창 아래 풀무로 불 키운 화로(補火)와 밖으로 물 퍼내는 물통(瀉水) — 해 비치는 밝은 골짜기(양곡) · 시원하게 뚫린 골짜기(족통곡) · 양쪽 바위가 좁은 시내(협계) · 해가 돕는 수레 덧방나무(양보)
- **고리**: 화로 불 키움 = 補火 · 물통 물 퍼내기 = 瀉水
### #5. 膽 熱格(補水瀉土) = 補 俠谿·足通谷 / 瀉 委中·陽陵泉
- **물건**: 해 뜬 창 아래 주전자로 물 붓는 물통(補水)과 퍼내는 흙/숯불(瀉) — 시원하게 뚫린 골짜기(족통곡) · 굽힌 오금 한가운데(위중) · 양쪽 바위가 좁은 시내(협계) · 볕 드는 언덕 아래 샘(양릉천)
- **고리**: 물통 물 붓기 = 補水(寒格의 瀉와 같음) · 흙/불 퍼내기 = 瀉土(또는 瀉火)
### #6. 膽 自經補瀉(虛 補俠谿 / 實 瀉陽輔) · 主客原絡(主 丘墟 / 客 蠡溝)
- **물건**: 가운데 선 초록 판관이(가) 쥔 제 경 오수혈 모형과 표리 짝 락혈 패
- **고리**: 제 경 안에서만 보사 = 自經補瀉 · 본경 原穴 + 표리경 絡穴 = 主客原絡
