- **정거장 수**: 8

## 정거장 매핑

### #1. 肝 正格 補(母=水) = 曲泉 · 陰谷 — 음곡에서 곡천 번다
- **물건**: 왼쪽 正格 찬장 위 칸(母) 물이 가득 찬 독 둘 — 초승달 그늘이 진 어두운 골짜기(음곡) · 굽이쳐 솟는 샘물(곡천)
- **고리**: 왼쪽 위 칸 채운 독 = 正格 補母 · 초승달 그늘이 진 어두운 골짜기(음곡) / 굽이쳐 솟는 샘물(곡천)
### #2. 肝 正格 瀉(官=金) = 中封 · 經渠 — 중봉 군은 경거해야
- **물건**: 왼쪽 正格 찬장 가운데 칸(官) 엎어져 쏟아진 독 둘 — 곧게 판 물길 도랑(경거) · 가운데 봉인한 흙제단(중봉)
- **고리**: 왼쪽 가운데 칸 쏟은 독 = 正格 瀉官 · 곧게 판 물길 도랑(경거) / 가운데 봉인한 흙제단(중봉)
### #3. 肝 勝格 補(官=金) = 中封 · 經渠 / 瀉(子=火) = 行間 · 少府
- **물건**: 오른쪽 勝格 찬장 가운데 칸(官) 물이 가득 찬 독 둘 — 작은 붉은 기와 관청(소부) · 곧게 판 물길 도랑(경거)
- **고리**: 오른쪽 가운데 칸 채운 독 = 勝格 補官 (正格의 瀉와 같은 두 혈)
### #4. 肝 寒格(補火瀉水) = 補 行間·少府 / 瀉 陰谷·曲泉
- **물건**: 눈 오는 창 아래 풀무로 불 키운 화로(補火)와 밖으로 물 퍼내는 물통(瀉水) — 작은 붉은 기와 관청(소부) · 초승달 그늘이 진 어두운 골짜기(음곡) · 굽이쳐 솟는 샘물(곡천) · 나무 사이를 걸어가는 길(행간)
- **고리**: 화로 불 키움 = 補火 · 물통 물 퍼내기 = 瀉水
### #5. 肝 熱格(補水瀉土) = 補 陰谷·曲泉 / 瀉 太衝·太白
- **물건**: 해 뜬 창 아래 주전자로 물 붓는 물통(補水)과 퍼내는 흙/숯불(瀉) — 눈 덮인 하얀 산봉우리(태백산) · 초승달 그늘이 진 어두운 골짜기(음곡) · 굽이쳐 솟는 샘물(곡천) · 크게 솟구치는 길목(태충)
- **고리**: 물통 물 붓기 = 補水(寒格의 瀉와 같음) · 흙/불 퍼내기 = 瀉土(또는 瀉火)
### #6. 肝 自經補瀉(虛 補曲泉 / 實 瀉行間) · 主客原絡(主 太衝 / 客 光明)
- **물건**: 가운데 선 초록 장군이(가) 쥔 제 경 오수혈 모형과 표리 짝 락혈 패
- **고리**: 제 경 안에서만 보사 = 自經補瀉 · 본경 原穴 + 표리경 絡穴 = 主客原絡
