# new-gr-33 十六郄穴 ① 手六經 — 孔最 · 溫溜 · 陰郄 · 養老 · 郄門 · 會宗 설계서

## 1. 장소와 구역 배치 (16:9, 위층 3칸 · 아래층 3칸 바위 협곡의 갈라진 틈새)
- **장소**: 암벽 협곡 윗단 틈새 — 郄(틈 극)의 뜻 그대로, 바위 절벽에 깊게 갈라진 여섯 개의 바위 틈(구멍·협곡 틈새)마다 손 경락 정본 인물 여섯이 서서 급성병·출혈을 다스리는 혈명 상징물을 지니고 있음.
- **위 줄 왼쪽 (1번 바위 틈 · 手太陰肺經 郄穴 = 孔最 LU6)**:
  - 바위 틈 가장 꼭대기(最 = 가장 최)에 뚫린 둥근 큰 구멍(孔 = 구멍 공) 앞에서 **흰 도포 흰 수염 노인(肺)**이 붉은 피가 스미는 구멍을 막고 서 있음 → **孔最**(급성 해혈·천식)
- **위 줄 가운데 (2번 바위 틈 · 手陽明大腸經 郄穴 = 溫溜 LI7)**:
  - 바위 틈 사이로 김이 모락모락 나는 따뜻한(溫) 물줄기가 흘러내리는(溜) 온천 폭포 앞에서 **관 청소솔 든 흰 작업복 일꾼(大腸)**이 서 있음 → **溫溜**
- **위 줄 오른쪽 (3번 바위 틈 · 手少陰心經 郄穴 = 陰郄 HT6)**:
  - 초승달 그늘이 짙게 드리운 어두운(陰) 바위 틈(郄) 안에서 **작은 금관 쓴 붉은 용포 임금(心)**이 가슴을 짚고 서 있음 → **陰郄**(급성 심통·도한)
- **아래 줄 왼쪽 (4번 바위 틈 · 手太陽小腸經 郄穴 = 養老 SI6)**:
  - 바위 틈 앞 평상에서 **체 든 붉은 앞치마 일꾼(小腸)**이 지팡이 짚은 백발 할머니(老)에게 따뜻한 밥상을 바치며 공손히 봉양(養)하고 있음(할머니는 분홍 저고리 치마로 肺 흰 도포 노인과 구별) → **養老**
- **아래 줄 가운데 (5번 바위 틈 · 手厥陰心包經 郄穴 = 郄門 PC4)**:
  - 바위 틈(郄) 사이에 세워진 크고 붉은 두 짝 대문(門) 앞을 **칼·방패 든 붉은 갑옷 호위무사(心包)**가 지키고 서 있음 → **郄門**
- **아래 줄 오른쪽 (6번 바위 틈 · 手少陽三焦經 郄穴 = 會宗 TE7)**:
  - 바위 틈 처마에 걸린 큰 종갓집 구리 범종(宗) 앞에 여러 색 깃발이 한데 모여(會) 있고, **삽 멘 주황 옷 일꾼(三焦)**이 종 옆에 서 있음 → **會宗**
