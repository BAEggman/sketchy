## 정거장 매핑

### #1. 足陽明胃經 郄穴 = 梁丘(ST34) · 足太陰脾經 郄穴 = 地機(SP8)
- **물건**: 나무 들보 다리가 놓인 언덕(梁丘) · 땅 위에 놓인 베틀(地機)
- **고리**: 바위 틈(郄) + 나무 들보 다리가 놓인 언덕(梁丘) · 땅 위에 놓인 베틀(地機)
### #2. 足太陽膀胱經 郄穴 = 金門(BL63) · 足少陰腎經 郄穴 = 水泉(KI5)
- **물건**: 번쩍이는 황금 대문(金門) · 맑은 물이 솟는 바위 샘(水泉)
- **고리**: 바위 틈(郄) + 번쩍이는 황금 대문(金門) · 맑은 물이 솟는 바위 샘(水泉)
### #3. 足少陽膽經 郄穴 = 外丘(GB36) · 足厥陰肝經 郄穴 = 中都(LR6)
- **물건**: 바깥쪽으로 솟은 언덕(外丘) · 한가운데 세운 도읍 성루(中都)
- **고리**: 바위 틈(郄) + 바깥쪽으로 솟은 언덕(外丘) · 한가운데 세운 도읍 성루(中都)
### #4. 陽蹻脈 郄穴 = 跗陽(BL59) · 陰蹻脈 郄穴 = 交信(KI8)
- **물건**: 발등 위 해 문양 장대(跗陽) · 서로 편지를 주고받는 달 장대(交信)
- **고리**: 바위 틈(郄) + 발등 위 해 문양 장대(跗陽) · 서로 편지를 주고받는 달 장대(交信)
### #5. 陽維脈 郄穴 = 陽交(GB35) · 陰維脈 郄穴 = 築賓(KI9, ★요약본 용빈 오기 주의)
- **물건**: 해 배지 금빛 그물이 교차하는 매듭(陽交) · 귀한 손님을 맞이하려 다진 돌축대(築賓)
- **고리**: 바위 틈(郄) + 해 배지 금빛 그물이 교차하는 매듭(陽交) · 귀한 손님을 맞이하려 다진 돌축대(築賓)
