## 정거장 매핑

### #1. 膽經 원문: 起於目銳眥 → 上抵頭角 下耳後 → 行手少陽之前 至肩上 却交出手少陽之後 入缺盆

- **고리**: 膽經 원문: 起於目銳眥 → 上抵頭角 下耳後 → 行手
### #2. 膽經 원문: 貫膈絡肝屬膽 → 出氣街 繞毛際 橫入髀厭中(環跳) → 下外輔骨之前 直下抵絶骨之端 → 入小指次指之間
- **물건**: 구역 #2의 경락 정본 인물과 상징 소품 (膽經 원문: 貫膈絡肝屬膽 → 出氣街 繞毛際 橫入髀厭中(環跳) → 下外輔骨之前 直下抵絶骨之端 → 入小指次指之間(支者 出大指端 還貫爪甲 出三毛))
- **고리**: 膽經 원문: 貫膈絡肝屬膽 → 出氣街 繞毛際 橫入髀厭
### #3. 肝經 원문: 起於大指叢毛之際 → 上踝八寸 交出太陰之後 → 入毛中 過陰器 抵小腹 挾胃屬肝絡膽
- **물건**: 구역 #3의 경락 정본 인물과 상징 소품 (肝經 원문: 起於大指叢毛之際 → 上踝八寸 交出太陰之後 → 入毛中 過陰器 抵小腹 挾胃屬肝絡膽)
- **고리**: 肝經 원문: 起於大指叢毛之際 → 上踝八寸 交出太陰之
### #4. 肝經 원문: 循喉嚨之後 上入頏顙 連目系 上出額 與督脈會於巔 / 支者 環脣內 / 復從肝 別貫膈 上注肺
- **물건**: 구역 #4의 경락 정본 인물과 상징 소품 (肝經 원문: 循喉嚨之後 上入頏顙 連目系 上出額 與督脈會於巔 / 支者 環脣內 / 復從肝 別貫膈 上注肺)
