# new-jq-08 氣機 — 升降出入과 다섯 실조의 치법 — 설계·제작 기록 (2026-11-11)

- 장소: 공항. 위쪽 정상 운항 = 升降出入 — 기수 든 이륙기(升) · 기수 숙인 착륙기(降) · 노란 셔틀버스에 오르는 셋(出) · 두 문으로 들어가는 줄(入).
