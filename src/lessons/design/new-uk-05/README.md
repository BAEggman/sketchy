# new-uk-05 調經論 寒熱과 損益 — 虛는 外寒·內熱, 盛은 外熱·內寒 → 損其有餘·補其不足 — 설계·제작 기록 (2026-11-11)

- 장소: 눈 덮인 산비탈, 앞벽을 떼어 낸 나무 오두막 네 채(지도의 「겨울 캠핑장 텐트」는 new-zj-23 텐트와 겹쳐 오두막으로 바꿈). 바깥벽 = 外(陽) · 방 안 = 內(陰). 파란 모자 = 補(들여옴) · 빨간 모자 = 損(내감).
- 그림과 뜻:
  - ① 작은 난로 · 바깥벽과 지붕의 서리 · 고드름 · 담요 두른 사람 = 陽虛則外寒(上焦의 陽이 皮膚分肉을 못 데움).
  - ② 눈에 막힌 굴뚝 · 붉은 열기 갇힌 방 · 땀 흘리며 부채질 = 陰虛則內熱(穀氣不盛 · 上焦不行 · 下脘不通 · 胃熱熏胸中).
  - ③ 큰 불 · 못 박은 판자 창과 문 · 창 판자 틈으로 내다보는 갇힌 갈색 개 · 달아오른 바깥벽 = 陽盛則外熱(腠理閉塞 · 玄府不通 · 衛氣不得泄越).
  - ④ 방 한가운데 얼음덩이 · 언 붉은 관 · 가슴 감싸 쥔 사람 = 陰盛則內寒(厥氣上逆 · 寒氣積於胸中 · 血凝泣).
  - 빨간 모자: 찬물 호스 = 熱者寒之 · 난로 들이댐 = 寒者熱之 · 장작 수레 · 얼음 삽 = 덜어 냄 → 損其有餘는 이 正治뿐.
  - 파란 모자: 얼음 집으로 통나무 = 益火之源以消陰翳(陰病治陽) · 마른 통에 물동이 = 壯水之主以制陽光(陽病治陰) → 補其不足(陰陽求 포함). 이름은 補하는 쪽.
  - 외우는 법: 자리는 陽=바깥 · 陰=안, 온도는 盛이면 제 성질 · 虛면 반대.
