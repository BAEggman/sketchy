# new-uk-07 宣明五氣 五氣所病 — 心噫·肺咳·肝語·脾吞·腎欠嚏 (+胃·膽) — 설계·제작 기록 (2026-11-11)

- 장소: 도서관 정숙 열람실. 뒤에 허리 짚고 노려보는 사서, 긴 책상에 일곱 독자(12경 고정 인물)가 저마다 소리를 냄.
- 그림과 뜻:
  - 금관 임금 — 볼 부풀리고 가슴에 손, 입에서 바람 덩이 = 心爲噫(트림). 王冰: 火炎上 烟隨焰出.
  - 흰 옷 노인 — 손수건에 기침 = 肺爲咳.
  - 초록 갑옷 장군 — 잠든 채 입 벌리고 침, 머리 오른쪽 위로 굵은 소리 물결 = 肝爲語(多言 · 譫語). 王冰: 木의 가지처럼 말이 뻗음.
  - 밀짚모자 농부 — 목 움켜쥐고 꿀꺽, 신 얼굴, 레몬 = 脾爲吞(呑酸). 王冰: 土包容 物歸於內.
  - 검은 옷 대머리 장사 — 졸린 하품 + 코의 부채꼴 재채기 물보라와 휴지 더미 = 腎爲欠 爲嚏(腎만 둘).
  - 노란 앞치마 요리사 — 배 움켜쥐고 딸꾹, 입에서 바람 줄기, 겁먹은 눈 = 胃爲氣逆 爲噦 爲恐.
  - 초록 옷 재판관 — 시뻘건 얼굴 · 귀의 김 · 책상 쾅 · 저울 = 膽爲怒(肝在志爲怒와 구별).
  - 大腸小腸爲泄 · 下焦溢爲水 · 膀胱不利爲癃 不約爲遺溺은 글로만.
