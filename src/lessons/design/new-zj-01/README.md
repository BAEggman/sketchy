# new-zj-01 藏象 총론 — 五臟 · 六腑의 갈래와 表裏 — 설계·제작 기록 (2026-11-11)

- 장소: 백화점 단면. 뒤편 창고 = 藏(五臟), 앞 매장 쇼윈도 = 象.
  - new-gr-17(백화점 안내 데스크)과 겹치지 않게, 이 과는 창고와 매장의 단면으로 그렸다.
- 그림과 뜻:
  - 지붕 마디 여섯 대나무 = 六節藏象論.
  - 땅속 주춧돌 넷(해부 모형 · 돋보기 · 약장 · 오색 태극) = 藏象 형성 기초.
  - 자물쇠 쇠창살 금고들(가득 참) = 五臟 藏精氣而不瀉 · 滿而不能實.
  - 속 빈 관 여섯(물건이 지나감) = 六腑 傳化物而不藏 · 實而不能滿. 위아래 뚫림 · 아래로만 = 以通爲用 · 以降爲順.
  - 금고 안 쌀 · 등불 · 붉은 물 · 풍선 · 구름 귀신 · 흰 보자기 = 本藏 藏精神血氣魂魄. 관에서 흐르는 물 = 化水穀而行津液.
  - 앉은 여직원 ↔ 뛰는 남자 = 五臟 靜 · 雌 · 內 ↔ 六腑 動 · 雄 · 外.
  - 금고와 관을 잇는 밧줄 = 表裏(기능 연계 + 經脈 相互屬絡).
