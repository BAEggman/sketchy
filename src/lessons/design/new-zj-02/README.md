# new-zj-02 肝의 기능 — 主疏泄 다섯 방면 · 剛臟 · 藏血의 실조 — 설계·제작 기록 (2026-11-11)

- 장소: 수문 달린 보. 저수지에 가둠 = 藏血, 수문으로 터서 흘려보냄 = 疏泄. 초록 갑옷 장군 = 肝.
- 疏泄:
  - 수문 바퀴 장군 + 사방 풍선 = 氣機 調暢(핵심).
  - 처진 남자 ↔ 소리치는 남자 = 情志(부족 抑鬱 · 太過 急躁易怒).
  - 오르는 농부 · 미끄럼틀로 내려가는 쌀 · 초록 병 재판관 = 脾升胃降 · 膽汁. 창고를 잠그며 장군과 맞당기는 장사 = 腎 封藏과는 제약.
  - 풍선이 끄는 붉은 배 = 氣行則血行.
  - 굽이도는 물길 · 아기 문 황새 = 水液 · 生殖(6기능설의 추가 축).
- 용수철 받침 = 剛臟(將軍之官, 억누르면 亢動).
- 금 간 둑의 붉은 방울 + 베개 안고 떠도는 구름 귀신 = 肝不藏血 → 出血 · 魂不守舍(多夢 · 易驚 · 夢遊).
- 언덕 모닥불(엉킨 밧줄 · 감정 가면 · 화난 가면) = 肝火上炎(鬱結化火 · 暴怒 · 七情).
