# new-zj-03 心의 기능 — 主血脈 · 主神志와 心의 虛證 — 설계·제작 기록 (2026-11-11)

- 장소: 바위섬 등대 단면. 君主之官 神明出焉 — 꼭대기 불빛 = 神志, 탑을 오르는 붉은 관 = 血脈.
- 그림과 뜻:
  - 하트 펌프 → 붉은 관 = 心主血脈(諸血者皆屬於心).
  - 빛에 비친 선원(얼굴 · 눈 · 말 · 몸짓) = 광의의 神. 지도 보는 임금 = 협의의 神(所以任物者謂之心).
  - 먼 꺼진 등대 + 금 간 탑에서 새는 붉은 물 = 心 失常 → 神志 · 血脈. 풀무 노인 = 肺 呼吸.
  - 침실 둘 = 心悸 · 失眠 · 多夢 공통. 하얀 얼굴 = 血虛. 붉은 볼 · 땀 · 손발 불꽃 = 陰虛.
  - 가슴 쥔 고드름 팔 + 관 속 덩어리 = 心陽虛 · 瘀血薄心脈.
  - 솟은 파도 + 꺼져 가는 불 곁 떠는 장사 = 水氣凌心(腎陽虛).
  - 방패병 = 膻中 心包 代心受邪.
- 정거장 9 · 카드 8.
- 바탕: v1 한 번에 씀.
  - drip_v2(붉은 띠 끊기) 코드는 띠 테두리와 풀무가 겹쳐 지저분해 버렸다.
- 일치 검사: ○5 · △3(먼 등대의 붉은 띠가 풀무에 닿음 · 고드름 자리 · 파도 방향) → 글을 그림에 맞춤.
