# new-zj-05 肺의 기능 — 主氣 · 宣發肅降 · 通調水道 · 朝百脈 — 설계·제작 기록 (2026-11-11)

- 장소: 분수 광장. 흰 옷 노인 = 肺가 분수 꼭대기에 섬. 宣發 = 솟아 퍼짐 · 肅降 = 내려옴 · 水道 = 수로 · 朝百脈 = 사방 물줄기가 수반으로.
- 그림과 뜻:
  - 풍선 줄을 다 쥔 노인 = 主一身之氣. 들이쉬고 내쉼 = 司呼吸.
  - 사방 물안개 → 털 울타리(皮毛) · 갈색 강아지(衛氣) · 잿빛 연기 = 宣發.
  - 떨어지는 물 · 빗자루 청소부 · 맑은 공기 = 肅降(氣道 淸潔).
  - 수로 = 通調水道 · 水之上源.
  - 요리사 → 농부 → 노인 → 수로 → 물장수 = 經脈別論 물길.
  - 붉은 물줄기 → 수반 = 朝百脈(朝 = 聚會). 노인이 임금과 붉은 바퀴를 돌림 = 治節 · 助心行血.
  - 벤치 둘 = 肺氣虛 ↔ 肺陰虛(초승달 · 핏자국).
  - 막힌 종 = 金實不鳴, 깨진 종 = 金破不鳴.
