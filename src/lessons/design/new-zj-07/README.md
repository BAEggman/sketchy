    - 밧줄로 탑을 묶는 학자 = 虞摶 兩腎總命門.

    - 활 학자 뒤 요람 문 = 張介賓 子宮 · 精管 · 産門.
    - 지붕 위 약초 학자가 머리 돔에 손을 얹음 = 李時珍 腦爲元神之府(교재: 腦爲命門).
