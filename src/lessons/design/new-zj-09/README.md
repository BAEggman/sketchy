# new-zj-09 六腑 ① 膽 · 胃 · 小腸 · 大腸 — 설계·제작 기록 (2026-11-11)

- 장소: 막걸리 양조장. 受納 · 腐熟 · 泌別淸濁 · 糟粕, 양조의 말이 곧 六腑의 말이다.
- 膽:
  - 저울 곁 도장 찍는 초록 옷 재판관과 줄 선 일꾼 = 中正之官 決斷 · 十一臟取決於膽.
  - 매듭으로 막힌 초록 관 + 습한 김 속 노란 일꾼 = 膽汁 장애 → 黃疸.
- 胃:
  - 곳간 + 바다만 한 술독 = 太倉 · 水穀之海 · 受納 · 腐熟.
  - 곳곳으로 가는 관 · 물 뿌리기 · 마른 항아리 = 六腑之大源 · 喜潤惡燥.
  - 위로 넘치는 작은 통 + 트림 = 胃失和降.
  - 요리사 둘 = 胃氣虛(덜 삭은 통 · 배 아픔) ↔ 胃陰虛(마른 입 · 먹지 못함).
- 小腸: 체 든 붉은 앞치마 = 受盛之官 化物. 맑은 술 위로 · 물은 물장수 · 지게미는 수레 = 泌別淸濁 · 小腸主液.
- 大腸: 지게미 수레를 끌고 나가는 흰 작업복, 수레 밑으로 떨어지는 물 = 傳道之官 · 大腸主津.
