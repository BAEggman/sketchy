# new-zj-12 七衝門 · 咽喉 — 소화관의 일곱 관문과 몸의 문 — 설계·제작 기록 (2026-11-11)

- 장소: 운하 갑문. 쌀자루 실은 배(음식)가 왼쪽에서 오른쪽으로 곧은 운하 하나를 따라 일곱 문을 차례로 지난다(難經 四十四難).
- 그림과 뜻:
  - 날개 달린 입술 문 = 飛門(脣) · 이빨 문 = 戶門(齒) · 덮개 문 = 吸門(會厭).
  - 넓어진 물길(저수지) = 胃 — 왼쪽 위 들어가는 문 = 賁門(胃上口), 오른쪽 아래 나오는 문 = 幽門(胃下口).
  - 나무 난간 문 = 闌門 · 흰 보자기 귀신(魄) 곁 통판 나무문 = 魄門.
  - 덮개 문에서 갈림: 배가 가는 물길 = 咽 水穀之道, 물 없는 유리관으로 오르는 풍선 = 喉 氣之上下, 덮개 위 종 · 나팔 = 會厭 音聲之戶.
  - 덮개 위 약상자 = 會厭은 身之藥籠(짝: 木喜條達 = 肝主疏泄).
  - 마지막 문의 밧줄 다섯을 임금 · 장사 · 노인 · 농부 · 장군이 당김 = 魄門亦爲五臟使.
  - 구멍 숭숭한 갑문지기 집(김 · 작은 귀신 · 어두운 문) = 汗孔의 다른 이름 玄府 · 氣門 · 元府 · 鬼門 · 魄戶.
- 정거장 7 · 카드 5.
