# new-zj-13 臟腑 相關 ① 氣·血·水로 묶인 짝 — 心肺·心脾·肺脾·肺腎 — 설계·제작 기록 (2026-11-11)

- 장소: 가을 운동회 이인삼각. 발목을 묶은 끈 = 相關(서로 묶임). 레인 넷이 장부 짝 넷.
- 그림과 뜻:
  - 1레인 임금(붉은 양동이) + 노인(풍선), 노인의 금빛 구름이 양동이를 감쌈 = 心肺 氣血 관계 · 宗氣 貫心脈.
  - 2레인 농부가 쌀자루에서 붉은 물을 따라 임금의 솥을 채움, 솥에 가죽 띠 = 心脾 — 脾生血 · 心 운행 · 脾統血.
  - 앞쪽 쓰러진 짝: 튀는 하트 心悸 · 풀리는 붉은 실 健忘 · 밀어낸 밥그릇 食少 = 心脾兩虛 / 빈 솥 · 빠진 풍선 = 氣血兩虧 · 빈 쌀자루 = 血虛의 뿌리 脾虛.
  - 3레인 노인 숨 줄기 + 농부 밥그릇 김 줄기 → 한 금빛 구름 = 宗氣(淸氣 + 水穀精氣) / 밥그릇의 끈적이가 관을 타고 노인 등 유리병으로 = 脾爲生痰之源 · 肺爲貯痰之器.
  - 4레인 노인 물뿌리개 → 장사 물통 = 肺爲水之上源 · 腎主水 / 장사가 숨 공을 배에 끌어안음 = 肺主呼吸 · 腎主納氣.
  - 오른쪽 큰 공을 노인(바람) · 농부(김) · 장사(밧줄) 셋이 부풀림 = 氣 생성은 肺 · 脾 · 腎 협동(肺者氣之本만으로 못 묶음).
