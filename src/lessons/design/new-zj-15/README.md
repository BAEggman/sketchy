# new-zj-15 ~之府 · ~之餘 — 몸의 별칭 대조표 — 설계·제작 기록 (2026-11-11)

- 장소: 기차역 물품 보관소. 府 = 넣어 두는 곳(사물함 칸에 든 것이 「무엇之府」), 餘 = 넘쳐 남은 것(분실물 바구니).
- 그림과 뜻:
  - 윗줄 = 脈要精微論 五府: 빛나는 눈 머리 頭 精明 · 창으로 심장 · 폐 보이는 등 背 胸中 · 허리띠 위 장사 腰 腎 · 밧줄 감은 굽힌 다리 무릎 膝 筋 · 골수 뼈 骨 髓.
  - 가운데 줄: 붉은 관 脈 血之府 · 등불 든 뇌 腦 元神之府 · 솔로 밀어 보내는 흰 작업복 大腸 傳道 · 체 들고 받는 붉은 앞치마 小腸 受盛 · 맑은 초록 즙 재판관 膽 中精.
  - 아랫줄: 곡식 자루 요리사 胃 五穀 · 물지게 물장수 膀胱 津液 · 혼자 도랑 파는 주황 인부 三焦 中瀆 · 孤腑 · 물동이와 횃불 장사 腎 水火之宅. (둘째 칸은 빈 칸)
  - 요리사 칸에서 넘친 물 · 쌀 · 붉은 물의 바다와 떠오르는 풍선 = 胃 水穀氣血之海(靈樞 玉版).
  - 분실물: 꼰 초록 밧줄 끝 분홍 손톱 = 爪 筋之餘 · 붉은 물 병의 머리카락 = 髮 血之餘 · 뼈 끝의 이 = 齒 骨之餘.
- 정거장 11 · 카드 9.
- 카드 의심:
  - JSG-008은 髓之府 = 腦라 답한다. 脈要精微論 원문은 骨者髓之府(腦는 髓之海) — 정거장 2에 밝힘.
  - JSG3-012는 水穀氣血之海 = 衝脈이라 답한다. 靈樞 玉版은 胃者水穀氣血之海, 海論은 衝脈 = 十二經之海 — 정거장 9에 밝힘.
