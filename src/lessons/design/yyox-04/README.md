# yyox-04 五行의 자리와 수 — 설계·제작 기록 (2026-11-10)

- 장소: 지도처럼 본 다섯 구역 과수원 — 위 검은 못(北 水) · 아래 붉은 모닥불(南 火) · 오른쪽 초록 나무(東 木) · 왼쪽 흰 연장 걸이(西 金) · 가운데 누런 흙(中央 土). 정거장 10 · 카드 6.
- 수: 구역마다 흰 판의 점 = 生數(1·2·3·4·5), 成數 = 生數 + 가운데 흙의 5. 점 수대로 세면 生成 순서 水火木金土.
- 相生 = 못의 물을 나무에 붓는 정원사(水生木 한 마디) · 相剋 = 나무에 박힌 쇠도끼(金剋木 한 마디).
- 바탕: Gemini 한 턴 → 편집 1회(오른쪽 판 점 4 → 3: 「오른쪽 위 점을 지워라」 · 가운데 레몬 같은 덩이 → 삽 꽂힌 흙무더기).
- 일치 검사 1차: ✗2(오른쪽 판 점이 4개) · △3 → 편집 뒤 재검 전부 ○, 점 수 1·2·3·4·5 확인.
- 배운 것: 개수는 「주사위 눈 같은 흰 판」으로 시키면 1~5가 한 번에 거의 맞고, 틀린 것은 「이 점을 지워라」로 고친다.
