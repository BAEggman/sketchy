- 장소: 씨름판 셋과 긴 의자. 정거장 10 · 카드 15.
- **지도는 정거장 12였으나 制化와 亢害承制, 勝復과 子復母仇를 한 정거장씩으로 합쳤다**(같은 물건 — 으스대는 장군 / 샅바를 당기는 노인 — 이 두 사실을 함께 진다). 카드 대조는 빠짐·남음 없음.
