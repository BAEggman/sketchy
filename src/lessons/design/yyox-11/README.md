# yyox-11 八卦 ① 여덟 괘의 象 — 설계·제작 기록 (2026-11-10)

- 장소: 여덟 폭 병풍 앞 대가족 잔칫상. 정거장 10 · 카드 16.
- 사람 = 家族, 병풍 그림 = 自然, 유난히 큰 몸 한 곳 = 近取諸身. 왼쪽부터 艮(막내아들·손·산) · 坎(둘째 아들·귀·물) · 震(맏아들·발·번개) · 乾(아버지·머리·하늘) · 坤(어머니·배·밭) · 巽(맏딸·넓적다리·바람) · 離(둘째 딸·눈·불) · 兌(막내딸·입·못).
- 정거장 차례는 부모 → 아들(가운데서 왼쪽으로) → 딸(가운데서 오른쪽으로). 지도의 차례(乾坤坎離艮兌震巽)와 다르지만 카드는 같다.
- 이 여덟 식구는 八卦 공용 인물로 예약한다.
- 바탕: Gemini 한 턴 → 편집 2회(아버지 머리·어머니 배·막내 손을 키움 → 머리를 조금 줄여 하늘 폭이 보이게, base_v3 최종).
- 일치 검사: ○9.
- **남은 약점**: 앉은 줄이 병풍보다 넓어 딸 셋이 제 폭보다 한 칸쯤 오른쪽에 앉았다. 병풍을 넓히는 편집·족자로 바꾸는 편집 모두 자리는 그대로였다(위치 편집은 잘 안 된다). 그래서 정거장 상자가 사람과 제 폭을 함께 짚고, 글이 「여섯째 폭」처럼 차례를 말한다.
