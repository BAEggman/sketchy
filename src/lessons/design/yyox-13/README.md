# yyox-13 八卦 ③ 後天(文王) — 설계·제작 기록 (2026-11-10)

- 장소: 물 위에 누워 도는 여덟 모 물레바퀴. 정거장 12 · 카드 9.
- 방향은 yyox-12와 같이 **위 = 南 · 왼쪽 = 東**. 칸마다 하늘이 하루의 때를 보여 준다 — 왼쪽 해돋이(東) · 위 한낮(南) · 오른쪽 노을(西) · 아래 한밤(北).
- 자줏빛 옷에 금관의 임금 = 帝. 칸마다 같은 임금이 그 칸의 동사를 한다 — 대문 나서기(出) · 자로 모종 맞추기(齊) · 꿩과 눈 맞추기(相見) · 소로 밭 갈기(致役) · 과일 안고 웃기(說) · 그림자와 칼싸움(戰) · 지쳐 주저앉기(勞) · 돌탑 마지막 돌(成). 왼쪽에서 시계 방향.
- 꿩(離爲雉)과 소(坤爲牛)는 說卦傳의 짐승과 맞는다. 처음엔 거울이었으나 거울은 hist-06·07·13에서 鑑·鏡이라 꿩으로 바꿨다.
