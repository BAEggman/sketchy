# yyox-14 五運六氣 ① 干支 五行과 同化年 — 설계·제작 기록 (2026-11-10)

- 장소: 六十甲子 관청 마당. 정거장 11 · 카드 8.
- 깃발 다섯 쌍(큰 것 = 형, 작은 것 = 아우) = 天干 형제배속. 색 방석 다섯의 열두 짐승 = 地支 五行 — 방석 자리는 지도 관례(오른쪽 = 東 木 · 앞 = 南 火 · 왼쪽 = 西 金 · 뒤 = 北 水 · 가운데 = 土).
- 옷 색 = 그해의 運. 머리 위(휘장·일산) = 司天, 깔고 앉은 방석 = 年支, 돌샘 = 在泉. 같은 색이 겹치는 곳이 同化의 종류다 — 판관(휘장) 天符 · 관리(방석) 歲會 · 귀인(일산 + 방석) 太一天符 · 샘가 큰 어른 同天符(太過) · 작은 아이 同歲會(不及).
- 손에 든 것 = 벼슬 — 방망이(執法) · 나팔(行令). 샘가 두 사람도 같은 것을 들어 급이 같음을 보인다.
- 금방울 넷(말·소·양·닭) = 太一天符의 해. 나팔만 든 토끼·쥐 = 순수 歲會(丁卯·丙子).
- 초 셋의 타는 모양 = 병세(速而危 · 徐而持 · 暴而死).
- 바탕: Gemini 한 턴 → 편집 2회(남는 검정 방석과 닭 두 마리 지움 + 토끼·쥐 표지 → 손 깃발을 놋쇠 나팔로: 지붕 깃발 = 天干과 한 그림에서 겹치지 않게, base_v3 최종).
- 일치 검사: ○10 — 깃발 10 · 짐승 12(겹침 없음) · 방울 4 · 초 3 확인.
