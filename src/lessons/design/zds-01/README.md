# zds-01 肝 — 설계·제작 기록 (2026-11-10)

- 장소: 바람 부는 시골 간이역 승강장(간이역의 「간」 = 肝). 정거장 8 · 카드 10.
- 한 사람(五臟 인물 肝 = 초록 갑옷 장군)의 몸에 여섯을 나눠 실었다 — 손톱의 꽃(華爪) · 활시위(充筋, 활 = 筋은 yyox-06과 같은 뜻) · 목의 쌍안경(竅目) · 바람 쪽 판자 울(惡風, 정지된 대항 사물) · 눈물과 손수건(淚) · 붕대와 점점 닳은 짚신 셋(久行傷筋, 짚신 셋 = 久는 옛 허브 문법).
- 장부 다섯 과(zds-01~05)는 같은 자리 순서: 華 · 充 · 竅 · 惡 · 液 · 勞. 각 과의 내레이션이 다섯 장부 전체 표(五華 · 五體 · 五液 · 五惡 · 五勞)를 한 번씩 되풀이한다 — 범주 카드가 다섯 과에 다 걸려 있다.
