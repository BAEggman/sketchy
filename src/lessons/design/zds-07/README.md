# zds-07 장부병리 감별 ① — 설계·제작 기록 (2026-11-10)

- 장소: 밤의 대중목욕탕 단면. 정거장 9 · 카드 13.
- 가운데 온탕(물) 바로 밑의 아궁이(불) = 心腎相交 · 水火旣濟(周易 旣濟 = 물 위 불 아래). 앞 마루에 잠 못 드는 임금과 黃連阿膠湯 사발 = 心腎不交(心煩不得臥, 傷寒論 少陰病).
- **같은 火의 두 갈래**: 임금(心)의 새빨간 혀끝·입 헌데 = 心火(혀) / 장군(肝)의 붉게 부은 눈·버럭 = 肝火(눈).
- **같은 腎의 두 갈래**(대머리 둘): 냉탕 = 腎陽虛(畏寒·浮腫·허연 두툼한 혀) / 달 뜬 한증막 = 腎陰虛(五心煩熱·盜汗·顴紅·붉고 가는 혀).
- 바탕: Gemini 한 턴 → 편집 1회(임금 혀끝 · 인삼처럼 보이던 뿌리를 닭발 같은 黃連으로 · 한증막 손바닥, v2 최종).
