# zds-14 六經 ① 三陽 — 설계·제작 기록 (2026-11-10)

- 장소: 늦은 오후의 한옥 — 왼쪽 대문 밖(太陽·表) · 가운데 문간(少陽·半表半裏) · 오른쪽 안마당(陽明·裏). 정거장 14 · 카드 14.
- **자리는 깊이 차례(太陽→少陽→陽明), 정거장은 傳經 차례(太陽→陽明→少陽)** — 과 지도의 경고대로 하나는 자리로, 하나는 내레이션으로 준다(zds-15의 循經傳과 맞춤).
- 太陽: 목덜미 잡고 떠는 두 남자(提綱) — 땀+계피 = 中風 表虛 桂枝湯 / 땀 없음+입김+마황 = 傷寒 表實 麻黃湯. 陽明: 큰 사발 + 흰 호랑이 = 經證 四大 白虎湯 / 해 질 녘 + 북 같은 배 = 腑證 承氣湯, 배가 말랑(淸) ↔ 단단(下). 少陽: 문간의 반 얼음 반 불(寒熱往來) · 갈비 아래(胸脇苦滿) · 쓴 입과 소용돌이 눈(口苦 咽乾 目眩) · 땔나무(柴 = 小柴胡湯).
- 흰 호랑이 = 白虎湯(yyox-14 地支의 띠 호랑이와 구별: 흰색). 얼음 = 寒 · 불 = 熱은 zds-07·12·13과 같은 뜻.
