# 한의학 Sketchy 예약표 — 물건 = 뜻 = 쓴 과

새 물건을 설계에 넣기 전에 이 표와 다른 과의 설계 문서에서 그 낱말을 찾는다(지침 9·24항). 과가 끝나면 새 상징을 한 줄씩 넣는다. 한 물건 = 뜻 하나, 예외 조항 없음.

생물학 덱(같은 사람이 봄)에서 이미 뜻이 정해진 물건 — 같은 뜻일 때만 빌린다: 동전 = ATP · 흰 방울 = O₂ · 연기 꼬리 단 어두운 방울 = CO₂ · 붉은 벽돌 건물 = 간 · 문 없는 돔 건물 = 뇌 · 초승달 = CAM · 노란 반달 = 반달판막 · 이층 집 = 심장 · 유턴 금지 표지판 = 판막 · 물레방아 = ATP 합성효소 · 돔 천막 = 핵 · 콩 모양 통 = 미토콘드리아 · 금색 자물쇠 = 저해 약물. 한의학 장부는 해부 장기 상징을 빌리지 않는다.
