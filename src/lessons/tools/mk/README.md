- `../lesson_kit.py` — 과 하나를 마무리하는 공용 도구(작업 때는 `lk`라는 이름으로 불러 썼다): 캡처 저장(`shot`) · 상자 환산(`bx`) · 과 JSON 쓰기와 카드 대조·검사 목록·음성 대본(`finish`) · 예약표 줄 넣기(`reserve`) · **획·점 타일 덧그림(`overlay`)**.
